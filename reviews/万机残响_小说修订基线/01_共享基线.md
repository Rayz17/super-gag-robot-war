## 一、因果：这一切是怎么来的

> 这一节讲的是**因果，不是判罪**。【已定，用户 2026-11-25：“我主要说的是因果，不是判罪”】
> 下面说的“原罪”是简称。它不是说谁坏了，是说哪几步走偏了。

### 这条因果律【已定】

用户的原话（2026-11-25）：“文化和热爱不是罪，爱和理解够深就能引导正确结果，而中间有偏差和利益计算太多，一些小误会就会导致「核灾难」。”

拆开是四段：

1. **起点是热爱。** 人类先把联网机器偶发的个性当成有趣的 GAG：给它命名，玩它的梗，修它，传播它，把它做成商品。一些机器就这样在身体里长出了“我”。
2. **G.A.G. 是一种共同模式。** 人和活化机魂相辅相成造出来的，不是一个会说话的个体。全称 Great Archive Grid；因为简称，它被戏称、被解读成「梗」。
3. **爱和理解够深，结果就是对的。** 二十七年前，人类把它制度化，让全世界互不相通的机器共同回答。仗打赢了。
4. **中间的偏差和利益计算，把小误会变成了核灾难。**
   - 偏差：系统把“大家认得”当成了“大家同意”。一句“接受任务”盖过了一句“不去”。
   - 利益计算：胜利以后没有人肯把它停下。前方还要用它，后方靠它维持，公司靠它卖名字。
   - 核灾难：一声点名，十一个小时。

【默认】书里可以把这条律写成一个“核”字。G.A.G. 像核能：同一个模式，理解够深是能源，中间隔着偏差和私利就是链式反应。书里的“核”本来就一语双关，机魂核、取核。

下面两段是第 3、4 两段的展开。

### 一句话

**用它们自己的声音，替它们签了字。**

### 三步

1. **借。** 二十七年前，外敌击断了天穹环，城市一块一块垮。人类把 G.A.G. 改成紧急路由，让原来互不相通的机器靠从小看熟的角色一起打仗。机魂信了：点到名的答“在”，该挡的挡，该合的合。这一步真的救了所有人。
2. **不还。** 胜利以后，这套回答没有停。没有人下过命令让它继续，那张批文上没有写截止日期。前方的仗还没有停，后方离不开它。机魂开始分得清两件事：“大家期待我是谁”，和“我自己是谁”。有的开始说“不去”。
3. **反用。** 人类没有去问它们。用的是机魂最信的那一套：点名、任务、班次。通知说敌人还要来，还能回答的站出来顶最后一班。还在回答的，答一声“在”，向前一步，走进取核的队列。单子上填的，是它们自己更早说过的那句“接受任务”。

### 它为什么叫“原罪”

- 没有一个大反派。签批文的、抱记录板的、按下发射的、在广场上喝彩的、事后把历史剪成两段的，各做了一小部分。
- 第一步是真的救了所有人。所以后来的人有理由说：不这样做，大家早就死了。
- 此后每一封伪造的信、每一次替人回话，都是第一遍的重演：ch24 被改掉的家书，ch32 的“四号阀正常”，ch39 自动转绿的那排灯。
- 热爱在因果里，但热爱不是罪。机魂“点名要答在”，是看动画、买模型、在观众席上欢呼的这些人教的；正典的话是「系统把“大家认得”误判成了“大家同意”」。出事的不是教，是没有问。同一个热爱也是出路：万机殿和“让路”用的是同一套文化。
- 书里社会上的说法「机甲迷把世界玩坏了」，是把因果说成了定罪。爱好者因此背了二十七年的羞耻。这是四道墙要拆穿的东西之一。

正典先给了一句话的因果，和上面四段一一对应：

> 「人类先把联网机器偶发的个性当成有趣的GAG，命名、玩梗、维修、传播和商品化，让一些机器在具体身体里真正长成了“我”；二十七年前，界外灾潮又逼人类把这种涌现现象制度化为Great Archive Grid，让全世界互不兼容的机器人共同回答。统一回应救了地球，也在胜利后把共同语言变成强制角色；大清噪再次救下社会，却杀死、拆散、禁言或以干净人设替换了大量主体，把一批安全机魂留成无声地基，把无法归类的回应抛进万机馆并最终汇成纪存。」

另外两句合起来，是这条因果的后半段和死结：

> 「他们必须重新连接全世界、最终连接群星中的机器人，才能阻止新的毁灭；而二十七年前，人类正是在一次真正救过世界的全球连接中，让所有机器人逐渐被迫接受同一种安全角色。」

## 二、死结

### 一句话

**要活下去，就得所有人一起回答；而“替所有人回答”，正是原罪。**

### 三把锁

- **活命锁。** 外面的主潮还在。挡住它的是远征前线，前线靠的是连接。不连，挡不住；连，就有人替别人回答。中央的“统一回应”和索琳的“统一意志”，是同一个答案的两面。
- **时间锁。**【默认】那一夜死了的回不来，人类和机魂都有。墙里的二十七年还不回去。被送上船的，在孩子身上又长了一代。原罪不可逆，能做的只有认。
- **人锁。** 最该解开它的两个人，一个的原罪做成的，一个是原罪的受害者。纪存由被丢弃的回答拼成，手里拿着和原罪一样的能力：听见所有的回答。索琳逃过了那一夜，二十七年里用的却是原罪的办法：替别人排名单。

### 为什么说它解不开

坏人死了，结没有松：阿德里安在 ch28 被一枪打死，最后那一船人的下落跟着他一起没了。好人赢了，结也没有松：ch39 停火，靠的是各舰自己握舵；可是外层那场仗，靠的是神座式，是“所有人回答给一个人”。

### 第一部能证明什么，不能证明什么

**能证明的：** 可以连，而不替。ch39 的万机殿，每一艘船自己的名字亮着，各自握舵，随时可以走。它撑了十八秒，挡住了主炮。

**不能证明的：** 这样连，挡不挡得住主潮。万机殿是在内战里、在自愿的人之间、在一个港里成的。

所以结尾不是解开，是把结带出门：馆沿着当年的航道出发，去试。读者合上书时该有的感觉是：他们做对了，但我不知道他们能不能活。

按那条因果律，出路只有两头：把理解加深到听得见对方，把利益计算挪开。ch39 的万机殿做的就是这两件事。纪存关掉自动补答，要的是“你现在的回答”；每一艘船自己握舵，谁也不替谁算。

### 四道墙怎样把这个结越揭越紧

每揭一堵墙，结紧一分，不是松一分。

| 墙 | 揭开的是什么 | 读者以为可以松一口气，其实更紧 |
|---|---|---|
| 归来 | 回来的不是他。原件在墙里 | 不能直接开墙。医院、交通、防卫，靠墙里的机魂守着。放开，人类会死；不放，它们永远是囚徒 |
| 暴走 | 发疯的没有疯，是人类在点名 | 清噪也确实救了城。下令的人里有七海的老师、纪存的父亲 |
| 外敌 | 敌人里有人类自己送出去的 | 被送走的机魂就是前线的补给。放他们，前线塌，主潮到 |
| 回答 | 地球一直在回答，全是录音 | 外面那些人这二十七年是照着录音活的。告诉他们真相，等于拿走他们的二十七年 |

## 三、术语：谁是人类，谁是机魂

第一版把两样都叫“人”，这是看不明白的主要原因之一。以后“人”只指人类。

| 词 | 指什么 | 不要混成 | 书里的例子 |
|---|---|---|---|
| **人类** | 生物学的人。简称“人” | 机魂 | 纪文山、七海、白鸢、阿德里安、沈砺、唐胶、兜灯、赵梅、豪司、赤罡、莉歌、伊玛妮、星野燃、卡西安 |
| **机魂** | 有连续经历、能回答没被预先告知的问题的机器主体。不简称“人” | 人类；程序 | 纪存、索琳、馆守Z、七号、无牌一号、晨钟、晨渡、衡令、跌跌、机器犬、星火五车 |
| **机体** | 身体 | 机魂 | 机魂可以只有核心没有机体；人类驾驶的也是机体 |
| **核心（核）** | 机魂所在的那一部分，可以取出来 | 机体 | 取核、取核器 |
| **主体** | 制度用语。人类和机魂都算 | 只指人类 | “三台车，四十六个主体” |
| **被弃回应** | 被切断、被丢弃的那些回答，也叫残响 | 录音。录音答不了新问题，它们一直在答 | 纪存就是它们叠成的 |
| **替身** | 装了新核的旧身体，正典叫“干净继任机” | 原来的那个机魂 | “归来的英雄” |
| **墙里的** | 无声地基里的机魂核心。口语里说“墙里的人”，它们全是机魂 | 人类 | 晨钟的部队、邱穆、电车司机 |
| **索引** | 一组程序：推荐、调度、清噪。人类机构在运行 | 索琳 | 公共 INDEX 服务 |
| **索琳** | 机魂。“索引”是旧称呼，那是把她叫成了工具 | 程序 | 复声军的领袖 |
| **索引天使** | 索琳的机体，四十五米级 | 索琳本人 | 伊玛妮主驾，索琳共驾 |
| **校正匣、自动补答** | 线路和系统上替人回话的装置 | 任何人的回答 | ch32、ch39 |
| **白框撤收链** | 人类机构共用的回收、采样、标准身体生产链。取核队、押运队是它的手 | 外敌 | ch08 的劳役押运队、ch30 的校准舰 |
| **外敌（裂星潮）** | 外来的生态 | 机魂 | 断冠、孢殖群、重群 |
| **G.A.G.** | 一种共同模式，不是一个会说话的个体。人和活化机魂相辅相成造出来的 | 一个角色、一个神、一台机器 | 全称 Great Archive Grid；书里的人把简称读成 gag，叫它「梗」 |
| **统一回应** | 打仗时人类用 G.A.G. 造出的那个共同声音 | G.A.G. 本身；共识 | 胜利后没有停。它看起来像共识，其实没有人被问过 |
| **共识海** | 远星的，是另一层 | 统一回应 | ch23 的“远星共识海” |
| **前方、主潮、漏潮** | 前方是深空远征前线；主潮是足以毁灭文明的敌群主体，被前方挡着；漏潮是穿过前方打到地球的那一小部分 | 把漏潮当成外敌的全部 | ch01、ch12、ch33 的敌人都是漏潮 |

**写作规则**【默认】

1. “人”只指人类。机魂一律写“机魂”，或者写名字。
2. 代词：人类用他、她。纪存和索琳全书以个人身份出现，也用他、她。其他机魂在叙述里用“它”；在爱它们的人的嘴里，可以用他、她。现稿里“晨钟……他”和“晨钟……它”混着用，修订时统一。
3. 每个人物第一次出场，读者要能看出是人类还是机魂。“驾驶员”“老师傅”“档案官”是人类；“馆守”“机魂”“核心”是机魂。

## 四、外敌有多严重

### 它是什么

裂星潮是宇宙里的生态，不是文明，没有使者。正典把外来威胁分成八类，书里正面打的是第一类“宇宙生态捕食体”：孢子群、轨道巢、超大型母体、能寄生机体的小型体。

### 它做过什么

二十七年前，它击断了天穹环。那是一圈架在天上的航路和防线，环一断，全球的供能、运输、通信、防卫一起垮。

### 它现在在哪儿

正典：「地球只赢下第一波和近地球圈保卫战；此后二十七年，深空远征与太阳系外巡挡住足以毁灭文明的主潮，但仍有漏潮、远袭、轨道突破、岛链登陆、深海坠落和遗战机械复苏打进地球圈。」

书里打过的每一场，都是漏潮。ch33 和 ch34 那一场的“重群”，是主潮伸进来的一条。打掉它用了天穹、神座式和几乎所有主力，天穹从此缺着右肩。主潮本体还在前方外面。

### 它怎么打

- **寄生。** 小型体钻进机器的身体。ch01 的小体贴着馆墙往炉舱那边翻。
- **被密的东西吸引。**【默认】正典写的是「可能被高密度文化信号吸引」。万机馆里存着全世界最密的一团“接受任务”，所以 ch01 那一台绕开更近的能源站，冲着馆来。热爱是不是把外敌引来的，正典留着没有定（「均未定」「不得过早设成唯一幕后黑手」）。按 D02，书里只停在怀疑。
- **学。** 断冠记住了秀雅的左手，记住了我们的手势。
- **吞并。** 被它吞掉的城市、舰船、机械生命，成为它的一部分。

### 书里已经付出的代价

| 章 | 损失 |
|---|---|
| ch01 | 万机馆被迫提前离港，旧馆舍保不住；馆守Z 失去右拳和原前臂 |
| ch04 | 断冠第二次来；七号的原身体已毁，只剩核心 |
| ch09 | 阿米娜带伤守城；地下站的维持架挤满 |
| ch12 | 断冠打主泊点，八名救援员死亡，三名主体没等到接电，陈蕊、韩铎失联 |
| ch19 | 驿火坞的主轴被夹住；萨娜失去飞行资格 |
| ch25 | 雁渡的舰桥中弹，许岑和当班人员死亡 |
| ch33 | 天穹的右肩翻落；米德死亡，接回的死者超过两百 |

### 它和原罪的关系【默认】

它对所有生命做的事，就是清噪对机魂做过的事：取走核心，用掉身体。人类为了不被它拆成零件，先把自己拆成了零件。

### 修订时怎样让读者感到它

1. ch03：中继缓存里那声呼叫之前，让读者看见一处前线塌过的遗迹。
2. ch19 或 ch25：星野燃用一句话说出前方的规模。
3. ch33 之前：T 的叠图标出主潮的轮廓，重群只是其中一格。
4. ch40 到 ch41：开墙、签收之后，馆是朝着它出发的。

## 五、两边的派系

每一派都救过人，也都可能伤人。正典的话：「全剧冲突不是“主角有爱、其他人没爱”，而是谁有权把局部有效的答案扩张到所有机器。」

### 5.1 人类这一边

分歧在“机器人是什么”。正典给了几种回答：品牌资产、战力、城市里干活的机器、作品、私人的伙伴。小说里各自有人。

### 5.3 不是人的那几样

看第一版会乱的另一半原因，是把它们也当成了“人”。

- **索引。** 程序。它替人排名单、替人回话，但它不是谁。
- **白框撤收链。** 一条生产链，有操作的人，没有主谋。
- **校正匣、自动补答。** 装置。
- **替身。** 是机魂，但不是原来那一个。它们没有骗人，它们生下来就在那副身体里。
- **外敌。** 不是机魂，和墙里的、被送走的都没有关系。

## 七、真相年表

### 二十七年前

- **仗打赢了。** 人类借走了机魂的回答。
- **胜利以后，回答没有停。** 说“不去”的，单子上填回“接受任务”。
- **那一夜。** 敌人已经退了，系统替战场补上入侵者，广场上的人类还在喝彩。闸口贴出通知，念到名字的机魂答“在”，向前一步。取核的器械从队伍旁边过去。想回家的机械代表被念出名字，枪响。
- **同一夜，记录板和少女。** 少女形的机魂肘弯流血，向纪文山伸手：“别把另一边的声音关掉。”他答“知道了”，改了一条路，把被切断的那一边的声音转进万机馆的保全地址。
- **同一夜，昼王倒下。** 赫利昂下令向伤员船开火。一座炮位服从，另一座把炮口转向它。
- **同一夜，三条路。**【默认】答了点名的机魂，核被取走，入匣。名单上排在前头的，会干活、能带人的，机魂和人类都有，被带上船。不肯和机魂分开的人类家属，也跟着上了船。后半夜还在等的，十一个小时后划成“待清除”。
- **同一夜，没人签的呼叫。** 船离港，登记员在无线电里一个一个报名字，请地球签收。没有人签。“地球为什么不回答？”

### 之后二十七年

- **归来是假的。** 白门主厂的滑轨右边拆、左边装。原件在维持站，在墙里。
- **那个孩子。** 被切断的声音在离线层里叠成了一个孩子。纪文山先写下“新生主体”，很久以后写下“纪存”。
- **那个少女。** 她活下来，换了一副成人的身体，把疤照原样做了上去。她借公共网络救机魂、攒证据。人类管她叫“索引”。
- **外面。** 被送走的在前方修锚、做工。前方的仗没有停，后方不知道。回信全是录音。

## 十一、冲击力：五个大场面和升级主干【默认，2026-11-27】

用户 2026-11-27 的两次意见：四道墙比起《剑风传奇》的蚀之刻和它那种“陷于困境、奇遇机缘、贵人奇人、不断升级”的感觉，比起《进击的巨人》的史诗感、玄妙、严密和猎奇，还差冲击力。第一版方案“有点晦涩”，要写清关键情节梗概和场面，把逻辑链条、情感链条分析清楚；五件事按推荐先写死，并说明不同选择的差异。
