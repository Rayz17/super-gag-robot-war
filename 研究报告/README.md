## 本版定位

这是“可持续扩写”的百科初版加第二层资料库，不是逐话台词抄本。它完成四件事：

- 把系列从 1991 年 Game Boy 初代到 2025 年《超级机器人大战Y》的主干历史、系统演进和叙事机制串起来。
- 按作品给出“参战剧情如何被改写、并入、互相缝合”的索引式说明。
- 把官方资料、攻略数据库、媒体评测、B 站/YouTube/机核等玩家资料分层，避免把玩家共识误写成官方设定。
- 建立 `data/*.tsv` 结构化表格，方便继续扩展成按作品、原作、剧情改写、玩家资料互相检索的知识库。

## 数据表入口

- [data/titles.tsv](./data/titles.tsv)：主要作品年表和串联模型。
- [data/roster_matrix_modern.tsv](./data/roster_matrix_modern.tsv)：代表性参战作品矩阵。
- [data/crossover_story_index.tsv](./data/crossover_story_index.tsv)：剧情采用、改写与串联索引。
- [data/franchise_roles.tsv](./data/franchise_roles.tsv)：参战作品家族功能分类。
- [data/community_sources.tsv](./data/community_sources.tsv)：官方、媒体、玩家资料入口。

## 核心结论一句话版

《超级机器人大战》的真正魅力不是“把机器人放一起打架”，而是把不同作品的战争、神话、青春创伤、末日危机和名场面，压缩进一支临时联合部队的旅程里；玩家每打一关，看的其实是“如果这些作品的人物真的彼此认识，世界会怎样被改写”。
