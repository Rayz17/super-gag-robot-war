# 03. 参战作品、梗点与玩家接受史

## 1. 参战作品的功能分类

SRW 的参战作品不是平等地“复刻原作”。每部作品在剧本里承担不同功能。

| 功能 | 代表作品 | 在 SRW 中的作用 |
| --- | --- | --- |
| 基石 | Mazinger、Getter、UC Gundam | 维持系列传统，提供前辈、超级能源、战争政治 |
| 政治战争 | Gundam UC/SEED/00/Code Geass | 提供阵营、军队、殖民地、革命、种族矛盾 |
| 宇宙航行 | Macross、Yamato、Harlock、Nadesico | 提供远航主线、移民船团、宇宙文明接触 |
| 都市防卫 | Evangelion、RahXephon、Gridman、J-Decker | 提供城市、组织、怪兽/使徒/异常事件 |
| 神话/末日 | Ideon、Gunbuster、Gurren Lagann、Aquarion、Demonbane | 推高世界毁灭级风险 |
| 异世界/奇幻 | Dunbine、Wataru、Rayearth、Ryu Knight、Escaflowne 类参战气质 | 解决世界观互斥，强化冒险感 |
| 职业/公路片 | Cowboy Bebop、Gun x Sword、VOTOMS、Patlabor | 降低救世主神话，提供成人社会视角 |
| 勇者/儿童英雄 | GaoGaiGar、Brave 系、Eldran、J-Decker | 提供勇气、友情、少年社群与城市守护 |
| 实验/边界扩张 | Godzilla S.P、ULTRAMAN、Sakura Wars、Shinkalion、Nadia | 证明 SRW 不只等于“机器人动画集合” |

## 2. 基石三系

### Mazinger 系

代表角色：兜甲儿、弓沙也加、Dr. Hell、暗黑大将军等。

常见功能：

- 给超级系提供祖师爷地位。
- 光子力研究所天然适合与早乙女研究所、NERV、TERRA、勇者系基地建立科学家网络。
- 甲儿常担当前辈：他能理解少年驾驶员的恐惧，也能用热血把队伍气氛拉起来。

常见改写：

- Dr. Hell 或机械兽军团被并入更大邪恶组织。
- Mazinger ZERO、真Mazinger 等版本会把“魔神是否会毁灭世界”变成更高危的原创/跨作议题。

梗点：

- “魔神”既是保护神又是破坏神。
- 甲儿作为老前辈的稳定存在感。

### Getter 系

代表角色：流龙马、神隼人、巴武藏/车弁庆、早乙女博士。

常见功能：

- Getter 线、进化、宇宙生命力、恐龙帝国/Invader 让剧情具有狂野生物学和宇宙恐怖味。
- 龙马常作为粗暴但可靠的战斗前辈，与甲儿、阿姆罗形成“御三家前辈团”。

常见改写：

- Getter 线经常被用来解释其他作品的进化、变异、外星威胁。
- 《世界最后之日》《Getter Arc》等版本让剧情更末世、更疯狂。

梗点：

- “Getter 线什么都能解释”是玩家常见玩笑。
- 龙马强度与狂气台词经常成为二创素材。

### Gundam 系

代表轴：

- UC：阿姆罗、夏亚、布莱德、卡缪、捷多、哈萨维等。
- 平成/新世纪：G、W、X、SEED、00、AGE、IBO、水星的魔女等。

常见功能：

- 提供政治战争、殖民地、军队结构、王牌驾驶员和量产机逻辑。
- 真实系数值、射程、回避、Newtype 能力构成玩法模板。
- UC 角色经常担任军事经验与道德争论的核心。

常见改写：

- 夏亚的阿克西斯坠落、卡缪的精神崩溃、Four/Puru 等悲剧角色的命运常被改写。
- 不同高达世界的战争会被并列为“人类重复犯错”的证据。
- 《G高达》因为武斗和超级系气质，常被桥接到超级系阵营。

梗点：

- “夏亚又要搞事了吗？”
- “阿姆罗当保姆/前辈教官。”
- “东方不败是宇宙人”式早期离谱改写，是玩家谈论老机战时常提的梗。

## 3. 重要参战作品索引

### Evangelion

功能：

- 都市防卫、少年创伤、人类补完、使徒危机。
- NERV 与其他防卫组织并列，制造“军方知道多少、科学家隐瞒多少”的张力。

串联方式：

- 使徒可以被解释为广义外星/高维威胁的一部分。
- Shinji 的心理线经常被其他少年主角、前辈驾驶员或热血角色介入。
- 补完计划与 RahXephon、Ideon、Aquarion、原创最终敌等世界重组设定相性极高。

玩家看点：

- 原作的孤独感在 SRW 中会被“大家都在”的氛围稀释，这是争议也是爽点。

### Macross 系

功能：

- 宇宙移民、异文明接触、歌、文化冲击。
- 舰队与母舰系统天然契合。

串联方式：

- 歌可以与勇气、精神指令、BGM、士气系统形成玩法/剧情双重效果。
- Zentradi、Vajra、Protodeviln 等敌人经常与其他外星文明并行。

玩家看点：

- 歌曲版权影响版本体验，Premium Sound Edition 很大程度服务这类作品。

### Nadesico

功能：

- 宇宙战舰、轻喜剧、宅文化自觉、剧场版的创伤转向。

串联方式：

- TV 版适合缓和气氛，剧场版适合制造“曾经的轻喜剧变成痛苦未来”的反差。
- 《W》《R》《V》等作品常利用 Nadesico 前后期差异制造时间线和救济。

玩家看点：

- Akito 的命运是 SRW 玩家特别在意的救济对象之一。

### GaoGaiGar

功能：

- 勇气、合体、原种、机械昇华、FINAL 的宇宙危机。

串联方式：

- GGG 组织可以与地球防卫机构无缝合作。
- “勇气”作为主题能拯救许多沉重作品的角色。
- 机械昇华和原种危机适合与外星/高维敌人合并。

梗点：

- “勇气不是数值，是外挂”式玩家玩笑。
- GaoGaiGar 的最终招式演出经常是战斗动画看点。

### Full Metal Panic

功能：

- 现代军事、校园轻喜剧、Whispered 黑科技、宗介与千鸟的关系。

串联方式：

- FMP 的秘银组织适合与各类国际军队、特务组织合作。
- 校园喜剧桥段可以与严肃战争形成反差。
- 小说后期的沉重主线在 Z3 等作品中适合放入世界真相层。

### Code Geass

功能：

- 革命、帝国、面具领袖、战略谋略、Geass 超常力量。

串联方式：

- 黑色骑士团可与其他反抗组织、Celestial Being、Gurren 团等合流或互相猜疑。
- 鲁路修很适合被放在 SRW 队伍里接受“更大棋局”的反噬：他习惯操纵别人，但 SRW 总有比他更老练的军人、外星势力和原创黑幕。

玩家看点：

- 鲁路修与其他军师/舰长的互动是现代机战台词宝库。

### Gurren Lagann

功能：

- 螺旋力、反压迫、宇宙尺度成长、热血神话。

串联方式：

- 从地下村庄到宇宙终局，天然适合 Z 系列这种多阶段多元宇宙叙事。
- 螺旋力可以和 Getter 线、勇气、精神指令、进化主题互文。

玩家看点：

- 终盘尺度极大，和 Gunbuster、Ideon、Getter 等作品同台时会形成“谁更离谱”的热血比较。

### Yamato / Harlock / Cowboy Bebop 等非传统参战

功能：

- Yamato 提供远航史诗。
- Harlock 提供宇宙浪漫和自由海盗精神。
- Cowboy Bebop 提供赏金猎人与成人日常。

串联方式：

- 它们证明 SRW 的核心不是“必须驾驶机器人”，而是“能否为联合部队提供世界观、人物和战斗单位”。
- V/T 以后，SRW 更愿意吸收这种边界作品。

玩家看点：

- 老玩家一开始会问“这也能参战？”随后看它是否真的服务主线。

### Gridman / Dynazenon / Godzilla S.P

功能：

- 都市怪兽、数字世界、特摄语法、现代青少年群像。

串联方式：

- 《30》用 Gridman 把虚拟空间、怪兽和现实城市防卫接入机战。
- 《Y》参战 Dynazenon 和 Godzilla S.P，说明现代 SRW 正在把“怪兽灾害/特摄式异常”与传统机甲战争融合。

玩家看点：

- 这类作品考验 SRW 剧本能否把“非军队、非宇宙战争”的故事自然放进大地图。

## 4. 著名梗点辞典

### 必中、闪避、热血、魂

精神指令是最常见的机战黑话。玩家说“开必中”“挂热血”“一发魂”时，实际是在说：角色意志把概率和数值按下去。很多跨作品吐槽也围绕精神指令展开。

### 说得

从初代开始的传统。说得是 SRW 对原作敌人的最大温柔：只要条件够刁钻，敌人、悲剧角色、竞争对手都可能被带回队伍。

延伸梗：

- “攻略不看会错过隐藏。”
- “这人原作死了，但机战能不能救？”
- “你这关没让特定角色打最后一下，隐藏没了。”

### 修理/补给练级

带修理装置或补给装置的单位可以通过支援行为获得经验。早期玩家常用它把辅助角色练上来，也形成“后勤才是成长最快的”的玩笑。

### 王牌前辈团

甲儿、龙马、阿姆罗、布莱德等老角色在许多作品里承担“跨作品前辈”。他们的存在让新参主角不会完全重复原作孤独。玩家喜欢看前辈把原作里没人说的话提前说出来。

### 死亡救济

SRW 最有辨识度的爽点之一。原作里死去或精神崩溃的角色，在 SRW 里可能被救下。

常见类型：

- 通过提前击坠敌人改变战局。
- 用说得解除误会。
- 用时间旅行/平行世界知道未来。
- 让其他作品角色介入原作孤立名场面。

玩家期待的是“既承认原作悲剧重量，又给一个如果大家都在场的答案”。

### 隐藏条件学

隐藏机体和隐藏角色经常要求：

- 特定角色击坠特定敌人。
- 特定话数前达到击坠数。
- 路线选择满足组合条件。
- 多次说得。
- 不击坠某 NPC。
- 过关前站到特定位置。

这让 SRW 攻略文化非常发达。Akurasu 等攻略站的重要性，正来自这些条件的复杂度。

### 强度梗

常见强度梗包括：

- 运动性高的真实系后期当闪避坦。
- 装甲厚的超级系配铁壁/不屈硬吃。
- MAP 兵器清屏。
- 后期精神组合把 boss 变成伤害木桩。
- 某些作品的主角机因为爱和改造被玩家捧成神。

强度梗不总是客观排名，很多时候是玩家投入资源后的“爱机即神机”。

### 官方玩梗台词

现代 SRW 特别重视特殊战斗台词。角色会对特定作品、特定敌人、特定类型机体说专属台词。它们承担三种功能：

- 给懂原作的人奖励。
- 让跨作品关系显得真的存在。
- 把玩家社群梗以较含蓄方式官方化。

## 5. 玩家接受史

### 早期玩家：攻略本与口耳相传

Classic 到 PS1/PS2 时代，玩家主要依靠攻略本、杂志、论坛和朋友交流。隐藏条件、路线分歧和机体评价是社群核心内容。很多“机战老害式记忆”来自这一时期：难、慢、动画珍贵、资源要省。

### 汉化与论坛时代

国内玩家长期通过模拟器、汉化补丁、贴吧、机战世界、NGA 等渠道认识系列。GBA/DS 作品因为硬件门槛低、汉化传播广，在中文玩家中影响巨大。《A》《R》《D》《J》《W》《K》《L》《UX》等掌机线的口碑很大程度由这一代玩家记忆塑造。

### 视频时代：B 站与 YouTube

视频平台改变了 SRW 的传播方式。许多玩家不一定亲自通关所有旧作，但会通过：

- 系列回顾视频
- 剧情解说
- 战斗动画合集
- 隐藏机体攻略
- 实况通关
- “最强机体/最难关卡/最离谱参战”盘点

来形成对系列的认知。

典型参考入口：

- B 站上有 GBA 机战全系列回顾类视频，如“GBA 上的所有超级机器人大战”。
- B 站上有《W》《30》等实况/剧情视频，适合观察弹幕对剧情梗的反应。
- YouTube 上有 DidYouKnowGaming 等频道做过 SRW 系列海外传播和“为何长期不出日本”的介绍。

这些资料适合整理玩家记忆，但不适合单独作为发售事实依据。

### 机核与中文媒体

机核这类媒体适合观察“中文核心玩家如何解释机战”。例如：

- 《SRW30》新闻和讨论能看出中文玩家对三十周年、参战表、Steam/中文化的反应。
- OG 故事回顾类文章能补充原创系复杂剧情的中文整理。

媒体评论的价值不是替代攻略，而是记录时代心情：玩家为什么在某个节点重新兴奋，为什么对某作失望，为什么某些参战作品被认为“破圈”。

### Steam/Switch 时代

《V》《X》《T》《30》《Y》让新玩家能直接买到中文或英文版本。玩家结构因此变化：

- 不再必须知道日文。
- 不再必须用模拟器。
- 更容易从某个喜欢的参战作品入坑。
- 也更容易用现代游戏标准批评 SRW：演出复用、难度偏低、系统重复、剧情节奏慢。

这让现代 SRW 面临双重任务：既要服务老玩家的参战表情怀，也要让新玩家愿意把它当作 2020 年代的策略 RPG。

## 7. 后续深挖建议

第二版已经建立基础 TSV 资料库，见 [04-结构化资料库说明.md](./04-结构化资料库说明.md)。如果要继续推进到真正“百科全书级第三版”，建议把现在的数据表扩成逐作专题库：

1. **每作完整参战作品表**  
   字段：作品、平台、发售日、参战列表、首次参战、隐藏机体、官方页面、Akurasu 页面。

2. **剧情采用表**  
   字段：SRW 作品、原作、采用章节、改写点、死亡救济、跨作品介入者、相关关卡。

3. **战斗台词/中断消息梗表**  
   字段：角色、触发对象、台词概要、原作出处、是否官方玩梗。

4. **玩家资料索引表**  
   字段：平台、作者、标题、链接、发布时间、讨论对象、观点摘要、可核验事实、社群观点。

真正惊艳的最终形态不是一篇文章，而是一个能按“作品、机体、人物、梗、关卡、路线”互相跳转的 SRW 知识库。当前 `data` 目录已经是这个知识库的地基。
