# 人类声线语义门

## 目的

这是一道写后首读门，不是给主笔背诵的禁词表。它判断角色是否真的在对某个听众解决眼前问题，还是作者借每个人轮流概括主题。

## 五项口读

### 听众

每句话具体说给谁？说完希望对方做什么、误会什么、停止什么或靠近什么？

没有听众和目的，只负责解释主题的句子应删掉或改成行动。

### 换人

遮住角色名。若纪存、七海、白鸢、唐胶、陆衡或普通NPC都能说同一句完整的话，声线没有成立。

机器可以更短、更字面或更重任务，但不能全都说成系统提示。

### 对称

警惕自动生成的整齐对偶、否定翻正和小型宣言。项目已反复出现的高风险结构包括：

- 你可以做某事，但别替我决定某事；
- 不是某物，而是某种宏大定义；
- 我不替谁做什么，也不让谁替我做什么；
- 没有把某物说成某物；
- 谁来背、谁欠谁、关系债、证词、记账等抽象结算语。

这些不是绝对禁用。只有角色在当场真的会这样说，且动作不能更好表达时才保留。

### 量纲

检查作者是否习惯用一格、一厘米、几秒、半拍、某盏灯、某道锁、某个槽或某个锚制造虚假分量。小细节可以存在，但不能替代巨型机器人、重大关系和可见后果。

技术人物先说普通人能执行的话；专业词只在它改变行动时出现。

### 朗读

朗读关键ADV、关系场和战中通讯：

- 角色会不会先改口、打断、绕开或说废话；
- 语气词和句长是否符合情绪；
- 连续三人是否轮流给出完成度过高的金句；
- 同一意象、句法或反问是否被不同人重复；
- 关掉声音后，动作是否仍然承载主要意义。

## 输出

只登记会改变人物、关系、因果或阅读信任的声线根因。不要把正常出现的灯、锁、槽、否定句逐条列为错误。

若一两句局部调整即可解决，标明具体场面；若整场所有人都在说作者的话，要求重写完整场面。
