## 以后如何更新

在这个文档仓库运行以下命令可从获授权的本地原工程重新导出，并验证快照。路径按本机实际位置替换；不将凭证写入参数。

```bash
node tools/export-review-snapshot.mjs /absolute/path/to/source-project
node tools/export-art-supplement.mjs /absolute/path/to/source-project
node tools/validate-art-supplement.mjs /absolute/path/to/source-project
node tools/validate-review-snapshot.mjs /absolute/path/to/source-project
```

基础导出工具读取`docs/`、`研究报告/`及三个项目专用Skill；美术导出工具另按明确采用回执和视觉参考页收集指定图片与依据。原文保留字节，只写本快照仓库，不操作原工程，也不自动提交/推送。以后更新应先复核采用回执与精选范围，不能将新候选图自动纳入已定源设计；导航和评审问题也需随用户最新决定复核。外部评审新产物放`reviews/`，与原始资料分开。
