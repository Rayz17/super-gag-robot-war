## 验证

- [文本/导航检查](VALIDATION.json)：清单、字节、指纹、UTF-8、凭证格式扫描和本地链接。
- [精选图检查](art/VALIDATION.json)：逐图采用指纹、图片尺寸及视觉参考页引用。
- [全量检查](library/VALIDATION.json)：全部Git内二维/设定文件与指纹、覆盖数量和三维排除。
- 远端发布后另核对Git树；本地提交不等于已经上传。

文件完整、来源可追溯与机器检查通过不证明画面好看、故事精彩、动画自然、声音合格或可玩性成立。没有自动签署任何用户认可。

## 明确排除

三维资产与相关源、机器/工具缓存、其他Vault与个人配置、原始第三方工具/vendor、自动备份、巨大生成测试矩阵、完整工作区副本及大量QA录屏/中间帧不作为本次二维资产上传。具体路径/原因见[排除表](library/EXCLUSIONS.tsv)。本次不是把整个200GB级调试目录当成美术库。

仓库在本轮复核时为公开状态，沿用已有设置。没有修改原工程的分支、远端、暂存区或仓库可见性。

## 更新方式

导出与打包工具只读原工程、只写评审仓库或独立打包目录。再次同步时先复核用户范围、原有采用回执和目录策略，不自动把新输出升级为已定资产，也不自动发布。

```bash
node tools/export-complete-review.mjs /absolute/source/project /absolute/separate/staging
node tools/build-complete-review-index.mjs
node tools/validate-complete-review.mjs
node tools/validate-review-snapshot.mjs
```

上次的精选导出工具仍保留作历史方法；不得在本轮完成后直接用它覆盖全量清单。外部新评审继续放`reviews/`，不覆盖原始源。
