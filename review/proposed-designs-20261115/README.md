## 合体与模型制作的阅读方式

合体组按单体板、总机板、背侧或功能辅助板的顺序看。重点检查同一舰艏、兽首、车头、风扇、钻头、履带、主舱、头盔和色块是否能在组合后继续追认。辅助视图负责交代被主视遮挡的结构，不能用不同颜色重新画一台无关机体来代替部件循环。

本轮完成的是视觉设计与组件关系提案。继续开发玩具模型时，需要将选定方案转成同尺度正交三视与零件表，再验证折叠行程、碰撞、重心、锁止、装配公差与受力。具体未验证之处已经写入每张图的说明；手绘多视图不能当作同一个三维模型的工程证明。
