# 《命运石之门》文档集 · 03 人物志

> 体例：每人为一节，含身份 / 性格 / 动机 / 能力 / 人物弧 / 关键节点 / 跨世界线命运分岔。细节把握不足处以"（细节以原作为准）"标注。

## 一、冈部伦太郎（Okabe Rintaro / 凤凰院凶真）

- **身份**：18岁（1991年12月生，故事开始时18岁），复读考入东京某大学的年轻人；未来道具研究所所长，所员001；自称"狂气的疯狂科学家·凤凰院凶真（Hououin Kyouma）"。
- **性格**：中二病晚期——长发、白大褂、邪笑，满口"机关"与"El Psy Kongroo"。但中二是他的铠甲：落榜与孤独锻造的表演型人格之下，是极端重情、责任感过剩、宁可自毁也不背弃同伴的内核。他给一切现象命名的习惯（Reading Steiner、Operation Skuld），恰好是他真正能力的形状。
- **能力**：Reading Steiner——跨越世界线保有记忆的唯一观测者。无任何超常智力或武力，他的武器只是"记得"。
- **动机**：开场是"为了对抗机关而发明"的玩票；D-mail事件后是"我要救所有人"的执念；终局升华为"作为唯一的观测者，替所有世界线记住一切"。
- **人物弧**：中二妄想家 → 无意中揭开潘多拉魔盒的实验者 → 无限救援的殉道者（α段）→ 唯一记得两个世界的人（β段）→ 学会"欺骗世界也欺骗自己"、以失去一切记忆共享为代价换回同伴生存的人。他的成长不是变得更强，而是学会承担"无人知晓的牺牲"。
- **关键节点**：7月28日目击血泊（起点）；发现D-mail；黑入SERN得知真相；8月13日后的死亡循环；铃羽摊牌后理解收束；β线"放弃"的至暗时刻；影像信件后的再起；Operation Skuld的执行与告别。
- **跨世界线分岔**：α线——无数次回溯的救援者；γ线（衍生）——黑化为SERN合作者"凤凰院凶真"成真（细节以原作为准）；β线——一度放弃救红莉栖、在痛悔中生活（《命运石之门0》的主视角）；Steins Gate线——带着全部记忆独自前行的"适格观测者"。

## 二、牧濑红莉栖（Makise Kurisu）

- **身份**：18岁（细节以原作为准），跳级进入美国名校的天才神经科学家，以脑与记忆研究闻名；因论文质询而出现在7月28日的发布会现场。
- **性格**：锋利、好胜、毒舌，理性至上，讨厌被当成"小女孩"或"天才花瓶"；实则笨拙怕生、渴望父亲认可、深夜泡在@channel（昵称"KuriGohan and Kamehameha"，炒饭盖饭与龟派气功之意，细节以原作为准）发帖的普通少女。Dr Pepper爱好者，本人坚称"这不是可乐"。
- **能力**：顶级的大脑。记忆物质化与传送理论是她亲手推到研究所面前的——时间跳跃机的理论母亲。同时是全队唯一能与冈部平等争论、快速消化"世界线"概念的人。
- **动机**：科学上的求真；对父亲中钵博士又爱又恨的救赎欲；以及（她自己也不愿承认的）对研究所这群"没出息的家伙"的归属感。
- **人物弧**：以"被目击的尸体"登场，以"活着的战友"身份入伙，在α线成为救援技术的提供者，在β线成为必须死去的人，在Steins Gate线成为"死而复生却必须假装死过"的人。她是全剧"观测与存在"主题的另一极——冈部记得一切，她则被要求"忘记一切"。
- **关键节点**：7月28日的"死亡"与"重逢"；果冻香蕉实验中的理论突破；与父亲决裂的晚餐；@channeler暴露的社死名场面；真由理死亡循环中的并肩；Steins Gate线的道别（她抱着刚认识不久却仿佛认识一生的心情，说会记住一切）。
- **跨世界线分岔**：α线——研究所的技术核心，活到最后（α未来命运剧中语焉不详，细节以原作为准）；β线——7月28日死于父亲刀下（收束）；Steins Gate线——被伪造死亡后活下来，以"已死之人"的身份继续研究；剧场版——成为反向"观测"冈部的人。

## 三、椎名真由理（Shiina Mayuri）

- **身份**：16岁（细节以原作为准），冈部的青梅竹马，研究所002号，被冈部称为"人质"（Hostage，冈部式玩笑）。
- **性格**：天然呆的温柔本体。语速缓慢，招牌问候"Tuturu~"，自称"真由真由（Mayushii）"。对死亡与代价毫无概念地善良——而这份善良恰恰是α线最锋利的刀。
- **能力**：无。她的"能力"是氛围性的：让所有人卸下心防的手作能力（cos服缝纫）、以及冥冥中感应命运的直觉——"身体变得好沉重"。
- **动机**：让冈部、让大家都笑着。她比谁都早察觉冈部的疲惫，也比谁都坦然地面对自己的命运。
- **人物弧**：全剧唯一"以死亡为叙事主体"的角色：8月13日起，她的死亡成为α场的收束事件。她在死后无数次被世界的重写抹去，又在每一次回溯中原样站着——她对自身命运近乎圣徒的接受（"真由知道，自己死掉的话，冈伦就不会再战斗下去了"），反把冈部推向极限。
- **关键节点**：祭典之夜的第一次死亡；各种形式的死亡循环（含来自最亲近之人的刀）；知情后的坦然；β线的活着；Steins Gate线与冈部的重逢（她什么都不知道，却抱住了"去了很远的男人"）。
- **跨世界线分岔**：α线——必死（收束）；Ruka线/菲利斯线等衍生α变体——同样难逃；β线与Steins Gate线——存活，并在《命运石之门0》中成为把冈部推向红莉栖的关键推手。
- **注**：真由理的"死亡引力"是全剧主题"命运与选择"的人格化身：她不是被剧情牺牲的工具，而是主动选择"自己的死不能成为冈部停止的理由"的行动者。

## 四、桥田至（Hashida Itaru / Daru）

- **身份**：19—20岁（细节以原作为准），超级黑客（自拼作"Super Haker"），研究所003号，网名"巴罗涅? （Barrel? 存疑）"。
- **性格**：宅、下流梗连发、见女仆就走不动路；但技术上一骑绝尘，人道上极可靠——关键时刻从不开玩笑，"宅"是他的社交铠甲，正如中二是冈部的。
- **能力**：世界级黑客技术：黑入SERN数据库、改造电话微波炉、组装世界线变动率探测仪、抢修时间机器。α场未来里SERN都要囚他造机器——他的才能是两条未来线共同的"战略资源"。
- **动机**：兴趣与同伴。他是研究所里最纯粹"因为开心所以做"的人，也因此是α反乌托邦里被夺走未来的人质。
- **人物弧**：废柴搞笑役 → 世界线真相的技术执行者 → 女儿铃羽的生父（不知情—知情）。他对铃羽的感情从"同级生式的欣赏"滑向"父女相认"的震撼，是全剧最收敛也最重的亲情反转之一。
- **关键节点**：与铃羽共同修复时间机器；撤销D-mail行动中的黑客主战；β线抢修时间机送冈部与铃羽回到7月28日；Steins Gate线终局的相认（细节以原作为准）。
- **跨世界线分岔**：α线——被SERN掳为技术奴隶；β线——在与阿万音由季的结合中生下铃羽（2017年，细节以原作为准）；Steins Gate线——在无战争也无反乌托邦的世界里，与铃羽父女相认、与由季的自然相识成为可能的"最好的桥田至"。

## 五、阿万音铃羽（Amane Suzuha）

- **身份**：表面是布朗大楼一楼"布朗管工? （细节以原作为准）"的打工女孩；实为2036年反抗军战士，时间旅行者"John Titor"本人，桥田至与阿万音由季之女（2017年生，细节以原作为准）。
- **性格**：爽朗、行动力超群、昭和味的正义感；因来自未来而在日常梗上时常脱线（对昭和文化的错位怀旧）。背负使命时的沉默与决绝，与打工时的元气形成两副面孔。
- **能力**：军事级格斗与枪械（标志性CZ75手枪）、时间机驾驶与机械维护；作为时间旅行者，她对"未来史"的记忆是全队的情报金矿。
- **动机**：α线——阻止SERN反乌托邦（其中含救回被掳的父亲达鲁的私愿）；β线——阻止第三次世界大战。她的"未来"在每条线上都毁于一旦，她是唯一一个"回不去也无法回家"的角色。
- **人物弧**：神秘打工妹 → 失败的1975年任务（α前史）→ 摊牌真身 → 与冈部共同理解收束 → β线的使命承载者 → Operation Skuld的执行搭档 → 留在2010年与父亲相认的女儿。她的弧光核心是"第二次机会"：第一次出发为了改变历史，第二次出发为了成全他人。
- **关键节点**："卫星坠落"登陆；1975年任务的失败；真由理之死前后向冈部摊牌；β线告知世界大战；与冈部重返7月28日；终局与达鲁的父女相认（细节以原作为准）。
- **跨世界线分岔**：α线——反抗军战士（两次出发）；β线——战争孤儿式战士；Steins Gate线——使命消失的"多余之人"，选择留在没有战争的2010年重新生活。

## 六、漆原琉华（Urushibara Ruka）

- **身份**：16岁（细节以原作为准），秋叶原附近神社之子，清丽如少女的美少年（性同一性障碍意义上的"生错了身体"的自认，细节以原作为准），研究所编外所员，冈部的后辈。
- **性格**：极度温顺怯懦，声音轻得像叹息；但在"想成为女孩子"与"喜欢冈部先生"这两件事上，藏着全剧最柔软的执念。
- **能力**：无科技能力；"能力"是她的存在本身对D-mail的适配——她成为α线第一个以自身命运做实验的人。
- **动机**：以真实的自己（女性）活着，并堂堂正正地喜欢冈部。
- **人物弧**：D-mail把她送进"生为女性"的世界线（女性琉华线）：在那里她幸福、并与冈部拥有一段近似恋情的时光；她最终自己选择放弃——因为她察觉这份幸福建立在改写与谎言之上，也因为她比谁都不愿拖累冈部的战斗。撤销D-mail那场雨中戏，是全剧早期最痛的泪点。
- **关键节点**：神社偶遇IBN 5100的线索；发出致母亲的D-mail；女性琉华线的"约会"与放手；真由理死亡循环中某个世界里那把举起的刀（α线诸多收束形式之一，细节以原作为准）；终局后的释然。
- **跨世界线分岔**：男性琉华（本篇基准线）——暗恋冈部、继承神社的少年；女性琉华线——得到性别却最终自愿归还的幸福少女；两条线构成"身份认同与真实自我"的镜像命题。

## 七、桐生萌郁（Kiryu Moeka / Moeka）

- **身份**：杂志编辑（自称），-rounders协力者，代号"FB"的部下；研究所短暂编外人员（细节以原作为准）。
- **性格**：几乎不用嘴说话，一切交流靠手机短信；优雅、礼貌、空洞。手机是她与世界唯一的接口——也是她的牢笼。
- **能力**：情报收集与武装行动能力（Rounders训练）；以短信速度而言是"世界最快"的怪人（动辄零点几秒回复的名梗）。
- **动机**：FB的指令就是她全部的存在理由。童年被遗弃的她，把"有人需要我"寄托在那个从不露面的短信对象身上。她抢夺IBN 5100、袭击研究所、杀死真由理，都不出于恶意，而出于一台手机的虔诚。
- **人物弧**：温柔的邻家姐姐假面 → Rounders真身暴露 → 被组织抛弃、被FB亲手处决的α线悲剧 → 撤销D-mail后的"另一种人生"（FB从未给她指令的世界里，她只是一个更空、更自由的无名者）。她是从未"被拯救成功"、只被"换了一种失去方式"的角色——全剧对"拯救的边界"最残酷的注脚。
- **关键节点**：以IBN 5100话题接近研究所；窃走IBN；突袭之夜（真由理之死的一种形式）；枪响与目击者Nae；替代D-mail的发送。
- **跨世界线分岔**：基准α线——Rounders爪牙，死于组织之手；撤销后世界线——无组织的普通人（其后续命运细节以原作为准）；《命运石之门0》中以"Re:Rounders"相关因果再度登场（详见06）。

## 八、秋叶留未穗（Akiha Rumiho / 菲利斯·尼安尼安 / Faris NyanNyan）

- **身份**：秋叶原地主秋叶家的独生女，女仆咖啡厅"May Queen Nyan2"的王牌店员，雷内特卡牌对战（RaiNet Access Battlers）的顶级玩家，人称"菲利斯·尼安尼安"。
- **性格**：全程猫叫腔（句尾"喵"）的营业人格之下，是精明、豪爽、重义气的大小姐。她的"萌"是职业，也是铠甲。
- **能力**：卡牌对战的压倒性实力（曾以压倒性手段制霸对战圈，细节以原作为准）；社交与商业头脑。
- **动机**：守护"秋叶原"这个她父亲与她共同热爱的街区；以及（得知D-mail后）一个女儿最私人的愿望——让死于空难的父亲活着。
- **人物弧**：她的D-mail让父亲免于空难，却让秋叶原的历史改道——那个宅文化的圣地消失了。她亲手得到父亲，又亲手放弃父亲，只为把"大家笑着生活的秋叶原"还回去。她与真由理的死亡互为镜像：一个用死亡收束逼问"生命的重量"，一个用父亲的选择逼问"世界的重量"。
- **关键节点**：雷内特对决与IBN 5100的转让；得知D-mail真相后的抉择；菲利斯线（秋叶原变形记）的历险与放弃；终局后的重逢。
- **跨世界线分岔**：基准α线——女仆咖啡厅之王；菲利斯线——父亲在世的"普通大小姐"，身处另一个秋叶原；Steins Gate线——一切如常的菲利斯，继续守护她的街区。

## 九、中钵博士（Nakabachi）

- **身份**：红莉栖的生父，学界失意的中年研究者。
- **性格**：自卑与嫉妒发酵成对女儿的病态敌意；把女儿的才华视为对自己的否定。
- **行为线**：7月28日发布会上夺取红莉栖的时间机器理论论文，冲突中刺伤（β场：杀死）女儿，携论文流亡俄罗斯——β场世界大战的引信由此点燃。
- **叙事功能**：他是"收束"的人形化身——在β线，无论因果细节如何，7月28日总是"父亲杀死女儿"。他与红莉栖那场不欢而散的家庭晚餐，是全剧最平视、也最窒息的一场文戏。
- **注**：其下场、论文最终去向与俄方接线的详情，本篇刻意留白多于实写（细节以原作为准），为《命运石之门0》的国际阴谋线留出接口。

## 十、配角群像（简档案）

- **天王寺裕吾（布朗先生 / FB）**：研究所房东，守旧顽固、深爱幼女的单亲父亲；实为SERN一方暗桩，FB的真身。α线以手枪终结萌郁后自尽。他证明了"机关"不在远方，就在楼下。
- **天王寺绯奈（Nae）**：裕吾的幼女，天真烂漫，研究所众人的开心果；α线目击父亲死亡与枪击惨剧，成为贯穿系列的创伤伏笔（《命运石之门0》中另有身份性展开，细节以原作为准）。
- **阿万音由季（Yuki Amane）**：铃羽之母、达鲁未来的妻子，开朗坚定的女性；主要在α/β未来的转述与衍生作品中登场（细节以原作为准）。
- **4℃（Yog? 存疑）等街坊与店员**：女仆咖啡厅同事、神社信众、秋叶原店家，构成秋叶原日常生态的背景板。
