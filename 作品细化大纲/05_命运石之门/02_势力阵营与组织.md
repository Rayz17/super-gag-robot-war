# 《命运石之门》文档集 · 02 势力阵营与组织

## 一、未来道具研究所（Future Gadget Laboratory）

- **位置**：秋叶原旧商楼"布朗大楼"二楼。房东天王寺裕吾（布朗先生）的公寓楼，充满昭和年代感的狭小房间。
- **成立**：经历大学入学考试失利、复读后考入大学的冈部伦太郎，为逃避"正常人生"而创立的"发明组织"，自封"狂气的疯狂科学家·凤凰院凶真"，宣称与神秘的"机关"（The Organization）对抗——所谓机关，开场时只是他的中二妄想，日后却与SERN的阴影重合，构成全剧最大的反讽之一。
- **成员编号（Lab Member）**：以"所员"徽章相称。001冈部、002真由理、003达鲁、004红莉栖（动画基准）；其后入所者依次编号，琉华、菲利斯、铃羽、萌郁等的具体编号分配细节以原作为准。
- **性质**：开场时是三个边缘人的避难所（失意的复读者、温柔的天然少女、宅气冲天的天才程序员），随着D-mail的发现逐渐变成"人类最早的有限时间干预组织"。研究所的凝聚力——"无论世界怎么变，这里都是我们的家"——是全剧最重要的情感资产，也是终局所有牺牲的意义所在。
- **组织弱点**：毫无保密意识与反侦察能力；所有实验数据经普通网络收发，早已暴露在SERN的ECHELON之下。研究所在α场的覆灭不是意外，而是必然。

## 二、SERN 与 Rounders

### SERN

- 欧洲核子研究组织（影射CERN）的剧中改名。LHC实验产生微型黑洞后，内部启动了时间机器秘密研究（剧中以内部机密文档形式被研究所黑入时确认）。
- 组织特征：科层化、冷酷、以"人类历史的管理者"自居。它不是脸谱化恶役，而是"科学失去伦理后的自然结果"——D-mail数据主动撞进了它的窃听网，α场的地狱一半是研究所自己招来的。
- 窃听系统ECHELON：全球级通讯监控，α场一切灾难的引信。
- 幕后层：科学ADV世界观的"300人委员会"式暗势力在SERN背后若隐若现（细节以原作为准，本文档不展开）。

### Rounders（圆桌骑士? 特务部队）

- SERN麾下的时间线特务部队，负责在2010年的"现在"清理时间机器研究的隐患：回收装置、灭口知情人、确保SERN的垄断。
- 2010年8月在α线的行动链：确认研究所的D-mail实验 → 收买/策反研究所周边人物 → 武力袭击研究所 → 真由理之死（收束形式之一）→ 掳走达鲁（α未来：被迫为SERN造时间机器）。
- 桐生萌郁即为Rounders的当地协力者（代号与职务细节以原作为准），听命于联络代号"FB"的上线。
- 《命运石之门0》中出现后继形态"Re:Rounders"及更复杂的国际情报博弈（详见06）。

### FB 与天王寺裕吾

- "FB"是萌郁唯一的支柱：通过手机短信给她下达指令、也在精神上"赋予她存在意义"的神秘上线。萌郁的一切行动动机，都是期待FB的一句回复。
- 真相：FB就是研究所楼下的房东、"布朗先生"天王寺裕吾（细节以原作为准）。他表面是顽固守旧、疼爱女儿的单亲父亲，实为SERN一方布在秋叶原的暗桩。α线任务败露后，他以手枪终结了失职的萌郁并自尽，全程被幼女绯奈（Nae）目击——这一枪的创伤在《命运石之门0》中仍有回响。
- 组织性反讽：研究所拼命对抗的"庞大机关"，其秋叶原分支竟然就住在楼下；冈部中二病里的"机关"，是真实存在的。

## 三、β线未来的反抗军

- β场（1.130205%）的2036年：第三次世界大战肆虐后的焦土世界，时间机器理论外泄引发的大国战争摧毁了逾半人口。日本在战火中残破，反抗军与占领势力周旋。
- 阿万音铃羽即反抗军战士：其父桥田至（达鲁）在β未来留下了时间机器的遗产（成品或图纸，细节以原作为准），铃羽驾驶它逆行至2010年，使命是阻止中钵论文外泄、斩断战争的火种。
- 与α线反抗军的区别：α线反抗军的敌人是SERN反乌托邦，核心道具是IBN 5100与数据删除；β线反抗军的敌人是战争本身，核心道具是论文与7月28日。两条未来线分别塑造了铃羽的两次出发——同一个女孩，两种绝望。
- 反抗军在剧中的实写极少（2036年仅以铃羽的转述与零星影像呈现），这种"未来不可见"的处理，让大战的恐惧全部压在"一个女孩为什么要回到过去"这个问题上。
