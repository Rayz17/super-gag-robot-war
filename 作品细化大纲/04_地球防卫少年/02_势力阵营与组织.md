# 《地球防卫少年》02：势力阵营与组织

> 本篇梳理故事中的各方势力与组织关系。个别组织名称与人名原作未给出正式表述或记忆不牢者，以角色功能概括并标注（存疑）／（细节以原作为准）。

---

## 一、孩子侧：签约十五人团体

- **性质**：故事唯一合法的驾驶者集团。没有正式队名（纳卡马为同伴制作队服的细节存疑），是一个由契约强行绑定的"同龄人临时共同体"。
- **成员**：**十五名签约孩子**（瓦库、小玉、大地、纳卡马、卡可、千鹤、茂志、真木、切江、小萌、安子、宽治、可奈、麻知、宇白——三处签约例外见03篇）；另加成年引导者科库佩里（不在十五人之列，但亲自承担第1战）。旧版"科库佩里＋十四名孩子"的口径有误。
- **内部秩序**：
  1. **出战顺位**：由谁驾驶、以何机制决定，现有资料未确证（存疑）；卡可未出战即死亡、麻知未及出战即死亡——顺位并非铁板一块。
  2. **同伴网络**：同伴间的互助与连带是团体存在的方式（如纳卡马制队服、真木向宇白托付可奈等，细节以原作为准）。旧版"笔记接力／驾驶员须知"体系未获资料证实，存疑。
  3. **情感结构**：团体内部存在亲近关系与裂痕（宇白与可奈的兄妹、麻知对宇白的恋慕等），争吵、排斥与和解不断；死亡顺序重塑着每个人的位置。
- **流动性**：随战斗推进人数递减，团体的"规模感"本身成为叙事时钟。终局时未阵亡的签约者为宇白（其最终战的结局存疑）。旧版"可奈＝运营者、以倾听者身份幸存"的框架**未获资料证实且与原作相反**（可奈为第13战驾驶员、战后死亡），已废弃。

## 二、家庭与成人后援网络

孩子们没有监护人式的"保护者"，他们的家人与身边成人以各自的方式被卷入：

- **宇白家**：兄妹之父（职业细节存疑）；兄妹的**生母是国防军田中一尉**（核验更正：旧版"母亲因产下可奈去世"有误）——她在可奈之战中驾驶战斗机支援女儿，被掳为人质后拒绝拖累，在敌人手中自尽（据剧透资料，细节以原作为准）。动画第24话中宇白出征前帮父亲做事、并为自己对可奈的暴力道歉（据分集资料，存疑）。
- **安子家**：父亲为新闻主播；安子之战中女儿以父亲的播报腔为范本向镜头发讯息（细节以原作为准）。
- **小萌家**：小萌之战中父亲持枪在场（据剧透资料；其家业与旧版"财阀经营者、注资科研"设定未获确证，存疑）。
- **千鹤的加害者侧**："波多老师"（ハタ先生）及参与"卖女"的大人们——被千鹤杀死（据剧透资料，细节以原作为准）。
- **教师等身边大人**：自然学校的带队教师及个别学校教职员在事件初期承担目击者、联络者角色（姓名存疑）。
- **总体特征**：成人无法替代驾驶；他们能做的是支援（国防军的协同作战）、见证与哀悼。旧版"遗族后援网络、企业注资科研、医疗破解死亡规则"等情节未获资料证实，存疑处理。

## 三、政府与军方阵营（日本）

- **日本政府／内阁层面**：从封锁消息到介入的主导者（细节以原作为准）。
- **国防军**（核验更正：原作军事组织称国防军，非"自卫队"）：
  - 前期负责目击压制与现场封锁；
  - 作战协同逐战升级：空军机特攻破坏敌驾驶舱（茂志战）、世界范围的声援与通讯支援（安子战）、**军人以血肉之躯充当光束校正标记**（宽治战，関一尉等众多军人阵亡）、战斗机近接支援驾驶员（可奈战，田中一尉）；
  - 武装接管类冲突的记载未获确证（存疑，旧版「军方接管危机」的枪战流血情节为重构，以原作为准）。
- **外国政府与军队**：情报关注贯穿中后期（细节以原作为准）；联合国实际介入有限（存疑）。

## 四、泽阿斯相关科研体系（存疑保留）

- 旧版"政府与企业联合的机体研究团队、死亡规则医疗破解"体系未获资料证实，存疑保留：原作对泽阿斯的科学解释集中在粪金龟的阶段性揭示（以生命力驱动、契约不可废弃等；细节以原作为准）。人类方面的"技术反击"以国防军的战术协同为主。

## 六、系统侧存在

- **粪金龟**：规则的管理与结算者；**真身为麻知之兄佐佐见一佐**——来自先前游戏世界的亲历者，本人曾是驾驶员；终局成为下一循环的新粪金龟（据剧透资料，存疑）。
- **科库佩里**：契约发起者与第1战驾驶员，战后沙化死亡；其真实身份未在现有剧透资料中揭示（旧版"系统侧种子型存在"框架废弃；"前次循环幸存者"等为社区推测，存疑）。
- **麻知**：中途自请签约的孩子；**粪金龟（佐佐见一佐）之妹**，与兄长同来自先前的世界（存疑）；未及出战遭枪击身亡。旧版"人造生命体／系统道具"设定废弃。
- **系统本体**：未以具体形象登场；卷末剧透资料称争斗的"黑幕"以"自然现象"的形式收束（存疑）——"规则在场而主宰缺席"的冷感处理成立，但其机制层细节以原作为准。

## 七、阵营关系图（文字版）

```
                    ┌──────────────┐
                    │  游戏（幕后）  │
                    │  粪金龟＝佐佐见一佐（前次世界亲历者）  │
                    └──────┬───────┘
                           │ 契约·结算
        ┌──────────────────┼──────────────────┐
        │                  │                  │
  本侧（我们的地球）      对手世界（客方地球）    其他平行地球
  ├ 孩子团体（15人）       ├ 契约驾驶员           （同样进行各自的"游戏"）
  ├ 家庭（田中一尉等）      ├ 本侧粪金龟
  ├ 日本政府·国防军（支援→协同作战）
  ├ 身边成人（教师、主播父亲等）
  └ 外国政府（情报关注）
```

> 阵营之间没有传统意义上的"敌我主线"：孩子与孩子互为敌手，大人与大人互为筹码，系统与所有人互为规则。这种"无恶人的悲剧结构"是本作冲突设计的底色。
