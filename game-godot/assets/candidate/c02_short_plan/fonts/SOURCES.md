# Candidate duel font

- Font: Noto Sans SC variable TrueType, bundled for consistent Chinese glyph coverage.
- Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- License: SIL Open Font License 1.1, see `OFL.txt` in this directory.
- Retrieved: 2026-09-21.
- Runtime: 450 weight through numeric OpenType `wght` tag. Tested `敌`, `鸢`, ability names, arrows and HUD symbols; curved rotation arrows were replaced with readable text buttons.
- Font variation reference: https://docs.godotengine.org/en/stable/classes/class_fontvariation.html

The font is scoped to this Candidate scene and does not change the default project theme.
