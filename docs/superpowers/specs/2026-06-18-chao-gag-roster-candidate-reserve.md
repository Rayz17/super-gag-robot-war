# 《超GAG机器人大战：万机残响》参战候选储备与可塑性分析 v0.1

> 本文是“参战投射与梗点 Bible”的上游候选池。它不等于最终参战名单，而是尽可能完整地列出高人气、高梗点、高互动潜力的机器人相关 IP、影视、游戏、现实机器人、创作者与模型文化，并给出原创换皮方向。

## 1. 调研口径

参战候选分为三层：

- **内部锚点**：团队内部知道它投射哪类 IP、人物、名场面和玩家梗。
- **游戏内换皮包**：实际对玩家呈现的原创名称、原创机体、原创角色。
- **可塑性判断**：它能否和其他参战包发生新的剧情化学反应，而不是只靠“我认识它”。

内部锚点只能用于策划沟通。游戏内不得直接使用受版权保护的角色名、机体名、造型、台词、标志、势力名和特征性剧情编排。

公开参考资料：

- Bandai Namco 的《Super Robot Wars Y》《Super Robot Wars 30》官方页面，用来校准近年官方参战组合与系列定位。
- Akurasu、维基类资料，用来交叉核对系列历史参战名单。
- UCG、游民星空、篝火、Bilibili、机核标签页等中文玩家/媒体内容，用来校准玩家对战斗动画、隐藏要素、跨作品互动、非线性流程的关注点。
- AniList 等动画榜单与社区资料，用来校准 EVA、Code Geass、Gurren Lagann、Gundam 等作品的泛人气。
- Boston Dynamics、Unitree、Figure、UBTECH 等官方或产业新闻资料，用来校准现实机器人方向。

## 2. 评分说明

每个候选用五项快速评分：

| 维度 | 含义 |
| --- | --- |
| P 人气 | 国内外机器人受众是否一眼认识，是否能带来自传播 |
| G 梗点 | 是否有大量可变奏台词、战斗演出、玩家共同记忆 |
| X 串联 | 是否容易和其他 IP 母题发生冲突、互补或反讽 |
| E 情感 | 是否能提供遗憾、牺牲、成长、宿命、浪漫或荒诞感动 |
| S 系统 | 是否能转化为独特战斗、养成、探索或路线机制 |

推荐层级：

- **S**：商业版核心骨架，优先改造成主线参战包。
- **A**：强候选，适合支线、隐藏、章节主客串。
- **B**：储备候选，适合作为图鉴、NPC、短支线或 DLC 方向。
- **C**：风险高或可塑性低，只保留内部参考。

## 3. 结论先行：更有人气和梗点的核心组合

上一版 24 个核心包的缺点是类型平均，但爆点不够集中。更强的方案应该把核心名额集中给四种高热区：

1. **机战传统高热区**：魔神、盖塔、高达、Macross、EVA、勇者、Gunbuster、Ideon、Gurren、Code Geass、Fafner、Patlabor、VOTOMS、Nadesico、Full Metal Panic、Gridman。
2. **全球机器人高热区**：Transformers、Pacific Rim、Megazord/麦克佐德、Voltes V/波鲁吉斯V、Voltron/百兽王、Terminator、RoboCop/ED-209、Iron Giant、I Robot、Chappie、Ex Machina、Real Steel、TARS（《星际穿越》）、HAL、Wall-E/Baymax。
3. **游戏与元叙事高热区**：Armored Core、Front Mission、Titanfall、Metal Gear、Zone of the Enders、13 Sentinels、NieR Automata、Into the Breach、Outer Wilds。
4. **现实与中文社区高热区**：流浪地球 MOSS/550W/笨笨/行星发动机、宇树/波士顿动力/优必选/特斯拉/Figure/Agility/乐高、洛洛历险记、超兽武装、果宝特攻、铁甲小宝式童年特摄机器人。

更适合商业版的核心不是“24 个平均包”，而是：

- **32 个主线/强支线核心包**：保证玩家感觉“这就是机器人全明星”。
- **40 到 60 个储备梗包**：通过支线、图鉴、敌方王牌、典藏 Pose、NPC、隐藏机体逐步释放。
- **8 到 12 个现实/创作者/厂商元包**：负责打破次元壁和形成《超GAG》的独特识别。

| 真人/公司影射 | 代哥、监督、模型厂、现实机器人公司 | 只写行业结构和创作生态，不写诽谤性事实 |
| 梗点压过人物 | 铁血团长、胶价、爆种、补完、不要停 | 梗必须绑定角色选择和代价 |
| 成本过高 | 大量变形、合体、歌舞、巨物战 | 用 Q 版小动画 + 典藏 Pose + 关键帧 Cut-in 控制 |
| 受众割裂 | 中文童年 IP、欧美影视、日系机战经典 | 用章节母题串联，而不是把它们放在同一张海报里 |

## 14. 下一步：从候选池进入制作表

下一阶段详细计划见 [下一阶段细化计划与参战人物层审计 v0.1](./2026-06-19-chao-gag-next-detailing-plan-character-layer.md)。

下一步不应只建立候选包表，而要先把人物层补出来。优先数据表为：

1. `character_archetypes.tsv`：人物原型、梗点来源、原创化方式、禁用边界。
2. `pilot_cast.tsv`：把核心候选包拆成驾驶员、AI、宿敌、支援、整备、舰桥、平民和 NPC。
3. `character_interactions.tsv`：只记录“两个或三个人物放在一起会发生什么新剧情”，避免名单沦为百科堆砌。
4. `roster_candidates.tsv`：把本文所有候选结构化，字段包括锚点、换皮名、推荐层级、风险、评分、互动对象。
5. `crossover_reaction_matrix.tsv`：记录参战包之间的章节级化学反应。

筛选逻辑：

- S 级候选先进入主线章节装配。
- A 级候选进入强支线与隐藏机体。
- B 级候选进入图鉴、城镇、敌方王牌或 DLC 储备。
- C 级候选只保留内部参考，不进入近期制作。
