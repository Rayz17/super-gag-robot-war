# V35 C02-C03三话场景拓扑收敛迁移

> Date: 2026-07-24  
> Status: `working_canon_migration`  
> Scope: C02、C03 Current scene topology and C03 outgoing state

## 一、迁移原因

V35第三层审定上界与当前L4 story-chain已经将C02、C03各自收敛为三话：

- C02第三话采用长三幕结构，合并旧拳馆/机械巨台与开放日。
- C03第三话采用Boss决战后的章末游玩收束，合并城梁决战、巨构校正、七海登舰与百机航路发动。

Current Canon仍保留旧四话拓扑，导致：

1. manifest、逐话结构表与Canon episode数量不一致；
2. C02E03仍错误指向已经并入本话的C02E04；
3. C03E03仍错误指向已经并入本话的C03E04；
4. C03百机航路一度在L4稿中被误写成天空铸环发来的邀请，与L3“纪存主动发出邀请”冲突。

## 五、边界

- 本迁移只收敛Current scene拓扑与已由C02-C03 L4决定的出入状态。
- 旧E04内容仍可在History追溯，但不得再次生成第四话Reader。
- C04以前的方舟折叠探测器只有状态音，不等于方舟T人格。
- C03没有集齐百机，也没有获得整城编队。
- 本迁移不提升C04候选剧情为Working；C04仍须通过自己的L4 story-chain。
