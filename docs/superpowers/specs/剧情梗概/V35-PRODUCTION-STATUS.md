## 三、固定执行顺序

当前上位门：创作第三层已经获用户有条件通过并升为Working，第四层逐章完整总纲现已解锁。第四层从C01开始逐章验证；C01-C03的已发生事实继续提供连续性，但其确认状态不代表内容免检，仍可发现和定点修复真实根因；C04起按新母盘重新决定发动机、容量和高光继承，章内话数可随真实容量调整，但全剧预算不得无依据回涨。**结构Working只解锁逐章总纲，不直接恢复C04以后Reader。**

以下为第四层逐章总纲及其下游恢复顺序，当前不得越级执行：

1. C01-C03保留已经成立的故事事实、逐话结构和期末状态，但与后续章节接受同一套独立审查；用户确认只提高推倒重写的证据门槛，不阻止时间、空间、控制权、玩法、IP、关系表演和人类声线问题被登记或定点修复。
2. 每章先建立章级对齐卡和戏剧发动机，再制作《章级预生产模型》与实体动作表，锁定本章真实存在的人物、机体、敌人、机制、空间、控制权、可见大动作、禁止能力与资产边界。重量章在完整总纲前先做尺度、空间、控制链、奇观和SRPG阶段的低精度预演。
3. 预生产模型通过后，再按需要运行角色有限认知沙盘，并制作《章节导演板》与《战斗与玩法预案》；关键场面必须引用预生产项，不能在导演板或预案里首次创造决定因果、胜负或身份的装置、权限、地点和动作。
4. 导演板与战斗预案通过后，再用《物理因果与人物站位板》验证位置、控制权、时间、信息来源和尺度。作者板共同执行玩家可见性门：每个关键场面都要写明玩家可见证据、暂定演出载体、当场必须理解/允许疑问、最低资产，以及删掉梗概旁白后能否仍靠画面、操作和人物行动成立。因果板只允许否决、拆场或简化；发现缺项必须回到预生产模型走新增票。
