# V23全剧重构压力板：15篇60话候选 v23.0

状态：候选全剧结构压力板，不直接覆盖 v01、V21 或 V22。  
用途：在正式重写逐话梗概前，先确认全剧容量、篇章功能、机体密度、玩法段落、关系热度和50问题升级方向是否成立。  
工作方法：本稿按 `chao-gag-writing-pipeline` 的压力板口径写作，先定发动机和章节职责，再进入逐话卡。

## 0. 任务口径

### Scope

本稿要做的不是继续在旧 48 话槽位里补点子，而是用 V22 根设定和 50 问题解法反向重构全剧主线容量。当前推荐方案为：

- 15篇主线。
- 每篇4话。
- 共60个主线话位。
- 支线仍保留开馆事件、关系事件、残响深潜、EX/隐藏关，但不能承担主线缺机体的问题。

### Mother Draft

本稿继承以下层：

- V21：开馆权战争、万机馆棋盘单位、G.A.G.开馆债。
- V22：机器人文化共同语言、会开馆的方舟、G.A.G.文化活化、缩尺锚件转换、原型工房。
- V22.10：A05 星火篇八话厚流程与多谱系机体同场。
- v15/v16/v16.1：大爆点、机战爽点、名场面原创变奏、成人关系卖相、中盘高能连续剧。
- v20/v21 的主线参战可见度、阵营互抢源点、索引表达语法、灯槽通信、陆衡×方舟T工况共生。

### Must Preserve

- 万机馆是“会开馆的方舟”，开馆是行动方式，不是终局营业目标。
- G.A.G.不是万能火种源，而是文化档案、梗、商品、误记、封存和远星误译共同活化出的系统。
- 模型/玩具与真实机体的关系走“模型锚件 + 残响道具 + 实机接口 = 可安装改装模块”，不能玩具直接变真机。
- 主线必须承担机器人大战的机体规模、封面戏、参战谱系和机战名场面。
- A5不能再被压成单一五车合体；V22.10的八话厚流程应作为星火双篇的母本。
- 七海不是恋爱脑或万能内鬼，她是成熟、危险、有手腕的制度内改革派。
- 白鸢不是普通作者女主，她的改写能力既迷人又危险，必须和纪存、七海形成结构性三角。
- 成人关系可以更有卖相和低俗娱乐感，但只限成年/成年感角色，儿童线完全隔离。

### Forbidden Failure Modes

- 只把 48 话拉长到 60 话。
- 每篇只换一个主题名，主线仍像串珠。
- 参战机体仍靠EX或隐藏关补。
- A5压薄，丢掉V22.10厚度。
- 关系线只在幕间聊天，不影响战斗、权限、支援、证词和终局站位。
- 索引被写成无处不在病毒或普通坏AI。
- 远星通信被写成稳定即时电话，丢失迟到回信的泪点。
- 术语压过故事，删除术语后场面不成立。

## 1. 为什么 V23 需要结构级调整

V21把主轴从旧大纲换成“开馆权战争”，这是对的；V22把内核、G.A.G.、原型工房、模型实机转换、谱系容量前置，也很关键。但真正写下去时会出现一个硬问题：48话容不下当前已经确认的材料。

最明显的是A5。星火、变形生命、战队、勇者、特摄、完全版病、重涂三车、彩队巨神残响、电磁五虎机残响、五兽王冠残响、小勇机训练壳、棚守巨影、目录翼模块战，这些不是一个四话篇能自然装下的量。强行压缩会让玩家觉得“你说献给机战爱好者，结果机体和文化都很寒碜”。

其次，原型工房不能只当模型街和作者线之间的一章补丁。它连接作者、模型师、模具、代哥生产、军方武器化和唐胶根系，是生产链主轴。它需要独立篇章，否则唐胶成长、白鸢作者线和模型实机转换规则都会悬浮。

第三，作者遗作、废案角色、原典圣堂、错版合体，本来在V21里挤在一篇共同记忆战争中，信息量过高。拆成“遗作拍卖与废案角色”和“原典圣堂与错版合体”两篇，才能既写创作伦理，也写粉丝共同记忆、仪式狂热和机战合体爽点。

第四，七海和白鸢如果只到中后段才真正加温，玩家很难相信她们能和纪存进入恋人/危险共犯层级。V23必须让她们从早期就以不同方式介入纪存的策展动作：七海给流程缝隙，白鸢给改写诱惑，纪存不是被动夹在两人中间，而是每次公开展示时都在选择怎样使用秩序和叙事。

所以V23不是“更长”，而是把旧结构压扁的几个大材料拆出来，让它们以主线级事件成立。

## 2. V23一句话主轴

万机馆带着被封存、商品化、改写、误译和清噪的机器人文化记忆，在十五次“开馆权战争”中逐步证明：共同语言不是让所有机器人服从一个最正确的模板，而是让超级系的燃、真实系的失败、勇者的承诺、变形生命的自我、战队的喊名、模型玩具的手作、战争里的撤退、创作者的缺页、制度里的例外、远星的迟到回信，都能公开站到观众面前，并为自己的后果负责。

## 3. 全剧压力板

### Premise

旧世界因G.A.G.事变而分裂：有人害怕机魂活化，有人把它商品化，有人把它武器化，有人把它封存，有人把它改写成正确版本。万机馆原本是机器人文化博物馆，后来展舰化，成为流亡中的开馆方舟。它每到一处都不是旅行，而是在争夺一种公共权能：谁能命名、展示、使用、解释并承担机器人文化的后果。

### Main Conflict

表层冲突是万机馆被代哥、平台、军方、原典圣堂、索引和远星误译追逐。深层冲突是：机器人文化到底是危险资产、商品目录、军事样本、作者原典、算法模板、异星遗产，还是仍然可以由人、机器、模型、玩家和观众共同继续创造的语言。

### Enemy Learning Chain

索引不是开局全知。它逐篇学习玩家和万机馆最珍贵的东西：

- C01-C02：学习命名、模型认亲、观众留言和旧件托管。
- C03-C04：学习失败记录、主体性、同步救场和改写诱惑。
- C05-C06：学习变形生命、五色喊名、勇者合体、巨大化、完全版病和共同语言。
- C07-C08：学习同步灾害、撤退战、歌声停火、红色追击和量产机逆袭。
- C09-C10：学习废案角色、作者保护、原典仪式、错版合体和粉丝共同记忆。
- C11：学习七海白名单、流程例外、纪存/白鸢/七海三角关系。
- C12：生成“完美战役”，用玩家最喜欢的强玩法反打玩家。
- C13-C15：把远星误译、开馆方式内战和终局全员支援压缩成“完美最终话模板”。

### A/B/C/D线

- A线，开馆权战争：每篇争夺一种开馆权能，并让敌方至少赢走某个东西。
- B线，G.A.G.真相与索引显影：前期是好笑有用的异常，中期被商品/制度/战争利用，后期变成开馆债与完美模板。
- C线，成人关系与团队分裂：纪存/七海/白鸢三角贯穿主线，唐胶/兜灯、赤罡/莉歌、陆衡/方舟T形成不同类型的亲密和债务。
- D线，机体与文化谱系：每篇至少有封面机体、可玩/支援新增、敌方镜像、馆藏锚点和隐藏/后续伏笔五层。

### Relationship Heat

纪存和七海的核心不是“敌对后被说服”，而是流程里的危险私心。她越帮纪存，越能掌握违规证据；她越封存，越证明她真懂危险。纪存和白鸢的核心不是单纯创作者恋爱，而是“记录者和改写者”彼此吸引也彼此伤害。白鸢能把纪存放进她的分镜里，纪存能把白鸢的错误也放进展柜里。三角关系要在C01-C03埋种，C07-C11升温和破裂，C14公开站位。

成人卖相的载体不是露骨行为，而是权限、封条、维修舱、战损、全息贴脸、接口、过热、共用终端、频道静音、病房守夜和不能解释的例外。儿童角色只承担家感、观众、托付和未来感，不参与暧昧。

### Mecha Roster And Asset Tiers

V23用五层机体可见度防止主线寒碜：

- 全量参战/主线候选：正式进入可玩或长期支援树的机体群。
- 中量援护：有Cut-in、战斗效果、支援台词和回收条件，但不完整入队。
- 临时支援参战：只在本篇或特定战斗响应，不开放完整数值和改装树。
- 场景机体/设施单位：改变地图、地形、胜败条件和演出，但不入队。
- 敌方镜像/模块：让玩家理解某类文化被误读或商品化后的战斗形态。

每篇功能表必须写清这些层级。隐藏机体可以提前支援、显影、Cut-in，但不靠EX补主线规模。

### Gameplay Modes

SRPG战棋仍是骨架，但每篇要有不同玩法入口：

- 闭馆路线探索、保护战、展舰起航。
- 模型街经营/开馆、防拍卖、防追踪。
- 原型工房潜入、灰模修复、模具/接口选择。
- 失败机试验、防剪辑、数据评审战。
- 星火双篇的护送、扫描、舞台、合体、巨大化、发布会、模块拆解。
- 同步灾害、撤退护送、歌声停火、三方混战。
- 废案拍卖、分镜格地图、原典仪式、错版合体。
- 白名单听证/审查规则战、三门战场。
- 残缺UI反攻、索引镜像战。
- 灯槽通信战、迟到回信拼接。
- 展舰分区内战、最终全员支援战。

### IP Homage And Gag Targets

V23每篇不直接复刻IP名词、造型和台词，而是把共同记忆原创化为规则：

- 红色更快变成诱人的追击路线。
- 合体口号变成承力、许可和错词。
- 修正掌变成角色之间的现实冲突，不做照搬。
- 歌停战变成一回合停火和敌我共同迟疑。
- 99命中/概率玄学变成G.A.G.概率异常。
- 后继机登场、量产机逆袭、最终话全员支援都进入主线。
- 完全版病、重涂军团、尖刺背包、支架依赖进入A5/A6的商品化战斗。

### Emotion Objects

全剧不靠大词催泪，靠物件三次使用：

- 万机馆馆名章：C01被冻结，C12被清噪，C15由观众重念。
- 社勇王盒/旧货柜锚件：C02认亲，C05-C06引发星火双篇，终局成为玩具到实机的共同证物。
- 失败计数：C04轻用，C12被索引清零，C15由失败机自己恢复。
- 撤退名单：C08痛点，C14成为路线争论，C15补上无人认领者。
- 错版台词卡：C10救场，C12被模板化，C15全员喊成自己的版本。
- 白名单编号：C11救人，C12反咬，C14/C15决定七海站位。
- 迟到回信：C13刺痛，C15成为远星声部。

### Branches And Long Debt

分支不只加变量。每个长期选择必须改变：

- 玩家常看的界面。
- 一台机体状态或支援台词。
- 一个角色站位或误会。
- 一个展柜/证词/观众声部。
- 一次后续敌方利用。

错误选择也要先好用，之后反咬。比如效率拆星火车队短期更强，但A06终局医疗胸灯缺失；七海白名单路线能救人，但C12成为索引学习流程例外的样本。

### Canon Boundary

V23是候选结构。它可以吸收V22根设定与V22.10 A5厚稿，但在用户确认前：

- 不直接改白鸢正式出场硬锁，只把白鸢前置继续列为候选迁移。
- 不把隐藏机体完整入队前移。
- 不把A05临时支援全部做成全量资产需求。
- 不把15篇60话提升为工作正典。

## 4. V23 15篇60话结构

### C01 闭馆夺名与展舰起航，E01-E04

功能：把玩家、纪存、万机馆、馆守Z、代哥清算、七海远程流程、开馆权战争一次性立住。  
开馆权：命名权。代哥不是单纯封馆，而是冻结“万机馆”这个名字，把它改登记为待清算资产。  
玩法：闭馆路线探索、展厅保护战、馆守Z半启动、火警/封存双压力、展舰起航。  
机体生态：馆守Z作为18米级退役实机压场；社勇王模型、超级系展柜、真实系驾驶舱、勇者玩具、舰桥模型和B1格纳剪影提供主线规模承诺；封存无人机和0号开启臂作为敌方执行单位。  
关系：纪存第一次用档案终端把混乱翻译成行动图；七海远程给流程缝隙但保留追责编号；唐胶/兜灯维修默契轻触。  
敌方收益：清算拿到未归档清单、0号异常样本和移动风险编号。  
新增理由：V21三话开局略紧，V23给四话让闭馆路线、万机馆厚度、火警信息、展舰化和第一战斗都有完整空间。

### C02 模型街临时开馆，E05-E08

功能：把模型/玩具从温情支线升级为主线关系钥匙和开馆行动。  
开馆权：展示权和托管权。模型街不是被救地点，而是万机馆第一次外部临时开馆。  
玩法：模型街探索、摊位防卫、限定拍卖打断、取件追踪、旧货柜锚件深潜入口。  
机体生态：社勇王送修模型继续回收；旧货柜玩具锚件首次明确；模型街旧件、改件、错拼件进入未来缩尺锚件库；小型暴走玩具和限定扫描无人机作为低阶敌群。  
关系：唐胶从维修吐槽者变成热爱被标价的见证人；纪存把羞耻旧件和昂贵限定放在同一场临时展；七海的清单不是坏意，而是模型街确实存在倒卖和危险。  
敌方收益：平台取得模型街热度、代哥取得限定流通风险证据，索引采到“羞耻也可以被优化成商品标签”。  
新增理由：承接C01变量，证明“玩具/模型”和“真实机体”不是后期解释，而是早期玩法和情感根基。

### C03 原型工房与灰模母版，E09-E12

功能：把原型工房正式推为生产链桥梁，让唐胶、白鸢、纪存和代哥生产逻辑同场碰撞。  
开馆权：生产过程能否公开成为展品。  
玩法：原型工房潜入/听证、灰模母版保护、模具接口选择、军方抢接口、防伪样件战。  
机体生态：灰模零号、母版吊臂、模具检验机、军方接口采样机、原型残响体；这些不都入队，但要让玩家看见“幻想如何变成结构”。  
关系：纪存必须做核心决策：万机馆是否有资格把生产链伤口公开成展品。唐胶承担修型责任，白鸢承认角色不是只靠作者意志活着。白鸢前置在本篇仍是候选迁移，若采用，应在C02尾声以空白格寄售台自然引入。  
敌方收益：军方拿到可武器化接口样本，代哥拿到母版合规争议，索引采到“创作可以被拆成标准流程”。  
新增理由：这是V23相对V21最大结构补充之一。没有它，模型实机转换、代哥生产链、唐胶成长和白鸢作者线都会缺少物质层。

### C04 失败机试验场，E13-E16

功能：把现实机器线从“失败也可爱”升级成制度剪辑和采购叙事战争。  
开馆权：失败记录能否公开展示。  
玩法：现实机器试验场、防剪辑战、数据评审无人机、失败路线保护、非致命压制。  
机体生态：跌跌/失败机群、数据评审无人机、采购演示机、陆衡现实机器工具链、方舟T幽默参数轻触。  
关系：陆衡不是纯理性派，而是曾经相信删掉失败上下文能保护项目；纪存策展高光是把失败白板、停顿、摔倒路线和维修手套并置成证词。  
敌方收益：索引采到成功剪辑模板；军方拿到“可采购成功样本”；方舟T留下第一条坏笑话日志。  
新增理由：把原V21 A03保留，但因为C03新增原型工房，本篇顺延；这能让“灰模到失败实机”的生产链更顺。

### C05 星火车队：变形生命与五色开馆，E17-E20

功能：继承V22.10 A05-1到A05-4，先完成旧货柜、形态扫描、五色站位、必要合体。  
开馆权：变形生命和群众喊名是否能脱离商品SKU被看见。  
玩法：护送战、标签修正战、重涂识别、形态扫描、五色舞台防卫、合体调试。  
机体生态：星火五车、火种旧货柜残响、重涂三车、五兽王冠残响、彩队巨神预显影、五色兽机残影、社勇王中量援护、电磁五虎机节拍、小勇机训练壳。

## 6. Writer Room 初审

### Showrunner

V23比V21更像一季机器人长篇番剧，因为它不再强迫A5、作者线、七海线和远星线挤在一起。当前最大风险是C09/C10都和“创作/原典”相关，逐话阶段必须用完全不同的类型片处理：C09是拍卖、潜入、分镜恐怖；C10是仪式、台词护盾、错版合体。

### 50-Issue Auditor

本稿回应了几个旧共性病：结构串珠、机体不足、A5压薄、关系dry、梗点机械、G.A.G.曝光少、深潜退化、EX补主线短板。但这仍只是压力板。下一步逐话卡必须继续对每话填写敌方得手、机体生态、玩法规则、关系后果、情绪物件和下一话债务。

### Mecha/IP Specialist

C05/C06是目前机体密度最明确的双篇。其他篇章还需要参战承载卡，尤其C07、C09、C11、C13不能只写剧情概念。每篇至少要明确封面机、可玩新增/强化、敌方/Boss、支援/隐藏、馆藏/外部会合五类。

### Gameplay Designer

玩法入口已经覆盖较多，但C09/C10/C14需要在逐话卡阶段特别细化胜败条件。尤其C14内战不能写成剧情CG，应通过展舰分区、支援点拆分、泊位争夺和路线试用战来玩。

### Character / Relationship Editor

纪存的魅力方向正确：策展、命名、并置、公开承担，而不是靠犯错。七海和白鸢有成为主关系线的空间，但必须从C01-C03就开始连续推进，不能等C11才升温。成人卖相要在C11大爆，但C05/C06、C07、C09也要有可回收动作。

### Canon / Asset Steward

V23应登记为候选结构，不应直接覆盖V21/V22。A5相关资产必须继续按V22.10的分层规则处理。白鸢前置仍需作为候选迁移管理，不得直接改硬锁。15篇60话若被用户确认，再进入逐话梗概和canon迁移。

## 7. 下一步建议

下一步不要直接写60话长梗概。建议按 pipeline 进入：

1. 先写 `C01-C03` 逐话 episode cards，验证早期读感和白鸢前置候选是否自然。
2. 再写 `C05-C06` 星火双篇的V23映射卡，确保V22.10完整继承。
3. 同步做“15篇参战承载卡”和“15篇名场面/玩法梗点矩阵”。
4. 通过后再逐批写 C04-C08、C09-C12、C13-C15。

本稿通过审稿前，不应把60话当正式定稿；它现在的作用是防止下一轮逐话创作又滑回旧48话、A5压薄、机体不足和关系线干聊。
