## 6. Draft Synopsis

### Function

C03E09要把残响深潜从“查资料”变成真正的玩法和情绪。玩家进入模具库的版本层，不是为了拿满资料，而是在有限窗口里选择什么完整带回、什么只带回一半、什么被牺牲。纪存的主角动作是承担优先级，不把取舍伪装成全保存。

### Story Flow

开局复核E08结果。若先查署名墙，入口多出手刻名残光；若先查母版仓，路径更完整；若先查失败测试区，安全参数更清楚但白鸢疑心更重。生产封存令在倒计时，预展对象越多，追踪压力越大。纪存把这些状态发成任务板，不解释给观众，而是让队伍知道这次深潜每一步都在烧证据。

地下模具库像一盒巨大模型被从内侧翻过来。流道变成道路，浇口像桥，说明书箭头成为移动方向，透明支架把道路吊在半空，废弃贴纸像路标粘在墙上。深潜窗口由万机馆旧黑匣子、模具母版和G.A.G.调律开出，伴随`oxygen_noise_level`。停得越久，地图越会被“官方正确姿势”修正：错件、旧名和失败批注会被擦掉。

进入前四方目标同时弹出。唐胶要灰模零号肩轴和后颈接口，想知道它为什么每次断在同一条线；白鸢要找旧标签“不要替它补完”的源头，怀疑那是角色最后一次拒绝商品化；兜灯要安全参数，因为馆守Z右肩和灰模零号接口有异常相似；陆衡远程要失败批注，因为C04现实机器线需要证明失败不是污点。纪存把任务分成署名、结构、主体性三类。玩家选主目标，另一类只能部分取样，最后一类必然牺牲。

第一段是说明书迷宫。玩家按箭头、卡扣方向和零件编号移动。硬掰捷径会缩短路线，但增加氧噪，让后续证据被修正夹具推回官方姿势。敌方不是怪兽，而是修正夹具、清洁机、浇口巡游机和贴纸剥离器。它们把手刻名擦成品牌编号，把失败姿势拉成标准商品站姿。旧拳王非致命支援若在C02保留，可把工具机推出格子而不伤证据。

第二段是三版本废案展示层。白鸢看到同一个角色被改成儿童版、限定尖刺版和接口武器版。她不是单纯愤怒，而是一瞬间兴奋，因为她看见可以把被改坏的角色重新画回自己能忍受的样子。纪存看见这个兴奋，没有当场羞辱她，只把“改写冲动”记进未公开关系债。白鸢注意到他的视线，先把分镜页往胸口压了一下，又故意把页角往外推半寸，像是在说：你看见了，那你敢不敢管。这个动作让二人的关系从互相判断变成互相试探。

三版本废案不是概念投影，而是三组半透明结构残响体。儿童版边缘圆滑，行动规则是把尖角和旧贴纸包成安全外壳；限定尖刺版会追着镜头伸出多余尖刺，把“强度”伪装成角色；接口武器版把右臂转换成枪臂轮廓，专门追逐后颈波形。它们每回合切换一种可视轮廓，敌方工具机会按当前轮廓重写证据。唐胶看见更硬的东西：三种版本都断在同一条轴线。白鸢问如果它宁愿断也不想被改成别人的手怎么办。唐胶只回答工艺：那就先别把手当武器，也别把断轴当性格。

母版铭牌台触发纪存机魂不适。铭牌被修正夹具拉成标准姿势时，他胸口和手腕同时发冷，像自己也曾被固定成某个“最适合展示”的角度。这不是身世揭示，但让他识别出修正夹具真正危险之处：它不是擦掉失败，而是把失败改成从未存在。他因此能标出一条隐藏路径，绕开最强擦除区，但代价是氧噪上升并让索引记录他的判断。这个记忆不会在本话解释完，只留下一个会继续回响到E10/E11的症状：凡是“漂亮站姿剪辑”和“条款改词”出现时，他的手腕都会先冷一下。

兜灯和唐胶的关系通过工具权限外放。唐胶为了追一个承力接口多走一格，兜灯远程切掉他工具权限十秒。唐胶嘴上嫌她比安全手册还烦，身体却退回来，因为前一格其实是清洁机重铺过的薄片。她没说我救了你，只把权限还回去；他也没道谢，只把找到的疲劳纹发给她。这种动作比调情台词更像他们。

高潮是三类目标塌缩。代哥封存令回写进版本层，军方接口采样机伸进另一层，平台故事包无人机开始自动命名“未确认角色三版本”。玩家选择最终带回物：母版铭牌、失败批注、拒绝补完边注。选择主体性时，边注真意揭示：不是“不要完成我”，而是“不要把我完成成唯一版本”。这句话刺中白鸢，因为她一直以为自己保护的是原意，却第一次看见原意本身也是争夺场。

退出时不是拿资料。唐胶工具箱里多一片白化轴套，兜灯安全表多三条红线，陆衡拿到半段失败曲线，白鸢分镜页角落多了一个她不记得自己画过的逗号。纪存把带回物分成可公开证词、需授权证词、危险接口。终端随后弹出一个看似贴心的建议：“下次遇到类似目标，建议优先保留可战斗接口。”旧守护者广播卡顿，把“建议”读成“剪掉”。玩家由此第一次感到索引不是病毒跳脸，而是把复杂冲突整理成太顺手的模板。
