## 6. Draft Synopsis

### Function

C02E02是模型街的第一场战斗，但它不能把玩家喜欢的模型样件变成经验包。战斗的核心是非致命、护摊、护人、截物流。玩家必须看见：这些样件不是真的想伤人，它们只是把“保持商品完好”误认为“活下去”。

### Story Flow

开场从价格屏集体跳红开始。旧卡扣、社勇王缺页、未发售样件和几件退坑柜旧模型被平台同时推成“灾后限定”“未发售概念”“馆守Z同批件”。倒计时本身不攻击人，却比敌人更能改变街区：人群向价格移动，摊主开始收盒，临时托管柜前出现争执，快递车从后巷改道。采样贴片趁乱给旧货贴白色编号，封存无人机不砍人，只拉出临时物流通道，把街区切成几段。

人群不是暴徒。一个老玩家站在退坑柜前明知道价格离谱，还是想买回当年错过的版本；一个摊主不是贪，只是看到旧盒突然能换孩子下个月房租。唐胶看见这种犹豫比看见恶意更烦，因为他知道这些人不是坏，只是被稀缺推着走。纪存必须把“保护街区”从口号变成目标分配。

未发售变形样件开始失控。它们先护住透明包装盒、错别字昵称牌和旧站位线，而不是攻击人。一个样件把展示盒当胸甲扣上，另一个把“限时锁价”贴纸当身份牌贴到关节。红/蓝/黑三台重涂喷气样件冲出仓库时，围观玩家脱口喊“红色三倍速！”红色样件真的获得高速移动，但刹不住，差点冲出安全线；蓝色样件用音爆打断价格屏，却震裂一排盒盖；黑色样件镜像换位，把自己和价格标签调包。笑点要准，但立刻有代价：价格屏把三台打包成颜色套装，引发更强自我识别混乱。

唐胶意识到直接攻击会让样件把自己锁死在商品状态。兜灯立刻要求切非致命程序。唐胶把工具箱踢到她脚边，兜灯封掉伤害输出，唐胶保留推离、定身和断价屏，纪存登记为“商品生命未确认非致命协议”。这不是台词讲伦理，而是玩家真正获得一套非致命动作：推离、定身、断屏、保护包装盒、截断弹幕输入。

战斗地图分成三处压力。旧货摊有姓名贴、旧卡扣和模型病历证物；折叠凳区有孩子，也有被人群挤住的成年人；物流车装着采样箱、样件和来源码。追物流能抓证据，但旧货摊会被价格屏人流冲散；护摊能保物件，但样件越积越多；守人群能保信任，但物流车会走。玩家低改队伍只能全保两项，高改可挑战全保，但全保会让清算追踪精度上升，因为所有行动都被记录。

中段开放样件仓库短调查。玩家在回合间用盒绘、昵称、疲劳纹和维修记录筛选哪些样件有真实关系痕迹，哪些只是平台拿来炒概念的壳。唐胶靠手感，兜灯靠疲劳纹，旧守护者若C01核心保存好，会用古板播报标出安全格。正确筛选减少C02E03胶价王护盾；错筛会让拍卖台多一层“伪残响故事包”。

第5回合七海清单弹出。她仍然不来现场，只把刚救下的对象列成“未登记商品生命”“移动风险源补给件”“儿童滞留安全隐患”“未授权非致命干预”。清单准确得能救人，也冷得能伤人。纪存可以公开清单，让街区知道清算正在追踪，降低谣言但提高恐慌格；也可以压住，降低混乱但形成信任债；如果C02E01转给唐胶，唐胶会主动通知摊主先收姓名贴，不先收价格牌。

公开清单会立刻带来外放后果：几个摊主开始撤摊，人流往出口挤，红色样件刹不住差点撞倒取件柜；但公开也让折叠凳区提前撤离，保住一个被人群挤住的老玩家。压住清单则街区短暂安静，非致命战更好打，但一辆物流采样车趁信息不透明带走一箱来源码，战后有人质问万机馆为什么没早说。纪存的选择不再只是账本变量，而是现场有人因此被救、有人因此失去证据。

高潮是物流车启动。采样贴片把一箱样件和一段来源记录装上车，价格屏把“灾后限定慈善拍卖”推到所有屏幕。玩家无论如何都很难完美阻止：至少一箱样件、一个旧卡扣来源码或一段物流证据会被带走。唐胶把错别字昵称牌贴回地上的透明盒；兜灯把非致命协议封存为临时工具，而不是战利品。结算界面清楚显示：孩子安全、旧货摊保存、物流证据、样件状态四项不能全部满。

结尾，胶价王第一次出现。它不像人，更像价格屏给自己戴的一顶王冠。直播预告把公文包姓名贴、馆守Z同批卡扣、未发售样件和旧拳王右拳护具排成拍品。屏幕把玩家保护动作也包装成卖点：有人护着，所以有故事；有人抢救，所以更稀缺；有人不愿公开，所以更值得看。唐胶第一次没有马上骂，先去看那个公文包成年人还在不在。

### Battle and Gameplay

类型为8回合非致命保护战、人群流向战和战中调查。地图包括主路、旧货摊、折叠凳区、样件仓库、价格屏塔和物流车出口。胜利条件是至少保住两类目标，阻止样件伤人，物流车不能满载离场。失败条件是人群恐慌清零、失控样件被致命击破、旧货摊核心证物全丢或物流车满载。

价格屏每两回合改变人群流向，红蓝黑样件各有功能：红高速冲线，蓝断屏但伤盒，黑换位混淆标签。非致命协议提供推离、定身、断价屏、保护包装盒。七海清单公开会让部分NPC撤离更快，但恐慌格上升；压住清单则街区暂稳但后续信任债更重。

### Heat / Spectacle / Gag

燃点是玩家用非致命方式保护还不知道自己是什么的样件。爽点是三台重涂样件各有战术功能，红色真的更快但危险，蓝色能断屏，黑色能调包。梗点包括限定倒计时、透明盒、错别字昵称牌、抢购Bot、物流车和“价格比敌意更像敌人”。

### Emotion

核心情绪物件是错别字昵称牌、透明包装盒和被带走的一箱样件。错别字说明它被某个人认真叫过，透明盒既是保护也是牢笼。泪点在于通关也会丢东西：玩家保住街区，却看见自己没守住的那一箱下一话被包装成故事卖点。

### Relationship

唐胶和兜灯出现更明确的维修间火花。兜灯拍掉唐胶伸向发烫卡扣的手，唐胶嘴上嫌她管得宽，实际把工具箱踢到她最顺手的位置。兜灯把他的临时改法写成“非致命工具”，没有写成违规武器。纪存和七海的关系继续锋利：她的清单精准到能帮忙，也精准地伤人。

### Protagonist Arc

纪存本话的选择不是“要不要40秒”，而是是否把风险告诉街区。他若公开，就承担恐慌和追踪，但救下被人群挤住的人；若压住，就保住秩序，却让物流车带走一箱来源码或让街区战后质问。机魂旧痛在“未登记商品生命”四个字出现时刺他一下：编号分类正在把旧昵称和姓名贴重新推成标签。这让他选择非致命协议而非清场。

### Jicun Memory

七海清单把样件列成“未登记商品生命”时，纪存短暂听见C01编号记忆和E01旧昵称记忆叠在一起。症状是终端自动把几个错别字昵称牌归入“可清算标签”。他手动撤回这个分类，非致命协议因此获得“先断误读，再动手”的限制。代价是系统记录他干预清算分类，后续七海会看到这不是普通操作失误。

### Branches and Debt

`street_trust`影响C02E03卖家说得。`logistics_evidence_state`影响能否证明胶价王和清算采样勾连。`sample_loss_state`影响拍卖台护盾。`nonlethal_protocol_state`影响旧拳王擂台能否稳定启动。`qihai_list_publicity`影响市民作证、七海误判和追踪。`public_panic_or_hidden_loss`记录公开造成恐慌还是压住造成证据损失。

### Clear State

模型街大部分人和旧货摊保住，但平台取得热度，代哥取得未登记商品生命证据，索引后台采样到“羞耻、稀缺、保护动作可以转价格”。胶价王拍卖台预告启动，C02E03进入规则Boss战。
