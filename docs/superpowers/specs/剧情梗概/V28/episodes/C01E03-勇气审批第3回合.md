## 6. Draft Synopsis

### Function

C01E03负责把“支援”做成第一章的第三层玩法。C01E01保护名字，C01E02让馆守Z动起来，本话让玩家明白：在这个世界里，援护、热血、合体口号和支援Cut-in都不是免费按钮。它们可以救人，也会留下责任、追责和敌方学习样本。豪司正式回到第一章，但他不是开着社勇王来抢戏，而是在远程审批系统里把“勇气”签成一次有代价的临时许可。

### Story Flow

C01E02战斗刚结束，玩家以为终于能用支援系统喘口气，所有支援按钮却同时灰掉。档案终端上不是“冷却中”，而是三行很冷的拒绝理由：未确认责任主体、未确认承力赔付、未确认异常归属。纪存想先用自己的权限强行恢复支援，终端却弹出一个空白签名框，框里没有名字，只有一行小字：无责任主体行动将归入G.A.G.异常。

勇气审批角的社勇王模型盒开始自己盖章。不是热血BGM，而是很小、很密的“咔、咔、咔”。小满在黄线里急得踮脚，她看见模型盒盖亮起来，脱口喊：“我来组成头部！”这句可以直接出现，因为它正好是玩家共同记忆，也是孩子理解合体的方式。纪存没有让她冲出去。他蹲下，把终端转给她看：头部不是最前面那个，是看得最清楚、签得下名字那个。模型可以亮，孩子不能替模型挨罚。

金章AI把这句误译成“头部责任签名”，在地图上盖出第一枚金色印记。豪司的远程窗接进来，他身后不是机库，而是一排合体申请柜、盖章机和被退回的周报。他确认的第一件事不是喊口号，而是问：你们那边还有人没撤完吗？听到还有小满、阿澄、旧导览机核心和被切在外侧的维修推车，他没有等完整审批。他说临时承力许可先批，责任写我。

第2回合，封存无人机投放责任空白框。空白框会吸附在玩家用过但没有签名的支援动作上，累计三次就把该动作归为G.A.G.异常，并提高封存等级。玩家开始分配支援点：纪存签策展风险，可以把社勇王盒、留言碎片或旧导览机核心登记为临时证词；兜灯签机械承重，可以让馆守Z右肩通道不立刻过热；豪司签勇气越权，可以用金章印记临时打开一条封存路线。三个人都签，支援强，路线亮得像勇者片，但待审名单也会变长。

第3回合，代哥支援封锁框切断勇气审批角和前厅封存闸。金章AI提示“最终承力许可未完成”，这句不是直接照搬名台词，而是勇者许可的原创化系统梗。豪司短暂沉默，像是被那句“最终”刺到。他承认自己没有完整批准权，但他有一个成年人的选择：先把人带出去，后面处分找他。这个动作让豪司不再只是搞笑社畜，而是一个怕勇气只是公司口号、所以宁愿把口号签成责任的人。

第4回合，纪存看见空白框吞掉一个未签名支援，机魂记忆突然回流。他短暂看见一段旧画面：一台机器替别人挡下攻击，记录里却没有签名；后来那次行动被归为异常，被清噪、被折叠、被写成系统自己失控。纪存的手指停在“由纪存统一签名”选项上，没有按。他意识到自己一个人全签，看起来像保护同伴，实际上会把所有人的行动变成他的命令，也会让未来所有人没有为自己作证的资格。

七海在第5回合弹出安全路线。她给出的路线很合理：放弃火种货柜锚件、跌跌演示屏和部分社勇王说明书缺页，换取观众和主厅结构更低损撤离。她没有嘲讽，也没有威胁，只是把代价摊开给纪存。纪存没有骂她冷血，他把这条路线也公开在终端上，同时标明被放弃物件会失去什么证词。七海看着公开记录停了两秒，把“勇气越权立即封存”改为“待审”。这不是帮忙，是给他可追责地继续犯险。

高潮是金章临时通道。纪存签策展风险，兜灯签右肩承重，豪司签勇气越权。三枚签名把社勇王模型盒、馆守Z右肩和勇气审批角地面连成一条金色临时通道。馆守Z没有站起来，只把右肩抬起半格，形成能让小单位通过的承力坡道，挡住0号开启臂残压，并把被切在外侧的维修推车和留言碎片送回安全区。玩家第一次真正玩到“舰内角色支援点数影响棋盘单位”的雏形：主角团不在棋盘上当普通步兵，但他们的签名、位置、关系和专业能力会改变棋盘。

战斗结束时，豪司通讯被上级切断。断线前他只留下普通一句：盖章是我盖的，别让模型盒替我背。纪存把这句存成“责任签名”，不把它修饰成漂亮口号。社勇王盒盖终于合上，但夹住了缺页说明书的一角。唐胶没说大道理，只把盒盖又调松半圈。小满在黄线里小声问，这次它算帮上忙了吗。纪存说，算，但不是你替它挨罚。

### Battle and Gameplay

类型为SRPG支援系统教程加责任签名战。地图是L1主厅残损版，包含勇气合规厅、前厅封存闸、馆守Z右肩通道、模型病院侧门、留言墙回收点和0号侧廊门口。馆守Z仍是2x2半跪单位，但本话的核心不是移动它，而是用支援点改变它的右肩通道、支援范围和封锁路线。

胜利条件：保护社勇王模型盒不被封存；清除或签名化至少3个责任空白框；用金章临时通道送回旧导览机核心或留言碎片之一；阻止0号开启臂残压连续接入。失败条件：责任空白框累计3次未签名支援；社勇王盒被拖入封存框；馆守Z右肩承重归零；小满/阿澄所在黄线被封存线覆盖。

核心机制：第1-2回合只有2点本地支援点，纪存/兜灯可签，豪司槽灰显；第2回合若保护住社勇王盒并清掉至少1个预告框，第3回合豪司接入时获得1枚预签金章。第3回合起每回合3点支援点，纪存/兜灯/豪司各可签一次。纪存签“策展风险”，把对象登记为临时证词，降低被封存优先级；兜灯签“机械承重”，降低右肩过热并扩大通道稳定范围；豪司签“勇气越权”，打开一条封存路线或提高一次援护强度。完整三签路线最强，但增加`haosi_violation_record`和`responsibility_signature_matrix`追责债；少签路线债少，但通关更难，`shayu_box_state`更容易受损。

目标判定块：

- `blank_frame_signed_count >= 3`：至少3个责任空白框被签名化，签名化后保留为追责证据而不是消失。
- `unsigned_support_count < 3`：全局未签名支援累计达到3次即失败；已签名支援不计入失败，但写入`responsibility_signature_matrix`。
- `shayu_box_state != sealed`：社勇王盒被支援封锁框拖入封存格即失败；若只受损，则进入C02为缺页/卡扣受损状态。
- `guardian_shoulder_load > 0`：馆守Z右肩承力归零即右肩通道崩塌失败；兜灯签名可恢复1级，纪存签名只能公开风险不能修机械。
- `yellow_line_integrity > 0`：小满/阿澄所在黄线被封存线完全覆盖即失败；纪存签名可把黄线登记为观众安全证词，降低敌方优先级。
- `zero_arm_residual_contact_count < 2`：0号开启臂残压连续2个敌方阶段接触右肩通道即失败；用金章通道、馆守Z肩桥或兜灯承重签名可重置计数。

签名效果表：纪存单签让一个目标从“异常物”变成“临时证词”；兜灯单签让一段通道稳定并降低过热；豪司单签打开一格封存路线但增加越权记录。纪存+兜灯可保守稳线，适合低债通关；纪存+豪司可快速救物但制造更多听证压力；兜灯+豪司可短时强行开路但容易损坏社勇王盒；三签触发金章临时通道，救回目标最多，同时把三人的名字写进待审矩阵。

回合触发：第1回合支援灰显和空白框预告；第2回合责任空白框投放，豪司槽仍灰显但可被社勇王盒预签；第3回合豪司远程接入并开放临时承力许可；第4回合纪存机魂记忆触发，解锁“分配签名”而不是“统一签名”；第5回合七海安全路线弹窗；第6回合或满足三签条件后触发金章临时通道救场。

### Mecha Appearance

社勇王模型盒是toy anchor，不是真机。它通过盒盖、缺页说明书和盖章声触发勇者谱系支援。

豪司是remote support character，不作为棋盘初始单位。他的功能是签署勇气越权责任，给一次或多次金章通道支援。

金章AI只以UI印记、盖章声和短句出现，不解释人格史。它的功能是把签名转成地图上的临时承力许可。

责任空白框和支援封锁框是代哥敌方模块。它们不说话，只把无署名支援归为异常，把支援按钮灰掉。

馆守Z右肩通道是地图机制，不是新机体。它承接E02右臂/胸牌债，并把支援点数转成可通行地形。

### Heat / Spectacle / Gag

燃点是“勇气也要有人签名”，不是把热血降格成手续，而是把手续变成热血必须承担的影子。爽点是第3回合金章印记从模型盒一路盖到馆守Z右肩，地图上灰掉的支援按钮重新亮起一排。梗点包括直接短引“我来组成头部！”、勇者审批、最终承力许可、合体头部责任，以及援护支援从UI按钮变成地图道路。

### Emotion

情绪物件是社勇王盒盖和缺页说明书。盒盖从E01的小满取件理由，到E02唐胶护住的小模型，再到本话被流程推成异常源。缺页不是隐藏设定说明，而是一块空白：系统想把它当无主异常，纪存和豪司则把它变成有人签名的支援证词。

### Relationship

纪存和小满的关系在本话有清楚边界。小满可以喊出热爱，可以让模型亮起来，但不能被剧情拿去承担成人后果。

纪存和豪司建立第一次同盟。豪司不是只会喊勇气的人，他愿意把审批系统里最危险的一栏写成自己的名字。

纪存和兜灯的E02信任延续。兜灯的机械承重签名不是“辅助Buff”，而是防止右肩通道塌掉的硬条件。

纪存和七海继续危险互认。七海给安全路线，纪存公开路线和损失，七海把立即封存改成待审。两人没有和解，但都在给对方留下可追责的活路。

### Emotional Accumulation

社勇王盒连续三话积累：孩子取件、唐胶抢救、豪司签名。本话的情绪不是突然煽情，而是让玩家意识到一个小模型能把孩子、模型师、勇者驾驶员、策展人和企业审查串在同一个责任框里。

### Protagonist Arc

纪存本话的诱惑是自己替所有人签名，省事、干净、像主角承担一切。外部打击是责任空白框把无署名支援归为G.A.G.异常。内部崩点是他记起某次无名支援被删除署名后变成异常。最终选择是分配责任：他签策展风险，兜灯签机械承重，豪司签勇气越权。代价是更多同伴进入待审名单；升级是纪存获得“支援权限调度”能力，并接受自己不能独占所有保护权。

### Jicun Memory

本话记忆碎片不是身世百科，而是一个规则恐惧：无人签名的行动会被系统归为异常，之后再也没人能为它作证。它解释纪存为什么害怕空白框，也让他明白，真正保护同伴不是替他们消除名字，而是让他们保留签名和质问权。
