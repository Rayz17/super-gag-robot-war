## Chapter Function

第三章把第二章尾声的灰模头推进为原型工房主线。它不是唐胶个人篇，也不是白鸢突然入队篇，而是“机器人在成为商品、故事、真实机体或参战单位之前，经历过什么”的章节。

本章的机战爽点不是新机无代价入队，而是原型机初战的反向爽点：灰模零号可以临时上棋盘，但每个帅动作都会损耗它作为证词的资格。最终它不入队，结算为三联证词展柜，并把失败批注、接口锁、白鸢分镜债和C04现实机器线全部接上。

## Continuous Synopsis

C03E08从C02证物审账进入旧会展中心后场。原型工房分三层：上层旧分镜和展示样件，中层灰模、母版、模具检验机和真空成型机，下层承力测试井和实机接口通道。灰模零号半身被吊在中央测试架上，母版吊臂一度误把它扶成接近出击姿势，又立刻被生产封条无人机压回未授权样本。玩家看到“启动仪式”的影子，也明白它现在不能被启动。

代哥生产层给出最合理也最危险的方案：按历史工艺样本接触，不能公开被覆盖署名，不能把废案角色写成主体性证据，不能提军工接口。纪存没有拒绝成口号，而是提出未开馆预展：只给必要当事人和审查方看，展签写未确认，先并置，不下结论。

白鸢在署名墙前正式入场。她不是凭空出现：C02分镜复印件背面的旧会展中心观众章、署名墙旧访客记录和她原稿页边压痕对上，残响灯把她临时列成必要当事人。她质问纪存是不是要把失败姿势摆出来给人看。她的私欲也正式成立：她想决定丑版本、错版本、失败姿势该被谁看见。纪存把预展名单和封存风险推给她，二人的关系从互相警惕开始。

唐胶和白鸢的冲突明确不是恋爱线。唐胶要拆内侧看轴，白鸢按住分镜页保护主体性。纪存把结构判断和主体性判断同时写进临时展签。岑砚只作为手刻名、旧访客记录和唐胶一瞬停顿存在，不给现时台词或立绘。玩家选择署名墙、失败测试区、母版仓或分散调查，输出`proto_route_order`、`signature_wall_integrity`和`production_seal_order`。

C03E09进入母版夜潜。深潜不是查资料，而是在巨大模型盒版本层中用有限窗口选择完整带回什么、部分带回什么、牺牲什么。流道是路，浇口是桥，说明书箭头是移动方向。修正夹具、清洁机、浇口巡游机和贴纸剥离器把手刻名、失败姿势和旧标签拉回官方正确状态。

白鸢看到三版本废案：儿童版、限定尖刺版和接口武器版。她一瞬间兴奋，因为她看见可以把被改坏的角色重新画回自己能承受的样子。纪存看见了却不羞辱她，白鸢压页又推页半寸，关系从互相判断变成互相试探。三版本残响体作为场景敌影行动，不入队。

母版铭牌触发纪存机魂记忆：他胸口和手腕发冷，像自己曾被固定成最适合展示的标准姿势。这不是身世揭示，但让他识别修正夹具的危险：它不是擦掉失败，而是把失败改成从未存在。玩家选择署名、结构、主体性主目标，索引获得优先级模板，军方拿到半段失败批注。

C03E10是本章机战主战。灰模零号作为12-15米临时大型单位上棋盘，但不入队。它第一次站起来就差点倒下，母版吊臂像老旧的手扶住它。玩家使用战斗、证词、支撑三模式：战斗模式清场快但损失败证据，证词模式护证据但前线压力变大，支撑模式挡线但损接口。

白鸢分镜支援可让灰模零号一回合站得更漂亮，像原型机突然爆发，但会覆盖失败姿势。纪存可以拒绝或登记为改写债。若限制她，白鸢笔尖停在“让它站起来”那一格外，指节绷白，半秒后收回。唐胶/兜灯安全锁进入战斗系统，七海安全表远程提供条款缝隙。

高潮是灰模第二次站不住。玩家可用战斗模式打爆采样机，证词模式跪下护母版铭牌，或支撑模式故意倒向封存臂，把失败姿势变成路障。平台把它剪成未完成英雄复活短片，纪存手腕冷感回响，意识到漂亮剪辑也是标准姿势暴力，于是公开完整未剪辑战场记录，生成`unedited_battle_record_public`。灰模零号保住，但不入队。

C03E11把战斗收益转成展签规则战。四类定义权被攻击：署名被条款替换机改成品牌资产整合，失败批注被精度遮罩机打成安全瑕疵，未确认角色被故事包投影套上英雄剪影，接口被降级申请机和军方遮罩机夹住。玩家使用C01-C03证据牌防守四类展签，每张牌都有公开代价。

白鸢撤回“禁止展示”，改成“保留未确认”，指甲在纸边压出白印。她不是被说服，而是第一次让未确认状态离开自己的分镜本。唐胶和兜灯把接口双权限写进规则：未来模型/玩具锚件影响巨大机体，必须同时满足模型锚件、残响道具、实机接口和双责任权限。纪存按下公开预展记录，承认公开伤口也会二次伤害。敌方获得违规公开证据和证词防守模板。

C03E12结算三联展柜。终端弹出诱人的“临时出击登记 / 完成形态修复”，相当于立刻补成一台漂亮大型单位。纪存折叠这个选项，把灰模零号结算为证词型展品。白鸢把纪存展签句号改成逗号，纪存保留改字记录。唐胶/兜灯双权限落系统。陆衡带走失败批注副本，C04现实机器小舞台灰显入口亮起。方舟T只在旧日志文件名边缘留下`remote_log_marker / non_entry`，不正式出场。

最后一波标签追踪中，三联展柜灯触发证词支援Cut-in：署名柜挡条款覆盖，失败结构柜播放未剪辑半秒，未确认柜把白鸢的逗号投到英雄剪影上，让剪影无法闭合成完成形态。灰模零号仍不出击，却证明未完成者也能改变战场。C03完成。
