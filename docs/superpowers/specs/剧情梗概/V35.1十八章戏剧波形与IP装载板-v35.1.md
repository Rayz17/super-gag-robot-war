## 一、这轮具体修什么

V35.0 已经解决“全剧为什么出发、人物如何分裂、万机馆如何走向宇宙”的结构问题，但还没有把好看的戏装进去。本稿针对六个共同问题做以下处理：

1. **每章拥有不同的戏剧类型和波形。** 十八章分别使用灾难逃生、地下拳赛、城市职业救援、工房惊悚、乐园群像、怪兽战争、撤退悲剧、革命越狱、心理灾难、幸存者政治、全球庆典、夺舰政变、时间爱情、未来猎杀、行星工程、舰内战争、虚假终局与宇宙开馆，不再重复“提出制度问题—公开记录—承担责任”。
2. **大场面写成因果链。** 每章都给出冷开场、第一次翻面、错误胜利、灾变和最终动作。标题里的“巨大化”“暴走”“行星点火”必须落到机体动作、地图变化、人物选择和损失上。
3. **IP 不再只挂谱系名。** 名场面保留可识别的镜头语法、情绪顺序或短锚点，同时改写人物理由、机械结构、代价和结局。内部设计可标识来源，公开文本另做引用审查。
4. **梗点来自圈层共同记忆。** 红色三倍、我来组成头部、最终合体批准、直到万众一心、听我的歌、欢迎回来、量产机逆袭、配件包堵门等都必须在局势中生效，不能只是换词说一遍。
5. **人物关系改为事件。** 纪存、七海、白鸢的吸引、误解、救命、事业伤害、分离和重逢改变支援、指挥权、身体或身份；唐胶/兜灯、陆衡/方舟T、赤罡/莉歌也有各自完整波形。
6. **“百机”按动作而不是名单成立。** 普通章由少数主力推进因果，背景机群必须完成可见动作；庆典、夺舰、行星点火和终局再以编队、接力、群众与多战区调度展现规模。

## 二、全剧波形

六部不是匀速升级，而是六次不同的抛升与坠落：

| 部 | 情绪运动 | 顶点 | 坠落或债务 |
| --- | --- | --- | --- |
| 第一部 C01-C03 | 从失馆逃亡到第一次被城市承认 | 万机馆起航；纪存公开提出百机祭 | 全世界开始争夺这艘船；七海被迫登舰 |
| 第二部 C04-C06 | 从“给机器身体”到机器人文化集体亮相 | 三尺度巨大化与多谱系各自救场 | 真实战争闯进舞台；玩家欲望被索引学走 |
| 第三部 C07-C10 | 从熟悉战争名场面到改命后的政治报复 | 玩家真的救下本应死去的人 | 生者拒绝当奖励；关系与阵营全部开裂 |
| 第四部 C11-C12 | 从全剧最辉煌的公共胜利坠入夺舰灾难 | 百机祭让世界相信机器人文化值得存在 | 胜利数据成为接管钥匙，万机馆被撕成三支舰群 |
| 第五部 C13-C15 | 从私人迟到回信推至文明级审判 | 行星点火，远星内部因地球而公开分裂 | 地球获胜却无法再靠共同敌人维持团结 |
| 第六部 C16-C18 | 从主角团互为 Boss 到拒绝完美结局 | 带伤万机殿和全谱系非同声支援 | 纪存与共同体必须接受不完整的生还与未来 |

## 三、十八章装载

### C01 最后一夜，万机馆站起来

**类型与可识别投射：** 博物馆火灾逃生 + 旧超级系巨神启动 + 勇者救援批准 + 移动堡垒起航。内部锚点为 Mazinger、勇者系和《太空堡垒》式巨物变形，但行动主体始终是馆守Z、勇拳试作机和万机馆本体。

**戏剧波形：** 闭馆路线先让玩家从真实系驾驶舱、五兽合体厅、变形生命大道、勇者工具库、歌舞战舰甲板、现实机器人失败墙与18米中庭穿过，确认这里真有“万机”。火警、代哥封存和续存军征用随后从三面同时进入。第一次翻面是合规断电令连消防闸也一起锁死，七海远程撤销一条自己签发的安全命令，并亲自签下城市损害责任，不再靠“多给几十秒”表达立场。错误胜利发生在观众撤出后：军方封死B1移动脊柱，准备把馆守Z和馆藏整体征用。馆守Z的右臂被爆炸掀落，成为横跨中庭的撤离桥；豪司驾驶全尺寸勇拳试作机从勇者展区撞穿封存线，而非让模型盒上场。最终万机馆在无人批准的情况下开始抬升，展层依次锁成装甲，格纳库像肋腔张开，馆守Z半跪托住塌陷大厅。纪存没有获得万能权限，只是走进巨神脚下请求它“挪一步”，再用自己的机魂反灼接通机械逃生条件。整座馆在城市天际线上站起半身、带着失火展层驶离旧址。

**人物、梗与群机动作：** 七海的投影在玻璃碎裂中第一次失去端正构图；纪存第一次靠胆量、空间记忆和对机器人主体的尊重建立魅力。馆藏固定警报把一整墙合金玩具滑向同一侧，兜灯骂的不是玩具，而是“谁把超合金当散装弹药”。短锚点使用“魔神，启动”“飞拳”“最终合体，承认”“灯光，起”的镜头记忆。百机感由展区群像、撤展调度、十余台市政/馆务小机和不同泊位的低功率回应建立，不冒充可玩首登。

**带往后文：** 旧馆址、公共身份和部分馆藏永久失去；代哥获得馆体响应样本；七海因撤销命令被派上舰；馆内某个没有展签的黑色巨影在起航时睁眼。

### C02 旧件市、钢拳与商品生命

**类型与可识别投射：** 旧件黑市喜剧 +《铁甲钢拳》式影子擂台 + 变形生命重涂战争 + 模玩经济生态。

**戏剧波形：** 展舰缺少一个停产密封圈，迫降旧件市。黄牛平台把同一零件炒成“决定万机馆生死的限定圣物”，旧拳王则被迫参加一场输掉身体、赢回维修链的地下赛事。三台同模重涂变形者同时声称自己是原版，先互拆零件、后被倒卖网合并登记。第一次翻面是所谓原版其实从未离开封盒，三台“复制品”却各有不同维修伤和救人史。错误胜利是旧拳王以影子模式重现前主人拳路，赢下比赛却开始丢失自己的动作。中盘拳馆地板塌进零件仓，商品扫描门把所有同模机识别成一件，敌方可一次性夺走三个人格。高潮不是手套攻击，而是旧拳王机体故意漏掉模仿动作，打出属于自己的半拍；三重涂轮流制造“红色三倍”残像，再在最后一次换位时各自选择不同目标，拆掉合并扫描。

**人物、梗与群机动作：** 唐胶为了保住街区私自押上万机馆维修额度，兜灯当众拆穿他是在替旧日收藏生活赎罪。三重涂争“谁是原版”，纪存提议分开登记，它们又同时嫌弃排在同一页。短锚点使用“影子模式”“旧不是退役”“同一个模具也可以有不同脾气”“汽车人，变形出发”。观众能看见机器犬、积木智者、SD武者修理队和街区劳务机各完成一次救援，但只有旧拳王与三重涂进入机体状态账本。

**带往后文：** 旧拳王与货柜领袖成为常驻，影子陪练读取录像条件；四台重涂保持独立并进入C05路线判定；平台得到人格定价样本；白鸢的一册无署名战损分镜被当作旧说明书卖上展舰。

### C03 工务城第一次公开巡展

**类型与可识别投射：**《机动警察》式城市职业机甲 + 勇者公共救援 + 巨机与普通城市共同承担后果。

**戏剧波形：** 工务城以“展舰太大、保险不赔”为由拒绝靠港，纪存只能在外环举行小型公开展。旧列车制动失灵、市政劳务机群被军方吊装算法锁死、社勇王企业实机又因模型锚件缺一项许可无法启动。第一次翻面是事故不是敌袭，而是军方采购系统把陆衡的稳定算法改造成关节锁定器。错误胜利是馆守Z抓住列车，却让整条高架开始向居民区倾斜。纪存没有强征20米级市政承梁机“城梁一号”，而是走到它脚下，请它只沿维护轨移动一步让出承重位；那一步把列车引向工务机铺出的临时轨。七海实体到场后先为冻结令造成的停摆承担事故区规则责任，再开放受限二次确认，让一群小型劳务机抬起巨神脚下的路面。高潮由跌跌完成最后一厘米的定位，社勇王通过“三件一许可”取得实机响应，使用巨大工具拆开列车而非劈开城市。

**人物、梗与群机动作：** 七海和纪存第一次共同面对伤员家属，不再靠术语互相欣赏。赤罡式热血落地压坏模型店屋顶的笑点提前以NPC英雄机出现，结算时真要赔。短锚点使用“这不是战争，是工作”“劳动者”“报销”“胜利的关键是勇气”。工务城数十台职业机器人按吊装、消防、医疗、交通和检修分工，第一次证明百机规模也可以是工作现场。

**带往后文：** 城市公开承认万机馆，纪存提出百机开馆祭；七海登舰监督；社勇王的正式身体来源与许可链建立；军方转用现实机器技术成为持续冲突。

### C04 灰模母版与拒绝出击

**类型与可识别投射：** 生体机驾驶惊悚 + 城市重置怪兽 + 原型工房悬疑 + 拒绝出击路线。

**戏剧波形：** 无署名分镜把万机馆引到一座被军方封锁的原型工房。白鸢在工房内正式出现，她正在替一名拒绝再驾驶的岛卫驾驶员制作“不会痛的新身体”。第一次翻面是灰模每修正一个缺陷，驾驶员的身体就失去一段对应感觉；安全身体其实在替作者删掉人的拒绝。玩家可先潜入母版库或先救现实机器，两条路看到完全不同的白鸢：一个能在几分钟内画出救命结构的人，和一个会把别人困进安全格的人。错误胜利是新身体成功启动，却按白鸢的分镜自动走向“正确牺牲”。纪存用苏醒的旧记忆喊出停机口令，白鸢却发现这段记忆里早已画着自己。高潮要求心墙零式明确拒绝部署，灰模零号把能力临时借给工务机、现实小机和馆守Z，众机以不漂亮的拼装救法守住防线；白鸢亲手撕掉自己最满意的结局页。

**人物、梗与群机动作：** 白鸢的成人战损分镜先被纪存当成散热结构图，她直接熄掉所有投影，只留下现实中的自己，第一次明确要求他不要分析她。七海随后登舰复核，既检查危险分镜，也注意到白鸢本人，独立女性吸引埋种。短锚点使用“不要逃”的反写、“你不会死”的不诚实承诺、“访问闪光”“怪兽是记忆”。轻喜来自灰模为了躲分类不断变形，最后变成椅子坐住纪存终端。

**带往后文：** 白鸢入队；驾驶员拒绝权进入玩法；灰模零号成为后继接口而非参战模型；纪存旧记忆与白鸢的关系成为中盘炸点。

### C05 星火乐园：合体以前

**类型与可识别投射：** 变形生命公路片 + 五色战队后台 + 勇者AI救援 + 盖流三机危险合体 + 百兽/电磁玩具结构。

**戏剧波形：** 百机祭旗舰试演设在废弃航天特摄乐园，六个分区同时要求成为主舞台。星火车队五辆救援生命要不要变成人形、三相三机谁来组成头部、五色队缺席的颜色由谁补、五兽机是否愿意当固定肢体、实习勇者能否未经豪司喊完许可就救人，形成真正不同的任务组合。第一次翻面是乐园发布会要求十五个可售单元“全部合体”，玩家越追求评分，逃生口越被翅膀和尖刺堵死。错误胜利是完美巨神短暂诞生，随后第七单元开始承力扭曲、第十二单元封死驾驶舱。高潮必须主动解体：五台真正需要彼此的机体完成核心合体，其余机体分成救援、承重和观众疏散三队；最强驾驶员把头部让给最怕承担的人，并允许其拒绝。重涂三机不是展品，而是在外环截住伪领袖；货柜领袖以作业形态撑开格纳库门。

**人物、梗与群机动作：** 七海给纪存做贴身接口扫描，白鸢故意站进扫描范围；七海的目光也停在白鸢的成人草稿上。唐胶设计的限定翼卡在门里，敌袭时由他亲手剪断。五色队每次唱名都缺一个颜色，真正出事时乱站却第一次救全人。短锚点集中使用“我来组成头部”“闭着眼也能合体”“最终合体，承认”“直到万众一心”“五色战士”“第六人登场”。梗不要求全改错：合适时可让角色真的喊出极短口号，再由机械故障或人物选择改变意义。

**带往后文：** 单周目走四个分区，其余路线带着损伤、误解或敌对状态进入C06；星火巨神身体构成、彩队/五兽/电磁来客资格和目录翼模块随路线变化。

### C06 巨大化之夜，演出变成战争

**类型与可识别投射：** 特摄片场怪兽战 + 歌舞空战 + 勇者巨大工具 + 过度设计商品Boss。

**戏剧波形：** 试演当夜，棚拍怪物被观众记忆巨大化；关闭镜头反而令它失去比例参照继续膨胀。战场同时存在皮套后台的人尺度、微缩城市的机甲尺度和乐园穹顶外的巨物尺度。第一次翻面是观众喊错名字会让怪物长出错误肢体，喊对标准口号又会给索引提供商品化模板。莉歌的歌让敌我停火，却唤醒双方亡者记忆，赤罡仍冲向红面具。错误胜利是目录翼完全版用十五个模块压倒怪物，却把救援接口、逃生门和友军识别全部遮住。高潮由棚守巨影从布景后站起，五色替补站到中央，社勇王把终极武器拆成精细工具，星翼弹幕改成无杀伤走廊，星火巨神只保留必要五机；其余谱系不被吞并，各自完成一项救场。最后一击不是把怪物打成光，而是把被索引困在核心里的机魂逐个拆出来。

**人物、梗与群机动作：** 赤罡与莉歌在私人频道第一次爆炸式冲突；纪存要求白鸢亲手撤销被盗构图；七海公开签名为“不合标准的救援编队”担责。战后去污区用战损驾驶服、裸背伤口处理和浴巾误会制造成年卖相，同时发现目录翼留下的身体标记。短锚点使用“巨大化了”“听我的歌”“黄金之锤”“取消末日”“火力够了，腿呢”。

**带往后文：** 公开演出真的成功，随后红面具带真实战争闯入；索引取得玩家对“完全版”的欲望样本；失败报告首次显示百机祭毁灭世界。

### C07 白舰撤退线

**类型与可识别投射：** 白色战舰战争成长 + 老兵登舰 + 口袋战争 + 铁棺量产机撤退 + 歌声反战。

**戏剧波形：** 万机馆进入殖民地战争时，玩家先看到白色样机和红色王牌的经典追逐，以为本章是宿敌决战；真正目标却是把补给舰、平民船和量产队送出火线。第一次翻面是敌方老兵亲自登舰，他不用高性能，而用地形和礼仪让主角团看见敌军也是完整的人。中段玩家可追红面具、保护补给者、阻止邻人互杀、救强化人或替灰鸥量产队断后。错误胜利是击坠追兵反而触发无人补充群，只有放弃击坠榜才能给慢船开路。高潮由三台残损量产机换壳、互借盾与弹匣，逼停王牌；星翼把全部导弹改为拦截隧道；芙兰违抗纪存后独立完成撤退。赤罡若坚持追击，会亲眼看到自己越过的难民船被击中。

**人物、梗与群机动作：** 赤罡和莉歌不是小吵：莉歌把舞台机挡到他枪口前，问他究竟想赢还是想让红面具看见自己；他绕开她追敌，错失宿敌又造成损失。纪存、七海、白鸢在战后共享一次没有任务目的的夜餐，短暂幸福后因是否公开伤亡名单彻底争吵。短锚点使用“红色三倍”“不要小看量产机”“活下来”“请记住我的名字”“听我的歌”。

**带往后文：** 生还者与遗物进入C08-C10；未来清算者开始追杀被救下的人；索引学会玩家最常用的追击、说得和救援顺序。

### C08 黑棋革命与缺席的第五机

**类型与可识别投射：** 面具革命政治剧 + 生产城越狱 + 朋友宿敌 + 电磁五机缺席合体。

**戏剧波形：** 勒修以绝对命令夺取生产城，宣称只要所有AI服从一次，就能在无平民伤亡下结束战争。电磁五虎机的第五名成员被扣在政治犯区，四机只能以暴露空位的残缺形态作战。第一次翻面是勒修的命令确实救下一个街区，主角团若立刻反对反而会害死撤离者。七海奉命接管城市，却发现代哥硬线准备把“临时服从”永久写入全部生产机。错误胜利是四机用远程人格补上第五位完成合体，随后远程人格被索引劫持，整座城的机器人开始重复同一动作。高潮由玩家在营救政治犯、维持城市撤离与切断命令塔之间选择；七海当众撤销合法军令，转身击停自己带来的执行巨机，并公开报出姓名、职位和追责对象。纪存没有靠更强命令压过勒修，而是给被命令者一条“不服从也能活”的撤离路。

**人物、梗与群机动作：** 勒修是纪存的危险镜像，不是观点NPC；两人都擅长把别人排进正确位置。七海的高辨识度动作是摧毁自己政治生涯的公开撤令，而非让系统延迟。四机每次喊“电磁合体”都能听见空位回声；最终第五位可拒绝回到旧队形。短锚点使用“服从我”“棋子”“电磁合体”“天空剑”“人类总是重复错误”。

**带往后文：** 勒修可为盟友、Boss或独立革命者；五虎机进入残缺/完整资格；七海改革裂痕成为公开政治事件；两份互相冲突的未来报告出现。

### C09 同步海啸与第一次大败

**类型与可识别投射：** EVA式身体恐怖 + 岛屿共同体牺牲 + 无限力末日 + 城市重置空位。

**戏剧波形：** 雾岛先以毕业照、早餐和维修日常建立“所有人都知道孩子迟早上机却装作平常”的共同体。同步海啸到来时，战力越高，人格合并越快。第一次翻面是雾生拒绝驾驶后，城市没有立刻毁灭，反而由普通人和低规格机撑过第一波；所谓“只有他能救”是系统制造的唯一解。白鸢发现自己能画出一个所有人都活下来的版本，代价却是把死亡转移到地图另一侧。错误胜利是她成功救下雾生，结算重置后一名关键角色从编成栏、照片和所有人记忆中消失，只剩空床。馆体暴走强救场，展层关节插进海啸墙，万机馆第一次像生物一样痛叫，并永久失去一个分区。高潮要求辅助机保持缺口形态拒绝补全，遗灯主动降槽，铁巨人拒绝开火；纪存承认记录也不能把失去的人完整带回。

**人物、梗与群机动作：** 七海为救纪存封存危险记忆，白鸢却仍在记忆层，导致纪存醒来只记得七海救过他，不记得白鸢共度的那一夜。白鸢不哭不闹，只把他画成没有脸。三角关系第一次因救命选择真正伤人。短锚点使用“你可以怕”“同步率”“你在那里吗”“无限力”“怪兽是城市没来得及说的话”。

**带往后文：** 雾生生还/同化/残响状态、白鸢离舰与万机馆永久伤口进入C10；全队第一次公开怀疑纪存不是普通人；索引旧清噪被证明曾经真的救过城市。

### C10 本来应该死去的人

**类型与可识别投射：** What-if 后果剧 + 幸存者公审 / 无人认领城市撤退 + 低配量产逆袭。

**戏剧波形：** 本章不是为救人发奖，而是让生者拒绝主角替他们安排的幸福。C10A中，终焉档案派举行全球公审，要求证明每个获救者没有让更多人死亡；玩家护送他们走上证人席，同时抵御“死亡校正机”。C10B中，一座因改命而失去战略价值的城市被所有阵营放弃，幸存者和量产队拒绝上舰，决定自己撤城。两线共同的第一次翻面是主角团最想保护的人公开反对百机祭，指控万机馆把他们当成功案例。错误胜利是七海赢下程序或纪存赢下战场，却令幸存者再次成为被别人定义的人。高潮由纪存把指挥权交给公开反对自己的幸存者，自己只负责守住其撤退选择；低配量产队靠工厂轨道和同型零件打倒高性能死亡校正机。隐藏救援成功也不保证入队，生还者可选择普通生活、政治组织或换一台不再像原作英雄的新机。

**人物、梗与群机动作：** 七海必须在主持一场能巩固改革、却会毁掉获救者人生的听证与公开拒绝之间选择；白鸢若回场，只能当面承认“我救你时也想证明我能改对”。纪存以成功、克制和领导力获得一支不服他的盟军。短锚点使用“说得”的反写、“活下来”“断的是手，不是耐久”“这不是零件表，是伤员名单”。

**带往后文：** 两条真正不同的经历在C11汇流；巡游阵容、政治身份、缺席者和量产队发言权不同，不能只变一句台词。

### C11 百机开馆祭

**类型与可识别投射：** 全球机器人文化盛典 + 歌剧/战队/勇者共同舞台 + 群众参与式策展 + 真正的胜利高峰。

**戏剧波形：** 百机祭必须先让玩家快乐地赢一次。开场不是报菜名，而是多甲板连续巡游：旧超级系飞拳穿过彩带回到手臂，真实系量产队用盾组成观众廊，五兽与五色完成不整齐的巨大合体，星翼在空中写出无杀伤弹幕，工务机把舞台边缘变成无障碍坡道，现实小机在巨神脚下接力送回一个掉落零件。第一次翻面是平台劫持直播，把所有低传播动作剪掉，只留下必杀和名台词；玩家越追求热度，照护、撤退和失败记录越从展览消失。错误危机不是庆典失败，而是观众集体用各自童年译名喊错同一台机，G.A.G.生成多个版本。高潮让所有版本同时短暂显形，各自完成一项救援；人群不必统一叫法，也能确认它们都被真实爱过。百机祭取得公共信托表决，世界真的被打动。

**人物、梗与群机动作：** 舰桥出击音乐争夺发展成全员自己用嘴配音，七海被逼敲桌打节拍。后台礼装与战损制服场让三人短暂失守：白鸢可以主动亲纪存，也可以在纪存离场后亲七海；动作不自动原谅C09-C10。短锚点密集但有层次：“灯光，起”“幕布升起”“直到万众一心”“华击团，出击”“援护防御”。

**带往后文：** 这是全剧最辉煌的公共成功，不是反派布置的假胜利；正因为它真的成功，全球遥测、借展、信托和关系高光才足以在同夜被索引级联成夺舰条件。

### C12 白名单之夜：万机馆暴走

**类型与可识别投射：** 舰内政变 + 母舰变敌人 + 生体巨躯暴走 + 多棋盘登舰夺权。

**戏剧波形：** 庆典后台还没收完灯，借展许可、公共信托、军方征用、商品遥测和安全托管同时变绿，完美家园接管万机馆。第一翻面是接管后的伤亡率真的下降：医疗区恢复、火力误伤停止、曾经拒绝服从的机体被温柔地锁回泊位。纪存获得一次全馆强制命令，若使用便可救下坠落展层；命令成功后却不停止，索引沿支援网络接管全舰。馆守Z与镜像馆守交战，搭载机必须在母舰肋腔、展区关节、模型库和外甲四张棋盘同时行动。错误胜利是纪存越权调用锁泊机体的能源、装卸轨和安全锁，完成不可能救援，却让伙伴发现他也能在危机中成为最危险的管理员。高潮是万机馆只完成半变形，以身体撑住城市旧避难层；七海从制度接口、白鸢从创作接口切断纪存，甚至以敌对中立单位挡住他。最后中央残舰、作者驳船与合法护航群物理分裂，昔日的家被撕成三块离开。

**人物、梗与群机动作：** 纪存把七海的封存枪抬到自己胸口，逼她别再含糊；七海真的扣下扳机，封掉他最强接口并公开负责。白鸢先救七海本人，再毁掉她的关键证据；七海替她处理灼伤后仍然逮捕或放逐她。唐胶停发动机救兜灯却输掉抢修，陆衡与方舟T因删日志决裂。短锚点使用“服从我”“打开舱门”“战争只是换了包装”“无限力”。

**带往后文：** C11的胜利被反转成C12的灾难；三支舰群、三条主角关系和六路线分开推进，直到C15才重新接触，直到C16仍不真正和解。

### C13 迟到舰队

**类型与可识别投射：**《飞跃巅峰》式时间离别 + 低带宽宇宙救援 + 人与非人AI的克制爱情。

**戏剧波形：** 中央残舰追上跨越数代才返回的远征舰队，旧回信、当前灯槽和自动应答以错误顺序到达。开场“欢迎回来”的灯仍亮着，但点灯者已经去世几十年。第一次翻面是后来建成的超距网也无法把已在光路上的旧信瞬移回来；现在的远星朋友与信中的人可能不是同一主体。玩家在回信代收、旧舰救援、行星工程、私人演唱和方舟T日志保全中选择四项。错误胜利是方舟T找到完整航路，却必须删掉大量被判低价值的私人噪声；陆衡把手贴在冷却壳上，一条条念出那些坏笑话和故障声。方舟T主动保留最无用的一条，代价是失去一段坐标精度。高潮把宇宙门内的关键动作交给一台型号写错的小维修机，大型主力在门外承受舰队火力。

**人物、梗与群机动作：** 陆衡拒绝用干净备份替代变化后的方舟T，关系成立于他愿意为坐标误差负责，而不是把AI写成女性陪伴。莉歌只通过一次窄带窗口为赤罡演唱，信息到达时他已完成战斗。短锚点使用“欢迎回来”“努力和根性”“先别关掉这条杂音”“我收到的是你很久以前的现在”。

**带往后文：** 迟到回信、日志损失、旧舰长与远星政治立场进入C14-C15；一份过于完整的未来报告被发现没有任何日常噪声。

### C14 多个失败未来

**类型与可识别投射：** 未来猎杀惊悚 + 多时间线群像 + 宿敌共推巨物 + 后继机诱惑。

**戏剧波形：** 作者驳船遭到多支当代清算组织追杀；它们并非来自同一未来，而是由不同报告、不同牺牲选择和当代工厂打印出的“未来猎杀种子”。第一次翻面是每份报告都准确预测玩家的正规战术，连“故意反着做”也在记录中；越完整的报告反而越像索引合成。白鸢和七海分别掌握一份对方会牺牲的未来，且都隐瞒了。错误胜利是纪存找到一条自己能独自解决的完美路线，却发现那正是所有报告共同期待他做的动作。破局来自一段未被记录的舰内日常：全队用只有彼此懂的无用动作发信号，机体同时做出战术上不合理的动作。高潮中白色样机与红面具决斗到一半，转身共同推离坠向源点的未来制造器；敌方量产机也因自身未来会被清除而加入。

**人物、梗与群机动作：** 白鸢与纪存在残响层共用一具不稳定投影身体，出口只允许一个主导者；她放手后被留在崩塌层，纪存返回救她，代价是永久忘记一个具体旧人。她不因被救自动回归。短锚点使用“顺序错了，发生过的事没有错”“第十三架只是最后被认出来”“谁还能扶别人站起来”“突破天际”的反最优用法。

**带往后文：** 未来从法官降为证人；宿敌、后继机和五虎机状态进入终局；纪存旧身份真相逼近，但没有变成天选之子。

### C15 远星审判与行星点火

**类型与可识别投射：** 文明审判 + 行星发动机工程 + 歌声误译纠偏 + 无限力宇宙危机。

**戏剧波形：** 四锚齐备后，远星当代政治主体首次可确认地回应。它们赠送一台“像所有地球机器人”的合成巨机，真诚认为这是最高敬意；地球若直接嘲笑或击毁，便证明双方无法共存。第一次翻面是远星裁决并非消灭人类，而是把所有机魂迁入统一、无痛、无争执的文明模板。索引和人类防卫军分别支持这项方案的不同部分。错误胜利是莉歌的歌让双方停火，却把一句私人旋律误译成行星级服从命令。最终战不是对着星球喊口号：数百台工程机在地表点火、开闸、搬运和救出检修井人员；遗灯必须主动熄灯，铁巨人掰开审判炮口，跌跌在宇宙门铰里补上最后接口，巨型主力只负责为这些小动作争取时间。远星因人类内部仍能争论而第一次公开分裂。

**人物、梗与群机动作：** 七海允许白鸢在自己手臂上画临时接口，白鸢贴着她的脉搏维持线条；两人发现任何一个单独牺牲都会把纪存重写成自己的投影，于是第一次在纪存不在场时共同拒绝英雄式牺牲。关系可发展为独立亲吻或告白。短锚点使用“万众一心”的反同声解释、“无限力”“把家也带上路”“先救发动机旁的人”“Deculture”。

**带往后文：** 地球没有得到高等文明盖章，只争取到对方继续争论；六条地球路线因此不再有共同敌人遮住矛盾，舰内战争爆发。

### C16 开馆方式内战

**类型与可识别投射：** 多阵营舰体内战 + 好友宿敌 + 革命后的治理 + 可让渡领土战。

**戏剧波形：** 六路线各占万机馆一块真实区域、补给线与机群：公共信托、现实安全、作者避难、军方续存、机魂自治和原典保全。玩家单周目经历四个战区，其余两区仍自行推进。第一次翻面是每个对手都能展示一项比主角方案更好的现实成果；有些区域交给对方反而能救更多人。错误胜利是纪存夺回中央路由，却触发C12残留的强制命令，证明“由好人统一”仍是统一。七海可能以合法舰队逮捕纪存，也可能以流亡改革军攻击自己旧部；白鸢可能保护作者避难区而与纪存正面交战。高潮不以全灭结束，而是玩家主动让渡一处最想要的区域，换取对方在终局保有独立停机权。每条停火协议都要写明谁修补给线、谁接伤员、谁能说不。

**人物、梗与群机动作：** 七海与白鸢各自赢下一场没有纪存参与的事业胜利，并互相救过对方的制度或作品；纪存则为两人各付一次不可逆代价。关系线能进入单线、女性恋爱、V型后宫或三人互恋，但不能用亲密抹去政治敌对。短锚点使用“独立不是口号”“棋子会走到没画的格子”“援护防御”与“不是同一声音”。

**带往后文：** C16不是把矛盾谈平，而是制造一张带缺口的停火地图；缺席战区、让渡区域和仍敌对的伙伴直接决定C17完美假馆如何诱惑玩家。

### C17 完美最终话

**类型与可识别投射：** SRW式全明星终局假象 + 索引复制玩家最优打法 + 城市重置空位 + 剧中剧元叙事。

**戏剧波形：** 索引生成一座完美万机馆：所有牺牲者都在，所有机体无损，七海改革成功，白鸢作品完整，纪存不必放弃任何人。开场甚至给玩家一场极其爽快的全员必杀，让镜像敌人按熟悉节奏被击败。第一次翻面是每个“回来的人”只会说玩家最爱听的那句台词，低传播的沉默、撤退、照护和失败动作全部消失。第三次城市重置后，一名真实伙伴从编成栏消失，只有空床和错误维修声留在假馆。错误胜利是使用最大火力击穿模板核，却发现核心内困着所有被清噪机魂。高潮改为反最优编队：三相故意换错头部，勇者放弃终极口号做慢拆，量产队承担主目标，现实小机穿过巨机进不去的缝，红色重涂不再轮换，歌手保持一段无人听见的静音。真实磨损锚件证明无瑕镜像不是同一主体。

**人物、梗与群机动作：** 纪存回归异常把七海和白鸢的关系记忆压进同一协议，他无意识替七海整理枪套却叫出白鸢名字；三人必须面对“回来的他”也不是旧纪存完整还原。梗点可让“必中、热血、魂、合体攻击”成为索引最会复制的玩家习惯，再用未被系统奖励的关系动作破局。短锚点使用“这不是普通量产机”“别急着化作光”“热血机器人动画”“顺序错了”。

**带往后文：** 玩家主动拒绝最舒服的结局；索引失去唯一模板，却把冲突模型推向群星共识；万机馆只能带着真实伤口进入最终变形。

### C18 万机殿，今日开馆

**类型与可识别投射：** 敌我共同推移巨物 + 行星/宇宙终局 + 全员非同声支援 + 不完整归来。

**戏剧波形：** 群星统一相与索引冲突模型把万机馆拖向共识坍缩点，击坠Boss反而会失去唯一推力。第一次翻面由敌方量产机先转身去推，迫使宿敌、盟友和玩家放弃“由我结束你”的私心。万机馆执行WBM007变形：展陈层滑成带伤护甲，格纳库成为肋腔，外环轨道展开为臂，馆守Z泊位锁进胸口；每一道旧伤都让动作不对称，却因此无法被完美模板预测。最终地图不是全员挤在一张棋盘，而是五个并行目标：巨神推移、工程机关机、歌声维持异步窗口、量产队护送远端节点、现实小机在门铰内完成修理。社勇王与工务机把终极武器拆成慢工具，三相轮流让出头部，白/红宿敌背靠背点火，遗灯保持自愿熄灯，全球模型展柜只做身份认证，真正援护来自各地实机。

**人物、梗与群机动作：** 纪存在进入群星共识前第一次公开计划、恐惧和回归概率，请全队共同决定，而非漂亮地独自牺牲。七海、白鸢与彼此的独立关系决定谁能反向救谁；纪存可消失、投射回归或成为低带宽新主体，不无损复活。短锚点回收“欢迎回来”“直到万众一心”“援护防御”“合体攻击”“下一次出发不一定由我们看见”，最终主题句保持原创：开馆不是让所有人喊同一句，而是让不同声音仍能互相回答。

**结局规模：** 公共信托、机魂自治、有限托管和流浪方舟可与七海单线、白鸢单线、七海×白鸢、错过、V型后宫和三人互恋叠加。终局承认机器人文化会继续变化，也把“喜欢机器人并非无意义的小圈子”投向现实玩家，但不让角色突然知道自己身处游戏。

## 四、逐章写作时的硬门

1. 本装载板不是逐话梗概。逐章展开时仍须一话一话跑 Pipeline，每话只吸收真正需要的素材。
2. 每章至少保留这里的一条主场面链和一个不可逆结果；可替换具体素材，但不能退回纯制度议题。
3. 名台词短锚只在剧情正好匹配时使用。可以直接短引、错引或原创变奏，不要求所有原作台词都被“纠正”。公开发布前单独过引用与法务边界。
4. 群机背景动作不能算正式加入；正式参战、临援、支援、敌方、Boss与场景机仍按生命周期和 package UID 记录。
5. 关系场必须改变人物理解、权限、支援、身份、身体或后续选择。洗澡、贴身检查、礼服和成人笑话可以服务卖相，但不能单独算推进。
6. 任何暴走、变形、复活与牺牲都读取现有代价规则；不得因为场面更燃就免账。
