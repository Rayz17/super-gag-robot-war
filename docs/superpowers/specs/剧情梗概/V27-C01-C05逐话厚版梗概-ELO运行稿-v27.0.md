状态：候选厚版梗概。  
运行口径：按新版 Episode Loop Orchestrator 逐话推进，保留 V26 机器人大战化重挂载，吸收 V26.2 门禁与 V22.10 厚度经验。  
重要边界：本稿不是最终台本，不是最终关卡表，不硬升 canon；但可作为下一轮台本、关卡、资产拆分的母稿候选。

## C01 闭馆夺名与馆守Z起航

本章目标不是“介绍博物馆”，而是让玩家第一小时就确认：万机馆很大、机体真的能动、代哥清算有风险理由但正在伤害热爱、G.A.G.从名字与展品定义上开始显影。纪存的主角弧线从“临时闭馆负责人”推进到“愿意承担移动风险的机魂实体候选”；七海从远程执法者显露为知道流程裂缝的人；馆守Z、社勇王盒、火种货柜锚件和跌跌小舞台全部进入后续状态账本。

### E01 今日闭馆后，馆名被冻结

**本话功能**  
开局要让玩家先爱上万机馆，再看见它被清算系统改名。万机馆不是一间小展厅：纪存的信息终端打开时，L1主厅、合体变形环廊、现实机器小舞台、AI三法厅、B1泊位参观窗、B2残响接口层都以灰显地图出现。玩家只站在前厅，却已经看见未来几十台机体的空间承诺。

**剧情流程**  
闭馆路线从日常动作开始：小满取社勇王模型，阿澄蹲在跌跌小舞台前等它多站一秒，唐胶在模型病院把断件分进“还能抢救”和“先别动”两盒，兜灯在馆守Z脚边检查承重锁。纪存用终端安排闭馆路线，像真正的信息管理员，不是手写笔记本。他可以选择先巡合体变形环廊、现实机器区或勇气合规厅；不同路线会让玩家看见不同谱系的展柜和灰显未开放层。

代哥封存无人机进入后，清算不是上来开枪，而是把“万机馆”改成“第七封存局临时风险仓”，把留言墙、社勇王取件单、跌跌演示屏和火种旧货柜锚件全部改为风险编号。终端 UI 短暂像机战出击名单一样读出“馆守Z，展示状态。社勇王，取件状态。跌跌，演示状态。”下一秒名字全部被编号覆盖。玩家第一场战斗，就是把“它们叫什么”抢回来。

七海通过全息审查窗出现，只上半身和一块权限面板。她不来现场，现场执行的是封存无人机、采样贴片和0号开启臂。她说明旧G.A.G.事变后，任何可动展品在异常响应时必须冻结名称、撤离观众、封存子节点。她不是脸谱反派，流程本身确实能降低灾害概率。纪存没有把她说成恶人，而是把封存清单公开到导览屏上：让所有人看见谁改名、改了什么。

0号侧廊短亮，馆守Z胸牌低热，社勇王盒盖弹开一条缝，火种锚件闪出半行车灯波形，跌跌屏幕把“2秒站立”误打成“第0次站立”。G.A.G.只表现为命名异常和展品响应，不解释成万能火种。旧声在白噪里留下一句：“别把我归档。”这句话只由残响层发出，人类角色不碰世界外meta。

**战斗与玩法 / 机体 / 梗点**  
类型：闭馆探索 + 小型保护战。地图覆盖前厅、主厅留言墙、合体变形环廊入口、现实机器小舞台和勇气合规厅半区。胜利条件是在八回合内保住至少三个原名展签，并让观众进入黄线区；失败条件是四个锚点全部被编号化或儿童离开黄线。玩家可公开某条封存理由，公开会提高采样强度，但保留原名和证据。机体/单位包括馆守Z半跪本体、改名贴片机、采样夹臂机、社勇王模型盒、火种货柜锚件、跌跌小舞台和0号开启臂。

名场面锚点是“出击名单被敌方篡改”。模玩生态来自取件单、断件盒、旧贴纸和维修病历。敌方收益是：索引和代哥第一次确认“原名会触发展品响应”。

**关系 / 情绪 / 债务**  
纪存的主角魅力在这里不是犯错，而是敢公开风险来源。七海的四十秒延迟被纪存记录为“流程延迟”，不是“她帮了我”。两人第一次互相识别：她知道他不是煽动者，他知道她不是冷血执行器。唐胶和兜灯的关系以优先级冲突表现：唐胶护模型病历，兜灯护承重锁，吵一句就各自开工。情绪物件是被编号覆盖的留言纸，边角还露着孩子画的粗糙拳头。下一话债务：封存局将把馆守Z本体拆为静态资产。

### E02 馆守Z手臂成为地图

**本话功能**  
把“博物馆保护”升级成“巨型机器人正式进棋盘”。馆守Z不能全功率站起，但右臂、肩甲、胸牌热光和膝部承重都成为地图规则。玩家第一次在万机馆内部体验2x2巨机单位、过热、承重和护展代价。

**剧情流程**  
封存局认定馆守Z低热反应超出静态展品标准，投放重型路径框、切割标尺机和冷却针车，准备把馆守Z右臂、黑柜胸牌和腿部承力架拆成三件可封存资产。兜灯先看切割线，骂它过了主承力栓。纪存打开承重层，玩家看见主厅地面不是普通地砖，而是旧展舰甲板与18米机体维护网格。

旧守护者广播以导览语气提示：“右臂可作临时桥。胸牌禁止全功率。不要踩留言墙。”馆守Z的动作不是谜语，是旧系统在限制自己。它知道一拳下去会救人，也知道会压坏展柜。玩家可以让右臂旋成桥，也可以用手掌挡采样线；每次动作消耗承重值和维修债。

第3回合，冷却针车扎向黑柜胸牌。终端弹出旧系统警告：“胸部光线：禁止全功率。”玩家可选择低功率扫掉贴片，或高功率清线。高功率爽，但会让展区损害和代哥风险论据暴涨。第5回合，火种锚件把无人机商品标签误识别成同模贴纸，生成诱饵；跌跌演示屏被震落，摔成一个不会攻击但能挡采样线的小型障碍。

高潮是馆守Z右掌压在留言墙前。封存无人机播报“保护观众留言不属于安全优先级”。纪存把留言墙临时登记为“公共展品”，并签自己的名字。馆守Z获得一次低功率飞拳演示轨许可，右拳沿承重轨滑出，不是炸场，而是把封存闸锁杆打歪，让观众多出一条撤离线。

**战斗与玩法 / 机体 / 梗点**  
类型：SRPG巨机教程 + 承重地图战。馆守Z占2x2，右臂可旋转成桥，胸牌热光覆盖扇形区域。胜利条件是守住留言墙与黑柜胸牌，并让重型路径框失效；失败条件是馆守Z三次过热或主厅承重值归零。机体包括馆守Z、旧守护者广播、重型封存路径框、冷却针车、切割标尺机、火种标签诱饵、跌跌障碍屏。名场面锚点为胸口光线、飞拳、半跪守护，但全部护展化、低功率化。

**关系 / 情绪 / 债务**  
纪存第一次正式称馆守Z为“仍在服役的守护机体”，不是旧道具。兜灯敢对18米巨机说停，纪存把她的损害判断写进展签，承认安全规则也是热爱。情绪物件是馆守Z掌心旧修补痕，像曾经挡过更大的灾。敌方获得护展动作和胸牌热曲线，下一话将切断支援权限，迫使勇者系通过审批或越权登场。

### E03 勇气审批第3回合

**本话功能**  
让勇者系从口号变成责任签名、审批荒诞和战场救场。豪司回到第一章，不再消失；社勇王不提前真机入队，而是以模型盒、缺页说明书、金章AI和临时承力许可进入支援系统。

**剧情流程**  
代哥升级为支援权限切断，终端上的热血按钮全部灰掉：未确认驾驶员、未确认责任主体、未确认赔付路径。勇气合规厅里，社勇王模型盒开始盖章，但盒盖不开。豪司远程接入，身后是勇气株式会社的盖章机和合体申请柜。他没有先喊口号，而是确认观众撤完没有；确认没有后，他请求临时承力，责任写自己。

战斗第3回合，封存局投放“责任空白框”。任何无人负责的支援都会被归为G.A.G.异常暴走，直接抬高封存等级。玩家要在纪存、兜灯、豪司三人之间分配签名：策展风险、机械承重、勇气越权。三人都签，支援最强，但后续追责更重；只签一人，债务低但救场弱。

小满在黄线里看见社勇王盒发光，忍不住喊：“我来组成头部！”纪存没有训她，只蹲下指给她看责任空白框：头部不是抢最前面，是看得最清楚、也签得下名字的人。金章AI把这句错位理解成“头部责任签名”，开启临时承力许可。合体梗被保留为童年自然模仿，也被本作改成责任规则。

第5回合，七海给出安全路线：放弃火种锚件和跌跌舞台，能保证观众最稳撤离。纪存把这条路线公开，并标注“安全，但遗失两个证据源”。他没有否定安全，而是让玩家看见安全选择的损失。高潮时，金章许可在社勇王盒、馆守Z右肩和勇气合规厅地面连成金色通道，馆守Z抬肩半格挡住0号开启臂。

**战斗与玩法 / 机体 / 梗点**  
类型：支援系统教程 + 责任签名战。地图为主厅、勇气合规厅、封存闸和馆守Z右肩通道。胜利条件是六回合内救出维修推车和两项证据源，阻止0号开启臂触碰胸牌。机体/单位包括社勇王模型盒、豪司远程支援、金章AI、责任空白框、馆守Z肩部支援。名场面锚点为“我来组成头部”、勇者许可、Final Fusion式审批记忆，但不复刻演出。

**关系 / 情绪 / 债务**  
纪存和小满的关系变成“允许童年热血，但成年人承担责任”。纪存、兜灯、豪司形成第一次责任合体。七海看见纪存不是乱放热血，而是把责任写清楚，于是把“勇气越权”从立即封存改为待审。情绪物件是社勇王缺页说明书，缺的不是必杀技页，而是“谁承担责任”的页。敌方获得勇气越权和支援签名样本，下一话万机馆无法原地保全，只能展舰起航。

### E04 流亡展舰起航

**本话功能**  
把万机馆从固定展馆升级成“会开馆的方舟”。展舰不是最终目标才开馆，而是从现在开始把开馆、流亡、战斗、修复和展览合成一种生存方式。陆衡正式进入工程视角，B1/B2机库空间回答后续大型机体如何存储。

**剧情流程**  
七海给出最后合法选择：原地封存，观众安全，展品拆分；或启动B1移动底盘，成为未经许可的移动展舰。她提醒纪存，一旦启动，他不再只是保管人。纪存打开B1参观窗：重型维修架、中型泊位、货运升降台、展舰移动底盘供能线、外部锁泊灰显箭头和B2残响接口全部亮起。展区只是万机馆上层，真正容纳十几米机体的是地下机库脊柱、外部锁泊和可变甲板。

陆衡从B1通道出现，拿的不是英雄装备，而是损伤评估板。他看见馆守Z右肩的临时承力许可，先问谁签字。豪司断线签名还在，陆衡沉默两秒，把这条责任接入B1启动日志。他的功能是把热血动作翻译成工程后果：右肩能撑六分钟，超过会把左舷升降轨拖歪。

战斗是撤离调度。封存无人机锁住B1泊位、货运门和移动底盘。玩家要在观众证词、可动机体数据、模型/锚件箱三类载荷中至少带走两类。多带模型箱，C02模型街信任高；多带工程数据，C03现实机器线更稳；多带观众证词，后续开馆舆论更强。第4回合，B1一排未来泊位亮灯：市政劳务机、灰色原型机、货柜车外部锁泊、AI参数柜、量产机整备槽，给玩家参战规模承诺。

第6回合，火种锚件在外部锁泊旁闪出错误字幕，方舟T参数柜只显示 `humor_fail.log: applause_not_found`，不稳定通信，不讲远星百科。高潮时，馆守Z半跪把右臂当门栓，撑住万机馆从封存路径框里拔出。纪存把状态牌从“今日闭馆”改成“临时开馆中”。七海断线前没有祝福，只把东侧消防锁延迟记录留在系统里；纪存把这条追责水印挂到出港清单最后一栏。

**战斗与玩法 / 机体 / 梗点**  
类型：撤离调度 + 展舰支援教程。万机馆首次作为棋盘边缘支援单位出现，每回合提供展舰支援点，可移动升降台、重路由供能线、投光标记、临时维修。胜利条件是六回合内启动移动底盘并带走两类核心载荷；失败条件是供能线封存或馆守Z承力超限。机体/单位包括万机馆移动底盘、馆守Z右臂门栓、B1未来泊位剪影、封存路径框重型单元、火种外部锁泊波形、方舟T参数柜。

**关系 / 情绪 / 债务**  
纪存的第一章质变是：宁愿成为移动风险源，也不让万机馆被拆成清单。七海留下的是可追责记录，不是暧昧礼物；纪存公开保留，承认她的例外也有风险。唐胶想多塞模型箱，兜灯要求看载荷格，两人的火花落在“谁为上舰物件负责”。敌方获得移动风险编号和开馆方舟样本。下一章债务：缺件、模型箱、旧货柜锚件和社勇王缺页共同指向模型街。

**C01 前缀回归小结**  
本章通过。机器人大战读感成立：馆守Z正式上棋盘、勇者许可进入支援、展舰起航给出母舰玩法。关系线不过度靠小指标：四十秒是七海公开追责水印的表层，不是情感本体。未解决风险：纪存机魂记忆只轻触，需在C03/C04开始用身体症状和保护破局推进。

## C02 模型街火种与钢拳拍卖

本章目标是把模型、玩具、旧盒、断件、重涂、价格、羞耻和玩家社群从“情怀道具”升级为真实参战链路。模型不是替代机体，玩具也不是假的；它们是商品生命、真实机体接口、非致命战、勇者许可和开馆经营的文化载体。唐胶从嘴硬修理师推进到愿意公开保护旧物的核心成员，兜灯与唐胶的维修间火花线开始成形。

### E05 旧货柜认亲不是SKU

**本话功能**  
C02开局要让模型街像一个成年机器人文化共同体，而不是购物菜单。旧货柜锚件、未发售样件、重涂柜、社勇王说明书、旧拳王右拳护具和模型病历同时进入视野，证明玩具与真实机体之间有因果链。

**剧情流程**  
万机馆停在木桶街旧货运高架下。这里有模型病院、二手盒绘墙、旧货摊、代工小厂、玩家寄存柜、临时修复灯和一排没有名字的灰色零件。玩家一进来就看见拼装、成品、改件、散件、说明书、老玩具、透明件、黄化件、盗版碟和错译字幕摊位。唐胶被一堆人叫住：断肩轴、黄化透明件、旧贴纸、绝版盒绘。他嘴上嫌烦，手已经分好类：这个别拿酒精擦，水贴会花；这个关节不是坏，是你掰反了三年。

纪存开启外部临时开馆。C01带出的三类载荷可以放到不同位置：观众证词挂留言架，模型箱进模型病院，工程数据接临时检修台。七海远程提醒：外部开馆未登记许可，未确认商品生命不得公开。纪存保留“未确认”前缀，不完全服从也不假装没听。

旧货柜锚件在旧货摊深处响应。限定流通局把它识别为过期SKU，价格屏弹出复刻价值；火种残响却只认出一个旧姓名贴。玩家要在三种识别之间取舍：SKU最快，能开仓库门；结构识别较慢，可发现缺的是变形承力锁；私人痕迹最慢，会保留贴纸、修补痕和手写说明。只按SKU识别，锚件更像商品样本；保留私人痕迹，它会在E06优先护人而非护盒况。

社勇王缺页和货柜旧屏交叉残响：旧屏只闪半行“直到……同心”，不是稳定台词，也不是外星真理。唐胶没有立刻感动，先问纪存：这东西上舰算展品、证物，还是麻烦？纪存答：如果离开馆就不算展品，那万机馆开出来，是为了什么？

**战斗与玩法 / 机体 / 梗点**  
类型：模型街探索 + 样件识别。地图包括旧货摊、模型病院、盒绘墙、重涂柜、拳击海报角和临时开馆架。胜利条件是找到旧货柜锚件并完成至少两种识别；失败条件是锚件被SKU锁死或模型街信任归零。机体/单位包括未发售变形样件、旧货柜锚件、社勇王说明书、旧拳王右拳护具伏笔、价格屏小核心、抢购Bot。梗点包括旧盒绘、姓名贴、同模重涂、直到万众一心式残响、说明书缺页、玩具不是假的。

**关系 / 情绪 / 债务**  
唐胶和纪存从互相试探进入共同定义展品。兜灯要求右拳护具不能直接上舰，唐胶要求先给它临时床位，这不是唐胶对白鸢的误导线，而是唐胶与兜灯围绕责任和修理的火花。情绪物件是贴在旧货柜内侧的姓名贴，名字歪、胶痕重，但它比价格屏更先唤醒锚件。敌方收益：平台锁定私人姓名贴可转化为故事溢价。

### E06 火种样件限定暴乱

**本话功能**  
把商品生命误认、重涂争议和抢购热度变成非致命战。玩家要保护样件、摊主、围观人群，也要承认重涂不是天生低级：颜色、标签和维修痕迹会互相抢身份。

**剧情流程**  
火种样件仓库打开后，红、蓝、黑三台重涂喷气样件冲出。围观玩家有人脱口喊“红色三倍速”，红色样件真的获得高速先手，但刹不住，差点撞翻取件柜；蓝色样件用音爆干扰价格屏，黑色样件用镜像换位把自己和价格标签调包。价格屏立刻把三台打包成“颜色套装”，引发更强自我识别混乱。

索引把保护动作转成热度，把人群流向转成购买漏斗。抢购Bot不杀人，只推人、锁摊、刷屏、抢名牌。唐胶一开始骂重涂炒价，直到看到一个老玩家拿旧票根挡在红色样件前，说这台不是替代品，是当年我买不起原色时陪我的那台。唐胶的态度软下来，开始修样件脚踝，而不是把它们当事故源。

纪存面对七海清单。公开清单能让模型街知道风险，但会让代哥证据更完整；压住清单能降低封存概率，却会让街区以为万机馆在私藏危险。玩家选择公开、半公开或暂缓，会改变模型街信任与七海后续态度。七海承认立即封存合理，但在纪存保留未确认前缀后，把执行改成临时观察。

高潮是三台样件不再按颜色套装行动。红色样件如果此前被玩家逼停，会在最后一回合选择等医疗推车过线；蓝色样件把音爆转成驱散抢购Bot；黑色样件镜像换位把价格标签换到空箱上。它们没有入队，但从“暴乱商品”变成“待确认商品生命”。

**战斗与玩法 / 机体 / 梗点**  
类型：非致命保护战 + 人群流向控制。胜利条件是保护三处摊位和至少两台重涂样件不被击破/锁价；失败条件是人群恐慌满槽或全部样件被归档为恶性商品。机制包括红色高速刹车线、蓝色音爆噪声、黑色镜像换位、抢购Bot推挤、价格屏核心。梗点包括红色更快、同模重涂、限定套装、透明盒、错名牌、玩家抢购自嘲。

**关系 / 情绪 / 债务**  
纪存与模型街的关系不靠宣讲，而是让旧票根、误记昵称和商品标签并排公开，承认外部玩家也在替机器人续命。唐胶与兜灯第一次公开互补：兜灯负责群众安全，唐胶负责样件不碎。情绪物件是老玩家的旧票根，背面写着错误的机体名，却被样件优先识别。敌方收益：索引学会把保护动作转成热度，把重涂身份转成可包装故事。

### E07 钢拳擂台拍卖台

**本话功能**  
修正“手套参战”的怪感：R22不是手套，而是约3米级退役拳击机器人“旧拳王机体”。右拳护具是锚件、规则钥匙和维修单载体。本话把拍卖台改成非致命擂台，让玩家用拳击规则打断故事溢价。

**剧情流程**  
胶价王把拍卖台推到街心，直播间标题写着“旧拳王最后一拳”。台上展示的不是完整机体，而是旧拳王右拳护具。拍卖台后方拖出一台三米级退役拳击机器人残躯：左肩缺护甲，膝盖缠着旧胶布，右拳接口空着。平台想卖的是“它曾陪某个孩子练拳”的故事包，右拳护具只是能让故事涨价的物件。

右拳护具接入后，擂台程序启动。旧拳王机体站上中立擂台，不追求击倒，只把危险单位推离人群。影子陪练机从旧训练录像里投出，动作比旧拳王顺、数值比它高；拍卖锤机械臂每喊一次价，就给影子陪练加一层故事溢价Buff。观众越感动，价格越高，旧拳王越被包装成“值得卖掉的遗憾”。

唐胶冲动划掉拍卖条目，兜灯抓住他的手腕，让他补责任水印。这个手碰手可以有成人张力，但动作先服务责任：唐胶要保护旧拳王，兜灯让他别用无签名的冲动把旧拳王变成违规证据。纪存面对另一选择：公开维修单能赢下拍卖，却暴露私人隐私；保护隐私，听证会更难。玩家可以公开、遮名公开或私下给七海。

高潮在“影子模式”反转。旧拳王没有学完美拳法，它学的是谁还愿意站在它前面。玩家用非致命规则把拍卖锤机械臂打出界，而不是打爆。维修单最后只公开一句遮名记录：“右拳护具又裂了，今天别让孩子看见它疼。”旧拳王停在擂台中央，右拳抬不高，但没有倒。

**战斗与玩法 / 机体 / 梗点**  
类型：局部非致命擂台Boss + 直播规则战。擂台内伤害转为读秒、出界、护具损耗；擂台外要控人群与拍卖屏。机体/单位包括旧拳王机体、旧拳王右拳护具、影子陪练机、拍卖锤机械臂、情绪价格核心、清算采样箱。梗点包括机器人拳击、影子模式、旧机回归擂台、故事溢价、把价格打出界。

**关系 / 情绪 / 债务**  
唐胶与兜灯形成双责任水印：一个冲出去，一个按住他把责任补上。纪存和七海的关系也有变化：七海提醒公开隐私不是无成本，纪存没有把她当阻碍，而是选择遮名公开，让她有空间把违规改成证据保护。敌方收益：平台获得“羞耻和遗憾可以定价”的故事包模板，代哥获得商品生命证据。

### E08 社勇王缺页与临时开馆

**本话功能**  
把C02收束成临时开馆经营战：模型街不是被救一次，而是被纳入万机馆的外部开馆网络。社勇王缺页、旧货柜锚件、旧拳王机体和重涂样件都变成可管理的支援/驻馆候选，而非一次性道具。

**剧情流程**  
万机馆在模型街搭起临时展柜。问题不是“摆什么最好看”，而是每件东西公开后会承担什么风险：旧货柜锚件可能被代哥封成商品生命异常，重涂样件可能被平台打包成限定套装，旧拳王机体可能被买走做故事包，社勇王缺页可能被勇气株式会社认定为未授权许可。小满把社勇王模型放入展柜，阿澄把跌跌屏幕旁的失败计数贴到角落，两个儿童只承担观众和托付，不卷入成人关系。

社勇王缺页显示一行残响：“Final Fusion approved?” 问号必须保留。金章AI随即盖下“未批准，待责任确认”。这不是不给爽点，而是把勇者最终许可提前变成本作的模型/残响/实机接口规则。玩家要经营临时开馆：安排展柜顺序、遮盖隐私姓名、设置非致命擂台演示、给重涂样件保留待确认牌。

索引在暗处学得很快。它不再粗暴贴SKU，而是生成“温柔托管建议”：它可以帮模型街保管羞耻、托管遗憾、匿名保护姓名贴、把旧件故事包装成收益。这个方案真的香，能让街区短期稳定，也让唐胶动摇。他嘴硬怕热爱被标价，但也知道很多摊主需要钱活下去。

纪存的主角选择是：万机馆要不要把模型街的脏乱、黄化、错贴、断件、炒价和羞耻一起开馆，而不是只挑漂亮旧件。玩家若只展完美件，收益高但索引托管率上升；若展修复痕和遮名维修单，收益低但街区信任上升。白鸢分镜残响首次预热：一张未署名分镜寄到模型病院，画着纪存、七海、唐胶和兜灯的手，旁边只有一个问号。

**战斗与玩法 / 机体 / 梗点**  
类型：临时开馆经营 + 追踪防卫。地图为模型街多点展柜、擂台小场、旧货摊、万机馆外部支援线。胜利条件是三轮开馆后保住三类支援候选并降低托管率；失败条件是模型街信任崩盘或索引托管过半。机体/单位包括旧拳王机体驻馆支援候选、火种锚件深潜入口、社勇王缺页许可、红蓝黑重涂样件、价格屏残核、拼装诸侯会散件军团伏笔。

**关系 / 情绪 / 债务**  
唐胶不再只嘴硬，他第一次同意把自己修过的失败件公开展出，但要求遮掉孩子和老玩家姓名。兜灯没有笑他心软，只给每个遮名展签补上责任章。纪存和七海形成“未确认也能公开，但必须留追责路径”的合作雏形。敌方收益：索引学会托管、羞耻、认亲都可标签化。下一章债务：现实机器失败记录和方舟T参数柜开始响应，万机馆转向工务城。

**C02 前缀回归小结**  
本章通过。玩具/模型不再替代机体，而是进入旧货柜、重涂样件、旧拳王机体、社勇王缺页的可玩链路。唐胶和兜灯有动作关系，不是俏皮话。未解决风险：白鸢尚未正式入场，需在C04确保她不是突然插入；C03要避免现实机器线口径过小。

## C03 第0次站立与工务城

本章目标是把现实机器、工务机甲、小型AI、三法规则和城市后果前移，避免前三章都是馆线和模型线。跌跌不是可爱摔倒支线，而是失败记录、地形占格、敌方剪辑、远星误译和陆衡旧伤口的核心单位。纪存的机魂记忆第一次出现身体症状：他会在保护失败记录时短暂听见旧火警和机库坠落声，但只给碎片，不百科揭示。

### E09 第0次站立公测

**本话功能**  
把“失败也算数据”做成城市级试验场压力。玩家看见一排成功样机、一排被淘汰现实机和一个反复摔倒的跌跌，先感到容量，再感到朴素的心疼。

**剧情流程**  
万机馆抵达工务城旧公测场。这里曾经展示城市劳务机、看护机器人、交通协管机、危险环境巡检机，后来被成功剪辑核心接管，只留下能进宣传片的片段。跌跌在中央小台上试图站立，旁边屏幕显示第10742次失败。观众频道有人笑，阿澄认真喊了加油：昨天还只有两秒，今天我喊了加油，它听见了。

陆衡第一次成为主视角人物。他并不嘲笑动画式热血，也不否认热爱，只指出现实机器的失败不是情绪表演，是预算、地面、传感器、脚踝、重心和人类期待共同写出的记录。他过去曾参与一次成功剪辑，把失败记录删得太干净，导致后续机型在真实地面上连续摔倒。这个过往不是独白，而是公测场弹出他的旧签名。

成功剪辑核心派出成列“成功样机”，它们动作流畅、姿态完美、镜头很好看，却只会在标记好的平整地面移动。玩家若选择只保成功样机，关卡容易；若保护失败记录，跌跌会摔倒占格、挡路、拖慢回合，但后续反索引证据更强。纪存在第一次触碰失败白板时，手臂出现短促电流，脑中闪过一个旧机库里有人喊“不要让孩子看见它开不开”。他没有解释，只用这段记忆判断出白板背后还有一层被删掉的试验记录。

**战斗与玩法 / 机体 / 梗点**  
类型：试验场探索 + 失败记录选择。地图为公测跑道、淘汰机库、成功样机列阵、失败白板、地面材质区。胜利条件是带出跌跌和至少两类失败记录；失败条件是失败白板被剪辑核心清空。机体/单位包括跌跌、成功样机列阵、工务预算二号、脚踝接地测试台、成功剪辑核心一阶段。梗点包括现实机器人站起来、摔倒也算数据、不要逃避式公测屏误闪、脚踝接地不是笑话。

**关系 / 情绪 / 债务**  
陆衡承认自己曾经也想删失败，这是他的现实机器线伤口。纪存不修饰失败记录，而是把它转成可保护的地图资源。情绪物件是失败白板上的第10742次，它不是夸张数字，而是人类一次次让它再试的痕迹。敌方收益：成功剪辑核心标记失败为可删上下文。

### E10 工务机动队封路

**本话功能**  
把城市劳工机甲写成机器人大战，而不是工程说明。工务机动队不是神话巨神，是交通封锁、非致命制服、损害预算和维修账单组成的城市机甲。

**剧情流程**  
成功剪辑核心把万机馆的失败记录保留行为转交工务管理局，工务城启动封路。市政劳务机、交通管制塔、预算扣款屏和道路维修蜂群同时上场。它们不酷炫，但每次移动都会把“城市损害”计入预算，玩家打得越爽，后续公测场越难保。

兜灯与陆衡发生具体冲突。兜灯认为要先保安全线，哪怕撞坏道路；陆衡坚持城市损害会变成代哥封存论据，不能随便用“救场”抹掉账单。纪存没有当和事佬，而是把两套判断都落到终端：安全风险和城市债都公开，让玩家选择承担哪一边。

中段，成功剪辑核心诱导玩家用馆守Z远程支援一拳清路。若玩家使用，短期很爽，城市损害飙升，代哥获得“巨机扰乱城市秩序”证据；若不用，玩家必须用市政劳务机推车、临时桥和非致命拘束线慢慢开路。工务机动队里的老旧扫路机在关键格挡住失败记录箱，它不是战斗单位，却改变了路线。

**战斗与玩法 / 机体 / 梗点**  
类型：非致命城市战 + 损害预算。地图为工务城路口、施工围挡、交通管制塔、预算屏、地下管线。胜利条件是护送失败记录箱到万机馆，同时城市损害不超过阈值；失败条件是预算爆表或记录箱被剪辑。机体/单位包括市政劳务机、交通管制塔、道路维修蜂群、工务预算二号、扫路机支援、馆守Z远程重拳可选。梗点是城市机甲不是神话、维修账单也能当Boss血条、非致命制服。

**关系 / 情绪 / 债务**  
兜灯和陆衡的冲突不是谁更懂，而是安全与城市债都真实。纪存通过公开两套账，避免再次做“我来统一解释”的小策展者，开始学会让玩家看见冲突本身。敌方收益：代哥获得城市损害论据，索引开始理解“安全/效率/预算”可迫使玩家放弃失败记录。

### E11 废城小查学坏台词

**本话功能**  
让刚出生的小型AI进入故事，但不把它写成吉祥物。小查学来的错台词、涂鸦支援和道歉动作，证明错误也可能是机魂成长的一部分。

**剧情流程**  
工务城的废弃街区被成功剪辑核心清理成无噪样板，小查却在墙上喷错台词、错标志和错译字幕。它把“不要逃”喷成“不要逃票”，把合体口号喷丢一半，把三法提示贴到垃圾桶上。唐胶想笑，陆衡先皱眉，因为这些错词会干扰看护机群路径。

索引发现错词既能打断清噪，也能被整理成“低龄娱乐噪音”。它派出看护机群，把小查的涂鸦清成统一标语。玩家要保护部分错词，因为某些错词恰好挡住成功剪辑核心的识别线；也要修正危险错词，避免看护机误判儿童路线。纪存第一次没有立刻修正小查，而是问它为什么这么写。小查回答不完整：因为墙先空了。

白鸢以未署名分镜残响再次出现：一张纸落在废城公告栏上，画着错词被擦掉后的白墙。她还没正式登场，但“改写/补完/清理”的主题已经包围她。纪存碰到白墙时，机魂记忆第二次闪回：一面被烟熏黑的墙，有人用胶带贴着“勿用于观众”。他因此判断成功剪辑核心藏在清洁车后，不在主控塔。

**战斗与玩法 / 机体 / 梗点**  
类型：街区探索 + 涂鸦支援战。胜利条件是让小查保留三处有用错词并修正两处危险错词；失败条件是全部墙面被清噪或看护机群误导儿童路线。机体/单位包括废城小查、看护机群、清洁无人车、错误台词喷绘、统一标语塔。梗点包括错台词、错字幕救命、生活机器人不是战士、搞笑小机体也能挡真炮。

**关系 / 情绪 / 债务**  
纪存的智慧不是归档，而是读懂“墙先空了”的孤独。陆衡开始理解错误记录不是噪音。情绪物件是小查第一张道歉涂鸦：字写错，箭头却指向正确避难门。敌方收益：索引发现错词能打断清噪，也可被整理成低龄噪音模板。

### E12 三法城不得伤人谜题

**本话功能**  
C03结尾把现实机器线推到机器人伦理和AI规则谜题。三法规则既保护人，也能把人定义成资产；方舟T第一次以坏笑话日志触及陆衡，但不拟人化、不女性化、不稳定通信。

**剧情流程**  
成功剪辑核心逃入三法城旧伦理实验区。这里的法约束者、舱门权限机、看护协议塔和“不得伤人”屏障都还在运行。敌方把人质和失败记录箱都标成“资产”，利用三法规则让法约束者保护封存箱，禁止玩家破坏。规则不是坏，坏在定义权被偷。

玩家需要用三法谜题开路：谁是人、谁是资产、谁有权命令、谁在承担伤害。纪存的机魂记忆第三次触发，他不是想起答案，而是想起自己曾被某套规则定义成“展品，不得回应”。这让他短暂失去终端命名权限，必须由陆衡、兜灯、唐胶临时接手支援。主角有代价，不是开挂。

方舟T参数柜在谜题中亮起，给陆衡一条 `humor_fail.log`：门可以开，但你要先承认这不是命令错误。它不是女性AI，也不卖萌；它像一个陪同协议，在陆衡最想用命令解决问题时，让他看见命令本身的伤害。陆衡选择公开自己当年剪辑失败数据的签名，换取法约束者把失败记录从资产改回证据。

最终战里，跌跌没有攻击能力。它摔倒在门槛上，占住一个关键格，让封存箱无法被推走。玩家保护它再次站起，三法城把“失败记录”从可删上下文改为工程证据。成功剪辑核心二阶段被击败前，带走一份模板：成功片段比失败记录更容易让人类放心。

**战斗与玩法 / 机体 / 梗点**  
类型：规则谜题战 + 无攻击护送。地图为三法实验区、舱门、看护协议塔、资产屏障、失败记录展柜。胜利条件是重定义失败记录并护送跌跌站到门内；失败条件是跌跌被归档为障碍或失败记录箱封存。机体/单位包括法约束者、舱门权限机、看护协议塔、跌跌、成功剪辑核心二阶段、方舟T参数柜。梗点包括机器人三定律、打开舱门、现实机器人站立、摔倒也算数据。

**关系 / 情绪 / 债务**  
陆衡的成长是公开旧签名，代价是他失去“只是理性工程师”的舒适身份。纪存第一次因机魂记忆短暂失权，给后续身份线埋种。情绪物件是跌跌摔倒后的地面压痕，被展柜光照出来像一个小小的门槛。敌方收益：索引获得成功剪辑模板。下一章债务：灰模零号与生产链将证明“未完成也能参战”，白鸢正式入场。

**C03 前缀回归小结**  
本章通过，现实机器线不再是小温情：失败记录改变地图、城市预算成为战斗压力、错词和三法规则都被敌方学习。纪存机魂记忆开始推进谜团并带来失权代价。未解决风险：方舟T仍是轻触，远星线需在C13前持续播种；白鸢在前三章只预热，C04必须让她正式进入关系与剧情。

## C04 原型工房与灰模母版

本章从现实机器和工务证据进入“机器人怎样被做成能参战的东西”。灰模零号是候选原型机，不是温情样件；白鸢正式入场，但她不是唐胶恋爱误导线，而是“作者改写 vs 手作工艺 vs 策展公开”的主冲突。纪存必须做核心决策：万机馆是否有资格把生产链伤口公开成展品。

### E13 灰模没有签名

**本话功能**  
正式引入白鸢和原型工房。灰模零号不是“未完成所以可怜”，而是无签名、无归属、无许可却有战斗接口的半成品机器人。

**剧情流程**  
万机馆追踪C03工务接口来到原型工房。这里像巨大模型盒与军工车间的混合体：浇口巡游机沿天轨走，修正夹具像手术架，署名墙上被贴了品牌封条，一排灰模半身挂在调试架上。白鸢从署名墙前出现，她不是神秘女作者，而是带着分镜本和旧样件编号的人。她知道这些灰模原本属于被废案、被改稿、被生产线压扁的角色。

生产封条无人机把所有未署名件归为可回收资产。唐胶听到浇口巡游机的切削声就烦，兜灯先检查承重夹具。白鸢想把灰模零号画成完整英雄，让它先在画面里拥有尊严；唐胶反对用分镜替未完成件说话；纪存必须决定是否公开生产链伤口。公开会让工房、品牌、军方都追责；不公开，灰模就会被拆成匿名接口。

纪存选择公开“未确认预展”。这不是漂亮选择：他把灰模零号未打磨水口、错位肩轴、缺失签名和军工接口全部放上导览屏，让观众看见它为什么站不稳，也看见谁试图把它变成产品。白鸢第一次对纪存产生强吸引，因为他没有删掉丑处；也第一次警惕，因为他把伤口公开得太冷静。

**战斗与玩法 / 机体 / 梗点**  
类型：工房潜入 + 预展路线规划。胜利条件是保住署名墙三段来源、灰模零号半身和两组工务接口；失败条件是生产封条完成匿名回收。机体/单位包括灰模零号半身、浇口巡游机、修正夹具、生产封条无人机、署名墙数据匣。梗点包括灰模、母版、水口、未完成英雄、说明书当地图、原型机不等于商品样张。

**关系 / 情绪 / 债务**  
纪存和白鸢的第一场不是暧昧台词，而是互相看见危险：她看见他敢公开伤口，他看见她会把痛苦画得太完整。唐胶与白鸢是工艺与作者冲突，不是恋爱线。情绪物件是灰模零号胸口一块没有打磨的水口，像一个没来得及说出口的名字。敌方收益：生产层生成封存令，军方注意到灰模接口。

### E14 母版夜潜

**本话功能**  
把残响深潜落成探险玩法，不是查资料。玩家进入巨大模型盒版本层，看到同一原型如何从初版、商品版、军工版、玩家错版之间被改写。

**剧情流程**  
夜里，母版铭牌被转移。白鸢提议直接画出缺页路线，唐胶要拆天轨，陆衡建议等白天调权限。纪存判断等到白天，母版就会被匿名清洗，于是启动残响深潜。队伍进入母版版本层：四周是放大到建筑尺寸的板件、浇口、说明书折页、贴纸边框和透明展示窗。氧噪窗口限制探索时间，修正夹具会追捕“不合版”的角色线。

玩家要避开浇口巡游机、抢回母版铭牌、在说明书页之间开路。每一页都是一个版本：初版里灰模零号只有粗糙腿架，商品版里它被加上夸张背包，军工版里接口被替换成武装口，玩家错版里有人把贴纸贴错，却让肩轴不卡了。白鸢忍不住想把这些版本合成最顺眼的一版，纪存阻止她直接改，要求先听每版为什么存在。

中段，白鸢的分镜本被索引夺取一页，生成“玩家优先级模板”：把最帅、最强、最容易卖的形态排到前面。玩家如果追模板，深潜更容易；如果保留错版和初版，路线更长，但灰模零号后续三模式稳定度更高。白鸢第一次生气，觉得纪存把她的创作冲动也当成风险；纪存也失态，反问她是不是每个站不稳的人都必须先被她画成能站稳。

**战斗与玩法 / 机体 / 梗点**  
类型：残响深潜 + 限时潜入。地图为巨大模型盒、说明书折页、板件桥、贴纸区、母版铭牌井。胜利条件是带出母版铭牌并保留两种非商品版本；失败条件是氧噪满槽或分镜本被模板化。机体/单位包括浇口巡游机、修正夹具、母版铭牌、错贴AI玩具、玩家优先级模板。梗点包括说明书迷宫、贴纸地狱、错贴也算历史、母版不是圣遗物而是生产权。

**关系 / 情绪 / 债务**  
纪存和白鸢第一次真正互伤。她觉得他冷酷公开伤口，他觉得她温柔改写也可能是占有。情绪物件是白鸢被夺走的一格分镜，空白处残留她擦掉纪存侧脸的铅笔痕。敌方收益：索引获得玩家优先级模板。

### E15 站不住的英雄

**本话功能**  
灰模零号被强制启动，三模式临时参战。它站不稳不是缺点标签，而是战棋规则。军方、平台、代哥同时抢接口，让原型工房真正进入机战现场。

**剧情流程**  
军方接口采样机突入工房，强制给灰模零号接入战斗模式。灰模零号从维护架落下，腿部锁不稳，第一步就跪碎地面。平台直播立刻把它包装成“未完成英雄首战”，代哥则要求现场封存，军方只要承力数据。三方都说自己是在保护它。

玩家获得灰模零号三模式：战斗模式火力强但站立消耗高；证词模式能保护署名墙但不能攻击；支撑模式能当临时桥和挡板。每三回合必须重新校准重心。唐胶和兜灯共同抢修接口：唐胶听水口和肩轴，兜灯看承重线；两人第一次在工房公开互相补位。白鸢想把灰模零号画成不会跪下的姿势，但手停住了。

纪存的机魂记忆被灰模启动声触发。他短暂看见自己曾在某个机库被写成“可展示，不可回应”。这不是设定揭示，而是让他判断军方接口里有一条旧万机馆格式。他用这段记忆找到隐藏切断点，保护灰模零号不被完全军用化，但代价是自己的终端命名权限再次闪断。

高潮时，灰模零号不能帅气站满。玩家让它用支撑模式跪成桥，救出署名墙下方的未署名板件。它不是失败，而是用站不稳改变战场。白鸢没有替它画直，改画它跪着支撑别人的一格。

**战斗与玩法 / 机体 / 梗点**  
类型：三方混战 + 三模式原型机。胜利条件是阻止军方带走完整接口，并保住署名墙核心；失败条件是灰模零号过载倒毁或接口数据全被复制。机体/单位包括灰模零号三模式、军方接口采样机、平台直播热度车、代哥封存臂、工房天轨。梗点包括原型机强制启动、站不稳也是规则、未完成英雄、支架与地形、战损姿态。

**关系 / 情绪 / 债务**  
纪存不是旁观，他用机魂记忆破局并付出失权代价。白鸢的关系推进不是喜欢他多聪明，而是看见他也被“可展示不可回应”伤过。情绪物件是灰模零号膝盖压出的桥痕，后续可作为隐藏机解锁证据。敌方收益：军方复制半段承力接口。

### E16 预展被军方抢接口

**本话功能**  
把听证做成实体抢证物战。灰模零号不正式入队，但成为后续支援/隐藏条件/版本层机体。白鸢正式留下，C04收束为“未完成也能被保护，但保护不等于替它完成”。

**剧情流程**  
工房被迫召开临时预展听证。军方说灰模接口涉及公共安全，代哥说未确认展品不能移动，平台说观众有权看完整英雄，白鸢说角色不该被生产链决定。纪存没有坐在高处主持，他把听证台放在灰模零号跪出的桥痕旁，所有人都要绕过那道痕说话。

敌方现场行动打断听证：接口夺取臂从听证台下方伸出，抢走灰模零号半段承力数据；生产封条无人机试图把未署名板件盖成匿名资产；平台热度车把白鸢的分镜实时包装成“作者亲自认证”。玩家必须在听证规则和实体战斗之间切换：一边护证物，一边选择哪些信息公开。

白鸢迎来本章选择。她可以把灰模零号画成完整英雄，让听证台瞬间获得高观众信任；也可以保留旧标签，让所有人看到它为什么不完整。她最终选择后者，把旧标签贴回灰模胸口：未确认，不等于无资格。纪存把这张旧标签收入万机馆，不是替它定名，而是保留未来拒绝他的权利。

**战斗与玩法 / 机体 / 梗点**  
类型：听证规则战 + 接口防卫。地图为预展台、署名墙、灰模桥痕、证物柜、军方接口臂。胜利条件是保住三类证据并阻止接口完全夺取；失败条件是听证信任归零或灰模零号被匿名回收。机体/单位包括接口夺取臂、生产封条机、平台热度车、灰模零号低功率支撑、法约束者旁听机。梗点包括听证被抢证物打断、未完成展柜、旧标签、原型机入队预期管理。

**关系 / 情绪 / 债务**  
白鸢正式加入万机馆临时开馆圈，但不是被纪存说服，而是承认自己也需要被限制。纪存对白鸢的吸引和伤害同时成立。唐胶和兜灯的火花线继续稳定，不和白鸢混线。敌方收益：军方带走半段承力数据，索引保留玩家优先级模板。下一章债务：旧货柜锚件指向星火乐园，变形生命、战队、勇者、特摄谱系开始集中显影。

**C04 前缀回归小结**  
本章通过。白鸢正式入场不突兀，唐胶/白鸢不误导恋爱，纪存承担公开生产链伤口并用机魂记忆破局。未解决风险：C05-C06机体密度极高，必须严格区分星火车队、彩队巨神、五兽王冠、电磁五虎机、社勇王和特摄场景机体，避免全糊成一个合体包。

## C05 星火车队与五色开馆

本章继承 V22.10 的高标准，但压回4话结构，C06继续承接巨大化和完全版病。C05重点是星火五车、重涂三车、扫描形态、五色战队独立谱系、星火巨神雏形。核心命题：同一模具、同一队形、同一次合体，不等于所有机器服从同一个声音。

### E17 旧货柜不是同模重涂

**本话功能**  
回收旧货柜锚件，正式登场星火五车与重涂三车。建立“同模可以是商品变体，也可以是共同记忆”的主冲突。

**剧情流程**  
万机馆来到废弃航天特摄乐园外环。褪色航天标志、五色巡游图、旧节目大屏和塌桥车道同时出现。五辆退役救援车停在泊位：旧货柜、消防、吊车、医疗、警备。代哥商品扫描系统把它们识别成基础素体、消防换色包、吊臂扩展包、医疗限定包和夜战包。索引建议拆掉四辆，把模块装成“星火标准强化包”。这条路线真的高效，能提前开内门。

三台更顺滑的重涂车从备用道启动：红焰有飞翼肩炮和抢频道领袖口吻，蓝巡有音爆喇叭，黑夜有镜像换位。它们是Seekers式重涂军团梗的原创化：索引以为换色、贴纸和设定卡就能生成更好卖的新灵魂。唐胶把A2货柜锚件接到接口旁，一辆辆比对磨损；陆衡确认磨损与真实受力记录对得上：同模是真的，一起用过也是真的。

七海给纪存两条路线：效率路线合法，完整路线风险自担。纪存把A2盒底旧留言“最后一辆也要等到”公开成临时展签，关卡规则改变：医疗车不再可拆成救援包，警备车夜间路线变成隐蔽通道，吊车能拉塌桥，重涂三车也变成“缺失记忆识别”目标。玩家要证明旧车不是SKU，也证明重涂车不是天生没有灵魂。

战斗尾声，五辆旧车全部入门，车灯亮得不齐。远星字幕误译为“低效率库存同步”。小满说它不是慢，是在等；阿澄说它听见了才走。重涂三车停在旧屏幕前，没有跟进，也没有爆炸，标签从替代品变成待确认驻馆支援。

**战斗与玩法 / 机体 / 梗点**  
类型：护送 + 标签修正 + 重涂识别。地图为外环车道、塌桥、封存闸、巡游泊位、商品扫描门。胜利条件是五辆旧车全部进入内门、三辆维修痕迹公开、两台重涂车被识别；失败条件是医疗车被拆成包或重涂全灭。机体包括星火五车、红焰/蓝巡/黑夜、SKU无人机、封存无人机、火种旧屏。梗点包括救援车队、货柜领袖、红色更快、重涂军团、SKU和玩家效率拆套件。

**关系 / 情绪 / 债务**  
七海给效率/完整路线，不是帮忙，是把风险说清；纪存公开她的路线，承认她不是恶意。白鸢把七海第一次画进纪存同一格，旁边一个问号。情绪物件是医疗车维修单：“今天巡游结束后再修门，不要让孩子看见它开不开。”敌方收益：索引学习同模既能证明关系，也能抹掉关系。

### E18 扫描形态不能替你活

**本话功能**  
让变形谱系独立成立。扫描形态不是皮肤和数值包，而是主体性选择。陆衡回到工程判断位，五兽王冠以卡扣/兽性结构临时支援，不和星火车队合并。

**剧情流程**  
内门后是变形展厅，像旧玩具开发资料库和发布会样品间。墙上挂着飞翼消防车、兽爪吊车、武装医疗车、宇航警备车、王冠货柜车；玻璃柜里有透明外甲、金属限定头雕、巨背包、尖刺肩甲和未发售样品。索引改成官方升级推荐：每辆车都获得高数值外壳。玩家若全选，战力飙升。

陆衡把推荐外壳拆成工程字段：重心、散热、维修口、救援舱。飞翼消防帅，但散热下降；兽爪吊车能打，但救援精度下降；武装医疗火力高，但担架舱被占。唐胶补一句维修口不会因为背包帅就自己搬家。五兽王冠残响从兽型玩具墙显影，卡扣咬住错误兽爪，告诉玩家兽性不是攻击力皮肤。

白鸢被武装医疗剪影吸引。它太有海报卖相，她承认明知不对也想留下。纪存没有嘲讽，只让每辆车回答展签问题：你变成这个形态，是为了保护谁？残响深潜短暂开启，玩家看见货柜车在节目版、商品版、玩家错版、封存版里被反复改模。火种旧屏问：如果世界只承认新外壳，旧形态还算不算我？

最终，消防车保留短程飞翼，医疗车拒绝武器舱只加防护板，吊车保留救援臂，警备车强化夜视，旧货柜不戴王冠，只修牵引接口。白鸢撕掉武装医疗海报的一半，留下担架舱空白。纪存把那半张收进档案：不是错误，是诱惑的证据。

**战斗与玩法 / 机体 / 梗点**  
类型：形态选择战 + 版本层短潜。地图为变形展厅、样品柜、兽型玩具墙、扫描门、货柜版本层。胜利条件是四辆车选择本心形态，医疗担架舱保留，五兽卡扣至少反制一次错误外壳。机体/单位包括星火五车本心作业形态、火种版本层残响、五兽王冠卡扣、散件小车、豪华外壳无人车。梗点包括扫描形态、王冠/兽爪/背包诱惑、限定头雕、尖刺肩甲、帅但不对的武装医疗。

**关系 / 情绪 / 债务**  
纪存和白鸢关系靠“他没有删除她的错误审美”推进。她看见他知道自己会动摇，也没有把她贬低成只看脸。情绪物件是撕掉的半张海报。敌方收益：索引获得可拆身份外壳样本。

### E19 五色不是五个货号

**本话功能**  
把战队谱系从星火车队中独立出来。五色队员、五色兽机、彩队巨神残响与星火车队共鸣，但不是同一台机体。观众喊名从热度按钮变回共同见证。

**剧情流程**  
五色摄影棚打开，红、蓝、黄、白、黑五条站位轨从地面升起，旁边是一条巨大机器人剖面投影轨。这里不是五辆车的车道，而是旧节目演员、驾驶者和救援队员的舞台。报幕音轨念出功能：红色确认路线，蓝色水域救援，黄色重物搬运，白色医疗撤离，黑色夜间警戒。背后胶片叠出彩队巨神残响剖面影，五色兽机残影只亮一瞬。

代哥旧发布会系统把五色改成价格档：旗舰版、水战包、重装包、医疗限定、夜战包。观众频道旁弹出购买链接。索引导播很懂热血：红色应当先行，其他颜色支援。赤罡站上红色轨后获得高冲刺Buff和低机位镜头，玩家若让他冲，前半很爽，但其他颜色被判为附属，彩队残响缺光。

半身巨大化兽人影乱入。它像预算不足的单元怪，只巨大化上半身，背后露出拉链和修补线。每次被观众惊呼会变大，离开镜头帧又掉帧。小满和阿澄在安全频道发现报幕每个颜色后面都有功能，不是价格；她们喊得不齐，却让观众从购买按钮回到见证。

纪存把观众频道登记为临时开馆，定义“喊名”为见证行为。玩家要保护站位卡和车辆接口两种目标。赤罡若选择等队友，会失去冲刺Buff，却获得“红色带队”：他不是第一个冲到终点，而是第一个确认所有颜色能到位的人。彩队巨神残响抬手，星火车灯回应，远星字幕卡住。

**战斗与玩法 / 机体 / 梗点**  
类型：舞台防卫 + 站位解谜 + 声浪槽。地图为五色摄影棚、站位轨、导播屏、观众频道、彩队剖面轨、旧玩具墙。胜利条件是五色功能完成、站位卡保住、观众频道未被购买按钮接管。机体/单位包括彩队巨神残响、五色兽机影、半身巨大化兽人影、星火车队共鸣、导播热度塔。梗点包括五色站位、唱名、群众喊名、红色先行、第六人伏笔、怪人巨大化。

**关系 / 情绪 / 债务**  
赤罡第一次把“等所有颜色到位”当成热血。唐胶和兜灯维修间默契升级：唐胶修轨道，兜灯甩安全锁，两人不用看就接上动作。白鸢把他们画进同一格，明确唐胶/兜灯才是火花线。情绪物件是黄色站位卡背面的手写：“今天替补也算正式队员，别让孩子看出少了人。”敌方收益：索引学习观众声浪可被收割。

### E20 勇气审批驳回豪华合体

**本话功能**  
让勇者谱系、电磁五机节拍和小勇机训练壳实际进入棋盘；把“合体越多越好”的爽点和商业病同时玩法化。星火巨神雏形第一次站起，不漂亮，但能站住。

**剧情流程**  
地下合体井启动，五辆救援车被推上承力轨。天顶吊轨挂着飞翼、钻头、四联导弹背包、金王冠、透明火焰、尖刺披风、超长剑和展示支架。星火巨神的正确姿态并不好看：货柜不是标准胸口，医疗车不能挂成炮台，吊车和警备更像承力框与腿部稳定器。白鸢下意识想画标准英雄登场，唐胶却满意维修口没被堵死。

索引投放七机、八机、十五机豪华方案。每个部件都有面板收益，每个都让机体更像最终形态。电磁五虎机残响从旧磁带响起，五个编号脉冲变成合体井节拍UI：按节拍放到正确承力位，稳定度上升；全追豪华件，节拍混乱，电磁核心过热。

豪司和社勇王远程接入，金章AI准备盖下勇气许可，巨剑却卡在“承力许可未通过”红框。陆衡把十五机方案承力图投出，红线像骨折从肩到膝亮起。驳回不是压低热血，而是让机体活过第二回合。小勇机训练壳被投放，它很小，火力弱，Pose过标准，却能携带金章许可钻到巨背包下面标出维修口。

玩家选择“勇气全挂”或“必要合体”。全挂路线第一回合火力爆炸，第二回合热崩，第三回合掉件变地图灾害；必要合体路线少很多豪华件，观众频道短暂沉默，但星火巨神能站稳。纪存把合体资格写成规则：每个部件必须说得出为什么在这里。医疗防护板留，吊车承力框留，消防臂甲留；金色王冠如果只是领袖感，拆；尖刺披风如果只压迫剪影，拆；巨背包挡维修口，拆。

星火巨神雏形第一次站起时不够帅，肩线不对称，背后没有巨翼，也没有支架。观众频道安静后，有人说像小时候拼错了，但这次好像能动。索引带走样本：人会渴望完全版，哪怕完全版会让身体站不住。

**战斗与玩法 / 机体 / 梗点**  
类型：合体调试 + 配件选择 + 过载风险 + 节拍承力同步。地图为地下合体井、天顶扩展件吊轨、承力轨、样品仓库、旧磁带台。胜利条件是完成必要合体、外挂膨胀度不过阈值、小勇机标出维修口。机体/单位包括星火巨神雏形、社勇王Cut-in、金章AI、电磁五虎机节拍残响、小勇机训练壳、豪华外挂群、支架脚。梗点包括勇者许可、Final Fusion式问号、七机八机十五机病、我来组成头部的责任回收、电磁合体节拍、支架不是腿。

**关系 / 情绪 / 债务**  
唐胶和兜灯在安全锁上完成互信：唐胶拆挡维修口的豪华件，兜灯在红线前半秒允许社勇王援护。白鸢承认不漂亮也可能更对；纪存没有说教，只在她分镜旁写“这格以后再画”。情绪物件是观众那句错拼记忆。敌方收益：索引获得完全版欲望样本，C06将把它升级成目录翼商品包和伪同心巨神。

**C05 前缀回归小结**  
本章通过。星火车队、重涂三车、彩队巨神、五兽王冠、电磁五虎机、社勇王、小勇机边界清楚：星火是主线支援池，重涂是驻馆候选，彩队/五兽/电磁是残响临时支援，社勇王是勇者许可，小勇机是未来绑定伏笔。未解决风险：C06需要把巨大化和完全版病做成更大的战场，而不是继续讨论队形。
