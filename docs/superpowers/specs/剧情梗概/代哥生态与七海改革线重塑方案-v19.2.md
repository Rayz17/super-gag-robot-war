# 《超GAG机器人大战：万机残响》代哥生态与七海改革线重塑方案 v0.19.2

> v19.1 已经让全剧有了“巡展开馆表”和活化源点争夺。  
> v19.2 解决一个更细但很关键的问题：代哥不能只是抽象秩序，七海也不能只是漂亮法务压力。

机器可读表：

- `docs/superpowers/specs/data/story/daige_ecosystem_layers_v19_2.tsv`
- `docs/superpowers/specs/data/story/qihai_reform_arc_v19_2.tsv`

## 0. 核心判断

之前把代哥清算部强调成“秩序”，是因为故事需要一个有正当性的对立面：

- G.A.G. 事变后，机魂活化确实可能伤人。
- 封存和合规确实救过城市。
- 七海不能只是坏公司打手，她必须让玩家承认“她说的有一部分是真的”。

但如果只写秩序，就会失去现实映射。  
现实里玩家吐槽类似“代哥”的核心并不只是版权法务，而是更复杂的体验：

- 限定、预购、错过窗口。
- 普通玩家被地区、渠道、库存和再版节奏卡住。
- 换色、重涂、装备包、限定编号把喜欢拆成购买资格。
- IP 被长期运营、DLC、季票、活动池和商品计划持续拆分。
- 公司话术常常说“扩大接触点”“最大化 IP 价值”，但玩家感受到的是“我的热爱正在被定价、切块、延迟、抽签和规训”。

所以代哥的新定位不是简单的法务秩序，而是：

> **品牌资产秩序生态。**  
> 它允许你爱机器人文化，但要求你在规定窗口、规定地区、规定版本、规定价格、规定授权和规定解释范围内爱。

这比“清算部来封馆”更准确，也更刺玩家。

## 1. 代哥像腐化联邦军

代哥不能是单一邪恶公司。它应该像机器人动画里的腐化联邦军：

- 它真的维护过秩序。
- 它真的保护过普通人。
- 它有愿意改革的人。
- 它也有庞大的预算、流程、派系、外包商、商城、媒体、法务和战略室。
- 它不是某个坏人一句话能变好的东西。

这会让剧情更有厚度。  
玩家不是打倒一个公司就解决问题，而是在一个和自己热爱共生的生态里，判断哪些东西要拆，哪些东西要救，哪些东西要逼它回到初心。

## 2. 代哥生态分层

### 2.1 安全封存局

这是七海所在的正式秩序线。  
它处理 G.A.G. 异常、机魂失控、事故责任、城市安全和封存许可。

它有正当性：如果没有它，旧世界已经更惨。  
它的问题是：它容易把所有不可控的爱、误读和失败都写成风险。

### 2.2 限定流通局

它负责预购窗口、地区渠道、库存配额、再版节奏和限定编号。  
它不一定违法，也不一定有恶意，但它会制造玩家最熟悉的焦虑：

- 错过就没。
- 有钱也买不到。
- 买到了还要等很久。
- 再版像天降恩赐。
- 黄牛、平台和玩家社群一起被它喂养。

它主要进入模型街和共同记忆篇。

### 2.3 商品化谱系局

它负责把机体、配件、换色、装备包、旧件、错版和隐藏形态拆成商品序列。  
它的逻辑不是“这个角色该不该活”，而是“这个部件能不能形成下一轮商品故事”。

这条线非常适合和万机馆的模型/玩具/真实机体关系对打。

### 2.4 数字运营局

它负责活动、季票、DLC、通行证、池子、联动任务、限时剧情和数值修正。  
它是索引天使最喜欢的部门，因为它天然会把玩家行为切成指标。

它主要进入残缺索引反攻篇和终局路线诱惑。

### 2.5 IP价值战略室

这是最冷的一层。  
它不会说“我们讨厌机器人”，它只会说：

- 最大化 IP 生命周期。
- 扩大接触点。
- 优化用户转化。
- 保持品牌一致性。
- 管理高风险二创和异常活化。

它是终局级压力。它看起来温和、正确、没有情绪，但它会把玩家最爱的一切变成资产曲线。

## 3. 七海的新定位

七海不是“代哥黑点拟人化”。  
她是代哥安全封存局里少数知道生态已经偏离初心、仍然试图在内部修正的人。

她知道玩家为什么恨代哥：

- 她知道限定窗口怎样伤害普通玩家。
- 她知道再版和配额怎样喂出黄牛。
- 她知道商品化谱系局怎样把一台机体拆成多个购买资格。
- 她知道数字运营局怎样把热爱变成活跃、留存和付费。
- 她也知道，如果没有封存和授权，G.A.G. 异常会让更多普通人受害。

她的痛点不是“不懂热爱”。  
她是太懂代哥为什么回不去初心，所以不得不先当那个冰冷执法者。

## 4. 七海为什么更成熟、更迷人

七海的魅力不该靠少女式反差，也不该靠单纯暧昧台词。  
她应该像一个成熟、克制、危险、疲惫但仍有手腕的成年人。

她有几个稳定动作：

- 说话礼貌，但不把话说满。
- 递文件时会把最危险的一页翻到纪存面前，不替他省痛。
- 可以放水，但她会让你知道这不是浪漫，是她押上职业生命的违规。
- 她会承认代哥错了，但不会允许纪存把所有风险丢给“热爱”二字解决。
- 她对纪存有吸引力，是因为她能看见他“策展”背后的控制欲，也敢把这个问题说出来。

成人感来自权力、距离、风险和互相看穿，而不是露骨内容。

## 5. 七海改革线的剧情推进

### 5.1 第一章：冷流程里的一点人为延迟

第一章七海仍然不现场到场。  
她必须是远程压力，否则第一章会被她抢戏。

但她的台词和动作要埋下两个信息：

- 她不是不知道万机馆是什么，她读过旧展册。
- 她不是不知道流程伤人，她只是认为眼前还不能让异常扩散。

她延迟消防锁不是“心软”，而是第一次选择用流程漏洞救人。

### 5.2 模型街：七海第一次面对玩家真正怨气

模型街不是七海主场，但应该让她的改革线进入背景。

她看到限定流通局和平台借清算名义收走初版说明书时，不是站出来大骂同僚，而是用更成熟的方式处理：

- 她给纪存发一份内部流通编号表。
- 表上有库存、地区、再版申请、异常封存和黄牛平台接口。
- 她只说：“这不是我部门的权限。”
- 但文件最后一页没有水印，说明她故意留下了可以公开的证据。

这比直接倒戈更迷人。

### 5.3 清算都市：她提出一个真的能救人的方案

清算都市篇必须保留七海的诱惑力。  
她给纪存的协议不是陷阱，而是一个真实可执行的改革试点：

- 万机馆可以合法保留。
- 一部分活化源点可以转为公共信托。
- 模型街和失败机试验场可以获得保护名录。
- 代价是巡展开馆表必须交给代哥监管，所有未授权活化要接受封存评级。

这份协议如果成功，确实会让很多人安全一点。  
所以纪存差点签字才有戏。

### 5.4 索引夺舰：她被自己想改革的系统利用

七海最大的失败不是“她相信秩序”。  
而是她低估了代哥生态里其他部门会如何利用她的合法系统。

索引不是绕过她，而是通过她的白名单、风险分级和合法协议进入万机馆。  
这让她的痛更具体：

> 她本来想把代哥往初心拉回一点，结果她的工具被更大的生态拿去夺名。

### 5.5 万机馆内战：她不再只代表清算

后期七海提出的不是“合法开馆”这么简单。  
她提出的是“公共信托开馆”：

- 万机馆不能完全私人化。
- 活化源点不能全由玩家阵营决定。
- 代哥也不能独占监管权。
- 观众、机体、创作者、维修者和被伤害过的人都必须有席位。

这让她从清算代理人升级为制度设计者。

### 5.6 终局：她的好进展

在纪存和角色团帮助下，七海最终不必“背叛代哥”，而是取得一些真实进展：

- 安全封存局从代哥品牌资产体系中部分剥离，改成公共审查机构。
- 限定流通局被迫公开再版、库存和地区配额。
- 模型街获得非商品化文化保护名录。
- 失败机记录不能再被直接删成训练样本。
- 万机馆获得“巡展开馆公共信托”身份。

这些不是童话式胜利。  
代哥生态还在，商品还会卖，限定还会有，玩家还会骂。  
但七海不是白忙一场，她和纪存一起撬开了一道缝。

## 6. 对 v19.1 的反向修正

v19.1 里的“清算部”今后要按以下方式重写：

1. **第一章**：仍是安全封存局出手，但封存清单同时带有品牌资产编号，说明它背后不只是安全。
2. **模型街篇**：主要敌方应从“平台与黑市”扩为“限定流通局 + 平台黄牛生态 + 商品化谱系局”。
3. **共同记忆篇**：遗作拍卖不是普通拍卖，而是 IP价值战略室与平台共同推动的“遗产资产化”。
4. **清算都市篇**：七海的协议是真改革方案，不是单纯诱捕。
5. **残缺索引篇**：索引使用数字运营局指标，把玩家爽点变成最优剧情季。
6. **终局**：官方唯一好结局来自 IP价值战略室、索引和安全封存局被挟持后的合流，不是七海本人意志。

## 7. 写作红线

- 不要把七海写成“其实一直是好人所以之前都不算数”。
- 不要让她靠撒娇、心软或恋爱脑改变立场。
- 不要把代哥写成单纯邪恶公司。
- 不要把玩家现实吐槽照搬成段子清单。
- 不要让改革一夜成功。
- 不要让七海替代纪存成为真正主角。

七海最好的写法是：

> 她穿着代哥的制服，说着代哥的话，执行代哥的流程。  
> 但她比任何人都清楚，那套流程已经把很多热爱磨成了资产。  
> 她不是来被纪存拯救的。她是被纪存和万机馆逼到一个位置：终于不能再只做内部修正。

## 8. v20 写作要求

写 v20 逐话骨架时，凡涉及代哥，先判断这一场来自哪一层：

- 安全封存局：事故、安全、封存、白名单、七海。
- 限定流通局：预购、库存、地区、再版、黄牛。
- 商品化谱系局：换色、配件、编号、旧件、装备包。
- 数字运营局：活动、DLC、指标、最优剧情季。
- IP价值战略室：品牌一致性、生命周期、资产化、官方唯一好结局。

凡涉及七海，必须回答：

- 她现在是在执行流程，还是在借流程改流程？
- 她知道这件事伤害玩家吗？
- 她能改到哪一步，哪里会被系统反噬？
- 她对纪存的吸引，是权力试探、互相理解，还是共同背锅？
- 她这一场有没有让代哥生态发生一点点真实变化？
