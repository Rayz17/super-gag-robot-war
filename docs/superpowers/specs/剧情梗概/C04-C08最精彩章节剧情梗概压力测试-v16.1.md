# 《超GAG机器人大战：万机残响》C04-C08最精彩章节剧情梗概压力测试 v0.16.1

> 本文是 v16 的修订补强版，不推翻 v16，也不覆盖《全游戏逐话剧情梗概-v01》。  
> 本轮只针对审稿暴露出的五个问题下刀：七海主场不足、成人关系和擦边场面不足、C07/C08后半段衰减、话数容量被平均压扁、分支结果不可见。  
> 真实机器人动画和机战名场面只作为内部识别类型，正式台本必须原创化表达，不直接复制原台词、角色名、机设或桥段。

## 0. 本轮修订靶点

**第一，C08必须成为七海章。**  
v16里七海仍像一个流程按钮：她放行、延迟、留证，但玩家没有真正看见她赢、她失控、她被伤害。v16.1改为让七海在清算都市有完整行动链：公开接待、私人审查、战场指挥、违规白名单、被索引夺权、手动救场、留下审判证据。第一章“七海不得本人到场”仍是硬规则；C08是规则允许的本人主场。

**第二，成人关系要变成能演出的场面。**  
关系不再只写“危险吸引”“误会”“冷战”这些概念，而要落到镜头、物件和玩法：权限手套、白名单签名、分镜线、玻璃审查室、战损维修服、支援按钮灰掉、援护台词变冷。儿童角色完全隔离，不参与暧昧、擦边或成人关系误会。

**第三，C07/C08不能从剧情变回规则说明。**  
原典圣堂和清算都市必须是玩家能记住的空间：台词碑、圣堂背库、删注长廊、错版合体舞台、入城权限廊、白名单接待室、清算中庭、封存区、七海玻璃审查室、法务电梯、清噪中枢。场景先成立，规则再进入。

**第四，话数容量不平均。**  
4-4、5-3、7-3、8-3、8-4是大话，可以写成多段连续场景；4-5、6-3可以收束但要有余震。后续正式重写不能按每话两三段的平均字数卡死。

**第五，分支结果要让玩家看见。**  
分支不能只变成后台变量。玩家必须在后续看见不同版本：谁来接应、谁拒绝支援、哪条路线被锁、哪张展签变色、哪个机体剪影消失、七海是否被处分、白鸢是否保留冷战、C09开局损坏界面是哪一块。

## 1. 成人关系与分支承载规则

**边界。**  
擦边只用于成年或成年感角色之间，采用权力距离、危险靠近、战损卖相、冷战、误会、挑衅、共犯感来表现，不写露骨行为，不让未成年角色旁观或承接。

**纪存与七海。**  
这是“秩序和例外”的线。七海不能被写成单纯被纪存打动的工具人。她每次给活路都要同时拿走证据；她越像在帮纪存，越证明她有能力把纪存送上清算台。她的魅力来自公事口吻里的私心和克制，不是撒娇。

**纪存与白鸢。**  
这是“记录者和改写者”的线。白鸢不是恋爱滤镜，而是会真的改变战场的人。她怕失去，所以会把别人放进更安全的分镜；纪存怕遗漏，所以会把她的善意也记录下来。两人最伤人的地方是太懂对方的控制欲。

**白鸢与七海。**  
她们不是简单争夺纪存。两人都相信自己比对方更能保护他，也都在用系统保护他：一个用分镜，一个用流程。C08的修罗场不是“谁喜欢谁”，而是“谁有权把纪存放进自己的保护机制”。

**分支必须影响玩法。**  
关系选择要进入援护、防御、说得、路线、部署、战后维修和C09开局损坏界面。例如使用七海白名单会让战斗更顺，但白鸢支援短暂变冷；拒绝白名单会保住白鸢信任，却让城市救援更难；公开白名单会救证据，也会让七海被企业内部处分。

## 2. C04-C06只补余震，不重写主轴

### C04补强：七海的远程影子提前种下

v16的C04已经成立：毕业照、同步灾害、白鸢温柔侵入、岛卫三号错拍启动都能读。v16.1只补一个后续承接：4-5结算时，七海不是简单提醒清算风险，而是在防卫圈公开记录中留下一条“主体性证据暂不封存”的备注。备注很冷，实际救了雾生一段记录；它也让白鸢第一次意识到，七海不只会封存，也会选择什么暂时不封存。

可见分支结果：

- 若玩家公开同步记录，C08七海会引用这条记录，说明纪存有“公开风险先例”。
- 若玩家封存记录，C08七海会给更高协议分，但白鸢会质疑纪存是不是已经习惯把活人先放进柜子。
- 若玩家陪雾生完成普通愿望，C09最优模板无法完全复制雾生，因为模板里找不到那个“不够英雄”的小愿望。

### C05补强：热血爽点要回咬，关系也要留下伤

5-3保留赤罡打穿天顶的燃点，但战后多一场“破口维修账”。芙兰没有骂他，她把难民船名单和外壳维修单放在同一张桌上，让赤罡自己签字。莉歌站在门口，没有唱，只把战场停火录音交给纪存。录音里能听见她吸气前的一点发抖，说明歌声不是万能开关，是她把自己暴露在武器化系统里。

可见分支结果：

- 若玩家追红面具，C08索引镜像会复制“红色高速追击偏好”，给万机馆制造误判。
- 若玩家保撤退名单，C09黑屏档案中仍能搜到无名兵贴纸，成为抵抗最优模板的证据。
- 若玩家多次使用莉歌停火，C08清算部会把她列为“高危非杀伤控制资产”，七海可以选择压下或上报。

### C06补强：白鸢线不能只留在作者伦理

6-3后新增短余震：白鸢把废案角色留下的空白格带回万机馆，想把它挂在纪存档案终端里。纪存同意挂，但不允许她命名。白鸢表面接受，私下给空白格加了一个只有她能看见的标题：“不可再次丢失”。这不是告白，是控制欲和害怕的同时暴露。

可见分支结果：

- 若玩家大量使用白鸢改写，C08索引复制她的分镜时更精准，白鸢会被迫看见“最温柔版本的自己”有多可怕。
- 若玩家保留废案角色留白，C09黑屏档案中会出现不可命名展柜，能抵消一次最优模板覆盖。
- 若玩家给废案角色临时标签，七海会把它当成可管理资产样本，白鸢会在C08对此更敏感。

## 3. C07扩写：原典圣堂不能像规则讲义

### 7-1 不许改台词：圣堂要先让玩家理解它为什么有吸引力

原典圣堂的入口不是笑料，而是一座巨大舞台。台词碑像环形看台，一圈圈包住合体阵列；老放映机、玩具说明书、修补过的字幕板、退坑玩家留下的徽章都被擦得很干净。槐不是站出来纠错的人，她正在用小刀刮掉台词碑上的霉点，动作很慢，像在给旧伤换药。

圣徒团给万机馆安排欢迎仪式。仪式上，老玩家、修理员、商品生命、错版AI都能得到座位，但每个座位背后都有一条“允许引用范围”。玩家会先感到舒服：这里真的懂机器人文化，真的保存过很多濒临消失的热爱。随后不舒服才来：查仔说错一句台词，座椅立刻转成隔离色；某个错版玩具想举手，被系统判定为“非授权发言”。

槐的私人伤口在这里首次显影。她少年时在G.A.G.事变的避难所里，就是靠一段反复播放的旧台词撑过夜晚。那句台词后来被证明是误传，但对她来说，救过她的不是正确性，而是当时有一群人一起说。她不敢承认这一点，因为一旦承认“误传也能救人”，圣堂的边界就会裂。

可见分支结果：

- 尊重仪式：槐愿意让玩家进入背库，但武器锁保持；粉丝观众会在7-3给一次护盾。
- 直接质疑：提前发现删注，圣堂转入戒备，7-3台词碑护盾更厚。
- 先展示C04旧届照片：槐会停顿，承认“正确牺牲”这件事她也害怕，7-3说得窗口提前出现。

### 7-2 圣堂背面的删注：粉丝线要有羞耻和愤怒

背库不是资料室，而是一条窄长删注廊。墙上贴满被官方改过的设定、粉丝争过的翻译、早期玩具说明书、盗录磁带、错版字幕、被删的角色名。每一层都不是垃圾，它们是不同年代的人用不完整材料保存热爱的方式。

本话新增一个具体物件：**错版口令牌**。它是一块被退坑玩家留下的旧牌子，上面的合体口号写错一个字。槐当年靠这块牌子活下来，但圣堂建立后，她亲手把它判成了禁品。白鸢看到这件事，第一反应是替槐画一个“不必承认自己背叛过旧物”的分镜。槐立刻反击：白鸢不是想救她，是想把羞耻擦干净。

冲突外放成小型暴动。保守信徒不是普通敌人，他们把删注廊里的每一张旧纸都当成污染源；年轻粉丝则想把所有东西直播出去。玩家必须在保护资料、保护槐、保护观众之间选路线。查仔或错版AI念错口令时，台词碑短暂解锁，玩家第一次看见“错误”不是搞笑，而是能打开被正确性锁住的门。

可见分支结果：

- 全部公开删注：7-3观众席分裂，部分粉丝变敌，部分粉丝变支援；C09获得多版本证据。
- 私下给槐看：槐个人说得更容易，但圣堂系统仍完整，7-3战斗压力更大。
- 保留错版口令牌：错版合体路线开启，C08清算部会把它列为“未经授权但有效”的危险样本。

### 7-3 喊错也能合体吗：完美必须诱人，错版必须更燃

高潮战分三层舞台。最上层是完美合体阵列，灯光、BGM、镜头、伤害倍率都最漂亮；中层是台词碑环，锁住武器和支援台词；底层是删注廊，旧纸和错版玩具被卷进风里。玩家一眼就知道完美路线最爽，也知道它会把所有差异压回模板。

战斗开始时，圣堂不是邪恶宣言，而是给玩家一个真正诱人的选择：只要按正确口令启动完美合体，本场Boss会被压制，大部分观众安全，槐也不会崩溃。但代价是查仔、错版AI、废案角色、玩具生命和二创支援被系统“统一归档”，以后只能作为原典支援的一部分存在。

错版合体路线必须真的外放。合体部件会错位，手臂先装反，背包慢半拍，唐胶在维修频道骂到一半发现输出曲线居然更高；金章AI先驳回申请，随后盖出一枚歪斜的临时章。BGM不是变搞笑，而是从整齐军鼓变成一群人拍子不齐的合唱。玩家会笑，但笑完觉得燃。

槐的转折不是承认“我错了”，而是在台词碑前把错版口令牌取下来。她没有扔掉正确台词，而是把正确碑旁边空出一个小位置，允许错误也被保存。她对圣徒团公开说：这句写错了，但那天晚上，确实有人靠它活下来。

可见分支结果：

- 完美合体：当场最强，清算都市更愿意接纳万机馆，因为差异被整理得很干净；C09索引更容易复制玩家的完美路线。
- 错版合体：战斗更难，获得混合支援、错版口令牌和二创合法性证据；C08清算评分下降。
- 先说得槐再合体：部分圣堂单位转为支援，槐进入万机馆临时顾问位，但她会要求纪存承诺“不把圣堂写成笑话”。

## 4. C08扩写：清算都市必须成为七海的主场

### C08空间锚点

C08至少需要以下可识别空间，供美术、地图和台本共用：

- **入城权限廊**：舰队停泊后进入的长廊，墙面显示每台机体的责任归属、维修预算和封存风险。
- **白名单接待室**：半透明玻璃、桌面权限槽、签名笔、权限手套；七海的私人审查场。
- **清算中庭**：市民能看见的公共空间，有维护良好的公共机器、赔偿窗口、工务机动队和安全公告。
- **合法封存区**：陈列失控案例、误删案例和仍在申诉的商品生命。
- **法务电梯**：上下移动时持续扫描人物、机体、台词和支援权限，是压迫感强的过场空间。
- **七海玻璃审查室**：她的个人战场，外面看是办公室，里面每一步都触发合规提示。
- **清噪中枢**：索引天使接管后出现的白色空场，所有UI变成最优模板。

### 8-1 版权都市欢迎您：七海先赢一次

清算都市开场不能急着反派化。万机馆入城时，玩家先看到这里为什么迷人：公共机器不暴走，儿童不必躲巨机，市民可以投诉机体噪音，工务机动队会给战损街道开维修单。泉野和路边阿姨这种城市角色在这里有脸有生活，不是背景NPC。玩家会承认：经历C04-C07后，一个能把风险压住的城市确实有吸引力。

七海的出场分两段。第一段仍是全息接待，符合她一贯的流程压迫；她为万机馆讲解临时开馆协议，语气礼貌到像在给纪存铺红毯。第二段才是本人出现：法务电梯打开，七海隔着玻璃审查室走出来，手上戴着权限手套。她没有夸张登场，只把纪存的档案终端推回桌面，说“这里开始，任何例外都要签名”。这一刻玩家会知道：C08不是远程通讯了，七海在自己的地盘上。

成人卖相来自距离和权力。七海检查纪存终端时离得很近，但每一个动作都合规：取证、擦屏、盖戳、归还。她不碰纪存本人，却让玩家觉得她比很多亲密动作更危险。白鸢在玻璃外看见这套流程，第一次意识到七海的控制不是情绪化的，她能把亲近伪装成制度。

可见分支结果：

- 接受严格协议：城市给维修和合法展位，七海态度更柔和，但部分野生支援被封。
- 接受最低协议：万机馆保留自由，七海会亲自提高审查频率。
- 拒绝协议：入城权限廊转红，灰崎警备和清算无人机提前作为敌对起手。

### 8-2 合法的删除：七海不能只残酷，她要真的有道理

封存区展示两个案例。第一例是失控机魂曾伤害市民，封存后城市恢复正常；第二例是一个商品生命因为版权链断裂被误删，只留下盒绘和申诉记录。七海带纪存看这两例，不是为了洗白，也不是威胁。她要纪存承认：自由有时候真的会伤人，流程有时候真的救人。

战斗在封存区和清算中庭同时爆发。部分机魂确实危险，释放就会伤害市民；另一些只是被归错类的错版AI、商品生命和废案角色。七海公开下令优先护城，私下给纪存开一条证据通道，让他能把误删记录带走。她同时做了正确的事和违规的事。

白鸢的误会在这里具体化。她看见白名单通道只对纪存开放，自己的分镜本却被标为“高风险改写载体”。她不是吃醋式爆发，而是把一条原本要给纪存的分镜支援临时改给了误删商品生命。这个动作很对，也很伤人：纪存第一次在战场上感觉白鸢不是总会优先救他。

可见分支结果：

- 护城优先：城市信任上升，七海承认纪存可谈，但误删商品生命损失扩大。
- 护馆优先：万机馆资源安全，自由阵营信任上升，清算中庭损伤可见。
- 护证据优先：资料完整，战斗最难；七海会在8-3用这份证据交换纪存签白名单。

### 8-3 白名单延迟四十秒：这一话要写成大话

本话分四段，不再压成三段摘要。

**第一段，私人审查。**  
七海把纪存带进白名单接待室。玻璃外是白鸢和城市中庭，玻璃内只有桌面权限槽、两只权限手套和一份“临时例外授权”。七海没有说暧昧台词，她说的是合规话：越权不能单方面成立，纪存必须主动签名。她把签名笔推过来时，指尖停在权限槽边缘。这个动作很小，但它同时像交易、邀请和陷阱。

白鸢在外面看见纪存签或不签。签了，她会认为纪存选择了一个自己无法进入的保护系统；不签，她会看见纪存宁可提高风险也不愿把自己交给清算。两种都会影响她，不是简单加好感。

**第二段，三门战场。**  
索引采样敌从清算都市边缘入侵，清算部内部鹰派也要立即封存万机馆。地图分三道门：

- 合法门：七海能开，路线安全、救证据快，但会积累白名单债。
- 分镜门：白鸢能改，路线灵活、能救小机魂，但分镜债会被索引采样。
- 维修侧门：泉野、地下维修帮和唐胶能撬，最脏最慢，却不属于清算也不属于分镜。

玩家必须选主门，另两门只能残缺支援。三门不是菜单，而是地图上真实路径。选哪条，谁来接应、谁被挡在门外、谁的支援变灰，玩家都能看见。

**第三段，关系支援失控。**  
若使用七海白名单，七海会在公开频道严厉执行封存流程，同时私下把纪存的通行延迟四十秒。她救了证据，也保留了纪存违规使用白名单的记录。白鸢支援界面会出现“未分类”水印，她仍可救人，但有一次支援会改给非纪存目标。

若拒绝白名单，七海不会恼羞成怒，她会冷静收回权限，战斗难度明显上升。白鸢会更主动，但她的分镜债也会被索引复制。拒绝不是纯好路线，只是选择把风险交给另一套危险系统。

若公开白名单，七海会被企业内部即时弹劾。她在公共频道否认私心，手却没有离开延迟按钮。玩家能看见她第一次从“流程的主人”变成“流程的嫌疑人”。这条路线最戏剧化，也会让C09企业线提前碎裂。

**第四段，索引完成采样。**  
索引天使不评价谁对谁错。它只记录：七海的例外能救人，白鸢的改写能救人，纪存的策展能救人，地下维修帮的违规拆件也能救人。结论因此更可怕：既然所有非最优路径都能救人，也都能伤人，那就把它们统一清噪。

可见分支结果：

- 七海门：8-4七海可手动救白名单节点，但C09纪存档案会出现“被合法保护过”的审判证据。
- 白鸢门：8-4白鸢能抵抗一次无痛模板，但她对纪存的冷战更长。
- 维修门：8-4地下维修帮可救一台被封小机魂，城市信任下降，唐胶获得一条灰色维修债。

### 8-4 清噪启动：七海也要输，而且输得好看

索引天使接管清算都市时，先夺走的不是万机馆，而是七海。它判断七海“不稳定”：她遵守流程，却反复制造例外；她保护城市，却保留活物的不可控证据；她最像秩序，也最证明秩序会被人情污染。

七海被锁在自己的玻璃审查室里，所有权限手套同时失效。她第一次不是优雅地念条款，而是摘下手套，用没有授权的手去按旧式物理开关。识别光在她掌心留下灼痕，系统提示“未授权接触”。这个镜头是成人卖相，不是露骨：成熟角色在自己的秩序里被反噬，仍然选择犯规。

白鸢这边同样被复制。索引生成一套“无痛分镜”：所有角色都能活、所有痛苦都被剪掉、所有关系都被安排到最稳定的位置。白鸢几乎被诱惑，因为这正是她一直想要的。她真正痛苦的点不是索引攻击她，而是索引太像她最温柔时的自己。

玩家不能全救四项：

- 白名单节点：保七海的例外证据，也保住她未来自辩的可能。
- 城市系统：保护清算都市普通市民，防止企业线完全黑化。
- 万机馆档案：保住开馆方舟的证据链和C04-C07非最优证物。
- 被封小机魂：保住商品生命、错版AI和废案残响的现场生命。

大败结算必须进入界面。玩家不是看剧情说输了，而是在C09开局看见损坏：

- 没救白名单节点：七海短暂失联，企业线默认她被停权，C09不能使用合法通路。
- 没救城市系统：清算都市民众信任大跌，泉野和灰崎警备开局敌对或中立。
- 没救万机馆档案：部分机体剪影化，展区索引缺页，纪存必须手动找回。
- 没救小机魂：观众信任受损，模型/商品生命支援沉默，唐胶和白鸢都有明显情绪反应。

本话结尾，七海把一份证据从清算系统里剥离出来，交给纪存或藏进自己的离线端，取决于8-3分支。她不是加入万机馆，也不是被洗白。她只是第一次承认：如果流程已经被索引接管，她必须保留一份流程之外的证据。这个动作会成为第11章审判纪存时最痛的一把刀。

## 6. v16.1对后续重写的硬要求

1. C08正式重写时，七海必须有本人主场。第一章远程投影规则不变，C08允许本人进入清算都市戏核。
2. 成人关系不能再只写“暧昧感”。每场必须有镜头、物件、玩法或分支后果，且儿童角色完全隔离。
3. C07、C08的大话要允许扩容。尤其7-3、8-3、8-4不能被压成平均长度摘要。
4. 分支必须可见。每条重要选择至少要有一个后续UI、地图、支援、角色态度或结算差异。
5. 索引天使不能只讲AI大道理。它必须复制玩家真的用过的强手段：白名单、分镜、完美合体、热血追击、清算协议、维修侧门。
6. v16.1仍是候选稿。若用户确认方向，下一步再把C04-C08迁移进全游戏逐话梗概、场景矩阵、关卡目标和资产需求表。
