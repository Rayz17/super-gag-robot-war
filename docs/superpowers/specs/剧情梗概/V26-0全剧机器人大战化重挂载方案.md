# V26-0 全剧机器人大战化重挂载方案

状态：候选重构方案，等待审稿后进入逐章厚写。  
产物类别：全剧重挂载蓝图，不是厚版章节梗概，也不是台本。  
核心目标：修复 V25 连读时“不像机器人大战、早期原创线过重、IP投射不明显、宇宙尺度消失”的问题。  
继承母稿：V21 开馆权战争、V22 根设定、V22.10 星火厚稿、V23 15篇60话结构、V25 全章厚稿、V25.1 审稿诊断、参战投射 Bible、50项问题 v15 爆破升级。

## 0. 结论先行

V25 的主要失败不是没机体、没设定或没字段，而是**前台承重错位**。它把万机馆原创线、证词、展签、生产链、听证写成主菜，把参战包、IP投射和机战封面戏降成了样件、残响、支援提示和证物。玩家连续读前三章时，看到的是“博物馆保护、模型街生态、灰模生产链”，不是“机器人大战已经开打”。

V26 的修正不是给 V25 每话再塞两台机体，而是重建主承重：

1. 每章先由 2-4 个参战包承重，再让万机馆原创线做胶水。
2. 每章必须有至少一个能做 PV 的机器人封面事件。
3. 每话的机体不能只是名字，要改变战斗、地图、关系、敌方收益或后续解锁。
4. G.A.G. 和宇宙尺度从第一章就以“旧灾变、异常响应、远星误读残片、索引整理冲动”逐步显影。
5. EX/隐藏关只做加料，不能补主线参战短板。

## 1. V26 和 V25 的关系

V26 不推翻 V25 的所有成果。V25 很多章节已经有厚度和可用场面，尤其是星火双篇、撤退战、白名单都市、索引反攻、开馆内战和终章方向。V26 只做承重迁移：

| V25内容 | V26处理 |
| --- | --- |
| C01闭馆夺名、馆守Z、展舰起航 | 保留，但增大 R07/R18/R24 的前台可见度，并扩成4话标准章。 |
| C02模型街、胶价王、旧货柜锚件 | 保留，但让 R18火种变形者、R22钢拳擂台、R07社勇王真正成为章节主承重。 |
| C03原型工房与灰模 | 后移为 C04，不再占据前三章主菜；白鸢正式登场仍可保留，但要承接现实机器和工务线证据。 |
| C04失败机试验场 | 前移为 C03，并扩成现实机器、工务机动队、废城小查、三法城的参战章。 |
| C05-C06星火双篇 | 保留为当前高标准主线，但继续要求机体层级清晰。 |
| C07-C15 | 基本保留顺序和主功能，但每章重新检查参战包、IP锚点和宇宙主轴是否摆到前台。 |

## 2. 新硬规则

### 2.1 参战包优先

每章必须先回答：

- 本章封面机体是谁？
- 主参战包是哪几个？
- 玩家本章能操作、援护、说得、护送、合体、暴走、锁泊或临时使用哪些机体？
- 敌方抢走、复制、误读或封存了哪个机体/玩法/名场面？
- 玩家不打 EX，是否仍觉得这一章像机器人大战？

若答案不清楚，不得进入厚版正文。

### 2.2 开馆是结果层，不是动作替代层

V26 保留“会开馆的方舟”，但削弱“展签/证词”作为剧情动作的频率。战斗高潮应优先用机战语法完成：

- 合体、变形、撤退、护送、母舰展开、后继接口、量产逆袭、说得、援护防御、暴走、敌王牌退场、巨大化、地图兵器、战损维修。

证词、展签和开馆记录用于战后结算、成长、路线债和终局声部，不再替代前台事件。

### 2.3 早期三章必须先给玩家吃到机器人

前三章的目标是让玩家立刻确认：

- 巨型超级机器人在场。
- 勇者/变形生命/现实机器人/城市劳工机甲都在主线前台。
- 玩具、模型和真实机体有因果关系，但不是替代真实机体。
- 世界不是单馆小事故，而是 G.A.G.灾变后的全球/宇宙级后遗症。

### 2.4 G.A.G.从早期就是宇宙问题

第一章不用解释 G.A.G.真相，但要明确它不是局部闹鬼：

- 代哥封存流程的浅层理由来自旧G.A.G.事变。
- 留言、玩具、现实机器、展品和通信噪声都会产生微弱响应。
- 索引最早表现为“把复杂东西整理成更合理标签”的冲动。
- 远星最早只以不稳定误译、迟到旧包、方舟T异常注释显影。

## 4. 前三章修复重点

### C01：从“博物馆保护”改成“机器人大战宣言”

要保留万机馆厚度，但第一章必须给玩家巨型机战冲击：

- 馆守Z每一步改变展厅地形。
- 社勇王盒和豪司不是彩蛋，而是支援系统的第一颗钉子。
- 火种旧货柜不是日后伏笔，而是显示“商品生命”正在响应。
- 跌跌现实机器小舞台要留下失败记录变量，连接C03。
- B1泊位露出未来机体剪影，让参战规模承诺出现在第一章末。

### C02：模型街不是逛街，是参战链路

模型街必须同时服务三件事：

- R18 火种变形者：旧盒绘、同模、重涂、昵称和维修痕迹触发商品生命。
- R22 钢拳擂台：旧拳王手套把拍卖台改成不伤人的擂台规则。
- R07 勇气株式会社：社勇王缺页说明书决定豪司支援是否能转为更稳定的勇者许可。

### C03：现实机器先上桌

第三章前移现实机器/工务/AI，是为了避免前三章全是原创馆线和模型生产链。玩家在第三章要看到：

- 城市级工务机甲。
- 小型现实机器和工程失败记录。
- 一个刚出生的AI如何学坏台词又学会道歉。
- 三法则如何在战场上保护人，也被敌人利用。

这样后续C04原型工房才不会显得“又是一章原创理论”，而是接上“机器人到底怎样从失败、规则和工艺中获得参战资格”。

## 5. 自动逐章厚写工作流修正

V26后续不直接写60话正文，按以下循环自动执行：

1. 读取本章重挂载表和上一章状态账本。
2. 写本章压力板：主参战包、封面机体、敌方学习链、G.A.G.阶段、关系压力。
3. 写4张话卡，每张必须明确机体动作、IP锚点、玩法、敌方收益。
