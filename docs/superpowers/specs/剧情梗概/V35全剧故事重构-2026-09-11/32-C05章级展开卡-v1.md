## 一、这章为何值得写

**他们应邀来庆祝一台巨人终于造完，后来却必须帮助它和驾驶员一起离开造就自己的地方。**

韩秀雅不是从第一场起就准备反抗沈砺。她盼望试航成功，也真心想把共同防卫做成；纪存同样想参与，不是被拖去受害。第一轮成功必须好看、好玩，值得拍照留念。正因为这份成果是真的，后来“保留这个项目”与“保住眼前的人”才会变成她无法请别人替自己解决的问题。

两条人物线相交而不互相代替：韩秀雅得到完整机体后决定带新搭档走；米拉与艾达则救回彼此，却失去了可能恢复共同过去的唯一完整档案。前一段是赢得未来，后一段是选择现在却仍会悲伤。纪存、七海、白鸢都在其中作出自己的行动，不负责轮流解释本章主题。

读完希望记住四件事：百相第一次舒展两只手的畅快；艾达还在眼前，米拉却舍不得开枪；一个记得今天的声音不肯被清除；韩秀雅用曾经共同庆祝的新臂打开封锁。对白和日常应使这些人值得在乎，而不是给四个场面各配一段宣言。

## 三、人物在争取什么

| 人物 | 真正想得到的事 | 本章主动动作与措辞方向 |
| --- | --- | --- |
| 韩秀雅 | 完成百相，继续做能上前线的驾驶员，值得信任地带好自己的队伍 | 先提试航顾虑、确认条件，实战中不用纪存的一次建议也赢得漂亮；后来亲自拒绝清除新主体。平时能开玩笑、嫌照片难看、主动夸人，面对沈砺才显出熟悉关系中的难开口 |
| 沈砺 | 让并非天生合拍的混编队也能活着回来，使防卫项目可训练、可重复使用 | 带来真实损失记录和设备，允许成功公开；随后为继续测试的判断负责，仍要求恢复验证版本、追回原型。不是只会说规定的坏上司，也不能用苦衷替她取消责任 |
| 纪存 | 想知道自己的天赋有多大，也想做一件大家郑重需要他的事 | 自愿试航、敢给有限提醒，看到韩秀雅更好的办法会兴奋；被隐瞒后有怨气，加测被劝停不等于心里立即服气。平常反应直接，不把每件事总结成哲理 |
| 七海 | 把改革承诺做实，又不让自己的签名继续伤人 | 真心为复飞高兴；查外运，去找本地生产和运输的实际负责人，分开停止的货运与继续的民用线。她不能只当监督席，也不是纪存的监护人 |
| 白鸢 | 希望纪存平安，也希望自己有能力帮助他 | 会为这群人的成功高兴，但把较重预演留住；争执后自己拿出来。措辞可以急、恼、嘴硬和承认，不再用“你可以……但别替我……”给每段关系配同一种句型 |
| 米拉 | 想与爱人继续生活，也盼熟悉的艾达回来 | 会逗人、会认真教机体；体贴里夹着不自觉的核对。临战必须真正听见现在的艾达，自己决定开火；救命不会使她一夜放下对过去的渴望 |
| 艾达 | 想知道自己的过去，但不愿被检查着过每一天 | 主动亲近米拉、接受测试、要求退出、暴露档案设备并请求射击；不是等人救出的失忆奖品。难过不证明此前选择错误 |
| 陆衡、唐胶、兜灯 | 让朋友的机器可用、让人平安回来；也各有喜欢的本事和玩笑 | 陆衡核对真实范围，不靠长解释代替行动；唐胶与兜灯作为懂行者欣赏新臂，照料馆守Z。不给每人硬派一次微小救场；个人主场在后续制造与修复中继续 |
| 七号、无牌一号与拳王 | 返访、学新东西、和人玩在一起 | 七号看韩秀雅兑现承诺，无牌一号向飞行搭档学危险姿态，拳王趁示范试假动作。这些可以单纯有趣，不必都回收成制胜机关 |

韩秀雅、七海、沈砺之间按已写恩义、事业和信任展开，不在本卡暗加三角恋。米拉与艾达是有真实亲密的恋人，不把几次笑容只当悲剧计时器。

## 四、五话怎么发展

以下是场面重心，不是强制台词表、每台机的动作顺序或单次模型调用清单。主笔可以在同一因果内调整场面长度和视点。先完整写E01，再根据实际读感校准其余篇幅。

### E01：回来参加试航

**本话中心：韩秀雅终于等到这一天，纪存也想加入。**

从百相举起两只手开始，不从设备说明或紧急事故开始。返访让七号、工房与韩秀雅的承诺有一个快乐的回声。沈砺比仪式早到，和韩秀雅谈起狼狈的复飞经历；七海第一次听见自己离开以后是谁陪她走过那些日子。她不必立即吃醋、认错或服软，但此后无法把这两人的关系理解成单纯利用。

沈砺拿出混编队返航的损失记录，说明为何邀请纪存。正文只需看懂“每个人都在处理危险，却没有人及时援护受损同伴”，不重演全场技术复盘。纪存想试；七海和陆衡提出实际问题，韩秀雅自己确认哪些风险接受、何时退出。

后半认识米拉、艾达和双机。两人飞得默契，落地后却会在饮料、旧住处这样的小事上接不上。随后米拉在馆里与无牌一号、拳王相处，艾达真的笑出来。以大家期待次日出击结束，不提前让读者等待一场注定失败的测试。

**写作容量：**返访与两只手、韩/沈/七海、试航邀请、双机亲密和馆内小场四个重心。不要额外插入黑城说明会和违规文件全文。读者只要认识这次共同工作值得做，也看见两段关系各有没说透的事。

### E02：完整的百相

**本话中心：他们合作做成了事情，成功也使纪存更想继续。**

韩秀雅先单独展示此前做不完整的本领，再加入双机。纪存提供自己确实感到的机会；一次他建议避开的火力，被韩秀雅用装甲和驾驶经验顶住，双机取得更好的位置。他的反应是叫好，不是被架空后的委屈。

边防试航遇到需要真实拦截的敌体，机队完成任务。只选几次一眼明白的变局：完整机体怎样打开局面、韩秀雅怎样承担、双机怎样各有用处。不给既有机群排一长串精密接力。敌人不是断冠，也不新造一个本章结束即消失的具名宿敌。

战后有完整的快乐：汗、照片、走下巨机的兴奋、第一次公开战果。白鸢发现纪存仍在逞强；谈起下一轮时，没交出的预演被察觉。纪存不满她替自己筛掉信息，白鸢不满他只看着成功。七海劝停当天加测，大家仍庆祝，只是合照少了一次主动邀请。

**话末改变：**试航成功没有撤销，公开成果存在；三人不再像上午那样无话不说。不要用突袭广播切掉这份尴尬，也不要把白鸢写成早已预见黑城灾难。

### E03：艾达要找的过去

**本话中心：想保住一件好事，不能靠回避另一件正在发生的伤害。**

外运核对找到七海签名被冒用的实际文件。沈砺承认程序加速有问题，但认为整体封停会伤到防线；韩秀雅问的也是仍在等身体的人。让她和七海有一次具体、带旧情绪的争执，接着真去工作：核对设备属于谁、这车货为何外运、本地哪段生产不能随便停。正文写人作决定，不写审计手册。

与此同时，艾达得到黑城测试与开放早年档案的承诺。米拉想替她拒绝，艾达却想自己知道那个人是谁。这条线不是在程序会议后突然换主角：前两话已经让玩家见过她被亲近的人不断询问过去，她这次有自己的理由。

黑城亮相、准备进入试验。提前看明白三点就够：这是套住矢量二号的外接巨壳；艾达仍在二号机驾驶舱；唯一完整可读档案位于巨壳侧胸，会用于比对试验反应。让读者知道她想拿回什么，不能到瞄准的一刻才宣布那块设备是她全部过去。

**话末位置：**艾达自己确认参与，测试即将开始。七海的违规外运调查与黑城试验是交错发生的两项行动，不伪造“查签名导致黑城失控”的单线阴谋。民用生产先得到继续的实际安排，外运结案回执可到E05。

### E04：现在的艾达

**本话中心：米拉终于作出了能救她、却不能替她把一切拿回来的选择。**

第一炮准确。随后同一段记忆被反复调用，艾达要求退出；沈砺听信技术组对余量的判断，允许完成本轮，失控却先发生。各人的知识和责任按这一顺序成立，不补一个恰好失联的指挥官来替她免责。

远程中止与正常脱离均失败。艾达用应急分离退出一截，又被巨壳拉回；这次看得见的失败说明后来为何需要打档案设备。米拉呼唤过去称呼，艾达却要求她看清胸前正在挣脱的二号机。不是越喊真名越能解除精神控制。

百相压住威胁，一号机得到靠近的机会。艾达用仍能活动的手臂打开侧胸护板；米拉看见射界和代价，犹豫，然后开火。毁档只切断重复校正与召回，不关闭全部武装。艾达再次使用同一种应急分离成功，一号机护她离开，百相与地面机群摧毁剩余炮组。

抱住对方以后，两人可以哭、说不出安慰的话。别用马上接一句金句替她们消化损失，也不在本话宣布她们爱情已经治愈。百相一直在经历这些事，新主体的公开确认放在下一话，不挤走这个结尾。

**不可逆结果：**唯一完整可读档案毁灭，艾达和二号机脱出，剩余炮组被毁；她仍保有现在的记忆和不完整的过往，不写成失去全部人格或语言。

### E05：带它一起走

**本话中心：韩秀雅不能再等待恩人批准自己的未来。**

先处理战后回收与恢复验证版本的要求。百相询问会不会失去今天，韩秀雅与它交谈，发现它记得自己的共同经历，却不知道纪存的童年。纪存在馆内清醒地见证。无需检测仪宣布“机魂已诞生”，更不能在另一个机体里突然留下一份纪存。

沈砺要求保留可验证的防卫项目，韩秀雅明确要带新搭档走。她们早年相助没有作废，正因如此关掉熟悉频道才有分量。封锁确实形成，部队不全是纸靶，也不是全部突然被感动放行。百相的新臂打开去路，与双机、已有机群保护运输舰离开。

外线驻地接纳韩秀雅及同行试飞人员，先保住主体再争机体归属。艾达与二号机留在那里，米拉和一号机登舰；不将这次分开直接写成后来的正式分手。七海让违规外运停止、民用线继续；沈砺仍有合法公开战果和待改进的项目，没有被全世界判成无所作为。

返舰后白鸢把预演给纪存看，纪存承认那天下午确实还想试。关系不是一方作检讨、另一方大度赦免；下次让对方看、当面争执，是可实际继续做的改变。随后一起查馆长资料，仍未获得身世答案。按早已约定的联展邀请去乐园，给下一章留下值得期待的事。

**容量警戒：**这一话有主体确认、恩义决裂、突破封锁和多组离别，是全章最可能过载的位置。先压掉重复表态、技术说明和全员告别，不能压掉韩秀雅的决定或艾达的损失。若实际成文仍拥挤，可在抵达外线驻地处分话，将共同善后与启程独立成短E06；这是待读感验证的容量备选，不预先增加新剧情或重写全剧。当前推荐仍为五话。

## 五、早期玩法共同构思，详细解构另写

采用当前总案的短回合、整队意图、有限主力方向；具体规则以正式玩法文件和后续验证为准。以下只说明玩家为什么想动手、怎样影响真实结果，不能据此声称已有原型或乐趣已获验证。

| 故事段 | 玩家可经历的玩法 | 本次独有的乐趣 / 有效结果 | 必须守住的角色权限 |
| --- | --- | --- | --- |
| 返访、试航准备 | 看新臂试动作、短协同试用、机库自由活动 | 熟悉完整百相与飞行双机；七号选过的工具在生活里真正可用。可跳过已熟练操作，不靠百科考试才准起飞 | 韩秀雅决定试航条件；玩家不在后台替她签同意书 |
| 正式试航与真实拦截 | 少量单位的协同战，提供已知威胁和可验证的机会；先试过的能力直接用于真实目标 | 百相能正面承担，双机能快速转换进攻位置；至少容纳强攻/掩护机动等不同可行安排。成果是完成拦截，不是背主笔唯一接力顺序 | 纪存的有限导航不等于指挥别人身体；韩秀雅不采纳一次提醒是清楚的角色事件，不能把玩家刚下达且合法的指令暗改成另一个结果 |
| 外运调查与工房巡访 | 看货单和实物、问当事人、比较哪批属于违规外运，哪段属于民用生产 | 根据证据解决具体问题，保住运作中的民用线；不刷完所有名词。小差分可落在保全与后续整备，正式设计时再确认 | 违规事实和七海的调查方向不是玩家道德测验；不用小游戏成绩决定等待者是否算生命 |
| 黑城危机 | 第一段看懂召回并保护撤离；第二段借百相压制、让一号机靠近，在驾驶舱外清楚地指认并射击档案设备；二号机脱出后处理残余火力 | 威胁、接近、准确打击与护送退出是不同任务；身体与目标具有直观空间，不靠数个抽象锁槽解题。保存已保护的人和实际损伤 | 艾达请求、米拉决定毁档为固定人物选择；操作从选择作出后执行。不许安排一个“完整备份全救成功”隐藏解，也不让玩家能否认毁档而被过场强制失败 |
| 突破出航封锁 | 新目标是保护运输舰并脱离，部队有不同执行态度；已有机群按实际在场参与 | 不再复制一遍黑城Boss战；路线、护航分工与追加损伤可有差别。韩秀雅的新臂是可靠所得，不再临时损坏右臂制造代价 | 拒绝回滚由韩秀雅作出；不把此处变成是否出售新主体的分支 |
| 分开与启程 | 驻地/舰内交谈、整备与联展准备 | 留下实际联系方式、旅途伙伴与未来协力；玩家可多了解人，不须把所有离别对话清空才准出发 | 艾达留地方、米拉随舰、韩秀雅与百相外线驻地的出口固定；没有强制好感复合 |

### 话界不重置战场

首轮试航、黑城事故、出航封锁是三件不同的现实冲突。前两件可以各有自己的完成条件；最后一件紧接回收争议发生，继承此前损伤与疲惫，不能默认全修复满补给。黑城之战中，毁档和二号机脱出只是目标变化，剩余炮组未停止前不能提前结算。E04与E05之间只有实际发生过的回收、检查可改变状态，不因标题变了重置机体。

户外试验场、基地与航路按可滚动空间考虑，建筑和掩体属于地图。黑城40米、百相55米与十几米级机体保持实际比例；大不等于每项火力都更强，也不需要为追平百相把黑城升成百米级。人类始终在驾驶舱、地面安全区或舰内，故事中的贴近谈话不意味着人与巨机在同一高度。

本章不为每话强配一场SRPG。E01可以以机库、关系和准备为主，E03以调查与选择为主；正式试航的大胜、黑城危机的救人与出航封锁的决裂，才是不同的主操作体验。游戏解构会在纯剧情成立后分别证明这些题是否真的好玩。

## 六、IP借什么，哪些必须由本作交代

主参照为《Z高达》TV香港篇：强悍巨机、失忆者被机构握住过去、亲密呼唤与战场行动不相等、当事人主动为眼前的人行动。[官方播出梗概第17、19、20话](https://www.bs11.jp/anime/z/)可作为当前核对入口。

不照抄卡缪与凤的整段生涯，也不依赖玩家识别脸才明白。米拉与艾达原有恋爱、档案位于外壳侧胸、毁档停止召回、两人不同去向都是本作必须讲清的改写，不是假称原作如此。前两话要让没看过《Z高达》的人也喜欢她们；熟悉原作的人则能从香港篇的气氛与困境认出参照，再发现这次被改变的答案。不能凭一声“强化人”跳过人物。

韩秀雅/百相和纪存三人的发展主要是原创，更不能用机战玩家先验省掉恩义、欲望与变化。无牌一号等是已有伙伴的小场，不替本章再开完整IP人物篇。合体、变形和黄金锤可以在既有能力允许时使用，但不为展示目录给每台机安排一次必杀。

## 八、向后交什么，不在本章提前兑现什么

章末固定带走的事实：完整百相与新主体存续；韩秀雅获得自由但需要自己找供给；米拉/一号机随舰、艾达/二号机留驻地并保持联系；记忆档案不恢复；民用线继续、违规外运停止；纪存更想调查自己，白鸢恢复直接交流但不会从此不再隐瞒或争执。
