# 最高层故事框架：哪些应保留，哪些正在限制故事

2026-09-13｜Candidate / framework_review｜主笔据当前文件作出的判断，不是正式迁移或独立四席验收。

## 一、先限定这次试写证明了什么

用户认为《百机祭以后》读感不错，但明确它缺少前文，只能作为独立测试，实写须重写。这项反馈不批准其中的背叛、身份公开、战争过程或人物去向。不能因为一场读起来成立，就反过来安排十章来证明它必然发生。

试写有帮助：它让我们看见私人期待、明确行动和事后相处可以比抽象关系标签更有力量。但它没有验证从C01开始的感情积累、主角伦理变化、战争发展的必然与意外，也没有验证游戏分支。特别是“纪存限制索琳离开”，仍属于项目反复使用的控制与退出冲突，不能仅因写得较顺就成为全剧新支柱。

**本轮结论：需要调整最高层的故事设计，而且应在继续扩写全剧之前做。主要问题不是本作精神不够好，而是总发动机把太多不同人物和历史，导向了同一种矛盾与同一种答案。**

## 三、真正的上层问题

### 1. 四个人看起来不同，成长却容易成为同一道题

L2第6节已经写了私人欲望和英雄能力，不是完全没有人物设计。但各人的危险与终局被归到相似结构：纪存替别人决定，七海建立难以退出的保护系统，白鸢让他人接受自己看到的未来，索琳不许受保护者离开。最后分别学习拒绝、撤回、改稿和退出。

这能形成主题呼应；若成为四条完整弧线的骨架，就会让四个角色轮流证明同一件事。大量“你不能替我决定”式对白，并非仅由遣词造成，上游不断安排这种争执，改掉句型仍会写回来。

**建议：保留这个共同危险，但不让它垄断人物一生。** 纪存要亲手建立什么、索琳要夺取什么、七海愿为哪一种真实前途离开熟人、白鸢怎样面对爱情与自己的事业，必须能产生不同的行动与结局。爱情、嫉妒、阶层、名望、忠诚、复仇和疲惫，不必全部被翻译成控制权问题。

例如，白鸢完全可能不被任何人限制，也知道纪存没有做错，却仍不愿继续陪他走；七海也可能成功建立有效秩序，但那个成功要求她长期留在另一个地方。这里的痛不靠新罪行或新机制，而来自她们真正拥有自己的生活。具体是否采用，仍须由前文与整体故事决定。

### 2. 六层世界很丰富，却被同一种解释串了起来

L2第4.6节与六层前提第6节，把城市劳动、跨文明翻译、归航、分支生命、终极合体、宇宙归静接成逐级升级的发动机。素材本身有区别；问题是它们经常都被解释为“曾经救命的安排，后来无法退出”。

于是揭开一层真相，常常只是把已知的伦理判断放大。玩家越来越明白作者会怎样回答，却未必越来越迫切地想知道接下来会发生什么。

**建议：保留可用机制，重写其戏剧用途和揭示顺序。** 归航可以首先是一群人拿着有效的返乡承诺，却发现故土已经住着别人；白框真相可以改变一个正在作战的群体究竟是谁，以及他们是否会继续效忠；历史责任可以让亲人由受救对象变成有人要追捕的对象。这些方向已有素材基础，但不能又只安排一场说明会。揭示需要改变眼前行动，不强求每层都完成同一种反控制论证。

作者仍需掌握关键真相的稳定因果。人物暂时不知道，不等于作者可以不断临时造答案。外敌则按用户最新要求保留部分不可理解性，不必补成完整人类政治史。

### 3. 世界缺少足以独立运转的争夺，不能只争“机器人是什么”

L2第2.2节把社会分裂集中到对机器人的定义，第7节又多次把阵营写成局部正确答案的扩张。这个角度适合解释世界，但不能包办战争。

新的00主案已经补了土地、驻地、工作、军用订单和政治承认，确实比旧母盘好。然而部分冲突仍在迁出、扣留、救援、记录与放行之间循环；第四部分甚至预先规定“没有人得到自己想要的结果”。这也会限制对手：阴谋可以失控，但布局者应有机会真的夺到权力、消灭对手或建立新秩序，而不是人人只留下悔恨。

**建议：让阵营拥有能赢、能输、能部分实现的具体事业。** 一些人为了土地与边防，一些人为了事业继承，一些人为了复仇或让自己的群体第一次成为主人。即使彼此理解，利益也不自动相容；反过来，不互相信任也可以有可靠合作。善恶不必平均分配，更不需要给每个残酷行为找一个可以原谅的解释。

多方计划相撞要能事后追出原因，却不能只要复盘就得出“补传一条消息便全员得救”。同时，玩家此前救下的人、夺到的资源和改变的战局必须真实有效，不用“世界混沌”替作者任意没收成果。

### 4. 终局提前写得过细，最大的矛盾反而被排除了

L1第9.3节、L2第14节、六层前提第4.5节，已经越过体验承诺，规定先用终极合体赢，再拆开、再组合的一条具体路线。L3的C19—C22更完整地规定了实体营救、联装大战、战损卡死、公共服务重复指令、救出驾驶员与重新合体。

这套设计有真实优点：机体强大不是骗局，胜利不被取消，巨大身体确有物理代价。但L3的C21明确各阵营都同意停机，索琳也要求切断服务。此时最晚两章的主要阻力变成战损与重复命令。二十余章积累的野心、亲密伤害与政治分歧，可能在高潮之前退出舞台，留下大家共同处理的一次超级事故。

**建议：保留终极机、逆合体、万机殿等高光候选，不提前锁定它们必然按这套顺序证明唯一答案。** 最终需要解决的事情，应同时受到真实战争、未解决的人物意志与玩家此前选择影响。并非必须把索琳改成最后Boss；重点是不要预先规定所有重要人物已经认同同一方案，只剩操作困难。

最新00主案已允许大型合体继续存在、索琳不归队与不同终局，这是进步。但末段仍主要列出结果，尚未形成能承担上述冲突的具体故事。不能以它已经开放选项，就宣称终局问题解决。

远星的本质与用户确认的方向不改：原发统一意识，不是战犯、法官或隐藏主谋。它最终认识到彼此不能完全互通的生命也能共存、创造和演化。应重写的是让这一认识发生的故事，不是把“通过自限测试”换一个文艺名称。

### 5. IP故事仍有被主题统一加工的危险

L1已经要求名场面、精神、玩梗和What-if，不缺这份愿望。六层前提第9.2节却又要求IP期待进入六层后果；L3的C20甚至为机群预定八条动作链及唯一动作入口。这样容易先决定所有机体应怎样交棒，再找IP来装进去。

按用户此前指出的优势，IP投射应为我们带来已经有吸引力的人、冲突与观众期待。师徒的崇拜与愤恨、宿敌的执着、故乡与血缘、王牌与部下、恋人的追赶，不必先改造成自治寓言才准入。它们应能改变原创主角的计划，而不只是等纪存帮助或在终战回援。

**建议：挑真正承担关键事件的IP故事，保留其最锋利的私人冲突，再让它与本作其他人的目标相撞。** 原作先验能够缩短铺垫，不能代替本作中谁知道什么、这次为何行动的说明。77条记录不等于必须写77份完整传记，也不意味着热门机只需要在全员Cut-in里被念到。

### 6. 故事还没分成不同历史，制作方案已经先收窄了它

L3第5.6节只允许一条完整高成本长线分支，其余主要使用状态差分。它是明确的成本策略，但早于当前用户希望的游戏故事范围；若当成创作根锁，两条路线会很快被写回同一串必经事件。

00主案的甲乙路线已经改进这一点。下一步要检验的是：玩家参与一方事业后，是否真的使另一方改变计划；同一个人、城市和机体在再次相遇时是否处在不同的历史里。不是给每个悲剧一条全员得救线，也不是给整部小说贴上两种结尾。

**建议：先写少量有意义的历史分歧，再比较独占内容与共享内容。** 制作上仍须节制，不承诺无限分支；但不能先让成本表替人物选择。同一战场可以复用，谁来进攻、谁要撤退、为什么相见却应由路线真实改变。

## 四、最高框架建议怎样变

### 保留的不是一条抽象口号

保留玩家真正会来玩的东西：喜欢的机器人活着、有身体、有魅力，可以驾驶、改装、合体、拥有和长期陪伴；熟悉的英雄与遗憾能在同一世界相遇；万机馆既是出征的家，也容得下喜剧、情色、俗气爱好和日常；大战可以真的赢，救人可以真的成功。

保留G.A.G.、机魂与人的关系所具有的原创潜力，保留纪存与索琳的不同来历，保留强大而并未被完全理解的外敌，以及远星作为更高尺度的另一种存在。物理规则继续约束行动，不能为高潮临时无所不能。

L1已经允许英雄、私欲、越界、背叛、失去和非圆满结局。因此不需要把本作从“温和游戏”强改成“残酷作品”。我们缺的不是允许残酷的条款，而是让人物真的想要、真的去做、真的互相改变的主线。

### 建议竞争当前总发动机的新方向

**前半部的驱动力，不只是在各地救人，而是让这些来自不同故事的英雄共同做成一件原作中从未存在过的大事。后半部的驱动力，不只是保护连接方式，而是他们怎样争取、争夺和守住这场共同胜利之后的世界。**

纪存从想让万机馆继续开门，走到想邀请那些只在故事里见过的人。他逐渐发现自己不只能挽救结局，还能促成一支真实力量：让原本不能同时存在的英雄、敌手和普通机群并肩办成大事。百机祭可以继续是这条愿望的成果，但不预设它就是所有政治与感情的唯一分水岭。

共同获胜之后，各方得到的不只是勋章，而是原先没有的能力、支持者、住所、军队与选择。有人想就此回家，有人终于有力量夺回故土，有人认为现在应清算旧罪，有人想把战时联盟变成长久秩序。索琳的事业在这里不应只是纪存愿望的极端版：她代表的许多机魂，即使喜欢万机馆，也可能确实不愿以客人的身份生活下去。

纪存必须追求自己的后续事业，不能只劝大家继续相爱。七海、白鸢和IP群像也各有愿意付出真实代价的目标。背叛、并肩、离去与复仇由这些目标相撞而来；有的人会故意伤害亲近者，有的人没有做错却仍失去重要关系，也有的人始终可信。不能把全部人物都安排成“为了你好而越界”的同类。

外敌会选择薄弱处、扰乱联盟的计划，也会为人类尚未理解的目标付出和放弃。它不只是迫使分裂者复合的警报器。归航与历史真相进一步改变各方能做什么、相信谁、承认谁的家，而不是轮流揭晓另一个权限陷阱。部分矛盾可以谈拢，部分即使真相大白也不会消失。

玩家参与的路线应使这些事业得到不同战果。最后的大胜需要此前真正积累的机体、同伴与选择；胜后仍有独立生活、无法挽回的失去和不愿和解的人。远星看见的不是全员同意的正确答案，而是这些并不相同的存在确实共同做出了它原先不能理解的事。具体战役、联装形态和最后谁与谁站在一起，要由上述故事写出来，不能由这段方向文字预先宣布。

这不是已选定的新母盘，只是明确提出：**用“共同创造历史，以及对共同未来的真实争夺”扩大“连接与控制”的单一总题。** 不能把它再变成“每次救人必受反噬”；许多相遇、胜利和爱情完全可以留下净收益。

## 六、接下来只做一件有用的事

下一份交付应是**新版全剧核心故事**，而不是再做一套更庞大的规则、人物表与审查流程。

1. 从C01—C04已经发生的事与C05—C06已认可方向往后写。先不按二十二章分配，形成能连续读懂的主要发展；生活和机战都在其中。
2. 写清四位核心及主要势力要赢得什么，选出少数真正改变局势的成功、阴谋、反转和关系动作。保留IP故事自己的情绪，不用同一模板串满。
3. 把中盘分歧和终局放回这条连续故事检验。若需要改变核心伦理选择、存亡或世界根机制，指出具体分歧与可比较走向，不把尚未选择的结果写成已定。
4. 在有实际意义的处分出少量历史走向；明确玩家能影响什么、角色已经决定什么，附简短玩法构思，暂不写详细游戏解构。
5. 方向得到确认后，再展开为用户要求的C04—C06跨章稿容量的全剧概要，随后才逐章Reader。此前独立试写不提供任何情节免检资格。

本轮先交框架审查与建议，不启动正式迁移。判定调整有用的证据，将是下一份故事能否让人读出不同人物在争取什么、愿意追下去，并在回看时发现转折有前因；不是又新增了多少门禁，更不可能用内部PASS保证作品“历史留名”。
