# 全剧玩法与真实分支构思

2026-09-15 | Candidate / 概要配套，不是详细游戏解构或实现授权。

对应[13号全剧故事概要](13-全剧故事概要-v1.md)。本文件回答玩家能做什么、什么真的改变、如何得到机战与长期成长；不反向要求故事逐回合描述操作。文中段号是概要阅读位置，不是冻结章数、关卡数或话数。

玩法依据是[核心玩法总案整合版](../../game-design/2026-08-10-full-game-design-candidate-v1/00c-core-game-design-master-review.md)已经认可的产品方向：可钻研的确定战棋、人物出席与专业、亲手促成名场面、巡访与记忆调查、修复收藏、回家与关系、有限世界回望。其数值和中性例子不提供本稿的故事事实。

## 一、这趟旅程怎么轮换

| 故事段 | 玩家主要在做什么 | 机战题目与主动空间 | 留下什么 |
| --- | --- | --- | --- |
| C01–C04前情 | 沿用已经确认的剧情与分别存在的玩法提案 | 本稿不重开旧关卡，不把五话C04换回失效四话铸环 | 已有同行者、损伤、工房胜利与七号公共体 |
| 百相试航与黑城 | 试飞观察、有限协同、查外运、突破失控武装 | 先让新右臂与双机打赢真实试航；黑城战分防压制、打出安全攻击条件、解救二号机；出航封锁是另一场冲突，非黑城复活 | 百相新搭档、韩秀雅外线身份、米拉与艾达不同去向、纪存与白鸢新的信任问题 |
| 星火乐园 | 参展、客演、模型与实机整备、节目与生活 | 敌方进攻供能与运输走廊；五车完整合体后可持续操作，而不只观看一分钟过场 | 星火巨神与可分用五车、联展网络、百机祭与新剧的积极目标 |
| 发行与创作 | 选藏品、修复、试拍、版本比较、少量真实交易 | 不强塞每店一战；工程与收藏可提供兵装选择，正确生意不等于全部用最低价成交 | 维修替代来源、外观与动作差分、作品与地方关系；纯梗不必给收益 |
| 武斗与寻兄 | 有胜负的对战、辨认招式破绽、主动追击押运线 | 比赛考验间合、朝向与预备；押运战考验击破与截留，不复制比赛地图。拉维离赛寻兄是角色选择，不摆出最后必被否决的“留下夺冠”菜单 | 无牌一号的长期战斗价值、拉维与家人的新处境、与莱拉必须另行修复的关系 |
| 三地防线 | 选择适配机群，进攻陌生敌型；认识当地生活 | 零式夺取主动、岛卫追击与反追击、潮墙浅海主战。不同尺寸与地形有各自进攻能力，非三次承重接力 | 三支自主外线队伍、具体敌情、地方人脉与有限获救结果 |
| 百机祭 | 布展、人物来访、节目观看、编组，然后多战区反攻 | 可调配已同意参战的队伍、争取不同战果；不必全员挤同一地图，不强迫所有热门机让一个冷门机独占最后一击 | 真实大胜、长期合击与金章伙伴、产业与公共体增长、庆典继续 |
| 未来追猎 | 城市巡访与逃亡、证据比对、地面运输和巨机截击 | 人形追踪与重装追杀不同尺度；液态体损耗有限、补给可截断。不能在全知地图上提前标出伪装者，又要求角色像不知道一样中计 | 卡西安的证言与责任、伊利亚斯的主动出击、寻找爱丽丝与纪文山的实际地点 |
| 解放设施 | 制定多目标进攻与运载安排，保载体、证据和出口 | 重装增援、转运和内部破坏分别可打；连续危机可跨话。固定索琳枪杀是本稿角色决定，不伪装成玩家可以靠一格走位阻止的失败 | 解放真实成立、工厂易主、父亲真相、公开追责受到破坏 |
| 地球线 | 工业区重开、地区战争、创作与关系、护送民用订单 | 有正面保卫、量产机地形战、派系遭遇和打断远射战，不只是修理小游戏 | 独立生产与安置较完整；钢花较能选择，远征缺少本队支援 |
| 远航线 | 舰队接应、陌生尺度作战、寻亲、夺舰、异文明接触 | 巨机有自己的战域与保障；Voltes式夺舰、五兽故地争夺、遗灯整船突围各有敌我目标 | 更多归航者与重型工程；地球联盟依赖加深；亲历战争不能由归航后一本资料全部补领 |
| 归航冲突 | 分批接应、地方协商、保卫降落区与对不同进攻者反击 | 人道接应与领土归属是不同问题。可以争取较好结果，不通过随机平民必死迫使“世上无完美选择” | 双路线之前的所得真正影响驻地、工业与同盟，不在会合时清零 |
| 巨体工程与总攻 | 后继实装、个人训练、编组、主力资源去向、多战域决战 | 普通单位仍能击毁强敌；巨机、联装与主舰各自有完整使用段，不把77机烧成一张终极技能卡 | 馆守Z新臂、万机馆巡航战装与万机殿前身、天盖王/三相后继、实际外战胜利 |
| 战后对峙 | 在已发生的胜利中执行兑现、拒绝或军事保护 | 和平历史也有主动压制危险火力与重组巨躯；决裂历史打真正内战，不把敌方突然削弱 | 不同的共同设施、关系和政治结果；两边都保留强大成长回报 |
| 归静与馆外 | 比对现场与远距证据，有限接触，护送与辨认 | 替代通信真有效；馆外回应不万能、不取代舰队。双向窗口改变有限操作关系 | 被分别听见的主体、持续接触的变化、能继续生活的余波 |

常规战的主要乐趣仍来自读意图、调位置、朝向与预备、实际使用已拥有的身体和兵装。人物的勇气、信任、愤怒、集中与合意体现为有条件的战术可能和名场面，不要求每次普通攻击先开一次劝说会。具体“精神”资源与牌形沿玩法总案进入后续设计，不在概要假定已实现。

## 二、三个层级的选择，不能混用

### 1. 角色已经作出的决定

索琳枪杀、拉维离赛寻兄、艾达请求米拉打掉驱动自己的档案、韩秀雅拒绝清除百相新搭档，是本轮候选故事写定的角色行为。玩家执行相关战斗、准备或后果，不能收到看似能够任意取消这些决定的假选项。

用户审阅本稿仍可选择修改这些写定行为；这与游戏内给玩家哪些选择是两层问题。当前没有把本稿写定内容提升为Canon。

### 2. 真正改变事件的主分支

最先开放的是“安全以后是否赴约”，随后是“地球或远航”。它们不互为善恶套餐：

| 组合 | 父亲在哪里、发生什么 | 纪存与七海/白鸢的关键差异 | 阶段独有经历 |
| --- | --- | --- | --- |
| 赴约＋地球 | 按时会面，父亲留在受保护居所持续调查；父子可探视、工作、争执 | 未发生藏父欺骗；亲密可以继续，后续分歧有别的具体原因；白鸢不必揭穿不存在的失约 | 共同重开产业、地方政治、实际生活磨合 |
| 赴约＋远航 | 按时会面后父亲留地球；信件、证据与探视期待持续 | 分开是事业与距离，不追加背叛指控；白鸢可保持合作而拥有独立团队 | 远征亲历与父子异地交流同时存在，不缺亲情内容 |
| 隐瞒＋地球 | 空约后父亲仍被藏；后来是否陪同迟到调查有实际不同 | 七海停止担保与亲密；白鸢发布失约，团队独立；共同作战不自动复合 | 支持者逐步拒绝协助隐瞒、父亲主动要求回答、错误如何持续进入生活 |
| 隐瞒＋远航 | 父亲起初随舰，面对外线见证者；当地询问不能冒充已完成地球调查 | 地理离开不能洗清失约；同行的制作组也不表示白鸢重新信任 | 更长父子相处、旧责任跨星域遇见现实、归来时仍需面对地球的人 |

两种远航历史中，白鸢均与部分自有团队登乘重剪舰，槐与地面团队留守；七海留在地球。共同接应与同船生活不是同一状态，同行也不自动修复隐瞒历史中的关系。

选择前要让玩家知道会面安排是可行的、隐瞒会让人继续等；不得提前用善恶颜色告诉玩家索琳以后哪句话正确。航路选择则明确出发窗口、己方能投入的主力与留守者，不能让玩家误以为稍后立刻补做另一条。

### 3. 局部战果与生活选择

包括七号当前作业模块、武斗表现、支援先后、普通战的损伤与保护、作品/收藏取向、关系见面、后期投入哪些实际资源。这些可形成差分，不升级为每次选择创造一部新宇宙史。

七号主体、人格和已发生命运不随模块改变。角色恋爱不能用“选地球送七海，选宇宙送白鸢”分发，也不能让一个无提示小收藏决定核心同伴必死。

## 三、集中反攻和最终停战不是同一按钮

“更早集中资源”和“保留独立生活能力”改变真实准备与战况，但不直接等于坏结局、好结局。最后还要面对各方已经形成的目标和当时是否履行。

概要暂只保留两种主要终局历史，沿途差分写进其中，不做四乘二再乘全部恋爱对象的完整平行小说：

- **有限停战历史**：有可落实的驻地、独立维修与实际防卫安排，机队通过行动阻止双方危险攻击；联盟不完全解散，索琳个人责任不免除。万机殿有主动重组、压制和保护的大场面。
- **实际炮战历史**：条件未被接受或行动已越线，万机馆与愿意离开的机群从联合阵位中脱出，击败继续攻击的能力。损伤与失去合作真实存在，不能额外随机杀核心角色替分支增重。

索琳在两种结局中都退出原对外作战指挥，并实际进入受保护的调查安排。前者是安置能够独立运作后主动交接，后者是在武装施压失败后接受限制；不能用统一“责任另算”遮掉过程差异。

详细解构前必须把可影响因素做成少量**可见事实**，如“某处驻地已经入住”“某条产线可独立维护”“某队答应停火且实际撤去攻击位置”，不能暗算一张玩家不知道的道德总分。已达成条件不会保证每个角色喜欢主角；暂时不足也应有明确成本与最后争取机会，而非突然锁成坏结局。

此处仍需下一层验证：最终分界选择出现在哪一场、什么行动足够使具体机队撤回、怎样诚实显示已经没有的机会。概要没有声称这些条件已经用完整流程跑通。

## 四、跨段状态与玩家代理

剧情段、Episode、连续战争、可操作段与任务结束不一一对应。黑城危机中场换话不是机体全修复；解放的多个战斗结束也不自动意味着全部载体已搬走。只有现实冲突得到对应解决，才能进行那项任务的结果确认。

后续详细解构至少跟随以下连续事实，而不把它们全部变成公开仪表：

| 连续事实 | 后续会用到哪里 |
| --- | --- |
| 谁在船上/留在地方，哪台是实体、远程或仅档案 | 关系见面、接应、可用机体，防止T分身、货柜领袖瞬移 |
| 损伤、装备与实际维修 | 完全版王者、馆守Z新臂、百相完整战装及外泊巨机 |
| 谁见过什么、得到哪部分资料 | 追猎辨认、父亲问责、白鸢发表、外敌学习；公开战果不自动包括私人预演 |
| 是否赴约、父亲当前地点、迟到调查进度 | 四组合所有后续，不能只读取“解放已完成” |
| 地方产业/归航能力及实际保护对象 | 归航冲突与最终谈判 |
| 原本不同的发出/收到/近距证据 | 归静认识，防止用通信文字直接证明主体已消失 |
| 某角色已选择的任务与拒绝边界 | 玩家执行战术，不以点击占有驾驶员；普通回合也不会无理由随机拒命 |

失败、保存、重试都必须保持真实软件可恢复性。普通重试不产生被杀掉的平行机魂，不用现实离线时间惩罚角色。固定故事结果与可争取的结果要在关卡开始前让人有足够理解。

## 五、Meta：现在能验证什么，还不能声称什么

本稿选择的是**一个陈列窗口变成双方都能试探、拒绝的会面空间**。它不是全部界面突然属于某幕后主机，也不把此前战斗降为实验。

| 进展 | 玩家以为在做什么 | 新证据与实际操作变化 |
| --- | --- | --- |
| 稳定收藏 | 整理自己的展品 | 先有真实乐趣；摆什么不产生道德审判 |
| 发现响应 | 看个性化档案画面 | 可重复改变未发布摆法，另一边同步重建；陌生物由另一边先加入 |
| 关系翻面 | 自由旋转观看一个虚拟对象 | 对方能按住拒绝；返回后露出物理房间，允许围绕有限桌面观察，而非假报错 |
| 双向试探 | 向一个NPC接任务 | 双方会误读，须区分看见与同意；另一边也能停止这一条联系，不能无限索要 |
| 实际协作 | 帮其取得自己已有的答案 | 馆外参照仅补一部分，现场必须核对并采取行动；可以拒绝，由较慢替代方案继续 |

后台作者需要承认的最小事实：变化只涉及这一个有限馆外联系；对面是归航档案工作室的真实设备与人，摆件由对方操作，非塑料直接操纵巨机；只读取本游戏已产生的陈列/观察交互，不读现实隐私；联系中的人物可知有限操作，不能知玩家全部思考。

**这项有限双向寻址仍是新Candidate机制。**正文写出了体验提案，不等于已经证明震撼、可实现或已与每条根机制完成正式迁移。须在其进入Reader前核对一个问题：当前G.A.G.与馆外响应如何支持这个特定窗口，而不推广成所有屏幕都能泄露私人想法。若无法限定，不以增加一套宇宙主机补救，应收窄到仍可解释的部分并重试。

最小交互原型将测试：去掉解释文字后，是否能辨认“我以为只是我的陈列，原来双方一直在建立参照”；拒绝是否真被接受；它是否比普通远程任务多一次可感的观察位置变化；既有战棋控制与真正退出是否仍可靠。**当前没有制作或运行原型。**不能只凭梗概将这一项写为效果已通过。

## 六、规模与制作负担

保留所有素材的参考价值，不承诺77条机体/驾驶包全部以相同剧情容量出场。本稿已有主场者需保住自己的故事，客演与轮换不能自动提高为全程主力；未被选中的原作剧情留在储备，不能靠片尾名单假称已经采用。

角色、普通机体、中型机、百米巨机、千米阵地体分别采用适合的战域。战棋表达可以抽象，但故事里的万机馆不能把二百米身体塞进现有机库。大型战场允许滚动与局部切换，建筑和重要设施属于地图的可作用部分，不只是背景。

两条长路线意味着真实写作与资产成本。可复用同一地区不同阵营到达状态、同一套敌人动作、归航会合后的基础地图；不能用同一段对白掩盖角色经历不同。没有算过的动画、人日、性能与完整路线测试一律视为未测，不因概要较清楚就宣称成本已降低。

下一步在用户选择故事方向后，先按自然发展分章，选一段典型战斗与一处分支做详细解构样板，再决定全局制作范围。当前不启动C01 Demo以外的新制作，也不要求它等待本稿。
