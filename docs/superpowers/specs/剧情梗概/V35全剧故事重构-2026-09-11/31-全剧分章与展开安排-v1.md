## 一、先看结论

建议一周目暂按**25个章位**展开。C01-C04保持已有事件；C05-C15为共同主线；C16-C18走地球或远航其中一条；C19重新会合；C24有两种政治战争版本；C25收束。标题是便于讨论的工作名，不是最终章节名。

```text
C01-C04 已有旅程
    ↓
C05 试航与离队 → C06 乐园 → C07 发行与创作 → C08 寻兄
    → C09 地方防线 → C10 索琳 → C11 自治与爱情 → C12 百机祭
    → C13 未来追猎 → C14 解放 → C15 是否赴约、选择航路
                                      ├ 地球 C16地 → C17地 → C18地 ┐
                                      └ 远航 C16远 → C17远 → C18远 ┘
    → C19 归来 → C20 巨人建成 → C21 事故、修复与新力量
    → C22 外战胜利 → C23 战后对峙
                         ├ C24限 有限交战 ┐
                         └ C24战 全面战争 ┘
    → C25 持续联系与重新开馆
```

“是否赴约”发生在选航路之前，沿两条路都保留，不能把地球写成七海的正确路线、远航写成白鸢的逃避路线。馆外接触放在归航后可进入的生活时段，不占一章人人必须经历的宇宙揭秘。

**这不是为了把22节扩成25章。**27号第一节已概括四个现成章节；十三、十四节互斥；十六节可选；十一节的解放与事后相处需要分开；十七节至少要让首次成功与后续事故隔开。按这些差异重新组合，才得到当前章位。

当前容量估计约为单周目百话量级，明显属于长篇，不是短流程作品。话是阅读与演出单元，不等于战棋地图、任务结算或一小时。以下推荐话数用于检查是否挤压人物，不是按模型输出上限排产，也不构成成本已经可承担的结论。C05实际成文后再校准篇幅；不为守住此表而添水或压掉有分量的场面。
