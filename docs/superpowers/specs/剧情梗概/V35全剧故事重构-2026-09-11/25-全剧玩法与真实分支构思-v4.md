| 万机馆人形试验与修复 | 首次试验完整成功并返舰庆祝；几天后的接应试验失控，转为现场救接与保全；修复后重新试航 | 首次成功不在结算时追认作错误。同一后续事故不随切话刷新。纪存扩大接驳、公共展廊毁损属于固定剧情，之后玩家改变追加损失。主舰普通停止与独立物理断路有不同效果，游戏本身暂停/退出不失灵 | 先有拥有巨人的快乐，再失去共同空间；私人收藏已移出试区。修复后人形长期可用 |
| 巨体工程与总攻 | 后继实装、训练、编组、主力资源去向、多战域决战 | 外层巨构、近地轨道、海岸分别操作。天盖王开路、迟归一号压入、盖流换形、火种载具转换、社勇王工具合击各有战法。天穹与万机馆独立；潮墙浅海主战，断冠在海岸终战 | 馆守Z新臂、万机馆人形主舰、可持续使用的后继机、实际外战胜利 |
| 战后对峙 | 在已发生的胜利中执行兑现、拒绝或军事保护 | 两路都有真实交火；有限路线限制目标，全面战争有脱出受阻和更广战损。天穹成员先退出，再由各自操作者接入万机馆构成万机殿 | 不同设施、驻地、部队和关系终态；两边都保留强大成长回报 |
| 归静与馆外 | 比对现场/远距记录、有限双向试探、在战后对峙同期持续接应 | 归静不替任何人规划；玩家核对实际发信者及结果，不选择宇宙答案。馆外从新增参照进入活桌面，请求/撤回/被拒绝均有实际反馈 | 分别传达的主体、持续接触；接触验证为尾声，不再加第三场终局Boss |

常规战的主要乐趣仍来自读意图、调位置、朝向与预备、实际使用已拥有的身体和兵装。人物的勇气、信任、愤怒、集中与合意体现为有条件的战术可能和名场面，不要求每次普通攻击先开一次劝说会。具体“精神”资源与牌形沿玩法总案进入后续设计，不在概要假定已实现。

## 二、三个层级的选择，不能混用

### 1. 角色已经作出的决定

索琳枪杀、拉维离赛寻兄、艾达请求米拉打掉驱动自己的档案、韩秀雅拒绝清除百相新搭档，是本轮候选故事写定的角色行为。本版继续将钢花分家、艾达结束原有恋爱、莉歌与红面具决裂、万机馆后续接应试验失控保留为固定故事变化。这些结果仍需用户审稿确认；不倒写为既有Canon。

若采用这版，玩家可以影响救接、损伤、资源和后续关系往来，不能用高好感强迫艾达复合、阻止槐发表证据，或将更完整的民用网络解释为钢花从未分裂。结局允许关系已经结束的人仍来援护，也允许有人拒绝赴宴。

自由双星一战中，萨米尔在接到人员未撤完的信息后仍攻击供弹设施，其直接伤亡是已经选定的角色事件，不是玩家正常瞄准后突然附赠的隐藏平民损失。后续可操作内容是疏散、援护、搜索幸存者和阻止扩大交火；不得提供看似能无伤制止全部发射的同段目标，再无视玩家完成结果播放固定死亡。若后续关卡发现实际规则确能兼得，必须回改场面或收窄可操作时段，不能偷偷让成功无效。现阶段尚未生成该关卡。

用户审阅本稿仍可选择修改这些写定行为；这与游戏内给玩家哪些选择是两层问题。当前没有把本稿写定内容提升为Canon。

### 2. 真正改变事件的主分支

最先开放的是“安全以后是否赴约”，随后是“地球或远航”。它们不互为善恶套餐。本轮把父亲后来接受调查写成有过程的共同出口，不再另开“无限继续藏人”主分支；最初隐瞒造成的失约、持续时间与信任损失不抹平：

| 组合 | 父亲在哪里、发生什么 | 纪存与七海/白鸢的关键差异 | 阶段独有经历 |
| --- | --- | --- | --- |
| 赴约＋地球 | 按时会面，父亲留在受保护居所持续调查；父子可探视、工作、争执 | 未发生藏父欺骗；亲密可以继续，后续分歧有别的具体原因；白鸢不必揭穿不存在的失约 | 共同重开产业、地方政治、实际生活磨合 |
| 赴约＋远航 | 按时会面后父亲留地球；信件、证据与探视期待持续 | 分开是事业与距离，不追加背叛指控；白鸢可保持合作而拥有独立团队 | 远征亲历与父子异地交流同时存在，不缺亲情内容 |
| 隐瞒＋地球 | 父亲主动联系调查方，唐胶拒绝继续隐瞒，纪存陪同迟到数周的会面；此后入住受保护调查居所 | 七海停止担保与亲密；白鸢发布失约，团队独立；后补调查不自动复合 | 支持者不再协助隐瞒，父亲夺回自己的决定；后续父子探视与关系修复可有局部差分 |
| 隐瞒＋远航 | 父亲起初随舰，主动交付外线记录、接受询问并通报位置；归来实际到地面调查居所报到 | 地理离开不能洗清失约；白鸢同行不表示重新信任 | 更长父子相处、跨星域见证与更晚的地球问责；不得与按时赴约共用同一信任状态 |

两种远航历史中，白鸢均与部分自有团队登乘重剪舰，阿岚与白翼在白色航舰；槐、七海、韩秀雅、艾达、百相及三地方旗舰留在地球。方舟T在外线才与陆衡见面，随后随归航主队返回；安雅留回程接力站负责后续船。地球路线的阿岚留在地球，陆衡直到归航会合才见T。不能把两条路线的出席叠加。

汇合时，远航玩家先见米格尔和夸梅分别负责不同场地，再听对方愿意讲的分家经历；通过萨米尔/亚历克斯维护停火、喷气叛星争报酬认识其余变化。地球玩家通过电磁家庭、五兽居住安排、天盖王维护组认识归航者，并随伊莎贝尔送托物、联系安雅。远征原始记录在归航后的联席会议进入地球线，不预先给该线玩家播放远航亲历视点。未选线重大经历不自动解锁为“主角亲历”。

选择前要让玩家知道会面安排是可行的、隐瞒会让人继续等；不得提前用善恶颜色告诉玩家索琳以后哪句话正确。航路选择则明确出发窗口、己方能投入的主力与留守者，不能让玩家误以为稍后立刻补做另一条。

### 3. 局部战果与生活选择

包括七号当前作业模块、武斗表现、支援先后、普通战的损伤与保护、作品/收藏取向、关系见面、后期投入哪些实际资源。这些可形成差分，不升级为每次选择创造一部新宇宙史。

七号主体、人格和已发生命运不随模块改变。角色恋爱不能用“选地球送七海，选宇宙送白鸢”分发，也不能让一个无提示小收藏决定核心同伴必死。

本轮将以下四处列为可以由准备和操作争取的具体差分。它们在24号中保留同一主结果，详细规模与资产待分章时确定：

| 既定人物选择 | 玩家真正能改变的事 | 如何预告与长期体现 |
| --- | --- | --- |
| 拉维离赛寻兄，兄长不独自逃走 | 在兄长所在运输机之外，能否把后续押运中的更多人一同接出；不是换一个夺冠结局 | 行前可查押运班次、准备额外运力；已有支援可派往另一出口。救出的人后来参加工房或百机祭，不只增加物资数字；错过不伪称已经获救 |
| 电磁五虎夺舰，父亲公开与占领者决裂 | 在合体攻击暴露行动前，能否接应更多愿意撤走的合作者；不强迫选择留守者离开 | 救援位置和开战后的关闭风险提前可见，主力分配与接应艇准备有效。归航舰的维修能力与具体乘员变化；不能靠熟悉原作猜隐藏按钮 |
| 钢花分家，夸梅另立民用工房 | 成品能否按约交付、哪些共同设备可以实际运出、何处已有接纳位置；影响临时租用/外包负担与恢复速度 | 先前客户、运输和厂址都需有可见来源。更早投入的玩家能实际减少损失，不只是听到更好评语；远航历史通过后来见面得知缺口，不能补播成已经亲历 |
| 万机馆后续试验已经失控、共同体决定修复 | 公共展廊固定损毁之外，能否保住其余共用实物、外装及无人训练艇；修复先恢复哪些公共功能 | 私人收藏已在事前移出试区，固定演出不删除玩家藏品、改装与图鉴；事故后的可救清单只含确实留在现场的对象。成功抢救必须在修复与新展中出现 |

这些不是新增四条宏观平行主线，也不是把每次未完成支线都算成死亡。救出人数与损伤数值尚未冻结，最终应以已建模的人、设施及运力兑现。不要为了填满差分临时造一批只负责被救的名字。

## 三、集中反攻和最终停战不是同一按钮

“更早集中资源”和“保留独立生活能力”改变真实准备与战况，但不直接等于坏结局、好结局。最后还要面对各方已经形成的目标和当时是否履行。

概要暂只保留两种主要终局历史，沿途差分写进其中，不做四乘二再乘全部恋爱对象的完整平行小说：

- **有限交战阻止全面内战**：有可落实的驻地、独立维修与防卫安排，一部分舰队退出。红面具警告射击、沈砺命令压制，引发有限实战；不再由匿名激进者承担开火责任。玩家保护分离、打断继续攻击能力，不攻击停火者。实际抵达的推进分舰、公共装甲与维修舷台接合成完整万机殿。
- **同盟战争全面爆发**：强制交接与武装反击相互扩大，尚未退出的维修舰组受波及。玩家从天穹外侧救接，部分装甲损毁、维修舷台只能独立避难；抵达构件组成仍然强大的万机殿。红白决斗、地面索引天使/百相冲突分别成立，不能将地面索琳传送到高轨供主角收尾。

索琳在两种结局中都退出原对外作战指挥，并实际进入受保护的调查安排。前者是安置能够独立运作后主动交接，后者是在武装施压失败后接受限制；不能用统一“责任另算”遮掉过程差异。

详细解构前必须把可影响因素做成少量**可见事实**，如“某处驻地已经入住”“某条产线可独立维护”“某队答应停火且实际撤去攻击位置”，不能暗算一张玩家不知道的道德总分。已达成条件不会保证每个角色喜欢主角；暂时不足也应有明确成本与最后争取机会，而非突然锁成坏结局。

最终分界放在外战回航后、各方是否接受撤位与兑现安排的会议。玩家先看到实际入住、订单和舰队表态，再决定万机馆愿投入哪些已经拥有的保障与护卫；各派是否接受取决于此前可见的事实和自身目标。拒绝、资源不足或仍坚持扩大武装条件，都可能使整体撤位失败，进入全面战争。父亲分支不直接锁定这个结果。

这是故事级分界，尚未证明每项战果到该会议的数值组合可行。后续样板要试出：玩家能否提前知道正在失去哪支支持；局部补救成本是否清楚；有限路线是否仍有足够机战，全面路线是否只是无谓受罚。不得把纸面分界当成已跑通。

| 终态 | 有限交战 | 全面战争 |
| --- | --- | --- |
| 钢花/公共生产 | 米格尔军工与夸梅公共工房分别继续，民用订单可作为退出军队的实际保障；不重并团体 | 米格尔部分厂房损毁，夸梅以独立组织救接家庭；维修与补给受战损影响，不以一次救援恢复原组织 |
| 归航驻地 | 已入住码头继续使用，保障船可轮换 | 一处码头停工，需要转移与重建；归航者没有被统一缴械 |
| 万机殿 | 接入构件完整，维修舷台开放，推进分舰保留按约拆离权 | 缺部分外装与维修能力，保有强大攻击形态，补齐依赖真实后续维修 |
| 红面具/前同盟 | 接受有限撤位，政治组织与地区防卫仍在 | 退回自治防区，失去前推远射阵位及统领全部归航舰的能力 |
| 索琳 | 确认安置独立后主动交出对外指挥，进入共同调查 | 武装施压失败后接受限制与调查；支持者继续保护居民而非替她免罪 |

这些是段落中的实际差异，不另添随机核心死亡，也不以一张隐藏总分算完全部政治与恋爱。

## 四、跨段状态与玩家代理

剧情段、Episode、连续战争、可操作段与任务结束不一一对应。黑城危机中场换话不是机体全修复；解放的多个战斗结束也不自动意味着全部载体已搬走。只有现实冲突得到对应解决，才能进行那项任务的结果确认。

后续详细解构至少跟随以下连续事实，而不把它们全部变成公开仪表：

| 连续事实 | 后续会用到哪里 |
| --- | --- |
| 谁在船上/留在地方，哪台是实体、远程或仅档案 | 关系见面、接应、可用机体，防止T分身、货柜领袖瞬移 |
| 损伤、装备与实际维修 | 完全版王者、馆守Z新臂、百相完整战装及外泊巨机 |
| 谁见过什么、得到哪部分资料 | 追猎辨认、父亲问责、白鸢发表、外敌学习；公开战果不自动包括私人预演 |
| 是否赴约、父亲当前地点、迟到调查进度 | 四组合所有后续，不能只读取“解放已完成” |
| 地方产业/归航能力及实际保护对象 | 归航冲突与最终谈判 |
| 原本不同的发出/收到/近距证据 | 归静认识，防止用通信文字直接证明主体已消失 |
| 某角色已选择的任务与拒绝边界 | 玩家执行战术，不以点击占有驾驶员；普通回合也不会无理由随机拒命 |
| 原来的关系是否仍存在 | 米拉/艾达停止恋爱但可援护；莉歌不再作联盟代言；钢花分家但可互救。共同出击不覆盖这些事实 |
| 钢花分家时实际带走与得到什么 | 地球投入影响设备、成品、客户与恢复地点；远航中当地自行分家，归来订单只能补后续能力。两路不能共用一份无差别迁厂结果 |
| 历史证据是在何时获得、哪些责任已证实 | 共同反击是真胜利；主体替换、失控分类、个体隐瞒、迟到返航记录分阶段可知，不将父亲一人写成全部历史的主谋 |
| 万机馆舰形/人形、外装损伤与共同操纵 | 首次成功、后续事故、修复训练、外战主动胜利、末战换接万机殿；不把事故后下一场的人形自动变成无伤满配 |
| 索琳获准参与什么、没有得到什么 | 科菲拒绝她取得归航舰的登舰许可与共同调度权；伊玛妮承担约定跨队联络。居民/工房补给不附条件，合作不赦免枪杀。后续索琳能命令的仍只是实际支持她的队伍 |

### 本轮明确的时空承接

| 连续段 | 现在采用的故事安排 | 游戏不能偷换的内容 |
| --- | --- | --- |
| 乐园至百机祭 | 四个月内往返、拍摄、发行、地方轮换；盛会里先开幕，再按约主动出击，分批返港 | 不将四个月压成同一天连续追击，不把参展等同强制出击 |
| 追猎至解放 | 数周调查和侦察；解放后数天才到父亲会面日期 | 战斗结束不自动运输所有人；枪杀后临时看守、争议移交与自治庇护有顺序 |

| 外线接应/回程 | 当地相邻航段约两个月；万机馆重返承运架，回程舰上三个月。合计舰内九个月、地球十六个月 | 时钟差是航程结果，不是时间倒流；不把实体交通和受限短窗通话混成瞬移 |
| 总装/总攻/回航 | 归航后几个月工程；首次人形试验完整结束，几天后接应试验出事，再用数周修复训练；各战区实际航行到位；胜利后数周回近地 | 修复期包含在工程期，不压成事故当天继续出击；海岸单位不靠切幕到外层 |
| 安雅接替/留下/归来 | 战后对峙同期等到接替者，临时留下一轮护送后重订班次；尾声经过真实运输才抵地球 | 情绪回应可以通过有限短窗提前传来，人不能随之瞬移；不是错过一次约会后马上补拍完美团聚 |

月份是本版Candidate连续性安排，不是正式排程或硬锁年龄。后续调整必须同步两条航路及人物经历，不能只在一段换数字。

| 外战区 | 主要单位/对象 | 与其他战区的关系 |
| --- | --- | --- |
| 外层接应区 | 天穹联装、万机馆巡航战装、迟归一号、天盖王、遗灯与各自保障舰 | 切断入侵主力持续维修；不是直接让地面敌群归零 |

三个巨体状态按顺序继承：天穹由各方构件组成；万机馆在自身主舰外接装人形巡航战装，首次成功、后续接应试验失控、修复后能重复使用 → 外战两者独立作战 → 天穹部分成员实际退出 → 各自操作者将构件接入万机馆形成万机殿。退出使天穹损失真实推进/维修能力，不删掉仍由其他阵营控制的重武装；接入不吞掉全机群。外装重心、乘员安全、净空和灾损须在后续预制作核验，概要中的大动作不冒充结构工程验收。

### 母舰事故：控制链与公平边界

| 时点 | 世界内实际发生什么 | 玩家与后续设计边界 |
| --- | --- | --- |
| 第一次展开 | 纪存留在主舰内，驾驶/工程组共同完成展开、托艇、放回和收拢，返回后有独立生活场面 | 可享受一次完整成功，不用事后事故撤销本次成绩。私人藏品和非必要人员已离试区 |
| 几天后的加测 | 纪存同意扩大接驳；既有自动接应设备读取其持续感应，未完成响应被重复当成新动作 | 加测是角色决定。此处若已提供有效停止选项，就不能继续固定事故；当前方案不提供这个伪选项 |
| 普通停止失败 | 停止传入同一接应控制环节，重复响应又启动动作；工程组先断纪存接驳，本地设备仍彼此重复未完成的要求 | 不将拔除纪存这个更简单办法遗忘；没有外部夺舍、远程驾驶友军或主舰第二人格。场面需看清断开了人而机器仍动 |
| 实体断路 | 七海确认，工程组切外装供能，主舰独立推进继续工作；外装坠向海面，主舰保持海面上方 | 不把整舰断电后仍飞行混写。固定公共展廊损毁已经发生，玩家的抢救从此处开始 |
| 抢救与修复 | 其他机体自控，抢救现场共用展品、外装和无人艇；改装后普通停止不会被感应重新启动 | 已成功救回的对象不得被修复段再宣告损毁。共享空间损失持续，但玩家私人收藏/改装/图鉴不被固定清空；陈列布局可在新展区恢复 |

固定损毁的是故事已建立的公共展廊结构与随附实物，不可由关卡临时把任意玩家自购珍藏划入。事故后的救接差分应有明确对象、到达条件和长期反馈；若成本不允许实现这些差分，应缩小承诺并重新审稿，而不是保留选择外观。Pause、Skip、Save/Resume是游戏功能，不能因故事写了“普通停止无效”而失灵。上述仅完成纸面边界，未作结构、碰撞或可玩性实测。

### 机器人高光不是同一种玩法皮肤

| 主场 | 与故事相符的操作差别 | 长期使用要求 |
| --- | --- | --- |
| 社勇王/金章、星火五车 | 合体前各组件的出击安排，合体后强力动作与工具用途；固定首次合体可为剧情事件，后续不能永远禁用 | 不以一个短动画替代所得；分离后仍保留各自用途 |
| 自由双星、红白宿敌 | 射界与远射威胁、分离兵装、近身反制、熟悉战法后的变招；限制破坏军用能力与全歼是不同目标 | 强力机仍可编成，政治立场影响哪些战役可同队，不等于数值性格随机拒令 |
| 火种变形者 | 同一主体不同形态的通路、速度、火力与转换位置，地图需真实提供用途 | 变形不是只在入场动画发生，伙伴也不烧成领袖一项支援技能 |
| 三相盖流 | 形态差异和换形时机、分离暴露与再接合、主驾驶变换带来的战法 | 后继百米形态在适用战域持续可用，不每次都靠失控触发 |
| 迟归一号、天盖王、遗灯 | 舰队级火力区与通道、突破大型结构、保护本机保障与家属船；尺度应改变战场而非只放大立绘 | 自有补给与部署，不能塞进万机馆，也不降格成全图一次性按钮 |
| 万机馆/万机殿 | 主舰独立人形的进攻、出击与接应；末战实际换接自愿退出的构件 | 操作与演出均区分舰形、人形、万机殿；暴走不等于可无限使用的强化模式 |

表内是玩法方向，未更改当前核心玩法总案的规则、数值与单位预算，也未批准更多独立地图或高成本动画。选出代表战斗试玩后再决定实现粒度。

失败、保存、重试都必须保持真实软件可恢复性。普通重试不产生被杀掉的平行机魂，不用现实离线时间惩罚角色。固定故事结果与可争取的结果要在关卡开始前让人有足够理解。

## 五、Meta：现在能验证什么，还不能声称什么

本稿选择的是**一个陈列窗口变成双方都能试探、拒绝的会面空间**。它不是全部界面突然属于某幕后主机，也不把此前战斗降为实验。

| 进展 | 玩家以为在做什么 | 新证据与实际操作变化 |
| --- | --- | --- |
| 稳定收藏 | 整理自己的展品 | 先有真实乐趣；摆什么不产生道德审判 |
| 发现响应 | 看个性化档案画面 | 只重现玩家实际留下的摆法；无记录者从本次可选操作建立第一个样本。陌生物由另一边先加入；不操作不补造历史 |
| 进入可操作参照 | 片库多出可选择的“桌面参照”，点开后使用熟悉的旋转查看 | 操作被传达为请求，对方伸手后又被同伴按住；物件未转、画面仍活着。退出近景回到真桌全景，再关闭可返回正常收藏 |
| 双向试探 | 验证这不是一段按菜单播放的录像 | 根据真实移动、姿势或初次试探提出相应问题。白鸢可能误认其意思，但玩家可纠正，后续必须改变理解；喜欢官方姿势不等于要求活人照演。查看误作允许拆开时可撤回 |
| 实际协作 | 帮其取得自己已有的答案 | 馆外参照仅补一部分，现场必须核对并采取行动；可以拒绝，由较慢替代方案继续 |

后台作者需要承认的最小事实：变化只涉及这一个有限馆外联系；对面是归航档案工作室的真实设备与人，摆件由对方操作，非塑料直接操纵巨机；只读取本游戏已产生的陈列/观察交互，不读现实隐私；联系中的人物可知有限操作，不能知玩家全部思考。具体观察必须对应可回看的动作记录，不以机体人气、角色主配角、停留时长推定喜欢、厌恶或命令意图。

| 实际输入情形 | 可以出现的故事反应 | 绝不能冒认的事实 |
| --- | --- | --- |
| 确实重现过海报/官方姿势 | 指认这一个姿势并询问意义；可以回答只喜欢模型，白鸢收起重拍假设 | 不概括成永远只要主角、要求演员服从或认同主体替换 |
| 将配角/冷门机放在前方 | 对这台机及这次位置变化发问 | 不套“总将配角放角落”的旧对白 |
| 自由改造、按颜色或构图排列 | 比较看得见的外观/位置变化，允许询问但不先给道德解释 | 不从外观推断政治立场、恋爱或人物控制欲 |
| 从未使用陈列台 | 提供本次可选试探；只在实际操作后回应该动作 | 不生成一段以前的收藏史、不默认玩家有最喜欢的机体 |
| 不回答/始终不操作 | 当前个人接触不发生或停止；普通剧情、收藏和安雅接应仍可继续 | 不以沉默推定同意，不扣除固定主线资格 |
| 玩家纠正档案员/白鸢的误认 | 角色承认并改用已确认的解释，后续引用也随之更新 | 不接受纠正后仍在高潮复述原来的指控 |
| 关闭联系后继续摆放 | 正常收藏变化不再传到工作室 | 不让关闭成为假退出；重开也不能补传未经选择的整个关闭期记录 |

这里需要记录的是具体动作与玩家是否作过解释，不是一套暗中的人格标签。后续档案协作只使用当事玩家已有资料；初次来者可比较现场实际提供的材料，不凭空获得收藏知识。尾声合照只在已经建立联系且实际选择后添加模型，不替未参与者伪造一次致意。转入正式解构前至少试验这七种情形，并检查无收藏、只爱配角、官方姿势爱好者、关闭后改摆四种反例。现在只是明确测试输入和预期，尚未执行原型测试。

Full/Skip/退出与恢复须遵守同一事实：已发生的响应和拒绝保留；关窗口不删除对方的人生，也不锁死正常收藏。跳过演出保留已经作出的同意、拒绝或尚待回应状态，不替任何一方补选答案。未发生的协作不会因重开界面被写成已经帮助过人。这里是待验证的操作约束，不是已有实现。

**这项有限双向寻址仍是新Candidate机制。**正文写出了体验提案，不等于已经证明震撼、可实现或已与每条根机制完成正式迁移。须在其进入Reader前核对一个问题：当前G.A.G.与馆外响应如何支持这个特定窗口，而不推广成所有屏幕都能泄露私人想法。若无法限定，不以增加一套宇宙主机补救，应收窄到仍可解释的部分并重试。

最小交互原型将测试：去掉解释文字后，是否能辨认“我以为只是我的陈列，原来双方一直在建立参照”；拒绝是否真被接受；它是否比普通远程任务多一次可感的观察位置变化；既有战棋控制与真正退出是否仍可靠。**当前没有制作或运行原型。**不能只凭梗概将这一项写为效果已通过。

### 归静不借Meta代解

实际发送者始终是人、机魂或某个具体异文明个体。远星不生成目的地、不替船队计划、不发任务。外线先发现原始声音经短窗失去个体差异，近距/实体原文仍在；换译码设备无效。随后从零星恢复又失去，发展到同一段联系连续容下拒绝、改意和不同去向；异地原始记录表明，部分恢复早于终盘这一次护送。持续接触中发生的外部变化可被观察，不能据此证明单场善举已经解开宇宙问题。

玩家可以护送实体记录、核对现场与来信、协助接应。可归因于玩家的成果是保住当事者的真实选择、送达不同目的地、取得证据；宇宙尺度恢复不能由完成该任务直接触发。归静缓解与政治终局交错，全面战争路线也保留外线接触。

24号将情绪闭合交给已经认识的安雅与伊莎贝尔：接替、临时折回、真实请求被单独听见、按新班次归来。玩家不得替安雅选择牺牲或返乡，也不因拒绝Meta协作便被取消这条人物线；可做的是帮助及时核实与保障她的选择。她们终于相见是有限、可证的结果，远星改变的全部原因仍未知。其情感效果尚须成文冷读，不宣称宇宙终局已被验证为感人。

## 六、规模与制作负担

保留所有素材的参考价值，不承诺77条机体/驾驶包全部以相同剧情容量出场。本稿已有主场者需保住自己的故事，客演与轮换不能自动提高为全程主力；未被选中的原作剧情留在储备，不能靠片尾名单假称已经采用。

角色、普通机体、中型机、百米巨机、千米阵地体分别采用适合的战域。战棋表达可以抽象，但故事里的万机馆不能把二百米身体塞进现有机库。大型战场允许滚动与局部切换，建筑和重要设施属于地图的可作用部分，不只是背景。

两条长路线意味着真实写作与资产成本。可复用同一地区不同阵营到达状态、同一套敌人动作、归航会合后的基础地图；不能用同一段对白掩盖角色经历不同。没有算过的动画、人日、性能与完整路线测试一律视为未测，不因概要较清楚就宣称成本已降低。

下一步在用户选择故事方向后，先按自然发展分章，选一段典型战斗与一处分支做详细解构样板，再决定全局制作范围。当前不启动C01 Demo以外的新制作，也不要求它等待本稿。
