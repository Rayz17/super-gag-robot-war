# V35 C02四话拓扑恢复与Current Canon迁移

> Date: 2026-07-26  
> Scope: C02章级场景拓扑、未发售样件首登、复产开放日  
> Authority: Working migration

## 一、迁移原因

2026-07-24的三话收敛把规则拳赛、机械拍卖巨台与复产开放日并入C02E03。C02进入正式L4预生产后，四席审查确认该结构会造成三类问题：

1. 一话连续承担规则拳赛、巨台Boss、白鸢肉身到场、开放日经营、清仓鲸防卫和登舰关系场，无法形成清楚的玩家目标与情绪休息。
2. 拳馆/巨台与开放日/清仓鲸使用不同地图、单位尺度、玩法和资产，本来就不能靠合话节省有效制作量。
3. 白鸢会在同一话完成到场、能力教学、伦理冲突、关系建立和登舰，人物进入过快；旧拳王的完整胜利也会立即被下一场大战盖掉。

L3容量已同步校正：C02、C03各扩为四话，C21收束为一话，全剧容量上界由85话改为86话，章数、章节职责和终局容量不变。

## 三、设定同步

1. 未发售变形样件是从制造时起即为两米级的全尺寸工程原型。E01在工业测试架上首显，E04第一次自行解除运输固定；玩家短时控制它取回原主人留下的旧控制器、爬上清仓鲸抓臂并打开检修口。它从未由收藏玩具放大，控制器也不是人格开关。
2. 复产开放日的正式场景是C02E04，不再记在C02E03。
3. 白鸢在E02远程发出权利申诉，E03末抵达木桶街，E04完成第一次现场L1预演并登舰；她没有战斗改写席。
4. C02E03只结算旧拳王、影子陪练、百刃、机械巨台和外泊校正架，不提前结算复产网络、白鸢登舰或工务城通行。
5. C02E04保证最低一条复产线、公共港测试与工务城主线通行；额外开放日战果只改变C03资源档位。
