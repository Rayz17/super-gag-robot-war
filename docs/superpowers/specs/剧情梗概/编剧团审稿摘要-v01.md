# 编剧团审稿摘要 v0.1

> 本文记录本轮“全游戏逐话剧情梗概”的审稿结论。它不是设定正文，作用是说明为什么采用46话结构，以及后续台本展开时要守住哪些边界。

## 1. 审稿分工

| 职能 | 审稿重点 | 采纳结果 |
| --- | --- | --- |
| 话数与节奏审稿 | 72个场景块如何压成商业版主线话数 | 采纳46话结构：C01/C02/C05/C06/C07为3话，C03/C08/C09/C11为4话，C04/C10/C12为5话。 |
| 玩法与分支预算审稿 | 分支是否会把剧情、道具、线索网络拖爆 | 采纳“每章一个主内容图”；大多数分支只改变战斗起手、证据完整度、援护窗口和战后反馈。 |
| 机设与万机馆连续性审稿 | 万机馆空间、展品、机体谱系和泊位是否连续 | 采纳每章最低展区/谱系锚点，保留留言墙、右臂旧件、模型病院、跌跌失败记录、0号侧廊、B1机库和空白展柜等回收线。 |

## 2. 为什么从50话压到46话

50话虽然仍在商业蓝图上限内，但中段会显得像“每个场景块都升格成一话”。46话更稳：

- C02、C05、C06、C07压成3话，避免模型街、战争章、作者章和原典章拖成重复讨论。
- C08保留4话，足够承载清算都市的秩序诱惑，但不让企业阴谋扩成全网。
- C04扩成5话，因为雾生主体性和远星首次明确转折都需要独立落点。
- C10和C12保留5话，因为远星理解和终局结算的信息密度最高。

## 3. 后续台本红线

- 梗概不是台本。后续台本必须逐话展开，不要跨多话批量写对白。
- 每话只能有一个玩家主要目标和一个情绪落点。
- C06不能发展成“玩家任意改写剧情”的系统。
- C08不能把企业写成纯恶，七海不能突然倒戈。
- C09不能只讲AI大道理，必须用镜像战术、UI修正和完美档案馆压迫玩家。
- C11不能让每个离队角色都膨胀成独立大路线。
- C12只回收，不新增大模板；结局分流不能变成乘法爆炸。
- 万机馆不是菜单基地。C02、C03、C06、C07、C09、C10每章至少要有档案终端、展柜证物、泊位状态、战后展陈或留言回收动作，把剧情拉回万机馆。
