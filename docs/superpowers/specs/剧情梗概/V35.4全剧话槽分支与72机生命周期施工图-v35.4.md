## 一、本轮解决什么

1. 把十八章的82个作者话槽逐一命名，明确每槽的玩法、机体、剧情反转、状态变化和下一槽逻辑。
2. 把六个旧分支窗口细化成九组实际游玩组合，明确玩家会经历哪些不同话槽。
3. 把72台可操作收藏逐台分配到首见、首控、正式加入/状态锁、C12分舰与终局回收。
4. 把班主任潮牺牲、纪存失忆、七海双身份、白鸢三态、馆长审判和参战规模写成50个跨章传播节点；V35.5新增七海C01现场撤令到C08制度断裂的两级传播。
5. 规定未走路线的机体、人物和事件如何保留失败尊严，不让内容从世界里消失，也不让隐藏关替主线补规模。

## 三、分支不再只是变量

### 1. C04身体来源

玩家不是在同一场战斗里选一句“相信工房”或“相信现实机器”，而是经历两话完整路线：

- 工房路线进入母版夜潜和替代身体同步战，得到后继接口、白鸢早期信任与军工样本债。
- 拒绝路线进入拒绝部署和低规格机器接管防线，得到拒绝协议、陆衡/工务支援与灰模损坏。
- C09不把差异抹掉，而是分别进入“替代身体记得谁的痛”或“说不的人也在守城”，最终都抵达班主任潮被删除的大败。

### 2. C05、C07、C08与C13任务组合

任务组合不是六选四之后只结算数值。每个未走槽都规定后续形态：敌方、损坏支援、独立盟军、后来者代收、EX补救或路线缺口。玩家仍能看见该谱系，只是没有获得同样的关系与控制资格。

### 3. C10和C12硬分线

C10公审与撤退城使用不同地图、章节主角、Boss处理和政治组织；C11只让他们来到同一个百机祭，不让他们变回同一种幸存者。

C12合法托管与非法脱页各有两槽完整剧情。合法七海保住医院、城市入口和司法链，却亲手扣押纪存；流亡七海保住机魂主体和未完人，却失去身份、医疗与靠港。C13-C16继续读取两种资源、敌我颜色和政治资格，直到C18才分别导向不同制度结局。

### 4. C16开馆内战

六战区不设置显眼善恶答案。每条路线都先证明自己真能解决问题，再暴露会伤害什么。玩家走四区，另外两区由相关角色自行作战，并成为C17完美假馆最精准的诱惑以及C18万机殿的真实缺口。

### 2. 为什么后半程不继续每话硬塞两台新主力

72台可操作收藏只是机战规模的一层；全剧还需要35至45台具名敌机/Boss和20至30台具名NPC/支援机，合计110至140台可辨认机体。后半程的重点从“不断入队”转为：

- 早期机体取得新形态、合体位置、驾驶/机魂关系和政治归属。
- C12把阵容物理拆散，玩家真正失去部分熟悉单位。
- C13-C15补足宇宙、未来与行星工程新气质。
- C16让熟悉同伴作为路线Boss或独立阵营出现。
- C17-C18用已有伤口、失败动作和关系历史反制完美模板。

如果每个终局槽仍只靠两台陌生机入队制造新鲜感，前面六十多台就没有生命周期，只是一长串首登名单。

### 3. C12后三舰不是三个仓库

- **中央残舰**：纪存、陆衡/方舟T、现实机器、部分三相与馆体核心，负责路由、迟到通信和万机馆身体。
- **七海护航群**：合法线拥有医院、公共系统和正式舰队；流亡线拥有灯槽、混编机与主体保护，但没有相同补给和靠港权。
- **作者驳船**：白鸢三态、灰模接口、同步/岛卫幸存者、未完人和创作者工房，可能是盟舰、匿名网络或敌对避难区。
- **独立声部**：红面具、铁棺、兽盟、撤退军、未来追猎和部分路线机不强塞进三舰，保留自己的政治与补给条件。

## 五、关键人物命运的连续传播

### 班主任潮

C04先让他承担“允许学生拒绝出击”的现实军事失败；C09先用普通一天建立关系，再让他主动站进成年责任空位并被城市重置删除。C10学生仍会使用他的教学动作，C11百机祭留下无人能解释的空椅，C17完美潮命令学生出击，因此被识破为假。终局最多恢复记忆、残响或教学支援，不无损复活。

### 纪存

他的记忆不是谜语碎片，而是逐步升级的能力和危险：C01读出旧路由，C04使用未公开停机口令，C12越权救舰也暴露唯一管理员风险，C14救白鸢而失去馆长命名他的私人记忆，C16只能依据证据审判馆长，C18公开牺牲计划并重新选择自己的名字。

### 七海

C01先撤销一条会造成人命伤亡的现场断电命令并公开签责；C08再撤销整套合法镇压权限，失去代哥执法安全位。C11取得公共信托的真实胜利，C12才有资格承受合法/流亡硬分。两条线在C13通信、C14未来追猎、C15远星裁决、C16路线Boss和C18制度结局中拥有不同资源和正当性，不以停火或恋爱自动合并。

### 白鸢

C04以能救人也会替人决定结局的创作者入队；C09烧伤优势手和视觉神经并被冻结署名；C12按合法/非法路线进入不同政治状态；C14锁定当面协作、无署名救援或创作者避难Boss三态；C16必须取得独立事业结果，之后才拥有C18关系结局资格。

### 馆长

C01仍只通过录音、钥匙和旧路由存在。C11出现窄带签名，C12只能解开一层托管，C14借旧目录机得到临时身体，C16公开封闭机魂避难区和静音合并新生机魂的旧罪。终局只能受审留下、降为普通馆务残响或完成交接后消散，不能重新成为万机馆主人。

## 六、制作与写作边界

1. `v35_4_author_slot_route_architecture_v35_4.tsv`是逐章拆话的唯一槽位入口；不能再从V35.2章段平均切话。
2. `v35_4_unit_lifecycle_slot_allocation_v35_4.tsv`负责72台可操作收藏的生命周期；首见、首控和加入不是同一件事。
3. `v35_4_playthrough_route_combinations_v35_4.tsv`负责单周目实际组合；互斥槽必须分别写稿和制作差异。
4. `v35_4_decision_branch_state_propagation_v35_4.tsv`是C09以后Episode Input Manifest的强制状态来源。
5. 每台可操作机仍受V35.3的26旗舰、32标准、14有限制作约束。共享技术家族不共享角色轮廓和招牌动作。
6. 缩尺模型、玩具、母版、展签和关系锚件不计入72台；“无牌一号”能占格，是因为三件一许可完成后对应的是全尺寸竞技实机。
7. 逐话阶段仍需重新选择IP名场面、台词锚、燃泪梗、玩法细节和关系场面。本稿只锁故事位置和状态，不冒充厚梗概。

## 七、下一阶段

V35.4通过审稿后，从C01开始按章生成Pressure Board。每次只把该章的槽位、相关机体生命周期、决策传播节点和素材池行送入单话Pipeline；完成一话再推进下一话。章末按Episode Loop进行前序连读，发现根因在旧章时按三轮上限回滚，并把未解决问题写入账本。

第一批最适合做C01-C03开局压力板，不直接写台本。目标是验证：18个早期可操作收藏不会造成入队流水账，万机馆闭馆路线足够吸引机战玩家，纪存/七海/唐胶/兜灯/豪司与白鸢前置能够自然连续，百机祭目标不是第三章突然宣布。
