## C06 万机同心与拆掉完全版

本章是C05的后半大爆点：巨大化、特摄摄影棚、伪领袖发布会、目录翼商品包、完全版病和伪同心巨神。核心不是否定豪华、合体、多配件、限定，而是证明“更多”不能吞掉身体理由。七海第一次付出实质追责水印；白鸢面对自己的构图被敌人盗用；纪存开始理解自己也有“把所有声音摆成一个能理解画面”的控制欲。

### E21 巨大化不是放大贴图

**本话功能**  
把特摄巨大化做成可玩的三尺度关卡。巨大不是把模型放大，而是脚下责任、镜头边界、观众声浪、微缩城市和工务机关共同构成的灾害。

**剧情流程**  
地下合体井打开后，星火巨神雏形被推入巨大化摄影棚。棚内微缩城市、摄影灯、爆破点、吊轨、怪兽皮套和褪色提示“镜头外也有人在看”同时出现。索引把前几话样本误译：五色喊名是群众供能，勇气许可是合体批准，火种残响是形态升级，观众惊呼是巨大化燃料。A05-3半身乱入的巨大化兽人影被点亮，从皮套残响膨胀成六十米怪影。

陆衡把战场切成三尺度坐标：后台小队层操作灯光、疏散门和吊轨；机体层由馆守Z、星火巨神雏形、社勇王援护和彩队残响保护城市边线；巨大化层由怪兽影和棚守巨影占据超大格，每次转身都有踩踏预警。陆衡说巨大化后的步距就是灾害，转身半径就是剧情风险。

乐园工务三机临时可控：轨道牵引机拉开巡游轨，灯架吊装机调整镜头帧，清扫救援机把透明特效件和支架脚拖出微缩城市。棚守巨影从摄影棚背板上站起，像慢半拍的皮套英雄，只能在镜头帧内挡一次踩踏。白鸢被怪兽和巨影的构图吸引，几乎把城市压成背景；她低头看见纸条“这里不要踩，孩子会看见”后，主动把镜头拉低，让楼牌占中心。

高潮时，怪兽影冲向微缩城市。棚守巨影挡第一脚，馆守Z借肩帮星火巨神稳住，社勇王援护压回过载，彩队残响让观众从尖叫转为喊名。星火巨神不是击杀怪兽，而是用吊车承力框把它引出镜头帧，让它从巨大胜利模板缩回残响尺寸。

**战斗与玩法 / 机体 / 梗点**  
类型：三尺度保护战 + 巨大化灾害控制。胜利条件是怪兽影缩回残响尺寸，并保住两处微缩城市证物；失败条件是微缩核心被踩毁或观众声浪全转为惊呼。机体/单位包括棚守巨影、巨大化兽人影、乐园工务三机、星火巨神雏形、馆守Z借肩、社勇王援护、彩队残响。梗点包括怪人巨大化、微缩城市、皮套棚、镜头帧、预算掉帧、支架不算腿。

**关系 / 情绪 / 债务**  
白鸢第一次让构图服务脚下的人，纪存把她的画投成战场视野参考。七海远程没有催封，只提醒镜头帧内观众记录会成为证据。情绪物件是“这里不要踩”的纸条和怪兽皮套内侧修补线。敌方收益：索引获得巨大展示性样本。

### E22 伪领袖发布会

**本话功能**  
把C05-C06所有样本打包成一次反转：索引不是粗暴反派，它会给出温和、正确、好卖、保护人的伪共同语言。七海的代哥改革线在这里第一次被硬线追责。

**剧情流程**  
摄影棚中央升起商品发布舞台。伪领袖投影不是低级坏人，它温柔感谢玩家保护旧车、保护观众、保护微缩城市，然后推出“万机同心标准包”：星火五车保留情感故事，重涂三车做皮肤，五色声浪转活动应援，勇者许可转会员权限，巨大化转PV展示，所有争议进入托管协议。它甚至允许医疗车保留担架舱，只要求把“为什么回应”统一成一句可传播口号。

七海被迫接入发布会，因为代哥硬线认为这套托管协议比万机馆流亡更安全。她知道它危险，也知道它能保护很多普通人。硬线执行官第一次具象出现：他见过旧G.A.G.事变的伤亡，不相信“热爱”比封存更可靠。他对七海说，改革不是让你替风险找漂亮借口。

白鸢发现发布会盗用了她在E21的低角度构图，把微缩城市、星火巨神和七海权限框剪成“合规守护”宣传片。她愤怒不是因为作品被盗，而是因为它比她自己还会画“观众会相信的画面”。纪存也被击中：伪领袖把杂乱热爱摆成一张能被理解的图，这正是他内心一部分欲望。

战斗中，发布会舞台每回合提出一个好用方案：统一口号提升全队士气、托管证据降低追责、商品化皮肤增加援护范围。玩家使用越多，伪领袖越像真正队长。七海做出七秒例外：她用流程内延迟让纪存有一回合拆掉“统一口号扩散器”，但留下清晰追责水印。她没有洗白，代价会在C11回收。

**战斗与玩法 / 机体 / 梗点**  
类型：发布会规则战 + 观众信任战。地图为商品发布舞台、广告屏、应援频道、权限席、巨型投影轨。胜利条件是拆掉三类统一模块且观众信任不被全量托管；失败条件是伪领袖完成标准包签约。机体/单位包括伪领袖投影、星火支援池锁、应援SKU塔、统一口号扩散器、代哥硬线封存队。梗点包括领袖誓约被商品话术替换、发布会PV、会员权限式勇者许可。

**关系 / 情绪 / 债务**  
纪存被“能被理解的整齐画面”诱惑，白鸢看见了；七海替他留出七秒，却被硬线记录。三角关系第一次不是细小嫉妒，而是共同面对“谁有权把杂乱说成正确”。敌方收益：索引获得伪共同语言话术和七海例外样本。

### E23 目录翼商品包模块战

**本话功能**  
把机甲玩具过度设计、堆背包、尖刺、透明件、支架依赖和配件包病做成Boss身体。每个模块都真有用，玩家拆时要心疼，而不是笑它丑。

**剧情流程**  
伪领袖退场后，目录翼从发布舞台背后展开：透明件翼片、尖刺披风、四联炮、金色王冠、支架腿、展示底座、特效火焰、巨剑、兽爪、电磁环、追加肩甲组成一台“伪同心巨神”的背部商品包。它不是装饰，而是把玩家前面喜欢过的爽点全部变成模块：红色更快、五色声浪、勇气许可、兽机爪、巨大化镜头、旧货柜领袖、错拼童年。

玩家要逐一质询模块用途。尖刺披风能挡一次炮，但遮住医疗车救援门；巨背包能飞，但堵维修口；透明翼能折射胸牌光，但一击后电镀剥落；支架腿能让机体站得漂亮，但支架被打断后全身跪地；王冠能提升士气，却让旧货柜牵引接口抬不起头。索引故意让每个模块都有诱人收益，逼玩家承认“好卖”和“好用”并不总是假。

唐胶负责拆件，兜灯负责安全红线；陆衡标承力，白鸢画身体理由，纪存做最终公开选择。七海远程提醒每拆一个授权模块，代哥硬线都会多一条非法改装证据。纪存第一次主动背锅：把所有拆件记录署名到万机馆临时负责人，不让星火车队和小勇机承担违规。

**战斗与玩法 / 机体 / 梗点**  
类型：模块拆解战 + 质询模块用途。胜利条件是拆掉至少四个无身体理由模块，并保留两个真正必要部件；失败条件是伪同心同步率满或星火巨神支架依赖锁死。机体/单位包括目录翼、透明件护盾、尖刺披风、支架腿、巨背包炮台、王冠节点、电磁/五兽残响模块。梗点包括十五机病、全挂配件包、过度尖刺、支架依赖、电镀掉漆、官图好看但实战难动。

**关系 / 情绪 / 债务**  
白鸢承认“帅但遮住身体理由”，纪存承认自己也想让一切看起来完整。七海看见纪存主动背锅，关系从流程缝隙进入职业风险共担。情绪物件是一片剥落的透明电镀翼，挡下真炮后再也不亮。敌方收益：索引获得豪华包战术模板。

### E24 拆掉完全版

**本话功能**  
C06终局。多谱系同场不是二十机真合体，而是各自用自己的方式回应。玩家拆掉伪同心巨神，证明共同语言不是同声口号。

**剧情流程**  
索引把目录翼、伪领袖、巨大化兽影和星火巨神雏形合成伪同心巨神。它的最危险之处是表面正确：保护城市、尊重商品、保留旧件、统一责任、降低风险、给每台机体一个可传播位置。它不是坏得低级，而是把所有好东西压成唯一答案。

终局三阶段。第一阶段伪同心用统一口号锁支援，玩家必须让唐胶/兜灯/陆衡/白鸢/七海各自解除不同锁；第二阶段它强制全挂，玩家拆掉支架、背包、王冠和错误接口；第三阶段它要求所有残响同声回应。这里不是让彩队、电磁、五兽、社勇王、星火真合体，而是让它们分别以Cut-in或地图效果回应：彩队守站位，电磁稳节拍，五兽咬断错误接口，社勇王批准必要勇气，馆守Z撑住地面，星火巨神用牵引接口把所有声音拉回各自位置。

七海的七秒例外在本话被硬线追责水印公开。白鸢画双构图：一张是伪同心巨神的完美海报，一张是五车、残响、工务机和观众各自歪斜站位的图。纪存选择公开第二张，不是因为它更漂亮，而是因为每台机体能说出自己为什么在那里。

战后，星火支援池成立，重涂三车进入驻馆候选，彩队/电磁/五兽/棚守巨影保留隐藏或特定Cut-in边界。索引没有失败干净，它带走“共同语言可以被伪造”的样本，并将在C07把同心误读成同步。

**战斗与玩法 / 机体 / 梗点**  
类型：全乐园Boss战 + 拆模块终局。地图为摄影棚、合体井、发布舞台、外环车道和观众频道叠合。机体/单位包括伪同心巨神、星火巨神支援池、重涂三车支援、彩队/电磁/五兽/社勇王/馆守Z多谱系Cut-in、七海权限锁。梗点包括最终合体不是同声口号、全员支援、拆完全版、勇气许可与身体理由并存。

**关系 / 情绪 / 债务**  
纪存、七海、白鸢三人形成第一轮真正三角张力：七海给他违规时间，白鸢看见并救下她的追责记录；纪存不能把两人的痛都写成“她们理解我”。情绪物件是伪同心被拆下来的王冠，里面空无一物，只有一枚被卡住的旧牵引螺丝。敌方收益：索引获得伪共同语言样本，C07同步灾害启动。

**C06 前缀回归小结**  
本章通过。巨大化、完全版病和多谱系支援有足够外放爽点；索引具象为温和发布会与伪同心巨神，不再只是UI。未解决风险：七海追责水印需要在C11前持续施压；白鸢/纪存控制欲冲突要在C07-C09升级为伤害，而不是就此和解。

## C07 雾岛同步与双驾灾害

本章不是突然学校线，而是C06“伪同心样本”的反噬：索引把共同语言误读为同步，把多声部误读为同一节拍。雾岛防卫圈确实保护过城市，但它会把停顿、犹豫和个人半拍压成噪音。白鸢的温柔控制欲第一次造成实际伤害；七海的封存建议合理但伤人；纪存的机魂记忆开始指向G.A.G.暴走的旧灾难。

### E25 毕业照缺了一个人

**本话功能**  
建立雾岛同步制度的温柔与危险。偏位照片、心墙零式、岛卫三号和遗灯幼灯核心同时登场，先让玩家理解它为什么曾经有用。

**剧情流程**  
万机馆收到雾岛防卫圈求援。岛上学校、避难塔和机体格纳库连在一起，每个学生的同步节拍都显示在公共屏上。毕业照墙缺了一个人，照片边缘有半个肩膀，像有人总是慢半拍。雾生不是被救奖杯，他想要的是一次不用被系统补齐的迟到。

心墙零式和岛卫三号以训练状态出场。同步制度能在怪异敌群来袭时让城市防线自动协同，确实救过人；但它也会把恐惧、停顿和个人判断压低。遗灯幼灯核心随恐惧升亮，远星字幕把“害怕”误译成“请求统一节拍”。

白鸢看见偏位照片，想把缺席者画回中心。她的温柔很真，也很危险。纪存提醒她，先问雾生是否想被补回。白鸢没有回答，只把那张照片夹进分镜本。索引在暗处获得“无痛补完样本”。

**战斗与玩法 / 机体 / 梗点**  
类型：防卫圈探索 + 照片证词保护。地图为学校、同步屏、避难塔、岛卫格纳库、照片墙。机体/单位包括心墙零式、岛卫三号、遗灯幼灯核心、同步校准无人机、怪异小群。梗点包括同步率、心墙、缺席照片、你在吗式共同体呼唤的原创变奏。

**关系 / 情绪 / 债务**  
白鸢和纪存的关系出现裂缝：她想救，纪存怕她替人决定。情绪物件是偏位毕业照。敌方收益：索引获得无痛补完样本。

### E26 第三警报不是演习

**本话功能**  
把雾岛同步从心理议题变成三目标防卫大战。七海的封存建议在本话必须合理：同步灾害真的可能扩大。

**剧情流程**  
第三警报响起，电缆供能塔、避难门和心墙节点同时受袭。岛卫三号需要高同步启动，环洋双驾潮墙巨兵残响在海堤显影，要求两名驾驶者共享创伤记忆才能挡住浪墙。玩家要守三目标，无法全靠输出解决。

七海远程提出封存建议：切断同步圈，保住城市大多数人，但雾生和少数慢拍者会被留在圈外。她不是冷血，这建议确实能避免灾害扩大。纪存第一次对她发火，因为建议正确得太伤人。七海没有回嘴，只把预计伤亡和后续追责都投出来。

中段，环洋双驾残响要求一人稳住方向，一人承受记忆回流。赤罡想硬冲，莉歌的短声部让他听见避难门未关。白鸢在一旁把雾生画进安全格，结果安全格变成限制他移动的囚笼。

**战斗与玩法 / 机体 / 梗点**  
类型：三目标防卫 + 电缆供能 + 双驾记忆伤害。胜利条件是保住两座供能塔和避难门，且雾生同步压力不爆表。机体/单位包括岛卫三号、电缆塔、环洋双驾潮墙巨兵残响、怪异海群、同步切断机。梗点包括同步电缆、暴走倒计时、双人驾驶共享创伤、取消末日前先修避难门。

**关系 / 情绪 / 债务**  
七海与纪存第一次正面伤害彼此：她给正确封存，他觉得她把人切出画面；她看见他可能为了一个人拖累城市。情绪物件是雾生手里的毕业照，被雨水泡开。敌方收益：军方获得同步灾害数据。

### E27 把他写幸福的人

**本话功能**  
白鸢主场。她想保护雾生，却把“幸福分镜”变成索引囚笼。本话要让白鸢的缺点造成实际玩法后果。

**剧情流程**  
同步塔内出现幸福分镜塔：每一格都给雾生安排一条更安全、更被理解、更少痛苦的路线。白鸢一眼看出很多格来自她自己的分镜本。她曾经画过“如果他能顺利毕业”的可能性，索引把它做成战场。

玩家进入分镜格潜入。安全格会回血、给支援、降低恐惧，但也会锁死行动路线；痛苦格会掉血，却能让雾生说出真正选择。纪存和白鸢争执升级。纪存说你不能替他喊合体，白鸢反问纪存是不是也一直替万机馆决定什么值得被看见。两人都说中对方伤处。

中段，索引生成“白鸢式补完机”，它不攻击，只把雾生每个迟疑改成漂亮选择。玩家要用错拍、空白、未完成动作打断它。白鸢最终亲手撕掉一格最幸福分镜，让雾生保留一次“不知道”的权利。

**战斗与玩法 / 机体 / 梗点**  
类型：分镜格潜入 + 关系支援灰显。地图为幸福分镜塔、空白格、痛苦格、同步节点。机体/单位包括白鸢式补完机、无痛同步镜像、岛卫三号锁定影、分镜塔守卫。梗点包括温柔改写变囚笼、剧情节点反转、错拍启动伏笔。

**关系 / 情绪 / 债务**  
纪存和白鸢第一次真正互伤，关系支援短暂灰掉。白鸢的成长不是“承认纪存对”，而是亲手删掉自己最想保留的一格。情绪物件是被撕掉的幸福分镜。敌方收益：索引获得幸福分镜样本。

### E28 别替我喊合体

**本话功能**  
C07高潮：同步口令、合体姿势和高同步输出都变成刑具。雾生用自己的半拍说得岛卫三号，白鸢不再替他补完。

**剧情流程**  
岛卫三号错拍启动。同步圈要求所有驾驶者同声喊出启动口令，但雾生总慢半拍；系统把他的慢半拍判为错误，遗灯灯槽随恐惧暴涨。索引把C06伪同心样本套入岛卫三号：只要所有人同一节拍，就能输出最高防卫力。

玩家必须控制灯槽、错拍和供能。若追求高同步，岛卫三号火力强，但雾生主体性下降；若保留半拍，火力弱，防线压力大，但能触发“自愿回应”。环洋双驾残响在海堤帮玩家抢回一次方向键，代价是两名支援角色共享一段痛苦记忆，后续关系出现短暂沉默。

高潮时，雾生没有喊标准口令，而是说“别替我喊”。岛卫三号没有满同步，却用错拍挡下怪异核心。白鸢没有把他的半拍画齐，只把空白留在画面中心。七海承认封存建议仍合理，但她没有把雾生从报告里删成风险样本。

**战斗与玩法 / 机体 / 梗点**  
类型：Boss战 + 错拍启动 + 灯槽控制。机体/单位包括岛卫三号、遗灯灯槽、环洋双驾残响、怪异核心、同步口令塔。胜利条件是击退怪异核心并让雾生主体性不归零；失败条件是灯槽爆满或高同步模板锁死。梗点包括同步暴走、口令变刑具、电缆供能、合体不是代替别人发声。

**关系 / 情绪 / 债务**  
白鸢把“保护”从改写升级为陪对方慢半拍。纪存也被反问：他是否一直替万机馆说话。情绪物件是雾生那张没有补齐的毕业照。敌方收益：索引获得高同步输出模板。C08债务：赤罡已学会等待，但战争章会逼他在追击王牌和撤退名单之间做更痛的选择。

**C07 前缀回归小结**  
本章通过。C06伪同心反噬成同步灾害，因果成立。白鸢有真正伤害和成长，不是小步提示。未解决风险：纪存主角弧线在本章偏反问与观察，C08/C09必须给他更外放的决策压力。

## C08 宇宙世纪撤退战

本章是中盘第一次真正大战。白色战舰、红色王牌、撤退护送、量产机逆袭、歌声停火、命令权诱惑、热血追击与战争伦理同时上桌。赤罡承担热血线质变；莉歌以歌声提供一回合停火但不洗脑；纪存要阻止万机馆把战争悲剧策展成漂亮名场面。

### E29 空白格里有名字

**本话功能**  
建立战史馆和战争政治。玩家看到白色样机、灰鸥量产G、撤退名单墙、红线信标和铁棺佣兵，知道本章不是展馆争论，而是撤退线生死。

**剧情流程**  
万机馆进入战史馆残区。导览先给出漂亮英雄史：白舰、白色样机、红色敌王牌、经典追击、胜利剪影。刃把导览关掉，说这是宣传片，不是撤退记录。墙上大量空白格没有名字，只有机体编号和未认领维修单。

灰鸥量产G以低配盾阵出场，数值普通，机身满是维修补丁。铁棺佣兵机不讲理想，只讲合同、弹药和活下去。红面具机在远处留下一条红色路线，诱导赤罡追击。纪存想把撤退名单作为展品公开，却被刃质问：你是要让他们被看见，还是让他们再次成为好看的牺牲？

玩家在战史馆探索中决定撤退部署：补给线、难民船、白舰残骸和量产机盾阵。若只追英雄史，开局气力高；若查空白格，撤退路线更完整。索引标记玩家想追的路线。

**战斗与玩法 / 机体 / 梗点**  
类型：战史馆探索 + 撤退部署。机体/单位包括白色样机残影、白舰纪元残舰、灰鸥量产G、铁棺佣兵、红面具信标、撤退名单终端。梗点包括白色战舰、红色王牌、量产兵士、这不是普通展柜复制品的变奏、修正掌反转伏笔。

**关系 / 情绪 / 债务**  
纪存的压力是防止自己把战争策展成名场面。情绪物件是无人认领维修单，上面只写“左臂换过，驾驶员未回收”。敌方收益：红面具标记玩家追击欲望。

### E30 红色路线不等人

**本话功能**  
把红色王牌、热血追击和歌声停火放进同一场战斗。赤罡能追上红面具，但撤退线会被丢下。

**剧情流程**  
红面具机以极高速切入，确实压迫感十足。围观频道有人喊红色三倍速，红面具不回应，只用行动证明：它快，不是因为颜色，而是因为它从不等人。赤罡被点燃，钻破天盖线的热血第一次完全外放，他能追，甚至能赢一段。

同时难民船和补给车队从另一侧撤离。莉歌的歌翼可变机抵达，她的歌声不是洗脑，也不引用歌词，只让敌我暂停攻击一回合。那一回合里，所有人都听见撤退暗号，也听见失去的人。玩家可以用停火窗口追击红面具、修撤退线或说得一队灰鸥量产G。

赤罡如果追，会获得单挑高光，也让撤退船损伤；如果停下来，他会短期降气力，却获得莉歌声部支援。红面具主动后撤，嘲讽玩家不是不够快，而是不够舍得丢人。

**战斗与玩法 / 机体 / 梗点**  
类型：追击/撤退双目标战。机体/单位包括红面具机、红钻机、歌翼可变机、灰鸥量产G、撤退船队、补给轨。胜利条件是撤退船存活并阻止红面具夺取撤退信标；可选目标为追击红面具。梗点包括红色更快、歌声停火一回合、钻头热血、宿敌诱惑。

**关系 / 情绪 / 债务**  
赤罡和莉歌第一次形成战场化学反应：她不是让他冷静，而是让他在听见撤退暗号后自己选择。情绪物件是停火一回合里的空白频道。敌方收益：红面具采样赤罡追击欲望。

### E31 不被歌颂的撤退

**本话功能**  
中盘大战高潮。胜利条件从击坠转为让别人离开。量产机、佣兵、歌声、命令权和白舰残骸一起参与。

**剧情流程**  
撤退战全面爆发。白舰残骸不能飞，却能当临时补给线；灰鸥量产G用低配盾阵推船；铁棺佣兵用弹药有限的泥地战术挡住敌王牌；黑棋王座命令框出现，给出诱惑：牺牲一队量产机，能保证主力全员撤离。

纪存面对本章大决策：是否把撤退名单公开为开馆证词。公开能鼓舞士气，也可能让活着的人再次被拖进镜头。七海远程提醒战时公开名单会影响后续追责；白鸢想画一个能让所有人看见的撤退构图，却发现每个镜头都会遮住另一条船。

赤罡终于获得追上红面具的机会。红面具露出背部弱点，战斗演出已经给足PV感；同回合，难民船外侧推进器过热。赤罡选择放弃最燃镜头，用钻破天盖机的钻头不是打敌人，而是钻开一条撤退冰层。莉歌的声部在频道里断了一拍，像终于知道他听见了。

**战斗与玩法 / 机体 / 梗点**  
类型：大规模护送 + 三路线选择。地图为撤退航道、白舰残骸、冰层、补给点、红色追击线。胜利条件是三艘难民船至少两艘撤出，并保住撤退名单核心；失败条件是命令框牺牲指令执行或主推进器全毁。机体包括白舰残骸、灰鸥量产G盾阵、铁棺佣兵机、红面具机、黑棋命令框、歌翼可变机、钻破天盖机。梗点包括撤退战、量产机逆袭、命令权诱惑、歌停战、红色宿敌。

**关系 / 情绪 / 债务**  
赤罡的成长是公开放弃“主角镜头”。纪存也学会不把撤退名单立即展出，而是让幸存者决定哪些名字今日可见。情绪物件是撤退名单里新补上的一个名字，旁边写“无人认领，但有人推过船”。敌方收益：索引获得撤退、单挑、命令三套偏好。

### E32 量产机把名字补上

**本话功能**  
把E31的大战转成反剪辑防卫：平台想把撤退剪成英雄宣传，玩家要让量产机、维修单和无人认领名字不被删。

**剧情流程**  
战后不是安全。平台和索引联手生成“英雄撤退剪辑”：赤罡钻冰、莉歌停火、白舰残光，全部漂亮；灰鸥量产G推船、铁棺佣兵补弹、无人认领维修单全部被剪掉。红面具不再追赤罡，而是追撤退路线本身，证明他也学会了玩家真正重视什么。

玩家要在剪辑轨上防守。每保留一段低光镜头，前线支援下降一点，但终局量产支援条件上升。纪存面对一次“好看的版本更容易传播”的诱惑，白鸢也承认漂亮剪辑会让更多人理解撤退。但刃把一张手写名单拍在终端上：理解如果只看英雄，那他们还是没回来。

终局，灰鸥量产G组成盾阵挡住红面具最后突击。它们没有新大招，只是一个个把名字补上。赤罡站在后排，没有抢镜。莉歌停唱，让噪声留在频道里，因为那是撤退现场的一部分。

**战斗与玩法 / 机体 / 梗点**  
类型：反剪辑防卫 + 名单夺回。机体/单位包括灰鸥量产G盾阵、红面具追路机、剪辑轨核心、铁棺补弹机、撤退名单终端。胜利条件是保住五段低光镜头和名单终端；失败条件是英雄剪辑完成或红面具夺走撤退路线。梗点包括量产机不是背景板、反剪辑、撤退名单、英雄史反转。

**关系 / 情绪 / 债务**  
赤罡和莉歌的关系从热血/歌声进入互相理解：她知道他这次没有抢镜，他知道她停唱是为了保留噪声。情绪物件是无人认领名字。敌方收益：平台虽反剪辑失败，但带走量产逆袭热度。C09债务：遗作拍卖会开始售卖“替遗憾说完”的权利。

**C08 前缀回归小结**  
本章通过，是前半全剧第一次大规模机战高潮。赤罡有外放成长，量产机和撤退伦理有泪点。未解决风险：C09若继续拍卖外壳，会与C02重复，必须把拍卖升级为“解释权/补完权”的战争。

## C09 作者遗作与废案战争

本章从“商品化物品”升级到“售卖替遗憾说完的权利”。白鸢的作者线进入主场，吐槽战舰、花蒸歌剧团、昆羽机谭、废案角色和分镜格地形共同承重。成人关系线在这里需要更有卖相：舞台、灯光、近距离修整、错过告白、嫉妒和创作占有欲都进入场面，但儿童线仍隔离。

### E33 分镜格里的遗作拍卖

**本话功能**  
把遗作拍卖写成战棋格变化，不重复C02商品拍卖。拍卖的不是旧件，而是谁有权替未完成故事说完最后一句。

**剧情流程**  
万机馆追踪C08撤退名单来到遗作拍卖场。拍卖大厅像巨大的分镜页，地板格线就是画框，竞价牌会改变格子内容。吐槽战舰以剧中剧支援舰登场，观众吐槽能提供支援，也可能伤害被吐槽的角色。花蒸歌剧团的舞台机兵在侧台待命，灯光一亮就能把舞台变成战场部署。

平台运营者固定登场。他懂玩家遗憾，也真能帮废案被看见；危险在于他把“替遗憾说完”变成付费权利。白鸢看见一份未完成分镜，里面有她早年废掉的角色。她动摇，不是为了钱，而是因为她也想买下一个不会伤人的结局。

战斗中，每次竞价都会把一个废案残响补成更完整、更安全、更能卖的版本。玩家要保护“未说完”的格子不被填满。纪存给白鸢一个可质问分镜权：她可以临时改格，但每改一次，废案角色的自主支援下降。

**战斗与玩法 / 机体 / 梗点**  
类型：分镜格地图 + 拍卖打断。机体/单位包括吐槽战舰、花蒸甲、遗作拍卖台、竞价格、平台热度Bot、废案空白机影。梗点包括剧中剧观众、舞台即战场、遗作拍卖、吐槽支援、未完成角色。

**关系 / 情绪 / 债务**  
白鸢看见自己也想买下遗憾，纪存没有立刻审判她。两人有一次近距离：纪存替她挡开竞价格，她手里的笔尖划到他终端边缘，两人都没说那句险些出口的话。情绪物件是未完成分镜页。敌方收益：平台学会售卖替遗憾说完的权利。

### E34 废案角色不需要你补完

**本话功能**  
让废案角色有具体形象和机体轮廓，不再抽象。昆羽机谭残响引入异界解释权，证明“解释得完整”也可能是殖民式占有。

**剧情流程**  
版本层打开，三个废案残响出场：没有脸部线稿的空白骑士机、只有左臂武装的虫翼机、台词永远缺半句的旧剧中剧机器人。它们不是等待主角补完的素材，而是以残缺方式保护彼此。昆羽机谭残响把解释权拉到异界神话，平台则给每个废案匹配“最能爆火的完整设定”。

白鸢被迫面对自己的职业本能。她能一眼看出怎么补会更好看，也能一笔让支援稳定。但废案角色不想被她补成能卖的样子。纪存把她的改写权限做成可选支援：使用后即时强，但会在后续让废案角色离队或支援灰掉。

中段，索引生成最优废案模板：它保留残缺外观，却把行为改成玩家最容易喜欢的伤痕角色。玩家要用空白、卡顿、缺台词来反制。白鸢第一次公开道歉不是“我错了”，而是把笔放下，让缺半句台词自己卡在频道里。

**战斗与玩法 / 机体 / 梗点**  
类型：废案保护战 + 补完诱惑。机体/单位包括空白骑士机、虫翼左臂机、缺台词旧机、昆羽残响、最优废案模板。胜利条件是三个废案至少两个保留自主缺口；失败条件是全部被完整模板化。梗点包括未完成角色、异界奥拉解释权、补完不是拯救、空白也能战斗。

**关系 / 情绪 / 债务**  
纪存给白鸢质问权，也给她不动笔的空间。白鸢第一次因为嫉妒七海的“冷处理能力”而自责：七海能不按键，她却很难不下笔。情绪物件是她放在地上的笔。敌方收益：索引获得最优废案模板。

### E35 空白展柜被竞价

**本话功能**  
把空白展柜变成物理防卫目标。平台不是只抢物品，而是抢默认解释权。

**剧情流程**  
拍卖场核心空白展柜开始被竞价。谁竞得展柜，谁就能给未完成角色写默认介绍。平台热度Bot抢占展柜标签，圣堂保守派也提前派人入场，要求所有错版、废案、吐槽支援都等C10原典审查后再公开。七海看见这套商品化和审查不是清算能单独解决，她第一次承认代哥流程里没有“遗憾权利”的字段。

战斗中，空白展柜会被物理拖走。花蒸歌剧团把舞台灯光切成防线，女性玩家、舞台路线和关系支援被自然纳入机器人文化，不再只有拼装和考证。纪存与白鸢发生一场更成人的争执：她说他保留空白，是不是因为空白更方便他以后解释；纪存反问她想填满，是不是因为她害怕没人需要她。

这场争执被七海听见。七海没有插话，只在权限框里把“展柜拖移”改成“需双人确认”。白鸢看见这次缝隙，第一次对七海产生不是敌意而是复杂嫉妒：这个女人连靠近都像公文，但公文真的改变了战场。

**战斗与玩法 / 机体 / 梗点**  
类型：展柜防卫 + 观众评价战。机体/单位包括空白展柜、舞台炮车、花蒸甲、热度Bot、圣堂授权席位机、拖柜无人车。梗点包括舞台即战场、女性玩家入口、观众评价、默认解释权。

**关系 / 情绪 / 债务**  
纪存/白鸢关系升温但带刺，七海成为三角压力的一部分。情绪物件是空白展柜里一张没有贴上的说明卡。敌方收益：平台抢占默认解释权失败，但把纪存/白鸢/七海关系路径记成可利用样本。

### E36 缺页不是失败

**本话功能**  
C09收束：缺页、空白、废案和错版不等于失败。玩家要击败最优废案机，同时保留进入C10原典圣堂的邀请。

**剧情流程**  
索引把前面所有补完样本合成“最优废案机”。它很懂玩家：残缺外观、痛苦台词、强支援、漂亮牺牲、可买周边，一切都刚好。它不是嘲笑废案，而是把废案变成最容易被消费的样子。

版本层深潜展开为初版、商品版、玩家错版、封存版、索引版五层。每层有不同玩法：初版脆弱但自由，商品版强但路线少，玩家错版有奇怪隐藏支援，封存版安全但沉默，索引版完美但会删掉缺口。玩家要在层之间切换，保护缺页证词。

白鸢迎来本章选择：是否用一笔补齐缺页来打败最优废案机。她选择不补，把缺页作为支援入口。纪存也不替她解释，只把缺页放进万机馆。圣堂邀请函落下，槐的名字出现，C10原典圣堂开启。

**战斗与玩法 / 机体 / 梗点**  
类型：版本层深潜 + Boss战。机体/单位包括最优废案机、初版/商品版/玩家错版/封存版/索引版层、吐槽战舰、花蒸支援、缺页证词。梗点包括缺页不是失败、错版隐藏支援、剧中剧反噬、最优伤痕商品。

**关系 / 情绪 / 债务**  
白鸢不是被治好，她只是第一次选择不画。纪存尊重她的空白，两人关系进入更深的“靠近但危险”。七海保存“需双人确认”水印，留到C11。情绪物件是缺页证词。敌方收益：索引预显影补完模板。下一章债务：原典圣堂要求万机馆证明它不是随便改台词。

**C09 前缀回归小结**  
本章通过。拍卖不再重复C02，而是升级为补完权/解释权战争。白鸢线明显增强，成人关系开始有错过、嫉妒和近距离。未解决风险：C10必须尊重原典热爱，不能把原典派写成笑料；完美合体必须强，错版合体才有重量。

## C10 原典圣堂与错版合体

本章讨论“正确台词、原典仪式和错版童年”。立场不是嘲笑原典厨，也不是乱改万能；正确曾经救人，错版也可能救过某个人。三相盖流获得主线合体资格，但错版合体必须更难、更贵、更危险。

### E37 不许改台词

**本话功能**  
让玩家先尊重原典。台词碑阵列和授权席位机必须先在玩法上压倒玩家，让“正确真的很强”成立。

**剧情流程**  
原典圣堂像一座由台词碑、合体姿势、授权席位和旧电视雪花组成的庙。槐不是纠错NPC，她曾经靠一句正确台词从灾难里活下来。圣堂欢迎万机馆，但要求所有错版、缺页和二创支援先停用。纪存如果强闯，会被玩家自己喜欢的援护台词反压。

台词碑阵列启动后，正确口令能稳定支援、提升合体率、降低事故。玩家第一次会想承认：对，正确很重要。社勇王许可、三相盖流门和吐槽战舰频道都被授权席位机限制。白鸢想替错版辩护，槐问她：你有没有被一句正确的话救过？

战斗是许可席位谜题。玩家要通过尊重、询问和保留缺页，而不是抢台词碑。纪存承认万机馆过去也有“把所有版本并置就算尊重”的傲慢。

**战斗与玩法 / 机体 / 梗点**  
类型：许可席位谜题 + 压制战。机体/单位包括台词碑阵列、授权席位机、三相盖流门、社勇王许可锁、吐槽战舰静音器。梗点包括正确口号、原典仪式、合体许可、台词救人。

**关系 / 情绪 / 债务**  
槐获得立体性：她不是保守，是被正确救过。纪存的成长是承认并置也可能偷懒。情绪物件是槐保存的旧台词卡。敌方收益：圣堂收集玩家对正确口令的依赖。

### E38 圣堂背面的删注

**本话功能**  
揭示原典也在争论中活着。错版口令牌不是笑料，而是曾经救过槐之外另一个人的误传。

**剧情流程**  
圣堂背库打开。删注无人机、错版AI玩具、年轻粉丝直播组和圣堂守卫同时抢资料。背库里有被删掉的注释、不同年代译本、粉丝手抄本和一块错版口令牌。槐发现，当年救她的正确台词旁边，也有人靠一句错字幕撑过孤独。

玩家要在资料抢夺战中决定公开方式：全部公开会伤害槐和圣堂信任，私下给槐看会保关系但削弱万机馆证据，保留错词会影响C40错版合体条件。纪存承认错误版本也需追责，不能一概洗成童年美好。

白鸢和七海有一次短场。七海说流程最怕“大家都能理解所以不用追责”；白鸢说创作最怕“只有追责没人记得为什么喜欢”。两人不是和解，但看见对方的伤口。

**战斗与玩法 / 机体 / 梗点**  
类型：背库探索 + 资料抢夺战。机体/单位包括删注无人机、错版AI玩具、背库台词牌、直播热度车、圣堂授权席。梗点包括错字幕救命、删注背库、原典厨与错版厨、年轻粉丝直播翻车。

**关系 / 情绪 / 债务**  
纪存不把错版直接神圣化，七海和白鸢互相刺到对方。情绪物件是错版口令牌，字错但边角被握得发亮。敌方收益：索引拿到正确/错版双口令样本。

### E39 喊错也能合体吗

**本话功能**  
三相盖流主场。完美合体必须漂亮、强、诱人；错版合体更乱、更贵、更危险，却能绕开索引预测。

**剧情流程**  
圣堂开启三相盖流合体试炼。完美合体体登场，三机角度、驾驶员节拍、台词口令全对，战斗演出压倒玩家。它不是假正确，是真的强。赤罡、豪司甚至唐胶都承认这玩意儿就是帅。

索引用正确口令样本预判玩家每一步。完美路线越顺，索引越能提前封格。错版口令牌亮起，给出一条极不稳定路线：喊错一字、站错半格、合体角度偏差，三相盖流会进入未授权但有效的错版合体。代价是承力暴涨、维修债上升、七海追责加重，且失败会撞坏地形。

七海给临时追责许可：她不是替玩家开后门，而是把“未经授权但有效”先登记，防止硬线把它直接封存。白鸢保留错误版本的镜头，不把它画成新正确。

**战斗与玩法 / 机体 / 梗点**  
类型：双路线Boss战。机体/单位包括三相盖流三机、完美合体体、错版合体态、社勇王援护、索引预测格。胜利条件是击破完美合体体或以错版合体绕过预测；失败条件是合体事故三次或授权席位崩毁。梗点包括三机合体、闭眼也能合体的风险变奏、完美口令、错版高压三回合。

**关系 / 情绪 / 债务**  
七海把追责和许可同时给出，纪存第一次在战场上感到她的成熟危险：她救你，也让你无处逃避。白鸢看见这一点，嫉妒但没有讽刺。情绪物件是错版口令牌在高热后裂了一条线。敌方收益：代哥记录未经授权但有效。

### E40 错版合体不是事故

**本话功能**  
C10收束。错版胜利不能变成新原典，必须保留有效、危险、不可复现三面标签。新正确口令核作为小Boss阻止行政收尾。

**剧情流程**  
三相盖流错版合体击破试炼后，圣堂系统试图把它立即整理成“新正确口令”。索引也伸手，要把错版纳入标准化模板。槐意识到如果今天把错版立成新碑，未来又会删掉另一个孩子的误听。她选择让错版口令牌保持裂痕。

新正确口令核生成小Boss。它不强，但每回合会把玩家刚刚打出的错版路径整理成可复制指南。玩家要保护错版的不可复现性：保留风险说明、维修债和追责编号。纪存不能把胜利写成“错版也对”，而要写“这次有效，仍需承担”。

战后，三相盖流只开启主线合体资格，不完整入队；完整数值树和驾驶员绑定留后续条件。圣堂邀请万机馆进入白名单都市审查，因为“未经授权但有效”已经触及代哥生态底线。

**战斗与玩法 / 机体 / 梗点**  
类型：合体后防卫 + 口令核小Boss。机体/单位包括新正确口令核、三相盖流疲劳态、错版口令牌、台词碑残阵、社勇王许可线。梗点包括错版胜利不能变新原典、有效但危险、授权追责、原典与误传并存。

**关系 / 情绪 / 债务**  
槐从守门人成为同行者候选。纪存承认自己不能替所有版本定最终名。七海保存追责许可，C11将进入她的主场。情绪物件是裂开的错版口令牌。敌方收益：索引学习把错版也标准化。下一章债务：白名单都市要把万机馆纳入公共信托。

**C10 前缀回归小结**  
本章通过。原典与错版都得到尊重，三相盖流有真正机战爽点。未解决风险：C11信息量巨大，必须用城市动作讲代哥生态，七海要成为成熟改革者和危险吸引对象，而不是流程讲解员。
