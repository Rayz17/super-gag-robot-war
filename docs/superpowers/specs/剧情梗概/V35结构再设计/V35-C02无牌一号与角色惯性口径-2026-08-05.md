# V35 C02无牌一号与角色惯性口径

**状态：** Working entity fact + C02 chapter-level dramatic rule  
**适用：** C02 L4、L4.5、Episode Reader及后续机体生命周期

## 无牌一号的稳定事实

- 无牌一号是十六米级全尺寸竞技实机，不是模型放大后形成的机体。
- 它的机魂位于实机控制核，可以自主行动和决定是否参赛、使用改件或随舰。
- 身体由历代出资与维护者共同持有，赵梅合作社托管维护。万机馆只能在完成共同维护人交接后提供泊位和日常维修，不取得所有权。
- 缩尺模型是玩家表达造型、动作和装备组合的构筑界面。它不供能、不承重、不长大，也不保存无牌一号的机魂。
- 构筑方案必须经历“模型表达 -> 唐胶转译战法 -> 陆衡与本地工程员重做全尺寸方案 -> 工房制造 -> 兜灯安装测试 -> 机体本人确认”的尺度链。

## C02的角色惯性

作者后台可暂称“角色惯性”，但这个词不进入人物对白、UI或当场百科解释。

无牌一号、完全版王者和旧拳王的全尺寸身体曾长期排练、扮演并被观看，旧动作和角色关系也参与了机魂自我的形成。因此，它们可能会真心认同自己的旧角色，甚至把那条路视为命运；这不等于被远程操纵。

C02的戏剧不是“机魂觉醒后一律反抗剧本”，而是三种不同选择：

- 旧拳王喜欢师父与拳手的身份，它选择保留角色，但不把“打完”凌驾于对手的停止信号。
- 完全版王者真心认同主角和冠军身份，它的危险不是“受骗”，而是害怕结局再次永远停在最后一幕之前。
- 无牌一号仍然愿意保护别人，但它第一次将原本只用来走向牺牲位的动作，也用来保住自己。

这三者都不是否定过去。自由的表现是它们可以认领、改写或拒绝熟悉的道路，也要承担自己的选择。

## Reader的揭示边界

- E01只让玩家看见无牌一号和完全版王者对旧编号、站位和半套动作产生熟悉反应。
- E02-E03通过训练、旧工号、未播分镜和当事人资料，让玩家推断这不是普通战斗程序。
- E04-E05用两台机体的不同选择回答本章问题，但不提前解释G.A.G.、机魂起源、索琳或二十七年前的完整真相。
