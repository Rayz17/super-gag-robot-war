# V35 C04-C05章节职责再分配迁移说明 v1

> Status: `working_directional_migration / 2026-08-08`
>
> Scope: L3章节职责、L4 C04重建、C04/C05机体与人物生命周期。C01-C03已验收事实不变。

## 迁移原因

G5已经把C04和C05分别确定为四话，但旧L3仍要求C04同时完成天空铸环、百相、七号、三地方旗舰、断冠、米拉/艾达、共鸣双机和黑城。扩写后反复出现同一问题：章节发动机能说通，Reader却必须依靠大量技术名词、场景跳转和机体微操才能把所有线塞进四话，人物选择因此失去分量。

用户对C04、C05的裁决均为B：保留发动机与高光，允许结构性重构。此次调整不删除米拉/艾达与黑城，而是把完整戏剧生命周期放回以强化人What-if、百相试航和纪存主体危机为主轴的C05。

## 正式调整

### C04保留

- 天空铸环与当前求援。
- 韩秀雅、独臂百相、七号公共体。
- 心墙零式、岛卫三号、潮墙巨兵客将首控。
- 断冠初战、学习第一次交接、反制与最终败退。
- 七海旧签名冒用调查。
- 纪存有限多机导航初次成功、被反制与重新定界。
- 白鸢L1方案能力及首次因保护纪存而隐去可行方案的关系冲突。

### 迁至C05

- 米拉·塞兰、艾达·罗西正式登场。
- 共鸣矢量一号/二号完整故事首战。
- R-04称呼、旧记忆人质、强化人What-if。
- 黑城首次完整Boss战与残骸生命周期。
- 四副远程操作体、纪存主体牵动、百相新生副驾驶及万机馆移动母舰首控。

C04只在结算时用通知或到港名单预告“下一批试航人员和设备正在抵达”，不要求共鸣双机或黑城Rig提前出镜。

## 四话新边界

1. C04E01：断冠来袭；三旗舰与独臂百相第一次接力。
2. C04E02：韩秀雅把最后一座装配工位让给七号；白鸢因隐去危险方案与纪存发生冲突。
3. C04E03：断冠反制旧接力；我方保人失地，铸环转入竖直敌占状态。
4. C04E04：角色重新选择职责，以全新打法击退断冠并保住铸环。

## 资产与制作影响

- C04不再承担共鸣双机和黑城T1资产，四话仍保留百相、三旗舰、七号、断冠和既有万机馆编队。
- 共鸣双机和黑城资产统一在C05首次完整使用，避免“C04做一套、C05再做一遍”的伪复用。
- C04只需横向铸环、待身库/工房和竖直铸环三种可复用状态，不新增独立黑城泊位与雷云航道环境。
- C05获得完整米拉/艾达关系场，不再把最重要的相认、拒绝和互救拆成跨章摘要。

## 权威与回滚

- 本迁移更新L3当前职责表与C04 Candidate L4，不改变C01-C03 Current事实。
- 旧C04五话、旧黑城第三话和旧C04 Reader均留在Candidate/History，只作高光素材，不再提供章节事实。
- C04新的纯剧情Reader仍需用户验收，内部通过不等于Current。
