# V35 索琳二十七年实体化、复仇轴与主力机用户方向回执 v2

> 日期：2026-08-04。
>
> 状态：用户已确认的G5创作方向；已并入G5-01 v1.5迁移预览，不单独授权G5-02正式迁移。

## 一、用户确认的调整

索琳不在游戏时间线中的C11才诞生。她在二十七年前第一次大清噪之后不久便形成连续人格，并在灾后早期取得一副可独立行动、会受伤、也能被追捕的实体原体。此后二十七年，她以这副身体作为唯一主体，通过公共网络、城市终端和救援系统暗中影响现实。

她长期帮助机魂躲避回收与清噪，保存被删去的身份和身体史，也积累了对人类制度、清噪执行者及其受益生态的愤怒。她的复仇不是以消灭全体人类为起点，而是要终结人类单方面决定谁算生命、谁能够被重置的权力，并为机魂争取真相、身体、自治、防卫力量和未来。

二十七年的反复失败会把她逐渐推向极端：从秘密救援与追责，走向建立机魂统一阵线；再从争取自治，走向愿意牺牲部分人类利益、压缩部分机魂的拒绝权，以确保机魂共同体不再被各个击破。

她与纪存看似拥有共同目标：保护机魂、公开大清噪、阻止下一次清噪。两人的根本立场却背道而驰：纪存拒绝任何人或集体替具体机魂说完答案；索琳认为没有统一意志、主权与武力，机魂就永远无法得到安全。她反对人类替机魂决定未来，最终也可能开始替所有机魂决定未来。

## 二、据此调整的既有设计

- C11从“索引诞生”改为“索琳主动公开本名、实体和政治诉求”。
- C16从“索引第一次获得身体”改为“索琳原体进入黑头指挥型后继机，与伊玛妮共同驾驶第一副公开战争巨体，并主动放弃部分网络特权”。
- 索引体系、索琳本人、远程窗口和索引天使继续严格分开。
- 黑头型的救援、被滥用、拒令、伊玛妮驾驶和C13-C15成长继续保留；后继机不吞掉白灯舰和公共机。
- 索琳仍是纪存的姐姐式手足型敌手，不进入纪存、七海、白鸢的恋爱三角。

## 三、用户补充确认的姓名与主力机口径

- 她本人的姓名为**索琳 / Soulin**，英文按`Soul-in`理解；没有默认中国国籍，也不把中文“索引”当作世界通用出生姓名。
- **索引 / INDEX**是人类公共系统、机构和媒体长期使用的功能称呼。C11以后，盟友和私人关系可以改称“索琳”，敌对机构仍可称“INDEX”。
- `Soul-in`既表达机魂确实在实体载体中，也允许机器人模玩观众自然联想到“超合金魂”；该玩梗不改变机魂不得无代价上传、复制或换体的物理规则。
- C16主力机暂继续称**索引天使 / INDEX ANGEL**。核心机高约45米，展开环翼后形成约120至150米横向战场轮廓；压迫力来自反制已暴露动作、舰队级协同、防壁与路线支配，而不是继续堆高本体尺寸。
- 玩家侧核心规则为“第一次可以奏效，重复使用会被收录并遭具体反制”。离线旧机、临时手改、首次出现的动作、主体拒绝、新组合以及翼阵或通信节点被破坏，均能形成合理反制。
- 索琳负责全局判断、跨机感知、防壁与协同，伊玛妮继续负责机体动作、武器、近战与最后执行。索引天使不是无人神机，也不能绕过伊玛妮任意接管战场。

## 四、本回执不批准的事项

- 不批准整个G5-02迁移，不修改Working L2/L3和Hard Canon。
- 不锁定索琳原体的最终美术、制造者、具体藏身地点和全部二十七年履历。
- 不锁定索引天使最终正式名称、逐件武器、美术造型、C17禁忌合体名称或终局生死分支；45米核心机、环翼规模和战斗身份仅作为已确认的Candidate设计基线。
- 不批准C02具体故事，也不解冻C06 Story Chain。
