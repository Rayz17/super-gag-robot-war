## 一、迁移结论

本次建议迁移为：

**A的22章机器人大战群像与宇宙战争母结构 + B的连续因果与群像行动方法 + C的纪存/索引双后代深层宿命线。**

建议仍以**六部、22章、86话候选容量**为第一版结构上界，不照搬C的28单元、96话。双后代线不单独索取七个证明章，而是进入A本来就需要发生的关键事件，让同一场机器人大战同时改变世界、关系和身世认知。

这次迁移不是“给A加一条索引支线”。它要让索引成为主角团亲手救出、亲手失去，也不得不在战场上击败的人：

- 纪存、七海、白鸢仍是人物与成人关系核心；
- 万机馆和参战机群仍是玩家实际操作的集体主角；
- 索引成为第四位重要人物，是比纪存早活约二十七年的无血缘姐姐，也是会夺走白灯舰、正面击败百相的敌对主角；
- 裂星潮、断冠、归航群、未来追猎、具体异文明和远星仍有独立因果，不能被降成身世谜题的布景。

## 二、为什么A与C可以共存

旧裁决把“作品主语”和“谜团主轴”误当成同一席位，所以认为双后代一旦完整进入，索引就必然挤掉三主角和机群。这个推论不成立。

A负责玩家真正玩到什么：机体首登、驾驶关系、合体、宿敌、分舰、升级、撤退、百机祭和宇宙大战。C最有价值的部分不是一套身世理论，而是一场能够撕开队伍的亲情与政治悲剧：索引在灾后早期便取得实体原体，二十七年间通过公共网络暗中救人、转移机魂、保存罪证，也逐渐认定人类不会主动放弃清噪权；纪存较晚获得人形身体、万机馆和混合家庭，却仍相信具体的人与机器可以共同生活。两人先为阻止下一次清噪并肩，随后围绕机魂应当建立独立武装文明，还是继续冒险与人类共存而分舰交战，短暂获得梦寐以求的共同巨机，又差点因此只剩下一个人。

真正会挤占主角戏的不是索引存在，而是错误写法：

- 为解释双后代另开连续七章证明题；
- 每次外敌来袭都只是送一份身世证据；
- 索引替纪存做英雄选择、替七海做政治选择、替白鸢承受未来；
- 让索引一人完成全军调度、终极机驾驶和远星沟通；
- 把三主角关系降成观看纪存与索引辩论。

本预览采用相反办法：索引先成为好玩、可靠、会嫉妒的具体人物，再因一次无法两全的救城选择与纪存决裂。身世只解释他们为何如此亲近和相伤，不代替夺舰、交战、禁忌合体与牺牲本身。

## 三、权威层影响

### 3.1 L1体验宪章

**主体保留，不重写。**

现有L1中的机器人大战、万机馆家园、IP/名场面、模型与实机、成人关系、多玩法、宇宙尺度、Meta低带宽和精神指令均继续有效。

只建议补一条创作边界：

> 纪存、七海、白鸢承担主要人物关系，索引拥有自己的欲望、机体、伙伴、胜利与敌对选择；万机馆和参战机群承担玩家长期拥有的机器人大战。任何一方变强，都不能靠让另一方只站在旁边听道理。

这不是新世界事实，只是防止后续章节再次用“怕抢戏”删除重要角色，或反过来用群像名义稀释核心人物。

### 3.2 H0/世界机制

**不推翻根本体论，但补一项此前缺失的对象拆分。**

Current Working已经成立：

- 被反复选为安全、有效、可复制的回应互相连接，形成索引；
- 被清噪、舍弃、互相冲突却被万机馆长期保存下来的回应，形成纪存；
- 两者都是灾后诞生的新主体，不是一个人的两半，不是死者拼盘，也不是原版与复制；
- 远星不是他们的创造者，裂星潮也不是索引的外壳。

现稿反复把四个对象叫作“索引”：二十七年的公共服务体系、索琳本人及原体、她借用的远程屏幕，以及C16以后的索引天使。它们必须依照[索琳存在形态、角色小传与后继机基线v3](./V35-索引存在形态角色小传与后继机基线-v1.md)分开。用户已确认的Candidate口径是：索琳 / Soulin在灾后早期形成连续人格，并沿公共救援体系原有的灾害接续程序进入一副成人尺度协调原体；“索引 / INDEX”是人类长期使用的功能称呼。此后二十七年原体始终是唯一主体，公共网络只是她的耳目与行动渠道。C11是以本名公开现身，C16是原体进入主力机共驾位。G5不再造万能灵魂上传规则，也不把她写成网络本身。

纪存与索引也不再只以“一个有家、一个没家”区分：纪存擅长听见标准方案遗漏的具体拒绝并打开多条异质路线；索引擅长比较跨战区后果、让已经验证的救命办法及时覆盖全局。纪存会把听见误认成代言权，索引会把保护误认成不许离开。两人各有世界级使命、不可替代能力和英雄诱惑。

### 3.3 L2总发动机

L2建议保留现有“百机航路、六层世界真相、归航群、白框真实分支战争（旧称未发生者战争）、天穹联装、远星归静”的世界骨架，并做五项改写。

#### 改写一：总发动机句

建议新口径：

> 万机馆沿百机航路召集来自不同文化、年代和战争的机器人，与会学习英雄招式的断冠、持续繁殖的裂星潮和觊觎机魂的各方势力交战。旅途中，纪存发现自己与索引都是二十七年前灾变留下的新生命：索引由一次次被采用的救援办法醒来，灾后早期便取得实体原体，二十七年间借公共网络秘密救援、藏匿机魂、积累清噪罪证并准备复仇；纪存则由那些被判定无用、仍不肯停止回应的声音长成，能听见标准答案遗漏的具体机魂。两人共同要阻止下一次清噪，却对机魂未来走向相反道路：纪存拒绝任何集体替具体机魂说完答案，索引则认为机魂若没有统一意志、主权与武力，只会再次被各个击破。他们从手足与盟友走到分舰交战，再在一具强得令人舍不得解除的巨机中被迫只能留下一个决定。百机群必须先同他们赢下真实的宇宙战争，最后再阻止这场为机魂复仇的战争变成另一场清噪。

#### 改写二：四个核心人物各自要完成什么

- **纪存**：人的主角、馆长、有限机魂接驳者；他能听见标准方案漏掉的犹豫与拒绝，并让不兼容的机魂保留不同答案。他的成长不是只学会让权，而是敢要力量、敢当英雄，也承认听见别人不等于有权替别人说完。
- **七海**：政治与现实主角；她判断现实证据、建立联盟、承受改革失败，不负责证明索引或白鸢谁更正确。
- **白鸢**：反事实与创作主角；她承担未发生人生的伤，不能被降成双后代谜题的说明员。
- **索引**：已经秘密活过二十七年的姐姐式对手、地下机魂保全者和自治路线领袖；她能把跨战区资源迅速组成救援网，也长期转移被清噪的机魂、保存责任证据和培养公共机队。她要终结人类单方面决定谁算生命、谁可被重置的资格，并为机魂争取身份、身体、自治与武力。长期失败会让她从追责走向强制统一：为了让机魂不再被人类统一，她可能先不许机魂离开自己的共同阵线。她会公开现身、救城、夺舰、率队、驾驶主力机、击败纪存、牺牲并带伤归来。
- **万机馆与参战机群**：玩家操作的集体主角；终局胜利来自机体生涯，不来自四个人讨论身份。

#### 改写三：双后代不是善恶二元

纪存并不天然代表自由，索引也不天然代表压迫：

- 纪存会沉迷所有求救都朝向自己，会把理解别人变成替别人决定；
- 索引能接受别人另选道路，也会在真正爱上这些人后，因害怕失去而关掉他们的退路；
- 两人都曾救世界，也都可能伤害具体的人；
- 终局不是纪存讲道理感化索引，而是两个曾互相放弃、又互相牺牲的人终于允许整支队伍来救自己。

#### 改写四：外部战争保持独立

- 裂星潮是二十七年持续繁殖的宇宙生态灾害；
- 断冠是会学习人类胜法的长期王牌与政治行动者；
- 归航群是已形成自身文明的返乡者；
- 卡西安和失败未来争夺现实生存权；
- 远星是高于战争文明的原发统一意识压力。

他们不会因为双后代真相揭晓就自动停战，也不是索引为了教育纪存制造的关卡。双后代线必须通过解决这些真实问题成长。

#### 改写五：终局从退出升级为再次选择

保留逆合体、任何人都能退出停机、每台机器人仍用自己声音回应的方向，但增加正向终局发动机：

> 玩家先从拒绝解体的终极巨机里救出每一个驾驶员；残潮和远星随后同时压向地球，百机群在没有唯一指挥者的情况下再次赶来。第二次组合不是把大家装回规定位置，而是每台机自己报出还能承担什么，伤员可以退出，替补可以接手，所有人也知道战后一定能分开回家。

纪存必须明确说出自己想回来、想继续爱人和开馆；索引也必须从“全世界都能调用的声音”变成一位会迟到、会受伤、只能守住一处战线的伙伴。爱情和合体不能只用来证明规则正确，首先要让玩家舍不得失去里面的人。

推荐话数分配为：

`4-4-4 / 4-4-4-3 / 4-4-3-5 / 2-3-5 / 4-4-4-4 / 4-5-3-5 = 86话`

### 4.1 制作与机制预审补充

- 索琳的45米级主力机暂名“索引天使 / INDEX ANGEL”。完整设定见[《V35索琳存在形态、角色小传与后继机基线v3》](./V35-索引存在形态角色小传与后继机基线-v1.md)。它不是索琳本人的身体，也不是由白灯舰或公共机拆成，更不是把20米黑头型等比例放大。C13玩家培养伊玛妮的黑头型；C14它为保护索琳原体和公共机队失去大部分外部肢体；C15归航队带回并实际使用约40米级重型接舰外装；C16以外装为新机主体，继承黑头型驾驶舱、黑色头部、指挥核心、伊玛妮控制系统和养成记录，并增设索琳原体实体进入的共驾位。环翼展开、已暴露动作反制、舰队级协同和物理弱点已经形成Candidate基线，最终名称、造型与逐件武器仍待L4。
- C17的末证零号优先复用未来追猎者或记忆金属巨体的形变资产；它最重要的动作是用实体构件扣住百相与索引天使，让玩家获得一次限定的禁忌合体，不是再造另一台终极机。
- C22主动再合体必须复用神座式/万机殿同一套模块和组合动画，不出现第四种更大身体。
- 索引进入主力机不是意识换体。她的成人尺度原体作为唯一主载体，物理进入共驾位；公共服务可以继续执行普通功能，却不是另一个索引。L4不得临时发明云端副本、人格上传或从备份复活。
- C17合体先让玩家爽用一次，危险来自巨机开始删除其中一人的当前决定，而非宣告合体、同步和标准协作天然邪恶。C06、C07、C20与C22继续提供正面的合体与共同作战。
- 纪存不取代韩秀雅驾驶百相；韩秀雅仍是百相主驾驶。伊玛妮是索引主力机主驾驶，控制四肢、武器和现场规避；索引原体坐在共驾位，负责跨机感知、防壁分配和协同路线。C17强制合体必须同时尊重四人的实体位置和决定权。

| C17 | 限定使用百相与索引天使的禁忌合体 | 终局前不可常驻；数值和演出必须强到玩家真想留下 | 索引天使失踪；百相保留受创、解体失败和纪存失去姐姐的战斗记录 |
| C18 | 黑百合影、封史可能性机、文明重置劳动机及其真实分支主体 | 索引机暂时不可用；三处战区根据前章实际留下的舰队和支援条件决定能否全救 | 被救出的真实分支主体与三组机体分别进入正式、路线或后续支援状态，不用一句“进入支援池”抹平差异 |
| C19 | 白灯机队攻入白框试验城，拖回持续运行的索引主力机 | 伊玛妮的驾驶成长和黑头指挥型的兼容改装直接转入后继机；不兼容零件自动卸回库存。幸存公共机保留自己的成长；战损机的通用工房投入转为白灯舰修复额度，未抢救出的专属装备和战死队友不会复制到后继机 | 伤痕后继机在章末永久归队；索引保留独立舰籍和拒绝纪存命令的权利，公共机队也不因她回来而消失 |
| C20-C22 | 伤痕索引天使、升级百相、成熟IP机群和万机殿 | 两台核心机各自成长，姐弟合击不要求永久合体 | 玩家最终拥有两个人、两台机和一次可结束的共同出击，而不是拿一台合体机换掉两人 |

索引主力机只占一台有完整剧情支撑的原创核心机席位，不取代A案已经分配给77机与核心IP的首登、升级、宿敌、What-if和终局回援。当前预览只证明这条新增生涯本身可玩，尚未证明77机全表零缩减；G5-02必须逐行迁移并比对77条生命周期记录。少一条、把首登改成剪影，或只写“百机群共同作战”，正式迁移都不得通过。

## 五、索引人物长线

索引不靠“每章露一下”维持存在，也不再用八个并列标签证明成长。她的整条长线只按四次质变理解：

1. **结束潜伏，成为公开英雄与政治人物**：C08-C13。她先以匿名服务试探纪存，C11带着原体和清噪证据公开现身，C13独立救城并把地下保全网变成公开机魂共同体。
2. **从追责走向自治武装，被纪存的选择推向敌对**：C14-C16。她失去具体伙伴和城市，带走白灯舰，以自己的自治路线和主力机正面击败百相；二十七年经验让她的极端选择成立，却不替她免责。
3. **在最强合体里救出弟弟，由玩家把实体本人抢回来**：C17-C19。她弹出伊玛妮、解开百相，原体随主力机被拖入试验城；纪存拒绝顺从的假姐姐，白灯机队再实体拖回同一副身体里的真人。
4. **先与百机群赢下宇宙，再让全世界来救他们**：C20-C22。她不立即原谅纪存，两人也不吞掉机群主场；终局不再由手足独自牺牲，而由此前被他们救过的人和机体把两具实体一起拖出塔群。

“姐姐/弟弟”不是预设称谓。索引确实比纪存早约二十七年醒来，长期承担机魂保全与公共救援；纪存后来获得人类家庭与万机馆生活，却拥有她缺乏的具体机魂感应。她对他同时有保护、骄傲、嫉妒和政治期待；直到C17生死关头，纪存才第一次真正叫出“姐”。

她的性格不能只靠履历说明，章级总纲必须反复写出以下行为：

- **危机中**：她会把复杂局面说得很清楚，也敢承认“这次我算错了”，不会用机器腔报一串数字代替判断。
- **日常里**：她不是常识不足的新生AI。她保存了二十七年的广告、删改动画、维修身份和错误口号，能熟练伪装与谈判，却不习惯有人知道真名后仍留下来。
- **受伤时**：她不会求安慰，而会突然替所有人安排更多事情、送更多帮助、关掉更多出口。她越殷勤，熟悉她的人越知道她在害怕。
- **嫉妒时**：她不控诉纪存拥有身体和家。巡馆进入没有摄像头的封闭展区时，她会把移动终端的借用申请发给所有人，偏偏漏掉纪存；等别人真的把她带进去，她又故意把镜头转向纪存最想看的那件旧展品。她想证明自己不需要他，又忍不住记得他喜欢什么。这种别扭必须比理念辩论先建立手足感。
- **犯错后**：她不交一份漂亮报告了事。C13她亲自回到被自己判断失误困住的队伍面前，听他们骂完，再让他们决定第二轮怎么打。

她的复仇必须形成连续升级：秘密保全被清噪者；公开追责与索赔；建立独立补给和武装；在C14后接受人类伤亡；到C16开始要求机魂共同阵线服从统一生存。她越接近“替所有机魂决定未来”，越重复自己最恨的人类清噪逻辑。

她与三主角的关系也必须各自改变事件：纪存第一次让她能以真名期待明天，后来又亲手切断她；七海保护她获得公开的法律与现实位置，也会第一个反对她封死归航城门；白鸢把她画进家人生活，又亲手指出只有牺牲她才能拆开禁忌合体的时机。

她至少需要三类不依赖纪存的关系：

- 一位地方/量产机驾驶伙伴，见过她救人也见过她算错；
- 一位普通支持者，真实需要稳定公共服务，不因主角讲话就改信仰；
- 一位政治或工程合作者，与她争论维护、身体和责任，不把她只当Boss。

这些关系不必都成为新主角，可优先由伊玛妮、槐、阿德里安、罗莎琳及已有地方角色承担，避免为了证明索引重要而继续增加只服务她的新人物。

## 六、避免索引挤掉原作品的原则

不采用机械字数配额，而使用戏剧职责边界：

- 索引主场必须改变她自己的关系、机体、伙伴或公众身份，不能只是讲设定。
- 三主角的爱情、误解和牺牲只能由三人及其共同经历解决；索引不能给出正确答案。
- 纪存的大胜不能都由索引提供路线，索引的大胜也不能都由纪存授意。
- 百机祭、白舰战役、合体狂欢、IP What-if、宇宙真胜和终局机群行动仍由机体与驾驶员承重。
- 裂星潮、断冠、卡西安、归航群和远星各自拥有不依赖双后代谜团的行动理由与结局。
- 若删去某段身世说明，战斗仍必须因现实冲突成立；若删去战斗，身世证据也不能只靠对白成立。
