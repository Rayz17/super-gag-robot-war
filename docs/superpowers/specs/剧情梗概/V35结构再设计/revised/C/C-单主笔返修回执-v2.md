## 双后代因果闭合

1. **形成**：第一次大清洗曾真救人。采用回应进入公共安全中继，弃答/矛盾回应进入万机馆离线回声匣。公共一路在地方持续确认中形成索引，离线一路在长期提问/回应中形成纪存的连续性。
2. **发现**：C04由伊玛妮在救援锁中发现同时间戳和双时钟；纪存、索引、七海共同取得现场日志。
3. **证实**：C15阿玛拉带回实体《双路回执匣》，陆衡与伊玛妮在温室救援中验证两路二十七年均未断链。
4. **不能合并**：C19的一秒测试正向删纪存刚作承诺，逆向删索引刚给撤回权；所谓无损合并只能格式化一个当前主体。
5. **改变行动**：C04分守外环/地下，C15取得双签名，C19分开救具身/空载，C23不共享头部，C27索引以有限机体先退出。
