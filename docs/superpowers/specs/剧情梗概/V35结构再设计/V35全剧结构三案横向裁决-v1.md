# V35全剧结构三案横向裁决 v1

> 阶段：G3-06，三案统一返修后的横向裁决。
>
> 权威状态：Candidate。本文只为用户结构决策提供证据，不迁移Working Canon，不改L2/L3，不解冻C06。
>
> 用户前史裁决：C01=A；C02介于B/C且明确不满意；C03=A；C04=B；C05=B。故C01/C03只保留已成立结果，C04/C05保留可重构发动机，旧C02故事不进入任何新案的固定前史。
>
> G4-02补记：用户随后否决了“A与C天然冲突”的推论，并确认只要写得好，索引不会挤占主角戏。最终选择已修正为A母结构、B连续方法、C双后代深层轴；本裁决中较早的排除意见以该用户选择为准完成修订。

## 一、裁决证据

本裁决不以表格完整度或机器检查代替故事判断，使用四类相互隔离的证据：

1. G1用户对C01-C05的明确裁决；
2. G3制作人、专业编剧、机器人文化专家、目标玩家四席对v1三案的独立审查；
3. 同一主笔依据七个共同根因，对三案分别完成的一轮整体返修；
4. 返修后目标玩家只读匿名故事进行的第二次冷读。匿名映射为`甲=C、乙=A、丙=B`，最终排序为`A > B > C`；A、B明确想追，C勉强想追。

机器校验只证明三案容量、结构表、遗产处置和固定边界没有失踪。它不能证明故事好看。

## 二、总裁决

### 推荐结论

**最终采用A案作为唯一结构母体，定向吸收B案的行动连续性与生产方法，并把C案的“双后代”与索引有限具身改造成穿过A既有大事件的深层宿命线。**

理由不是A字段最多，而是A目前最接近本项目真正的玩家幻想：

- 下一台机器人值得期待；
- 不同IP气质拥有不同驾驶关系和名回，而非换皮出现；
- 宿敌会学习主角的胜法并反过来使用；
- 世界先真赢，玩家能真享受；
- 人物关系有父子、旧爱、三角吸引、误会和共同驾驶，不只剩权限安排；
- 86话不超过当前87话上界，仍有明确制作压缩空间。

A不是原样通过。它必须接受三项选后结构手术：

1. 用B的章间动作接力和核心配角持续行动，修掉A第五部的“新地方逐章开题感”；
2. 把双后代从后台事实改成C04-C18逐级显影、C17质变的事件链，同时确保三主角、机群、宿敌和外部战争各有独立主场；
3. 重写共同终局欲望，不能让全剧所有浪漫最后都只负责证明“退出最重要”。逆合体可以保留，但终局还必须兑现新的合体、新的关系选择、宿敌最终选择和继续冒险的正向欲望。

### 为什么采用分层融合而不是平均融合

三案不是三份素材表，而是三种不同故事：

- A问：这么多不同的机器人文化，怎样共同赢、共同生活，又不被写成一种机器？
- B问：一场救援的物理后果，怎样不断把同一群人推入下一场行动？
- C问：纪存与索引这两个由同一历史选择长出的后代，怎样拒绝被合并成一个正确主体？

三者可以共存，但必须分层：A决定玩家看见和操作的机器人大战，B决定事件怎样连续，C决定大事件累积后揭开的宿命。只有把三者当作每章等量配额，才会重新回到C04过载和旧V35“什么都有但读不进去”的状态。

## 三、A案裁决

### 玩家幻想

玩家驾驶一座巡展母舰，沿百机航路遇见真正不同的机器人作品气质；取得、培养、分舰、召回和升级这些机体；与会学习英雄叙事的宿敌长期交手；最终同全球机群造出最强机器人、赢下宇宙战争，并决定这种力量以后怎样继续存在。

### 独占优势

**最强的“机器人大战长篇消费欲”。**

赤道坠环拳王赛把父子、旧机缺陷、比赛、灾难和万机馆航力结成一个动作；C04-C07让百相、共鸣旧爱、星火完整合体、三相危险进化、五兽伙伴、电磁第五人和彩队替补色位各有主场；C08-C11由白舰撤退、地方防线、三法城和百机祭形成连续战争上升；断冠持续偷学冠军、交棒、撤退和联合，而不是换一个Boss讲一章主题。

这些优势不能从A抽成若干“机体名场面”后搬走，因为它依赖A的宽章幅、机体生涯和断冠学习链共同成立。

### 主动舍弃

- 不采用B的18宏章压缩，不把合体谱系合并成少数核心包；
- 不采用C的28单元、96话证明结构；索引升为独立第四人物轴，但不进入恋爱三角，也不取代三主角与机群的前台主语；
- 29项机体处置只承诺13项完整生涯，其余明确为路线或储备，拒绝用剪影冒充参战规模。

### 主要风险

- C04-C11仍是最高资产密度区，若每章继续补机体会重新变成名场面清单；
- C15-C18的迟到委托、归航、具身What-if和完美馆可能连续落入“正确安置主体”的同音题；
- C19-C22共同工程、真胜、奖励和逆合体虽分开，但最终六话仍可能成为逐机退出点名；
- 成人关系在中段已产生欲望，后续仍容易被换算成钥匙、授权和救援差分。

### 必须修改的最早位置

不是C02。A的新C02已经用一场父子拳王赛承担桥接，并在两轮冷读中成为最强钩子；但它仍只是候选，后续必须单独做章级故事卡和玩家短样，不能自动继承为Working。

A最早需要结构修改的是第五部入口：C15的迟到委托必须直接引出同一批归航人物、卡西安和物件，使C15-C18像一条不断变形的追逐线，而不是四座主题馆。第二处是C22：逆合体必须同时发生一个无法由“正确退出”预测的新欲望或新结盟。

## 四、B案裁决

### 玩家幻想

玩家跟随一座受损万机馆，被前一场战斗的物理后果不断推向下一场；看同一群核心人物和机体反复把旧本领用在新局面；逐步解锁万机馆的承台、托举、护航和展馆展开；最终把这条紧密动作链推到宇宙大战。

### 独占优势

**最强的章间因果和核心队持续在场。**

货运带把万机馆甩进工务城，城梁开启星火轨道门，白舰撤退被断冠学走后直接袭击三防线，索引救城推动百机祭，百机祭的公共接口又使坠城奇迹与分舰成为同一个结果。唐胶/兜灯、陆衡/方舟T、韩秀雅/阿维不只拥有一章，后续继续改变胜负。

B的中央身份不能被完整搬入A；若把所有A章都改成无停顿物理接力，会压掉巡展、生活、恋爱、不同作品短篇气质和世界辽阔感。

### 主动舍弃

- 只保10个完整核心机体包，五兽、电磁、彩队等降为储备；
- 不追求A的广阔IP巡礼和C的宇宙身份史；
- 用18个宏章承载88话，接受章节作为制作单元偏大的代价。

### 主要风险

- B13-B18重新被身体、退出、停机和逆合体接管，后六章的因果比情绪热；
- 18宏章中多章5至6话，章节名虽少，实际制作与审稿并不更轻；
- 关系“钥匙化”最明显，爱情被证明有用，却未必让人欲罢不能；
- 核心包最稳，但目标机战玩家可能仍觉得IP宽度不足；
- 88话比现行上限多1话，需要显式L3迁移。

### 可以迁入A的部分

- 每章结尾留下物理出口、敌方收益或人物交接，而不是下一张邀请函；
- 唐胶/兜灯、陆衡/方舟T、韩秀雅/阿维跨章持续改变主线；
- 万机馆能力分阶段解锁并持续用于地图；
- 将长章拆成2至3个行动段做生产规划，但不把行动段写进Reader语体；
- C15以后使用同一人物、对手、物件贯穿多地，减少文明重启感。

## 五、C案裁决

### 玩家幻想

玩家发现纪存与索引是同一场历史选择长出的两个独立后代，跟随他们穿越二十七年归航、具身失败世界和远星压力，亲手证明同源主体不能被合并成一个正确版本；最终让索引放弃无处不在，驾驶一台有限的新机体与众人并肩作战。

### 独占优势

**最高辨识度的科幻身份与最完整的索引机体化。**

采用/弃答双回执、两只独立时钟、一秒合并会删除一方刚作出的选择，是清楚的证据链；“索引天使·一页式”拥有外观、局限、首战失败、与伊玛妮重订关系和三路养成，终于让索引成为能画、能开、能卖、能成长的机器人角色。

双后代不能缩成一句“纪存和索引像兄弟”，但也不必连同C的28单元全部移植。Current Working本就已经规定两者分别由被弃回应与被选回应长成；真正需要迁移的是二十七年证据链、索引独立欲望和合并失败的戏剧事件，并由A的铸环、百机祭、救城、分舰、归航和未发生者战争承载。

### 主动舍弃

- 不维持A的广阔机体主场密度；
- 不维持B的紧凑动作推进；
- 让索引和伊玛妮获得大量中后盘中心篇幅；
- 接受96话和最高的移动文明、分支身体、索引新机、神座终盘资产规模。

### 主要风险

- C15-C21连续证明“同源不等于同一主体”，玩家会在故事结束前很久猜完答案；
- 索引手足线可能吞掉纪存/七海/白鸢以及机群共同体；
- 卡西安、全相环和归静都偏概念，断冠的宿敌热量被分薄；
- 索引天使到C26才正式参战，亮点过晚；
- 96话需增加9话，且新增高成本资产最多；
- 成人关系和机器人IP快感均弱于A。

### 迁入A的部分

迁入“双后代真相 + 索引从全域公共主体主动选择有限身体”的完整人物功能，但不迁入C的96话章节排列。该线重新编排为：早段留下选中/舍弃两类物证；索引先真救人，再因害怕保护中断而越界；归航物证把两种传承连回二十七年前；一次强制合并失败证明两人都是当前的人；索引随后选择有限身体和自己的关系。它是A后半的重要人物轴，不进入纪存、七海、白鸢的恋爱三角，也不能等到终局前才首控。

远星危险的身体化表达也可迁入：呼号消失、座舱不认名字、关节趋同、生命维持只接受一种参数。这是演出方法，不绑定双后代。

## 六、共同未解决根因

三案虽然都补上公共真胜、奖励期和最强机普通用途，最终价值语法仍然高度相同：

`获得最强力量 -> 出现退出故障 -> 撤回钥匙/打碎同步/退出头部 -> 逆合体 -> 万机殿`

问题不在“逆合体”本身。这个创意适合本作，也能成为机战史上少见的终局玩法。问题在于，全篇已经大量使用拒绝、撤回、交还、停机和有限化；若终局只把这些动作放大一次，观众会感觉所有合体、爱情和英雄欲最终都只为更正确地解体服务。

选案后的L2/L3迁移必须加入一条新的终局约束：

> 终局既要让主体能够退出，也要让有人在完全可以退出时，因爱、野心、约定、冒险欲或共同创造而重新选择加入。万机殿不是“永远不再合体”，而是“下一次合体不再只有一种理由和一个头部”。

具体故事答案留给选案后的结构迁移，不在三案裁决阶段预写。

## 七、融合边界

### 推荐融合：A为母体

保留：

- A的22章/86话基本波形、广阔机体/IP生涯、断冠学习链、白舰战争、百机祭、三舰分裂、归航、具身What-if、神座真胜和万机殿；
- B的章间动作接力、核心群像跨章任务、万机馆分阶段玩法、长章行动段生产方法；
- C的双后代真相、索引有限机体化、独立关系线和远星危险身体化。

重做：

- A C15-C18的连续追逐发动机；
- 三主角感情线从权限差分升级为持续改变欲望、误会和牺牲；
- 断冠、红面具、罗莎琳、卡西安在后半的主脸分工；
- C22终局正向欲望，避免“退出即唯一成熟”。

不融合：

- C的28单元/96话结构、连续证明章和把双时钟当反复考试的叙事；
- B的18宏章和10包收窄；
- 三案三套C02。只保留A的新拳王父子案作为下一阶段首选候选，仍需用户故事卡裁决；
- 任何旧C02 Reader、平台合同、开馆四任务或修件行政叙事。

## 八、进入用户决策门的结论

G3-05与G3-06已经关闭，G4-02也已取得明确用户选择：A母结构、B连续方法、C双后代深层轴。下一步只制作L2/L3迁移预览；预览再次获得用户确认前，不把任何v2结构提升为Working，也不启动C02或C06正文。
