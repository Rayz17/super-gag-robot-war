## 0. 本轮究竟裁决什么

本轮只决定C01-C05中哪些**故事事实、章发动机、人物选择、机体结果和高光场面**可以进入全剧结构三案的共同前史。它不等于冻结逐句文字，也不等于跳过后续演出规划、Episode Reader和台本修订。

三个裁决代码的含义：

- `A / ACCEPT_CURRENT`：当前章的故事脊柱与不可逆结果可直接成为前史；以后只做不改变故事的表达、演出和台本优化。
- `B / TARGETED_REPAIR`：章发动机成立，列明的高光与结果可以继承；问题场面必须定向返修，未经返修的细节不能成为后续硬事实。
- `C / RETURN_TO_ENGINE`：当前章连故事发动机或关键选择都不成立；只保留单独列出的素材，重新设计整章。

## 第一批：C01

### C01《闭馆以后，万机出击》

**三句话故事**

万机馆最后开放日，纪存带观众走完闭馆路线，玩家先认识它是一座即将被拆散的机器人博物馆，也看见它曾是一艘巡展舰。裂星潮突入体BREAKER袭击城市并主动追逐万机馆，退役展品馆守Z从展台起身，与勇拳试作机以双拳击碎敌壳，却永久失去原战斗右前臂。敌方飞行核心继续追击，纪存让万机馆恢复航行，把战场从居民区带向海上；旧馆由此完成第一次身份翻转，开始第七次巡展。

**最强场面**

馆守Z从中央展台站起，拿起真正承受过碎片雨的退役重盾走进广场；随后它与勇拳完成双拳接力，右拳贯穿BREAKER外壳并再也没有回来。战斗胜利后，外壳中的飞行核心升空，万机馆的导览图切换成百余米巡展舰状态图，整座馆从“被保护的建筑”变成带着敌人离城的行动主体。三个场面是同一条升级链，不是并排摆放的奇观。

**目前仍需留意，但不足以推翻本章的点**

- G.A.G.、机魂、模型锚件与实机的完整关系只做神秘感埋种，后续必须按揭示计划解释，不能靠C01临时百科补完。
- 馆守Z、轮式导览终端“旧守护者”和万机馆是三个不同实体；台本和美术必须持续用尺寸、声源与位置让玩家分得清。
- 机械变化已经从早期“一厘米挪动和大量零件名”收束为起身、破墙、取盾、离港等大动作；后续演出规划仍需继续控制工程细节。
- 七海位于代哥东区封存中心，只能撤回自己签发的停机令，没有城市防卫指挥权；后文不能再把她写成远程总指挥。

**不可丢失的事实与高光**

- 闭馆生态与拆散馆藏的现实压力。
- 四站闭馆路线对万机馆厚度、馆守Z、模型文化和未开放区域的展示。
- 馆守Z在C01E02首次实战，原战斗右前臂在C01E03永久毁损，未来必须有重新获得右臂的成长线。
- 勇拳试作机与豪司的首次并肩；双拳不是单机必杀，而是两台不同世代机器人的接力。
- BREAKER地面壳与飞行核心的二阶段身份翻转；白色采样体只取得碎片，不在本章解释幕后全貌。
- 万机馆恢复巡展舰航行能力并开始第七次巡展；尚未获得完整战舰、人形变形或暴走能力。
- 纪存主动把敌人带离城市，而不是被动逃亡。

**主笔建议：`A / ACCEPT_CURRENT`**

理由：本章已经具备清楚、外放、可操作的机器人大战开局，人物选择、城市危机、机体牺牲和万机馆身份翻转互为因果。现存风险主要属于后续揭示与演出表达，不需要重新打开章发动机。

## 第二批：C02-C03

### C02《木桶街，万机初开》

**三句话故事**

受损的万机馆来到木桶街寻找足以让巡展舰继续航行的退役主转子，纪存一行在模型、维修史与六米实物之间找回被商品页面抹掉的真实差异，也让唐胶第一次面对自己帮助别人遮掉维修痕的旧手艺。平台把四台同骨架飞行机压成一个商品号，又让清仓鲸按异常名单抢走工程样件、维修记录和万机馆新转子；玩家帮助四机以各自不同的动作作战，旧拳王也从失败录像中重新学会如何赢。万机馆与木桶街共同守住开放日，恢复一条停产附属件生产线，取得前往工务城的资格；白鸢追随被盗用的分镜来到现场，完成有限行动预演后登舰。

**最强场面**

一个中年收藏者终于拆开被平台标成“未拆原版”的旧教学模型，盒底仍留着他童年的姓名贴和唐胶当年的灰色垫片；这件小物不是直接变成巨机零件，而是引导唐胶和陆衡回到六米实物上找到被删掉的维修事实。它把收藏者的感情、唐胶的旧账、模型文化和万机馆的现实维修接到同一件事上，是本章最不可替代的场面。

**当前阻塞点**

- C02E01虽已比后续Runtime试稿完整，但转子物流、平台抢位与巨环控制仍抢走了唐胶、母亲和具体物主的情绪中心；第一话需要重新配重，而不是再加规则。
- “总是在救援”的动作同质化仍存在。四机人格战、拳赛和清仓鲸战已经有差异，局部段落仍需把目标从安排、托举、抢运改成更鲜明的对抗和胜负。
- 平台本地席、异常白色组件、归一星和清仓鲸的关系必须用玩家可见因果表达：哪些是平台逐利，哪些是外来劫持，不能只在资料折叠区解释。
- 白鸢的纸面分镜不是魔法。当前口径是把摄像、地形和动作送入移动模拟器做L1候选路线，驾驶员可以改或拒绝；这一机制需要在她首次到场时用一个简单操作完整演给玩家看。
- 第一晚纪存与七海的关系有温度，但两人没吃成的饭、七海所在地点和白鸢后来如何得知，必须遵守可见信息来源，不能靠作者默认她们共享场外知识。

**不可丢失的事实与高光**

- 母亲接着完成已故儿子的维修委托，以及委托最终被孩子拿去玩的回信。
- 童年姓名贴、教学模型、唐胶修补史和六米实物之间的证据链；模型提供历史与设计线索，陆衡负责全尺寸工程验证。
- 火种货柜领袖是可变形的救援车队生命，帮助公共车流并护送万机馆；无牌一号是约八米的实体作业机，不是模型巨大化。
- 四台同骨架飞行机拥有不同维修史、动作习惯和选择；不能重新压回“同模四色皮肤”。
- 旧拳王通过失败录像、真正基本功和小拳登鲸完成本章胜利，并正式进入万机馆训练位。
- 未发售样件从制造起就是约两米实体原型；它自主启动，不是玩具突然膨胀。
- 木桶街首次公开开馆、停产生产线重启、工务城试验泊位开放。
- 白鸢在E03末肉身到场，E04第一次使用L1行动预演，章末以追索者与观察者身份登舰；她尚无直接改写现实的权限。

**主笔建议：`B / TARGETED_REPAIR`**

理由：四话发动机、机体群和情感物件已经成立，推倒会损失目前最有生命的模型文化场面。需要返修的是E01配重、阵营可见因果、战斗动作差异和白鸢首次能力展示；这些都能定点解决。

### C03《工务城，谁在让城市站着》

**三句话故事**

万机馆为新转子做全尺寸校正时，被工务城当成临时承重点压在城市下方；已经被撤销任务的自治工程机衡令依靠灾时离线钥匙继续征用职业机，并试图把所有不标准身体改成可跨城复制的工具。陆衡承认衡令使用的是自己为进入市场而删掉现场语境的旧程序，唐胶、本地工务员和四台职业机则用真实磨损、地方经验和不同动作夺回城市；豪司与社勇王完成首次正式合体，却在第二锤会伤及住宅时接受机体拒绝，改用施工形态赢下战斗。工务城成为万机馆第一个可返回港口，七海放弃当次复职面谈、以有限调查身份登舰；二十七年前旧信与天空铸环当前求援同时抵达，纪存发出“百机航路”邀请。

**最强场面**

社勇王堂堂正正打出第一记黄金巨锤，Boss耐久确实降到最后阶段；第二锤却会把冲击传进住宅，主体AI拒绝执行。豪司不是被训话后退场，而是撤回攻击，与社勇王把巨锤拆成施工工具，在馆守Z和四台职业机配合下移动城梁、夺回城市。这让勇者系爽点、拒绝权和玩家战术换挡在同一个高潮里成立。

**当前阻塞点**

- 衡令、灾时离线钥匙、承点、职业附件和陆衡旧程序集中在前两话，术语坡度仍偏陡；正式演出必须让玩家先看见“城市停摆和机器被锁直”，再理解程序来源。
- 唐胶与陆衡的分工虽已补清，台本仍需反复遵守：唐胶读出手修痕和现场窍门，陆衡验证真实尺寸、载荷与安全边界，两人都不能单独完成另一人的工作。
- 七海的返程票、三人热饭和放弃复职都偏含蓄，Episode Reader与台本要让她真正做出选择，而不是只靠观众读文件箱。
- 衡令带着受损本体和旧程序逃走，必须作为长期敌方行动继续发展，不能在工务城后失踪。

**不可丢失的事实与高光**

- 四台职业机以专业协作夺回城市，不因动作整齐就失去人格；其中三台留城，消防架桥机回原城。
- 陆衡暂停旧跨城资质并公开十七个部署地，旧错误没有因本章坦白一次就自动结清。
- 社勇王四模块现场合体、黄金巨锤第一次成功、第二锤拒绝与施工工具形态；豪司取得三个月公共道路试用驾驶。
- 城梁一号移动到新承点，永久改变城市道路与天际线；万机馆获得真实可返回港口。
- 无牌一号经正常工程列抵达并常驻万机馆。
- 七海以随舰事故观察员和旧签名滥用调查员登舰，没有恢复代哥现职权限。
- 当代求援与二十七年前迟到回信同现，但不能据此认定来自同一艘白舰。
- 纪存主动发起百机航路；这是邀请与协力网络的开始，不是百机已经集齐。

**主笔建议：`A / ACCEPT_CURRENT`**

理由：章发动机、勇者高潮、陆衡责任、七海登舰和下一章因果已经闭合。剩余问题主要是术语显隐、对白和演出承载，属于下一层的表达修订，不应重新打开故事结构。

## 第三批：C04-C05

### C04《天空铸环，谁给机魂一副身体》

**三句话故事**

万机馆为更换承力结构抵达天空铸环，遇见心墙零式、岛卫三号、潮墙巨兵和可换装巨机百相，也第一次看见机魂在维持匣中等待身体的现实；七号选择一副普通、可维修、可替换的公共作业体，而不是唯一而华丽的英雄身体。二十七年前曾与三条地方防线交战的断冠袭击铸环，先被四机接力击退，继而学会我方位置和交接顺序、反过来击溃同一套路；米拉与艾达的黑城战线、七海被冒用的旧身份和白鸢有限预演同时进入冲突。纪存不夺取百相控制，只作为“下一棒”的临时导航，与韩秀雅及多谱系机群设计第二套接力，把铸环送回天空并保住机魂身体生产线。

**最强场面**

第一战，岛卫改变落点、潮墙承接重量、心墙用两面防壁收窄通路、韩秀雅驾驶单臂百相从空处切入，四台不同谱系巨机完成漂亮接力。断冠没有立刻复仇，而是让分裂体逐一站回四个交接位置，把整局动作带走；下一战它用我方赖以取胜的秩序反克我方。这个场面同时具有EVA式同步作战、圣斗士“同一招不会再奏效”和机战多作品协同的可辨认快感。

**当前阻塞点**

- 五话同时承载机魂身体伦理、三旗舰二十七年战争史、米拉/艾达关系、纪存导航天赋、白鸢L2前置和断冠学习能力，主次仍过密。需要按情绪中心重排场面，必要时扩话，而不是继续压缩说明。
- 早期V16里获得认可的IP投射与人物冲突有一部分在物理修正中被削掉。应有选择地恢复“作品精神和角色伤口”，不能恢复旧版中百相夺魂、巨体互拖和站位矛盾。
- 纪存的导航天赋必须继续被理解为感知多机动作交接，不是远程驾驶所有机体，也不是此处直接公开“他是机魂实体”的真相。
- 白鸢目前只能把实时资料放进模拟器预演可能路线；她的L2能力若在本章发展，必须明确代价、操作者和可拒绝性，不能用“画一条线”替代因果。
- 七海只处理自己七年前身份被冒用的证书链，没有军方授权权；她重返旧地需要更强的人物冲突，不能只剩技术操作。
- 三旗舰的植物盒、缺席毕业照和隔离声道旧爱很有生命，但每件物品都必须在战斗选择中得到一次真正回响，不能成为漂亮人物卡。

**不可丢失的事实与高光**

- 天空铸环的六百米山体结构、三旗舰与待身工房；万机馆不能拖动整座铸环。
- 机魂可以在维持匣中持续存在，但需要供能、散热和感知接口；身体是生存与行动载体，不是随意更换的皮肤。
- 七号选择八米公共作业体；模型维修样手只保存过往改修思路，全尺寸身体由工房另行制造。
- 心墙零式两面防壁与拒绝第三墙；岛卫三号缺席毕业照；潮墙巨兵双驾旧爱；三者都承载二十七年间地球持续受袭的历史。
- 韩秀雅是百相唯一正式驾驶员；纪存肉身留在万机馆或实际所在位置，只提供有限导航，不进入百相夺取控制。
- 米拉与艾达、黑城及强化人悲剧投射必须保留并增强可辨识度。
- 断冠的第一次学习、我方第一次败战、第二套接力反胜；断冠是有编号和人类呼号的具体地外敌，不是神话化抽象概念。
- 天空铸环生产线存续，万机馆更换承力脊节，下一章百相试航具备现实条件。

**主笔建议：`B / TARGETED_REPAIR`**

理由：章发动机、敌我学习反转、巨机接力和人物物件均有强烈潜力，不应推倒；但当前信息密度和IP情节恢复仍未达到直接冻结标准。应先做一次“主次重排+选定高光恢复”，再决定是否扩为六话。

### C05《百相试航，巨人里醒着另一个人》

**三句话故事**

百相公开试航取得大胜，纪存以多机交接感知协助韩秀雅，却发现战装局正用伪造的七海电子签名、公开遥测和四名远程操作员，把这种有限协作包装成可复制、可接管的标准副驾。万机馆夺回服务器箱与不可复制的实体接驳钥匙，压制百相四套外挂，取得首次正式多格母舰部署并赢下战斗；与此同时，百相本地副驾核中出现一个只能继承少量导航经验、却开始独立回应的新声。运输舰事故令四名操作员坠落，百相放弃离开的窗口回头救人；纪存也放弃击伤百相、强留巨机的机会，馆守Z与万机馆把他们一起拉回，韩秀雅和试飞组随后摆脱远程接管离开。

**最强场面**

本章把“胜利”和“选择”拆成两个高潮：E05中万机馆作为多格母舰正式进入棋盘，玩家确实击落百相外挂、夺回服务器与实体钥匙，拿到永久能力和入队奖励；E06中，失去外挂的百相听见新副驾第一次说出样本里没有的“左边”，转身抱住坠落操作舱。玩家本可趁机打断百相左腿把它留下，纪存却让全队收枪，馆守Z发锚、万机馆绞盘回收，把巨人和人一起拉回来。这不是把上一话胜利判错，而是在已有胜利之后决定自己要成为什么样的队伍。

**当前阻塞点**
