## 4. G2-05人工复核

### C02不是四项桥接清单

三案都把四项桥接结果放进一场有私人欲望、对手和巨大机器人动作的完整事件：

- A的胜负问题是旧拳王能否赢下正在坠落的天门，同时阻止断冠夺走“冠军动作”。
- B的胜负问题是能否拆开完美队列，让旧拳王用步法救下移动拳馆、承重件与万机馆。
- C的胜负问题是能否在样本赛事中保住旧拳王完整身体，并拖着万机馆把失控货运环停进泊位。

四项桥接均由同一胜局产生；没有另开四趟运输任务。至于三案哪个真正精彩，将交由G3目标玩家与编剧席裁决。

### 未来峰值未被遗漏

三案均明确落位：百机航路、百机祭真胜、好日子、索引正面功绩、万机馆高收益暴走与分舰、二十七年归航、未发生者/What-if、完美终极机真胜、最强机普通用途、逆合体、全机群回援、远星余韵。

### 机体不是数量占位

三案均提交驾驶员/主体、首登、代表战、升级、关系、分舰/离队、回援和永久奖励表。A采用29包动态轮换，B采用17个重点完整包，C采用30包；这只是各案的创作选择，尚未证明资产规模、故事密度和热门度最优。

## 5. 移交G3的真实风险

以下不是机器错误，不在G2强行修：

1. **A的饱和风险**：C02与若干大会战同时动用大量主力、断冠、复制体和轨道奇观，可能精彩，也可能在实际章节中争夺情绪主语；29包“全部拥有生涯”是否真能落地需机甲席审。
2. **B的压缩风险**：18章却反推101话，单章平均容量最大；六处`entry_state`没有直接复述上一章结果，需要编剧席确认是文字差异还是实质跳接。
3. **C的扩张风险**：28单元、30包、12势力和15类玩法最宏大，也最可能稀释群像或让双后代母题吞掉机器人大战；目前没有明确总话数和制作预算。
4. **三案C02共享拳王/移动基础设施母题**：地点、胜法和对手不同，但桥接约束使三个新C02仍有家族相似性。目标玩家席必须判断哪一个真有独立魅力，不能因“比旧稿合理”就判好。
5. **人物表不等于人物戏**：生命周期表都很完整，但唐胶、兜灯、赤罡、莉歌、豪司等是否在连续阅读中真正有外放场面，要由编剧和玩家席检查。
6. **索引正面胜利高度一致**：三案都接受“索引先真救城再进入接口”的上位承诺，G3应检查具体执行是否仍像同一套行政调度故事。
7. **后盘共同峰值相同**：真胜、普通用途、退出故障、逆合体是必须保护的功能；审查重点是三案如何用不同人物因果抵达，而不是因结尾功能相同误判换皮。
8. **关系烈度需冷读**：三案均写入身体距离、嫉妒、分舰破裂和牺牲条件；是否真的“好磕”不能由关系表和自检回执证明。
