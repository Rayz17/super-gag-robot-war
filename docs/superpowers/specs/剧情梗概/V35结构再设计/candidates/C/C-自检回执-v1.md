## 2. 隔离与工作顺序

1. 第一遍先读取两份指定Skill、G2共同输入、候选合同与Current Canon的身份/物理边界。

## 3. 中央因果不是“旧结构加索引支线”

### 一条可复述因果链

纪存建立百机航路以免再漏掉任何人，索引建立公共体航路以免正确答案再迟到；两者各自救城并互相改进，共同赢得百机祭和玩家批准的共享接口；四位核心人物在全相环灾难里同时开启自己最有效的保护，万机馆因此先大胜再无法退出并物理分舰；三舰在归航移动文明和实体失败未来中学会无中央协作，却也共同选择当下唯一能赢的神座式；真救世之后，纪存和索引都被自己的总路由锁住，只能与全机群执行逆合体，再把同一批最强模块改成可换位、可拒绝、可退出的万机殿。

### 删除索引测试

若删掉索引，不只是少一条支线，而是以下中央事件无法成立：

- C04七灯弱机守城没有独立英雄和第二种救援方法。
- C08主角缺席的公共真胜利、七海改革民意和玩家批准接口的可信理由消失。
- C10“真安全仍需选择”失去执行主体，只剩七海和规则辩论。
- C11百机祭无法由两张成熟网络互相复原，C13也没有共同批准接口与双向失控。
- C21完美生活不再是曾经真救过人的迷人方案，只会退化成廉价幻觉。
- C22神座式没有来自二十七年安全答案的可信闭合计算，C23真终极胜利失去第二位共同驾驶英雄。
- C26没有支持者拔钥匙、七号公共体毁损和有限具身，C27逆合体只剩“打坏坏AI”。

结论：索引是从第一部到终局持续制造主因、胜利、关系、机体与玩法的第二英雄，不是后盘附加反派。

### 删除纪存测试

若删掉纪存，索引线同样不能单独承载本案：

- C01/C03固定前史、万机馆、百机航路和被弃回应后代全部失去主语。
- C07关闭普遍监听、C13“听见所有人”造成的总路由与C20烧断高带宽无法成立。
- 索引没有另一个同源后代可理解它为何恐惧迟到，也无人用冷门机、旧伤和迟到回信证明非最优协作。
- C26的镜像自认与C27两位有限后代互换主角席消失。

结论：本案中央冲突是两条英雄方法彼此成就后争同一最强位置，不是一个主角对一套外部制度。
