## 三、旧结构的实质治疗差异

1. **串场方式改变。** 旧结构常由新邀请、接口或待办开启下一章；A案由上一场胜负制造下一场条件：C02风帆只能去C03，C04两位英雄的大胜必须进入C05试航，C08让断冠学会撤退后才有C09三线突袭，C11脉冲延迟唤醒C14旧锚，C14三舰只能被C15迟归委托重新拉到同图。
2. **长期对手改变。** 断冠从C02带伤冠军争夺一路成长到C20最后主角席，不是章末取样员；它会输掉冠环、救走同族、在异地赢节点、取得指挥块、击穿归航城外层，并把上一场学到的动作变成下一场实战。
3. **C04/C05人物主语改变。** 旧身体方案字段被压到后台；前台改成纪存与韩秀雅争当英雄，两人C04都真赢，C05由纪存享受服从而犯错、百相新副驾和韩秀雅先回头救人。
4. **强大先幸福。** C06完整合体、C07完整轮值组合、C11百机祭、C13索引救城、C14万机馆巨躯救援、C20神座式救世与C21普通用途均先取得真实收益，代价延迟且不取消奖励。
5. **人物战争进入地图。** 纪存扩大/关闭监听改变可被追猎范围；七海的托管与公开脱离改变舰群、合法性和联盟；白鸢封路与开门改变真实撤离。三条关系边会改变支援、分舰、牺牲和抢回，不只在结算页加好感。
6. **机体有整段生涯。** 29包逐包列出首登/拥有、升级、关系困局、分舰位置与C20/C22动作；城市巨构、外部友舰和路线机保留尺度，不用模型盒、支援影或终局点名充数。
7. **后盘不压成终局摘要。** 迟归一人C15与移动文明C16分开；失败未来C17与完美生活C18分开；共同工程C19、终极真胜C20、普通一周C21、逆合体C22各有独占高潮。
8. **开放不等于弱化。** 神座式不会被揭成骗局或炸掉；万机殿保留合体战力、分舰、停机和后游戏，只拆固定槽。

## 四、C02为何不再平

旧C02的平，不在四项桥接本身，而在四项结果分别占据场面，主角只是被送去C03。新C02只讲一件大事：**一场决定坠落轨道环命运的巨型机器人大奖赛，断冠来争“赢过所有机器的动作”。**

| 桥接义务 | 新因果中的自然结果 |
| --- | --- |
| 有限航行能力 | 冠军权限才能启动风帆转子；机群夺回五段货轨后，万机馆借整座坠环弹回高空，只够飞到工务城 |
| 陆衡合作 | 他反对硬炸天环，把自己的硬停算法交给驾驶员现场改写，先与队伍共同赢过一次，C03再面对衡令旧错 |
| 白鸢肉身与L1 | 她追盗用分镜的白框复制体到赛事现场；预演只来自旧图、传感和机体数据，并被旧拳王当场改线，不是未来视或现实改写 |
| 旧拳王到场 | 旧拳王本来就是最后一届参赛者；它靠训练、停手习惯和父子维修组赢得随舰资格，不从C03开场凭空出现 |

这一章还有独立的玩家快感和全剧后果：移动擂台、五路追车、单臂摆荡、白框无伤冠军、断冠王牌战、坠环弹射；赤道风门真实获救，旧拳王与火种五机获得生涯，断冠也从此把万机馆认作长期对手。即使删去所有桥接字段，它仍是一章能复述、能剪PV、能改变全剧的故事。
