## 2. 为什么不是 A 式二十二章治疗

本案与合同中 A 路径的差别不是少一章、多一章或换标题，而是结构生成方式不同：

1. **先产生新中央因果，再决定容量。** B 案由“航路开放→撤退战法泄露→三地受袭→索引真救城→公众批准接口→巨体救援停不下→分舰通信延迟→归航群抵达→白框主体释放→开放路线被同时追猎→被迫造封闭最强解→胜后退不出→逆合体”反推六部十八章、一百零一话。
2. **旧章壳与五套旧装载整组舍弃。** 遗产表中 `old_chapter_engine`、`old_character_relationship_bundle`、`old_mecha_ip_bundle`、`old_gameplay_reward_bundle`、`old_world_branch_bundle` 共 85 行全部为 `DROP`；只把经审计的功能重新写进 B 事件，不把旧 C06-C22 改名成 B04-B18。
3. **十七个后盘功能重新聚类。** 自愿合体与轮值核心共享 B04 同一组合危机；安全选择与索引正面证明共享 B07 同一救城；高收益巨体、同意过的接管与分舰共享 B10 同一物理联锁；个人迟归 B11 与移动文明保卫 B12 刻意拆开；真终极胜利 B16 与退出失败 B17 之间保留时间缓冲。
4. **部容量不匀速。** 六部章数为 `3/3/3/3/2/4`；B10 需要 8 话完成真收益、三人越界、内外双战场和物理分舰，B17 只用 4 话完成胜后享受与普通退出故障。容量不服从旧统一章格。
5. **旅行不是站点邀请。** 每章的 `next_engine` 都是上一章留下的实体通道、敌方学习、伤亡需求、接口、分舰延迟、物证或故障；没有“收到下一城市邀请”作为串场发动机。

固定 C01、C03 仍位于开局，是因为共同输入锁定结果，不是因为沿用了旧二十二章母盘。C02 恰好承担两者之间唯一必须重建的桥，因此 B01-B03 与其他十五章的生成逻辑不同也有明确原因。

## 3. C02 新戏剧发动机证明

### 发动机

《奔城擂台》的单一问题是：一列载着工务城承重件、少年拳馆与大量车辆的环城货运列车被“不得单独脱离”的完美安全程序锁死，正在加速撞城。罗莎琳已把事故包装成旧拳王对无败王冠的直播败北；陆衡必须停掉自己参与编写的删语境程序；穆萨想让旧拳王以救援而非怀旧结束生涯；白鸢则被关在会预写零伤拳路的测试舱里。

四个桥接结果不是四份任务：它们都由“把失控整列车逐段拆开并把万机馆甩进工务支线”这一场高潮同时产生。

| 固定桥接 | 戏剧内生成方式 |
| --- | --- |
| 万机馆有限航行 | 馆守Z单臂挂住货车，旧拳王击开联结销，陆衡借列车惯性把万机馆甩入支线；只获得去工务城的有限能力 |
| 陆衡建立合作 | 纪存把百余米舰体真实交给陆衡掌舵，陆衡用现场测路而非作者补课完成最后转向 |
| 白鸢肉身接触且 L1 | 她从无败王冠实体测试舱跳上万机馆；肉身接触只提供约九秒碰撞分支，最终决定仍交给陆衡和驾驶员 |
| 旧拳王自然到场 | 旧拳王与少年拳馆本来就在失控列车上；穆萨以救援步法完成主胜利后，把巡展货舱经营成流动拳馆 |

### 机器人大战体验

- 高速列车顶层多层 SRPG，不是运输过场。
- 玩家驾驶旧拳王跨车厢垫步、摆拳改横摆、击开联结销，拳击身体语法直接解决巨物运动。
- 陆衡测路机铺只能维持数秒的转向面；馆守Z以永久断臂状态承担挂舰和支撑。
- 无败王冠能复制标准拳路，却无法理解旧拳王为救人而主动改变重心；Boss 规则由机体生涯破解。
- 最终大图是整列车的惯性甩动万机馆，不是获得导航许可证或完成维修清单。

### 关系转折

纪存第一次把控制权交给刚认识的陆衡；白鸢第一次不替纪存挑一个未来，而把三种碰撞角交给别人；穆萨第一次承认拳王可以靠救援而非击倒获得正式胜利。三种信任都在同一驾驶动作里成立，并直接改变 C03 谁能合作、谁已登舰、哪台主力可用。

## 9. 主动风险与开放变量

1. 一百零一话是按当前高潮容量反推的候选数，不应在三案选择前锁为制作承诺。
