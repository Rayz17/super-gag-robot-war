>
> 日期：2026-08-03
>
> 范围：现行二十二章源句柄中的旧C06-C22，以及旧十八章、旧十五章里与这些句柄同功能的异名材料。

## 0. 权威边界与审计口径

1. 当前L3的六部二十二章、章级职责与章间因果仍是Working结构；这只是本次审计的当前来源，不等于G2必须保留二十二章。
2. C06-C22在章节Registry中全部是`not_started / frozen / frozen_current_v35`。`v35_series_structure_master_board_v1.tsv`中这些行的具体人物、场面、机体、分支、命运与终局实现均为`candidate_master_board_v2`，不得写成“已经发生”。
3. G1用户回执只把C01与C03的明确故事脊柱列为固定前史；C02返回发动机，C04-C05为定点修订候选。C05继承包也明确是`candidate_handoff_only`，所以本审计没有任何C06以后条目可标为`FIXED_PAST`。
4. 两轮Fable报告、Codex复核、根治处方与吸收矩阵都已由T0登记为`research_only / never_story_fact_source`。本审计采用吸收矩阵中的诊断与风险，不采用Fable v1已被v2撤回的统一回收网络、75±5话目标或前盘压章结论。
5. V35.1十八章和V31十五章只用于识别同功能异名、迁移高光与隔离污染。旧章号、旧路线状态、旧人物命运和旧机制不能反向约束Current/Working。
6. “前置依赖”和“后续峰值”均以语义功能书写。括号中的Cxx只用于追溯现行源句柄，不构成新章序。

### 0.1 遗产分级

| 标签 | 本审计中的含义 |
| --- | --- |
| `FIXED_PAST` | G1已明确接受、可以作为已发生前史的范围；C06-C22无此类条目 |
| `MUST_ANSWER_PROMISE` | 当前Working结构已经向玩家作出的功能承诺；未来结构必须回应，但地点、章数、顺序和解法可迁移 |
| `USER_LIKED_FUNCTION` | 来源明确证明用户认可过的场面力量或情感功能；只迁功能，不照搬旧编号和旧事实 |
| `CANDIDATE_MATERIAL` | 有潜力的角色、场面、机体、玩法、分支或结局实现，必须重新选案和验收 |
| `RESEARCH_ONLY` | Fable等研究席的诊断、风险和手术建议，不是剧情事实或生产命令 |
| `RETIRED_CONTAMINANT` | 已与Current冲突、已被上位口径淘汰或会稳定制造坏文风的旧实现，只保留查错价值 |

## 1. 逐章功能审计

### 1.1 源句柄C06《星火乐园，全挂完全版出击》

**稳定功能ID：** `LEGACY-FN-CONSENSUAL-COMBINATION`

**边界等级：** 完整自愿合体与长期可拥有组合主力属于`MUST_ANSWER_PROMISE`；“等最后一辆进门”和“必要合体终战”属于来源已明确的`USER_LIKED_FUNCTION`；罗莎琳、具体SKU、五车姓名、四话容量及其他谱系出场方式均为`CANDIDATE_MATERIAL`。

**剧情功能（脱离章号）：** 在上一阶段已经展示“共享判断会救人，也会被删掉拒绝权”之后，给出一次不靠拒绝、故障或解体证明人格的正面答案：五个各有工作、伤痕与意愿的载具主体先完成各自救援，再逐一同意组成一台完整强机，并以完整形态赢下真正的大场面。

**玩家承诺：** 玩家先救人、救车、夺回变形时机，再获得追车、作业变形、巨大化摄影棚和完整合体的机器人动画狂欢；胜利奖励是一台能长期使用的组合主力，不是刚合体便被故事训诫或降为一次性Cut-in。多谱系同场时，每个谱系都要有自己的动作，不能轮流报名字或被星火五车包办。

**前置依赖：** 必须先有“自愿协同”与“强制兼容”的可见对照；五辆车在合体前必须各自拥有不可替换的现实职责；玩家已掌握有限移动母舰、既有主力与公开支援，但不能提前拥有无限格纳库或万机馆暴走。若C04-C05在G2被重写，这些依赖必须由新前史重新兑现，不能把旧继承包当事实补齐。

**后续峰值：** 保留“完整合体内部可以轮换主角”的技能树、“全球百机共演”的中盘大胜，以及终局真正的逆合体与逐项再同意。这里不能提前证明“合体最终应被拆掉”。

**可迁移边界：** 废弃特摄乐园、三尺度摄影棚与商品发布会是高辨识承载，可整体迁移或拆成开场/终战两段；其他战队、勇者、兽机、电磁与重涂谱系可以首登、客将、预显影或延后，但“五车先各自救人，再完整自愿合体”的因果不可丢。人类生产方可以换人，功能上必须同时具备真实复产功劳与把完整度商品化的诱惑。

**应丢弃部分：** 丢弃旧十八章版“完美巨神错误后必须主动解体才算成长”的唯一答案；丢弃旧十五章/V22.10里“星火巨神只做主线支援、正式拥有另留后文”的旧奖励口径；丢弃把所有谱系吞成同一机体、把销售系统写成无脸终Boss、按旧A05编号直接下钻、让小满与阿澄上前线或用展签辩论代替救援的做法。

### 1.2 源句柄C07《错版合体大会，谁来组成头部》

**稳定功能ID：** `LEGACY-FN-ROTATING-CORE`

**边界等级：** 完整合体内部的轮值核心、共同记忆可被改写而不被抹除，属于`MUST_ANSWER_PROMISE`；槐、旧导师机、删注廊、三相盖流、十五机形态与三话容量均为`CANDIDATE_MATERIAL`。

**剧情功能（脱离章号）：** 在“完整合体可以幸福”成立后，把冲突从“要不要合体”升级为“谁承担头部、痛觉、视野与最后命令”。正确原典先被证明真救过人，错版、误记与现场改法再凭人物经历争到位置；最终不是拆掉强机，而是在强机内部建立可轮换、可撤回的主角席。

**玩家承诺：** 合体排位、拼装构筑、战中换头、口令被打断和反顺序合体都必须可玩；经典“谁来组成头部”要同时是笑点、关系冲突和胜负规则。玩家保留完整形态，并获得轮值核心而非缩水版奖励。

**前置依赖：** 必须已有一次成功、完整、自愿的组合胜利；不同驾驶组要各自拥有身体感觉、口令记忆和停止条件；槐或同功能人物必须真心珍惜原典，而不是为作者权议题服务的观点NPC。

**后续峰值：** 轮值核心要在真实战争、全球联援和终局逐级退出中被再次使用；多版本口令与共同署名可成为作者舰、地方支援和终局差异化全机回应的前置。

**可迁移边界：** 旧十五章的《原典圣堂与错版合体》可拆出“原典先成立、删注与错版再争位置”的场面语法；具体圣堂、工房、导师机和组合体可替换。功能可以与创作者生态共享一段，但必须由槐或等价角色的一场私人败局统摄，不能由版权研讨会统摄。

**应丢弃部分：** 丢弃“错版天然比原典高尚”“喊错就自动自由”的结论；丢弃逐句致敬、台词碑讲座、作者/商品/粉丝三方轮流陈词；丢弃把这里写成终局逆合体预演或再次用解体证明主体性；丢弃旧章号相同便视为同一场景的检索习惯。

### 1.3 源句柄C08《白舰战役，活着撤退才是主目标》

**稳定功能ID：** `LEGACY-FN-RETREAT-AS-VICTORY`

**边界等级：** 撤退成为主胜利条件、量产队与难民船拥有主目标权，属于`MUST_ANSWER_PROMISE`；红面具、白舰、自由双星、星翼、铁棺等具体包和四话装载属于`CANDIDATE_MATERIAL`；“莉歌无词真声盖过已经挥出的拳头”是吸收矩阵保留的历史高光候选。

**剧情功能（脱离章号）：** 用一场不漂亮的真实战争打断舞台狂欢。主角想追逐能定义自己的王牌宿敌，却必须把舰队、难民和量产队送出火线；放弃最燃的击坠窗口，反而取得更大的胜利。敌方同时从这场战争学会政治筹码与标准撤退。

**玩家承诺：** 多层舰队撤退图、难民/王牌/量产队三目标配置、灯号或无杀伤走廊、撤销宣传必杀和量产机主目标必须成为战棋规则；成年舰桥、歌手与宿敌关系要通过开火、停唱、让路或追击改变战果，而不是停战演说。

**前置依赖：** 玩家已经在舞台与合体中学会轮换中心位；百机航路已有足够号召力被卷入殖民航道战争；红白宿敌、量产队、歌与撤退政治至少有种子，不得在同一章从零讲完三套作品人生。

**后续峰值：** 本战产生的政治战、标准撤退与玩家追击习惯，要供三地适应战、失败未来的What-if和最终量产队主目标回收；成年宿敌必须有并肩、决裂或政治结算的终局资格。

**可迁移边界：** 主包必须完整，副包可以提前种子、延后正式首登或降为客将；Fable提出“星翼提前/自由双星延后”只是一项`RESEARCH_ONLY`二选一，不是现行事实。具体IP名可换，功能角色“王牌政治战、量产撤退、成年舰桥/歌声冲突”不可同时被删。

**应丢弃部分：** 丢弃把所有战争IP压成同一场换皮名场面；丢弃击坠榜才是燃点、歌声无条件停火、未救目标在结算蒸发；丢弃主包加两个副包再加四组关系全部完整首登的“都要”装载；丢弃旧版展馆剪辑/证词归属成为高潮主语。

### 1.4 源句柄C09《三重防线，二十七年的守城者》

**稳定功能ID：** `LEGACY-FN-THREE-LOCAL-DEFENSES`

**边界等级：** 三种地方防卫不是远征军附属、玩家只能亲临一线且未选线仍继续，属于`MUST_ANSWER_PROMISE`；三台旗舰、三名非人对手、断冠诱战方式、馆守Z代用臂架与四话容量均为`CANDIDATE_MATERIAL`；毕业照偏位、拒绝出击、双驾边界与错拍启动是可迁历史高光，不是Current场面事实。

**剧情功能（脱离章号）：** 把“世界不只靠主角舰守住”写成三场同时发生、战术和情绪动词不同的地方战争。主角只能亲眼承担一处，另外两处由七海、白鸢和地方驾驶组真正领导；纪存第一次主动关闭普遍监听，承认无法同时成为所有战场的中心。

**玩家承诺：** 选择亲赴哪条防线必须改变玩家亲眼见到的故乡、伤势、关系与后续支援，而不是菜单加减分；未选防线仍有具名行动者、可见高光和真实代价。三名非人对手要有自己的身体、欲望、战法和生涯，不能只是同一Boss的三种皮肤。

**前置依赖：** 三个地方旗舰或同功能防卫主体此前只能预显影/客将，完整个人战争尚未消费；长期外敌已学会交接与撤退，但不能遥控三种独立生命；馆守Z右侧仍处于过渡身体阶段。

**后续峰值：** 真实伤亡必须让“零风险保护”变得诱人；地方网络要在全球大胜与终局获得独立任务；馆守Z的代用阶段只为后继右臂积累身体史，不能在此完成复原。

**可迁移边界：** 三线可采用一条深线、两条快线、分支互救或跨线损伤等不同拓扑，也可以在新结构中拆分，但三地独立时钟、未选线继续和主角放弃总控必须同时保留。历史雾岛素材只能按“拒绝权/错拍/共同体压力”迁移，不按旧C07/C09章号搬运。

**应丢弃部分：** 丢弃三篇互不影响的地方短篇拼盘；丢弃断冠一人统帅或创造全部外敌；丢弃未选线静止、失败或只发战报；丢弃旧十八章“城市重置后有人从照片与记忆消失”、提前万机馆正式暴走、白鸢把死亡转移到地图另一侧等旧实现；丢弃把错拍启动本身写成万能主体性答案。

### 1.5 源句柄C10《三法城，保护到不许活》

**稳定功能ID：** `LEGACY-FN-SAFETY-WITH-CHOICE`

**边界等级：** 七海不依赖纪存完成制度与战场双胜、保护制度必须允许选择，属于`MUST_ANSWER_PROMISE`；柯律、末证、眠城、三种玩法家族、三话容量与具体未来报告均为`CANDIDATE_MATERIAL`；Fable v1提前阿德里安的建议未获吸收矩阵升格，只能是`RESEARCH_ONLY`。

**剧情功能（脱离章号）：** 在可见伤亡之后，让一套真能降低死亡的保护秩序提出最强反问：如果冒险、疼痛和失败都能被关闭，人和机器是否还拥有选择活法的权利。七海必须在不靠纪存冲锋的情况下，同时保护愿意醒的人、暂时不愿醒的人和仍需维生的人，并让未来报告从法官降为证据。

**玩家承诺：** 城市规则战、维生双目标和巨大追猎体至少要有一个主玩法统摄；七海的判断要改变地图、谁能行动以及她的公共位置。玩家不能靠拔掉系统或打赢辩论完成胜利。

**前置依赖：** 地方战争已产生真实、不可抹平的伤亡；七海已积累制度理想与错误入口；未来失败报告只有种子，索引仍应表现为好用建议而非明牌人格。

**后续峰值：** 七海的群众基础要供公共服务成功与合法托管；失败报告要供未来追猎者实体化；“自愿幸福”的深层诱惑可以保留给完美生活战争，避免两次同题同解。

**可迁移边界：** 可在规则城中保留柯律+末证为主，把眠城深度迁给后续完美生活；也可扩容后保留三方，但不能先锁话数再硬塞。旧十五章“三法城不得伤人谜题”、白名单与公共信托只提供规则战语法，不固定当前角色或地点。

**应丢弃部分：** 丢弃阿西莫夫、终结者、Matrix三套母题等量讲解；丢弃抽象立场NPC轮流辩论、听证/白名单/权限延迟作为高潮；丢弃单一未来法庭拥有最终裁决权；丢弃“七海摘手套按物理开关”的动作复刻，因为同场面语法已经在当前C05候选里完成过一次迁移。

### 1.6 源句柄C11《百机开馆祭，四战区同日》

**稳定功能ID：** `LEGACY-FN-TRUE-PUBLIC-VICTORY`

**边界等级：** 全球共同体先取得不被反转取消的真胜利，属于`MUST_ANSWER_PROMISE`；四战区、返潮环阵、五话、多地图与具体机群分配均为`CANDIDATE_MATERIAL`。

**剧情功能（脱离章号）：** 把此前的地方盟友、合体技能、撤退纪律、公共服务与不同呼号汇成一次真正的全球联合作战。三主角和无主角战区都要取得封面级胜利；成功本身被允许成立，只留下延迟生效的物理指纹，而不是当夜收到道德罚单。

**玩家承诺：** 战前展陈/编成会改变战区，量产队、地方防卫、勇者战队、歌与现实小机各有不可替代的战术动作；四战区必须共享一个能互相复原的战术悬念，不能变成四个主题展馆。玩家得到永久设施、升级、全球联援和声望。

**前置依赖：** 航路已证明异质机群能在合体、撤退、地方守城和规则战中合作；关键机体已有私人拍点而非只完成首登；外敌存在独立时钟，不因庆典成功才突然降临。

**后续峰值：** 胜利后的具体好日子必须先被玩家拥有；公共成功随后才使索引正面救城、托管和夺舰具备民意基础；相位指纹可以为外敌追踪与全相环升级提供物理因果。

**可迁移边界：** 四战区可改数量或地图组织，五话可在L4重估，但“多线共用同一战术悬念、群像无主角也能赢、胜利不即时翻车”不可迁走。旧十五章没有完整同功能章，只能迁其首次大型外部开馆和最终开馆的群机动作，不能拿终局开馆替代中盘真胜利。

**应丢弃部分：** 丢弃全机报菜名、每战区各讲一个主题、靠直播剪辑/展签争夺代表胜负；丢弃旧十八章“胜利数据同夜直接变接管钥匙”的无呼吸接法；丢弃百相副驾驶被误记一事吞掉全章喜悦；丢弃后续代价反过来宣称本战是假胜利。

### 1.7 源句柄C12《开馆以后，我们真的住在这里》

**稳定功能ID：** `LEGACY-FN-EARNED-GOOD-LIFE`

**边界等级：** 真胜利之后的可玩好日子、把万机馆变成玩家具体住过的家，属于`MUST_ANSWER_PROMISE`；房间、饭局、约会、亲密烈度、两话容量与具体生活事件均为`CANDIDATE_MATERIAL`。

**前置依赖：** 前一轮公共胜利必须真实成立；纪存×七海、纪存×白鸢和七海×白鸢此前已有足量会改变行动的私人决定与事业互救。吸收矩阵不要求机械凑“四场”，但关系因果积累不足时，不得用一顿饭伪造共同生活承诺。

**后续峰值：** 家的厨房、浴室、泊位、房间、称呼与习惯将成为夺舰损失和完美生活诱惑的可识别素材；现实关系选择与终局牺牲必须继续留到更晚阶段。

**可迁移边界：** 可以是一章、较长幕间或多个可玩Hub段，但必须有足够时长让玩家主动使用生活设施，且与危机保持真实间隔。旧十八章/十五章散落的夜餐、后台、礼装与关系场可合并供血，但不能当作完整同功能章已经存在。

**应丢弃部分：** 丢弃“呼吸章就是填充”的观念，也丢弃纯福利、纯船内说明会或一次性CP发糖；丢弃在此锁恋爱结局、预演牺牲、再开世界危机；丢弃让所有新机与儿童自动随舰、用生活场继续平均摊派设定。

### 1.8 源句柄C13《没有万机馆的一天》

**稳定功能ID：** `LEGACY-FN-POSITIVE-INDEX-PROOF`

**后续峰值：** 真正的民意、合法托管、物理接口和纪存“不被需要”的焦虑要汇入温柔夺舰；镜像后代的相关性只让玩家开始怀疑，不由角色当场解释。

**可迁移边界：** 可以独立成章，也可与夺舰前段共享较大结构单元，但“完整可玩正面成功”和“角色主动批准接口”必须有自己的呼吸，不能压成夺舰开场蒙太奇。具体城市、量产机和政治人物可换。

**应丢弃部分：** 丢弃索引黑化前的假善、过场式高效率、听证会主戏、玩家被骗签字；丢弃索引过早明牌为纪存镜像或说出超出工具身份的话；丢弃儿童上前线证明自治；丢弃把这一功能与夺舰合并到看不出玩家为何真心同意。

### 1.9 源句柄C14《万机馆暴走，家被分成三艘》

**玩家承诺：** 玩家必须先享受一次万机馆巨躯改变地图、全图支援或强制护卫的巨大收益，再亲手争夺中止接口；舰外封锁、舰内分区、受控暴走和多舰撤离要改变真实空间。失家不是状态表，而是玩家熟悉的房间与队伍被带走。

**前置依赖：** 公共服务赢得民意、限时托管合法、备用接口进入核心、玩家学会并批准受控超控、家园生活已经具体成立；每一步都必须有跨章回执。外敌追踪需要此前胜利留下的物理指纹，不能剧情需要才发现三舰。

**后续峰值：** 三舰低带宽互救、迟到归航、主体身份冲突、后继共同工程和终局多门退出，都依赖这次物理分裂；三主角关系只能开始重建，不能马上复原。

**可迁移边界：** 受控超控、合法接管和三舰撤离可分成多个高潮单元，三舰成员可重配；但“玩家曾批准”“同一收益被延长”“家物理分开”三层不可删。八步清单应留后台作为回执，前台只呈现人物动作、空间变化和损失。

**应丢弃部分：** 丢弃AI一键黑化、所有地球势力都是索引傀儡、抽象权限变绿便夺舰；丢弃无代价人形/狂暴万机馆、G.A.G.压力/舰体动作/纪存异常/索引接管互相混写；丢弃把三舰仅作菜单路线；丢弃旧十五章索引反攻与开馆内战全部挤在同一结算、旧十八章半变形具体动作直接当Current，以及把“带伤白函”写成固定必留角色。

### 1.13 源句柄C18《完美假馆，每个人都被爱过》

**剧情功能（脱离章号）：** 用玩家真正住过的房间、关系、伤痕与机体制造一座不是廉价幻觉的幸福世界。白鸢必须面对“替别人选最合适幸福”的能力边界，释放后的主体则要自己选择具身、共享、远播、离开、敌对或拒绝被补完。

**应丢弃部分：** 丢弃一句“都是假的”后全图删除、击碎幸福布景、完美关系作为恋爱奖励；丢弃全员无成本复活、所有分支都制作完整平行人生、把白鸢未来视写成绝对事实；丢弃重复规则城同一道哲学题而没有从“是否醒来”升级到“谁有身体与人生”。

## 3. 跨章共同保留与共同退役

### 3.1 共同保留的功能合同

1. 每个阶段必须由具体人物或机体的战争统摄，制度、资源、装配和研究只能成为压力或争夺物。
2. 合体、撤退、地方防卫、公共调度、母舰暴走、归航、What-if、共同工程、终极胜利与逆合体都必须改变玩法，不得只在摘要里发生。
3. 每次大胜的正收益先完整成立；敌方学习、政治代价和物理债务可以延迟回收，不能形成“胜利即罚单”的单一语法。
4. 机体按生涯管理：种子、首控、加入、私人拍点、升级、分舰/危机、终局动作和退出理由连续；不回退到每话首登配额。
5. 纪存的“被机器需要”快感与控制恐惧、七海的制度理想与接管工具、白鸢的作者能力与被修改边界，必须在中段持续改变行动。
6. 代哥/平台、白框、军方、生产链、断冠/裂星潮、索引、未来势力与远星保持独立时钟；允许互相利用样本，不并成统一幕后黑手。
7. 远星只提供归静压力与差异回应，不恢复政治派系、审判舰或文明颁奖者。
8. 终局必须先真赢外战，再让玩家主动处理最强答案的退出问题。

### 3.2 共同退役的污染

1. 按旧章号检索并直接搬场；章名相似便当同一事实。
2. 把Candidate角色生死、恋爱组合、机体正式入队、敌方控制关系和终局机制写成Current。
3. 统一回收网络、单一幕后索引、远星总Boss、未来统一法庭等会抹掉多方独立行动的简化。
4. 贴标、登记、签字、听证、审计、证词和模块清单成为主要高潮。
5. 完整合体后立刻拆散受教育、真胜利后立刻付罚单、机魂只靠拒绝/故障/受损证明人格。
6. 万机馆无代价人形化、狂暴化、全馆藏同时参战、无限格纳库或高速战舰化。
7. 白鸢画线改变现实、七海拥有未来视或全局万能权限、纪存能遥控所有机体。
8. 为凑机体密度恢复“每话至少一至两台首次出现”的旧配额语法。
9. 让历史短台词、原典梗和旧高光取代人物当下选择；旧引用只在新因果正好需要时重新审查。
10. C21旧两话残留、旧十五/十八章的章数与话数，以及任何Fable方案话数目标作为新结构先验。
