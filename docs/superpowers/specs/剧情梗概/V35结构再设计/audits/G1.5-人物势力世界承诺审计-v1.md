## 0. 使用规则

### 0.1 权威顺序

1. 2026-08-03 G1 用户事实裁决优先决定 C01-C05 哪些内容可进入三案共同输入。
2. L1 体验宪章、L2 总发动机、H0 机制基线共同约束作品承诺；三者不能被旧章表或旧人物表降级。
3. Canon 中 Current / Working 的实体和机制继续有效；若 Canon 尚未迁移而与最新 G1 用户裁决冲突，本审计记录冲突，留待 G5 迁移，不在本文件擅改权威。
4. 六层前提只锁机制、正功能、失控方式和终局接口，不锁六章、六部或具体章位。
5. L3、人物生命周期表、反派表、势力动作表、地外敌脊柱表提供候选功能与现成解法，不因被引用而升格为固定事实。
