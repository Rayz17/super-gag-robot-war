- 文档性质：三套全剧结构方案的共同输入；功能审计，不是新章序方案

- 非目标：本文不决定新结构章数、章序、首登章、正式加入章或终局章编号

## 0. 审计结论

1. 当前素材并不缺机体或 IP，真正风险是“表里有名字、剧中没有驾驶员欲望与作品级故事”，以及“首登以后没有升级、分离和回援”。三案都必须以包级生命周期为最小核算单位，不能以机体名录或单次彩蛋作为完成。
2. 77 条生命周期记录是库存，不是 77 台必收、93 台上限或平均配额；29 个既有包与 8 个晋升热门包也不是平均分章要求。每案可以合并、竞争替换或降为路线内容，但不得静默消失。
3. RQG01-RQG06C 所代表的热门高热度强机谱系必须逐项给出处置：核心保留、并入现有包、路线保留、同功能更强替换或明确封存。只有“没位置”不构成审计理由。
4. 玩法共同输入应保留 5 个循环、6 个系统家族及其互相供给关系。结构案可以重新安排教学和升级时机，但不能把探索、家园、制造、关系、战略网络拆成一次性小游戏。
5. 万机馆的固定底线是“会动的家、文化与关系中枢”，不是天然人形终极机。低矮巡游展舰是已确认前史结果；战斗展开、受控超载、分舰网络和万机殿开放组合仍须按候选层处理。
6. 13 类永久奖励都要有“得到、实际享受、受压后仍留存、恢复或升级、终局再用”五个状态。尤其真正完美胜利不能下一拍被宣布为假胜利，最强状态必须先被玩家正常使用。
7. 10 类分支拓扑可脱离旧 Cxx 章位继续使用。分支必须改变机体、人员、资源、治理或结局读取，并为未选路线保留执行者与失败尊严；不能只换台词。

## 3. Roster 总口径与质量门

### 3.1 完整包的最低合同

一个完整可玩机体/IP 包必须同时拥有：

- 一台或一组可辨认主机，以及不靠台词说明也能区分的轮廓、武装和战术位置。
- 明确驾驶员、共同驾驶者、核心 AI 或控制主体；控制权、所有权、维修权不可混写。
- 驾驶者的正向欲望、个人对手、生活或亲密关系，以及作品级矛盾，不得只剩“致敬名场面”。
- 一次代表性胜利、一次损伤/失败/关系破裂、一次机制或形态变化。
- 首次看见、首次协助、首次可控、正式加入、重大升级、主动分离、终局回援的可追踪生涯。
- 至少一个玩法触发器和一个永久回报；升级不能只换立绘与数值。
- 闭合胜利 F 与开放结局 G 中各自不可替代的动作，不得全员退化为支援切入。
- 对应作品精神、可公开转写的场景/台词状态、原创 What-if 与明确避让边界。

完整包不等于永久停放在万机馆。量产队、城市工务机、独立舰队、巨构、外部盟友和路线机可以保持外部驻留，只要可玩性、回援与结局状态可追踪。

## 4. 生命周期审计

### 4.1 七段生涯

每个入选包至少填写下列七段；空白必须标明“本案主动省略”及补偿功能，不能默认没发生。

| 生涯段 | 必答问题 | 常见误判 |
|---|---|---|
| 1. 首次认出 | 观众何时第一次把它认作该作品/谱系的独特存在？ | 背景剪影不等于首登 |
| 2. 首次协作或控制 | 谁能操作、借用、指挥或获得支援？代价是什么？ | 帮打一次不等于加入 |
| 3. 正式关系绑定 | 驾驶员为何留下？所有权、维修权、政治立场和生活关系如何落地？ | 进机库不等于成为万机馆财产 |
| 4. 重大升级 | 机体、驾驶者、编队、关系或玩法发生什么不可逆变化？ | 单纯数值加成不算升级 |
| 5. 分离/独立 | 它因什么主动目标离开、分舰、拒绝合体或转为外部路线？ | 未出场不等于有尊严的分离 |
| 6. 回援 | 回来时执行什么只有它能做的动作？前期关系如何兑现？ | 全员镜头或支援切入不算回援 |
| 7. 结局状态 | F/G、路线结局和后游戏中，驾驶者、机体、事业与控制权在哪里？ | “大家继续旅行”不能代替具体状态 |

### 4.2 77 条记录的正确用法

- 77 条包含主机、分机、量产队、舰船、巨构、敌体与新形态，不应被读成 77 台永久自有机。
- 首次物理出现、首次可玩、正式加入、所有权获得必须分列；社勇王的企业所有权与公路试用是现成校准例。
- 合体机既要记录组合体，也要记录各分机/驾驶者在拒绝、换位、缺员和分离状态下的价值。
- 城市工务机、量产队、独立舰队与行星巨构可以不登舰常驻，但必须保有调用条件、损伤、升级和终局动作。
- 馆守 Z 的继任右臂、白舰的后继旗舰、可变/觉醒机、身体路线、合体框架等升级，必须同时改变故事关系和玩法。

### 5.2 每个入选 IP 的吸收合同

每个完整包至少形成一条连续链：

作品精神 → 驾驶者欲望/关系 → 可辨认场景 → 机体动作 → 玩家触发 → 可见后果 → 后续再语义化。

具体要求：

- 第一次使用可以轻松、好玩或带梗，但必须在后续严肃场景中改变含义。
- 公开对白应原创转写；外部名句只作内部锚，控制可识别长度并保留法务复核口。
- 作品名场面必须被角色当前选择重新制造，不能靠镜头复刻代替因果。
- FMP、Dunbine、Ideon、Metal Gear 等覆盖表中较稀疏谱系若晋升完整包，必须先补作品级故事和驾驶关系。
- TARS、Chappie 等支援角色按真实尺度和功能进入，不为凑“巨机数”硬造巨大身体。
- 模型盒、招牌、锚件、维修单和背景展品不计机体密度；临时可玩、敌/Boss、场景机和新形态可按实际玩法核算。

### 5.3 What-if 进入条件

一个 What-if 只有同时满足以下条件才可进入结构案：

- 改动的是可被角色、机体、关系或物理条件触及的变量，而不是作者直接赦免。
- 有战斗、探索、制造、关系或分支触发，不从无上下文菜单领取。
- 至少说明成功代价、失败状态和失败尊严；失败路线也留下人物行动与世界后果。
- 不用廉价复活抹掉原作重量，不直接复制原作文本/镜头，不混淆未成年与成人关系边界。
- 每个故事单元以一个主 What-if 为上限倾向，必要时仅加一个次级 IF；这是密度控制，不是机械配额。

## 12. G1.5 验收红线

出现任一项即判该结构案未通过本席审计：

- RQG01-RQG06C 或既有选中包无处置，热门强机因表迁移而静默消失。
- 机体只有名字和招式，没有驾驶员/控制主体、欲望、关系、个人对手与作品级故事。
- 首登即加入，加入后无升级，离队靠长期不出场，终局只剩无差别支援镜头。
- 77 条库存被当作全收目标、硬上限或永久登舰清单。
- 玩法系统只在一章出现，升级只加数值，不回流到关系、家园、探索、制造或战略。
- 万机馆恢复天然人形、暴走神机、无限机库、百相胚胎或无成本终极兵器语义。
- 永久奖励在下一波压力中被叙事清零，闭合真胜利被立即揭成假胜利。
- 分支只换台词，未选路线无人执行，失败没有尊严，合流后差异完全消失。
- 开放结局以丢光力量和关系换自由，而不是增加退出、停止、拆分与治理权。
- 直接复制旧 C04-C22、旧 22 行玩法表、旧 95 槽或旧终盘章位，未重新证明因果。
