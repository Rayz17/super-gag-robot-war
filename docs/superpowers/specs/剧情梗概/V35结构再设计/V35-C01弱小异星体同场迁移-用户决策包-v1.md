## 裁决前权威事实

- C01E01：十几个小型接触点散在海面和低云，暂时被海防挡在城市外。
- C01E02：已验收Reader只演馆守Z对BREAKER地面壳，没有小体进入旧广场。
- C01E03：飞行核心显形后第一次发出脉冲，让外海小体由各自行动变成同一箭头。
- C01E04：小体进入离港与追舰战，核心毁灭后失去统一方向。

用户已经提出方向偏好：BREAKER首战应有一批较弱异星体同场，而不是棋盘上只有Boss。因为这会改变敌群首次进入城市战区的时间，必须裁决后迁移。

## A 保持当前故事

E02仍是Boss单体突破城市防线。小体全部被海防压在城外，E03核心显形后才首次编队进入主战场。

**效果：** E02更聚焦馆守Z与BREAKER，E03“核心召群”升级最清楚。缺点是E02战棋单位密度低，首战较像单Boss教学。

**返工：** 无。现行Reader、Canon、状态账和用户验收保持有效。

## B 少量无组织小体先漏入，E03才同步指挥

E02已有少量现有同类随BREAKER钻地造成的防线缺口漏入。它们只会各自扑击、游荡或围堵消防车和出口，不会配合Boss。馆守Z必须在挡住BREAKER的同时保护撤离线。具体棋盘数量由关卡尺寸、节奏与可读性测试决定，不升格为故事Canon。

E03飞行核心显形后，第一次把E02幸存小体与仍在外海的同类统一编队。玩家能够直接感到升级：刚才还是散乱骚扰，脉冲之后才会让路、包夹和追舰。

**效果：** 首战更像机器人大战，城市与支援单位更有战术价值；E03同步能力仍保留第一次，且从“前一阶段还是散乱骚扰”升级为“整个敌群忽然像一台机器”。这是当前推荐案。

**返工与失效：**

- 最早受影响层：C01完整剧情总纲、战斗预案与剧情—游玩拓扑；导演板需检查是否补一幅群体威胁画面。
- 故事层：C01E02、E03纯剧情Reader及机械合成章节Reader需定点迁移；E04仅复核小体连续性，不把关卡数量写进正文。
- 审读与回执：完整总纲之后的首读因果、逐话结构、状态账、四视角审查、累计连续性、演出承载、Reader因果/声线/章节审定及原用户验收回执均须按依赖失效并重跑，不能只改正文后沿用旧PASS。
- 账与说明：C01机体/敌群状态账、开放资料、游戏流程和敌方首登索引更新。
- L6后续影响：Current Demo与Godot的敌军部署、个体AI、增援/存量继承、胜败条件和Checkpoint状态都要重做；本轮只登记影响，不实施Godot修改。
- 美术与表现：补Q版弱小异星体的地图单位、动作/VFX与受击反馈，并测试数量可读性、建筑遮挡、Boss轮廓遮挡和滚动地图信息密度；本轮不生产资产。
- 验收：C01 Reader需要用户重新确认该局部迁移。
- 下游：C02、C03正文预计无需改写，但前章指纹、累计连续性和story-chain必须重新绑定并复核，不能静默宣称原哈希仍有效。

## C 只在游戏层放小体，不改Reader

关卡中凭空添加弱小体，Reader仍说它们在E03核心显形后才从城外同步汇聚。

**效果：** 制作测试成本最低，但故事与玩法会对敌群位置、首登和升级时点给出两套答案。正式版本不采用。只允许作为不回写Canon的临时战斗密度原型，用完即废。

## 原推荐与已回答问题

推荐 **B**。它不削弱E03同步指挥升级，反而让升级有前后对比，同时解决首战只有Boss的战棋单薄感。

原裁决问题为：
