# V35 G3四席独立审查接口 v1

> 状态：`Candidate / review interface`
>
> 适用范围：G2三案完成并通过机器合同后。本文只规定审查隔离和证据格式，不提供任何方案的标准答案。

## 1. 总原则

四席彼此独立，只找阻断问题，不改稿。每席三案合计最多十项，并对每案给出简短结论；必须给出候选稿中的具体证据、问题为什么会伤害玩家体验，以及问题最早产生在哪一层。不得因为自己偏好另一案，就把差异本身判成错误。

四席完成后，由一名总主笔统一判断根因并返修。总主笔每案只有一轮系统返修机会，不得把四份意见逐条并排塞回正文。

## 2. 共同输出格式

每项问题包含：

| 字段 | 含义 |
| --- | --- |
| finding_id | `A/B/C + seat + number` |
| severity | `BLOCKER / MAJOR / WATCH` |
| evidence | 文件、结构单元与原文短句 |
| player_harm | 玩家会如何困惑、无聊、失望或失去投入 |
| earliest_root | `L1 / L2 / L3 / lifecycle / chapter-cluster / expression` |
| diagnosis | 根因，不写空泛的“加强” |
| repair_boundary | 必须改变什么，以及哪些已成立内容不能被牺牲 |
| counterproof | 修改后用什么反例证明问题真的消失 |

## 3. 游戏制作人席

### 可读输入

- 三案可读MD；
- 三案结构TSV；
- 玩法、永久奖励、机体生涯、分支和制作风险表；
- 不读取其他审稿席意见。

### 只审这些问题

1. 玩家每一部主要做什么，SRPG、多玩法、整备、舰内生活是否形成持续循环。
2. 主力机体、驾驶员、升级、合体、离队、回归和永久奖励是否形成拥有感。
3. 地方事件是否改变编成、玩法、资源、世界或关系，而非只讲完一个主题。
4. 战斗胜负是否来自可操作规则，奇观是否能被地图、短动画、ADV和资产预算承载。
5. 分支是否改变命运与玩法，而非只换结算文本；未选路线是否有持续发展。
6. 万机馆从馆到舰、巨躯、分舰、开放共同体的身体与玩法成长是否成立。
7. 资产是否可以复用；是否为只用一次的细碎机械动作制造了大量昂贵场景。

### 禁止

- 不因制作困难要求删机体、删群像或取消宇宙尺度。
- 不把玩法表有字段当作已经好玩。
- 不修改候选稿。

## 4. 专业编剧席

### 可读输入

- 三案可读MD；
- 三案结构TSV；
- 固定前史和C02桥接边界；
- 不读取其他审稿席意见。

### 只审这些问题

1. 能否用白话复述谁想要什么、谁阻止、为什么必须继续旅行。
2. 每个结构单元是否由上一单元不可逆结果发动，而非邀请函和主题轮换。
3. 长期对手是否独立行动、获胜、受伤、误判和改变，不等主角到场才开机。
4. 纪存、七海、白鸢及群像是否拥有主动大胜、大错、崩溃、领悟和事业选择。
5. 三主角的亲密、嫉妒、误解、体谅、破裂、互救和牺牲是否改变行动或结局。
6. 中段胜利、好日子、大败、分裂、归航、What-if、终极胜利和逆合体是否形成递进波形。
7. 设定揭示是否通过人和事件发生，是否又让“证词、权限、债务、槽位”等术语替代戏。

### 禁止

- 不用“再补一场对话”修理中央事件无聊。
- 不把所有问题归因于文笔。
- 不修改候选稿。

## 5. 机器人文化专家席

### 可读输入

- 三案可读MD；
- 结构TSV；
- 机体/IP生涯与十个PV场面；
- G1.5机体包和素材索引可按需窄查；
- 不读取其他审稿席意见。

### 只审这些问题

1. 机体是否像角色和队友，而非一次性工具、论点插图、模型盒或支援影子。
2. 每个重要包是否有驾驶员、首登、加入、代表战、升级、关系、离队/回归和终局动作。
3. IP投射是否吸收作品精神、人物伤口、名场面与名台词，而不是只模仿外形或形式。
4. 超级系、真实系、勇者、战队、变形生命、特摄、现实机器人、科幻电影/游戏等气质是否能同场互相改变。
5. 战斗是否有巨大尺度、招牌动作、宿敌、合体、后继机、量产机逆袭和救世快感。
6. 纯原创机体是否有足以支撑其席位的剧情魅力；热门候选是否因旧表缺口被静默删除。
7. 玩梗是否让熟悉者会心一笑、陌生者仍能看懂；是否把原作都改成了“错误版本”。

### 禁止

- 不按每章机体数量机械打分。
- 不因某IP个人偏好要求替换整包。
- 不修改候选稿。

## 6. 目标玩家席

### 唯一输入

只读三案的玩家可读故事摘录，不读结构TSV、遗产处置、自检、Canon、作者说明、其他审稿和方案标签。三案匿名并打乱顺序。

### 每案只回答

1. 用不超过三百字复述这部游戏发生了什么。
2. 从哪里开始看不懂或觉得平。
3. 最想驾驶哪几台机体，为什么。
4. 最记得哪三个画面、哪段关系、哪次胜利和哪次失去。
5. 哪个敌人或对手最想继续看。
6. 是否愿意继续追：`想追 / 有条件想追 / 不想追`，并说明决定性原因。
7. 哪一部最强、哪一部明显衰减；不得先猜作者意图替文本补答案。

若无法准确复述，不得因为“主题很有深度”给通过。

## 7. 五道反证门

四席完成后，由总主笔对每案统一回答：

1. **阴谋简化门**：是否把独立阵营偷懒并成一只幕后手。
2. **主题展馆门**：是否只有文化议题，没有具体人物战争和长期线变化。
3. **机体寒碜门**：是否用删机体解决过载，而非迁移、分层、延后和建立生涯。
4. **胜利罚单门**：是否把玩家刚取得的胜利立即解释成错误或敌方收益。
5. **高概念幻觉门**：玩法、巨构、What-if与终局是否只在表上成立，尚无可玩或可演证据。

每门只能给`PASS / CONDITIONAL / FAIL`，并列一个最强反例。不能用“已有字段”作通过证据。

## 8. 返修与横向裁决

总主笔先把四席问题归并为少数根因，判断应在L2发动机、L3结构、生命周期还是表达层修复。每案只返修一轮；若同一根因仍失败，记录在问题账，不继续无限回滚。

横向裁决不计算总分，只回答：

- 这案最能兑现哪一种玩家幻想；
- 它最独有、最难被另两案吸收的是什么；
- 它为此主动牺牲了什么；
- 最大艺术风险、制作风险和长期写作风险；
- 哪些功能可以融合，哪些一融合就会破坏中央发动机；
- 是否至少有一案被目标玩家明确判为“想追”。
