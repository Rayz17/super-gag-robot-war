# V35 C02人物Runtime候选话序隔离修复

## 问题

`scene_entity_presence.tsv`保留了C02旧四话方案的候选在场记录。这些记录已在`authority_overrides.tsv`中降为Candidate，但人物模型生成器仍无条件收入，导致作家仍可看见“白鸢E03肉身到场”和“陆衡C02完全禁止出现”等已退役的话序答案。

## 修复

1. 稳定人物模型只收入Hard/Working且active的在场记录。Candidate在场信息只能由具体阶段包在选案后按需准入。
2. 白鸢稳定模型只锁定“C02先以作品痕迹进入，C03前肉身接触主角团”，精确话序由当前获准章级方案提供。
3. 陆衡稳定模型允许C02远程工程合作，但不允许肉身到场或远程控制实机；C03保留肉身正式登场。
4. 旧拳王生命周期从旧四话稿的E03迁移为新五话稿：E02完整实机首登并短控指导战，E03正式半决赛，E05交接后随舰。

## 本轮C02E02读取

当前通过的C02五话L4/L4.5作为本话设计来源：白鸢于E02下午肉身抵达，陆衡只以远程工程顾问形式介入。该话序不会倒灌成所有方案必须遵守的永久身份规则。
