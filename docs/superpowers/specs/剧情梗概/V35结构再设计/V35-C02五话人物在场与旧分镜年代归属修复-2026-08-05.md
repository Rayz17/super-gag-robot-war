# V35 C02五话人物在场与旧分镜年代归属修复

## 修复原因

C02融合D案已经迁为五话并通过L4/L4.5，但`scene_entity_presence.tsv`仍保留旧四话顺序：白鸢被写成E03末才到场，陆衡被禁止在C02远程出现，豪司则沿旧方案在E03到场。这与当前完整总纲和逐话结构表冲突，也会让Runtime在后续话重新检出过时人物状态。

同一问题也存在于`scenes.tsv`的`V359-C02E01-CREATIVE`至`E04`四行：场景仍指向旧件市场、归一星、机械拍卖台和四话开放日。现已用融合D案五话场景链整体替换，并补入E05节点与坞工杰克实体。

E02因果骨架还临时写入“白鸢二十多年前停笔”。当前只锁定未播旧企划具有二十多年历史、白鸢早年为其补过分镜；旧企划、补图与当前赛事之间的精确年代关系应由E03实物证据确认，不能在E02旁白中擅自等同。

## 当前裁决

- E01：白鸢仅以被盗作品痕迹出现；陆衡不出现；七海远程。
- E02：白鸢实体首登，只做L1预演；陆衡首次远程工程会诊；七海可缺席。
- E03：白鸢继续在场；陆衡只按需远程；豪司旧到场路径退役。
- E04：七海远程、白鸢现场、陆衡可远程；豪司不在场。
- E05：七海远程，白鸢战后临时登舰，陆衡远程确认转子连接并发动C03。
- 白鸢E02只知道本人早年补图、公开直播和抵达后的获准资料；她不能证明补图与二十多年前原企划发生在同一时点。

## 不改变

- 不改变旧企划本身的年代、完全版王者想演完失落最终话的愿望，或E03需要揭示的三证结构。
- 不改变七海C03肉身到场、陆衡C03肉身正式登场、白鸢当前无战斗指令权和画稿不能改变现实的边界。
- 不把本次人物在场迁移视为C02E02用户验收或C02整章完成。
