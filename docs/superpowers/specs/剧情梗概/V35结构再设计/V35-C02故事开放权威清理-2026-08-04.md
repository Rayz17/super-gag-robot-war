# V35 C02故事开放权威清理

> Status: `validated_working_governance_migration`
>
> 日期：2026-08-04
>
> 依据：`G1V002`用户裁决、`V35-G5-02定向融合正式迁移回执-v1.md`、C01当前Reader用户验收回执。

## 一、清理原因

用户已明确退回C02旧发动机、场面链、情绪配重、战斗组织和Reader；木桶街生态、模型修复、旧拳王、货柜领袖、重涂机和白鸢到场等只是可重写素材。但Canon权威覆盖表仍把四条`V359-C02E0?-CREATIVE`场景标为Working，会在选案阶段把旧答案重新塞给主笔。

本迁移只修正权威口径，不创作新C02故事。

## 二、裁决

1. `V359-C02E01-CREATIVE`至`V359-C02E04-CREATIVE`全部降为`candidate / retained_for_rebuild`；可按功能拆用，不得作为当前话序、发动机或结局。
2. 白鸢仍是Working核心角色，只固定“C02内先留下作品或远程痕迹，并在C03前肉身接触主角团；此时仅有L1战术预演”。具体第几话、为何来、是否登舰由故事卡决定。
3. 陆衡仍是Working核心角色；C02内必须建立可用合作，但可通过远程工程协诊、作品/工程痕迹或一次短暂会面完成；其正式人物登场与加入仍留给C03重建。
4. 旧拳王、货柜领袖、重涂机、无牌一号、未发售样件、平台敌人和具体万机馆大件继续待选；三张故事卡可全用、部分用或不用。
5. C02唯一硬输出仍是G1V002的C03桥接：万机馆取得抵达工务城的有限航行条件；陆衡与队伍建立可用合作；白鸢已肉身到场且仅有L1预演；C03所需旧拳王或等价既有战力来路成立。

## 三、生产边界

- 本迁移不修改C01 Reader及其验收回执。
- 不修旧C02 Reader，不提升任何候选机体、敌人或场面。
- 下一步仅生产三张一页故事卡。用户选案后再编译Runtime、准入具体素材并回写精确登场节点。
