# V35 前三层全球角色与陈旧母题根因审计

> 状态：`working_migration_basis`
>
> 日期：2026-07-21
>
> 作用范围：创作第一层体验宪章、第二层总发动机、横向世界机制支撑、第三层结构母盘及其当前机器表；C04只作为下游验证样本。

## 一、结论

当前问题不是C04偶尔起错了几个人名，也不是删掉几次“慢半拍”就能解决。它有两个共同的上游根因：

1. **把中文本地化写法误当成角色原生身份。** 旧协议把`Latin转写`和`Latin原名`混为一栏，于是`葵司 / Kui Si`、`雾生 / Wusheng`这类先造中文艺名、再转拼音的做法也能通过“全球双语”检查。视觉表虽然提出多肤色和移民背景，却没有要求姓名、家庭、语言、生活经验与地区历史互相支持，最终容易变成换肤。
2. **把一条角色线的音乐意象扩张成全剧自动语法。** “慢半拍、错拍、节拍、声部、合唱、领唱、全声道”本来可以属于莉歌、星翼、舞台机和少数音乐型IP投射，后来却进入G.A.G.文明、远星归静、敌方学习、纪存能力、合体、地方防卫和终局分类。不同人物与机体因此反复用同一种方式证明主体性，旧Canon开始替创作预先生成答案。

第一至第三层若不先修正，第四层无论重写多少次，仍会继续生产“全球角色都是中文名加拼音”和“所有差异最终都写成不同拍子”的场面。

## 二、命名问题的具体表现

### 2.1 拼音不是国际角色身份

`Ji Cun`可以是中国角色纪存的国际转写；它不能因为使用拉丁字母就被计为另一文化。相同道理适用于`Kui Si`、`Wusheng`、`An Yao`和`Han Su`。判断角色是否真正来自全球演员生态，必须看：

- 原文或法定姓名是什么；
- 中文显示名是翻译、音译、笔名、呼号还是本名；
- 角色在哪里长大、由什么家庭或舰群养大；
- 日常使用哪些语言，跨语交流依靠什么；
- 文化经历如何进入职业、生活、机器人爱好和重大选择。

### 2.2 中国角色不是问题，默认所有人都是中国人才是问题

万机馆开局位于东亚都市圈，本地核心角色保留中国姓名、地方昵称和工房称呼是合理的。错误做法有两种：

- 为了“国际化”把纪存、七海、唐胶等已成立人物全部换成欧美名；
- 让全球防卫基地、轨道工房、归航文明和多国舰队继续批量出现两个汉字的诗意人名，再补一行拼音或深肤色设定。

正确迁移是：**保留有来历的本地群像，同时让从C04以前就开始出现的长期新演员拥有真实不同的原生身份。** 全球化不能等到归航篇才突然出现三张外国面孔。

### 2.3 人名、笔名、呼号和机器名必须分开

白鸢、赤罡、莉歌、槐可以继续作为笔名、呼号或舞台名，但必须另有法定名或明确保持隐名的剧情理由。柯律、末证、金章、索引天使属于机器、AI或系统称谓，不得在人物名单里与人类姓名混排后让玩家误判。异文明译名也不能按地球人名规则强行统一。

## 三、音乐母题过载的具体表现

### 3.1 角色专属意象被误升为宇宙定律

目前上游主文档与核心机器表中，相关词簇已出现九十余处。它们同时承担：

- 机体动作差异；
- 驾驶员主体性；
- 敌人学习样本；
- 全球作战校时；
- 纪存的连接能力；
- G.A.G.文明定义；
- 远星归静症状；
- 终局全员支援。

同一意象承担这么多职责，会让每条线失去自身物理、文化和人物特征。岛防机、双驾巨兵、合体机、量产队、政治联盟和宇宙网络不应都靠“故意慢一点”获得自由。

### 3.2 保留范围

音乐并不从作品中消失。以下场合仍可使用：

- 莉歌及其舞台、演唱、呼吸、声场与私人关系；
- 星翼等明确以音乐或广播为能力的机体；
- 歌声被军方利用、被具体异文明误译的故事；
- 动画制作、剪辑、演奏或合体口号确实讨论时间组织时；
- 极少数经过单章创作证明、具有明确物理原因的时间差动作。

### 3.3 退出范围

以下用法从通用创作语法中退役：

- 用“慢半拍/错拍”自动表示反抗、个性或活着；
- 用“不同声部”代替具体人物、机体、城市和制度怎样协作；
- 用“合唱/领唱/总声部”描述纪存的控制权、牺牲或领导力；
- 用“全球节拍”描述军事标准、通信协议或敌方学习；
- 用“非同声”给终局贴主题标签，却没有逐台机体的动作、退出条件和战术作用。

## 四、迁移后的三套表达

### 4.1 面向玩家的主题语言

不再反复说“多声部文明”，改为更直观的承诺：

**每台机器、每个人和每种热爱都可以保留自己的欲望与退路，并在真正需要时并肩完成谁也无法独自完成的事。**

### 4.2 世界内技术语言

- `异构主体路由`：不同主体之间传递请求、状态和动作条件。
- `可撤回协作`：参与者能够拒绝、退出、换位和停止复制。
- `独立寻址节点`：远星归静不再压缩姓名、选项、私人片段和独立接口。
- `全机自由联援`：终局玩法名；各机按自己的身体与生涯完成不同动作，不要求统一口号。

### 4.3 音乐角色的专属语言

莉歌线仍可使用声部、节拍、停唱、换气、和声与噪点。正因为全剧不再人人说音乐隐喻，这些词回到她身上才会重新有角色魅力和IP辨识度。

## 五、第一至第三层的具体修改要求

1. 第一层增加“全球群像与语言合同”，明确本地核心与全球新演员的区别。
2. 第二层补充万机馆起始地域、全球通用语/翻译基础设施及其不完美边界，让跨文化交流成为生活和冲突，而不是默认人人共享中文语境。
3. 世界机制基线把`G.A.G.多声部活化文明`迁为`G.A.G.万机共生文明`，技术定义改用`复数主体协作`；远星症状改为姓名、选项、接口和私人信息被压缩。
4. 第三层的章节发动机、长线表、人物表和敌方学习链删除通用“错拍/全球节拍/全声道”解法，逐项换成机械时序、指挥协议、通信延迟、驾驶习惯、政治授权或身体结构。
5. 现有角色表采用新的身份字段；C04的地方驾驶员和韩素首先完成真实迁移，作为第四层验证。
6. 历史稿保留原词用于追溯，但不再进入Current查询和新稿提示上下文。

## 六、迁移边界

- 这次迁移改变的是上游表达规则与Candidate人物身份，不自动锁定角色生死、恋爱结局、最终参战表或具体台词。
- 纪存、七海、唐胶等本地既有角色不因全球化被强行换文化。
- 新法定名、混合家庭和地区背景在进入正式台本、美术与配音前仍可由用户调整；旧假国际化拼音不再作为默认回退项。
- 莉歌线的音乐能力和机器人动画中的歌战传统继续保留，但不得替其他人物完成主题表达。

## 七、已执行的权威迁移

本轮没有停在“以后少用这些词”的风格建议，而是处理了会反复生成旧答案的权威根：

1. `CONCEPT_SYNC_WRONG_BEAT`、`MECHA_SHIMAE_NO3_WRONG_BEAT`与旧雾岛路线池已转为History/`superseded_history`，不得进入Current查询。
2. 岛卫当前候选机制改为`CONCEPT_ISLAND_LOCAL_COMMAND_HANDOFF`：撤销中央自动齐射，把开火、停火与撤离优先级交还三个地方席位；它可能因此丢失外圈阵地，但不会自动献祭驾驶员。
3. 纪存的顶层能力改为全域机魂监听、路由与跨星有限中继，不再称领唱、总声部或合唱核心；每个连接对象必须仍可独立寻址和退出。
4. G.A.G.玩家面向名称改为`G.A.G.万机共生文明`，技术层使用复数主体协作、异构主体路由与可撤回联锁；远星归静改由姓名、选项、私人片段和独立接口消失来表现。
5. 终局玩法名改为`全机自由联援`。不同机体必须在地图、目标、身体、资源和撤回条件上执行不同任务，不以不同台词Cut-in冒充差异。
6. C04作为下游样本已删除通用拍点解法；三台地方旗舰分别以防壁断开、本地火控/撤离权与双驾载荷边界体现主体性。

仍保留的音乐用法必须能回答三个问题：**谁真的在唱或演奏、声音通过什么载体作用、停唱以后战局和人物还能靠什么继续。** 回答不了，就不属于音乐场面，而是旧通用隐喻回流。

## 八、机器验证与源头封堵

1. 旧《项目框架》和旧《终局牺牲合唱语法》已在文档注册表降为History；它们仍可打捞角色牺牲、完美假馆和关系高光，但不能再向Current提供远星、共同体或终局命名。
2. `N_STAR_CHORUS`、`TERM_STAR_CHORUS`现只保留历史别名；Current改用`N_FARSTAR_COSMIC_CONSCIOUSNESS`与`TERM_FARSTAR_COSMIC_CONSCIOUSNESS`。旧后天合唱、共同调律、非同声支援和纪存合唱核心ID同样只保留History映射。
3. 修正`build_canon_authority_manifest.py`的状态判定：`superseded_history`现在按History生成，不会因只检查字符串前缀而被错误提升回Working。
4. 新增`scripts/check_v35_upstream_identity_motifs.py`，统一扫描第一至第三层Working、C01-C04当前Reader、当前驾驶员表、第三层机器表、身份登记与Canon/Graph迁移状态。
5. 2026-07-21首轮结果为：`81 files / 13065 lines / 40 identities / 0 errors / 0 warnings`。真实演唱、舞台、配音、战队唱名和合体歌只有在行内能识别角色或媒介时才放行。

这道检查只能阻止已知的旧默认语法复发，不能替代编剧判断。若未来出现另一种被滥用的新比喻，应先判断它是否已经跨越角色专属、物理机制和主题语言三层，再决定是否扩充迁移表。
