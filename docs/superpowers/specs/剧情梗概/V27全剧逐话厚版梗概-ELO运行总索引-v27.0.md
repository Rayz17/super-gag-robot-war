## 全剧运行口径

V27不把“开馆 / 证词 / 展签”当成万能解决动作，而把它们放回战后结算、路线债和终局声部。前台高潮优先使用机战语法：巨机上棋盘、支援审批、展舰起航、变形、重涂、合体、巨大化、同步暴走、撤退、量产逆袭、说得、清噪反制、母舰变形、全员非同声支援。

V27把参战规模从“EX隐藏补短板”迁回主线。60话每话都有至少2个机体/单位/模块/场景机体曝光，大部分话至少1个机体改变战斗或玩法。残响/Cut-in/场景机/支援/正式可操作单位的边界在正文中分层说明，避免玩家把所有名字都误认为正式入队。

V27把主角团成长从“小指标”升级为熔炉：纪存从保留/命名走向公开削权和自限；七海从流程缝隙走向带追责的改革代价；白鸢从保护性改写走向允许空白拒绝她；陆衡从删失败走向与方舟T共同保留痛苦；赤罡从追击热血走向撤退伦理。

V27把关系线从账本推进转成情绪事件：七海有实体主场、身份扫描距离、追责灼痕和职业牺牲；白鸢有嫉妒、误会、撕页、补完伤害和不动笔；纪存不再获得“她们都理解我”的廉价结论，而是继续被质问、被救、被限制。儿童角色仍完全隔离成人向。
