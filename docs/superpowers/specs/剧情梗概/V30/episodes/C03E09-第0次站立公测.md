## 6. Draft Synopsis
火种深潜入口没有把玩家带进漂亮的未来实验室，而是带到废弃科技展会公测场。入口处的宣传屏还在循环剪辑：光洁的人形样机站起来，掌声响，字幕闪出“不要逃”。下一秒，真实舞台上的跌跌从充电架上迈出半步，啪地摔在地上。唐胶本能想笑，看到陆衡的表情后忍住了。陆衡没有解释，只盯着一张旧展会门票，像看见一件自己没有修好的事。

成功样机列阵从展台另一侧启动。它们姿态漂亮、动作整齐、没有多余情绪，目标却很冷酷：删除失败计数板里的未剪辑记录，把“第0次站立”改成“首次成功演示”。玩家的单位不能简单攻击，因为跌跌没有攻击能力，成功样机也带着观众安全锁。玩法核心是护送跌跌、扶正地形、阻止删除。跌跌每摔倒一次，会占住一格，挡住敌方扫描线；如果玩家只追求站稳，会错过它作为防御动作的价值。

七海远程要求失败记录必须可审计，但开发者私人姓名不能直接公开。陆衡一开始支持剪掉失败，他说现实机器不是玩具，一次错误公开会让团队十年没人敢投钱。纪存没有否认这个伤口，却坚持失败不能只作为笑料或励志剪辑存在。他提出双轨公开：失败次数、机械状态、场地条件进入证词；开发者姓名、私人留言进入保护水印。这不是漂亮折中，因为两边都会不满。七海接受审计口径，陆衡则沉默很久。

中段，宣传屏再次播出同一条命令。这句本该燃的短锚在这里变得刺耳：是谁在要求一台一直摔倒的机器继续表演？观众？投资人？剪辑模板？成功样机列阵步步逼近，试图把计数板改成“1次成功”。跌跌爬到计数板前，第一次没有试图站起来，而是跪下，用身体挡住删除光线。它摔倒的动作在玩法上变成防御姿态，情绪上也完成反转：失败不是还没成功，失败正在保护自己存在过的证据。

纪存的机魂记忆被摔倒声触发。他看见一段旧画面：某个系统要求删除“不好看的站立记录”，他曾经按住确认键很久，最后不知道有没有删。记忆不解释全局，却让他这次毫不犹豫地公开完整失败次数。计数板亮起：10000次尝试，其中9999次被宣传片剪掉。唐胶终于吐槽出来，说现实机器人最贵的不是关节，是“演示当天别翻车”保险；笑完以后，他把减震胶垫贴到跌跌膝盖下方。

战斗结尾，玩家守住失败计数板，成功样机列阵被迫停止删除。索引却不算输，它采样了“只保留成功画面”的模板，也记录了纪存选择保留失败的反例。跌跌没有正式入队，只获得“失败证词支援”：以后可在特定地图摔倒占格、替友方挡一次扫描。陆衡把旧门票收进口袋，承认自己以前把失败演示当成逃离现实机器的理由。公测场后门打开，通向一座堆满施工机、预算牌和封路标志的工务城。

战后，跌跌的奖励不是“站稳升级”，而是获得失败证词支援。它在后续地图中可以主动摔倒占格，保护一条记录、挡一次扫描或让敌方成功模板短路。成功样机列阵的漂亮动作则被收入敌方样本，提醒玩家索引也会学习美观和效率。陆衡拿走旧门票不是煽情收尾，而是把现实机器线的旧误判带入下一话工务城，让C03从失败机器自然推进到公共责任。

纪存把失败计数板装进展舰时没有修饰标题，只写“第0次站立：未完成”。唐胶说这名字太丧，陆衡却第一次主动说别改。这个小同意让现实机器线从羞耻转向尊重，也让玩家明白C03不是支线小品，而是万机馆如何定义“失败也可参战”的根基。
