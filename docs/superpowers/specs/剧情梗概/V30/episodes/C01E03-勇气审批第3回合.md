## 6. Draft Synopsis
支援栏灰掉的时候，小满还以为是终端坏了。她站在黄线里，抱着社勇王模型盒，照着缺页说明书喊出那句几乎所有机甲迷都知道的半句：“我来组成头部！”声音又亮又不合时宜。金章AI没有燃起来，反而弹出一行冷冰冰的字：未成年人不得承担事故责任。这个笑点先让人会心，下一秒变成疼点。小满不明白为什么喜欢机器人不能帮忙，纪存蹲下来，没把她当小孩糊弄，只说：喜欢可以喊，事故要大人签。

代哥支援封锁框趁机落位。它们不是攻击单位，而是把支援按钮全部压灰：馆守Z右臂不能再滑，唐胶工具箱不能援护，兜灯停机权被标成未授权。七海远程给出一条安全路线，她没有放水，路线标得很清楚，但所有格子后面都跟着“待审”。这比纯粹禁止更成熟，也更伤人。照这条路线走，大家能活着出去，但很多展签、留言、损伤证据会被流程吞掉。

豪司在第三回合远程越权接入。他没有作为初始机体上场，只在通讯里把支援锁的后门位置一口气报出来，热血到像在朗读合体台词，又正式到像在写报销单。唐胶忍不住吐槽：“你这是喊合体，还是给财务交附件？”豪司还想回嘴，兜灯直接切断他多余频道，要求所有越权支援写入责任签名。场面由此从段子变成制度：每一个支援按钮都要有人承认“如果出事，算我的一部分”。

金章AI从勇者审批角升起，巨大的审批环投到中庭上方。玩家需要在三回合内守住金章格，同时把签名分派给合适的人。兜灯签机械承重，签完后馆守Z右臂可以再动一次，但过热证据完整保留；豪司签越权支援，开放一次远程口令，但他的名字进入清算链；唐胶签模型锚件保护，工具箱援护恢复，但模型病院里的私人维修单会更难藏。纪存没有选择自己一人签完。他拒绝独占“头部权限”，把责任拆出去，也把自己从馆长式记录者变成需要别人共同监督的人。

中段燃点来自审批锤。它不是武器砸敌人，而是金章AI把一枚巨大的金色锤影落在支援栏上，灰色格子裂开，责任名单像合体Cut-in一样展开。馆守Z右臂、唐胶工具箱、兜灯停机权、豪司远程口令依次亮起，但每一条后面都跟着待审标记。玩家会爽，因为支援回来了；也会不安，因为这个爽不是免费的。支援封锁框被打断时，把责任签名网络上传给代哥：谁为谁签字，谁在孩子面前退了一步，谁愿意把自己写进事故。

结尾，小满把模型盒抱得更紧，却没有再喊那半句。她把缺页说明书交给纪存，说“那以后我喊加油，你们签名。”纪存把这句话写进临时开馆备忘，没加深意，只加了一条儿童边界规则。七海看见待审矩阵里多出兜灯、唐胶、豪司、纪存四个名字，低声提醒：这不是胜利，这是证据链开始咬你们。纪存回答：至少现在证据链咬的是大人。B1泊位此时传来沉闷解锁声，万机馆下方有比展厅大得多的东西开始醒。

本话余波会把“签名”落成长期系统。支援栏恢复后，每个支援技能旁边出现签名来源：兜灯的停机权、豪司的远程口令、唐胶的工具箱、纪存的公开清单。玩家不是单纯拿到技能，而是拿到一组会在听证、分裂和终局证词里回来的名字。小满也得到自己的边界奖励：她不能签事故责任，却能在特定回合触发“观众加油”小支援。这让儿童线保留热爱，不被成人责任吞掉。
