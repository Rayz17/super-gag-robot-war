## 一、检查方法

本表不要求七条线每章平均出现。它检查的是四件事：一条线有没有消失；推进是否发生质变而非重复提示；几条线是否在同一场事件中互相改变；后段高潮是否被前段提前消费。

每章最多区分四种承重状态：

- **主承重**：这一章必须让该线发生不可逆变化。
- **碰撞**：该线与另一条线互相改变，不能抽出来单写。
- **维护**：保留人物、机体或状态连续性，不强做大转折。
- **休眠**：刻意不谈，为胜利、生活或其他线让出空间。

## 二、七条长线在二十二章中的实际波形

### L1 世界主因果与六层揭示

开局只让G.A.G.表现为不同机器偶尔能互相回应，白函、归一星和衡令则分别采走成功样本。C04-C05用身体制造、纪存被未结束请求拖住以及百相本地副驾的新生解释机魂必须依附载体；C06-C09用多身体接力和地方外敌史证明协作不等于合成一人；C10第一次把未来报告、舒适矩阵和保护逻辑放进城市常识。

C11让返潮环阵被真实击破，也让已经实体生活二十七年的索琳为了最弱编队公开姓名和原身；C12让谜团休眠，证明她不是初生AI；C13给她一场没有纪存兜底的独立救城胜利。C14不是索引夺舰，而是天穹旧环坠落、万机馆百米船骨托举和公共机队伤亡共同造成三舰分裂；断冠沿旧锚追踪撤离航路。C15-C16扩大到归航文明，索琳以同一具原身进入索引天使共驾位并与纪存正面交战。C17区分白框实在分支、白鸢反事实共感、纪存聚合机魂与索琳二十七年连续原身；C18-C19用低功率求救和实体打捞证明她没有备份复活。C20-C22最后回答：共同工程早于所有当前角色，战时锁合确实能救世，但必须先救出被困驾驶员，再由各主体自愿组成万机殿。

**通过条件：** G.A.G.、白框、清噪、索引、具体外敌和远星分别有可见机制；没有任何一个概念替全剧所有敌人背锅。

### L2 阵营、长期反派与世界局势

C01-C03先让代哥封存、平台商品、军方外防、作者旧口令和地方工务各自做成一件有用的事。C04-C10逐步让韩秀雅、罗莎琳、阿德里安、沈砺、槐、红面具、百相新生副驾驶、断冠和匿名行动的索琳取得自己的资源、支持者和身体。百机祭时这些阵营共同获胜；C14分裂来自坠环、万机馆超控和真实伤亡，不是各阵营突然合谋夺舰。公共INDEX服务、索琳本人、代哥、军方、白框和外敌始终是不同主语，也会互相冲突。

全剧四条行动链持续交叉：公共服务链从救人、量产与跨城调度走到战后重建；主体身份链从百相副驾驶、槐与分支主体走到C18具身结算；外敌学习链从C04断冠受伤、C09适应试验、C11旧锚指纹、C16复制编队走到C20全相环；索琳线则从地下保全、匿名留路、公开救城、武装自治、手足敌对、实体牺牲走到同体打捞和终局分离联携。终局时各阵营都对天穹联装真胜利有贡献，保留最强战时形态因此具有现实诱惑，但没有任何AI拥有全世界的统一控制权。

**通过条件：** 至少三名具名长期对手跨越前中后段主动行动，每人有公开功劳、私人抓手、反复机体和独立结局。

### L3 三主角、索琳与三条成人关系边

纪存的长线是从“听见别人”到享受普遍监听与多机接驳，再到敢用最强力量却拒绝永久替别人决定；七海从体系内专业者成长为能独立组织城市与跨星联盟、也必须承认自己曾扶植错误接口的改革者；白鸢从作品被盗的作者，成长为能让别人改写她的图、又因偏爱和未发生痛苦崩塌，最后主动保留盲区的人。

三人关系不是小许可累积。C04-C05建立能力吸引、贴身复核、嫉妒和第一次严重误读；C08-C10让他们在不同战区互相体谅又产生价值分歧；C11-C12兑现胜利后的亲密，C12只完成“愿意共同生活”；C14让三种不同错误共同毁家；C15-C16通过三舰救援和共同工作作有限修复；C17-C18因未来与现实再度破裂，C18只承认私心与能力边界；C21才作现实关系选择，C22只执行牺牲、抢回、居所和关系后果。

七海与白鸢拥有不经过纪存的关系边：竞争、互救、身体照料、嫉妒、对彼此事业的保护与终局成全都必须成立。未来视只属于白鸢的反事实共感或白框证据，七海始终依据现实作判断。

索琳是第四核心人物，但不进入恋爱拓扑。她与纪存是非恋爱手足型宿命关系：两人都来自灾变后被清除机魂的回应，却分别走向“让每个主体自己选择”和“先建立机魂不必求人批准的共同阵线”。C11公开、C12共同生活、C13独立大胜、C14失去与决裂、C16索引天使击败百相、C17牺牲并第一次被称姐、C19同体抢回、C20分离联携、C22互救或继续政治敌对，构成一条有亲情也有战争的完整波形。

**通过条件：** 三人各有大胜、越界、失去、崩溃、能力升级和独立事业；恋爱选择不能决定女性角色有没有价值。

### L4 核心群像、舰内生活与普通世界

唐胶/兜灯、陆衡/方舟T、豪司/金章、赤罡/莉歌、槐以及小满/阿澄已经各自建立独立欲望、非主角授予的事业胜利、C14舰籍、C18专属诱惑和C22独有动作。C14不是“群像自行站队”的空话：纪存、白鸢、兜灯、赤罡留中央残舰；索琳、伊曼妮、七海、陆衡、豪司、金章、莉歌和孩子进入白灯公共舰；唐胶、槐、原型师、模型师及创作者网络进入作者工房舰。方舟T与归航/旧锚线保持独立接入，不为了凑三舰名单硬塞中央。每个人因身体、事业、照护或政治责任选择，不按恋爱对象站队。

全球与多文明演员生态从C04而非C15开始：阿米娜·迪奥普 / Amina Diop、新垣凪 / Nagi Arakaki、伊内斯·纳瓦罗 / Ines Navarro、岬真琴 / Makoto Misaki、韩秀雅 / 한수아 / Han Su-a先进入天空铸环；C15-C16再由伊莎贝尔·陈 / Isabel Chen、科菲·阿杜 / Kofi Adu、安雅·彼得罗娃 / Anya Petrova把尺度推到归航文明。新增驾驶员和长期对手必须分别维护中文显示名、法定/母语名、母语文字、国际转写、地域、语言和生活锚，不能把拼音当外国身份。C15的模型母亲只作为具体人物的工作、遗憾和继承，不升级成宇宙钥匙。儿童线在C13安全巡展、C14公共生活舰、C18静止童年诱惑和C22安全撤离中持续存在，但完全隔离成人擦边与牺牲资格。

**通过条件：** 群像不是主题讲师；至少一项事业、关系和终局动作不依赖主角发任务。儿童与青年线和成人擦边彻底隔离。

### L5 参战机体、驾驶员、IP与名场面生命周期

前三章先建立馆守Z、社勇王、工务机、现实小机、旧拳王和火种重涂的玩家拥有感。C04用三地方旗舰客将和米拉/艾达可变共鸣双机完成故事级投射，C05让米拉主机永久拥有，并让BODY路线可提前获得一台地方旗舰；百相和新生副驾驶则进入长期敌我生涯。C06完整自愿合体，C07轮值核心，C08以一个主包和两个副包承重但保留十余台战场机体，C09三旗舰正式结盟/加入。C11不是继续点名，而是让旧机升级、量产队完成主目标、已认识的驾驶关系第一次大规模共演。

C14用泊位、驾驶员和舰籍真的拆开编队；C15-C18再加入归航、异文明和**已经在C08-C11成熟**的热门悲剧What-if。机体重裁现将43项来源分为直接入选、路线、客将、战略、敌转、热门提升、合并和降级/退役；Z、CCA/Hi-Nu与沙扎比、独角兽、SEED、铁血、Turn A、G、00、Wing均已有双语驾驶员包和生涯窗口。独立OG旗舰当前退役为储备，C19不再空降一台没有作品级人生的新主角机。

**通过条件：** 每个最终核心包都有首登、正式加入、一次升级或关系变化、一次危机和一个终局动作。模型盒、展签、框体、道具和纯规则单位不能冒充机体。

### L6 SRPG、多玩法、万机馆身体与永久成长

C01-C03形成基础循环：舰内生活、场地探索、小型玩法、SRPG和战后整备互相回写。C04-C10轮换巨构吊装、试驾、身体选择、意识分裂、追车、合体、巨大化、舰队撤退、三地防卫、规则城和残响深潜。每一站都留下泊位、城市、制造、驾驶、通信或防卫功能，不只看完主题便离开。

C11把经营配置变成四战区条件，C12开放自由日，C13让玩家操作索琳、伊曼妮与地方公共机队，C14让万机馆受控超控完成正面大救场，又因实体载荷、损伤和英雄选择裂为三舰。C15-C18升级为敌对双舰护航、错序通信、移动城市、索引天使对百相、敌人读取常用编队和三处实体What-if战区。C19-C22依次完成同体打捞、全球装配、九相位巨战、胜后普通生活、双塔卸载、逆合体与后游戏巡展。

当前Working容量为86话：56完整SRPG、3短任务、7探索、4舰内ADV、16复合话。G5-02把C04、C05各收束为四话，C21扩为三话，让胜利享受、常识故障和关系决定分别成立；章内可按真实容量下调，不能机械填满。万机馆状态从固定馆、受损巡航展舰、百机巡展、祭典共同体、受控超控堡垒、三舰分离、联装母舰群、天穹联装战时形态到万机殿开放组合；形态变化必须读取实际损伤、泊位、驾驶员位置与停止条件。

**通过条件：** 玩法每次换挡都改变下一场战斗或下一章状态；万机馆损伤、资源、泊位和机体位置持续记账。C12和C21可以主动低压，不藏必败陷阱。

### L7 分支、What-if、未选路线与终局差分

早期差分先改具体物件、战损、支援和人物去向；C04建立公共体、英雄体、共享体与无体四种长期身体状态；C08-C10用放弃击坠、保护低价值目标、允许角色不归队和承担维修成本建立机战式隐藏条件。C11保证基础路线也有完整胜利，不把全收集写成更道德的结局。

C14是第一条硬分舰，但只有七海的合法改革/公开脱离构成全剧唯一完整H4长线分叉；其余舰籍是H3/H2状态。C16-C18不能再新增第二套完整路线。C17固定索琳以同一原身随整台索引天使被夺，C18三处What-if通常救二、条件全救；C19固定抢回本人而非备份，伤势、援军和政治态度可差分。C21透明完成关系现实选择，C22最多使用两套终战根演出，让恋爱、手足互救、牺牲、治理、舰籍和机体状态正交组合。

**通过条件：** 关键条件可见、有补救窗口；未选路线继续行动；H4完整分叉受预算限制，不为每个变量制作一条全新游戏。

## 四、当前过载与断线预警

1. **C06、C08、C09、C11、C14、C20、C22是重资产峰值。** 逐章总纲必须决定哪些动作共用地图、骨架和演出，不能七章都按最终话成本制作。
2. **C17-C18热门IP候选过多。** What-if必须按人物关系与当前主线选择，不能成为高达作品悲剧串烧。
3. **C04-C05仍是第一处高密度风险。** 两章已按“造身体”和“夺身体”分开，但需要共同物理因果板，避免百相、纪存肉身和导览路由再次混乱。
4. **演员全球化从C04开始而不是到C15才补。** C04-C14地方驾驶员、工房员、军方人员、长期对手和异文明角色均需按身份协议命名；C15-C16负责扩大尺度，不能成为前三部缺乏全球演员的补丁。
5. **独立OG旗舰已退役为储备，不再占C19资产与戏剧席位。** C19只建造天穹联装共同工程和馆守Z后继右臂；未来若有完整驾驶员、宿敌、必杀、升级和封面级胜负的新企划，必须另走Roster质量门，不能在第四层顺手迁回。
6. **86话仍是长篇制作。** 它已有环境家族、章节T1 Rig上限和复用组；逐章总纲仍需按资产、演出和游玩时长逐章验证，不能把86当作必须填满的产量指标。
