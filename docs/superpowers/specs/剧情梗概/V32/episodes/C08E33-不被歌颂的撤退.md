## 6. Draft Synopsis

### Function

本话是 C08 的真正大战。它要把上一话红线追击的爽感转成撤退代价，让玩家在难民船、撤退名单、能源核心和红面具牵制之间做不能全保的选择。它不是反热血，而是让热血背人、背账、背回程。

### Story Flow

白缝号离港前，宇宙世纪城给万机馆发来的不是求救，而是一份包装过度的“战术转进公告”。公告蓝线平滑，胜率预测漂亮，甚至自动生成了适合发布会播放的撤离镜头。芙兰只看了三秒，就把白舰教学沙盘切成实战指挥，问后勤：“白缝号上有热水吗？毯子够不够？三号舱门还能不能从里面开？”赤罡刚想说这不像舰长，芙兰把未上船名单推到他面前。三十七个名字没有位置，公告里一个都没有。

地图展开时，四个目标同时亮起：白缝号难民船已经离港，但因为 E32 撤退准备度不同，起手可能在安全航道，也可能贴着敌火；撤退名单节点散在航道两侧，被直播名单无人机篡改；能源核心站给万机馆和白缝号共同供电，过载就会让支援池降级；红面具机停在远端击坠窗口外，一条红线折成通向王牌Cut-in的漂亮路径。玩家一眼就知道：追过去真的会很好看。

第一阶段，直播名单无人机开始把名字改成“未归档资产”“英雄编号”“低效支援”。灰鸥量产G如果没有具名状态，会被 UI 折成一整块灰色盾牌；如果玩家在 E31/E32 保护过灰鸥和遗物墙，它们会带着贴纸名上场，其中一台的盾牌上还歪歪扭扭写着“推进器噪声当BGM”。纪存必须让单位移动到名单节点，提交空白格记录、灰鸥贴纸、无头像维修单和阿岚的丑星星贴纸。每修一个名字，灰色群体格就展开成一个小头像、一句脏话通讯或一个维修指印。修名单不造成伤害，还会丢掉击坠窗口，但它直接提升灰鸥盾阵稳定和撤退名单完整度。

红面具机在第二阶段给出诱惑。它故意停在赤罡能追到、但回防会慢一拍的位置。阿岚的白色试作教练机被宣传评分推着往侧翼压，频道里弹出“少年英雄补位建议”。芙兰第一次下硬命令：“阿岚，回白缝号侧翼。赤罡，别越线。”赤罡没有立刻吼回去。他看见红面具下一步会压到白缝号，也看见如果自己追出去，灰鸥推船框会少一个承力角。纪存这时要求他先让名单节点亮完。赤罡压着火说：“你上次已经把我的追击挂到屏幕上了，这次还要把我的拳头排进展柜？”纪存没有解释，只把白缝号的剩余门数和未上船名单并在他的战术窗旁边。

莉歌的正式声场平台在第三阶段进入地图边缘。它不是无形BGM，而是一座可被锁定、可被干扰的半透明远程舞台，像折叠的舰桥侧翼扣在战场上方。她只唱出近似“Listen to my song”的半句，又把后半句吞回去。空白频道展开一回合：导弹轨迹、红面具残影、赤罡机体的击坠Cut-in、白色试作教练机的瞄准框，全部悬在半空。美得像奇迹，也尴尬得像违规，因为敌我都不能攻击。玩家只能趁这一回合推船、换防、修名单、拖伤机，不能补刀。军方和索引同时弹出标记：可重复非杀伤控制候选。七海远程把这条记录改成“高危但有效”，没有匿名，也没有替任何人擦掉工号。

中段，砂海型棺桶AT推舰机从航道侧面的废弃泊位爬出来。它慢、吵、热量高，驾驶舱通讯里传来刃一句很硬的判断：“别嫌慢，它是这张地图唯一拖得动白缝号尾舱的东西。”唐胶在维修频道忍不住吐槽：“这玩意儿慢得很真实，真实得我想退货。”兜灯立刻让他闭麦，因为砂海型已经顶着过热警报把第一节难民舱从火线里拖出来。它让 R11 的硬派低配感和灰鸥量产线合在一起：不是酷，是活下来。

主撤退路被封死时，能源核心开始过载，撤退名单还剩最后一列没修，红面具给出整章最漂亮的击坠窗口。赤罡终于冲出去，镜头几乎要切进必杀演出，但他没有追红面具。他把整台机体的热量砸向殖民地天顶。天顶破开，碎片像流星倒落，新的撤退航道从破口下方亮起。灰鸥三机盾牌翻成推船框，裂盾互相咬住；砂海型拖住白缝号尾舱；白缝号被一点点推过破口。万机馆外屏第一次把“撤退成功”显示得像超级系击破字样一样亮。

同一秒，代价也弹出。天顶破口维修账生成，敌方追踪信标顺着破口缝钻入，能源核心损伤按玩家选择结算。芙兰没有夸赤罡，只把维修账传给他：“签。”莉歌报数：“三十七个，上船了。”这不是安慰，是把他停下来的价值换算成人。赤罡看着红面具从破口另一端离开，没有道歉，也没有给那一拳起名字。他只签了账。

战后，白鸢把这场撤退画成一排格子。主角格空着，灰鸥的贴纸格歪在边上。她本来想把天顶破口画得更漂亮，最后只给名单上没回来的人画了一条遮挡线。纪存看见，没有评价。七海的远程记录停在“高危但有效”上，光标闪了几下，最后保留原样。下一章如果有人追责，所有人的名字都在。

### Reader Synopsis

白缝号从殖民地内环离港时，战争叙事还在试图变漂亮。公告叫它战术转进，红面具给玩家一条能打出王牌Cut-in的路，阿岚的白色试作教练机又被镜头往中心推。可是芙兰把漂亮蓝线拆成热水、毯子、舱门和三十七个没上船的人。纪存把撤退名单修复写进胜利条件，玩家每补一个名字，灰鸥量产G就从可消耗的灰色群体格里展开一点真实痕迹。

莉歌展开声场平台，只唱出半句就把后半句吞回去。战场停住一回合，所有最美的攻击和最危险的弹道一起悬在半空。玩家不能趁机击坠，只能推船、换防、修名单。赤罡终于得到追红面具的窗口，却把那一拳砸向天顶，打开新的撤退路。灰鸥和砂海型推舰机顶着裂盾、过热和低配动作，把白缝号推过破口。“撤退成功”像击破字样一样亮起；维修账、追踪信标和莉歌高危记录也同时亮起。

### Battle and Gameplay

类型：S级多目标撤退护送战 + 名单修复 + 放弃击坠奖励。

地图：殖民地内环、白缝号航道、撤退闸门、能源核心站、直播名单节点、红面具追击线、天顶破口点、破口推进位、声场平台投射区。

胜利条件：白缝号抵达撤退线，并至少完整保住两项：难民船安全、撤退名单完整、能源核心稳定、王牌牵制成功。

失败条件：白缝号被截断；撤退名单归零；能源核心爆毁；阿岚过载击坠；赤罡越过撤退边界后无法回防；莉歌声场被完整锁定。

特殊机制：

- 撤退准备度：读取 E32 红线使用和撤退闸保全。数值越低，白缝号越靠敌火，撤退闸越少。
- 名单修复：纪存或指定支援单位修复名单节点，牺牲行动效率，提高灰鸥稳定和名单完整度。
- 灰鸥盾阵推船框：三台灰鸥量产G按三角站位翻盾推船，消耗盾耐久；具名状态越高越稳定。
- 砂海型拖拽：慢速拖拽白缝号尾舱或伤机，热量越高越容易停机，但能越过红线诱导区。
- 歌翼声场平台：敌我全停一回合，只允许移动/推船/修名单/换防，不允许攻击；每次使用增加 `song_weaponization_evidence`。
- 红面具击坠窗口：可追击获得高伤害和短期评价，但会放弃撤退目标或提高追踪信标强度；红面具不可完整击坠。
- 天顶破口：赤罡终盘可开新撤退路，立刻提高白缝号逃离概率，同时生成维修债和敌方追踪入口。

路线差异：

- 追击路线高：红面具预测玩家常用路，白缝号起手更危险；赤罡气力高但回防更难。
- 撤退路线高：撤退闸更多，能源核心可保窗口更宽；红面具埋伏更深。
- 歌声路线高：停火范围更准，但莉歌按钮发红，C11 风险上升。
- 灰鸥路线高：灰鸥具名上场，盾阵稳定，有陷阱预警；低则群体编号上场。
- 白鸢路标已用：有一条安全提示，但索引获得安全控制路线样本。

### Mecha Appearance

白缝号难民船：本话主保护 scene_mecha，慢、重、有尾舱和舱门状态，是“撤退成功”的实体。

歌翼声场平台 / 舞台战舰远程声场：R04 承重支援单位，以半透明平台占据地图边缘，触发空白频道和歌停战。

砂海型棺桶AT推舰机：R11 硬派低配支援机，慢速拖拽白缝号尾舱和伤机，热管理与低配地形价值可见。

灰鸥量产G盾阵推船框：返回单位的新编队功能，三机裂盾推船，不算新首登但算本话承重动作。

直播名单无人机：敌方叙事单位，篡改名单、折叠头像、抢占战果归属。

红面具机：返回敌方王牌，制造击坠窗口和采样，不完整击坠。

白色试作教练机：阿岚友军机，承接少年英雄镜头诱惑。

### Heat / Spectacle / Gag

燃点：赤罡放弃红面具击坠窗口，一拳打穿殖民地天顶；灰鸥裂盾推船，砂海型拖尾舱，白缝号从破口下被推过，“撤退成功”像击破字样一样亮起。

爽点：玩家用低效动作赢一场大仗。修名字、推船、停火、拖拽这些“不帅”的行动组合成比单挑更大的胜利。

梗点：歌停战、白舰撤退、量产机逆袭、不可击坠王牌、放弃击坠奖励、硬派低配机体。唐胶吐槽砂海型慢，但立刻被事实打脸：慢的那台在救命。

PV级画面：透明声场穹顶扣住战场，子弹和Cut-in都停在半空；灰鸥三机盾牌变成推船框，裂盾火花沿船身滑动；赤罡机体从红面具方向急转，一拳轰向天顶。

### What-if / Regret Repair

Selected rows: `WIF_R03_003`、`WIF_R14_001`。

本话的 IF 不是救回某个原作死人，而是修复“量产机和底层兵只能给主角铺路”的机器人动画遗憾。玩家可以让一台低配量产机的撤退比王牌单挑更像胜利。错过条件时，灰鸥仍会留下群体编号支援和一张没贴上的贴纸，E34 还有补名窗口。

### Emotion

泪点不是演说，而是名单展开时的小动作。某个没回来的名字没有头像，只有灰鸥贴纸和维修单上的手印。灰鸥队员低声说：“他没上船，但这格他推过。”这句话在台本阶段要写得像战后填表，不写成纪念碑。

莉歌报“三十七个，上船了”也不是安慰。她把赤罡停下来的价值换算成人，让他没法用必杀名盖过去。

### Real-world Testimony

本话不使用直接现实证词。现实共鸣采用虚构维修单、贴纸、热水桶和未上船名单。边界：不影射真实战争，不借现实悲剧替代机体行动。

### Value Axis

RCV003 非人之物尊重训练：灰鸥量产G、砂海型推舰机、白缝号和名单节点都不是主角机，但它们决定谁能回来。

RCV004 反唯一正确模板：直播名单无人机和索引把撤退压缩成英雄编号、战术转进和高燃剪辑；玩家用低效、多声部、不漂亮的行动反制它。

### Finale Sacrifice Grammar

本话只种“非同声支援”和“低规格单位终局声部”的资格，不决定终局谁牺牲、谁回归、谁恋爱结算。牺牲语法仅表现为：真正保护团队/世界的动作不一定来自主角中心。

### Daily Life / Shipboard Warmth

芙兰把撤退从口号落到热水、毯子和舱门。战后她让赤罡签维修账，不骂也不夸。热水桶和备用贴纸不进入证词系统，保留为普通生活物件。

### Relationship

纪存与七海：七海远程把莉歌停火和纪存名单优先策略标为“高危但有效”。她没有放水，没有匿名，没有替他擦日志。纪存也没有删掉她的备注。两人都知道这会在 C11 追责时伤到对方，但都保留原样。

纪存与白鸢：白鸢本能想把破口画得更漂亮，最后画成一排格子，主角格空着。她暂时不刺纪存，因为她看见他这次不是把伤口放进展柜，而是把名字放进胜利条件；但她也警惕他仍然有把痛苦结构化的能力。

赤罡与莉歌：莉歌停下他的击坠窗口，也为这一停付出武器化证据债。她报数，他沉默。火花来自互相看见对方代价，而不是甜言蜜语。

赤罡与芙兰：芙兰不夸他的破口，不骂他的冲动，只让他签账。这比训斥更狠，因为它承认那一拳救人，也要求它继续背后果。

### Emotional Accumulation

E31 的空白格、E32 的半格偏移、莉歌旧麦克风胶带、七海“证据不足”、灰鸥贴纸名都在本话放大。小物件不再是芝麻事，而是变成起手地图、支援按钮、风险灯和结算账。

### Protagonist Arc

纪存的成长不是“更会记录”。他把策展判断推到战术层：名字优先于战果。这会让他丢击坠、丢效率、伤赤罡信任、牵连七海，也让索引学到“低效撤退也可以被模板化”。他的升级是获得一次把名单节点转成撤退路标的机魂判断；新限制是他不能再假装记录是中性的。

### Jicun Memory

主撤退路封死时，纪存胸口一冷，右手短暂失触，档案终端显示一个旧残句：“手不是刀，先让……过。”他没有听清后半句，也没有解释自己是谁。他只判断出名单节点不只是记录点，可以被临时承认为“推船承认点”。灰鸥盾阵因此获得一次稳定推船，白缝号多一格移动。代价是纪存个人权限留痕上升，C12 可被索引用来追问他是否也曾把谁归成空白支援。
