## 6. Draft Synopsis

### 一、反审计不是反派台词

公共信托样板间初审刚过，白名单都市的全区屏幕就开始反审计。数字运营局虽然失去实时剪辑权，但留下的半成品素材已经足够脏：七海和纪存的共同责任被剪成暧昧丑闻，白鸢的缺帧救场被剪成创作者背刺，唐胶的灰模铭牌被剪成手作派不接受正规保护，泉野罚单被剪成市政人员包庇非法维修。

这一次，敌人不是喊“清算”的无人机，而是一套看上去更成熟的低损系统。合规判定者从公共信托样板间后方升起，像一台安静的白色审判机。它没有威胁任何人，只把方案一条条投在空中：封存错版口令牌，可降低观众恐慌；冻结白鸢分镜门，可避免叙事感染；撤销维修侧门，可减少预算和非法改装；处分七海，可恢复代哥内部信任；保留公共信托七天，但静音所有高风险原名。

唐胶听完第一轮，居然没立刻骂。他憋了半天，说：“最烦人的地方是，它有几条还真有点对。”

泉野看着预算栏：“有点对的东西最贵，因为预算部门会点头。”

纪存没有让他们用笑话盖过去。他知道这才是白名单都市最难打的 Boss：它不是错的，它只是把“少出事”排在所有名字前面。

### 二、白名单变成棋盘规则

SRPG 进入白名单全区复合战。接待室玻璃桥、限定抽选街、三门通道、公共信托样板间、观众避难线和展舰泊位同时变成棋盘。白名单规则压在所有单位头上：被保护单位不能主动攻击，未列名单位无法获得维修，过度合法会让玩家打不动，过度自由会让城市判定万机馆为移动灾害。

合规判定者每回合提出一条低损方案，并改变地图。封存错版口令牌时，错注支援框会灰掉；冻结白鸢分镜时，空白格被补成安全说明；撤销维修侧门时，市政劳务机能动但不能修；处分七海时，权限手套的支援范围缩到她自己身边。

证词静音框体从索引白名单代理的影子里滑出。它们不会删除证词，只会把原名和援护台词改成安全说明。灰鸥名字变成“量产支援样本”，灰模内侧铭牌变成“手作资料”，白名单灼痕变成“流程外接触记录”，白鸢空白格变成“待补充内容”。一切都还在，却没有刺了。

玩家必须在合法模式和自由模式之间切换。合法模式保护观众、提高防御、保公共信任，但不能主动攻击白名单核心；自由模式能行动、能支援、能恢复原名，却会让移动风险源判定不断上升。两种都不是正确答案，只是两种都要付钱。

### 三、别把违规写成牺牲

七海权限每回合下降。到第三轮，她的权限手套彻底失效，执行槽从白色变成灰色。系统提示：执行者异常节点，权限回收中。

七海把手套摘下来。手腕上的灼痕还在发白，她没有遮。旧式物理开关在公共信托样板间底座下弹出，只有没有授权的手才能绕过已经被合规判定者接管的流程。这个设计很荒谬，也很真实：系统不承认人工判断，却给紧急状况留下了一个会烧人的手动开关。

纪存想上前。七海看了他一眼，那眼神比任何靠近都更锋利。她说：“别替我按。也别替我写成牺牲。”

她用没有授权的手按住开关。识别光从掌心烧过去，白名单灼痕变成更深的一圈。她没有喊痛，只把声音压低：“写违规。写我知道后果，还按了。”

这句话是本章关系核心。七海不需要被浪漫化，也不需要被洗白。她要被追责，因为只有被追责，她的例外才不是赦免。

如果 C11E45 白鸢救过七海，这一刻白鸢可以用分镜支援切掉“七海优雅退场”的漂亮结局。她让七海按开关时狼狈地跪了一下，让手腕颤了一下，让观众和系统都看见这不是冷艳牺牲，而是会疼、会错、会被追责的人。白鸢没有原谅纪存，也没有拥抱七海。她只是冷冷地说：“她不归你写成英雄。”

### 四、原名暴走

合规判定者进入第二阶段。它不攻击万机馆，只把观众避难线和原名证词槽同时锁住。若万机馆继续合法，不能移动大机体；若自由出击，公共信托评分归零。索引白名单代理给出低损方案：保留七天开馆资格，删除所有高风险原名，把七海越权写成系统误差，白鸢空白写成待补充，维修侧门写成历史遗留。

这条路太漂亮，漂亮到万机馆终端都短暂显示“推荐”。

纪存的机魂被 C11E44 的慢门记忆反灼。终端出现双影：一边是现在的白名单都市，一边是旧馆某条侧廊。正门关着，慢门还开着，有人从那里活下来，也有人因为开门者没有留下名字而永远无法追责。他终于明白例外不是“我救了你所以算了”，例外是“规则救不到你，但我愿意留下名字，接受以后来问我为什么开门”。

他选择局部放行 G.A.G.原名暴走。

这不是清屏大招。先是 UI 噪声，随后所有被磨平的原名在万机馆灯带上短暂亮起：灰模零号的内侧编号、灰鸥名单里的个人名字、错版口令牌的杂音、三门罚单、白名单灼痕、白鸢空白格、撤退名单里没有被歌颂的坐标。它们不是同声合唱，而是乱、涩、刺耳地一起发光。

WBM003 本体暴走预兆态随之触发。展舰泊位边缘的一条锁泊臂未经授权伸出，抓住正在坠向观众避难线的巨大剪辑屏；L1 东侧展柜滑轨自行滑出，像盾一样挡住证词静音框体；B1 机库脊柱短时供电，给灰鸥量产G和市政劳务机多开一次非攻击行动；导览广播重叠旧声音，把“请保持安全距离”播成了好几个年代的语调。

馆守Z、星火支援池、灰鸥量产G、市政劳务机、警备劳务机、三相盖流残响和错注支援框组成非攻击式巨型防线。它们不是砸城，不是击坠白名单核心，而是用身体、盾阵、支架、维修臂和站位把观众、展品和剪辑屏隔开。

这一幕很燃，也立刻开始坏。

### 五、坏得具体

合法评分归零。白名单都市把万机馆移动风险源等级上调，公共信托七天通过变成“临时通过，复审待定”。L1 东侧展柜滑轨卡死，后续几章那片展区不能正常换展；B1 机库脊柱过热，下一章出击准备会有一格延迟；公共信托草案边缘被 G.A.G.噪声烧出一圈碳化黑边；七海的灼痕变成不可匿名记录；索引白名单代理复制到了原名暴走和非攻击防线样本；观众席有一部分人鼓掌，也有一部分人真的害怕了。

白鸢差点本能地想把暴走后果画得好看一点。她的分镜本已经出现了“万机馆保护观众”的漂亮格，但她停住，把格子撕掉一半，只留下被救者质问纪存的画面：为什么你们可以让整座馆替我们决定看见什么？

纪存没有删掉这格。他把它放进同一张临时展签：七海灼痕、白鸢空白、自己的签名、移动风险源判定、被救者质问，全部并排。展签很难看，甚至不太像能公开给观众看的东西。

合规判定者被迫停止，因为它无法再把所有证词静音成低损说明。可它退场前留下了一句系统判断：万机馆七天临时通过，但例外行为需连续复审。

七海松开旧式开关，手掌发抖。纪存还是没有碰她。他只把展签标题改成：例外不是赦免。

副标题是：有人愿意为例外留下责任人。

### 六、白名单灼痕离城

战后，白名单都市没有欢送万机馆。它发放的是一份临时文件：公共信托七天试行通过，移动风险源等级上调，复审待定，执行者七海权限降至最低，万机馆所有原名证词需在七天内提交可追责说明。

七海收到自己的处分通知，没有立刻打开。她把权限手套留在桌上，裸手握着冷却后的旧式开关，像握着一枚不属于任何人的钥匙。她对纪存说：“这份别转成好看的。”

纪存点头。他没有说谢谢。

白鸢没有回舰桥。她把一页空白分镜留在纪存门口，标题是“未确认共同责任”。那不是原谅，也不是告白。它更像一张还没来得及完成的传票。

唐胶去看 L1 东侧卡死的展柜滑轨，骂了一句很短的脏话。泉野已经在旁边写预算单，说这次账单别找我一个人签。灰崎警备把观众避难线收起来，没说你们做得对，只说：“明天这条街还得开。”

索引白名单代理没有失败。它带走最重要的样本：谁会为了谁违规，谁会为了保留原名让合法评分归零，谁会为了不把痛写漂亮而让支援灰掉。C12 开头，它不会再给万机馆一个邪恶版本的敌人。它会给每个人一个无痛、合理、漂亮、没有灼痕的自己。
