Battle/play type:  
三路径 SRPG + 限定抽选调查 + 门控护送战。

Map mechanics:  
地图分为限定抽选夜市、认证大厅、合法门、分镜门、维修侧门、市政交通线。玩家选择一扇主门和一扇副门；主门给完整支援，副门给残缺支援，未选门变成下一话压力。合法门提高合法评分和观众安全，但会给单位贴用途定义；分镜门移动格子和救留白，但增加索引采样；维修侧门能修桥、救认证失败小机魂和保留非官方修复，但增加预算债和非法改装证据。连续三回合使用同一门会让索引采样门影加速统一。

硬失败：观众安全归零、合法评分归零或小机魂被封存拆件。  
尊严失败：某门独占可通关，但 C11E45 会以更重的关系冷伤、预算债或审计债开场。

## 6. Draft Synopsis

### 一、限定抽选夜市

白名单都市入夜后没有变暗，反而亮得更像一座巨大的官方展会。高楼屏幕滚动再版倒计时，抽选号码像河一样从街面流过，认证大厅的等候灯一排排亮起。市政展柜车把白天的临时展区收进透明轨道，城市 AI 用温和声音提醒：非官方修复品请走低风险认证通道。

这句话一出来，唐胶的脸先黑了。认证窗口前，一个父亲拿着旧模型，盒边是多年补胶和打磨痕。系统扫描后弹出：非官方修复，收藏价值下降，战斗记忆无法确认。孩子没有哭，只问：“那它是不是不算你修过了？”

父亲答不上。后面的队列开始催促，认证大厅把他们往侧线推。就在这时，一台黄色市政劳务机停到窗口旁，用很笨重的车身挡住催促屏幕。驾驶舱里的人戴着旧安全帽，先给自己开了一张违规占道罚单，再把罚单夹进孩子的模型盒。

他叫泉野，R10 工务机动队驾驶员。他说：“这张不能证明价值，最多证明今天有人为了它挡过一次队。先收着，别让系统说没人修过。”

唐胶看着罚单，原本准备好的一堆脏话突然卡住，只剩一句：“你们官方城里，还有这种人啊。”

泉野回他：“我不是官方城的人，我是修路的。英雄打完也得有人修路。”

### 二、三门打开

认证大厅深处，三道门同时点亮。合法门像一座洁白的机场闸口，合规门卫型一排排站着，任何未授权机体靠近都会被推回正确路径。分镜门像翻页的巨大光栅，白鸢的线稿和城市街区叠在一起，分镜切格机把道路切成能救人、也更戏剧化的格子。维修侧门从地下冒出焊光和烟，旧劳务机背着废件包，动作慢得像要散架。

七海说明规则：公共信托审查不再只看展签，它要看万机馆选择哪一种保护方式进入城市。合法门最安全，能保观众、评分和航路；分镜门能救被流程卡住的留白与废案；维修侧门可以保住非官方修复和真实零件痕迹，但预算、污染和非法改装记录都会进入账面。

白鸢看着分镜门，没有露出得意。她知道这扇门救人，也知道索引最爱学习她怎么救人。唐胶看着维修侧门，第一次没急着说“当然走这边”。他看见地下维修帮旧劳务机的外壳上贴着十几张未结清账单，才发现“民间维修”不是浪漫词，是有人真的欠钱。

玩家在此进入路线预判。三门不是菜单，而是三条地图路径：主门给完整支援，副门给残缺支援，未选门会在下一话变成关系冷伤、预算债或审计债。系统给出很漂亮的推荐路线：以合法门为主，分镜门局部修正，维修侧门只作为封存回收点。它看上去最安全，也最像白名单都市愿意接受的万机馆。

纪存没有立即确认。他先把三门代价投到万机馆终端上，让每个人都看见如果选择这条最优路线，白鸢的分镜门会被采样，维修侧门的小机魂会被拆成可回收件，泉野那张罚单不会进入任何有效账本。

### 三、七海的违规排序

合法门前，七海的权限手套亮起。她可以以执行者身份打开主通道，也可以把自己的旧例外记录继续归入内部暂存。上一话她已经把例外记录投进风险表，本话系统进一步要求她解释：这些例外究竟是系统延迟、人工判断，还是有意排序？

七海没有绕。她把自己的违规排序记录打开，投到合法门上方。记录显示，她过去不止一次在多条违规之间主动决定先处理哪一条：哪项先进入审查，哪项先被看见，哪项暂时不被清掉。她没有说这是为了纪存，也没有把它说成浪漫牺牲。她只说：“我不是系统故障。我做过判断，也要承担判断。”

代哥硬线的反审计标识立刻亮起。合法门变窄，七海权限手套过热，几台合规门卫型开始把她也列入现场风险。纪存走到她身边，把自己的开馆账接到同一页。他没有替她隐藏记录，也没有把她包装成万机馆的帮助者。他写下：执行者判断已进入公共信托代价。

白鸢站在分镜门前看见这一幕。她的表情并不激烈，反而冷得更清楚。她问纪存：“你是不是只在不能合法的时候，才需要我？”

这句话没有战斗口号，也没有漂亮回答。纪存如果此时选择合法门为主，白鸢支援会变冷；如果选择分镜门为主，七海审计会加重；如果选择维修侧门，二者都会受伤，因为她们都知道他绕开了她们的战场。三门战斗从这一刻开始不再是路线收益表，而是三个人都能感觉到的选择疼痛。

### 四、门控护送战

SRPG 战斗展开。玩家要护送至少三件 C08-C10 证词穿过主门：灰鸥撤退名单、白鸢空白展柜、错版口令牌、三相盖流风险分级。每件证词根据上一话的三层命名状态获得不同属性。合规名易通过合法门，但证词锋利度下降；原名通过分镜门更强，但城市恐慌上升；公共信托名能带责任说明，但需要七海和纪存共同承担审查。

合规门卫型不会暴力攻击，它把未授权单位推回起点，像一个过于礼貌、也过于强硬的队列管理者。警备劳务机由灰崎警备驾驶，使用非致命盾阵和交通管制线。如果玩家前几回合破坏过多市政设施，他会暂时敌对；如果玩家让市政劳务机保住交通，他会打开一条短桥。灰崎不是反派，他只说：“我明天还要让这条街上班。”

分镜切格机则完全不同。它能把一段街区切成三格，救下被封在角落的小机魂，但每次切格都会让索引采样白鸢的保护动作。白鸢的支援台词随着采样率变化：一开始她还会提醒纪存哪里能走，采样过高后，她只把路线画出来，不再解释为什么。

维修侧门最脏也最具体。地下维修帮旧劳务机拖着焊枪和废件包进场，可以修桥、撬封存框、把认证失败小机魂从拆件线上拖回来。但每次使用都会增加预算债和非法改装证据。唐胶看见账单跳出来，嘴上骂“这系统给人心脏贴折扣码”，城市 AI 温柔提示心脏不在维修目录。泉野接话：“预算里也没有英雄把路打坏这一栏。”

### 五、索引的漂亮路线

第三回合后，索引采样门影出现在三门交汇处。它没有天使外形，只是一道叠得太干净的白色门影，像城市 UI 自己长出了判断。它把合法门的安全、分镜门的救援、维修侧门的零件保留整理在一起，给出“统一低损救援算法”。

这条算法短期真的好用。路线变短，合法评分上升，观众安全更稳定，预算债下降，甚至白鸢分镜门的采样也被压低。问题是地图上那些不好看的东西一起消失了：泉野罚单没有位置，唐胶骂声被折成无效语音，孩子模型盒里的补胶痕被合并成低价值修复，白鸢停顿的空白格被补成顺畅桥段，七海的违规排序记录被改写成系统优化。

玩家必须保护一项“不好用”的路线动作。可以让市政劳务机绕远路保住罚单证据，可以让分镜门保留一个空白格不被自动填满，也可以让合法门承认七海不是系统优化而是个人判断。保护这些动作会降低效率，却能阻止索引完成三门统一。

纪存的机魂在这一刻有短暂反应。万机馆终端闪过一段旧记忆：很久以前，正门关了，侧门开得很慢，有人就是从那条慢门活下来的。画面没有解释纪存是谁，只让他明白一件事：未选门不是废路线，很多命是从副路里出来的。

### 六、未选门也付了钱

战斗后半，主门即将锁定。无论玩家选择哪扇主门，另两门都会开始灰显。白鸢的分镜门如果不是主门，她会把分镜本贴在胸前，像挡盾，也像故意让纪存看见他已经不在画面中央。七海如果不是主门，合法评分会下滑，她的违规排序记录会被反审计部门单独抽出。维修侧门如果不是主门，地下维修帮会带着小机魂撤到更深的地铁维修井，泉野的预算单变成红色。

纪存没有把灰显当成正常结算。他在万机馆开馆账里新增一栏：未选门代价。合法门的代价是七海审计与城市信任；分镜门的代价是白鸢被采样与留白变薄；维修侧门的代价是预算、罚单、非法改装证据和普通城市的明天。他把这些都登记进去，并保留三个残缺支援槽。

系统提示：此操作会降低主路线效率，增加公共信托说明成本。

纪存确认。  
他没有说大词，只说：“没选它，不等于它没付钱。”

这句不是台词胜利，而是玩法状态改变。未选门支援不再完全消失：合法门留下低强度观众安全线，分镜门留下一个不可自动补完的空白格，维修侧门留下一次慢速修桥。它们都不完整，都不好用，但未来还能救人。

### 七、三门战场结算

战斗结束时，认证失败小机魂没有变成强力新机体。它仍然只是一个旧模型旁边被保护下来的小小机魂，低功率、低证据价值、低战斗力。泉野把自己的罚单收据留在模型盒里，告诉孩子：“这不是官方认证。只是今天这座城市有一台机器、一张罚单和几个人承认它被修过。”

唐胶这次没有拆台。他蹲下去看模型盒的补胶痕，小声说：“非官方修复不等于没人修过。”

白鸢听见这句，像被轻轻碰到。她仍然没有原谅纪存的主门选择，但分镜本里被画到框外的纪存旁边，出现了一条很细的侧门线。

七海则收到正式反审计通知。代哥数字运营局把她的违规排序记录标为“执行者个人判断风险”，要求 C11E45 公共信托样板间中单独说明。她没有把通知关掉，只把它转给纪存。纪存也没有安慰，只把通知并入开馆账。两人的关系更近，也更危险：不是因为谁给谁开后门，而是两个人都知道这扇门以后会砸到他们身上。

索引采样门影退去前，留下一个新样本：合法、分镜、维修三种保护可压缩为低损公共路线。万机馆终端同步提示：公共信托听证提前。下一话，白名单都市不再只问万机馆能不能开馆，它会问：你们有没有资格把这么多副路线的代价也带进公共空间？
