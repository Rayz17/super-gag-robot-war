# V32 true ELO 从 C08E33 起逐话重跑

状态：进行中。

本目录用于从 `C08E33` 开始按真正的 episode loop 重跑后半程剧情。旧 `V31` 仍保留为母稿、素材源和对照，不在本轮直接覆盖。

## 运行契约

- 上游冻结状态：`V31` 的 `C01E01` 到 `C08E32` 暂作为已接受前序输入读取。
- 重跑起点：`C08E33 不被歌颂的撤退`。
- 输出密度：厚版剧情梗概，不允许退化成路线图。
- 单话规则：一次 core pipeline 只写一话；每话必须先建 pressure board 和 episode card，再写正文。
- 章节规则：章文件只在本章所有 episode packet 通过后组装。
- 审稿规则：普通话使用 Standard Episode Loop；章节门和失败回滚使用 Strict Chapter Gate。
- 分支规则：分支必须在本话剧情经历、战斗机制、汇合差异和后续状态债中可见，不能只写成变量名。
- 机体规则：每话至少选择 1-2 个真实可计数的 IP 映射机体/支援/敌方单位；锚件、展签、名单、模型盒不得冒充机体。
- 名场面规则：每话至少有明确 quote/scene/culture anchor，直接短引只在场面合适且不重复消费时使用。
- 人物规则：纪存、七海、白鸢等主角团必须有大选择、公开代价、关系裂痕或能力/权限变化；不得只用秒数、半格、标签、记录这些小指标撑戏。
- Fable 规则：本轮先本地完成 Codex pipeline；Fable 作为后续固定审稿外挂，不冒充真实 GUI/Fable run。

## 目录

- `episodes/`：一话一包，正本。
- `chapters/`：章节组装稿。
- `reviews/`：章节前缀回读、回滚票据和 replay log。
- `ledgers/`：机器可读状态账。
- `fable_review_packs/`：后续给 Fable 的单话审稿包。

## 版本说明

`V32` 的目标不是给 `V31.4` 打补丁，而是从 `C08E33` 起重建真正可追踪的写作运行。若本轮某话质量不达标，应回到该话 pressure board 或 episode card 重建，而不是靠后续章节补一句说明。
