# C01-C12创作重校准审查 v2

> 输入：去工程字段连续阅读稿，以及专业编剧、机器人文化、游戏制作、关系/情绪四席独立盲审。
>
> 本文不以合同绿灯替创作结论；V35.9既有61槽继续作为合同基线，创作层另行判定。

## 总体

C01-C12已经不是“看不懂、小打小闹”的旧稿：C01断臂成桥与万机馆起航、C03社勇王跪地救援、C06完全版挡灭城炮、C07白舰护慢船、C09普通一天与潮的缺席、C11百机祭、C12万机馆暴走与三舰冷饭，足以构成长篇第一大部的记忆骨架。四席均愿意继续追看或试玩。

真正的新问题不是内容少，而是成功方法被用得太熟：统一方案先有效救人，随后越界；主角公开代价；机体以拒绝、错拍、留空、解体或去中心证明人格；敌方取得样本；关系停在不和解。第一次是锋利命题，连续出现便成为作者答案。玩家会提前知道越整齐、越完整、越高效的方案越可疑，战术判断逐渐退化为识别作者立场。

此外还有三条独立根因：C01起三角关系先以职责而非私人欲望入场；C04起分支状态跨章相乘；C11前的无主体检索/推荐层与C11后连续人格索引称谓混杂，对手机体也缺少可追踪的身体史。

## 最记得

必须LOCK的共同记忆包括：馆守Z断臂成桥并嵌入万机馆；四台同模机由整齐变形炸向四条救援线；社勇王跪进废墟把巨锤拆成救援工具；C06完全版先赢一轮再在全绿状态主动拆开；C07慢船、灰鸥盾墙与飞拳桥；C09普通一天和潮留下的椅子、零件箱、收音机；C11不齐声的百机开馆与索引第一次承认遗漏；C12镜像馆守Z、万机馆半人形暴走、皇影停拳、三舰分裂和不同时间响起的晚饭铃。

关系层必须LOCK：七海给白鸢披外套；三人宣传图暴露真实嫉妒；七海童年口令误播；C07最后一份热食、七海锁席与白鸢伪造纪存回声；C08七海和白鸢同带互救互毁；C11纪存明确说想活到开馆以后；C12九十秒声音走廊。

## 最早根因

本轮确认四个不同层面的最早根因，不能强行合成一个：

1. **关系根因在C01。** 七海先作为错误断电令签发者，白鸢先作为无署名安全分镜存在；私人旧温度、欲望、幽默和身体好奇未前置，导致C03-C05的亲密增长显得快。
2. **戏剧发动机根因在C02。** 同模四机和旧拳王连续用偏离标准动作证明人格，悄悄建立“越完整越可疑、越失败越像人”的单向公式。
3. **制作根因在C04。** 首次把身体路线、接口、敌方样本、关系债和后续回报绑进分支后，C05六选四、C07四选二、C08三选二、C10组织路线继续叠乘。
4. **结构症状集中在C05、C08、C11。** C05六区等高，C08三线像第二轮考试，C11五个段落都像章终；这三章不是删几句术语能解决。

## LOCK

- C01、C03、C06、C07、C09、C10、C12的主因果与上述名场面不推翻。
- C05保留六区选四区、未选区域仍有尊严、S07汇流和广播资格。
- C08保留根命令真实零伤亡、七海完整执法主场、七海与白鸢互救互毁、烧毁根证书。
- C11保留世界来开馆、多名并存、公共信托和索引因记住一次遗漏而成为连续人格。
- 机体人格继续由身体、维修史、战损和动作表达；小型机、工务机、量产机不得退成巨机背景。

## PATCH

1. C01前置纪存与七海正常闭馆生活中的凉饭通讯和旧杯子；C02让白鸢的无署名夹页同时暴露专业、成人趣味和幽默；C03补三人第一次身体误会与被迫协作。
2. C02以后给机体补“我愿意做到”的正向人格：主动争胜、想再次合体、保护机械骄傲、与宿敌较量。拒绝与解体不再是唯一人格证据。
3. C07战前建立两句互相矛盾的私人请求，战后让失败道歉落到身体距离；C10安排一次真实局部和解，终止连续五章原地不和解。
4. C08把七海的损失从根证书字段变成旧同僚频道熄灭、宿舍门拒认和基层执行者改称全名，并补七海/白鸢伤口处理。
5. C11把关系选项说明改成具体发生的身体场；C12让纪存承认强令也源于无法承受任何人再次离开，而不仅是正确救援的职业冲动。
6. 每个Episode只聚光三至五项旧状态；其余压入宏观路线包和结算回放。未选线保留后果，不默认全量专属地图与演出。
7. 早期系统敌人通过旧伤、惯用武器、关节和战术记忆形成身体继承；红面具/赤罡宿敌线必须在C09-C12留下可见回声。

## REBUILD

### C05：从六个等权命题短片改成四阶段单周目弧

保留六选四，但玩家实际选择顺序分别承担“欲望显形、欲望碰撞、真实损失、共同承诺”四个阶段；同一调试区在不同阶段承担不同压力。各谱系高潮不再都以拒绝中心收尾：车队可完整合体赢一次救援，三相允许一个头位赢得一场战术胜负，五色把颜色当主动表演，勇者堂堂正正完成一次必杀，电磁线承担无法补齐第五人的悲剧，兽机允许一兽自愿戴冠并留下永久伤痕。S07中央不是禁区，而是任何机体可自愿占据两拍、必须能够离开的公共位置。未选二区合并为一段并行世界战与一次残损到场，不生产两个等量隐藏章节。

### C08：把三条并列考试改成彼此引爆的因果组合

保留三选二合同，但第一条选择必须制造第二条危机，未选第三条成为主动对手资源。例如命令线的塔链令忠诚采样仓获得完整路径，从而逼出红面具/白骑枪线；忠诚线的红面具夺走黑王座残片，反向逼出命令线；电磁代理携带根命令样本，使空席问题直接引爆城市接管。三种组合拥有不同敌方欲望、地图主语和胜负资源，不再是三次“系统替人答题”。S05-S06仍汇到七海主高潮。

### C11：只保留一个章级主峰，并给索引一段被喜欢的时间

C11主轴改为“世界来开馆，成功的公共服务漏掉一个人，新的连续人格在补漏中出生”。迟归来客是开馆服务测试，多名爆发是中段危机，三人未来生活与亲密是安静低谷，不再各自冒充章终。建议发起上游迁移：索引的第一句连续自我前移至S03尾或S04前半，使它先真实帮助一段完整Episode、赢得一台机体或一群幸存者的自愿信任；S04再完成公共信托与接管申请。这样C12是一个刚被信任的新生命走向越权，而不是出生后一槽就发动终盘战役。

### 生产结构

C05、C06、C09、C11、C12按多Episode拆分；C12至少拆为六区失控、合法/非法路线、万机馆暴走、三舰编成与首夜四个验收段。跨章分支收束为少量宏观路线包，只让少数核心机体保存逐台永久伤痕和关系回声。
