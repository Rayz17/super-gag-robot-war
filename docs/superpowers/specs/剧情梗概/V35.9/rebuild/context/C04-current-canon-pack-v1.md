## 四、能力与控制权

### 纪存有限导航

- 纪存提供“下一台该由谁接”的判断，不替驾驶员移动、开火或同意接入。
- 他的身体留在万机馆B1；B1只是接驳与保护设备，不是第二载体。
- 当前只能让玩家怀疑这份能力与灾前万机馆多机导览接口有关，不能提前公布纪存机魂实体的全部来历。

### 白鸢L2预演

`可信现场与人物陈述 -> 白鸢预演候选动作 -> 陆衡/工房校验 -> 驾驶员接受、修改或拒绝 -> 真实机体执行`

她不能画出物理门、让线条自动控制机体、替驾驶员选择或凭空知道未来。

### 七海权限

- 本章实体证书一直在七海本人手中。
- 她只能处理本人旧许可、现场追加页和自己能够证明的授权链。
- 她不能替军方批准项目、关闭全国系统或恢复自己的现职权限。

### 断冠学习

- 断冠从公开战场动作中学习完整协同链。
- 白色兼容框架从采样、供货、接口与生产记录中学习。
