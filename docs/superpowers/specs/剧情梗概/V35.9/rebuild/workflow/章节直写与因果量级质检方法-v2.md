# 章节直写与因果量级质检方法 v2

> 状态：`active_candidate_method_from_C02_v2`
>
> 继承：`章节直写与轻量质检方法-v1.md`
>
> 新增目的：防止单段读起来顺，但依靠术语跳过物理过程、角色知识来源和场景转场；防止巨大机器人长期只处理小倒计时、小距离和重复救援。

## 一、创作顺序保持不变

仍采用：冻结继承包 → 定整章发动机和能量波形 → 整章连续直写 → 一次整章结构审稿 → 局部修订 → 制作拆分 → Canon与图谱回填。

本版不恢复逐段多席Loop，也不要求每个场面填表。新增检查只在三个时点运行：动笔前的发动机设计、整章直写后的连续复读、候选Canon回填前。

## 二、场景因果五问

每个新机制、新实体或关键转场至少能在正文中自然回答：

1. **它从哪里来？** 当前地点、运输方式、通信来源或前序伏笔是什么。
2. **谁先知道？** 角色为什么看见、听见或获得这条信息；其他人是否也能知道。
3. **谁真正执行？** 纸、模型、标签、合同和数据通常只提供信息或规则，必须指出哪台实机、机械门、工房、人员或网络节点完成动作。
4. **中间经过什么？** 至少给出一个可见的验证、制造、运输、授权、通信或身体动作，不能从“发现线索”直接跳到“战场生效”。
5. **它改变了什么？** 地图、身体、钱、关系、路线、机体条件或敌方能力必须有一项可见变化。

五问不是正文说明书。合格写法通常只需一条清楚的动作链，例如：白鸢画线 → 终端对齐透视 → 陆衡划掉不承重落点 → 玩家得到候选路线。若只能靠章末附录解释，Reader仍判失败。

## 三、玩家可见证据与演出承载门

每个关键机制、转折、关系伤害和高潮在进入正文前，还必须回答：

1. **玩家具体看见或操作什么？** 不写“他理解了”“系统承认了”，要写可见动作与后果。
2. **暂由什么承载？** ADV、探索、地图事件、SRPG、战中通讯、短动画、Cut-in、UI、经营或舰内事件。
3. **此刻必须懂什么？** 不懂便无法继续当前目标的信息，只保留最低量。
4. **什么只需成为疑问？** 异常可以先让玩家感到不对，不急着给答案。
5. **什么仍是作者后台？** 角色不得提前说出未来真相或Canon注释。
6. **删掉旁白是否仍成立？** 若只剩作者解释，退回场面设计。

第四层只锁证据、载体、信息边界和最低资产，不写具体镜位、秒数、完整台词或数值。完整总纲通过后另做章级演出承载规划，再进入Episode Reader。统一语法见`V35游戏叙事演出语法基线-2026-07-22.md`。

## 四、角色知识来源门

对白、调侃、吃醋和推理都要记录最低知识来源：

- 亲眼看见；
- 在同一频道听见；
- 被某人转述；
- 从公开资料查到；
- 从自身前史知道；
- 仅作者知道，角色不得使用。

尤其检查：新角色为何知道上一章的私人饭局、伤口、昵称、秘密选择；远程角色是否误听了现场私聊；战场外角色是否知道玩家分支；白鸢的画是否包含她无从获得的现实细节。

关系梗若没有知识来源，不因好笑而放行。需要时把“得知”本身写成一场关系戏。

## 五、媒介与身体门

以下对象默认不能直接在物理战场生效：

- 分镜纸、模型盒、玩具、维修单、展签、名字、合同文本、扫描结果、残响资料。

使用时必须区分：

- **信息/锚件**：提供形状、版本、记忆、预测或关系；
- **转换过程**：扫描、复核、制造、编译、运输、调律或许可；
- **行动身体**：真实机体、全尺寸原型、机械门、工房设备、网络执行节点或有人驾驶单位；
- **主体选择**：机魂、驾驶员、所有者或责任人是否采用。

“模型变成两米机”“一张纸让机器人转弯”“改名后身体立刻失灵”都必须退回这四层检查。

## 六、阵营动作链门

机构不能以一个名字包办所有能力。每次阵营行动区分：

1. 制定政策/拥有资产的人或部门；
2. 提供交易、物流、通信或推荐的基础设施；
3. 面向公众说话的代理人格；
4. 在地图上执行的实体机、无人机、闸门或人员；
5. 暗中学习或受益的第三方。

例如C02：罗莎琳/商品生态掌握售后与复产；平台掌握寄售物流；胶价王主持与抬价；归一星实体回收；索引只从无主缓存学习。正文不必一次讲完，但动作不能互相瞬移或越权。

## 七、量级梯与小物件放大链

每话先写主量级：个人、房间、街区、城市、巨构、战争区或宇宙。机器人题材允许用小物件承载情绪，但高潮量级不能长期低于本话主机体的身体承诺。

小物件成为关键时，至少形成一条放大链：

`小物件里的具体信息/关系 → 专业验证或人物选择 → 实机/地图大动作 → 可见后果`

示例：教学模型中的旧维修修正 → 陆衡检查巨型转子 → 工房制造全尺寸适配座 → 馆守Z、货柜领袖和无牌一号在高架上交接二十余吨转子。

禁止用“十分钟、一厘米、一格、一次扫描”本身冒充戏剧强度。数字只有在观众能看见它连接巨物、身体或生死时才进入高潮。

## 八、重复动作语法门

章级复读时，为每话只写一个主动词：夺取、决斗、突围、追猎、潜入、竞速、合体、守城、演出、撤退、调查、经营、审判等。

若同一章三话以上都只能写成“救援/护送/公开”，即使地形和对象不同也判结构重复。允许一话以救援为主，但下一话必须改变玩家幻想和胜负逻辑；角色偶尔救人不等于整话又是救援关。

同理，不能连续依赖：

- 纪存犯错后让权；
- 七海留下时间缝隙；
- 白鸢删掉一格；
- 机体以自伤或拒绝证明人格；
- 胜利后立刻塌楼并改做救援。

## 九、情绪种子回收门

姓名贴、未吃的饭、维修单、旧录像、断件和私人草稿一旦被正文特写，就登记为情绪种子。章末必须选择：

- 在本章完整回收；
- 明确交给哪一章、由什么场景回收；
- 主动降为普通生活物，不再假装伏笔。

只写一个催泪开头、后面让任务吞掉，判为“情绪借款未还”。回收不必上价值，可以只是物主把模型带回家、两个人承认饭已经坏了、失败录像终于被完整放完。

## 十、整章连续复读清单

复读时暂时隐藏制作拆分、状态表和Canon附录，只看Reader正文，并回答：

- 每个场景能否从前一场自然发生，而不是“走着走着看见”“终端突然收到”“某实体忽然登场”。
- 每话是否有不同的玩家幻想和大型画面。
- 角色是否知道不该知道的事。
- 删除作者解释后，关键转折能否由操作、画面、人物反应或最低UI被玩家看懂。
- 纸、模型、扫描、合同是否越过了执行身体。
- 小物件是否真的撬动大动作，还是只被作者宣布重要。
- 章节对手的政策、前台和实体身体是否能沿同一条利益链追踪。
- 至少一个胜利、亲密、笑点或机器人浪漫是否被允许完整落地。
- 情绪种子是否有回收或明确去向。

发现问题时只修最早根因。若需要在三处以上补解释，说明发动机或媒介规则仍错，应重写该场景链而不是继续加注释。

## 十一、验收证据

候选章通过本门需要：

- 一份可连续阅读的正文；
- 一张关键场面的可见证据与暂定载体表；
- 一张四话主动作表；
- 关键媒介与身体链可从正文复述；
- 主要阵营动作链可从正文复述；
- 小物件到巨机动作至少有一条完整放大链；
- 私人信息梗点有角色知识来源；
- 情绪种子有回收表；
- 结构检查和Canon smoke通过。

机器检查只能证明标题和文件结构；上述证据必须由连续阅读得到。
