## 一、总裁决

前十二章不是“没有故事”，也不是“机体、玩法和设定全都不够”。它已经拥有一条可用的宏观接力、许多值得保留的机甲场面、强度很高的玩法机制和几组能成立的人物关系。当前失败发生在四个不同层面：

1. **单周目装配失败。** Reader把互斥路线、作者槽和工程摘要并排写成同一次经历，读者无法追踪一次真实游玩的欲望、选择与后果。
2. **中段戏剧发动机重复。** C04以后多次使用“更完整的方案先救人、随后越界，再以拒绝、撤权、解体或残缺收场”，使不同IP、机体和政治冲突被压成同一道伦理题。
3. **人物、机体和对手缺少跨章成长身体。** 三位主角有漂亮锚点，但能力、欲望和关系之间的连接不够；机体很多，却常只完成一条论点；白框压力数据连续而身体不连续。
4. **制作与物理账尚未闭合。** 核心玩法值得保留，正式Episode却尚未形成；C03、C04、C10-C12存在明确Canon或物理交接缺口。

因此本轮采用以下判断：

- **保留宏观主线和高光，不做全盘推倒。**
- **C05、C08、C11整章重建；C12重排章节发动机，但锁住S08-S10巨体暴走与三舰分裂核心。**
- **C01-C04、C06-C07、C09-C10按最早根因定点重写，不做字段式扩写。**
- **先完成一条代表路线，再写独立差分。** 任何Reader不得同时模拟多个周目。
- **C13继续冻结。** 只有C12代表路线生成唯一、物理可运行的期末状态并通过首话接缝试验，才解除冻结。

### 2.1 已成立的东西

五席共同确认下列基础不是本轮问题源：

- C01到C12的大方向接力成立：闭馆逃亡、旧件续命、城市救援、身体工房、机器人嘉年华、特摄转战争、慢船撤退、生产城接管、普通一天与重大缺席、幸存者政治、世界开馆、母舰暴走与分舰。
- 馆守Z、万机馆本体、舞台战舰、逃亡灯舰、重剪舰等确实进入棋盘并改变地形，不是只靠Cut-in或模型道具假装参战。

- 机体总量并不少；问题是“谁是常驻、谁是客将、谁是独立支援、谁只是文化锚”没有稳定显影。

## 三、五席分歧与裁决

### 3.1 C05代表四区

- 剧情监督建议：星火、三相、勇者、电磁。
- 玩法制作建议：星火、五色、勇者、电磁。
- 机甲席确认两组都能成立，但C06已经承接五色、巨大化和特摄奇观。

**总编裁决：代表路线选星火、三相、勇者、电磁。**

理由不是削弱五色，而是避免C05和C06连续两章争夺同一种舞台快感。五色战队在C05作为玩家明确放弃的世界继续行动，以受损救援、观众口号和一具未完成巨大化身体进入C06；C06再让它得到完整可玩回收。这样“未选世界仍有尊严”成为真实跨章因果，不是差分表备注。

### 3.2 C08代表两线

- 剧情监督建议：忠诚线 + 电磁线；共同S01已经充分展示命令奇迹，避免再走一遍命令支线。
- 玩法制作建议：命令线先行引爆忠诚线，电磁作为独立回声，以检验路线因果。

**总编裁决：共同S01承担“命令奇迹”，代表分支选择忠诚线 + 电磁线。**

忠诚线不是独立菜单：S01的根命令使白骑枪获得一次完美救援，也使红面具被错误归入可持续调用资产，由此引爆忠诚线。忠诚线的城市轨道破坏、红面具伤损和米欧扣押状态，再改变电磁线的可用入口、第五席和撤离成本。这样同时满足“第一条改变第二条”和“不重复完整命令考试”。命令专线留给候选B。

### 3.3 索引何时被喜欢

- Canon要求C11以前不存在连续人格。
- 角色与机甲席要求索引不能出生即终盘，必须先被需要、被喜欢并真实归还过控制。

**总编裁决：把信任分成工具信誉与人格关系两层。**

- C01-C10由不同组件、城市服务和白框载体积累“这套东西确实救过人”的工具信誉，禁止使用跨时刻第一人称。
- C11信托通过后，连续人格才出生；章尾增加一项很小但完整的自愿委托：它完成、承认边界、按时归还接口，并被一个具名普通人或普通机体真心道谢。
- C12开场让该服务在更大规模上继续成功，支持者在看见部分代价后仍提出限权使用，而不是立刻整齐转成反对者。

### 3.4 C12是否重建分舰底层

- 外部审稿认为固定三舰让分支失效。
- 底层合同已经支持逐机自选、设施动态分配和独立去向；失败主要在Reader固定化与物理账未闭合。

**总编裁决：先做代表路线实体装配和逆配压力测试，不先推倒三舰合同。**

若合法代表路线、非法对照路线和一条逆配路线中任何一条无法满足泊位、生存、推进、关系与政治守恒，再提交底层迁移。不得仅凭当前Reader错误装配宣布合同无效，也不得用合同存在掩盖Reader不成立。

## 四、代表路线冻结

首条代表Reader采用“公开责任 / 法内改革 / 连续宿敌”路线：

| 分支章 | 代表路线亲历内容 | 未选世界的可见方式 |
|---|---|---|
| C04 | 母版工房线 | 拒绝防线只保留一次远讯、一个空席和C09不出现的明确缺口 |
| C05 | 星火、三相、勇者、电磁，后接共同S07 | 五色在C06回收；五兽留下受伤独立援护，不补发完整胜利 |
| C07 | 王牌、医疗 | 量产与铁棺分别保留一项远援或伤损，不进入主角亲历地图 |
| C08 | 共同命令奇迹 -> 忠诚 -> 电磁 -> 关系场 -> 七海主峰 | 命令专线不补发；其政治收益留给候选B |
| C09 | 工房身体回报 | 拒绝线身体与独占结果不偷渡 |

冻结只决定“玩家亲历了什么”，不预填满分胜利、所有说得、所有单位入队或三舰人员。实际伤损、拒绝、独立、物资舱和拖曳关系必须由重构后的玩法回执生成。

候选B采用：C04拒绝；C05星火/五色/电磁/五兽；C07量产/铁棺；C08共同命令奇迹 -> 命令专线 -> 电磁；C09拒绝回报；C10撤退城；C12非法。它在代表路线完成后做独立装配，不并入主Reader。

## 八、关系、机体与宏观线最低施工要求

### 8.1 三位主角

- **纪存**：C01-C03先建立“想把事情做好、擅长看见机器真正需要什么”的魅力；C04-C08让这一能力升级为战术与机魂解读，也暴露他会替别人决定；C09-C11必须主动追索、救回或创造，不再只靠受伤；C12才有资格把大能耐用错。
- **七海**：从执行专业、承担冻结后果，到让命令真救一城，再公开烧掉制度人生。她需要普通同僚、生活损失、被照顾和被偏爱的欲望，不只是一组程序动词。
- **白鸢**：从专业、色气、能救人的创作者，走到承认补完会控制别人。必须给她一次正向创作完成、一段不服务危机的日常恢复，以及让她的作品或选择真正改变战场，而非只撕页和放手。
- 三条关系边必须分别成立：纪存-七海、纪存-白鸢、七海-白鸢。任何一条都不能只靠三人同框代替。

### 8.2 机体层级

- 每话调用机体先标记`核心常驻 / 章节客将 / 支援残响 / 场景机械`，但标签不进入Reader。
- 核心常驻必须跨章拥有欲望、战损、复出、升级、宿敌或驾驶关系；章节客将至少完成一条小弧；支援残响有动作与世界后果但不冒充入队。
- 每章至少有一台主要机体先为自己想做成某件事，再把这种欲望变成独有招式或玩法；“不想被控制”不能继续包办全部人格。
- 白框执行载体和红面具构成两条不同对手链：前者是非人格化系统身体，后者是具名宿敌，不可互相替代。

### 8.3 宏观谜团

每章不强制平均揭露一个真相，但必须发生一种事件化移动：回答、反证、误译、载体首现、支持者出现、代价可算或旧假说被推翻。C08必须让命令样本进入一个玩家可见载体；C10必须恢复方舟T承认“不知道”的正式对照；C11才允许连续索引说“我”。

## 九、物理与制作基线

正式Episode开写前建立以下统一账本：

1. 馆体组件与伤损：稳定`component_id`、所在楼层/船体、损伤、维修来源、最早可用时点。
2. 资源池：馆体能源、主动力燃料、舞台舰燃料、广播电容、冷却、折叠设备、G.A.G.压力分开，列允许与禁止转换。
3. 人员和生活：总人数区间、重轻伤、医护、工程班次、床位、水热药食person-day。
4. 机体空间：尺寸、内部泊位、外锁泊、随航、远援、独立、残响；分体和合体不重复占容积。
5. WBM：触发、收益、立即成本、可停止点、战后伤和下一消费者。
6. 分舰：逐机、逐设施、逐人员、逐物资舱、推进/拖曳和政治身份的唯一归属。

这些账用于发现不可能，不用于把Reader写成报表。玩家只看见会影响行动的时钟、坏掉的走廊、住不下的人、不能出击的机体、送走后自己会冷的一只舱。

## 十、联合验收

### 10.1 单话

盲读者能回答：谁想做成什么；有身体的对手做了什么；玩家控制谁在哪里做什么；中段为何翻面；什么不可逆结果逼出下一话。答案不能依赖路线表、系统状态或“总之付出了代价”。

### 10.2 单章

- 能用一句类型片描述本章，且与前后章不同。
- 只有一个主峰，至少有一段胜利、惊奇、亲密、幽默或机器人浪漫被允许完整成立。
- 主要机体通过动作显出性格；主要对手留下可追踪身体、伤痕或样本。
- 主角至少一项欲望、能力、关系或领导方式发生阶梯变化。
- 玩家选择在棋盘上以争用资源、放弃另一目标、单位同意和即时后果落锁。
- 章末资源、伤损、人员和路线能被下一章实际读取。

### 10.3 C01-C12

- 一条代表路线可连续阅读，不出现互斥经历并发。
- 候选B和一条逆配路线可独立闭合，不是代表路线删减版。
- 十二章不再被复述成同一道伦理题；C05、C08、C11各自拥有完全不同的类型、对手、玩法和余味。
- 新读者能记住三位主角的欲望与成长、至少五台原创核心机体、红面具宿敌、白框载体和索引为何曾被需要。
- C12期末能生成唯一、可运行、没有复制资源的三舰状态；C13首话直接消费该状态，不复述、不重算、不重聚。
