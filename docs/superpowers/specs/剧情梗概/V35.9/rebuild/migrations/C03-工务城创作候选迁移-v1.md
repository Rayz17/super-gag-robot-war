# C03工务城创作候选迁移 v1

> Status: `superseded_by_accepted_creative_baseline_v2`

## Reason

旧C03以听证、冻结、三件一许可、连续救援和赔付/表决收束，重复C01-C02已经用过的行政语法，且白鸢首次出现、七海再次撤令、豪司重复交易、城梁只移动一步等状态与C01 v3.1/C02 v2创作工作基线冲突。

## Change

- 主发动机迁为旧巡展接口触发的公共巨构征用与反施工都市战争。
- C03采用四话：承城、职业机追击、勇者/城梁决战、非战斗巨构校正与百机航路发起。
- 白鸢承接C02E04既有乘客状态；七海经公共交通到场，章末以至少持续到原型工房的限段调查身份入住，到站后续留待剧情决定。
- 社勇王完整合体并以可撤回公共应急部署随舰；豪司误判固定发生，机体保留拒绝权。
- 城梁一号横移一个完整环区；馆守Z使用空右肩诱敌，不重复托桥或身体牺牲。
- 无牌一号由木桶街工程货列在E3庆祝尾声到场，E4正式使用第一套作业模块。
- 方舟折叠探测器只执行最低安全转发，白舰双时间戳与原型工房入口建立因果。

## 用户连读澄清补丁

- 衡令先以灾害征用机身份获得城市临时授权，随后试图把本地工务机永久钉进承重系统；市政工班与万机馆的联手目标明确为夺回工具、完成替代施工、让城市第二天仍能运转，不再无缘无故转为同阵营。
- 预算二号改为工务城多年在役的旧底盘改造供能机，并在首话随本地工务生态完成正式介绍；C02旧件市只保留中立搬运底盘和工务城互助旧标作为预显影，不提前消费职业机首控。
- 白鸢在C03只使用与现场镜头对齐的透明战术板进行运动预演；驾驶员与工班修改、确认后，路线才成为玩家选项。红线只是现场示警，不是纸面改写现实，她仍无战斗指令权。
- 陆衡负责接口协议、动作与受力是否安全；唐胶负责磨损、干涉、试配和全尺寸加工经验。缩尺模型只帮助看懂结构，实机适配件仍由全尺寸量具、城市机床和工程复核产生。
- 取消退役转子与七海任意共用的十二天倒计时。转子按高负荷后停机复检管理；七海只获准把事故链调查至原型工房，到站后是否续留由新证据、处分结果与人物选择重新决定。
- 完整稿与Reader末尾均新增“章末钩子与后续必须承接”。原型工房入口、七海续留、白鸢权限、纪存/G.A.G.谜团、陆衡扩散程序、衡令样本、社勇王产权、远星通信、万机馆资源、百机航路、三人关系和C04防重复发动机均成为续写硬输入。
