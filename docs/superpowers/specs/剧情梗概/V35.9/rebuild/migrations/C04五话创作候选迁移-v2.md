## 为什么再次结构重写

前一版虽然扩大了场面，却把事故、采样、夺能、肉身移动、人格复制和战术改写塞进同一条复杂链，产生多处无法回答的物理问题：十二体去向不完整、韩秀雅位置漂移、七海像能替军方同意、白鸢像凭纸张造出口、纪存肉身和机魂信号混写、百相控制权无来由跳变、人格核爆炸又丢失后续价值。

v4用一条可检查的控制链替代：

`4-1本地吊架事故` → `4-2身体选择与生产样本` → `4-3军方正式夺体/纪存远程信号被截/七海换根` → `4-4十一分钟百相体验/十二切片全部重连/完美纪存形成` → `4-5万机馆母舰与多谱系联合拔除人格架`。

## 核心迁移

| 旧口径 | v4现行口径 |
| --- | --- |
| 百相在第一话抽取三旗舰能力 | 4-1只以单臂救场和采样；4-3军方才通过吊臂正式转运四套模块 |
| 纪存肉身随可脱离导览舱进入百相 | B1主机固定在万机馆；全章只有导航机魂远程接驳，肉身不离舰 |
| 十二副本中存在可辨认的真纪存 | 十二种不同功能/情绪切片都来自纪存，必须全部重连 |
| 白鸢扫描后画出离舱出口 | 白鸢只做轮廓判断、旧分镜识别、通信标注和可修改战术预演 |
| 七海用权限替军方/工房同意 | 七海是旧证书被冒用者；她现场换根，使工房拒绝冒名许可，军方自有武装仍有效 |
| 韩秀雅在百相、灰模、主铸井间瞬移 | 4-1警报前短暂离舱后回百相；4-2首试灰模后由陆衡接手；4-3至4-5留在百相 |
| 人格复制核心在终战摧毁 | 人格架完整拔除并共同封存；完美进程停止，百相底盘仰躺试压池 |
| 纪存丢失整段驾驶记忆 | 保留驾驶和返程选择，只对十二切片回流顺序有空白，永久损伤未定 |

## 新增硬锁

1. **双层十二体**：上层三旗舰加九副退役/未完成全尺寸工程体；下层十二副校准白身。两套资产不得混算。
2. **九回合吊架战**：十八分钟、三片战区、三条区段制动轨；每区旗舰加两副背景体，十二副上层身体全部有去向。
3. **百相控制分层**：韩秀雅实体骨架；战装局武装/模块；纪存导航选择。4-3换根加断三桅只产生十一分钟本地窗口。
4. **机魂维持**：低温、磁约束、模拟感觉回路；核心不供能。
5. **十二切片**：保护、进攻、撤离、记录、服从、怀疑、修理、求生、保密、好奇、嫉妒、留恋，一副白身一个。
6. **非致命玩法**：姿态槽归零后保护停机，邻接单位断锁；致命击毁会丢失切片。
7. **百相模式规则**：每回合一种主模式，切换消耗副行动，上一模式冷却一回合，开放接口只抓相邻武器。
8. **终战单位层**：三旗舰、社勇王、灰模为五台普通可控；万机馆为母舰；馆守Z地图行动；无牌一号援护；七号NPC；折燕地形。
9. **新对手沈砺**：战装局驻厂试驾负责人，黑头指挥型复用接收战装Rig；被完美纪存替换后撤退，不洗白。

## 保留的高光

- 天空铸环与双层十二体的制造文明厚度。
- 三旗舰第一次真正成为可操作机体。
- 七号选择普通作业身体。
- 七海重返七年前开启过的主铸井并亲手换根。
- 纪存主动想要、并在十一分钟里爽用四十五米百相。
- 十二种纪存同时开口，关系问题与非致命抢回战交织。
- 万机馆作为大型棋盘单位参战，多谱系围攻百相。
- 完美纪存熟悉所有正确答案，却输给拒绝、改意和玩家接出的第四方向。

## 角色权限迁移

- 纪存的成长由“被救出来”改为三次主动选择：申请接驳、替驾驶员承受复制、接回不体面的自己。
- 七海由“旧权限持有人”改为“旧签名被冒用、必须亲手结束后果的人”；她仍保留制度改革身份。
- 白鸢从连续画线降为分阶段能力，直到4-5才取得一次临时战术席。
- 陆衡接手灰模驾驶并负责实时遥测；唐胶只处理锚件、手修与装配余量。
- 兜灯决定万机馆入场并承担第二道脊节裂纹。

## 分支迁移

- BODY_HAVEN只改变4-2资源取舍及4-3至4-5可见后果，不改当前远程接驳、换根、十二切片与人格架封存规则。
- 该路线保住六副主体旧身体、灰模左肩与更多维修史；七号继续等待，主铸井失去快产。
- C05必须读取维修速度、万机馆负载、灰模状态、七号身体和军方样本能力差异。
