# C01 v3.1与C02四话创作迁移候选 v1

> Status: `superseded_by_creative_working_baseline_migration_v2`

> 当前执行口径改读`C01-v3.1与C02-v2创作工作基线迁移-v2.md`。本稿只保留用户确认前的候选决策过程。

## 迁移原因

C01 v3.1的连续故事、人物私欲、机体爽点与软科幻表达明显优于现行Reader v2，但其中部分事实尚未进入逐话Episode和制作合同。C02若继续按旧三槽与旧人物入口写，会重新压缩白鸢到场、模型街外部开馆和拳王高潮，并与v3.1人物关系脱节。

## 候选变化

1. C01读者创作基线暂时从Reader v2切到`C01-闭馆以后万机出击.md`，仅用于C02创作，不改变制作事实源。
2. 七海明确位于本市东区封存中心；与纪存有一年续期复核形成的未确认私人关系。
3. C02代表路线采用四话而非三话：补给、同模空战、拳王擂台、外部开馆。
4. 白鸢由C02作品先行推进到C02E04本人到场；只取得临时权利人/乘客身份，正式团队和战斗资格仍留后续。
5. 旧拳王高潮由“漏拍而败”调整为“先取得堂堂正正的胜利，再把同一套动作转成救援”；避免第二章再次把胜利全部换成道德损失。
6. C02章末至少形成火种货柜领袖客将、旧拳王常驻/支援、影子陪练条件保留、无牌一号赴工务城登记的清楚机体去向。
7. 万机馆首次外部开馆采用分布式借展：街区物件仍在原主与原场所，万机馆只借少量实物并建立可撤回链接；这不是最终开馆目标，也不是把模型街清空装舰。
8. C02重涂主线统一为`V353U044`至`V353U047`四台全尺寸具名机体；旧红速/蓝盾/黑镜三色限定样件组只保留为历史原型和素材来源，不与四机在同一代表周目重复首登。
9. `MECHA_UNRELEASED_TRANSFORM_SAMPLE`与`MECHA_BUILD_LORDS_STALL_UNIT`的主要可玩首显从旧C02E01调整到新C02E04，避免第一话首显过载；E01只保留无名本地劳务/积木支援动作。
