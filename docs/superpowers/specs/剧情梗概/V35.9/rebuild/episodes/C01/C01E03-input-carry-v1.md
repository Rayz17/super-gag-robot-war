## 1. 唯一人口前态

- 原始29名撤离对象已在楼外四个固定安全格；小满、阿澄、前厅值守员与需协助成人均包含其中。E03不得召回、重刷或再做一次观众撤离。
- 馆内侧人类起点恰为5人：纪存、唐胶、兜灯，以及两名在29人离楼后进入的城市消防接驳员。
- 跌跌、机器犬、消防架桥机和勇拳试作机均不计作人类；不得把跌跌写成第六名馆内人员。
- E03若让豪司入场，必须演出他从馆外到场的具体路径与原因；不能把他伪装成E02一直在场。

## 2. 空间与物理前态

- 当前战区为万机中庭及L1南侧维修承台、L2内环消防转运唇口构成的双层空间。
- B1泵处于手动低压；供水总管热变形，商业后勤风道局部烧损，档案主库紧急冷却。
- 消防架桥机SEG3已反折为支撑，左前腿过载；它是固定城市职业支援Rig，不转成自由移动攻击单位。
- 馆守Z仍半跪，主动力和胸灯关闭；右臂机械核心仍与右肩连接，只有前臂外甲、检修板和安全索处在维修/滑架状态。
- 右臂桥必须使用已锁物理锚：5米级右前臂、1.4米伸缩维修滑架、双安全索，共同跨接水平净距4.2米、标高差0.9米的两端；不得画成单根手臂垂直跨越完整楼层。
- 完整移动脊柱、B2和馆体全图仍未暴露；E03结尾才能用军方封锁把E04起航逼出来，不能提前让馆体完整变形。

## 3. 人物与关系前态

- 纪存已经证明自己能把离线结构、现场物证和多种机器编成共同救援图；他不是只会贴签的档案员。E03必须继续让观察、判断、调度与不明身体记忆叠加破局，不能用反灼自动给答案。
- 七海已经撤销本人错误命令并停权；城市消防支援仍在线。她可被提及或保持只读通讯，但不能远程解锁四令、门泵、馆守Z或勇拳。
- 唐胶与兜灯已在E01-E02建立材料判断、硬停和现场工具默契；E03要把关系推到“她亲手切掉仍可修的部分，他不替她许诺一定修好”。
- 豪司尚未到场；勇拳运输架责任卡有他的签名，E02自动防坠请求在机外许可继电被截断。E03必须建立该失败请求如何进入企业应急记录并把他引到现场。
- 金章在E03只能作为远程/终端预告和口号额度冻结界面，不独立入队、不拥有完整人格主场。
- 白鸢尚未正式出场，不得为了补三角关系提前塞入本话。

## 4. 机体与敌方前态

- 馆守Z：E03才正式/首控/战斗加入；首次抬肩、飞拳和永久断臂必须同属本话。
- 勇拳试作机：有人试验救援壳，无独立机魂；E03才由豪司实名越权驾驶。它不是社勇王前身、升级体或换皮，战后必须被公司回收并剥离数据。
- 白函：E02只有远程语音、重框投影、区域改报、从机调度和18米中庭框位预量；E03才以完整白色重框身体占格、切图、承伤并带着右肩/内收索损伤撤离。
- 冷却针车与切割标尺机：可随白函进入作功能执行单位；E03标尺机才可威胁馆守Z承力筋，但仍无人格、无独立王牌待遇。
- 消防架桥机：保留E02过载伤和固定支援身份；不得抢走馆守Z/勇拳/白函三体对撞的主峰。

## 5. 权限与宏观前态

- 公共消防/撤离层已开放共同写入；完整移动脊柱仍未公开。
- 敌方已取得公共消防图、消防桥接口、七海撤令模式和“救援可改报为资产迁移”的样本。
- 白函不是索引人格；C11前索引仍只允许协议、组件与代理痕迹。E03敌方学习只能通过白函身体、从机和战术样本表达。
- 纪存只知道自己对馆体结构有异常熟悉和反灼，不知道自己是机魂实体。本话可提交`JICUN_MEMORY_FRAGMENT_00`，但不得解释来源。

## 6. 本话必须新增、不得提前

### 必须新增

1. 白函完整身体首次占格、切图、受击和带伤撤离。
2. 馆守Z首次作为2x2巨型单位被玩家控制。
3. 豪司因失败的企业应急记录到场，实名越权驾驶勇拳，以肩背承梁而非必杀完成第一次英雄动作。
4. 馆守Z右臂先沿维修轨完成一次破框动作，再由兜灯主动切断尚可修筋束，和滑架/安全索组成五人撤离桥。
5. 纪存进入断臂内部，以专业排除假承力线后被不明身体记忆补出最后一点；记忆发生在他主动判断之后。
6. 白函取得“损坏可以被重新定义成功能”的样本；军方随后封死B1移动脊柱，把E04变成不站起来就会被拆的局面。

### 不得提前

- 不得让社勇王真机出场或首控；它留到V355-C03E03。
- 不得让金章正式加入、让七海恢复系统写权限、让白鸢登场，或让万机馆完成起立/巡航。
- 不得用爆炸直接切断右臂；结构冲击只能震松承力栓，最终永久损失必须来自兜灯的选择。
- 不得让右臂在桥上有人前失去全部可修可能；“仍可修”是选择成立的前提。
- 不得用一句责任、证词、权限或牺牲宣言替代重量、承力、路线、身体动作与人物反应。
