## 阻塞证据

1. **E03场12 -> E04场1重复同一组六锚。** E03结尾已经写六枚军方锚依次落锁并由`RT034/RT035`提交；E04开头又从第一声写到第六声，而`RT001`的前态已是六锚锁定。连续阅读没有“回放/同一时刻换视角”标记，会被读成第二组六锚。
2. **E04场7 -> 场8倒退到第四锚。** 场7已写第五、六锚解除，场8却称“第四锚解除后”进入载荷固定；最终Runtime顺序是`RT017`六锚全解后才到`RT020 LOADOUT_LOCAL`。应统一为“六锚全部解除后”。

## 高价值锁点

1. **人口与唯一事务链锁定。** `32=29+3 -> 29前厅 -> 29楼外+3馆员 -> 29楼外+5交接岗位 -> 峰值6/过桥5 -> 全员楼外 -> 四登记操作员返入、零疏散载荷`；`RT013S -> RT038 -> RT035 -> RT054`只有一条跨话提交链。
2. **机体与损伤锁定。** 馆守Z右臂从连接、飞出、可修、主动切断、旧址成桥到E04单臂承重无回生；勇拳从零动作预告、豪司实名承梁到企业回收剥离，无社勇王人格偷渡；白函从远程框到具身、右肩裂/断索、单一样本撤离；供水、商业风道、档案冷却与消防架桥机左前腿伤均持续。
3. **巨构与载荷锁定。** 六锚是实体锁；WBM按`固定建筑 -> 向东提前位移 -> 半身抬升 -> 受损巡航`推进；代表路线精确保生活维持与实体馆藏、失档案服务器，未选项留旧址且不以冷备冒充携带。
4. **宏观谜团以事件推进。** G.A.G.由旧警报/群机转头、基础对位痕、无命令预动递进；远星由错寄空白函推进到错序箭头；纪存由“馆藏状态不明”、身体找筋、反灼到旧供电动作；零号先真实提高回收率再剥夺分布式停止权；皇影实际卡死锁泊臂并改写路线。均改变人物判断或地图，不只是术语后台。
5. **C02输入唯一。** `RT054`锁定四名操作员、零疏散载荷、`LIFE_PHYSICAL`代表Bundle、档案旧址冷备、右臂旧址、B1历史/当前双值、36小时与木桶旧件市；新版Reader末场一致。旧版E04“馆内仍有人/人员模块也参与二选”已被正确废止。

## 残余风险

- **合同气味，非Canon阻断。** E02在29人出楼后引入两名接驳员、独立应急点与次梁险情，是最像“为E03精确五人态搭桥”的段落；但泵站交接与次梁红标均已提前铺垫，且换来了E03断臂桥的真实重量，保留因果，不再加解释字段。
- **Reader工程词泄漏。** `R5`、支援点、`BRAVE_FIST_BEAM_CLAIMED`等词与Reader“移除变量”的定位不完全一致，易让自然场面读成纸演记录；建议章稿清理措辞，但不改事件与状态。
- **E04谜团密度偏高。** 零号、纪存记忆、皇影、远星依次出现仍各有动作边界；台本阶段须留停顿，禁止把四者合并解释或追加Index人格。

## 最早根因

**最早阻断根因在E03场12与E04场1的组装边界：同一组六锚既被当作E03提交事件，又被E04无标记重演。** 这是Reader/转场表达问题，不是单话合同或Canon模型失效；修正该边界后，再改E04场8的“四锚”措辞即可。

## 成本判断

**高成本Canon闭合值得。** 相比旧版，新版消除了隐藏人口、人命进载荷、右臂/勇拳/白函时序含混和一句Cut-in起航；盲读时这些约束大多已经转化为救援、伤痕、承重、取舍和巨构释放。应锁住成果，只修两处时序，不回退为旧版摘要。
