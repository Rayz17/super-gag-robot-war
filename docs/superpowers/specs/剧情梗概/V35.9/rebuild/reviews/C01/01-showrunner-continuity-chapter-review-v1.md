# C01 剧情监督 / 连续性章级独立盲审 v1

> 审读顺序：先只读现行C01代表路线Reader并形成初判，再对照旧连续稿C01；未重开单话合同。

## 一、终判

- **章级处置：`PATCH`**
- **创作门：`PATCH`**
- **`LOCK`**：四话因果脊柱、四种玩法/戏剧指纹、断臂与巨构两级峰值、E04起立后释放。
- **`REBUILD`**：无。问题是Reader过度施工，不是故事发动机失效。

## 二、盲读初判

**玩家能顺畅复述。**纪存先想体面闭馆并赴晚饭约；四令、火灾、白函与六锚把“闭馆”逐级逼成“救人、保退路、让整馆离开”。核心反转依次是正确断电因缺图反而加重烟灾、飞拳变成不可回收的桥、馆体在完整命令前先动；结果是全员脱险、馆守Z永久单臂、旧址与部分档案留下、万机馆带伤起航并只剩36小时。

**四话递进且指纹清楚：**

| 话 | 戏剧指纹 | 递进作用 |
|---|---|---|
| E01 | 温暖闭馆 + 小机救援 | 先让玩家喜欢馆、人和机器，再切断日常 |
| E02 | 职业火场 + 错误命令的主动撤回 | 把私人熟悉升级为多人共同救援，也制造真伤 |
| E03 | 巨神身体战 + 可修断臂的主动牺牲 | 从救援技术升到人物与机体共同付出不可逆身体代价 |
| E04 | 城市巨构逃离 + 移动方舟诞生 | 把前三话的人、伤和空间全部装进同一副身体，完成章主峰 |

## 三、最记得的3个场面

1. **E01“主动侧倒”**：跌跌故意用失败身体卡住礼貌复闭的路径框，机器犬叼着湿晚饭袋带人过线，馆守Z只亮一圈低热胸灯。
2. **E03“它还可以修”**：飞拳先给出超级系释放，随后停在两层之间；兜灯在“确实还能修”的前提下切断主筋，战后馆守Z再用左手递回扳手。
3. **E04“万机馆站起来”**：旧展层逐段成为身体，巨构走完首个稳定区段；场外拍车门、舰内四岗位沉默听了几秒，账单随后才追上来。

## 四、最累 / 最闷 / 最重复的3处

1. **E02 §4-5共同图与三段桥施工**：落腿、桥序、软管、旧管、针车、罩面、支援点逐项解释，物理可信但信息密度持续压住七海犯错后的情绪焦点。
2. **E02 §7-8“29/29”之后再开五人出口与反折承梁**：`三十二呢`本可形成强力段落峰值，随后又进入一轮完整工序高潮，使E02像一话半，并提前消耗E03的桥/承重注意力。
3. **E03中段至E04岗位战**：多次复现“预览风险—拒绝高效动作—多人Owner复核—全部变绿后执行”的叙述句法；`FULL_SHOULDER_ACTUATION`、`FIXED_BUILDING`、载荷英文键等还把生产脚手架漏进Reader。

## 五、主动性、章峰与最早根因

- **人物主动：成立。**纪存会判断也会误读；七海下错命令后主动撤回并承担停权；兜灯、唐胶、豪司、陆衡都有不可替代的决定；跌跌、机器犬、馆守Z也以正向动作改变局面。
- **敌方主动：基本成立。**路径框会预测复闭，四令制造物理冲突，白函有身体、目标、伤痕、学习与撤退，六锚和火锁持续追击；但E04对手更接近环境规则，跨话敌意仍主要靠白框同源和军方预埋锚维系。
- **章峰释放：成立。**E03是痛感预峰；E04从微小固定件到城市尺度起立，再给稳定行走、场外回应和舰内静默，赔付、编号、36小时均后置，足以成为C01主峰。
- **最早根因：C01E02。**E01的细节服务喜欢与惊喜；E02开始把每次正确行动都完整写成图层、预览、Owner和复核流程，此后E03/E04继承了同一叙述习惯。根因是Reader没有把生产可信度压缩成戏剧因果，不是E02事件设计错误。

## 六、旧版对照与Story-First判断

**Story-First带来实质增益。**旧版能概括事件，却把火场、断臂和起航压成结果句，E04还残留“馆内有人未撤/人员模块取舍”的混乱口径。新版让纪存的闭馆愿望、七海的错误与修正、白函的连续学习、馆守Z的身体欲望、断臂选择和巨构释放都成为可复述场面，人物、机体和玩家动作真正互相致因。

**同时存在过度施工。**新版Reader没有充分执行“工程字段退居幕后”：E02篇幅与工序层级过多，E03/E04仍解释若干回合、Owner、状态名和合法性检查。增益真实，但尚未完成最后一次面向读者的去工程化。

## 七、必须修改动作与账本风险

只改Reader：压缩E02重复的桥序/支援/复核说明，保留“错误命令—共同图—撤令—29/29—三十二呢—五人出口—白框量十八米”的因果；E03/E04各只保留一组最能体现重量的验证过程，删除英文状态键与重复全绿确认。不得改变人口、伤痕、载荷、场面顺序、玩法结果或任何Episode合同。

**账本风险**：压缩过度会把新版重新削成旧版结果摘要；每话必须留下一个完整过程型动作、一个人物决定和一个可见后果。完成Reader层补丁并章级窄复核前，不授予C01创作PASS。
