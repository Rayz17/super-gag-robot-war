## 一、为什么重新编译

外部连续读稿证明，此前的`C01-C05连续阅读稿-v1.md`虽然包含若干高光，却混合了第四层、演出层和Reader层的问题，也没有真正做到一话一源。该五章稿因此降为冻结压力测试快照。本轮从C01重新执行：

```text
L4三板纠错
→ 章级演出承载
→ 一话一文件
→ 两种独立复审
→ 单话定点修订
→ 机械合成章节Reader
```

## 四、层级修复

- L4负责的空间、控制权、能力和主题重复，已经写回C01导演板、物理站位板与战斗预案。
- 实际游玩顺序、可见证据和信息载体，已经进入`C01-章级演出承载规划.md`。
- 表演、对白和连续阅读语体，只在四份单话Reader中修订。
- `C01-闭馆以后万机出击.md`由脚本机械生成，禁止直接改写。
- `C01-C05连续阅读稿-v1.md`只保留为跨章压力测试证据。

## 五、尚未宣称解决的事

1. 本轮没有把四话扩写成正式台本、分镜或关卡数值。
2. 确定性人话检查为零命中，只能证明已知坏句没有回流，不能替代用户对自然度和吸引力的判断。
3. E04仍是本章信息最重的一话；若用户连续阅读仍感到吃力，应优先拆演出节拍或减少同时前台化的机制，不再增加解释段落。
4. C02及以后尚未按这套单话源流程重编，不能用C01的候选状态替它们背书。
