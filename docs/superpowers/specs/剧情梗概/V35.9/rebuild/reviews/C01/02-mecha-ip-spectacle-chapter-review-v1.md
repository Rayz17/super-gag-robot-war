# C01 机器人文化/IP/机战演出章级独立盲审 v1

> 审读顺序：先独立连续阅读新版C01 Reader并形成初判，再只对照旧连续稿C01部分。

## 结论

- **盲读初判：`LOCK / PASS`。**
- **旧版对照后：维持`LOCK / PASS`；`REBUILD`不成立。** 新版明显更长，但新增篇幅真正换来了可玩机体动作、受力连续性和两次章峰，不是单纯字段膨胀。
- 开局已像机器人大战：第一屏就是巨构、单臂巨神与断臂桥的未来图，随后用跌跌/机器犬小型战棋和馆守Z低热Cut-in兑现，而非只靠馆名或设定口播。

## 三个高光

1. **E01“主动侧倒 + 低热胸灯”**：最小现实机与十八米巨神在同一棋盘互相需要，既是教程玩法，也是机器人文化宣言；馆守Z主动收暗一瓣灯，比常规开场必杀更能建立角色。
2. **E02至E03职业机升级链**：架桥机先用工程语法赢得自己的承梁名场面，勇拳再以无口号肩背接力，最终馆守Z飞拳从一次超级系释放翻成永久公共地形；白函随后用自己的伤口复现该语法，敌我机体都在行动中学习。
3. **E04“万机馆站起来”**：模型病院、留言墙、真机台不是换背景，而是逐段变成肩、胸与锁泊基座；缺臂馆守Z、新舰体、旧右臂桥和旧址同镜，场外拍车门与舰内静听又给足释放。这是真正可剪PV的章主峰，且没有吞掉E03断臂预峰。

## 三个不足

1. **第一具完整敌机来得偏晚**：E01路径框、E02针车/标尺机都更像规则与工序体。硬核玩家能读出机器人战棋，普通机战观众在白函E03落地前仍可能把前两话归类为高规格灾害救援模拟。
2. **正向欲望强度不均**：馆守Z、跌跌、白函、WBM001都有主动意志；勇拳的欲望几乎全部借自豪司，机器犬与架桥机也更多通过职业使命被读出。它们有名动作，但并非每台都达到“我想看它下一次登场”的同等角色黏性。
3. **“万机”容量够用但记忆点集中**：十九区、六站、纵向楼层和外泊边界证明了规模，合体、模型、现实机、旧影像与飞行廊也覆盖类型；但观众离场后最可能只记住馆守Z、社勇王系和现实救援机。旧版首段对白舰舰桥舱、制造链的横向类型提示反而更快，新版没有把这部分广度都转成同等级画面。

## 最早根因

最早根因在E01六站闭馆的取景原则：本章优先证明“机器在现实约束下怎样正确救人”，再证明“它属于哪一种机器人文化幻想”。这让物理因果和SRPG可信度极强，也让非核心机体容易先被读成优秀功能机，类型身份、登场仪式和炫耀欲集中到馆守Z、勇拳与WBM001。该问题是局部辨识度不均，不足以推翻章节。

## 方法成本

**值得。** 旧版C01更快、更像一份漂亮总览，但架桥机、勇拳、白函、断臂和巨构起立多是结果句；新版让玩家知道每台机器为何动、怎样动、动完留下什么伤，并把E01至E04的SRPG快感稳定抬级。机甲文化回报显著高于篇幅成本，适合C01这种开局标杆章和关键生命周期章峰；不应把同等工序密度机械复制到每个普通章节。

**锁定意见**：锁住上述三个高光、七台机体的现有动作身份、E03断臂预峰与E04巨构主峰。三个不足进入后续台本/镜头层观察即可，本章机器人文化/IP/奇观席允许通过。
