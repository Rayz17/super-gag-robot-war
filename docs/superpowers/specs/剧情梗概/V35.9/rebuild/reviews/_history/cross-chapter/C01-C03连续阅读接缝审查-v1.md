# C01-C03连续阅读接缝审查 v1

> Read order: C01 v3.1 → C02 v2 → C03 v1 revised
>
> Result: `continuous_creative_pass / C04_handoff_required`

## 连读总感受

三章现在第一次像同一部游戏的连续开篇，而不是三份围绕同一主题写的项目说明。

C01回答“为什么必须走”：万机馆在闭馆、火灾与清算中起航，馆守Z以永久单臂形态加入。C02回答“走起来靠什么，也会遇见谁”：木桶街提供主循环转子、真实机体生态、白鸢肉身入场、旧拳王与货柜领袖同行。C03回答“继续走是为了什么”：万机馆先用身体接住一座城市，再靠不同机器人把城市卸下来，取得第一个可以回去的泊位，并主动发出百机航路邀请。

这条升级是成立的：**逃亡方舟 → 能续命的机器人共同体 → 有归处仍选择出发的巡展舰。**

## 三章的能量波形

| 章节 | 类型与主快感 | 最大画面 | 章末获得 |
| --- | --- | --- | --- |
| C01 | 灾难片 + 博物馆保卫 + 巨神初战 + 母舰诞生 | 馆守Z与勇拳接力飞拳；百米万机馆脱地离城 | 单臂馆守Z、母舰岗位、明确逃生目标 |
| C02 | 旧件市冒险 + 空战 + 机器人拳击 + 巡展防卫 | 巨型转子空中交接；四重涂各自收尾；旧拳王沿拍卖锤攻顶 | 转子、外泊条件、旧拳王、货柜领袖客将、白鸢乘客 |
| C03 | 公共工程都市战争 + 勇者合体 + 巨构校正 | 展舰承城；社勇王完整合体；城梁横移整环；坞环与舰体相向转动 | 社勇王、无牌一号、归港泊位、七海入住、百机航路 |

三个章节的动作类型、地图语法和机器人文化语气可区分。C02不再把模型街写小，C03也没有把工务城写成又一场听证。

## 人物连续性

### 纪存

C01隐瞒旧图造成火灾链，随后公开并承担；C02四次以记忆、观察和组织能力主动赢事；C03在公开风险后作出承城决策，又让一条工务线在自己看不见时成功。他已经从“可靠但控制欲强的馆员”走到有魄力、有异常能力、也能建立队伍的主角，不再只靠犯错获得戏份。

### 七海

她的路径是远程联络人、闭馆签署人、停权责任人、跨城到场的事故见证者、分布式止动规则设计者，最后以限期调查身份正式入住。她不是连续放水，也不是被恋爱收编；同时，C01的晚饭与一年共事让她和纪存的吸引有生活来源。

### 白鸢

她先以异常旧分镜进入C01，再以实时预演、权利申诉和本人到场进入C02，C03才开始舰内生活、与七海独立协作并完成共同作品。这个顺序解决了早期“突然加入”和“只会留空/撤稿”的问题。她仍无战斗改写权，C04有清楚的继续成长空间。

### 其他主角

唐胶从修理个体、承认旧信用走到交出可复制工法；兜灯从独占硬停走到分布物理止动。陆衡从工程解释员走到承认自己删掉语境并失去旧认证。豪司从临时救人、拒绝改史，走到被机体选择后犯错并学习与AI互相拒绝。四条线均有动作升级，不只是换台词复述人设。

## 机体与机器人文化

开篇三章已经形成一个能玩的核心编队：馆守Z、社勇王、旧拳王、货柜领袖客将、无牌一号、跌跌与机器犬；影子陪练按分支同行。四台重涂机、三台本地工务机、消防架桥机、城梁一号、乐森偶、积木智者等则构成具名盟友与公共支援层。

重要的是，它们不是只在名单里出现：旧超级系、勇者系、变形生命、机器人拳击、Build改装、现实机器人和城市职业机均有自己的运动语法。前三章的“机器人大战”观感已经建立，但还只是开篇规模，C04以后仍需持续新增有故事、有动作、有后续声部的机体，不能反复只调用这一批。

## 谜团推进

三章留下的谜团不是互相替代：

- G.A.G.能把分散的设计、维修、观看与记忆放大为主体，但灾变根因未知。
- 纪存能把旧相机与机器高度视角当作自身记忆，身份未知。
- 白鸢七年前取得不可能的B1视角，发送链未知。
- 万机馆、木桶街旧会展车与工务城调查网属于同一套灾前巡展舰群。
- 延迟回信、半幅四航迹和白舰双时间戳开始把本地旅程推向错序通信与宇宙尺度。
- 白函、归一星、衡令及无主缓存正在形成执行身体与学习样本链，但索引尚未显性人格化。

信息量已足够产生“背后有一张大图”的感受，同时没有在前三章解释完。风险是G.A.G.本体仍主要活在C01说明和局部现象里；C04-C05必须让它对某个具体主体、身体制造或玩家玩法产生新作用，不能只继续以名词背景存在。

## 分支与玩家意志

代表路线能够连续阅读，分支也已经从正文旁边的并排摘要变成可追踪差分：C01载荷选择影响资源；C02物主选择与影子陪练决定同行状态；C03承重方式、工务机顺序、豪司公开方式和教学机去向改变外甲、城市开放与支援。前三章没有因漏选剥夺馆守Z、社勇王或主角关系线，适合作为SRPG主线。

## 仍需防止的回退

1. C04不能再次写成“抵达新地点→系统识别万机馆→拒绝/征用→公开材料解决”。前三章已经用完这一结构。
2. 不要把每章末都做成“刚庆祝，敌方立刻偷数据”。C03将撤收核心反转放进校正中段，C04应换一种尾钩。
3. “开馆、权利、停止、现场解锁”都只能服务具体事件，不能重新占据角色语言。人物下一步需要欲望、争吵、嫉妒、疲惫、胜负和私人选择。
4. C02和C03信息很密。台本阶段必须以场面为单位拆分，不让角色在战斗前后补念机制说明书。
5. 三章尚未出现真正重伤关系的大情感爆点。开篇可以先建立羁绊，但C04-C06至少要有一次信任破裂或不可兼得的选择，不能一直专业地互相欣赏。

## C04必须继承的状态

- 万机馆：退役转子支持低速巡航，每次高负荷移动后复检；拥有一处安全外泊，工务城成为可返回泊位。
- 核心战力：馆守Z永久单臂、社勇王可撤回公共部署、旧拳王、货柜领袖客将、无牌一号正式改装席。
- 七海：以至少持续到原型工房的限段调查正式入住，仍停权、可召回、可被叫停；到站后必须重新决定是否续留。
- 白鸢：权利乘客与共同预演作者，无战斗改写权；灰模哈希和母版控制码把她推向原型工房。
- 陆衡：旧认证被暂停，扩散版本无法召回。
- 敌方：白函、归一星、衡令身体伤必须保存；撤收核心只带走残缺校正样本。
- 物件：灰模头和旧货柜玩具均只续借至下一站，有归还期限。
- 大谜团：旧巡展舰群、双时间戳白舰、纪存视角、白鸢母版与G.A.G.主体化必须至少推进一项。

## 结论与下一步

`continuous_creative_pass`

三章连读已经达到“可以继续写”的标准。下一步不是再抛光C01/C02，也不是马上批量跑C04-C12，而是先提交C03的Canon/图谱状态，再制作一个严格读取上述状态的C04继承包与章发动机。C04应以原型工房、身体制造、创作者权力和机魂能否选择自己的身体为独有戏剧发动机，先做一章厚稿，再决定是否继续沿用这套直写方法。
