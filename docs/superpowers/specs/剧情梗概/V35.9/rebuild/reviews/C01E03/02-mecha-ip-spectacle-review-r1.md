# C01E03 机体 / IP / 奇观独立评审 r1

> Review seat: `mecha_culture_ip_homage_spectacle`
>
> Scope: 仅评 `C01E03-断臂成桥-v1.md`
>
> Verdict: `PASS`

## 一、Findings（按严重度）

- **P0 / P1 / P2：无。**没有发现需要补场、改因果或迁移生命周期才能放行的机体 / IP / 奇观问题。
- **最低修复：无。**本席判定来自可读剧情中的机械运动、人物反应和战后身体结果，不以“机体动作”“IP投射”“资产边界”等字段已经存在作为通过依据。

## 二、通过证据

### 1. 五个机械对象有不同欲望、动作语法与结果

- **馆守Z不是放大版普通攻击单位。**第一次抬肩先让L2内环下沉、展柜低鸣、尘土落下，玩家先看见建筑受力再看见巨神抬头；兜灯因此确认它再多动一点就会亲手压断救援线（`C01E03-断臂成桥-v1.md`，§二.3，L99-L109）。随后它以右臂滑轨破框、左臂挡住最后一次内收、普通导览广播重排“人员通道—结构稳定—自身回收”的优先级，欲望始终是守住人而非恢复漂亮姿态（§二.6，L141-L151；§二.9，L177-L193）。
- **勇拳不是馆守Z的小号替身，也不是社勇王偷跑。**它的欲望属于“没有机魂替驾驶者背书的测试壳仍要承担重量”：批准窗全黑、品牌动作被冻结，豪司只能实名开启紧急承力；液压启动后它以肩背顶梁、短距抬梁和援护防御留在受力链里（§二.4，L113-L125；§二.5-6，L129-L145）。战后企业锁机、剥离训练数据并回收本体，没有把一次越权兑换成入队或升级（§二.10，L203-L203）。
- **白函有独立敌机身体史。**四脚逐次读数、找平、锁死，主框和内收臂不是造型说明，而是落地裂砖、切断L1/L2、收窄通路和改变可走区的动作（§二.2，L85-L95；§二.5，L127-L135）。受飞拳后，它立刻把弯框插入裂缝改作支脚；败退也不是消失，而是以裂开的右肩、断索和折叠吊运完成带伤撤离（§二.6，L143-L151；§二.10，L195-L201）。它想把变化固定成可回收价值，与馆守Z“为人改变自身用途”构成清楚的机械对位。
- **消防架桥机保持职业Rig身份。**它继承左前腿过载，只用其余三腿调平；勇拳先抬梁后，它才把反折SEG3的外缘压到维修轨旁，为巨臂离轨提供托面（§二.3，L99-L103；§二.6，L141-L144）。这既延续E02伤痕，又与勇拳的肩背承梁、馆守Z的巨体动作分工明确，没有自由移动、攻击或抢主峰。
- **右臂不是剧情道具。**它先以离体攻击部位完成滑轨、撞击、Hit-stop、白函整格位移和回收轨卡死，再以副筋、1.4米滑架和双安全索变成持续结算载荷的地图身体；桥上停位、巨机追加动作和白函内收都会改变它是否坠落（§二.6，L139-L151；§二.9，L175-L193）。馆守Z随后以“右臂已转作临时通道”的普通广播参与用途改变，避免把手臂写成无主观关系的万能桥板（§二.9，L177-L191）。

### 2. 超级系与勇者系投射可辨、够燃且完成原创化

- 超级系识别度由“十八米巨神受限苏醒—右肩解锁—整臂沿轨推出—五米拳端破框—期待回收却永久不回”的完整运动建立，而非借经典招式名或直接台词（§二.3，L97-L109；§二.6，L139-L151）。把免费回收的飞拳改写成玩家亲手维持的公共地形，既保留爽点又改变母题含义。
- 勇者系识别度来自胸前批准窗、起势吸气、被冻结的口号和驾驶者仍然进舱；真正的英雄动作是把那口气用来顶梁，不是获得品牌必杀（§二.4，L119-L125；§三“战斗内剧情演出”，L304-L307）。这是对勇者系“宣言—许可—最终动作”节奏的可读变奏，不复刻具体人格、台词或真机生命周期。
- 三段时序完整：白函先折叠落地切图，馆守Z受建筑重量限制，勇拳接入承重链，飞拳命中产生短暂胜势，九十秒可修窗口反转为主动切离，最后五人走过滴液巨臂并留下单臂余波（§二.2-9，L83-L193）。奇观具有接近、动作过程、反应和余波，不是一个结果句。

### 3. 规模、PV画面与Roster可见性足够

- 本话至少有三幅可独立剪入PV的机器人画面：白函从排烟口吊入并四脚落地压裂中庭（§二.2，L85-L91）；馆守Z抬肩前整层先下沉（§二.3，L99-L109）；飞拳从烟中推出、白函退一整格、馆外人群隔玻璃目击（§二.6，L141-L149）。高潮再叠加单臂巨神半跪、勇拳肩背承梁、五人推设备走过滴冷却液的巨臂（§一“戏剧指纹”，L57-L64；§二.9，L187-L193）。
- 有效Roster暴露边界清楚：馆守Z是本话首控旗舰机；勇拳是豪司实际驾驶并改变地图受力的临时真机；白函是首次具身、占格、承伤、退场的完整Boss。消防架桥机是E02回归的固定支援，右臂是馆守Z部位 / 地图身体，跌跌与机器犬是回归小机；后四者没有被偷算成新的Roster首登（§四“本话有效机体动作”，L335-L344；`C01E03-input-carry-v1.md`，§4，L34-L40）。
- 没有生命周期偷跑：金章只以终端印记短提示且明确“不人格化登场”（§二.4，L119-L125）；勇拳战后被回收，不加入万机馆（§二.10，L203-L203）；社勇王真机、金章完整人格与万机馆完整起立均留在后续窗口（§五，L373-L378）。

### 4. 身体伤痕真实、可见且具后续约束

- 馆守Z的主筋由兜灯在“仍可修”的绿色方案存在时主动切断，右肩随即后沉并永久失去回收可能；战后只剩左手递回扳手，残缺继续参与角色表演（§二.9，L175-L193；§二.11，L215-L227）。
- 白函以右肩斜裂、内收索断裂撤离，文本明确规定下次出现不得抹掉裂口（§二.10，L195-L201）。
- 消防架桥机左前腿过载、馆守Z缺臂、白函双处损伤都进入结算且不得自动修复；勇拳则以锁机回收和数据剥离结束临时生命周期（§三“结算状态”，L320-L333）。伤痕同时落在我方、敌方和职业支援机上，足以支撑后续机体史。

## 三、非补丁型制作观察项

1. 飞拳必须保留滑轨拖曳、完整命中、白函整格位移、馆外反应与“不回收”的停顿；若制作时缩成一张Cut-in，本次奇观PASS失效（§三“战斗内剧情演出”，L302-L311）。
2. 勇拳必须显示有人测试壳的完整身体、肩背承梁和短距推梁；不能只剩批准窗UI，也不能补上社勇王人格、招式或正式入队（§六，L380-L389）。
3. 计数时只把馆守Z、勇拳、白函作为本话三项有效新变化 / 新身体暴露；不得把右臂复合桥、消防架桥机回归、金章印记、模型或功能从机重复计数。
4. 馆守Z右臂、白函右肩 / 内收索和消防架桥机过载腿必须跨话保留；任何无损复原都会推翻本席PASS。

## 四、结论

`PASS`。C01E03已经把超级系飞拳、勇者系起势、职业救援Rig、框架Boss和部件地图化压进同一场可玩的巨物救援，而五者仍有不同机械欲望、不同动作曲线与不同身体后果；无需首轮补丁。
