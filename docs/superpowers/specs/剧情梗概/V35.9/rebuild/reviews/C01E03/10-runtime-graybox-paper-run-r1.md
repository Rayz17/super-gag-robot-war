## 1. 纸演前硬断言

- 人口：开局L2五人；豪司从西门后入L1一人；现场峰值六人；桥上撤离目标恒为五人。楼外二十九人和消防架桥机远程操作员不生成战场Token。
- 拓扑：白函第一脚废止旧楼梯；右臂成桥前，L2与L1之间没有可走边。复合桥只允许`L2 -> L1 -> 西门外`，不允许逆行和会车。
- 物理：右前臂5m + 滑架1.4m + 双索，跨越水平净距4.2m/标高差0.9m，两端各搭接至少0.8m。
- 持久化：`RT035`是唯一原子提交；`RT036`只读断言；其他所有检查点与伤痕都是本局态。

## 2. 代表成功路线（较紧容错组合）

### P1-P3：开场、切区、豪司入场

1. `RT001-003`：读入E02唯一快照。五人正在L2分段交接；白函落脚使旧楼梯失效，因果上截住五人，而不是用胜利条件宣称他们被困。
2. `RT004`：选`ROBOT_DOG_HOSE_PRIORITY`。热量余量6，楼层位移余量4；另一路垫片保持基础稳定。
3. `RT005`：馆守Z抬肩12度，结算热量1/位移1；L2下沉，B1六痕淡亮。固定2x2足迹无平移、无转向。
4. `RT006-008`：七海只保持普通语音；豪司携失败回执从西门进入L1锚位，峰值人数变6。他启动勇拳的紧急承力，西门内回路随后被白函主框关闭；豪司不进L2。
5. `RT009`：选`LOWER_PERSON`。获得一次人员错位恢复，代价是桥面压力钟增加1 Tick；这是两条路中时间更紧的一条。

### P4-P5：拒绝捷径、交接载荷、飞拳

1. `RT010`：面板预览`FULL_SHOULDER_ACTUATION`，L2五点同时变红。纪存按实体断开；此动作不进指令队列，不能作为高收益隐藏路线。
2. `RT011`：兜灯/唐胶/豪司/纪存分别确认电、材料、承力、撤离；两名接驳员复核管线与设备。
3. `RT012-016`：载荷Owner依次为`SEG3 -> SEG3+勇拳 -> 勇拳 -> 勇拳（SEG3关节可转） -> 勇拳（右臂已落托槽）`。任一帧都不存在Owner=None；消防机四足位移恒为0。
4. `RT017-018`：馆守Z执行唯一次滑轨冲击，热量2/位移2，均未越过本路线余量。白函右肩开裂并锁住回收轨；右臂进入`ARM_SUSPENDED_RECOVERABLE`，此时仍可修、不能过人。

### P6：断臂探索

1. `RT019`建立探索入口本地点，锁定外部姿态。
2. `RT020`三次检查分别排除上方空腔、外甲梁和热脆第三筋，消耗3个`SEARCH_TICK`。对白和对话不暗扣时间。
3. `RT021`的身体记忆只显示隐藏隔板，不给桥面权限，消耗0 Tick。
4. `RT022`用唐胶三击、勇拳微抬梁和跌跌松垫片完成公开验证，消耗第4个Tick，产出`FOURTH_RIB_VERIFIED`。搜索钟4/4，但因目标已完成而冻结，不会在转场对白后补结算失败。
5. `RT023`建立切前本地点；界面只显示“手臂尚可修/复合桥可承载”两条真实诊断，不显示两个绿色通关按钮。

### P7-P8：主动切离、单向撤离、回收与落锁

1. `RT024-025`：兜灯在唐胶托刀下切主筋，白函内收索断裂；右臂进入本局`ARM_CUT_COMPOSITE_BRIDGE_ACTIVE`。三段桥面先保持关闭，馆守Z把左臂降入内收路径并锁成零位移等长承力；巨型动作结束后才开放桥面并建立切后本地点。
2. 桥分`L2_OVERLAP / ARM_MID / L1_SLIDER_OVERLAP`三段。人类每段容量1；设备令牌上桥时预留全桥，第二件不能同时进入。
3. `RT026-030`的行动成本为`1+2+2+1+1=7`：唐胶先到L1接应；设备A/接驳员A通过；设备B/接驳员B通过；兜灯通过；纪存最后出臂。`LOWER_PERSON`的额外压力Tick使总结算变8/8，仍有一条完整成功路线。
4. `RT031`白函用自己的裂框作支撑折叠，只提交`DAMAGED_BODY_TO_SUPPORT_FUNCTION`一条本地样本。
5. `RT032`先完成勇拳数据盒卸除和企业拖援，豪司留安全区；`RT033`完成兜灯手部/豪司肩部照护和左手递扳手。
6. `RT034`把馆守Z位移阈值与白函撤离回执合并，六锚物理落锁。
7. `RT035`在五人/两设备安全、白函撤离、勇拳企业回收、六锚落锁同时成立后一次原子提交。`RT036`只读复核，不存在第二次写入。

## 4. 三类失败与回滚

### A. 切前：载荷Owner链不成立

在`RT013`勇拳只完成接触、尚未得到`BEAM_CLAIMED`时尝试转SEG3。预览显示次梁Owner将短暂为None，指令不可确认，不消耗行动。若因引擎/脚本异常让支撑实际丢失，`RT037`立即回滚至Setup本地态；右臂连接、人员位置和所有跨话键不变。

### B. 探索中：第四Tick校验失配

前三筋排除后，玩家在第四Tick未将唐胶三击、勇拳微抬梁和跌跌松垫片对齐。第四Tick被消耗而`FOURTH_RIB_VERIFIED`未产生，`RT038`立即回到`EXPLORE_ENTRY_LOCAL`：右臂恢复悬置可修态，外部姿态恢复，记忆、白函样本和断臂都未持久化。

### C. 切后：两枚设备同时进桥

设备A尚占用三段桥面时，尝试确认设备B进入。界面先给全桥超载预览；如果测试构建强制确认，`RT039`立即回到`POSTCUT_LOCAL`。本局仍保留“已切臂”的戏剧起点，但五人/两设备重置L2，桥面清空；世界快照仍是E02，不会出现“手永久没了但人还在桥上”。

## 6. 结论

区域级纸演找到至少四条合法成功组合，两项真实选择均不改变右臂丢失与白函固定伤痕。载荷交接不存在无支撑帧，五人/两设备可同向过桥，三类失败均有明确本地回滚且不污染跨话状态。
