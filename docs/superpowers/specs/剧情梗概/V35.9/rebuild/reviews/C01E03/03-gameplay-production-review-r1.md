## 一、发现（按严重度排序）

### [P0] `GPR1-01_ATOMIC_RETRY`：永久断臂发生在仍可失败的护送之前，但没有本地检查点与唯一持久提交

**证据**

- `玩法与制作拆分 / SRPG段 / 失败条件`（正文L273-L280）允许在人员受截、勇拳过载、消防机腿位移、未验证开桥或桥载荷超限时失败。
- `阶段结构`（L289-L291）先执行永久切离，再进行五人护送与Boss退场；也就是`GZ_RIGHT_ARM_LOST`发生后，关卡仍有多个硬失败窗口。
- `结算状态`（L322-L333）直接列出永久断臂、五人安全、白函伤痕、勇拳回收和B1锁死，却没有说明何时一次提交、失败回滚到哪一阶段、哪些状态只在本局存在。
- 唯一上游明确只有E02 `RT038`可持久化，且E03期末必须同时满足五人安全与全部伤痕（输入包L68-L76；E02最终放行L29-L30）。

**风险**

若护送阶段失败，运行时可能留下“馆守Z已永久断臂但五人未安全”的半套世界状态；反向实现则可能在重试时恢复右臂，却保留白函断索、纪存记忆或公司处罚。两种都会形成跨话状态污染，且可能重复提交敌方样本或人物。

**最小修补**

建立一条E03本地事务链：切臂前检查点、切臂后护送检查点、Episode唯一持久提交。切臂、白函两处损伤、记忆和五人位置在战斗中都只写本地状态；护送失败可回到“已切臂但未持久化”的本地检查点。只有`五人+设备安全、白函撤离、勇拳锁机、B1六锚ADV完成`同时成立后，才一次提交E03期末快照。退出、重开与任何硬失败都不得留下半套持久状态。

### [P0] `GPR1-02_SAFE_SIDE_TOPOLOGY`：双层空间尚无唯一安全侧和单向撤离链，五人、豪司与消防机操作员可能互相增员或走出不同版本

**证据**

- 五人开局被写在泵站入口、L1维修承台、馆守Z脚边和低压接头（`可读剧情梗概 / 1`，L71-L75）；后文又明确两名接驳员及设备在L2唇口（`7`，L153-L157）。
- `9. 兜灯切的是还能修的部分`称“五人的撤离顺序”为两名接驳员推设备过桥、唐胶在桥中段接、兜灯随后通过、纪存最后出检修口（L191-L193），但没有标明桥哪端是安全侧、五人各自从哪端进入、是否有人逆向会车。
- 豪司沿西门路线进入运输架（`4`，L113-L125），随后白函才进一步把战场切成三块（`5`，L127-L133）；当前没有锁定西门何时关闭、为何五人不能复用豪司刚走过的路线、豪司最终位于安全侧还是成为第六名待撤人员。
- 消防架桥机“驾驶员”在馆内剧情开头报告压力（L71），而输入包锁定馆内人类起点恰为5人，豪司入场还必须单独演出（输入包L9-L14）。驾驶员若在车内，会直接破坏人口合同。

**风险**

当前无法画出一张不自相矛盾的区域连通图，也无法证明“所有五人都必须过同一座桥”。程序可能把两名接驳员放在安全端、让核心三人逆向过桥，或保留西门捷径，使断臂不再是唯一必要解。豪司或消防机驾驶员若被当作馆内人类Token，胜利计数会变成6/7人并软锁`FIVE_INSIDE_HUMANS=SAFE`。

**最小修补**

本轮不要求x/y坐标，但必须给出唯一的**区域拓扑**：L1危险区、L2危险区、白函框内区、西门入场区、桥入口、桥出口和最终安全区；为五人、设备、豪司/勇拳、跌跌、机器犬、消防机及其操作员标明起点与终点。锁定豪司进场后西门被哪次白函动作切断，并说明豪司始终随勇拳处在不计入五人桥载荷的承梁侧。消防机操作员须明确为楼外/远程职业操作员，或另行纳入人口与撤离合同。五名目标必须具有同向、无会车歧义的可执行撤离链。

### [P0] `GPR1-03_SUPPORT_HANDOFF`：SEG3同时承担E02遗留承梁和E03右臂托面，勇拳也同时“顶梁”和“推梁”，缺少无悬空瞬间的载荷交接状态机

**证据**

- 输入包锁定消防架桥机SEG3已经反折支撑次梁、左前腿过载，且本机不能变为自由移动单位（输入包L18-L22）。
- E03先让消防机以三条未过载腿调平、左前腿保持原格（`3`，L99-L109），又在白函切区后让它继续维持外侧支点，勇拳肩背顶住L2次梁（`5`，L129-L133）。
- 飞拳前置动作要求勇拳把下沉梁顶高半格，同时消防机把SEG3外缘压到维修轨旁，作为右臂离轨后的托面（`6`，L139-L149）。正文没有说明SEG3离开原承梁接触面前，梁重是否已经完整转交勇拳，也没有说明“压到维修轨旁”是桥板关节转动还是整Rig位移。
- 失败条件又规定勇拳负载越线或消防机过载腿再次位移即失败（L273-L280）。

**风险**

若SEG3不能离开次梁，右臂没有托面，飞拳阶段不可进入；若它先移动，次梁坠落；若勇拳为了推梁离开承梁姿态，同样坠落。这是当前最直接的物理条件环软锁。

**最小修补**

锁一条可纸演的载荷交接：`SEG3_REVERSE_BRACE -> BRAVE_FIST_CONTACT -> BRAVE_FIST_BEAM_CLAIMED -> SEG3_JOINT_PIVOT_ARM_CRADLE -> ARM_ON_CRADLE`。说明消防机四足零位移，仅SEG3在关节许可范围内转位；勇拳“推梁”是承梁姿态内的受限行程，不消失支点。每一步给出前置、载荷所有者、失败预警和可取消预览；任何合法确认都不得造成一帧无支撑或把左前腿重新计入动作。

### [P1] `GPR1-04_PHASE_OBJECTIVE_CLOCK`：八阶段是剧情顺序，不是可运行的目标、行动经济与敌方节拍

**证据**

- 胜利条件把“持续不坍塌、完成飞拳、固定桥、护送、迫退Boss”并列为五项（`SRPG段`，L265-L271）；这些其实是不同阶段的前置、不变量和结果，不能作为同一时点的任务面板。
- 失败条件没有绑定生效阶段；例如“强行站起”“回收右臂”“额外巨型攻击”可能在对应指令尚未开放或已经关闭后仍被实现为全局监听（L273-L280）。
- 白函每次内收都会减少一条通路，标尺机还会推进（`5`与`7`，L129-L133、L161-L163），但没有敌方行动相位、内收次数上限、目标选择或玩家延缓方式。
- “可修复窗口九十秒”（L147-L151）与“战斗时间暂停到低速压力态”（阶段5，L288）没有转换为回合/压力Tick；章地图要求豪司第三回合介入（章地图L48），正文阶段表也没有对应触发。
- 全段没有单位移动/行动次数、场景工序费用、巨机热量增量或白函几何进度的可求和合同（L282-L300）。

**风险**

实现方无法判断玩家何时操作、敌人何时收框、对白是否吃掉九十秒，以及延误到哪一步是可恢复压力、哪一步是硬失败。白函若按“每回合少一路”直译，可能在强制探索或演出期间把最后通路关掉，形成无合法行动但尚未触发失败的状态软锁。

**最小修补**

为每阶段补一行运行合同：入口状态、当前目标、可控对象、可用动作/费用、敌方意图与结算相位、退出触发、失败、检查点。把九十秒映射为固定数量的压力Tick或明确的玩家动作额度，暂停/对白不暗扣时间。白函内收与标尺机推进必须有限、可预览、可被玩家动作延缓/改向；所有合法选择要么存在后续合法动作，要么立即给出明确失败，不允许零行动悬挂。

### [P1] `GPR1-05_FAKE_AGENCY_AND_TRAPS`：主线正确地锁定主动切臂，但当前仍把必败按钮和未兑现的“自由”写成玩家选择

**证据**

- 兜灯界面同时显示“回收右臂”和“切断主筋”两个绿色可行方案（`9`，L175-L179），失败条件却规定回收右臂会使退路消失（L278），核心规则又明确主线固定主动切离、不做保臂分支（L300）。若玩家可确认“回收”，它只是包装成分支的必败按钮。
- 失败条件列出馆守Z强行站起和额外巨型攻击（L277、L280），但阶段1只开放抬肩，馆守Z也被定义为不能连续普通攻击（L284、L295-L296）。若这些按钮不存在，失败条件是假的；若存在，则是没有正收益的自杀按钮。
- 规则声称玩家自由包括“白函破框方向和五人撤离调度”（L300），但正文固定右侧主框弯裂、右肩伤与内收索断裂（L145-L151、L187、L328-L329），五人顺序也已唯一写死（L191-L193）。

**风险**

玩家会发现所谓选择只是猜作者指定答案；或者关卡为避免必败而把所有动作脚本化，首控馆守Z退化成依次点亮剧情按钮。两种都不满足“固定故事结果、真实战术 agency”。

**最小修补**

把兜灯的两绿方案明确为**角色戏剧信息**，主动切离由剧情门锁定，不在玩家路线菜单伪装分支。强行站起、未验证开桥和额外攻击若必然致命，应作为不可确认的危险预览/教学反馈；若保留为可用动作，就必须提供可读收益、预警与可恢复代价。另至少落地两项真实战术选择，例如上下层支援分配、白函主框开口方向或设备分批节拍；它们改变通路、压力Tick或桥载荷，但共同汇入已锁的右臂永久失去与白函两处伤痕。若不实现，就删去L300的自由声明并把本关诚实定义为高编排解谜战。

### [P1] `GPR1-06_UNIT_ACTION_OWNERSHIP`：单位、Token、固定Rig、场景动作与敌方部件没有唯一owner，2x2巨型首控也缺少身体规则

**证据**

- 准备阶段同时调用跌跌顶垫片、机器犬牵软管、消防机三腿调平和纪存标范围（`3`，L99-L109），没有说明哪些是玩家指令、自动维持、工作人员工序或一次场景事件。
- 白函切区后，勇拳、馆守Z、跌跌、机器犬和消防机都在维持不同承点，五名人类位置还要持续可见（`5`，L127-L137）；后半又要控制馆守Z左臂格挡、勇拳承梁、三处桥载荷和五人护送（L191-L193、L290）。
- `核心规则`只说明馆守Z动作先结算建筑受力、勇拳许可范围和右臂动态载荷（L293-L300），没有说明馆守Z2x2是否可平移/转向、肢体作用区、热量上限、援护是否消耗回合，或勇拳究竟是可移动单位还是固定姿态支点。
- 白函、两台标尺机、内收索和采样贴片在叙事中均有动作（L91-L93、L161、L199），但生产拆分没有区分Boss组件、独立敌单位、轨道Hazard和纯演出道具。

**风险**

关卡、程序和演出会各自拥有同一动作：例如“跌跌释放垫片”既可能是探索输入，也可能是战棋技能；“白函内收”既可能由Boss AI执行，也可能只是过场切图。首控2x2馆守Z若没有足迹/朝向/肢体作用规则，只剩一个大型剧情菜单，无法兑现巨型单位玩法。

**最小修补**

补一张不含坐标也可用的owner表：对象、表现层级、控制方、占格/所在楼层、阶段可用性、动作及费用、维持姿态、受击/失败责任和资产层级。馆守Z可保持固定2x2半跪足迹，但必须明确是否允许转向，以及抬肩、巨型援护、滑轨飞拳、左臂格挡各自作用区、热量和建筑位移；勇拳明确为锚定承梁单位还是短距单位。右臂按`ATTACHED -> LAUNCHED -> SUSPENDED -> VERIFIED -> CUT_BRIDGE`转移owner；白函主框/内收索是Boss组件，标尺机则明确为占格单位或轨道Hazard，不能两者兼有。

### [P1] `GPR1-07_LOAD_AND_HYBRID_MODE`：探索确实能改变战斗，但桥载荷与模式切换仍只有叙事规则，无法验证一条无软锁成功路线

**证据**

- 断臂探索要求纪存检查三处可见筋束，再结合唐胶敲击、勇拳抬梁和跌跌释放垫片完成第四筋验证（L161-L173；`探索/副玩法段`L253-L257）。这些外部动作是否预先锁定、是否消耗SRPG行动、探索时敌人是否继续收框均未说明。
- 阶段5称战斗暂停到“低速压力态”，外部单位姿态成为解谜输入（L288），但没有模式入口/退出、时间流速、失败或重试规则。
- 护送阶段只说错误格会提高载荷、额外巨机动作会超限（L191-L193），核心规则也只说桥上单位、巨机动作与内收会改变载荷（L299）；没有人员/设备重量级、桥段容量、同格/会车、设备交接或过载后能否卸载恢复。

**风险**

探索可能在玩家失去外部控制后等待一个尚未建立的姿态，或反过来在探索期间被白函自动耗尽时钟。护送则可能出现唐胶站在中段接设备后堵住唯一通路、设备与人员无法同格、或一次错误停格造成永久超载但不判失败的物理软锁。

**最小修补**

探索入口先原子锁定外部姿态并冻结其行动归属；用固定检查次数/压力Tick完成，输出至少包括`FOURTH_RIB_VERIFIED`、桥可开放段和桥承载等级，失败回到探索入口本地检查点。桥规则只需先做小型离散合同：人员、设备的重量级；前臂/滑架/唇口三段容量；进入、移动、交接、退出的载荷结算；超限预警、可撤回预览和硬失败点。给出一条逐动作纸演，证明五人和必要设备能同向通过且唐胶中段交接不会堵路。

### [P2] `GPR1-08_ASSET_STATE_MATRIX`：资产总量可控，但当前清单低报了玩法状态和碰撞切换，尚不能据此排期

**证据**

- 资产边界已主动限制馆守Z不做完整自由行走、勇拳不做正式必杀、消防机复用E02固定Rig（L380-L389），这是正确的范围控制。
- 但实际玩法还需要馆守Z半跪援护/左臂挡框、右臂连接/发射/悬吊/已验证/切桥、桥面受力反馈、右臂内部探索剖面、白函多部件碰撞切图、标尺机推进、五人及设备跨越/交接等状态（L263、L287-L299），未全部映射到资产清单。
- 白函同时有压缩吊运、四脚落地、主框旋转/弯框自撑、内收索、右肩裂、断索和折叠撤退（L382-L386）；若每项各做独立全动画，单话会膨胀为三套新主机体加一套动态双层地图。

**风险**

美术可能按L382-L389只交镜头状态，程序却还需要可碰撞中间态；或反过来为每个状态制作全套战斗动作，压垮C01高潮预算。

**最小修补**

补一张状态到资产矩阵，逐项标`新主体 / 复用主体 / 新动作clip / 程序骨骼变体 / 地图碰撞态 / UI-only / Cut-in-only`。建议继续锁：馆守Z为既有半跪主体加有限肢体clip，勇拳为受限承梁包，消防机与小机复用，右臂内部为模块化短场景；白函是本话唯一完整新Boss主体。右臂桥的五个物理态和白函框体碰撞态必须优先于额外镜头，不新增馆守Z自由行走或勇拳完整武装集。

## 二、成立项与锁定建议

1. **复合桥物理前提可成立。** 输入包L22锁定的5米级右前臂、1.4米滑架、双安全索、4.2米净距与0.9米高差，正文L143-L149、L187-L193及资产边界L383-L386均保持一致；当前不需要为此索要精确坐标，也不构成故事层BLOCK。
2. **无HP几何Boss方向成立。** 白函以主框、内收和自撑改变可走区，玩家以巨型部件反改地形（L129-L151、L291-L299），比普通削血Boss更贴合本话；应保留，只需补目标与组件状态。

## 四、席位结论

**独立结论：`PATCH`。** 本话的主玩法幻想、桥体物理锚、探索因果和资产收口均值得保留；但在`GPR1-01`至`GPR1-07`关闭前，双层图仍无法可靠纸演，存在永久状态半提交、SEG3载荷条件环、人口/安全侧歧义和无合法行动软锁。故Story Core可锁，Runtime/Graybox制作暂不放行；`GPR1-08`须在排期前关闭。
