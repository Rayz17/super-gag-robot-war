# C01E03 机体 / IP / 奇观最终窄复核 r3

> Verdict: `PASS`

## 证据

1. **左臂格挡时序已关闭。**桥面不会在切臂后立即开放；纪存先关闭三段通行，馆守Z再把左臂降入白函内收路径，待肩、肘与楼板位移归零后锁成静态挡梁，明确写成“五人上桥前最后一次巨型动作”，随后才依次开放桥面（`C01E03-断臂成桥-v1.md`，§二.9，L197-L201）。五人通过时左臂只保持上桥前已锁定的等长承力，没有再次挥动（L203-L205）。生产段同步规定锁定维持不增加热量/位移，左臂一旦离开锁定位就立即关闭三段桥面，与“任何额外巨型动作关闭通行权”一致（§三“核心规则/桥面载荷”，L328-L350）。上轮P1已关闭。

2. **白函学习提前已关闭。**飞拳受击前后的白函动作现被限定为原有卡止机构的被动防倾覆：受力时只锁住变形侧，弯框压入裂缝也只是避免侧倾，文本两次明确说明它尚未学会新用途（§二.5，L133-L137；§二.6，L157-L159）。五人完成断臂桥撤离后，白函才主动照着右臂成桥翻转裂框，把伤口同时变成支撑与折叠踏步，并在该动作后提交唯一`DAMAGED_BODY_TO_SUPPORT_FUNCTION`样本（§二.10，L207-L215）。被动卡止、观察、主动模仿、稳定学习的因果顺序成立，上轮P2已关闭。

3. **馆守Z首控与飞拳奇观未缩水。**首控仍以十八米巨体令L2先下沉、玻璃与尘土先反应，再让馆守Z抬头；重量先于英雄构图（§二.3，L101-L111）。飞拳仍完整保留SEG3承梁、勇拳肩背接触与预载、梁权转交、固定轴翻托槽、右臂落槽、滑轨高速推出、拳端撞框、白函整格位移、馆外目击、豪司喝彩被负载警报压回座椅，以及“但右臂没有飞回去”的停顿和九十秒可修窗口（§二.6，L145-L159）。没有被压成Cut-in或结果句。

4. **勇拳、白函与右臂的身体动作仍清楚。**勇拳以肩背真实吃载并在承梁行程内推梁，`BEAM_CLAIMED`只是可见动作完成后的确认，不是UI替身（§二.6，L149-L153）。右臂仍经历攻击部位、悬置可修身体、主动切断后的复合桥三态，并以五米前臂、1.4米滑架、双索、4.2米净距和两端搭接落实物理尺度（§二.6，L151-L157；§二.9，L185-L205）。白函则保留四脚落地切图、右肩裂框、断索、主动翻裂框自救和带伤折叠撤离（§二.2，L87-L97；§二.9-10，L197-L215）。

5. **IP投射与伤痕没有被流程术语压死。**超级系快感仍由飞拳运动、冲击、观众反应和不可回收反转承担；勇者系快感仍由口号冻结后豪司进舱、肩背承梁和肉身挫伤承担。馆守Z永久缺右臂、白函右肩裂口/内收索断裂、消防架桥机左前腿过载继续跨话保留，勇拳仍由企业回收并剥离数据；没有社勇王、金章人格或无损复原偷跑（§二.10-11，L211-L243；§三“结算状态”，L382-L404）。

`PASS`。上轮两项PATCH均已以读者场面和生产规则双重关闭，且飞拳、勇拳承梁、裂框自救、断臂成桥与三方伤痕的镜头强度均未下降。
