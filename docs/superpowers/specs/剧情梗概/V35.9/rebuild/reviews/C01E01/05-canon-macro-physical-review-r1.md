## 一、结论

C01E01的新故事发动机成立，且明显强于旧版的行政说明式开局。跌跌、机器犬与馆守Z低热胸灯的多尺度救援可以保留；六站只展示万机馆一小部分、远星空白回信、零号门异响和索引尚未成人人格的层级也基本正确。

当前不能直接判通过。阻断点不是要求退回旧故事，而是新方案尚未把五处上游合同或物理口径迁完：

1. S01缺少S02硬读的`C01_COLLECTION_PRIORITY`。
2. 白函在S02究竟是远程压场还是实体Boss，V35.8内部互相冲突。
3. “29名观众”与“29人撤离组”不是同一工作数，且多出维修员和核心工作人员。
4. 新稿让七海在零号异响前先开私人频道，与现行实体/场景触发顺序冲突。
5. 馆守Z开局是“整条右前臂已拆”还是“机械臂仍连接、只拆外装甲”，Canon表内部及新稿口径冲突。

这五项都能用定点迁移关闭，不要求改写本话核心戏。

## 三、Patch

### P01 六站路线需给出唯一有向路径

当前“六站”在可读层被展区蒙太奇淹没，且旧PB把白舰舰桥舱写成路线站点，但Canon将L2舰桥廊锁为只可见。最小补丁是在制作层锁定：

`WL_L1_FRONT_HALL -> WL_L1_GUARDIAN_Z_PLINTH -> WL_L1_COMBO_TABLE/WL_L1_MODEL_HOSPITAL -> WL_L1_REAL_MACHINE_STAGE -> WL_L1_OLD_VIDEO -> WL_L1_ARCHIVE_ROOM`

六站结束后，纪存单独经`WL_L1_STAFF_CORRIDOR -> WL_L1_ZERO_GATE`调查；0号门是异常支线节点，不冒充第七个公开展站。L2舰桥廊、飞行天桥、同步廊、B1泊位和外部锁泊都只通过抬头视线或终端灰图显影，玩家不得实际进入。

**通过条件**：探索节点表逐站给出`from / to / access_state / sightline_only`；不存在从L1步行进入L2、L3、B1或B2的镜头。

### P02 远星回信需要合法的L1物理载体

Canon把正式远星观测廊放在锁闭的L3；初稿却写“远星展柜”在六站途中吐信。无需开放L3。最小补丁是在L1旧影像厅或前厅总图旁定义一个只读延迟回信副柜，它只显示L3离线缓存的信封元数据，不提供实时通信。

**通过条件**：场景注明载体位置、离线来源和只读边界；没有远星真景、当前政治主体、即时回复或导航能力。若不新增副柜，则把事件改为L1终端收到L3缓存异常，不能让人物进入L3。

“全馆熄灯”必须是按闭馆计划关闭展陈照明，不等于城市电网、维生和B1泵站已经停电。建议E01结算固定：

### P04 白框、白函和责任主体需在制作层分栏

初稿层级大体正确，但“同一白框”很容易被读成早期索引人格或白函本人控制四机构。制作层必须固定责任矩阵：

| 层 | 能做什么 | 责任边界 |
|---|---|---|
| 四机构 | 各自签发接管、冻结、军资和安全命令 | 各自保留签名，不能把责任推给同一UI |
| 七海 | 签发并撤销代哥侧统一断电令 | 只为自己可控制的命令负责，不替军方/商品/平台签字 |
| 共享白框组件 | 分类、推荐、提前半拍移动光标 | 无连续人格；工具依赖不等于免责 |
| 白函 | S02远程改报，S03实体执行 | 具名执行载体，可按具体行动追责；不是索引肉身 |
| 索引 | C01只有分布式工具层 | 不会说“我”、不记得上一秒、不承担跨章人格计划 |
| 0号侧廊 | 旧接口与异常载体 | 来源未证，不是下令者或人格名 |
| 远星空白回信 | 旧时代离线/迟到包异常 | 不是当前远星观察、下令或援助 |

**通过条件**：E01/E02每个命令、机械动作和异常信号都有`issuer / executor / carrier / observer`四栏；不出现“零号命令四机构”“索引派白函”或“远星触发接管”的越级结论。
