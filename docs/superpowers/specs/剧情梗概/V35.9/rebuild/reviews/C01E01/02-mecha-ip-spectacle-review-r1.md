# C01E01 机器人文化 / IP / 奇观席独立审读 R1

> 审读对象：`C01-逐章重构地图-v1.md`、`C01E01-最后一条闭馆路线-v1.md`
>
> 核对基线：`V358LOAD001`、`V358U001-01..05`、`V358ABS001-01..06`、`wanji_exhibition_zones.tsv`、`wanji_floors.tsv`、`wanji_locations.tsv`、相关 Canon 实体与美术锁
>
> 本席范围：机器人大战开篇感、真实参战/首显、机体身体与欲望、IP共同记忆、万机感、尺度、PV镜头、机体层级
>
> 审读结论：`BLOCKED_FOR_TARGETED_PATCH`

## 一、总判定

这已经像一个有自己气质的机器人大战开篇，不再像博物馆行政摘要。玩家首话实际控制跌跌和机器犬，用小尺度、牵引、占格和环境反射打三回合救援战；馆守Z以18米巨物和低热胸灯进入同一棋盘；路径框、贴片机和撤离Token让“机器人如何改变地图”可玩。冷开场的馆体巨影、断臂地形，正篇的胸灯安全阴影和逐区熄灯，也已经给出后续巨构升级的承诺。

但当前版本还不能锁。最大的问题不是机体少，而是五台`first_appearance`里只有跌跌、机器犬完全通过可读层证明。馆守Z有身体却没有自己的意图，市政吊装机仍可能被观众当成普通吊车道具；社勇王是真机首显，但镜头和来源吸收都太轻。于是合同上是“五台”，观众记忆里容易只剩“两台小机、一盏巨灯、屏幕里两件大型设备”。

最小修复不需要增加一场大战，也不需要新增主资产。只需让馆守Z完成一次自主保护动作，让社勇王和市政吊装机的馆外直播形成有起因、受力、选择和结果的连续六至十秒，再把六站速览从一个名词段落拆成几次移动中的具体观看。

## 三、Blocker

### B01 馆守Z仍像一盏被人操作的巨型灯

**证据**

- 正篇已经建立18米半跪、主动力断开、右臂维修和胸灯温区，身体尺度非常好。
- 高潮却由唐胶拆安全罩、兜灯开放灯圈、玩家调角度；馆守Z只“亮了一下胸口”。
- `CAND001`要求它作为棋盘巨型单位证明“这是机器人大战”，Canon又把旧守护者导览人格的正式出现放在C01E01。现在观众只看到巨型设备被调用，没有看到守馆者想把人送出去。

**为什么阻断**

本话最大的机器人若没有一次自主判断，“最小与最大互相成全”就只完成尺寸组合，没有完成机魂关系。它在功能上能计场景支援，在观众心里却仍可能是布景、灯塔或武器平台。

**最小修法**

不站起、不挥拳、不提前首控，只在现有胸灯段补一个四拍动作：

1. 兜灯开放最外圈，唐胶把挡板推到预定角度。
2. 最后一名观众偏离反射线，纪存来不及重算。
3. 馆守Z的头部或上身在断主动力状态下自行偏转极小角度，或自主熄掉会扫到跌跌的一格灯瓣，把安全阴影送到观众脚下。
4. 旧导览人格只说一句普通引导语，或用闭馆提示音确认“最后一位观众已过线”；兜灯仍握有硬停权。

这样只增加头颈/胸灯微动作和一句声音，不增加站立战斗集，却能同时证明身体、欲望、旧超级系苏醒前奏和兜灯的安全边界。

### B02 市政吊装机是“工务结果”，还不是一台被看见的机器人

**证据**

- `V358U001-05`把它列为`standard_32`真实首显，独有语法是推拉、架桥、地形施工，形象锚是“在巨神脚下搬动整段高架”。
- Canon要求它有独立吊臂和稳定腿，属于城市劳务机器人谱系。
- 初稿只有“吊装机随后缓慢移走一段外部承力轨”。没有稳定腿、底盘、关节、受力变化、操作选择或现场目的；删掉“机”字后完全可以是一台普通吊车。
- 逐章地图“机体分层与正向欲望”表也漏了它，说明它尚未真正进入本章机体关系。

**为什么阻断**

这是本话最接近“道具冒充机体”的位置。单纯搬完一件东西只能证明工务发生，不能证明`V353U031`完成观众层首显，更不能建立城市职业机甲的共同记忆。

**最小修法**

继续放在同一块馆外取件屏，不增加新场景。把一句结果扩成三拍：稳定腿依次撑开并让路面下沉；独立吊臂在社勇王目光提示后主动换受力点；机体横移或退一步，把整段承力轨让出清算车转弯半径。给它一个朴素目标，例如“封路前完成夜班移轨、给送修车留出转弯位”。动作结束后让吊臂因回弹抖一下或负荷灯降回绿色，观众才能感到重量真的经过了它的身体。

逐章地图后续回填时，应在机体分层表补一行市政吊装机：层级为馆外首显/后续工务核心，本章欲望是完成夜班移轨并保持公共通道，独有身体是稳定腿、独立吊臂和承力换点。它仍不参加本话SRPG。

### B03 社勇王来源吸收被写成“已采用”，可读层只完成了预告

**证据**

- Canon锁允许C01E01只在馆外送修直播中做头颈/目光受限首显，禁止完整HUD、武装动作和首话参战；当前稿遵守了这一点。
- `V358ABS001-03 / BFR025`的核心不是“出现一台勇者”，而是AI在未批准状态下愿意承担责任。
- `V358ABS001-06 / CAND020`要求说明书许可实际改变支援、合体或责任签名。
- 当前直播只有一次转头，足够证明是真机，却不足以证明许可端已经改变玩法；来源表把`BFR025 / CAND020`并列写成已采用，证据强度不匹配。

**为什么阻断**

若保持现稿故事，`CAND020`只能是后置来源，不能声称已在本话吸收。若为了追字段硬塞完整许可动作，又会违反社勇王的受限首显锁并抢走C03勇者高潮。

**最小修法**

故事层只加强`BFR025`的预告：直播先显示送修模式“全伺服保持”，错误吊点即将受力时，社勇王仍自行转动头颈，用目光或短促自检灯指出红色禁挂标记；操作员据此停吊，市政吊装机换位。不要喊著名许可台词，不给武装HUD，不完整亮相。

来源层后续应把本话证据写成`BFR025责任母题预吸收`，把`V358ABS001-06 / CAND020`明确`defer_to_C03`，除非上游合同另做迁移。C01E01只锁`V353U024 first_visible`，不虚报许可端已经成为本话支援单位。

## 四、Patch

### P01 机器犬有身体，欲望仍被玩家代办

机器犬钻台、咬牵引带和叼晚饭袋都很好，现实四足机器的触感成立。但“开哪扇门、让谁先过”全由玩家决定，它自己的正向欲望只存在于地图和自检字段里。

最小补法是在第一回合给它一个坚持：系统要求它回充电区，它却先回头锁定被展岛遮住的最后一名维修员，叼住牵引带不松口。玩家决定的是为它打开哪条高风险门、放哪台贴片机进来，不替它决定要不要救这个人。这样既保留`BFR069`的“会开门却不知道该把谁关在门外”，又让机器犬不是会执行指令的开门钥匙。

### P02 六站的“量”成立，“逛过”仍主要靠一段名词蒙太奇

对照 Canon，当前稿可辨认的收藏样本已超过八类：中庭巨神、合体剖面、变形骨架、勇气审批、现实机器、旧影像、模型玩具、L2舰桥、飞行天桥、同步身体廊。十九区、L1/L2/L3/B1/B2和外锁泊边界也正确，万机馆不是无限机库。

问题是六站几乎全部压在同一段说明里。玩家知道这里“有很多”，却还没有六次移动、抬头、绕行、停手和舍不得离开的经验。`飞行歌舞`与`废案创作`还在文化容量总结中被点名，正篇却没有足够具体的可见物，存在总结比场面多算两类的风险。

最小补法不是新建十九个房间，而是把现有段落拆成四至六个短镜头，每个只保留一个动作：驾驶舱座椅降到老观众旧高度；三台剖面样机在错误卡扣前停住；唐胶让修好的模型腕轴转一毫米；现实机器区听见跌跌左膝尖叫；纪存抬头看见飞行器腹面越过馆守Z肩线；旧影像厅的爆音让人提前捂耳。废案墙若不进镜头，就从本话“至少八类”自证中删去，不靠制作字段补数。

### P03 缺一条把0.7米、18米、24米净高和外锁泊连成一体的尺度镜头

数字都对，镜头尚分散。建议复用现有资产做一次连续运镜：从跌跌软垫旁的0.7米视平线出发，穿过馆守Z半跪的膝和脚，向上扫到18米头部及24米顶棚，再从L2飞行天桥空隙看见馆外社勇王送修屏和外锁泊灰标。这个镜头比再说一次“十九区”更能让玩家相信自己只看了万机馆很小一部分。

### P04 社勇王与市政吊装机必须组成一个有因果的双机镜头

现在是“社勇王转头，吊装机随后移轨”，两动作之间没有明确受力因果。按B02/B03的最小修法合并后，应成为：错挂即将受力，社勇王在送修锁定中示警，市政吊装机展开稳定腿并换吊点，承力轨擦过巨机脚边移开，钢索松弛，现场人员才呼气。这样同时得到勇者AI的责任欲、职业机的劳动身体、超级机与工务机的层级差，以及一个不直抄名场面的PV短镜头。

## 五、Lock

### L01 锁定“小机首控 + 巨神限区支援”的开篇结构

不要为了更像传统机器人大战而让馆守Z站起、社勇王入场或追加全灭战。跌跌摔倒占格、机器犬狭窄牵引、馆守Z低热胸灯已经构成独特的机器人战术开篇。补的是机体意志和镜头过程，不是火力吨位。

### L02 锁定跌跌的完整动作链

“左膝尖叫预告 -> 第一次摔倒被判故障 -> 复位后再摔 -> 发现肩壳卡轨 -> 主动用另一腿抵住 -> 等人过线 -> 不漂亮地自己站起”是本话最完整的机体弧，也是现实机器人共同记忆最好的原创化。不得删成“跌倒触发技能”，不得让纪存替它扶起，也不得加台词解释“失败就是人格”。

### L03 锁定馆守Z的边界

本话只允许半跪、头颈/上身微调、导览人格、低热胸灯和硬停，不给完整战斗HUD、站立、飞拳或正式首控。完整首控与巨物承重留给C01E03。增加自主性不等于提前消费复活高潮。

### L04 锁定社勇王的受限真实首显

保留“模型仍是模型、真机在馆外送修直播”的双层关系。真机只可做头颈、目光、自检灯和吊点风险响应，不给武装动作、完整轮廓、著名许可台词或豪司入场。它是首显，不是参战。

### L05 锁定非计数锚件边界

三台透明支架小机、金色胸像、社勇王模型、说明书、审批表、盒绘、重涂、断件病历、旧录像、留言墙和终端图都可以强化机器人文化，但都不能替代真实机体。路径框、贴片机和成功样机列阵也只能按敌方规则机/环境机关计，不得拿来凑 roster-package 首显。

### L06 锁定万机馆物理尺度和容量边界

保留L1主厅约70x45米、24米净高、十九区总图、L2可见受限、L3/B1灰显、B2黑层标、15至30米机体主要外锁泊、战舰任务地会合。万机感来自“馆藏谱系多、空间纵深深、未来入口多”，不是把所有巨机塞进展厅。

### L07 锁定两张已成立的PV图

第一张是火灾后馆体巨影、单臂馆守Z与断臂地形的冷开场。它只作未来结果闪回，不能冒充正篇已经挣到的奇观。第二张是正篇真正完成过程的胸灯镜头：挡板就位、灯圈启动、控制膜烧卷、安全阴影出现、跌跌最后站起。结尾逐区熄灯和胸前余光是很好的余韵，不要用四令说明覆盖掉最后停留时间。

### L08 锁定IP共同记忆的原创化方向

旧超级系用“半跪守馆、胸灯先于站起”改写；现实机器用“摔倒改变地图、开门带来选择”改写；勇者系用“送修锁定中仍主动避险”预告；城市职业机用真实承重和夜班劳动建立。继续不用著名台词直引，不复刻完整合体、出击或必杀构图。

## 六、最小修复包与复审门槛

最小修复包只含四处可读层动作和一处来源状态修正：

1. 馆守Z胸灯高潮补一次自主保护微动作，兜灯仍掌硬停。
2. 社勇王/市政吊装机直播扩成一个连续双机受力镜头，不新增战斗集。
3. 机器犬先自主锁定救援对象，玩家只决定通路代价。
4. 六站段拆成四至六个已有资产的动作镜头，并补一条纵向尺度运镜。
5. `BFR025`只记责任母题预吸收；`V358ABS001-06 / CAND020`后置，不虚报许可玩法已经发生。

复审通过条件：

- 新读者能准确说出本话实际控制两台、场景支援一台、馆外首显两台，而不会把模型和展具算进去。
- 新读者能说出馆守Z自己做了什么选择，也能画出市政吊装机至少两种独立身体部件。
- 社勇王首显仍受限，却有“未批准仍主动避险”的清晰责任欲。
- 至少八类收藏样本在可读层有具体视觉物，文化容量总结不多算未入镜类别。
- 胸灯高潮保留完整过程，馆外双机镜头也具备起因、受力、选择、结果和短暂反应。

达到以上条件后，本席可把总判定改为`PASS_WITH_LOCKS`。当前不要求重写Episode发动机，也不建议把小型救援升级为巨机正面战。
