## 一、签署结论

## 二、Blocker

**无结构性 Blocker。**

纪存的私人欲望、主动能力、关键选择和高潮动作均已具身；本话关系层的问题都能在现有场次内修复。不得因此加新事故、再让纪存反灼，或把一话重写成关系主场。

## 三、Patch 与最小修法

### P1 七海：把“熟到像监控”改成普通旧熟悉，并补一粒公务错认

**证据**

- 可读稿 77-79 行把餐具、肩后疼痛、精确行走位置、杯子位置和“今晚没有下次”叠在一个段落里。尤其“准确报出他刚走过合体变形环”过于精确，七海像定位系统，不像熟人。
- 145-151 行的频道变色、先确认观众再问零号侧廊很自然，证明她并非突然翻脸；但她并未误判任何事。自检所称“旧温度切成公务误判”目前超前于场面。

**最小修法**

1. 删除“她没有问清算，也没有问零号侧廊”及“从肩痛精确报出所在展区”。肩痛在本话不承担关系或破局功能，也不必提前增加纪存受难纹理。
2. 把同段改成两轮普通对答：七海报出具体饭菜/餐具所在，纪存仍只答“马上”，她用一句“几点的马上”或同等熟人反问戳穿他；杯子仍在档案室水槽边。示例只锁方法，不锁逐字台词。
3. 在 151 行收到消防回线图后，只补一个有依据的小错认，例如七海问“这条线从零号侧廊出来的？”她错把局部旧消防线当成纪存触碰完整零号路由；先要求他离门远一点，不立刻定罪。若不补，则把本话全部口径统一改为“公务切换 / 误判前态”，把完整误判留给 E02。

**通过证据**：读者能同时感到她熟悉纪存的坏习惯、真在担心人，也能看出她为什么会依据不完整现场图作出错误职业判断。

### P2 唐胶 / 兜灯：让两人的专业先发动，纪存负责合成而非授予

**证据**

- 71-73、89 行已给唐胶工艺判断、悲观嘴硬和修模型时的紧张，人物种子成立。
- 117-139 行中，兜灯只问要不要开、握硬停；唐胶只拆安全罩。Story Core 又写成纪存“把停机权交给兜灯、把拆解判断交给唐胶”，容易把两人的既有专业权写成主角赐予。
- 地图承诺 E01 要建立二人的工作默契，当前读者看见的是并行功能件，不是关系。

**最小修法**

1. 保留纪存分工，但把“交给”改成“确认并服从两人的原有边界”。删掉解释他如何正确授权别人的评语。
2. 在胸灯前只加一轮两人互接专业的动作/短句：兜灯先限定“只开外圈，过温就停”；唐胶摸过安全罩边缘后给出会卷膜/开裂的工艺余量并调整角度。两人可以刺一句，但必须一边争一边把同一件事做完。
3. 让最终支援缺一不可：兜灯拥有真实硬停，唐胶拥有导光罩是否承热的否决，纪存只负责把观众路线、小机位置和两项边界叠成战术图。

**通过证据**：遮住姓名后，读者仍能从“工序硬停”认出兜灯、从“手感/材料余量”认出唐胶；这一轮默契能自然前置 E03“兜灯作身体决定、唐胶只递正确工具”。

### P3 小满 / 阿澄：各给一个儿童逻辑动作，不让安全等于无人格

**证据**

- 69、103、143 行把二人留在前厅并隔离后场，方向安全。
- 小满在 89 行试动社勇王腕轴，但没有自己的话；阿澄除共同收留言卡外没有独有动作。旧警报处又合称“两个孩子只是被吓了一跳”。

**最小修法**

1. 开场各补一个不超过一句话的独有动作：小满用“感叹号/最强/我能帮忙”的错误儿童逻辑维护社勇王；阿澄一边抚平留言卡一边数人数，指出一个具体未归队对象或问谁来接。不得让两人讲世界观。
2. 旧警报只做安全反应差异：小满先嘴硬，阿澄抓紧卡盒并确认要跟哪位大人走；不让任何孩子冲回展区、操作机器或安慰成年灾变幸存者。
3. 把“馆方只能先把两人留在前厅黄线内”改清楚为“交给前厅值班员或已登记成年人看护，留在黄线内”；纪存去零号门前再次确认二人已并入安全组。

**通过证据**：读者能用“嘴快怕添乱”和“数人来压住害怕”分别复述两人；所有动作仍发生在成人看护和安全区内。

### P4 删掉三处作者辩护，让动作自己证明

**证据**

- 75 行：“这句话没有被当成口号。”
- 119 行：“这是他第一次……不是交出责任……”
- 133 行：“这不是把失败解释成人格。”

三句都像评审结论闯进 Reader：它们提前反驳可能的批评，反而提醒读者对白被设计过。

**最小修法**

- 75 行直接让唐胶重新按紧锁扣，其他人继续闭馆。
- 119 行直接写兜灯拿硬停、唐胶选可拆柜、纪存展开路线图并进入最危险位置。
- 133 行只保留跌跌主动用另一条腿抵轨、等人通过后自己站起。
- Story Core / 自检可保留设计判断；可读剧情不得解释“这不是某种主题语法”。

**对白 LOCK**

- 71 行锁扣/拆件展示：技术细节先行，干笑成立。
- 97 行“现在不用趴……跟着地灯走”：有听众、有动作、能稳人，是纪存魅力核心。
- 129-131 行“先别起来……等人过去，再自己站”：既是战术请求，也把尊严还给跌跌。
- 149 行“馆藏状态不明”：只出现一次时，幽默寒意有效。

### P5 把关系动作分清“锚点”与“因果线”

1. **旧杯子 / 凉饭：`LOCK_ANCHOR`。** 它们只需证明共同生活过，不要在 E02 变成证据、权限钥匙或敌方样本。
2. **删信改发消防回线图：`LOCK_CAUSAL`。** 这是本话真正改变后续的纪存/七海动作。E02 的错误火场模型应部分来自这张“真实但不完整”的图；七海撤令时也应读取纪存没有把她排除在现场真相外，而非重新从零认识他。
3. **兜灯硬停 + 唐胶导光否决：`PATCH_TO_CAUSAL`。** E02/E03 必须延续为两项独立专业权，不能下一话又由纪存逐次批准。
4. **孩子各自的小动作：`LOCK_ANCHOR`。** 它们可以只改变玩家对“这里像家”的感受，不必硬做长期变量。

## 四、Lock 清单

1. 纪存“想体面闭馆、赴约、证明馆长不在也能照看好”的三重私人欲望。
2. 纪存通过听声、观察、安定人群、拆一段路由和叠合空间破局；禁止补成反灼给答案。
3. 唐胶嘴上说“没有明天”却仍修好小满的腕轴；悲观与手上不肯敷衍的矛盾要保留。
4. 七海私人频道转公务颜色，以及她先核对全部观众、再问异常的职业顺序。
5. 纪存删掉“你先别来”，发送实际用过的回线图。
6. 机器犬叼湿晚饭袋、紧张观众笑出声、纪存取回纸袋时的无奈笑。
7. 馆守Z胸灯照完后允许全员撤离和小机归位完整成立；不要在同一句里追加纪存疼痛、道德账单或敌方取样。
8. 小满、阿澄不进入零号门、危险维修、责任签署或任何成人关系语法。

## 五、最小合并范围

无需新增场次。建议只动四个现有位置：

1. 场 2（69-79 行）：儿童各一动作、七海两轮普通对答、明确成人看护。
2. 场 4（97-103 行）：儿童安全反应差异，并入安全组。
3. 场 5-6（117-139 行）：唐胶/兜灯一轮专业互接，删除三处作者辩护。
4. 场 7（145-151 行）：保留公私切换，补一粒证据型错认；锁定消防图进入 E02。

总修补应是数句对白与动作，不应新增关系事故、告白、擦边、伤病或权限字段。

## 六、通过条件

完成以下六项，本席可直接签 `PASS`，无需重建复审：

1. 纪存的破局仍由观察、判断、组织和风险选择完成，肩痛/异常不承担答案。
2. 七海旧温度来自普通生活熟悉；公务错认来自不完整证据，且保留先护人再查人的顺序。
3. 唐胶、兜灯各拥有一个不可互换的主动判断，并共同改变胸灯方案。
4. 小满、阿澄各有一个可辨认的儿童动作/声音，且看护责任明确。
5. 可读层不再出现“这不是口号 / 不是交权 / 不是失败人格”式自我解释。
6. E02 明确读取消防回线图，E03 明确读取兜灯硬停与唐胶工艺否决；旧杯和凉饭继续只是生活。
