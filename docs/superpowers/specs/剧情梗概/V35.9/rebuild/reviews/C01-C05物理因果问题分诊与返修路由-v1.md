## 一、裁决

两份报告并不等价。

旧v2仍能证明它实际检查的十项身份、权限、人物和路线问题已经处理过，
但它没有以普通读者边界重建完整时间轴、巨构空间、受力、安全链和证据来源，
所以不能继续承担“整批无硬伤”的结论。

后出的物理因果报告所列九项P0逐条成立。根因不是五章故事全部失效，
而是L4总纲通过后，逐话表演重新引入了相对日期、夸张规模、错误证据和
未回答的简单替代方案；现有验收门没有在章节Reader生成后重新检查这些问题。

处理原则：

1. 不直接修改机械生成的章节Reader或跨章合订稿。
2. 每项问题回到最早拥有该事实的L4、L4.5或单话Reader源。
3. 保留已经成立的角色选择、机体高光和章节发动机。
4. 只为玩家必须理解的因果增加可见动作，不增加专有名词。
5. 修完单章后机械重建；C01-C05全部修完后再做一次只读正文的累计盲审。

## 三、逐章返修包

### C01：建立能被后章继承的物理事实

必须修：

- 明确广场、南侧泊位、馆守Z路线和群众避难点。
- 起航前给出一组一眼能懂的动作：公共管线自动脱离、展柜锁定、工作人员
  进入加固地下避难区、一次性泊位支撑折断。
- “不能回旧址”改为“还能飞回城市上空，但旧址起降座已经毁坏，普通地面
  无法承接百米舰体”。
- 章末让白色采样机抓取时在水淹旧泊位刮下一片内衬。城市清理组次日把它
  登记为不明碎片；我方尚不知道它来自什么。
- 开放资料明确旧守护者三层载体：人格根、馆守Z胸腔导览席、可更换轮式终端。

保留：

- 火灾、清算与闭馆同时爆发。
- 馆守Z和社勇王首次出击。
- 万机馆紧急起身、离开旧址。

### C02：修复承接、证据与固定Boss动作

必须修：

- E01改为次日上午，并明确轮式终端是备用外壳。

- E03固定巨台只做转体、屈膝和落槌，不行走。
- E04将“采样机残骸”改为城市清理组送来的不明白色内衬碎片；
  它与平台匿名供应批、归一星护框和白色组件材料相近，但身份仍是推断。
- 高空战关停民航空域；最后一班交通艇撤离后才开放战区。
- 试验架坠落前由馆守Z或本地吊机挂住慢降索，避免胜利后凭空安全落地。

保留：

- 四台重涂机和木桶街地方援护。

### C03：把巨构协作从夸张句收回可见受力

必须修：

- 市政批准的是低比例试载；衡令绕过人工确认，把一条载荷支路升到紧急级。

- 万机馆进入承重槽，只接住西环局部支路；馆守Z锁住滑移制动点；
  旧拳王击回卡死的导向楔。
- 补衡令为何封门：它触发了危险隔离逻辑，并把居民与观察塔误留在隔离区。
- E04按一夜到次日下午排时间，给维修、签约、面谈通知和离舰留出常识时间。
- 两封不同年代回信同时到达，只用一条通俗解释：旧包在坏中继里滞留，
  新包走不稳定超距信标；节点恢复时一起吐出。

保留：

- 城市职业机群的专业协作。
- 七海取得随舰调查身份。

### C04：先建立铸环机构，再让动作发生

必须修：

  平时横置生产，竖起后才成为发射环。

### C05：重接人员艇事故，不削弱人物选择

必须修：

保留：

## 四、生产线修订

新增`reader_causal_audit`，顺序为：

```text
单话Reader
-> 机械合成章节Reader
-> Reader时间空间与物理因果盲审
-> 人类声线语义审查
-> 章节总审
-> 用户创作验收
```

盲审者只读玩家可见文本，检查：

- 绝对与相对时间、航程、维修和通信延迟；
- 人、机体、舰体、建筑的尺度、站位、可达范围和受力；
- 驾驶、远控、机魂接入和控制权；
- 证据从何而来、角色如何知道；
- 正常安全装置、失效链和群众避难；
- 有能力角色为何不用更简单的方法；
- 世界内首次与玩法解锁首次是否混淆。

发现问题时只输出证据、根因和最早责任层。审稿人不替正文发明补丁，
单一主笔完成修订。

## 六、完成标准

本轮不是要求把故事写成工程说明，而是要求玩家在不看后台资料时：

1. 不会遇到时间倒流、证物凭空出现或已毁物件复活；
2. 能看懂大机器人究竟在托、拉、挡、追、救什么；
3. 明白事故为何发生，也明白专业角色为何没能提前避免；
4. 能区分世界内发生过的事件与玩家刚解锁的玩法；
5. 仍然保留五章已经成立的机体高光、人物抉择和关系后果。
