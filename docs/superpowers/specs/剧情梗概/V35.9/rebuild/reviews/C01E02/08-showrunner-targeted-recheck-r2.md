## 总判

按连续游玩口径，玩家现在可以清楚复述这条单次因果：E01里纪存为救人暴露了一段消防回线，四令借此封门、灭灯、冻钥匙、停泵；E02里七海依合理但缺层的现行图切电，短暂灭掉电弧却令旧风阀合拢、烟压暴涨；纪存组织小机取证，各方共编救援图，七海撤销本人错令并停权；消防架桥机将二十九人送出、再以反折桥板保住留守者退路；白函最后沿这张图为实体落地量好十八米框位。

这条因果不再需要制度附表才能理解。纪存的主动性、七海的错误/修正/关系伤口、工业火场的过程、二十九人的释放、消防机的物理主峰与白函尾钩均已成立。本话可放行，不需要再做剧情结构性修补。

## 放行证据

### 1. E01 -> E02 的单次因果清楚

- E01「灯熄灭以后」末段（`C01E01:153-171`）明确留下同一个时间、空间和人口快照：29人仅越过闭馆线、尚未出楼；四令控制门/灯/钥匙/泵；烟进入、喷淋只落黑水；七海已命令走西侧。
- E02「一滴黑水」（`C01E02:61-77`）从同一滴水、同一条黄线、同一只湿晚饭袋和同一身赴约便装继续，没有重置人数、灯光、泵压或关系温度。
- 此后每一步都由前一步逼出：切电令旧风阀下落（`85-97`） -> 三证与专业工序证明缺层（`101-121`） -> 各方共编救援图（`125-137`） -> 消防机才能进场、落腿和铺桥（`139-165`） -> 七海撤销本人命令，现场再机械恢复门泵（`169-185`）。

### 2. 纪存是破局者，不是记录员或被动承伤者

- 他在开场先定西门、禁止回头拿东西，随后自己回到火场（`65-67`）；这立住「把29人送出去」的欲望。
- 他没有用旧记忆压过七海，而是在被要求只报已确认状态后，改为安排机器犬和跌跌取得烟流与温度物证（`87-119`）。
- 他不是再抽出一条私人捷径，而是放开离线结构底图的共同写入，把现行图、继电、材料、小机数据和消防承重组织成一张可用图（`125-135`）。这个不可逆动作既符合他「把不同专业和尺度编成同一动作」的核心能力，又与 E01 的「单人拆出一段秘密路由」有实质区别。
- 七海停权后，他仍把她的口头路线原样写入公共图（`183-185`）；「三十二呢」之后，他亲手取消自动清场，保留公共支援（`199-213`）；次梁下落时，又是他旋转公开图找到SEG3反折解（`221-225`）。主角能力连续发生三次不同形式的有效动作。

### 3. 七海的错误、修正与关系伤口自然连在一起

- E01已用催饭、餐具和水槽边的杯子建立两人的旧生活温度（`C01E01:73-83`）；E02开场让七海的便装、湿晚饭袋和纪存关掉过时的九点提醒进入同一镜头（`C01E02:69-75`）。因此她后面刻意转入公务称谓，不是突然冷脸。
- 她在六分钟、城市电网扩散风险和一张可被同僚复核的现行图下下令（`85-91`）；电弧先熄灭，说明该命令确实有正收益，然后烟压才暴涨（`93-97`）。她的错误是有限信息下的专业误判，不是为了给纪存让路而降智。
- 物证闭合后，纪存没要求她相信自己；她也没念责任报告，只撤本人的高压锁、保留母线隔离并放消防低压（`169-181`）。她停权后仍用声音报出路线，纪存一字不改地采用（`183-185`），完成「专业伤害已发生，但对方的有效判断仍值得信任」的行动回收。
- 「三十二呢」不是一句孤立金句：它实际改写清场状态、延长公共支援并让三人主动回工位（`199-213`）。关系行动直接改变了 R5 能否获救，成立。

### 4. 工业火灾片成立，不是行政摘要换名

- 四令在「七海的第一条命令」中只以门、灯、钥匙、泵和互相顶住的机械权限章出现（`81-85`），没有四段机构说明。
- 现场破局依靠双色温度片、反向烟流、管壁冷凝、双层管回声和低温示踪（`101-119`）；紧迫感来自低位烟、六分钟、七十秒、水压和桥位，而不是风险字段。
- 消防架桥机的登场和高潮拥有完整工业过程：外形、工具与身体分层（`141-145`）；三段桥的受力、拒绝非法落点、水压换通行格（`151-165`）；冲洗针车、挡偏切割轮、手动复泵与总管变形（`189-195`）；最后是SEG3反折、左前腿移位、梁桥撞击和压力报数（`217-235`）。
- 「白框量到十八米」开头用喷红环、手动泵针和烧黑风道的连续镜头交代状态（`241-243`），没有退回结算列表。

### 5. 能量波完整：反噬 -> 建图 -> 救人 -> 承梁 -> 静默 -> 尾钩

1. **反噬**：切电后先有一秒安静，再让烟压下沉、时钟从十一分钟跳到六分钟（`89-97`）。
2. **建图与机体起势**：三证让知道什么不知道，六层信息共编后，消防机以倒车蜂鸣、四腿和液压报压进场（`101-147`）。
3. **人员释放**：总管鼓胀的代价在最后一组过门时发生，随即给出`29 / 29`、「我听见了」与「三十二呢」（`191-209`）。胜利不被立即撤销。
4. **职业机物理主峰**：次梁已在铺第三段桥时从绿跳黄（`151-155`），装卸坪排热又使它由黄跳红（`191-195`），所以 R5 坠梁是代表路线的延迟代价，不是临时追加危机。SEG3反折完成本话真正的机体高潮（`217-235`）。
5. **高潮后呼吸**：驾驶员的报价玩笑、梁桥停沉、楼外绿色人数、馆内窄退路与「没有人立即说下一步」给了明确释放（`231-237`）。
6. **白函尾钩**：释放之后才用一句改报、测量光与重型运输锁开启抬高对手（`241-255`），没有把二十九人获救改写成「等于没救」。

### 6. E03 保留了足够升级，且不需重演 E02

- E02的期末快照是29人楼外、3名核心留守者+2名消防接驳员在内侧、供水受损、SEG3反折、勇拳静止、馆守Z右臂连接、白函只有远程框位（`C01E02:338-383`）。`07-runtime-graybox-paper-run-r1.md:20-34`独立证明这一人口、权限、桥状态和重试边界可以单次闭合，没有隐藏的「重救29人」。

## 残余风险（非放行阻断）
