## 一、锁住不重写的核心

1. 七海基于缺层现行图切东侧高压，命令先有正收益、再制造烟压危机。
2. 三件现场物证证明所有人都只有半张图；纪存不得靠机魂反灼跳答案。
3. 七海撤回本人命令并当场停权；不放水、不偷开按钮、不念责任报告。
4. 消防架桥机逐腿落地、三段铺桥、定点冲洗、反折承梁和左前腿过载。
5. 29名撤离对象全部出楼，C3完整，维修员不重生；代表伤痕固定`FIRE_SUPPLY_BURNED`。
6. 勇拳本体绝对静止、豪司不到场；馆守Z只被动冷却；白函只远程，完整身体留E03。
7. `29/29`、`三十二呢`、报价笑点和短胜利呼吸先成立，白函随后才改报并预布18米框位。

## 二、根因级改法

### RC1：E02改为“共同实时建图”，不再复写E01

- 删除纪存再次关闭完整搬运脊道、再决定公开更大秘密图的主破局语法。
- 纪存开放的是万机馆离线结构底图和公共共编入口；七海叠入现行城市消防层；跌跌/机器犬提交温度与烟流；唐胶标材料和旧管；兜灯以被动继电/温感校正旧层；外部消防补上栓位与路面承重。
- 得到的是“足够完成本次救援的完整消防/撤离层”，不是全知馆体图；`FULL_MOVING_SPINE=NOT_EXPOSED`继续成立。
- 纪存的不可逆动作变为放开全馆消防/撤离底图的共同写入和调用权，不是再次选择多披露几段路线。
- 唐胶、兜灯从重复否决者改为主动补图者；专业边界仍在，但团队语法翻转。

### RC2：三名核心人员必须主动留馆，且“三十二呢”改变玩法后果

- `29/29`后系统准备清场；七海问“三十二呢”，纪存立即把状态改为“29人出楼、3名工作人员仍在馆内、现场未清”。
- 唐胶主动返回桥铰/隔板工位，兜灯主动返回馆守Z硬停位，纪存守手动泵与现场调度，三人都在馆内侧。
- 正因清场没有结束，城市公共救援频道和R5最后一点支援仍保持；消防架桥机才能接受反折桥板指令，保住三人出口。
- 白函在泵站/消防队交接完成前解锁运输落点并堵住他们，E03因此必然，不是三人为了等Boss不走。

## 三、局部场面补丁

1. 场1-2补七海看见湿饭袋停半拍、纪存关掉晚饭提醒；她以正式称谓截断未经验证的旧层猜测，纪存误以为自己已被归为危险源。
2. 场5补唐胶按兜灯硬停腕带侧切握位，兜灯不复验材料直接接用，并把高温夹具让给他；不说“信任”。
3. 消防架桥机入场先给完整职业机本体：低矮作业头/驾驶舱、承力躯干、四条独立髋轴腿，再给背负桥板与冲洗臂附件。
4. 补一条跌跌短臂 -> 机器犬软管 -> 消防机腿/桥腹 -> 馆守Z黑暗巨影的连续三尺度镜头；馆守Z不得动作。
5. 勇拳由运输架防坠系统自动发出一次紧急启动请求，许可继电在机外断开；机内压力零、批准窗黑、本体零位移。豪司仍不到场。
6. 针车/标尺机补夹轨底盘、工具接触、受力反冲与止挡余波，不新增HP或人格。
7. 第三桥段铺设时提前带到封闭运输架和受热次梁；装卸坪泄压继续顶弯该梁，使R5成为代表伤痕的后果而非临时加戏。
8. 白函覆盖前给一小段物理呼吸：29/29稳定、三人出口仍绿、七海灰窗未断、消防机压力回到红线内。

## 四、玩法合同施工顺序

1. 模式唯一化：`ADV切电/烟压翻面 -> EXPLORE三证提交OLD_LAYER_EVIDENCE_READY -> SRPG_SETUP -> R1共同建图/消防机接入 -> R3七海撤令 -> R4撤离局部完成 -> R5承梁 -> ADV_END白函改报 -> ATOMIC_SNAPSHOT`。
2. 新建精确12x14 Graybox：A11/B10/C3/D5固定Token、两小机、B1高差入口、桥三段、四个安全格、敌轨、消防机落脚与三名工作人员位置。
3. 锁行动经济和相位：小机`move + 1 context`；人员工序逐回合分配；消防公共支援与七海写权限分池；非法落点预览零消耗。
4. 桥状态机：`SEG1/2/3`固定物理身份；`SEG3=DEPLOYED_WALKWAY -> EVAC_CLEARED -> REVERSE_BRACE_ELIGIBLE -> REVERSE_BRACE`。
5. R4只实现代表路线`FIRE_SUPPLY_BURNED`；`VISITOR_SMOKE`为失败压力，`ROUTE_KEY_COMPROMISED`放分支差分，不进入本轮Graybox UI。
6. R4只写本地`EVAC_COMPLETE_LOCAL_NONPERSISTENT`；R5失败从本地检查点重试，29人保持楼外且不上图。
7. R5与尾部ADV完成后只提交一次`C01E02_PHYSICAL_SNAPSHOT`；E03只读此快照。
