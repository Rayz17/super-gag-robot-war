## 总判

本话已经能被读者复述：**七海依缺层图切电，反而使烟压暴涨；纪存以现场物证找到旧层，七海撤回自己的命令并停权；消防架桥机铺出退路、救出二十九人并承住次梁；白函借公开图为下一话量好十八米落点。**

开场物理前态与 E01 精确连续；纪存和七海都有欲望、错误和不可逆行动；针车、标尺机、火、烟与提前半拍的白光标共同构成了具身对手。消防架桥机的高潮有完整过程，`29 / 29`、「三十二呢？」与报价玩笑也给了分层释放。Reader 整体已不是制度摘要。

但两个创作阻断仍使本话不能 PASS：一是它在深层复写了 E01 的解法语法；二是「三人为何不跟二十九人出楼」只有期末字段，没有人物选择。这两处不补，E02 的独特指纹和 E03 的必然性都不成立。

## P0

### P0-1：换了职业机，但深层解法仍在重演 E01

**精确证据**

- E01「被列进库存的人」里，纪存拒绝打开完整搬运脊道，只拆出一段消防回线；兜灯以硬停权拒绝越界通电，唐胶否掉纪存的挡板角度。紧接着「三回合小型救援战」把专业边界、小机和馆守Z编成救援，末尾让对手捕获消防路由与纪存声纹。
- E02「图少了半层」里，兜灯再次拒绝馆守Z通电，唐胶再次否掉纪存的挡板切法；「把整座馆摊开」里，纪存再次关掉打开完整脊道的快速方案，改为公开更大的消防图；随后又把小机、两名专业者和一台更大机体编成救援，末尾再让白函学会这张图。
- 因此重复的不是「小机摔倒」这个表层动作，而是**拒绝整条秘密脊道 -> 由唐胶/兜灯再次以否决纠偏 -> 公开更大路由 -> 多尺度协作救人 -> 对手学到救援语法**的整条戏剧引擎。这是「同一故事放大一号」，不是近话变奏。

**最小修法**

1. 保留七海切电/撤令、完整消防结构公开、消防架桥机和白函学图四个锁定结果。
2. 不再把「纪存又一次关掉整条脊道，改选更大披露」作为本话核心破局。让两张缺层图、温度片、烟流、管壁与现场人员共同生成一张**实时可写的公共救援图**；纪存的不可逆动作是放开全馆结构的共编/调度权，不是再决定「这次多给几段秘密图」。
3. 唐胶、兜灯至少有一人从「再次否决纪存」改为主动提供一块缺图或一个正向操作，让 E02 的团队语法从「专家给主角设边界」翻成「没有人有全图，大家必须共同建图」。

**过关证据**：修后复述 E02 的解法时，不再需要说「纪存又拒绝了整条脊道，改为公开更多路线」，而能说「所有人都只有半张图，他们边救人边共同把路画出来」。

### P0-2：E03 的物理条件有了，但「三人留馆」还没有成为选择

**精确证据**

- 输入包 LOCK 8 要求：七海问「三十二呢？」之后，纪存、唐胶、兜灯**选择留下完成排火与迎击 E03**。
- E02「二十九人出楼」目前只说「我们三个还在里面」，七海回「那就别报清场」。这是位置核验，不是三人的决定。
- 紧接着「一台没有动的勇者机」写唐胶和兜灯「越过铰链」，但没有说他们越到内侧还是外侧；「白框量到十八米」又明说西门保持开放。按当前镜头，三人在白函落地前有路也有理由撤出。
- 因而结尾的重型运输锁虽然预告了 E03 对手，却没有回答最朴素的连续性问题：**为什么二十九人都走了，他们三个没走？**

**最小修法**

1. 紧接「那就别报清场」补一个三步动作：纪存说明手动泵/排烟还要守到消防队交接；唐胶主动留在隔板/桥铰位；兜灯主动留在馆守Z硬停位。三人各自转身回工位，而不是被结算留下。
2. 在承梁段明确唐胶/兜灯「越过铰链」的方向和纪存位置，保证三人期末都在馆内侧。
3. 让「重型运输锁解开」发生在手动泵交接完成前，使 E03 不是他们为了等 Boss 而站着不走，而是因为刚才主动留下的工作，被白函真正堵住。

**过关证据**：读者能用一句具体动作回答三人为何留下，并能指出白函落地时他们分别在哪个工位。

## P1

### P1-1：「两人各有半张图」到「全馆完整消防图」之间有一步因果跳跃

**精确证据**

- 「图少了半层」通过温度片、烟流和冷凝证明旧回风/消防共用层存在，纪存明说「你的图没错，它少了半层。我的也一样」。
- 下一场他却立即能发出包含「门、泵、风道、手柄、承重点，全部」的全馆图。当前物证能证明「有隐藏层」和大致流向，不能自动生成全馆每个接口与承重点。
- 这使本话最重要的不可逆动作看起来像调出了一份制作附表，而不是人物现场赢来的答案。

**最小修法**

与 P0-1 同步修，但必须多给一个可见的拼图步骤：纪存开放受限的全馆结构底图，七海叠入现行消防层，唐胶/兜灯或小机用现场材料、继电标记或温度数据校正旧层。图应当是「为当前救援足够完整」，而不是纪存突然拥有的全知蓝图。

### P1-2：消防高潮的过程和释放已成立，但次梁需在早一场进入因果链

**精确证据**

- 过程已成立：「把整座馆摊开」写四腿试压、避管、接水、锁身；「桥不是飞过来的」写三段桥依次落位、水压换可通行格和敌方插口压力；「一台没有动的勇者机」写桥板反折、左前腿移位、碰梁、压力报数与涂层发黑。
- 释放也已成立：`29 / 29`、纪存/七海的「我听见了」、「三十二呢？」，以及唐胶与驾驶员的报价玩笑，都在白函改报前给了胜利空间。这些不应因 PATCH 被删或缩成结算字幕。
- 唯一因果薄点是：次梁和勇拳运输架到第8场才首次出现，而二十九人已经获救。所以 R5 承梁暂时像为 PV 高光后加的第二个危机，不是代表路线付出的必然价格。

**最小修法**

在「桥不是飞过来的」第三段落点时带到运输架和受热次梁；在「二十九人出楼」选择装卸坪排火时，让玩家看见外侧热量继续顶弯它。这样次梁坠落就是`FIRE_SUPPLY_BURNED`路线为保人/保钥匙承受的可见后果，无需增加新场或新灾难。

### P1-3：E03 上游地图仍保留了与本话期末矛盾的「二楼观众」

**精确证据**

- E02 输入包和本稿都锁定：29人全部出楼，馆内仅纪存、唐胶、兜灯三名核心工作人员。
- `C01-逐章重构地图-v1.md`的 E03 场面仍写白函「把二楼观众和一楼机体切开」，并写「所有人踏过右臂」。按当前唯一前态，E03 不应再生成一批观众。

**最小修法**

这不应由 E02 加回观众来补。E02 保持`29 / 29`出楼；章地图/E03 输入在下一话起稿前，将被切开与过桥的人员改为三名留守者、消防员或其他明确新进场人员。本席只登记该连续性冲突，不用本话正文替 E03 预写。

## P2

### P2-1：只剩一处轻微的「结算摘要」语感

**精确证据**

「白框量到十八米」开头连续报告「商业后勤风道烧黑、档案主库紧急冷却、B1泵勉强可用、西侧总管红环」，是 Reader 中唯一段较像把结算字段改写成句子的地方。它不足以使整话回到制度摘要，但会在白函尾钩前让镜头停一下。

**最小修法**

把该段改成一次沿撤离路线的连续镜头：消防员给变形总管喷红环，手动泵针抖在最低格，紧急冷却声从烧黑风道后传来。保留同样三项状态，不再额外解释它们对后续字段的意义。

## 修后复核门槛

1. 用一句话分别复述 E01 与 E02 的破局时，两句不得只差「小机/职业机」和「局部/全馆」。
2. 不看结算状态，读者能说出完整消防图是怎样在现场被拼出来的。
3. 不看 E03 输入，读者能说出三人为什么主动留馆、白函又如何在交接完成前真正堵住他们。
4. 保留消防机四腿落地、三段铺桥、反折承梁、`29 / 29`、「三十二呢？」与报价玩笑；白函仍只在这些释放完成后改报。
5. 上述 P0 清零后可回本席做针对性复核；P1/P2 不应引发全话重写。
