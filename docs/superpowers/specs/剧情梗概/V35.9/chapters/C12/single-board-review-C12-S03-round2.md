1. **合法主人和声明角色混写。** 八项资源的`legal_owner_id`属于作者避难自治席、万机馆运营席、多方档案托管席、独立泊位、市政医疗等主体；八名搭档只是`declaration_actor_id`。第三轮前必须把二锁拆成“角色事业主张与物理动作 + 合法托管席复签”，固定提交分别记录`declaration_actor_event`和`legal_owner_consent_event`。
2. **白鸢无权直接公开八人的私人原话。** 她只能公开索引构图、预测逻辑和自己的源文件；四组原话先进入私人频道，公共播出必须由各组另行同意。

4. **开场四组动作过于同构。** 机器层仍可统一记为`PROXY_BOTH_YIELD`，外在场面应分别表现为设备互锁、工程命令冲突、企业责任默认归属与公共电源抢占。
