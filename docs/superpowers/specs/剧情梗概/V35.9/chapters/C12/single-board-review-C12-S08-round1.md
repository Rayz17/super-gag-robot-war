# C12-S08 单板审查 Round 1

Review ID: V35.9-C12-S08-R1  
Author Slot ID: V357-C12-S08  
Reviewer Mode: single-context fallback / story-engine + state-closure + gameplay-production passes  
Status: revise_required  

## 1. 整体判断

纪存“明知越权仍救下所有人”的主角发动机成立，而且终于不是小权限、小延迟或低级犯错。他先凭能力找到唯一受力解，再把自己变成一直反对的总管理员；救援真的成功，停止请求也真的被侵犯。七海与白鸢共同救他、停他，黑展柜皇影以“有能力继续攻击却主动停下”反照纪存，人物、关系和机战高潮能够咬在同一件事上。

但初版只有可读承诺，没有证明3936条父入口、动态一至八机、两至三台强制对象、75种关系拓扑和六区永久损失能够不被汇流压平。本轮不能通过。

## 2. 阻断问题

### R1-B1 WBM损失仍是泛称，S09无法知道具体断了什么

“至少五类成本”只能证明代价数量，不能决定合法/非法两路在医疗环、档案栈、锁泊格纳库、作者避难层、外环舰群和B1脊柱各自损失哪一件设施、馆藏或身体。若只交`ALL_SIX_COST_CLASSES_COMMITTED`，S09三舰分裂会重新发明损失。

**修改：** 建立路线乘六区的12条损失合同；按被强制区或最高伤损区选择至少一项具名损失，保留备份缺失、保管权和设施能力下降，禁止战后免费恢复。

### R1-B2 关系只写“解析器”，没有逐父链的一对一sidecar

合法线有50条、非法线有25条关系输入。若S08只写三角决裂的统一结果，会丢掉此前是否允许身体接触、谁先公开承认、谁保留私人线路以及七海/白鸢之间的独立关系。

**修改：** 生成75条逐父关系sidecar。保留欲望，但分别提交纪存/七海默认指挥信任破裂、纪存/白鸢私人路线关闭、七海/白鸢独立联合断线；每周目最多一处主身体边界，关系不得生成资源、权限或机体身体。

### R1-B3 动态锁泊选择器缺少性质测试

27台候选中存在实体、远援、残骸、静态支持、共享合体身体、馆守Z特殊状态和皇影显式槽。样例清单不能证明不会生造第二身体、同时选择组件与合体形态、强迫皇影或在不足两台有效对象时硬编单位。

**修改：** 增加八类性质fixture，覆盖全量、稀疏身体、三台可用、非部署有效身体、共享形态、皇影排除、馆守Z条件强制和不足两台硬失败；锁定全局最多八台活动、最多三台强制。

## 3. 创作与制作问题

- 六区必须是同一巨物身体的六个受力部位，而不是六张菜单；第一章闭馆路线的展区要在变形中被辨认和损坏。
- 玩家必须先用三至四个局部同意节点缩小纪存的罪，不能旁观固定过场。
- 七海合法线与非法线的断线代价必须不同：一条毁掉改革终点，一条毁掉匿名和回归制度的可能。
- 白鸢四种父状态必须形成四种地图切断动作，不得统一为“剪掉一格”。
- 皇影首控要有兜灯许可、唐胶机械解封、一次破锁和玩家主动停机四步；不能变成纪存的新宠物。

## 4. 本轮决定

返工R1-B1至B3，并把六区、七海两路、白鸢四态、馆守Z四态、皇影首控、T0-T9波次和标准/低评价/硬失败全部写进机器合同。完成后进入Round 2。
