## 2. 新发现的Canon阻断问题

### R2-B1 初版把半变形本身误称为WBM005

馆体模式表明确区分：`WBM004`是C11-C12整舰超控和巨型战场身体；`WBM005`不是下一套更完整变形，而是失败、错版、灼痕、迟到、空白与停止声部打断清噪后形成的残缺开馆态。初版生成器把T7半变形写成`WBM005_HALF_TRANSFORM`，会抹掉本话最重要的二次反转：纪存先以统一强制救人，七海、白鸢和皇影再用残缺声部夺回停止权。

这不是术语小错。若不修，纪存越权和三人反制会变成同一个状态，皇影主动停机也不再是WBM005成立的必要条件。

## 3. 定点修正

1. T7改为`WBM004_FORCED_HALF_TRANSFORM`：纪存机魂桥接旧B1，强迫两至三台具名机体完成一次动作，伤痕半变形托住六区。
2. T8保留七海责任/验证层切断与白鸢传播/叙事层切断，生成残余停止与失败声部。
3. T9由皇影破锁、玩家主动停机、纪存断线后，失败、错版、灼痕、空白和停止记录反灌同一伤痕身体，才提交`WBM005_ACTIVE`。
4. WBM005复用WBM004已经损坏的巨物骨架，只改变支援声部、UI和反接管规则，不新增一套完整人形资产。
5. 生成器、执行域、结算、S09适配和checker必须同时要求WBM004救援与WBM005残响转换；无残缺声部直接进入WBM005列为硬失败。

## 4. 本轮决定

完成上述语义迁移并重新生成全部合同。Round 3需同时验证可读层、机器层、资产层和S09边界；只要任一层仍把WBM005当成半变形本体，本槽不得采用。
