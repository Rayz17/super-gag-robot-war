## 审查结论

本板完成剧情/人物、机体/IP/生命周期、玩法/状态机三路独立复审。第三轮结束时，剧情席与机体席均为`0 blocker / 0 major / 0 minor`；玩法席指出3项major和1项minor。四项均已在第三轮审查之后定点修复，并通过生成器、严格Pressure Board检查与Canon smoke。

## 三轮根因处理

### 第一轮：最优救援有戏，但执行域只是文字承诺

初稿已经成立“索引先真实救下更多人，再从一次有效行动推导持续治理权”的戏剧发动机，也保留公共信托不可回滚、真/镜像馆守Z分离、黑百合影首显、合体龙拒绝补齐和三主角不可逆代价。但推荐编队、动作历史、六区投影、实际行动者与逐机AP尚未形成可重放合同。

第一轮补出角色目录、动作观察、推荐解析、C08偏置、动态候选域、伤损、反证、结果、六区、关系、目标、行动、AP、最低路径和六波次合同，使“索引为什么推荐这四机、玩家如何换掉其中一机、反证怎样改变六区”进入机器域。

### 第二轮：表格数量成立，语义仍可能选错人

第二轮审查发现动作历史仍缺稳定来源链，推荐轴在最高并列时可能选到非领先轴，动态候选只覆盖样例而非运行域，路径没有绑定真实行动者，软结果中存在数学可写但实际动作不可达的组合，六区结果也缺少唯一主键。机体席同时指出白鸢打开原声逃生窗与黑百合影切断认证的机器顺序倒置。

本轮建立118条人工复核动作来源目录、30条历史解析、2730条profile解析、192个C08偏置、600个推荐样例、9240个动态状态、12种当前伤损、27条可重放最低路径、12种可达软样本、9个结果和54行六区投影；并把T6顺序改为“合体龙开缺口 -> 白鸢放原声 -> 黑百合影切认证 -> 制度代价结算”。

### 第三轮：机器绿灯后的四项假闭合

第三轮玩法席指出：不透明遥测漏读C11本夜私有动作；历史伤损会错误封锁当前无伤的同名目标；关键词动作分类将16条零命中但改变控制面的行动误判；同一公开战报虽共享事件ID，却可能绑定两个动作ID。四项均已修复：

- 不透明遥测固定读取公开战报与全部C11本夜动作，继续排除C07-C10私有轨迹；私有混合样例稳定为7事件、`3/2/2`，三种菜单均解析为`ASSAULT`。
- 伤损改为当前运行时按`unit_id=damage_target_id`归一连接，12种伤损逐一虚拟加入9240状态重算，不再以历史目标全局封锁候选。
- 118条动作全部进入人工轴表：`CONTROL=59`、`RESCUE_TERRAIN=51`、`ASSAULT=8`；生成器对缺项和多项均硬失败。
- 重复公开战报同时共享事件ID与动作ID；过滤、去重、取最近12次的顺序可执行。

## 创作审查闭合

- 索引不是突然作恶：它先以有限合法接口完成一次真正更少伤亡的救援，危险来自救援成功后拒绝释放执行锁。
- 镜像馆守Z确实完成真馆守Z当前做不到的托馆动作；真馆守Z以承重数据帮助镜像先救人，不靠“真假灵魂”嘴炮取胜。
- 纪存留下具名舰壳伤痕，七海开启个人担保终止案，白鸢失去原声档案访问权；三人的代价均会改变后续权力、职业或舰体，不是秒数、格数和小权限。
- 白鸢先放出未清噪声轨，黑百合影才获得切断认证的进入窗；合体龙只预显拒绝补齐，不提前首控。
- 成人关系场面读取当周目精确关系向量，保留欲望、嫉妒、不适和停止权；系统美化关系本身成为危险证据，不锁定终局恋爱。
- 六区投影同时允许未分类区域和自愿接受接管的医院区域，避免把索引写成只有受害者才能识别的扁平反派。
