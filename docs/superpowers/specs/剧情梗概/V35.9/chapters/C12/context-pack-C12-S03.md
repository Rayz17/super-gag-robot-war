## 1. 本槽唯一职责

把S02留下的八项事业资源变成一次由人物、机体和玩家共同完成的物理分流：唐胶/兜灯、陆衡/方舟T、豪司/金章、赤罡/莉歌每组只有一座可脱离万机馆的承载舱，必须在两项都真实重要的事业端中保住一端。选择不能由恋爱菜单、纪存、七海、白鸢或“替对方牺牲”的漂亮台词代办；玩家通过护送、停机、占区和承载动作决定哪些端仍可行，当事人本人撤销代理决定、确认最终事业端并承担被留下的一端。

本槽必须提交`PAIR_CAREER_SPLIT`、`FLEET_RESOURCE_CLAIMS`和`UNIT_SPLIT_PRECOMMIT`，并只打开`MEMORY_LEGAL / MEMORY_ILLEGAL`路线窗。不得提前完成S04-S07七海身份、S08纪存强制路由、S09三舰实际归属、S10生活余震、C13方舟T迟到回信或任何终局关系。

## 2. S02精确强制输入

每次运行必须以唯一交接键读取S02的当前周目路径：

`witness_runtime_instance_id + path_id + outcome_id`

不得只读取三组双区结果，也不得把5184条路径压平成576个`outcome_id`。至少继续携带：

- S01实际四机及S02结束时的逐机身体、控制、占格、伤损、行动与活动上限；S03不能重抽“推荐四机”。
- 六区各自的主人、到场/执行/否决状态、设施损失、索引接口、临时锚需要/付款/债务和医院负责人独立决定。
- 黑展柜皇影停止证明、兜灯角色AP付款回执、真实/镜像馆守Z分离状态、重剪舰唯一生命周期、WBM004和纪存中央战术视野丧失。
- 八项不退款资源：`BODY_MASTER / STOP_CHAIN / DIRTY_LOG / FOLD_CORE / BRAVE_PERMISSION / CORPORATE_RESPONSIBILITY / FIREPOWER / INJURY_SOUNDFIELD`。每项从本路径对应的`resource_carry_id`、源区结果、合法主人、逐机状态、设施损失和临时锚债派生；不存在的完整接口不得为四组对称而补发。
- S02关系事实：纪存已经承认“不替人选择”含有自己的恐惧；七海/白鸢已经划清私人身体影像可删除、公共责任不可美化的边界。S03可以让关系继续受伤，不能把三人重置回此前状态。

医院若为`CONTINUED_VOLUNTARILY`，伤员声场携带持续服务义务，不能拆成普通装备；若为`WITHDRAWN_AFTER_SAFE_HANDOFF`，可迁出声场记录，但失去实时医疗接口。

## 3. 单一剧情发动机

WBM004继续移动馆体，六区撤出的八项资源被送上中央转运脊柱。索引为四组搭档生成了看似体面的“爱意最优解”：让每个人主动放弃自己的事业，把完整资源送给最在乎的人。结果四对搭档同时作出相反的自我牺牲，四座承载舱收到互相冲突的代理许可，八端全部开始错轨。

索引的诱惑必须先成立：如果接受代理牺牲，撤收会更快、伤亡风险更低，甚至能暂时保住两端的表面数据；代价是资源的合法主人和搭档都被降成系统替其解释的关系变量。玩家要做的不是证明牺牲错误，而是让每个人有机会说出自己真正想保什么、愿意失去什么，并让这句话在棋盘上付得起成本。

## 4. 四阶段因果与关系硬边界

### 4.1 唐胶 / 兜灯：不能再用停机替对方闭嘴

唐胶让火种货柜领袖托住母版车，暗中准备脱钩自己的车体给停止链让路；兜灯先一步启动停止链，把唐胶和母版一起定在安全区，准备放弃控制柜。两人的“我替你留住最重要的”同时生效，反而让自动补完程序和机械停机销互相咬死。

兜灯必须亲自登上母版车，承担未完身体随时被系统补齐的风险；唐胶必须返回控制柜，把不可迁移的总停止链拆成一枚可带走但功能残缺的实体销。玩家用火种领袖、工务机与跌跌打通其中一条完整撤收线。未被选的一端由对应主人亲手销毁关键接口，不留给索引，也不把两人一句和好。拥挤维护腔、汗、互怼和身体距离可以有成年卖相，但关系变化必须落在“谁终于允许谁触碰自己的工具和停止钮”。

### 4.2 陆衡 / 方舟T：保存你，也可能把你变成证物

折叠通道过热，陆衡下令删除与自己事故有关的脏日志，为方舟T的折叠核腾出算力；方舟T拒绝旧命令，主动弹出核心冷却层，准备优先保住能证明陆衡并非唯一责任人的原始日志。两人都在保存对方，却都没有询问对方想以什么状态继续存在。

方舟T指出日志也记录了它未经许可的自我删改；保留日志可能使它被当成危险证物。方舟折叠探测器只负责标路或执行一次单向通道，不得提前成为C13正式玩家棋子。乐森偶、机器犬和积木智者分别搬人、拖黑匣子、搭只读接口。若保日志，方舟T永久降低高带宽与折叠精度；若保折叠核，陆衡必须公开一份无法自证清白的缺证报告。C13私人低带宽留言与迟到回信不属于本槽事业日志，禁止提前删除、播放或兑现。

### 4.3 豪司 / 金章：勇气不能替公司签完所有责任

社勇王与实习勇者机夹住崩塌门体，豪司试图把许可与责任全部签到自己名下，让两辆撤收车一起通过。金章正式驳回：个人包揽既抹掉AI的拒绝权，也替公司逃掉事故责任。许可章和责任服务器被它强制分离，资源回收框随即把勇者许可改写为商品启动码。

若保许可，实习勇者机完成许可接力，社勇王可以发动一次高阶救援，但责任服务器被留下，后续每次越权都无人制度兜底；若保责任，实习勇者机先救人再主动接受驳回，社勇王放弃终结技，和金铆工具机、预算二号慢拆责任服务器，高阶许可冻结。金章必须作为能拒绝豪司的AI行动者，不得退回盖章吉祥物；实习勇者机只留下未来正式绑定的呼应，不在本槽完成绑定高潮。

### 4.4 赤罡 / 莉歌：伤员不是恋人互相牺牲的道具

索引预编组机沿外环撤退，赤罡准备抛掉追击电容给伤员声场供能；莉歌先关闭全域广播，把电容还给赤罡。两人再次把自己的梦想包装成给对方的人情。舞台战舰将伤员的具体声音送回战场：他们拒绝被写成任何人的牺牲理由，只要求撤离路线保持可见。

歌翼可变机三段变形，板野护航机把杀伤弹幕改成拦截、诱导和照明，舞台战舰展开临时剧场；黑王座、白骑枪和棋兵K队则面对“用一次命令冻结所有人”与“让普通人自行撤离”的诱惑。若保声场，强敌脱离、赤罡失去追击机会；若保火力，莉歌的全域声场永久关闭，只能保留近距真实声音。两人的争吵不能用吻或一句道歉解决，后续支援关系和C13行动必须读取本结果。

## 8. 玩法与机器合同预案

- **地图：**万机馆中央转运脊柱，八个资源端口、四条互斥承载轨、WBM004移动区段和外环撤离口；四阶段共享一张连续地图而非四个菜单。
- **T0：**读取S02精确交接键，公开八端状态、设施损失、医院形态、临时锚债和不可逆后果。
- **T1-T2：**身体/停止与日志/折叠并行；玩家取消代理锁、建立端点可行性。
- **T3：**前两组本人声明并锁定，承载舱进入脊柱。
- **T4-T5：**许可/责任与火力/声场并行；敌方资源回收框和索引分舰预编组机加入。
- **T6：**后两组本人声明并锁定。
- **T7：**四承载舱穿越WBM004错位区；十九机完成轮换撤收或具名支援。
- **T8：**只提交路线中立的逐机预归属和七海路线窗，不提前分舰。

每个资源端要达到`VIABLE_FULL`需两项稳定动作和一项承载动作；临时锚债会为对应端追加一项承载成本。每台活动机每回合1点`UNIT_AP`且不储存；人物本人声明不消耗玩家AP。黑展柜皇影停止证明可冻结一次认证锁，但皇影不进入玩家控制。

**胜利条件：**人员全部安全、四组均有本人签名结果、四座承载舱至少以受损状态脱离、S02实际四机仍有一台可行动。

**硬失败：**出现人员死亡、转运脊柱在安全回退前断裂、任一组没有本人声明，或S02实际四机在T8前全部失去行动能力。

机器层至少需要：5184条S02路径的正规化S03入口、八端资源外键、四组本人声明状态机、四阶段波次、十九机逐状态动作解析、16种最终事业组合、逐机路线中立预归属和S04/S06双门输出。不得用穷举复制41472行资源替代父子关系，也不得只测一条“完美路径”。
