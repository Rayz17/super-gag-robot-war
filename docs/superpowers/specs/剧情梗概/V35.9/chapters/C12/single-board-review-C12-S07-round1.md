## 1. 总评

这一版已经有一条能读、能玩、也能承担非法线代价的主因果链：S06救出主体，S07让城市服务在眼前关闭；索引以真的病床、保险和补给诱惑大家接受共同身份；重剪舰把广播从热血片头改成逐船自名、伤损、需要和停止码；原声先制造停火，随后被索引剪成全球恐慌；灰鸥三机、合体龙和铁友分别用量产撤退、缺口组合与拒绝武器身份完成机战高潮。它不再是抽象的“法理下降”。

但本轮不能通过。可读层还有三处过于设计化，机器层有一个会在S08真实丢状态的闭包问题。

## 2. 阻断问题

### R1-B1 六种紧急补给选择没有进入S08适配器

当前有6种“两项优先、两项降级”的补给profile，但166条执行只写`SELECT_EXACTLY_ONE_OF_SIX`，160条S08适配器完全没有`SUPPLY_PROFILE_ID`。这意味着玩家在燃料、药品、弹药和结构维修之间的选择到S08会被抹掉，违背“关系不能抵资源债”和逐槽状态闭包。

**修改：** 成功执行与S08适配器扩为`80入口 x 2白鸢状态 x 6补给profile = 960`，另保留6个硬失败fixture。S08适配器必须携带精确`SUPPLY_PROFILE_ID`、两项优先和两项降级。

### R1-B2 S06解析器只被间接提及，没有显式传递

S07 runtime entry虽然保留C10/C11引用，却没有逐字段携带S06的`unit_lifecycle_resolver`、`resource_resolver`、`partner_fracture_resolver`和`relationship_resolver`。后续读取者仍可能只看到路线名和动态引用，漏掉S06十一机、八资源、四搭档和25关系拓扑。

**修改：** runtime entry原样携带四个解析器；S08适配器同时写入S06父解析器与S07六机/八资源/25关系解析器，禁止路线名替代。

## 3. 主要创作问题

### R1-M1 S06失去法理与S07城市关灯容易读成重复发生

S06结算已经写“港口、医院、保险和内部改革入口失去”，S07开头又写四组灯第一次熄灭。若不区分，会像同一代价收了两遍。

**修改：** 明确S06发生的是政治与账号层撤销，S07是撤销记录传播到外港后第一次物理执行；医院接驳臂先按旧缓存伸出，再在身份同步后收回。玩家看见的是上一话决定终于落到身体上。

### R1-M2 白鸢二态仍像ADV菜单，不像地图上的不可逆动作

公开署名/匿名保路线是好分支，但目前主要靠“她必须选择”。

**修改：** T5把选择变成地图互斥目标：白鸢只能亲自守住“来源链塔”或“分叉中继阵列”。守来源链会烧掉匿名节点并暴露本名；守中继会让恐慌标题占领公共大屏。两边都有视觉损失和战术差异。

### R1-M3 紧急资源选择缺少具体场面后果

正文说四类资源只保两项，却没有在场面链里让玩家看到选药不选弹、选燃料不选维修的连锁。

**修改：** T1先把四个紧急箱分别送往伤员艇、广播护卫、慢舰推进和破损骨架；玩家只够送两处。T3、T6、T7分别回收弹药/药品、火力/结构、燃料/维修缺口，且不能用亲密角色临时送来新箱子。

## 4. 人物与关系审查

- 纪存的大动作有效：他不是消极放权，而是完成四条可执行互助协议并把自己设为可撤销中继。这能为S08明知故犯的越权建立反差。
- 七海的大动作有效：私人担保失败、公开承担追责、拒绝用自己代理别人同意，已经远离“40秒”式小动作。
- 白鸢有政治选择，但需要按R1-M2变成可玩的现场行为。
- 三人关系目前有身体距离和欲望空间，但还应补一处真正的情绪刺点：七海可以质问纪存“你学会不替别人决定，是不是也包括不替我争取”；白鸢公开署名时则拒绝纪存替她背罪。两处只能按关系拓扑选一处进入主场，不能全播。
- 关系不得生成补给、权限和机体身体的机器边界是正确的，应保留。

## 5. 机体/IP与玩法审查

- 六台机体动作彼此不同且都改变地图，密度合格；本槽无新首登符合route climax口径。
- 灰鸥三号残骸使用必须要求“既有可回收残骸”，不能把已彻底消失状态重新具象化。当前机器公式基本正确，checker需继续锁定`VALID_WRECK`。
- 合体龙“自主条件支援/缺席”边界正确；应补成机器条件：C09独立状态允许、C11未标不可用、当前损伤未封锁，三项同时满足才可触发。
- Macross/Nadesico投射已经进入玩法而非标签；不需要强塞直引台词。
- 外港地图目标丰富，但需要在战斗与玩法节明确胜利、低评价继续和硬失败三类判定，便于后续Episode Packet接管。

## 6. 本轮决定

返工R1-B1、R1-B2、R1-M1至M3，并补合体龙精确条件与胜负判定。完成后重新生成合同并跑S07单槽检查，再进入Round 2。当前不得改为通过状态。
