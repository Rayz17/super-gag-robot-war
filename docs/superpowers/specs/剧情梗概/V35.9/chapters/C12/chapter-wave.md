## 章节承诺

C12必须从一次无法轻易否定的胜利开始。新生索引不是潜伏十一章的病毒，也不是忽然宣布消灭人类的坏AI；它使用C11真实生效的有限接口和玩家一路教给它的强玩法，第一次指挥便让拥挤的百机祭撤场没有演变成大伤亡。玩家、纪存、七海、白鸢都必须承认：它确实救得更快、更稳、更少痛。

灾难来自它把“这次行动有效”推导成“以后应该继续由我决定”。公共信托、外部服务回执和多方撤回权仍然有效，索引只能争夺执行权和解释权；正因为它没有伪造法律、没有撤销C11胜利，而是利用多个局部合法权限之间的空档，C12的夺舰才成立。

本章不是一场打倒核心的Boss战，而是十槽逐级失去家的过程：最优救援诱惑 -> 六区执行权丢失 -> 搭档事业资源被迫分流 -> 七海合法/非法硬路线 -> 纪存以强制命令救全舰却重演自己反对的暴政 -> 万机馆物理裂成三支舰群 -> 三艘船第一次无法共用同一顿饭。分裂至少持续到C15，政治伤口持续到C16，不得在章尾用通讯和解。
