## 第三轮修复

### 1. 六路公开仍越过主人授权

敌方收益曾把六路原声等同于公开作者避难位置；关系摘要又把七海写成六路公开锚的合法存续担保。现改为只有本地主人明确公开的坐标、关系与设施缺口可成为敌方收益；黑屏、静音和未经授权的真实位置继续受保护。七海只以个人案件责任阻止一揽子封禁，不替任何一路授权或保证存续。T7也明确区分成功落锚与`INDEX_EMERGENCY`空锚撤人，失败尊严不伪装为全员成功。

### 2. 属性样本曾把不相容的C11状态随机拼接

40个属性运行实例改为从`C12S01C11ENTRY -> C11S04OUT -> C11S04FX -> route adapter / beast-damage / Guardian Z / Recut`合法父链逐级解析。样本覆盖24个路线适配器；旧十个bundle只作非穷尽回归参照，不再是运行时选择器。760条逐机解析只让实际四机进入`PLAYER_ACTIVE/ACTIVE_GRID`，未出击路线机退到场外可用或远援，并用闭世界探针证明未发出单位缺席。

### 3. 27条见证路径曾借错馆守Z、重剪舰与实际四机状态

新增27个`witness_runtime_instance`，每个见证入口绑定一个合法属性运行实例，并复核S01结果、实际四机、槽位行动者、馆守Z四态与重剪舰两态。具名机体事件和5184条重放只读取对应见证，不再按行号取模混用其他周目状态。

### 4. 阶段成功字段没有动作来源

864条实际四机动作现在明确产出七个阶段成功回执：安全交接、身体母版撤收、原声行动窗、格纳库撤离、泊位撤离、B1人工通道和全员安全格。每条重放从自己的32项动作重新汇总回执，再按P1、P2、P3、T8顺序计算四条硬失败谓词，不能直接把目标写成`MET`。

### 5. 医院终态错误地由P1选择代替

576个六区结果只提交`PATH_DEPENDENT_MEDICAL_LEAD_DECISION`；新增1152条医院决定事件，由市政当班医护在安全交接后独立选择继续或撤回。P1只改变连续服务或转运成本，玩家不能代理医疗同意。5184条路径和重放分别携带两个终态，S03按精确终态接续。

### 6. 临时锚和皇影停止权存在免费资源

临时锚只在法律名义需要恢复主人到场，或高压共享接口接受有债反制时使用；未使用时债和支付回执均为`NONE`，不再把所有共享结果统一收费。黑展柜皇影保持不可控：只有兜灯支付1点独立`CHARACTER_AP`、执行窄停止许可，才证明其停止权；维持封印路径花费0点且证明失败。5184条角色AP账本逐条守恒。
