## 三轮根因处理

### 第一轮：人物余震成立，但路线、机体与资源仍是语义承诺

初稿已经有“开馆以后想过的生活”、纪存牺牲报告、七海/白鸢交叉承认和无攻击护送的核心场面，但独立审查发现：报告生成权限、C09越界、单周目身体边界、公审/撤退差异、C08四锁、C10路线机、S02五项成本、四核心最低路线和结果优先级均未完全闭合。

第一轮补出三份当夜事故预案、事故频道误扩权、四阶段关系状态、单一主要身体边界、两条政治路线的T4不同行动，并建立S02成本、C08投影、十包轮换、路线机、AP、结果与敌方收益表。

### 第二轮：表格齐全仍不等于可执行

剧情席确认三主角冲突、五组关系事业外放和路线人物行动已成立；机体与玩法席仍发现四类假闭合：S02十二种受损目标只列名未消费；C10路线机真实ID存在却被`ACTIVE_OR_STATIC`压平；U022儿童停止权与U023成年监护锁混合；最低航道T2开闸未付AP、T3拦炮后恐慌值未增加。

第二轮把十二个损伤目标连到选项、费用、支援、动作槽、移动上限、PV变体和S04 carry；路线机逐包恢复`participation/control/grid`；U022增加不可覆盖的本场停止请求；最低航道改为十五个具名动作。

### 第三轮：从T0重算，消灭最后的隐形状态

检查器改为按`PRE_MOVE -> MOVE -> POST_MOVE -> CANNON -> EXIT`从T0逐回合复算位置、信赖、恐慌、闸门与每机AP。T1全航道广播明确三船各加信赖；T2由舞台战舰另付1AP开闸；T3救援船被锁未中仍增加恐慌；T5全出口开放后自动炮无合法目标；T6三船全部合法离场。

资源证明由旧288组升级为`72合法输入 x 2路线 x 12个互斥损伤目标 = 1728`组，全部可达，最大`FIELD_AP=15/16`、`CHARACTER_AP=6/6`。U052/U076医疗加价改为无条件真实代价，不再被预算二号自动抹去；U023删除未定义舰体输入；U057旧表同步为T5无人溢流门光刃动作丧失。三路复审最终全部PASS。

- 真实开馆胜利没有翻成骗局；危机来自胜利接口开始把人与机器的未来模板化。
- 纪存不再只讨论存档或标签，而是读完自己的牺牲预案，拒绝被两位爱他的人提前写死，公开说出想活过开馆之后。
- 七海与白鸢分别承认对方能救回纪存的一部分，但不因此和解；单周目只发生一个主要身体边界，不锁终局恋爱。

- 歌翼三形态、舞台战舰展开、重剪舰原声选择、社勇王慢拆、光刃切门和多谱系机器把战斗动作转为生活/救援动作，保留机战快感。
