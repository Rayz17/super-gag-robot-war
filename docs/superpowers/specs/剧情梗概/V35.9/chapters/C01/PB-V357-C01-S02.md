## 2. 本话故事发动机

七海依据现行消防图切断东侧高压，正确消除了旧线复燃，却关闭图纸里没有的旧回风/消防共用层，令低位烟压陡升。纪存若强送整条总线，也可能把火场变成不可预测的G.A.G.通电试验。两人都没有完整答案。

跌跌的温度片、机器犬的烟流、唐胶的管壁回声、兜灯的低温示踪、七海的现行图、纪存的离线结构底图和城市消防的栓位/承重数据共同拼出实时公共救援图。七海撤销本人刚签的东侧高压锁并停权；纪存放开消防/撤离层共同写入，但不暴露完整移动脊柱。

故事快感来自不同尺度的专业机器共同完成一场火场救援，而不是用行政名词替代动作，也不是投票决定烧掉哪栋设施。

## 3. 单次游玩因果脊柱

1. 喷头只落下一滴黑水；二十九人距离街道几十米，却被门、烟和零压泵困住。
2. 七海第一次正式改变现场系统：切东侧高压、保留西侧维生。电弧停下，旧风阀落下，伤亡时钟缩至六分钟。
3. 玩家用三件物证查明现行图与离线图各缺一层；纪存不靠反灼或馆长提示跳过调查。
4. 众人共同写出公共消防/撤离图；冷却针车和切割标尺机沿轨道实体压住桥接口与泵杆。
5. 消防架桥机逐腿落地、铺出三段桥、水幕和冲洗动作；馆守Z只提供被动温感/低压继电。
6. 七海撤销本人命令，系统写权限灰掉；门、泵仍需工作人员、小机与城市消防完成机械旁路。
7. 四个撤离Token在R4全部到达楼外。七海问“三十二呢”，纪存取消自动清场，保留三名核心工作人员的出口和公共消防支援。
8. 两名城市消防接驳员在29人离楼后进入馆内侧接管泵站。次梁坠落；消防架桥机反折SEG3、左前腿过载承梁。勇拳运输架只发出被机外继电截断的自动防坠请求，本体不动。
9. 白函远程把救援改报为“封存对象主动迁移”，预量18米中庭落点；此后才允许E02原子提交。

## 4. 战斗与玩法合同

- 地图：固定`12x14`，前厅、装卸坪、B1入口三线同图。
- 人口：`A11 + B10 + C3 + D5 = 29`；C3照看组不可拆，D5沿用E01同一维修员。
- 回合：R1-R4按`小机 -> 工作人员 -> 消防支援 -> 工具机 -> 撤离自动移动 -> 环境 -> 本地守卫/回执`执行；缺少桥段、C3、门泵工序、烟值或人口门槛时，相关移动停住并在环境后失败。R5为29人离楼后的承梁检查点。
- 支援：R1按唯一合法顺序联合部署`SEG1 -> SEG2 -> SEG3`；R2在护人水幕与抢先冲洗之间作一次可预览选择，R3完成相反补偿，R4池用尽。两名接驳员入内后，消防端才为新承梁险情另发R5应急点，不允许跨回合囤点。
- 空间：跌跌R4退入泵站检修凹位并留馆；两名接驳员沿西门两条声明路径入内。消防架桥机四腿全程固定，R5只允许左前悬挂在原格内压缩/滑移。
- HUD：R1-R4持续显示四Token端点、C3完整、B1泵、烟值、工作人员AP、消防点池与工具意图；R5明确换为“反折SEG3、保住五人退路”，同时保留`29/29楼外`。
- 胜利：四Token出楼；三名核心人员和两名消防接驳员拥有可用退路；SEG3反折承梁；白函ADV结束。
- R1-R4失败：从SRPG设置重试，零持久化。
- R5失败：从R5本地检查点重试，29人保持隐藏在楼外，不重救、不提交故事状态。
- 唯一提交：白函远程结尾之后写入`C01E02_PHYSICAL_SNAPSHOT`。
