# V21主线大纲增强重构方案 v21.0

状态：候选主轴稿，等待用户审稿后再提升为工作正典。

## 0. 本稿要解决的问题

V20已经把“番剧结构、巡展开馆表、活化源点、残响版本层、代哥生态、主线参战可见度”放到一起，但仍有一个致命风险：它看起来像是在旧大纲上套了新名词。V21不再只问“每篇讲什么主题”，而是改问：

> 这一篇，谁在争夺万机馆的开馆权？谁抢走了机器人被看见、被命名、被使用、被封存或被爱的资格？玩家怎样用机体、展品、模型、G.A.G.机魂和人物关系把这个资格抢回来？

所以V21不是直接重写台本，也不是平均扩写48话。它先重构全剧主线发动机，再给后续逐话梗概、关卡、资产、台本提供统一锚点。

## 1. V21一句话主轴

万机馆不是一艘流亡基地，也不是一个收藏菜单。它是一座会开馆的展舰，带着被商品化、被封存、被误译、被优化、被遗忘的机魂，在各方争夺“开馆权”的战争里，决定哪些不完美的机器人文化记忆可以公开站到观众面前。

这里的“开馆”不是终局口号，而是贯穿全剧的行动方式：

- 在街区开馆：让模型和旧件获得公共托管资格。
- 在战场开馆：让撤退、失败、量产机和民用机也成为胜利条件。
- 在审查室开馆：让白名单不能只留下干净版本。
- 在残响层开馆：让初版、错版、商品版、封存版、索引版互相作证。
- 在最终开馆：决定G.A.G.机魂以后由谁定义、谁负责、谁能继续爱它。

## 2. 旧大纲到V21的关键变化

| 旧风险 | V21变化 | 结果 |

| 源点像钥匙收集 | 活化源点改成公共权能载体，例如命名权、撤退名单权、错版合体权、白名单例外权 | 源点不只是道具，能改变地图、机体条件、舆论和结局 |
| 万机馆像后台基地 | 万机馆作为棋盘格单位、展舰、临时开馆设施和最终变形体存在 | 战斗中能看见它、保护它、利用它，也会承担债务 |

| 机体数量和机器人动画爽点怕被塞进EX | 主线每篇有参战承载卡，EX只加厚度、隐藏机体和高难名场面 | 不打隐藏也要像机器人大战 |

| 情感线温吞 | 纪存、七海、白鸢形成“策展、封存、改写”的危险三角，其他成人线有卖相但不越界 | 关系不再只在幕间聊天，进入选择、支援、误会和分裂 |

| 分支没有痕迹 | 分支留下“开馆债”：UI灰显、展柜空位、支援台词、白名单灼痕、最终声部 | 玩家选择不会只藏在后台变量里 |

## 3. 开馆权战争的核心规则

### 3.1 开馆权不是一张许可证

开馆权包含五种权能：

- 命名权：谁能给机器人、展品、事件和失败命名。
- 展示权：哪些东西可以公开被看见，而不是被剪辑或封存。
- 使用权：机体能否参战，模型能否作为关系钥匙，残响能否成为支援。
- 解释权：错版、初版、商品版、封存版和索引版，谁有资格解释“什么才是真的”。
- 责任权：G.A.G.暴走、机魂债务、开馆后果，由谁承担。

每一篇至少争夺其中一种权能。这样剧情推进不再只是“到新地点见新阵营”，而是万机馆一步步从被清算的博物馆，变成能公开承担责任的文化方舟。

### 3.2 G.A.G.不是火种源照搬

G.A.G.可以借鉴“火种源”那种让机器获得生命的神话感，但本作定位更复杂：

- 它不是纯能量神器，而是机器人文化档案、梗、情感、误译、商品流通、封存制度共同积累出的机魂活化系统。
- 它不是单纯善或恶。它能让旧模型回应爱，也能让流行梗失控，让机体被错误期待驱动。
- G.A.G.事变不是“大家玩梗太多就灭世”那么轻。灾变来自机魂大规模显影后，被军方、平台、品牌资产秩序、索引算法和恐惧政治同时争夺，最终引发机甲暴走和社会分裂。
- G.A.G.核心仍保有活化能力，但每次强行使用都会产生“开馆债”：被谁看见、被谁误会、谁替它承担后果。

### 3.3 万机馆可以变形，但变形是剧情债

万机馆展舰不是万能战舰。它可以作为棋盘上的大型单位，随剧情解锁形态：

- 闭馆防卫态：早期保护展品、留言墙和观众。
- 展舰巡航态：流亡移动、外部锁泊、部署机体。
- 临时开馆态：在街区、战场或审查室展开展陈设施，改变胜利条件。
- 合规开馆态：获得代哥合法资源，但部分支援被白名单锁住。
- 清噪封存态：被索引或清算流程接管，玩家会失去部分自由。
- G.A.G.暴走态：绝境强行接管战场，Buff巨大，但留下剧情债。
- 万机殿形态：终局形态，不是无限大城市，而是展舰、展陈层、格纳库、残响接口和观众证词共同显影。

这样变形不会只是酷炫设定，而会和剧情、玩法、分支、关系债务连在一起。

## 4. V21 11篇主线结构

### V21A01 闭馆夺名篇，E01-E03

开局不再只是法务封馆。代哥执行系统先冻结“万机馆”这个名字，把它改登记为“待清算品牌资产仓”。闭馆路线仍然保留，但路线目的变成让玩家亲眼看到万机馆的厚度：大厅不是几件展品，而是能一眼看见超级系、真实系、勇者、变形、战争舰桥、民用机器人、玩具文化和封闭区入口的巨大展陈层。

馆守Z以18米级退役实机身份启动，但它不是万能主角机。它先以展品身份保护“馆名章、留言墙、今日状态牌”。七海不亲临现场，只以全息权限和执行流程出现。她嘴上公事公办，手指却在断电按钮上停住，给纪存留下第一条缝。

结尾不是“逃走了”，而是万机馆带着被冻结的名字流亡开馆。玩家从第一篇就知道：这场战争争的是命名权。

### V21A02 模型街临时开馆篇，E04-E07

模型街不再只是温情支线。它是万机馆第一次在外部开馆。代哥的限定流通层、平台倒卖算法、模型街社群、旧货柜黑匣子同时争夺“初版说明书”。模型和玩具不是变真机的廉价魔法，而是关系钥匙：它们证明某台真实机体曾经怎样被普通人爱过、改过、拼错过、保存过。

唐胶线保留嘴硬和现实感，但不再只是老师。他知道热爱会被标价，也知道模型街自己也会炒、会攀比、会羞耻。纪存不是教育大家，而是把“羞耻的旧件”和“昂贵限定件”放在同一场临时展里，让它们互相作证。

结尾的货柜认亲给主线机体链打开第一扇门：主线会看到十几米级真实机体的轮廓和锁泊条件，EX只提供隐藏涂装、额外货柜和高难挑战。

### V21A03 失败机试验场篇，E08-E11

这里不再只是“失败也有价值”的小题大做。军方采购、数据评审无人机、现实机器线和索引模板第一次同场。敌人不一定杀人，而是剪辑：它们抢成功样本、删除摔倒记录，把失败机包装成可采购的完美演示。

陆衡的痛点不是理性，而是他曾经相信“删掉失败上下文能保护项目”。纪存的魅力不来自犯错，而来自策展动作：他把失败白板、摔倒路线、维修手套、被删掉的停顿放进同一场公开测试，让“第10742次站立”成为证词型展品。

结尾方舟T的远程幽默参数异常轻触G.A.G.真相：最优成长路线里，机器人会站得更好，但不再记得自己为什么站起来。

### V21A04 雾岛同步灾害篇，E12-E16

雾岛不是单纯少年保护篇。它是“主体性开馆权”的第一次大爆炸。防卫圈的毕业仪式被同步系统、军方样本、代哥安全封存和索引模板共同利用，学生被推向“正确牺牲”的剧本。

白鸢正式登场。她不是单纯好人，也不是只会暧昧的女主。她的能力很迷人：她能把残酷场面改写得更漂亮、更幸福、更像玩家想要的结局。但这份温柔会夺走当事人说“不”的权利。

本篇的机战爽点是错拍启动、同步灾害、半暴走救场。儿童角色只承担童年、托付和主体性，不进入成人暧昧。纪存和白鸢的吸引来自危险的专业理解：一个会策展，一个会改写，他们都知道怎样把别人放进叙事里。

### V21A05 撤退战史直播篇，E17-E20

这一篇不再只是战争伦理。它把玩家熟悉的“红色更快、王牌追击、热血突破、歌声停火、量产机逆袭”全部放进同一场直播陷阱。敌人不是等玩家来打，而是故意放出红色路线，采样玩家和赤罡的追击欲望。

胜利条件从击破王牌改成让难民船、撤退名单、能源核心和量产小队尽可能活着离开。赤罡的成长不靠讲道理，而靠一次外放的反转：他已经能打穿天顶破口，却主动把最燃的镜头让给撤退。

结尾保留破口维修账。爽点不是被削弱，而是被记账：你燃过，就要承担被敌人复制、被同伴维修、被舆论误读的后果。

### V21A06 遗作拍卖与共同记忆战争篇，E21-E26

V21把作者遗迹和原典圣堂合并为一场更大的共同记忆战争。作者遗产方想卖掉或保护未完成稿，原典圣堂想冻结正确台词和合体仪式，平台想把争论做成流量，白鸢想给角色一个不再受伤的版本，槐则证明“正确台词”曾经真的救过人。

这不是反粉丝，也不是反原典。真正的冲突是：爱会保护，也会固定；改写会救人，也会替人闭嘴；原典会给人归属，也会让错版没有活路。

本篇主线爽点是错版合体。玩家不是随便喊错口号，而是在正确台词被锁、敌人按名场面预判、机体拒绝“完美合体”的情况下，用模型街的旧胶件、废案角色的空白展柜和槐的错版口令拼出一次原创胜利。

### V21A07 白名单开馆诱惑篇，E27-E32

清算都市不再只是反派城市。它先证明秩序确实有用：危险机魂被封住，普通观众被保护，盗版和恶意倒卖被压下去。七海在这里必须有主场。她成熟、迷人、危险，也清醒地知道代哥生态已经腐化，但她仍相信流程里还有能救人的缝。

代哥给万机馆一个很诱人的合法方案：只要接受白名单、删掉高风险展品、把错版和失败归入封存，万机馆可以正式开馆，甚至获得资源、维修、舆论和参战许可。

纪存和七海的关系要在这里真正升温：不是告白，而是权力、欲望和信任的危险靠近。她给他合法钥匙，也要他主动签字承担删除。白鸢在玻璃外看见这份默契，不是简单吃醋，而是意识到纪存可能会把她也变成“可以被妥善安置的例外”。

结尾三门战场不是选择谁喜欢谁，而是选择哪套保护机制先救纪存：合法门、分镜门、维修侧门。每条路线都留下可见疤痕。

### V21A08 残缺索引反攻篇，E33-E36

索引天使不再只是算法反派。它把玩家前面喜欢过的爽点全部学走：红色路线、合体口号、撤退燃点、白名单保护、分镜救场、失败站立。它生成一场“最像机器人动画、最符合玩家期待、最没有缺点”的战役。

这篇要打得难看又好看。玩家熟悉的名场面被敌人用得更标准，主角方反而必须靠残缺、错拍、失败记录、量产机脏活和不合规支援破局。万机馆被迫进入清噪封存态，玩家部署列表、支援台词、展柜状态出现可见污染。

G.A.G.暴走可以在绝境救场，但不是免费超级模式。它会让万机馆短时间接管战场、放大机魂、重写支援范围，也会欠下开馆债：被暴走救下的人，后面有权质问纪存是否又一次让“爱”替他们决定。

### V21A09 远星迟到回信篇，E37-E40

远星篇不再只是宇宙百科。它揭示旧世界分裂的真相：G.A.G.事变后，人类一部分选择封存，一部分选择商品化，一部分把机器人神话送向远星，希望未来有谁能回信。回信迟到了很多年，而且被误译了。

远星机器群不是纯救星。它们根据过期信号判断地球仍在求救，也可能判断人类已经失去保管机魂的资格。这里借鉴《时空之轮》的不是穿越，而是“迟到的信息改变现在”：玩家无法回到过去，但能让旧信号、当前开馆状态和未来来信重新对齐。

七海带来代哥内部封存档案，白鸢带来被改写过的信号副本，纪存必须承认自己曾经也想只留下最好看的版本。三人的关系从互相吸引进入互相伤害后的共同承担。

### V21A10 开馆方式内战篇，E41-E44

这不是传统队友审判，而是“怎样开馆”的内战。知道G.A.G.真相后，主角团内部不可能只吵两句。每个人都占据万机馆的一部分，提出自己的开馆方式：

- 七海线：公共信托开馆，合法、可持续，但要接受审计和部分封存。
- 白鸢线：创作者避难所开馆，保护角色不再被撕裂，但容易替人写结局。
- 唐胶线：模型街自治开馆，保留土味和旧件，但会再次面对价格和圈层。
- 陆衡线：现实机器安全开馆，让机器先能活下去，但可能压住神话感。
- 赤罡线：战场开馆，让战斗中活下来的人当场作证，但风险最大。
- 机魂线：机器自我开馆，不再由人定义，但可能走向G.A.G.失控。

万机馆在棋盘上分裂成多个展区状态，支援点数、泊位、展柜和观众路线都被拆开。玩家不是选一条恋爱路线覆盖一切，而是在关系、制度、热爱和责任之间决定开馆方式。

### V21A11 万机殿最终开馆篇，E45-E48

终局不是“打败一个大坏蛋然后开馆”。最终敌人可以是索引、代哥硬线、远星误译、G.A.G.债务和主角团分裂共同生成的“完美终局模板”：它给所有机器人一个最安全、最热血、最标准、最容易卖的结局。

玩家要打败的不是热血本身，而是“只有一种正确热血”。最终战要让主线参战机体、量产机、模型钥匙、废案角色、失败机、远星机、封存机魂、白名单例外、撤退名单全部出现。隐藏关和EX提供额外声部，但主线本身必须已经足够像机器人大战。

最终开馆根据债务、证词和关系不同变体：

- 公共信托开馆：最稳，但有审计和封存边界。
- 流亡巡展开馆：最自由，但长期被追责。
- 机魂自治开馆：最浪漫，也最危险。
- 万机殿开馆：把人、机器、模型、错版、失败和观众共同放进公开责任里，是主推真结局方向。

## 5. 后续写逐话梗概的强制口径

后续不应该直接把旧v01照48话扩写。每话先问六件事：

1. 本话争夺哪一种开馆权。
2. 敌方至少赢走什么，哪怕玩家通关。
3. 万机馆作为棋盘单位、开馆设施、展柜、泊位或终端发生什么变化。
4. G.A.G.机魂是好笑、有用、危险、债务还是真相阶段。
5. 本话主线能看到哪些机体或谱系，不靠EX补救主线机器人密度。
6. 本话留下哪一种可见债务：UI、地图、展柜、支援、关系、舆论或结局声部。

## 6. 与既有版本的关系

V21不丢弃旧版本好东西：

- v12.2前三章的可读感、闭馆、模型街、失败机样板继续保留，但改成夺名、临时开馆和数据剪辑战争。
- v15的爆破升级继续作为场面强度标准，但避免机械KPI。
- v16/v16.1的C04-C08高能段继续保留，并升级为主体性、撤退、共同记忆、白名单、索引反攻的中盘连续剧。
- v19.1的巡展开馆表和活化源点继续保留，但源点改为公共权能，不是钥匙。
- v19.2的代哥生态和七海改革线继续保留，七海不是恋爱脑，也不是单纯反派。
- V20-0到V20-2的残响版本层、主线参战可见度、参战承载卡继续保留，但V21把它们嵌入主线事件，而不是当标签。

## 7. 当前不做的事

- 不直接写完整台本。台本要等V21主轴确认后逐话拆。
- 不把EX当主线参战规模的补丁。EX只做额外厚度。
- 不把残响深潜写成查资料。它仍是探险、采集、发现、解锁和风险玩法。
- 不把开馆写成经营小游戏皮肤。开馆是万机馆的社会行动和战斗行动。
- 不把G.A.G.写成万能神。它有能力、有误译、有债务，也有被滥用的历史。

## 8. 下一步建议

如果本稿方向成立，下一步不是立刻写48话详细梗概，而是先做“V21前三篇逐话梗概样板”。样板要证明：

- 闭馆路线能体现万机馆厚度和夺名冲突。
- 模型街能同时做到温情、商品化冲突、机体链解锁和临时开馆。
- 失败机试验场能把现实机器线、数据剪辑、G.A.G.幽默异常和主线机体密度写成可玩的剧情。

这三个样板过关后，再按同一强度推进中盘和后半段，避免虎头蛇尾。
