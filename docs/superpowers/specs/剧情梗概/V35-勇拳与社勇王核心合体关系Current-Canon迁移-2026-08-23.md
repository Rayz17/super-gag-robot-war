# V35 勇拳与社勇王核心合体关系 Current Canon 迁移

> Date: 2026-08-23  
> Scope: `MECHA_BRAVE_FIST_PROTOTYPE`、`V353U024`、豪司与勇气株式会社包的物理连续性和美术接口  
> Authority: 用户明确纠正后的 Working migration

## 一、迁移原因

此前 Current 数据把勇拳写成“与社勇王同工程族、但物理上互不连续的试作机”，并要求 C03 另出现一台完整社勇王。这一口径导致美术把勇拳画成胸口空置的测试壳，也无法回答它与勇者王系 IP 的核心机／合体结构映射。

用户现已明确裁决：**勇拳就是社勇王的核心机器人；它本身是完整、可独立作战的有人机体，之后与外部组件合体成为社勇王。** 因此本迁移只纠正物理身份与美术关系，不改写 C01 已验收剧情动作，也不把完整社勇王提前到 C01。

## 二、当前统一关系

1. `MECHA_BRAVE_FIST_PROTOTYPE / 勇拳`是完整的有人核心机器人，不是空胸壳、可替换驾驶舱或等别人塞入的外装。
2. C01 时勇拳可独立完成公开测试、冲击储存与回送、地面战和空战援护；此时没有独立机魂，行动责任全部归豪司与勇气株式会社。
3. C01E04 后企业回收的是同一台核心机，不是退役废壳；其维修、数据与合体资格成为 C03 的连续输入。
4. C03 的`V353U024 / 社勇王`是同一台完整勇拳核心机与外部合体组件结合后的完整形态。`V353U024`记录完整合体后的生命周期；它与`MECHA_BRAVE_FIST_PROTOTYPE`是同一物理核心的两种部署层，不得重复计为两台独立机体。
5. 社勇王主体 AI 在 C03 完整合体时首次作为当前叙事中可持续、可拒绝豪司的伙伴参与战斗；这不倒写成 C01 勇拳已经有独立机魂，也不提前启用金章的独立人格时序。本迁移不擅自锁定该 AI 的安装位置、产生方式或激活时刻。
6. C03 仍是第一次完整社勇王合体、第一次社勇王主体 AI 与豪司并肩／拒绝／重新协调；C01 只展示核心机勇拳，不展示完整社勇王战斗形态。

## 三、美术与动作硬边界

- 勇拳必须先读成一台完整机器人：头、胸、躯干、四肢、驾驶与承力关系完整。
- 拳甲在储能、压缩、回送三个状态中保持同一只大拳的主体比例；收缩发生在拳后套筒、关节与储能环，不把拳缩成小内核。
- 胸口不得挖成空安装洞，也不得把勇拳缩成小内胆；外部组件必须围绕完整核心机形成合体，具体连接位置由后续概念板确认。
- 社勇王完整形态必须保留可追认的勇拳核心结构，同时由外部组件建立更大的勇者轮廓与工具能力。
- 精确变形步骤、外部组件数量、头冠和胸甲最终造型仍是美术 Candidate，须经用户概念板确认；本迁移不替用户定稿。

## 四、不变的 C01／C03 事实

- C01E01 豪司与勇拳公开测试；C01E02 不参战；C01E03 豪司越过企业撤离令参战；C01E04 援护后由企业回收。
- C01 的勇拳没有独立机魂，豪司承担越权与公司处分；不因本迁移自动入队。
- C03E03 完整合体、首锤、AI 拒绝第二锤、重新协调与衡令受创撤离不变。
- C03E04 三个月公共道路试用、企业产权和维护义务不变。
- 社勇王送修模型仍只是模型／关系锚，不放大成实机，也不参与战斗。

## 五、退役口径

以下表述自本迁移起降为 History，不再约束 Current 美术或 Demo：

- “勇拳和社勇王是三种不同实体中的两台不同机体”；
- “C03 社勇王不是勇拳升级或物理连续形态”；
- “不得把勇拳写成社勇王前身”这一不区分人格与物理核心的旧禁令；
- 把勇拳画成空胸测试壳、极小拳内核，或让 C03 用一台无关新机替换它。

仍有效的禁令是：模型不能变成实机、C01 不能提前出现完整社勇王、C01 勇拳不能提前拥有社勇王主体 AI、豪司不能提前正式入队。
