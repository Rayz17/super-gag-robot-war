## SOURCE C07E24《毕业照缺了一个人》

## 6. Draft Synopsis
### Function
C07E24是雾岛同步灾害的核心开场，也要把本章真正的故事名钉住：雾生不是被邪恶系统献祭，而是被很多真诚的爱写成了名场面。它不能一上来就宣布“同步制度有问题”，否则雾岛会变成脸谱化献祭岛。本话要先让玩家承认：防卫圈的学校、海墙、学生机队和同步塔确实救过城市，班主任潮也不是坏人。然后再从一张小小的毕业照里发现制度最痛的部分：它把人的恐惧、停顿和不想成为英雄的愿望，都排成正确位置。

### Story Flow
万机馆靠近雾岛时，远星字幕还残留C06的低效合唱误译。海面上，几台雾岛学生机沿防波线巡航，动作整齐得像开幕式，却在每一次转身时多停半拍。陆衡看出这不是技术失误，而是驾驶舱里的恐惧被同步系统平均掉了。方舟T低声说，这种平均在远星语里很接近“安全”，也很接近“没有人单独说话”。

七海这次不再只是全息窗口。她没有下到雾岛学校，而是坐在万机馆模型病院旁的临时复核位，封存箱还带着C06的水口粉擦痕。她调雾岛资料时，唐胶从旁边经过，想把那半截白色水口偷偷拿走，七海用笔帽压住它，说：“低风险，不入报告。别再塞我箱子。”这句很轻，却改变了纪存对她的听感：她仍然是审查者，但她开始知道哪些东西不该被系统化。白鸢看见这段，没画七海的脸，只画了她压住水口的手。

学校区域先是温和的。真昼带万机馆看毕业照墙，学生把第三警报当课表，班主任潮让他们先完成避难演练再回答问题。这里没有反派压迫感，只有过于熟练的安全。学生们说起恐惧时也像说日程：第三警报、同步检查、撤离编号、补课安排。玩家调查照片叠层时发现：每一届毕业照都有一个位置偏离中心，有的学生被贴在最边，有的直接空出来。雾生正在修相框，他把自己的照片贴偏一点，说中间太显眼，警报会先叫名字。

白鸢看不下去。她在终端上画出一个“没人缺席”的幸福构图：雾生站在中央，真昼在旁边笑，岛卫三号在背后以标准英雄角度护住海墙。画面很好看，甚至比现实更像机器人动画的漂亮主视觉。问题是分镜一生成，照片墙上的同步环就跟着亮，雾生座位被系统自动挪向中央，心墙零式医疗舱弹出“驾驶适性优先”的白色提示。白鸢那一瞬间的冲动不是坏，她只是太害怕空白；但玩家第一次看见，这种爱也会替别人决定站位。

纪存的选择不是训斥白鸢。他把四样东西并列：雾生贴偏的照片、班主任潮的训练表、旧届照片背面被擦过的批注、白鸢的幸福分镜。然后他请雾生自己看。雾生没有说大道理，只问：“如果我站中间，真昼是不是就不用被叫到？”这一句让白鸢沉默，也让七海远程弹出封存建议。七海的建议是合理的：幸福分镜已经影响现场系统，应该暂停。纪存拒绝删图，但把七海建议公开给雾生和班主任潮，让他们知道这不是万机馆单方面决定谁能被看见。

半封存机库打开作为本话PV场面。岛卫三号半跪在海墙轨道，十几米级机体背部插着学校旧标，胸口同步灯像一排还没点名的教室窗。旁边心墙零式的白色舱体从医疗玻璃廊滑出，雾岛学生机群在轨道边待机；更深处有一只幼灯核心封存柜，贴着儿童安全标，却发出和学生心跳相近的低亮光。万机馆终端提示：本章进入正式章内路由池。

路线池不是菜单文字，而是地图上同时亮起的五处压力。操场同步节点正在读取学生机群；白色机库里心墙零式等待驾驶员确认；海墙双驾坞传来两套输入互相抢方向的噪声；旧教室的分镜格把空位补成笑脸；地下封存柜的灯槽低亮。它们看似是五条玩法线，实际上是五种把雾生推到中央的方法：制度、家长式命令、亲密共感、作者温柔、无限支援。玩家从这里就知道，本章不是沿一条走廊解谜，而是在几种“看似正确的保护”里选择先面对哪一种。

结尾，第三警报不是突然袭击，而是像日常铃声一样响起。整面毕业照墙同时翻面，背后不是遗言，而是本届学生的撤离编号和同步顺位。学生自动排队，老师自动下令，学生机自动启动，心墙零式询问驾驶员是否进入同步。雾生把偏位照片塞进口袋。白鸢想伸手替他把照片抚平，最终停住；七海的封存建议没有消失，而是留在纪存终端右上角。索引在后台记录：幸福构图与风险封存都可以让驾驶员回到正确位置。下一步，玩家必须选择先处理哪条路线：同步节点、拒绝出击、双驾共感、幸福分镜或灯槽风险。

## SOURCE C07E25《第三警报不是演习》

## 6. Draft Synopsis
### Function
C07E25是雾岛第一场正式战。它要让玩家体验“同步制度不是坏，但它会把恐惧压成命令”。战斗必须比概念更先到：海墙真的要塌，学生真的在撤，敌群真的在逼近。玩家不能用一句“尊重主体性”解决三目标，只能在保护学生、破坏节点和守海墙之间承受损失。

### Story Flow
第三警报响起时没有惊叫。学生把课桌推到墙边，真昼把补课编号贴到避难牌上，班主任潮按点名册下令。万机馆来不及展开完整展舰阵列，只能把岗位支援投到学校操场和海墙之间。小查错话库从C04远程弹出，把第三警报念成第三节课，几个学生下意识去拿课本，下一秒电缆供能塔从地下升起，像巨大神经插到学生机背后。

第一阶段，玩家护送学生撤离。雾岛学生机实战态作为半可控友军上场，等级不高，但防线纪律极强。同步槽越高，它们越能自动援护，越像漂亮的机器人编队；同步槽越高，心墙裂纹支援屏也会把驾驶舱恐惧显示成白色裂纹。星火医疗车远端胸灯只能照亮一条撤离线，不能救全场。这里玩家第一次感到C06得到的支援强了，但不万能。

第二阶段，同步污染敌群出现。它们不是怪物，而是一批被伪共同语言改写的旧胜利姿势：标准口令、标准踏步、标准守城角度。它们攻击的不是学生，而是学生机队的停顿。只要某台学生机犹豫，污染群就会替它补上动作。短期看这是保护，长期看就是把“我怕”删掉。白鸢忍不住用分镜格救一台机，救得很有效，却在那台机的支援窗口上留下灰字：已改写。

纪存的主角动作发生在中盘。他本可以让白鸢继续改写安全格、让七海暂停阵列、让学生机高同步防守，从而拿更漂亮的三目标胜利。可那样所有学生都会以系统允许的恐惧形状过关。纪存选择公开低分路线：保撤离优先，节点破坏第二，海墙只守最低线。他对班主任潮说这会让城市账面很难看。班主任潮没有立刻反驳，只把点名册压在终端上，说难看可以，别让孩子下次看到自己被写成资源。

七海在本话不再是微小缝隙。她明确提出暂停同步阵列，后果是海墙防卫力下降，城市财损和伤亡风险都可能上升。纪存承认她是对的，但要求她把风险承担人写清楚：不是“系统建议暂停”，是七海和万机馆共同要求暂停。七海沉默很短一瞬，然后把名字写上去。白鸢看见这条署名，分镜笔在纪存和七海之间停了一下，最后没有把他们画在一起。

## SOURCE C07E26《拒绝出击也是命令》

## 6. Draft Synopsis
### Function
C07E26是心墙路线的关键话。它要修正一个常见机器人动画爽点：大人对少年喊“不要逃”，观众为出击燃起来，但少年有时不是怯懦，而是被所有出口堵死。本话不反热血，而是让玩家亲手证明：先呼吸、先拒绝、先确认，也可以保护人。

### Story Flow
警报后半，心墙零式白色舱门打开。雾生站在舱前，没有进去。父令广播塔从学校旧指挥室升起，不断播放“驾驶员请进入位置”“你的恐惧会危及全岛”“同步稳定后会安全”。这些话都不邪恶，甚至很像正确的安全提示。拘束器执行机沿轨道滑向心墙零式，准备把舱门固定到出击角度，冷却针车・心墙型则瞄准雾生后颈的同步贴片。

如果玩家按常规出击，心墙零式会获得高防御与强援护，短期能把海墙缺口补上；但同步槽会直升，雾生偏位照片会从道具栏灰掉，C07E30正确牺牲锁增强。正式路线要求玩家反过来打：拆拘束器，关掉父令广播塔，调低冷却针输出，同时让心墙零式保持不出机库的拒绝出击态。它不前进，却展开白色心墙，保护撤离通道和机库门口的学生机。

雾生的台词不能写成神圣宣言。他只是说：“我不是不想保护大家。我是想知道，我能不能先怕一下。”真昼在后面接了一句：“你怕一下，我帮你看海墙。”这个小小的生活互助，比任何热血口号都更扎。白鸢听见后，分镜本自动生成雾生坐进驾驶舱、流泪出击的漂亮分镜。纪存伸手按住分镜本边缘，动作不重，但白鸢能感觉到他在拦她。她低声问：“那你会不会也把我留在门外？”纪存没有用道理堵她，只说：“如果你说先别让我画，我也得听。”

七海的动作是本话制度高点。延迟出击在雾岛协议里等同战术违抗，她可以让纪存背锅；她没有。她把“拒绝出击态”改成待审有效命令，条件是现场有替代防线、二次确认、损伤上限和责任人。她的声音很稳，但终端显示她的权限层被扣到低位。纪存公开读出这条改判，不把它写成系统延迟。白鸢看见七海不是抢走纪存，而是在把自己放进更危险的位置，关系误会开始变复杂。

中盘，父令广播塔开始模仿班主任潮的声音，催雾生“不要让大家等你”。班主任潮冲进通讯，第一次承认自己有时也用正确的话逼过学生。他没有道歉长篇，只说：“这句不用听我的，听现场。”这让拘束器执行机短暂停滞，玩家可以拆掉主锁。唐胶吐槽父令广播塔比家长群还会催作业，兜灯立刻补一句催作业也要确认是不是本人发的，笑点没有破坏压力，反而让命令权问题落地。

高潮时，心墙零式仍未出击。海墙外敌群逼近，心墙在机库门前扩成透明白光，把撤离学生、未出击驾驶员和维修轨道都包进去。玩家第一次以“不动”赢下一段战斗。通关后，系统不写未出击失败，而写“拒绝出击态有效”。雾生没有成为英雄，也没有被保护成奖杯；他只是把偏位照片重新塞进口袋，说等下如果我自己按按钮，那是下一次的事。

战后，索引记录了一条危险样本：拒绝也能被制度化。它开始生成“更温柔的拒绝模板”，后续可能把拒绝权也清噪成控制。七海降权，纪存得到一个新指挥原则：有些命令不是让人动，而是允许他暂时不动。C07E30若读取本路线，雾生错拍启动时可以先停半拍；若没完成，本章拒绝权会在终局被同步塔伪造成“你已经拒绝过了，现在该服从”。

## SOURCE C07E28《把他写幸福的人》

## 6. Draft Synopsis
### Function
C07E28是白鸢关系线的真正推进。它不是“白鸢温柔但危险”的重复说明，而要让玩家亲手走进她的诱惑：如果你能把一个注定痛苦的少年画进无痛幸福里，你真的忍得住不画吗？本话同时要给纪存/白鸢/七海三角关系加热，但落点仍然是雾生主体性，不让主角情感抢走少年的故事。

### Story Flow
夜间旧教室没有警报声，反而安静得像放学后。桌椅被幸福分镜塔切成一格一格，黑板上出现分镜编号，窗外岛卫三号影子被切成连续画格。白鸢站在黑板前，手里拿着粉笔，像终于回到自己的主场。她画出一个没有第三警报、没有海墙破口、雾生站在中央但不用出击的分镜。这个画面一出现，教室外的同步灯真的暗下来，雾生呼吸也平稳了。

玩家一开始会发现幸福格很强。单位站进去可以免伤，白鸢支援变得可靠，雾生恐惧槽下降。可是每用一次幸福格，无痛同步镜像就会长出一台。镜像会替雾生回答问题，替他笑，替他说我已经好了。它们不像怪物，甚至很温柔。花同化花瓣噪点从窗缝飘进来，模仿学生口头禅，说大家一起就不会害怕。这种温柔比攻击更可怕。

纪存让玩家收集普通愿望：面包券、窗台植物、补课留言、真昼给雾生留的铅笔、旧届照片背面一句话。最扎的是旧届照片背注：“如果我不在，别替我笑。”这句话不讲牺牲大义，只是拒绝被别人补成漂亮结局。白鸢看到这句时，粉笔停在黑板上。她不是被说服，而是被刺到，因为她明白自己也常常替别人笑。

关系线在这里爆出来。纪存没有审判白鸢，而是把白鸢的分镜、雾生贴偏的照片、旧届照片背注和七海高危备注放进同一个并置视图。白鸢第一反应不是被说服，而是被刺痛：纪存准确理解了她，可这种准确也像把她的内心放进展柜，连她想藏起来的控制欲都被照亮。她伸手改掉终端标题，把“白鸢支援”改成“未确认善意”。这不是可爱小脾气，而是她关系模式第一次显影：她越被看穿，越想改掉对方给她的位置。

白鸢问纪存：“你是不是也要封存我？”这句话不是撒娇，也不是装深沉，是她真的怕自己被归入危险工具。纪存没有说“我相信你”，那太便宜。他把七海的高危备注投出来：白鸢支援有效，但可能固定当事人。他又把自己的备注并列：未确认善意，可被质问，可撤回。白鸢看着七海的备注，第一次没有骂冷酷，因为她意识到这条备注是在保护她不要成为加害者。

七海不在场，却像一把冷刃插在关系里。她没有通过全息说教，只留下一条流程意见：若白鸢继续强改写，纪存必须具名承担共犯责任。纪存没有隐藏，白鸢看见了。她笑了一下，靠近终端，手指压在纪存刚刚写下的“可撤回”上，问：“那你要签吗？”空气很暧昧，也很危险，因为她问的不是一份文件，而是纪存愿不愿意和她一起承担一条不漂亮的救人路线。纪存说：“如果你还要我签漂亮结局，我不签。如果你要我签你可以停下，我签。”这句不是金句，而是关系条件。

玩法中盘，幸福分镜塔开始强制把空白格改成幸福格。玩家必须让单位站上空白格承受不确定伤害，保住雾生不被自动推向中央。星火医疗胸灯和心墙裂纹屏可以支援，但不能消除风险。若C07E27不看区域完成，白鸢会多一个选项：承认有些格子她不看；若没有完成，她会更倾向强改写。

高潮时，无痛同步镜像包围雾生，镜像一起说“这样就不用怕了”。雾生没有喊大话，只说：“我想明天补课，不是想被写成明天。”白鸢终于擦掉中央幸福构图，保留边缘空白格。她没有完全放手，分镜本仍在发抖，但她把粉笔交给雾生，让他自己画一条不漂亮的出路。通关后，白鸢强改写债不是消失，而是变成可克制支援条件。

战后，索引带走无痛分镜样本。它学会最可怕的一点：不需要强迫人痛苦，只要给人一个没有误会、没有恐惧、没有失败的幸福格，就能让很多人自愿进去。花同化噪点也记下“大家一起就不会害怕”的错误亲近。C07E30同步塔会把幸福分镜、同步口令和灯槽恐惧压在一起，逼白鸢选择强改写、克制改写或纯保护。

第三阶段，花同化残响终局态和无痛同步镜像合流。它们说大家一起就不会害怕，幸福分镜塔也给出不痛结局。白鸢的选择在这里发生：强改写能保单位、能降伤害，却会降低雾生主体性；克制改写需要前置普通愿望；纯保护则最难但关系债最少。白鸢如果完成C07E28，会把粉笔交给雾生；如果没有，她会忍不住画出漂亮英雄格，然后战后必须面对灰字。

第四阶段，灯槽和双驾路线回收。低槽路线完成时，G.A.G.半暴走救援壳可以在七海/兜灯共同停机条件下救一次；它从上一话烧黑的支援栏裂缝里弹出，挡住同步塔反噬后立刻退回残响，不能连用，也不能替岛卫三号完成启动。高槽则遗灯审判态进入Boss相，强行把全场停下。双驾不看区域完成时，潮墙巨兵用不齐的左右输入撑住海墙；若没有完成，方向键抢夺镜像会让支援互相打架。七海在最危险时没有封掉岛卫三号，而是把雾生主体性风险登记为允许出击条件。她公开承认制度可以允许不齐声，这不是小缝隙，是她对自己职业信仰的一次改写。

最终说得窗口由具体物件打开：偏位照片证明雾生不是缺席；补课编号证明他还有明天；小票根证明愿望不是开火许可；旧届背注证明不要替别人笑；不看区域证明亲密也有边界；七海签名证明风险不是没人承担；白鸢未确认备注证明温柔可以被质问。窗口里还出现一条新提示：不要替他证明勇敢。雾生终于进入岛卫三号，但没有喊完整口号。他漏了一个字，慢了半拍，甚至第一次动作判定不完美。同步塔立刻替他补完，他操纵岛卫三号第一拳打断的不是Boss本体，而是替他喊完口令的塔声。

岛卫三号错拍启动形态站起。它没有最强火力，命中也不稳定，但每一次动作都保留雾生的停顿。终局一击不是“正确合体”，而是半拍错位的防卫动作：心墙挡住拘束，潮墙撑住海墙，星火医疗胸灯照撤离线，白鸢画出可撤回支援，七海低权限旁证，馆守Z远程撑住万机馆外侧，半暴走救援机挡一次反噬后退回残响。同步塔核心碎裂，花同化没有被消灭，只留下错误亲近的花瓣噪点。

战后，雾岛保住，但制度没有被简单否定。班主任潮承认成年人要面对历代名单，雾生也承认以后可能仍会选择出击，但要自己按下。这里追加一个低声收束，不再继续打大仗：万机馆临时开馆，展出的不是英雄剪辑，而是雾生那段漏字、停顿、错拍和没说完的普通愿望。防卫圈官方想删掉停顿，因为它会削弱制度权威；白鸢下意识想把剪辑修得漂亮一点；纪存坚持保留那一小段难看的空白。七海远程提醒，这类未经授权的主体性记录以后都会成为清算对象。她没有威胁，只是把代价说得太准确。

G.A.G.在后台把这段记录标成“笑点失败”。唐胶盯着这个分类半天，说这次它终于知道不好笑了。陆衡把同一段信号标为“外源误译”：同步系统只是接收器，更大的文化/信号网络把“我害怕”误读成了“请让我加入合唱”。万机馆支援栏仍有三格发黑，兜灯没有让它自动复原，只把“低槽救援壳不可再触发”写进值班面板。这个反转把C07真正交出去：雾岛不是同步系统一个坏零件，而是整个世界正在学习一种危险语言；而万机馆真正整舰级的暴走，还没有发生。

岛卫三号开启后续支援/入队条件，不直接全入队；心墙零式、潮墙巨兵、遗灯核心进入路线支援候选；白鸢强改写债、七海主体性风险登记、纪存机魂目标化记忆都进入后续C11/C12。C08接战争撤退线：有人会问，万机馆凭什么把少年恐惧公开成展项；赤罡要从热血追击转向撤退伦理。
