## 6. Draft Synopsis
### Function
C05E16是星火双篇的开门回，也是变形生命和救援车队正式登场。它要先把谱系关系讲清：星火车队不是五色战队，也不是单纯货柜领袖加四个配件；它们是五辆有载具人格的退役救援车，可以进入本心作业形态，未来可合体成星火巨神。火种旧货柜残响是文化锚点，重涂三车是同模生命候选，彩队巨神和勇者支援都留在后续谱系，不在本话混成一团。

### Story Flow
万机馆循旧货柜锚件来到废弃航天特摄乐园。外墙褪色，旧屏断续播放巡游片段：五辆救援车穿过纸板城市，旁白总卡在“最后一辆确认后出发”。乐园不是小场景，入口一眼能看见外环车道、变形展厅、五色摄影棚、巨大化闸门、地下合体井和旧广播塔。万机馆在远处低空停泊，像一艘带伤母舰来到一座死去的机器人儿童乐园。

护送战启动。五车不能一口气冲门，医疗车慢，吊车会为了塌桥停下，警备车会反向去挡扫描门，消防车总想救旁边的纸板城市。胜利条件不是最快进门，而是全部进内门，并至少公开三辆车的维修痕迹。公开维修痕迹会降低效率，却能证明它们不是配件。若玩家贪速，把医疗车拆成救援包，短期战力变高，但星火誓约破裂。

三台重涂车从备用巡游道启动。红焰抢领袖频道，动作更快更帅，像所有热门红色高速重涂的集合；蓝巡用音爆干扰扫描门，偏防御但总被误认成普通版；黑夜镜像换位，像暗黑镜像和阵营反转玩具线的残响。它们不是假货杂兵，陆衡比对磨损后确认它们有真实受力记录，只是记忆被SKU覆盖得更严重。唐胶说重涂不是罪，罪是你把它写成“买不起原色的替代品”。

燃点在最后一辆慢车。封存闸八回合后关闭，医疗车因为舱门卡住落后。玩家若愿意低效率绕行、让吊车撑桥、消防车灭纸板城市的假火、警备车挡扫描门，旧货柜车会停在内门前不走。它没有喊领袖口号，只开着牵引灯等医疗车。五辆车灯依次亮起，旧屏卡了几十年的旁白终于播完：“最后一辆确认，出发。”这一刻不是同声口号，而是每辆车知道自己为什么回应。

章末，星火五车进入内门，重涂三车根据识别结果成为驻馆支援候选或继续游离。医疗车维修单成为泪点证物，火种旧货柜残响只在旧屏里闪出波形，不解释成火种源。远星字幕把“等最后一辆”误译成“库存同步未完成”，方舟T标注低置信度。C05E17进入变形展厅，扫描形态诱惑开始。

## SOURCE C05E17《扫描形态不能替你活》

## 6. Draft Synopsis
### Function
C05E17要回答“为什么玩具/模型零件和深潜道具能影响巨大机体”。答案不能像魔法：模型锚件提供文化/结构记忆，残响道具提供版本层信息，实机接口决定能不能安装。本话通过扫描形态展厅把这套逻辑变成玩法。玩家不是给车换皮，而是在诱人的升级方案里判断什么外壳会改变它们的用途。

### Story Flow
内门后是变形展厅，像旧玩具开发资料库和发布会样品间混合。墙面上挂满扫描形态：飞行消防车、兽爪吊车、武装医疗车、宇航警备车、王冠货柜车。每个外壳旁边都有漂亮数值和预购风格说明。形态推荐塔用温柔声音告诉玩家：升级并非剥夺，而是让它们更完整。

白鸢先被武装医疗车海报吸引。那张图确实好看，医疗车背后展开双炮，红白涂装在逆光里像主角机。她甚至小声说这个镜头可以留。纪存没有嘲她虚荣，只让医疗车自己回答一个展签问题：你变成这个形态，是为了保护谁？医疗车沉默很久，最后拒绝背炮，保留担架舱。它的战斗数值下降，但救援范围扩大，且C06合体稳定性上升。

五车逐一选择本心作业形态。消防车拒绝飞翼，改成消防臂甲和耐热水炮；吊车放弃兽爪，保留承力框和救援臂；医疗车保担架舱；警备车不换成宇航战车，而是强化腿部稳定器和警戒灯；旧货柜不戴王冠，只修牵引接口和脊柱框。每个选择都不够帅，但都让玩家明白：变形生命不是为了变成更会打的人，而是让自己的用途被看见。

玩法上，玩家可以短暂装备高战力外壳清掉敌人。飞翼让消防车跨越塌桥，但水炮散热过载；兽爪让吊车攻击强，但吊装精度下降；武装医疗车能打远程，却占掉担架舱；王冠货柜能提高全队士气，却会让四车判定为附属。若玩家全选高战力，通关更轻松，但星火誓约裂纹扩大，并强化C06目录翼商品包。若玩家选择本心形态，战斗更难，却保住终局必要合体的理由。

散件小车和五兽王冠残响在本话登场。散件小车不是星火车队的一部分，它们像被遗忘的配件包，到处滚动寻找可以挂上的接口。五兽王冠残响则只出现一次Cut-in：五道兽形轮廓从展厅天花板掠过，提醒玩家兽形合体是另一条隐藏谱系，不是吊车长兽爪就能冒充。唐胶趁机吐槽：有些配件不是不能买，是买了以后你得先问它到底帮谁。

七海的制度动作比上一话更微妙。她指出本心作业形态不符合原规格说明，按流程属于未经授权改装。纪存要求她把规格说明改成“可解释例外”：如果机体能说明用途、接口可追责、风险可撤回，就允许临时测试。七海没有立刻同意，但她最终把这条写入待审测试条件。她不是给纪存放水，而是第一次让制度承认“例外”本身也可以被设计得正当。

结尾，五车完成本心作业形态，展厅里的高战力外壳没有消失，反而被索引记录成“可脱离主体的升级包”。白鸢把撕下的一半武装医疗车海报交给纪存，像承认诱惑也要被保存。纪存把它标为“诱惑证词”，不是废案。五色摄影棚的站位灯在远处亮起，红、蓝、黄、白、黑五条轨道升起。C05E18进入五色不是五个货号。

通关结算还要明确给玩家看见代价：选本心形态的车辆在普通攻击、移动范围或武器格上不如外壳形态好用，但支援台词、救援范围、维修口可达性和终局合体稳定性全部上升。若玩家保留某个高战力外壳，它不会立刻判坏，只会在目录翼表里变成一个“还没有被问清理由的漂亮模块”。这让选择不是道德填空，而是会影响C06战斗手感的长期负债。

## SOURCE C05E18《五色不是五个货号》

## 6. Draft Synopsis
### Function
C05E18负责把战队/特摄文化放入星火章，但不能把它并入星火车队。五色摄影棚是另一套谱系：五色队员、五色兽机和彩队巨神代表群众喊名、队形、巨大化和舞台感。星火车队在本话是旁观/支援共鸣，不变成五色战队。

### Story Flow
五色摄影棚像一座保存不完整的特摄拍摄现场。红、蓝、黄、白、黑五条站位轨从地面升起，纸板城市背后是兽机剖面轨和巨大化闸门。旧报幕词说明每种颜色不是价格档位，而是任务：红色确认路线，蓝色水域救援，黄色重物搬运，白色医疗撤离，黑色夜间警戒。导播热度屏却把它们改成五个价格档位，红色最高，黑色限定，白色稀有，黄色普通。

赤罡一踩上红色轨，低机位镜头、冲刺Buff和热血BGM全开。他很爽，也知道自己很爽。问题是如果他抢跑，其他颜色会被判为附属，观众频道会只记得红色。纪存没有训他，而是把任务说明放到他面前：红色先看路，不是先抢镜头。赤罡不服，直到半身巨大化兽人影从纸板城市后方升起，一只手臂横跨数格，把黄色替补站位卡压在脚下。

半身巨大化兽人影像预算不足的单元怪，只巨大化上半身，下半身还是皮套拖在轨道上。它不是纯敌人，而是观众声浪、导播热度、未发售兽机和巨大化闸门残响混成的东西。它越在镜头中心越大，离开镜头又露出拉链和补线。玩家要保护五色站位卡、观众频道和彩队剖面轨，同时控制热度/安全双槽。

彩队巨神和五色兽机残影在本话只做一次可见Cut-in。玩家守住五条轨后，五只兽机轮廓从剖面轨上掠过，彩队巨神轮廓在纸板城市后方站起一秒。它不入队，不可操作，但不是“影子装饰”：它用一次站位修正把半身巨大化兽人影从观众频道推回摄影棚轨道，让玩家明确这是未来隐藏谱系。

结尾，五色棚恢复短暂秩序。导播热度屏没有被摧毁，只被锁进可审计状态；索引带走观众声浪样本，并把巨大化机制与C05前两话的同模/外壳样本连起来。地下合体井传来巨大的机械锁声，社勇王金章远程亮起，豪司已经在通讯里把“合体许可”四个字憋到脸红。C05E19进入勇气审批驳回豪华合体。

## SOURCE C05E19《勇气审批驳回豪华合体》

## 6. Draft Synopsis
### Function
C05E19是星火前半章的合体高潮。它必须很燃，也必须把“合体不是越多越好”的槽点打出来。玩家要看到多机合体、勇者许可、金章AI、训练壳、电磁残响和玩具过度堆配件，但结论不能是反燃，而是让燃点从“全挂更帅”转成“每一件都有理由”。

### Story Flow
地下合体井打开时，乐园像终于想起自己曾经是机器人动画的游乐场。五辆星火车被推上承力轨，轨道下方亮起五机节拍。天顶吊下飞翼、钻头、四联导弹背包、金色王冠、透明火焰特效、尖刺披风、超长剑和展示支架。每个配件都让人想买，每个预览都很帅。

问题也很明显。旧货柜不是标准胸口，医疗车不能挂成后背炮台，吊车和警备车更像承力框和腿部稳定器。若按商品海报来，星火巨神会好看很多；若按救援用途来，它会像拼错了，却能站更久。索引投放七机、八机、十五机豪华合体方案，全挂路线第一回合火力爆炸，第二回合热崩，第三回合掉件变地图灾害。唐胶看着尖刺披风和透明件，直接说这不是强化，是售后报复。

社勇王中量援护接入。豪司快把口号喊出口，金章AI已经准备盖章，下一秒巨剑卡在“承力许可未通过”的红框里。豪司憋得很痛苦，但这次他没硬喊。陆衡把承力图投出来，小勇机训练壳钻到巨背包下面，用训练灯标出被遮挡的维修口。这个小勇机不是正式勇者，只是未来C08绑定的训练壳伏笔，但它第一次证明“勇气许可”也要看维修口。

玩法是合体调试。玩家要为星火五车选择位置和配件。旧货柜可以当胸口更帅，也可以退到脊柱牵引位更稳；消防车可以挂飞翼，也可以保持水炮散热；医疗车可以背炮，也可以保担架舱；吊车可以戴兽爪，也可以做承力框；警备车可以戴王冠腿甲，也可以做腿部稳定器。每个选择都有短期爽度、终局稳定和维修可达性。

本话可以直接使用“我来组成头部”作为名台词锚点，但要有新意。星火合体到头部时，系统提示头部位置空缺，所有配件都争头。豪司终于忍不住喊出这句老梗，下一秒金章AI驳回：头部不是最威风的位置，是最后一个看见所有人的位置。最后由警备车提供稳定器，旧货柜牵引脊柱，头部灯不是一个人组成，而是五车确认“最后一辆已到”后共同点亮。玩家会心一笑，同时理解这不是廉价复读。

白鸢在这里也有推进。她本能想画一个标准英雄构图：旧货柜胸口、医疗背炮、吊车巨爪、王冠头。可她看见承力图和C05E17那张撕掉的武装医疗车海报，最终承认不漂亮也可能更对。纪存没有夸她懂事，只把漂亮构图和正确构图都保存，一张叫诱惑，一张叫合体条件。

高潮是星火巨神雏形站起。它不完美，甚至有点不对称。旧货柜退到脊柱，医疗车胸灯像心口，吊车和警备车撑住腿部，消防臂甲在侧面。它没有挥出巨剑，只用双臂挡住落下的豪华配件群，保护合体井里的小车和观众频道。观众留言弹出：“像我小时候拼错了，但这次好像能动。”燃点来自它真的能动，而不是它最像商品图。

战后，索引带走完全版欲望样本。若玩家保留太多豪华配件，C06目录翼会更强；若坚持必要合体，星火巨神稳定性高但输出弱。七海把全挂风险记录给生产层，纪存公开接受风险，她第一次不是封合体，而是为必要合体留下审计路径。巨大化摄影棚灯亮起，半身兽人影的声浪样本和豪华合体欲望在后台融合。C06进入万机同心与拆掉完全版。

## 6.5 制作拆分
> 本节为存量改造层，只拆分制作执行信息；上一节可读剧情不重写，剧情因果以原文为准。

#### A. ADV剧情段
- 地点/背景资产：玩家在承力稳定、维修可达性、输出、主体同意之间分配部件。全挂路线爽但留下C06目录翼强化；必要合体更难但星火誓约稳。
- 出场与冲突：C05E19是星火前半章的合体高潮。它必须很燃，也必须把“合体不是越多越好”的槽点打出来。玩家要看到多机合体、勇者许可、金章AI、训练壳、电磁残响和玩具过度堆配件，但结论不能是反燃，而是让燃点从“全挂更帅”转成“每一件都有理由”。
- 角色动作：陆衡回到核心工程位，小勇机训练壳帮他标出被背包遮住的维修口；白鸢承认不漂亮也可能更对；豪司憋住热血口号，等金章许可通过才喊。
- 转入触发：警报、敌方动作、地图开启或关键物件变化后进入B/C段；下一段玩法以 `合体调试 + 配件选择 + 过载风险战 + 五机节拍同步。` 为准。

#### D. 战斗内剧情演出段
- 触发条件：按C段回合、HP阈值、位置、支援封锁、路线变量或关键物件状态触发。
