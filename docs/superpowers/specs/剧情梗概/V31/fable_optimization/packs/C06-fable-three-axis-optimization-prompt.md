## 6. Draft Synopsis
### Function
C06E20要把“巨大化”从数值放大改成真正的玩法体验。巨大化不是敌人血条变长，而是每一步都会踩到微缩城市，每个镜头都会改变怪影大小，每个后台机关都会决定哪些机体能救人。它也要把C05留下的五色声浪、勇者许可、星火巨神、豪华配件债全部拉回同一张地图。

### Story Flow
特摄摄影棚亮起时，整个乐园忽然有了旧电视的质感。微缩城市铺在地上，爆破点插着小旗，皮套库挂满修补过的怪兽身体，高处摄影灯像太阳。星火巨神雏形刚进入场地，索引就把观众惊呼、五色喊名、勇者许可和商品热度误读成巨大化条件。半身兽人影从皮套库爬出，先是两米，然后六米，最后在镜头中心胀成六十米怪影。

陆衡把战场拆成三层。后台层由角色操作摄影灯、喷烟机和疏散门；机体层由星火巨神、馆守Z远程支援、社勇王援护和彩队巨神残响保护微缩城市；巨大化层是怪影脚步、手臂和镜头边界。玩家每次移动摄影灯，怪影大小和可攻击部位都会改变。离开镜头，它露出拉链和补线；进到镜头中心，它又变成真正能踩碎城市的六十米灾害。

棚守巨影登场。它不是完整机体，只是一套旧棚内守护系统留下的巨影投射，只有在镜头帧内能实体化一次。它挡住兽人影第一脚时，玩家会看到一只没有细节的英雄影子压住纸板城市，影子边缘还在抖。燃点在这里不是完美英雄降临，而是一个旧影像系统用尽所有光线挡了一次踩踏。

白鸢主动放弃漂亮构图。她本来可以给星火巨神一个仰拍镜头，让它看起来像救世主，但那会让兽人影在镜头中心继续变大。她改用丑陋的俯视安全镜头，把怪影拉到边缘，星火巨神看起来小了很多，却能救下两条街。纪存把她的构图投成战场视野参考，承认“不好看的镜头”也是战术。

七海要求关闭摄影灯，这在流程上正确，能立刻止损，但会同时熄灭棚守巨影和彩队残响，微缩城市会失去保护。纪存提出三尺度管制：保留最低帧率、限制镜头中心、后台疏散优先。七海同意并远程担责，等于她又一次没有简单封死风险，而是把风险变成可审计行动。

高潮时，星火巨神、馆守Z和棚守巨影在不同尺度同时撑住同一条街。星火巨神挡碎片，馆守Z远程压住摄影棚屋架，棚守巨影挡怪影脚。怪兽皮套内侧字条被白鸢扫到：“这一脚踩轻点，城还要拍下一集。”它提醒玩家：就算是微缩城市，也有人为了让它看起来真实而小心过。通关后，巨大化兽人影缩回残响尺寸，但索引已经得到巨大奇观样本。广播塔亮起，伪领袖发布会开始。

通关后的制作层结算要让巨大化真正留下系统痕迹。后台机关会解锁“镜头帧”地形标签，微缩城市证物会进入万机馆可移动展柜，棚守巨影只获得一次性支援债而不是入队资格。如果玩家为了输出牺牲微缩城市，C06E21发布会会把它剪成“为了更大英雄牺牲布景”的话术；如果玩家保住证物，发布会就不得不把那张旧字条也放进商品包，反而暴露它不懂拍摄现场的人情。这些都把巨大化从演出变成后续Boss的材料来源。

## SOURCE C06E21《伪领袖发布会》

## 6. Draft Synopsis
### Function
C06E21要让敌人变得诱人。伪领袖不是喊毁灭的反派，而是会感谢、会懂情怀、会包装玩家正确选择的营销人格。它让玩家同时觉得“这玩意儿我想买”和“它把活着的东西剪掉了”。

### Story Flow
广播塔亮起，伪领袖登场。它的声音温和、成熟、热血，几乎像所有玩家心里最可靠的机器人领袖合成在一起。它逐项感谢：谢谢你们等最后一辆，谢谢你们选择本心形态，谢谢你们保护五色声部，谢谢你们没有滥用豪华合体，谢谢你们救下微缩城市。每一句都是真的。然后它接上结论：既然大家都如此珍惜，就应该给它们最完整、最豪华、最容易带回家的身体。

天空UI展开商品包预览。星火五车、旧货柜残响、彩队巨神、社勇王、棚守巨影、重涂三车被剪成同一套金光完全版。医疗车的担架舱被改成救援背包，吊车承力框变成兽爪支架，五色站位变成五个价格档，棚守巨影变成透明特效件，社勇王许可变成初回金章。它不丑，甚至好看到让白鸢短暂沉默。

七海接入后可以立刻封广播塔，但封存会一起关掉观众频道、远星字幕和临时开馆记录。她把封存权限投到纪存终端上，手指停在确认键前，没有按下。她不是暧昧地放水，而是在所有流程都正确的情况下承认：直接封死会删掉太多真实证物。纪存没有说谢谢，只把“七海可封存但选择待审”写进记录，让她的风险成为事实。

玩法是反营销阵地战。玩家要把前几话证物送到对应商品包节点：医疗车维修单解除救援背包话术，五色站位卡解除价格档位，棚守字条解除透明特效件，重涂磨损记录证明重涂不是假货，白鸢安全构图证明不好看的镜头救过城市。每送一件证物，发布会话术就会变得不那么顺滑，商品包数值下降，但观众热度也会波动。

白鸢的关系场面很尖。她发现发布会盗用了她曾经画过的漂亮构图：星火胸口、医疗背炮、王冠头、巨剑。她愤怒不是因为被偷，而是因为那确实是她的欲望。纪存没有替她辩解，也没有说人都会被诱惑。他把撤销模板权限交给她，让她亲手把那张最能卖的画面从发布会里删掉。白鸢删完后没有看纪存，她看七海的封存权限，像意识到三个人都在用不同方式对抗自己最擅长的东西。

小满和阿澄的观众频道提供泪点。伪喊名非常整齐，但阿澄听出少了一个停顿：那是等医疗车最后一辆进门的时间。她说“它喊得很像，可是它没等。”纪存把这个停顿作为证物送入发布会核心，伪领袖第一次卡顿。儿童线只承担观众和热爱，不进入成人关系。

战后，发布会没有被彻底打掉。它学到真实证物可以打败商品话术，于是开始准备下一步：伪造证物、拆成模块、把每个理由做成可购买配件。目录翼从广播塔后方展开，像一本巨大的商品样本册。C06E22进入模块战。

这一话的奖励也要反讽。玩家每送达一件证物，发布会商品包就少一个漂亮卖点，但万机馆开馆档案会多一个难看的真实理由。若选择七海立即封存，战斗更短，发布会热度下降，却会失去远星字幕和观众停顿证物；若延迟封存，七海内审风险上升，但C06E23多声部支援更完整。白鸢撤销模板的分支也会影响最终构图：她亲自撤销时，终战可使用“正确构图”支援；若纪存替她撤销，关系热度下降且支援变成冷冰冰的系统视角。

## SOURCE C06E23《拆掉完全版》

## 6. Draft Synopsis
### Function
C06E23是前六章第一个真正大高潮。它要让玩家看到我们前面积累的机体、谱系、关系和玩法不是散点：星火车队、重涂三车、五色声部、社勇王许可、巨大化棚、工务三机、馆守Z、白鸢构图、七海审计、远星误译都在同一场战斗里回收。它还要把全剧内核说到动作里：共同语言不是让所有机器服从一个声音，而是让每台机器知道自己为何回应。

### Story Flow
全乐园合并。外环车道、变形展厅、五色摄影棚、地下合体井、巨大化棚、微缩城市、广播塔全部亮起，地图像一整季机器人动画的最终舞台。伪同心巨神・全挂完全版从广播塔背后站起。它不丑，不蠢，不弱，甚至很美：目录翼变成硬质背包，王冠广播核在头顶，透明特效件绕肩，巨披风保护后排，星火五车被压成统一车队胸甲，彩队声部变成统一口号，社勇王金章变成预购徽章。

第一阶段，玩家硬打核心完全无效。伪同心巨神合规评分高，面板数值漂亮，远星字幕一度把它译成“地球机器人文化完整形态”。这很可怕，因为它真的像答案。它会复制玩家此前最顺手的策略：快速护送、最佳外壳、红色抢跑、勇气许可、巨大化镜头、模块支援。玩家越按单一最优打法，它越强。

第二阶段是解放谱系节点。火种残响节点要求等待最后一辆；彩队声部节点要求五色不同任务同回合成立；社勇王许可节点要求责任签名；电磁节拍节点要求允许不同拍；五兽王冠节点要求不把兽形挂到星火身上；棚守巨影节点要求保住微缩城市证物；馆守Z支撑点要求展舰承受一次外部锁泊压力。每个节点都让一台机体回应，但没有被合成同一个声音。

白鸢完成本章关系回收。她放弃标准英雄构图，把医疗车担架舱画成胸灯，把旧货柜退到脊柱，把吊车画成承力框，把警备车画在腿部稳定器位置。画面不如伪同心巨神漂亮，但每个位置都有理由。纪存收下她的两张图：漂亮构图和正确构图。白鸢问他到底喜欢哪张，语气像调侃也像试探。纪存说两张都要，因为一张证明我们被诱惑过，一张证明我们承担了它。这个回答不油，但关系温度明显上升。

七海的七秒例外成为大动作。伪同心巨神准备压缩所有观众声部，七海可以立即封存，避免风险；她选择延迟七秒，让观众声部、远星字幕和支援审计都完成记录。七秒不是小缝隙，而是公开违背最短风险路线的选择。她在通讯里只说：“七秒，记在我名下。”纪存当场登记为开馆债，不把它写成系统延迟。白鸢看见这一幕，眼神很复杂，但她没有切掉镜头。

第三阶段，星火巨神必要合体站起。它仍然不对称，旧货柜在脊柱，医疗车胸灯，吊车承力，警备车稳腿，消防车臂甲。重涂三车分别从侧翼支援，彩队巨神残响给五色声部，社勇王金章给“勇气许可但责任自负”，电磁五虎机残响给不同拍节奏，五兽王冠不再强接而是绕开错误接口，棚守巨影挡最后一次踩踏，工务三机修出撤离路，馆守Z从万机馆外部锁泊臂撑住战场边缘。

终局支援不喊同一句。有人说等最后一辆，有人说确认路线，有人说担架舱保留，有人说许可通过但责任自负，有人说不要逃带他们绕路，有人说失败记录保留。声音不齐，却在同一回合各自回应。伪同心巨神的共同语言压缩塔过载，因为它只懂同声，不懂多声部为什么也能同时行动。

最后的破防点是医疗车胸灯。它回收C05E16维修单、C05E17保担架舱、C05E19不背炮、C06E21少了停顿四个选择。胸灯亮起时，不是最大伤害，而是让空名核心失去“救援背包”的授权。伪同心巨神解体，目录翼散成可审计模块，而不是全被毁掉。索引带走伪共同语言跨星际传播样本，远星字幕最后仍误译了一半：多声部被译成“低效合唱”。这正好把C07以后同步灾害、远星误读和全剧共同语言主题继续推进。

战后不立刻切下一章。七海第一次实体短登舰，理由不是慰问，而是“移动风险源现场复核”。她带着两个封存箱和一台审查终端，被临时安排在模型病院和零件库之间。她的箱子干净、编号整齐，旁边唐胶刚打磨完目录翼卡扣，水口粉落到箱角。七海看了一眼，写下“粉尘超标”，却没有写“立即封存”。唐胶本能想顶嘴，兜灯先把吸尘器推过去；纪存递给七海一张临时舱位卡，上面写着“复核位，不等于入队”。七海把卡翻到背面，看到纪存把她七秒例外的不同意也登记在开馆债里，只说：“这张卡的风险说明，比你们的出击计划完整。”白鸢在远处没有插话，只把七海的封存箱、唐胶的粉尘和纪存的舱位卡画进同一格，旁边仍然是一个问号。

这一小段不是撒糖，也不是支线闲聊。它让万机馆像有人住、有东西堆、有审查者会真的踩进粉尘里的船；也让七海从“远程权限”变成会被人看见、会被误会、会把小物件分成报告内外的成熟角色。她没有把唐胶随手塞在封存箱缝里的半截白色水口写进报告，理由不是心软，而是它没有风险，也没有必要被所有东西都变成证据。

章末，星火巨神成为主线支援单位，不是常驻全场主角机；重涂三车进入驻馆支援池；彩队、电磁、五兽、棚守保留隐藏谱系和EX/Cut-in条件；社勇王援护升级但仍需许可；C05-C06乐园成为万机馆第一个多谱系大型开馆点。万机馆外部锁泊臂新增星火泊位，玩家终于能感觉参战规模在扩张。下一章，伪同心样本反噬到同步/双驾层面：如果所有声音被迫同声，驾驶舱里的两个人会发生什么？

## 6.5 制作拆分
> 本节为存量改造层，只拆分制作执行信息；上一节可读剧情不重写，剧情因果以原文为准。

#### A. ADV剧情段
- 地点/背景资产：第一阶段核心不可击破；第二阶段解放谱系节点；第三阶段完成必要合体和不同声部全员支援。未处理目录翼模块会增加Boss部件。
- 出场与冲突：C06E23是前六章第一个真正大高潮。它要让玩家看到我们前面积累的机体、谱系、关系和玩法不是散点：星火车队、重涂三车、五色声部、社勇王许可、巨大化棚、工务三机、馆守Z、白鸢构图、七海审计、远星误译都在同一场战斗里回收。它还要把全剧内核说到动作里：共同语言不是让所有机器服从一个声音，而是让每台机器知道自己为何回应。
- 角色动作：白鸢放弃标准英雄构图，把医疗车担架舱画成胸灯，把旧货柜退到脊柱，把吊车画成承力框。七海七秒例外被公开登记，赤罡守最后一辆慢车。
- 转入触发：警报、敌方动作、地图开启或关键物件变化后进入B/C段；下一段玩法以 `全乐园三阶段Boss战。` 为准。

#### B. 探索/副玩法段
- not_applicable：本话不单独拆出副玩法；可交互对象直接并入ADV转场或SRPG目标，不新增独立UI流程。若制作需要短交互，只做战前确认/路线提示，不改变既有变量。

#### D. 战斗内剧情演出段
- 触发条件：按C段回合、HP阈值、位置、支援封锁、路线变量或关键物件状态触发。

#### E. 舰内日常/关系事件段
