# C07 Codex合并计划 - 雾岛同步与双驾灾害

## 总体判断

Fable 对 C07 的诊断有效。它没有只挑台词，而是指出了这一章更根本的问题：C07 的路线池、变量和系统债务很成熟，但人物声部和机体身体性不够稳定，导致“同步灾害”容易读成一组好规则，而不是少年、老师、成人主角团和机体一起被压进同一套错误保护语言里的灾害。

合并时不推翻 C07 的核心结构。保留五路线池和 E30 汇合 Boss，但要把每条路线都补一个身体场面、一个人物回声、一个机体/PV锚点，并修复真昼、班主任潮、豪司、幼灯核心、白鸢灰字、七海位置这些断线。

## 强制合并

1. **C07E24 路线池五压力改为五个现场小事故**
   - 不让纪存或叙述直接总结“五种推到中央的方法”。
   - 玩家在探索中撞见：学生机手臂被同步节点摆回标准角度、双驾坞噪声震落旧标牌、旧教室分镜格把空椅补成笑脸等。
   - 让玩家自己拼出“这些压力都指向雾生”，路线池才像发现，不像讲解。

2. **C07E24 学生群像去同声化**
   - 学生不能全用“恐惧日程化”的同一种语气。
   - 加三个声部：把撤离编号当成绩的学生、问外来者警报响几声的学生、真昼“不接题”的个人句。
   - 雾生“站中间的话，下次警报会先叫我”保留。

3. **C07E25 纪存低分路线视觉化**
   - 纪存当着班主任潮把三目标优先级拖到全岛可见频道。
   - 城市评分实时下掉，掉分声在每个学生机驾驶舱里响起。
   - 这让“选择低分但救人”成为现场牺牲，不是价值观宣言。

4. **C07E25 万机馆主力机纯体力参战**
   - 不能让雾岛章中段只有本地单位和敌方装置。
   - 至少安排一台万机馆主力机在海墙缺口不开火、用背或肩顶住缺口。
   - 用“顶住”证明万机馆是参战队伍，不只是远程监督。

5. **C07E26 雾生舱外共同承重**
   - 拒绝出击不能只靠规则赢。
   - 高潮加流弹越过心墙，心墙零式必须瞬间外扩，雾生在舱外按住舱门传感器，替机体撑住扩展。
   - 这是他第一次用自己的身体和机体共同承重，为 E30 自己按下按钮铺身体记忆。

6. **C07E27 满同步失败示范**
   - 不看区域协议不能像伦理会议结论。
   - 先让强制满同步带来一次甜头，同时双方看到一帧不该看的画面：纪存看到七海内审室的门，七海看到0号碎片。
   - 潮墙巨兵当场僵直挨怪兽骨机一撞，之后不看区域才像救命方案。

7. **C07E27 白鸢嫉妒对象改为“删除权限”**
   - 白鸢深夜查同步日志，发现不该看的那段被覆盖，覆盖签名是七海。
   - 她嫉妒的不是普通亲密，而是七海拥有“为纪存删除/遮住”的权限。
   - 这比单纯吃醋更贴合三角关系和七海职业魅力。

8. **C07E28 无痛镜像终态变成宣传涂装版岛卫三号**
   - 这一话机体投射最弱，必须补 PV 锚。
   - 无痛同步镜像最终形态不是抽象塔，而是官方宣传涂装版岛卫三号：干净、标准、永远英雄角度。
   - 它与带旧撞痕的真机同框，白鸢认出“漂亮的那台，是我会画的那种”。

9. **C07E29 小票根回收 E24 毕业照空位**
   - 幼灯核心不能突然从抽象无限力变成泪点。
   - 兜灯查安全阀时发现小票根背面印着某届毕业照编号，对应 E24 直接空出来的位置。
   - 让幼灯核心成为“那个空位里的孩子留下的灯”，同时给 E30 说得窗口加弹药。

10. **C07E30 漏字口令具体化**
    - 终局不能只说“漏了一个字”。
    - 口令示例：“岛卫三号，同步——确认——出……”雾生停住，同步塔抢着补“击”。
    - 岛卫三号第一拳打在那个“击”字上，物理打断替喊口令。

11. **C07E30 真昼和班主任潮进入说得窗口**
    - 真昼举起补课编号，与 E25 她贴广播塔形成动作回环。
    - 班主任潮用点名册对抗同步塔：“它念顺位，我念名字。”
    - 修复本章两条最大配角断线，让 E30 不只靠主角团说得。

## 可选合并

1. **C07E24 七海临时复核位生活化**
   - 唐胶走开后，纪存把七海临时复核位的椅子推正，被白鸢画进速写。
   - 这是轻关系钩子，不必写长。

2. **C07E25 唐胶远程认领小查错话库梗**
   - 小查错话库弹“第三节课”时，唐胶远程吐槽一句。
   - 修掉梗点无主，也让唐胶/兜灯不在 E25 完全消失。

3. **C07E26 拘束器执行机“温柔固定”细节**
   - 它把舱门扶到出击角度的动作像帮学生系安全带。
   - 让“温柔控制”更可怕。

4. **C07E27 怪兽骨机旧灾难痕迹**
   - 班主任潮或老维修工认出骨架里嵌着沉没救援艇龙骨。
   - 给怪兽骨机低频呼吸音，做成记忆点。

5. **C07E29 兜灯成为停机确认人的小戏**
   - 她检查安全阀时不许唐胶说话，唐胶真的憋住。
   - 事后唐胶说“你刚才像馆长”，让兜灯成长有一点温度。

6. **C07E30 岛卫三号错拍视觉签名**
   - 双眼点亮永远差半拍，左眼先亮。
   - 这能变成 PV 和周边识别点。

## 禁止合并

1. 不把雾岛章写成“系统变量试验场”；每话必须有机体身体场面。
2. 不让少年线被成人三角戏吞掉；雾生、真昼、班主任潮必须在终局有自己的动作。
3. 不让七海的例外变成暧昧便利道具；她遮住记录、低风险不报告、登记风险都要有制度代价。
4. 不让白鸢只吃醋；她的嫉妒必须与“谁拥有改写/删除/保存纪存的权力”有关。
5. 不给 G.A.G.半暴走救援壳补战果；它只能挡一次反噬并退场，否则会破坏 C07 的债务纪律。
6. 不让远星误译和索引取样每话都用同一个尾句格式；至少部分挪到战斗中段或 UI 异常里。

## 合并后预期收益

- C07 会从“路线池很聪明”升级为“每条路线都有身体代价、机体记忆和人物回声”的机器人动画章。
- 雾生的错拍启动会真正成为章级名场面，而不是一个漂亮主题句。
- 七海/白鸢/纪存三角关系会更有张力：七海是能遮住危险记录的人，白鸢是能画出漂亮危险的人，纪存必须学会让两个人都能被按停。
- C08 对万机馆“凭什么公开少年恐惧”的追责会更有重量，因为 C07 不再是抽象实验，而是有人、有老师、有小票根、有漏字口令的现场。
