# C03 Fable建议的Codex合并计划

来源：`C03-fable-output.md`

## 总体判断

Fable 对 C03 的诊断命中核心：本章概念和结构不错，但太像“合规程序剧”，机战可操作单位和人物情绪都被协议、署名、变量压扁了。它提出的“测试监理”“七海实体到场”“白稿王剪辑复读”“反类型必杀演出”属于真正有新增价值的建议，应作为后续修稿优先项。

C03 不建议推倒重写。灰模零号、三模式强启、白稿王听证和“未确认不等于替它完成”的主题成立。要做的是把它从规则寓言升级成一组有机体、有对手、有关系碰撞的机器人动画章节。

## 强制合并项

1. `C03E08`：补“封条无人机群试图给白鸢本人贴访客封条”的小型护卫战，让规则战首次产生针对活人的实体威胁。
2. `C03E08`：纪存对白鸢的台词改成人话和现场辩解，不再每句像责任条款。
3. `C03E08`：加入白鸢抓到纪存“策展人本能”的关灯场面，建立纪存/白鸢的镜像冲突。
4. `C03E08`：旧拳王维修盒残件至少展开一次，替署名墙或灰模挡封条，把 C02 机体资产接进接力修件母题。
5. `C03E09`：夜潜过程中加入结构复写兽复制夜潜艇推进姿态、舱内进硅胶水倒计时的实体危机，让“三目标不可全拿”先发生在身体层面。
6. `C03E09`：补舱内具体对话，尤其唐胶认工艺痕、陆衡压深度、白鸢导航时的生活化语言。
7. `C03E09`：导航页改为返航口塌方时白鸢被迫交出，避免信任来得太庄重太快。
8. `C03E09`：版本海“五版本伸手”定格具体化，分别表现儿童安全版、军工版、灰模本体的差异。
9. `C03E10`：军工试验机群增加远程“测试监理”画外音，让本章获得有脸、有声音、可被玩家记恨的对手。
10. `C03E10`：明确我方既有单位在护航战中的棋盘分工，至少包括旧拳王残件、星火/馆内支援、唐胶兜灯工程支援中的两到三项。
11. `C03E10`：完整化“必杀技输入框→稳定槽碎裂→Pose垮成跪撑→难看拖行救人”的反类型演出。
12. `C03E10`：七海改判台词改成先程序性口误再承担，例如“依据条款……不对，没有条款。依据我。”
13. `C03E10`：白鸢画支撑线前加纪存本能挡笔、白鸢瞪回、纪存收手递终端的半拍冲突。
14. `C03E11`：白稿王话术改为索引剪辑复读三话内人物原话，含纪存自己的话，让诱惑来源更阴冷。
15. `C03E11`：入队按钮在我方一台机体被击坠的瞬间弹到最大，诱惑踩在玩家最疼时。
16. `C03E11`：七海实体到场听证，和白鸢在纪存签销毁责任时同时按住同一页两角。
17. `C03E11`：白稿王中段完美复现灰模三模式，但每一种都缺失“不完美”，让玩家在机制层面识别它是假的。
18. 全章：削减纪存、七海、白鸢的金句密度，用口误、改口、疲惫、现场短句替代责任条款式发言。

## 可选合并项

1. `C03E08`：把误扶事件挪前作为冷开场，审账屏改成事后复盘。收益较高，但需要确认现稿节奏是否能承接。
2. `C03E08`：递防静电套细节去重，保留一次即可。
3. `C03E09`：陆衡补半句“我以前给人做过这种承力件。做完之后它去了哪，没人告诉我。”为 C04 工务城线埋情绪债。
4. `C03E10`：唐胶反向把兜灯拽出封条落点，平衡 C02 以来兜灯单向照看唐胶的关系动作。
5. `C03E11`：白鸢把泡皱的导航页要回去，但留下压痕条，强化“暂驻监督”的私物关系。
6. `C03E11`：误会线、B1泊位、岑砚残响三债三选二回收，不必把所有债都硬塞进结尾。

## 暂不采纳或需谨慎项

1. 不把七海提前改成全章多次到场。C03E11 第一次实体出席更有冲击力，前面仍以远程和权限痕迹保持压力。
2. 不把旧拳王残件写成正式复活参战。它在 C03 的作用应是“老机体替未出生机体挡一次”，不是抢灰模主线。
3. 不给测试监理做过多角色戏。此人只需要声音、编号、冷静报读即可，否则会抢走白稿王和灰模的章Boss位置。
4. 不把白鸢/七海同按销毁页写成和解。它应是同时阻止纪存独自承担的狗血关系画面，不是两人互相理解的温情场。

## 连续性债务

1. 小满/阿澄在 `C03E08` 出现后需要在后续至少有一次观察或离场回收，不能像安全观察格一样消失。
2. `C03E08` 的白鸢误会线要在 `C03E11` 有正面落点，否则“问号加深”只是重复。
3. `C03E10` 需要回收 B1泊位 ping 或至少让其震一次，否则此前标注自断。
4. `C03E11` 裁纸机应威胁到岑砚残响边界，哪怕只亮半秒，才能兑现 `signature_wall_integrity`。
5. 七海在 `C03E10` 被锁内审后，`C03E11` 权限必须受限：她可以被传唤到场，但不应像正常状态一样自由翻条款。
6. 模型街信任作为公开见证变量，C03 至少需要一个模型街见证人或街区远程证词露面。

## 写回本地时的注意

- 优先先修 `C03E10/E11`，它们承担本章机战高光和关系爆点。
- `C03E08/E09` 以补实体威胁、舱内对话、关系动作和旧机体接力为主，不要把信息量继续堆成规则说明。
- 七海实体到场要作为本章一次大动作写，不要再用“40秒/额度/署名”这种小动作替代。
- 白稿王的索引剪辑复读要严控：必须来自章内已说过的话，避免凭空变成万能AI解释器。
- 合并时同步更新制作拆分中的战斗单位、战斗内触发、关系状态、章节债务和后续 C04 工务城入口。
