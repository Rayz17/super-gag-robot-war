# C01 Fable建议的Codex合并计划

来源：`C01-fable-output.md`

## 总体判断

Fable 对 C01 的判断可采纳度较高。它没有试图改 canon、改名单或重写章节，而是准确抓住了三个系统性问题：

- 四话高潮动作都落在“签/责任/复核”上，读起来会像同一种规则戏。
- 规则敌人偏多，缺少能被玩家记住的身体化敌方场面。
- 白鸢、方舟T、豪司后续、冷却针车、E02分支落点等连续性种子不够稳。

这批建议适合以“局部增强补丁”合并，不需要推翻 C01 原稿。

## 强制合并项

1. `C01E01`：将闭馆路线巡礼改成带故障的巡检，夺名症状早于广播半拍出现；保留万机馆厚度展示，但降低一次性专名堆叠。
2. `C01E01`：馆守Z巨掌落下前加入旧展演小动作，强化“老超级系身体记忆”。
3. `C01E02`：加入一次“半次滑拳 + 兜灯中途硬停机”，兑现飞拳爽点，同时不破坏克制主题。
4. `C01E03`：加入 0号开启臂残压物理破门未遂，让本话不再只有纸面规则和审批道具。
5. `C01E03`：豪司声部降术语，改成“行政黑话用出热血感”；弱化责任词根连续轰炸。
6. `C01E03`：B1中型泊位待认领原名短亮，补下一台友军机商业钩子。
7. `C01E04`：黑展柜残压复刻 E01 巨掌防线构图，但掌下生成黑框，形成镜像反转。
8. `C01E04`：馆守Z起航收口，孩子留言贴到重型架护栏，胸牌低热回闪。
9. `C01E04`：补豪司下落一行、冷却针车尾随一帧，缝合连续性。

## 可选合并项

1. `C01E01`：纪存找回阿澄数出的“少了的留言”，看一眼再递还，不评价。
2. `C01E02`：终端误标纪存/七海“风险共签”，七海伸手想撤销但停住。
3. `C01E02`：从维修箱视角补一帧孩子贴纸与十八米掌纹同框。
4. `C01E03`：阿澄帮豪司数封锁框，豪司叫他“小同事”，只给被认真对待的一秒，不让孩子背责任。
5. `C01E04`：陆衡计算漏掉馆守Z自行动作，被迫改数，形成第一次工程和解。
6. `C01E04`：外部普通人目击万机馆起航剪影。

## 暂不采纳或需谨慎项

1. 白鸢在 C01 正式出场不宜提前。可在无人认领名单、抄送对象、废稿缩略图里埋一个“白鸢式”种子，但不让她压过七海第一章的远程压力。
2. 方舟T在 C01 也不宜直接说话。可在 B1工程频道或陆衡终端里出现一个“异步通信槽位/未命名舰载翻译模块”暗位，等后续 C07/C08 再正式确认。
3. Fable 建议的“七海伸手想撤销”如果做成全息动作，会轻微提前亲密感；可改成“复核界面停留在撤销按钮上未按下”，保留暧昧但不让七海显得过早心软。
