# Fable三维优化建议 - C01 闭馆夺名与展舰起航

来源：Notion 页面 `Fable优化 C01 闭馆夺名与展舰起航`，Fable 5，2026-07-08。

## 总体判断

本章最大的优点是"命名-责任-审计"这条系统戏是真的原创且贯通的：夺名不是设定说明而是现场后果（订单冻结、门锁误判、导航绕路），巨掌防线、右臂成桥、金章通道、破船起航四个大画面全部长在规则上，E02的"桥还是拳"是全章最好的可玩两难。

最大的问题是**四话的高潮动词全是"签字"**。E01签服役、E02签自限、E03签矩阵、E04签复核，单话看每次都成立，连读会疲劳，且导致全员台词向"条款腔"塌缩：七海、纪存、兜灯、陆衡、甚至豪司，都在说"责任/证据/承力/追责"的变体。第二个结构性缺口是**敌方没有身体和脸**：贴片机、标尺机、封锁框、火锁模块清一色是沉默规则机，直到E04第4回合黑展柜残压才出现第一个"有戏剧存在感的敌人"，来得太晚、戏份太薄。第三，用户点名的白鸢、方舟T在全章零出场零提及，需要决定是补种子还是明确后置。

最该补强的方向：给E03一个物理敌人时刻；把黑展柜残压在E04提前预震并与E01巨掌形成镜像刺痛；在四话里至少插入两个与责任无关的人味小场面，让"怪船"的可爱先于账本成立。

## 逐话建议

### C01E01《今日闭馆后馆名被冻结》

**剧情设计**

- 问题：开场前三段是纯展区巡礼（导览墙 -> 环廊 -> 愿望墙 -> 模型街），冲突迟到，读者在第一波贴片机入场前要吞下约四十个专有名词。作为章头这是最贵的几分钟。
- 具体补强：把巡礼压成"一次带故障的巡检"，纪存点名到第三处时就有一个原名闪烁失败（比如跌跌屏幕的原名读不出来），让夺名的症状比七海的广播早半拍到场，展区名词随症状分批出现而不是一次铺满。
- 合并建议：**强烈建议合并**（只调顺序和密度，不动任何设定）。

**台词设计**

- 最该改的对白类型：纪存的宣言腔。"我不会把你的名字藏起来，也不会把馆里的名字藏起来"是全话唯一一句"写出来的金句"，和他全话低声短句的人设打架。
- 示范方向：改成动作里带话，他一边把清单投上大屏一边说："名字都在这了。你的也在。"七海那句"那你的名字也留下"就能接得更冷更狠。另外小满的"跌、跌跌跌那个！"和唐胶的错别字吐槽是全话最像人话的两句，保住，别被润色统一掉。
- 合并建议：**强烈建议合并**（仅纪存一句）；小满/唐胶台词**不建议改动**。

**人物关系**

- 本话应推进：纪存x七海（实名对峙已成立），缺的是纪存x孩子们的一个非职责瞬间。
- 具体动作：纪存找回那张"少了的留言"（阿澄开场数出来的那张）时，可以让他先看一眼内容再递还，不评价。这个半秒的私人好奇为后面"策展人舍不得丢东西"的弧线埋第一颗种子，也让阿澄的数数技能当场兑现而非悬空。
- 合并建议：**可选合并**。

**机体/IP/爽点**

- 缺口：巨掌防线的燃点成立，但巨掌本身缺一个"旧超级系的身体记忆"镜头。它现在是一堵会动的墙，还不是一台老机器人。
- 补强：掌心压下前，让指关节按几十年前的展演程序先做了一个多余的旧动作（比如摊掌亮相半秒），再落下。观众会瞬间懂它"演过很多年"。PV价值极高，成本一行。
- 合并建议：**强烈建议合并**。

### C01E02《馆守Z手臂成为地图》

**剧情设计**

- 问题：本话骨架是全章最强，但货币太多（过热、证据完整度、切线进度、承力单、硬停机、贴片净化），可读层里规则解说挤压了场面呼吸；另外"轨道滑拳"作为最爽的招，标准路线下可能全程不放，飞拳幻想没有一次兑现。
- 具体补强：加一次**剧本内的半次滑拳**，比如第5回合敌方逼到留言墙死角时，纪存批准一次短程滑拳但由兜灯在半途硬停机，拳停在标尺机面前十公分。爽点放了一半、停机权当场立威、"克制"的主题反而更响。
- 合并建议：**强烈建议合并**。

**台词设计**

- 最该改的：七海的"证据有时也会留下刀"。她全话人设是不修辞的条款人，这句太像编剧替她说。改为她把三条切线和上一话日志的匹配结果直接转发给纪存，只补一个词："看见了？"更冷、更七海。
- 保留样板：兜灯的验收单腔（"偏了半齿""不给我硬停机权，我不让它动"）是全章最成功的角色声音，唐胶"售后被骂到退休"同样成立。这两人的声部是基准线，别动。
- 合并建议：七海一句**强烈建议合并**；其余**不建议改动**。

**人物关系**

- 本话最好的一场是唐胶签来源那段（"我是不想它第一次真护了人，转头就被你我当耗材"），误会-戳穿-体谅三步全有，**不建议改动**。
- 缺口：纪存x七海的"风险共签"落点略平。补一个身体细节：终端把两人水印合栏误标"风险共签"时，让七海伸手想撤销、停住、没撤。她的不撤销比任何台词都暧昧且不越界。
- 合并建议：**可选合并**。

**机体/IP/爽点**

- 缺口：小队踩巨掌过中庭是本话燃点，但目前是叙述句，缺一个仰拍机位。
- 补强：给一个从维修箱视角的镜头，箱子上的孩子贴纸和十八米掌纹同框滑过，下方是冷却红线。这一帧就是本话PV卡。
- 合并建议：**强烈建议合并**。

### C01E03《勇气审批角临时许可》

**剧情设计**

- 问题：这是四话里"机器人动画浓度"最低的一话，敌我双方全是框、章、锤、纸，八回合里没有任何东西真的挥过一次拳。作为勇者文化致敬话，它讲了勇气的手续，没讲勇气的身体。
- 具体补强：让南侧"0号开启臂残压"在第6-7回合有一次真实的物理破门未遂，门缝里伸出半截旧机械臂，被金章通道的光压回去。既给本话唯一的实体威胁镜头，又把0号从字段升级为伸过手的东西，为E04的低频诱惑加重量。
- 合并建议：**强烈建议合并**。

**台词设计**

- 最该改的：责任词汇过载。纪存的分工宣言、兜灯的承重句、豪司的补句、七海的摊牌在同一场戏里连发，四个人共用"签/追/责"词根。
- 示范方向：让豪司彻底脱离这套词。他是被周报驯化的热血中年，口癖应该是行政黑话用出热血感："流程我熟，熟到知道哪页可以先撕。"断线前那句"别让模型盒替我背"很好，保留。兜灯在本话可以少说一句：她把扳手往审批锤轨道上一放就是表态。
- 合并建议：**强烈建议合并**（豪司声部）；**可选合并**（兜灯减句）。

**人物关系**

- 本话最准的一场是纪存蹲下来对小满讲"头部"，边界干净、有温度，**不建议改动**。
- 缺口：阿澄在本话蒸发。补一个小动作即可：阿澄在黄线后替豪司数封锁框还剩几个，隔着通讯报数，豪司答"收到，小同事"。不给孩子责任，只给他被大人认真对待的一秒。
- 合并建议：**可选合并**。

**机体/IP/爽点**

- 缺口：三话过去，己方可操作单位仍只有馆守Z（且本话它只是通道）。商业上需要在E03尾部给"下一台友军机"的钩子。
- 补强：金章通道照亮B1那一秒，除了移动底盘轮廓，让某个**中型泊位**的登记灯短亮并显示一个待认领原名（不指定是谁），玩家会自己开始猜第一台入队机。
- 合并建议：**强烈建议合并**。

### C01E04《万机馆临时展舰起航》

**剧情设计**

- 问题一：新系统一次到货七件（三选二、岗位点、火锁、黑框、0号捷径、远星半帧、旧模板），可读层有回归"规则书"的风险。建议远星半帧和旧模板两项只保留画面、删去解说，规则留在制作层。
- 问题二：黑展柜残压作为全章第一个有脸的敌人，登场只改了一个token就退场，镜像的痛感没打出来。
- 具体补强：让黑展柜残压显影时**复刻E01的巨掌防线构图**，同样的抬掌、同样护向留言墙方向，但掌下生成的是黑框。玩家上一次为这个动作热血过，这一次会本能地发冷。这是全章最便宜也最狠的一个反转镜头。
- 合并建议：**强烈建议合并**（黑展柜镜像）；**可选合并**（规则减载）。

**台词设计**

- 最该改的：陆衡与兜灯声部撞车风险。两人都讲工况参数。区分方向：兜灯对机器说话，陆衡对人说机器；且陆衡应该有一种干燥的坏笑，"重量写克，不写心疼"正是这个声部，全话应向这句对齐。他那句"我盯着你们，不是为了否定你们"略显自白，可改为他把损伤板翻面签名时只说："下回先给我看工况，再耍帅。"
- 保留样板：七海"这不是同意。只是复核需要时间。"是她全章最好的一句，**不建议改动**。
- 合并建议：**强烈建议合并**（陆衡结尾句）；**可选合并**（全话陆衡声部梳理）。

**人物关系**

- 泡棉窗口一场（唐胶误会 -> 发现兜灯留窗 -> "下次先报重量"）是全章关系戏最佳，**不建议改动**。
- 缺口一：陆衡全程正确，没有付出被打脸的成本，容易变成完美审计员。补法：他对"先卸重型架一半负载"的计算漏了馆守Z自己会伸手挡无人机这个变量，被迫当场改数。他咂一声"它没在我表里"，既是幽默也是他和这座馆的第一次和解。
- 缺口二：馆守Z救了全馆三次，起航时只得半句。让孩子们贴新标题时顺手把一张留言贴在重型架护栏上，胸牌低热闪一次作为回应，巨机线的泪点收口。
- 合并建议：陆衡改数**可选合并**；馆守Z收口**强烈建议合并**。

**机体/IP/爽点**

- 起航连续镜头（L3红线 -> L2星图 -> L1下沉 -> B1肋骨 -> 外锁泊臂）已是PV级，不缺。唯一缺口是"临时开馆中"灯带亮起时缺一个**外部视角的目击者**，街对面留一个抬头看见破馆升起的普通人剪影（不给身份），机器人动画的"城市目击巨舰"记忆一帧补齐。
- 合并建议：**可选合并**。

## 章内连续性问题

1. **白鸢全章零出场零提及**。若是章后角色，至少需要一个可回收的种子（无人认领名单、待审见证抄送对象等位置都能藏）；否则读者名单和实际名单不符。
2. **方舟T缺席**。同上，需决定后置还是在B1泊位/工程频道里留暗位。
3. **豪司在E04蒸发**。E03末他顶着处分断线，E04起航这么大的事没有他一行下落（哪怕一条"周报编号+1"的短讯），越权的余温断了。
4. **冷却针车E03/E04无交代**。连续两话的核心压制单位无声退场，敌方部队像换了班。E04外围尾随镜头里带它一帧即可。
5. **E02留言墙抉择的结果没有落点**。第4回合"救墙还是保臂"的分支结局在E02结算和E03开场都未读出，直到E04才以"黑边留言纸"隐约出现，中间悬空一话。
6. **唐胶旧膜"别问来源"**。已签名入账，作为债可以，但E04模型街预告时应有一次轻触（他看到旧供货牌时神色变化），否则读者会当它是丢掉的伏笔。
7. **高潮动词四连同**。E01签服役、E02签自限、E03签矩阵、E04签复核，节奏上建议E03的高潮重心从"签"挪向"豪司的人"（工牌一按已是好动作，把落点戏份从矩阵匀给他）。
8. **时间感模糊**。四场战斗+起航似乎发生在同一个闭馆夜，但正文无时间锚。每话开头一个时刻标记（23:40 / 00:15 / ...）能让"一夜失馆"的压迫感成立。
9. **正面记录**：阿澄E01数留言 -> E04数撤离人数的呼应是成立的，合并时注意别被删。

## Codex合并优先级

1. **E04 黑展柜残压复刻E01巨掌构图**。全章镜像主题的成立点，成本最低收益最高。（强烈建议）
2. **E02 半次滑拳+兜灯中途硬停机**。兑现飞拳爽点又立住克制主题。（强烈建议）
3. **E03 0号开启臂物理破门未遂**。给最纸面化的一话唯一实体威胁。（强烈建议）
4. **E04 馆守Z起航收口（留言贴上重型架+胸牌回闪）**。巨机情感线补完。（强烈建议）
5. **E03 豪司声部去责任词根、改行政黑话热血腔**。解决全员同声最严重的一话。（强烈建议）
6. **E01 巡礼压成带故障巡检、症状前置**。章头留客率问题。（强烈建议）
7. **E01 馆守Z落掌前的旧展演小动作**。一行字的PV级角色化。（强烈建议）
8. **E03 B1中型泊位待认领原名短亮**。下一台友军机的商业钩子。（强烈建议）
9. **豪司E04下落一行 + 冷却针车E04尾随一帧**。连续性缝合包。（强烈建议）
10. **E01 纪存宣言句降调 + E02 七海"刀"句改转发**。两处金句腔清理。（可选合并，但建议一起处理以统一声部基准）
