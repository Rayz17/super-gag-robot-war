# C04 Fable建议的Codex合并计划

来源：`C04-fable-output.md`

## 总体判断

Fable 对 C04 的输出质量较高，尤其抓住了用户此前指出的“小打小闹、温水推进、缺少大开大合”的问题。C04 现稿的主题链条强，但情绪经过制度、日志、规则过滤太多；Fable 的补强方向是把每话增加身体级失控和可感场面。

C04 不需要推翻。现实机器、工务、错话、三法城四级递进成立。需要增强的是反转失手、人物轮换、关系肉身感和机体PV瞬间。

## 强制合并项

1. `C04E12`：第七次挡梁改为半主动选择，由玩家或白鸢标记倒伏方向，跌跌“选择”朝钢梁倒，避免燃点像巧合。
2. `C04E12`：白鸢撕下“帅气跌跌”画稿垫进缓冲垫，用自己的“漂亮”给失败当垫子，推进白鸢/纪存线。
3. `C04E12`：陆衡恼怒段动作化：他去够计数器电源，被方舟T锁权限后脱口问“你到底站哪边”。
4. `C04E13`：插回完整失败记录先反噬，站立标尺塔判废分数暴涨，封锁升级。
5. `C04E13`：破局改为路面修复机读到完整记录里的缓冲垫位置数据，自行给跌跌留出一格路。
6. `C04E13`：唐胶/兜灯抢修用四句短对白落地，不再只旁白“节奏合拍”。
7. `C04E13`：唐胶换到迎雨一侧替兜灯挡风，兜灯只把绝缘布递得更快，关系升温靠动作。
8. `C04E14`：中段增加错话导致轻伤事故，让七海删库要求和纪存二次确认方案都有地面依据。
9. `C04E14`：纪存/七海错话库谈判压缩成短兵器对白，条款细节放终端画面，不让角色互念政策。
10. `C04E14`：白鸢教小查“画错也可以留着”，小查把她分镜学歪成涂鸦，她不擦还签名。
11. `C04E15`：旧救援机器人往事改为可玩低分辨率回放，玩家亲手重走那晚命令线，先被规则困住再谈改规则。
12. `C04E15`：伊莱补私人细节，“我以前的编号只发给残骸。今天第一次发给还在动的。”
13. `C04E15`：七海签名段用笔尖停在第四格的动作替代“声音平稳”的旁白定性。
14. `C04E15`：纪存把自己的名字写进事故桌第一格“谁下令”，和七海形成对等承担。
15. `C04E15`：遥控铁卫演出强化为“操纵权悬空→责任落笔才动”，用足遥控机文化投射。

## 可选合并项

1. `C04E12`：开场加前批次公测报废机残骸被拖走的冷场面。
2. `C04E12`：通关时跌跌坐回缓冲垫，两枚状态灯第一次同步稳定发光。
3. `C04E13`：纪存引错一条法规，被七海纠正但仍认可思路，避免主角全知。
4. `C04E13`：三机雨中接力做“不喊口号的工务合体”，唐胶吐槽“这才叫合体，懂吗”。
5. `C04E14`：涂鸦巡游壳的旧贴纸吸掉一次刮刀无人机删除判定。
6. `C04E15`：第零法投影压缩到三个镜头以内，把主情绪让给旧救援机器人。
7. `C04E15`：陆衡看旧救援机器人被问“你还要试吗”后低语，轻收删除债。

## 暂不采纳或需谨慎项

1. 不把 C04 改成全章强战斗火力章。现实机器章以非攻击、保通、说得、规则战为主是合理的，但可在 E14/E15 留一个小型火力宣泄。
2. 不让小查错话变成纯搞笑段子。错话必须造成风险、被确认、被保留，不只是梗。
3. 不让白鸢和小查关系暧昧化。该关系只能是创作/教导/保护式，儿童或近儿童表达严格隔离成人向。
4. 不让伊莱变成大段自述型人物。一个私人细节足够，主场仍是规则战和七海/纪存承担。

## 连续性债务

1. 白鸢在 `C04E13/E14` 缺席，需要补一格雨中护稿、留舰原因或小查分镜互动。
2. 唐胶/兜灯在 `C04E12/E15` 缺席，至少要让 E15 结尾不只一句梗，或前面有缺席理由。
3. 跌跌在 `C04E14` 的位置需交代，避免 E15 突然在场。
4. `C04E12` 七海“三次压线终止”规则要在结算里说明七次摔倒并未全部压线，例如“压线两次，距终止一次”。
5. `C04E13` 城市功能评分要在 E15 回读，影响工务三机支援规模。
6. E12/E13 关于失败记录和成功剪辑的双标讽刺需要一句角色点破。
7. 陆衡删除债需要 E15 轻落一拍，不然 E12-E14 建立后悬空。

## 写回本地时的注意

- C04 的最大修稿原则是“让规则战落到身体和场面”，不是继续堆协议名。
- E12/E13 是白鸢和唐胶/兜灯补关系的关键，不要让 C04 只剩陆衡/方舟T和七海/纪存。
- E15 要控制信息密度。第零法、铁巨人残响、远星误译都保留，但必须压成收尾钩子，不抢旧救援机器人的泪点。
- 合并时同步更新战斗触发、角色在场表、机体支援表、关系状态和 `episode_state` 债务。
