# Fable三维优化建议 - C02 模型街临时开馆

来源：Notion 页面 `Fable优化 C02 模型街临时开馆`

## 总体判断

**最大优点**：章主题高度统一（“热爱被定价”），情绪全部挂在实体小物件上（姓名贴、错字昵称牌、维修单），这是本章真正的资产；E03旧拳王“把价格打出界”是全章唯一达到机器人动画名场面强度的段落，三话敌方升级链（哨塔 -> 核心 -> 五部件Boss）也干净。

**最大问题**有三个。第一，**台词系统腔过重**：大量对白在念规则名词（来源码、责任水印、非致命协议、授权边界），街面NPC几乎无声，模型街共同体是“被描述的”而不是“被听见的”。第二，**纪存/七海三话同一拍**：每话都是“你正确但我拒绝 + 署名留痕”，第三次出现时已无新信息，关系没有升级只有复读。第三，**舰内空场**：三话E段全是pass占位，陆衡只剩远程冷声，方舟T全章消失，万机馆本身没有生活感，这条船上的人只在街面上存在。

**最该补强的方向**：把E02/E03已有的好骨架“落成具体镜头和具体人声”；给三色样件和旧拳王各一个非台词的“发声方式”；补齐七海的一次破防和白鸢的前置痕迹。

## 逐话建议

### C02E01《木桶街入夜》

- **剧情设计**：问题一，开场结构仍是“B1缺件清单 -> 上街”，尽管文本自称不是采购任务，玩家体感依然是采购；建议冷开场先给一个街面视角（摊主收摊前把姓名贴翻到盒底的手部特写，或退坑柜前老玩家犹豫的一格），再切B1清单，先让玩家想留在街上。**强烈建议合并**。
- **剧情设计**：问题二，“旧灾变模板误套”是本话真正的爆点，却埋在一句叙述里；建议做成全街可见的一次演出：价格屏上“来源保护”四个字被红光逐字改写成“灾后物资处置”，全街价签同一秒跳动，围观者安静半拍。**强烈建议合并**。
- **剧情设计**：问题三，价格屏跳红作为中段转折过于线性、无反转，可接受但建议在跳红前加一次假安全（热度短暂回落，众人松口气）再跳红。**可选合并**。
- **台词设计**：最该改的不是主角对白，而是**街面NPC零台词**。建议补2-3条生活声：摊主“这盒不卖，看可以，手汗先擦了”；退坑柜主人“都退坑了……你别问我为什么每周还来”；围观老玩家看到手汗痕溢价时“那我这十年手汗岂不是理财”。**强烈建议合并**。
- **台词设计**：纪存的“不是买件，是去敲别人不一定愿意开的门”略金句化，但作为本话题眼可保留；建议删的是终端提示型复述。**可选合并**。公文包成年人全程无台词是对的，**不建议合并**任何给他加词的改法。
- **人物关系**：建议在结尾回执处补一个动作：唐胶看见纪存把“禁止公开主人”写进回执，把自己的维修箱往纪存那边推了半格，没说话，形成第一次工具层面的认可。**强烈建议合并**。纪存/七海本话写法成立，不必加戏。
- **机体/IP/爽点**：样件抬身时摆出的姿势正是它旧盒绘上的站位构图，唐胶先认出来，低声“它记得自己的盒绘”。这能把“商品生命误认”变成燃点。**强烈建议合并**。
- **机体/IP/爽点**：馆守Z掌影段建议加声音与地面震感，以及一个围观者举起手机又默默放下的反应镜头，把“巨大机体为小盒子忍痛”的泪点放大。**强烈建议合并**。

### C02E02《限定版暴乱》

- **剧情设计**：第5回合信息过载：七海清单、误读锁、分类撤回、路线倒播、限命烧痕全部挤在同一回合；建议把倒播和限命烧痕移到第6回合价格屏换流时。**可选合并**。
- **剧情设计**：泪点“通关也会丢东西”目前是结算描述不是镜头；建议补一个具体画面：物流车关门前，被装走的透明盒里，样件把错字昵称牌贴在盒壁内侧、字朝外，像把自己的名字举给玩家看。**强烈建议合并**。
- **台词设计**：兜灯“快不是刹车许可”不像人喊出来的话，建议改成“它没学过停！先给它个能撞的东西！”唐胶“你快归快，先学会停”保留。**强烈建议合并**。
- **台词设计**：纪存对七海的“别让我替你改成系统自动”后半句拗口，建议方向：“撤回记我名下。你的截证署你的名，别让我心软替你抹掉。”七海“我看过，确认过，发给你”是全章她最好的一句，保留。
- **人物关系**：唐胶/兜灯“共同造工具”保留。可加一个延迟体谅：兜灯写协议时把唐胶列为共同责任人而非被监督对象，唐胶当场没发现，战后收工具时才看见签名顺位，愣了一下没说话。**可选合并**。
- **人物关系**：公文包成年人在本话正片中完全缺位、只在结尾被找，建议在人群流向戏里给他一格无台词镜头（他站在折叠凳区没走）。**强烈建议合并**。
- **机体/IP/爽点**：三色样件战术功能清楚，但没有性格发声。建议让它们复读弹幕碎片作为唯一“台词”：红速只会重复“限定……限定……”，蓝盾护盒时低声重复“普通版……普通版……”，黑镜从不出声只让倒影先动。**强烈建议合并**。
- **机体/IP/爽点**：限命烧痕第二次出现时，建议让兜灯注意到并皱一次眉，否则像素材复用。**可选合并**。

### C02E03《胶价王拍卖台》

- **剧情设计**：高潮成立，问题在战后长尾：四态经营、旧灾变误判、寄售台、2回合sting连续排队，情绪从旧拳王峰值一路阴干。建议在ADV层空间叠写：纪存插四态牌时，寄售台的灯已在画面深处亮起，灰模头轮廓入镜但不给正面，把“下一个问题已经进场”叠在结算里。**强烈建议合并**。
- **剧情设计**：旧拳王上台段落本身不要动。**不建议合并**任何给它加冠军往事或悲壮回忆的扩写，“只有安全限制、没有光环”正是它的力量。
- **台词设计**：主持投影只有概念没有语癖。它应该像带货主播一样贱得具体，例如：“家人们看这道裂纹，这不是伤，这是真实守护过的纹！”“最后一件！错过这次，你的童年就真的下架了！”“旧主人不愿露面？那就更值了！”**强烈建议合并**。
- **台词设计**：七海的“更难替你辩护”是同一拍第三次出现，建议给她唯一一次破防：说完流程后停一拍，“……你小时候也有过这么一盒吗？”随即自己掐断，“当我没问。抽样复核，明早九点。”这是高收益高风险项，需要对照七海canon口径。**可选合并**。
- **人物关系**：唐胶/兜灯共签和拇指停半秒已到位，保留。**不建议合并**任何更进一步的暧昧动作。白鸢线索空降是关系层最大缺口，建议在E01旧盒绘墙某格角落埋一笔同款红笔改字痕（“未采用”被划掉），或E02弹幕里闪过一条无来源的修正弹幕。**强烈建议合并**。
- **机体/IP/爽点**：旧拳王没有声音签名。建议它唯一的“发声”是机体内置老式读秒铃：起身时铃响一声；把拍卖锤打出界后铃自动读秒，数到八，观众席有人跟着接“九，十”，全场自己完成读秒。**强烈建议合并**。
- **机体/IP/爽点**：三色样件回收不均。蓝盾晃镜、黑镜贴标签都有回收，红速在E03无动作；建议给它一拍“学会停”的payoff，它追直播无人机冲到折叠凳区前，第一次自己刹住，停在一寸之外。**强烈建议合并**。
- **机体/IP/爽点**：灰模头、旧货柜锚件维持不启动、不真机化。**不建议合并**任何让锚件在sting里“动一下”的诱惑写法。

## 章内连续性问题

1. 方舟T全章缺席，陆衡/方舟T这条线在C02完全没有存在感；至少需要一句提及或一次B1背景露面。
2. 舰内日常段三话皆为pass占位：万机馆内部零生活戏，纪存与船员没有任何街外互动，“流亡展舰”只剩地图上的一个支援点。
3. 社勇王缺页、模型病历来源码：E01建立后E02/E03未再触碰一次，章内连回摸镜头都没有，容易被玩家判定为无效收集。
4. 七海三话同构：远程面板、署名、“我不替你选”重复三次，无升级无变奏。
5. 红速“学会停”梗E02建立、E03无回收。
6. 公文包成年人E02正片缺位，结尾突然被找，中间断链。
7. 陆衡口吻三话零变化，E03只剩一句接口台词，接近角色消失。
8. E03结算四段连排，峰值后节奏阴干。
9. 限命烧痕跨话复用但无角色累积反应，第二次出现应有人认出“又来了”。
10. 白鸢红笔拖痕空降，全章无前置痕迹。

## Codex合并优先级

1. E02：物流车关门前，错字昵称牌贴盒壁字朝外，泪点具象化。
2. E03：旧拳王读秒铃 + 观众席接数“九，十”，燃点声音签名。
3. E02：三色样件复读弹幕碎片作为唯一“台词”，半成品性格化。
4. E03：红速在折叠凳区前第一次自己刹住，回收“学会停”梗。
5. E01：样件首动摆出旧盒绘站位构图，唐胶认出，商品生命误认变燃点。
6. E01/E02：埋白鸢红笔痕迹前置伏笔，修复E03空降。
7. E01：灾变模板误套改成全街价签同秒改写的可见演出，爆点前台化。
8. E01：补2-3条街面NPC生活台词，共同体有声化。
9. E03：主持投影带货主播语癖具体台词，Boss叙事煽动落到人声。
10. E02/E03：公文包成年人E02人群一格镜头 + 七海一次掐断的破防问句，断链修复与关系变奏。
