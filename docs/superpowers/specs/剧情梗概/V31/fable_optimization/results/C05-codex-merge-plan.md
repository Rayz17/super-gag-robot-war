# C05 Codex合并计划 - 星火车队与五色开馆

## 总体判断

Fable 对 C05 的诊断有效：这一章的机甲文化谱系已经比较扎实，但人物和机体“不开口”，导致很多情绪靠登记、保存、公开等抽象动作完成。合并时不推翻现稿，应重点把已经好的谱系结构变成更外放的机器人动画场面。

## 强制合并

1. **C05E16 五车开口与路线之争**
   - 让红焰重涂车短暂抢走领袖频道，提出“更快、更帅、数据更好看”的高效率路线。
   - 医疗车掉队后，红焰主张放弃慢车；旧货柜用一句低调但有重量的话夺回频道。
   - 五车各有一次签名动作，避免“星火车队只有锈迹和灯光，没有机体个性”。

2. **C05E16 纪存与七海摩擦式体谅**
   - 纪存公开封存路线时抹掉七海署名，七海误会他在遮掩。
   - 纪存解释不是替她洗白，而是不让她失去后续审查位置。
   - 白鸢目击两人都不领情但都替对方留位置，后续“画进同一格/问号”才成立。

3. **C05E17 推荐塔软Boss化**
   - 形态推荐塔从推销、阴阳怪气，升级到强制试装，成为本话可对抗目标。
   - 散件小车寄生外壳，谁装高战力外壳，谁就被配件群追着挂。
   - 保留“高战力外壳短期爽、长期伤主体”的机制，但必须场面化。

4. **C05E17 外壳先甜后苦**
   - 允许一次真正的海报级试装：飞行消防车清屏或医疗车背炮运镜。
   - 随即散热崩、担架舱卡死、维修口被遮挡，让玩家理解诱惑不是纸面选项。
   - 五车拒绝台词分声部，不再像五张展签。

5. **C05E18 巨大化兽人影完整相位与谢幕**
   - 热度槽满时兽人影完整巨大化一回合，给玩家真正的特摄威严和压迫。
   - 战败不爆炸，拉链打开，露出空皮套和旧风机，像下班演员被送走。
   - 赤罡转变先由白鸢的人群画面触发，再由黄色替补卡补刀。

6. **C05E19 完全版镜像巨神**
   - 索引用重涂话术、外壳升级包、声浪、完全版欲望临时拼出“完全版镜像巨神”。
   - 镜像巨神只亮相、压制一回合、撤离，不在 C05 决战，作为 C06 目录翼种子。
   - 形成“拼错但能动”的星火巨神 vs “拼对但空心”的商品图怪物。

7. **C05E19 纪存失守与白鸢记录**
   - 星火巨神站起时，纪存下意识跟着观众念出半句，露出不是审计员的自己。
   - 白鸢画下这个瞬间，纪存要求删，白鸢拒绝。
   - 这是 C05 内纪存第一次被记录，而不是只记录别人。

8. **C05E19 陆衡与方舟T回收**
   - 方舟T把“最后一辆确认”标成低置信度误译。
   - 陆衡这次不走流程，手动改译并署名，回收 C05E16 远星误译。
   - 作为陆衡/方舟T克制亲密线的小推进。

## 可选合并

1. **兜灯补场**
   - C05E17 加一段兜灯想给唐胶配“防护外壳”的短戏，唐胶拒绝但不拆穿。
   - 让唐胶/兜灯与五车“拒绝漂亮外壳”形成镜像，不必加长太多。

2. **赤罡前置垫场**
   - 在 C05E16 或 E17 给赤罡一句看重涂三车飙车的反应，让 E18 红色抢跑不再空降。

3. **儿童意象轻连**
   - C05E16 医疗车“不要让孩子看见”的维修单，与 C05E18 小满/阿澄安全频道用一句台词轻轻连上。

## 禁止合并

1. 不让彩队巨神在 C05 正式入队或可操作；只保留预显影、站位修正和隐藏谱系提示。
2. 不扩大五兽王冠残响到抢走星火主线的位置。
3. 不让“完全版镜像巨神”在 C05 被打倒；它必须逃走成为 C06 的目录翼燃料。
4. 不把七海写成单纯放水；她每次让步都要变成她自己会被追责的制度动作。

## 合并后预期收益

- C05 从“设定很清楚的星火章”升级为“会说话、有对手、有商品怪物、有合体对照的机器人动画章”。
- 纪存/七海/白鸢从证物隐喻推进，变成误会、体谅、被记录和拒绝删除的具体关系场面。
- C06 的目录翼不再凭空出现，而是从 C05 的重涂、外壳、声浪、完全版欲望逐步攒出来。
