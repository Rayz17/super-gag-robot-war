# Fable三维优化建议 - C06 万机同心与拆掉完全版

## 总体判断

本章最大优点：主题闭环极其完整。从E20巨大化、E21营销话术、E22模块质询到E23伪同心巨神，敌方样本链（巨大奇观→模块身体→伪共同语言）逐话咬合，玩家的每个正确选择都成为敌人的素材，这是一个真正的"章级Boss养成"结构，在机战题材里罕见且成立。医疗车胸灯回收四话选择作为破防点，是目前全剧最好的一次"系统即情感"设计。

最大问题：**戏剧密度落后于机制密度**。四话里几乎所有情感都以"叙述结论"的方式给出（"她愤怒不是因为被偷，而是因为那确实是她的欲望"），而不是用台词和动作演出来；角色台词大量是流程句、条件句、审计句，人味台词占比过低。其次，纪存全章零代价、零失手，作为主角在章级高潮里情绪太稳，像主持人而不是当事人。第三，配角断线：方舟T全章缺席，唐胶/兜灯在E20-E21退化成单句吐槽机，小满E21露面后消失。

最该补强的方向：把已有的好设计从"设定说明"翻译成"可拍的场面"——每个机制节点配一个10秒演出锚；给三角关系每话至少一次"有来有回"的对视/回应，而不是单向观察；给纪存在E23留一道真实的伤口。

## 逐话建议

### C06E20《巨大化不是放大贴图》

- **剧情设计**：问题——三尺度机制信息量大，但开场直接由陆衡讲解三层战场，玩家没有"痛过"就被教学，机制记不住；棚守巨影出现太顺，登场即懂事，缺一层"它是谁留下的"的小谜。具体补强：开场让玩家用常规打法先失败一次——硬打怪影本体无效，反而一回合内踩碎一条街，损失落进F段变量，然后陆衡才拆三层，教学变成教训；棚守巨影登场前给一个空镜：皮套库深处一台没人认领的旧放映机还亮着待机灯，为字条和巨影留一个共同的无名主人。合并建议：**强烈建议合并**（失败教学）；**可选合并**（放映机伏笔）。
- **台词设计**：最该改的是"会议纪要腔"——"三尺度管制：保留最低帧率、限制镜头中心、后台疏散优先"这类句子应该留给UI，不该从纪存嘴里完整念出。示范方向：七海："灯全灭。五分钟内，没有任何东西会被踩。"纪存："灯灭了，影子也没了——棚守只活在光里。"白鸢（切俯拍时自嘲）："拍了这么多年好看的镜头，第一次庆幸我也会拍丑的。"合并建议：**强烈建议合并**。
- **人物关系**：本话应推进纪存/白鸢的战术信任，但现在只有"投成参考"一句结论，缺白鸢的反应——建议加一拍：她发现全队战术屏上用的是自己那张"丑镜头"，署名没被抹掉，尴尬和骄傲各占一半，别让她说谢谢。七海"远程担责"太顺滑，建议加一次真实迟疑：她同意三尺度管制前，先问了一句只有纪存能听到的"如果城没保住，记谁的名字"。合并建议：**强烈建议合并**（白鸢反应拍）；**可选合并**（七海私下通讯）。
- **机体/IP/爽点**：特摄棚、皮套、微缩城市的巨大特摄文化投射很足，棚守巨影"影子英雄挡一脚"燃泪成立。缺口：星火巨神本话没有自己的动作记忆，风头全被棚守巨影拿走——建议补一个"以小护大"镜头：巨大化层里它显得很小，却用吊车承力臂顶住倾倒的摄影灯，让"小机体在大尺度里干笨重的活"成为它的本话签名。合并建议：**强烈建议合并**。

### C06E21《伪领袖发布会》

- **剧情设计**：问题——反营销阵地战概念新，但"送证物到节点"容易玩成跑腿，敌方缺少主动威胁；伪领袖"几乎成功"只停在"星火车队差点回应"一句。具体补强：让一台我方机体真的被短暂收编——建议是社勇王（它最吃"许可"话术），金章被改写成预购徽章、单位变灰离控一到两回合，玩家必须用证物现场赎回，敌人的诱惑才从演出变成损失。合并建议：**强烈建议合并**。
- **台词设计**：伪领袖五连"谢谢你们"是本话最强段落，但排比过于整齐反而像广告文案——建议留三删二，并让最后一句露出微小破绽（感谢的事实对，但用词是商品部的，比如把"等最后一辆"说成"耐心营销窗口"），给阿澄的停顿泪点埋逻辑。白鸢段落目前是心理分析文，不是戏；示范：白鸢："那张图是我画的。画完那天晚上，我删了三次，没删掉。"纪存："那就删第四次。当着所有人。"合并建议：**强烈建议合并**。
- **人物关系**：三角在本话形成"各自对抗自己最擅长的东西"，方向很好，但白鸢看向七海的封存权限那一眼是单向的，缺回应——建议七海察觉到这道视线后，把封存界面往纪存终端推远了一格，等于当着白鸢承认"我也在被看"。这种非语言回应比任何台词都狗血且克制。阿澄的停顿证物强烈保留，但建议在E20先埋一拍：她在观众席数喊名的节拍，被小满笑"你看戏像在做算术"。合并建议：**强烈建议合并**（阿澄前置铺垫）；**可选合并**（七海推界面）。
- **机体/IP/爽点**：天空商品包画面成立，但本话敌方是纯UI，PV里没有"对手"——建议给伪领袖一个临时躯体投影：用玩家所有机体的轮廓碎片拼成的领袖剪影，越看越熟悉、越看越不对，这既是画面钩子也直通E23伪同心巨神。合并建议：**可选合并**。

### C06E22《目录翼商品包模块战》

- **剧情设计**：问题——一话塞八个模块加七个角色职能质询，节奏有菜单化风险，玩家会疲。具体补强：模块分层——三个战场必答（王冠广播核、尖刺背包、勇气徽章包，各绑一场小演出）、三个可选、两个无论如何流入E23，减负同时保住"未处理模块变Boss部件"的钩子；尖刺背包必须配一次真实的救援受阻演出（担架舱被挡，倒计时里差一秒），不能只在条件文本里说"挡住担架舱"。合并建议：**强烈建议合并**。
- **台词设计**：最该改的是职能标签化对白——陆衡看承力链、唐胶看接口、兜灯看安全锁，每人一句岗位说明，全员同声。豪司的"许可不是让大家都更帅"方向对但太格言；示范：豪司："……我以前觉得，喊得最响就是勇气。现在这盏灯照着维修口，我喊不出来了。"唐胶（看着尖刺背包）："讲道理，这玩意儿真帅。"兜灯："安全锁过不了。"唐胶："……那把卡扣拆给我，卡扣没罪。"合并建议：**强烈建议合并**。
- **人物关系**：白鸢那格"三个人围着同一本错误商品册拆线"的分镜是全章三角关系最好的画面语言，强烈保留。缺口：唐胶/兜灯需要上面那种"帅vs安全锁"的斗嘴来恢复双人线；陆衡全章是工具人，建议给他一句私心——他在承力图上标红线时停了一下，说这条红线的画法是方舟T教的，一句话即可，同时回收失踪角色。合并建议：**强烈建议合并**（白鸢分镜、唐胶兜灯斗嘴）；**可选合并**（陆衡提方舟T）。
- **机体/IP/爽点**：重涂三车"被误认者反证误认"是本话最大爽点，红焰晚半拍、蓝巡打限定标签、黑夜镜像换位三个动作都有辨识度，强烈保留；小勇机照维修口泪点成立。缺口：我方王牌在模块雨里存在感低——星火巨神被展示支架炮台锁定后，应有一次"不借支架、自己不好看地站起来"的演出，膝盖打滑也要站，这是对E23不对称合体的预演。合并建议：**强烈建议合并**。

### C06E23《拆掉完全版》

- **剧情设计**：问题——三阶段结构完整，第一阶段"越用最优解它越强"的镜像Boss非常好，但第二阶段七个谱系节点全是条件语句（"要求等待最后一辆""要求责任签名"），缺演出锚，玩起来会像在交表格；另外E21埋的"索引开始伪造证物"在本话没有兑现。具体补强：每个节点配一个10秒画面（如火种残响节点=一辆慢车的前灯在废墟尽头亮起，全场静一拍）；第一阶段加一手伪造证物反制——伪同心巨神出示一张"以假乱真的维修单"，逼玩家分辨真假，回收E21的敌方学习。合并建议：**强烈建议合并**（两条都是）。
- **台词设计**：终局"不喊同一句"是全剧核心场面，但现有支援台词全是功能句（确认路线/担架舱保留），需要掺两三句有人味的：示范：赤罡（守最后一辆慢车）："别催它。它这个速度，是载着人的速度。"某工务机："路修好了。修得难看，能走。"白鸢的"你到底喜欢哪张"可以更狡猾："如果只能烧掉一张，你留哪张？"——纪存"两张都要"的回答本身很好，保留。合并建议：**强烈建议合并**。
- **人物关系**：七秒例外+"记在我名下"+登记为开馆债，链条完整；战后七海实体登舰、"半截水口不写进报告"是全章人物成长最佳一笔，理由（"不是心软，是它没有风险"）写出了成熟而不是放水，强烈保留。缺口：纪存全章没有付出任何私人代价，高潮里他像裁判——建议在医疗车胸灯亮起前，让他有一次几乎按下"统一口号"快捷指令的手（因为多声部眼看要崩），被白鸢或阿澄的声音拦住，他也被自己最擅长的东西诱惑过，这一秒失手才配得上"一张证明我们被诱惑过"那句台词。合并建议：**强烈建议合并**（七海登舰全段保留、纪存失手一拍）。
- **机体/IP/爽点**：医疗车胸灯破防是章级泪点，多尺度全员支撑是章级燃点，都成立。缺口：伪同心巨神"很美"的设定要落在PV上——建议给它一个正面的、真正帅的登场全身镜头（逆光、目录翼展开如圣像），越帅，玩家后面拆它越痛，不要让镜头先替玩家嫌弃它。合并建议：**强烈建议合并**。

## 章内连续性问题

1. **方舟T全章缺席**：四话材料中一次未出现，陆衡因此退化为纯职能角色。至少需要一处口头回收（E22承力红线处最自然）。
2. **唐胶/兜灯关系断档**：E20-E21两人只剩单句吐槽（拉链、责任另售），E22才恢复职能，双人互动线在章前半段消失。
3. **小满E21出现后蒸发**：阿澄的停顿泪点独自承担儿童线，E23观众声部里应有小满的一声回收，否则像少了一个人。
4. **棚守巨影的"一次性"前后矛盾**：E20明确"只获得一次性支援债"且已在E20挡过一脚，E23又"挡最后一次踩踏"——需要统一为"债务偿清即消散"（E23那一挡是还债并退场，反而更泪）或修改E20表述。
5. **豪华配件债回收落空**：E20 Function声称把C05豪华配件债拉回地图，但四话正文中该债务没有任何实际动作或结算，只剩一句概念。
6. **远星字幕的分支漏洞**：E21写明"立即封存会失去远星字幕"，E23的"低效合唱"误译却默认字幕存在——立即封存路线下E23该误译如何发生需要注明差异版本。
7. **索引"伪造证物"计划未兑现**：E21 F段写入敌方学习，E22/E23均未使用，章内钩子悬空（见E23剧情补强）。
8. **节奏断裂风险**：E22信息密度是全章峰值（八模块×七质询人），紧接E23三阶段大战，中间没有任何喘息场；建议E22章末留一场30秒的舰内静场（哪怕只是唐胶数拆下来的螺丝），否则玩家会带着疲劳进高潮。

## Codex合并优先级

1. **E23 纪存"几乎按下统一口号"的一秒失手**——全章唯一能给主角补代价的位置，成本一拍，收益全章。（强烈）
2. **E20 开场常规打法失败教学**——把三尺度机制从讲解变成教训，顺带解决本话说明书腔。（强烈）
3. **E21 社勇王被短暂收编再赎回**——让伪领袖的诱惑造成真实损失，敌人从UI变成对手。（强烈）
4. **E23 七个谱系节点各配10秒演出锚**——高潮从交表格变成看戏，工作量最大但最值。（强烈）
5. **E20→E21 阿澄数节拍前置铺垫**——一句台词，让全章最强泪点从巧合变成必然。（强烈）
6. **E22 八模块分层减负（3必答+3可选+2直通E23）**——保钩子、救节奏。（强烈）
7. **E21 白鸢撤稿段台词去分析化**（"删了三次没删掉/删第四次，当着所有人"方向）。（强烈）
8. **E23 终局多声部掺入2-3句人味支援台词**（赤罡"载着人的速度"方向）。（强烈）
9. **E22 唐胶/兜灯"帅vs安全锁"斗嘴 + 陆衡一句方舟T**——一段戏修两条断线。（可选偏强）
10. **E20/E23 棚守巨影"还债退场"统一化**——把连续性漏洞改写成泪点。（可选偏强）
