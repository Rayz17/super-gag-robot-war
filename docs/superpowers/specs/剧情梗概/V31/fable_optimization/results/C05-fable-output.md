# Fable三维优化建议 - C05 星火车队与五色开馆

## 总体判断

最大优点：四话的机器人文化投射准确且各有分工：E16重涂/同模、E17形态与配件、E18五色战队与巨大化、E19勇者审批与合体，谱系边界干净，玩法与主题咬合（低效率=主体性），“最后一辆确认”是全章最好的燃泪装置。

最大问题：这是一章“没有人说话的机器人动画”。除唐胶外，几乎所有情绪都通过登记、公开、写入、保存等档案动词完成；纪存全章像审计员，没有一次失手、动怒或私心；敌方（索引/代哥）只在结算栏“获得样本”，地图上缺一个有性格、有台词、会被打脸的对手。台词层目前接近空白，人物关系推进多靠“证物隐喻”（画进同一格、半张海报、责任人名单），缺一场面对面、有温度、可以误会的戏。

最该补强：给五车和对手“开口”；给纪存一道裂缝；把E17从选择菜单变成有活体威胁的战斗；让重涂三车、兜灯、陆衡不要登场即蒸发。

## 逐话建议

### C05E16《旧货柜不是同模重涂》

- 剧情设计：问题：护送战压力全部来自无人格的SKU扫描门/无人机，缺一个会说话、会被反驳的对立面；重涂三车目前只是“被识别的对象”，没有戏剧动作。补强：让红焰在战斗中段真的抢走领袖频道并短暂指挥（更快、更帅、数据更好看），四车开始听它的，直到医疗车掉队，红焰的方案是“放弃慢车保整体”，旧货柜只回一句话就把频道拿回来。这样“等最后一辆”是从一次真实的路线之争里赢回来的，而不是预设正确答案。**强烈建议合并**。
- 台词设计：最该改：旧货柜全程零台词，情绪全靠牵引灯，是全话最大浪费；医疗车的泪点也全押在维修单纸上。示范方向（老司机式的短、平、不煽情）：旧货柜等在门前时：“我等它。误点记我账上。”红焰质问为什么等：“你比我快。没人比我记得它拉过多少人。”医疗车最后过线：“门卡了三十年，人没少抬过一个。”**强烈建议合并**。
- 人物关系：该推进：纪存×七海、白鸢×两人。补强：现在的互证太干净。加一段摩擦：七海发现纪存公开她的封存路线时抹掉了署名，质问他；纪存答“署了名它就成了你的立场，你就没法继续当审查者了”。七海没领情，但愣了一下。白鸢正好目击这段各说各话的体谅，那个问号才有来处。**强烈建议合并**。另：陆衡比对吊车补焊痕时认出“这是手工活不是产线活”，两个工程者隔着一条焊缝互相认了，为E19他回核心工程位垫底。**可选合并**。
- 机体/IP/爽点：缺口：五车登场只有“锈”，没有各自的一格帅镜头；救医疗车段落里只有吊车撑桥是画面。补强：让每辆车在护送中亮一次签名动作（消防车水炮打穿假火墙、警备车单灯逆行别住扫描门、吊车臂当桥、医疗车舱门半卡着硬开），最后车灯依次亮起才配得上开章PV。**可选合并**。

### C05E17《扫描形态不能替你活》

- 剧情设计：问题：这是全章最像“设置菜单”的一话：冲突都发生在选项说明里，没有活体威胁，五车的拒绝一顺到底、没有代价当场发生。补强：散件小车不该只是气氛道具，谁装上高战力外壳，散件就成群往谁身上挂（外壳吸引寄生配件），把诱惑变成地图上的实时危险；形态推荐塔做成软Boss：从温柔推销，到阴阳怪气，到最后直接锁定“未升级车辆”的接口强制试装，五车的拒绝才需要打出来。**强烈建议合并**。
- 台词设计：最该改：五车的拒绝理由现在全是同一个声部的主题句（“让用途被看见”式），像五张展签。示范分声：消防车（糙）：“翅膀好看。着火的楼里没跑道。”吊车（慢、字面）：“爪子抓得动敌人，抓不稳楼板。不换。”警备车（省字）：“腿要稳。灯要亮。完了。”推荐塔（推销腔写满，这是本话最好的喜剧位）：“亲，武装形态本月转化率最高，仅剩最后一个接口名额……”**强烈建议合并**。
- 人物关系：该推进：白鸢×纪存（全章最好的双人戏，值得加长半拍）。补强：白鸢撕海报前先做好了被嘲的准备、连反驳的话都想好了，结果纪存没嘲，她反而更不自在；她只交出半张，另外半张自己留着，纪存看见了，没问。诱惑被承认、也被允许保留，这比“上交证词”更像人。**强烈建议合并**。另：唐胶×兜灯镜像主题：兜灯私下想给唐胶配一个“防护外壳”，唐胶拒绝的理由和五车一模一样，两人谁也不说破。**可选合并**。
- 机体/IP/爽点：缺口：玩家从头到尾没真正爽过一次外壳，“诱惑”必须先甜后苦才成立。补强：设计一段外壳试装的高光演出（飞行消防车一炮清屏、逆光海报运镜完全复刻），紧接着散热崩、担架舱弹不开，落差本身就是本话的燃点兼槽点。**强烈建议合并**。五兽王冠Cut-in保持一次即可，任何给五兽加戏的方案：**不建议合并**。

### C05E18《五色不是五个货号》

- 剧情设计：问题：赤罡在本话突然以“熟人”姿态承担成长弧，章内前两话零铺垫；半身巨大化兽人影“不是纯敌人”的设定很好，却缺一个收束动作：它最后去哪了没有交代。补强：在E16或E17给赤罡一句垫场（看重涂三车跑得快就手痒之类）；兽人影战败时不炸，拉链自己拉开，里面是空的皮套和一台还在鼓风的旧风机，观众频道自发给它鼓掌，它像下班的皮套演员一样被“送走”而非被消灭。**强烈建议合并**。
- 台词设计：最该改：七海同意保留观众频道并自列责任人一段，现在全是条款语。示范：“关掉最省事。以后有孩子问那天为什么没有声音，这个问题归我答。”另外五色守轨成功时，别让五个声部喊统一口号，让他们各喊各的任务（“路线确认”“水域就位”“重物我来”），不齐，但都在。**强烈建议合并**。
- 人物关系：该推进：赤罡×黄色替补卡（客座弧）、白鸢×人群。补强：把赤罡的转变改为双重触发：他先看到白鸢在画的不是他的低机位特写而是喊名的人群，愣住，然后才看到卡背那行字。让画面先动摇他，文字只是补刀。**可选合并**。小满、阿澄严格留在安全频道的边界处理是对的，保持；只建议给阿澄一句“听出停顿”的伏笔台词，为C06E21埋线。**可选合并**。
- 机体/IP/爽点：缺口：兽人影只有“越拍越大”一个相位，热度双槽压力曲线偏平。补强：热度槽满时它完整巨大化一回合。这一回合它是真的威严、真的像正片怪兽，BGM都转正剧，玩家会在“想多看一眼”和“必须压热度”之间真实纠结，这才是本话的机制燃点。**强烈建议合并**。彩队巨神一秒站起+一次站位修正的分寸正确，任何让彩队巨神参战的方案：**不建议合并**。

### C05E19《勇气审批驳回豪华合体》

- 剧情设计：问题：章末高潮的对立面又是无人格的“配件雨”，索引全章零正面出场；星火巨神站起后只做了防御动作，缺一场真正的对手戏。补强：让索引把全章回收的样本（重涂话术+外壳升级包+声浪+完全版欲望）当场攒出一台“完全版镜像巨神”轮廓：王冠、兽爪、背炮、飞翼全挂，和商品图一模一样地帅。它不用被打倒：亮相、压制一回合、带着样本撤离，成为C06目录翼的种子。“拼错但能动”必须对着“拼对但空心”才成立。**强烈建议合并**（注意与C06目录翼的canon衔接，只做预演不做决战）。
- 台词设计：最该改：金章AI“头部是最后一个看见所有人的位置”偏金句。示范方向：让它以公文腔宣读驳回理由：“驳回。理由：头部视野义务未分配。头部不是奖励席位。”公事公办反而更好笑也更不说教。豪司憋话要给足生理性：“合体许……”（红框弹出）“……可以再等等。”最后获准时那句喊出来才值钱。**强烈建议合并**。
- 人物关系：该推进：纪存的裂缝、陆衡×方舟T。补强：纪存全章都是审计员，星火巨神站起那一刻给他一次失守：他下意识跟着观众留言一起念了半句什么，被白鸢画下来，他要求删掉，白鸢拒绝。全章唯一一次他成为被记录的人。**强烈建议合并**。方舟T又把“最后一辆确认”标成低置信度误译，陆衡这次不走流程，手动改译并署名，既回收E16远星误译线，也是人机之间一次小小的托付。**强烈建议合并**。
- 机体/IP/爽点：缺口：合体缺一个仪式底座。补强：合体BGM的底鼓直接用五车引擎点火声依次叠上去（对应E16车灯依次亮起），金章驳回的红章“哐”一声砸下做梗点定帧；头部灯由五车共同点亮的处理保留。**可选合并**。

## 章内连续性问题

1. 兜灯全章零出场，唐胶单口撑满四话喜剧位：搭档结构失衡，至少E17补一场。
2. 陆衡E16比对磨损后消失，E19才回工程位；E17讲接口本是他的主场，缺一句在场。
3. 重涂三车E16成为“支援候选/游离”后三话再无下文；红焰进E17外壳展厅是最顺的回收位（它就是“更快更帅”的化身，面对外壳诱惑最有戏）。
4. 赤罡E18空降承担成长弧，前两话零铺垫。
5. E18的热度/安全双槽到E19消失，但E19仍有观众留言弹出：观众系统应贯穿到章末。
6. E16远星误译+方舟T低置信度标注埋下后，章内无回收（建议按E19方案在陆衡处收）。
7. E16与E19两次把“最后一辆确认”当情绪顶点，需要变奏：E16是旧屏替车说，E19应改为五车自己应答，否则装置贬值。
8. E16、E17连续两话都以“纪存保存证物”收尾，收束手法重复，E17可改为白鸢留半张海报收尾。
9. 七海线（缝隙→例外→责任人→审计路径）梯度完整，但纪存全章无一次对等回应，情感账单单边累积。
10. 小满/阿澄只在E18出现，E16医疗车维修单写着“不要让孩子看见”：两处儿童意象可用一句台词轻连，不必加戏。

## Codex合并优先级

1. E16：五车开口：旧货柜、医疗车、红焰的路线之争台词（强烈建议合并）
2. E19：索引“完全版镜像巨神”预演亮相并撤离为目录翼种子（强烈建议合并，注意C06衔接）
3. E17：推荐塔软Boss化+散件小车寄生机制，把菜单变战斗（强烈建议合并）
4. E17：外壳先甜后苦：一次真正的高光试装再崩（强烈建议合并）
5. E16：七海署名之争，摩擦式体谅+白鸢目击（强烈建议合并）
6. E18：兽人影完整巨大化一回合+皮套谢幕收束（强烈建议合并）
7. E19：纪存失守被白鸢记录，全章唯一裂缝（强烈建议合并）
8. E17：五车拒绝台词分声部改写（强烈建议合并）
9. E19：陆衡手动改译署名，回收远星误译线（强烈建议合并）
10. 章级：重涂三车回收进E17+赤罡前置垫场+兜灯补场（可选合并，三项可拆分执行）
