# C06 Codex合并计划 - 万机同心与拆掉完全版

## 总体判断

Fable 对 C06 的诊断有效，而且戳中了这章最容易出问题的地方：C06 的机制和主题已经很完整，但如果直接照现在结构改稿，很可能会像一组优秀的战斗规则说明，而不是一章有痛感、有对手、有主角失守、有关系拉扯的机器人动画高潮。

合并时不推翻现有章级结构。C06 仍然保留“巨大化不是放大贴图 → 伪领袖发布会 → 目录翼模块战 → 拆掉完全版”的链条，但必须把每一话的机制节点变成可拍、可玩的场面，并让索引/目录翼从 UI 和规则变成有身体、有诱惑、有反击能力的敌人。

## 强制合并

1. **C06E20 开场失败教学**
   - 先让玩家用普通战棋思路打巨大怪影，结果攻击无效，还踩碎微缩街区或误伤救援路线。
   - 陆衡的三尺度说明放在失败之后，让规则成为教训，不是开场说明书。
   - 失败损失进入本章 F 段变量，后续影响 E23 的城市场景破损和棚守巨影债务。

2. **C06E20 白鸢“丑镜头”进入战术屏**
   - 白鸢提供的不是漂亮分镜，而是一张难看的俯拍/错位镜头，正好让玩家看清三尺度关系。
   - 纪存把这张图投进全队战术屏，并保留署名。
   - 白鸢不道谢，只尴尬地移开眼睛。这是纪存/白鸢从“彼此防备”走向战术信任的一拍。

3. **C06E20 星火巨神在巨大化层的签名动作**
   - 棚守巨影挡下第一脚，但星火巨神不能完全被抢戏。
   - 加一镜：星火巨神在巨大化层显得很小，却用吊车承力臂顶住倾倒摄影灯，保护微缩城和普通机体。
   - 让它的英雄性不是“更大更帅”，而是在大尺度里干笨重活。

4. **C06E21 社勇王短暂被收编**
   - 伪领袖发布会不能只是话术战，必须造成真实单位损失。
   - 社勇王因“许可/批准”话术被改写成预购徽章，短暂灰掉或离控一到两回合。
   - 玩家要用证物和现场动作赎回它，证明伪领袖不是 UI，而是能偷走我方语义和行动权的敌人。

5. **C06E21 白鸢撤稿段去分析化**
   - 保留“她也被商品化构图诱惑过”的核心，但不要写成心理分析。
   - 改成场面：白鸢承认那张图是她画的，删了三次没删掉；纪存逼她当众删第四次。
   - 七海看见白鸢望向封存权限，把界面往纪存终端外推远一点，形成三角关系的非语言回应。

6. **C06E22 模块分层减负**
   - 八个模块不要平均审问。
   - 设为三必答：王冠广播核、尖刺背包、勇气徽章包；三可选；两个无论如何流入 E23 成为 Boss 部件。
   - 尖刺背包必须有真实救援受阻演出：担架舱被挡、倒计时差一秒，让“帅但碍事”从槽点变成战斗后果。

7. **C06E22 唐胶/兜灯斗嘴与陆衡/方舟T回收**
   - 唐胶承认尖刺背包“真帅”，兜灯用安全锁否掉，唐胶再退一步拆卡扣。
   - 陆衡在承力图红线处停一下，说这条画法是方舟T教的。只一句即可，让方舟T不在本章消失。
   - 这段同时修复唐胶/兜灯关系断档和陆衡工具人问题。

8. **C06E23 纪存一秒失手**
   - 医疗车胸灯亮起前，多声部濒临崩溃，纪存几乎按下“统一口号”快捷指令。
   - 白鸢、阿澄或终端里某个声音拦住他，让他也被“完全版/统一答案”诱惑过。
   - 这一下是纪存的私人代价，支撑“我们被诱惑过”这类后续台词。

9. **C06E23 七个谱系节点演出锚**
   - 不让七个节点只像条件表。
   - 每个节点要有 10 秒画面，例如火种残响节点是一辆慢车前灯在废墟尽头亮起，全场静一拍；责任签名节点是七海权限锁烧红但没有按下封存；等待最后一辆节点是医疗车胸灯延迟亮起。
   - 节点是演出，不是规则文本。

10. **C06E23 索引伪造证物兑现**
    - 回收 E21 的敌方学习：伪同心巨神拿出以假乱真的维修单或停顿记录，试图证明自己也有“记忆”。
    - 玩家需要用前几话获得的具体差异分辨真假。
    - 这样索引/目录翼的学习链闭合，敌人不是等到 Boss 战才突然强。

## 可选合并

1. **棚守巨影一次性支援统一为“还债退场”**
   - E20 首次挡脚是欠债启动，E23 最后一挡是还清并消散。
   - 这样修掉“一次性支援”前后矛盾，还能把漏洞改成泪点。

2. **E22 章末 30 秒静场**
   - 唐胶数拆下来的螺丝，兜灯只问“少了几颗”。
   - 不立刻解释意义，让玩家从 E22 信息洪峰里缓下来，再进 E23 大战。

3. **小满 E23 回声**
   - E21 阿澄数节拍后，E23 观众声部补小满一句不讲概念的喊声。
   - 不让儿童线只剩阿澄。

4. **伪同心巨神登场先给帅镜头**
   - 逆光、目录翼如圣像展开，必须真的好看。
   - 玩家拆它时才会感到“这东西诱惑很真”，而不是打一个已经被文本判死刑的丑怪。

## 禁止合并

1. 不把三尺度、模块战、七节点全部改成 UI 条件；C06 的主题必须由机体动作、地图损坏、救援受阻、支援灰掉来表达。
2. 不让纪存继续无伤主持整章；他必须在 E23 有一次真实失守或被诱惑。
3. 不把七海写成单纯帮忙放水；她每次例外都要有追责对象、权限代价或公开风险。
4. 不让社勇王、棚守巨影、星火巨神互相抢戏；它们各自承担不同谱系：许可/勇气、特摄巨大化、变形救援与不对称合体。
5. 不让“完全版”只成为反消费主义口号；它必须先迷人、先强、先让玩家理解为什么角色会想要它。

## 合并后预期收益

- C06 会从“规则很聪明的一章”升级为“玩家亲眼看见错误玩法、错误营销、错误模块、错误共同语言一步步长成 Boss 的章节”。
- 纪存/七海/白鸢三角关系会获得真正的互相观看和互相拦截，而不是继续靠小动作记账。
- 索引/目录翼的敌方学习链闭合，C05 的完全版镜像巨神、C06 的伪领袖和 E23 的伪同心巨神会成为同一条威胁升级线。
