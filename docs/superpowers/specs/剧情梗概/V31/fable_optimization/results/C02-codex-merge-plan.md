# C02 Fable建议的Codex合并计划

来源：`C02-fable-output.md`

## 总体判断

Fable 对 C02 的建议很可用，尤其适合处理用户此前反复指出的三类问题：台词不像人说话、人物关系缺少变化、章节虽然有机体但缺少可记忆的机器人动画瞬间。

这一轮不建议推翻 C02 正稿。C02 的主题“热爱被定价”、旧拳王把价格打出界、三话敌方升级链都成立。需要做的是局部增强：让街面有声音，让样件和旧拳王有记忆点，让七海/纪存关系不再每话同一拍，让白鸢线索不要突然掉下来。

## 强制合并项

1. `C02E01`：冷开场先给模型街街面视角，再切 B1 缺件清单，削弱“采购任务”体感。
2. `C02E01`：把旧灾变模板误套前台化为全街可见演出：价格屏从“来源保护”逐字改为“灾后物资处置”，全街价签同步跳动。
3. `C02E01`：补 2-3 条街面 NPC 生活台词，让模型街共同体被听见，而不是只被旁白描述。
4. `C02E01`：样件首动摆出旧盒绘站位构图，唐胶认出“它记得自己的盒绘”，把商品生命误认变成燃点。
5. `C02E01`：结尾回执处，唐胶看到纪存写入“禁止公开主人”，把维修箱推向纪存半格，形成第一次工具层面的认可。
6. `C02E02`：物流车关门前，透明盒里的样件把错字昵称牌贴在盒壁内侧、字朝外，具象化“通关也会丢东西”的泪点。
7. `C02E02`：将兜灯“快不是刹车许可”改成更像现场喊话的句子，例如“它没学过停！先给它个能撞的东西！”
8. `C02E02`：三色样件增加非人式“发声”：红速复读“限定”，蓝盾复读“普通版”，黑镜不出声只让倒影先动。
9. `C02E02`：在人群流向中补公文包成年人一格无台词镜头，为 E03 作证/离场补根。
10. `C02E03`：插四态牌时叠入寄售台远景灯亮、灰模头轮廓入镜，不把结算和下一问题排成四段长尾。
11. `C02E03`：主持投影改成带货主播式具体语癖，让 Boss 的恶心感从概念落到人声。
12. `C02E03`：旧拳王加入读秒铃声音签名，拍卖锤出界后观众席接数“九，十”。
13. `C02E03`：红速在折叠凳区前第一次自己刹住，回收“学会停”。
14. `C02E01/E02`：提前埋白鸢红笔痕迹或无来源修正弹幕，避免 E03 红笔拖痕空降。

## 可选合并项

1. `C02E01`：价格屏跳红前增加一次假安全，形成更明显的反转节拍。
2. `C02E01`：馆守Z掌影段补地面震感和围观者举手机又放下的反应镜头。
3. `C02E02`：把倒播和限命烧痕从第5回合移到第6回合价格屏换流时，降低信息过载。
4. `C02E02`：唐胶战后才发现兜灯把他列为共同责任人而非被监督对象，关系推进更柔和。
5. `C02E02`：限命烧痕第二次出现时，让兜灯皱眉认出“又来了”。
6. `C02E03`：七海出现一次极短裂缝：“……你小时候也有过这么一盒吗？”随即掐断并恢复流程口吻。该项收益高，但需要对照七海 canon，避免过早软化。

## 暂不采纳或需谨慎项

1. 不给公文包成年人加台词。他的沉默比解释更强，最多补无台词镜头。
2. 不给旧拳王加冠军往事或悲壮回忆。它的力量来自“只是陪孩子打一场不疼的拳”的普通性。
3. 不让灰模头、旧货柜锚件在 C02 尾声真机化或动一下。它们保持 C03/C05 入口锚件，不计入本话机体。
4. 唐胶/兜灯不要在 C02E03 进一步暧昧，当前共签和拇指停半秒已经够，过量会抢旧拳王高潮。

## 连续性债务

1. 方舟T与陆衡/方舟T线在 C02 全章缺席，后续修 C02 时至少要补一次工程频道背景露面或一句提及。
2. 舰内日常段三话均为 `pass`，C02 需要补一个短的街后回船/临时展柜日常状态，否则万机馆只像地图支援点。
3. 社勇王缺页、模型病历来源码在 C02 后两话没有回摸，需要在 E02/E03 结算或临时展柜处轻触一次。
4. 七海三话同构是需要后续连续修正的问题，不建议只靠 C02E03 一句破防解决。
5. 陆衡口吻三话零变化，后续需要他在 C02 或 C03 有一次工程判断之外的情绪反应。

## 写回本地时的注意

- 优先改 `C02E01` 的开场、街声、灾变模板前台化；这几处能明显提升章节可读性。
- `C02E02` 重点改台词和样件“发声”，不要重做玩法结构。
- `C02E03` 重点保旧拳王高潮，压缩结算长尾，把新钩子叠入画面。
- 七海破防句必须谨慎。如果合并，要写成她立刻自我收束，而不是突然温柔告白。
- 合并时同步更新制作拆分中的 ADV 演出、战斗内触发、情绪物件和关系状态。
