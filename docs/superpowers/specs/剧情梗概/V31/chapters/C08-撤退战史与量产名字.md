## 章节推进

### C08E31 空白格里有名字
- 主推进：战争博物馆把白色样机、红色路线和撤退沙盘剪得很好看，却把量产兵名字折成空白格。
- 战斗/玩法：战史馆探索 + 档案解谜 + 演习人格保护。
- 机体/单位：撤退战史守卫机、灰鸥量产G点名型、阿岚训练机/白色样机训练态。
- 关系/债务：纪存限制性公开雾生记录；七海最低权限水印进入追责；赤罡被红线诱惑但第一次看见掉队格。

### C08E32 红色路线不等人
- 主推进：红面具把红色路线变成真实强收益诱饵，玩家和赤罡都被“红色更快”拉离撤退线。
- 战斗/玩法：诱饵追击战 + 红线加速路线 + 撤退准备资源管理 + 歌声停火支援。
- 机体/单位：红面具高速机、白色试作教练机、赤罡机赤路追击态、灰鸥撤退盾阵。
- 关系/债务：莉歌声场第一次救场并被武器化采样；纪存公开追击得分样本，赤罡信任受伤；七海“证据不足”暂压莉歌风险。

### C08E33 不被歌颂的撤退
- 主推进：白缝号撤退、名单修复、能源核心和红面具击坠窗口不可全保，撤退被写成真正燃的胜利条件。
- 战斗/玩法：S级多目标撤退护送战 + 名单修复 + 放弃击坠奖励。
- 机体/单位：白缝号难民船、灰鸥量产G小队、白色试作教练机、红面具高速机、莉歌声场浮游台、直播名单无人机、破口推进拖船。
- 关系/债务：赤罡放弃击坠改打一拳天顶破口并签维修债；莉歌报出停下那一格救下的人数；纪存把修名单放进胜利条件。

### C08E34 量产机把名字补上
- 主推进：平台和索引把撤退战反剪成英雄PV，玩家要守住战果归属权，让量产机进入撤退名单。
- 战斗/玩法：反剪辑防卫 + 量产逆袭战 + 临时开馆证物保护。
- 机体/单位：灰鸥量产G点名型、英雄剪辑核、王牌残影镜像、白舰断桥支援、莉歌空白频道设备、赤罡机撤退护卫态。
- 关系/债务：赤罡把主角位让给灰鸥；阿岚把镜头切给裂盾量产机；七海把撤退名单列为公共证词而非战争商品，接 C11 白名单冲突。
