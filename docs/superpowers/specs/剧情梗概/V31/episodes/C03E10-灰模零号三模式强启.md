## 6. Draft Synopsis
### Function
C03E10是原型工房章的机器人大战化证明。前两话讨论未完成者能否被看见、能否被夜潜理解，本话必须让玩家看见它真的站上棋盘，但站得难看、危险、不完整，且每一步都要付代价。爽点不是“终于拿到新主角机”，而是“一个还不能被叫完成品的巨大机器人，在所有人承认它不完整之后，仍然救了一次场”。

### Story Flow
开场，生产层宣布灰模零号进入稳定性测试。措辞很干净：不启用武装、不承认主体、不开放外部操控，只测试承力安全。陆衡一听就变脸，因为承力井、接口门和测试塔同时开机，说明这不是保守检查，而是把灰模零号推到军工接口试验机面前。七海在通讯里要求暂停，生产层反问她：你上一话已经烧掉内部例外额度，现在还要继续为未确认样本背书吗？

灰模零号落到棋盘时，场面必须有分量。吊架松开，半身机体没有帅气落地，而是右肩先撞上承力轨，缺腿框架拖出火星。它占据3x3不规则格，胸口空白名牌在棋盘中央像一个洞。玩家不能按普通机体操作，只能切三种临时模式：半身承力模式用巨大躯体挡住封条线，线稿投影模式把白鸢的分镜线投成临时桥，接口防卫模式展开灰色护盾保护署名墙和母版仓。

军工接口试验机上场。它们不像反派怪物，更像太懂工程的捕捉工具：试验桩打肩轴，标准臂锁胸腔，测试塔每三回合生成一个“合格姿势”。完成稿诱导机则更恶心，它给灰模零号投放漂亮站姿、武装背包、动画主视觉角度。只要玩家贪爽让灰模摆出漂亮Pose，稳定值就会下跌，因为那些姿势没有承力依据。唐胶忍不住骂，这玩意儿看着像海报，站久了得把腰赔进去。

C03E09的路由组合在本话发生，不是结算说明。若上一话完整走结构线，承力模式能多挡一回合，但旧手刻名在战斗中更容易被封条盖掉；若完整走署名线，线稿模式会认出旧工友留下的辅助线，但接口防卫模式更脆；若完整走主体性线，灰模会更主动拒绝完成稿诱导，却因为缺结构图而拖行更慢。未走路线会以更尖锐的形式出现：缺署名时，灰模会把一个救援目标识别成“未授权空白”；缺结构时，它每次拖行都会在地面留下新的裂纹；缺主体性时，它会短暂接受完成稿诱导机的漂亮站姿。玩家会真实感到：上一话不是填表选择，而是这台机体今天如何受伤。

中段关系爆点在第4回合。完成稿诱导机生成一个完美主视觉，灰模零号差点被拉成标准英雄站姿。白鸢本能想让它漂亮，她的笔已经画出高肩、低镜头、逆光胸线。可她看见稳定槽暴跌，又看见纪存没有责备她，只把终端递过来。白鸢咬牙改掉那格，把一条不好看的支撑线画进战场：它让灰模膝框拖得更明显，镜头不帅，但能活。纪存当众把这条线登记为“白鸢支撑线”，不是万机馆战术修正。白鸢第一次不是替角色变好看，而是让它难看地站住。

七海的大动作发生在测试塔准备判废时。生产层宣布灰模零号稳定性不达标，按流程封存。七海没有说“系统延迟”，也没有给纪存四十秒。她直接用自己的实名权限把场景改判为“待审救援现场”：因为军工接口试验机已经造成二次风险，现场优先级从样本测试变为人员与证据救援。封存权限短暂失效，七海的上级通讯当场切进来。她没有解释私情，只说：“风险是我改判的，记录给我。”这不是小缝隙，而是她第一次公开站到生产层对面。

高潮是灰模零号用三模式救场，而不是打爆敌人。承力模式挡住倒塌母版轨，线稿模式让唐胶和兜灯撤出封条死角，接口防卫模式把署名墙残响灯护住半面。最后一击不是必杀，是灰模把完成稿诱导机推离自己的胸口。它没有完整语音，只回放上一话完整经历的两条路线：若有署名，旧手刻名浮起；若有结构，承力图亮起；若有主体，低频拒绝响彻工房。没走到的那条则以沉默回应。玩家会被迫承认，这不是完成品，但它已经不是废件。

战后，灰模零号被重新吊起。白鸢盯着自己那条难看的支撑线，忽然笑了一下，又很快收住。纪存没有把胜利写成“灰模证明自己可用”，而是写成“强启造成伤害，灰模零号暂列未确认候选，需当事人质询、结构修复、主体回应三项同时满足前不得入队”。七海的改判记录被生产层锁为内部调查。她看着纪存发来的战斗日志，低声说：“别把我写得好看。”纪存回她：“那就写准确。”白鸢在旁边看见这行字，没有说话，只把纪存和七海画在同一格的问号加深。
