## 6. Draft Synopsis
### Function
C07E27是成年关系和双驾机体的主场。它要给主角团关系升温，但不是廉价擦边。本话的成人向卖相来自身体距离、驾驶舱共感、湿掉的权限手套、低声命令和“我看见了但选择不看”的危险亲密。它同时要把环洋双驾谱系真正做成可玩关卡：两个人不是互相信任就能同步，亲密也不是完全透明。

### Story Flow
海墙破口扩大，雾岛学校的操场被潮水切成两半。旧防卫坞从海面下升起，双驾潮墙巨兵露出胸口驾驶舱。它不是漂亮的新机，而是一台为怪兽灾害造的巨兵，肩部有旧撞痕，手臂像能把海浪推回去。与此同时，怪兽骨机从海墙外侧出现。它不是活怪兽，而是灾害残骸、军方测试骨架和索引同步样本拼成的敌方巨物，撞击时会把地形格变成潮汐危险区。

玩法开始很直接：潮墙巨兵需要两名操作者分别输入左右动作。若两人方向一致，命中高；若方向矛盾，巨兵会抢方向键，动作迟滞。系统建议提高共感率，甚至弹出双炉机透明同步残响：开放彼此恐惧、私心和旧记忆，可以短期把所有输入校准。这个建议很诱人，像很多机器人作品里“互相理解就能突破”的名场面。

纪存拒绝直接100%透明。他想起C04三法城和C07拒绝出击的条件，提出“不看区域”：每名操作者可以锁定一段记忆或情绪，不允许共感读取。陆衡认为这样会降低反应速度；方舟T补一句，低带宽反而可能减少误译。七海接入临时副驾时，权限手套被海水打湿，指尖还在发抖。她贴近终端低声要求纪存别乱动，语气冷静，距离却近到白鸢从旁边看得很清楚。

第一次同步，七海短暂看见纪存旧系统称呼“0号馆守”的碎片。她可以读取更多，甚至能掌握C01以来纪存一直被残响刺痛的根源。她没有。她主动断开，并把那一段记录盖成“现场噪声不可用”。纪存看见她手背在抖，没有道谢，也没有追问，只把自己的不看区域也打开给她确认：他不会看她白名单内审最深的那一层。这不是甜言蜜语，却比任何暧昧台词都更危险。

白鸢的伤口因此被推上来。她看见七海替纪存遮记录，误以为两人已经拥有她插不进去的秘密。幸福分镜路线里的控制欲在这里变成更尖的嫉妒：她不是单纯想恋爱，而是害怕自己连角色的空白都不再有资格看见。她在分镜本上画出两个驾驶舱格子，又把中间撕开，留下明显的裂痕。纪存没有立刻安慰，这让关系更痛也更真实。

中盘转折是唐胶和兜灯被双驾接口塔误配。两人一边吵安全距离，一边同步率高得离谱，系统评价“争吵稳定”。笑点之后，唐胶反而给出关键建议：两个人都抢方向键，不如一个看前轮，一个看维修口。兜灯补成规则：谁看见危险，谁有权喊停。玩家据此把潮墙巨兵的左右输入改成前进/止损两套职责，而不是同一个方向键。

高潮，怪兽骨机冲撞海墙。追求满同步路线可以打出华丽反击，但会公开双方创伤；不看区域路线火力低，潮墙巨兵动作甚至有点难看，却能在最后一格把海墙撑住。两条方向线没有合成一条，而是互相留出缓冲。结算时，潮墙巨兵只作为临时支援，不直接入队；怪兽骨机残骸成为后续灾害商品化和军方数据的伏笔。

战后，七海摘下湿掉的权限手套，手腕有一圈红痕。白鸢看见了，想说什么又没有说。纪存把“不看区域”协议写入万机馆支援系统，代价是索引也获得了边界样本。远星低帧字幕把它误译成“两人互不理解但仍共同动作”，这句不完全错，反而成为C13粗糙译本的早期好样本。
