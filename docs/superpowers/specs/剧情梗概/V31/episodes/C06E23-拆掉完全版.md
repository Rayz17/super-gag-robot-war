## 6. Draft Synopsis
### Function
C06E23是前六章第一个真正大高潮。它要让玩家看到我们前面积累的机体、谱系、关系和玩法不是散点：星火车队、重涂三车、五色声部、社勇王许可、巨大化棚、工务三机、馆守Z、白鸢构图、七海审计、远星误译都在同一场战斗里回收。它还要把全剧内核说到动作里：共同语言不是让所有机器服从一个声音，而是让每台机器知道自己为何回应。

### Story Flow
全乐园合并。外环车道、变形展厅、五色摄影棚、地下合体井、巨大化棚、微缩城市、广播塔全部亮起，地图像一整季机器人动画的最终舞台。伪同心巨神・全挂完全版从广播塔背后站起。它不丑，不蠢，不弱，甚至很美：目录翼变成硬质背包，王冠广播核在头顶，透明特效件绕肩，巨披风保护后排，星火五车被压成统一车队胸甲，彩队声部变成统一口号，社勇王金章变成预购徽章。

第一阶段，玩家硬打核心完全无效。伪同心巨神合规评分高，面板数值漂亮，远星字幕一度把它译成“地球机器人文化完整形态”。这很可怕，因为它真的像答案。它会复制玩家此前最顺手的策略：快速护送、最佳外壳、红色抢跑、勇气许可、巨大化镜头、模块支援。玩家越按单一最优打法，它越强。

第二阶段是解放谱系节点。火种残响节点要求等待最后一辆；彩队声部节点要求五色不同任务同回合成立；社勇王许可节点要求责任签名；电磁节拍节点要求允许不同拍；五兽王冠节点要求不把兽形挂到星火身上；棚守巨影节点要求保住微缩城市证物；馆守Z支撑点要求展舰承受一次外部锁泊压力。每个节点都让一台机体回应，但没有被合成同一个声音。

白鸢完成本章关系回收。她放弃标准英雄构图，把医疗车担架舱画成胸灯，把旧货柜退到脊柱，把吊车画成承力框，把警备车画在腿部稳定器位置。画面不如伪同心巨神漂亮，但每个位置都有理由。纪存收下她的两张图：漂亮构图和正确构图。白鸢问他到底喜欢哪张，语气像调侃也像试探。纪存说两张都要，因为一张证明我们被诱惑过，一张证明我们承担了它。这个回答不油，但关系温度明显上升。

七海的七秒例外成为大动作。伪同心巨神准备压缩所有观众声部，七海可以立即封存，避免风险；她选择延迟七秒，让观众声部、远星字幕和支援审计都完成记录。七秒不是小缝隙，而是公开违背最短风险路线的选择。她在通讯里只说：“七秒，记在我名下。”纪存当场登记为开馆债，不把它写成系统延迟。白鸢看见这一幕，眼神很复杂，但她没有切掉镜头。

第三阶段，星火巨神必要合体站起。它仍然不对称，旧货柜在脊柱，医疗车胸灯，吊车承力，警备车稳腿，消防车臂甲。重涂三车分别从侧翼支援，彩队巨神残响给五色声部，社勇王金章给“勇气许可但责任自负”，电磁五虎机残响给不同拍节奏，五兽王冠不再强接而是绕开错误接口，棚守巨影挡最后一次踩踏，工务三机修出撤离路，馆守Z从万机馆外部锁泊臂撑住战场边缘。

终局支援不喊同一句。有人说等最后一辆，有人说确认路线，有人说担架舱保留，有人说许可通过但责任自负，有人说不要逃带他们绕路，有人说失败记录保留。声音不齐，却在同一回合各自回应。伪同心巨神的共同语言压缩塔过载，因为它只懂同声，不懂多声部为什么也能同时行动。

最后的破防点是医疗车胸灯。它回收C05E16维修单、C05E17保担架舱、C05E19不背炮、C06E21少了停顿四个选择。胸灯亮起时，不是最大伤害，而是让空名核心失去“救援背包”的授权。伪同心巨神解体，目录翼散成可审计模块，而不是全被毁掉。索引带走伪共同语言跨星际传播样本，远星字幕最后仍误译了一半：多声部被译成“低效合唱”。这正好把C07以后同步灾害、远星误读和全剧共同语言主题继续推进。

战后不立刻切下一章。七海第一次实体短登舰，理由不是慰问，而是“移动风险源现场复核”。她带着两个封存箱和一台审查终端，被临时安排在模型病院和零件库之间。她的箱子干净、编号整齐，旁边唐胶刚打磨完目录翼卡扣，水口粉落到箱角。七海看了一眼，写下“粉尘超标”，却没有写“立即封存”。唐胶本能想顶嘴，兜灯先把吸尘器推过去；纪存递给七海一张临时舱位卡，上面写着“复核位，不等于入队”。七海把卡翻到背面，看到纪存把她七秒例外的不同意也登记在开馆债里，只说：“这张卡的风险说明，比你们的出击计划完整。”白鸢在远处没有插话，只把七海的封存箱、唐胶的粉尘和纪存的舱位卡画进同一格，旁边仍然是一个问号。

这一小段不是撒糖，也不是支线闲聊。它让万机馆像有人住、有东西堆、有审查者会真的踩进粉尘里的船；也让七海从“远程权限”变成会被人看见、会被误会、会把小物件分成报告内外的成熟角色。她没有把唐胶随手塞在封存箱缝里的半截白色水口写进报告，理由不是心软，而是它没有风险，也没有必要被所有东西都变成证据。

章末，星火巨神成为主线支援单位，不是常驻全场主角机；重涂三车进入驻馆支援池；彩队、电磁、五兽、棚守保留隐藏谱系和EX/Cut-in条件；社勇王援护升级但仍需许可；C05-C06乐园成为万机馆第一个多谱系大型开馆点。万机馆外部锁泊臂新增星火泊位，玩家终于能感觉参战规模在扩张。下一章，伪同心样本反噬到同步/双驾层面：如果所有声音被迫同声，驾驶舱里的两个人会发生什么？
