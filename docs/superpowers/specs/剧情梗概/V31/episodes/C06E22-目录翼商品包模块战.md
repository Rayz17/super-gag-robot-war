## 6. Draft Synopsis
### Function
C06E22要把机甲玩具堆配件、完全版病、透明件、尖刺、支架、背包、王冠这些槽点变成可玩的模块战。关键不是嘲笑“帅”，而是问每个帅有没有理由。没有理由的帅会压住主体，有理由的帅可以保留。

### Story Flow
目录翼展开时，天空像打开一本巨大商品册。每一页都落下一个看起来有用的模块：王冠广播核能提士气，尖刺背包火力高，透明特效诱饵能吸引攻击，展示支架炮台让单位站姿稳定，巨披风墙能保护后排，电磁节拍包强化合体节奏，兽王卡扣包提供兽形接口，勇气徽章包让支援口号更燃。玩家第一反应会是：这些都挺好。

问题在于隐藏代价。王冠广播核让旧货柜成为唯一领袖，其他四车降为附属；尖刺背包挡住医疗车担架舱；透明特效诱饵把棚守巨影当装饰；展示支架炮台让星火巨神不能移动；电磁节拍包要求所有声部同拍；兽王卡扣包把彩队/五兽谱系误接到星火吊车；勇气徽章包把社勇王许可改成预购特典。

玩法是逐件质询。陆衡看承力链，唐胶看接口，兜灯看安全锁，白鸢看剪影可读性，七海看审计条件，豪司和金章AI看勇气许可。玩家不能只拆，也可以保留模块，但必须满足条件：帮助谁、不挡谁、能维修、主体同意、可撤回。没有条件的模块被拆掉，有条件的模块转为支援。

重涂三车在这里真正回收。红焰用晚半拍领袖频道暴露王冠广播核剪辑缝；蓝巡用音爆打掉限定标签，证明蓝色不是普通版附属；黑夜镜像换位救回被尖刺背包误判的医疗车。它们不再争自己是不是正统，而是用自己被误认的经历反证目录翼正在误认别人。

小勇机训练壳也有泪点。它被散件小车撞歪Pose，训练灯摇摇晃晃，却仍把金色许可灯照到被巨背包遮住的维修口。豪司这次没有喊最大声，而是小声说许可不是让大家都更帅，是让大家还修得回来。社勇王金章短暂亮起，给出一次“拆模块也算勇气”的Cut-in。

七海和纪存的关系变得更像危险共犯。七海负责把每个可保留条件写进审计，不再只是记录违规；纪存负责在战场上把这些条件公开。白鸢看见七海不是简单放水，而是把自己放进证据里。她没有吃醋式爆发，只在分镜里把三个人画成围着同一个错误商品册拆线的人，线条很近，危险感比直接告白更强。

高潮时，目录翼核心不可击破。玩家必须处理至少七个模块，让商品册失去“完全版必需”的逻辑。未处理的模块不会消失，而是飞向广播塔背后，组成下一话伪同心巨神的身体。索引获得模块身体样本，证明它已经学会把每个理由做成可购买部件。C06E23进入拆掉完全版。

模块战的分支要在界面上很清楚：拆掉模块会降低C06E23 Boss部件，但也失去一次临时火力；正名模块会保留支援，却要求对应证物和角色行动，例如王冠广播核必须交出五色声部记录，尖刺背包必须让医疗车确认不挡担架舱，展示支架炮台必须证明不会限制移动。这个设计能让玩家感到“帅不是原罪，没理由才是原罪”，也让后续终战的伪同心巨神因玩家选择而改变外形。

章末还要把队伍状态压紧：每拆一件模块，万机馆就少一个短期火力；每保留一件模块，七海的审计表就多一条风险，白鸢的构图就多一条限制，陆衡的承力图就多一处红线。这样C06E23不是凭空大Boss，而是玩家亲手留下的选择反噬。
