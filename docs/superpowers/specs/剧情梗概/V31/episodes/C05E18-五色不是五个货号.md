## 6. Draft Synopsis
### Function
C05E18负责把战队/特摄文化放入星火章，但不能把它并入星火车队。五色摄影棚是另一套谱系：五色队员、五色兽机和彩队巨神代表群众喊名、队形、巨大化和舞台感。星火车队在本话是旁观/支援共鸣，不变成五色战队。

### Story Flow
五色摄影棚像一座保存不完整的特摄拍摄现场。红、蓝、黄、白、黑五条站位轨从地面升起，纸板城市背后是兽机剖面轨和巨大化闸门。旧报幕词说明每种颜色不是价格档位，而是任务：红色确认路线，蓝色水域救援，黄色重物搬运，白色医疗撤离，黑色夜间警戒。导播热度屏却把它们改成五个价格档位，红色最高，黑色限定，白色稀有，黄色普通。

赤罡一踩上红色轨，低机位镜头、冲刺Buff和热血BGM全开。他很爽，也知道自己很爽。问题是如果他抢跑，其他颜色会被判为附属，观众频道会只记得红色。纪存没有训他，而是把任务说明放到他面前：红色先看路，不是先抢镜头。赤罡不服，直到半身巨大化兽人影从纸板城市后方升起，一只手臂横跨数格，把黄色替补站位卡压在脚下。

半身巨大化兽人影像预算不足的单元怪，只巨大化上半身，下半身还是皮套拖在轨道上。它不是纯敌人，而是观众声浪、导播热度、未发售兽机和巨大化闸门残响混成的东西。它越在镜头中心越大，离开镜头又露出拉链和补线。玩家要保护五色站位卡、观众频道和彩队剖面轨，同时控制热度/安全双槽。

小满和阿澄只在安全观众频道出现。他们喊名会增加声浪，也可能喂大巨大化兽人影。纪存把喊名登记为见证行为，而不是热度资源；七海要求关闭观众频道，因为儿童声音被采样风险太高。纪存提出安全频道过滤和延迟审查，七海同意，但把自己列入责任人。她不是卖萌式让步，而是明知道这条记录以后会咬她，仍然承认观众不是噪声。

彩队巨神和五色兽机残影在本话只做一次可见Cut-in。玩家守住五条轨后，五只兽机轮廓从剖面轨上掠过，彩队巨神轮廓在纸板城市后方站起一秒。它不入队，不可操作，但不是“影子装饰”：它用一次站位修正把半身巨大化兽人影从观众频道推回摄影棚轨道，让玩家明确这是未来隐藏谱系。

泪点来自黄色替补站位卡。卡背写着“今天替补也算正式队员，别让孩子看出少了人”。赤罡看到后，终于从红色直冲位退到黄色旁边，帮替补卡挡下兽人影手臂。他不是变温柔，而是理解战队爽点不是所有人围着红色转，是每个颜色有自己必须站住的位置。

结尾，五色棚恢复短暂秩序。导播热度屏没有被摧毁，只被锁进可审计状态；索引带走观众声浪样本，并把巨大化机制与C05前两话的同模/外壳样本连起来。地下合体井传来巨大的机械锁声，社勇王金章远程亮起，豪司已经在通讯里把“合体许可”四个字憋到脸红。C05E19进入勇气审批驳回豪华合体。

战后小结不做温情收尾，而是让玩家看到五色谱系的独立奖励：若五条轨都被保住，彩队巨神残响会进入隐藏谱系索引；若只保红色，赤罡获得短期冲刺支援，但彩队声部在C06更容易被伪同心压成单声部；若观众频道被关闭，安全值提升，但阿澄听出停顿的泪点会在C06E21缺席。这样五色不是一次舞台梗，而是后续巨大化和全员支援的声部根。
