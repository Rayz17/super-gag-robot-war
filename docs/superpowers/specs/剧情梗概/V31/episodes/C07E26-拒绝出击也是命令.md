## 6. Draft Synopsis
### Function
C07E26是心墙路线的关键话。它要修正一个常见机器人动画爽点：大人对少年喊“不要逃”，观众为出击燃起来，但少年有时不是怯懦，而是被所有出口堵死。本话不反热血，而是让玩家亲手证明：先呼吸、先拒绝、先确认，也可以保护人。

### Story Flow
警报后半，心墙零式白色舱门打开。雾生站在舱前，没有进去。父令广播塔从学校旧指挥室升起，不断播放“驾驶员请进入位置”“你的恐惧会危及全岛”“同步稳定后会安全”。这些话都不邪恶，甚至很像正确的安全提示。拘束器执行机沿轨道滑向心墙零式，准备把舱门固定到出击角度，冷却针车・心墙型则瞄准雾生后颈的同步贴片。

如果玩家按常规出击，心墙零式会获得高防御与强援护，短期能把海墙缺口补上；但同步槽会直升，雾生偏位照片会从道具栏灰掉，C07E30正确牺牲锁增强。正式路线要求玩家反过来打：拆拘束器，关掉父令广播塔，调低冷却针输出，同时让心墙零式保持不出机库的拒绝出击态。它不前进，却展开白色心墙，保护撤离通道和机库门口的学生机。

雾生的台词不能写成神圣宣言。他只是说：“我不是不想保护大家。我是想知道，我能不能先怕一下。”真昼在后面接了一句：“你怕一下，我帮你看海墙。”这个小小的生活互助，比任何热血口号都更扎。白鸢听见后，分镜本自动生成雾生坐进驾驶舱、流泪出击的漂亮分镜。纪存伸手按住分镜本边缘，动作不重，但白鸢能感觉到他在拦她。她低声问：“那你会不会也把我留在门外？”纪存没有用道理堵她，只说：“如果你说先别让我画，我也得听。”

七海的动作是本话制度高点。延迟出击在雾岛协议里等同战术违抗，她可以让纪存背锅；她没有。她把“拒绝出击态”改成待审有效命令，条件是现场有替代防线、二次确认、损伤上限和责任人。她的声音很稳，但终端显示她的权限层被扣到低位。纪存公开读出这条改判，不把它写成系统延迟。白鸢看见七海不是抢走纪存，而是在把自己放进更危险的位置，关系误会开始变复杂。

中盘，父令广播塔开始模仿班主任潮的声音，催雾生“不要让大家等你”。班主任潮冲进通讯，第一次承认自己有时也用正确的话逼过学生。他没有道歉长篇，只说：“这句不用听我的，听现场。”这让拘束器执行机短暂停滞，玩家可以拆掉主锁。唐胶吐槽父令广播塔比家长群还会催作业，兜灯立刻补一句催作业也要确认是不是本人发的，笑点没有破坏压力，反而让命令权问题落地。

高潮时，心墙零式仍未出击。海墙外敌群逼近，心墙在机库门前扩成透明白光，把撤离学生、未出击驾驶员和维修轨道都包进去。玩家第一次以“不动”赢下一段战斗。通关后，系统不写未出击失败，而写“拒绝出击态有效”。雾生没有成为英雄，也没有被保护成奖杯；他只是把偏位照片重新塞进口袋，说等下如果我自己按按钮，那是下一次的事。

战后，索引记录了一条危险样本：拒绝也能被制度化。它开始生成“更温柔的拒绝模板”，后续可能把拒绝权也清噪成控制。七海降权，纪存得到一个新指挥原则：有些命令不是让人动，而是允许他暂时不动。C07E30若读取本路线，雾生错拍启动时可以先停半拍；若没完成，本章拒绝权会在终局被同步塔伪造成“你已经拒绝过了，现在该服从”。
