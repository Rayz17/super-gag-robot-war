## 6. Draft Synopsis
### Function
C06E20要把“巨大化”从数值放大改成真正的玩法体验。巨大化不是敌人血条变长，而是每一步都会踩到微缩城市，每个镜头都会改变怪影大小，每个后台机关都会决定哪些机体能救人。它也要把C05留下的五色声浪、勇者许可、星火巨神、豪华配件债全部拉回同一张地图。

### Story Flow
特摄摄影棚亮起时，整个乐园忽然有了旧电视的质感。微缩城市铺在地上，爆破点插着小旗，皮套库挂满修补过的怪兽身体，高处摄影灯像太阳。星火巨神雏形刚进入场地，索引就把观众惊呼、五色喊名、勇者许可和商品热度误读成巨大化条件。半身兽人影从皮套库爬出，先是两米，然后六米，最后在镜头中心胀成六十米怪影。

陆衡把战场拆成三层。后台层由角色操作摄影灯、喷烟机和疏散门；机体层由星火巨神、馆守Z远程支援、社勇王援护和彩队巨神残响保护微缩城市；巨大化层是怪影脚步、手臂和镜头边界。玩家每次移动摄影灯，怪影大小和可攻击部位都会改变。离开镜头，它露出拉链和补线；进到镜头中心，它又变成真正能踩碎城市的六十米灾害。

棚守巨影登场。它不是完整机体，只是一套旧棚内守护系统留下的巨影投射，只有在镜头帧内能实体化一次。它挡住兽人影第一脚时，玩家会看到一只没有细节的英雄影子压住纸板城市，影子边缘还在抖。燃点在这里不是完美英雄降临，而是一个旧影像系统用尽所有光线挡了一次踩踏。

白鸢主动放弃漂亮构图。她本来可以给星火巨神一个仰拍镜头，让它看起来像救世主，但那会让兽人影在镜头中心继续变大。她改用丑陋的俯视安全镜头，把怪影拉到边缘，星火巨神看起来小了很多，却能救下两条街。纪存把她的构图投成战场视野参考，承认“不好看的镜头”也是战术。

七海要求关闭摄影灯，这在流程上正确，能立刻止损，但会同时熄灭棚守巨影和彩队残响，微缩城市会失去保护。纪存提出三尺度管制：保留最低帧率、限制镜头中心、后台疏散优先。七海同意并远程担责，等于她又一次没有简单封死风险，而是把风险变成可审计行动。

高潮时，星火巨神、馆守Z和棚守巨影在不同尺度同时撑住同一条街。星火巨神挡碎片，馆守Z远程压住摄影棚屋架，棚守巨影挡怪影脚。怪兽皮套内侧字条被白鸢扫到：“这一脚踩轻点，城还要拍下一集。”它提醒玩家：就算是微缩城市，也有人为了让它看起来真实而小心过。通关后，巨大化兽人影缩回残响尺寸，但索引已经得到巨大奇观样本。广播塔亮起，伪领袖发布会开始。

通关后的制作层结算要让巨大化真正留下系统痕迹。后台机关会解锁“镜头帧”地形标签，微缩城市证物会进入万机馆可移动展柜，棚守巨影只获得一次性支援债而不是入队资格。如果玩家为了输出牺牲微缩城市，C06E21发布会会把它剪成“为了更大英雄牺牲布景”的话术；如果玩家保住证物，发布会就不得不把那张旧字条也放进商品包，反而暴露它不懂拍摄现场的人情。这些都把巨大化从演出变成后续Boss的材料来源。

同时，本话会给玩家一个很直观的操作记忆：后台角色明明没有上机体棋盘，却能通过灯、烟、门和镜头改变六十米怪影的尺寸。这能为后续“展舰内角色支援点”做前置说明，也让非驾驶员角色在机战关里不是旁白，而是改变战局的人。
