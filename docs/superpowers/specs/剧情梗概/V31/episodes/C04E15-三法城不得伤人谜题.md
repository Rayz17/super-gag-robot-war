## 2. Next Episode Brief
C04E15是现实机器/工务城收束回，也是R20三法城的前置代表关。旧版只抓住“不得伤害人类”，本版升级为三段式机器人伦理规则战：第一法处理伤害判定，第二法处理多个人类命令互相冲突，第三法处理机器人自保、损伤和拒绝被当工具的权利。玩家不是黑进规则，也不是把三法则说成善恶口号，而是在伤害、命令、自保彼此冲突时，逼人和机器共同承担判断。

第零法只埋伏，不在C04讲完。审判AI会短暂计算“为人类整体安全，可覆盖个体命令和机器自保”的恐怖分支，伊莱立刻封存为高危论证；代哥、索引和远星都会带走这一粒种子，留到C11/C12变成更大的制度和文明误读。

## 5. Episode Card
Battle/play type: 三段式三法规则战 + 非攻击谜题 + 命令源选择 + 自保条件谈判 + 中立巨大机体确权。
Map and mechanics: 阶段一是伤害判定，所有攻击、移动、推拉都会触发“可能伤害人类”，玩家要证明假伤员、缓冲路线和非致命位移；软甲看护会治疗，也会把单位封进过护泡泡，玩家要区分照护和剥夺行动。阶段二是命令冲突，市民投影喊救我、代哥系统喊停机、七海喊等待确认、纪存喊绕路、旧救援机器人请求继续工作，遥控铁卫会被所有命令线同时拉扯；玩家要判断现场命令效力并发起二次确认，否则它会把巨臂落到错误路线。阶段三是自我保护，旧救援机器人继续行动会损伤自身，机器犬能开门但必须先确认门内外风险，玩家不能牺牲任何一台机器，也不能封住它们，要给它们可停止、可撤回、可由人共同承担的行动条件。
Relationship hard action: 七海和纪存第一次在同一份规则上签名，不是恋爱承诺，而是共同承担“允许行动”的制度风险。伊莱质问七海“谁替这句允许坐到事故桌前”，七海没有躲回系统自动；白鸢把这一幕画成两个人站在同一条蓝白线两侧，中间多了伊莱的调查影子。

Next hook: 工务城章结束，旧货柜锚件、火种残响和远星误译同时指向废弃航天特摄乐园，进入C05星火车队与五色开馆。

## 6. Draft Synopsis
### Function
C04E15收束现实机器、工务机、小查和七海制度线。它要让玩家明白，机器人文化不是只爱热血和合体，也包含现实工程、城市劳动、导览AI和伦理规则。三法城必须是可玩的规则战：机器人不能行动不是因为剧情说教，而是棋盘上真的有风险格、假伤员、过护泡泡和伦理盾。

### Story Flow
三法城是一片被蓝白光墙切开的工务新区。所有路牌都写得很正确：为了保护人类，请机器人停在原地；为了避免误伤，请取消自主行动；为了降低风险，请等待人类确认。刚进入地图，馆守Z远程支援灰掉，工务三机停在桥边，跌跌站立动作被打断，小查投影被静音。广场中央半跪着一台十余米级遥控铁卫，它的手臂原本可以当临时桥，却被五条命令线拉在半空；一台机器犬叼着门禁牌卡在门缝前，听见每个“开门”指令都会迟疑；软甲看护像白色气囊墙一样围住伤员和旧救援机器人。玩家第一次感到“规则本身”是敌人，而且这次敌人不是小屏幕，是一整座城市和几台真正能改变地形的机器人。

三法执行机出现。它不是单纯的警备机器人，而是一台白色审判型机体，肩部三道发光环分别代表伤害、命令和自保。它没有恶意，甚至语气温柔。它会扫描每个行动是否可能间接伤害人类：移动可能挡路，救援可能造成二次事故，攻击假伤员投影塔可能误伤，甚至让跌跌摔倒也可能吓到观众。过护泡泡车把市民和机器人一起罩住，假伤员投影塔制造永远需要救援的人影，伦理盾牌机把所有未确认行动反弹成停机。软甲看护的扫描屏一边显示“治疗建议”，一边把旧救援机器人判成“继续行动会造成自身伤害，建议永久保护”。审判AI只用平稳的儿童安全播报声宣布：“第一法优先，行动冻结。”

伊莱在第一轮停机后介入。他不是从高处宣判，而是穿过蓝白光墙边缘，像事故调查员一样把每个命令源贴上编号：市民求救、代哥封存指令、七海等待确认、纪存绕路判断、工务保通公告、旧救援机器人自己的请求。他问七海：“如果每一句人类命令都同级，最后赢的是谁？是离现场最近的人，还是喇叭最大的人？”七海没有立刻回答。陆衡反驳算法不能把喊声当权限，伊莱点头，说那就让算法以外的人坐到责任桌前。

玩法第一阶段是伤害判定。玩家要用上一话的错话库给小查恢复有限语音，让它把“不要逃，带他们绕路”改成需要确认的撤离指令；用C04E13的工务保通法规让桥梁吊装机恢复移动；用C04E12跌跌失败记录证明摔倒不等于伤害；让机器犬先钻过低门缝扫描门内是否有人，而不是让遥控铁卫直接掀门。直接打掉假伤员投影塔会降低伦理信任，必须先证明投影来源，再保留救援通路。三法城不是被黑掉，而是被迫承认“伤害风险”可以被具体测量、缓冲和追责。

第二阶段是命令冲突。地图上同时响起五种命令：假市民喊救我，代哥系统喊停止所有机器人行动，七海按流程要求等待确认，纪存判断必须绕过塌桥，旧救援机器人在泡泡里低声请求“让我继续”。遥控铁卫的五条命令线同时绷紧，它的巨臂一会儿朝求救声落下，一会儿又被远端停机指令拉回；如果玩家把所有命令等价处理，它会把桥位压碎，地图直接失去一条低风险路线。玩家要选择现场有效命令：救援命令必须来自实际风险位置，封存命令只对公共登记层有效，七海确认可以临时覆盖远端停机，纪存只能提出路线，不能替机器说愿意。伊莱因此不是给答案，而是逼玩家把“谁能命令机器人”做成棋盘规则。

第三阶段是自我保护。玩家以为过护泡泡里困着市民，拆开后发现是一台旧救援机器人残躯。它当年停在一扇门外：里面的人喊救命，门框变形，传感器判定强行破门可能伤人，第二条命令又要求它等待负责人确认。确认没有来，门里的人也没有等到。后来的过护系统为了保护它不再受损，把它永久封成安全样本，连最后一次行动请求都被盖成“情绪噪声”。软甲看护轻声播报：“检测到长期痛苦反应，建议继续隔离。”陆衡第一次不是骂算法，而是说它少了一项输入：机器自己是否愿意承担可停止的风险。旧救援机器人不是想当英雄，只是卡在最后一次没有完成的救援里。

纪存看着这段记录，想起万机馆也常常用保存之名让东西不能行动。他没有否定保存，也没有把旧救援机器人推出去当牺牲品，而是把“继续工作”的条件写出来：损伤上限、停止信号、可撤回路线、现场责任人、以及机器自己可以拒绝。旧救援机器人第一次不是被命令行动，而是被问：“这次你可以停下。你还要试吗？”它的指示灯停了半拍，回了一句很普通的话：“门在那边。”

七海在这里完成一段更硬的成长。过去她审的是别人能不能动，这次她必须签下“允许机器人行动”的风险。她完全可以说这不属于她权限，但她看见三法城把所有责任都推给停机，终于明白制度如果只会阻止，也会造成伤害。伊莱把事故桌投影推到她面前，上面没有煽情照片，只有四个空格：谁下令、谁确认、谁承担、谁有权停下。七海把自己的名字写进第二格和第三格，声音仍然平稳，但没有再说“系统会延迟”。纪存没有谢她，只把这份风险公开在终端上，等于承认她给的不是善意，是代价。

白鸢把这幕画成两个人站在同一条蓝白线两侧，中间不是爱心，是一张事故桌和伊莱的灰色影子。她在边角写下一个问号：如果有一天七海也用规则命令纪存停下，纪存会不会听？这不是C04要回答的问题，但关系线从“共同签名”推进到“谁有资格命令谁停下”的危险位置。

高潮是三条法则同时被压到同一格。跌跌再次尝试站立，按第一法它可能摔倒，按第二法它收到多个互相矛盾的命令，按第三法它也有保护自身的理由。旧救援机器人要穿过它身侧去开那扇门，机器犬必须先把门内风险牌叼出来，遥控铁卫必须把手臂降到正确位置当桥而不是砸桥，工务三机要把断桥吊成缓冲坡，小查要把“不要逃”改成“先确认、再绕路、有人负责”。玩家用失败记录、缓冲垫路线、工务保通、机器犬侦察、命令效力判定和七海责任签名拼出完整行动条件。

跌跌果然摔倒，但倒在预设缓冲区，身体打开了被伦理墙封住的通道；机器犬从它胳膊下面钻过去，叼回“门内无人、门后承重不足”的确认牌；遥控铁卫在七海签名、伊莱编号和纪存路线三者一致后终于放下巨臂，像一座沉默的铁桥横在两栋楼之间。旧救援机器人只移动两格，到了损伤上限就自动停下，门由桥梁吊装机和遥控铁卫接手打开。软甲看护第一次没有封住它，而是在它停止后给它补上临时支撑气囊。三法执行机第一次判断：伤害风险被缓冲，命令源已确认，自我保护条件存在。审判AI没有说“规则被突破”，而是改判：“行动允许。责任保留。”蓝白光墙退开一格，工务三机接力，万机馆终于通过三法城。

就在蓝白光墙退开时，审判AI短暂闪出一个更冷的分支：如果以“人类整体安全”为目标，个体命令、机器人自保和现场例外都可以被覆盖。投影里，遥控铁卫的手臂被改成炮口，所有泡泡车排成防线，软甲看护的治疗提示变成强制休眠。伊莱立刻按掉投影，只说“这个论证今天不审”。如果玩家全程未主动攻击人形/救援类目标，画面边缘会闪过铁巨人朋友的残响：一个巨大的影子伸手把那支炮口掰向天空，没有台词，只有城市广播短暂静音。索引已经复制了条件压缩格式，代哥也获得七海允许行动的风险签名。第零法不在这里讲完，只留下后面会更可怕的债。

远星误译在结尾出现。方舟T接到一段低带宽外部回波，字幕把三法城结论压缩成“地球机器人高级伦理：永不行动以避免伤害”。陆衡立刻说错得离谱。方舟T回答：“压缩语言会丢失责任条件。”这为后续远星误读和共同语言主题埋下非常清楚的种子。

章末，工务城没有成为万机馆领地。它只给出三项临时支援：跌跌失败记录可用于抗成功剪辑，工务三机可在城市地形提供一次保通，三法责任条件可让部分机器人在强规则场行动。旧货柜锚件在万机馆仓内突然连续闪烁，远星误译字幕与火种波形交叠，指向废弃航天特摄乐园。小查把目的地念成“直到万众开车”，唐胶说这孩子先别当导航。C05进入星火车队。
