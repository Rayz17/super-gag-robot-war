# V31 全剧逐话厚版梗概运行

状态：进行中。  
目标：按严格 Episode Loop Orchestrator 从 C01E01 开始重写 15 章 60 话厚版剧情梗概。  
方式：一话一 packet；章节只在本章所有 packet 通过后组装；每章后做 prefix review；C01-C03 后做 opening arc review。  
母稿来源：V30 packet、V25 厚版章节、V22.10 A5 厚度基准、V26/V29 机体/IP重挂载与素材池。  
严格模式：`--strict-creative-gates`；早期 packet 保留 `--strict-writer-room` 记录。本 session 无真实子智能体工具可调用，C03E09-C06E23 使用 `internal_writer_room` 按17职能清单自审，不伪造外部 subagent ID。  

## 本轮防衰减约束

- 不把模型盒、展签、留言、维修单当作参战机体。
- 每话至少 1 台、默认 2 台真实首次出现的 IP 映射机体/单位/敌方模块/场景巨机。
- 非过场话至少 1 个参战包级承重单位。
- 名台词与名场面必须进场面和玩法，不可重复消耗。
- 纪存、七海、白鸢等主角团不能只做小指标动作，必须有代价、状态变化和可回收的关系事件。
- 第一话必须先证明万机馆真的有“万机”厚度。
- C09-C15以后牺牲和结局只记录语法与资格，不提前定稿；七海/白鸢/纪存的牺牲必须保全全队或世界局势，并侧面成全另一人，不能只是人设或体制结算。
- V31后续分支采用两层结构：普通变量分支继续写入`branch_variables.tsv`，关键章节使用`chapter_route_matrix.tsv`记录章内路由池；机战式遗憾补完、隐藏条件、失败尊严和what-if素材使用必须写入`what_if_usage_ledger.tsv`。
