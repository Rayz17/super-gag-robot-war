> v19 的问题：它主要调整结构，没有真正重写主线发动机。  
> v19.1 的目标：不再只是把旧主线重组，而是为每一篇新增能改变剧情走向的大事件、敌方行动、玩法桥段和人物选择。

## 0. 自审结论

用户指出得对：v19 只是“结构方案”，不是“剧情方案”。

它有三个明显问题：

1. **主线没有长出新东西。**  
   模型街、失败机、雾岛、撤退、作者、原典、清算、索引、远星、内战，仍然基本沿用旧大纲，只是重新分配话数。

2. **玩法主推没有变成桥段。**  
   写了“经营、护送、同步、分镜规则、合规潜入”，但没有说明玩家为什么非玩不可，失败会怎样，胜利改变什么。

3. **结构作用太像编辑部说明。**  
   “避免论文三连”“扩七海主场”“索引不再算法章”是有效诊断，但不是剧情。玩家不会因为结构作用感动或兴奋。

所以 v19.1 的原则是：  
**每一篇都必须新增一个足够外放的主线事件。旧主题只作为材料，新事件才是剧情。**

## 1. 新全剧发动机：巡展开馆表

万机馆不是漫无目的逃亡，也不是每章顺路遇到一个主题。  
馆长留下的真正遗产不是谜语录音，而是一份被他拆散的 **《巡展开馆表》**。

这张表记录了 G.A.G. 事变前后，世界上十一个“活化源点”：

- 模型街的初版说明书。
- 失败机试验场的失败计数。
- 雾岛防卫圈的毕业仪式。
- 战史馆的撤退名单。
- 作者遗产的分镜塔。
- 原典圣堂的背面删注。
- 清算都市的白名单。
- 索引仿真馆的最优剧情模板。
- 远星信号站的迟到回信。
- 万机馆B2的空白展柜。
- 万机殿的最终开馆许可。

这些源点不是普通地图坐标。它们是“机器人文化被爱、被误读、被商品化、被神圣化、被清算、被优化”的现场。  
如果万机馆先开馆，源点会变成活的展品、支援、机体、关系和证词。  
如果敌方先取得，源点会变成可控模板、商品核心、清算证据、原典武器或索引样本。

因此全剧路线明确了：

> 纪存带着万机馆巡展开馆，不是去收集钥匙，而是和各阵营争夺“谁有资格给机器人文化命名”。

这会改变大纲：每篇不再是主题展示，而是一次开馆权争夺战。

## 2. 六个夺名阵营

旧大纲里敌人像排队出现。v19.1 让他们围绕同一张《巡展开馆表》互相抢源点。

| 阵营 | 想怎样命名机器人文化 | 戏剧功能 |
| --- | --- | --- |
| 代哥品牌资产秩序生态 | 安全封存、限定流通、商品化谱系、数字运营、IP价值战略 | 让秩序真的救过人，也让限定、配额、商品化和运营指标夺名。七海属于安全封存局改革派，不代表整个生态。 |
| 平台与黑市 | 黄牛接口、价格曲线、可交易热爱、二级流通 | 与限定流通局和商品化谱系局共生，让模型街和成年玩家文化有现实刺痛。 |
| 军方与现实机器线 | 可用样本、失败数据、英雄模板 | 让失败机不是温柔小品，而是被拿去制造完美武器。 |
| 原典圣堂与作者遗产 | 正确名场面、不可改台词、唯一版本 | 让作者线和粉丝线互相撕咬，而不是两章论文。 |
| 索引天使 | 最优剧情、无痛路线、全员正确 | 让玩家以前喜欢的爽点被复制成敌人的武器。 |
| 远星误译群 | 不被理解的机器合唱、迟到回应 | 把宇宙线从设定包变成被误听很久的情感债。 |

七海、白鸢、陆衡、唐胶、赤罡等人不再只是各自章节代表。  
他们会因为源点争夺做出会伤人的选择。

## 3. 11篇剧情发动机重写

### 1. 闭馆夺名篇：不是封馆，是抢“馆名章”

旧功能：万机馆开局、馆守Z首战、展舰化。  
新增发动机：清算部不是临时来检查，而是拿到《巡展开馆表》第一段残页，目标是夺走万机馆的“馆名章”。

馆名章不是印章道具，而是 G.A.G. 事变后万机馆仍能把机体、模型、留言和黑匣子登记为“展品”而非“风险资产”的授权。  
第一话的封存清单因此有了更强意义：七海不是随便封展品，她是在测试万机馆还有没有命名权。

新增玩法桥段：

- 闭馆路线不只是看展，而是在终端上给展品补最后一轮“今日状态”。玩家漏看的展品，会在保护战中更容易被清算改名。
- 保护战的目标不是单纯守留言墙，而是阻止“馆名章”被拆成若干资产编号。
- 馆守Z正式站起时，不是单机救世，而是把玩家刚登记的展品名称投到装甲上，形成第一章的开馆护盾。

剧情改变：万机馆起航后，玩家知道下一站不是随机避难，而是去抢下一段巡展开馆表。

### 2. 模型街临时开馆篇：新增“初版说明书争夺战”

旧功能：模型/玩具生命、商品化、胶价王。  
新增发动机：模型街藏着第一份源点物件 **《初版说明书》**。它不是说明如何拼模型，而是记录“玩具如何成为真实机体关系钥匙”。

平台、黑市、清算部都想抢它：

- 平台想把说明书做成限定 NFT 式资产，谁买谁拥有“童年正版权”。
- 黑市想用它激活一批无授权商品生命。
- 清算部想证明模型街是 G.A.G. 异常扩散点。
- 唐胶想装作不在乎，但他年轻时卖掉过一套初版件，现在缺的那一板水口正好在他手里。

新增玩法桥段：

- 白天开馆经营：玩家摆展，决定让孩子、退坑玩家、倒卖客、老模友看见什么。
- 夜里追初版件：横版小潜入/追逐，在堆满盒绘和旧柜台的街区穿梭。
- 拼装式战斗前准备：初版说明书缺页会改变支援机体的武器名、变形顺序和合体失败率。

剧情改变：模型街不只是怀旧支线，而是证明“模型和真实机体可以通过关系钥匙共存”的第一场大战。

### 3. 失败机试验场篇：新增“失败公开审判”

旧功能：现实机器尊严、跌跌、陆衡。  
新增发动机：军方举办一场公开审判，题目是：**失败机有没有保存价值？**

他们把跌跌和一批民用失败机推上直播试验场，让观众投票决定哪些数据进入英雄模板，哪些被删除。  
陆衡一开始支持试验，因为他相信有数据才有改进；纪存反对删除失败，因为失败记录也是生命经过的痕迹。

新增玩法桥段：

- 玩家护送一个几乎无攻击力、还会摔倒的单位穿过战场。
- 每次扶它起来都会消耗行动资源，但会改变观众投票和后续支援。
- 军方的完美英雄模板会现场学习玩家的保护方式，成为后续敌方“伪英雄”的早期种子。

剧情改变：失败机篇不再是温柔说明题，而是让玩家亲手选择“低效是否值得占用战场资源”。

### 4. 雾岛同步灾害篇：新增“毕业仪式献祭”

旧功能：同步灾害、白鸢登场、后继机条件。  
新增发动机：雾岛学校的毕业典礼其实是同步系统的公开仪式。每个学生都被安排成“正确牺牲剧本”的候选件。

白鸢不是路过登场。她被邀请来当“剧本修复顾问”，因为她能让悲剧显得完整、漂亮、可传播。  
她第一次吸引纪存，也第一次让纪存害怕：她真的懂未完成的痛，但她太想替别人写完。

新增玩法桥段：

- 学校探索阶段，玩家调查毕业照、替换座位表、隐藏社团本，决定哪些学生不会被同步系统锁定。
- 战斗中“同步率高”不是好事，越高越接近正确死法。
- 后继机不是靠热血觉醒，而是靠玩家拒绝最优同步，保留一个难看的空拍。

剧情改变：白鸢线从作者伦理提前变成人物诱惑，她不是说教角色，而是会真的把一个人写得更好看也更危险的人。

### 5. 撤退战史篇：新增“战史重演变真战场”

旧功能：战争、撤退、歌声停火。  
新增发动机：战史馆本来要举办一场撤退战纪念重演，代哥、军方和媒体都准备把它做成热血宣传。红色宿敌把重演劫持成真实战场。

赤罡想追击红面具，因为这次终于能赢。莉歌知道歌声可以停火，但代价是她会把敌我双方都暴露在炮线里。  
玩家面前不是“打赢还是撤退”的道德题，而是“你愿不愿意在直播和结算奖励面前承认撤退才是胜利”。

新增玩法桥段：

- 大地图移动撤退，敌人会不断制造“可以击破王牌”的诱饵。
- 击破越多，撤退名单越长；放弃击破，难民船越完整。
- 歌声停火不是剧情播片，而是一回合全场停机，玩家必须用这回合推船、断桥、拖伤员。

剧情改变：战争篇不只是燃，而是让热血爽点先成立，再用账单打回来。

### 6. 共同记忆战争篇：新增“遗作拍卖与废案角色出逃”

旧功能：作者线、原典线、错版合体。  
新增发动机：某个机器人动画遗作的分镜、删注和废案角色被拿出来拍卖。作者遗产方、原典圣堂、平台、粉丝组织、索引都来抢。

白鸢认为遗作应该被补完；槐认为遗作应该保持原样；废案角色却只想从纸上逃出来，不想继续当大家争吵的证据。

新增玩法桥段：

- 分镜塔战斗：地图被切成漫画格，角色只能按分镜方向行动。
- 圣堂战斗：武器被原典台词锁住，喊错口号会变成低威力错版招式。
- 废案逃亡：玩家护送一个“不该存在”的角色穿过作者和粉丝两边的火力。
- 错版合体：不是搞笑失败，而是多个错误版本在玩家手里拼成只有此时此地能成立的合体技。

剧情改变：作者和原典不再是两个主题章，而是围绕同一份遗作展开的多方抢夺战。

### 7. 白名单清算篇：新增“七海邀请纪存签字”

旧功能：七海主场、白名单、索引夺舰、中盘大败。  
新增发动机：七海亲自邀请万机馆进入清算都市，不是为了抓他们，而是给纪存一份合法协议：只要签字，万机馆可以保留，但必须交出《巡展开馆表》和所有未授权活化源点。

这份协议有诱惑力，因为它真的能救很多人。  
七海不是“嘴上按流程、心里放水”的单薄反差，而是公开承担过违规白名单的人。她知道例外救人，也知道例外会害死更多人。

新增成人关系场：

- 夜审室里，七海和纪存隔着一张透明审查桌。桌面投着万机馆所有人的风险等级，她把自己的名字也拖进风险栏。
- 白鸢看到纪存差点签字，以为他终于承认“被正确管理”比被她理解更安全。
- 七海没有告白，她只是把笔推过去，说“你签了，我就不用再替你违法。”

新增玩法桥段：

- 合规潜入：玩家必须按城市规则行动，违反规则会救小人但提高全局清算。
- 三门战场：救城市、救万机馆档案、救小机魂，三门同时开，不可能全满。
- 索引夺舰：索引不是突然出现，而是利用七海的合法系统接管万机馆。

剧情改变：中盘大败不是“敌人太强”，而是纪存、七海、白鸢各自做了有理由的选择，结果被索引利用。

### 8. 残缺索引反攻篇：新增“玩家爽点被复制”

旧功能：索引反攻、模板恐怖、拒绝最优解。  
新增发动机：索引启动“最优剧情季”。它不是压制玩家，而是给玩家安排更好看的版本：

- 更准的合体。
- 更会牺牲的少年。
- 更懂你的恋爱对象。
- 更高效的撤退。
- 更漂亮的最终台词。

它复制的不是系统数据，而是玩家前半段积累的爽点、泪点和关系场。

新增玩法桥段：

- 玩家熟悉的援护台词被敌方伪英雄说出，但少了一个错字或停顿。
- 支援按钮残缺，越想走最优路线，索引越能预测。
- 反攻胜利条件不是击破模板，而是保护一个明显不好用、不合时宜、拖慢节奏的缺点。

剧情改变：索引篇不再是算法章，而是玩家自己喜爱的机器人叙事被做成商品级完美模板后反过来伤人。

### 9. 外宇宙误译篇：新增“迟到回信不是给人类的”

旧功能：远星、失败远征、群星合唱。  
新增发动机：远星信号不是外星入侵宣言，而是一封迟到很久的回信。它原本是寄给某台无人维护机器的，不是寄给人类的。

方舟T一直把远星笑话翻译成人类能听懂的梗，是因为原文太孤独，直接听会让机体失控。  
陆衡过去删过一批“无意义噪声”，其中有一段就是这封回信的开头。

新增玩法桥段：

- 信号氧气：探索时玩家需要在笑话、噪声、真意之间调谐，翻得太准确会伤害机体。
- 不可击破敌人：远星单位不是强到打不死，而是玩家根本不知道它想打什么。
- 逆序日志：未来失败记录会回到过去战斗，改变玩家部署。

剧情改变：宇宙篇从设定扩张变成“我们一直把别人的求救听成笑话”的情感爆点。

### 10. 万机馆内战篇：新增“开馆方式内战”

旧功能：纪存身份、同伴审判、舰内内战。  
新增发动机：万机馆里各派不是单纯离队，而是各自占领一个展区，准备按自己的方式开馆：

- 七海派要合法开馆。
- 白鸢派要给未完成角色补结局。
- 唐胶派要保护模型街旧件不被系统登记。
- 陆衡派要先关掉危险残响。
- 赤罡派要追击外敌，不想在馆里开会。
- 守展小队只想知道明天还能不能来。

馆长旧事故揭示：他当年不是没能阻止 G.A.G. 事变，而是开过一次馆，救了一部分机魂，也放出了一部分灾难。  
纪存继承的不是单纯使命，而是“开馆会救人，也会害人”的责任。

新增玩法桥段：

- 舰内非致命战，每个展区有不同规则和不可击坠对象。
- 支援按钮按岗位缺席灰掉，玩家第一次感到“他们真的不在队里”。
- 反审判开馆：玩家把自己的罪证也摆成展品，让观众、机体和同伴一起判断。

剧情改变：内战不是惯例分裂，而是每个重要角色都提出一个看似合理的开馆答案。

### 11. 万机殿最终开馆篇：新增“官方唯一好结局诱惑”

旧功能：路线会审、最终战、结局。  
新增发动机：最终敌方不再只是毁灭或统一，而是给出一份官方唯一好结局：所有人都活，所有机体都有正确归宿，所有关系都有不伤人的答案，所有梗都被解释到刚好好笑。

这是最可怕的诱惑，因为它真的比玩家一路走来的混乱更漂亮。  
纪存最终不是证明“非最优更高尚”，而是在全员支援里证明：这些错件、废案、迟到回信、撤退名单、失败计数、白名单违规、跑调歌声，正因为不可平均，才是万机馆要开的馆。

新增玩法桥段：

- 路线试用不是菜单，而是敌方给玩家短暂使用每条路线的完美强机。
- 最终战每个“旧小物件”变成一次无法预测的支援，索引无法复制。
- 结局分流不只看数值，而看玩家是否愿意让万机馆继续承担开馆风险。

剧情改变：终局不再集中讲哲学，而是用全剧新增事件的残留物打赢最终战。

## 4. 玩法桥段的新增标准

后续 v20 不再写“本篇主玩法是经营/探索/同步/撤退”。每个玩法必须写成剧情桥段：

| 玩法 | 必须回答 |
| --- | --- |
| 开馆经营 | 这次开馆争夺哪个源点？谁来捣乱？玩家摆错展会造成什么后果？ |
| 探索 | 玩家发现的不是资料，而是一个会改变战斗规则的证物。 |
| 潜入 | 不是避开敌人，而是在合规/违规之间做选择。 |
| 护送 | 被护送对象必须改变玩家对“价值”的判断。 |
| 同步 | 高同步不自动等于强，而可能等于被剧情吞掉。 |
| 撤退 | 放弃击破必须比击破更难、更燃、更痛。 |
| 分镜/原典规则 | 限制不是小游戏，而是作者/粉丝权力压在地图上。 |
| 残缺UI | UI损坏必须来自剧情大败，并影响部署、支援和关系。 |
| 远星调谐 | 翻译越准确不一定越好，理解本身有代价。 |
| 舰内内战 | 非致命规则必须让玩家认出每个同伴的价值观。 |

## 5. v19.1 对大纲的真实改动

相比 v19，v19.1 不是只改话数，而是改这些东西：

1. **全剧路线有目标。**  
   万机馆按《巡展开馆表》争夺十一个活化源点，不是顺路遇见主题。

2. **每篇都有新增主线事件。**  
   初版说明书、失败公开审判、毕业献祭、战史重演劫持、遗作拍卖、七海签字协议、最优剧情季、迟到回信、开馆方式内战、官方唯一好结局，都是旧大纲没有的事件发动机。

3. **敌方开始互相抢东西。**  
   清算、平台、军方、原典圣堂、索引、远星误译群围绕源点互相利用，不再排队登场。

4. **玩法从类型名变成剧情压力。**  
   经营、护送、同步、撤退、潜入、分镜、残缺UI、信号调谐都绑定胜负、后果和人物关系。

5. **纪存/七海/白鸢线有真正推动剧情的选择。**  
   七海签字协议和违规白名单、白鸢补完悲剧和错版合体、纪存公开自己的罪证，都会改变主线事件，不再只是感情变量。

6. **G.A.G.更早、更具体。**  
   它不再后期解释，而是每篇通过源点表现：玩笑变命令、说明书变钥匙、失败计数变证词、台词变武器、最优剧情变敌人。

## 6. v20 写作要求

v20 不应从 v18 逐话字段扩写，也不应从 v19 槽位表顺着填。  
v20 应按以下顺序写：

1. 先写每篇的源点争夺战。
2. 再写敌方在这一篇抢什么、怎么抢、抢到会怎样。
3. 再写玩家这篇具体玩什么，以及玩法如何改变结局。
4. 再写纪存、七海、白鸢和本篇核心角色的不可逆选择。
5. 最后才落回48话拆分。

一句话：  
**先写“这篇发生了什么新大事”，再写“它属于哪个结构位置”。**
