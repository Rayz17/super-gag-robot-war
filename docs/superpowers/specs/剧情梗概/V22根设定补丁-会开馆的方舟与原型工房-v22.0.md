# V22根设定补丁：会开馆的方舟与原型工房 v22.0

## 状态

本稿是 V22 大纲重构前的根设定补丁，级别为 `needs_review` 候选施工层。它不直接覆盖旧 v01、V20 或 V21 逐话骨架，而是先把已经在讨论中成立、会牵动后续大纲的根规则登记清楚。

本稿解决一个核心问题：如果不先改设定地基，后续大纲会继续被旧结构压扁，导致万机馆、G.A.G.、模型玩具、深潜、原型工房、代哥生态、参战机体和多玩法各说各话。

## 一句话内核

《超GAG机器人大战：万机残响》是献给热爱机器人与机战之人的一封情书，也是一段让不同路线的爱好者重新找到共同语言的旅程。

万机馆不是单纯逃亡战舰，也不是普通经营基地。它是一艘会开馆的方舟：在流亡、战斗、修复、深潜和展览中，让机器人文化的记忆、失败、错版、商品、手作、战斗和机魂被看见、被解释、被争夺，也被重新托付。

## V22相对V21的迁移理由

V21 把主线发动机升级为“开馆权战争”，这个方向成立，但仍有四个缺口：

1. 开馆的精神目标还不够清楚，容易被误写成许可证、基地经营或终局口号。
2. G.A.G.、模型玩具、深潜道具和巨大机体之间缺少硬规则，容易变成方便的魔法。
3. 作者线只强调创作和解释，缺少把幻想变成物体、商品、模具、实机的中间生产链。
4. 参战谱系和名场面投射还没有成为大纲结构前置条件，容易继续出现主线机器人密度不足。

V22 不废弃 V21，而是给 V21 的开馆权战争加上更坚固的物质链、生产链和情感内核。

## 开馆不是终点，而是行动方式

开馆不是“最后终于开门营业”。开馆是万机馆一路行动的方式：

- 到达一个地方，把当地机器人记忆临时布展。
- 接待仍然愿意相信机器人文化的人。
- 把被封存、被定价、被剪辑、被误解、被战争利用的机体和物件公开展示。
- 让某个机体、模型、残骸、错版说明书或失败记录获得证词资格。
- 在战斗中用展舰本体、支援点、展区、泊位和机魂响应保护这个公开过程。

终局要解决的不是“能不能开馆”，而是“这个世界是否承认这种杂乱、热血、幼稚、昂贵、痛苦、手作、商品化、战争化又仍然真诚的机器人热爱，有资格继续开馆”。

## G.A.G.定位

G.A.G. 不是普通火种源，也不是单纯机魂能量。它是机器人文化档案、梗、说明书、商品流通、玩家误记、影像、战斗数据、封存记录、远星误译和集体热爱互相叠加后形成的活化系统。

它能做六类事：

1. **活化**：让模型、展品、旧机体、黑匣子、错版台词或战斗数据显出机魂。
2. **误译**：把玩家的梗、商品标签、战斗口号或远星信号理解错，并真的执行。
3. **清噪**：把复杂热爱压成最优模板，形成索引式反派逻辑。
4. **开馆**：让某个记忆被公开展示、被观众理解、被记录为证词。
5. **暴走**：在绝境中接管战场，替人做出保护或胜利的决定。
6. **记债**：每次封存、改写、暴走、定价、合法化或临时开馆，都留下开馆债。

因此 G.A.G. 的重点不是“给机器人灵魂”，而是“把人类怎样爱机器人的混乱方式实体化”。它能救人，也会放大误会；它能让玩具站起来，也能让商品标签变成枷锁；它能把口号变成合体条件，也能把最优解变成清噪灾难。

## 模型、深潜道具和巨大机体的转换规则

核心公式：

**模型锚件 + 残响道具 + 实机接口 = 可安装改装模块。**

模型和玩具零件不是直接变大装到机器人身上。它们是“缩尺锚件”：保存比例、机构、玩家手作痕迹、错版装配、涂装记忆、说明书误读和模型师的手感。

深潜带回的不是普通材料，而是“残响材料/协议证据”：黑匣子碎片、旧设计协议、被删改的变形逻辑、战斗录音、远星误译信号、旧模具母版数据或事故现场的机魂噪声。

万机馆工坊负责“同构放大”：它不会凭空复制玩具，而是用真实材料、维修架、泊位接口、G.A.G.调律和原型工房知识，把缩尺结构翻译成真实机体可承受的模块。

这个规则有四个限制：

1. 必须谱系匹配。勇者合体玩具不能随便装到现实机器小机魂身上，除非剧情证明它们共享某种接口或证词。
2. 必须有实机接口。没有泊位、维修架、核心槽、驾驶舱板或武器校准器，就只能成为展陈或支援演出。
3. 必须付出资源和债务。改装会占用材料、时间、关系信任、展柜状态或开馆债。
4. 必须保留来历。模块不能只显示数值加成，要能看出它来自哪个模型、哪次深潜、哪段错误或哪位模型师的手。

## 原型工房 / 铸形工房

V22 新增一个关键中间层势力：原型工房，也可在剧情中称为铸形工房、造形师同盟、灰模工房。

它不是作者派的下属，也不是代哥或军方的附庸。它处在作者、模型街、代哥、军方和万机馆之间，负责回答一个问题：幻想如何变成能站起来、能变形、能量产、能修复、也可能被武器化的物体？

各方立场：

- 作者派说：它本来就该这样。
- 原型师说：这样站不住。
- 代哥说：这样量产不了，或者这样无法通过安全标准。
- 军方说：这样可以装武器。
- 唐胶说：坏了没人修，就不算真的被爱过。

原型工房内部至少有五类人：

1. **原型师**：把设定稿、分镜和玩具概念变成可立体化的灰模。
2. **模型师/修型师**：修复、改件、补件，保存玩家手作痕迹。
3. **模具师**：掌握母版、浇口、分件、量产误差，知道量产会牺牲什么。
4. **机构设计师**：负责关节、卡扣、变形轨道、合体锁和安全结构。
5. **军工转化派**：把玩具机构、模具母版和合体接口转译为实战模块。

原型工房的戏剧价值在于，它能同时连到四条线：作者的原意、玩家的手作、企业的量产、军方的武器化。

## 唐胶的新根系

唐胶不是“作者派”的人，而是手作派/修型师谱系的继承者。他的价值观来自维修桌、断件盒、浇口、肩轴、补土、卡扣和那些被人反复玩坏又反复修好的东西。

他的成长不应只是“怕热爱被标价”。V22 追加一层更硬的矛盾：唐胶知道手作知识可以救活玩具和机体，也知道同一套知识会被代哥变成限定母版、被军方变成武器接口、被平台变成炒价标签。

他的后续主线可以从“修模型的人”升级为“决定哪些结构可以被放大成实机、哪些结构不能交出去的人”。

## 代哥与军方的生产纠葛

代哥不是只有法务和清算。它拥有生产标准、品控、模具、限定流通、商品化谱系、安全封存、数字运营和 IP 资产战略。它确实让机器人文化进入更多人的手里，也确实通过配额、限定、再版、溢价、运营指标和资产化伤害热爱。

七海因此更成熟，也更危险。她知道腐化存在，但不能简单炸掉系统，因为系统也承载过安全、流通和公共信任。她要做的是借流程改流程，直到流程反过来追杀她。

军方关注的不是情怀，而是结构、稳定性和模块化。它会发现玩具合体卡扣、变形轨道、可换关节和模型灰模数据，其实可以成为真实兵器的接口语言。原型工房因此成为代哥、军方和万机馆共同争夺的生产源点。

## 残响深潜的修正

残响深潜不是查资料，也不是单纯剧情回放。它是探险类玩法：进入 G.A.G. 残响浓度高的封闭区域、旧工厂、模具库、拍摄基地、废弃发射场、事故展柜或远星信号井，在有限安全窗口内寻找带回物。

带回物可以是：

- 模具母版数据。
- 错版说明书残页。
- 黑匣子碎片。
- 变形协议。
- 战斗录音。
- 玩家手作记录。
- 远星误译信号。
- 未公开的生产安全批注。

这些带回物进入三类回流：开馆证词、机体改装条件、剧情证据。深潜如果不回流到至少一类，就不该进入主线或支线。

## 万机馆战斗定位

万机馆可以作为棋盘上的展舰单位存在。它不是无限机库，也不是纯背景基地。

战斗中，机体仍是主要战棋单位；主角团中的非驾驶员、维修员、策展人、模型师、档案官和孩子不需要都上棋盘。他们主要通过展舰支援点、舰内岗位、展区状态、泊位维修、开馆指令和 G.A.G.债务系统影响战场。

基础规则方向：

- 万机馆在部分关卡是大型棋盘单位，有有限移动、朝向、展开、护展、广播、维修、泊位和撤离动作。
- 舰内角色每回合按支援点行动，范围由展舰位置、展区开启状态和通讯干扰决定。
- G.A.G.暴走是少数绝境机制，可以接管战场、强制援护、临时合体、重写目标或保护观众，但必然留下开馆债。
- 展舰变形不是常规每关按钮，而是剧情节点、关卡高潮和资产重点。

## 参战谱系和名场面矩阵前置

下一版大纲不能先定 48 话或 60 话，再把参战机体往里塞。顺序要反过来：

1. 先列机器人文化谱系和玩家共同记忆。
2. 再列每类谱系至少要有的主线可见机体、敌方机体、支援或展品锚点。
3. 再判断每篇能承载多少主投射、副投射和玩法梗点。
4. 最后决定 15 篇约 60 话是否必要。

EX/隐藏关只能加厚度，不能补主线短板。玩家不打 EX，也必须感觉主线已经是一场足量的机器人大战。

## 对下一版大纲的硬要求

V22 之后重写大纲时，必须满足这些条件：

1. 每篇至少明确一种被争夺的开馆权，以及敌方通关后仍赢走什么。
2. 每篇至少有一条生产链或物质链：模型、模具、实机、黑匣子、战舰、远星信号、商品流通或军工接口。
3. 每篇至少让一个参战谱系在主线中可见，而不是只在 EX 或图鉴里出现。
4. 每个深潜节点必须带回可用于开馆、改装或证词的东西。
5. 每个模型/玩具到实机的强化，必须说明缩尺锚件、残响道具和实机接口。
6. 唐胶不能只当模型街 NPC，七海不能只当代哥通讯人，白鸢不能只当作者线工具人。
7. G.A.G.每次救场都要留下债务，每次搞笑或梗点都要可能被误译成真实后果。
8. 结构扩容要服务谱系、名场面、生产链和人物关系，不得为扩容而扩容。

## 当前不锁死的内容

以下内容先作为候选，不在本稿锁死：

- 最终主线是否为 15 篇 60 话。
- 原型工房的最终正式名称。
- 唐胶的旧导师是否作为具名角色登场。
- 星火战队与变形誓约篇的具体篇号。
- 远星、火种、战队和特摄是否合并为一篇，还是拆成两篇。
- 每个参战谱系的正式机体名单。

这些应在 V22 大纲重构阶段，根据谱系矩阵和话级容量判断。
