# V34 前三章重写运行稿

日期：2026-07-09

本目录是按 V34 Episode Loop / Pipeline 修复方案重跑的前三章。它不继承 V31/V32 的一次性批量输出方式，而是按“每话输入 -> 场面绑定 -> 可读正文 -> 制作拆分 -> 审稿 -> 账本”的链路组织。

## 目录

- `episodes/`：12 个单话包，每话都有 Episode Input Manifest、Scene Binding Matrix 和 Source Absorption Review。
- `chapters/`：前三章可读整合稿。
- `reviews/`：章节连读复审。
- `ledgers/`：V34 运行账本。

## 结构调整

本轮重写采用 V26 机器人大战化重挂载判断：

- C01 保留“闭馆夺名与展舰起航”，但增强万机馆藏品密度、馆守Z巨物感、勇者审批、火种旧货柜和移动展舰起航。
- C02 保留“模型街临时开馆”，扩为四话，并让火种变形样件、重涂限定、旧拳王机体和社勇王许可端成为真实玩法承重。
- C03 不再继续原型工房，而改为“第0次站立与工务城”。灰模/白鸢正式入场后移到 C04，以免前三章过早被原创生产链压住。C03 前台承重改为现实机器人、城市工务机甲、废城小查和三法伦理。
