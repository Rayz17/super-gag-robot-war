## 6. Draft Synopsis

C03E09 让万机馆跟着 C02 的生活机器人门牌信号来到废弃现实机器试验场。这里曾经叫“第0次站立计划”，大门外的宣传屏还在循环播放：样机们站得稳、挥手漂亮、转身流畅，字幕写着“失败已经成为过去”。屏幕外却是一片灰尘和断电训练框。跌跌就在那里，第1847次摔倒，摔倒后还认真向地面发出“接触确认失败”的提示。

本话不把跌跌写成笑料。它很笨，行动慢，摔倒后会占格挡路，起身需要地面标定、重心校准和同伴护住侧向空间。玩家不能让馆守Z或市政机把它抱过终点，也不能用热血让它硬站。成功样机列阵作为敌方/测试单位出现，动作完美、路线整齐、挥手统一；它们不打人，却会把跌跌的失败过程自动剪掉，生成“未达标样本”报告。现实机器训练框则不断把终点拉远，逼跌跌把一次站立变成宣传片式成功。

陆衡正式成为本话核心。他不反机器人，也不反热爱。他反对的是把热爱变成对实验对象的逼迫。纪存最初想保住“它努力站起来的证据”，陆衡问他：如果它现在不想站呢？这句话让纪存胸口短冷，像某个旧系统称呼从很深处浮上来。纪存没有被训得沉默，而是做出主角级改写：把战斗目标从“让跌跌成功站立”改为“让跌跌可以拒绝下一次尝试”。玩家需要建立可撤回条件：它能试，能停，能被接住，能在自损阈值前说不。

本话情绪物件是失败计数白板。白板正面写着摔倒次数，背后贴着旧工程师便签：“今天别剪掉它摔倒那段，地面也需要被记录。”成功剪辑核心试图删掉便签，只留下漂亮宣传片。玩家如果保护便签，跌跌会在第6回合自己扶住地面，站起半秒。这个镜头不能拍成夸张胜利，它只是灯抖了一下、轮足找到了平衡、陆衡没说话、纪存把失败次数加一又划掉“失败”两个字，改成“地面回应一次”。

七海没有出场，但她的逻辑仍在场。C01/C02 的流程压力让纪存知道：公开失败会带来封存风险，不公开失败又会让机器人只剩成功模板。陆衡在这里成为现实机器线的另一种七海：他也要求责任、边界和风险，只是不来自代哥，而来自工程伦理。方舟T参数柜只在陆衡终端角落短闪，显示“安慰语句可信度不足”，陆衡把它关掉，又没有删除日志。

结尾，跌跌不入队为强力机体，只解锁低规格支援候选和现实机器训练条件。索引获得“失败记录也能产生情绪强度”的样本，代哥获得现实机器实验风险材料。工务城的交通灯从远处亮起，像有人仍按旧时刻表等一台笨机器走过去。下一话进入城市工务。

制作上，跌跌必须让玩家既想保护又不想把它当道具。它摔倒时会挡住敌方，也会挡住玩家；扶它太急会造成自损，放任不管会被成功样机剪成失败样本。最佳操作不是最快，而是读懂地面、读懂它的停顿。这样“现实机器人很笨”不会变成笑料，而会变成一种和超级机器人完全不同的战斗节奏。

如果玩家选择强行完成宣传目标，战斗会更快，但跌跌后续只提供一次性数据支援；如果保留失败记录并允许它停止，它会在终局低规格支援中拥有独立声部。

这条路线也会反过来影响纪存：他第一次把“没有完成”写成合格结果，而不是暂缓处理，为C04灰模不被补完提前建立判断底座。
