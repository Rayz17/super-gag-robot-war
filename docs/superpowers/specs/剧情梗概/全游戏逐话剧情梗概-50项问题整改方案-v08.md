# 《超GAG机器人大战：万机残响》逐话梗概50项问题整改方案 v0.8

> 本文接替 v0.7，仍然不是新版逐话梗概，也不是台本。  
> v0.8 的目标不是再补一轮“每个问题举几个话号”，而是建立下一版逐话梗概重写的编剧室硬约束：  
> **每一话承受多条问题压力，每个广域问题形成跨话覆盖，每条核心人物线必须有外放事件和质变节点。**

## 为什么 v07 还不够

v07 相比 v06 已经补了话号密度，但它仍然有四个根本问题：

1. **“密集”仍然像抽样。**  
   广域问题只挑 8 到 12 个话号示范，不能证明全剧已经从结构上解决。真正重写时，某一话往往要同时承载事件驱动、机体规模、路线变量、G.A.G.证据、关系场面和梗点映射。只从问题侧列少量话号，会漏掉“每话到底背了多少压力”。

2. **人物弧线还是并列提示。**  
   纪存、七海、白鸢、陆衡、赤罡等人的落点看起来像一串小动作，没有“我先犯错，再越界，再付代价，再被公开质问，再选择承担”的上升曲线。这样第11章分裂会像结算变量，不像伤口爆开。

3. **外放型高潮不足。**  
   很多关系推进仍停在“某人理解了某事”，缺少可演出的动作：越权开门、抢责任单、取消大招确认键、当众质问、临时敌对、守某层导致另一层损坏。

4. **交织仍容易写成拼贴。**  
   A/B/C线不应只是三条摘要，而应互相拖累。比如 8-3 不是“公开真相、七海动摇、索引学习”三件事并列，而是公开越多越能救民众，也越会喂给索引，纪存和七海的交易又会刺痛白鸢。

所以 v08 改用三层结构：先从“每话承压”检查密度，再从“问题覆盖链”检查问题是否贯穿，再从“人物弧线阶梯”检查戏剧是否升级。

## 重写逐话梗概的新顺序

下一版逐话梗概不要从章节主题开始写。推荐顺序如下：

1. **查本话承压矩阵。**  
   先确认本话主压力、次压力、暗线和人物/梗点压力。若一话只服务一个问题，先重构事件。

2. **查相关问题覆盖链。**  
   从 50 项问题里找出本话涉及的项，确认本话在每条链上是种子、推进、转折、爆发还是回收。

3. **查人物弧线阶梯。**  
   如果本话涉及纪存、七海、白鸢、唐胶、陆衡、赤罡或万机馆/G.A.G.主轴，必须写清本话是否造成外放事件和后续债务。

4. **回到 v05 逐话戏剧卡。**  
   用 A/B/C线碰撞、泪点物件、关系爽点和名场面梗点补戏剧质感。

5. **最后才写梗概正文。**  
   梗概正文可以短，但必须能看出事件、分支、玩法、变量、机体、情绪和余波。

## 四个硬门槛

### 1. 每话不再单线程

每话至少要回答四类问题：

| 压力类型 | 例子 |
| --- | --- |
| 主压力 | 本话眼前必须解决的行动问题，例如撤离、护送、撤退、公开、守层。 |
| 次压力 | 与主压力互相拖累的系统或阵营问题，例如清算物流、军方采样、索引训练、城市损伤预算。 |
| 暗线/伏笔 | G.A.G.事变、万机馆秘密、馆长记录、远星噪声、旧世界伤口等。 |
| 人物/关系/梗点压力 | 成人关系、错事账本、机战名场面、泪点物件、观众证词等。 |

比如 5-2《红面具的课》不能只写“赤罡被宿敌诱惑”。它同时要背：

- 单挑名场面的机战爽点。
- 撤退任务被拖慢的战术代价。
- 莉歌用唱错半拍做撤退暗号的关系场。
- 索引记录玩家是否偏爱宿敌爽点的暗线。
- 刃用撤退路线打断热血的价值冲突。

这样一话才不是小品，而是后续 5-3、10-3、12-2 的共同种子。

### 2. 人物弧线必须升级，不许原地撒点

v08 把人物推进改成阶梯。以纪存为例：

| 阶段 | 话号 | 外放事件 | 质变 |
| --- | --- | --- | --- |
| 种子 | 1-1 | 用档案终端维护闭馆秩序，却被清算清单打断 | 记录第一次显得像封存。 |
| 推进 | 1-3 | 三选二撤离，亲手留下缺口 | 从旁观档案员变成会造成损失的负责人。 |
| 转折 | 4-3 | 用“记录不是修图”刺痛白鸢 | 准确也可能很冷。 |
| 质变 | 6-2 | 主动请求白鸢改写一格战场 | 他越过自己的原则，形成共犯债。 |
| 爆发前 | 8-3 | 以证据换七海白名单 | 他会做不干净的交易来保住万机馆。 |
| 爆发 | 9-3 | 被质问“你也是模板吗” | 越安抚越像系统。 |
| 崩裂 | 11-1 | 选择如何公开自己与G.A.G.残响关系 | 他不再能把自己放在档案之外。 |
| 回收 | 12-3 | 空白展柜前命名自己 | 他接受自己不是答案，而是被关系共同定义的人。 |

这种写法要求每一步都能被演出、玩法或变量承载。不是“纪存更理解大家了”，而是“纪存做了某个会留下账的动作”。

### 3. 关系线要有场面，不是关系值

成人关系可以更危险、更有吸引力，但要靠动作和代价，不靠露骨描写。

| 关系 | v08主语法 | 高压节点 |
| --- | --- | --- |
| 纪存×七海 | 程序缝隙、白名单、越权、可追责记录 | 8-4七海切断通讯前只说出口在北侧；12-3她证明纪存不是资产。 |
| 纪存×白鸢 | 记录和改写互相吸引，也互相伤害 | 6-2共犯改写；9-3她质问证词是不是交易；12-3她让纪存自己写名字。 |
| 唐胶×兜灯 | 修理间火花、抢责任单、手比嘴诚实 | 11-3共同守维修区，责任单被改成共同施工。 |
| 陆衡×方舟T | 非人陪伴、沉默、参数无法处理离别 | 10-2迟到回信时方舟T不再开玩笑，陆衡也不断开频道。 |
| 赤罡×莉歌×刃 | 热血、撤退暗号、停手和传递 | 10-3赤罡取消大招确认键，刃不骂他，只重发撤退路线。 |

关系爽点不等于所有人喜欢主角。它可以是误会、共犯、沉默、质问、替对方背锅、战损优先维修、当众开路，也可以是“我不证明你是人，但证明你不是资产”。

### 4. 万机馆和G.A.G.要从背景变成剧情机器

万机馆的主脊柱：

| 阶段 | 话号 | 作用 |
| --- | --- | --- |
| 表层博物馆 | 1-1 | 玩家先喜欢上多展区、留言墙和闭馆路线。 |
| 流亡展舰 | 1-3 | B1机库脊柱和移动底盘启动，万机馆带伤逃亡。 |
| 开馆经营 | 2-3,3-4,5-3,7-2 | 模型临展、失败白板、撤退名单、删注展成为公共展项。 |
| 合法性危机 | 8-1,8-4 | 合规开馆与清噪封条改变万机馆的社会位置。 |
| 家园崩裂 | 11-3 | L1/B1/B2/外部锁泊成为内战地图。 |
| 会开馆的方舟 | 12-5 | 开馆或关灯成为世界如何处理机魂的制度选择。 |

G.A.G.揭示曲线：

| 阶段 | 话号 | 玩家理解 |
| --- | --- | --- |
| 展示异常 | 1-1 | 它会让展项活化接口被清算盯上。 |
| 关系钥匙 | 2-3 | 模型和玩具的热爱痕迹也能成为残响证物。 |
| 失败数据 | 3-1 | 真实机器日志也可能形成机魂证据。 |
| 优化生命 | 6-2 | 它会把未完成误判为等待补完。 |
| 清噪台前 | 8-4 | 它不是混乱怪物，也可能是更高效率的秩序。 |
| 最优恐怖 | 9-1 | 完美修正版比破损更可怕。 |
| 个人化 | 11-1 | 纪存的身份让世界系统压回亲密关系。 |
| 价值回收 | 12-4 | 终局不是杀掉系统，而是决定记忆如何继续存在。 |

这能避免 G.A.G.到后期才像名词登场，也避免万机馆只是移动基地菜单。

## 四个高压样本

### 6-2《重剪第七幕》

这话必须同时解决：

- 作者权力不是论文，而是分镜轨道和死亡格规则。
- 白鸢的温柔控制第一次被纪存主动调用。
- 改写能降低难度，但会制造共犯债。
- 索引后续会把这次越界训练成“温柔控制模板”。
- 玩家可以选择拒绝、有限使用或补完角色，每种选择都有玩法收益和关系代价。

不合格写法是：纪存和白鸢讨论“角色是否属于作者”。  
合格写法是：废案角色站在死亡格边缘，纪存明知道会欠债，仍请求白鸢改写一格战场。

### 8-4《清噪启动》

这话必须同时解决：

- 第二幕系统级大败。
- 七海发现自己的秩序也会被更高效率吞掉。
- 白名单节点、城市系统、万机馆档案三者无法全救。
- 索引天使正式台前。
- 纪存和七海的危险共犯从程序缝隙变成逃生路径。

不合格写法是：清噪程序开始，大家逃走。  
合格写法是：七海看着自己保留的异常编号变灰，切断通讯前只说出口在北侧。

### 9-3《你也是模板吗》

这话必须同时解决：

- 主角身份危机先在人际关系爆炸，而不是在设定百科里解释。
- 七海证词救纪存，也刺痛白鸢。
- 白鸢的质问不是吃醋，而是“证词是不是又一层控制”。
- 索引把纪存的安抚选项列为模板化证据。
- 玩家不能靠嘴炮立刻修复信任。

不合格写法是：纪存解释自己不是坏人，队友理解。  
合格写法是：纪存越想照顾每个人的情绪，越像在给大家选择最优回应。

### 11-3《流亡展舰内战》

这话必须同时解决：

- 身份线、家园线、设施线同场崩裂。
- L1、B1、B2、外部锁泊不是背景，而是互相拖累的战场区域。
- 守一层会让另一层更坏。
- 唐胶/兜灯、纪存/最高关系角色、旧守护者/观众证词都要进入地图。
- 至少一个设施永久损伤，否则大败不成立。

不合格写法是：队伍吵架后打一场。  
合格写法是：索引清掉补丁色地板和留言墙错字，玩家才发现这些丑东西是亲手修过的家。

## 采纳与取舍规则

下一版逐话梗概不需要把三张表里的每个条目原样塞进正文。它们是约束，不是正文。

采用时遵守三条取舍：

1. **一话可以压很多问题，但正文只写最能造成行动后果的三到五个。**
2. **同一问题跨多话推进时，要明确本话是种子、推进、转折、爆发还是回收。**
3. **如果某个关系或设定没有外放事件，就先不要写成“理解”或“成长”。**
