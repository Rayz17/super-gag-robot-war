## 0. Canon迁移结论

V20 不应理解为“把 v19.1 改写成逐话版”。  
V20 的正确口径是：

> **48话主线番剧骨架 + 约60到70个完整可玩剧情节点。**

48话负责全剧主线、篇章高潮、主要机体入队、核心关系爆发和结局分流。  
主线外的开馆事件、角色/关系事件、残响深潜、EX隐藏关负责万机馆厚度、机体谱系扩容、模型/玩具文化、成人关系场、隐藏机体和支线回收。

因此，旧的“46话主线结构”从当前推荐口径降级为历史材料；v19 的“11篇48话”成为 V20 主线骨架候选。  
但 48话不是全部内容长度，也不允许把所有剧情、关系、玩法和藏品都硬塞进主线。

## 1. V20必须继承什么

V20 不是重新开始，而是合成以下层级：

| 来源 | 必须继承 | V20中怎么用 |
| --- | --- | --- |
| v19 | 11篇48话、番剧节奏、主玩法分段 | 作为主线话位和篇章结构。 |
| v19.1 | 巡展开馆表、11个活化源点、阵营互抢源点 | 作为全剧主线发动机。 |
| v19.2 | 代哥品牌资产生态、七海内部改革线 | 作为清算/代哥线和七海线的硬校准。 |
| v15 | 大爆点、反转、机战爽点、成人卖相 | 作为每篇高潮和关系场的加压标准。 |
| v16/v16.1 | C04-C08高能段、白鸢误会、七海主场、中盘大败 | 作为中盘连续剧核心，不得稀释成摘要。 |
| v12.2 | 前三章可读样板 | 作为早期篇章的展开密度参考。 |
| v10-v14.1 | 50问题专属解法、场面池、继承保护 | 作为逐话增写的弹药库，不得只索引不吸收。 |
| v17.1 | 50问题反拷旧大纲 | 作为防止只补恋爱/成人向或少数病灶的审稿底座。 |
| v09/v05 | 逐话戏剧卡、人物弧线、A/B/C线碰撞 | 作为历史对照，检查每话是否有戏而不是论点。 |

每个来源进入 V20 时都必须标明：采纳、改造、合并、废弃或延后。  
没有处理结果的材料，不允许在交付说明里写“已融合”。

## 2. V20内容体量口径

V20 的结构不应是 48 个等长摘要。

推荐内容体量：

- 48个主线话位。
- 10到14个开馆事件。
- 10到14个角色/关系事件。
- 6到10个残响深潜或探险事件。
- 6到10个EX/隐藏关或隐藏机体事件。

总可玩剧情节点约 60到70 个。  
这个口径能让主线保持番剧推进，同时让万机馆“万机感”、参战规模、关系线、经营探索和隐藏内容有空间。

## 3. 每话分级写作

V20逐话梗概按话级分工写，不平均分配篇幅：

- **S级**：篇章高潮、中盘大败、后继机、恋爱/关系爆发、终局全员支援。必须写厚。
- **A级**：重要转折、敌方大动作、主角不可逆选择、关键机体加入。必须写完整。
- **B级**：推进话、玩法承接话、地图展开话。可以短，但要有新事件。
- **C级**：余波、整备、路线整理、经营回收。可以短，但要给后文债务。

如果一话只有“推进主题”而没有具体场面动作，判为不合格。

## 4. 每话最低内容字段

V20 每话至少回答：

1. 本话发生了什么新事件。
2. 这件事争夺哪个源点、展品、机体、证据、关系或命名权。
3. 敌方本话做了什么具体动作。
4. 玩家具体玩什么，胜败或选择改变什么。
5. 纪存或核心角色做了什么不可逆选择。
6. 本话有哪些机战爽点、名场面变奏、梗点或视觉封面。
7. 本话有哪些关系推进、成人张力、误会、裂痕或陪伴。
8. 本话留下什么下一话债务或长期变量。

这些字段不是表格KPI，而是防止剧情再次变成主题讲稿。

## 5. 支线节点职责

主线外内容必须有明确承载，不是碎片补丁：

- **开馆事件**：承载展区、藏品、观众、经营、模型/玩具文化和支援效果。
- **角色/关系事件**：承载七海、白鸢、唐胶、陆衡、赤罡等人的私欲、误会、暧昧、修复、冷战和终局证词。
- **残响深潜/探险事件**：承载封闭区域、机魂档案、远星误译、黑匣子和隐藏设定。
- **EX/隐藏关**：承载隐藏机体、参战规模、名场面变奏、特殊合体技和玩家收藏触发的真实机体事件。

支线不能只给资源；它至少要给一个剧情证据、关系变化、机体条件、展区变化或终局支援声部。

## 6. V20交付顺序

V20 不一次性写完整48话，以免后半段缩水。推荐顺序：

1. 先写 V20 全剧继承账本与总结构。
2. 再按 11篇逐篇写“篇章剧情梗概 + 话级槽位 + 支线节点”。
3. 每篇写完立刻做四轮自审：剧情审、机战审、人物关系审、继承审。
4. 中盘 C04-C08 单独加一次压力测试，确认 v16/v16.1 的亮点没有缩水。
5. 全48话完成后，再做覆盖表：源点、代哥层、七海线、白鸢线、机体谱系、50问题、支线节点。

## 7. 写作红线

- 不允许把 v19.1 的“巡展开馆表”写成普通收集钥匙。
- 不允许把 48话当全部内容，把万机馆、关系线、隐藏机体和多玩法塞爆。
- 不允许把 v10-v14.1 的旧成果只写成“参考过”，必须明确采纳或弃用。
- 不允许后半段只用摘要交代宇宙、内战和终局。
- 不允许把代哥写成单一恶企或把七海写成万能内鬼/恋爱脑。
- 不允许让白鸢线在中盘后消失。
- 不允许把机战爽点写成小数值、小回合、小规则，而没有地图、机体、BGM、部署、cut-in或结算层面的外放。
