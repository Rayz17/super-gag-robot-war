# V35 C01用户审定故事回迁与Canon收敛

> Status: `working_canon_migration`
>
> 日期：2026-07-26
>
> Scope: L3 C01切片、C01 Current Canon、C02继承入口、L4重新封存

## 一、迁移原因

用户已经确认`C01-完整剧情总纲.md`当前故事成立。该版本以`BREAKER`外敌突入、馆守Z与勇拳双拳协战、万机馆巡展舰升空和第七次巡展为主脊柱，取代此前由旧Reader反编译出的行政清算、白函主战、断臂撑桥、载荷二选一和36小时逃亡。

若只保留故事正文而不回迁L3与Canon，后续预生产、C02继承和资产查询仍会自动恢复旧因果。因此本轮按“稳定身份保留、局部实现退役”的原则收敛。

## 二、继续成立

- 万机馆因馆长失踪、长期亏损、灾后恐惧和代哥停止续约而闭馆。
- 纪存与七海已有一年多私交，原本约好闭馆后吃饭；七海C01始终留在东区封存中心附近。
- 馆守Z是18米实机；旧守护者是同一机体的机魂人格；轮式导览终端只是远程感官和扬声器。
- 兜灯负责馆守Z物理整备与停机，唐胶负责馆藏和巡展装备；陆衡C01不出场。
- 豪司驾驶无机魂勇拳试作机，社勇王真机仍留C03。
- 万机馆是百米级巡展舰身体，不是馆守Z，也不在C01变成人形巨躯。
- 模型、玩具和展品不凭空巨大化；巡展武装来自历史上真实使用过的全尺寸装备。

## 三、新Current事实

1. `BREAKER`突破近海防线，地面黑甲与飞行核心是同一主体的两阶段。
2. 馆守Z在E02首次正式战斗；纪存只在导览席提供路线与判断。
3. 馆守Z在E03主动使用过载火箭右拳，豪司以勇拳储存冲击完成第二次推送；原右拳和完整前臂毁损。
4. 馆守Z在E04装上救援锚改成的巡展臂装。它只能抓握、放锚、牵引和固定，不是完整后继右臂。
5. 万机馆恢复巡展舰身体，以有限防卫炮、退役重盾、救援锚和推进骨架参加空战。
6. BREAKER被馆守Z左拳击毁；无标志白色采样机在尾声取得右拳残片。
7. 万机馆主动启动第七次巡展。旧引擎可可靠抵达邻近一站，但巡展臂装不能承受第二场大战，舰底也缺现代泊位接口。
8. 木桶街因拥有旧式泊位、全尺寸改件和临时手臂升级能力成为下一站。

## 四、迁入History

- 白函作为C01重型Boss和本章主要敌方；
- 四方接管作为火灾与起航的主因果；
- 馆守Z断臂成为撤离桥；
- 人员脱险后的载荷二选一、档案主库留置与公开未带走清单；
- 36小时生存窗口；
- 陆衡C01到场并成为随舰第四操作员；
- 七海消防锁延迟记录、移动风险编号和C01火锁回写单位；
- C01的0号侧廊捷径、迟到回信与错序箭头必显；
- 黑展柜皇影相关退役决定继续有效。

旧文件、Runtime、Graybox和资产可作为History追溯，不再对新L4和C02产生兑现义务。

## 五、C02新继承入口

C02不得读取旧载荷Bundle、白函损伤、36小时窗口或陆衡随舰。它必须继承：

- 第七次巡展已经启动；
- 馆守Z处于巡展臂装期，真正后继右臂仍未取得；
- 万机馆需要现代泊位兼容、长期补给和可持续巡展装备；
- 豪司与勇拳已被企业回收；
- 七海留城受调查，饭约只完成一半；
- 白色采样机已经带走馆守Z右拳残片；
- 木桶街主动邀请万机馆来开馆和改装，不是单纯救命零件商店。

## 六、公开资料与Canon边界

`万机馆｜本次开放资料`保存玩家阶段性理解，不直接写入Canon真相：

- `确认资料`可以引用Current事实；
- `馆内推定`、`当事人口述`和`未确认事项`不得因为出现在UI里升为Working Canon；
- 后续修订必须保留旧版与修改者；
- 玩家必须先从故事看懂主因果，资料页不能承担补洞。

## 七、L4封存要求

本迁移只提供稳定输入，不替代C01预生产、导演板、战斗预案、物理板、逐话表、状态账、四视角章审和累计连续性回执。C01仍必须按story-chain逐门封存，完成`write-performance`后停止，不进入L4.5或Reader。
