## 一、审查方式

本轮采用“独立提问题，单一主笔统一修改”的方式。游戏制作人、专业编剧、机器人文化专家和目标玩家分别只读同一版母盘，不共享彼此结论；主笔将四席证据合并为共同根因，再一次修改正文和事实表，避免四个人各自在正文里塞一套规则。

审查共分三段：

1. 第一轮检查宏观规模、章间因果、长期对手、群像、Roster、分支与终局峰值，形成22章和85话候选骨架。
2. 第二轮对完成版机器表做独立压力审查。四席结论分别为`CONDITIONAL PASS / CONDITIONAL PASS / CONDITIONAL PASS / FAIL`，共提出八项定点结构阻断。
3. 主笔完成定点闭包后，原四席只复核自己提出的阻断，不再发散新增方案。同一根因至多三轮；未彻底解决者进入账本但不伪造通过。本轮制作人、编剧、机器人文化专家和目标玩家四席最终均给出`PASS`。

完整逐项记录见 `v35_series_structure_review_ledger_v1.tsv`。

## 二、第二轮发现了什么

四席没有要求推倒六部二十二章主脊，阻断集中在“正文已经想清楚，附件仍在说另一件事”：

- 制作人发现C04三个T1上限无法同时容纳三地方旗舰、共鸣双机、百相和共享身体；C22治理还带着第二个H4标签。
- 编剧发现C14舰籍仍有模糊枚举；C17的“融合”可能把已释放主体重新吞回；白鸢的终局能力动作在C19和C22重复消费。
- 机器人文化专家发现C20只有内外槽站位，没有各参战包怎样击破九相位与三个节点，最大胜利会退化成报名字。
- 目标玩家发现C01把社勇王模型、勇拳试作机和社勇王真机混成同一项开局收益；母盘父分支号与投影结果号没有闭合。

这些问题的共同根因有五个：

1. **剧情首登、玩家首控与完整资产完成被当成同一时点。**
2. **父分支语法、具体投影和制作成本标签混用。**
3. **章级“众机参战”没有继续拆成可玩的机械动作。**
4. **人物牺牲和能力升级在不同表里被重复或取消。**
5. **已通过的前三章事实没有被所有新表重新读取。**

## 三、统一修订

### 1. 资产与机体生命周期

新增 `v35_series_structure_peak_asset_binding_v1.tsv`。C04完整制作三地方旗舰客将Rig；米拉/艾达共鸣双机只以驾驶舱、剪影和局部变形预显影，完整T1和永久主机落在C05；百相复用已有Rig，共享身体使用一套T2模块家族。C06、C08、C11、C14、C19和C20也分别锁定了新Rig、复用窗口和计费方式。

C01勇气包恢复Working事实：玩家只见社勇王模型锚，豪司临控没有独立机魂的勇拳试作机，战后机体被公司回收；C03才首控真正拥有主体AI、会拒绝豪司的社勇王实机，并取得可撤回公共应急部署。模型不变大，勇拳也不是社勇王的升级前形态。

馆守Z恢复三阶段右侧生涯：C04只装无前臂、无手、无武器的空肩牵引背架；C09得到第一套永久代用臂架；C19获得完整后继右臂。原右臂永远留在旧址。

### 2. 分支与关系动作

唯一完整H4仍是C14七海合法改革/公开脱离。三主角关系是H2状态，C22治理是H2加H1模块尾声。投影表补齐BR-02合体、BR-05白鸢预演和BR-08未来报告，并把所有具体投影ID统一为“父分支号+动作+发生章”；母盘只引用投影ID，不再拿父分支号冒充结果。

C17确证执行纪存和那些长期被系统压低优先级的独立地址都具有主体资格，并由纪存当场切断所有者权限、永久失去普遍监听；C18只结算具身、远播、可拒绝的协作加入或继续敌对，不能再无代价融合回一个纪存。白鸢C19只放弃预写装配结果并允许现场改图，真正关闭最后一格预演保留到C22。

### 3. 最大机器人胜利

新增 `v35_series_c20_mecha_action_matrix_v1.tsv`。C20不把二十九个成熟包排成二十九段Cut-in，而以八条战术链互相递交破口：舰队量产目标、三地方防线、完整合体与轮核、变形归航、近战接力、现实机器物理断开、规则与未来脚本反杀、最终同回合终结。每条链锁定相位/节点、具体机械动作、玩家目标、IP精神变义、可见战果、路线替补和制作边界。

定点复核进一步补上两处机器闭包：米拉/艾达的可变共鸣双机现在拥有独立的C20错位换形与强化人悲剧反转，不再被“全成熟包”统称吞掉；C22新增一套明确计费的万机殿开放接口重构资产，复用神座本体但完整制作撤槽、换位、接替、拒绝再加入和主动停机。

### 4. 位置与终局消费

C14舰队表是人物与机体位置权威：豪司/金章/莉歌/陆衡及勇者、星翼、现实机器代表进入七海公共护航舰；方舟T人格与旧锚留中央残舰；白鸢、唐胶、槐和作者工房进入作者舰；三地方旗舰保持外部独立舰籍。路线包若拆分，第四层必须具体到驾驶员、主机和载体，不能写“可能在A或B”。

C20先取得不附带即时否定的真正战争胜利；C21第一话完整享受最强形态的普通使用，第二话才从小范围物理退槽故障进入逆合体；C22只能使用同一批受损资产完成撤槽，不得追加更强外敌或第四终极形态。

用户追加审定也已反写结构：二十七年地球圈存在持续近地侵扰；无声主唱、第九园丁和佩拉戈斯是三种独立威胁生态，断冠只能诱导航路和观察，不能统帅三者。C09因此诚实增加三套可辨识Boss Rig，不再用“零新T1共享虫群”掩盖成本。全球演员从前半段起采用中文显示名与Latin名并存；Z、CCA、独角兽、SEED、铁血、Turn A等热门强谱系升为优先完整包，终结者、Matrix和Chappie分别按巨构敌体、玩法语法和小型角色支援使用。馆守Z原臂永久留旧址，C19取得新造后继右臂；未过旗舰级剧情门的纯原创机继续退役储备。

## 四、未关闭但不阻断第三层审定的问题

以下项目不是“以后再想”的空白，而是明确下放到第四层的门禁：

- C04-C05必须共用一张物理因果与站位板，锁纪存肉身、机魂路由、百相控制权、导览接口和每场战斗时间。
- C08严格只让白舰承担主关系回合、星翼与自由双星承担两个副关系回合；铁棺、钢花和钻破只能使用一个既有动作或后续钩子。
- C17-C18每话必须由一台玩家已经熟悉的机体和一段具体关系作镜头主语，禁止未来报告、主体资格和完美世界轮流讲概念。
- 五机任务组只有C10-C11已建立具名关系与失败尊严时，才可在C17占用硬What-if席位。
- C15-C20连续25话需要在角色、语音和UI生产上形成内部谷底；旧图变体和装配探索不能只写成“复用”二字。
- 85话、约68至88小时仍是主线长篇上界；第四层可按实际戏剧容量增减章内话数，但总环境、Rig和时长不能无依据回涨。
