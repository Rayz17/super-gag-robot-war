## 因果与人物欲望复述

战装局想把纪存的有限导航经验推广成可复制标准；韩秀雅想让百相证明通用身体能够救人；沈砺因旧远征十二机只回来七机，越来越确信统一导航必须尽快扩大。公开试航真实成功后，她把“救过人”当成继续越界的理由。四副测试体、黑城、百相副驾核与运输舰因此由同一条控制冲突逐步升级，而不是四场互不相干的事故。

玩家先在E05赢下万机馆首次正式、可控的多格母舰部署战，卸除百相四套外接武装并夺走装有实体接驳钥匙的服务器箱；E06才面对受损操作舱脱落。纪存明知停火会失去无伤扣留百相的机会仍选择让开，韩秀雅实际驾驶百相回头，百相新生副驾驶第一次提出样本之外的方向。

## 玩家目标与玩法复述

六话目标可以只靠总纲连续复述：

1. 完成百相复验并迎击断冠远端楔队。
2. 阻止E01胜利后新造的伪外运令把铸环公共接口、现场数据和在线任务一起带走。
3. 在不击毁测试体的前提下让四名操作员停机并结束请求。
4. 判断百相副驾核是否已经形成与纪存不同的主体。
5. 以万机馆首次正式多格部署夺取实体接驳钥匙并完整赢下母舰战。
6. 在放走百相的即时战略代价下先救回操作舱。

## 独立复核结果

- 四名操作员从E01起使用同一艘可拆操作舱并实际驾驶测试体；E03停机后四人离席到机旁检查，再沿同一地面桥回到原席并锁好固定带，E05才随操作舱升起。四副身体没有自行长出人格。
- 纪存的人形身体始终留在万机馆B1。普通记录能够复制，未结束的请求却持续等待本人；本章只把这一差异作为机魂真相线索，没有叠加第二套解释。
- 百相副驾核从未接入四副测试体，只保存百相当天亲历；它与已经醒来的纪存具有不同记忆和不同物理载体。
- 本地船长一直持有实体飞行钥匙和舰载短滑钥匙；E02地面运输组使用铸环轨道牵引车，E06沈砺只能建议船长启动舰载短滑推进器。操作舱事故前，吊车、百相直接伸手和外侧托架三种救法均因已经建立的空间条件失败。
- E05完整结算正式多格母舰部署的胜利，E06才让纪存以失去扣留百相和未来再武装风险为代价停火；事故没有把上一话的胜利倒写成错误。
- C01白色衬片、C02白色组件和C05兼容架只证明材料链同源，没有凭空取得完整采样机。
