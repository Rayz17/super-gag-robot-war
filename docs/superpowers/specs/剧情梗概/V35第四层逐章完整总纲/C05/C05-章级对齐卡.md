# C05《百相试航，巨人里醒着另一个人》章级对齐卡

> Status: `candidate_layer4_alignment_v7 / causal_repair_20260727`
>
> 代表路线：`BR01-COMMON + BR05-COAUTHOR`
>
> 话数：六话。人物决裂、首次正式多格母舰部署、可拆操作舱事故与百相自主回头分别获得完整落点，避免把一场完整SRPG胜利和第二场人物高潮挤进同一话。该话数已由L3容量迁移计入当前87话上界，不从后章机械扣回一话。

## 一、为什么必须在C04之后发生

C04已经让集中协同获得了真实价值：纪存通过万机馆B1导航，韩秀雅驾驶百相，三台地方旗舰和现有机群自愿开放各自视野，最终完成一场任何单机都做不到的反击。百相、纪存和韩秀雅因此同时拥有声望、力量感和继续试验的理由。断冠本体没有留在铸环；C05E01来袭的是它从远端放出的侦察楔队，承担一次短促的真实外敌检验，不把断冠主战重新打一遍。

天空铸环也留下了危机需要的现实条件：七海七年前批准过灾后共身救援；白鸢提出、陆衡与工房编译、驾驶员共同校验的动作层已经进入共享测试包；百相辅助席后有一枚每次试验都会重置的本地副驾核；米拉与艾达的可变双机只差完整首战，`R-04`编号、接管旧伤和黑城第一次交战仍未结算；万机馆的新承力结构尚需高负荷复验。心墙零式进入C05时只剩一面完整防壁和半片已经判废的残墙，残墙只能作为掩体或承伤物，不得写成第二面可用防壁。艾达的灾前离线档案不是C04既成事实，必须在C05E01先由项目方拿给她看见、让她产生欲望，才允许在E03成为代价。

C04结束后的数日里，战装局把百相缺失的标准右臂、四套试航模块和四副12至18米工业测试体一起送进铸环。四副测试体原本就是战装局用来验证重载、防壁、高机动和远距标定任务的现役资产，由四名远程操作员驾驶；四人也只在C05E01第一次到场、第一次看见本地试航单并逐一签署，不继承任何C04现场确认。测试体不倒写成C04库存，也不冒充四台新主角机。

战装局不需要突然绑架纪存。它只要把众人都希望成功的公开试航推进一步：保存纪存已经完成的画面、动作和判断，再把四项尚未结束的任务继续交给四副测试体，证明这种协同不必永远依赖同一个人。它把这一步宣传成“导航备份”，但四副测试体只是换了远端窗口，仍在向纪存本人索要下一步。这是一个能救人的合理愿望，也是后来最容易被索引继承的人类误判。

## 二、章发动机

**表层发动机**

万机馆必须在纪存被四项未结束任务拖住、四副测试体正被运走的情况下逐一让任务真正结束，并夺下导航记录服务器；同时不能摧毁韩秀雅驾驶的百相、米拉与艾达的试作机、嵌有艾达与二号机的黑城驾驶区或仍在现场的工房人员。

**深层发动机**

战装局把“许多驾驶员愿意回应纪存”误读成“纪存发出一种可以复制的控制能力”。它想把奇迹变成可靠公共设施，却逐渐把接口标准化推进成主体标准化。

纪存本人也不能站在道德高处。他主动要求再次接入百相，真心享受巨大身体和全队响应；当百相里一道只借过他导航方法的新声音醒来时，他最初也本能地怀疑那只是可以清除的程序回声。

## 三、本章必须兑现

- 百相先作为公开Boss接受全队挑战，再由韩秀雅驾驶、纪存导航完成一次正面大胜。
- 米拉与艾达的共鸣双机完成全形态首战；C04已经建立的`R-04`编号、观景廊亲密、接管旧伤和黑城第一次未能一起离开必须直接承接。项目方在E01才公开一份可能属于艾达的灾前离线档案，E01-E02先让她想取回又不肯信任，E03才允许它成为选择代价。
- 公开试航使用战装局正式权限。四副测试体、运输舰和军用模块本来就是战装局资产；它无权带走的是铸环为测试体新装的公共身体接口、现场适配数据和仍连接纪存的实时任务。运输组把七海七年前救援证书上的旧签名拼进新的跨线外运单，试图把这些东西连同自有骨架一起装走。她以实体U盾紧急撤销本人旧证书，废掉假外运单，右掌受伤并永久失去旧系统入口。该动作不关闭战装局正式试验遥控；四副测试体仍由远程操作员驱动，必须另行停下。
- E01大屏展示的是9月18日03:14由远程节点伪造、并在C04末被划废归档的跨线外运附页；真正执行装载的第二张伪外运命令必须在E01公开胜利、最后一架侦察艇落地后新生成，并带有明确的生成时间。七年前留下的是本地救援证书，不是外运附页；玩家必须能一眼分清这三件东西。
- C01留下的只有白色内衬碎片。C05只能证明测试体兼容架的涂层、内衬与该碎片及C02匿名白色组件呈同批材料特征，不能声称已经取得或识别C01完整采样机。
- C05只有四副校准测试体，均在E01第一次入镜、由远程操作员实际驾驶并在本章全部进入战场；不存在另外八副库存。
- 四名操作员随运输舰乘可拆操作舱抵达。它没有独立飞行推进，只能由运输舰腹部吊架降到试验场边缘或重新吊回外舷；落地后兼作四人的远程操作室。E03四体停机后，铸环安全队加装实体止动夹并将其移入事故隔离位，四人从机旁沿同一段地面桥返回操作舱，重新入席并扣好固定带；E05操作舱才收桥，由腹部吊架升起并锁到外舷。该路线与四体保管状态必须在E01、E03和E05连续可见。
- 工业安全默认规则是“失去建议立即制动”。最后一架侦察艇停稳后，沈砺用自己的现役试验权限签发“连续测试”附令，运输组从地面试验席推送到四副自有测试体，把规则改成“建议中断后维持最后动作”。她有权调度战装局测试体，却越过了四名操作员刚签过的本地安全条款；E01尾声必须显示授权人、推送席和操作员的当场异议，不能继续用“战装局改了”省略责任人。
- 四条在线分流逐一停止向纪存提问，他才从保护性昏迷中醒来；纪存的机魂始终以自己的人形身体为载体，没有进入或退出百相。
- 百相本地副驾核在战装局关闭本次试验的自动清除、写入纪存已经完成的有限导航样本后，第一次连续保存同一天的百相传感、韩秀雅驾驶和战场选择。新声来自这件固定在百相内的物理设备，不是四路中的优胜者、纪存缺失碎片或服务器里的复制魂。`JICUN-EXEC`只出现一次，明确是战装局给样本工程起的产品标签。
- 白鸢只提出动作候选；陆衡、工房和驾驶员把它校验成试运程序。战装局本来就能遥控四副测试体，盗用程序的作用是绕开已知拦截并删除拒绝点。她必须面对允许测试包留存的具体后果，但不是四副身体的驱动者或百相新主体的创造者。
- 韩秀雅与沈砺完成“共同事业、第一次拒绝、明确分道”三段关系变化。
- 沈砺的越界必须来自可见旧败因而非抽象效率崇拜。多年前她负责十二机混编边防队返航，因不同机型无法共享路线而强行统一导航，最终只带回七台。她一直把画有十二个出发记号、七个返航箭头的纸质航路卡留在指挥箱里；本章每次成功都加深她“再统一一点就能让十二台都回来”的确信。
- 沈砺阵营必须有一名亲历旧败、看见本章代价后仍支持标准导航的具体执行者。黑头指挥型驾驶员伊玛妮·奥科福是当年七名归航者之一；她反对冒名外运，也坚持标准导航确实救过边防编队。E06她用“四个人也得回来”否定沈砺拿过去七人生还为今日风险辩护，但仍选择留在体系内修正它。
- 艾达亲口选择放弃旧记忆捷径，主动让共鸣二号从黑城中弹射；米拉接住她后，两机共同回身击毁已无人驾驶的黑城侧胸记忆舱。双方都活着并主动选择不同道路，动作不得重演C04“艾达开甲、米拉穿入胸腔”的同一套救援。
- 导航记录服务器里的录像、日志可以复制，但箱内插着一枚不可复制的实体接驳钥匙；谁持有它，谁就能把新的远端任务重新接到另一个人。服务器位于运输舰固定压力隔壁外的非增压设备舱。E05的战争不再只由“先放行还是先夺箱”发动：百相四套武装和运输舰航路仍接在战装局外线上，万机馆要求巨体留场卸装、隔离观察并断线；韩秀雅则必须在接管组抵达、格式化副驾核以前把百相带走。她只掌握百相，不能替运输舰船长交钥匙或切断战装局线路；沈砺也拒绝中止发射。因此并行搬箱无法消除百相去留冲突。
- 万机馆完成首次正式、可持续操纵的多格母舰部署，展开一侧出击甲板和有限舰员支援。C01已经发生过紧急航行战，本章不得再称“第一次母舰战”。
- E02、E05与E06必须区分两套完全不同的移舰手段：E02由运输组操作铸环地面的两台轨道牵引车，推着运输滑架慢慢前移；第一台被掀离轨道，第二台只被社勇王解除挂钩并退入侧线，没有被摧毁。E05由这台仍可运行的第二牵引车重新咬住滑架，把运输舰拉进维护框；万机馆横入长轨时，玩家切断牵引供电总闸，牵引车随即断电、自动脱钩并停在框外，运输舰靠低速惯性滑完最后一段，维护框与救援设备继续使用独立应急电路。两次都不动用运输舰动力或船长钥匙。E06开始时，失去动力的牵引车仍在框外，舰腹挂接点却已进入维护框，来不及重新接驳；此时才由本地船长亲手开启舰载短滑推进器。E05胜利后先发生一次可见的直接救援失败：操作舱位于运输舰外舷，维护框挡住百相，顶部吊机够不到受损挂点，硬拖会撕断仅存主锁；折叠救援托架又位于维护框外。船长只能让运输舰短滑一段，才能让百相与托架获得接舱角度。
- 伊玛妮从E01至E06的战斗与危机阶段始终在黑头指挥型驾驶舱内。E06地面席把四名操作员状态和旧航路卡的俯拍送进她的副屏；她完成挡护与降落后才离舱走到沈砺面前。
- 可拆操作舱没有独立飞行能力。E06主锁断裂后，它只能靠小型姿态喷口减缓翻滚，不能自行止坠。百相以一次跳跃接住操作舱时也无法悬空返回；纪存下令停火后，馆守Z把随舰牵引锚打进百相腰背承力框，万机馆主绞盘将百相与操作舱一起拖回轨外救援托架的覆盖区，艾达只负责稳定操作舱尾部。托架沿侧轨把操作舱送到运输舰尾部完好的气闸，四名操作员转入主舰；空舱留在天空铸环维修，不随舰离开。这个回收链必须在画面里完成。
- 服务器箱位于运输舰外侧非增压服务舱，内侧另有固定的压力隔舱。社勇王只剪断外盖锁销并把服务盖沿导轨推开，不把整扇舱门扯离舰体；本地船员可在离场前重新夹紧外盖。
- 纪存拥有击落百相的窗口，因百相副驾驶自主回头救人而下令停火。

## 四、本章可以推进但不能结算

- 战装局与索引逻辑相似，却仍是有人类目的、法律责任、政治支持和可改革空间的机构；索引本章不现身、不说话、不指挥战装局。
- G.A.G.只让持续回应有机会被周围主体辨认，不负责复制纪存、给百相供能或从程序中凭空造魂。
- 纪存、七海、白鸢发生第一次真实裂痕并保留照料，不确定最终恋爱关系。
- 一台BR-01地方旗舰取得提前协力资格，但三台旗舰的完整故乡、旧爱和毕业照故事仍留C09。
- 万机馆只开放低速母舰玩法，不暴走、不站立、不进入万机殿或终局共同工程。

- C09三台地方旗舰完整个人篇与馆守Z第一套永久代用右臂。
- C14万机馆暴走与更大身体形态。
- C17纪存、被白框真正复制出的分支主体、百相副驾驶和索引围绕“谁有资格被叫原本、谁有权使用谁的模型”的全面战争。
- C18以后白鸢反事实共感、七海未来牺牲条件与三人结局。
- C22终局共同工程、全机自由联援和远星回应。

## 七、人物大动作

### 纪存

主动复验并赢得世界瞩目的大胜；承受四条实时会话请求同时扣住身体；逐路断开后醒来，并第一次留下“普通备份不会这样等待原件”的身份疑点；醒来后对七海、白鸢产生真实愤怒与恐惧；失去全域监听后仍靠逐人询问指挥万机馆；最后承认另一个主体的选择，不把对方吞回自己。

### 佐伯七海 / Nanami Saeki

E01延长接驳时，她先认出一次与七年前相似的“退出延迟”警告，却因本地试航仍在合法范围、最后一架侦察艇尚未落地而没有把旧事故说完；E02发现有人用自己的名字签发新外运命令，再凭旧经验阻止白鸢硬拔接驳。她使用实体U盾撤销并烧毁旧入口，保住纪存，也让曾经救过韩秀雅的旧许可永久失效。纪存醒后对她的隐瞒生气有了真实依据，她必须在后续参与重建。

### 白鸢 / Evelyn Voss

先因七海阻止硬拔接驳而怀疑她隐瞒旧事故，又发现共同试运程序被删去确认点、改作远程绕行工具；代表路线中请陆衡把当前地形重新写回程序，再由现场驾驶员共同确认，帮助纪存回来。她承认自己为保留下一次追上艾达的可能，主动让可执行版本留在测试包；她不是四副身体的驱动者或百相新声的意识来源，却也不再把外流说成单纯事故。

### 韩秀雅 / Han Su-a

完成百相英雄首战；先相信战装局能够安全关闭复制；发现武器层优先保护设备并夺走自己右臂控制后第一次拒绝沈砺；确认格式化会抹去百相刚形成的新声后第二次明确拒绝；最终仍亲自驾驶百相，保护这名副驾驶离开。

### 沈砺 / Shen Li

多年前，她在一次混编边防返航中面对十二套互不兼容的导航，只带回七台。她把那张十二个出发记号、七个返航箭头的旧航路卡一直留在指挥箱里，不是为了卖惨，而是因为她真心相信：标准路线若早一点完成，另外五台也能回来。E01伊玛妮独立救回侦察艇，第一次证明她没有全错；E02她不肯再等手续；E03她命令最后两名操作员驾驶测试体跨过收容线，硬把试验继续下去；E04她因不可复制的新主体要求格式化；E05她拒绝交出实体钥匙、解除百相武装或切断远程航路，仍要在接管组抵达前推进发射。E06她看着四名操作员的舱坠落，终于下令停机，却已经晚于韩秀雅、百相副驾和伊玛妮的选择。她失去百相、韩秀雅、本地船员、实体接驳钥匙和天空铸环的本地合作，仍保留公开遥测、政治支持、统一导航的真实救援成绩与伊玛妮这一内部改革者，继续作为长期对手。

### 伊玛妮·奥科福 / Imani Okafor

驾驶黑头指挥型，是旧边防事故中七名归航者之一。她知道统一路线确实救了自己，也知道另外五个人并没有因此变成统计数字。她不为冒名外运辩护，会转达操作员的停机要求；E06操作舱坠落时，她以“四个人也得回来”公开拒绝沈砺继续用未来收益压过眼前生命，并亲自挡下短滑推进气流卷起的碎片。她仍选择留下修正系统，是战装局正面价值与内部矛盾的活人证据。

### 米拉·塞兰 / Mira Serran 与艾达·罗西 / Ada Rossi

C04已经建立她们的亲密史、`R-04`、接管旧伤与黑城首战；E01让两台完整中型机共同取得大胜，并第一次让艾达看见可能属于自己的灾前离线档案；E02让她明确想取回又不肯再用服从交换。E03中艾达主动弹出共鸣二号，米拉接住她；两机共同回身摧毁已经无人驾驶的黑城侧胸记忆舱。艾达活着离开，也失去找回旧人生的捷径，双方由此保有爱、怨气、事业与长期What-if。

## 九、分支

### BR-01

四条BODY路线改变C05E03怎样限制一副测试体，以及C05E05由哪台地方旗舰提前协力。它们不产生四套不同主线，也不要求三旗舰同时加入。

### BR-05

- `FORCE`：白鸢用原始图预判战装局下一次绕行，纪存更快醒来；代价是她再次成为单一战术中心，部分驾驶员可用动作被临时锁窄。
- `BLANK`：白鸢关闭共享试运程序，双方都失去路线辅助，玩家设备损失更高；现场驾驶员在终战更主动补足路径。
- `COAUTHOR`：白鸢请陆衡与工房把当前地形写回程序，再把候选路线交给四名远程操作员逐项接受、修改或拒绝；附近受影响的驾驶员保留叫停权。回收较慢，却重建一套真正由现场采用的版本。代表路线采用此项。

该选择在E02发现删改程序时完成，E03只执行结果，避免一场战斗同时处理分支抉择、四体回收、艾达选择、纪存苏醒和百相发声。三条分支都不改变百相副驾驶是否成立，因为主体来源是本地副驾核保存的连续经历与自主选择，不是白鸢按出一个人格。

## 十、资产与制作边界

- 复用C04天空铸环、主铸井、单臂百相、三旗舰、万机馆低位泊位和既有机群；百相标准右臂与四套模块是C05新增、后续可复用的正式试航资产。
- 共鸣双机共用一个可变骨架家族，但驾驶舱、翼形和完整变形必须一眼可分。
- 黑城复用C04同一套四十米Boss外壳、重装泊位、堡垒/巨人两态和城市级防壁表现；E03只新增侧胸记忆舱破坏差分，E05不再出场，C17复修复用。
- 四副测试体共用一套工业Rig，只用重载、防壁、高机动和远距标定模块形成易读差异；不另造库存、人格、实战枪炮或四套主力机Cut-in。
- 战装局运输舰是巨机运输资产，Reader只称重型运输舰；只需看懂百相泊架、可拆操作舱、维护框外的折叠救援托架和本地驾驶四个功能。E01必须先让本地试飞组实际驾驶它、持有物理飞行钥匙；E06拒绝远程接管才不是临时出现的解法。
- 导航记录服务器放在运输舰外置非增压设备舱，以明确占领目标夺取；箱内实体接驳钥匙不可复制，录像与日志可以复制；外盖沿导轨打开，固定压力隔舱保持完整；不再从百相背部拔出大型设备。
- 两盏确认灯只服务韩秀雅与沈砺，不作为全章通用状态表现。
- C05E04允许无完整SRPG，为人物冲突和观众理解留出空间；不得因“每话都要打一仗”重新塞入一张机库小战。
- C05E06复用E05发射轨、运输舰、操作舱和百相，不另建地图、不另算完整SRPG；它负责把E05已赢得的战果转成主体选择与阵营分道，不允许事故吞掉首次正式多格部署战的爽感。

## 十一、C06必然入口

旧货柜锚件先收到一段五车追逐：五辆退役救援车一边躲避摄影棚巨大怪物和坠落布景，一边各自救人，半空却不断飞来第六、第七套“豪华合体附件”，把它们拖向错误的巨大化姿态。录像最后才看见主办方为了保证复活演出成功安装的强制合体控制器；五车可以合体，也曾经喜欢合体，但拒绝被同一个程序在直播中强行驾驶。

现场已有工作人员和观众受困，万机馆必须立刻出发。C06首先提供追车、变形、巨大化和完整合体快感，再让不同谱系围绕“为什么愿意合在一起”产生喜剧与冲突，不能把C05再讲一次。

**对齐结论：**本章只读取C04已封章事实，并承接断冠远端楔队、心墙一面完整防壁加半片报废残墙的现行口径。四副测试体、四名操作员的首次签署、百相标准右臂和四套模块均在C05现场引入；纪存没有进入百相，百相中也不存在旧纪存副本。六话结构不增加新地点或新高成本资产；维护框、顶部吊机和折叠救援托架都是长轨现有设施，只把两个已经成立的高潮用可见因果连接起来。
