# C05《百相试航，巨人里醒着另一个人》章级实体、空间与行动预制包

>
> 本章属于“同一地点连续六话、四种控制关系同时争夺、两组成人关系发生质变”的高密度章。完整剧情总纲只能调用本包已经定义的人物、实体、空间、能力与大动作；新增专名设备前，必须先证明现有空间和资产无法完成。

## 一、章前硬输入

- C04结束数日后，天空铸环仍在修复。断冠本体已经撤离，本章真实外敌只使用它从远端投放的侦察楔队。心墙零式只剩一面完整防壁与半片已经报废的残墙；残墙只能作为掩体或承伤物。万机馆B1脊节已经过两班静态复验，舰体可低速离开泊位，但尚未作为可持续操纵的多格母舰单位出击。
- 火种货柜领袖已在C03离舰转递百机航路邀请。C05舰上主力为馆守Z、仍处三个月公共道路试用期的社勇王、旧拳王、无牌一号和BR-01代表路线单位；三地方旗舰只按路线提供一次客援。社勇王可长期操作不等于万机馆取得产权，企业维护与到期复核继续有效。
- 百相高55米，韩秀雅是唯一实体驾驶员。纪存的人形身体留在万机馆B1，只在各驾驶组主动开放视野后提供跨机导航。
- 战装局为C05公开试航带来四副12至18米工业校准测试体。它们在E01整备场第一次入镜，由四名远程操作员分别驾驶；四人也在E01第一次阅读并签署本地试航单，不继承C04确认。不存在其余八副，也不倒写成C04已经停放在铸环。
- C04结束时百相仍只有左臂。C05开始前，天空铸环用保住的生产线为它装上标准右臂，并由战装局带来重载、防壁、高机动、远射四套试航模块。E01模拟战先教学前三套近场模块，远射留到真实迎击首次解封。
- 百相驾驶舱后有一枚固定在机体内的本地副驾核：包含处理器、耐久记忆和百相传感接口，可给驾驶员建议，但不能操纵机体脚步。C04它只是未启用设备，不得倒写成七年前已经醒着的人。
- 米拉与艾达已经在C04完成第一次黑城内外的共同选择，但没有一起离开；共鸣双机将在本章获得完整战斗形态。
- 七海的实体U盾仍能撤销自己七年前在天空铸环留下的离线救援许可。四副测试体、运输舰和军用模块属于战装局；铸环新装的公共身体接口、现场适配数据和仍连接纪存的实时任务不属于它。战装局无需为带走空骨架造假，伪签名只用于把后三者一并写进跨线外运单。
- 白鸢为L2候选：可以依据可信现场同时维持数条互斥行动方案、标出未知和死亡风险；方案必须经工程验证并由现场操作者采用，不能直接驱动身体或改变现实。
- C01只留下白色内衬碎片，C02留下匿名白色组件。C05材质报告只能把兼容架与这两类物证连成材料/供应链，不能宣称识别了C01完整采样机。
- 四名操作员随运输舰乘可拆操作舱抵达；落地后操作舱降到试验场边缘，兼作四人的远程操作室。E03停机后，四人先沿同一地面桥到机旁检查，再返回原席位并扣好固定带；E05运输舰进入悬空长轨、地面桥撤收后，操作舱才重新升起并对接运输舰外舷。
- 四名操作员固定为马特奥·席尔瓦 / Mateo Silva（重载）、妮娅·门萨 / Nia Mensah（防壁）、水野玲 / Mizuno Rei（高机动）、阿妮卡·福格尔 / Anika Vogel（远射标定）。首次签署时显示姓名与岗位；马特奥和妮娅以贴满客场球票的保温杯形成一组生活记忆，水野玲和阿妮卡以反复缠松的右腕护带形成另一组。E06获救时只回收这两个动作，不为四人额外扩张独立支线。

## 四、能力与因果模型

### 4.1 纪存为什么醒不过来

1. 纪存的人形身体始终是机魂主载体，位于万机馆B1。
2. 公开试航时，各机主动开放局部视野，纪存通过B1回答交接问题。
3. 为等两架侦察艇安全落地，纪存提出延长接驳，韩秀雅同意继续开百相，沈砺批准延长到“最后一艇停稳”。三人共同承担延长决定，但都没有同意在此后新增任务。
4. 最后一艇停稳后，战装局没有按约断开，而是保存已完成的录像和判断，同时让四副测试体接手四项新任务。真正驾驶它们的是四名远程操作员；每当操作员需要下一步，远端系统仍会回到B1询问纪存。
5. B1安全系统检测到四组相互冲突的动作反馈仍未结束，不允许纪存恢复清醒的身体控制，避免主载体同时执行四种动作；这是保护性昏迷，不是灵魂飞出或复制。
6. 普通人的录像不会让本人昏迷。纪存的当下回应却被四路同时牵住，由此留下“他并非普通神经驾驶员”的硬线索；本章不解释其身世。

### 4.2 百相里为什么会出现另一个主体

1. 百相本地副驾核是一件真实设备，固定在空置辅助席后，能持续感知百相、保存记忆并校验自身建议，满足机魂载体的物理前提。
2. C04它没有持续自我，只是每次测试都重置的辅助程序；本章不倒写七年人生。
3. E01战装局为保存成功方法，关闭本次测试的自动清除，并写入纪存已经完成的导航样本。样本只是一种判断方法，不含纪存私人记忆或机魂。
4. 副驾核随后连续经历百相大胜、韩秀雅拒绝举手、艾达放弃旧档案、自己面临格式化，以及终战的撤离/救人选择。
5. 它先能说出“今天发生过什么”，再说出“我怕明天记不得”，最后主动建议百相回头救人。G.A.G.探测器只说明这一回应已进入机魂网络可识别范围，不负责凭空造魂。
6. 韩秀雅仍驾驶百相。新主体只能建议方向，不能移动巨体；它在取得名字前称“百相副驾”或“百相新声”。`JICUN-EXEC`只作为战装局项目标签出现一次，不使用纪存声纹制造真假纪存悬念。

### 4.3 白鸢的路线怎样产生现实作用

固定链条为：

`现场传感和操作者陈述 -> 白鸢维持多条候选 -> 陆衡/工房验证 -> 远程操作员或驾驶员选择 -> 真实机体执行`

- 战装局盗用的是C04留下的可执行路线库，并删除确认、拒绝和叫停步骤；它让四名远程操作员更容易选到绕开我方的走法，不会自动驱动测试体。
- BR-05在E02发现删改程序时完成选择，E03只执行结果；它决定如何处理被盗路线库，不决定机魂诞生：
  - `FORCE`：保留原库，用它预测敌方绕行；战斗较易，敌方继续获得更多路线样本。
  - `BLANK`：当场销毁共享可执行副本；双方都失去提示，战斗较难，白鸢也永久失去这份作品。
  - `COAUTHOR`：陆衡、工房和愿意合作的远程操作员按现场共同重编；流程较慢，但恢复确认与中止。

### 4.4 七海U盾能做什么

- 七海七年前签下的是天空铸环断网时的民用救援许可，正常启动必须插入本人实体U盾。
- 9月18日03:14出现过一张冒用该签名的跨线外运附页，C04已经将它划废归档。它只能作为有人曾经越权的证据，不能执行C05的装载。
- 战装局拥有百相试航、自有测试骨架和运输的正式权限，却用伪造电签把铸环公共身体接口、现场适配数据和仍在线的纪存任务也写进外运单。
- C05试航胜利后，沈砺批准的是第二张新外运命令。它再次冒用七海旧签名，并照搬9月18日伪附页的越权范围。
- 七海插入实体U盾后，可以撤销自己的七年前救援许可并使C05新外运命令失效；新旧命令冲突令U盾过热，灼伤右掌。
- 这不会关闭战装局的运输舰、武器、四名远程操作员或已启动测试体。授权冲突只截停装载，之后仍需现场战斗。

### 4.5 四副测试体怎样停

- 四名操作员始终拥有本地制动和动作拒绝权；战装局服务器控制的是任务是否结束，以及测试体下一次动作时是否继续向纪存请求建议。
- 正常工业规则是建议链断开后立即制动。最后一艇停稳后，沈砺以现役试验负责人身份签发“连续测试”附令，运输组通过地面试验席把战装局自有测试体改成“建议中断后维持最后动作”，理由是避免试航样本出现空段。该权限能调度自有机体，不能合法越过四名操作员刚签过的本地安全条款。E01尾声必须显示授权人、推送席和操作员当场质问，操作员随即踩下本地制动。
- E03玩家不是替操作员“获得刹车”，而是切断远程任务通道，让已经停住的人能够真正关闭任务。后两名操作员在沈砺命令下继续驾驶测试体跨线；她们仍能刹车和拒绝，只是要在军令与眼前风险之间作出选择。

### 4.6 服务器为什么必须夺取实体箱

- 录像、日志和已完成判断都能复制，万机馆争夺的不是唯一数据副本。
- 箱内实体接驳钥匙保存新建实时会话所需的硬件身份，不能远程复制。谁持有它，谁就能把类似四项任务重新挂到另一个人。
- E05开战前，百相四套军用模块和运输舰远程航路仍连接战装局。万机馆提出“百相留场卸装、断线、隔离观察；服务器箱和钥匙交出”；韩秀雅无权替船长与沈砺答应这些条件，也拒绝让副驾核留到接管组抵达。战争由百相去留和控制权的真实冲突发动，不由搬箱顺序单独发动。
- E05运输舰进入发射准备后，战装局拒绝释放外置设备舱锁、切断运输舰航路或解除百相外接武装；韩秀雅无权替船长打开设备舱或交出钥匙，也不肯让百相等到接管组抵达。双方争夺的是百相走留、军用控制权和新主体能否继续存在，实体钥匙只是必须一并夺取的危险工具。

### 4.7 操作舱为什么不能先救

1. 四名操作员随操作舱抵达，落地后把舱体当作远程操作室；E03四体停机后，铸环安全队给机体加装实体止动夹并移入事故隔离位，四人沿同一段地面桥从机旁返回，重新坐进原远程席并扣好固定带。
2. 操作舱没有独立飞行推进。E05运输舰进入悬空长轨前，四人收回地面桥，由运输舰腹部吊架把整舱升回外舷并完成对接；这是四人唯一有气密保护的回舰方式。
3. 交火碎片撞弯外侧副支撑并卡住转运门。战后顶部吊机先尝试接近，但维护框遮住外舷挂点；拉力测试显示硬拖会撕断仍承力的主锁。
4. 百相在运输舰内舷，也被维护框挡住，无法在原位把手伸到操作舱。
5. 折叠救援托架位于维护框外侧。E05结束时，第二牵引车已随牵引供电总闸切断而自动脱钩、停在框外；维护框与托架使用独立应急电路。运输舰舰腹挂接点已经滑进框内，主锁正在失效，现场没有时间把地面牵引重新接上。运输舰必须由本地船长开启舰载短滑推进器滑出一小段，托架才能展开，百相也才获得接舱角度。
6. 操作舱脱落后只能用姿态喷口减缓翻滚。百相可以跃出发射轨接住它，却没有远距飞行背包，无法抱着载人舱自行飞回。
7. 纪存停火后，馆守Z从万机馆外侧固定座发射牵引锚，钩住百相腰背承力框；万机馆主绞盘把百相与操作舱拉回托架覆盖区，艾达只托稳舱尾。沈砺与本地船长因此不是无视一个简单方案，而是共同选择剩余的高风险救援方案；错误在于他们相信受损主锁能撑过这段滑行。

## 六、一眼可懂的大动作词库

1. 完成双臂的百相在全球直播中连续切换四类模块，先作为Boss压住全队，随后与全队转身迎击真实外敌并赢下一场真正的大胜。
2. 四副测试体连同滑架被伪造外运单拖向运输舰；七海把实体U盾压到底，四台滑架同时急停，右掌在火光中受伤。
3. 韩秀雅拒绝第二盏确认灯，驾驶百相整机转身，以左臂接住倾覆的检修平台。
4. 四副测试体脱离滑架，从同一圆场朝四个方向奔出；每停下一副，B1里的纪存恢复一部分身体控制。
5. 黑城从泊位升起并展开城市级防壁；艾达放弃档案并弹出共鸣二号，米拉接住她，两台矢量机共同回身击穿已无人驾驶的侧胸记忆舱。
6. 万机馆百米舰身首次以正式多格母舰部署低速横入长发射轨，一侧甲板展开，现有主力依次出击；C01紧急航行战保持成立。
7. 玩家逼百相逐一放弃四类模块，但韩秀雅始终控制脚步，副驾核始终只给建议。
8. E05由E02退入侧线、仍可运行的第二台地面牵引车把运输舰拉进维护框；万机馆横入长轨时，玩家切断牵引供电总闸，牵引车断电、自动脱钩并停在框外，运输舰靠低速惯性滑完最后一段；维护框与救援设备保留独立应急电路。万机馆打穿护卫、压下百相四套模块，使这台55米军用巨体先失去战装局外接武装。社勇王剪断外侧服务盖锁销并沿导轨推开盖板，无牌一号从非增压服务舱拖出装有导航记录服务器与实体接驳钥匙的防震箱；内侧压力隔舱保持完整。交火碎片擦弯操作舱外侧副支撑并卡住转运舱门，主锁仍显示绿色，四名操作员只能继续留在舱内；胜利结算后遥测突然消失，发射倒计时仍在继续。
9. E06顶部吊机沿维护框移动，吊钩被外舷框梁挡住；试拉警报显示硬拖会撕断主锁。百相在内舷伸手同样被框梁阻住；框外牵引车失去动力，舰腹挂接点又在框内，无法及时重接。玩家先亲眼排除这些更简单的救援与移舰办法。
10. 地面席把沈砺的旧航路卡俯拍与四名操作员状态送进黑头指挥型副屏；伊玛妮不离开驾驶舱。本地船长在直接救援失败后，接受“使用舰载短滑推进器滑出维护框、展开救援托架”的方案。主锁提前断裂后，百相终于获得角度，整机跃出长轨接舱，艾达以飞行形态稳住舱尾。
11. 伊玛妮说“四个人也得回来”并挡住碎片；七海当场说明停火意味着百相、新副驾和完整公开遥测都会离开，纪存仍命令收枪。馆守Z向百相腰背打入牵引锚，万机馆主绞盘把巨人与操作舱一同拉回托架覆盖区；这条物理回收也让“万机馆选择放它回来”成为可见动作。
12. 轨外托架沿侧轨把操作舱送到运输舰尾部未受损气闸，四名操作员转入主舰，空舱留在铸环维修。米拉只切断军方远程航路接入，保留运输舰本地飞行能力。百相背向运输舰退入外泊架，实体固定后随舰离开；辅助席的新声仍继续回应韩秀雅。

### 必须明确

- 一张天空铸环C05灰盒：中央试验场、黑城泊位、主铸井授权室、装载坪、万机馆侧泊位与切入口、长轨维护框、运输舰内外舷、短滑余量、点火拱。
