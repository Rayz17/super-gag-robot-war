## 二、当前可复述故事

纪存主动参加百相公开复验，与韩秀雅把一次模拟Boss战打成全球直播的真实大胜。三方只同意把连接延长到最后一架受损侦察艇停稳；沈砺却为了抢下公开验证窗口，用现役试验权限实名签发“连续测试”附令，运输组从地面试验席推送，把四项新任务接回仍在回答问题的纪存，并越过四名操作员已签的安全条款，把断线制动改成维持最后动作。四副测试体属于战装局，也始终由四名操作员驾驶，所谓“导航备份”并没有复制四个纪存，只让四条未完成任务不断回到万机馆B1向本人追问下一步。

七海发现战装局冒用她七年前的电子签名，把自有测试体与天空铸环的公共接口、现场数据和在线任务捆在同一张外运单里。她用实体U盾废掉旧许可和假命令，右掌被过热接口灼伤。白鸢则发现自己为追查艾达而私自保留的可运行试运程序，已经被删掉驾驶员确认和现场叫停；玩家在本话决定保留原版、彻底关闭或共同重编。

玩家在单层环形跑道任选两副测试体先停机。剩余操作员也要求结束任务，沈砺却为保住最后两条线路，命令两副身体跨越橙色收容线撤入中央区，主动触发黑城。玩家切断余下两体的远程命令并压低黑城防壁后，艾达放弃以服从交换旧人生的捷径，主动弹出共鸣二号；米拉驾驶一号机接住她，两台矢量机在下坠中共同回身，击毁已经无人驾驶的侧胸计算舱。防壁消失，最后两名操作员完成停机，纪存醒来。

百相内部另有一枚一直存在、过去每天试验后都会清除的本地副驾核。它只学过纪存已经完成的少量导航样本，此后积累的却是百相自己的传感、韩秀雅的驾驶和当天战场。纪存醒来后，它仍显示“今日记录仍在使用”，并第一次问韩秀雅：“结束以后，今天会不见吗？”它没有纪存的人生，也不能驾驶百相；韩秀雅拒绝格式化，和曾帮助她重返驾驶席的沈砺正式分道。

本地船长告诉韩秀雅，安全发射窗口即将关闭，战装局接管组随后就会抵达。万机馆要求百相留场卸装、断线、隔离观察并交出服务器箱与实体钥匙；韩秀雅只掌握百相，不能替船长交钥匙或替沈砺切线，又必须在格式化以前把新副驾带走。即使搬箱与发射准备并行，百相仍只能走或留。韩秀雅亲自驾驶百相挡住发射轨，万机馆第一次作为多格母舰入盘；一台未被破坏的地面牵引车把运输舰拖入维护框。全队压制百相，并从固定气密隔壁外的设备舱夺下服务器，先获得完整胜利。混战碎片却在玩家眼前撞弯可拆操作舱外侧副支撑、卡住转运门；主锁仍亮绿，四名操作员只能困在舱内。下一话，本地船长先拒绝主点火，沈砺以主锁闭合、最低推力和接管组逼近说服他尝试短滑，船长亲手转动短滑钥匙，受损副支撑随即断裂。没有独立飞行动力的操作舱只能以姿态喷口减缓翻滚。旧事故七名归航者伊玛妮说“四个人也得回来”，新生副驾驶主动建议回头，韩秀雅驾驶百相跃出接舱。七海明确告诉纪存：放它完成救援，运输舰就能带走百相，战装局仍保有公开遥测与重新武装它的能力。纪存明知自己会失去不伤主舰便扣住百相的最后机会，仍然命令全队收枪，并让馆守Z向百相发射牵引锚，由万机馆主绞盘把对手和操作舱一起拉回救援托架覆盖区。

六话波形为：

**公开大胜与力量诱惑 -> 假签名、关系破裂与夺运 -> 四向追击、黑城What-if与纪存苏醒 -> 新生副驾开口与韩沈决裂 -> 正式多格母舰部署与服务器夺取 -> 可拆操作舱坠落、巨人回头与主动停火**

## 三、已经关闭的共性病灶

### 1. 概念不再混成一团

- 纪存的人形身体始终在万机馆B1，是当前机魂主载体。
- 四副测试体是战装局资产，由四名远程操作员驾驶；四项实时任务只是仍在向纪存追问的窗口。
- 导航记录服务器保存录像、样本、日志和接驳工具，不保存完整主体。
- 百相副驾驶存在于百相内部的实体副驾核，只拥有百相当天亲历。
- 白鸢的候选路线必须经陆衡、工房和操作者采用，不会直接驱动现实。

### 2. 战斗由人物欲望发动

- E01外敌是断冠在C04失败后新发的侦察楔，不是上一章漏掉的残兵。
- E03由沈砺主动命令剩余测试体跨橙线，黑城不是关卡到点自动刷新。
- E05由韩秀雅主动挡轨，她要抢在接管组抵达前保护新副驾；百相Boss不是军用模块强迫她参战。
- 可拆操作舱事故的物理前因在E05可见：交火碎片撞弯外侧副支撑、卡住转运门，主锁却仍亮绿。E06由沈砺与本地船长共同作出错误风险判断，不是远程点火或蓄意牺牲。

### 3. 操作权和控制权已经锁定

- E01模拟战由玩家操作现有编队；真实迎击阶段百相与共鸣双机成为临时可操作客援。
- E03米拉是一话客援；玩家负责切断两体命令、压低黑城防壁，艾达弹射与双机毁档是达成条件后的演出。
- 韩秀雅始终驾驶百相的脚步、平衡和停机；副驾只建议，战装局只限制军用模块。
- 伊玛妮驾驶黑头指挥型；沈砺始终位于地面指挥席。
- 运输舰由本地试飞组驾驶，船长全程持实体飞行钥匙。沈砺只能下达任务、提供风险判断和远程航路建议，不能替船长点火；事故后船长拔掉的是远程航路插头，不是把本来就属于自己的钥匙“转回本地”。
- 可拆操作舱没有独立飞行动力；它由运输舰舰腹吊机起降，仅有姿态喷口，脱落后不能自行返航。
- 百相只有短距跃迁能力。它能跃出接舱，却不能抱着操作舱飞回；馆守Z的牵引锚与万机馆主绞盘负责返收。
- 运输舰在E05退入维护框由一台剩余的铸环地面牵引车完成；E06短滑才首次调用舰载动力。

### 4. 机战爽点不再被伦理议题阉割

- E01先给百相、共鸣双机和旧编队一场完整大胜。
- E03以二号机弹射、一号机空中接机、双机半变形回身射击完成黑城Boss高潮。
- E05让万机馆入盘、全员出击、压制百相并夺取服务器，完整结算母舰胜利；E06才让玩家在“扣住一台仍可重新武装的军用巨体”和“让它完成眼前救援”之间作出不可兼得的选择。
- 玩家永久获得米拉与共鸣一号、万机馆移动母舰与舰员支援、地方旗舰提前协力和百相“中立应答”回归入口。

### 5. 尺度与资产没有靠临场解释

- 百相55米，黑城40米，馆守Z18米，旧拳王3米，万机馆约130至160米低矮舰体。
- 旧拳王只击打外露推进锁与轨道吸附器，位移来自大机与轨道惯性。
- 万机馆只低速移动并展开一侧甲板，不人形化、不暴走、不让馆藏参与复杂机构联动。
- 四副测试体共享一套工业Rig；黑城复用C04外壳；C05高成本资产包维持既定上限。
- 服务器箱位于固定压力隔壁外的非气密设备舱。社勇王只解除外盖锁销并让盖板沿导轨滑开，运输舰气密与后续飞行不受影响。

## 四、人物与关系审定

### 纪存、七海、白鸢

纪存先享受能力与大胜，危机不是他又犯了一个芝麻小错。七海隐瞒七年前见过同类接驳事故，白鸢隐瞒自己为追艾达保留了可运行程序，纪存则承认最后一艇前的延长是自己同意的。三人都没有被写成单纯受害者，也没有靠一句“我理解”复位。

E04的误触、抓腕、道歉、先问再碰和请两人离开B1，是关系伤害而非成人卖相清单。E05三人能够重新分工并赢得母舰战，证明合作仍在；E06换药只恢复身体照料，信任与恋爱没有结算。

### 韩秀雅、沈砺

两盏确认灯从E01的共同骄傲，经过E02第一次空等，发展到E04“当年你先问了我”的关系反转。十二去七归的旧航路卡说明沈砺为何害怕等待，E01标准导航救人又强化了她的误判；E06伊玛妮以“四个人也得回来”证明旧幸存者不会无限为她背书。韩秀雅的离开因此是价值与亲密关系同时断裂，而非看到反派真面目。

### 米拉、艾达

C04建立观景廊亲密、`R-04`编号、黑城第一次追击；C05先让两机完整并肩获胜，再给艾达一份真假未明的旧人生。最终由艾达主动放弃、主动弹射，米拉负责接住，两人共同开火。她们同时活着，却没有因为一次配合自动复合。

## 五、下放L4.5与L5的风险

以下问题不能反向膨胀L4，也不能被遗忘：

1. E01容量较大，L4.5必须安排清楚试航准备、Boss挑战、真实袭击、侦察艇返航和四任务越界的承载顺序。
2. Reader前台少说“公共接口、在线任务、样本标签、接驳工具”等后台名词，优先用画面、按钮、角色动作和可见结果表达。
3. E04三组争执不能写成主题辩论；每场只围绕当时的伤、一个没说出口的事实和一个旧动作失效。
4. 成人关系要有吸引、身体距离和未完成欲望，但不能再次变成对称摆拍。
5. 伊玛妮必须保持独立声线和正面价值，不能只负责给沈砺洗白。
6. 轻松呼吸不能全交给唐胶吐槽；试航准备、纪存醒来和母舰点火前都应有群像生活。
7. “万机馆｜本次开放资料”负责整理已经发生但不宜塞进对白的阶段知识，不得替剧情解释关键因果。
