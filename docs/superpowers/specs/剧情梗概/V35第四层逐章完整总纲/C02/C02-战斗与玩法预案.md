### 可操作单位与可见奇观总览

各话的“玩家单位”即本话可操作单位；临时切控、自动援护与剧情出场严格区分。可见奇观依次升级为无牌一号在铜锣前打不出拳、旧拳王命名半招、逆转天冲拳首次把师父送出界、必杀技拿下对全装冠军的第三分、旧外轨断裂、万机馆入图、冠军主动卸装，以及两台机共同把舞台巨炮送回海侧。冠军只在E04产生一次。

## 二、构筑系统的章内样板

### 玩家选择

玩家不替无牌一号挑一件会自动完成动作的装备，而是在缩尺素体上拆解它缺失的后半招，并选择本轮训练先练哪一项：接拳后的重心、主动踏入的时机，或拳与脚同时向前。三种选择只改变E02试招的操作提示和失败演出；正式比赛仍要求玩家把四个动作连起来。

全尺寸工房只在试验锤周围布置通用防摔架、停机线和地面标志，不制造三套永久模块。E03完成的逆转天冲拳属于无牌一号本人。

### 玩家必须经历的转换

```text
缩尺模型拆解动作
-> 唐胶说明动作意图
-> 陆衡/本地工程员核验身体活动范围
-> 兜灯设置停机保护并开始试招
-> 玩家练习接住、蓄势、踏前与出拳
-> 无牌一号在真打中自己完成
```

玩法保留Build系“用缩尺身体把想法摆出来”的快乐，但不让工程说明抢走修炼戏。玩家设计的是打法，机器人完成的是战斗。

## 三、E01：无牌一号，出场！

### Hub阶段

玩家第一次自由探索木桶街，目标不是收集一堆设定，而是完成三件当前任务：

1. 去泊位确认万机馆需要的奖品转子。
2. 去合作社找到能够参赛的全尺寸机体。
3. 去报名处了解木桶杯和杂鱼港的真实交换条件。

第三项必须让玩家亲眼确认：转子由杂鱼港出资购入，赛事赞助、直播和搬迁款都以“冠军取得转子”为交换；杂鱼港拒绝赛前出售或外借，万机馆也拿不出现金、抵押和商业保险。报名台还会拒绝把待移交的万机馆当作商业参赛主体：在舰人员只有事故后的临时保全权。赵梅合作社承担本地赛事担保，无牌一号代表自己出赛，万机馆只借出赛后必须归还的必要设备。参赛由现实选择收束而来，不靠一句“规则如此”。

泊位阶段还要用一张简单路线图排除四条捷径：C01应急余量已在靠泊时耗尽，万机馆不能直达工务城；旧转子主轴已经受热弯曲，木桶街没有整件校直和动平衡设备；货柜领袖只能牵引位于连续重载托架上的船台和其他陆路巨构，不能跨水空段拖航；赛事结束后泊位要交给搬迁，普通岸电也不能长期维持旧舰主循环。馆守Z十八米本体留在外泊位，它把注意力转到B1轮式终端跟随兜灯检查，既回收C01状态，也让主循环损伤成为本章现场发现。

可选交互只负责气质和生活：未拆派与改件派争论、有人靠卖藏品支付现实账单、有人骂杂鱼港炒价也承认它找回了买家。赵梅的早期错单和分派图各出现一次，不在这里讲完整家庭史。

### 资格战类型

**类型：** 非致命环形障碍SRPG。

**地图：** 锁定货运环外圈。两台门将机从左右半场封路，报名铜锣位于中央终点。

**玩家单位：** 无牌一号；万机馆提供有限岗位支援，不能出现在擂台上。

**中立/对手：** 使用共享赛事Rig的两台报名门将机。它们只负责守住最后一个公开席位，不获得具名生命周期。

**当前目标：** 九十秒内突破两台门将并击响报名铜锣。

**核心规则：** 比赛按完成动作和保持机体可运行结算，不以击毁对手为目标。攻击只造成失衡、退场和部件损耗。

### 三段推进

1. **左右夹击：** 无牌一号没有主武装，玩家先利用不对称肩甲撞开一台门将，再用赛道柱迫使两机无法同时正面对撞。
2. **有限横移：** 借来的舰侧推进模块只能发动两次；每用一次，万机馆侧向控制就维持灰色。玩家必须把有限位移留给真正的封路，而不是把它当飞行背包。
3. **铜锣前：** 最后一台门将正面压上，无牌一号接住重击，肩、腰和腿一起蓄势，右拳已经拉回，却在踏出第二步前停下。倒计时将尽，它改用肩头撞响铜锣。玩家看懂的谜团很简单：这副身体会接、会收拳，却不会把最后一拳打出去。

**胜利演出：** 铜锣响起，无牌一号取得公开席。完全版王者用旧编号叫它，两台身体短暂站回旧最终话的半套位置。

**失败处理：** 资格赛允许重试，不把剧情失败解释成世界线。重试前赵梅和兜灯会根据战损提供一项普通调整。

## 四、E02：必杀技未完成！旧拳王的挑战

### 构筑与制造

先完成缩尺构筑和全尺寸转换。白鸢在这一流程中途抵达，因此玩家先看见她与纪存、唐胶在现实工房里发生冲突，而不是让她以神秘远程能力救场。

### 构筑、重涂小品与指导战

**类型：** 缩尺构筑小游戏 + 全尺寸训练 + 非计分指导战。

**地图：** 缩尺构筑室、全尺寸工房和相邻训练场；货运环只用于显示已经锁定的四强签表。

**玩家单位：** 无牌一号；后半短时切换旧拳王，体验其非致命武斗规则。

**地方单位：** 红、蓝、黄三台同骨架飞行实机只做空域安保短演示，不参加积分、不给无牌一号让路。模型店先用三个同模重涂盒制造笑点，再用三台实机的飞法和工作差异证明“同模不等于同一个角色”。

**当前目标：** 把缩尺动作翻译成一套真机可练的方案，再由旧拳王用一次非计分指导战确认缺失动作。四席在本话开头就写清：卫冕冠军完全版王者、挑战者种子旧拳王、地方优胜坞工杰克、E01公开席无牌一号。

**核心规则：** 玩家所选构筑只辅助承受、进身或出拳稳定中的一项，也留下一个清楚短板；它不能替无牌一号踏出第二步。切换战术比堆更多部件有效。

### 玩法推进

1. 玩家在缩尺模型上选择训练重点；唐胶说清动作意图，陆衡和本地工程员删掉无法放大的部分，兜灯确认真机可以安全试练。
2. 模型店的三盒同模重涂引出小品；外场三台同骨架飞行实机用高速巡查、低速护航和远距警戒三种动作掠过，完成机体首登和E05伏笔。
3. 旧拳王进入不计分指导段。玩家先控制它打出足以触发蓄势的重拳；无牌一号右拳收紧却迟迟没有落下，玩家主动让旧拳王收招，避免把训练打成事故。
4. 无牌一号再次尝试主动进身，右脚抬起后又落回原地。旧拳王给这未完成的招式取名`逆转天冲拳`；公开签表将两者排进同一场半决赛，另一场由完全版王者迎战坞工杰克。

**话末钩子：** 白鸢把旧分镜与无牌一号的半套动作并排，发现两者相同；她只说这张画不是为今天的比赛画的。

## 五、E03：逆转天冲拳！师徒真打

### 后台调查玩法

玩家不在一台终端上读答案，而是在三个地点取得互证：

- 合作社三层工作资料；
- 无牌一号和完全版王者身体上的旧授权痕；
- 白鸢保留的旧分镜与杂鱼港旧宣传片。

一段短分派玩法让玩家代赵梅把资料交给模型师、工程员和旧物主复核。玩家由此看懂她如何工作，也看懂她不是突然掌握所有技术。

实机痕迹不是在菜单里自动取得。兜灯先完成无牌一号停机和实体支撑；玩家随后控制跌跌穿过低位检查道，把相机送到腰髋工号下方，再让机器犬沿安全路线牵住信号线并回传画面。这是一段小尺度探索，不增加第四种证据，也不把两台小机器人写成维修专家。

### 半决赛类型

**类型：** 一对一非致命擂台SRPG。

**玩家单位：** 无牌一号。

**对手：** 旧拳王。

**当前目标：** 把旧拳王堂堂正正送出界外；不能靠剧情自动判胜。

**核心规则：** 常规伤害改为重心和界线压力。无牌一号只有在正面接住一次达到阈值的重击后才进入蓄势；旧拳王会用轻重、虚实和换位拒绝把完整力量白送给它。玩家必须主动抢到距离，逼出真正一拳，再决定何时踏出第二步。

### 情节与玩法回收

1. 旧拳王以扎实近战压住无牌一号，不拿年龄和旧伤当笑话；连续小拳和虚招让“等对方送力”彻底失效。
2. 无牌一号主动向内抢位，第一次不是为了替别人挡，而是为了逼旧拳王认真出拳。
3. 旧拳王重拳落下，无牌一号接住并蓄势；玩家踏出此前缺失的第二步，整个身体跟着拳头向前。
4. `逆转天冲拳`第一次完成。旧拳王正面接下，整机被送出界外，却仍以双脚落地，承认学生堂堂正正赢了。

**胜利演出：** 拳风越过界线，旧拳王在场外滑出长痕仍没有倒。它回到边线，把自己愿意扮演“被徒弟超越的师父”说成个人选择，并提出继续训练无牌一号；能否带着十七米身体随舰，要到E05由本人和旧武斗馆完成维护交接，不由奖杯自动解锁人格。

**决赛发动：** 胶价王公开追加赛后演出条件。两台核心机看完旧资料后都主动同意参加冠军战，也分别决定是否参加赛后演出。普通观众进入固定观景厅，货运环落锁，中央检修架中的冠军转子只做低速空转。

赛前检查把舞台设施说清楚：赛后终幕使用装在临海外侧运输车上的舞台巨炮，只装烟光弹；外侧黄色边线之外只允许舞台车通过，巨机不得进入。这条边界在事故前必须被玩家看见。

## 六、E04：全装王者！三比二之后的最终话

### 第一阶段：真正的冠军战

**类型：** 锁定擂台非致命冠军战。

**地图：** 货运环锁定在赛事泊位。普通观众位于固定观景厅，中央检修架与赛场隔离，外侧舞台轨暂不开放。

**玩家单位：** 无牌一号。

**对手：** 完全版王者。

**当前目标：** 先得到三分。击倒并保持五秒，或让对手全身出界，各得一分。

**核心规则：** 完全版王者的外翼、双盾、钻进和背负式重炮各自对应一种明确战法；装备切换有可见准备动作，但不能靠打掉所有配件直接获胜。无牌一号必须在真打里主动制造足以发动`逆转天冲拳`的重击。

完全版王者依靠全装先取两分，无牌一号以贴身抢位和必杀技追到二比二。最后一分，王者以盾组正面压上，无牌一号主动踏进拳距，接住盾击后发动`逆转天冲拳`，将王者全身送出界。比分、冠军灯和转子奖品确认连续出现：无牌一号三比二夺冠，冠军战到此结束。

### 第二阶段：赛后失落最终话演出

**类型：** 短动画与角色动作，不计比赛分数。

旧影像只需让玩家看懂五个动作：轨道堡垒歼灭炮瞄准城市；王者耗尽装备突入；A-7在炮门内侧撑住发射闸，把胸甲和路线钥匙交给王者；王者摧毁堡垒；黎明归来时呼叫A-7三次，没有回应。白鸢三年前画过A-7走出来的补页，但本次没有公开或授权使用，现场只按原存档搭设角色站位和无动力舞台巨炮。

无牌一号走到A-7应当消失的位置，却转身离开；完全版王者也放弃胜利姿势，追出原分镜。两台机主动改变演出，白鸢根据旧分镜做的短期路线当场失效。

### 第三阶段：旧外轨事故

完全版王者带着全装越过黄色边线，踏上只承载舞台车的旧外轨。轨道先弯再断，王者右腿与一侧外翼被卡；舞台巨炮运输车失去水平，断电后仍因重力向临海侧下滑。

**当前目标变化：** 白鸢立即叫停演出并协助观众从固定厅撤向Hub；七海要求保存原始画面并切断演出动力；纪存把下一阶段目标归成三项：固定炮车、救出王者、让万机馆接住临海侧。

**话末：** 无牌一号本可回到内环，却转身站到炮车与王者之间。三台重涂飞行机分向不同空域；货柜领袖和地面车队接上万机馆船台，E05无缝开始。

## 七、E05：新的最终回！万机同援

### 第一阶段：三机分工与地面固定

**类型：** 空域侦察、护航与远射支援。

**玩家单位：** 三台重涂飞行机按任务临时切控；坞工杰克与地方工程车作为地图支援。

**当前目标：** 红色高速机绕环标出继续变形的外缘；蓝色护航机挡开碎片并护送工程车；黄色远射机等待固定索先承重，再打断两条拖拽炮车的卡索。

三个目标依次开放。红机完成高速侦察后因过热退出低空；黄机若在固定索承重前开火，会使炮车继续下滑。规则用大动作和地图状态表达，不做连续微调。

### 第二阶段：多格母舰支撑

**类型：** 多格母舰部署与区域稳定。

**玩家单位：** 万机馆、馆守Z、火种货柜领袖、旧拳王；飞行队改为自动援护。

**当前目标：** 让万机馆沿平行作业道抵达临海侧，并建立一条不会继续下沉的地图边。

**核心规则：** 万机馆借出舰侧推进模块后不能自己横移，必须由货柜领袖和地面车队牵引承载舰体的船台托架。万机馆只用舰侧宽面接住一侧，另一侧仍由地面支脚承担；馆守Z固定一段断桥，旧拳王清开卡住王者的外装。任何一台都不能包办整场。

### 第三阶段：冠军自主卸装

胶价王拒绝直播组把事故剪成“A-7再次牺牲”的宣传片，开放赛事自救设备，并接通旧承包商当值维护员确认事故拆离。装备仍归原持有人；决定拆什么、何时拆的是完全版王者本人。

- 外翼铺成一段撤离桥；
- 双盾保护坞工杰克和地方工程车；
- 背负式重炮移到内侧，减轻被卡一侧重量；
- 头冠保持承重警报，让玩家知道王者还能撑多久。

**当前目标：** 保护完全版王者完成卸装，而不是趁它卸装时击破它。

### 第四阶段：舞台巨炮与共同终幕

**玩家单位：** 无牌一号与完全版王者共同作战；其余单位负责稳定地图和清场。

**当前目标：** 完全版王者以基础身体托住无动力炮车，无牌一号接住炮车回落的力量；玩家在正确时点发动`逆转天冲拳`，把舞台巨炮送回临海拆解架。随后保护工程车固定底盘、工作人员卸走烟光弹箱并让吊机移走炮身。

**核心规则：** 王者负责托住并把炮车送入发力位置，无牌一号负责最后一拳。两台机共同完成的是旧最终话之后的新动作，不是另一场冠军赛。

### 第五阶段：赛果、交割与启航

裁判重申E04三比二结果，无牌一号已经是冠军。救场表现不换分，也不触发重赛。无牌一号确认把冠军转子交合作社限定代管并用于万机馆维修。

万机馆先把热损旧转子移到B1旁侧锁架，龙门吊再从中央检修架卸下九米奖品转子；货柜领袖牵引运输架，泊位吊机经B1大型货运升降台送入空位。全尺寸工程组完成连接和低功率试转，兜灯收回舰侧推进模块，陆衡只批准一次升到航行功率后的连续运行窗口。

无牌一号与共同维护人、旧拳王与旧武斗馆分别完成维修责任交接后才成为常驻机体；万机馆临时保全组只承担舰上泊位和日常维修，合作社与原持有人把保险延伸至工务城，不取得两副身体的所有权。完全版王者、坞工杰克和三台飞行机留守木桶街，成为后续可回援的地方力量。

## 八、战中叙事预算

每个阶段的战中通讯只承担一个功能：

- E01：说明当前赛事目标或借件代价。
- E02：指出构筑强项/短板，不讲模型史。
- E03：表现旧拳王停拳和无牌一号完成动作，不讲机魂百科。
- E04：三主角改变当前目标，不在战中解释全部合同。
- E05：每台机确认自己负责的区域；冠军卸装时只保留角色反应。

赵梅学习史、旧作品身份、杂鱼港成本与权利来源都放在Hub、ADV和调查段。战斗不承担背景讲座。

## 九、IP与机甲文化在玩法中的落点

| 投射 | 玩法化方式 | 禁止退化 |
| --- | --- | --- |
| Build系“我的机体” | 缩尺素体拆解动作、实机试招、玩家练习并由机体在真打中完成 | 模型直接巨大化；把工程件当成自动必杀技；只换外观皮肤 |
| 机器人拳击、G高达武斗精神与“未完成奥义” | 旧拳王真打、师徒修炼、可喊出名字的逆转天冲拳、非致命出界规则 | 手套参战；复制尊者高达造型、石破天惊拳动作或浪客剑心招式与整套台词 |
| 超级机器人腰斩最终话 | 实机旧站位、支援机拒绝牺牲、主角机追求终局 | 只播一段致敬动画；角色毫无自主性 |
| 全装甲与配件包文化 | 冠军装备真实有效；终局由本人卸装并改变地图 | “配件多所以蠢”；主角把装备打烂等于成长 |
| 变形生命 | 货柜领袖两态重载动作改变母舰位置 | 一句口号后万能拖拽；提前演完星火五车 |
| 同模重涂 | 三台共享Rig但任务、习惯和支援位置不同 | 只换颜色便计三台新机 |
| SRW式全员支援 | E05按尺度分工，最后给两台核心机留出舞台 | 全员挤在中央打一套同质攻击 |

短台词锚点可以直球，但不得用台词代替场面。旧拳王可以被胶价王包装成“流派不败”，再由它真实输过的战绩拆台；“我来组成头部”式口号留给合体包，本章不硬塞。

## 十一、制作与复杂度验收

- 主要战场只制作一座货运环的赛事锁定、旧外轨断裂、救场后三种差分，不另做移动城市或追车地图。
- E01、E03、E04复用同一货运环赛道并逐步开放区域；E02主要复用构筑室和全尺寸工房；E05使用同一货运环的危机差分，不再新增复赛场地。
- 三台飞行机共用Rig和大部分动画，但有不同武装、飞行动作与任务逻辑。
- 完全版王者的装备均在E01展示、E04对战、E05卸装三次复用。
- 同一阶段只显示一个主要目标和一个核心规则。
- 任何需要连续近景才能明白的锁舌、卡扣、接口和厘米偏差都不进入胜负条件。
- 观众在E04前离环，人类只通过ADV、岗位支援和战中通讯参与巨机战。
- 五话每话都有机体行动、玩家所得或玩法变化，不出现连续三话只讲背景。
