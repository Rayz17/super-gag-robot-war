# C02《木桶街，万机初开：最后一届木桶杯》四视角章审与问题账

> 日期：2026-08-05

> 审查对象：当前五话L4总纲、逐话结构表与状态账。旧四话稿、移动货运环方案和事故后重赛方案不参与判定。

## 一、总判定

**内部结构审查：PASS。用户对机械合成Reader的复读验收仍未发生。**

本章现在拥有一条清楚而有变化的五话波形：

```text
万机馆为了继续航行必须参加木桶杯
-> 无牌一号取得资格，却打不出最后一拳
-> 模型构筑、师徒训练和白鸢追责把旧终局带回现场
-> 无牌一号学成必杀技并以3:2击败全装冠军
-> 赛后两台机改演旧最终话，王者越过老化外轨引发事故
-> 全员救场，两台机共同完成没有牺牲者的新终幕
-> 维持赛果，交割转子，两台主力与白鸢登舰，驶向工务城
```

本轮审查不再以“设定都出现了”为合格依据，而检查四件事：玩家是否先看懂、人物是否主动改变事件、机器人是否拥有自己的高光、现有资产是否能把故事演出来。

## 二、游戏制作人视角

### 已成立

- 五话玩法不同：Hub求生与资格战、模型构筑与指导战、资料调查与半决赛、冠军Boss战与事故突变、母舰支援战与重件安装。
- 木桶杯赛制只有四席：完全版王者、旧拳王、坞工杰克和资格战胜出的无牌一号。三台重涂飞行机不挤占名额。
- 货运环仅在E01开场被拖入泊位，落脚后全章锁定。E04只新增局部外轨断裂态，不制作一张边移动边战斗的新地图。
- E04已在事故前决出`3:2`。E05没有第二场缩水决赛，全部制作预算服务于空域清障、母舰接近、冠军卸装和双机共同终幕。
- 完全版王者的外翼、盾、背炮和头冠经历首秀、冠军战、主动卸装与救场复用；不是只为一幕制作的装饰。
- 九米转子的交付有清楚的大动作：旧件移出、新件吊运、送入B1、接合试转。Reader不需要讲内部机械百科。
- 章末永久奖励明确：无牌一号、旧拳王、构筑台、新转子、木桶街回援网络和白鸢登舰。

### 制作边界

| 风险 | 处理 |
| --- | --- |
| 260米环、百米舰和多台巨机同屏难读 | 每阶段只突出一条大关系：外轨断裂、万机馆接一侧、王者卸装、双机送炮车 |
| E05参战单位过多 | 红蓝黄三机依次完成侦察、护送、远射；其余单位转自动援护，不要求玩家逐台调度 |
| E03资料容易变成信息墙 | 原画、实机工号、维修册各用一次短互动；赵梅只讲“怎样学会继续工作”，不朗读一生 |
| 模型与实机制作链过重 | 只演缩尺姿态、一次工程否决、一次全尺寸安全试招；详细边界放开放资料 |
| 人类置身巨机事故不可信 | 普通观众始终在固定厅，事故后先撤离；人类不作为巨机棋盘单位 |

**制作人裁决：** 可制作，但E04-E05必须遵守“大画面优先”。任何需要解释三层内部机构才能成立的动作应改成更简单的外部动作。

## 三、专业编剧视角

### 已成立

- C02不重复C01的闭馆、火灾和城市救援，而切换成明亮、喧闹、有输赢的机器人赛事篇。
- 无牌一号有独立欲望：它不是为了帮万机馆才临时被推上场，而是早就想把自己的第一场正式比赛打完。
- 完全版王者不是系统控制的反派。它珍惜冠军身份，也真心想完成腰斩作品；它在输掉比赛以后仍追出旧站位，正因为它不能再接受搭档消失。
- 赵梅的现实情感线与主事件相连：她从儿子的笔记、错件、退件和客户询问一点点学起，最终建立合作社；她帮助无牌一号参赛，却不突然掌握巨机工程。
- 纪存主动提出合作方案、组织构筑与比赛、在事故中改变玩家目标，并坚持事故不改写既有赛果。
- 七海的远程行动有边界：反对押上万机馆退路、要求区分比赛与演出、发起原片保全并承担署名风险；她不批准赛事或遥控现场。
- 白鸢有清楚的到场原因。她追查被盗用的三年前补稿，在短期预演被两台机主动选择推翻后停止演出并参与撤离；她不是纸面法师。

### 戏剧波形检查

| 话 | 情绪主色 | 关系或人物质变 |
| --- | --- | --- |
| E01 | 巨物开场、求生压力、资格爽感 | 唐胶被迫面对赵梅；纪存与七海第一次就全舰风险硬碰 |
| E02 | 构筑快乐、武斗喜剧、追责紧张 | 白鸢到场；七海与她经纪存介绍初识；无牌一号获得师徒关系 |
| E03 | 失去与接续、真打释放 | 赵梅从“亡子母亲”成为行动者；无牌一号亲手学成必杀技 |
| E04 | 冠军爽战、胜利、旧命运破裂、事故骤降 | 无牌一号成为冠军；纪存与白鸢互救但仍争执；王者从对手变成被救者 |
| E05 | 群像协作、共同终幕、离别与启航 | 胶价王第一次损失商业利益；王者和无牌一号改写关系；白鸢登舰 |

### 剧作风险

1. E03不可让五个人轮流发表主题；“赵梅拿出什么、机体看见什么、比赛因此怎样改变”必须先于说明。
2. E04必须先让玩家享受完整冠军战和明确胜利，再开始赛后演出。事故不能吞掉无牌一号的冠军高光。
3. 王者越线要有三次前置：认出A-7、表达不愿作品再次中断、在输掉比赛后仍选择参加演出。这样事故是性格后果，不是突发降智。
4. 三主角关系必须通过行动改向：七海的要求改变现场安全准备；白鸢的停止演出改变事故扩大方式；纪存的调度使救援成为可能。理念对白只能补充，不能代替行动。

**编剧裁决：** 章发动机成立，事件有大开大合。Reader的主要风险不再是主线贫弱，而是解释欲和对白机锋重新把故事压扁。

## 四、机器人文化专家视角

### 已成立

- Build系精神落在“玩家先用缩尺模型找到自己的打法，再由工程现实删改，最后由实机本人完成”，不是塑料模型直接巨大化。
- 无牌一号与完全版王者承载“腰斩动画、支援机牺牲、主角接甲、黎明呼叫无回应、What-if救回意难平”的完整情节，不只是外形影射。
- 旧拳王承载机器人武斗的师徒、真打、必杀技修炼与夸张报招。它停拳不是软弱，而是强者决定怎样教；半决赛也没有放水。
- 完全版王者让全装甲先成为压倒性的真实优势，再由本人主动卸装。作品没有宣判“爱配件是错的”。
- 红蓝黄三台同骨架飞行机先以模型盒承担重涂笑点，再以全尺寸地方机体完成不同救援动作；既好笑也有回收。
- 火种货柜领袖以载具与作业人形两态解决真正的物流问题，提供变形生命的劳动感和人格，而不是只在台词里致敬。
- “角色惯性”允许机魂认同旧角色。自由不等于人人反剧本，而是知道结局后仍能选择怎样继续演。

### 文化风险

- 原作精神必须通过可辨认组合出现：轨道堡垒、A-7撑闸交甲、王者黎明三次呼叫、师徒真打、全装Boss与同模重涂。不能只靠资料卡告诉玩家“这里致敬了某类作品”。
- 台词梗可以直接使用玩家熟悉的短锚点，但必须由合适角色在合适时刻说，不能改成绕口的“高级原创句”。
- 原创机体需要靠战绩和关系获得魅力。无牌一号必须在E03、E04、E05连续拥有三种不同高光，而不是只被设定成“很重要”。

**机器人文化裁决：** 本章已经像机器人大战，而不是模型市场社会议题。Reader必须保住机体出场、招式、胜负、宿敌和入队的拥有感。

## 五、目标玩家视角

玩家一章内可以得到：

- 一台从资格战开始亲手培养、在半决赛学成必杀技、冠军战获胜并正式入队的主力机；
- 一位能真打、能教学、能在事故中继续有用的旧拳王；
- 一个全装压迫感成立、输得堂堂正正、后续还能回归的宿敌；
- 模型构筑、机器人竞技、旧作调查、母舰救场和重件安装五种可辨认玩法；
- 赵梅现实故事、唐胶旧关系、三主角首次同场张力以及木桶街生活生态；
- 木桶街飞行队、货柜领袖和地方工房作为未来能回应的真实网络。

玩家仍可能不满意的点：

1. 如果E01用大量权限解释拖延无牌一号出场，会失去开局兴奋感。
2. 如果E02把动作原理讲得比师徒过招还长，必杀技会像工程作业。
3. 如果E03的旧最终话不够壮烈，E04-E05的改写就没有分量。
4. 如果E04冠军战只有结果摘要，E05再热闹也补不回玩家亲手击败王者的爽感。
5. 如果三主角继续人人说半句话、互相装腔，关系线会再次失真。

**目标玩家裁决：** 值得进入Reader，但需要用直白、具体、有人情味的场面兑现，不可重新变成精密说明书。

## 七、Reader门槛与剩余问题账

### 必须做到

- 每话正文先交付故事和机器人高光，复杂边界进入“本话已公开情报”。
- 比赛规则各用一句话讲清，并用明显的记分牌、铜锣、出界或倒地反馈显示。
- 每台首次登场机体都用轮廓、招牌动作和结果建立记忆，不靠名字列表。
- 对白优先回答“这个人此刻为什么开口”，避免“你可以……但……”“不是……而是……”“不替谁决定”等作者句式。
- E04、E05标题、赛果、事故时间点和机体去向必须与状态账一致。

### 仍待用户判断

1. 机械合成后的五话Reader是否整体好读、有趣、够燃。
2. 赵梅现实故事的情绪强度是否足够而不过度拔高。
3. 三主角对白与相处是否终于像具体的人，而非三位主题发言人。
4. 无牌一号、旧拳王、完全版王者是否已经达到玩家愿意长期记住的魅力。

内部四视角审查不能替代这四项用户创作验收。
