当前版本已经形成一条能被普通读者复述的主线：万机馆缺少九米主循环转子，因此参加木桶杯；无牌一号在比赛中学成自己的必杀技并以`3:2`击败完全版王者；赛后，两台机自愿重演一部未完成动画的最终话，却因完全版王者越过只允许轻型舞台车通过的旧外轨而引发事故；众机救场并完成一个没有牺牲者的新终幕；既有冠军结果不因救援被改写；奖品随后以可见的吊运和安装流程进入万机馆。

## 二、白话因果复述

1. 万机馆逃离原城后抵达木桶街，才发现原装主循环转子已经热损。当地无法修复整件，剩余动力也不足以抵达工务城。能临时替代的九米转子正在杂鱼港的固定货运环中央做低速测试，并被列为最后一届木桶杯冠军奖品。
2. 万机馆是待移交资产，不能以商业主体报名。赵梅合作社愿意担保由多人共同维护的无牌一号参赛；无牌一号亲自确认，如果夺冠，就把转子交给合作社受限代管并安装到万机馆。万机馆只借出一件赛后必须归还的舰侧推进模块。
3. E01资格战规则简单：九十秒内突破两台门将并撞响铜锣。无牌一号接得住重击，却始终无法把蓄起的力量向前打出去。玩家第一次明确得到本章欲望：让一台总替别人收尾的机体，完成属于自己的比赛。
4. E02中，缩尺模型只帮助拆解姿态和动作意图，不能变成实机零件。唐胶解释手作与动作语言，陆衡和本地工程员判断全尺寸身体是否做得到，兜灯负责停机和训练安全。旧拳王用一次非计分指导战逼出半招，并把它命名为“逆转天冲拳”。同模重涂笑话先由模型盒建立，再用红、蓝、黄三台地方飞行实机证明同骨架也能活成不同的机体。
5. 白鸢因自己的三年前补充分镜被杂鱼港擅自用于宣传而到场。她、实机工号和赵梅保存的维修资料共同确认：无牌一号原本是未播最终话里必然牺牲的A-7，完全版王者则会带着它留下的护甲摧毁轨道堡垒、在黎明三次呼叫却得不到回应。白鸢的补稿曾试图让A-7活下来，却留下歼灭炮仍在充能的空白页；这份补稿没有被赛事采用。
6. E03半决赛中，无牌一号主动抢进旧拳王的重拳范围，第一次完整做出“接住、蓄势、踏前、出拳”，以逆转天冲拳获胜。另一场半决赛由完全版王者击败坞工杰克。两台决赛机都在知道旧角色关系并拥有退出权后，选择继续比赛。
7. E04冠军战采用先得三分：有效击倒并维持五秒，或把对手整个推出界，各得一分。完全版王者凭全装先取优势，无牌一号最终以`3:2`获胜。比赛已经结束，奖品归属也已经确定。
8. 两台机随后自愿参加一段不计分的旧最终话演出。无牌一号不肯再站进A-7必死的位置，完全版王者也没有留在胜利站位，而是追了出去。它越过只允许舞台运输车通过的黄色边线，旧外轨断裂，王者与无动力舞台巨炮的运输车一同被困在临海侧。事故来自清楚可见的承载越界，不来自神秘程序或货运环突然启动。
9. E05中，三台地方飞行机分别侦察桥面、护送人员和破坏继续拖拽炮车的变形支架；火种货柜领袖与地面重载车把万机馆沿平行作业道拖到事故区。万机馆只能接住临海一侧，馆守Z只能固定一处断桥，不能一舰包办救援。
10. 胶价王拒绝把事故剪成“A-7再次牺牲”的卖点，解锁自救设备并承担停播损失。完全版王者主动卸下装备脱困，装备仍然在救场中发挥作用。它把断电炮车托回发力位置，无牌一号用逆转天冲拳将炮车送回临海拆解架。两台机共同完成了比旧剧本更完整的最终回。
11. 裁判维持E04的`3:2`结果：无牌一号是冠军，事故后的救援不计分，也不重赛。无牌一号再次确认转子用途。旧件先从万机馆B1移到旁侧锁架，新件才由龙门吊、重载通道、泊位吊机和大型升降台送进空位。低功率试转不算正式航程；一旦升到航行功率，万机馆必须不停机抵达工务城。
12. 无牌一号和旧拳王在本人及原持有人完成临时维护交接后登舰；完全版王者、坞工杰克和三台飞行机留在木桶街。白鸢以追查机体后续处境为由登舰，七海仍留在原城。C03由正式运营身份、长期保险和转子校正自然发动。

## 五、已通过的关键核验

### 权限与处分

- 七海没有追认C01的离馆，也不能授予木桶街赛事资格。
- 万机馆临时保全组只能停泊、保命、必要维修和接收受限替换件。
- 转子赛前属于杂鱼港；无牌一号夺冠后决定用途；合作社代管不等于万机馆取得所有权。
- 无牌一号、旧拳王和完全版王者都有身体持有人、维护关系和机体本人意愿。

### 模型与实机

```text
缩尺模型表达造型、姿态和动作意图
-> 唐胶解释手作与动作语言
-> 陆衡与本地工程员核验全尺寸可行性
-> 兜灯建立停机与训练保护
-> 无牌一号用自己的全尺寸身体学会动作
```

模型不放大，模型零件不直接装进巨大机体，纪存也不遥控机魂完成必杀技。

### 比赛与事故

- 资格战、指导战、半决赛、冠军战各有不同功能，不存在第二次资格赛。
- 冠军战在事故前完成，比分为`3:2`。
- 事故发生在赛后自愿演出，只影响现场安全，不推翻赛果。
- 货运环全章锁定；断的是老化外轨，不制作移动擂台。
- 舞台巨炮始终无动力、无机魂，只是会沿破损轨道滑落的重型舞台资产。

## 六、Nonblocking P1：Reader表现门

1. **旧最终话必须一次看懂。** 正文用少量原画、配音和机体反应交代“城市危机、A-7牺牲、王者胜利、黎明三次呼叫”；白鸢三年前的补稿另行说明，不与原版混成一套。
2. **比赛规则必须先于动作。** 每场只用一句规则和可见计分反馈；不得再用“计分线、终幕加分、低输出复赛”等旧机制。
3. **三台重涂机先是笑点，后是有用的地方机体。** 模型盒承担同模重涂梗，全尺寸实机只在E02亮相和E05救场，不挤占四强赛制。

## 七、不要改坏

- 不要把本章重新写成连续救援；E01至E04首先是求生、训练、调查和竞技，E05才是巨构救场。
- 不要把完全版王者的装备写成笑话；每件装备先证明有用，主动卸装才有分量。
- 不要让救援授予冠军，也不要再安排重赛。
- 不要用微小机械动作代替大场面因果；玩家应先看懂“谁赢、谁越线、哪里断、谁被困、怎样救”。
- 不要把白鸢的纸面分镜写成现实改写。她在C02只有短期预演、创作调查和现场判断。
- 不要让白鸢与七海在纪存介绍以前表现得像熟人。
- 不要恢复怪句式、行政术语或作者式金句。角色先把事情说清楚，再允许少量属于本人的锋芒。
