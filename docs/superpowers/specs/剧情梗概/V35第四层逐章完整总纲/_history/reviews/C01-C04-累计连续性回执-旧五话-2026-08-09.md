# C01-C04累计连续性回执

> 连读范围：C01-C03有效章节Reader + C04通过四席审查的L4候选总纲  
> 任务：确认C04由前三章自然发动、不改写既有事实，并为C05留下可执行而非抽象的入口  
> 结论：**连续性通过；不需要回滚C01-C03。**

## 一、四章故事是否连成一条路

C01让万机馆失去固定馆址。纪存不是为了讨论展陈伦理而离开，而是在外敌、白框回收和代哥封存同时压境时，让馆守Z与万机馆第一次站起来，带着人和展品逃出城市。

C02解决的是“逃出来以后靠什么继续走”。木桶街与旧件市场提供航行转子、可部署机体和模型到全尺寸工程的现实链；纪存、唐胶与白鸢也第一次围绕“被修过、被改过、被重新解释过的东西是否仍属于原主人”真正发生关系。

C03解决的是“这艘馆舰能否成为一处生活与战斗共同体”。工务城完成低速校正，给万机馆一处能回去的港口；社勇王、无牌一号和公共工务支援网成为长期力量。七海以同行调查者身份实体登舰。纪存主动发出百机航路邀请，不再只等灾难找上门。

C04因此是第一次主动远航。天空铸环同时回应三条需求：

1. 当前求援说明铸环正在遭受外敌攻击；
2. 七海认出其中夹带自己七年前参与过的救援许可；
3. 万机馆需要全尺寸制造接口和高负荷结构升级，才能承担越来越大的参战编队。

抵达以后，故事从城市级求生放大到近地轨道巨体战。地方旗舰、百相、BODY路线、米拉与艾达、断冠和万机馆现有编队在同一章相互改变。章末不是恢复原状：铸环保住，断冠重伤撤离；万机馆取得制造能力，纪存取得有限导航，白鸢取得L2模拟席，七海确认旧许可被冒用，军方得到足以发动下一章试验的资料。

## 二、前三章所得是否真正兑现

### 万机馆与馆守Z

- C01留下的馆守Z缺失右臂没有被免费修好。C04只制造空肩牵引背架，使缺臂成为改变巨物角度的战术动作。
- C03的低速校正与B1导览接口成为纪存有限导航的物理基础；万机馆在C04仍是固定范围支援，不提前成为可移动棋盘单位。
- C04取得高负荷脊节和全尺寸制造接口，属于新增能力，不取消现有转子复检、速度和载荷限制。

### 模型、手艺与工程

- C02建立的常识链继续有效：模型或手作锚件用于识别造型、用途与主体记忆；原型师处理形体和可制造母型；唐胶判断手修、公差和损伤；陆衡完成全尺寸结构换算；工房另行制造真实机械。
- 任何模型都没有自行巨大化、给实机供能或凭情感生成金属。
- BODY路线的“回应”只决定主体愿意尝试哪类动作，不替代材料、工程、驾驶与安全验证。

### 现有参战力量

- 社勇王继续由豪司与主体AI共同决定危险动作，取得正面迎击与工具化拆锁的爽点，不退回一次性支援动画。
- 旧拳王、灰模零号、无牌一号和馆守Z均以整机或明确支援动作参与终战。
- 火种货柜领袖已在C03离舰转递邀请，C04不以没有铺垫的远程替身参战。
- 工务城四台职业机留在公共支援网络，不为凑阵容突然跨城常驻。

## 三、人物弧线是否连续

### 纪存

C01已出现低功率机群回应，C02让他分辨共享装配记忆与主体，C03让他提前感到巨机重心交接。这些都只是“他对机器异常敏锐”的可见线索。

C04由韩秀雅把这项天赋第一次用于巨体协同。纪存的人形身体始终留在万机馆B1；驾驶员自愿开放局部视野，他只建议“下一次由谁接”，不能移动机体、读取记忆或夺取驾驶权。

这不是突然开挂，也不是提前揭晓他是机魂实体。真正的新变化是欲望：他第一次享受这份力量，并主动答应再试。C05可以让这份欲望付出代价，但不能倒写成C04的胜利毫无价值。

### 七海

七海在C03已经登舰，C04不是首次出场或远程放水。她仍无代哥现职权限，只能使用本人持有的旧实体证书和现场调查身份。

她在本章确认：七年前用于救人的许可仍被军方冒用。她既不否定当年的救援，也不接受今天的伪造。E04拔线只为阻止纪存继续失去辨认能力，不会导致百相受伤，也不造成白鸢路线中断。

### 白鸢

白鸢从C02的权利人、C03的L1现场预演，进入C04临时L2模拟席。她的能力始终遵守同一条链：

`真实现场与可信数据 -> 意识预演 -> 普通模拟器中的可读路线 -> 驾驶员或现场人员选择执行`

她不能画出门、创造地形或让机体自动行动。E03只开放局部追击段；E05为了全队能够自由改线，才公开包含失败、拒绝与修改的完整动作层。

### 三人关系

C03的晚饭只建立共同生活入口。C04的推进来自实际选择：

- 纪存决定是否重新接入，不由七海或白鸢替他决定；
- 白鸢触碰旧热痕前先询问；
- 七海在纪存无法辨认她时切断接头；
- 白鸢在外环断讯后取消残缺路线，保护工房人员；
- 三人在终战前共同建立分段退出和多方可停机制。

关系有吸引、担忧和不同的保护方式，但没有在C04提前完成恋爱结算。

## 四、机体、驾驶员与敌人是否串位

- **百相**：55米级可换装巨机，韩秀雅是唯一实体驾驶员。纪存提供有限导航，不进入驾驶舱，不取得控制权。百相全章保持右臂缺失，并在终战把窄轮廓变成优势。
- **三地方旗舰**：心墙零式、岛卫三号、潮墙巨兵以客将身份参战，章末留铸环维修；完整故乡与关系结算保留后续。
- **共鸣双机**：米拉驾驶一号；艾达被黑城系统与二号绑定。E03只完成第一次主动开甲与未能同行，完整What-if留C05。
- **BODY路线**：COMMON代表路线由七号获得八米公共体；另外三条分别产生战斗体、双主体支援体和小型分布支援网。四条路线互斥，不会在同一周目同时生成四支队伍。
- **断冠**：独立地外王牌，不受白框、索引或军方指挥。它只能学习真实观察过的阵位、接口和交接时间，不知道驾驶员私密记忆，也不会令所有重复招式无效。
- **白框与索引**：C04没有让索引人格出场。白框只作为人类机构运营的身体、试装和采样链存在；它与断冠不是同一敌人。

## 五、战斗和物理因果是否升级

四章的战斗尺度形成可见上升：

1. C01：馆内防卫、城市突围、万机馆第一次起立；
2. C02：旧件市场争夺、机体加入、航行部件夺回；
3. C03：万机馆托住工务城、职业机改图、勇者合体与移动城市巨构；
4. C04：六百米天空铸环、五十至六十米地方旗舰、七十米级长期宿敌和全竖环反向发射。

C04的胜负不靠微小关节差异：

- E01是二级制动下的持续坠落夺回；
- E03用可变双机的三种形态追入黑城；
- E04在救下载人平台后识破宿敌反制，以撤离为正式胜利；
- E05由玩家改派“下一棒”，让现有机体拆掉固定，再用四巨机新顺序完成完整反攻。

万机馆和馆守Z只能牵引、固定与改角，不能单独搬动六百米铸环。人类不在巨机脚下边跑边开会。

## 六、C05由什么明确发动

C05必须同时回收四件已发生的事：

1. **纪存主动答应再次参加百相导航试验。**
2. **韩秀雅取得正式试驾资格，并希望证明百相不必靠夺取驾驶权变强。**
3. **军方取得纪存已完成的导航记录、白鸢局部追击段和完整动作层；天空铸环各方同意本地试验，但战装局伪造七海的电子签名，企图接入旧救援通路并取得试后外运权。**
4. **米拉与艾达尚未脱离黑城控制链，第一次What-if只成功了一半。**

C05的核心危险不得解释成“电脑复制出十二个纪存”，也不在本章证明纪存的机魂构造。应保持简单：

- 已完成的导航录像、动作和判断可以复制；
- 战装局在C05E01首次运来四副工业测试体；它们仍由四名操作员驾驶，只是四项没有结束的任务不断回到B1追问纪存下一步；
- 纪存的人形身体始终留在万机馆，安全系统因冲突输入使他保持昏睡；任务真正结束后，他在原处醒来；
- 百相自出厂起便有一枚只保存当日机体经历的本地副驾核。它只学过少量导航样本，后来形成的新声属于百相自己的连续经历，不是纪存残魂或服务器副本；
- 这一差异只暗示“记录可复制，正在经历的主体不能如此处理”，纪存身世真相继续保留。

C04还锁定三项跨章事实：小满与阿澄留在原城；代表身体路线的七号公共体进入C05；白框兼容性链通过供货与试验继续取样，而断冠只从实战学习。

## 七、仍留给L4.5与L5的风险

1. C04角色和机体多，Reader必须分话认识，不能把状态账搬进对白。
2. BODY四路线需用一次清楚选择与一条代表主线表达，不能四条并排念说明。
3. E04至E05共图换态要让玩家看见倾斜环竖起、三处固定和敌方部署变化。
4. 三旗舰与米拉/艾达的IP投射必须由行为、关系和机体动作成立，不能由作者在资料卡宣布“像某作品”。
5. C05不得恢复旧稿中的十二白身、人格筛选、路线自动驾驶、技术装置增殖和行政争执主导。

## 八、累计裁决

C01-C04已经形成一条可以顺读的第一部前半段：

> 失去馆址 -> 找到继续航行的身体与伙伴 -> 获得港口和主动航路 -> 进入天空战场，为机魂制造身体并建立第一次跨谱系巨体联盟。

C04没有推翻前三章已审定事实，也没有提前消费C05的机魂抽离、万机馆移动棋盘首控和关系大危机。章末所有新增能力、战损、关系与敌方资料都有明确去向。

**累计连续性状态：`C01-C04_continuity_passed_candidate`**
