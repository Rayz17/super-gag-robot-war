# C04《天空铸环，谁给机魂一副身体》章节导演板

> Status: `candidate_director_board_v4`
>
> 本板只决定场面顺序、视点、情绪、玩家可见证据和暂定演出载体。战斗规则见战斗预案，尺寸与站位见物理板。

## 全章导演原则

1. **先让巨机做事，再解释名字。** 三旗舰首次出现时，各以一个巨大动作和一件生活物件建立人物，不用连续人物介绍卡。
2. **机械动作只写改变局势的部分。** 一场战斗最多保留四至六个读者能复述的大动作，微操进入玩法解构。
3. **所有关键因果都能被玩家看见。** 两座工位毁一留一、韩秀雅让出工位、白鸢隐去方案、断冠摆出旧阵形、七海证明伪签，都必须有前台证据。
4. **轻分支也必须发生在画面里。** 资源键不能由结算页后台默认；玩家要在地图上看见两个不能同时保住的对象、作出取舍，并在本话和下一话看见结果。
5. **情绪不靠术语。** 人物争的是承诺、身体、危险和选择，不说根、槽、路由、债务或“替谁背”。
6. **C04先讲完自己的胜负。** 断冠撤退、七号具身、百相正面胜利都是真的；C05压力只能从胜利被利用而来。

## 玩家体验承诺

玩家先在横卧山巅的铸环上经历一次四机接力的正面胜利，再亲眼看见敌人学会这套打法、夺走整座巨构；终战则由旧队员、新身体与未完成的百相共同换位破局。全章既要交付一场完整的巨型机器人攻防战，也要让“谁能拥有身体、谁能决定它怎样行动”落实为韩秀雅、七号、纪存和白鸢真正会争吵、会受伤、也会改变选择的事情。

## 四话场面链

`初战得胜并发现工位只够一个` → `韩秀雅让工位给七号，白鸢隐瞒方案引发关系破裂` → `断冠反用旧阵形，玩家撤出人和机魂却失去外环` → `所有人换职夺环，独臂百相完成终结突击`。

## 人物关系导演主线

- 韩秀雅与纪存从互相戒备，到承认导航与驾驶可以协作，但百相最后一脚始终由韩秀雅决定。
- 纪存与白鸢的冲突不是抽象的安全争论：白鸢因为害怕失去他，擅自藏掉一条危险方案；纪存因此第一次明确感到，她的保护也可能剥夺他的选择。
- 七海既不替白鸢开脱，也不借制度压住她。她负责把事实和风险摆到桌面上，同时用自己掌握的证据阻止伪签继续生效。
- 唐胶与陆衡通过帮助七号选择身体，第一次把模型手艺与全尺寸工程的分工演给玩家看。

## 人类声线与对白边界

- 对白先回应眼前的人和具体麻烦，不把世界机制说成格言。
- 禁止用“你可以……但别替我……”“谁替谁背”“先欠一笔债”等旧式对仗句推动关系。
- 角色不轮流说短促金句：韩秀雅直接、专业且会不耐烦；七海说话完整、克制但不是公文；白鸢会躲闪、刺人，也会在被追问时说漏真心；纪存先听懂别人再回答。
- 能由机体动作、损坏部位或终端证据说明的事实，不让人物重复口述。

### 情绪波形

败后冷静 → 七海反击 → 老队与小机体积累优势 → 多谱系大开大合 → 百相终结高潮 → 温暖结算 → 新压力。

## 关系与生活场配额

- E01：韩秀雅与纪存第一次专业试探；七海发现伪签。
- E02：韩秀雅/七号承诺；唐胶/陆衡工房生活；纪存/白鸢正面争执；七海既理解白鸢又要求公开选项。
- E03：纪存力量欲外放；七海在B1贴身守断路但不写成暧昧工具；白鸢坦白害怕。
- E04：三人共同工作仍留裂缝；战后以七号登舰、百相留站和正常吃饭/休息收束，不再用“吃饭等于日常”替代真正相处。

## IP与机器人文化承载

- 心墙零式：生体巨人、防壁、痛觉与“不要逃”的反命题。
- 岛卫三号：岛屿共同体与缺席的毕业照，只种不讲完。
- 潮墙巨兵：双驾巨物与旧爱共驾，不用同步自动复合。
- 百相：OG原型主角机、未完成形态、王牌驾驶员和最终沿轨突击。
- 断冠：适应型外敌与“同一招不会第二次奏效”的共同记忆；不是同武器免疫。
- 七号：量产/公共素体也能成为角色，模型构筑精神通过手艺和选择进入实机，而非塑料放大。

## 导演板验收

- 每话都有明确人物欲望、局势变化和一幅能记住的机器人画面。
- E02没有因为少一场完整SRPG而变成说明书；人物选择本身足以撑话。
- E03败战有可操作的撤离胜利，不把玩家努力判为错误。
- 任一关键事实删掉旁白后，仍可由画面、动作、短对话或界面证据理解。
- C04不需要读取旧黑城第三话或旧五话Reader才能成立。
