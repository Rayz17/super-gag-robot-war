# C04《天空铸环，谁给机魂一副身体》章级预生产模型

> Status: `candidate_preproduction_v4 / four_episode_rebuild`
>
> 目的：在扩写剧情以前，锁定本章真实存在的人、机体、敌人、空间、控制权和大动作。这里只解决“场面能不能成立”，不替Reader预写机械过程。

## 一、三块空间

### 1. 天空铸环

天空铸环是一座固定在高山旧发射场上的环形巨构，直径约六百米。山体内部的主轴承承担全部重量；巨机只会操作局部吊架、检修轨、制动和发射轨，不能徒手举起整座铸环。

同一资产只做两种主要姿态：

- **横向**：E01初战和E03败战。三旗舰悬挂在返修区，百相从中央试机位出击。
- **竖直**：E04终战。断冠占住环心，发射轨从地面一路通向云层。

E03由山体驱动把铸环从横向转到竖直，过程用章末短动画表现，不在SRPG地图里逐厘米演算。

万机馆停在环底泊位，只提供固定支援与舰内场面；本章不变成人形，也不作为自由移动棋子。

### 2. 待身库与装配工房

人类、模型样件、机魂维持匣、八至十四米骨架在这里活动。玩家一眼能看见：原有两座最终装配工位，一座已被断冠毁坏，另一座只能在下一次袭击前完成一副身体。

模型和实机不互相放大：唐胶从缩尺样件、手修痕和旧设计里读出意图；陆衡把意图换算成全尺寸材料、关节和载荷；工房制造真实身体；机魂自愿接入后，身体才会行动。

### 3. 万机馆B1与生活区

纪存的人形身体始终留在万机馆。有限多机导航发生在B1普通操作席：屏幕、耳机、生命监测和实体断路都能被玩家看见，不进入精神异空间。

厨房、住舱和外泊观察窗复用C01-C03资产，承担韩秀雅与七号的旧承诺、白鸢隐去方案后的争执，以及七海核验签名等人物场。

## 二、绝对时间

本章约持续两天，不逐小时排满：

1. **第一天白昼**：万机馆抵达，E01初战。
2. **第一天夜至第二天上午**：清点损伤，E02决定最后工位归属并完成七号身体。
3. **第二天下午**：E03断冠反攻，我方保人失地，铸环转为竖直。
4. **第二天夜至次日清晨**：准备新打法，E04夺回铸环。

七海只需核验三个生活常识层面的证据：她手中的实体证书没有在现场使用；系统里却出现了她的电子签名；那份命令把战后数据和设备送往战装局。正文不再创造更多授权层级。

## 五、三项机制

### 1. 纪存的有限导航

驾驶员决定是否开放局部视野。纪存能感到不同机体何时愿意接住下一步，只能给出建议。驾驶、开火和停止始终由机体与驾驶员完成。任何一方关闭视野，连接立即结束；七海另握实体断路。

E01这项天赋帮助第一次接力成功。E03纪存把成功顺序当成答案，断冠因此提前堵住每一个交接点。E04他不再发布完整队列，只把局部判断交给当事人。

### 2. 白鸢的L1行动方案

白鸢把自己看见的资料整理成一至三种行动可能。陆衡或本地工程师先检查物理条件，驾驶员再采用、修改或拒绝。她没有未来视，也不能把画稿写进现实。

E02她认为一条方案会让纪存承受过高负荷，便没有把它交给讨论席。技术上她没有篡改系统，关系上却替纪存和七号做了决定。这一错误比“画线开门”更普通，也更伤人。

### 3. 模型、工程与机魂具身

缩尺样件保存版本、手艺和动作意图；唐胶能读懂这些痕迹。陆衡与工房把意图重新设计成真实机械。七号机魂仍在自己的维持匣中，完成身体后自愿建立感觉与动作连接。

样件不放大、不供能、不存放七号人格。七号新身体也不会因为外形相同便变成另一名机魂。

## 六、四个大动作

1. **第一次接力**：心墙留下空位，岛卫改变落点，潮墙把断冠撞向缺口，独臂百相高速切入，逼退断冠。
2. **七号站起**：普通身体先站不稳，七号自己换一种撑地方式，走去关掉仍在空转的工房设备。这个动作不催泪表演，它证明身体真的属于它。
3. **同一招被反制**：断冠用分裂体占住旧站位，逐一打断我方熟悉的交接。纪存第一次看见“正确答案”在下一场变成陷阱。
4. **竖直铸环反攻**：三旗舰交换职责，既有机群拆掉断冠固定，七号进入内环恢复发射轨；韩秀雅驾驶独臂百相借整条轨道的速度击碎冠环。百相赢在速度、路线和驾驶，不赢在突然增加吨位。

## 七、资产边界

### 本章需要

- 一套天空铸环母资产，横向与竖直两种主要状态。
- 三地方旗舰、断冠、七号公共体的可辨认资产。
- 百相独臂差分；既有万机馆编队复用。
- 待身库/装配工房和万机馆B1/生活区复用场景。

### 本章不做

- 共鸣双机、黑城、独立试飞外廊和黑城泊位。
- 十二副白身、十二个纪存、四副远程操作体。
- 新的路由槽、根槽、接收母架或一次性技术装置。
- 白鸢发光画线改现实。
- 馆守Z新右臂、万机馆人形变形或暴走。

## 八、进入导演板前的门槛

- 三块空间能够画成简单平面并解释人、机体与万机馆各在哪里。
- 四话每场战斗都有一幅主画面，不依赖十几个小动作才看懂。
- 纪存、七海、白鸢、韩秀雅各有一次改变故事方向的主动决定。
- 七号得到身体和韩秀雅未完成百相两件事互为因果。
- E03败战来自断冠学会E01，而非临时黑科技；E04胜利来自人物换选择，而非更大的临时武器。
- C05的人物、机体和危机均未提前消费。
