## 4. Operation、Checkpoint与Mission Clear

- **同一Operation：PASS。** `TOPO L2-L8`全部使用 `OP-C04-BROKEN-CROWN`；E02是同一战斗Incident内的制造间奏，E01损伤、唯一工位产能和断冠学习不清零。`STATE L2`再次锁定S0至S7为一个Operation。
- **Checkpoint：主体PASS。** E01两阶段、E02制造段、E03反制与撤离段、E04第一阶段均设Checkpoint；`C04-BC-S0 → S1 → S2 → S3 → S4 → S5 → S6 → S7`形成连续IncidentState链（`TOPO L2-L8`）。
- **Mission Clear：PASS。** E01局部胜利、E02具身完成、E03撤离胜利均不是整章Mission Clear；唯一Mission Clear位于E04 P7并同时结束Operation（`TOPO L3-L8`、`STATE L2`）。
- **失败恢复：PARTIAL。** P6有Checkpoint，P7包含三旗舰阶段和玩家操作百相的终结阶段，但P7本身无Checkpoint；百相失败后从哪里恢复尚未定义，见N06。

## 5. 玩家代理权限

- **三旗舰与百相：边界充分。** 玩家在SRPG层短控客将、决定行动顺序与路线；人物层仍由各驾驶员决定移动、开火、共享和停止。纪存只显示交接范围或缺口状态，不替单位移动攻击（`PLAY L34-L44、L97-L107、L145-L150`；`PHY L21-L28`）。
- **七号：边界充分。** 玩家负责辨认主体、选择首模块和完成轻交互；七号自己否决身体方案、控制新身体并决定动作，工房没有远程驾驶权（`PLAY L57-L81`；`PHY L27`）。
- **白鸢与七海：边界充分。** 白鸢只提交可修改方案，七海只掌握实体断路与伪签处置；两人均不能代替驾驶员或机魂行动（`PHY L23-L28`）。
- **停止权：可测试。** 潮墙主动退出后仍可正常行动，只失去导航提示；这避免“玩家控制”吞掉角色拒绝权（`PLAY L99-L107`、`STATE L31`）。

## 6. 轻分支与IncidentState

- 已定义两类轻分支：E01材料列／驾驶组附属设备取舍（`STATE L46`），以及E02维修臂／救援钳／探索传感模块（`PLAY L69-L77`、`STATE L26`）。两者均只改变便利、援护、路径或额外回收，不改变七号具身、E03保人失地、百相终结和断冠撤退。
- 模块分支在叙事和效果账上成立，但当前 `TOPO` 每行的 `carry_from_state` 均为 `none`，S2/S3等state_delta也没有命名模块ID、E01资源差分或E01实际交接顺序。Save Resume后如何恢复这些变量尚不可执行验证，见N02、N03。
- `C04-BC-S0`至`S7`能保存主线IncidentState，但目前更像单一路径阶段枚举；尚未成为“主阶段状态 + 轻分支变量 + 断冠学习样本”的完整状态包。

## 7. 制作预算与动画峰值

正向控制已经存在：每战只保留四至六个可复述大动作（`DIR L9-L13`）；横卧地图压缩为三战区、竖直地图压缩为三层（`PLAY L23-L27、L123-L127`）；三旗舰和断冠列为T1，百相复用既有Rig做独臂差分，七号为T2，既有编队复用，并排除C05机体资产（`PLAY L156-L169`）。

动画峰值至少有四组：E01四机接力、E02七号首次站立、E03六百米铸环横转竖、E04三旗舰换职加百相竖轨突击（`PLAY L16-L21`）。其中E03巨构转态和E04 PV级Boss画面连续出现，且涉及环境差分、冠骨／主冠节状态、分裂体、轨道通电、防壁碎裂与多尺度镜头。现有预算只列单位层级，没有把环境Rig、状态差分、一次性镜头、FX和可复用战斗动画逐项计入，因此制作边界仍是PARTIAL，见N04。

## 9. 必做回归测试集

1. **R-OP连续性**：分别从S2、S3、S5、S6存档重进，确认工位产能、百相独臂、三旗舰伤势、断冠学习、外环归属和地图横／竖状态不重置。
2. **R-G01模块闭环**：三模块各完成E02选择、E03差分、E04差分和章末登舰；七号主体、归属与固定剧情不得变化。
3. **R-G02目标转换**：E03触发外环失控后，主目标、地图标记、结算文案同步切为撤离；完成撤离只能给Checkpoint／Encounter Complete，不能提前发Mission Clear。
4. **R-G03空间连续性**：从外环失控前连续追踪最后工位至S5和S6，镜头、棋盘占格、碰撞与任务锚点必须展示同一物体的合法移动或明确的不移动状态。
5. **R-G04敌体连续性**：补规则后分别验证E01可重塑部件与E04永久损失部件；战后模型、状态账和后续读取不得让永久部件无解释复原。
6. **R-G05顺序组合**：至少覆盖三旗舰换职的三种不同先后，确认都能合法暴露最后冠骨并进入百相阶段，且不会跳过固定状态门。
7. **R-代理权限**：纪存导航不得移动或攻击单位；驾驶员关闭共享后本回合仍可行动；七海断路与任一驾驶员停止均能立即终止导航。
8. **R-资产峰值**：以代理资产跑通E01接力、E02站立、E03横转竖、E04竖轨终结，检查同屏尺度、镜头遮挡、状态加载和演出可跳过性。

## 10. 最终第二阶段结论

`SECOND_STAGE_VERDICT：WARN`

六份工程板有效解决了第一阶段G01、G02、G05，且同一Operation、唯一Mission Clear、角色与玩家控制权边界均已形成可信骨架。它们没有解决G04，只部分解决G03；同时新增N01-N04四项P1，说明当前桥接尚不能直接进入无条件制作锁定。

最小复核条件是：补完最后工位的物理过渡；建立断冠可重塑／不可再生部件规则；统一三旗舰撤离条件与固定出口；把E01实际战术签名、七号模块和E01轻资源写入可跨Checkpoint读取的IncidentState；完成环境与动画资产预算。第一阶段首读回执及其 `WARN` 结论保持原样，没有修改、软化或推翻。
