- **E01**：万机馆赶到天空铸环，发现外面活动的是被旧命令驱动的空机身，真正求救的机魂还困在待身库。断冠来袭，三地方旗舰与独臂百相打出一次漂亮接力并击退它，但断冠把整套战法记走了。唯一安全装配周期必须在百相右臂和等待七年的七号身体之间二选一。
- **E02**：韩秀雅承认是自己让七号等了七年。七号终于说出“我想出去”，于是工位给了它。它选择普通作业体，并保留旧手不对称但熟练的卸力习惯。白鸢因害怕纪存出事而隐瞒多机导航方案，差点令七号再次被拆回去，纪存与她产生裂痕。

- **E04**：七海冻结冒用自己签名的外运命令；七号与无牌一号从狭窄内环修复发射轨；既有机群拆控制冠骨；三旗舰改变具体使用方式；韩秀雅驾驶独臂百相沿六百米竖轨冲天，击断增援接合。七号加入万机馆，百相留在铸环，断冠受损撤退，战装局则因公开遥测开始关注这套导航能力。

**5. 最佳 5 场**

1. **空壳在外面走，真正的机魂在库里叫。**  
   证据：无头半成品反复举盾，残腿机体走向封闭发射口；纪存确认它们没有完整回应，呼叫来自后方待身库（L35-37）。  
   有效之处：不用理论讲“身体与人格”，直接用一组诡异、悲伤而清楚的机器人画面立题。

2. **E01 四机接力与“踏板归我”。**  
   证据：心墙收路、岛卫改落点、潮墙送重量、独臂百相撞断冠骨；韩秀雅随后强调“刚才是我踩的”（L89-99）。  
   有效之处：四台机体动作不重复，纪存负责听见“愿意”，驾驶员仍保有操纵权。机魂协同没有滑成精神接管。

3. **七号选择身体并亲手关掉旧设备。**  
   证据：“我想出去”；拒绝缩小英雄机，选择公共作业骨架；保留不对称样手；站稳后按停等待它多年的设备（L161-189、L247-255）。  
   有效之处：身体是生活方式，不是战力皮肤。“不像我”“手熟”让机器人的身体记忆获得了极具体的人格重量。

4. **断冠用救人职责逼出旧答案。**  
   证据：它把分裂体投向运输口、工位、返修台和撤离线，让每台旗舰必须回到最能救人的旧位置（L293-331）；随后夺取外环并将铸环竖成巨冠（L343-363）。  
   有效之处：敌人不是数值变强，而是理解我方不会牺牲谁。战术失败由伦理选择产生，视觉上也有全章最强的败局图像。

5. **小机体修路，独臂巨机沿竖环冲天。**  
   证据：七号和无牌一号进入巨机无法通过的通道逐段恢复轨道（L441-443）；百相利用重新分配的姿态模块及缺臂后的窄轮廓贴刃穿过，撞断主冠节（L475-489）。  
   有效之处：普通作业体、公共工房、六百米轨道和未完成原型机形成完整因果链。高潮不是临时获得新武器，而是让缺陷变成经过准备的战术形状。

**6. 最疲劳／易忘／不可信 3 处**

1. **三地方旗舰的“人物名片”一次发得太密。**  
   阿米娜的植物盒与痛觉、新垣凪的毕业照、伊内斯与真琴的旧爱和记忆事故连续出现（L39-45），E04又各自对应一次主题性翻转（L461-465）。机体功能记得住，但驾驶员姓名、关系和象征物彼此争夺首读记忆。

2. **E04 临战准备复述条款偏多。**  
   “不补第三面墙”“工务员自己回答”“交换控制侧”“不装临时右臂”“停止权仍有效”“方案允许修改”集中排列（L411-425）。内容都正确，但在高空裂口倒计时已经成立后，这一段更像逐项验收主题，削弱出击加速度。

3. **“不可再生冠环”目前不可信。**  
   E01明确写断冠退入云层后能让冠环“重新生长出”硬化结构（L105-107）；E04只写主冠节断裂、破损本体撤退（L487-491），章末却升级为“失去一段不可再生冠环”（L563）。正文没有说明这次受损部位为何属于不同规则。

**11. 断冠的主体性、学习边界与身体／战术连续性**

- **主体性：战术强，人格弱。** 它会选样本、利用我方救人原则、夺取铸环、建立增援标记并判断撤退，不是站桩工具；但尚没有超出任务优化的欲望或偏好。
- **学习边界：清楚且公平。** 它能现场观察、闪避和调动分裂体，却必须退出现场重塑冠骨，才能把整套站位与次序做成预制反制。没有读心，也没有突然获得武器免疫。
- **身体连续性：总体优秀。** 冠环负责干扰和重构，分裂体负责占位，冠骨能钉入控制点，主冠节连接发射设施；铸环由山体驱动而非被它凭空举起，物理关系清楚。
- **唯一破口：不可再生性。** 正文没有区分普通冠骨、主冠节与章末“不可再生冠环”的再生规则，必须修正。
