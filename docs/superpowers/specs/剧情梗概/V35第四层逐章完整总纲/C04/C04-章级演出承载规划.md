## 二、合同规则

### 1. 三层边界

- **纯剧情Reader**拥有场面、人物选择、情绪、关键机器人动作和结果。本文中的UI、目标、Phase、状态键、重试和资产说明不得进入Reader。
- **L4.5演出承载**拥有载体、玩家动作、触发、状态桥接、最低资产、复用、降级和后续验收接口。它不能补写故事动机。
- **开放资料**只能整理玩家已经通过剧情或操作获得的问题与证据，不能成为理解主线的前提。

### 2. 载体类型

每话均显式登记六类：`ADV`、`探索/副玩法`、`SRPG`、`战中剧情/通讯/Cut-in/短动画`、`舰内或关系事件`、`结算与状态回写`。不使用的类别仍保留分段卡并写明skip reason。

### 3. Story-to-Play与玩家代理

- `direct_play`：玩家直接完成故事目标。
- `supported_play`：玩家完成局部操作，关键人物选择仍由角色作出。
- `observe`：玩家观看已经由前置操作赢得的故事动作。
- `expanded`：把总纲中的大目标展开为少量可读的游玩步骤，不新增剧情结果。
- `compressed`：把工程过程压缩为一组可理解动作。
- `optional_echo`：可选关系或资料回声，不提供主线必要答案。

玩家代理只使用：`execution_only`、`cost_or_route`、`authorized_branch`。P7B中玩家只执行韩秀雅已经作出的终结选择，不能替她决定是否驾驶百相或是否牺牲谁。

### 4. 成本等级

- `C0`：既有背景、头像、地图Sprite和普通ADV复用。
- `C1`：新增静态Cut-in、Pose差分、局部FX或小规模互动。
- `C2`：动态漫画型短动画、受控巨构状态切换或多机组合演出。
- `C3`：本章唯一PV峰值。当前只允许独臂百相冲冠进入此档。

成本等级不是正式BOM、工时或资产开工授权。

### 3. Full、Skip、Retry、Resume、Replay

- **Full**：第一次游玩按分段顺序呈现，战斗内短演出不隐藏关键状态变化。
- **Skip**：任何可跳过演出都必须先提交与Full相同的状态写入，再恢复到同一单位位置、伤势、装备和目标；跳过不是胜负捷径。
- **Retry**：只从已登记Checkpoint恢复。P7B失败从S6B恢复，不回到P6，也不重播三旗舰换职。
- **Resume**：Episode Cut恢复时先读取IncidentState和轻分支键，再生成地图、单位和目标；不得使用“每话默认初始编队”。
- **Replay**：剧情回看不写回存档；战斗回放使用隔离快照，不能覆盖Current Save。
- **失败回退**：若高成本载体不可用，改用已登记fallback，不得删掉关键动作、改变人物归属或把状态结果交给旁白。

### 4. 地图原则

横卧和竖直铸环都是可滚动的户外/开放环体棋盘。建筑、吊架、发射轨、工位、裂口与可破坏结构属于地图本体。只有待身库、人类安全区和确实封闭的内环维修通道可使用固定小图或ADV背景。

任一时刻只允许一个主目标、一个次要风险和一个仍可保留的疑问同时占据前台。角色背景、工程原因和长期谜团不得在战中成批解释。
