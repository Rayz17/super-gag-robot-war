## 一、导演总命题

玩家在第一章应当完成一次清楚的感情转换：

> **起初舍不得一家即将闭馆的机器人博物馆；随后亲眼看见它保存的巨神重新战斗；最后主动想跟着这座博物馆去下一站。**

本章的主语是机器人、万机馆和在其中共同生活的人，不是清算流程。闭馆原因只需让危机具有现实重量；真正推动剧情的是BREAKER来袭、馆守Z醒来、双机破甲和万机馆恢复巡展舰身体。

能量波形：

`舍不得但仍有笑声 -> 外敌坠落 -> 散乱小体压住撤离线 -> 巨神起身 -> 首胜 -> 双拳大胜 -> 散兵突然同步 -> 整馆升空 -> 云上终结 -> 第七次巡展`

## 三、逐话导演节拍

### E01：先让玩家喜欢这里

1. **开场不是危机。** 以仍亮着全部灯的最后开放日进入，让玩家先看见观众、笑话、模型和全尺寸藏品。
2. **闭馆事实只讲一遍。** 海报、纪存避而不谈和七海需要回去确认移交名单已经足够，不再插入清算会议。
3. **万机馆厚度用一条紧凑路线表现。** 主展厅与全尺寸巡展装备承担停留和互动；模型病院、驾驶舱廊以行进中的短场面带过；黑暗里的多层剪影说明路线之外还有大量内容，不允许可选互动把勇拳与警报拖到本话后半才出现。
4. **勇拳是并行的机器人动画预告。** 它在本话中点前展示“接住再打回去”的固定测试回放，同时用停车测试制造好懂的喜剧和豪司的不满足。
5. **饭约让纪存先成为一个人。** 两人熟悉、会互相挤兑，也确实想见面；公务打断私人时间只做底色。
6. **闭馆已经留下普通人的空缺。** 半装箱的藏品、空下来的展位和一名观众关于“以后还能去哪儿看”的追问在警报前出现；不再安排会议解释生态。
7. **老余的认出不可选。** 他在散热系统旧照片里认出馆守Z，给静止展品补上一段曾经工作过的生活，不把泪点藏进可跳过支线。
8. **结尾以外敌压入。** 近海防线未能拦住，BREAKER钻地直奔旧会展区，馆守Z胸灯亮起。第一话停在“这座馆里有什么在回答”。

### E02：让撤离与巨神首战短暂重叠，但不混淆操作尺度

1. **人类尺度段只做一件事：出去。** 跌跌、机器犬和消防架桥机处理巨机碰不到的门、走失者和燃烧通道。BREAKER破坏防线后，少量小体分别袭扰消防车、出口和街口；它们没有队形，也不替Boss开路。
2. **小满只带走一台模型。** 这一动作同时保护儿童线、表现唐胶的取舍，也不让儿童留队；阿澄发现旧守护者仍困在馆内后喊出这一事实，由成年人完成清点和返回决定。
3. **警戒线不是避难所。** 大部分人先进入封闭消防通道；馆守Z起身时，地图上只保留消防架桥机、最后应急车辆和东侧出口状态，不把普通人放在巨机脚下。馆守Z站到BREAKER与撤离线之间，直到防爆门闭合、出口灯转绿，战斗重心才完全移回广场。
4. **三个人分别选择留下。** 唐胶拉下模型病院防火帘，兜灯确认馆守Z还能站，纪存回身去带旧守护者出来；动作先于同体真相，避免大家只是为揭设定而留下。
5. **旧守护者同体揭示必须靠声音续接。** 轮式终端被砸中，同一句话从馆守Z胸前继续；纪存问清楚，兜灯打开导览席。她同时用一句人话交代：展示回路下仍有可直连主动力，老化冷却最多只撑完本次连续出动。
6. **七海只撤自己的命令。** 她先确认人群和机况，再承担后果，不替城市批准战斗。
7. **首战只建立四件事。** 馆守Z比Boss小、退役盾仍能保护人、散乱小体会把一场Boss战变成多方向压力、纪存能读懂馆守Z准备先保哪条路。以撤离线封闭后重盾拍翻敌人结束第一轮满足。

### E03：把第一章的机器人爽点打满

1. **豪司的越界源于此前欲望。** E01想测拳、两次申请待命失败、E03实名承担处分，行动链完整。
2. **双机战术保持一眼能懂。** 馆守Z正面扛，勇拳绕侧快攻，城市边缘炮火只打纪存指出的同一片甲。
3. **纪存第一次显出主角能力。** 他不是发许可，而是观察敌人、理解馆守Z、把不同单位组织起来，亲自找出胜机。
4. **断臂先由馆守Z自己决定。** 兜灯说明代价，馆守Z握拳，旧守护者要求标出核心；纪存和豪司尊重它的选择。
5. **高潮动作只有四拍。** 发射、夹住、补拳、贯穿。所有细部只服务这四张图。
6. **胜利必须立刻反转，但不否定胜利。** 黑甲确实被打碎，右臂牺牲确实换来结果；只是玩家发现那是第一阶段。
7. **同步升级必须用一个大画面完成。** E02幸存小体在广场边缘仍各自乱闯；红孔第一次收缩后，它们与外海黑点同时停顿、让出核心航线并朝万机馆转向。观众不需要听“统一指挥”解释，也能看懂敌人升级了。
8. **战损要有回收动作。** 飞行核心升空后，馆守Z用左臂拎起开裂重盾，沿南侧服务道退回外部泊位；盾在E04继续掩护离港并承担归舰冲击，右臂则真的留在封锁广场。

### E04：让馆藏、母舰和巨神合为一次奇观

1. **人物位置先讲清楚。** 馆守Z沿南侧服务道回到外部泊位；纪存从导览席经检修平台进入主厅，兜灯在平台上亲自检查右肩后随平台回舰，唐胶始终在馆内。观众已撤离，不再安排含混的“现在上舰”。
2. **起飞时间由战斗争取。** 勇拳和城市防空持续拦截；馆守Z用裂盾保护检修桥和最后作业人员。准备和攻击交替发生，不让Boss悬空等待。
3. **前厅恢复航行功能。** 入口导览台本来就是巡展时期的公共航行台，紧急离港时切换显示、护板和座席即可；不新增一间突然出现的地下舰桥。
4. **七海只转发她能取得的情报。** 她从代哥危机联络室叠合城市公开净空航路、禁射区与企业交通卫星图，不批准起飞、不指挥炮火。私人通话在航行台激活后才转到主屏。
5. **巡展装备各有一个大用途。** 裂盾保护离港并承受两台机体归舰；巡展臂抓取贴舰敌体；推进骨架只负责一次发射。禁止把三件装备组合成复杂机关。
6. **万机馆火力有限。** 屋檐近防炮已在E01照片中出现，固定时期用于坠落碎片拦截；E04只能赶走小型贴舰目标，不能击伤Boss。母舰奇观来自离地、移动和机体协战，不来自突然齐射重炮。
7. **纪存不是熟练舰长。** 旧自动航行系统负责推力、转向与配平；纪存选择净空航路并组织友军。主角高光是判断敌人会跟随万机馆、把战场带出城市。
8. **最终击破只保留六拍。** 勇拳接住俯冲、回送核心、兜灯允许单次点火、纪存叫出“就是现在”、馆守Z直冲并以左拳贯穿、勇拳协助它落回裂盾。不要锚索追敌或预挂回收索。
9. **敌群失去统一方向必须可见。** 核心破碎的同一瞬间，原本同步追舰的黑点分别停顿、偏航或各自扑向附近目标。只表现统一指挥消失，不新增另一套清除机制。
10. **左右拳因果必须可见。** E03右臂摧毁地面重甲，E04左拳只击中裸露核心；左拳并未突然增强。
11. **战后关系和下一站说人话。** 七海回到预约餐厅，只留下未完成饭约和下次订位；随后用舰腹震动、转子温度不降和兜灯的直接判断说明万机馆必须尽快停靠检修。万机馆发出全域求援后，赵梅才从木桶街回应重载泊位和九米级测试转子；她不承诺必然兼容。目的地写`木桶街`，不再靠陌生招揽、潮位或泊位术语硬推。

## 四、人物与关系场面

### 纪存

- E01先展示他熟悉观众、藏品与路线，也保留一点不肯说闭馆的逃避。
- E02由他正确判断不能去地下避难，并进入导览席；不是被事故推着受难。
- E03他找出BREAKER合甲慢拍、组织多机协战，得到一次属于主角的明确战术胜利。
- E04他提出把战场带往外海、推动路线杆，主动决定万机馆今后继续走；前厅只把路线选择交给他，实际推力、转向和配平仍由自动航行系统完成。
- 本章只暗示他对机体请求异常敏感，不解释其机魂真相。

### 纪存与七海

- 私交基线：认识一年多，多次约饭未成；这次特意订了滨海塔楼的晚餐，说明两人都把见面当回事，也能拿迟到与十八米机器人互相打趣。
- E02第一次重大动作：七海为纪存、兜灯和馆守Z承担撤令后果，但她的判断依据是现场确实需要这台巨神。
- E04纪存拿整座馆引敌离城，七海担心的是他可能死，不是程序不完整；她只叠合公开净空航路、禁射区与企业交通卫星图。
- 章末预约餐厅已经闭厨，纪存答应下次订位。关系留下真实的下一次见面，不用保温盒、欠饭或共犯口径。

### 唐胶与兜灯

- 唐胶负责模型、手修、藏品使用史和临时适配；兜灯负责馆守Z的实机机况、安全边界和装配。
- E02两人分开行动：唐胶收模型病院，兜灯守馆守Z。
- E03兜灯报告右臂代价，唐胶不替机体煽情。
- E04两人共同装巡展臂：兜灯负责结构与点火边界，唐胶完成外层固定和馆藏清场。合作中有熟练感，不用装饰性手势或金句替代关系。

### 唐胶与赵梅

- 万机馆先公开发出维修请求，赵梅才因唐胶留下的联系方式回应；她不是神秘地提前知道舰况。
- 唐胶只说明她是自己已故徒弟的母亲，并相信她不会拿不存在的修理条件招呼人。他的停顿来自旧事和亏欠，不把赵梅写成冤家或麻烦制造者。
- 赵梅亡子的经历、她如何从遗留笔记学会组织合作社，留到C02当面展开；C01只建立故交、能力边界和现实帮助。

### 豪司与旧守护者

- 豪司把馆守Z当老前辈，旧守护者认真纠正；这是两种机器人动画气质第一次相遇。
- 战斗中二者不靠深交便能协作，因为纪存把意图说清、豪司愿意承担。
- 战后拳甲碰夹爪，既回收双拳战，也保留“下次带会回嘴的机体”这一后继欲望。

## 八、概念重力与对白自然度门

### 前台允许出现的专名

`万机馆`、`馆守Z`、`旧守护者`、`勇拳`、`BREAKER`、`机魂`、`巡展舰`、`巡展臂装`、`木桶街`。

### 人类对白守卫

- 不使用“你可以X，但别替我Y”“我不替谁背”“今天先X，别Y”“这笔债以后算”等成对宣言。
- 不用`槽、锁、锚、语法、半格、一拍、亮灯`隐喻感情或人格。
- 人说话必须有听众和当下目的；解释设定时先说日常因果，再由资料页补名词。
- 旧守护者可以机械礼貌；七海可以简洁准确；唐胶可以口语和挤兑；豪司可以直率热血，但四人不能共享同一种金句腔。
- 关系场用等待、打断、身体反应、物件和没有说完的话承载，不让三个人轮流发表主题。
