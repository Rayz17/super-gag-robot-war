# C01开篇设定减负与娱乐重构裁决

> Status: `candidate_story_rebuild_governance / user_rejected_l4_replacement`
>
> 日期：2026-07-26
>
> 用途：只约束C01纯故事重写。它不是新的百科设定，也不自动修改Hard Canon。

## 一、为什么必须重构

用户连续阅读C01-C05后明确否决现有L4总纲。失败不是局部台词问题，而是创作顺序错误：

- 每章同时解释太多系统、阵营、能力和后续谜团。
- 把闭馆、授权、签名、消防图、载荷与责任分配写成主事件。
- 馆守Z、社勇王等机甲爽点刚出现便被限制、撤回或转成工程任务。
- 角色不断替作者解释机制，基本动作、转场和因果反而不清楚。
- “设定全部兼容”替代了“故事是否让人想继续看”。

因此C01-C05原L4全链已经失效。C01新稿先证明故事成立，再讨论战斗拆分、物理板和演出规划。

## 二、C01玩家真正需要知道的五件事

第一章结束前，普通玩家只需理解以下事实：

1. 万机馆今晚闭馆，明早将被拆散处理。
2. 这个世界仍会遭到地外巨型敌人的零星侵袭，城市拥有常备防卫体系。
3. 一些与人共同生活很久的机器人会形成稳定人格，大家把它俗称为“机魂”。
4. 馆守Z是十八米级退役救援巨神，“旧守护者”是它一直通过导览终端与观众交流的人格。
5. 万机馆并非普通建筑，而是一艘被当成固定展馆使用多年的旧巡展舰。

任何不属于这五件事的世界观，都不能成为理解本章胜负的前提。

## 三、只允许作为疑问出现的内容

以下内容最多出现一次可见异常，不作解释：

- 纪存为什么能比别人更早听见馆守Z和万机馆。
- 二十七年前的远征回信为什么把纪存识别为收件人。
- 地外敌人为什么在万机馆附近改变了路线。
- 一台白色采样无人机为什么带走战斗残片。
- 旧馆长为什么提前保留了万机馆的出航钥匙。
- 无署名分镜为什么画过万机馆离地后的样子。

疑问必须是画面或行动，不能由人物连续追问、终端解释或旁白提前回答。

## 四、C01禁止前台化的设定

以下概念在第一章正文中不应出现，内部作者也不得用它们替代事件：

- 索引连续人格、清噪哲学、远星归静。
- 白框生产链、四方资产拆分、跨机构权属拓扑。
- 开馆权、证词、路线债、责任债、定义权。
- 实体U盾、签署链、旧根证书、多体路由、主体切片。
- 三类载荷保二、档案优先级分支、维修史伦理结算。
- 万机馆完整暴走代价表和终局可变人形。
- 模型锚件如何影响全尺寸机体的完整机制。

若正文必须使用以上任一概念才能讲通，说明故事仍未减负。

## 五、概念的开篇通俗说法

| 后台概念 | C01只允许怎样表达 |
| --- | --- |
| G.A.G. | 旧灾难留下的异常共鸣；本章只听见广播中一次旧称 |
| 机魂 | 一台机器长期形成的稳定人格 |
| 导览终端与馆守Z | 同一个旧守护者通过小终端和巨体说话 |
| 万机馆移动结构 | 旧巡展舰，可以离地航行 |

| 白函/白框 | 章末只出现一台沉默的白色采样机，不介绍组织 |
| 模型与实机 | 模型是人们记住机器的方式；完整作用留给C02 |

## 六、C01的娱乐性合同

C01必须先是一章机器人动画开局，而不是社会制度说明：

- 闭馆导览必须让玩家产生“这里有好多机器人”的拥有欲。
- 地外巨敌必须作为真正可恨、可打败的物理敌人登场。
- 馆守Z必须完成一次完整、正面的首战胜利。
- 豪司与勇拳试作机必须带来勇者系的冲动和并肩作战，而非审批笑话。
- 馆守Z失去原右臂必须发生在最痛快的一击中，并在本章结束前获得可用的临时工程臂。
- 万机馆起航必须是第二个PV级高潮，并让玩家第一次操作母舰火力。
- 纪存必须从闭馆负责人主动跨入巨神、作出出击和起航决定。
- 七海必须以一次清楚、果断的行动帮助战斗，同时承担她自己的选择。
- 胜利本身成立。白色采样机只能制造后续威胁，不能宣布玩家今晚做错了。

## 七、C01-C05前向边界

为了避免C01再次吞掉后续内容，前五章暂按以下娱乐脊柱分工：

### C01：巨神苏醒，博物馆起航

闭馆之夜遭遇地外突入。馆守Z与勇拳迎战，万机馆恢复巡展舰形态。只建立家园、首批伙伴、纪存异常和七海关系。

### C02：木桶街，玩具记忆变成真正的援军

主打模型街、收藏生态、变形生命、拳击机体、白鸢正式登场与多台实机加入。模型和实机的关系在这里第一次获得清楚解释。

### C03：工务城，勇者完成第一次正式合体

主打城市级劳动奇观、现实机器、社勇王完整合体和七海实体登舰。制度问题只能作为城市被夺取的手段，决战必须由机器人完成。

### C04：天空铸环，巨体与宿敌

主打百相、三台地方旗舰、身体制造和断冠来袭。纪存第一次获得驾驶/接驳巨体的快感，外敌历史扩大。

### C05：英雄能力被夺走

主打军方试图复制纪存的战场天赋、百相新主体、米拉与艾达的悲剧改写，以及一场内外夹击的大型战役。它不能再只是授权和身份争议。

C01不得提前解释C02模型机制、C03社勇王人格、C04百相身体或C05主体复制。

## 八、通过标准

新C01只有同时满足以下阅读事实，才可重新进入L4：

- 不看设定文档也能用几句话复述四话主线。
- 每一话都有清楚的地点、目标、敌人、转折和结果。
- 读者能记住馆守Z、勇拳和万机馆的至少一个大动作。
- 玩家得到的不是“理解了限制”，而是拥有了机体、母舰和继续出击的欲望。
- 纪存、七海、唐胶、兜灯与豪司说话和行动的理由不同。
- 没有段落依赖技术术语、表格字段或作者补充才能成立。
- 第一章结束后，读者首先想知道下一场机器人大战会怎样，而不是追问某个系统字段是什么意思。
