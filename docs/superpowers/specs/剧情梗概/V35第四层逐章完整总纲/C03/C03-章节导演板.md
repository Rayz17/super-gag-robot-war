# C03《工务城，谁在让城市站着》章节导演板

> Status: `candidate_layer4_director_board_v3_repair`  
> 结构：四话；第三话完成Boss决战与完整胜利，第四话处理巨构校正、入队依据、七海选择与下一航段。  
> 本板只决定场面、人物欲望、玩家可见因果与暂定载体，不进入具体镜头、逐句台词或关卡数值。

## 一、本章要给玩家的体验

工务城不是一座等待主角拯救的背景城市。它每天都由各类机器人抬路、接电、封街、架桥，市民对机器的依赖像对水电一样普通。万机馆来到这里，本来只想完成一次安全校正，却在衡令越权提高试载后，成为能补回西环医疗交通段一个失效承点的百米巨物。旧基座、城梁一号和其余承点始终承担主要载荷。

本章的爽点来自三层递进：

1. 纪存在低比例试载被越权加码后先卸载止险，再看清局部桥面倾斜，主动复位承担万机馆本章的公共工程任务。
2. 四台职业机夺回各自的工具，用吊轨、供电、封路和水幕打出一场只有工务机器人才能完成的追击战。
3. 社勇王完成完整合体，黄金巨锤正面击穿衡令工具冠；随后它在条件变化后拒绝第二击，豪司没有被羞辱或撤下驾驶席，而是学会与一台能说“不”的勇者并肩作战。

本章不把专业协作写成“所有机器必须动作不一致”。真正的答案是：它们可以整齐、精准、英勇，也可以在危险时撤回同意；专业与主体性并不冲突。

全章能量波形：

**移动城市奇观 -> 低比例试载被衡令越权加码 -> 纪存最小卸载止险、看清后主动复位 -> 工务群夺回工作 -> 三层追击 -> 勇者合体大胜 -> 第二击被拒 -> 城梁横移与全员拆城 -> 跨夜稳固与公共泊位 -> 完整午饭 -> 旧中继恢复并吐出双时间戳 -> 纪存发出百机航路邀请。**

## 二、人物导演主线

### 纪存

- 开场目标是证明万机馆能安全停靠，不再只是一艘逃亡中的临时巨舰。
- 市政和舰方先明确同意低比例试载。衡令跳过口头确认并提高载荷时，纪存先做最小卸载；局部医疗交通桥段因四组退出支撑已被挪去强撑其他城区而倾斜，他立即停下并主动复位。城市剖面必须当场显示四组支撑正在别处承重、备用库已空、职业工具又被夺走，从画面上封死“搬回来即可”的简单解。
- E02不亲自解决每台机器的问题，而是让陆衡、本地工班和四台职业机组成视野外的行动链；他的领导魅力来自读懂局势、敢担风险和让专业的人上场。
- E03在豪司准备强行完成第二击时，他不抢走驾驶权，只要求全军先看清城梁后方的住宅承载线。最终由豪司自己撤令。
- 章末面对工务城提供的稳定泊位，他没有把继续远航包装成伟大牺牲。他承认留下来会很舒服，也承认万机馆已经收到下一处真正需要它的求援。

### 陆衡·姆旺吉

- 工务城把他当外来的工程专家欢迎；他原本期待用这次校正证明自己仍能解决现实问题。
- 衡令锁直市政吊装机时，他从右膝的动作认出自己当年删掉现场询问的廉价程序。
- 他不长篇自责，先把旧版和商用版并排给工班看，承认自己为了让项目活下来删掉了哪三次确认。
- 他主动公开风险，导致自己的跨城资质暂停；这不是“认错便结清”，而是使十七座城市都需要重新检查旧部署。
- 他与唐胶的分工必须可见：陆衡计算全尺寸载荷和安全边界，唐胶让一只实际磨损、年代不一的接头今天真能装上。

### 七海

- 因自己仍是C01移动风险文件和C02通行担保的原签署人，她必须实体到场。她乘公共高速线换乘工务列车，比低速航行的万机馆先到。
- 她没有代哥现职权力，不能替军方或市政批准行动；她只能出示原始材料、记录现场事实，并以随舰事故观察员和签名滥用调查员身份提交异议。
- 她与白鸢在本章完成现实会面，场面先从专业摩擦开始：白鸢的路线很漂亮，七海指出其中一台机的左腿做不到；她没有否决整张图，而是把驾驶员叫来亲手修改。
- 观察塔受损时，七海先把白鸢从窗边拉回；白鸢随即用红笔在透明窗上划出横扫高度，喊七海低头。红线只是预警，不是能力造物。
- 章末她带普通行李登舰。她的身份是随舰事故观察员和旧签名滥用调查员，不是恢复职位，也不是代哥派来的舰上监军。

### 白鸢 / Evelyn Voss

- 她已在C02登舰，本章把行动预演用于此前尚未处理过的动态大型现场。
- 她能根据公开摄像、机体读数和目击信息画出候选路线；只有驾驶员和工务员复核后，路线才会进入战术界面。
- 她最初画出一条视觉上完美的三层包围线。本地驾驶员指出灰崎机左腿无法完成最高一跳，直接用油笔改掉中心构图。
- 她没有抢回作品，也不把被修改写成自我牺牲。战后她保留所有油笔、污迹与不同署名，接受一件大型现场作品可以被别人改得不再像她，却仍然成立。
- 她和七海的互救建立独立关系，不把每次互动都变成纪存的三角恋证明。

### 唐胶与兜灯

- 唐胶从实际磨痕判断不同年代附件为什么装不上，带本地工班做出第一只失败适配件，再一起做成第二只。
- 他留下量具和失败样品，让工班以后能独立判断；不再重复C02的公开忏悔。
- 兜灯为万机馆、馆守Z、社勇王合体和工务机解锁分别准备物理停机手段。她不会用“只有我能叫停”证明亲近，而是把硬停柄交给真正站在风险旁的人。
- 两人关系通过共同工作和互相抢工具表达，避免主题式对话。

### 豪司与社勇王

- E01调度屏即显示社勇王预留测试位与D2运输排程；它原本就要在工务城完成四模块全尺寸移动校正与公开试验。豪司有同控制家族试作机驾驶和四模块模拟合体经验，暂停的是试驾资格。
- 豪司没有驾驶席时仍在地面搬导轨、清理合体通道、指挥群众避开转弯半径。
- 社勇王主体AI观察的是他如何工作，不是他会不会喊口号。核心车主动为他打开驾驶舱。
- 社勇王与豪司在本章的完整合体出击和第一锤必须完整成功，让玩家得到勇者系的正面奖励。
- 工务城先把临时公共救援任务发给社勇王主体AI；机体接受任务后自行选择豪司。企业在救援进行中只能保留遥测和事故异议，不能远程锁死驾驶舱。
- 第二锤开始蓄力时目标仍安全；衡令在锤头展开以后临时把承载缆接到住宅主梁。攻击线当场由安全转红，社勇王锁住武装，豪司先愤怒，再从驾驶舱看见必杀线穿过住区。玩家不是被要求明知危险仍点错指令。
- 他撤回命令，把全功率改给防壁。社勇王重新响应，并与他一起把巨锤拆成施工工具完成终战。

## 五、关系与生活场面

### 七海与白鸢的本章现实会面

- 地点：事故观察塔，周围有人工作，不设置专属浪漫密室。
- 七海先指出路线问题，白鸢不服，但把驾驶员请进来验证。
- 七海救白鸢是身体本能；白鸢救七海靠观察和喊声，不靠超能力。
- 战后白鸢把七海与本地驾驶员的涂改保留在图上，七海在事故记录中署上共同成果。
- 两人各自留下好感与戒心，不能在同一场里同时总结关系。

### 七海登舰前的三人同桌

- 七海此时以现场观察者身份登舰吃饭，尚未把行李搬进客舱；她手中已有次日返程票和复职审查机会，饭后看见白舰旧签署链，才作出放弃本轮审查的选择。
- 饭不是支付、债务或暗号，只是一顿终于没被打断的热饭。
- 舰内午饭只能提醒纪存与七海那顿正式晚饭仍未兑现，不能用一碗面把约会结清，也不解释“这代表什么”。
- 白鸢可以察觉两人过去不浅，但信息来源必须是她现场看见的熟悉动作或纪存主动提起，不能凭空知道私密细节。
- 三人不同时说相同的话，不以抓下巴、按颈侧等编排动作制造速成亲密。

## 七、概念重力与声音预警

玩家前台只需记住：

`工务城`、`衡令`、`四台工务机`、`城梁一号`、`社勇王`、`公共泊位`。

写作时用普通话表达：

- “临时把它压在城下”优于新造接口名。
- “陆衡删掉了三次现场询问”优于一组协议术语。
- “把工具还给明天要上班的机器”优于权利宣言。
- “那一锤会穿过住宅承重线”优于抽象风险判定。

禁用高频句式：

- “你可以……但别替我……”
- “今天先……但不代表……”
- “谁也不替谁背……”
- “没有把X说成Y”
- 用“债务、语法、槽、锚、亮灯、时间窗”替代人物欲望与可见后果。
