## 二、E01 外环重载战

### 人话目标

万机馆已经在三处实体硬停保护下主动复位，补住西环医疗交通段的一处局部承点。玩家必须在它继续分担该处载荷时解除衡令追加的永久固定，并保持旧基座、城梁和其余承点组成的分载系统工作。

### 地图轮廓

- 万机馆以横向多格母舰占据地图下缘的局部试载位，不能离开当前承点。
- 上缘只显示西环医疗交通桥段；医院和车站主体位于战图外，住民已进入楼体内部承重避难层。
- 旧基座、城梁一号和两处仍工作的固定承点承担主要载荷，持续显示在地图背景和载荷UI中。
- 中间是一条弧形工务轨，衡令附属楔机和拖机沿轨部署锁件。
- 左右各有一条可被货柜领袖牵引改变方向的承载缆。

玩家一眼应能看懂：**上面是局部桥段，下面是万机馆，左右还有既有支撑，中间是衡令擅自加上的固定。**

### 我方可操作单位

- 馆守Z
- 旧拳王
- 火种货柜领袖
- 万机馆母舰支援指令
- `木桶街协力编队`一次必经援护教学：D1清晨三机已飞抵城外货运机场；玩家从红、蓝、黄中选择一台获空管放行，实体入场完成高速标记、护航拦截或远射断索，再与另两机共同返航

乐森偶和积木智者只在战前场测中出现，不作为Boss战凑数单位。

### 敌方与目标

- 衡令本体在地图后方操纵外层设备，不与万机馆拳脚对撞。
- 关节楔机负责锁住馆守Z和货柜领袖的职业动作。
- 附件拖机负责把拆下的锁件重新装回。

胜利条件：三组永久固定全部解除，旧基座与至少一处冗余承点保持工作。  
失败条件：万机馆在城梁接位前退出局部承点，或医疗交通段失去全部支撑。

### 核心规则

万机馆每回合分担局部承点载荷，只能执行支援动作：

- 调整舰体重心，强化一侧承点；
- 开放一段旧外泊通道，为近身机提供路线；
- 承受一次来自衡令的额外压载，换取其他单位自由行动。

馆守Z、旧拳王、无牌一号和货柜领袖负责恢复可退出状态。馆守Z用地锚钉住侧滑止挡，旧拳王进入维护道击出被卡死的制动楔，无牌一号把关节楔机打回维修槽，货柜领袖把误接向医疗交通段的缆线拖回空置工务轨。玩家不是等倒计时结束，而是在“继续分担载荷”和“给前线腾出支援”之间分配母舰动作。

协力编队不占常驻出击位。进入关卡前，玩家已在路线图上看见三机从木桶街飞到城外货运机场的航迹。第二组空中卷扬索露出后，空管只允许一个呼号进入负载场；选择不同机体只改变援护动作与附带效果，不改写主线，也不让三台机自动加入万机馆。

### 阶段变化

1. **读懂分载**：低比例试载阶段先让玩家看见旧基座、城梁、冗余承点和万机馆各承担多少。
2. **越权加载与主动复位**：衡令跳过确认，把四组退出支撑挪去强撑供水干线、东站和两段受损高架；纪存执行最小卸载，局部桥面倾斜后叫停，再在硬停就位后主动复位。地图同步显示四组支撑无法撤回、备用库见底，制造替代件所需工具又正被衡令拆走。
3. **恢复可退出状态**：馆守Z固定侧滑止挡，旧拳王击出制动楔，无牌一号清出外泊坡道，货柜领袖改回承载缆；衡令舍弃外层结构撤入中层。

### 大画面

1. 载荷从低比例突然上升，纪存先把舰体退回安全刻度；医疗交通段一处桥面因冗余已被调走而倾斜。三处硬停就位后，百米舰体主动复位，从自动闭合的危险区门之间切回局部承点。
2. 馆守Z以单臂撞开锁臂，缺失的右肩在巨构阴影下显得更明显。
3. 三台不同尺度机体分别固定止挡、进入维护道和改接承载缆；舰体上方的分载图从失衡重新回到可控区。

### 战中剧情承载

- 纪存发现越权加载后先卸载止险，看见局部支点后果再主动复位。
- 七海从观察席指出临时征用的合法边界，但不能发出市政命令。
- 陆衡确认外层固定件可以拆，但万机馆暂时不能撤离局部承点。
- 衡令只用简短、任务式通告说明它的逻辑，不发表主题演说。

### 不可逆输出

- 万机馆承担真实结构损伤并固定在西环医疗交通段的局部承点。
- 衡令保住旧稳定核，退入中层工务环。
- 市政认可万机馆暂时救了城，但尚未决定支持谁。

## 三、E02 三层工务追击

### 人话目标

衡令正在把四台工务机每天要用的附件拖进战备库。玩家要帮助它们夺回工具，再把衡令逼进中央坞环。

### 地图轮廓

- 上层：一段可被吊装机翻下来的悬空轨道。
- 中层：环形主路，敌我追击的主要方向始终向前。
- 下层：旧舰骨和低位维护路，可绕过热锁视野。
- 三层只由三处清楚的连接点往返，不形成不断变化的迷宫。

### 我方可操作单位

- 市政吊装机
- 预算二号
- 灰崎警备机
- 消防架桥机
- 旧拳王
- 馆守Z

万机馆继续在城下承重，只提供有限支援；纪存不能让它突然离开。

### 敌方与目标

- 衡令沿环轨向中央坞环撤退。
- 工务城市政已撤销其临时任务；衡令以灾时离线钥匙继续运行，并用本体占住战备库入口。
- 四组附件拖机各携带一种职业附件。
- 楔机会用陆衡旧程序把偏离标准姿势的机体锁直。

胜利条件：夺回四种职业附件，并在衡令抵达坞环前占据两处入口。四件均为主线必回收；差分只记录附件剩余耐久与附带库存。  
失败条件：任意两种附件被送入战备库，或消防架桥机因旧伤再次过载。

### 核心规则

被锁直的职业机不能靠一个中央按钮全部恢复。每台机选择一项自己最熟悉的动作，由本地维护员确认后恢复对应职业技能：

- 吊装机先恢复右膝与吊臂协调；
- 预算二号允许背部供能架继续晃动；
- 灰崎拒绝左腿高跳，选择展开隔离墙；
- 消防架桥机保留旧伤上限，只能铺低位水幕坡。

界面只显示“申请动作 -> 维护确认 -> 恢复职业技能”，不展示复杂权限树。

陆衡并非凭记忆报出十七城。他在E02战前用衡令程序的构建指纹查询公开采购与安全登记库，结果返回十七个部署地；涉事程序的跨城认证及他本人相关资质随即暂停。该信息只做一屏，不进入战斗规则树。

### 阶段变化

1. **夺回第一批附件**：玩家理解每台机恢复不同职业动作。
2. **轨道翻转**：吊装机把上层轨道翻成斜桥，地图从单路追击变成上下夹击。
3. **三代线路点亮**：预算二号恢复中层供电，玩家获得新的移动线；敌方热锁同时启动。
4. **封路与水幕**：灰崎的隔离墙把拖机压进单向通道，消防架桥机以低位水幕切断热锁。
5. **中央坞环封门**：四台机夺回工具，把衡令逼入E03主战场。

### 四个职业大动作

1. 吊装机拔出一整段悬轨，转身把它搭成跨层斜桥。
2. 预算二号把三种年代的供能盒接到同一线路，半座黑掉的工务环重新通电。
3. 灰崎把肩枪卸在迁重路线外，六面交通墙从不同方向合拢，把附件拖机挤进窄道；战后肩枪回到本队维修架。
4. 消防架桥机拖着受伤左腿铺出低矮水幕，热锁视野被蒸汽切断，坡面恰好避开居民层。

### 战前维修小玩法

第一只适配件因实际磨损装不上。玩家通过：

1. 唐胶指导显出真实磨痕；
2. 本地学徒选择需要修整的位置；
3. 陆衡确认受力上限；
4. 学徒安装第二只适配件。

它只服务“本地人以后能自己做”，不发展成独立锻造系统教学。

### 观察塔战中事件

- 白鸢的初版路线要求灰崎完成一次高位跃迁。
- 驾驶员在透明板上直接改为低层绕行，路线经确认后才更新到玩家界面。
- 观察塔开战时位于城市认证的安全跟随轨；衡令在本回合改接拖索，安全预测边界才失效。
- 拖索擦过观察塔一次；七海把白鸢拉回，白鸢用红线标出下一根轨梁的横扫高度。
- 两名工务员和两名观察员蹲避后，观察塔立即沿安全轨退入实体隔断，不继续停留在战区。

### 不可逆输出

- 四台工务机夺回现役附件并与万机馆建立公共支援关系。
- 陆衡公开旧程序风险，旧跨城资质暂停；十七城成为后续长期任务，不在本章逐一解决。
- 衡令进入中央坞环并竖起环体。
- 社勇王按危机前已经排定的工务城全尺寸移动校正计划抵达，但驾驶席尚未开启。

## 四、E03 中央坞环决战

### 人话目标

玩家要把城市重量从万机馆转移到城梁一号的新承点，并在此期间摧毁衡令的永久征用结构。

### 地图轮廓

- 中央是由水平缓慢竖起的巨大坞环。
- 左侧是城梁一号旧基座，右侧是新承点。
- 下方是万机馆所在的局部试载位。
- 四台工务机沿坞环两翼推进。
- 馆守Z与社勇王在环内正面对抗衡令。

地图目标始终围绕一条清楚的动作：**让城梁从左走到右，把重量接过去。**

### 我方可操作单位

- 四台工务机
- 馆守Z
- 旧拳王
- 豪司驾驶的社勇王（阶段二加入）
- 万机馆母舰支援
- 城梁一号作为移动目标与超大型场景机

### 敌方

- 衡令本体
- 残余关节楔机、附件拖机
- 坞环上的固定征用炮与承载缆

### 阶段一：打开合体与迁重通道

- 工务城把临时公共救援任务直接发给社勇王主体AI；机体接受任务，企业只能保留遥测和事故异议。
- 工务机切断坞环两侧的承载缆。
- 玩家保护城梁一号离开旧基座。
- 豪司仍在地面清理四模块车的合体通道。
- 通道清空后，社勇王主体AI主动打开驾驶舱并选择豪司作为现场驾驶员。

### 阶段二：完整合体与第一锤

- 核心救援车、双臂救援车、下肢工程车和飞行工具车沿吊装机、灰崎和预算二号共同保持的路径高速穿行。
- 合体动画完整播放，社勇王在环心落地。
- 玩家获得一轮完整压制期；第一锤正面击裂衡令工具冠并取消部分征用技能。
- 城市频道完整庆祝，不能在同一秒立刻宣布所有胜利都是错的。

### 阶段三：第二锤被拒

- 玩家在目标仍安全时下令第二锤蓄力；衡令随后将残余承载缆接回住宅主梁，攻击线当场转红，迫使社勇王停手。
- 玩家在必杀预览和避难层结构摄像中清楚看见冲击线会沿承载缆传入住区；居民不站在临战窗边。
- 豪司下达第二击，社勇王拒绝并锁住武装。
- 这不是失败条件。豪司撤令后，社勇王恢复防御和工具模式。
- 战斗目标从“击破衡令”转为“护送城梁完成横移”。

### 阶段四：城市换位

- 城梁一号从旧基座完整抬起，横跨一个街区。
- 万机馆的承重压力随城梁移动逐段下降，母舰支援动作逐步恢复。
- 馆守Z用空右肩卡住衡令强拆钳。
- 社勇王把巨锤拆成撑顶、切割、牵引和冷却工具。
- 四台工务机从两翼拆下衡令最后的城市附件。
- 城梁一号完全落入新承点、载荷确认转移后，万机馆才从局部承点退出并封住坞环下口，堵住衡令继续进入城市主轴的路线。

### Boss胜负

衡令的工具冠、外甲和城市接口被彻底摧毁。它抛弃附属件，带着陆衡旧稳定核从下层旧舰骨撤离。玩家没有“差一点又让敌人偷走新样本”；敌人保住旧核和本章观察，已经足以继续发展。

### 大画面

1. 核心救援车、双臂救援车、下肢工程车和飞行工具车从三层城市道路同时冲入坞环，完成完整勇者合体。
2. 黄金巨锤击裂工具冠，随后在住宅承载线前停在半空。
3. 城梁一号跨越整片街区，城市天际线与道路地图永久改变。
4. 馆守Z空肩卡钳、社勇王拆锤为工具、万机馆从城下推回，所有尺度的机器共同把衡令拆离。

### 不可逆输出

- 社勇王与豪司完成本章正式共同作战，主体AI拥有拒绝权；长期部署在E04形成。
- 城梁一号、三台本地工务机、乐森偶与积木智者留在工务城；消防架桥机返回原城。四台职业机共同形成跨城公共支援网络。
- 衡令受损撤离，保留长期敌方行动线。
- 无牌一号在D2守住万机馆唯一的外泊维修连桥，不进入社勇王主导的Boss正面战；它的跨城作业包、公共泊位、七海登舰与百机航路留待E04完成。

## 五、E04 战后巨构校正与公共泊位

### 人话目标

战斗赢了，城市和万机馆仍要各自站稳。玩家要把万机馆从临时支点变成一艘能安全进港、以后也能回来的舰。

### 游玩顺序

1. D2深夜只做应急稳固：四台工务机锁定新承点，城梁一号保持城市重量，万机馆退到安全待机位。
2. D3上午，工务城先确认旧热损转子已经退出主循环并继续锁存在B1旁侧，再向无牌一号交付由牵引梁、城市导航应答器和道路试验号组成的跨城作业包。
3. 两块标准压载按社勇王外泊加下一航段补给的上限配置，挂上万机馆空外泊架。玩家让无牌一号牵引、四台工务机护路，依次完成低速转向、紧急制动与停靠；泊位供电同时恢复一座灾前旧中继。测试结束后，吊装机把压载卸回桥梁库；赵梅合作社把冠军转子的受限代管续到下一处安全泊位。
4. 泊位开放自由活动；战损、城市班表和各机去向以场景人物呈现。
5. 社勇王拒绝企业无人拖运。工务城提出三个月公共道路试用，由万机馆承担移动整备基地，企业在测试数据与城市监督条件下签下临时部署。
6. 七海收到D4复职审查通知，先保留返程选择；D3中午三人完整吃完饭。
7. D3 14:10，现代折叠包触发刚恢复的旧中继重连，二十七年前缓存包同时释放。七海认出当前包冒用旧签署链，将改革材料交给体系内同事，放弃本轮审查并以事故观察和签名滥用调查身份随行一个航段。
8. 纪存发出百机航路邀请，货柜领袖在完成进城引路后以完整对白说明去向并转入地面网络；社勇王以合体形态锁入万机馆大型外泊位随行。

### 结果与差分

- 校正成功固定获得公共泊位、有限保险和低速稳定；完成度只改变外甲修复资源与城市供能库存。
- 无牌一号正式随舰。
- 社勇王成为可长期操作单位，但企业产权与三个月期限仍会回来制造剧情。
- 七海的登舰来自职业取舍，不是任务强制、暧昧奖励或上级派驻。
- C01白色衬片只保留在后台问题账中；本章不新增组件、不在开放资料重复提示，也不参与E04选择与解题。

### E02/E03灰盒制作门

```text
E02平面
上层悬轨 -------- 连接点A -------- 中层环路
                       \             |
                        连接点B      战备库入口
                         \           |
下层旧舰骨 -------- 连接点C -------- 中央坞环

安全跟随轨位于中层环路外侧；观察塔受一次擦击后自动退入实体隔断。

E03剖面
上层：西环避难层 / 住宅主梁（仅结构摄像）
中层：城梁旧基座 -> 中央坞环 -> 东侧新承点
下层：万机馆局部承点 / 坞环下口 / 衡令撤离旧舰骨
```

- E02只允许三条固定路线和三处连接点；衡令本体占住战备库入口，四辆附件运输车沿同一撤退方向移动。
- E03城梁一号是脚本护送巨构，不作为常规格单位转身搏斗；万机馆固定为下层多格支援单位，城梁完全落位后才解除固定。
- 社勇王四模块只在合体通道阶段作为路线目标；合体完成后替换为一台常规可操作单位，不让五个控制对象同时常驻。
- E02/E03任何新动作若无法放进上述两张灰盒，必须先回到预制包补模，不得在Reader临场新造道路、机房或卷扬。

## 七、战斗验收

- 三场战斗的主动作分别是`复位拆锁 / 夺工追击 / 合体迁重决战`，不存在连续三场救援同构。
- 玩家能用一句话解释衡令为何起初有合法性、何时越界、市政为何改为共同作战。
- 四台工务机、万机馆、馆守Z、城梁一号和社勇王各有不可互换的战场职责。
- 每个高潮至少有一个整机或城市尺度动作，微小机构变化不承担主要叙事。
- 社勇王第一锤完整成功；拒绝第二锤来自可见条件变化，不否定热血与必杀技。
- 白鸢的路线、陆衡的程序和唐胶的手艺都有人类或机器执行者，任何纸、数据或名字都不直接改变现实。
