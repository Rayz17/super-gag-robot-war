## 一、连续剧情是否成立

C01不是四个并排事件，而是一条连续升级的因果链：

```text
万机馆次晨闭馆，纪存进行最后导览
-> 地外突入体BREAKER突破近海，十余个同类接触点大多被海防挡在城外
-> BREAKER钻地破防，少量弱小体散乱漏入旧会展街区
-> 人群进入封闭通道，馆守Z在最后应急车辆撤离期间起身护线
-> 东门关闭后，馆守Z把29米地面壳拖进清空广场并以盾拍取得阶段优势
-> 豪司驾驶勇拳加入，双拳打穿重甲
-> 真正飞行核心展翼，首次把街区幸存体和城外同类同步为统一追击
-> 纪存决定把战场带离城市，万机馆恢复巡展舰
-> 勇拳与城市防空压住核心，馆内外并行完成紧急离舰准备
-> 馆藏中的旧巡展装备重新用于战斗
-> 馆守Z以推进骨架离舰，在外海击毁核心；勇拳托住其左肩，两机落回放平裂盾
-> 核心毁灭后追舰小体失去统一方向，整场BREAKER危机至此结束
-> 终战后主循环转子持续高温并异常震动；万机馆发出全域维修求援
-> 赵梅从木桶街以重载泊位和九米级测试转子回应，与巡展臂问题、右拳采样共同发动C02
```

每一次转折都由上一阶段的胜负与选择产生，没有使用新任务通知、行政处罚或临时装置强行转场。

## 二、C01章末唯一有效状态

### 人物

- **纪存：** 位于万机馆入口前厅恢复的公共航行台，已经完成导览、撤离、巨机协战和起航决定；玩家只知道他异常擅长理解机器意图，不知道其机魂真相。
- **佐伯七海：** 留在东区接受内部调查。她撤回的是本人签发的馆守Z停机令；外海航路由城市应急系统开放，她只是把公开路线传给纪存。
- **唐胶、兜灯：** 随舰。唐胶负责模型、手修、旧件与适配史，并在转子求援中留下技术联系方式；兜灯负责馆守Z实机结构和安全边界，也作出“当前可飞、停机后未必能再启”的万机馆机况判断。
- **赵梅：** 仍在木桶街，本章仅以远程语音出现。她是唐胶已故徒弟的母亲；因全域求援而提供重载泊位和测试转子线索，不承诺必然兼容。
- **荒川豪司：** 留城接受企业处分；勇拳已由企业回收。他不是C02默认常驻队员。
- **小满、阿澄、老余和其他观众：** 全部进入东区加固灾害避难所，通过直播观看后续战斗；安全留城，不随舰。
- **陆衡、白鸢：** 均未在C01出现。不得从History稿件补回C01。

### 机体与舰体

- **旧守护者/馆守Z：** 同一主体。馆守Z是18米实机，旧守护者是机魂人格及日常称呼；人格根位于馆守Z胸腔，轮式终端只是输出端。E02损坏的是在用外壳，飞行稳定后已换上库存备用外壳。终战时推进骨架完成一次短程离舰；击破后勇拳托住馆守Z左肩，两机落回放平裂盾，不使用回收索。
- **馆守Z原右前臂：** 在过载火箭拳中毁损，主要残骸留在封锁旧址；右肩接头烧损。
- **巡展臂装：** 已接在馆守Z右肩，只能抓取、放锚、牵引和工具作业，不能握拳，不是永久后继右臂。
- **退役重盾与推进骨架：** 重盾在E02只留下四处焦痕、热变形与边缘凹折；E03重新交战时承受BREAKER正面冲撞，才形成首道贯穿裂纹；E04小体撞击只能延长旧裂纹并崩落边角。馆守Z随后一路把裂盾带回外部泊位，先保护离港作业，终战前放平作为双机归舰缓冲面并彻底碎裂；它不是发射坡。推进骨架在离港前已固定，只在终战点火一次，不形成馆守Z常态飞行能力。
- **勇拳试作机：** 无已知独立机魂，由豪司驾驶完成协战与冲击回送，战后回收。
- **消防架桥机：** 归城市消防驾驶组，完成撤离支援，无强制新增旧伤。
- **跌跌、机器犬：** 随舰，属于小尺度探索伙伴，不计入巨机主力。
- **万机馆：** 起飞前已断开市政连接、收回外桥、撤空外部机位并锁住馆藏；随后以自身旧动力压毁一次性支撑座，恢复约130至160米长的巡展舰形态。主展厅和主要馆藏随舰。舰体没有普通起落架，不能原样落回旧址；它不是馆守Z身体，不是人形，也尚未确认独立机魂。

### 敌人与世界

- **BREAKER：** 地面黑甲外壳和飞行核心均已击毁；其同步的小型突入体群在核心毁灭后立刻失去统一方向，残余威胁随后由防空和近防处理。
- **小型突入体群 / ENEMY_C01_RIFT_SWARM：** 这是跨层一致性使用的中性群体锚，不是公开物种名。E01大多在城外，E02少量散乱漏入，E03首次被核心同步，E04继承同步状态并在核心毁灭后失序；不锁造型、能力、动机或精确部署数量。
- **地外轴：** 玩家已经知道地球仍受具体地外势力骚扰，并亲眼看见一个大型突入体与一群弱小同类，不知道裂星潮完整生态。
- **白色采样机：** 带走馆守Z右拳残片，断裂支撑又从其夹爪内侧刮落一枚未知白色衬片；所属、目的与是否连接白框/索引均未确认。
- **万机馆主循环转子：** 持续高温并异常震动；当前低功率飞行可以维持，停机后能否再次安全启动未知。主轴弯曲等内部损伤尚未确诊，留待C02靠泊检查。
- **原址：** 一次性支撑座和市政连接被巡展舰挣开，成为灌水船坞；万机馆不会回去恢复成原先的固定馆。城市次日只把白色碎片登记为未知复合材料。
- **城市防卫表现：** C01只保留近海与地图边缘炮火，不登记新的城市防卫机体、驾驶员或保全变量。

### 关系与日常

- 纪存与七海的正式饭约被敌袭完全打断。七海战后回到已经闭厨的餐厅，两只主餐盘都没有使用；纪存答应下一次由自己订位。
- 两人有不浅私交和明显牵挂，但没有告白、破裂、和解或关系定性。
- 唐胶与兜灯通过巡展臂装表现专业合作，尚未进入正式恋爱节点。

## 三、C02的直接发动条件

1. 万机馆不是因为燃料即将归零而被迫去木桶街；它当前能以低功率继续飞行，但主循环转子温度不降、舰腹异常震动，停机后能否再启动无法保证。
2. 巡展臂装经不起下一场同等级大战，馆守Z仍缺真正的战斗右臂。
3. 万机馆先发出包含舰体尺寸、转子异常、接口图和唐胶联系方式的全域维修请求；赵梅再从木桶街回应足以承载万机馆的重载泊位与九米级测试转子。她不保证兼容，具体结论留待落地实测。
4. 唐胶说明赵梅是自己已故徒弟的母亲，并确认她的接应可信。C02必须让这段关系既能解决问题，也带回他真实的旧责任；赵梅如何从亡子遗留资料学会组织合作社，应在C02展开而非C01说完。
5. 纪存已经是巡展组织者。C02不能把他降回审批、贴标签、被动受难或重复犯错。
6. 七海仍然远程且受调查。她若要登舰，必须由后续故事提供正式职责、个人选择和实际交通过程。
7. 豪司与勇拳不在舰上；若回归，必须延续企业处分和机体所有权。
8. C01留下的是从采样机夹爪内侧刮落的未知白色衬片，不是采样机残骸。C02可以做材质比对和有限推断，但不得凭碎片直接确定采样方、让敌方知道纪存本质或远程控制馆守Z。

## 八、结论

C01已经形成一个可读、可玩、可制作并能自然发动C02的L4基线。它的核心不是“万机馆完成合规撤离”，而是：

> **玩家在最后一场导览里爱上一座馆，亲手让它保存的巨神重新站起，再把整座博物馆开进天空。**

累计连续性无L4阻断。L4.5四席审查曾发现广场方向、城市防卫资产等级和馆守Z飞行边界三项上游问题；后续Reader物理因果盲审又发现观众避难、终端载体、起飞准备、返航条件和采样证据缺口。最新迁移修正了“话数等于关卡”的生产误读，锁定重盾损伤只能在可见战斗中逐级发生，并补回C01至C02真正的转子急修因果：E02至E04仍为同一BREAKER Operation，完整继承敌方形态、小体组织态、馆守Z伤势、裂盾状态、地图破坏和撤离线状态；Mission Clear之后才进入机况检查、求援和路线选择。上述事实已同步到总纲、逐话结构、状态账与演出承载；Reader及其三层派生物仍待本轮重建与用户验收。

### 最终物理回迁

1. 离地以前，万机馆仍锁在一次性支撑座和馆舍结构中，只测试左右舵面响应、侧推器短脉冲和紧急停机；舰艏不发生实际偏转。
2. 起飞准备不再被压进敌方一次俯冲的几秒钟内。勇拳与城市防空连续拦截飞行核心，角色用战斗换出断管线、收检修桥、固定馆藏和切换航行炉的窗口。
3. 馆守Z的出入路线固定为“主厅南侧巨门—暴露在地面的巡展舰前甲板泊位—南侧广场”；万机馆升空时，这座外部泊位随舰体一起成为舰首甲板。
4. 旧自动航行系统负责巨舰姿态、推力分配和扶正。纪存负责判断逃离城市的路线、指定火力方向并唤醒旧系统；他在没有读标识前便认出航路杆，是主角异常能力的第一次提示，不等于突然掌握全部巨舰驾驶技术。
5. C01可称万机馆的“第一次紧急航行战”或“第一次舰体参战”。以后若使用“第一次母舰战”，必须限定为新的可见差异，例如C05的“第一次完整、可控的多格母舰入盘”。

上述回迁完成后，当前复核结果为`P0=0 / P1=0 / P2=0`。封存本回执后，可重新审定L4.5演出承载规划并由Episode源稿重组Reader。
