## 一、连续阅读结论

**PASS。C01能够直接发动C02，C02也没有提前消费C03及全剧谜底。**

C01在天亮后结束：固定馆毁坏，万机馆未经批准离开原城；馆守Z右前臂报废，推进骨架与裂盾耗尽；七海留在原城接受调查；勇拳仍是临时友军；白色采样机带走一块馆守Z残片；唐胶认出一通来自木桶街的电话，纪存把航向转向东南。

C02在数小时低速航行后开始。万机馆抵达木桶街、完成最后一次靠泊调整，兜灯才确认九米级原装主循环转子已经热损。这个损伤不是C01正文遗漏的已知任务，而是“逃出来以后才敢完整检查”得到的新坏消息。当地能做全尺寸训练件和低速改装，却没有整件吊出、校直与高速动平衡能力；万机馆也没有足够动力继续去工务城。

木桶杯因此不是绕路支线。唯一能及时替换的同代九米转子属于杂鱼港，固定在赛事泊位中央检修架上做交付前低速测试，并被列为冠军奖品。万机馆作为待移交资产不能参赛，越界后的临时保全人也不能自行处分它；赵梅合作社只能担保自主机体无牌一号代表自己报名。无牌一号若夺冠，才有权把奖品交给合作社受限代管并安装于万机馆。

C02的情绪与玩法也完成换挡：C01是闭馆、突袭、巨神起身和逃离城市；C02是模型街、机器人竞技、师徒必杀技、全装冠军、腰斩动画最终话和群像救场。两章都谈机体是否拥有自己的行动，但没有重复同一种灾难或同一种解决方法。

章末，万机馆获得的仍是临时生存窗口，不是完全修复。新转子一旦升到航行功率，就必须不停机抵达工务城；无牌一号与旧拳王的既有保险也只延长到那里。C03的正式运营身份、长期保险、旧转子修复和新转子校正仍然不可跳过。

## 三、时间、空间与尺度

### 时间

```text
C01黎明：万机馆离开原城
-> 数小时低速航行
C02第一日近中午：抵达木桶街并完成靠泊
-> 第二日：构筑、指导战、白鸢到场
-> 第二日夜至第三日上午：调查与半决赛
-> 第三日下午：冠军战与赛后事故
-> 第三日傍晚至第四日：救场、交割、安装与启航
```

白鸢从另一座城市赶来至少经历一昼夜，没有瞬移。七海始终留在原城。陆衡只远程会诊，肉身首次登场保留到C03。

### 空间

- 木桶街不是狭窄商业小巷，而是“内圈模型街、中圈全尺寸工房、外圈巨构泊位”的沿海工业聚落。
- 约260米货运环经重载道拖入赛事泊位后锁定。E04断裂的是临海外侧老化外轨，不是整座平台在比赛中移动。
- 万机馆坐在有连续地面支撑的船台托架上，能由货柜领袖与车队沿平行作业道低速挪近；货柜领袖不能直接拖舰壳跨越水空段。
- 九米转子始终固定在中央检修架，事故不把它变成战场道具。E05确认无损后才走吊运、牵引、升降和安装路线。

### 尺度

- 无牌一号16米、旧拳王17米、完全版王者20米、三台飞行机约13米、馆守Z18米。
- 缩尺模型只在桌面表达动作意图；全尺寸工房另行制作训练保护；巨机本人完成真正动作。
- 万机馆只承接货运环临海一侧，馆守Z只固定一处断桥。没有任何十几米机体徒手托住整座260米平台。

## 四、人物与关系连续性

### 纪存与七海

C01已经建立两人有不浅的私交和价值冲突。C02沿用这条前情：纪存为继续航行愿意押上横移退路，七海认为他又把自己和整艘舰当成可消耗资源。她没有靠“放行几秒”帮助他；她的实际贡献是迫使赛事和赛后演出分开、要求观众撤离，并在事故后承担原片保全的署名风险。

### 纪存与白鸢

白鸢在C01没有实体登场。C02先以三年前补稿被盗用建立她的行动动机，再让她实体到场。她与纪存从追责、判断机体愿望和风险争执开始；E04互救建立身体距离，但不立即和解或相爱。

### 七海与白鸢

两人在E02由纪存正式介绍，才第一次通话。此前只能知道对方的公开身份，不能表现成熟人。E04的协作来自已经建立的有限工作关系：白鸢停止现场演出，七海提出保全原片的方法，本地人员实际执行。

### 唐胶、赵梅与兜灯

赵梅不是突然出现的技术大师，也不是为唐胶关系线服务的工具。她从儿子留下的工作一点点学会提问和组织合作社；唐胶负责手作与动作语言，兜灯负责全尺寸安全。唐胶与兜灯的靠近来自一起把方法交给别人复做，不用吃饭和吃醋代替关系发展。

## 五、谜团与未来保留

C02只允许玩家看到这些表层现象：

- 长期扮演、排练、观看和商品叙事会在机魂身上留下角色道路；
- 自主机体可能认同、修改或拒绝这条道路；
- 白鸢对短期行动结果异常敏锐，但她画出的可能会被真实选择推翻。

C02不得解释：

- G.A.G.活化机制和机魂形成全过程；
- 纪存真实身份；
- 索琳、白框和二十七年前清噪；
- BREAKER与白色采样机的后台归属；
- 远星与终局判断。

## 六、C03继承包

C03必须从以下事实开始，不能免费重置：

1. 万机馆已经升到航行功率并在途中，停机后无法再次启动。
2. 新转子已装入但未完成正式校正；热损旧转子仍在B1旁侧锁架等待修复。
3. 万机馆没有正式运营身份和长期保险。
4. 无牌一号与旧拳王可用，但身体所有权未转给万机馆，现有保险只到工务城。
5. 白鸢已经实体登舰，七海仍在原城，陆衡在工务城等待肉身会合。
6. 火种货柜领袖只护送港区与陆路转接，不能充当永久万能拖车。
7. 完全版王者、坞工杰克和三台飞行机留在木桶街，可在百机航路中回援。
8. C01的BREAKER、白色采样机和城市调查仍在继续，不能因赛事篇而消失。

## 七、裁决边界

C01-C02章间连续性内部通过。当前结论只说明两章放在一起不矛盾、能自然发动下一章；是否好看、好玩、好磕，仍需以重新合成的C02 Reader由用户复读判断。
