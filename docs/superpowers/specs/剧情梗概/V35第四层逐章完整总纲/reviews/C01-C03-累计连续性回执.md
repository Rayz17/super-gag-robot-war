## 一、三章连续主线

C01让主角团在闭馆、火灾与封存执行中失去固定旧馆，并以受伤的万机馆第一次起航。C02没有把逃亡当成免费升级：百米舰体缺少主循环转子，主角团必须进入木桶街的维修、物流、收藏与商品生态，才能夺得一套退役实机转子。C03继续读取这套现实条件，新转子只能把万机馆送到工务城，仍需满载校正、公共泊位和事故保险。

工务城的冲突也由抵达目的直接发动。三方只同意局部低比例试载；衡令认定再次停摆比越权更危险，擅自加荷，并把四组退出支撑挪去强撑供水干线、东站和两段受损高架。纪存以最小卸载发现退路被破坏，随后主动复位接回西环医疗交通段的局部承点。四组支撑不能直接撤回、备用库已经见底，衡令又拆走制造和架设替代支撑所需的职业工具；陆衡旧程序、四台工务机、社勇王和城梁一号因此进入同一条“把重量真正搬走”的故事。

三章的因果链已经形成：

**闭馆失去固定家园 -> 起航需要新转子 -> 转子需要木桶街 -> 新转子需要工务城校正 -> 获得第一个可返航港口 -> 天空铸环发来身体制造与外敌求援。**

没有一章依靠“主角随便想到去下一站”推进。

## 三、主角与群像连续状态

### 纪存

- C01在旧馆被迫起航，能力表现为听见近场机器请求。
- C02以策展与调度能力组织模型线索、全尺寸工程和多机协作，但所有异常判断仍需现实复核。
- C03第一次主动让百米万机馆复位并分担西环医疗交通段的一处局部承点，并在终战选择守住成果而非追击敌人。
- 到C04为止，他的“多机导航天赋”已有三章递进，但机魂实体真相仍未公开。C04可以让百相对这项天赋产生强响应，不能突然改成纪存远程控制所有身体。

### 七海

- C01因闭馆事件停权，选择保留事实而非完成封存。
- C02仍在东区远程参与事故保全，与纪存保持既有私交；纪存正式介绍后，她与白鸢建立有限合作，并确认万机馆抵达工务城后继续发送机身记录。
- C03因原签署链实体到场，与白鸢先形成专业冲突和独立互救；她在获得真实复职审查机会后，因现役系统冒用旧签署而把改革材料交给体系内同事，放弃本轮审查，以随舰事故观察员和旧签名滥用调查员身份登舰。
- C04必须把她写成停权、有限权限但拥有真实经验的人，不能恢复成万能授权者，也不能再次长期只存在于通讯屏。

### 白鸢

- C01只留下被盗分镜的痕迹。
- C02从追查被擅用的补图进入木桶街；在看到无牌一号与完全版王者拒绝照旧终幕演出、并亲历事故后主动登舰。
- C03首次将L1预演用于动态战场，并接受驾驶员改掉中心构图。
- 她的能力链已经锁定为“现实输入 -> 个人预演 -> 可读草图 -> 驾驶员/工程员采用 -> 物理执行”。C04若出现更高层预演，必须新增清楚的输入、执行者、代价与限制。

### 唐胶、兜灯、陆衡与豪司

- 唐胶已完成C02公开维修史，C03只承担手艺教学与实际磨损判断；C04可进入模型师/原型师/生产链冲突，不再让他重复忏悔。
- 兜灯连续负责馆守Z、转子、万机馆和社勇王的安全，但已经把硬停权交给现场，不以独占控制表现亲密。
- 陆衡在C03失去旧跨城资质，十七城旧程序成为长期事业线；其角色不再只是理性评论员。
- 豪司从C01失去勇拳、C02失去优先席，推进到C03被社勇王选择、完成大胜并主动撤回错误命令，已经形成一段完整成长阶梯。

4. 纪存肉身始终在万机馆或明确的人类空间；任何精神/机魂连接都不能让他同时出现在多个驾驶舱。
5. 百相、三地方旗舰、米拉与艾达、断冠及灰模身体均需在C04预生产中重建尺寸、控制权和位置，不能继承旧Reader临场术语。

7. 工务城是可返回基地，不必在C04立即失去；下一次危险不应靠摧毁刚获得的家来制造。
8. 木桶街协力编队已在C03E01实际兑现一次；C04不得把红蓝黄三机忘回“背景盟友”状态，也不得把它们写成自动舰载机。
