## 一、统一门槛

从本轮起，每个第四层关键场面必须同时回答五项：

1. **玩家可见证据：**屏幕上究竟出现什么动作、物件、状态变化或人物反应。
2. **暂定演出载体：**由探索、ADV、地图事件、SRPG、战中通讯、Cut-in、短动画、UI、经营或小游戏中的哪一种承载。
3. **信息边界：**玩家当场必须理解什么，什么只需产生疑问，什么仍是作者后台真相。
4. **最低资产：**若不增加额外场景和一次性机关，最少要有哪些角色、机体、背景、状态差分与UI。
5. **旁白删除判据：**删掉梗概解释后，玩家能否复述“谁想做什么、为什么打、作了什么选择、结果改变了什么”。

任何一项缺失，都只能叫设定说明或作者推理，不能算完成第四层设计。

## 三、跨章可见连续性

### 纪存的能力

C01先让玩家听见低功率机群回应他；C02让他区分共享装配记忆与个体选择；C03让他比仪表更早察觉巨构重心交接；C04才由韩秀雅用既有记录确认，并借铸环导览系统放大到巨体导航；C05把能力推到公开大胜与过载风险。能力不是角色口述出来的新设定。

### 模型、分镜与现实机器

- 模型只保存形状、维修和版本线索；C02必须经过扫描、实机复核和全尺寸制造，才影响巨机。
- 白鸢的分镜只产生可供人和系统选择的预演路线；C02-C04均以战术UI、现场修改和骨架复现表现，不让纸面线条直接改变物理现实。
- 唐胶负责缩尺形状、材料痕迹与版本手艺；陆衡负责全尺寸承载、控制与工程验证。两者在C02-C04保持不同职责。

### G.A.G.、白框与索引

- G.A.G.以多种候选回应、旧残响同时活化和机体主动拒绝表现，不承担供能、签名或复制功能。
- 白框以实体设备、物流、扫描、空白骨架和复制主机表现，是人类机构可操作的身体与数据链。
- 索引在C02-C05只以系统偏爱可复用模式、保存优化摘要的静默结果露出，不显形替敌方下令。

### 万机馆成长

C01脱离固定馆址，C02换上主转子，C03完成重载校正和公共泊位，C04只作铸环固定支援，C05才首次低速作为多格母舰入盘。暴走、完整战斗展开与人形化仍留后章，不靠一句“升级完成”跳级。

## 四、制作边界

本轮没有提前决定具体机位、镜头秒数、完整台词、Cut-in长度、敌军数量、数值、逐帧机械受力或最终资产拆单。它们属于后续层级：

```text
章级完整剧情总纲
-> 章级演出承载规划
-> 逐话Episode Reader
-> 台本 / 分镜 / 地图事件 / 战斗设计 / 资产任务
```

章级演出承载规划必须按一次真实游玩的顺序排布舰内自由活动、ADV、探索、地图事件、SRPG、战中通讯、短动画、Cut-in、结算和可选事件，并统一检查动画峰值、ADV长度、地图复用与资产成本。未经过该层，不得把章纲里的解释段直接拆成对话。
