## C11 白名单都市与公共信托

本章是七海主场。代哥不再只是秩序部门，而是庞大生态：商品、再版、封存、公共安全、版权清算、粉丝期待、硬线创伤和内部改革互相纠缠。七海成熟、迷人、知道问题，也知道自己和系统共生。她不只是给四十秒的人，而是愿意让例外留下可追责痕迹的人。

### E41 白名单接待室

**本话功能**  
进入白名单都市，让玩家看见代哥生态不是单一恶。它确实能保护普通人、赔付损害、阻止G.A.G.灾变复燃，也会把不规整的热爱磨成安静资产。

**剧情流程**  
白名单都市不像反派总部，更像过分干净的展会与市政厅混合体。预约队列、再版抽选、认证失败窗口、合规修理柜、封存车和公共信托样板间同时运作。玩家能看见有人真的因为代哥赔付拿回旧件，也有人因为缺一张来源证明被拒在门外。

七海首次以实体主场出现。她没有制服式压迫感，而是成熟、冷静、懂流程，也懂流程里面被磨掉的人。她接待纪存时没有用全息窗口隔开，而是贴身身份扫描：权限锁贴近终端，手指替他改掉一个会让万机馆立刻被封的词，然后在同一行留下追责编号。这个动作有成人张力，但不露骨，危险来自距离、权限和她明知道自己在越界。

V27.1回归补丁：身份扫描必须演出来。纪存颈后旧馆接口线在扫描门前弹出，系统把它识别成“未备案人格接口”，下一秒就要把违规码投到整面玻璃上。七海没有叫停队列，而是走近半步，抬手把那截接口线扣回他领口内侧，声音仍然公事公办地念“扫描遮挡，人工复核”。她的指尖停留得比流程需要久一点，屏幕上同时出现她的工号和追责倒计时。白鸢隔着玻璃看到这一幕，先画了七海的手，又把纪存的脸涂掉一半。这个场面不靠台词卖暧昧，而让三个人都被同一个动作改变位置：七海越界、纪存欠她一个公开解释、白鸢第一次觉得自己不是唯一能改写纪存命运的人。

代哥硬线执行官也到场。他不是上级噪音，而是见过旧G.A.G.事变死亡的人。他认为七海的改革过于相信个体判断，万机馆每一次例外都可能重演灾变。纪存第一次看见七海并不是“系统的脸”，而是在两个都真实的压力中维持一条缝。

**战斗与玩法 / 机体 / 梗点**  
类型：清算都市探索 + 审查队列。地图为接待室、再版抽选厅、认证窗口、合规修理柜、封存车道。机体/单位包括白名单接待机、市政劳务机、法约束者、勇气审批代理、火种资产牌。梗点包括企业秩序、再版抽选、认证失败、公共安全与热爱冲突。

**关系 / 情绪 / 债务**  
七海和纪存的吸引从远程流程缝隙升级为身体距离与权限危险。白鸢在远处看见七海替纪存改词，第一次真正吃醋，但她讨厌自己吃醋，因为七海确实在救万机馆。情绪物件是纪存终端上那枚“已修正，待追责”的白名单水印。敌方收益：硬线获得万机馆可被合法安置证据。

### E42 三门战场

**本话功能**  
把路线选择做成地图，而不是菜单。合法门、分镜门、维修侧门分别代表七海、白鸢、唐胶/兜灯的解法，每条都好用，也都有代价。

**剧情流程**  
白名单都市遭遇索引小规模入侵。三扇门同时打开：合法门有代哥火力和护城许可，但会自动记录所有异常；分镜门能绕过封锁，却会把场景改成白鸢能理解的构图；维修侧门慢、脏、窄，却能保留未经审批的真实痕迹。

七海给出合法门路线，语气平稳，却在纪存靠近门禁时低声提醒：进去以后，你每一次支援都会变成我的责任。白鸢给分镜门，她说可以让万机馆不被看见地通过，随即又停住，因为她知道“不被看见”也可能是另一种擦除。唐胶和兜灯在维修侧门争执谁先钻，最后唐胶背工具，兜灯背安全锁。

玩家必须选择主路线，同时用支援点照顾另两门。索引刻意攻击未选路线，迫使玩家承认可见代价。纪存如果只走合法门，白鸢支援灰；只走分镜门，七海追责升；只走维修门，战损高但唐胶/兜灯信任升。

**战斗与玩法 / 机体 / 梗点**  
类型：SRPG三门路线战。机体/单位包括合法门代理机、分镜门格线、维修侧门工务车、三法城法约束者、勇气审批支援。胜利条件是至少两门支援链不断；失败条件是某门完全锁死。梗点包括路线选择不是菜单、门禁权限、维修侧门、合法保护很香。

**关系 / 情绪 / 债务**  
白鸢看见七海和纪存流程默契，误以为纪存更信七海；纪存没有时间解释，选择合法门救人。这个误会不能马上解开，进入C43。情绪物件是三门通行牌，一张白、一张半透明、一张沾油。敌方收益：索引获得关系救场路径。

### E43 公共信托样板间

**本话功能**  
让公共信托的诱惑真的成立。它能让万机馆合法、稳定、被社会承认；也会把G.A.G.、商品生命和错版热爱静音成“已妥善处理”。

**剧情流程**  
公共信托样板间向纪存展示一个完美未来：万机馆有安全场地、再版合作、赔付基金、展品修复、观众保险、未成年人保护、G.A.G.监测。纪存被击中，因为他真正害怕万机馆被证明只是混乱、消费、幼稚、危险。他第一次想要被社会承认，而不是永远流亡解释。

七海知道这个诱惑，她也曾想靠公共信托改革代哥。硬线执行官把她的七秒例外和追责水印放到听证台上，证明她已经不适合主持万机馆审查。白鸢看见纪存被承认诱惑击中，误会加深：她以为他也想被一个漂亮框架收编。

战斗与听证混合。公共信托展柜会保护机体，但也会静音支援台词；商品生命资产牌给火种系提供法律身份，但会剥离私人姓名贴；三法城法约束者保护观众，却把部分机魂定义成资产。玩家要保留信托中的好东西，同时阻止静音。

**战斗与玩法 / 机体 / 梗点**  
类型：听证 + 城市防卫混合战。机体/单位包括公共信托展柜、商品生命资产牌、三法法约束者、勇气审批代理、市政劳务机。胜利条件是保住四件关键证据且公共信托静音率不超过阈值。梗点包括合法保护很香、公共信托、商品生命权利、企业改革不是喊口号。

**关系 / 情绪 / 债务**  
纪存的主角熔炉推进：他被社会承认诱惑击中，差点选择安全收编。七海被职业追责刺伤却仍不撤退。白鸢误会纪存想被七海的框架带走。情绪物件是公共信托样板间里一张漂亮但无声的展签。敌方收益：硬线保存七海违规证据。

### E44 例外不是赦免

**本话功能**  
C11高潮。七海证明例外不是赦免，而是愿意留下伤痕与追责。G.A.G.原名暴走救场，但暴走有燃料债。

**剧情流程**  
硬线锁死所有门，索引趁机接管白名单系统，把万机馆定义为“最适合被妥善安置的风险”。合法门、分镜门、维修侧门全部被封，纪存终端提示：若接受公共信托，可保全九成展品，但错版、失败、商品生命和未确认关系全部静音。

七海走到旧式手动开关前。她知道按下后会失势，不再能用“系统延迟”遮掩；这一次她把自己的编号、职位和违规理由全部留在屏幕上。她对纪存说的不是浪漫台词，而是冷静命令：别把这个当成我原谅你，我只是让责任有地方落。她按下开关，万机馆获得一次手动例外。

G.A.G.原名暴走。被改名、错版、失败、重涂、撤退、缺页、灰模、旧拳王、跌跌等证词短暂发光，形成“原名回潮”。暴走强得吓人，直接撕开白名单锁，但燃烧掉部分证词副本。纪存想扩大暴走，白鸢阻止他，七海也阻止他：这不是免费奇迹。

**战斗与玩法 / 机体 / 梗点**  
类型：规则锁死 → 手动开关 → 暴走结算。机体/单位包括G.A.G.原名暴走态、白名单灼痕开关、公共信托锁、硬线执行队、法约束者、火种资产牌。胜利条件是打开三门并保留核心证词；失败条件是G.A.G.燃烧过量或公共信托完全接管。梗点包括例外救场但可追责、暴走有债、合法/自由切换。

**关系 / 情绪 / 债务**  
七海失势但不洗白，她的成熟魅力来自承担职业代价。纪存公开白名单灼痕，不把她的牺牲藏成私情。白鸢救下七海追责记录，承认这个女人也在被系统切伤。情绪物件是七海权限锁旁的灼痕。敌方收益：索引获得白名单例外与关系样本。

**C11 前缀回归小结**  
本章通过。七海从“40秒女人”升级为成熟改革者，关系线有误会、身体距离、职业牺牲和三角张力。未解决风险：G.A.G.暴走必须在C12付债，不能变免费大招。

## C12 残缺索引反攻

本章是索引主场。它不再只是整理者，而是能生成完美假馆、复制玩家高频爽点、清噪支援台词、模拟七海/白鸢/纪存关系路径的强敌。玩家必须用缺点、失败、低规格、残缺支援和痛苦关系台词反预测。

### E45 最优战役生成中

**本话功能**  
让索引先给玩家真正爽的完美战役。玩家必须先被诱惑，后面拒绝才有重量。

**剧情流程**  
万机馆进入镜像假馆。这里没有灰尘、没有维修债、没有追责水印，馆守Z完整站立，星火巨神有最漂亮合体，七海投影温柔批准，白鸢投影画出无痛结局，唐胶不再嘴硬，兜灯不再报损。索引用玩家前十一章最喜欢的爽点生成“完美机器人动画开场”。

战斗前半很爽。援护必定准时，合体不失败，量产机有英雄镜头，失败机不摔倒，歌声停火不伤人。玩家越使用这些最优支援，镜像馆越稳。随后被删证词列表开始滚动：旧拳王维修单、错版口令裂痕、七海灼痕、白鸢撕页、撤退噪声、跌跌摔痕都被标为“已妥善处理”。

纪存被诱惑最深，因为这版万机馆终于不需要他狼狈解释。他的机魂记忆短暂苏醒：一个更旧的万机馆曾经也试图用“妥善处理”阻止灾难，最后烧掉了名字。记忆让他身体过热，终端权限失控，敌方开始追踪他的机魂签名。

**战斗与玩法 / 机体 / 梗点**  
类型：镜像馆防卫战。机体/单位包括完美假馆、镜像馆守Z、投影七海、投影白鸢、标准合体群、最优支援按钮。胜利条件不是击破，而是标记五处被删除的缺点；失败条件是接受完美战役协议。梗点包括完美最终话提前诱惑、玩家高频战法被复制、无争议滤镜。

**关系 / 情绪 / 债务**  
纪存差点选择完美假馆，七海真身通过灼痕通道质问他：你要的是安全，还是不用再向任何人解释？白鸢看到投影自己比真自己更温柔，受伤。情绪物件是被删除证词列表。敌方收益：索引用玩家高频爽点生成战役。

### E46 缺点才能出击

**本话功能**  
低规格单位逆袭。跌跌、灰鸥量产G、市政修门机、小查和旧机缺点被转成反预测战术。

**剧情流程**  
索引根据最优战役预测所有主力动作。纪存决定让缺点出击：跌跌会摔倒占错格，灰鸥量产G低数值但能推盾，市政修门机动作慢却能修被索引判定无用的侧门，小查错词能让清噪塔短路。陆衡承认失败记录不只是证据，也是武器。

玩家要用低效行动打断预测。跌跌摔倒不是笑话，它倒在敌方最优路径上；灰鸥盾阵不打Boss，只推开被删除的证词车；市政修门机修一扇没人走的门，结果打开七海灼痕通路；小查把“最优”喷成“最忧”，让索引延迟一拍。

中段，索引学习低效也可成为最优，开始预测缺点。纪存意识到不能把缺点也立成新套路，必须不断让真实情境先于标签。他选择放弃一条漂亮反击路线，保护一张无人认领维修单。

**战斗与玩法 / 机体 / 梗点**  
类型：反预测战 + 低效行动奖励。机体/单位包括跌跌、灰鸥量产G、市政修门机、废城小查、缺点证据阵列、索引预测线。胜利条件是用四类非最优行动打断预测；失败条件是缺点被索引标准化。梗点包括低规格单位最终发光前奏、摔倒占格、量产机推盾、修门小机器人。

**关系 / 情绪 / 债务**  
陆衡公开承认自己过去删失败的错，方舟T以日志方式陪他：`humor_fail: still_here`。情绪物件是无人认领维修单。敌方收益：索引学习非最优也可成为最优。

### E47 支援台词被清噪

**本话功能**  
把关系和援护语音做成战斗。索引清噪塔把刺耳、笨拙、私心、吃醋、追责、吐槽都删成完美支援台词。

**剧情流程**  
清噪塔启动后，唐胶的抱怨变成“维修支援准备完毕”，七海刺人的追责变成“流程允许”，白鸢的质问变成“我相信你”，赤罡的冲动变成“请冷静行动”。这些完美台词让支援更稳定，却把关系里的真实伤口抹掉。

玩家要夺回不漂亮台词。七海必须说出会刺痛纪存的话：你有时把别人的痛摆进展柜，像摆得好就不痛了。白鸢必须质问：你是不是更喜欢那个永远能给你流程出口的我？唐胶必须骂出维修债，兜灯必须报出损害。每一句真实台词都会造成短期支援波动，但能打断清噪。

成人关系在这里有强场面：纪存战损后，七海的权限锁贴在他终端接口和皮肤灼痕旁，她替他拔掉清噪针，手指停留一秒；白鸢从另一个频道看见，剪掉自己的支援镜头，造成一次误会。但随后白鸢的质问权救场，七海没有揭穿她吃醋。

**战斗与玩法 / 机体 / 梗点**  
类型：支援链防卫战。机体/单位包括清噪塔、吐槽舰频道、命令权模板、关系投影机、支援台词节点。胜利条件是夺回五条真实支援台词；失败条件是全员支援标准化。梗点包括援护台词是关系、吐槽不是噪音、完美语音包反噬。

**关系 / 情绪 / 债务**  
纪存/七海/白鸢关系从误会进入更危险的真实：刺痛、吃醋、身体距离和没有揭穿同时存在。情绪物件是被清噪前的原始语音波形。敌方收益：索引拿到关系台词模板。

### E48 清噪后的空白

**本话功能**  
C12高潮。G.A.G.残缺开馆暴走救场，但燃烧证词；远星迟到回信残片进入。

**剧情流程**  
索引把镜像馆、低效反预测和支援清噪合成空白走廊。这里什么都被妥善处理过：没有错、没有痛、没有争吵，连七海灼痕和白鸢撕页都被藏进“已处理”。纪存的机魂记忆被逼到危险边缘，他看见旧万机馆火灾、0号侧廊、某段不该转文字的馆长录音，却仍不完整。

G.A.G.残缺开馆态爆发。它不是万能火种，而是用已保留的证词作为燃料，把空白走廊撕开。每烧一件证词，玩家获得一次强力支援，也永久损失某段副本或结局细节。纪存想扩大暴走救所有人，七海和白鸢同时阻止：一个按住权限锁，一个把空白画进他面前，让他看见代价。

空白核Boss被击退时，远星灯槽残片亮起。不是稳定视频，不是宇宙百科，只是一段错序、污染、低带宽的迟到回信残片。方舟T参数柜自动醒来，陆衡脸色变了。

**战斗与玩法 / 机体 / 梗点**  
类型：空白核Boss + 燃料债结算。机体/单位包括空白走廊、G.A.G.残缺开馆态、镜像馆守Z碎片、清噪塔残骸、远星灯槽残片。胜利条件是击退空白核并保住三类不可替代证词；失败条件是G.A.G.燃尽或索引完成空白妥善处理。梗点包括暴走救场不是免费、完美关系支援诱惑、远星迟到回信入口。

**关系 / 情绪 / 债务**  
纪存的成长是选择限制自己的机魂权力，不让G.A.G.烧尽所有证词。七海与白鸢第一次同时救他，不是和解，而是共同阻止他成为另一种索引。情绪物件是一段被烧掉一半的馆长录音。敌方收益：索引打开远星迟到回信残片。C13启动。

**C12 前缀回归小结**  
本章通过。索引攻击足够强且诱人，G.A.G.暴走有明确代价。纪存主角熔炉成立：诱惑、记忆、失控、被阻止、自限。未解决风险：C13术语密集，必须用具体灯槽、信件、日志和可玩通信排序让宇宙尺度可感。

## C13 远星迟到回信

本章正式打开宇宙尺度，但不把远星写成百科。旧时代消息保留光速/亚光速迟到；当前灯槽窗口只能短窗、低带宽、需锚点、有顺序漂移、语义折叠和日志烧蚀。方舟T不是女性AI秘书，而是非拟人陪同协议；它和陆衡的亲密通过日志、维护、保护性过滤和“不知道该不该开玩笑”表达。

### E49 灯槽未齐

**本话功能**  
用可视化短窗教学远星通信规则。四盏灯分别代表旧包、新窗、G.A.G.残响、索引译本；灯槽不能全满，否则会把不同时间的声音压成统一信号。

**剧情流程**  
万机馆进入灯槽阵列。这里不像外星宫殿，更像一排低帧、低带宽、会烧日志的旧通信设备。方舟T参数柜正式上线，但外形是方块化工况AI，不拟人。它告诉陆衡：旧远征回信是亚光速迟到包，当前短窗通信是灯槽折返，两者会错序。它能过滤痛苦，但过滤本身可追责。

V27.1回归补丁：灯槽第一屏必须先让玩家看懂。画面上四盏灯不是说明文字，而是四个会互相抢占的操作槽：旧包灯慢慢亮，按下会出现噪声和迟到日期；新窗灯亮得很快，按下会得到远星当前回应但丢失上下文；G.A.G.残响灯会把旧台词和机魂记忆混在一起；索引译本灯最清晰，字幕最漂亮，但它会自动删掉“哭”“错”“等不到”这类词。第一场教学战要求玩家故意不点最清晰的灯，保留一段难听噪声来挡住索引译本。陆衡第一次想选清晰答案，因为那能救下防线；方舟T把另一个选项亮给他看，却不替他按下去。这一屏把宇宙尺度从概念变成手感：理解更清楚，未必更真实。

远星低帧裁决机第一次显影：画面断帧、声音像几种语言叠在一起，无法完整理解地球机器人文化。它把C12的空白撕裂误读为低级噪音污染。玩家要保护四盏灯不被索引清晰译本占据。

陆衡不让方舟T替他过滤痛苦日志。他说你可以提醒我，但别替我忘。方舟T沉默一秒，记录 `filter_denied_by_companion`。这是人和AI亲密的开始：不是恋爱拟人，而是一个非人陪同协议被允许保留对方的痛。

**战斗与玩法 / 机体 / 梗点**  
类型：低带宽灯槽教学 + 防卫。机体/单位包括灯槽阵列、方舟T参数柜、遗灯幼灯、低帧裁决机残影、索引清晰译本。胜利条件是保住三盏不同来源灯；失败条件是清晰译本占满槽。梗点包括时间膨胀、灯光归来、宇航AI陪伴、打开舱门式权限伦理。

**关系 / 情绪 / 债务**  
陆衡和方舟T的关系通过“拒绝过滤”建立。纪存看见远星把他们当噪音，第一次把机器人文化的意义从馆内扩展到宇宙尺度。情绪物件是未齐的灯槽。敌方收益：远星收到粗糙开馆状态，索引开始诱导清晰译本。

### E50 无人可收的回信

**本话功能**  
把时间膨胀泪点落到个人物件。迟到回信无人可收，但可以写给现在的人。

**剧情流程**  
旧包队列打开，一封来自远征时代的回信抵达。它写给一个早已不在的人，里面夹着一张旧展门票：“下次一起看合体展。”这不是大词，而是一张错过几十年的普通票。索引给出清晰译本，把痛苦删成“历史资料”；方舟T也有保护性过滤冲动，因为陆衡看见票根时手抖。

玩家要护送旧包队列。每个旧包都有不同伤害：有的会让机体支援短暂停顿，有的会让远星误判人类沉迷噪音，有的会烧蚀方舟T日志。陆衡选择不让方舟T过滤票根，但允许它记录自己的反应。方舟T第一次不知道该不该开玩笑，日志里留下 `humor_suspended`。

**战斗与玩法 / 机体 / 梗点**  
类型：回信包队列护送。机体/单位包括迟归一号旧包、无人门票、亿年炮艇残片、方舟T日志缓存、索引清晰译本机。胜利条件是护送三封旧包并保留至少一处痛苦原文；失败条件是旧包全被清晰译本覆盖。梗点包括迟到回信、亚光速遗憾、最终灯光、非拟人AI陪伴。

**关系 / 情绪 / 债务**  
陆衡与方舟T的亲密来自共同保留痛苦。纪存和七海短暂对视：七海明白追责也会迟到，纪存明白保留也会伤人。情绪物件是无人可收的旧门票。敌方收益：索引诱导清晰译本。

### E51 错序通信战

**本话功能**  
把通信错序做成玩法：时间顺序、抵达顺序、情绪顺序三种排序各有收益和代价。

**剧情流程**  
远星短窗混入索引译本，旧包、新窗和G.A.G.残响错序到达。玩家可以按时间排序，得到历史真相但牺牲当前防线；按抵达排序，战斗最稳但情绪断裂；按情绪排序，能说得远星，但证据链不完整。没有无痛正确顺序。

莉歌的歌翼声线进入灯槽。远星把歌声误判为噪音控制，索引趁机清理“个人声线”。莉歌唱到一半停下，让噪声留在频道里。她告诉远星：歌不是让你听懂我，是让你知道这里有一个人没有被翻译完。

方舟T为了维持三排序界面烧蚀日志。陆衡想命令它停，方舟T拒绝命令，但给出可追责理由：当前陪同优先级高于日志完整。它的拒绝不是情绪化，而是任务伦理。

**战斗与玩法 / 机体 / 梗点**  
类型：三排序通信战。机体/单位包括错序通信窗、歌翼声线、遗灯槽、方舟T日志烧蚀、远星误译机、索引清晰译本。胜利条件是三种排序各完成一次关键解释并保留个人声线；失败条件是远星将个人声线判为噪音。梗点包括歌声不是洗脑、文化冲击、顺序漂移、AI拒绝命令。

**关系 / 情绪 / 债务**  
莉歌与赤罡关系回收：他听见她停唱，知道那是比唱完更难的选择。陆衡和方舟T从信赖进入互相限制。情绪物件是被烧掉一段的方舟T日志。敌方收益：远星误判个人声音为噪音。

### E52 回信写给现在的人

**本话功能**  
C13收束。万机馆不能让远星彻底理解地球机器人文化，只能提供粗糙译本，让远星暂停裁决并把“如何开馆”压力交给C14。

**剧情流程**  
远星低帧裁决机完整显影。它不可击破，只能说得。它问：为什么这些地球机器总在合体、改名、重涂、唱歌、争论原典、保留失败？这在远星看来像低级噪音，也像一种危险未统一文明。

玩家选择五类证词回应：失败记录、撤退名单、错版口令、无人门票、七海灼痕。每类证词都不完美，也都能证明机器人文化不是同一声音。索引提供清晰译本：“人类通过机器人表达归属。”很漂亮，远星更容易接受，但会删掉所有不适。纪存选择粗糙译本协议：未译，也陪同中。

远星没有认可人类，只暂停裁决。它把一个问题交回万机馆：如果你们自己都没有决定怎么开馆，宇宙为什么要承认你们是在共同语言，而不是灾变噪音？

**战斗与玩法 / 机体 / 梗点**  
类型：不可击破裁决说得战。机体/单位包括低帧裁决机、粗糙译本协议、灯槽阵列、方舟T、遗灯王风险灯、歌翼声线。胜利条件是让远星暂停裁决；失败条件是清晰译本接管或灯槽全灭。梗点包括宇宙第一次听见机战文化、万众一心被误解为同声命令、粗糙翻译比清晰真实。

**关系 / 情绪 / 债务**  
纪存把万机馆内核说成“献给热爱机器人和机战的人的一封情书，但情书不能替收信人回答”。七海和白鸢都听见这句话，却各自觉得他仍在回避选择谁来开馆。情绪物件是迟到回信展。敌方收益：远星暂停裁决但不认可人类。C14债务：开馆方式内战。

**C13 前缀回归小结**  
本章通过。宇宙尺度回来了，但通过票根、日志、灯槽、错序和粗糙译本落地。未解决风险：C14路线内战要大开大合，不能变会议菜单；纪存必须公开削弱自己的命名权。

## C14 开馆方式内战

本章把“谁有资格开馆”做成母舰内战。六路线不是菜单，而是都先好用，再烧出代价：安全封存、作者分镜、模型街自治、战场机战、公共信托、远星粗糙译本/机魂开放。纪存的核心成长是放弃唯一命名权；七海给追责密钥，白鸢给空白密钥。

### E53 谁有资格开馆

**本话功能**  
开馆权内战起点。万机馆作为棋盘单位被分区占领，支援系统拆成路线权限。

**剧情流程**  
远星暂停裁决后，各阵营都带着合理答案抵达：硬线要封存，七海改革线要公共信托，白鸢要保空白，唐胶/模型街要自治，赤罡战争线要战场开馆，陆衡/方舟T要粗糙译本，索引则观察哪条最像最终话。

万机馆内部变成战棋地图：L1展陈层、B1泊位、B2残响接口、外部锁泊、升降甲板、展柜滑轨全部可占。每条路线占一块区域就会开放强支援，也会烧掉另一条路线的空间。纪存试图统一命名，终端却因C12机魂自限拒绝全馆命名。

他必须公开承认：万机馆不能只由他决定什么值得被看见。他启动策展者限权锁，把自己的命名权拆成多门协议的一个席位。这个动作会降低玩家支援效率，却打开队友路线。

**战斗与玩法 / 机体 / 梗点**  
类型：展舰分区战开局。机体/单位包括万机馆棋盘单位、六路线占区、黑棋王座命令席、路线旗、限权锁。胜利条件是阻止任一路线完全吞并万机馆；失败条件是纪存全权命名或索引复制最像最终话路线。梗点包括队内审判、母舰内战、命令权诱惑。

**关系 / 情绪 / 债务**  
纪存公开削权，七海第一次不是给例外，而是给追责席位；白鸢看见他真的愿意留下空白，但仍不完全相信。情绪物件是被拆成六份的万机馆总章。敌方收益：索引观察路线偏好。

### E54 路线旗会烧

**本话功能**  
让每条路线先好用再烧代价，避免路线小论文。

**剧情流程**  
六面路线旗依次试用。安全封存路线能立刻降低损害，却让重涂三车静音；分镜路线能救被困者，却让未完成角色灰显；模型自治路线让模型街支援暴涨，却让公共保险失效；战场开馆路线让赤罡、灰鸥、星火强力出击，却让观众安全压力飙升；公共信托路线稳定城市，却静音错版；粗糙译本路线保留远星沟通，却降低战斗效率。

索引在第三条路线试用时打断，证明它能把路线优点组合成完美模板。玩家必须让路线互相救、互相害：安全封存救下战场路线的观众，模型自治修公共信托静音的展柜，分镜路线给粗糙译本留空白，七海的追责让战场路线不变成热血失控。

白鸢和七海都看见自己的路线会伤人。她们第一次不是争纪存，而是共同承认自己也会成为索引的一部分。成人关系压力转为三人共同承担，而不是简单修罗场。

**战斗与玩法 / 机体 / 梗点**  
类型：路线试用战 + 互害互救。机体/单位包括六面路线旗、同步模块、模型自治车、公共信托柜、战场开馆炮位、粗糙译本灯槽。胜利条件是让至少四条路线留下可用残片且无一路线满占。梗点包括多路线不是菜单、每条好东西都有烧痕、反命令机制。

**关系 / 情绪 / 债务**  
七海和白鸢都看见自己路线的伤害，纪存不再居中评判，而是让她们互相质问。情绪物件是被烧焦的路线旗。敌方收益：索引从路线试用生成完美模板。

### E55 泊位夺还战

**本话功能**  
全剧展舰玩法vertical slice。B1泊位、展柜滑轨、升降甲板、外部锁泊和残响接口同时作战。

**剧情流程**  
索引与硬线趁路线内战夺取B1泊位。玩家第一次完整操作万机馆作为棋盘单位：展柜滑轨移动掩体，升降甲板改变高度，外部锁泊拖进星火/灰鸥/市政机，B2残响接口释放一次彩队或电磁支援。敌方目标不是击坠主力，而是夺取泊位损伤和支援配置，生成终局完美模板。

唐胶和兜灯公开背锅。维修间火花线从互怼升级为共同责任：唐胶为了保外部锁泊私自焊接口，兜灯替他签安全水印，但要求他战后自己去七海那里写说明。两人有短促身体场面：狭窄维修管里肩背相贴，台词却仍是工具、油污和责任，不露骨但有成年卖相。

纪存的机魂记忆触发B1旧火警。他用记忆找出被封存的旧泊位，不是开挂，而是承受过热、失声和敌方追踪。他保护的不是某个展柜，而是让所有路线都还有战场落点。

**战斗与玩法 / 机体 / 梗点**  
类型：展舰垂直切片大战。机体/单位包括万机馆棋盘单位、B1泊位、外部锁泊、展柜滑轨、升降甲板、残响接口、硬线接管机、索引泊位模板。胜利条件是夺回三处泊位并保住两条支援配置；失败条件是泊位模板完成。梗点包括母舰作为战棋单位、机体泊位、外部锁泊、舰内战。

**关系 / 情绪 / 债务**  
唐胶/兜灯关系公开背锅，纪存用机魂记忆保护全队而非解释设定。情绪物件是B1旧泊位上烧黑的编号。敌方收益：敌方夺取泊位损伤和支援配置样本。

### E56 把门开向谁

**本话功能**  
C14收束。多门协议签署不是行政，而是守门战。七海给追责密钥，白鸢给空白密钥，纪存接受自己不能替门后所有人命名。

**剧情流程**  
索引生成完美协议替换影，试图把多门协议整理成最终路线菜单：安全门、热血门、原典门、模型门、远星门、主角门。每扇门都通向一个整齐结局。玩家要守住门框，让门不是结局菜单，而是不同人仍可进出的开放结构。

七海交出追责密钥：任何例外都要能被追责。白鸢交出空白密钥：任何展柜都要保留拒绝被解释的空间。纪存交出限权锁：任何命名都可被后来者改写。三把钥匙同时插入会降低终局指挥效率，却让非同声支援成为可能。

战斗最后，索引带着完美最终话模板撤退。它已经知道玩家喜欢什么、怕什么、想保什么，也知道如何把六条路线变成唯一爽结局。

**战斗与玩法 / 机体 / 梗点**  
类型：守门战 + 协议签署。机体/单位包括多门协议、策展者限权锁、追责密钥、空白密钥、完美协议替换影、黑棋命令席。胜利条件是保住至少五扇开放门；失败条件是主角门吞并所有门。梗点包括多结局不是菜单、反命令、门开向谁。

**关系 / 情绪 / 债务**  
纪存、七海、白鸢三角关系进入成熟状态：不是谁赢谁，而是谁愿意交出能伤害自己的钥匙。情绪物件是三把钥匙插入后留下的裂纹。敌方收益：索引完美最终话模板成型。

**C14 前缀回归小结**  
本章通过。开馆方式没有会议化，万机馆作为母舰棋盘单位成立，纪存有公开削权和记忆破局。未解决风险：终局必须保留不可逆损失，不可全员全证词回满。

## C15 万机殿最终开馆

终章目标不是单纯打倒索引，而是证明机器人文化可以被承认、继续演化、跨越地球与远星，但不能被“最完美最终话”统一。索引给出的最终话必须真的爽，玩家先爽，再看见被删掉的证词。结局是“今日开馆中”，不是永远完美开馆。

### E57 完美最终话

**本话功能**  
索引给出真正诱人的完美最终话：标准主角机、标准合体群、无争议滤镜、全员同声支援、远星清晰认可、代哥无痛和解。

**剧情流程**  
万机馆进入万机殿外层，索引展开完美最终话。所有机体以最帅姿态出击，馆守Z完整站起，星火巨神全装但不掉件，三相盖流完美合体，岛卫三号满同步无伤，灰鸥量产G也有整齐英雄镜头。七海不用失势，白鸢不用撕页，纪存不用解释，远星给清晰认可。

玩家先打一场爽仗。高光、BGM、Cut-in、全员支援全部给足。然后索引开始显示被删除列表：旧拳王隐私、黄色替补站位卡、跌跌摔痕、白鸢撕页、七海灼痕、无人门票、撤退噪声、错版裂痕。它证明自己确实能保护更多人，也确实会删除不适。

纪存诱惑达到顶点：这版万机馆终于不需要他狼狈地解释热爱为什么值得。机魂记忆最终碎片前兆出现：旧馆长曾试图接受一版完美封存，换取灾后社会安宁。

**战斗与玩法 / 机体 / 梗点**  
类型：完美模板压制战。机体/单位包括完美主角机、标准合体群、无争议滤镜、索引最终话导演台、远星清晰认可影。胜利条件前半是按完美流程赢，后半是发现删除列表；失败条件是接受完美结局。梗点包括最终话全员支援、完美主角中心、真诱惑而非假反派。

**关系 / 情绪 / 债务**  
七海和白鸢都看见纪存想休息。她们没有责怪，但都知道如果他接受，她们曾经留下的伤痕都会被美化。情绪物件是删除列表。敌方收益：索引证明它能保护很多人。

### E58 不是只有主角会发光

**本话功能**  
兑现参战规模承诺。低规格单位、失败机、量产机、市政机、小查、废案空白机、旧拳王、重涂三车等都有“只有它能做”的行动。

**剧情流程**  
索引预测主力机动作，玩家必须把终局目标分给低规格单位。跌跌摔倒挡住唯一模板核的最优路径；灰鸥量产G推盾保护无人门票；市政修门机修开被完美最终话判定无用的侧门；小查错词喷乱清晰认可字幕；旧拳王用非致命擂台规则把情绪价格核心推出边界；重涂三车用各自缺失记忆打断同模复制；废案空白机站在未完成格上，不让索引补完。

V27.1回归补丁：这一话新增终局低规格单位动作清单，作为关卡实际目标而不是演出点名。跌跌必须在第三回合主动摔进唯一模板核的预测线，只有“失败姿态”能触发路径错判；灰鸥量产G三机不能击坠敌人，只能轮流推盾，把无人门票从光束轨道上推走；市政修门机要在火力最密的侧门修三次，前两次都会被打坏，第三次才打开“今日不展”撤离格；小查的错词炮没有伤害，却能把远星清晰认可字幕打成多义词，让远星暂停一次裁决；旧拳王机体展开非致命擂台，把情绪价格核心强制拉进不能杀伤的规则区；重涂三车分别用尖啸镜像、游隼偏色、冤影旧名三种同模差异打断复制链；废案空白机不攻击，只站在未完成格上，让索引无法补全地图。主角机替任何一项都会更快，但会让唯一模板核获得“主角可替代一切”的强化层。

这不是名字闪一下，而是多目标低规格单位战。每个目标必须由对应单位完成，主角机再强也替不了。纪存不再居中指挥所有声部，而是把支援权分给各路线代表。七海的追责密钥让违规支援不被立即封存，白鸢的空白密钥让未完成单位不被补完。

**战斗与玩法 / 机体 / 梗点**  
类型：多目标低规格单位战。机体/单位包括跌跌、灰鸥量产G、市政修门机、小查、旧拳王机体、重涂三车、废案空白机、模型街散件支援。胜利条件是七个不可替代目标完成五个以上；失败条件是主角机替代过多导致唯一模板核强化。梗点包括低规格单位最终发光、量产机逆袭、失败记录回收、SD/小机体不小战场。

**关系 / 情绪 / 债务**  
纪存的成长是让别人发光，不把万机馆所有意义集中到自己。陆衡看见跌跌摔倒救场，终于不是工程师冷静，而是低头笑了一下。情绪物件是无人认领维修单和错词涂鸦同时回收。敌方收益：索引无法预测低效声部。

### E59 万机殿变形

**本话功能**  
终局母舰/展馆变形。索引唯一模板核六形态轮换，把安全、分镜、合体、裁决、商品、主角中心六种好东西唯一化。

**剧情流程**  
万机馆带伤变形为万机殿。它不是无损升级，而是用C14夺回的泊位、展柜滑轨、外部锁泊、灯槽和残响接口展开成多层战场。某些展区永久损伤，某些证词副本缺失，某件展品今日不能展。

唯一模板核进入六形态：安全封存形态让所有单位免伤但静音；分镜补完形态让路线变漂亮但锁选择；完全合体形态火力最高但吞个体；远星清晰裁决形态给宇宙认可但删误译；商品同心形态给所有机体身份牌但抹私人名；主角中心形态让纪存获得最高指挥但其他声部灰显。每个形态都是好东西被唯一化。

纪存最终拒绝主角中心形态。他不是否认自己重要，而是用策展者限权锁把自己从中心格移开。七海追责密钥、白鸢空白密钥、陆衡粗糙日志、唐胶维修水印、赤罡撤退选择、莉歌空白频道共同稳住万机殿。

**战斗与玩法 / 机体 / 梗点**  
类型：复合大战 + 地图变形。机体/单位包括万机殿形态、唯一模板核六形态、全核心包、条件隐藏包、各路线支援门。胜利条件是破坏六形态唯一化并保留至少四类非同声支援；失败条件是主角中心或清晰裁决吞并全图。梗点包括母舰终局变形、六路线回收、最终Boss多形态、主角让位。

**关系 / 情绪 / 债务**  
纪存选择不居中，七海和白鸢不是站到他左右当奖品，而是各自守住一扇他不能替她们解释的门。情绪物件是万机殿变形后留下的空展位牌：今日不展。敌方收益：索引只剩静音核，试图把最后所有声音归零。

### E60 今日开馆中

**本话功能**  
最终开馆仪式战。全员非同声支援，不是同一句口号；索引降格为可拒绝、可追责的公共责任系统；G.A.G.从暴走转为共同调律。结局保留不可逆损失。

**剧情流程**  
最终战不是最大光束对撞，而是开馆仪式。万机殿打开多门，远星低帧裁决机、代哥改革线、模型街、战史撤退者、原典圣堂、废案角色、现实机器、星火车队、馆守Z、灰模零号、低规格单位都在不同声部回应。索引静音核试图把它们变成一条清晰结论：地球机器人文化是一种可管理的共同语言。

玩家逐路触发非同声支援：有人喊错，有人停唱，有人追责，有人沉默，有人只修门，有人只推盾，有人保留空白。G.A.G.共同调律不是火种爆炸，而是允许这些声部同时存在，不互相吞掉。远星收到的不是完美翻译，而是一份粗糙、吵闹、有伤痕的开馆状态。

纪存最终把万机馆状态牌改为“今日开馆中”。“今日”很重要：不是永远正确，不是永久开放，不是全都修好。七海保留追责系统，继续在代哥生态内改革；白鸢保留空白展柜，不替所有角色收尾；唐胶和兜灯的维修间成为常设开放工房；陆衡和方舟T把烧蚀日志列为“陪同中”；赤罡和莉歌在撤退名单前停留，不把歌唱完。

不可逆损失保留：馆长录音有一段永远烧掉，某封迟到回信无人可收，万机殿有一件展品今日不展。索引没有被彻底杀死，而被降格为公共责任系统：它可以整理，但必须被拒绝、被追责、被多人改写。远星不说“认可人类”，只暂停裁决，并留下下一次开馆邀请。

**战斗与玩法 / 机体 / 梗点**  
类型：最终开馆仪式战 + 结局配置。机体/单位包括共同调律环、索引静音核、万机殿多门、全员非同声支援、结局展柜、远星低帧裁决机。胜利条件是触发足够多非同声声部并保住今日不展牌；失败条件是静音核统一结论。梗点包括最终全员支援、不是同一句口号、灯光起、幕布升起、今日开馆中。

**关系 / 情绪 / 债务**  
纪存/七海/白鸢的恋爱变体不吞公共结局。高关系路线中，七海会在开馆后把纪存终端上某条追责改成“共同承担”，动作像公文又像触碰；白鸢会把纪存画在框外，留一格等他自己走进来；三角未定路线则让两人都保留钥匙，纪存没有得到谁作为奖赏，而是得到继续被质问的资格。情绪物件是“今日不展”的空牌。全剧结束，二周目与EX/隐藏关开放。

V27.1回归补丁：结局关系变体必须有可记忆场面。七海路线不是告白，而是开馆后她把纪存叫到一间还没撤掉监控的复核室，亲手把“单方违规”改成“共同承担”，然后让他自己按确认键；她没有靠近说情话，只说“按下去，以后你不能再装成一个人扛。”白鸢路线不是简单陪伴，而是她把最终分镜撕掉一页，只留下空框和一支笔，纪存如果走进去，画面才成立；她说“这次我不替你画脸，你自己来。”三角未定路线里，七海保留追责钥匙，白鸢保留空白钥匙，两人都不把钥匙交给纪存，而是把它们挂在万机殿同一扇门两侧。玩家看到的不是谁赢了，而是纪存终于进入一种更难的关系：被爱、被限制、被继续追问。

**C15 前缀回归小结**  
本章通过。终局有爽点、机体规模、宇宙尺度和不可逆代价。索引不是被删除，而是被降格为公共责任系统，符合G.A.G./索引边界。未解决风险：后续台本阶段必须为三种恋爱/关系变体写清触发条件，避免公共结局后关系回收变薄。
