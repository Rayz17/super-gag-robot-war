# 《超GAG机器人大战》V35.3 关键剧情决策、机战规模与多文化命名

> 状态：`needs_review_v35_3`。
>
> 本稿承接 [V35.2融合完整大纲底座](./V35全剧融合完整大纲底座-v35.2.md)，回应八项待定问题的用户反馈。前七项进入推荐决策候选；第八项不再压缩参战机体，而把“可操作机体数量”和“完全独立制作管线数量”分开管理。

## 一、推荐决策

### D1 保留十八章与82个作者话槽

现阶段不扩章，也不压回十五章。保持十八章、82个作者话槽和约67话单周目；C04、C05、C10、C12、C13和C16保留互斥经历或任务组合。下一步按章拆话后，只在出现连续两话功能相同或单一话明显超载时局部迁移。

### D2 C09固定牺牲者为班主任潮

班主任潮在C04先允许学生拒绝出击，并亲自承担防线失败；C09白鸢的幸福构图转移代价时，他主动站进成年责任空位。城市重置后，毕业照和办公室留下无法解释的位置，学生仍遵守他教过的拒绝协议，却不记得是谁教的。

他不在主线无损复活。隐藏条件最多保存低带宽残响、恢复世界对他的记忆或让一段教学动作成为支援，不能把身体、记忆和关系全部还原。C17完美假馆让他以“完美教师”身份回来并命令雾生出击，反而成为假馆最刺眼的破绽。

### D3 C14纪存失去馆长给他名字的私人记忆

纪存保留馆长参与旧清噪、签署托管、牺牲机魂和接入路由的事实，却失去馆长第一次叫醒他、给他名字、教他“保存不是占有”的生活记忆。他不再知道馆长是否爱过自己，也不知道自己为何愿意保留“纪存”这个名字。

C16审判馆长时，他只能依据证据；C18由他自己重新选择名字。失忆改变身份、关系和终局自我认领，不是抽象记忆槽。

### D4 七海合法托管/流亡改革两条身份持续到C16

合法托管七海保留医院、城市入口、供应链和公开司法，代价是亲手扣押纪存/白鸢并被同伴视为接管者。流亡改革七海保护机魂主体和粗糙译本，行动更快，却失去合法靠港、公共医疗和稳定补给。

C13合法线护送官方远星信标，流亡线保护被判非法的灯槽；C14合法线查报告造假并可能追捕纪存，流亡线袭击报告工厂但损毁证据；C15两线从不同政治位置参与远星裁决；C16只能停火汇流，不能恢复成同一种七海。C18分别导向有限托管或公共信托/流浪方舟方案。

### D5 白鸢失去直接执行改写的能力

C09代价分三层：执行分镜接口烧伤优势手与部分视觉神经；核心母版被认定为灾害源、署名和创作许可冻结；救下雾生却让班主任潮和一块战略防区进入代价空位。

C14三态明确为：当面归来时毁掉母版、以协作型分镜师重新入队；无署名救援时通过其他创作者提供结构，不恢复公开身份；拒绝回头时领导创作者避难区，与纪存作战，保护不愿被任何阵营补完的未完人。三态都不是恋爱好坏结局。

### D6 新关键人物改用多文化命名

已经成立的纪存、七海、唐胶、兜灯、槐、豪司、陆衡等保留本地或东亚文化根系。新增全球企业、远征、外星与国际驾驶员不再统一使用中文式姓名。

- 白鸢是创作笔名；正式姓名候选为**艾芙琳·沃斯（Aveline Voss）**。
- 代哥安全封存派导师由“裴岸暂名”迁为**阿德里安·维斯（Adrian Weiss）**。
- 商品生态派由“罗绮暂名”迁为**罗莎琳·维加（Rosaline Vega）**。
- 数字价值派由“闻序暂名”迁为**伊莱亚斯·诺德（Elias Nord）**。
- 逆时清算者零号正式人物名候选为**卡西安·雷姆（Cassian Rem）**。
- 远星听译者本名为**莱弗拉（Refr'a）**，地球译称“折光”。
- 电磁缺席成员使用国际资料名**米欧·一文字（Mio Ichimonji）**，东亚资料可写“一文字澪”。

命名按角色文化、家庭、移民和阵营形成分布，不执行僵硬比例。白舰/远征/舞台/代哥总部可以明显多语，万机馆本地和模型街保留本地姓名，远星采用构造语音译加地球释义。

### D7 馆长以低带宽残响和旧馆务机身体回归

馆长肉身已死，不作为全知AI复活。他留下带区域签名、记忆残缺的低带宽残响：C11只能发窄带认证，C12只能解开一层托管，C14以后借老旧目录搬运机获得临时身体，C16正式接受审判。

他的旧罪是：第一次行星同步时，他封闭了一整个机魂避难区，允许索引静音、合并大量刚诞生的机魂，以阻止灾害扩散。他救下城市和纪存，却隐藏了那些机魂的名字，并把纪存接成档案路由锁。C16他必须公开名单、交出区域签名；结局可留下受审、失去特权做普通馆务残响或在完成交接后消散。

## 二、第八项修正：扩充到真正机战规模

“26套A级”改为**26台旗舰级制作资产**，不再代表全剧只有26台正式参战机体。

V35.3目标：

| 层级 | 数量 | 说明 |
| --- | ---: | --- |
| 可操作收藏总量 | 72 | 包含主线、路线、隐藏和完整分机状态 |
| 单周目可操作经历 | 约48至56 | 至少临时控制或正式部署一次 |
| 旗舰级独立制作 | 26 | 独立高规格模型、Cut-in、复数招牌演出 |
| 标准可操作制作 | 32 | 独立轮廓/武器/招牌技，共享同谱系技术控制器 |
| 有限动作/组合制作 | 14 | 分机组、小型机、临时机、场景支援 |
| 具名敌机/Boss目标 | 35至45 | 不计普通量产杂兵 |
| 具名支援/NPC机目标 | 20至30 | 有故事动作但未必自由部署 |
| 全剧可辨认机体目标 | 110至140 | 包含敌方、支援和临时机，不含背景剪影 |

共享的是程序控制器、骨架规范、通用移动和受击动作，不是把不同谱系做成换色机。每台可操作机必须拥有独立轮廓、驾驶员/机魂、战术位置、至少一项招牌攻击或支援演出，以及一次真正改变剧情的机体动作。

## 三、八个新增来客包

仅靠现有十二核心与既有来客包扩充分机，会增加数量却不增加作品气质。V35.3因此新增八个`guest_arc`候选包，嵌入现有章节，不独占主题章：

1. **铁棺佣兵**：C07-C10，补量产生存、换乘、巷战与撤退。
2. **吐槽战舰**：C11-C12/C17，补懂动画的人面对真实战争、剧中剧和原声支援。
3. **网格修复者**：C09/C12/C17，补城市重置、辅助机合体和记忆空位。
4. **环洋双驾**：C04/C09/C15，补双人驾驶、共享创伤和城市巨物责任。
5. **未来追猎**：C07埋种、C14主场、C17回收，补终结者/矩阵式当代制造追杀。
6. **钻破天盖**：C06/C15/C18，补外放突破、导师传承与尺度升级，但服从低规格机器主目标。
7. **拼装战场**：C02/C05/C11，补Build系玩家机、改件竞技和模型实机接口。
8. **地行发动机队**：C13/C15/C18，补行星工程、带着家园远行和普通维护者尺度。

八包只增加14台收藏可操作条目，其余通过临时支援、敌方、场景单位和后续EX存在，避免主线再变成八个排队出现的主题副本。

## 四、制作策略不是缩水策略

生产层按技术家族复用：旧超级系、三机合体、真实系人形、生体同步、可变空战、勇者工具、载具变形、战队/兽机组合、城市工务、现实小机、宇宙舰与巨构。共享控制器不共享角色轮廓和招牌动作。

四个制作闸门：

1. C01-C03完成馆守Z、勇者、拳王、变形生命、工务/现实机器和WBM001。
2. C04-C06完成同步机、三相、星火、彩队/兽机、星翼和三尺度巨物。
3. C07-C12完成白/红宿敌、量产队、黑王座、遗灯、铁友、来客包与夺舰形态。
4. C13-C18完成迟归舰、远星裁决、未来猎杀、行星工程和万机殿。

镜像机使用公共装甲、着色、VFX与规则变化，不制作完整第二套底盘。分机可以在玩法上独立操作，但通过组合资产、共享骨架和有限动作控制成本。
