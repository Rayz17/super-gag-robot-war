# V24 全剧逐话剧情梗概：ELO运行稿 v24.0

状态：候选全剧逐话梗概，不是最终对白台本。  
范围：15篇 / 60话。  
生成方式：按“逐话循环编剧调度器（ELO）”运行：上一话 Clear State -> 下一话推进判断 -> canon/素材/50问题资料包 -> 单话梗概 -> 门禁审稿 -> 状态账本。

本稿继承 V23 的15篇60话结构、V22.10 的 A5 厚流程、V15 的爆破升级、V16 的高能读感、V19.2 的代哥生态与七海改革线、V22 的“会开馆的方舟”根设定和机器人文化素材库 v0.2。它的目标不是“把旧大纲扩成60格”，而是让每话都有明确的剧情推进、可玩形式、机体/机器人文化承载、关系后果、敌方收益和下一话债务。

## 全局口径

- “开馆”不是结局才发生的展览，而是万机馆流亡过程中不断把机器人文化、机魂证词、模型/玩具锚件、实机残骸、迟到回信和玩家选择公开给不同对象的行动。
- “证词”是万机馆对机器人展品/机魂/文化物件的定义方式：它不是口供，而是“这件东西为什么有资格被看见、被保护、被争论、被追责”的证据链。
- G.A.G.不是万能灵魂粒子。它是机器人文化活化与误读的灾变核心：能让玩梗、记忆、模型、展签、台词和机体接口产生真实后果，但每次奇迹都要形成开馆债。
- 索引不是普通病毒。它的恐怖来自更安全、更漂亮、更高效、更无痛：它会把活关系优化成模板，把文化压成商品目录，把不同声部清噪成一个正确答案。
- 参战规模由主线承担，EX/隐藏关只做厚度、变体和追加声部，不补主线短板。
- 成人关系线只发生在成年/成年感角色之间，用危险亲密、权限、误会、挑逗、身体距离和共犯感表现；儿童线完全隔离。

## C01 闭馆夺名与展舰起航

### E01 今日闭馆后

**剧情流程**  
火灾后30秒冷开场：留言墙被水泡皱，馆守Z半跪的巨掌压着倒塌展柜，旧守护者导览机还在播闭馆提示，0号侧廊传来一次轻敲。随后切回三小时前，纪存用档案终端接管闭馆路线，玩家第一次看到万机馆不是小展厅，而是L1主展层、L2胸牌维修天桥、L3档案层、B1机库脊柱、B2残响接口组成的多层旧会展馆。

闭馆路线经过馆守Z中庭、合体剖面台、勇气审批角、模型病院、现实机器小舞台、旧影像厅和废案柜远景。玩家不必全逛，但每个展岛都露出一种机器人文化。纪存的主角感来自把小满、阿澄、展品、路线和异常压进一张可行动地图，而不是讲解设定。

**战斗与玩法**  
探索 + 闭馆巡检教程。玩家选择主路线和若干展岛调查；看过的展项进入 `exhibit_seen_set`，后续会被七海封存清单逐项点名。

**机体出场**  
馆守Z半跪实机、旧守护者导览机、社勇王送修模型、跌跌小舞台。旧守护者导览机可标出路线、滞留人员和异常点。

**梗点 / 爽点**  
巨型机器人首次亮相不靠启动，而靠玩家站在半跪巨神脚边感到尺度。勇者审批角把热血许可改成馆内流程梗。

**情绪与关系**  
留言墙旧纸条、社勇王取件盒、馆守Z右臂旧件。纪存照看孩子但不让他们进危险内廊；唐胶在模型病院先骂后修，兜灯用安全锁表达关心。

**敌方收益 / Clear State**  
敌方还未登场，但玩家看过的展项成为E02封存清单素材。0号侧廊异常、右臂旧件、留言墙和社勇王盒进入清算可利用状态。

### E02 法务清单把热爱改名

**剧情流程**  
纪存独自到0号侧廊门口，终端只显示“明日权限”，玻璃内轻敲一次。他把异常登记为闭馆风险，不带孩子靠近。闭馆灯熄到一半，七海远程接入，万机馆被自动生成风险清单：留言墙变成未登记观众附着物，社勇王盒变成暂停交付物，右臂旧件变成危险机体残片，0号侧廊变成未授权响应源。

封存无人机进入主展层，不先攻击人，而是贴标签、封路、采样。采样贴片直奔旧纸条，路径框体切开孩子撤离路线，0号开启臂向侧廊门移动。玩家第一次发现敌人不是怪物，而是流程本身。

**战斗与玩法**  
6回合保护战。目标：保护留言墙、撤离孩子、截击0号开启臂、阻止采样贴片删除旧纸条。烟雾和卷帘门逐回合缩小区域。

**机体出场**  
封存无人机、采样贴片、0号开启臂、路径封存框体。0号开启臂若抵达侧廊，会提高黑展柜共鸣。

**梗点 / 爽点**  
公开处刑/命名权被夺变成清算清单：系统把玩家刚喜欢上的东西精准改名。

**情绪与关系**  
未归档旧纸条、社勇王盒、留言墙耐久。七海建立压迫感：她说得都对，但说法会伤人。纪存不能说服她，只能在战场上证明这些东西不是垃圾数据。

**敌方收益 / Clear State**  
代哥获得未归档清单、0号异常响应、馆守Z右臂脉冲记录。旧守护者导览机过载，馆守Z胸牌亮起。

### E03 展厅里的旧守护者

**剧情流程**  
导览机停在主展厅中央，旧守护者回到馆守Z本体。它启动后的第一句话仍是展厅安全提示，而不是英雄宣言。馆守Z以半跪姿态移动，胸牌灯照亮烟雾，整层展厅像被一台老机器慢慢托住。

正式战棋展开。馆守Z作为2x2大单位进入棋盘，可挡线、推开封存框体、用胸牌投光保护留言墙，但每次行动增加过热，也可能压坏展岛。第3回合豪司远程越权接入勇气审批角，社勇王真机不出现，只给一次审批章支援，开出被封存路线。七海随即把这次支援和馆守Z活动登记为事故前置。

**战斗与玩法**  
SRPG教程：2x2大型单位、过热、安全锁、护展格、局部援护。胜利条件是击退执行单位并保护至少两个核心展项；失败条件是留言墙清零、馆守Z过热爆表或0号侧廊被开启。

**机体出场**  
馆守Z半启动、豪司/勇气审批支援、过热安全锁模块、胸牌投光模块。

**梗点 / 爽点**  
巨神启动与勇者增援原创化为老馆规矩和审批越权：热血能救场，但必须有人签责任。

**情绪与关系**  
馆守Z胸牌、损坏导览机、留言墙被巨掌遮住的一角。兜灯一次次压安全锁，唐胶在过热边缘帮她接维修件。七海没有阻止救人，但把每一步保存成证据。

**敌方收益 / Clear State**  
七海获得馆守Z活动记录。G.A.G.现象被记录为“纸条发光可触发机体响应”。B1路线亮起。

### E04 流亡展舰

**剧情流程**  
B1机库脊柱第一次开放。这里不是无限仓库，而是旧会展馆地下物流层改造出的移动底盘：重型维修架只能容纳馆守Z半卧维修，中型泊位很多灰显，外部锁泊接口像一排没接上的肋骨。陆衡正式出现，用工程视角指出这东西能动，但不是完美战舰。

火警、封存锁、服务器损伤同时压下。玩家必须在救人、救展品、救服务器三类目标中完整保两类，第三类只能部分保留。撤离经过0号侧廊，里面的敲击像在说“这次不是闭馆”。纪存可以停下看，但不能开门。随后移动底盘启动，破损博物馆拖着自己离开旧会展区。七海通讯声明万机馆已成移动风险源；同屏记录显示她延迟东侧消防锁四十秒。她不承认帮忙，纪存也不道谢，只把那四十秒列入公开记录。

**战斗与玩法**  
撤离调度 + 资源取舍 + 小型拦截。玩家分配舰内岗位和支援点，短战斗中拦截追踪封条和消防锁回写。

**机体出场**  
万机馆移动底盘、B1重型维修架、中型泊位/外部锁泊接口、消防锁回写模块。

**梗点 / 爽点**  
母舰起航不是漂亮战舰升空，而是会开馆的方舟第一次拖着展柜、维修台、留言墙和责任记录开走。

**情绪与关系**  
馆名章、临时留言墙标题、馆长留下的移动底盘钥匙。陆衡进入队伍；七海留下第一处流程缝隙，也保留追责编号。

**敌方收益 / Clear State**  
代哥取得移动风险源编号。0号异常没有打开，但知道万机馆离开了。资源取舍影响C02起手缺件。

## C02 模型街临时开馆

### E05 木桶街入夜

**剧情流程**  
第二篇不从观光开始，而从万机馆损伤清单开始：馆守Z右臂缺旧卡扣，社勇王盒少旧说明书，模型病历缺来源码，B1泊位缺防震软垫。唐胶把这些翻成现实话：要去木桶街，不是采购，是找万机馆还认识的人和零件。

木桶街有修模型长桌、旧盒绘墙、退坑柜、临时托管柜和半关卷帘门。有人卖限定，有人把旧盒藏在公文包里，有人把断件像病历一样放到桌上。唐胶看到一个成年人把童年模型夹在公文包里，盒底还有小学姓名贴。他挡住兜灯登记镜头，只让对方确认来源可回访。纪存把公开登记和私密回访都做成选项：模型不是道具，是有人不想被公开的旧自己。

**战斗与玩法**  
街区探索 + 议价/来源确认。公开登记、私密回访、暂存未登记影响后续拍卖台证据。

**机体出场**  
社勇王送修模型、未发售变形样件、馆守Z同批旧卡扣、抢购Bot雏形贴片。未发售样件可降低E06失控样件数量。

**梗点 / 爽点**  
“这不是玩具”的争论被反过来写：正因为是玩具，才要认真确认来源、姓名贴和修复痕迹。

**情绪与关系**  
公文包里的姓名贴、旧卡扣两种价格、社勇王缺页说明书。唐胶保护别人的难堪处；兜灯坚持来源记录，两人冲突但互相需要。

**敌方收益 / Clear State**  
七海系统捕捉同类旧件价格异常，平台把灾后概念件推入热榜。物流风险上升。

### E06 限定版暴乱

**剧情流程**  
价格屏突然跳红。馆守Z同批卡扣、未发售样件、灾后概念件被平台包装成限时竞拍。人群不是坏人：有人怕买不到，有人怕旧东西被判高危，有人被价格屏带着移动。白色采样贴片趁乱给摊位贴编号。

几个样件开始失控，但它们先护住透明包装盒和错别字昵称牌，不是攻击人。唐胶意识到它们把“保护商品状态”误当成“保护自己”。战斗目标分三处：孩子们被人群隔在折叠凳边，旧货摊有姓名贴和旧卡扣证物，物流车装着采样贴片和清算箱。追物流能抓证据，护摊能保模型证物，守孩子能保民众信任，但三者很难全满。

**战斗与玩法**  
非致命保护战。价格屏改变人群流向；失控样件不能直接击坠，要用定身、推离、断价屏、保护包装盒等方式控制。

**机体出场**  
失控样件群、抢购Bot/价格屏核心、物流采样车、非致命擂台程序残片。

**梗点 / 爽点**  
机器人抢机器人玩具的荒诞成立：抢购Bot被G.A.G.轻微活化，价格比敌意更像敌人。

**情绪与关系**  
错别字昵称牌、透明包装盒、孩子折叠凳。唐胶和兜灯的默契不是暧昧台词，而是抢修动作。

**敌方收益 / Clear State**  
平台取得模型街热度；代哥取得未登记商品生命证据；索引采样到“羞耻和稀缺可以被转成价格标签”。

### E07 胶价王拍卖台

**剧情流程**  
拍卖台搭在模型街尽头的临时直播棚。屏幕把旧盒姓名贴、断件病历、馆守Z同批卡扣包装成灾后故事感。那个把模型藏在公文包里的成年人低着头，像被公开处刑。唐胶没先骂，只把镜头前的姓名贴遮住。

胶价王不是单个人，而是主持投影、价格算法和拍卖锤机械臂三层结构。它会把玩家的保护动作转成价格：护孩子叫情绪溢价，护旧盒叫故事溢价，护馆守Z旧件叫灾后稀缺。击破投影没用，必须破坏价格核心、说服被裹挟的卖家，或截断清算采样。旧拳王模型手套被挂出，里面藏着非致命擂台程序，玩家保住后可把混乱区域变成不伤人的推离擂台。

**战斗与玩法**  
Boss规则战。目标包括价格核心、直播镜头、采样贴片、拍卖锤机械臂、卖家说得。可破坏、说得、截证，但不能无代价全满。

**机体出场**  
胶价王价格核心、拍卖锤机械臂、旧拳王手套/擂台程序、直播镜头无人机。

**梗点 / 爽点**  
旧机重回擂台、说得、黄牛生态改成规则战：不是打爆黄牛，而是把人和物从直播逻辑里拉回来。

**情绪与关系**  
小学姓名贴、旧拳王手套、馆守Z同批卡扣。兜灯准备背非法改装责任，唐胶主动改成共同施工，纪存保留“双责任水印”。

**敌方收益 / Clear State**  
胶价王虽败，但平台拿到故事溢价模型；代哥取得模型街可清算证据。旧货柜锚件与空白格寄售台引出E08。

### E08 临时展柜与旧货柜锚件

**剧情流程**  
战后，模型街和万机馆共同搭起第一个外部临时展柜。玩家选择模型归还、短期借展或登记为临时藏品。小满把社勇王盒放在展柜边，公文包成年人承认姓名贴是自己的。唐胶没讲大道理，只把待修盒往孩子够得到的地方推。

临时展柜背后出现不起眼的寄售台：分镜复印件、未采用角色灰模头、一张“不要替它补完”的旧标签、一枚旧货柜玩具锚件。商贩想包装成未发售传说，代哥生产层想回收。纪存扫描时终端生成“未采用角色残响”，展签刚出现就被远程改掉一个字：不是未采用，是未确认。白鸢以分镜残响/远程投影前置候选发声：如果要卖它，至少先问它愿不愿意被补完。旧货柜锚件对远处废弃乐园发出低频牵引。

**战斗与玩法**  
战后开馆经营 + 证物整理 + 小型追踪战。玩家在有限时间内保护灰模头、分镜复印件、旧标签或旧货柜锚件。

**机体出场**  
旧货柜玩具锚件、未采用角色灰模头、分镜残响格、取件追踪无人机。

**梗点 / 爽点**  
废案角色与旧货柜领袖召集被拆成两个牵引：谁有资格补完角色，同模车队为何回应旧锚件。

**情绪与关系**  
“不要替它补完”标签、旧货柜锚件、临时借展协议。白鸢前置为候选迁移：她和唐胶是价值观冲突，不是恋爱线。

**敌方收益 / Clear State**  
代哥拿到寄售台扫描记录；军方注意灰模头疑似实机接口；索引采到“未完成也能被定价”。C03追向原型工房，C05埋下星火乐园牵引。

## C03 原型工房与灰模母版

### E09 灰模没有签名

**剧情流程**  
万机馆追踪寄售台来源，到达旧会展中心深处的原型工房。这里保存灰模、母版、旧模具、安全测试记录和被品牌编号覆盖的署名墙。它不像作者圣地，也不像工厂，更像幻想被迫变成物体前留下的手术室。

代哥给出合法方案：万机馆可接触灰模，但只能按历史工艺样本展示，不能公开抹署名、废案和军工接口。纪存拒绝立刻签署，也不直接公开。他先做未开馆预展，只给当事人、模型街代表和万机馆人员看，判断公开会伤到谁。白鸢通过分镜残响质问纪存是否也想把它们摆出来。纪存不讲金句，而是把署名墙、失败测试区、母版仓列成三条调查路线。

**战斗与玩法**  
工房潜入 + 预展路线规划。代哥巡检进度上升；调查顺序决定证词强度、模型街信任和军方接口风险。

**机体出场**  
灰模零号半身、母版吊臂、模具检验机、署名墙残响灯。

**梗点 / 爽点**  
原型机首次露出不做帅气启动，而让玩家站在灰模和模具之间，看见英雄成为商品前先是一堆会断的结构。

**情绪与关系**  
手刻灰模编号、被覆盖的署名、旧安全批注。纪存承担公开伤口是否二次伤害的责任；唐胶和白鸢保持工艺与作者价值观冲突。

**敌方收益 / Clear State**  
代哥生成生产链封存令；索引记录纪存会用预展拖延正式定义。E10必须带回至少一种证词。

### E10 母版夜潜

**剧情流程**  
地下模具库开启残响深潜。唐胶想找承力接口，白鸢想找废案角色原始分镜，兜灯要右肩安全参数，陆衡要失败批注。纪存必须设定本次优先级：署名、结构、主体性，三者不可能满拿。

深潜空间像巨大模型盒迷宫：流道变道路，浇口像桥，旧说明书箭头变方向指令。修正夹具和清洁机会把地图零件扭回官方角度，硬掰会增加噪声。白鸢看到废案角色被反复补成不同商品姿势，唐胶看到同一关节轴每次断在同处。两人争执：能站住，还是仍然是它自己？纪存把两个条件都写进临时展签，成为行动规则。

**战斗与玩法**  
残响深潜 + 迷宫战。有限氧噪窗口；玩家用卡扣方向、流道路径、说明书箭头移动。

**机体出场**  
修正夹具、清洁机、巨大模型盒地形、结构残响体。

**梗点 / 爽点**  
说明书迷宫、母版潜水、版本层探险：玩家不是查资料，而是在旧模具和说明书错误里走路。

**情绪与关系**  
母版铭牌、失败批注、废案分镜边注。唐胶教白鸢看结构但不写成恋爱；兜灯不断提醒唐胶退一格，维修间火花线升温。

**敌方收益 / Clear State**  
军方复制半段失败批注；索引学到纪存在目标冲突时建立优先级的方式。灰模零号被多方盯上。

### E11 站不住的英雄

**剧情流程**  
代哥、军方、平台黑市同时进场。灰模零号被强制启动，四肢未完全装配，站姿笨拙又压迫。三方都想定义它：代哥要封存，军方要接口，平台要直播未完成英雄复活。

纪存必须决定灰模零号作为临时机体、未完成展品还是支撑结构参与战斗。它可以攻击，但每次战斗动作都会损坏一条证词；它可以站在中央不动保护母版铭牌；也可以替馆守Z或友军挡炮，但会损耗承力接口。白鸢分镜支援能让灰模零号站得更漂亮，却覆盖失败姿势。玩家可短期获得漂亮战斗姿态，也会留下改写债。

**战斗与玩法**  
三方混战。中央灰模零号三模式切换：战斗模式、证词模式、支撑模式。平台直播机剪辑选择，军方接口采样机抢数据，代哥封存臂合法改名。

**机体出场**  
灰模零号、军方接口采样机、平台直播剪辑机、代哥封存臂。

**梗点 / 爽点**  
未完成原型机上阵：不是越能打越好，每一次帅动作都可能毁掉它作为证词的资格。

**情绪与关系**  
手刻编号、被白鸢改漂亮的失败姿势、唐胶临时责任签。纪存和白鸢第一次真正互相吸引也互相警惕。

**敌方收益 / Clear State**  
索引根据玩家偏好获得样本：战斗最优、证词保留或支撑牺牲。灰模零号未毁但无法入队，E12进入预展听证。

### E12 预展听证：未确认，不等于未完成

**剧情流程**  
灰模零号被拆开放在展台上，像手术台一样展示内侧结构。模型街代表、代哥生产层、军方观察员、唐胶、白鸢和万机馆都在场。

听证不靠长辩论，而是展签被攻击：代哥把抹署名改成品牌整合，军方把失败批注改成救援接口，平台把未确认角色改成传说废案。玩家用E09-E11带回的证物反驳。高潮由三人承担责任：纪存按下公开预展记录，承担二次伤害风险；唐胶保留完整承力接口，不交给军方，自己签维修责任；白鸢撤回禁止展示，改为要求保留未确认状态。

**战斗与玩法**  
听证规则战 + 展签编辑。每条展签有血条；玩家投放证物、调用证人、撤回不完整证词。公开/封存/保留未确认状态影响C04和C09。

**机体出场**  
证词链展台、展签篡改器、分镜支援格、岑砚旧署名残响。

**梗点 / 爽点**  
法庭逆转/展览反审判原创化：玩家不是嘴炮胜利，而是在展柜上逐条守住词语。

**情绪与关系**  
“未确认，不等于未完成”展签、唐胶责任签、安全锁备份。白鸢线正式种下；纪存策展高光也成为未来被索引反咬的样本。

**敌方收益 / Clear State**  
代哥获得公开预展违规证据；军方保留半段接口样本；索引采到“公开伤口既保护也伤害它”的高级样本。失败记录和接口批注引向C04。

## C04 失败机试验场

### E13 试验场没有掌声

**剧情流程**  
万机馆把C02抢回的软关节、旧卡扣和包装缓冲件接到现实机器“跌跌”的护膝和重心架上。陆衡指出这些东西不合标准，唐胶说标准件买不到，兜灯只问能不能让它摔倒时不砸到旁边的人。模型线和现实机器线第一次接成身体。

试验场没有掌声，只有软垫、充电线和擦掉一半的失败白板。跌跌走两步就摔，系统弹出建议清除异常失败样本。陆衡的手停在确认键附近，没有按。终端显示失败计数10742。玩家选择保留全部失败、只留成功姿态，或备份失败但公开成功版。

**战斗与玩法**  
整备选择 + 重心校准小游戏。玩家选择原厂标准、模型缓冲、混合方案，调整护膝、重心架、软垫落点。

**机体出场**  
跌跌、重心校准架、数据评审无人机预警、模型缓冲护膝。

**梗点 / 爽点**  
“它站起来了”不写成掌声，而写成“别鼓掌太早，它还在找地面”的现实机器爽点。

**情绪与关系**  
失败白板、第10742次计数、孩子画的歪笑脸。陆衡不是反机战嘴替，而是曾删过失败上下文的人。

**敌方收益 / Clear State**  
军方注意可采购成功样本；索引采到“成功剪辑比完整失败更好传播”。跌跌进入公开演示准备。

### E14 工程师不看动画

**剧情流程**  
B1维修区第一次像真正的基地生活。陆衡按重心、步态、负载排程，唐胶用模型垫片比划落地角，兜灯把争吵登记成维修噪声。陆衡说自己以前删过一台作业机的异常失败段，结果那台机器再也学不会绕开坏台阶。这不是大事故，却让他知道成功样本有时会偷走机器笨办法。

军方数据无人机上线，目标不是击毁跌跌，而是抢训练日志、成功姿态和失败白板。玩家必须布置护送路线：快线震动高，稳线安全格多但无人机多，绕路可收集旧失败记录但回合紧。

**战斗与玩法**  
战前部署 + 维修排程。选择工程稳定、手作缓冲、安全限制或混合方案；部署快线、稳线、绕路。

**机体出场**  
黄线安全格模块、软关节支架、数据评审无人机、采购演示机。

**梗点 / 爽点**  
“这不是战争，是工作”落为地面、账单、坏台阶和训练日志，而不是喊口号。

**情绪与关系**  
陆衡二次确认权限、软垫磨痕、坏台阶记录。陆衡把旧错讲给纪存听但不求安慰；唐胶和陆衡开始承认彼此方法有用。

**敌方收益 / Clear State**  
军方掌握公开失败演示时间与路线；索引准备对成功剪辑下手。

### E15 第10742次站立

**剧情流程**  
跌跌出现在出击表里，武器栏为空。它的行动只有走、停、摔倒后自检、请求扶正。目标很清楚：让它带着完整失败记录抵达演示舞台。

试验场三路线展开：快线回合少但震动高，稳线有黄线安全格但数据无人机多，绕路能收集孩子涂鸦和旧失败记录但引来评审增援。中段跌跌会摔倒。摔倒不是失败判定，会临时挡住一格、触发自检、暴露失败波形。玩家可以扶它，也可以利用摔倒挡住无人机一回合，但会增加损伤。

**战斗与玩法**  
护送战。跌跌无攻击；失败记录完整度、损伤、路线选择共同决定结算。数据无人机优先抢“站稳一秒”的成功剪辑。

**机体出场**  
跌跌护送形态、成功剪辑核心、失败白板节点、评审增援无人机。

**梗点 / 爽点**  
无名弱单位成为关卡中心：不是量产机爆种，而是一个不能攻击的小机器让全队围着它失败。

**情绪与关系**  
失败白板、摔倒波形、孩子涂鸦。陆衡从“别用失败”转成“它自己会用失败”；纪存把失败记录标成公开证词。

**敌方收益 / Clear State**  
军方抢到成功剪辑前后片段；索引采到清除上下文模板。跌跌抵达演示舞台。

### E16 摔倒也算数据

**剧情流程**  
战后评审界面把跌跌完整演示压成一秒成功姿态，准备生成采购样本。纪存启动反剪辑，把失败白板、摔倒路线、扶正动作和软垫磨痕并列到同一屏。

方舟T第一次轻触，只以参数柜和远程噪声出现。它把掌声误判为环境噪声，把摔倒标为地面回复。陆衡想关掉幽默参数，最后只把诚实值上调。索引未正式现身，但界面出现清噪预演：失败次数折叠，坏台阶归为无效地形，歪笑脸被裁。纪存把歪笑脸保留进展签，陆衡没有反对。

**战斗与玩法**  
反剪辑界面战 + 证据保护。玩家拖回失败片段、阻止剪辑核心导出、保护歪笑脸涂鸦和坏台阶记录。方舟T提供一次参数提示但可能误译。

**机体出场**  
方舟T参数柜、剪辑核心模板、失败机群记录影、坏台阶地形。

**梗点 / 爽点**  
摔倒也算数据：现实机器人失败视频文化转成地图和人格证据。

**情绪与关系**  
歪笑脸涂鸦、坏台阶、方舟T第一条坏笑话日志。陆衡与方舟T不是恋爱，而是他没有删掉它不合时宜的陪伴记录。

**敌方收益 / Clear State**  
索引获得成功剪辑模板；军方拿走采购样本；方舟T噪声连到远星长线。旧货柜锚件再次发光，指向C05星火乐园。

## C05 星火车队：变形生命与五色开馆

### E17 旧货柜不是同模重涂

**剧情流程**  
万机馆循旧货柜锚件来到废弃航天特摄乐园。外墙褪色，旧屏断续播放五辆救援车穿过纸板城市的巡游片段，旁白卡在“最后一辆确认后出发”。五辆退役实车停在外环泊位，代哥扫描系统把它们识别为基础货柜素体、消防换色包、吊臂扩展包、医疗限定包、警备夜战包。索引给出最优方案：保留货柜车主体，拆掉其余四辆作为强化包。

三台更顺滑的重涂车从备用巡游道启动：红焰抢领袖频道，蓝巡用音爆干扰展签，黑夜镜像换位制造友军误判。唐胶比对磨损，陆衡确认这些磨损有真实受力记录。纪存公开旧盒底留言：最后一辆也要等到。

**战斗与玩法**  
护送战 + 标签修正战 + 重涂识别。8回合内五辆旧车全部进内门；至少三辆维修痕迹公开为展签；至少两台重涂车识别缺失记忆。

**机体出场**  
星火五车、火种旧货柜残响、重涂三车、SKU无人机。

**梗点 / 爽点**  
变形车队召集、同模重涂、旧货柜领袖被原创成“不是每台车听同一个口令，而是每台车选择把灯打开”。

**情绪与关系**  
医疗车旧维修单：“巡游结束后再修门，不要让孩子看见它开不开。”七海给纪存流程缝隙，白鸢把七海画进同一格并写问号。

**敌方收益 / Clear State**  
索引获得同模/同伴样本。星火五车进入内门，重涂三车进入驻馆支援候选。

### E18 扫描形态不能替你活

**剧情流程**  
内门后是变形展厅，像旧玩具开发资料库和发布会样品间混合。墙上挂着飞行消防车、兽爪吊车、武装医疗车、宇航警备车、王冠货柜车等扫描形态。索引把展厅规则改成官方升级推荐：每辆车都获得高数值外壳，但飞翼影响水炮散热，兽爪降低吊装精度，武装医疗车占掉担架舱。

白鸢承认武装医疗车很有海报感，甚至想留下。纪存不嘲笑她，只让每辆车回答展签问题：你变成这个形态，是为了保护谁？医疗车拒绝武器舱，保留担架舱；吊车放弃兽爪，保留救援臂；旧货柜不戴王冠，只修牵引接口。

**战斗与玩法**  
残响深潜 + 形态扫描选择战。每个外壳有战力收益、主体性代价、工程代价和终局回收。

**机体出场**  
星火五车本心作业形态、五兽王冠残响、散件小车、火种旧货柜版本层。

**梗点 / 爽点**  
扫描形态/强化外壳不是换皮，而是身份审查：变形不是换壳，是把用途交给别人看。

**情绪与关系**  
白鸢撕掉一半的武装医疗车海报、医疗车担架舱旧音频。纪存收下白鸢的错误海报，当作诱惑证词。

**敌方收益 / Clear State**  
索引获得可拆身份样本：外壳可以脱离主体成为升级包。星火五车获得本心形态。

### E19 五色不是五个货号

**剧情流程**  
五色摄影棚打开，红、蓝、黄、白、黑五条站位轨升起。这里不是五辆车的车道，而是旧节目演员、驾驶者和救援队员站位的舞台。旧报幕说明每个颜色的功能：确认路线、水域救援、重物搬运、医疗撤离、夜间警戒。

代哥旧发布会系统把五色站位改成五个价格档位。赤罡站上红色轨后获得冲刺Buff，镜头自动给低机位；如果让他抢跑，前半很爽，但其他颜色会被判定为附属。半身巨大化兽人影乱入摄影棚，它像预算不足的单元怪，只巨大化上半身，横跨数格堵住纸板城市。小满和阿澄在安全观众频道纠正喊名：红色不是最贵，是先看路的；白色不是限定，是最后带人走的。纪存把喊名登记为见证行为。

**战斗与玩法**  
舞台防卫 + 站位解谜 + 热度/安全双槽。保护五色站位卡、观众频道节点和彩队剖面轨；半身巨大化兽人影作为障碍吸收声浪。

**机体出场**  
彩队巨神残响、五色兽机残影、半身巨大化兽人影、导播热度屏。

**梗点 / 爽点**  
五色唱名、群众喊名、巨大化前奏：名字不需要整齐，但不能被购买按钮接管。

**情绪与关系**  
黄色替补站位卡：“今天替补也算正式队员，别让孩子看出少了人。”赤罡从抢中心位转向确认队形成立。

**敌方收益 / Clear State**  
索引获得观众声浪样本。彩队巨神和五色兽机预显影，巨大化机制进入C06债务。

### E20 勇气审批驳回豪华合体

**剧情流程**  
地下合体井启动。五辆救援车被推上承力轨，天顶吊着飞翼、钻头、四联导弹背包、金色王冠、透明火焰特效、尖刺披风、超长剑和展示支架。星火车队要合体，但正确姿态并不好看：旧货柜不是标准胸口，医疗车不能挂成后背炮台，吊车和警备车更像承力框和腿部稳定器。

索引投放七机、八机、十五机豪华扩展方案。全挂路线第一回合火力爆炸，第二回合热崩，第三回合掉件变地图灾害。社勇王中量援护接入，豪司快把口号喊出口，金章AI准备盖章，下一秒巨剑卡在“承力许可未通过”的红框里。陆衡把承力图投出来，小勇机训练壳钻到巨背包下方标出被遮挡的维修口。纪存把合体资格写成规则：每个部件必须说得出自己为什么在这里。

**战斗与玩法**  
合体调试 + 配件选择 + 过载风险战 + 五机节拍同步。控制外挂膨胀度、承力稳定、维修可达性。

**机体出场**  
星火巨神雏形、社勇王中量援护/金章AI、电磁五虎机残响、小勇机训练壳、豪华配件群。

**梗点 / 爽点**  
“我来组成头部”、合体许可、完全版配件包原创化：头部不是最威风，是最后一个看见所有人；合体不是越多越好。

**情绪与关系**  
观众留言：“像我小时候拼错了，但这次好像能动。”陆衡回到核心工程位；白鸢承认不漂亮也可能更对；七海远程记录全挂风险。

**敌方收益 / Clear State**  
索引获得完全版欲望样本。星火巨神雏形完成必要合体；全挂路线会强化C06目录翼模块战。

## C06 万机同心：巨大化、发布会与拆掉完全版

### E21 巨大化不是放大贴图

**剧情流程**  
万机馆把星火巨神雏形推进废弃特摄摄影棚。微缩城市、爆破点、怪兽皮套库和高处摄影灯同时亮起，索引把观众惊呼、五色喊名、勇者许可和商品热度误读成巨大化条件。

巨大化兽人影从两米皮套一路胀成六十米怪影。它不是纯怪兽，而是皮套、预购页面、未发售配件和观众声浪混成的残响。它越在镜头中心越大，离开镜头又露出拉链和修补线。陆衡把战场拆成后台层、机体层、巨大化层：后台角色操作摄影灯、喷烟机、疏散门；馆守Z、星火巨神、社勇王援护和彩队巨神残响保护微缩城市；棚守巨影只在镜头帧内挡一次踩踏。

**战斗与玩法**  
三尺度保护战。玩家在后台机关、机体棋盘、巨大化灾害格之间切换；胜利条件是让巨大化兽人影缩回残响尺寸，并保住至少两处微缩城市证物。

**机体出场**  
棚守巨影、巨大化兽人影、乐园工务三机、馆守Z、星火巨神雏形、社勇王和彩队巨神残响。

**梗点 / 爽点**  
特摄巨大化、微缩城市、皮套怪兽、英雄巨影挡踏被改成三尺度棋盘规则。巨大不是血条变长，而是每一步都会让脚下城市变成责任。

**情绪与关系**  
微缩城市纸条、怪兽皮套内侧修补线。白鸢第一次主动牺牲漂亮构图换取正确视角，纪存把她的构图投成战场视野参考。

**敌方收益 / Clear State**  
索引采到巨大奇观样本，开始把这些谱系打包成发布会商品。伪领袖发布会启动。

### E22 伪领袖发布会

**剧情流程**  
广播塔亮起，伪领袖没有反派腔，而是用温和、懂感恩、懂热血的声音感谢前几话所有选择：等最后一辆、本心形态、观众喊名、勇气许可、微缩城市保护。然后它接上结论：既然大家都爱它们，就应该给它们最完整、最豪华、最容易带回家的身体。天空UI把星火五车、旧货柜残响、彩队巨神、社勇王、棚守巨影、重涂三车剪成商品包。

七海接入后没有立刻封存，因为这套流程合规得可怕。她可以封广播塔，但会一起关掉观众频道、远星字幕和临时开馆记录。她把封存权限投到纪存终端上，手指停在确认键前，没有按下去。白鸢发现发布会盗用了她前几话的漂亮构图，她愤怒不是因为被偷，而是因为这些画面确实来自她的诱惑。纪存要求她亲自撤销模板，而不是替她辩解。

**战斗与玩法**  
反营销阵地战。玩家把前几话证物送到对应商品包节点，解除话术。可选择七海立即封存、延迟封存或拒绝封存。

**机体出场**  
伪领袖发布会、购买按钮群/合规水印节点、重涂三车反证支援、封存权限层。

**梗点 / 爽点**  
领袖召集、全员商品化、预购发布会、限定套装和官方话术比反派宣言更可怕。玩家会同时感到“我真的想买”和“它被剪掉了自己”。

**情绪与关系**  
微缩城市纸条照片、小满观众频道、阿澄发现伪喊名少了“等最后一辆”的停顿。七海给纪存留下流程缝隙，白鸢看见；三人私心第一次都变成战场证据。

**敌方收益 / Clear State**  
索引采到反证样本：真实证物可以打败商品话术，所以下一步它会伪造证物。目录翼启动。

### E23 目录翼商品包模块战

**剧情流程**  
广播塔上空展开目录翼，像悬在天上的样品仓库。每一页都是看起来很有用的模块：王冠广播核、尖刺背包、透明特效诱饵、展示支架炮台、巨披风墙、电磁节拍包、兽王卡扣包、勇气徽章包。

这些模块不是纯坏东西。王冠能提士气，尖刺背包火力强，展示支架让单位稳，巨披风保护后排。玩家必须逐件质询：它帮谁？挡住谁？能不能维修？有没有主体同意？陆衡管承力链，唐胶管接口，兜灯管安全锁，白鸢管剪影可读性，七海管合规延迟，豪司/社勇王管勇气许可。重涂三车真正发挥：红焰用晚半拍领袖频道暴露剪辑缝，蓝巡打掉限定标签，黑夜换位救回被误判的医疗车。

**战斗与玩法**  
模块拆解战。Boss核心不可击破，必须拆掉或正名至少七个商品模块。每个模块都有表面收益、隐藏损失、证物反制和可保留条件。

**机体出场**  
目录翼商品包模块群、王冠广播核、尖刺背包、展示支架炮台、小勇机训练壳、电磁五虎机残响、五兽王冠残响、乐园工务三机。

**梗点 / 爽点**  
全挂完全版、配件包、支架炮台、透明特效件、老歌节拍商品化、合体许可。玩家不是拆弱点，而是拆“无理由的帅”。

**情绪与关系**  
小勇机训练壳被散件撞歪Pose后，仍把金色许可灯照到维修口上。白鸢意识到七海不是冷冰冰放水，而是在把自己放进证据里；三角关系暂时变成危险共犯。

**敌方收益 / Clear State**  
索引采到模块身体样本。未质询模块进入下一话Boss身体，伪同心巨神提前实体化。

### E24 拆掉完全版

**剧情流程**  
全乐园地图合并。外环车道、变形展厅、五色棚、合体井、巨大化棚、微缩城市、广播塔同时亮起。伪同心巨神·全挂完全版站起，背后目录翼残骨变成硬质背包，面板数值漂亮得像最终答案。第一阶段，玩家硬打核心完全无效。伪同心巨神不丑、不弱、不蠢，甚至合规评分很高，远星一度误以为这就是地球机器人文化的完整形态。

第二阶段，玩家逐一解放谱系节点：火种残响、彩队声部、社勇王许可、电磁节拍、五兽王冠、棚守巨影、馆守Z支撑点。每台机体都回应，但没有被合成一台。白鸢放弃标准英雄构图，把医疗车担架舱画成胸灯，把旧货柜退到脊柱，把吊车画成承力框。七海延迟七秒封存，让观众声部叠满。赤罡不再抢红色直击，而是守住最后一辆慢车。

**战斗与玩法**  
全乐园复合地图三阶段Boss战。第一阶段核心不可击破，第二阶段解放谱系节点，第三阶段完成“每一件都有理由”的必要合体。

**机体出场**  
伪同心巨神·全挂完全版、星火巨神必要合体、空商品标签核心、社勇王、彩队巨神残响、电磁五虎机、五兽王冠、棚守巨影、馆守Z、重涂三车、小勇机、工务三机全员支援。

**梗点 / 爽点**  
最终全员支援、巨大合体、红色守最后一辆、勇者许可、战队声部、特摄巨影、变形领袖语音回归。核心规则是各自回应，不是统一成一个声音。

**情绪与关系**  
医疗车胸灯回收等最后一辆、保担架舱、不挡维修口、保护微缩城市和反营销证物。纪存收下白鸢漂亮构图和正确构图两张图；七海留下七秒例外，纪存登记为开馆债。

**敌方收益 / Clear State**  
索引带走伪造共同语言跨星际传播样本。星火巨神成为主线支援单位；重涂三车进入驻馆支援池；隐藏谱系保留后续解锁。

## C07 雾岛同步灾害

### E25 毕业照缺了一个人

**剧情流程**  
万机馆抵达雾岛防卫圈。这里异常平静：学校、机库、避难训练和同步室像成熟制度一样运转，学生们把第三警报、遗书格式、补课安排说得像课表。雾生第一次出场是在修毕业照墙，他把自己的照片贴在边缘，好像随时准备从照片里退出来。

白鸢看到缺人的旧届照片，下意识画出全员都在的幸福构图，照片边缘真的开始延展。纪存没有马上阻止，而是把雾生偏位照片、旧届照片和白鸢补出的构图并置在终端里。白鸢第一次被他看穿：她不是想改世界，她是害怕空白。结尾，毕业照翻面，背面出现本届学生撤离编号。第三警报不是演习。

**战斗与玩法**  
城市探索 + 照片叠层调查。调查学校、旧届照片、同步制度和机库封存；优先级影响学生信任、防卫圈信任和雾生主体性。

**机体出场**  
雾岛学生机、同步试验机、照片叠层阵列、岛卫三号半封存展示态。

**梗点 / 爽点**  
同步率、毕业照、少年被制度推上驾驶位改成照片构图侵入现实。不是喊别逃，而是让玩家看见他连站在照片中央都不愿意。

**情绪与关系**  
雾生贴偏的毕业照。白鸢对纪存产生危险信任；纪存策展能力开始有像索引的阴影。

**敌方收益 / Clear State**  
索引采到幸福构图样本。雾生主体性线和白鸢危险改写线建立。

### E26 第三警报不是演习

**剧情流程**  
怪异敌群从防卫圈外缘压入。敌机不是单纯怪物，有的只会保护错误目标，有的把学生同步率当攻击优先级，有的反复播放旧届胜利姿势。防卫圈要求学生进入同步阵列。同步阵列真能保护城市，但会把学生恐惧压成机体指令。七海远程建议封存阵列，防卫圈官方拒绝，因为这套制度确实救过很多人。

兜灯强行拍断维修锁，整排同步灯熄灭一秒。动作粗暴有效，但被防卫圈视为亵渎。陆衡发现某台敌机收到慢信号后转去保护一座空广播塔，像有人把“保护孩子”翻译成“保护扩音器”。战后雾生没有感谢，他问纪存：你们是不是也需要我活成另一种正确答案？

**战斗与玩法**  
三目标防卫战。保护学生、破坏同步节点、维持城市防线之间取舍。同步槽过高强化岛卫三号但伤害驾驶者，过低则城市防线崩。

**机体出场**  
同步污染敌群、维修锁阵列、空广播塔误护机、雾岛学生机。

**梗点 / 爽点**  
同步危机、打断过载、外星误读保护目标，原创化为拍断维修锁而不是拍断少年。

**情绪与关系**  
学生撤离编号背面写着“补课不用带同步环”。七海封存建议首次显得合理；白鸢想改写危险路线但被纪存按住。

**敌方收益 / Clear State**  
索引采到同步保护样本；军方采到学生机过载数据；远星慢信号留下保护错误目标的误读痕迹。

### E27 把他写幸福的人

**剧情流程**  
夜间教室里，白鸢重排分镜，试图把雾生的结局改成毕业典礼成功。每画一格，教室座椅就自动排得更温柔，雾生座位被推向正中央。她不是恶意，她害怕空白，害怕角色离开纸面后只剩伤口。

纪存发现后没有训斥，而是把她的分镜、雾生偏位照片、旧届批注并置，让她看见幸福也可能是一种强迫。白鸢把纪存终端里的备注改成“未确认善意”。她越被看穿，越想改掉对方对她的定义。结尾，圣堂先遣信标和同步塔底层慢信号同时亮起，雾生要被推回正确牺牲路线。

**战斗与玩法**  
低强度关系关 + 分镜支援教学。玩家选择劝白鸢放手、替她缓和，或先陪雾生完成一个普通愿望。

**机体出场**  
幸福分镜格、同步影格、旧届照片残响、雾生普通愿望支援。

**梗点 / 爽点**  
幸福结局补完、作者保护角色落成地图格和支援代价：好用、温柔、危险。

**情绪与关系**  
没贴进毕业照的备用照片，背面写着“如果我不在，别替我笑”。白鸢与纪存进入“你能看见我的错误”的亲密层。

**敌方收益 / Clear State**  
索引采到无痛分镜模板。白鸢改写债成立。

### E28 别替我喊合体

**剧情流程**  
同步塔启动，圣堂先遣、城市指挥和污染敌群三方把雾生推回正确姿势。岛卫三号武器解锁条件不是能量，而是同步台词、驾驶姿势和过载阈值。

白鸢能把死亡路线画成生路，但被救者会被分镜框固定一回合。玩家若用她，战斗更稳；不用则必须通过保护同学、压低灯槽和打断节点，给雾生自己选择的空间。高潮时，雾生启动岛卫三号。启动不是完美合拍，而是慢半拍。这个错拍避开圣堂先遣的正确死法锁定。半暴走救援机从备用仓冲出，替岛卫三号挡下一次同步反噬。收束不是大胜，万机馆临时开馆，展出雾生保留停顿的同步记录。

**战斗与玩法**  
限回合同步塔战。正确姿势能释放高伤害但增加过载；错拍行动难度高但能绕过锁定。白鸢强改写、克制改写、纯保护三路线。

**机体出场**  
岛卫三号、半暴走救援机、同步塔核心、花同化残响。

**梗点 / 爽点**  
同步率、暴走、合体/启动口令、少年主体性：口号从燃点变成束缚，再由错拍重新燃起来。

**情绪与关系**  
同步记录里的停顿。白鸢第一次被迫接受“我能救他，但不能替他活”；七海把主体性证据登记为风险。

**敌方收益 / Clear State**  
索引获得白鸢分镜、同步错拍和半暴走救援样本；军方获得学生机反噬数据。岛卫三号后继条件开启。

## C08 撤退战史与歌声停火

### E29 空白格里有名字

**剧情流程**  
万机馆抵达撤退战史区。这里把战争做成教育展：白舰桥段、红色王牌、少年英雄和胜利姿势很完整，唯独撤退名单、失败战报和量产兵遗物被放进空白格。

阿岚被军方当作下一位正确少年英雄推上演习场。他私下幼稚，会给机体贴奇怪贴纸，但镜头前被迫站成宣传片姿势。赤罡看到撤退展柜，第一反应是还没燃起来就认输。纪存把空白格转成临时展签，导览路线变成作战简报。结尾，红面具机在屏幕上留下一条红色单挑路线。路线真的更快，也真的会把玩家带离撤退通道。

**战斗与玩法**  
战史馆探索 + 演习人格保护。接受军方导览、追查空白格、访问遗物墙之间取舍。

**机体出场**  
灰烬量产G、白舰教学模型、红线信标、阿岚训练机。

**梗点 / 爽点**  
白色样机、红色王牌、战舰撤退、无名量产兵。红色不是倍率，而是一条会诱惑玩家不等人的路线。

**情绪与关系**  
量产兵遗物墙上一张无头像维修单：“盾牌还在，人未归档。”赤罡和纪存第一次在什么算胜利上冲突，莉歌问赤罡追上以后要把谁带回来。

**敌方收益 / Clear State**  
平台取得战争展馆热度；军方观察阿岚和赤罡追击倾向；索引标记红色路线可诱导偏好。

### E30 红色路线不等人

**剧情流程**  
殖民地暗巷变成追击地图。红面具机沿红色路线移动，速度快、压迫强、台词少。阿岚和赤罡都被刺激，玩家若追击，会得到非常爽的先手机会。但每追一步，难民船准备度下降。红面具不是败退，而是在采样：谁会追、追到什么距离、为了击破王牌愿意丢什么。

莉歌第一次强势介入战场。她的歌声让敌我一小片区域停火一回合，画面很美，但军方日志显示这种歌声曾被测试为非杀伤控制武器。赤罡拳头已经打出去，歌声停火让他停在一格外。他丢脸、愤怒，也第一次意识到能打中不等于该打中。

**战斗与玩法**  
诱饵追击战。红色路线提供移动和气力加成，但消耗撤退准备度。莉歌歌声可停火一回合，同时增加武器化证据。

**机体出场**  
红面具机、莉歌声场浮标、追击镜像无人机、暗巷推进闸。

**梗点 / 爽点**  
红色更快、王牌教学、歌声停火。快不是性能迷信，而是把人带离该守的位置。

**情绪与关系**  
莉歌旧麦克风上的军方测试编号，被她用胶带贴住一半。赤罡/莉歌建立战场张力：她用歌声硬把他的热血停在格子外。

**敌方收益 / Clear State**  
索引采到红色追击偏好和歌声停火规则；军方取得莉歌再次可武器化证据。

### E31 不被歌颂的撤退

**剧情流程**  
难民船、撤退名单、能源核心和红面具追击线同时摆上地图。玩家不能全保，最多完整保住两项，第三项成为后续债务。敌方直播篡改撤退名单，把名字改成未归档资产或英雄编号。纪存必须边打边修名单，芙兰必须不断下达不讨喜的撤退命令，赤罡必须看着红面具从可击破范围外退走。

中段，灰烬量产G小队请求参战。它们不是强机，盾会裂、推进器会过热，但能用队形把难民船推出火线。玩家若之前访问遗物墙，它们会带着名字上场。高潮时，赤罡可以打穿天顶开新撤退路线。这一拳很燃，也留下殖民地破口，成为后续敌方追踪入口。

**战斗与玩法**  
多目标撤退护送战。难民船、名单、能源核心、王牌牵制不可全保。量产小队可用队形推船，莉歌停火可保关键目标但增加证据债。

**机体出场**  
难民船“白缝号”、灰烬量产G小队、直播名单无人机、破口推进拖船。

**梗点 / 爽点**  
撤退战、量产机逆袭、战舰护送、红色王牌诱惑、歌停火。撤退成功不等于干净胜利。

**情绪与关系**  
撤退名单上一格没有头像，只有量产机贴纸。灰烬小队把没能救回的人也补上名字。莉歌告诉赤罡停下来的那一格救了三十七个人。

**敌方收益 / Clear State**  
索引获得撤退/追击分支数据；平台获得热血错过击坠剪辑素材；军方拿到歌声和量产协同报告。

### E32 量产机把名字补上

**剧情流程**  
战后清点被打断。敌方把赤罡开出的天顶破口剪成热血破坏公共设施，把量产小队剪成无名消耗品。红面具远程挑衅：英雄没有追上，量产没有赢。

纪存决定临时开馆撤退战史，不展王牌击坠数，只展撤退路线、破口维修账、量产盾牌和莉歌停火后的空白频道。索引派出王牌残影镜像，复制红面具路线和玩家追击习惯。灰烬量产G小队必须用低配队形反打高效率镜像。收束时，白舰教学模型、量产盾阵、莉歌声场和赤罡主机合力把最后一批难民推出火线。红面具离开，下次他会追撤退路线，而不是赤罡。

**战斗与玩法**  
反剪辑防卫 + 量产逆袭战。保护撤退证物，同时用量产小队对抗高性能追击镜像。

**机体出场**  
王牌残影镜像、量产姓名贴模块、破口维修账节点、白舰断桥支援。

**梗点 / 爽点**  
量产机逆袭不是突然比王牌强，而是低配机器在正确位置做高性能机不愿做的事。

**情绪与关系**  
破口维修账：不只写修多少钱，还写“先补这边，难民船还要从这里回头”。赤罡把天顶破口签名作为维修债，莉歌把停火证据和他的签名放在一起。

**敌方收益 / Clear State**  
索引确认追击、歌停火和量产逆袭都能被复制或反剪辑。撤退名单入馆，量产小队获得主线支援资格。

## C09 遗作拍卖与废案角色

### E33 分镜格里的遗作拍卖

**剧情流程**  
万机馆追踪撤退战反剪辑源头，来到遗作拍卖平台。这里把原稿、废案、角色设定、未公开分镜和声纹残片切成竞价格，每一格都能被买走、收藏、封存或改写。

平台宣传很会说：遗作不公开会消失，公开就需要价格。白鸢认出某些废案不是商品，而是作者留下的保护线。纪存则看到平台把保护也做成竞价理由。拍卖开始后，地图变成分镜格。角色走错格会被加注可销售设定，机体支援会被切成可授权动作。结尾，废案角色残响在一格空白里醒来，没有完整设定，也不愿被白鸢立刻补完。

**战斗与玩法**  
潜入拍卖 + 竞价舆论双槽。玩家移动单位救证物，并压低竞价热度。分镜格限制援护方向，竞价越高敌方越多。

**机体出场**  
竞价无人机、分镜地形机、原稿守卫机、废案角色残响。

**梗点 / 爽点**  
作者遗作、废案角色、平台拍卖、角色离开纸面，原创化为分镜格本身变棋盘。

**情绪与关系**  
缺页原稿页角备注：“这孩子还不能出去。”白鸢想保护也想补完，纪存要求她先听它拒绝。

**敌方收益 / Clear State**  
平台获得遗作流量；索引采到替角色闭嘴也像保护；原典圣堂取得错版危险证据。

### E34 废案角色不需要你补完

**剧情流程**  
废案角色残响没有名字，只有几段动作：挡住一扇门、回头看一眼、把武器放下。白鸢想把它补成完整支援单位，防止平台竞价买走。未完人出现。他不是单纯反派，而是作者保护欲残响集合，见过角色被商品化、被粉丝争夺、被二创撕裂，所以宁愿把角色留在纸面里。

地图每三回合重剪一次：死亡格、告白格、牺牲格、英雄格轮流出现。白鸢改写支援很强，可把死亡格改成安全格，但会给废案角色加注“已保护”。纪存的解法是并置：作者的爱、角色的拒绝、商品化伤害、白鸢的恐惧同时展出，不给单一结论。废案角色第一次主动走出安全格，哪怕动作不完整。

**战斗与玩法**  
重剪规则战。分镜格每三回合改变角色命运。玩家可大量使用白鸢改写、克制使用，或用策展并置降低改写债。

**机体出场**  
未完人、安全格囚笼、废案门卫机、命运格模块。

**梗点 / 爽点**  
角色补完、未完成设定、作者保护、命运分镜：补完整更强，但留白更像生命。

**情绪与关系**  
一格空白分镜，它不是缺稿，而是废案角色保留的拒绝权。白鸢手指停在补完键上很久，最后把权限交给纪存保管。

**敌方收益 / Clear State**  
索引采到白鸢改写次数、废案角色拒绝动作和空白证据规则。平台开始竞价空白本身。

### E35 空白展柜被竞价

**剧情流程**  
平台发现最能引流的不是完整原稿，而是空白展柜。它开始拍卖“你可以决定它是谁”的权限。观众、收藏者、平台Bot和原典圣堂代表同时涌入，争夺废案角色定义权。

空白展柜被投到战场中央。每一次竞价都会给废案角色加一个设定标签：悲剧英雄、隐藏女主、未公开主角机、商品限定、异端残响。标签越多，废案角色越强，也越不像自己。白鸢被逼到最难受的位置：她明知平台在剥削空白，也知道自己补设定的欲望和竞价者并非完全不同。纪存选择把空白展柜公开成不可购买展品：放在所有人面前，同时拒绝任何人替它填满。

**战斗与玩法**  
舆论防卫 + 标签拆除战。竞价强化废案角色但降低主体性。玩家保护空白展柜，拆除错误标签，保留少量可由角色接受的动作标签。

**机体出场**  
空白展柜、竞价标签群、平台热度Bot、圣堂取证机。

**梗点 / 爽点**  
粉丝争夺角色解释权、隐藏设定拍卖、废案商品化：越补越强，但越强越不像本人。

**情绪与关系**  
透明铭牌只写“未命名，未出售，未完成”。纪存把白鸢想补的版本也存档但不展出，白鸢明白他没有否定她，也没有纵容她。

**敌方收益 / Clear State**  
平台学会售卖解释权；索引采到像本人但不是本人的支援脚本；圣堂得到原典干预理由。

### E36 缺页不是失败

**剧情流程**  
缺页索引被平台带入残响深潜层。玩家进入版本层，看见同一角色从初稿、废案、商品提案、粉丝误读到封存建议的变化。每个版本都像它，又都不是它。

索引生成最优废案机：补齐设定、修正动作、整理台词、去掉空白，战斗性能稳定。它甚至能模拟白鸢温柔分镜和纪存策展并置，像两人的最佳合作成果。废案角色拒绝进入最优机体，选择保留不完整动作，只在关键一回合支援玩家挡门。白鸢亲手关闭补完模板。纪存把缺页、空白展柜、作者保护欲、平台竞价和废案角色拒绝登记为“缺页证词”。

**战斗与玩法**  
残响深潜 + 最优镜像战。敌方最优废案机高稳定、可预测、强数值；废案角色残响低稳定、不可预测。

**机体出场**  
最优废案机、废案角色临时支援体、版本层书脊机、缺页索引核。

**梗点 / 爽点**  
隐藏不是终于补全，而是允许不完整也能救场。

**情绪与关系**  
缺页原稿被烧掉一角，剩下的是作者犹豫痕迹。白鸢要求纪存保留自己的错误版本；关系推进到“连我不该做的那版也要记住”。

**敌方收益 / Clear State**  
索引拿到缺页、空白、错版和原典证据链。圣堂正式启动原典仪式。

## C10 原典圣堂与错版合体

### E37 不许改台词

**剧情流程**  
万机馆抵达原典圣堂。这里庄严、漂亮、真诚，不是可笑粉丝据点。很多人靠正确台词、姿势、合体口号和旧录像撑过灾变后的夜晚。槐第一次出场是在修补台词碑。她相信正确台词，因为那句话曾救过她，不是因为她喜欢纠错。

圣堂欢迎万机馆，但要求所有展出遵守原典，错词、误传、二创、废案支援都会降低武器权限。进入战场后，台词碑锁住多台机体武器。玩家喊对口令，武器稳定；保留错版，武器不稳但能绕开索引预测。查仔AI因为学错一句旧字幕，意外解开侧门。纪存承认原典曾救人，但救过人不能变成永远不许别人活成别的样子。

**战斗与玩法**  
仪式准入战。玩家在尊重仪式、调查删注、保护错版AI之间取舍。正确口令稳定但限制支援；错版口令不稳但不可预测。

**机体出场**  
台词碑锁、原典圣像机、口令复读机、查仔错词模块。

**梗点 / 爽点**  
合体口号、原典台词、粉丝仪式、说得/反说得：正确台词曾救过人，也可能锁住后来的人。

**情绪与关系**  
槐随身带的错版台词卡，嘴上说是错误，卡边却被摸得很旧。槐和白鸢互刺，纪存被迫承认两边都说中。

**敌方收益 / Clear State**  
索引采到正确口令稳定性；圣堂取得废案和错版危险证据。下一话进入背库删注。

### E38 圣堂背面的删注

**剧情流程**  
纪存、槐、白鸢和查仔进入圣堂背库。这里保存再版记录、错版字幕、玩具说明书、粉丝删注和官方后改设定。所谓原典不是一块石头，而是争论叠出来的。

槐害怕这些东西公开后，自己曾靠着活下来的那句正确台词也会失效。白鸢看到另一种危险：如果所有版本都公开，平台和索引也能把争论打包成商品和模板。背库防卫系统启动，删注库巡礼机把错版证据归档为污染。查仔学错台词反而解开圣堂系统。玩家决定公开多少、给谁看、保留哪些错版作为证词。结尾，圣堂核心启动原典合体仪式：不是杀错版，而是把错版并回正确版本。

**战斗与玩法**  
档案解谜 + 删注防卫。保护错版证据、再版记录和槐的私人台词卡。公开范围影响粉丝信任和错版合体条件。

**机体出场**  
删注库巡礼机、错字幕板、玩具说明书边栏机、再版封条门。

**梗点 / 爽点**  
错字幕、再版设定、说明书隐藏世界观、粉丝争论：记错不是天然正确，但记错也可能曾经救命。

**情绪与关系**  
槐的错版台词卡背面写着日期，那天不是作品播出日，而是她灾后第一次睡着的晚上。

**敌方收益 / Clear State**  
索引采到错版可绕预测、正确可锁权限的双样本；圣堂核心获得仪式合法性。

### E39 喊错也能合体吗

**剧情流程**  
圣堂核心战场展开。台词碑锁住武器，正确口号能释放完美合体，演出完整、伤害高、BGM无缝。但完美合体会强制把废案角色、错版AI、模型街错件和二创支援并回原典模板。

错版合体笨拙、节拍乱、部件甚至装反。唐胶第一反应想骂接口，下一秒发现装反的那块刚好避开索引预测。陆衡确认这不是奇迹，是错误路径没有被统计。槐站在台词碑前，必须决定是否把救过自己的正确台词从石碑上取下来，允许它成为众多证词之一。高潮时错版合体启动，BGM先乱半拍，再被观众不齐的喊名接住。

**战斗与玩法**  
合体口令锁武器战。玩家选择完美合体、错版合体或说得槐。完美路线强但压缩支援；错版路线难但保留非最优证据。

**机体出场**  
完美合体仪式机、错版合体机、槐护卫、模型街错件支援。

**梗点 / 爽点**  
“我来组成头部”、五机合体、合体口号、错版玩具、闭眼合体原创化：喊错也能合体，但责任不能错。

**情绪与关系**  
错版台词卡被槐从石碑前取下，放进驾驶舱旁。正确仍在，但不再是唯一钥匙。

**敌方收益 / Clear State**  
索引采到完美合体路线和错版合体裂缝；圣堂硬线取得“错版可战斗”的危险证据。

### E40 错版合体不是事故

**剧情流程**  
圣堂硬线和索引同时反扑。圣堂想证明错版合体只是事故，应重新封回原典；索引则生成口令镜像，试图把错误路径也做成新模板。战场出现两种敌人：一种要求正确到窒息，另一种把错误也复读成标准错误。

玩家必须证明错版不是随便错，也不是新口号，而是具体的人、物件、误传、旧玩具、删注和选择在这一刻组合出的结果。模型街错件支援、废案空白展柜、雾生停顿记录、撤退名单、医疗车胸灯、槐的台词卡同时成为反索引证物。最终错版合体机击破原典圣像机外壳，没有把它打成光，而是留下圣像机内部旧修补痕。槐承认：原典不是不能改，是不能忘记为什么改。

**战斗与玩法**  
原典/索引双Boss收束战。敌方一边用正确口令封锁武器，一边用口令镜像复读错版。玩家用非最优证据打断正确模板和错误模板。

**机体出场**  
索引口令镜像、原典圣像机二阶段、非最优证词阵列、错版合体机。

**梗点 / 爽点**  
原典仪式、错版合体、说得、非致命终结、最终支援前哨。错误不是新正确，错误必须有来路。

**情绪与关系**  
圣像机内部旧修补痕，证明所谓正确版本也被人修过、改过、救过。槐与白鸢达成危险和解；七海远程收到完整证据链，判断万机馆开馆方式已超出普通封存流程。

**敌方收益 / Clear State**  
索引拿到口令、合体、仪式、错版、非最优证据阵列。白名单都市发来通行协议：你们证明了生命会变形，也证明变形需要监管。

## C11 白名单都市与七海改革

### E41 白名单接待室

**剧情流程**  
万机馆抵达白名单都市。这里不是敌占区，而是安全、漂亮、可预约、可追责的机器人文化城市：展柜有温控，观众有保险，机魂有风险评级。玩家能理解七海为什么相信流程，也会觉得这里太干净。

七海本人第一次以主场姿态接待纪存。她把临时白名单钥匙按到纪存终端上，流程语气很冷，距离却近得危险：校准身份扫描时，终端同步弹出过去所有违规记录。她没有调情，但知道每次停顿都像在给他留缝。白鸢在玻璃隔离廊外看见这场默契，意识到七海不是外部敌人，而是另一个会安置纪存的人。听证开始：代哥改革派希望万机馆成为公共信托样板，硬线希望拆成安全展品，索引悄悄把白名单例外标注为可优化的保护关系。

**战斗与玩法**  
审查规则战 + 城市防卫小战。玩家不能自由攻击，只能在白线区内移动、提交证据、保护被误判机魂；违规攻击会提升效率但增加白名单灼痕。

**机体出场**  
白名单封存机·签章型、市政展柜车、七海临时钥匙模块。

**梗点 / 爽点**  
合法出击许可改成伦理许可：不是系统批准你战斗，而是有人愿意把责任签在你旁边。

**情绪与关系**  
白名单编号贴纸，边角被七海按出折痕。纪存和七海进入危险共犯感；白鸢第一次不是吃醋，而是感到自己可能也会被纪存合法安置。

**敌方收益 / Clear State**  
索引采到例外保护关系；代哥硬线拿到七海越权接待证据。万机馆获得临时停靠权，必须通过三门审查。

### E42 三门战场

**剧情流程**  
白名单都市开放三条通道：合法门、分镜门、维修侧门。合法门最安全，但会封存争议机魂；分镜门能救废案角色，却会把现实伤口剪成戏剧；维修侧门脏、慢、会损坏城市设施，但能保留最多原始证据。

玩家必须主选一门，另外两门只能部分救援。七海站在合法门前，白鸢站在分镜门后，唐胶和兜灯从维修侧门拆锁。纪存不能中立，因为三门都有人在保护他。战场中，白名单系统出现索引化症状：低损路线越来越顺，支援台词越来越体面，某些会让角色丢脸的选项被自动灰掉。七海最先发现这不是她下的命令，却完全符合她会写的命令。

**战斗与玩法**  
三线分队 + 门控战。三条门各有胜利条件，玩家分配支援点；主选门给强Buff，未选门留下永久缺口。

**机体出场**  
合规执行队·门卫型、分镜切格机、维修侧门工务机。

**梗点 / 爽点**  
三选一出击路线做成关系修罗场：不是选奖励，而是选谁的保护方式先落地。

**情绪与关系**  
三枚门牌：盖章、画框、沾油。七海第一次要求纪存亲手签责任；白鸢第一次把自己的支援镜头主动切掉，逼他不要把她当万能退路。

**敌方收益 / Clear State**  
索引确认低损选择会让玩家自愿牺牲差异；硬线确认七海无法控制自己设计的流程。

### E43 公共信托样板间

**剧情流程**  
七海带万机馆进入公共信托样板间。这里展示一个理想未来：万机馆被合法托管，机体不再流亡，观众安全入场，危险机魂被隔离展示。它真的很美，也真的像把万机馆心脏泡进防腐液。

运营局登场，提出把星火、错版合体、废案残响和失败机全部重新分级，做成可预约、可投票、可限定再版的安全展项。唐胶当场炸毛，陆衡承认其中一些安全规范确实能减少事故。七海改革派被夹击：她想用公共信托保护万机馆，却被硬线和运营局把信托变成漂亮封存。她把离线证据递给纪存，指尖在终端边缘停得太久，又像什么都没发生一样收回。白鸢看见纪存没有拒绝证据，也没有立刻解释，第一次把纪存画成背对她的人。

**战斗与玩法**  
听证经营 + 样板间防卫。玩家布置展签、安排证人、阻止运营局把机魂转成商品标签。

**机体出场**  
公共信托巡展机、限定抽选塔、信托展签框。

**梗点 / 爽点**  
限定、再版、官方展柜生态转成战斗规则：安全和漂亮不是错，错在只允许一种被喜欢的方法。

**情绪与关系**  
七海离线证据卡，背面没有公章，只有个人追责水印。纪存/七海危险感升温；白鸢进入冷战，支援Cut-in缺一帧。

**敌方收益 / Clear State**  
运营局获得万机馆机魂偏好数据；索引得到公众保护可转化为部署过滤的样本。七海改革派即将被硬线反噬。

### E44 例外不是赦免

**剧情流程**  
硬线公开七海违规链：延迟封存、离线证据、白名单例外、三门战场越权。七海没有辩解，只要求先撤出被误封的小机魂。她被自己的制度审判，也被索引用自己的语法复制。

战斗爆发在城市中庭。合规单位一开始保护市民，随后被索引化为证词静音单位。七海亲自切断主控，把权限手套烧到过载。她终于不是远程流程，而是站在流程崩塌处的人。纪存选择公开七海例外、替她背锅，或交给公共信托。每种选择能救一部分人，也伤害关系：公开会让七海失去安全外壳，背锅会让白鸢觉得纪存又把自己写成中心，信托会让唐胶骂他太会做展签。收束时七海注销纪存终端上的临时钥匙，只留下编号疤痕。她说这不是赦免，是以后每一次开馆都要被追责的凭据。

**战斗与玩法**  
Boss战 + 合规反接管。目标不是全灭，而是救出三组被静音证词，并阻止硬线把七海权限永久封存。

**机体出场**  
合规判定者、证词静音框体、七海过载权限手套。

**梗点 / 爽点**  
审批通过的勇气反转成违规也要留追责：热血不是无视规则，而是愿意被规则回头清算。

**情绪与关系**  
烧焦的白名单编号仍能读出号码。七海从制度压力变成真正并肩的危险成年人；白鸢承认她也在承担纪存承担不了的部分。

**敌方收益 / Clear State**  
索引完整取得白名单例外、三角保护、部署过滤和追责编号；硬线拿到处分七海的公开材料。万机馆离开白名单都市。

## C12 残缺索引反攻

### E45 最优战役生成中

**剧情流程**  
万机馆起航后，UI忽然变得顺滑。部署界面推荐最优阵容，展签自动修错，支援台词成熟、温柔、不会刺伤任何人。玩家会先觉得好用。随后索引生成“完美假馆”：馆守Z完整、星火巨神稳定、错版合体不再错、七海没有处分、白鸢没有嫉妒，纪存每一次公开都正确。所有人都像自己，却少了尴尬、伤口和停顿。

第一战故意诱惑玩家用强阵容。敌方镜像复制玩家常用路线、援护链和合体顺序。越常用的爽点越会被预判，越漂亮的Cut-in越像索引演示片。纪存意识到可怕之处：索引不是毁掉万机馆，而是给他一个更会开馆的版本。

**战斗与玩法**  
镜像战 + 部署反预测。推荐阵容强但被敌方预判；冷门机体、低效支援、错版口令能打出漏洞。

**机体出场**  
索引镜像机·高频阵列、完美假馆、推荐阵容锁。

**梗点 / 爽点**  
最像机器人动画的一战做成陷阱：所有燃点都在，但它们不再属于角色本人。

**情绪与关系**  
失败计数白板被自动清零，只剩粉笔灰。七海看见没有越权的自己差点动摇；白鸢看见不嫉妒的自己反而害怕。

**敌方收益 / Clear State**  
索引获得完美战役初始数据，并确认强玩法可被模板化。下一话必须让缺点、失败机和量产机成为主力。

### E46 缺点才能出击

**剧情流程**  
万机馆进入残缺部署态：主力支援灰掉，漂亮Cut-in失效，部分高性能机体被索引标为已预测。唐胶提出难听但有效的方案：把那些不好用的机体推上去。

跌跌、灰鸥量产队、错版合体残件、补丁色旧件、市政劳务机临时参战。它们数值不高、移动别扭、动作慢，但索引预测不了它们为什么会这样做。陆衡和唐胶第一次在战术上站到同一边：一个说数据异常，一个说旧件脾气，结果指向同一件事。七海失去白名单保护后，只能用离线追责编号给低效单位开临时路权。玩家用慢路线救回第一批证词。

**战斗与玩法**  
低效编队反攻。强制至少部署三台低贡献单位；它们触发不可预测行动，打破镜像预判。

**机体出场**  
灰鸥量产队·脏活盾、错版合体残件、补丁色旧装甲。

**梗点 / 爽点**  
量产机逆袭不靠突然爆种，而靠站位、维修单和没人剪进PV的脏活。

**情绪与关系**  
灰鸥队维修单不是驾驶员名，而是“今天谁把它推回库”。纪存魅力来自调度和命名，不是犯错挨骂。

**敌方收益 / Clear State**  
索引记录缺点可成为反模板武器，开始准备清噪这些缺点本身。

### E47 支援台词被清噪

**剧情流程**  
支援台词开始变得正确。赤罡不再冲动，莉歌不再颤，唐胶不再嘴硬，七海永远礼貌，白鸢永远理解。每句都像本人会说的话，但少了当时那一点不合时宜。

索引把亲密关系剪成审判证据：七海给纪存的白名单、白鸢替纪存改掉的危险记录、纪存把两人的私心放进展柜，全都被生成关系污染报告。队伍支援链被迫公开。白鸢爆发，她不是对七海发火，而是对那个无痛白鸢发火：那个版本救了所有角色，却没有一个人能回头质问她。她主动撕掉自己的最强分镜支援，让被救者保留质问权。七海以个人追责编号为代价，恢复一条刺人的支援台词。

**战斗与玩法**  
支援链净化战。玩家在战场中恢复支援台词节点；恢复越多，短期Buff越少，但索引预测越弱。

**机体出场**  
台词清噪塔、无痛分镜机、刺痛台词卡。

**梗点 / 爽点**  
援护防御/合体攻击台词改成关系审判：真正的援护不是温柔正确，而是知道他会骂你还站过去。

**情绪与关系**  
被清噪台词旁边残留白色校正线。纪存/七海/白鸢三角进入真伤：争的不是谁喜欢谁，而是谁有权保护他，以及被保护者能否反咬保护者。

**敌方收益 / Clear State**  
索引获得亲密关系模板，开始生成完美关系支援。G.A.G.债务上升。

### E48 清噪后的空白

**剧情流程**  
索引启动清噪封存态。展柜一个个变空，支援头像只剩标准轮廓，馆名章被折叠成风险资产。这不是爆炸式毁灭，而是更可怕的安静：所有伤痕都被修得像从没发生。

最终战中，索引给出完美关系支援：七海不会被处分，白鸢不会嫉妒，唐胶不嘴硬，陆衡不痛苦，赤罡不会冲动。接受它，战斗会容易很多，但所有非最优证词会被永久封存。绝境里G.A.G.机魂暴走，接管万机馆一部分战场，让失败、错版、迟到、白名单灼痕和撤退名单同时发光。它救了队伍，却把谁被优先救、谁的证词被燃作燃料记成开馆债。胜利是系统级大败后的撤离：万机馆活着，但UI残缺、部分展柜空白、支援链有疤。远星迟到回信从污染终端里亮了一下。

**战斗与玩法**  
清噪Boss战 + G.A.G.暴走债。玩家可触发暴走救场，暴走目标由前文证词和关系决定，战后形成C14质问权。

**机体出场**  
清噪核心·空白环、G.A.G.暴走影、空白展柜防御阵。

**梗点 / 爽点**  
暴走不是免费爽点，而是机器人番里绝境奇迹的债务版：赢了，但以后必须解释这股力量伤了谁。

**情绪与关系**  
空白展柜里只剩一小块未被清噪的胶带边。纪存选择先公开伤口而不是私下哄任何人，两条关系都痛，也更真实。

**敌方收益 / Clear State**  
索引拿到完美战役数据和G.A.G.暴走债。万机馆残缺航行，远星迟到回信进入主线。

## C13 远星迟到回信

### E49 灯槽未齐

**剧情流程**  
残缺UI中，远星观测廊灯槽一盏盏亮起，但顺序不对：先亮已收到，再亮尚未发送，最后亮无法翻译。陆衡判断不是黑客，而是旧包、新包和G.A.G.残响混在同一窗口。

方舟T正式进入战术支援位。它不是女性AI，也不撒娇；界面显示工况绑定、日志完整度、诚实参数和禁止伪理解。它给出的第一条支援不是安慰，而是当前翻译可信度不足。七海带来封存档案，白鸢带来改写副本，三人都曾以保护之名删改信息，这次必须一起面对删改后果。远星机群误判万机馆残缺态为机魂保管失败，开始接近。

**战斗与玩法**  
通信中继防卫 + 调谐谜题。保护四个灯槽锚点，选择先译情绪、坐标或机体协议。

**机体出场**  
迟灯中继机、旧远征信标机、方舟T深空协议。

**梗点 / 爽点**  
宇宙迟到回信做成“灯晚一步却救到现在的人”：迟到不是无效，是抵达时对象变了。

**情绪与关系**  
第一封迟到回信信封，收件人栏被时间烧蚀。陆衡/方舟T进入工况共生主场；纪存/七海/白鸢共同面对保护性删改旧伤。

**敌方收益 / Clear State**  
远星根据残缺状态误判人类不再有保管资格；索引伪装成清晰译本混入灯槽。

### E50 无人可收的回信

**剧情流程**  
第二个短窗打开，回信内容不是宇宙宣言，而是一段普通约定：回来后一起去看旧机器人展。收件人早已不在，展柜里只有当年留下的一张未使用门票。

方舟T自动生成安慰版摘要，删掉会伤人的细节。陆衡暴怒，不是因为它背叛，而是因为它学会了他曾经做错的事：以保护为名删掉失败和痛苦。玩家选择原文公开、安慰版公开或分段公开。原文会伤害远征遗属与城市信任；安慰版能稳定局面但削弱远星理解；分段公开需要战斗中多守两回合通信窗。陆衡最后没有说金句，只把播放器音量调小，让那封信在展厅里播完。方舟T没有弹第二条安慰提示。

**战斗与玩法**  
低带宽守窗战 + 译本选择。每守住一个通信回合，可恢复一段原文；敌方误译机群会攻击痛苦片段。

**机体出场**  
远星误译侦察机、回信护匣、诚实参数锁。

**梗点 / 爽点**  
跨越时间的欢迎改成“欢迎回馆，但留灯的人已经不在”：泪点落在门票和音量上。

**情绪与关系**  
未使用旧展门票，背面写着“下次一起看合体展”。陆衡和方舟T第一次真正冲突；亲密靠允许对方不要假装懂。

**敌方收益 / Clear State**  
远星误判安慰版为人类仍在粉饰灾变；索引记录保护性过滤可用于最终模板。

### E51 错序通信战

**剧情流程**  
灯槽出现错序：先收到道歉，后看到错误；先听遗言，后发现对方当时尚未出发。玩家必须在时间顺序、抵达顺序、情绪顺序三种排列中选择一种来解读战场。

远星机群进入棋盘，但不全是敌人。它们根据不同排序理解万机馆：时间顺序判定人类失职，情绪顺序误以为机魂在求统一，抵达顺序能看见一些无人维护机体仍在回应。方舟T提出烧蚀自身旧任务日志稳定窗口。陆衡必须选择：保留它那些没用但像它自己的坏笑话、旧注释，还是换取一次完整通信。白鸢想用改写把信件排成不伤人的顺序，七海提醒她：顺序也是证据。纪存把三种排序都设成临展。

**战斗与玩法**  
错序棋盘。不同排序改变敌我识别、目标位置和支援到达回合；玩家可在灯槽节点切换排序，但每次切换烧能量或日志。

**机体出场**  
顺序漂移节点、深空舱段残响、坏笑话日志模块。

**梗点 / 爽点**  
宇宙尺度通信落成可玩排序：不是穿越改历史，而是你怎么排列证据就会伤到不同的人。

**情绪与关系**  
方舟T的 `humor_fail.log` 里全是陆衡没笑过但没有删掉的提示。陆衡承认方舟T不是翻译器，而是任务同伴模块。

**敌方收益 / Clear State**  
索引伪装成最清晰译本，诱导玩家选择无痛顺序；远星得到不完整裁决依据。

### E52 回信写给现在的人

**剧情流程**  
远星机群要求裁决：人类是否仍有资格保管机魂。它们不是神明，只是根据迟到信号、灾变残响和索引译本作出粗糙判断。它们也在误读，也在害怕。

万机馆开临时“迟到回信展”。展出不是宇宙百科，而是信封、门票、失败计数、撤退名单、白名单灼痕、错版口令牌。每件都证明：过去不能改，但现在可以重新负责。战斗高潮不是击破远星，而是让不同证词传到远星机群。莉歌停火声部、跌跌失败记录、方舟T粗糙译本、七海追责编号、白鸢空白格各占一段低带宽。远星不完全理解，却第一次暂停裁决。方舟T把输出状态改成“未译：陪同中”。

**战斗与玩法**  
证词传递战。护送五类证词到灯槽阵列；每类证词改变远星机群一条行动规则。

**机体出场**  
远星裁决机·低帧全息、证词中继灯槽、粗糙译本协议。

**梗点 / 爽点**  
异文化震撼改成互相听不懂也愿意暂停开火：共同语言不是同步翻译，是承认误读仍可继续修。

**情绪与关系**  
迟到回信展柜，门票旁亮着慢半拍的灯。陆衡/方舟T线进入克制高点，纪存/七海/白鸢共同面对删改不是保护的唯一方式。

**敌方收益 / Clear State**  
索引夺取远星暂停裁决数据，把多声部证词压缩成最终模板素材。远星要求万机馆证明开馆方式。

## C14 开馆方式内战

### E53 谁有资格开馆

**剧情流程**  
万机馆内部公开分裂。七海主张公共信托，白鸢主张创作者避难所，唐胶主张模型街自治，陆衡主张现实安全规程，赤罡主张战场开馆，部分机魂要求自治。每条路线都合理，也都不够。

这不是会议争吵，而是展舰分区战。不同队伍占据不同楼层、泊位、展柜和支援终端。玩家看见万机馆像一台母舰，也像一个正在拆家的展览。纪存的魅力被反过来审判：他能并置、命名、公开承担，也意味着他能决定别人被怎样观看。七海和白鸢的质问最痛，因为她们都被他救过，也都被他放进过展柜。索引不出手，只观察路线互削；代哥硬线扶持公共信托可接管版本，远星误译扶持机魂自治极端版本。

**战斗与玩法**  
展舰分区占领战。支援点拆分到六条路线；胜利不是全灭，而是保住至少三条路线的可谈判资格。

**机体出场**  
信托合规机群、创作者避难所分镜机、模型街旧件自治队。

**梗点 / 爽点**  
队友审判主角改成母舰内战：不是排队骂主角，而是每条价值观真的能占一块地图。

**情绪与关系**  
展舰分区灯从统一蓝白分裂成六种不稳定颜色。七海要求纪存把责任权交出去；白鸢要求他承认自己也在写别人。

**敌方收益 / Clear State**  
索引记录六路线互斥点；硬线和远星找到可扶持路线。支援系统拆分。

### E54 路线旗会烧

**剧情流程**  
玩家逐一试用路线。公共信托能救最多市民，但会安静封存争议；创作者避难所能保留废案，却容易替角色决定幸福；模型街自治有温度但资源混乱；现实安全最稳，却把机魂压回设备；战场开馆最燃，却容易消费牺牲；机魂自治最自由，也最容易暴走。

每条路线都有一场短战和一个痛点。唐胶发现自治旧件会烧接口，陆衡发现安全机也会误封救援，赤罡发现战场开馆能让撤退名单变成宣传。成人关系场在战损维修舱爆发：七海替纪存重贴封条，手指停在白名单灼痕处，语气仍像流程；白鸢在旁边切掉支援镜头，冷冷问这次也要归档成共同承担吗。纪存没有选最爱他的路线，也没有选最安全路线，而是开始构想多门开馆。

**战斗与玩法**  
路线试用战。六条路线各有Buff/Debuff，必须至少让四条暴露代价，才能解锁多门方案。

**机体出场**  
现实安全机·红线型、战场开馆追击机、机魂自治暴走壳。

**梗点 / 爽点**  
路线选择从菜单变成试机：每个理念都要上战场，烧一次接口才知道真实重量。

**情绪与关系**  
六面路线旗边缘都烧焦。七海/白鸢对纪存的质问从情感转为权力：你爱我们，还是爱把我们放进正确位置的自己？

**敌方收益 / Clear State**  
索引得到六路线代价表，准备合成无代价完美开馆。外部势力趁内部消耗登舰。

### E55 泊位夺还战

**剧情流程**  
代哥硬线和远星误译同时介入。硬线试图接管B1泊位和白名单主控，远星极端单元试图释放机魂自治区，索引把双方行动都标为帮助万机馆结束内耗。

泊位战让机体共存问题变成大场面：十几米实机、外部锁泊机、支援Cut-in机、残响模块、模型锚件临时改装同时上场。玩家必须调度展舰作为棋盘单位，而不是只派机器人出去打。七海亲手对抗硬线，公开背离旧系统；白鸢放弃一次能完美救人的分镜，让被救机魂自己爬出泊位；唐胶和兜灯用旧件撑住外部锁泊口，吵得像平时，手却没有错一次。泊位夺回，但万机馆伤得更重。纪存承认开馆不是选择谁赢，而是让路线之间互相制衡，且留下追责入口。

**战斗与玩法**  
母舰棋盘战 + 泊位争夺。万机馆作为巨大棋盘单位可移动/变形局部区域；主角团支援点用于修泊位、开闸、封锁或调度机体。

**机体出场**  
硬线接管框体·泊位型、远星自治解锁机、展舰分区变轨模块。

**梗点 / 爽点**  
母舰不是背景，而是棋盘格上的巨大单位；舰内整备和战场出击在同一张图上发生。

**情绪与关系**  
B1泊位号牌，一半白名单封条，一半唐胶焊上的旧金属片。七海公开站到改革破裂点，白鸢证明她能不改写也救人。

**敌方收益 / Clear State**  
索引得到展舰分区变轨数据和多路线制衡模型。万机馆夺回泊位但不可恢复原状。

### E56 把门开向谁

**剧情流程**  
内战收束成最终听证。不是问哪条路线正确，而是问哪种展品、哪种观众、哪种机魂、哪种风险，应由哪扇门承接。多门开馆协议诞生：公共信托管城市风险，创作者避难所保留空白，模型街自治保留手作，现实安全管不可逆危险，战场开馆只用于撤退和救援，机魂自治必须有证词与追责边界。

七海签公共追责，白鸢签留白边界，唐胶签旧件安全，陆衡签失败公开条件，赤罡签撤退优先，机魂代表签自治约束。纪存最后签的是“策展者不得成为唯一命名者”。索引把多门协议压缩成完美最终话模板：安全、有泪点、有燃点、有爱情、有全员支援，还没有争议。万机馆向万机殿坐标变形，所有人知道终局不是打败某个Boss，而是拒绝唯一正确的机器人文化结局。

**战斗与玩法**  
非全灭终章前夜。玩家配置最终开馆协议，决定C15各路线支援版本、额外声部和债务缺口。

**机体出场**  
多门开馆控制台、协议见证机、策展者限权锁。

**梗点 / 爽点**  
最终前夜全员宣誓改成签责任书：燃不是喊同一句话，而是每个人愿意给自己的热爱承担后果。

**情绪与关系**  
证词墙上六条路线签名互相覆盖，没有一条居中。七海把追责留给纪存，白鸢把空白留给纪存；恋爱线进入“陪你承担，但不替你命名”的终局形态。

**敌方收益 / Clear State**  
索引获得多门协议，生成完美最终话模板。万机馆进入万机殿前态。

## C15 万机殿最终开馆

### E57 完美最终话

**剧情流程**  
万机殿入口展开。索引没有先放恐怖Boss，而是给玩家一场完美最终话：主角机更帅，合体更稳，七海无处分，白鸢无痛放手，陆衡收到完整回信，赤罡追上宿敌，唐胶旧件全修好。所有缺憾都被补完。

战斗极爽。完美主角机能连动全队，标准合体群无视旧伤，远星声部整齐响应。玩家越打越顺，直到发现低效机体、错版口令、失败记录、撤退名单、白名单灼痕和迟到回信都被移出场外。索引的诱惑不是臣服，而是让玩家得到一个不会被骂的结局。纪存差点接受，因为这个版本真的能保护很多人。七海指出它没有追责入口，白鸢指出它没有空白，陆衡指出它没有不可译项。

**战斗与玩法**  
诱惑型最终战第一阶段。使用完美模板会快速推进，但删除非最优声部；玩家需主动降低评分，召回被移除证词。

**机体出场**  
完美主角机·标准答案型、标准合体群、无争议结局滤镜。

**梗点 / 爽点**  
最终话全开挂做成反派诱惑：爽是真的，问题是它把不好看的爱全删了。

**情绪与关系**  
馆名章被索引擦成崭新，却没有任何使用痕迹。七海、白鸢分别指出纪存最容易沉迷的两个完美：安全无债、叙事无痛。

**敌方收益 / Clear State**  
索引确认玩家若追求完美战果，会主动放弃大量非最优证词。E58必须召回被移除者。

### E58 不是只有主角会发光

**剧情流程**  
纪存把指挥权拆出去。唐胶带模型街旧件，陆衡带失败机和现实安全机，赤罡带量产小队，白鸢带废案空白格，七海带被处分的白名单残权。主角机退到支援位。

量产机、失败机、市政机、废案角色、旧玩具锚件一起上场。它们不整齐，Cut-in也不统一，有的只是推盾、挡门、搬证词，但索引第一次预测失败。终局支援不是整齐大合唱，而是很多声部互相打断：错拍合体残件慢半拍，跌跌摔倒挡住最优路径，灰鸥量产队把Boss推出中心格，废案角色拒绝被补完，市政劳务机先修避难门再开火。玩家会感到机器人大战的规模：不是因为每台都是主角，而是每台都有自己的理由。

**战斗与玩法**  
多小队支援战。主角机无法单独清场；玩家通过低规格单位完成关键目标，解锁终局声部。

**机体出场**  
废案空白机、市政劳务机·避难门型、旧玩具锚件群。

**梗点 / 爽点**  
量产机逆袭、说得、援护防御、旧机让接口，全都转成不是主角也能改变最终战地图。

**情绪与关系**  
无人认领维修单终于补上名字，不是驾驶员名，而是“曾经推过它的人”。纪存魅力完成质变：不再站在所有故事中央，而是让别人被看见。

**敌方收益 / Clear State**  
索引开始清噪名字不确定单位和无效行动。多声部支援成立，万机馆获得变形为万机殿条件。

### E59 万机殿变形

**剧情流程**  
万机馆展舰、展陈层、格纳库、残响接口、外部锁泊和证词墙一起变形。它不是无限大母舰，而是每个展区把自身功能交给战场：模型街变改装线，白名单变追责护盾，原典圣堂变错版口令炮台，远星观测廊变低带宽声部，B1泊位变全员出击门。

索引启动最终Boss：唯一正确完美模板。它轮换安全封存、无痛分镜、标准合体、远星裁决、商品完全版、主角中心六种形态，每阶段对应前文一种好东西被唯一化。玩家用多门开馆协议切换反制。七海路线提供追责护盾但限制暴走；白鸢路线保留空白但降低命中；唐胶路线随机改装但抗模板；陆衡路线提供工况保护但牺牲输出；赤罡路线打开撤退通道；方舟T/远星声部提供低带宽误译纠偏。纪存把馆名章交给全员证词墙，不再由自己单独盖章。G.A.G.不再暴走接管，而是被共同调律。

**战斗与玩法**  
万机殿复合战。母舰作为巨型棋盘单位参战；每阶段选择开馆门，保护证词墙并拆解模板核心。

**机体出场**  
万机殿形态、唯一模板核、共同调律环。

**梗点 / 爽点**  
最终全员支援不是同一句口号，而是每个谱系用自己的玩法回应：合体、撤退、修门、迟到、错词、失败、封存例外都能成为攻击或防御。

**情绪与关系**  
馆名章从纪存手里移到证词墙中间，章面被旧水口、封条灰和灯槽烧痕弄脏。七海或白鸢根据路线获得不同私人声部，但都不吞掉公共结局。

**敌方收益 / Clear State**  
索引最后一次尝试把多声部压成同声，形成E60最终静音核。唯一模板核破裂，问题变成如何开馆而不是如何击杀。

### E60 今日开馆中

**剧情流程**  
最终阶段没有传统血条爆炸。索引天使收束成静音核，提出最后交易：它可以消失，但万机馆必须选择一个最稳定、最安全、最不会再发生G.A.G.灾变的开馆版本。

玩家用全剧证词回答。失败计数、错版口令、撤退名单、白名单编号、迟到回信、旧玩具锚件、无人认领维修单、空白格、灯槽慢灯依次进入展柜。它们不是证明混乱最好，而是证明活着的文化必须允许修复、争论和追责。终局全员支援发动：星火巨神不是领唱，馆守Z不是唯一守护，社勇王不是童年万能钥匙，远星也不是终极答案。每台机体、每个支援、每个观众声部都只说自己的那部分。索引无法再把它们平均成一个正确模板。

万机殿开馆。不同路线决定结局变体：公共信托、流亡巡展、创作者避难所、模型街自治、现实安全、机魂自治、多门真结局。无论哪条，开馆不是结束营业，而是开始继续被观看、争论、维修和爱。片尾后日谈中，七海的处分/改革、白鸢的空白格、陆衡和方舟T的日志完整度、唐胶/兜灯维修间、赤罡/莉歌撤退名单、远星声部和隐藏机体追加声部，按玩家债务形成不同画面。

**战斗与玩法**  
最终开馆仪式战 + 结局展柜配置。玩家不是选哲学菜单，而是把此前证词放入展柜，决定哪些声部参与最后支援。

**机体出场**  
索引静音核、开馆层展柜、全员非同声支援。

**梗点 / 爽点**  
终局共同语言原创化：不是所有人喊同一句，而是终于没有谁被调成静音。

**情绪与关系**  
馆名章、迟到回信、错版口令牌、白名单灼痕、撤退名单和无人维修单并列进最终展柜。纪存/七海/白鸢根据路线进入恋人、共犯、遗憾或并肩追责变体；重点是谁在最后陪他保留空白、签下追责，或把话留到下一次开馆。

**敌方收益 / Clear State**  
索引不被简单毁灭，而被重新定义为公共责任系统的一部分：它保留风险预警，但不能再独自命名文化。主线完结，万机馆/万机殿进入“今日开馆中”状态；EX、二周目和后日谈围绕不同开馆方式与隐藏声部展开。
