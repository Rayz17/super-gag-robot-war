# 《超GAG机器人大战：万机残响》第一话角色深度小传与话术材料 v0.1

> 本文不是人物设定表，而是编剧和演员案头。目标是让第一话角色像“刚好活在万机馆这一晚的人”，不是替游戏框架讲话的标签。

## 1. 反 AI 味原则

上一版声音表仍有一个问题：它把角色说话方式整理得太干净。真实人物在压力下不会总是说完整观点；他们会绕开、会讲手边的东西、会把真话说错、会突然卡住。

第一话对白要遵守这些规则：

| 规则 | 说明 |
| --- | --- |
| 少说抽象名词 | 不说“记忆”“主体”“秩序”“后天合唱”，除非角色职业本来会这样说 |
| 多说手边物 | 茶杯、黄线、胶带、螺丝、展签、感叹号、袖口、封条 |
| 让角色误会 | 人物先按自己的旧经验误读事件，然后再被现场纠正 |
| 留半句话 | 重要情绪不说满，尤其是纪存、七海、馆长 |
| 让身体先说话 | 摸终端、擦零件、整理袖口、数纸条、抢工具，比解释更可信 |
| 不急着聪明 | 不是每句都要有信息量，也不是每个角色都要在同一场景里说对 |
| 梗要像习惯 | 梗点不是“现在抛一个机器人梗”，而是角色日常语言里自然带出来 |

对白判断：

> 如果这句话像预告片字幕、角色海报文案、章节主题句，删掉或打碎。  
> 如果这句话像某个人在低头做一件小事时顺嘴说出来，保留。

## 2. 纪存 / 玩家名

### 2.1 不是“主角”，而是值夜班的人

纪存在第一话里不应该像已经知道自己是世界真相钥匙的人。他更像一个熟悉展馆琐事的夜班档案员：知道哪盏灯容易坏，知道馆长喜欢把禁令写在便签背面，知道小满会把“滑行”当借口，也知道旧守护者的广播哪一句会把孩子吓跑。

他习惯把事情记下来，不是因为冷酷，而是因为“被记录过的东西比较不容易消失”。这个习惯已经深入到身体里：紧张时先找笔，听见怪声先看终端，看到别人哭会问“要不要先坐下”而不是“你怎么了”。

他不自认为温柔。他觉得自己只是负责把东西放回正确位置。

### 2.2 生活材料

- 档案室抽屉里有三支写不出字的笔，他一直没扔，因为馆长说“还能当镇纸”。
- 他会把展签贴得略微偏低，方便孩子读。别人指出时，他说是展柜灯反光问题。
- 他不爱关灯太快。每晚闭馆后会让主展厅多亮两分钟，理由是“旧投影机冷却慢”。
- 他会记得每个孩子最后一次留言的笔迹，但不承认自己认得出来。
- 他害怕空白表格。空白表格会让他觉得有东西还没被允许存在。

### 2.3 说话破绽

纪存会把情绪说成工作：

- “我记一下”其实是“我有点怕”。
- “这个先别删”其实是“我舍不得”。
- “等馆长回来再说”其实是“我不想一个人决定”。
- “流程上不合适”其实是“你这样会受伤”。

他最不像人的地方不是冷，而是过分相信“记录以后就能处理”。第一话要让玩家觉得这个习惯可靠，也隐约觉得不对。

### 2.4 第一话现场反应

| 刺激 | 第一反应 | 真正情绪 |
| --- | --- | --- |
| 馆长没回来 | 看杯子、看便签、确认时间 | 不安，但不想吓孩子 |
| 旧纸条署名像自己 | 想归档成普通留言 | 害怕自己早就来过 |
| 右臂残响 | 先摸终端，确认是否录音串线 | 害怕只有自己听见 |
| 黑展柜叫他 | 想退后，但职业本能让他查权限 | 恐惧和被需要感混在一起 |
| 七海删除未归档留言 | 沉默比反驳快 | 第一次意识到“没整理好”会真的害死东西 |

### 2.5 原生话术

- “先别贴，胶还没干。”
- “这条我没归档。不是忘了，是……还没找到该放哪。”
- “馆长的杯子还在。人不在，杯子倒挺守时。”
- “你别急着撕，我先拍一张。拍糊了也算。”
- “等一下，我刚才听见的不是广播。”
- “旧守护者，帮我查一下这段声音从哪个喇叭出来的。没有喇叭？那就更要查。”
- “小满，感叹号不算独立展品。两个也不算。”
- “七海小姐，你念清单的时候，能不能先别念孩子那面墙。”

## 3. 兜灯

### 3.1 她不是“傲娇整备”，她是怕手一松旧东西就会杀人

兜灯从小在馆守Z脚边长大。对别人来说，馆守Z是开祖合金英雄投射样本；对她来说，是一台会在雨天漏电、右臂接缝需要垫两层布、胸牌灯泡有一次把她烫哭的旧机器。

她对旧机体有很深的爱，但这份爱不是浪漫的。是拧螺丝、擦油、检查封条、熬夜听异响。她最讨厌别人说“这是传奇”，因为传奇不用负责维修，传奇也不用面对被它伤过的人。

她说话硬，是因为只要软下来，就会承认自己其实一直在替祖辈道歉。

### 3.2 生活材料

- 她在每个旧件背面写拆装日期，字体很小，像怕被人发现。
- 她讨厌白手套。觉得白手套是给参观用的，不是给修理用的。
- 她会把断掉的小螺丝收在糖盒里，糖盒外面写“不要吃，唐胶尤其不要”。
- 她知道馆守Z每一处异响的方位，但不知道怎么和人好好道谢。
- 她被吓到时会先骂机器，再骂人，最后骂自己。

### 3.3 说话破绽

兜灯从不直接说“我担心”。她会说：

- “手拿开。”
- “那块还没冷。”
- “你知道这个拆下来多麻烦吗？”
- “别站那个位置，右臂锁还没完全死。”

她亲近别人时，会允许对方靠近工具、靠近机体、靠近旧件。她最深的信任不是说“谢谢”，而是把一把扳手递过去。

### 3.4 第一话现场反应

| 刺激 | 第一反应 | 真正情绪 |
| --- | --- | --- |
| 唐胶挑水口 | 立刻反击 | 怕祖传旧件被当成玩具 |
| 纪存触碰右臂 | 下意识喊停 | 怕他被烫，也怕右臂回应他 |
| 七海叫展品资产 | 声音变冷，不再斗嘴 | 被人把家人写进清单 |
| 旧守护者安全锁解除 | 去看封条，不看脸 | 怕馆守Z再一次被迫战斗 |

### 3.5 原生话术

- “手拿开。不是脏，是烫。”
- “别用‘旧’那个语气说它。”
- “这块不能扔，背面有日期。谁写的我知道。”
- “唐胶，你再说水口，我让你今晚睡零件箱。”
- “它不是模型。模型坏了还能买补件，馆守Z坏了，补的是谁？”
- “右臂锁没死。它只是很久没醒。”
- “七海是吧？你清单上那串编号念错了。它不叫资产。”
- “纪存，别站胸牌下面。它亮的时候会掉灰。”

## 4. 唐胶

### 4.1 他不是“吐槽役”，他是用挑剔保护珍惜

唐胶嘴毒，是因为他从小见过太多人把玩具当成廉价东西，把孩子当成“长大就会忘”的东西。他的第一台旧模型被大人扔掉时，不是因为坏了，而是因为“占地方”。后来他学会修复，学会挑毛病，学会在别人还没嫌弃之前先嫌弃。

他真正看重的不是完美，是“有人摸过”。新件漂亮，但太干净；断件丑，但有手温。他讨厌官图，也讨厌收藏评级，因为那些东西容易把人的手从玩具上拿开。

### 4.2 生活材料

- 他的工具包里有一把缺口镊子，早该换了，但他说“夹旧件刚好”。
- 他闻得出补土和旧塑料的味道，会因此判断这件东西被谁修过。
- 他嘴上说“塑料就是塑料”，但给每个孩子的断件贴名。
- 他讨厌别人用“童年”两个字煽情。真有人煽情，他会去看水口。
- 他有一盒“暂时没用但不能扔”的零件，盒子已经满到盖不上。

### 4.3 说话破绽

唐胶越在乎，越会讲工艺细节。他不会说“这东西很珍贵”，他会说“这断口不是摔的，是拧的时候舍不得用力”。

他夸人很别扭：

- “不算太外行。”
- “你这次没把好东西弄成垃圾。”
- “手还行，脑子另说。”

### 4.4 第一话现场反应

| 刺激 | 第一反应 | 真正情绪 |
| --- | --- | --- |
| 兜灯护旧右臂 | 挑工艺问题 | 认可她在认真照顾旧物 |
| 孩子留言 | 嘴上嫌幼稚 | 记下孩子名字，准备后面修 |
| 七海要回收留言墙 | 第一次少话 | 他知道纸和塑料一样，没人护就会被当垃圾 |
| 黑展柜异常 | 不承认害怕，改查玻璃材质 | 用工艺判断压住灵异感 |

### 4.5 原生话术

- “别拿年份吓我。十年前的毛边也还是毛边。”
- “新件好看。好看到一眼就知道没人碰过。”
- “这断口不是摔的。是拧的时候心疼，手软了。”
- “别扔。没用和以后没用是两回事。”
- “小满那个感叹号贴歪了。算了，先别动，他贴得挺用力。”
- “七海小姐，你们回收纸条按重量算吗？这面墙不重，但麻烦你搬的时候轻点。”
- “纪存，你别用那种要写报告的眼神看裂纹。裂纹会害羞。”
- “我不是舍不得。我是讨厌浪费。尤其讨厌浪费别人舍不得的东西。”

## 5. 旧守护者

### 5.1 它不是“萌AI”，它是坏掉的规则还在努力照顾人

旧守护者的语言来自展馆广播、安全规范、观众管理和旧式服务 AI。它不懂“爱”，但懂“观众离开前要检查遗失物”；不懂“家”，但懂“闭馆后仍有儿童滞留时不得断电”。

它的感人之处不是突然像人，而是规则在极端情况下弯了一下。那一下很小：把“禁止奔跑”改成“可以跟紧本机”；把“展品不得移动”改成“观众优先”；把“旧守护者无自主权”改成“本机正在闭馆”。

### 5.2 生活材料

- 它会记录孩子身高，因为围栏高度要调整。
- 它会提醒观众带走雨伞，也会把没人认领的雨伞按颜色排好。
- 它把馆长偷吃饼干记录为“食品去向异常”。
- 它记不住第0次闭馆，但每晚都像在补那次错。
- 它会误把“迷路的大人”也归入观众照护。

### 5.3 说话破绽

旧守护者不能说“我害怕”。它会说：

- “本机记录缺失。”
- “建议忽略该异常。”
- “当前流程不支持此结果。”
- “观众仍在馆内。”

它的亲密感来自错误分类：把七海识别成迷路观众，把纪存识别成临时负责人，把跌跌识别成“低速儿童”。

### 5.4 第一话现场反应

| 刺激 | 第一反应 | 真正情绪 |
| --- | --- | --- |
| 小满跑动 | 纠正速度和分类 | 它一直在看孩子 |
| 黑展柜异常 | 建议忽略 | 它知道危险但说不出为什么 |
| 七海授权 | 重复闭馆流程 | 用旧规则对抗新权限 |
| 法务机兵进馆 | 改写优先级 | 从展品规则转向保护观众 |

### 5.5 原生话术

- “请将恐慌移动至黄线外。”
- “小满未奔跑。小满正在以奔跑速度否认奔跑。”
- “馆长不在。馆长杯具仍在。该组合不常见。”
- “建议忽略0号展柜。建议来源：记录缺失。”
- “闭馆流程未包含移交观众。”
- “七海女士，您当前站位属于迷路观众高发区域。”
- “请勿奔跑。但可以跟紧本机。”
- “本机正在闭馆。请外部许可明日再来。”

## 6. 七海

### 6.1 她不是“优雅反派”，她是把事故现场写进表格后活下来的人

七海见过自由机魂失控后的现场。她不把那些回忆讲成故事，因为故事会让人激动，激动会让人忘记风险。她把它们写成表格、封存等级、授权链、事故复盘。她的礼貌不是修养而已，是控制局面的工具。

她不是讨厌万机馆。她讨厌的是万机馆这种地方总能让人忘记事故发生时有多难看。她尤其警惕纪存，因为纪存看起来像一个愿意为了“留下”而推迟“处理”的人。

### 6.2 生活材料

- 她的袖口永远平整，压力越大越会整理袖口。
- 她不喜欢喝热茶，怕手抖时被人看出来。
- 她念清单前会确认每个名字的发音，哪怕她要删除它。
- 她不会说“我害怕”，会说“风险不可接受”。
- 她给自己保留了一份白名单，文件名不是“私心”，而是“延期复核”。

### 6.3 说话破绽

七海说话像流程，但偶尔会露出人：

- 如果她称呼“纪存先生”，她在谈判。
- 如果她称呼“临时策展人”，她在施压。
- 如果她停顿后改称“你”，她被刺到了。
- 如果她说“我理解”，多数时候是“我不同意，但我知道你为什么会这么做”。

她的残酷不应该写成威胁，而应该写成流程已经开始，情绪没有入口。

### 6.4 第一话现场反应

| 刺激 | 第一反应 | 真正情绪 |
| --- | --- | --- |
| 旧守护者重复闭馆 | 纠正访问性质 | 她不想被展馆语言拉进“观众”位置 |
| 孩子问留言是否资产 | 认真回答 | 她认为谎言比残酷更危险 |
| 纪存要求别念留言墙 | 停顿半秒 | 她知道那面墙不是普通资产 |
| 黑展柜说话 | 第一次沉默 | 她确认风险比授权文件写得更深 |

### 6.5 原生话术

- “你可以拒绝签收。回收不需要签收。”
- “我念清单，是因为后来一定会有人问，为什么没人通知。”
- “纸质留言可以拍照留档。前提是你们不要把它们挡在封存路径上。”
- “临时策展人，你现在保护的是证据，不是孩子。”
- “我知道这句话难听。所以我放在流程后面说。”
- “报告上不会写小满。报告上写未成年人一名。”
- “别急着恨我。等流程走完，你会有更完整的理由。”
- “0号展柜立刻移交。不是请求。请求已经在三年前被驳回了。”

## 7. 馆长

### 7.1 他不是“谜语人”，他是一个把真相拖到来不及的人

馆长最危险的习惯是拖延。他拖延修漏水，拖延更换展签，拖延告诉纪存真相。他总能把拖延说得像幽默，像生活智慧，像“明天再说也来得及”。第一话录音里，他仍然在拖：先说闭馆照常，先说孩子，先开玩笑，最后才说0号展柜。

他的罪不是不知道，而是知道太多以后，把别人当成还不能知道的人。

### 7.2 生活材料

- 他喝茶总剩一口，因为“杯底那口最像今天”。
- 他在便签上写禁令，但经常写在背面。
- 他喜欢说“明天再修”，但有些东西已经没有明天。
- 他偷吃孩子饼干，会留下同口味的两包补回去。
- 他把最危险的钥匙放在最普通的旧票夹里。

### 7.3 说话破绽

馆长越亏欠，越家常：

- “先别急。”
- “你又要皱眉了。”
- “这事明天……算了，不能明天。”
- “如果我没回来，先把灯关好。”

他不能总说谜语。谜语要少，生活细节要多；这样真相来时才像被一个熟人背叛。

### 7.4 第一话录音材料

- “纪存，别把这段转文字。你一转文字就会装没听懂。”
- “如果我没回来，先把东侧走廊那盏灯关了。它闪一天了，我知道，你不用在报告里骂我。”
- “旧守护者会说自己不需要滤网。它说的不算。”
- “0号展柜今晚别开。不是坏了，是太像没坏。”
- “清算部如果来，别和他们比谁更有道理。他们带来的就是道理。”
- “你要是真听见里面有人叫你，先别答应。你这孩子，别人一叫你帮忙，你就忘了自己站哪边。”
- “还有，留言墙……算了，这句来不及了。”

## 8. 小满

### 8.1 他不是“吵闹小孩”，他是在用吵闹证明这里还安全

小满在万机馆里长大一截。他知道哪里能跑，哪里不能跑；知道旧守护者什么时候只是广播，什么时候真的生气。他越害怕越吵，因为安静意味着大人开始说他听不懂的话。

他把世界理解成贴纸、感叹号、谁最强、谁有没有偷吃饼干。清算部来时，他不会理解“资产回收”，他只会理解“我贴的东西要被撕掉”。

### 8.2 生活材料

- 他会把留言贴得很高，好像高一点就不容易被大人撕掉。
- 他认为感叹号可以单独表达战斗力。
- 他给馆守Z偷偷贴过“今天也很强”的纸条，被兜灯发现后罚擦围栏。
- 他不知道“统计学”是什么意思，但喜欢用这个词。
- 他害怕时会摸口袋里的废票根。

### 8.3 原生话术

- “我没有跑，我是在让鞋先过去。”
- “那我把感叹号撕下来藏口袋里，算不算已经保存？”
- “旧守护者，你刚才那句不是平时的广播。”
- “纪存哥，如果他们删掉留言，墙会不会变轻？”
- “我可以不哭，但你们别关灯。”
- “社勇王最强还没写完，少三个感叹号不算最强。”

## 9. 阿澄

### 9.1 她不是“懂事小孩”，她是太早学会从细节判断大人有没有事

阿澄比小满安静，也更早懂得万机馆并不稳。她会数人，会收纸条，会记得馆长有没有洗杯子。她不是天生懂事，是因为她发现大人出事前，总会先漏掉一些小习惯。

她对异常的反应不是尖叫，而是指出一个小事实：“馆长没洗杯子”。这比直接说害怕更有力。

### 9.2 生活材料

- 她负责把掉下来的留言重新贴好，贴得比纪存还齐。
- 她记得每个孩子的笔迹，因为怕有人走了以后没人认得。
- 她会把饼干分成“馆长会偷吃”和“馆长不会偷吃”两堆。
- 她害怕时不问“怎么办”，会问“还有几个人没回来”。
- 她有时会学旧守护者说话，给自己壮胆。

### 9.3 原生话术

- “馆长没把杯子洗掉。他每次出远门都会洗。”
- “这张不是小满写的。小满的感叹号更胖。”
- “纪存哥，你刚才没按保存。”
- “他们说镜像，是不是纸还在，字不在？”
- “我可以把最旧的几张先藏起来吗？不是偷，是临时展陈。”
- “旧守护者，人数不对。你少数了自己。”

## 10. 陆衡

### 10.1 他不是“不懂浪漫的理工男”，他是见过真实机器被幻想羞辱

陆衡不在第一话核心登场，但第一章后段会进入。他的声音要提前准备好，因为他很容易被写成“吐槽不科学”。这不够。他不是讨厌幻想，他是讨厌幻想轻易赢过现实努力。

他见过小型机器摔倒一千次，只得到发布会剪辑里的三秒失败笑点。他讨厌超级系招式名，是因为那些名字让真实机器的笨拙显得没资格被爱。

### 10.2 生活材料

- 他会保存失败日志，文件名不用“fail”，用“attempt”。
- 他随身带备用扎带，认为扎带比多数宏大理想可靠。
- 他讨厌别人说“它只是不会动”，会立刻问“不动前做了几次尝试”。
- 他嘴硬，但会蹲下来和跌跌保持同一高度说话。
- 他不相信神话，但会偷偷给跌跌的关节贴一小块软垫。

### 10.3 原生话术

- “别叫它摔倒。叫第10742次姿态恢复失败。”
- “你们的飞拳如果能过安全审查，我请全馆喝水。”
- “不要重置。重置以后它是站稳了，还是忘了自己怎么摔的？”
- “我不是心疼机器。我心疼数据。数据比较诚实。”
- “这段噪声别删。太规律了，像有人装作不是信号。”
- “旧守护者，你这条规则写得不坏。谁写的？别说馆长，馆长写不出这么短。”

## 11. 第一话重写时的优先级

第一话下一轮不要整篇大改，先改四个高风险段落：

1. **留言墙三条回复**  
   把“玩家性格选项”改成纪存三种防御方式：归档、岔开、把决定权还给孩子。

2. **展柜右臂争论**  
   让兜灯和唐胶少说主题，多说零件、手感、日期、拆装风险。

3. **黑展柜反应**  
   让纪存先做职业动作：查终端、摸展签、误以为广播串线，再慢慢害怕。

4. **七海登场**  
   删掉预告片式金句。七海的刀藏在流程里：签收、授权链、复核、无申诉入口、风险下降。

## 12. 一个小样：同一事件的三种写法

事件：清算部要镜像留言墙。

错误写法：

```
七海：
秩序必须管理记忆，否则自由会带来灾难。
```

仍然偏工整的写法：

```
七海：
报告上会写风险下降。报告不会写谁少了一句话。
```

更像七海的第一话现场写法：

```
七海：
纸质部分先拍照。
如果你们不挡在路径上，原件可以等第二阶段。

小满：
第二阶段是什么？

七海：
你不会喜欢。

小满：
那你别阶段。

七海停了一下。

七海：
我没有这个权限。
```

这里的重点不是七海说出主题，而是她在孩子面前仍然坚持流程，又被孩子一句不懂规则的话刺了一下。
