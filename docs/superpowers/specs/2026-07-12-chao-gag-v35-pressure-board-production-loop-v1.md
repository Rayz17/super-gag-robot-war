# V35逐话Pressure Board防衰减生产循环 v1

> 状态：`superseded_for_new_work`  
> 后继：`2026-07-14-chao-gag-v35-pressure-board-production-loop-v2.md`。V1保留为C01-C12历史生产证据；C13以后以及C01-C12创作重校准使用V2。  
> 适用范围：V357-C01-C18共95个作者槽及其拆话Pressure Board  
> 目标：让长篇生产保持V35.5的因果密度和场面完整度，同时真正吸收V35.8装载合同，不把字段、字数或审稿席位当成故事。

## 一、基本单位

生产单位是**一槽一板**。作者槽若因双地图、重大关系场、巨物高潮或分支汇流过载，可以拆成两张以上Pressure Board；每张板必须有独立场面链、玩法转折和状态出口。三章可以作为一个检查批次，但禁止一次生成三章正文。

### 1.1 产物层级硬边界

本循环只生产`Pressure Board`，不生产正式逐话梗概或`Episode Packet`。任何板即使状态为`accepted`，也只能把对应槽标记为`board_ready`，不得把章节标记为“逐话完成”。正式逐话进度必须同时满足：

1. 在独立的`episodes/`目录存在一话一文件的`Episode Packet`；
2. 该文件含可连续阅读的厚剧情梗概和六层制作拆分；
3. 该话独立通过单话Pipeline、Writer Room Review、Source Absorption Gate和状态提交；
4. 对应行写入Episode Loop运行账本，而不是Pressure Board账本。

V357首次正式逐话运行必须从`C01E01`开始，但**不得在Pressure Board层尚未完成时提前启动**。本轮交付目标是全剧18章95槽Pressure Board，因此解锁Episode Pipeline必须同时满足：95槽全部有板、逐章章审完成、C01-C18前缀回归完成、全剧分支/人物/机体/IP/玩法/谜团/状态回收审计通过。此前只完成C01-C03便立即启动Episode的规则废止；不得从C04开始，也不得用局部试跑绕过全剧规划门禁。

每张板单独保存，命名为`PB-V357-Cxx-Sxx.md`；拆板时追加`-A/-B`。章节完成后再组装章级索引，不把多个槽先压入一个大文件。

## 二、V35.5质量基线

V35.5的11张板通常约1100-1600个非空白字符、6-9个因果场面拍；C03E04明显过载，不作为普通话配额。数字只承担缩水告警：

- 少于1100非空白字符：`warn_thin`，必须人工说明为何仍完整。
- 少于6个因果拍：`fail`，这仍是话卡，不是Pressure Board。
- 连续三张同等级板均低于此前中位数85%：触发批次衰减审查。
- 超过2600非空白字符：检查是否塞入两个高潮、两张地图或两个不可逆选择，必要时拆板；不是自动失败。

真正的通过条件是因果、人物、机体、IP、玩法、关系、分支和状态共同成立。

## 三、单板固定循环

```text
前序审计
→ 读取Author Slot + V35.8 Loadout
→ 解析路线/舰群/谜团/伏笔/素材
→ 写章级波形中的本槽职责
→ 写一张Pressure Board
→ 结构与ID机器校验
→ 1至3个最高风险专业镜头审稿
→ 定点补写
→ 单板Gate
→ 更新运行账本、素材吸收、台词复用和问题账本
```

单板必须包含：

1. 槽位合同、有效门禁、输入状态、路线/跳过状态；
2. 本话两难、A/B/C线碰撞及玩家关心的问题；
3. 6-9个由前一拍逼出后一拍的因果场面；
4. 地图、目标、失败压力、玩家工具和中盘翻面；
5. 至少两条具名机体动作，以及首登或生命周期变化；
6. IP/名场面/台词/文化生态如何改变冲突，而非作品名清单；
7. 主角不可逆行动、关系场面、持续群像动作和敌方收益；
8. 燃点、泪点、梗点与PV画面；安静话允许降低声量但不能全部空缺；
9. 玩家可见谜团/伏笔、输出状态、下一槽债务和禁止重置项；
10. ADV、探索/副玩法、SRPG、战斗内演出、舰内关系、结算的制作分层与资产风险。

## 四、审稿强度

逐话不机械召集全部席位。每张板根据风险选择1至3个镜头：剧情监督、角色弧线、关系/成人向、机甲文化/IP、玩法、分支、谜团、制作资产。审稿必须提出可执行补写位置，不能只给“通过/更燃一些”。

章末执行六席严格审：

1. 专业编剧：章节起承转合、反转、高潮与余波；
2. 角色/关系监督：主角和持续群像是否产生质变；
3. 机器人文化专家：谱系、参战规模、名场面吸收与重复消费；
4. 游戏制作人：地图差异、玩家意志、失败尊严和结算；
5. 连续性监督：前序债务、谜团窗口、路线状态与未走世界；
6. 厚度监督：是否缩水、并列信息化或用字段替代故事。

## 五、章级与全前缀回归

每章先写章级波形：开场钩子、第一次升级、中盘翻面、不可逆选择、高潮、余波、下一站现实理由；分支章还要列共同开场、互斥经历、失败尊严和差异化汇流。

本章全部板通过后：

1. 连读本章公共线与全部分支板；
2. 结算机体首登/成长、人物波形、敌方学习、谜团和状态；
3. 连读C01到当前章公共主线；
4. 抽查所有仍有后续影响的旧分支；
5. 找到最早根因章并定点返工；
6. 从根因章依次重验到当前章，不盲目重写未受影响板。

同一个`root_cause_id`最多三轮。第三轮后选择证据最好的版本继续推进，并把残余问题、取舍、影响面和用户决策需求写入问题账本，避免dead loop。

## 六、三章冷启动批次

| 批次 | 章节 | 核心压力 |
|---|---|---|
| 基线 | C01-C03 | V35.5校准、开局吸引力、展舰起航、共同体建立 |
| 试生产 | C04-C06 | 身体/作者分支、多谱系选择、星火巨物与战争撞场 |
| 战争 | C07-C09 | 撤退、牺牲What-if、革命、中盘大败 |
| 分裂 | C10-C12 | 生者政治、百机祭、索引出生、夺舰分舰 |
| 宇宙 | C13-C15 | 三舰异步、迟到回信、未来报告、远星裁决 |
| 终局 | C16-C18 | 六区内战、完美假馆、全球调律与结局资格 |

每三章关闭旧临时写作上下文，只携带：当前Canon、V35.7槽合同、V35.8装载合同、已完成章节摘要、未清债务、台词/IP复用、机体生命周期、关系状态和问题账本。这样减少上下文污染，但不丢连续性。

## 七、C04-C06试生产放行条件

- 16个作者槽全部有独立Pressure Board；未选路线也有完整世界经历，不是两行备选说明。
- 每板通过结构/ID校验，且至少6个因果拍。
- C04两条身体路线拥有不同经历、不同机体动作、不同人物伤害，并在C05汇流时保留差异。
- C05六选四不是六张主题展台；每条路线能改变C06的敌方模块、盟军损伤或解法，S07完成主动拆合高潮。
- C06四板形成“巨大化成功感→商品化伪胜利→真实战争撕场→主动拆掉完全版”的尺度升级。
- 纪存、七海、白鸢、唐胶、兜灯、陆衡、方舟T、豪司/金章、赤罡/莉歌等不因机体密度被挤没；缺席要有可见原因或后果。
- 章节审和C01-C06前缀审没有critical；同根因最多三轮。

通过试生产后才能继续C07-C18。若失败，先修流程或C04-C06，不用更多低质量章节掩盖问题。

这里的“继续C07-C18”仅指继续生产Pressure Board。正式逐话始终回到`C01E01`调用核心单话Pipeline，但只有95槽全剧门禁通过后才允许切换任务层。
