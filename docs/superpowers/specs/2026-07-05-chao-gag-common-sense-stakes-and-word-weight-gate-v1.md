# 超GAG写作常识重力与词语重量门禁 v1

日期：2026-07-05

## 背景

V31 已经比早期稿更像可制作的机器人战棋故事，但也暴露出一种新的体验风险：`证词`、`展签`、`开馆`、`授权`、`水印`、`公开`、`债务`、`夺名`、`改名` 等词在设定内确实重要，却容易在玩家常识里显得小题大做。

问题不在概念本身，而在词语重量超过了事件体量。玩家会先用现实常识判断：这到底损失了什么？谁被伤害？机体发生了什么变化？会不会死人、失去钱、失去身份、失去关系、失去路线、失去战斗力？如果答案只是“系统状态变化”或“某个术语成立”，再用大词就会显得荒谬、装腔或设计汇报。

## 核心原则

1. **常识先于设定。**  
   一个词在世界观里再重要，也必须先让玩家看到现实层面的后果。设定内权重不能直接替代玩家感受。

2. **大词必须有大事承托。**  
   `证词`、`开馆债`、`公开责任`、`夺名`、`改名`、`授权边界` 等词只能在事件已经造成明确损失、危险、羞耻、利益、关系或机体后果之后使用。

3. **小事用小词。**  
   普通线索、记录、备注、维修单、登记、临时状态，不要升格成证词、债务、开馆权或命运选择。保留生活口语和具体动作。

4. **先戏剧动作，后系统结算。**  
   玩家先看到机器人动、地图变、角色受伤、关系破裂、敌方得利、路线关闭；系统再把这些结算成记录、展签、证词或开馆状态。

5. **术语不负责制造情绪。**  
   情绪来自人和机器的处境：被抢走名字、被当成商品、被迫撤退、合体失败、维修单无人认领、旧机体再次站起来。术语只能命名结果，不能替代场面。

## 事态等级

| 等级 | 玩家常识体量 | 可用表达 | 禁用风险 |
| --- | --- | --- | --- |
| L0 普通信息 | 查到线索、看见记录、发现异常 | 记录、备注、线索、提示、日志 | 不得叫证词或债务 |
| L1 轻微利益 | 影响资源、钱、信任、路线效率 | 登记、回执、临时许可、风险提示 | 不得写成命运选择 |
| L2 具体损失 | 某人丢脸、亏钱、暴露隐私、机体受损、关系误会 | 证据、公开风险、责任、赔偿、修复条件 | 可以严肃，但要有场面 |
| L3 不可逆后果 | 机体被封存/入队条件改变、角色被处分、路线关闭、敌方获得样本 | 证词候选、开馆债、公开责任、命名权冲突 | 必须有敌方收益和关系后果 |
| L4 世界/命运级 | 阵营路线改变、万机馆资格改变、G.A.G.暴走、终局声部变化、文明误译 | 证词、开馆权、文明语言、共同体选择 | 不能频繁使用，否则贬值 |

## 术语使用校准

### 证词

`证词`只适用于 L3-L4。它必须满足至少三项：

- 可被公开展示或被迫公开。
- 会被敌方攻击、伪造、定价、清噪或封存。
- 改变机体条件、路线、关系站位、开馆资格或终局声部。
- 有一个具体物件或机体状态承载。
- 角色愿意为它承担损失。

普通记录、线索、证据、维修单、名字贴和展柜说明不自动成为证词。

### 开馆

`开馆`不是每次登记、布置或对外接触。只有当万机馆把某个东西放到公共观看和公共争议里，并承担因此产生的风险时，才叫开馆。

小范围内部确认、临时调查、线索审账，优先叫：查看、验件、试展、预展、登记、回访、收容、托管。

### 债务

`债务`必须有未来偿还方式。它可以是角色被追责、支援技能失控、机体条件变差、敌方取得样本、公众信任下降、某人必须在后续公开解释。没有回收路径的变量，不叫债务。

### 夺名/改名

`夺名`和`改名`不能停留在标签变化。要让玩家理解它为什么是大事：

- 名字连接驾驶员、机魂、旧主人、模型街隐私、战斗识别、授权系统或原作品记忆。
- 改名会导致机体无法响应、支援灰掉、关系被抹平、敌方能接管、玩家失去识别。
- 如果只是展签文字变了，就用“改标”“换编号”“贴风险码”，不要叫夺名战争。

### 公开

`公开`的戏剧性来自公开后谁会受伤。必须说明公开对象、公开范围、谁会因此失去什么、敌方能利用什么。否则只写“展示给谁看”“发到哪里”“谁看见了”。

## 写作门禁

每话 pressure board 增加以下问题：

1. 本话最大的术语是什么？
2. 按玩家常识，它对应的事态等级是 L0-L4 哪一级？
3. 玩家能看到的现实后果是什么：钱、人、机体、关系、权力、路线、世界？
4. 如果删掉术语，只保留场面，故事还成立吗？
5. 如果术语比事件更大，是否改用更小的生活词？

每话 reviewer 增加 `common_sense_stakes` 角色：

- 检查大词是否脱离现实常识。
- 检查小事是否被过度庄严化。
- 检查系统结算是否抢在戏剧动作之前。
- 检查玩家是否能复述“发生了什么大事”，而不是只能复述“某个概念成立”。

## 对 V31 的直接判断

V31 的机体、玩法和关系场面已经有明显进步，但 `证词/展签/开馆/授权/水印/公开/记录` 组词频过高，使文本读感偏向博物馆法务和设计文档。后续修订不应删除这些概念，而应把它们后置为结算层。

示例：

- `建立未开馆预展规则` 可以在系统层保留；读者层应写成 `灰模差点出击，但纪存选择先让它带着失败姿势被少数人看见`。
- `授权边界` 可以在变量层保留；剧情层应写成 `有人不想让童年旧名被拍进热榜，纪存选择让这条线索变弱也不公开姓名`。
- `开馆债` 可以在 ledger 保留；场面层应写成 `这次暴走救了人，却让七海被内审、某台机体下一战少一个支援槽、敌方拿到一段样本`。

## 禁用方式

- 不得因为 canon 说它重要，就在正文里直接写成重大事件。
- 不得用术语替代人物对白、机体动作、地图变化和敌方收益。
- 不得让角色频繁说 `证词`、`债务`、`开馆权`、`授权边界` 这类词。人物应优先说人话、行话、吐槽或当下判断。
- 不得把一张纸、一条线索、一次登记写成命运级选择，除非它会真正改变后续机体、关系、路线或世界状态。
- 不得让结算字段成为读者记住的高潮。
