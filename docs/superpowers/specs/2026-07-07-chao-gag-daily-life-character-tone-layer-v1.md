# 《超GAG机器人大战》生活温度层与主角团人设补丁 v1

## 定位

生活温度层不是番外糖水，也不是把主线危机降级成舰内闲聊。它是让主角团从“功能角色”变成“能一起生活、一起犯蠢、一起受伤、一起变强的人”的叙事层。

本层用于后续逐话梗概、台本、开馆事件、舰内探索、支援对话、战后维修、角色关系和美术资产brief。写作时必须与机战玩法、参战机体/IP投射、G.A.G./索引/远星宏观线并行使用，不能替代它们。

## 硬规则

1. 生活戏必须改变玩家对角色的感受，或改变关系/支援/权限/玩法状态。纯水时长的闲聊不计入有效生活戏。
2. 每个主线章至少应有一到两个生活温度场，重点章可更多。战后、出击前、舰内值夜、维修间、自动贩卖机、厨房、临时舱位、模型桌、格纳库和开馆后台都是优先场所。
3. 生活物件不应全部立即变成证据、债务、敌方样本或大词结算。必须保留一部分“暂时只是生活”的物件，让万机馆像真的有人住。
4. 儿童/少年角色只承担童年、观众、托付、家感和日常笑点，完全隔离成人向、擦边、修罗场和性隐喻。
5. 成年/成年感角色可以使用挑逗台词、误会、吃醋、贴身检查、战损、维修舱、权限隐喻、低俗玩笑和擦边分镜，但不得写露骨色情，不得把角色降格为奖励。
6. 生活戏不能替代参战机体密度。模型盒、草稿、饭盒、维修单、衣服和终端都只是锚件，除非触发明确支援、机体动作、玩法规则或关系状态，否则不计入机体曝光。

## 七海生活化补丁

七海不能只作为远程法务、合规接口或“40秒例外”存在。她的生活层核心是：一个成熟、优雅、控制力很强的人，被万机馆的混乱、温度、违规电线、维修粉尘、深夜值班和人情拖进共同体。

当前创作时间线：

- C01：七海始终远程，既有一年共事和闭馆后约饭的私人关系，也有清算签署与撤令停权的制度后果。
- C02：她仍未登舰，以原签署人与普通公民身份参与召回、合同和豪司改史争议；白鸢在C02E04肉身到场并随舰。
- C03：七海经公共交通实体到达工务城，先把封存原件盒带入万机馆作现场观察，章末才拖普通行李正式入住。身份是另行起算十二个行政工作日的现场调查者，仍停权、可召回、可被机体和公共维修席叫停。她不是加入甜点，而是来核验自己签过的连续风险，也第一次在舰内生活。
- C04-C07：生活层由临时舱位、检查、值夜、吃饭和与白鸢共同工作逐步积累，不再安排“首次实体登舰”。
- C08：发生更高层的制度身份断裂、改革公开选择或监督权限升级，而不是七海第一次成为现场人物。

生活场关键词：

- 临时舱位被安排在模型病院和零件库旁边，七海的整齐封存箱与唐胶的水口粉尘形成喜剧冲突。
- 舰内安全检查发现违规电源、未登记模型盒、白鸢成人向分镜草稿、豪司乱盖的勇气许可。她只拔掉最危险的电源，把其他写成“暂不构成即刻风险”。
- 她吃饭看风险说明，纪存递来维修间炒面。她评价“这份食品的风险说明比你们的出击计划完整”。
- 值夜时她把睡眠写成待补偿时间。纪存想关她终端，她说“你越权了”，但没有立刻重新打开。
- 她把外套搭在纪存椅背上只是为了遮住违规维修口，白鸢误会并画下这格，三角关系有生活化火花。

## 白鸢人设补丁

白鸢不应只有“改写者/创作者遗民/控制欲”三张牌。她可以更有色气、可爱和反差，但必须服务人物主题。

新增设定：白鸢私下会画成人向、擦边、战损和驾驶舱距离感很近的同人/分镜草稿。她会把它解释成“人体结构、机体承力和镜头调度研究”，越解释越可疑。这个习惯不是单纯卖肉，而是她把欲望、控制、害怕失去和角色身体感全部压进构图里的方式。

写作用途：

- 日常喜剧：白鸢的草稿被纪存误以为战术分镜，被七海作为舰内违规纸张拿起检查，被唐胶吐槽“你这不是分镜，这是危险品说明书”。
- 关系反差：白天她冷静谈角色权利，晚上画很大胆的近距离构图。她越能画欲望，越害怕自己真的想要控制某个人。
- 三角张力：她会故意把七海和纪存画进同一格，又用“构图需要”掩饰嫉妒；七海看穿但不揭穿。她也会画只有自己和七海的危险近景，七海审稿时究竟在看构图还是看她本人，两个人都不肯先说明。
- 玩法承载：白鸢的分镜不是普通CG收藏，可进入支援Cut-in、可质问分镜、错误版本公开、空白格保留和最终关系路线。

边界：

- 只作用于成年/成年感角色。
- 不写露骨性行为，不把白鸢写成色情符号，不让擦边盖过她的作者权力、留白权和角色拒绝权主题。
- 不涉及小满、阿澄、雾生、守展小队等儿童/少年角色。

## 七海与白鸢的女性关系层

七海与白鸢之间必须存在不依赖纪存的成年女性吸引。它不是后宫润滑剂，也不是给男性角色或玩家观看的一次亲吻：两人要有纪存不在场的秘密、身体距离、事业互救、嫉妒、背叛和选择。

优先场面包括：七海单独审查白鸢成人分镜却保留一页；白鸢替七海整理礼服背带或遮住权限灼痕；七海在敌对状态下替白鸢固定伤处；白鸢用无署名分镜保住七海的改革证据；二人在C11后台、C12医疗舱或C15重聚时发生亲吻未遂、主动亲吻或明确告白。亲密不能取消逮捕、毁证、离队和政治后果。

这条关系可独立进入`QIHAI_BAIYUAN_END`，也可与纪存两条关系叠加成`THREE_HEART_TRIAD_END`。未满足互恋条件时，`THREE_STAY_HAREM_END`仍可保留双方明确的酷儿吸引和未定义关系，但不得写成两位女性仅仅礼貌共享男友。

## 主角团生活层方向

- 纪存：深夜巡馆不是只记录，而是确认大家有没有睡、机体有没有疼、支援栏有没有异常。他从档案员变成像舰长也像家长的人，但必须保留机魂记忆和危险策展权。
- 七海：从远程流程人变成现场监督，再被生活拖进共同体。她的魅力来自成熟权力感、克制欲望、被混乱打乱的整齐，以及愿意把人味写进可追责流程。
- 白鸢：白天是危险改写者，晚上是大胆分镜画手。她的可爱来自强装镇定和欲盖弥彰，危险来自她真的能把欲望画成命运。
- 唐胶/兜灯：维修间火花线。吵零件、吵预算、吵饭盒、吵谁把安全规程当情书，关键时刻默契稳定。
- 陆衡/方舟T：克制的人机亲密。方舟T不说“我陪你”，只在迟到回信未到时给陆衡留一盏屏幕灯。
- 豪司/金章：低俗机战日常笑点入口。泡面、洗衣、换灯管都可能被盖“勇气许可”，但不能抢主线危机。
- 小满、阿澄、守展小队：只承担童年、观众、家感、托付和无害笑点，不进入成人暧昧或牺牲修罗场。

审稿时应问：

1. 本话是否让角色更像能一起生活的人？
2. 日常是否改变了关系、玩法、支援、权限、情绪或后续债务？
3. 是否保留了一部分不立即变成证据的大普通生活？
4. 成人卖相是否只作用于成年/成年感角色，且有角色主题和后果？
5. 低俗机战笑点是否服务角色，不是让角色变蠢？
6. 生活层是否没有挤掉机体、玩法、IP投射和宏观剧情？
