# 主战棋白话规则：玩家究竟在判断什么

> Status: `candidate_supporting_plain_language_reference / no_independent_design_authority / current_core_design_review`

> 本页只解释 [05f基础主战棋完整例](05f-first-neutral-tactics-v0.3-decision-ladder.md) 背后的公共概念，不是另一份玩家流程。若例子、目标或结果与05f冲突，应修订本页，不能让读者自行选择版本。
>
> 这份文档只把当前候选规则翻译成玩家能想象的操作，不新增 Canon，不绑定 C01–C03。本轮先用它评审规则方向；实际趣味和易用性留到以后决定进入制作时再验证。

如果只记一句话：**这不是靠刷等级把敌人清光的战棋，而是让几台具名机器人在可读的危险中，用自己的身体、位置和协作完成任务。**

想先看完整例子，先读 [第一张中性战术图 v0.3](05f-first-neutral-tactics-v0.3-decision-ladder.md)。想逐项检查合法、非法和同刻冲突，可读 [中性战术八张规则卡](05e-neutral-tactics-rule-cards.md)。被否决的作者回放只保留在 [v0.2失败基线](05d-first-neutral-tactics-graybox-brief.md)。下面解释公共方向，以及以后别的战场应怎样复用同一套规则。

## 1. 玩家打开一张战术地图，先看到四类东西

```text
┌────────────── 战场地图 ──────────────┬──── 当前选中机体 ────┐
│ 我方与敌方身体、朝向、路线和地形       │ 机动      正常         │
│ 敌方意图箭头、预计接触时间             │ 左臂承力  受限         │
│ 车辆、闸门、桥梁、样本等任务对象       │ 传感器    正常         │
│ 尚未确认的接触只显示误差区             │ 热量      偏高         │
│                                      │ 本轮可做：移动、稳固   │
├──────────────────────────────────────┴────────────────────┤
│ 目标：撤离车辆 0/2　桥梁：危险　样本：尚未被取得             │
└───────────────────────────────────────────────────────────┘
```

玩家不需要先打开人物属性表找“攻击力最高的人”。第一眼应该能回答：

1. 这场行动真正要保住什么；
2. 敌人现在准备对谁做什么；
3. 哪个位置、身体或设施正在成为瓶颈；
4. 我方每台机体此刻还能承担什么职责。

如果地图必须先点开三层菜单才能看懂危险，界面设计就失败了。

## 2. 一次操作固定经历六步

无论最终采用哪一种回合制，单个机器人动作都遵守同一条语法：

1. **观察**：点击身体、地形或敌方意图，看已知事实和未知项。
2. **画路线并定朝向**：拖出短路线，在终点转动朝向箭头。
3. **选一个主要身体动作**：例如稳固、推拉、射击、开闸、救援。
4. **选择是否预留反应**：例如有人撞入时保护、物体坠落时承接、危险出现时中止。
5. **看因果预览**：系统说明接触时刻、身体条件、已知结果和不确定来源。
6. **确认**：提交后按真实动作执行，不能因为结果不理想免费换招。

### 鼠标、键盘和手柄怎样操作

| 意图 | 鼠标／键盘候选操作 | 手柄候选操作 | 屏幕必须立即反馈什么 |
| --- | --- | --- | --- |
| 看一个对象 | 左键点击；`Tab`切换可见对象 | 左摇杆移动焦点；`A`确认 | 名称、身体状态、来源、可做动作 |
| 画移动路线 | 按住左键拖动；右键撤销上一段 | `A`设路点；`B`撤销 | 路线时间、终点朝向、受威胁区 |
| 选择动作 | 点击动作条；数字键快捷选 | 方向键选动作；`A`确认 | 目标、准备／作用／收招时间、代价 |
| 预留反应 | 在动作条切换“保护／中止”等条件 | 肩键打开反应栏 | 触发条件、保护弧、会放弃什么 |
| 查看预览 | 鼠标悬停时间点；按住`Alt`展开原因 | 扣住扳机键 | 最好／最坏结果、未知原因、冲突时间 |
| 提交（短全队协同） | `本机排好`只标记该行检查完；`执行本周期`才锁定全队 | `Start`或专用确认键 | 尚未解决的风险和不可撤回提示 |

这些只是帮助想象操作的候选键位，不是已经确定的按键方案。

## 3. 每台机器人一轮究竟能做多少事

候选共同规则不是“每人两点行动力，想买什么技能就买什么”。一台机体通常安排：

- 一段符合自身身体的短移动和终点朝向；
- 一个主要动作；
- 至多一个事先预留的反应条件。

例如护卫机可以“向前两格、面朝东、稳固，并预留承接正面冲撞”。它不能在同一段里又稳固、又追人、又拖车、又免费反击。

预留反应会占用本机这一段的反应能力，不是额外送一次行动。若反应触发，它会使用真实执行时间、能源或弹药，并可能中止尚未完成的主要动作；若没有触发，玩家不能在看完敌方结果后把它兑换成一次新攻击，只会保留已经成立的姿态。A／B／C／D 四种时制可以使用不同界面，但这笔物理代价不能因时制变化而消失。

### 为什么要分主要动作和反应

因为“保护别人”必须是玩家提前作出的承诺，而不是敌人行动后系统白送的动画。

例子：

- 玩家让护卫机预留 `保护车1`，敌人真的撞向车1时，它会进入保护路线；
- 敌人改撞桥墩，保护条件没有触发，护卫机不会凭空改成攻击敌人；
- 玩家若没有预留保护，即使护卫机站在附近，也不自动替车挡下冲击。

这样，站位和承诺本身就是玩法。

## 4. 朝向为什么重要，但不会变成背后加伤的算术题

朝向首先决定身体怎样使用，而不是简单的“背刺加 20%”。

- 护卫机正面有承力结构，能接住冲撞；侧面受力更容易失稳。
- 工程机必须让维修臂朝向接口，才能开闸或加固。
- 游击机的压制扇区由武器朝向决定，不能同时覆盖身后车辆。
- 大型身体转身需要空间和时间，狭窄通道里不能原地无成本旋转。

具体例子：护卫机面朝东稳固时，可以挡住从东面来的重机。如果它为了追猎手把身体转向南面，同一位置仍然存在，但“保护主路”的身体条件已经消失。

## 5. 机器人不是一根血条

玩家看到的是几个与动作直接相关的身体功能，而不是一串需要堆高的成长数值。

| 身体功能 | 正常时能做什么 | 受限后发生什么 | 失效后发生什么 |
| --- | --- | --- | --- |
| 机动 | 按正常路线移动、转向 | 路线变短、制动更早 | 只能原地支撑或等待救援 |
| 操作／承力肢体 | 推、拖、抓、开闸、保护 | 只能承担较轻对象或简单动作 | 对应动词关闭，但其他身体仍可用 |
| 传感／通信 | 看清接触并共享来源 | 信息变旧、误差区扩大 | 只能依赖友军转报或近距离观察 |
| 稳定／防护 | 承受冲撞、保持姿态 | 更容易被推移或中止 | 无法安全稳固或保护 |
| 能源／热量 | 连续执行高负载动作 | 必须在高价值动作之间取舍 | 进入安全降载，不能继续强行输出 |

例子：护卫机左臂从“正常”变成“受限”以后，它仍能走路、站在桥口和用身体挡路，但不能安全拖动样本箱。玩家失去的是一种职责，不是单纯少了 21 点生命。

这里仍保留整体结构安全与驾驶员／机魂安全底线；“没有单一 HP”不等于机器人永远不会被击毁。

## 6. 预览告诉玩家因果，不替玩家给答案

已知的物理条件使用同一套规则来预览和结算。玩家不应该看到“预计能挡住”，提交后却因为另一套隐藏公式随机被撞飞。

### 信息充分时

```text
敌重机冲撞：已确认
护卫机正面稳固：已确认
桥面支撑：已确认
结果：护卫机不位移；左臂从正常变为受限
```

### 信息不足时

```text
未知接触体质量：只知道在中型到重型之间
最好结果：护卫机保持位置
最坏结果：护卫机后退一格并失去稳固
怎样缩小范围：近距离扫描，或取得现场称重记录
```

### 计划本身非法时

```text
不能提交：工程机维修臂没有朝向闸门接口
失败位置：路线终点
怎样修正：旋转90度，或改到接口南侧停靠位
世界状态：没有变化
```

不确定性必须来自玩家当时不知道或已经过期的信息，不能来自隐藏命中率、随机暴击或作者临时改规则。

## 7. 敌方意图到底公开多少

每条意图至少显示五件事：

- 谁准备行动；
- 动作类别；
- 当前目标；
- 预计接触时间或时间范围；
- 信息来源和新鲜度。

例子：

```text
敌重机1／冲撞／目标车1／约4秒后接触
来源：游击机光学确认／刚刚更新
```

如果只有远处的旧报告，玩家可能只看到：

```text
重型接触／可能向主路移动／4–7秒进入危险区
来源：两秒前的中继报告／目标未知
```

敌人仍然可以干扰、佯动、改变目标和利用盲区。公平的要求不是敌人永不变招，而是变招必须有原因，战后能从日志说明“它看见了什么，为什么重规划”。

## 8. 战斗目标不是清光敌方单位

一场地图会把目标分开结算。典型目标包括：

- 让两辆车撤离；
- 在桥断前完成交接；
- 阻止敌人带走样本；
- 让某个自主机体愿意继续协作；
- 证明某个设施不能安全启动；
- 带着当前伤损主动撤离。

在断桥例子中，“撤离两辆车”是主要目标，“保桥”和“保样本”是独立次要目标。玩家可以主要目标成功但承担一个真实损失。

这不等于没有失败：如果四个决策段后连两辆车都不再有合法撤离可能，而且故事也没有合理的救援后段，才回到稳定检查点重试。

## 9. 两种有效战法必须改变因果，不是换一条颜色不同的路线

本页不再发明第二组路线。唯一基础战棋例只读[05f第一张中性战术图](05f-first-neutral-tactics-v0.3-decision-ladder.md)：

- **保公共设施：** 锚机和工程机把职责投给主桥，换来桥完整；代价是样本失守与锚定腿受限；
- **保住证据：** 游击机和工程机把职责投给猎手与样本，换来证据保全；代价是桥降级与保护框架失效。

真正的区别是谁用身体承担哪项责任、哪一项后果进入下一轮，而不是同一攻击组合先按哪个按钮。本页后续只解释通用规则；不提供第三条基础战法真值。

## 10. 主角团能力怎样进入操作，而不是变成四个增益按钮

先把基础身体战术讲清，再在同一套规则上叠加主角团的协作层。

### 纪存：提出可行路线

操作例子：玩家选择车队报告和工程机视野，在地图上拼出一条候选路线，再把提案发给护卫机。界面返回“接受／拒绝／附条件接受”。纪存不能直接拖动那台机体，也不能读取没有来源的全图真相。

### 白鸢：比较条件结果

操作例子：玩家把05f的“保公共设施”和“保住证据”放入两个预演栏。系统显示每个方案在“桥面承力成立／猎手提前改线”等条件下的结果，并标出仍未知的敌重机质量。她给的是可推翻的条件分支，不是未来必然发生的答案。

### 七海：核验和使用真实权限

操作例子：玩家点闸门的控制节点，先查看谁拥有停机、开门和紧急断路权。只有真实授权链成立时，才能提交对应操作；她可以叫停越权动作，但不能凭空给自己城市或军方权限。

### 工程组：把猜测变成可执行或不可执行

操作例子：玩家选择桥面测量、护卫机承力档案和现场支撑点，提交一次核验。结果可能是“正面承力可行，但左臂会受限”，也可能是“支撑不足，禁止这样做”。工程验证消耗时间和工具，不是提示按钮。

### 驾驶者和机魂：对具体动作作回应

操作例子：玩家提出“让你在断桥上承接冲撞”，对象可以接受、拒绝、要求先撤离平民，或在条件变化后撤回。同意绑定这次动作，不会因为关系值高就永久服从。

这些能力改变的是信息、路线、许可、验证和协作承诺，不提供免费行动点、固定增伤或必中。

### 一条完整的协作链是什么样

在这个 C2 操作例里，同一个“让护卫机去连接口保护车辆”的请求要经过四步，而不是点亮一个头像：

1. 玩家在纪存席位选择“车队位置报告”和“护卫机现场视野”，画出一条候选保护路线。UI 标记路线依据，也标记“侧路闸门控制权未知”。
2. 玩家切到七海的核验栏，点击闸门。系统返回：本地维护员拥有本次开门权，七海没有；因此玩家只能请求本地授权，不能直接开门。
3. 本地授权取得后，工程组检查连接口宽度和护卫机转身空间，结论为“路线可行，但必须等车3先通过”。这条条件被自动附到提案上。
4. 玩家把提案发给护卫机。它可以回答“接受，车3通过后执行”，也可以因当前左臂受限回答“拒绝承接冲撞，但愿意站位警戒”。只有接受的具体身体动作才进入战术计划。

如果任何一步缺少来源、权限、物理条件或主体回应，界面应停在那一步，并给出合法替代，而不是把整条链压成“导航成功＋20%回避”。

## 11. 主策推荐与三个比较参考

当前主策推荐 **B 短计划同时执行**，因为它最能承载巨型身体同时让路、保护、碰撞、C2协调和因果演出；**A 交替激活**是低负担备选。C只有当“先锁谁”本身值得成为核心博弈时才重开，D只保留传统SRPG参照。它们不再是四个等权主方案。

| 身份 | 玩家怎样下令 | 玩家主要在想什么 |
| --- | --- | --- |
| B 主推荐：短计划同时执行 | 为全队安排一个短时间段，再一起提交执行 | 多台身体怎样在同一时刻配合或冲突 |
| A 低负担备选：交替激活 | 我方选一台行动，世界回应后再选下一台 | 现在先动谁，是否会暴露下一台 |
| C 条件参考：逐台锁计划、随后同时执行 | 我方逐台确认，锁定后不能随意改，再一起结算 | 先承诺谁，后续计划怎样适应已经锁定的动作 |
| D 传统参照：阵营回合 | 我方阶段可决定己方行动顺序，之后敌方阶段 | 怎样用完整己方阶段形成阵线并预留反应 |

四版必须使用同一地图、身体、目标、敌方原则和信息量。不同版本可以有适合自己的界面，但不能偷偷改变动作成本或结果。

### 同一个开场，四种方式到底怎样按

共同开场都是：敌方重机8秒后撞向主桥，猎手7秒后接触样本；我方锚机要站稳、游击机要决定压主路还是截猎手、工程机要修桥还是开侧门。

- **B 主推荐：**玩家依次编辑三台机；`本机排好`后仍可回来改。长按`执行本周期`才锁全队，敌我和环境共同推进8秒。周期末一次看到站稳、截击、车辆移动和桥压是否互相冲突。
- **A 备选：**玩家先选锚机，画路和站稳后确认，这台就锁定；世界给出一次回应，再轮到游击机或工程机。已经行动的锚机不能免费重排。共同世界周期结束时才刷新敌方意图和协作次数。
- **C 条件参考：**玩家仍要安排三台，但每确认一台就永久锁住该计划；全部锁完后共同执行。它强调“先承诺谁”，但容易让后点机体只是替前面的承诺收拾残局。
- **D 传统参照：**玩家在己方阶段逐台行动，按`结束己方阶段`后敌方集中行动。它最熟悉，却最容易把同刻碰撞和协同变成先手顺序题。

C2协作只作用于尚未越过锁定点的具体动作：A在确认当前单位前，B在`执行本周期`前，C在锁定该单位前，D在确认该单位动作前。越过锁定点后不能临时再买一次协作，只能读取已经预留的反应。一个共同世界周期总计两次协作介入，不会因为逐台行动或分阵营而重复刷新。

因此本轮真正需要判断的不是四选一细节表，而是：**本作核心幻想更像“编排一段短全队动作”，还是“逐台决定、世界逐次回应”？**最终秒数、动作成本和按键以后再定。

## 12. 重故事、轻练级怎样影响战棋成长

玩家成长主要来自三种东西：

1. **学会新的身体用法**：例如一台机体从只会挡路，发展到能在合法支撑下承接坠落对象。
2. **建立新的协同协议**：两名角色、驾驶者和机体经过故事后，允许一套新的交接动作。
3. **获得新的信息与准备条件**：调查、关系和万机馆整备让玩家更早知道风险，或带上合适工具。

不会把主要乐趣建立在反复刷关、堆驾驶员等级、叠百分比被动和用高数值碾过地图上。装备、维修和资源仍然有取舍，但它们应改变可用办法与承诺成本，不把旧关卡变成无脑清场。

## 13. 当前究竟完成了什么，没完成什么

### 已经能供你判断的候选方向

- 玩家操作链：观察、画路线、定朝向、选主要动作、预留反应、预览、确认；
- 身体功能伤损代替单一 HP 主导；
- 敌方意图有目标、时间、来源和不确定性；
- 已知物理预览与结算使用同一规则；
- 非歼灭目标和可持续失败；
- 主角团通过信息、路线、权限、工程验证和同意进入战术。

### 尚未决定

- 短全队协同与逐台行动的一级方向尚待用户批注；最终秒数、动作成本和按键未定；
- 每个身体动作最终需要多少秒、多少能源和多少工具；
- 敌方 Intent 应公开到什么精度才既可读又不失去惊喜；
- 身体功能需要保留多少层，才能有深度又不造成界面负担；
- 哪些成长、装备和关系回报真正能丰富方案而不形成刷数值。

### 留待以后制作验证

- 这套战棋实际好玩；
- 没有提示时玩家能否发现两种战法；
- 玩家能否看懂同刻冲突和身体损伤原因；
- 主角团能力会不会被误读成万能技能；
- 操作节奏、镜头和界面是否舒服。

当前交付就是文字设计和纸面操作例。本轮先据此收束产品方向、核心规则和角色协作方式；以后是否制作中性灰盒与怎样验证，另行决定，不是你现在阅读这套策划的前置。
