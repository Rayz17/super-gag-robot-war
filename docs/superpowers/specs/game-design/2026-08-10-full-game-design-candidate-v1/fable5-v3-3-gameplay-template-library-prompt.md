# Fable 5 V3.3 委托｜把 04–14 的高能创意固化为可持续产出关卡的玩法模板库

> 任务类型：`external creative consolidation / Candidate input only`
>
> 本轮只新建一份外部 Candidate 文档，不修改 04–14、现有玩法总案、Canon、Reader、story-chain、Runtime、代码或资产。

## 一、你这次不是再设计一版游戏

04–14 已经经历了多轮发散、收敛、失电和重新找回乐趣。现在的问题不是“还缺一个更大的新方案”，而是：

- 很多强创意仍埋在长案例中；
- 后续主策或 Codex Sol 容易只照抄礼步壹号、标本师、雨夜围馆等表层内容，却没有学会它们为什么好玩；
- 也可能因为“整理”，又把机器人欲望、舞台感、爆发、恋爱、收藏、探索与 Meta 削成干净但无聊的工程规范。

**你的任务是提炼，不是重启。**

请把 04–14 中真正有电的体验功能、关卡母型和长期变奏提炼成一套：

- 普通玩家读得懂；
- 策划能拿来组合；
- 换一台机体、一座城、一个对手，仍能产生新关卡；
- 随游戏进程能增长新判断，而不是只加数值或多几层菜单；
- 能保住只有《超GAG机器人大战：万机残响》才能成立的味道。

不得提交 V3.4 新总案，不得再发明一组平级大系统，不得再写一条几万字的新 Candidate 剧情线。如果提炼时发现真的缺一条连接规则，可以新增小型桥接规则，但必须写明它替代或合并了什么旧摩擦。

## 二、先理解“案例”与“模板”的区别

14 号中的礼步壹号、担山、白鹭十三、标本师、秦老爷子等，都可以是为压力测试临时创设的 Candidate 演员。

这些具体内容不需要直接迁入 Current，也不能因为它们不在 Current 就否定其创意价值。评价它们时看的是：

1. 这个案例背后，玩家重复想要的快乐是什么？
2. 换掉人名、机名和城市，还剩下哪些不可少的玩家动词和因果？
3. 哪些部位可以替换，一换就能长出真正不同的关卡？
4. 玩家熟练后能不能卡规则、做构筑、诱导敌人，打出作者没预写但合法的漂亮解？
5. 它适合常驻、每部几次，还是全剧只用一次？

**理性玩家钻规则是正面乐趣。**只阻止两种情况：

- 所谓“强解”不是从事先可知或可调查的规则推出，而是到结局才临时增加一条作者便利；
- 某个循环稳定让其他选择全部失效，并长期奖励玩家做违背人物、机魂或作品核心幻想的事。

请另外给出一张 **“14 号案例去向表”**。A 包的三解、首战理解和角色编组，B1–B4，C1–C3，D1–D4，E1–E5 都必须逐项出现；每项只能裁为：

- 保留为独立模板；
- 融入另一张模板；
- 降为周期性特型或全剧高峰；
- 暂不采用。

不得静默漏项。若暂不采用，必须指出它原本提供的快乐由哪张模板接走；若没有承接者，就不能只因“不够整齐”而删除。

> **抽象不是把好玩的场面压成字段，而是说明为什么这个场面换一批人物、机体、地点和敌人后，仍能再次产生不同但同样强烈的快乐。**

## 三、务必保住 04 以来的“电”

下面保护的是体验功能，不是指定机制名称、数字或案例剧情。你可以合并、改名或用更强的方法取代，但不能静默丢失：

1. **活的机群**：机器人会争舞台、毛遂自荐、炫耀、怕丢脸、抬杠、改主意，不是红黄绿审批灯。
2. **玩家亲手搭出名场面**：机体可以请战或给机会，但路线、时序、身体、配合和最后决定由玩家组织，不由 AI 自动代解。
3. **燃爽正反馈**：必杀、合体、变形、地图炮、援护、宿敌翻面、无遗憾全胜和大规模百机战都必须有位置，不能只留救援和遗憾。
4. **机器人身体和正面欲望**：占格、朝向、功能损伤、承力和地形要服务“它想赢、想出拳、想合体、想保护谁”，不能只证明故障与禁止。
5. **经典机战口味轮换**：纯爽全灭、阵地、护送、追逐、巨物工程、擂台、宿敌、合体和大会战不能被同一个“承接”动词吞掉。
6. **角色出席与组牌**：谁亲临、谁随乘、谁通讯、谁远援，会真正改变战法；人物技能是一生习惯与关系的戏剧按钮，不是通用 Buff。
7. **规则钻研与构筑**：行动顺序、预备反应、身体、地形、敌方习惯、人物编成和装备新动词能被组合、利用和反制。
8. **机器人文化江湖探索**：现实城市巡访、地方人情、机器规矩、模玩手作、旧比赛、老人与年轻人的记忆，要是可走、可看、可选的玩法，不是地点清单。
9. **残响深潜与主观空间**：机体记忆、误读、现实物证和身体历史可以变成可步行、可发现、可重演的空间。
10. **手修、策展、收藏与家**：玩家的照料、修法、展陈、偏爱和保留痕迹，要改变机体动作、万机馆空间、群体生活和后期回收。
11. **笑、爱、色与多角关系**：机体虚荣、错版身体、玩具与规则可以产生可玩 GAG；成年人的吸引、吃醋、照料、拒绝、退出和重组不以纪存为唯一中心，不兑换战力。
12. **有边界的 LLM 互动**：只在“怎么说”本身构成体验时自由表达；自由语言不做规则裁判者，记忆属于服务、世界事实还是人物本人必须分开。
13. **世界内 Meta 和馆外观测者**：可靠、好用的界面逐步开始折叠不完美、冷门机、失败、尴尬、沉默与拒绝权；玩家可以先利用它，再用自己留下的实物、关系、战报和错误反制。
14. **延迟回收与“只有我这局”**：早期偏爱、拯救、失败、对话、保留和公开的东西，后期要以改变命运的方式回来。
15. **情绪波形**：每一部都要有纯快乐、庆典、大胜或无遗憾的时刻，不能每一关都签债、遗憾、付代价。

交稿时必须给一张简短的“创意继承对照”：

`体验功能 → 最强来源（04–14 哪份文档的哪个标题）→ 由哪张模板承接 → 如何保住快乐`

若某个旧机制被合并或退役，必须说明它原本要给玩家的快乐被谁接走，不允许用“控制复杂度”一句话就删除。

最低限度必须在来源中逐项核对这些高能内容，不得只读后版摘要：

- **04**：机体主动请战与抢戏、玩家导览和回应请求、从噪声中夺回声音、残响与见证、绝活和锚件、会改变局面的 GAG、具名承诺；
- **05**：收录与反制、角色出席像组牌、人物一生习惯凝成的戏剧按钮、巡展／深潜／舰内生活、燃爽笑爱色感动的体验兑现；
- **09／10**：气势如何长成名场面、敌方也会抢高光、完整胜利与庆典、战报公开与馆藏记忆、手修、延迟回收；
- **11／12**：规则钻研、默认不限现实思考时间、群像出席、现实探索、残响深潜、多角关系、有边界的 LLM 记忆与版本 Meta；
- **14**：A 的三方行为战，B 的巡访／深潜／关系／返馆，C 的 LLM／Meta，D 的经典机战类型谱，E1–E5 的突破玩法。

## 五、主文必须用普通人的语言

这份文档首先给玩家、主策和后续 Sol 阅读，不是给数据库看的。

### 5.1 语言硬门

- 新概念首次出现时，先用一句生活话说清，再决定是否需要名称。
- 一句话说不清的名词，就不要在主文发明。
- 不得用一长串井号、箭头、字段名或英文缩写代替解释。
- 每张模板必须有一段“玩家实际会做什么”，不允许只写主题和系统关系。
- 最强画面和最强情绪必须用普通语句写出来，不得塞进表格字段。
- 主线战棋默认是回合制，玩家现实中的思考时间不限；“一轮”、“十分钟体验段”或“60 秒读法”不得偷换成强制倒计时。现实限时若存在，只能是另行选择的挑战规则，不能成为模板默认前提。

主文中禁止把下列工程词当作玩家语言：

`receipt / gate / schema / registry / owner / consumer / ledger / envelope / fixture / contract status / authority boundary / pass / blocked`

下列中文词也只能在末尾内部说明中出现，不得主导玩家体验：

`回执 / 门禁 / 状态域 / 消费者 / 写入链 / 权威边界 / 执行包络 / 负责页 / 生命周期实例`

请统一改成人话：

- `行为合同`→“它平时的习惯、执念和绝不做的事”；
- `台口`→“适合它打出名场面的位置与时机”；
- `一拍`→根据真实意思写“一轮”、“一次出手”或“一个事件阶段”；
- `写入／读取`→“这次选择留下什么，以后在哪里再看见”；
- `硬后果／软后果`→“会改变世界的事／只改变气氛与记忆的事”；
- `三级结算`首次出现时先写“一行结果、一屏因果、需要时再翻全记录”。

可以保留“气势”、“名场面”、“预备反应”、“残响深潜”等一读就能想象的词，但必须说它让玩家做什么。

### 5.2 可读性自检

每写完一张模板，问：

- 不看 04–14，能不能用两句话向一个战棋玩家解释？
- 他能不能说出自己一轮会点什么、犹豫什么？
- 他能不能想到至少两种不同的关卡？
- 他记住的是一个机器人动作和情绪，还是一个表名和流程？

## 六、先将模式分成不同频率，不要伪装都是常驻系统

你最终自行合并为 **8–12 张模板**。先分四类：

1. **常驻母型**：能支撑至少 5 场有不同判断的游玩，是普通战、探索或返馆的主要来源。
2. **周期性特型**：每部或每几章使用一次，用来换气、展示新尺度或机器人文化。
3. **全剧高峰**：只需用一次或极少数次，价值来自长期积累的回收，不需要伪装成可重复刷的日常玩法。
4. **横向表现层**：例如有边界的 LLM 表达和宿敌学习，它们改变多种玩法的表现与后果，但本身不冒充一张独立关卡。

请重点审视，但不必机械照抄下列候选：

- 14A 的“有自己目标的第三方机体＋有执念的敌人＋场地节律＋我方身体”；
- 经典机战类型谱与其组合方法；
- 角色出席、人物技能与冷门机构筑；
- 现实城市巡访；
- 残响深潜与残响重演战；
- 手修／策展／收藏／客座生涯；
- 关系中的共同行动、错位、靠近、拒绝与重组；
- “你布置的家会在危机时成为地图”；
- 百机大会战的多战区导演；
- 有真实便利的完美版 Meta；
- 与自己的公开战报对弈；
- 词条／公共解释权争夺（如果仍只是证据大小表，就合并到探索或 Meta，不单立成模板）。

## 七、每张模板怎样写

不要写数据库字段表。每张模板先说人话，再给策划使用方法。

### `模板编号＋一眼能懂的中文名`

#### 1. 玩家会怎样跟朋友形容这个玩法

用两到四句话。必须包含玩家亲手做的事和最想给别人看的画面。

#### 2. 为什么好玩

说清欲望、犹豫、规则钻研、即时回报和长期期待。不得用“很有深度”或“沉浸感强”代替。

#### 3. 一次游玩怎样进行

以“玩家先看见……然后……如果……最后……”写一小段。战棋模板说一轮做什么；探索模板说一段路怎样选；关系模板说玩家怎样介入而不接管人物。

#### 4. 绝不能丢的三到五条

这些是换掉人物、地点、敌人以后仍必须存在的因果。不要把礼步壹号等具体内容当成必须项。

#### 5. 可以替换什么，换了会长出什么新关卡

至少给出三类可替换部位，例如：机体欲望、敌人执念、场地节律、人物编成、可保留的物件、玩家曾公开的行为。

用三个只有一到两句的小变体证明不是换皮；不得再展开三篇完整剧情。

#### 6. 它随游戏进程怎样长大

只写早期／中期／后期：各自多了什么真正的判断，以及哪个旧提示、旧操作或旧负担已经退场。不要擅自把模板锁到未验收章节。

#### 7. 能和什么组合，不能与什么同时堆满

说清一场游戏主要让玩家想哪一件事。一场普通战不得同时塞行为习惯、百机、多战区、合体、Meta、深潜和多角关系全套。

#### 8. 失败、强解与退化风险

说清：

- 失败后还能玩什么；
- 熟练玩家可以怎样漂亮地卡规则；
- 什么时候会变成只有一个最优解、只猜策划答案或重复劳动。

#### 9. 使用频率与内容成本

只写玩家前台负担和内容量级，不写人月、Build、技术 Schema 或资产 BOM。必须决定它属于常驻、周期性、全剧高峰还是横向层。

#### 10. 它保住了 04–14 的什么电流

指向一到三个原文标题，说清保留的是哪种快乐，不是照抄了哪个名词。

## 八、另做一页“关卡组合方法”

不要再写新剧情，只给出五种策划配方：

1. **普通战**：一个常驻战棋母型＋一个场地变化＋一种情绪回报；
2. **机战换气战**：一种经典口味（纯爽全灭／合体／宿敌／地图炮）＋一个本作独有变式；
3. **机体个人篇**：一段城市巡访＋一次手修、收藏或残响深潜＋一次后期战棋回收；
4. **章节高潮**：一个已熟练母型＋一个周期性特型＋一次人物／机魂主动选择＋一个能被预告片截下的动作；
5. **Meta 高峰**：一个玩家早已信任的日常系统＋一项真便利＋一个被折叠的个人差异＋一件玩家曾亲手保留的反证。

每个配方用不超过六行说清：主判断是什么，哪些元素必须不同时堆入。
