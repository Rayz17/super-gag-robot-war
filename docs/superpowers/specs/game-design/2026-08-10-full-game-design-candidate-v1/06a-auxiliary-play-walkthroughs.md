# 轻探索怎么操作：10分钟找到一条进场路线

> 当前状态：`Candidate / current_light_exploration_example / core_design_review / user_not_decided`
>
> 本例只用中性地点，不给 C01–C03 新增剧情或设定。它只说明一件事：轻探索怎样让玩家亲手形成路线，又不变成搜满发光物。
>
> Hub与调查已各有独立主稿，本页不再重复。系统边界与提交规则以[00c核心玩法总案](00c-core-game-design-master-review.md)为准；[00b连续两周期示例](00b-full-game-common-gameplay-skeleton.md)只展示本例怎样接入完整循环。

## 共用操作语法

轻探索、Hub和调查／工程实证都用同一条操作语法：

`聚焦对象 → 记录事实 → 比较方案 → 主提交 → 返回`

本场的主提交键别名是`报告路线`；报告之前的走动、查看、交谈和比较都只在编辑草案，不偷偷改变后续任务。

## 共用语法怎样落到轻探索

轻探索每次只解决一个清楚问题。玩家不需要记一套新键位：

- 移动：走向地标或集合点；
- 看向：用镜头对准一个真实对象；
- 观察：放大并记录它能说明什么；
- 互动：交谈、请求或帮忙；
- 现场手册：并排当前已知的2–3条信息；
- 报告／返回：做到够用就走，接受当前结果。

屏幕不显示“收集0／6”，只显示本次问题：`怎样让后续队伍安全到达集合灯？`

## 玩家先看见什么

玩家来到一座中性山脊转运站。远处能看见任务集合灯，面前有三个显眼地标：

- 左边公共坡道最直，但一台装卸机堵住了一半；
- 右边维护走道更短，门上写着“仅本地维护人员开启”；
- 高处观景台能同时看清两条路，但要绕一小段。

## 玩家具体怎么做

1. 走到公共坡道边按观察键。镜头框住地面新磨痕，手册记下：`重型机通过时会占满坡道宽度`。
2. 走近本地维护员交谈。玩家可以问“装卸机什么时候移走”，也可以问“维护走道能否临时开放”。
3. 若去观景台，玩家用相机框住维护走道的出口，会确认它直通高处观察位，但宽度只够轻型先遣组通过。
4. 打开现场手册，两条合法路线会以结果卡并排，而不是隐藏一个“正确答案”。
5. 选择一张路线卡，回到集合点，点击`报告路线`。

## 两种真正不同的选择

### 方案A：帮维护员先移装卸机

- 玩家在附近找到手动制动柄，维护员负责解锁，玩家协助确认移动范围；
- 公共坡道恢复，轻机与重机都能通过；
- 全队到场时间从`T0`推到`T1`，在`T1`从西侧公共坡道一起进场；
- 维护员记得玩家先处理公共安全，之后愿意提供一条本地设备说明。

### 方案B：只为轻型先遣组申请维护走道

- 玩家不能自己撬门，必须向维护员说明谁要通过、为什么；
- 轻型组在`T0`从东侧高处入场，先获得观察位；
- 重型机仍到`T1`才从西侧公共坡道到达，所以轻组在第一阶段没有重机保护；
- 玩家没有获得永久门卡，这次许可只绑定这次行动。

## 没找全或主动离开会怎样

- 只看了坡道就返回：报告仍成立，全队按`T1`采用最保守的公共路线；
- 没去观景台：玩家不会知道维护走道直达高位，方案B只显示“轻队先进”，不额外预告观察优势；
- 走错路：只回到最近路口，不掉血、不长途重跑；
- 到`T1`仍未报告：早到窗口关闭，玩家可立即带现有信息离开，或继续观察但接受更晚的进场。

## 结果怎样写到后续

探索不奖励经验值。报告卡直接写：

```text
入场时间：T0 或 T1
轻队入口：东侧高位 或 西侧公共坡道
重机入口：西侧公共坡道
一次性许可：已获得 或 未申请
维护员回应：公共安全优先 或 仅本次放行
```

每一项只写入一个明确的状态处，下一屏不再自己重算一份：

| 写回项 | 写到哪个负责状态页 | 下一屏谁读 |
| --- | --- | --- |
| `入场时间` | 当前任务的出发时刻卡 | 下一张任务简报与战场部署 |
| `轻队入口／重机入口` | 当前任务的入口卡 | 下一张战场的初始站位 |
| `一次性许可` | 本地许可记录 | 对应维护门与路线合法性检查 |
| `维护员回应` | 地点人物回应记录 | 下次当地会谈或设备说明事件 |

下一场战术至少必须读取到达时间和入口。只有玩家真正走到对应门或再次见到维护员时，许可与人物回应才由各自的下一屏读取。若下游不读这些结果，这段探索就应被删除。
