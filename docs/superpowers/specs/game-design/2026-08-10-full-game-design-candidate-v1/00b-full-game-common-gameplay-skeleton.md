# 核心玩法总案的连续两周期示例：到底怎么玩

> 当前状态：`Candidate / supporting_continuous_example_after_00c / no_independent_rule_authority / core_design_review / user_not_decided`
>
> 这不是 C01–C03 的新剧情，也不批准万机馆房间、角色能力、正式数值或制作。下面只用一组中性人物、机体与地点，让你先判断这些系统放在一起像不像一款游戏。
>
> **版本边界：** [00c核心玩法总案](00c-core-game-design-master-review.md)是唯一玩法总案；本文只用一条中性案例演示总案规则在“返馆到再次返馆”的连续两个周期中怎样接力，不独立定义系统边界、提交规则或持久写回。若本文与00c冲突，系统边界和提交规则以00c为准；本文只保留案例内的先后顺序与已声明结果。`06a`、`06b`、`06c`与`06d`只放大专项的单页操作；`02a`与`04c`保留为旧稿。

## 一句话体验

玩家返馆看见上次留下的身体、关系、物件和世界后果，用三个时间格安排最多三张重要工作卡；暂选下一项责任后，再配置真实人员、机体、工具、路线和许可并最终承担。到场后的一个“现场准备位”通常只放轻探索或调查／工程实证其中一种，决定能否直接解决，还是进入以机器人身体、空间、保护和撤离为核心的战术。结果不会刷新，而会改变下一次返馆。

```text
返馆变化
→ 三格日程
→ 任务暂选
→ 编队与路线草案
→ 最终承担
→ 现场准备位（探索 或 调查／工程实证）
→ 直接解决 或 主战术
→ 一次综合摘要
→ 变化后的返馆
```

主战术承担主要复杂度。其它系统应该更短、更轻，但每次都要真实改变人物、身体、地点、工具、信息或下一项任务。

## 中性示例对象

本例不使用任何正式角色和地点：

- 岑安：调度员，负责比较任务与路线；
- 石稜：工程员，可以留馆维修，也可以随工程机出击；
- 闻野：档案员，负责核验证据，不会自动知道真相；
- 堰立：护卫机“堤”的合法操作者；
- 凌越：游击机“梭”的合法操作者；
- 护卫机“堤”：左臂承力受限，有独立主体回应；进入05f战术图时承担“锚机”职责，二者是同一测试身体；
- 游击机“梭”：快速换位，有独立主体回应，一窗只能把武器通道用于一种主要责任；
- 工程机：负责开门、实体测试、修复和救援；
- 局部扫描器、绝缘跨接头与便携地面支撑架：各一件；本例出发包只有两个任务工具槽，三件不能全带，也不能复制或同时出现在两处。

开场纸面种子：

```text
护卫机左臂受限
旧信号芯匣来源未知
一次停止建议尚未回应

每次返馆：3个时间格｜最多3张工作卡
材料2｜维修设备容量2｜运营资金3

任务A：断桥撤离，窗口正在关闭
任务B：旧中继实证，窗口较长
```

这些数字只服务这次纸面体验，不是最终平衡。

> 首读只需记住：`T` 是 Hub、航行和现场停留使用的长期时间；战术里的8秒只结算同一场战斗，不会推进一个 `T`。约45分钟只是希望玩家完成这一整轮所花的现实时间。下面先跟着12个屏幕走，技术换算可以跳过。

## 第一个周期：早出发，救到人但丢掉样本

### 屏幕1：返馆变化

- **玩家看见：** 返馆首页最多激活4张后果卡；本例是左臂受限、芯匣未知、停止建议未回应、两张任务合并成一张“世界请求继续变化”卡。每张只写“发生了什么、目前怎样、下一消费者是谁、若不处理会怎样”；更细事实留在只读记录中。
- **玩家输入：** 展开原因，或按一次继续进入日程。
- **真正取舍：** 本屏没有新取舍；事实已经在发生它的玩法里决定。
- **本屏不做：** 不让玩家批准事实，不发胜利评级，不自动修复身体。
- **结果写回：** 本屏只读机体、关系、物件和世界状态，不产生新结果。

### 屏幕2：三个时间格，最多三张工作卡

玩家面对四件想做的事：

```text
正式维修左臂：一张卡，连续占2格，材料-2，恢复完整承力
左臂临时箍架：一张卡，占1格，材料-1；只服务下一次完整任务，可在受限包络内跨多个战术周期承接，离场后报废
核验芯匣：一张卡，占档案员1格，缩小现场未知
处理停止建议：一张卡，占相关人物和机体1格，可能形成叫停边界
结束排班：放弃未用时间格，进入任务比较；不算工作卡，也尚未出发
```

- **玩家看见：** 三格时间带、工作卡`0/3`、人员／机体／设施冲突，以及两张任务的预计抵达时间。
- **玩家输入：** 拖卡、把不冲突的卡叠在同一格、检查冲突、逐格提交；没有已经开始的连续工作卡时，任一格完成后都能选择`结束排班，前往任务比较`。
- **真正取舍：** 连续两格彻修后较晚进入任务比较，或把临修与核验放在第一格并行后提早结束排班。
- **本屏不做：** 浏览不走时间；同一人、机体、房间或唯一工具不能并行；没用的时间格不能存到下周期。
- **结果写回：** 世界时间、身体功能、已知信息、材料、设施占用和未处理关系。

本例选择：

```text
第1格：左臂临时箍架＋芯匣核验，并行
随后结束排班，进入任务比较
放弃：后两格、第三张工作卡、停止建议
```

第1格结束后，材料`2→1`，左臂只有“下一次完整任务内受限承接”，芯匣频段可比对但来源仍未知。

“左臂临时箍架只服务下一次任务”，不是只准按一次按钮。它可以在同一任务的多个战术周期中承力，但一旦进入红区、再次受损、主动中止或离场就会失效，任务后必须报废。标准维修则占用连续两格，可靠地恢复功能；玩家可以在开工前撤回，开工后不能无代价中断。

### 屏幕3：世界图上的任务暂选

- **玩家看见：** 两张任务卡都显示请求者、早到／晚到差异、已知、未知，以及不选时由谁处理到什么程度。
- **玩家输入：** 点开、并排比较、暂选其中一张；仍可返回日程或换卡。
- **真正取舍：** 先救正在撤离的维护车，还是先取得中继证据。
- **本屏不做：** 暂选不扣时间、不锁队伍，也不自动判另一项任务失败。
- **结果写回：** 这里只保存草案，不改变世界状态。

本例暂选“断桥撤离”。

### 屏幕4：编队、路线与最终承担

默认页只显示三条职责：

```text
前线承力：堰立＋护卫机“堤”＋左臂临修条件
机动截击：凌越＋游击机“梭”＋扫描器
现场工程：石稜＋工程机＋绝缘跨接头
```

右侧同时显示一个很小的任务工具区：

```text
任务工具槽 2 / 2
[局部扫描器：游击机] [绝缘跨接头：工程机]

馆内候选
[便携地面支撑架：可替换上面任一件]
```

玩家把支撑架拖向已满的工具区时，系统不会暗中增加第三槽，而是让两个已占槽高亮并要求先替换一件：

- `扫描器＋跨接头`：能缩小未知频段并试开侧门，但没有额外身体支点；
- `跨接头＋支撑架`：能试开侧门并在桥边设置一次安全支点，但敌方样本与重量未知范围更宽。

`扫描器＋支撑架`也是合法草案，只是不能取得侧门供能动作。拖动、比较和撤回不消耗时间；最后长按`承担任务`时，队伍、路线和两件工具才一起锁定。只有出现拒绝、借用、权限不足或岗位冲突时，页面才展开相应原因。

- **玩家看见：** 谁承担什么职责、每台机体还能做什么、三件工具怎样争夺两个槽、工具在哪里，以及免费集体路线与付费先遣路线的区别。
- **玩家输入：** 换职责、拖动并替换工具、请求主体回应、选路线、看预演，最后长按`承担任务`。
- **真正取舍：** 免费一起进场互相保护，或花资金让轻机先行但队伍分开；同时决定这次留下扫描、供能或支撑中的哪一种能力。
- **本屏不做：** 不显示推荐战力；预览不收费；机体接受不等于物件所有者授权；工具不能复制。
- **结果写回：** 最后一次长按才把任务、路线、到达时间、队伍、身体、工具、许可／同意和资金一起锁定；若有冲突，系统先指明哪一项不成立，不会偷偷提交一半。

本例保留`扫描器＋跨接头`，让便携地面支撑架继续留馆；同时保留资金，选择免费集体路线。长按`承担任务`后才真正从 `T1` 出发；出程推进一格，于 `T2` 到场。

### 屏幕5：现场准备位——本例使用调查／工程实证

普通任务不会为了显得内容丰富而强制玩家先探索、再调查、再解谜。一个现场准备位通常只承担一个清楚问题：需要找路线和问人时使用轻探索；需要判断实体能否安全工作时使用调查／工程实证。本例是后者。只有同一个任务确实需要先找到对象、再验证对象，而且两段合计仍保持轻量时，才允许串联；否则删掉较弱的一段。

现场只有三个大地标：主桥裂损、关闭侧门和中央样本。玩家可以走近观察、询问维护员、做一次低风险测试。

调查给出两种合法办法：

- **直接工程解决：** 等待压力下降一个长期时间格，把跨接头留给地方队；三辆车可安全绕行，但样本随敌方离开，任务B窗口继续缩短。
- **立刻进入战术：** 不等长期时间，保留工具和争夺样本的机会；代价是机器人身体、桥和车辆真正进入风险。

这两项不是走近三个发光点后自动出现。本例实际做法是：

```text
观察主桥传感片 → 事实：有车辆经过时，旧裂纹读数会上升
询问维护员       → 事实：车队之间会出现一个完整卸载间隔
检查侧门控制盒   → 事实：机械锁完好，但远端供能已经断开
提出假设         → “跨接头只接本地控制盒，可以低风险开门”
配置并做空载试验 → 门抬起10厘米，桥读数没有变化；假设由“推测”变成“已验证”
```

试验通过后，玩家才得到“现在带着跨接头进战术开门”；若不做试验，则只能多等一个 `T`，由地方队按保守程序绕行。错误接法只让试验灯显示反向回流并退回配置，不会把桥炸坏。

- **玩家看见：** 每条事实来自哪里、仍不知道什么、两种办法怎样改变时间、工具与现场状态。
- **玩家输入：** 移动、观察、情境互动、比较证据、请求一次低风险试验，最后选择直接方案或战术方案。
- **真正取舍：** 用时间换稳定的直接解决，或用身体风险保住时间和改善结果的机会。
- **本屏不做：** 不搜满发光物，不猜作者密码，不用调查进度条自动开门。
- **结果写回：** 已知／未知、现场入口、长期时间、工具位置和战术初态。

本例选择立刻进入战术。

### 屏幕6：三个执行周期和一次撤离确认

这一屏只概括它在整款游戏里的位置；两条逐周期命令链、等待、主要失败和摘要统一以 [基础主战棋完整例 v0.3](05f-first-neutral-tactics-v0.3-decision-ladder.md) 为当前玩家版提案。

玩家看见三辆维护车、主桥、侧门、样本、两条压制方向和敌方下一窗意图。每个短决策窗的操作只有：

下面直接使用主策当前推荐的“短全队协同”：玩家在同一8秒周期内逐台编辑，点`本机排好`后仍可回来修改；只有长按`执行本周期`才锁定全队，并让敌方、车辆和环境共同推进。逐台行动仍是低负担备选，这里不再让四种旧方案等权占据主例。

```text
画短路线与朝向
→ 选一个主要身体动作
→ 预留一个反应
→ 查看确定结果／情报未知范围；条件反应另标触发时刻
→ 执行本周期并观看共同发生
```

前三个完整的8秒周期和撤离确认分别是：

1. **第1周期：**保公共设施路线选“承力＋压主路＋修桥”；保证据路线选“横身掩护＋截猎手＋开侧门”。
2. **第2周期：**保公共设施路线继续承力和压主路，并用跨接头开门为工程机准备侧路撤离；保证据路线则让工程机从维护带进入样本位，放弃维修停驶车。
3. **第3周期：**两条路线都明知锚机转身推离可减少身体压力，却会立即结束承力／掩护；玩家主动放弃自保，用锚定腿或保护框架的代价，换主桥完整或携样工程机撤出。
4. **撤离确认：**两辆车已经确定安全后，检查下一周期是否真有一项能够完成的具名改善动作；本例没有，所以只提交撤离，不摆一个只有风险的假选项。

第一窗的完整操作例是：

```text
1. 悬停敌方意图：主路压制机将封住车道；猎手预计第7秒取得样本。
2. 给护卫机“堤”画到西支撑位的短路线，朝东，主要动作选“结构承力”。
3. 给工程机选西支撑位旁边维护带的“修复旧裂损”；预览提示它必须等“堤”站稳才从侧面接口开始，两副身体不会占在同一位置。
4. 给游击机“梭”指定主路压制机，选“反压制”；本窗因此不能再预留截猎手。
5. 长按`执行本周期`后按纸面目标发生：第2秒“堤”站稳，工程机开始6秒修复；主路车辆因反压制继续，第7秒猎手取走无人拦截的样本，第8秒修复完成。
6. 第二窗打开时，敌方意图已经变成“重机撞支撑、猎手携样本撤离”，玩家面对的是新局面。
```

第5步是给读者理解因果的纸面预期，重点是判断前三条命令的先后、取舍和结果是否说得通。

- **玩家看见：** 敌人想做什么、三台机当前还能用哪些身体功能，以及每份计划放弃什么。
- **玩家输入：** 逐台编辑路线、朝向、主要动作和反应，再一次`执行本周期`。
- **真正取舍：** 撤离人员／设备、公共通行、证据和我方身体不能轻松全部保住。
- **本屏不做：** 不要求全灭，不靠等级碾压，也不用隐藏按钮强迫玩家只走一条路。
- **结果写回：** 车辆、桥、样本、具名功能损伤和敌方观察分别保存。

本例暂按“保基础设施”路线展示目标向量：

```text
两辆车撤离
主桥保持完整通行
样本被敌方带走
护卫机开场已有的左臂承力受限仍未修复
护卫机本次新增锚定腿轻度受限
敌方观察到游击机惯用站位
游击机弹药0／3｜工程机工具1／2
游击机与工程机撤出｜护卫机留在友方回收区等待拖带
```

左臂和锚定腿是两项不同的身体功能：前者是进入本轮前已经存在的伤损，后者是本场新伤，不能用一句“机体仍受限”互相覆盖，也不能用抽象胜利评级把它们抹平。

### 屏幕7：后台三级记录，前台一张摘要

- **玩家看见：** 一张“谁做了什么，所以留下什么”的任务摘要；可展开本地图事实和整次任务结果。本例未到章末，明确显示“不产生章结算”。
- **玩家输入：** 展开因果；若有尚未决定的工具借用或回程责任，返回相应负责页；最后按一次继续。
- **真正取舍：** 已发生事实没有取舍，只有尚未提交的保管、公开或路线责任可在自己的页面决定。
- **本屏不做：** 不重选战果，不突然发明追击，不连续弹出“单场”“整任务”“章末”三张奖励页。
- **结果写回：** 地图事实与任务结果在一次稳定提交中落入机体、世界、材料、资金、物件位置和敌方学习；章结算只在真正章末出现。

本例还有一项尚未发生、因此可以由玩家决定的保管责任：跨接头仍在侧门，合法所有者是测试馆。玩家在负责抽屉里选择`随队取回`，或先取得所有者授权后选择`借给地方维护组至T7`。本例准备后者；此时只形成待提交责任，直到最后一次`继续`成功，工具的位置、持有人和借期才一起改变。收藏页只读这份实物账，不能同时显示一只已经回馆的复制品。

任务合同在交付时明确提供`通用材料＋1（来源：地方维护交付）`和`运营资金＋1（来源：公共救援合同）`；因此最终按一次`继续`后，材料`1→2`、资金`3→4`，不是结算页凭空发奖。护卫机也不会从战场瞬移回馆：地方回收队先在友方区完成拖带挂接，回程清单写入`拖带返馆／到馆待检`，现场处理与标准返程合计推进一格，玩家在 `T3` 返馆。伤损、失物和关系延期不刷新；到馆不等于护卫机已经可再次出击。

玩家在返馆摘要上看到的是几条具体后果，而不是一笔含混的“工具-1”：扫描器随游击机回馆；跨接头获准暂留侧门，所以暂时不能再装载；游击机的三发具名弹药用尽；工程机剩一份现场耗材；左臂临时箍架已报废；护卫机被拖带返馆、完成诊断，但只允许在固定架上做低载试验，仍不能正常出击。

若玩家在摘要中途退出，下次仍回到同一张摘要和尚未处理的责任；已发生的事实不重选，资源和时间也不重复发放。

## 第二个周期：让失败和未选任务组成新问题

### 屏幕8：变化后的第二次返馆

```text
自己留下：
样本在敌方｜左臂承力仍受限（旧伤）｜锚定腿轻度受限（新伤）
护卫机已拖带返馆并完成到馆诊断：禁止出击，只准固定架低载试验
敌人学会旧站位｜停止建议再次延期

没选任务的具名处理结果：
档案组关闭旧中继外发｜没有重型身体，未取得内层日志
北入口坍落｜南入口仍可进入
```

- **玩家看见：** 少量合并后的变化事项，不是十几个红点。
- **玩家输入：** 展开来源，进入第二轮日程。
- **真正取舍：** 本屏不要求新取舍；下一屏才分配有限行动。
- **本屏不做：** 未选任务不冻结，也不自动变成最坏结果；身体、任务和工具不会瞬移复原。
- **结果写回：** 本屏只读取上一周期和具名外部行动者造成的变化。

### 屏幕9：维修，还是把经历分成身体范围与协作条件

第二轮给出两套方向：

```text
恢复与反制：
正式维修锚定腿连续2格＋核验敌方诱导信号
得到正常站稳与转向；左臂旧伤仍在；材料耗尽；关系继续延期

发展与协作：
第1格低载训练＋信号核验，并行
第2格用训练结果处理停止建议
得到左臂40%轻载的物理范围，以及一条明确叫停边界；左臂与锚定腿都仍未正式修好
```

- **玩家看见：** 上一场真实承接记录仍分成两个问题：身体在什么范围内可行，以及相关主体愿不愿意按什么边界再尝试。
- **玩家输入：** 先排低载训练和信号核验；训练写出物理范围后，再把读数带进关系页讨论停止边界；逐格提交。
- **真正取舍：** 优先修复这次新伤、恢复可靠站稳，还是带着两项受限功能保留材料并发展一项条件清楚的新做法。
- **本屏不做：** 不发技能点，不用重复刷同一动作解锁；关系不变成好感货币，协议不等于未来永久同意。
- **结果写回：** 训练只写身体适用范围；关系页另写主体条件；知识与长期时间分别记入自己的卡片。

低载训练先回答物理问题。护卫机固定在测试架上，工程员逐级加到40%轻载；操作者与护卫机可以同意、附条件或拒绝参加**这次训练**。训练完成只写`40%轻载内物理可行`、角度和停止读数，不代表它们已经同意下一次任务使用。

第二格才“处理停止建议”。护卫机“堤”提出：`左臂载荷进入红区时，我要有权中止继续承接。` 玩家把刚得到的40%读数带进谈话，与操作者、工程员和“堤”讨论一个可执行条件：红区时由“堤”发出停止，操作者必须释放承接。相关主体可以接受、附条件或拒绝，玩家不能替它们点“同意”。两条记录都成立后，下一次出发包才显示`条件承接｜可提议`；真正战术动作仍要在当时发出具体提案并取得当次回应。

这次低载训练消费一格时间和一单位本周期测试设备容量，但不消费材料。它读取`T3`到馆诊断的具名放行：固定测试架锁住锚定腿，只测试左臂的停止阈值，不要求护卫机走动或站稳。因此“锚定腿仍受限”不会被文案偷偷忽略；若诊断没有完成、放行条件失效或测试架被其它工作占用，这张训练卡必须显示冲突并不可提交，护卫机继续保持不可出击。

这三道门不能合成一张“协议解锁”印章：

```text
真实行动证据＋低载训练＝身体在什么范围内可行
身体范围＋关系回应＝可以按什么协作边界提出动作
本次具体动作＝仍要重新提案，并由当前操作者与机魂回应
```

身体用法与关系条件怎样保持清楚，见[长线系统白话操作](06b-long-term-systems-player-walkthroughs.md)；本例只需看清，成长是“多了一种有依据、可提议的做法”，不是获得无条件数值加成或永久服从。

本例选择“发展与协作”。

### 屏幕10：变化后的任务卡与第二次承担

世界图已经不是第一次的原始版本：

```text
追踪敌持样本：
敌人知道旧站位，第一次公开意图可能是诱导

旧中继内层取件：
外发已停，北路关闭，只剩南路
可用身体承力进入，或等待完全断电后安全进入
```

这里沿用第一轮已经演示过的提交方法：先比较并暂选，再准备人员、机体、工具与路线，最后长按`承担任务`才写入。新的取舍只是“追自己丢掉的样本，还是完成别人只做了一半的公共问题”；选择旧中继不会删除追踪任务，资金为零也必须有合法保底路线。本例在第二个Hub时间格结束时到达`T5`，随后承担“旧中继内层取件”，出程一格于`T6`到场。出发包读取新的身体协议、关系边界、地点入口和敌方学习；跨接头仍借在地方，因此显示为`不可装载／T7到期`，不会凭空补一件。

### 屏幕11：第二次调查可以直接解决，不强制战斗

玩家检查外发器、支撑柱和内层波形后，确认可以由本地人员保留停止权，等待完全断电，再分段取回日志。

具体操作是：先读到“外发功率为0，但内层储能仍为36%”；再把维护日志中的一次回流事故与三个断路器对照。玩家提出`先断外发、等待缓冲组自然放电、最后开内门`，把三步拖到试验板上，用替代负载做一次试验。若试验灯平稳熄灭，方案变为`已验证`；若先开内门，试验灯反向闪烁，系统指出回流来源并让玩家重排。玩家不是背答案，而是在实体反馈中确认顺序。

- **等待安全断电：** 多走一个长期时间格，无战斗、无人受伤、日志完整；样本追踪任务继续远去。
- **带电进入：** 保住追踪时间窗，但会进入一张对付主动防御设备的战术图。

- **玩家看见：** 为什么这里能直接解决，以及多走一格会影响哪张任务。
- **玩家输入：** 观察、配置断电顺序、请求开始、观看或跳过实体反馈。
- **真正取舍：** 保存身体与完整证据，还是保存追踪时间并承担战术风险。
- **本屏不做：** 不把战术当调查答错的惩罚；跳过演出不改变结果；失败试验不炸毁装置重来。
- **结果写回：** 中继安全态、日志知识、长期时间、跨接头借用位置和追踪任务的新窗口。

本例选择安全断电，从`T6`等待到`T7`后取回日志。这说明探索／调查可以直接解决或进入战术，但不意味着重大冲突都能绕过主玩法。

第二周期也不是“做两格Hub＋瞬移完成任务”，而是一条连续的时间线：

```text
T3 返馆：护卫机待检，扫描器归馆，跨接头仍在地方
→ T5 完成两格Hub：形成条件协议，但两处身体限制仍在
→ T7 安全断电：无战斗，日志取回，跨接头借期到期
→ T8 再次返馆：只在到馆后打开章末摘要
```

### 屏幕12：真正章末才出现章末结算

为展示第三级，本中性例假设这里正好是这一章的结尾。旧中继的地图／任务事实先在`T7`封存，标准返程推进到`T8`，章末摘要只在再次返馆后打开：

- 地图层记录安全断电、日志取回、无人受伤；
- 任务层记录旧中继请求完成、跨接头借期在`T7`到期并生成归还待办、安全等待和标准返程各推进一格；
- 章层只封存长期差异：条件承接协议、停止边界、中继安全状态、收藏知识层、样本仍在敌方以及下一轮需要。

- **玩家看见：** 三层因果合并成一张章末摘要。
- **玩家输入：** 先在负责页处理尚未提交的公开／展陈或借用请求，再按一次继续。例如玩家点“芯匣信号家族”收藏卡，会同时看见`知识：已确认同一信号家族`、`实物：仍由地方保管`、`公开权：尚未取得`。可选择只存内部档案、向保管者请求公开一段说明，或暂不展陈；本例选择内部档案，所以图鉴出现可查条目，但展柜保持空位，库存也不会复制一个芯匣。
- **真正取舍：** 已发生事实没有取舍；玩家只对未来公开范围和唯一物责任作决定。
- **本屏不做：** 收藏页不复制实物，不因入库自动补完背景；章结算不重复发前两层奖励，也不在这里突然选择下一航向。
- **结果写回：** 长期动作、关系、地点、知识层、唯一物位置、世界任务和下一周期入口。

`T8`最终返馆快照是：

```text
左臂仍受限，但多了一项条件协议
锚定腿也仍为轻度受限，下一次编队必须显示这一限制
停止边界已经说清
芯匣来源仍未知，信号家族已确认
跨接头借期已在T7到期但实物仍在地方，归还交接完成前不能从库存装载
样本追踪任务已经变化，没有消失
```

第二轮不是替第一轮补作业，而是把局部失败、未选任务、成长和世界变化重新组成新问题。

## 与总案的关系

本例只帮助理解[核心玩法总案](00c-core-game-design-master-review.md)的连续循环，不增加新的评审问题。若两个周期读起来不像同一款游戏、返馆像打卡，或失败只像罚补作业，请直接在总案对应部分批注。
