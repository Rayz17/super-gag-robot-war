# C01–C03怎样复用公共玩法：未来适配预览

> 当前状态：`Candidate / future_adaptation_preview / optional_reading / not_current_review`
>
> 本页只预览“公共玩法方向审定后，已验收的前三章可以怎样成为三个适配场”。它不计入本轮交付，不要求现在判断，也不声称C02／C03已有完整关卡方案。它不修改Reader，不设计正式地图，不给每话新造玩法。

## 先固定同一套游戏语言

前三章都只使用这套公共顺序：

```text
看见问题与敌方／环境Intent
→ 移动、观察或询问，取得够用的路线与条件
→ 选择机体，画短路线并定朝向
→ 选择一个主要身体动作和一个可能的反应
→ 提交，观看身体、敌人和环境共同推进
→ 按目标、伤损、地点和责任结算
→ 把结果带到下一段故事或返馆周期
```

章节可以少用其中一段，但不能为比赛、事故或巨构场面另造一套控制方式。故事已经固定“发生什么”；玩法要让玩家亲手决定“怎样做到、付出什么、留下什么”。

## 三章各自只验证一个层次

| 章节 | 主要复用 | 本章新增的唯一主要维度 | 玩家真正操作什么 | 不由玩法改写的Reader事实 |
| --- | --- | --- | --- | --- |
| C01 | 基础身体战术、轻探索、连续事故与撤离 | 移动、朝向、阻挡、保护和非歼灭目标 | 找到撤离／接近路线；让不同尺寸的机器人站到正确位置；保护人和设施；在连续场面中带伤继续 | 馆守Z起身并行动；万机馆最终离开地面 |
| C02 | 复用C01身体规则；加入非致死竞技与证据调查 | 功能损伤、身体Intent和实证链 | 从动作姿态读出对手意图；以得分、迫停、越线、缴械等非致死目标交手；把原件、身体痕迹和维修连续性组成结论 | 无牌一号以三比二赢得冠军；事故发生并被救下；章末人物与机体去向不变 |
| C03 | 复用身体战术、调查和停止；让城市提供真实工程条件 | 多格地点身体、载荷路径、许可与安全中止 | 在桥、巨环、轨道、泊位等大型结构上分配承力；先核验本地控制权；让职业机取回自己的工具；在必杀技与城市安全冲突时执行停止 | 工务城危机被解决；社勇王与万机馆取得既定章末关系；公共泊位与天空铸环出口成立 |

## C01：先让机器人身体本身好玩

玩家在C01不需要先学角色权能。开场的轻探索只做一件事：通过地标、展品状态和工作人员回应，知道人从哪撤、巨型身体从哪通过、哪些位置不能承重。

进入战术后，每次判断都回到三个问题：

1. 哪台机体现在能到达危险点？
2. 它到达后应该朝哪边，才能用完整身体阻挡或保护？
3. 玩家愿意让哪项设施、路线或身体功能承担代价？

一个Candidate操作例：玩家先让轻型机沿侧路接近裂口，再让大型机器人转身占住主通道。大型身体一旦横住，就不能同时追击另一侧敌人；轻型机若提前越过安全线，则能更早截击，却失去大型机保护。两种安排都使用同样的移动、朝向、动作和反应操作。

C01的结算重点不是击破数，而是：谁撤出了、哪条路仍可用、哪台机体留下什么具体功能损伤，以及这些后果怎样进入下一场连续事故。

## C02：把“打赢”改成身体表达与证据判断

C02不重新教学移动和朝向。比赛把基础动作换成非致死目标：取得有效触碰、迫使对手越线、完成指定动作、保护自身关键功能，或在对手失稳时选择停止追击。

玩家仍然读Intent，但Intent不再只是“敌人准备攻击谁”，还包括：

- 对手身体正在蓄哪种动作；
- 哪一侧承重已经接近极限；
- 它是在争一分、诱导反击，还是保护仍未完成的动作；
- 哪种接触会造成比赛允许的功能受限，哪种会越过安全边界。

调查段也不做资料问答。玩家要把三类东西放到同一张证据板：舞台或档案原件、两台实机的身体痕迹、跨年份维修连续性。正确结论必须至少跨两类证据；白鸢后来的图只能说明后来的创作关系，不能反推更早的机魂来源。

Reader已经固定冠军赛三比二，因此逐话适配时必须另行决定哪些分数由玩家完整操作、哪些由短演出交代，以及失手怎样继续而不伪造“结果自由”。在这个问题明确前，不能用三个相同战术小关硬拼成三比二。

## C03：让地点和工作关系进入同一张战术图

C03增加的不是更多技能，而是“地图本身也有身体”。桥梁、货运环、泊位和巨构接口都要显示：占用范围、载荷路径、可承受动作、当前控制者和停止条件。

一个Candidate操作链可以是：

```text
点击城市结构，看见它正在把重量传向哪里
→ 询问本地负责人，确认谁能开门、断电或叫停
→ 让职业机提出它愿意怎样取回自己的工具
→ 用万机馆或大型机体承担一段明确载荷
→ 预留“读数进入红区即停止”的反应
→ 提交后，看城市结构、职业机和敌方巨构共同变化
```

这里的许可不是七海点一下就产生。她只能核验真实授权链、发现签名被冒用或帮助把请求送到正确的人；本地负责人、驾驶者和机体仍要分别作出回应。白鸢可以把现场视野和路线条件并排，却不能画出一条现实中不存在的通道。纪存可以提出目标和协调信息，不能遥控整座城市。

C03的停止也是一个主动玩法结果：玩家在强力动作落下前看见它会把力量传进医院、住宅或城市主梁，于是选择取消必杀、改成支撑、拆缆或保护。停止不是“没打爽”，而是用身体和关系完成更困难的胜利。

## 未来每章适配时只填这一张小卡

```text
本段调用的公共系统：
本段唯一新增维度：
玩家从第一屏到结算的操作链：
至少两种可理解的方案：
不行动／局部失败怎样继续：
已验收Reader固定事实：
本段允许变化的代价与责任：
下一段实际读取哪一项结果：
```

如果一段玩法不能使用这张卡说清，就先回公共系统修订；不能靠增加专属UI、一次性QTE或新资源把它包装成“本章特色”。

## 未来适配时再用这三项检查

本页不要求你现在回答。当公共玩法方向审定、真正进入C01–C03适配时，再用下面三项检查：

1. C01先建立身体战术、C02加入非致死竞技与调查、C03再加入地图身体和许可，这个学习顺序是否自然？
2. 固定Reader大结果、只让玩家决定达成过程和持续代价，是否能保住故事同时仍有足够能动性？
3. 三章都复用同一组移动、朝向、动作、反应、调查与结算操作，是否比逐章发明新玩法更像一款完整游戏？
