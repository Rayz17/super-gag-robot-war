## 0. 先不管术语：三个画面、一条完整操作路线、另一条可选胜法

这段快速例采用主策当前推荐的“短全队协同”：玩家在同一战术周期里逐台编辑三台机，最后按一次`执行本周期`，敌我与环境才共同推进。它用来讲清C2怎样嵌进当前主方案，不代表用户已经批准最终时制。

### 画面一：先看出危机

中央平台放着一只样本，敌方小型机已经伸出夹爪。它原本想从右边的大门离开；门上方显示“约 6 秒后可关闭”。地图上还有一条北侧货运坡道和一条更窄的紧急撤离叉路。

我方有三台机器人：小型机能上高处瞄准夹爪，长条工程机能关门或切断结构件，方形重机能在坡道口封路或接住倾斜平台。

### 画面二：六步操作走完两段决策

1. 先点东门的“谁有权关”问题，再从可用来源里选七海：核验当班安全主管已经签发、仍有 16 秒有效期的临时关门授权；七海只确认真假、授权对象、范围和撤回条件。协作介入从`0／2`变成`1／2`。
2. 再点重机与北坡的“怎样绕开人员”问题，选纪存，并勾选检修区人员报告与重机自愿共享的正面视野：纪存整理一条去低位承台的候选路线，再由驾驶者和机魂分别回应。协作介入变成`2／2`，回应本身不另收费。若任一方拒绝，请求不会进入计划，已经花掉的协调也不返还；玩家可接受双方兼容的条件、换路线／身体，或放弃这项职责。
3. 点工程机，把路线拖到东门控制台，转动朝向让工具端对准接口，选 `关门`。
4. 点重机，按已接受的绕行提案把终点放在低位承台，选 `横盾封路`；再点小型机到高处射位，保留一次拦截。
5. 按 `预览`：界面用普通句子说“东门会先关；重机晚两秒到；敌人还有北侧路线”。同时展开敌方行动意图：`本周期：取样后走东门；东门被挡就停下，不临时换路。下一周期：改走宽坡道；若携样路线都被实体封住且继续前进会触发拦截，则放下样本，从窄路空载撤离。`打开`提交摘要`检查整队得失，再长按`执行本周期`。门落下、敌人刹停、重机到位，但敌人还没有放下样本。白鸢以后只能估计这个公开条件可能触发；真正迫退仍要由门、重机和压制线共同造成。
6. 新战术周期的协作介入重置为`0／2`，但第一周期关门以后，`切东侧承力销`的另一条胜法已经关闭，额度重置不会拿回没选的路线。可用人物仍由出发前锁定的岗位和通信决定，不能临场免费换人。点“敌人何时会放弃样本”问题，选白鸢（`1／2`）；再点“重机还能不能承力”问题，选陆衡（`2／2`）。这意味着本周期没有纪存的新路线汇总，也没有七海的撤回复核。玩家据此让小型机在宽货运坡道前建立压制线、重机继续封路、工程机转到中央控制节点执行本地安全接管。敌人若继续带样本，就进不了宽坡道；只有放下样本、收起夹爪，才挤得进窄应急叉路。

### 画面三：结果不是“扣了多少血”

上面六步得到的是`封撤离＋迫退`。`切节点＋功能缴械`不是同一计划的随机结果，而是玩家从第一周期就改选白鸢、陆衡和切节点动作。

**封撤离＋迫退。** 敌方放下样本，收起夹爪，空手钻进宽度只够它自己通过的紧急叉路；样本停在本地控制区的安全挡边，状态是“现场待回收”，工程机同时把中央控制节点交回本地安全控制。场地没被破坏，敌人也完整逃走，下次会记住这种封路方法。

**切节点＋功能缴械。** 先花两次协作介入：白鸢比较两案并标出敌方佯动，陆衡确认“重机承接后只切东侧承力销”在物理上可行。设施已有规则决定能不能切；陆衡只判断会不会塌；驾驶者和机魂分别决定是否承接；工程机才真正执行切割。任何一项不成立，都不能提交。条件成立后，玩家点重机在低位承台四点稳固并承接平台；点工程机对准东侧承力销，预览确认后切断；最后点高处小型机，只选择暴露出来的取样夹爪。承力销同时承载敌方给中央控制节点的远程供能，切断后节点进入中立隔离。样本保住了，但平台和我方重机都留下需要维修的伤。

到这里已经可以判断核心方向：角色只给带来源的核验、比较、工程判断或可拒绝提案；工程机、重机和小型机才执行关门、封路、切割、压制与接管。详细地图为了方便定位，后文才把低位承台、宽坡道、中央节点、窄叉路和东侧承力销写成 `G／C／N0／R／P2`。

### 五分钟评审到此为止

本页不另开一轮批准，只为[核心玩法总案](00c-core-game-design-master-review.md#活的机群与人物组牌同伴会改题不替玩家解题)保留一个信息、方案、权限、工程判断和主体回应的完整操作例。新总案已将它改造为角色组牌与活机群；下文不再是当前规则权威。

## 先看这一眼：玩家为什么会犹豫

敌方取样机已经把夹爪伸向中央样本。它离东侧撤离门只差十几秒。

你的三台机器人分别在低地、维修坡道和高架下方。屏幕顶部只显示：`本周期协作介入 0／2`。玩家先点战场上的具体问题，例如“这条路是否有人”“谁有权关门”“切掉以后谁来承力”；右侧才列出本次出发包里确实在岗、通信可用且拥有相应来源的人物，而不是常驻技能头像。一个具体问题最多显示3名可选人物；下表为了比较四类帮助才同时列出四行，不是战场上会常驻四张人物卡。本例的出发包确实特意占用了四个现场／远端岗位，因此少做了相应的留馆工作：

- 纪存：给重机找一条不会压到维修人员的拦截路线；
- 白鸢：比较“切断承力节点”和“关闭撤离门”两套计划，并指出敌方佯动可能骗谁转身；
- 七海：核验你是否真的有权调用 `N0` 的本地安全链关闭东门，而不是把“能接上控制台”误当成“有权操作”；
- 陆衡：核验切掉东承力销以后，高架会倾到哪里、样本和机器人会不会一起掉下去。

四个方案都合理，但本周期最多完成两次协作介入。次数重置不等于人员免费刷新：谁在岗、频道是否接通、来源是否过期，都会继续到下一周期；战斗中不能把留馆角色临时换进来。

玩家面前不是“哪个技能伤害更高”，而是两种不同的胜法：

1. **切节点＋功能缴械：** 让工程机切掉一个已经核验过的承力销，迫使取样机在倾斜高架上暴露夹爪；轻机从高处打坏取样功能。敌机仍能走，但带不走样本。代价是现场留下真实结构损伤和维修债。
2. **封撤离＋迫退：** 先取得临时关门权，让工程机关闭东门；重机在不伤害维修人员的低位承台 `G` 横住宽坡道 `C`，轻机在 `C` 前做压制。取样机判断继续带样本会被截住，主动放下样本、收起夹爪，再从窄叉路 `R` 完整撤退。场地保住了，但敌人也完整活着，下一次会记住这套封路方法。

两种解都不要求全灭，也不靠等级碾压。设计上先用公开普通事实说清基础身体层的两种解：一个用场地损伤换确定缴械，一个用空间封锁换敌人撤退；再用角色C2说明玩家如何取得信息、核验许可和协调提案。角色C2不会凭空多出一条能赢的路。

下面先完整走一遍第二种方案。读完以后，应该能直接想象自己在屏幕上点了什么、为什么没法什么都要。

## 1. 这个中性题面究竟要赢什么

中性玩法例暂名 **“K-17 中继栈桥”**，不属于任何正式章节。

主要目标有两个同时成立的条件：

- 二十秒关键窗结束时，样本不在敌方保管链中；
- 中央中继节点 `N0` 不再受敌方控制，至少进入“本地安全控制”或“中立隔离”。

次要目标：

- 两个承力销 `P1/P2` 尽量都保住；
- 不击穿任何机器主体的核心安全区；
- 不让占用回报已经过期的封闭检修湾承受巨机载荷；未核实前按可能仍有人处理。

任务开始前还存在两条真实但范围不同的现场规则：当班安全主管可以把东门／中央节点的临时安全操作转授给本地登记的工程执行者；K-17设施权利人公开的紧急结构隔离规则，则只允许在“人员已清空、工程可行、承接身体同意”三项都成立时切断一枚承力销。七海可以核验前一条回执，陆衡只能判断后一条的物理条件；两人都不能凭自己创造权限。

这意味着“打爆取样机”不是默认答案。敌机放下样本并撤退，也可以是完整的主要目标成功；但它会以完好身体和观察记录进入未来敌方学习账。

## 2. 玩家在屏幕上看到的战场

### 2.1 一张地图有三层高度

```text
                      北侧双路口
                 C 宽货运坡道 ↑   R 窄应急叉路 ↑
                 可带样本通过      只容空载小机通过
                         \       /

高度2  维修天桥       [低墙掩体]──[轻机可达射位 H2]
                          │梯／短跃

高度1  西坡道 ── P1 ── [样本 S + 中继 N0]─┬─ P2 ── [东撤离门 E]
                  ▰          ▰低掩体       └── C/R 分叉

高度0  我方起点 ── [低位承台 G：正对 C] ── [封闭检修湾：占用回报已过期]
          轻机      1×2工程机        2×2重机
```

初态中，针行机在西南低地，轨匣在 `G` 西侧，砧城在检修湾西口而不是湾内。`G` 的正面恰好对着能携带样本的宽货运坡道 `C`；重机在 `G` 横起盾梁可以封住 `C`，但 2×2 身体进不了窄叉路 `R`。敌方只有放下样本、收起外张夹爪后，才能空载从 `R` 撤离。

重机向北有两条可画路线：穿湾的短线和绕 `G` 的长线。但检修湾的占用回报已经过期，短线初始只显示为“物理上可绘制／人员状态未确认”的黄线，不是已知安全路线。机魂的现场感知会在具体请求时说明里面仍有人，并因转向与载荷风险拒绝该路线。

玩家切换视图时，不会换成三张彼此无关的地图：

- **物理层**显示高度、坡道、低墙、足迹、转向扫掠区和两个承力销；
- **控制层**显示 `N0`、东门和本地紧急隔离开关由谁控制；
- **信息层**显示敌方意图来自哪台传感器、是否过期，以及佯动后的条件分支是否已被识别。

高度不是“站高处加 15% 命中”。这里的高度直接改变动作：

- 高度 2 能看过低墙，打到取样机外露夹爪；地面射线会被低墙完全挡住；
- 1×1 轻机能走梯或短跃上维修天桥；1×2 工程机只能走西坡道；
- 2×2 重机不能登一格宽的维修天桥，只能在高度 0 的承台支撑高架或封路；
- 从高度 1 跌落不会抽随机伤害，而是按落差、身体姿态和接住它的承力链结算。

### 2.2 掩体和承力点不是装饰

- `▰低掩体`完全遮住低位功能件，但不遮住站立机体上部传感器；玩家必须点具体身体部位看射线。
- `P1/P2`是可破坏承力销。切掉一个时，样本台向该侧倾一层并生成一条新坡面；重机若在 `G` 正确朝向并完成稳固，可以接住载荷。两个都断，平台会坠落，属于当前目标不可接受的继续态。
- 东门关闭后是实体阻挡，不是地图上亮一个“禁止通行”图标。门体若被撞坏，会留下可穿越缺口和现场维修债。

### 2.3 多格机器人必须真的转得过来

屏幕会把单位当前占位画实，把转向需要扫过的区域画成半透明扇面：

- 1×1 轻机原地转身只改变朝向；
- 1×2 工程机横竖互换时要扫过一个 2×2 区域，前端工具舱必须最后对准接口；
- 2×2 重机转 90 度要有完整 3×3 扫掠区。检修湾入口只有两格宽，所以它一旦正面开进去就无法原地横过来；这不是“多花一点移动力”，而是这条路线物理上不成立。

当玩家拖出不成立的路线，预览直接变红并写：`重机右后腿扫掠区与检修湾墙体重叠；无法转向`。按下确认不会侥幸挤过去。

### 2.4 实际战术屏幕长什么样

```text
┌ 目标：样本未撤出 / N0夺控 ─ 协作介入 0/2 ─ 战术周期 00:00–00:08 ┐
│                                                                  │
│  [物理] [控制] [信息]               中央地图：高度、足迹、路线、Intent │
│                                                                  │
│  主目标／次要目标                              当前选中：轨匣 1×2    │
│  样本：本地安全                                前格工具：正常         │
│  N0：敌方                                      后格电源：正常         │
│  P1/P2：正常                                   朝向：东               │
│                                               动作：接管 / 切割 / 救援 │
├──────────────────────────────────────────────────────────────────┤
│ 计划：轨匣 0–6s关门｜砧城 0–8s绕行｜针行 0–6s上高处｜[提交摘要] │
└──────────────────────────────────────────────────────────────────┘
```

中央地图永远保留主要目标、敌方行动意图箭头和当前足迹；点开人物建议时，只替换右侧卡片，不把战场整个盖住。屏幕底部的具体命令带可以随操作节奏改变，但所有方案看到的事实、未知项和身体后果必须相同。

## 3. 三台示例机：身体先于数值

这些是匿名示例身体，不是正式机体设计。每台只有 3–4 个真正改变战场的动作。

### 3.1 1×1“针行机”：到高处看清并打功能

身体拓扑：

```text
传感桅杆 ── 提供远距识别与功能瞄准
    │
躯干转台 ── 右侧脉冲针 / 左侧牵引索
    │
两条反关节腿 ── 移动、短跃、制动
```

动作：

1. `短跃路线`：跨一格落差或上维修天桥；落点必须可见且能制动。
2. `功能针击`：只打已经识别并有射线的外露功能，例如取样夹爪、武器转台或传感桅杆；没有“随便选核心暴击”。
3. `四格压制线`：对穿过这条线的移动施加制动／中止压力，消耗一发；友军将进入时按预设条件停火。
4. `预留闪避／拦截`：占用本轮反应，不触发也不能改成免费攻击。

若传感桅杆受限，它仍能移动和压制已知走廊，却不能再精确选择一个未由友军共享的功能件；若右臂失效，移动与牵引仍可用。

### 3.2 1×2“轨匣工程机”：前端做事，后端供能

身体拓扑：

```text
[前格：履带头＋测量头＋切割/接口臂]──[后格：电源匣＋卷缆器]
```

动作：

1. `履带路线／对接口转向`：前格必须真正抵达并朝向目标接口。
2. `接管或隔离`：在具名权限成立时接管 `N0/东门`；没有权限时只能读取或执行现场已经公开的紧急隔离。
3. `切割承力销`：只有工程核验给出允许的销、方向和承接条件后才开放；工具刃消耗一次。
4. `架设／救援`：把卷缆接到承台、样本或受限机体；会占用后格电源，不能同时高速移动。

如果前格工具臂受限，工程机仍能移动和供电，却不能切销或接接口；如果后格电源匣受限，接口读取还在，但切割和卷缆关闭。敌人从哪一侧攻击因此会改变职责，而不是只减总血量。

### 3.3 2×2“砧城重机”：用四条腿和朝向承担空间

身体拓扑：

```text
[左前承力腿]──[右前承力腿]
       \  前胸盾梁  /
          中央腰架
[左后驱动腿]──[右后驱动腿]
```

动作：

1. `重步路线／90度转身`：转向必须通过 3×3 扫掠检查，不能穿人、穿墙或穿过另一台身体。
2. `四点稳固`：四腿都接触有效地面时，把正面承力提高到最高档；移动会解除。
3. `盾梁封路`：占住两格宽通道，并把正面来力导向脚下支撑；侧后方仍是弱面。
4. `推回／承接`：对接触中的身体或倾斜平台施力；必须声明推向、接触边和承力后果。

若任一前腿受限，重机仍能走，但不能在该侧完成四点稳固；若一条后腿失效，它可以原地当支架，却不能安全转身。它的价值来自“这个身体能占住、接住、挡住什么”，不是较高的防御数值。

### 3.4 先关掉角色协作，看清基础身体层

同一张地图先看一版 **不出现纪存、白鸢、七海、陆衡，也没有协作介入** 的基础层。为了把身体战术单独说清，任务简报在开场一次性给出完成任务所需的普通事实：

- 检修湾仍有人，穿湾路线不可用；
- 当班安全主管已经批准本次使用东门紧急隔离，并允许工程机随后把 `N0`转为本地安全控制；
- K-17设施权利人的紧急结构隔离规则允许在人员清空、工程可行和承接主体同意时切断一枚承力销；
- 现场工程报告已经确认：重机在 `G` 正向稳固时，只切 `P2`不会让平台整体坠落；
- 敌方当前动作和“携样本路线全被封锁时优先保全身体”的行为规则都公开；这一版暂时不考信息战。

这不是正式游戏里永远白送答案，而是设计分层：先让读者判断移动、朝向、足迹、阻挡、功能损伤和反应是否已经组成一道完整战术题。

在这版里，玩家不用任何角色按钮也必须能发现两种解：

1. **封撤离＋迫退：** 工程机关东门，重机绕 `G`横住 `C`，轻机上高处后在 `C`前留压制反应；下一周期工程机接管 `N0`。敌人继续携样本就没有安全出口，只能放下样本后经 `R`撤离，两个主目标同时完成。
2. **切节点＋功能缴械：** 重机先在 `G`承接，工程机切 `P2`使平台倾斜并切断敌方给 `N0`的远程供能，轻机从高处只打坏外露夹爪。敌人身体仍能撤离，但带不走样本；`N0`进入中立隔离，两个主目标同时完成。

本轮评审的分层要求是：基础层必须自己说清两条身体解，不用“再加一个纪存提示”或“白鸢直接给答案”遮盖空洞规则。下面的角色协作层则收回开场白送的占用确认、工程结论、许可核验和敌方后备条件，让不同人物帮助玩家改善信息质量与协作效率；地图、身体动作和两条物理解不变。两层都属于本轮可评审的核心设计。

## 4. 第一轮：先点具体问题，再从合法来源里选两次协作

每个 8 秒战术周期暂定最多完成两次协作介入。顶部只显示`本周期协作介入 0／2`；玩家先点一个战场问题，再选择一名拥有合法来源的人物，完成一次输入并取得一条结果后，计数增加一次，未用次数不累积到下一周期。这个上限表示团队此刻能认真协调多少件事，不是角色魔法点，也不能绕过权限、工程条件、主体回应或身体不在场。

本节为了比较四类建议，假设出发包已经把四人安排在合法的现场／远端支援位置，通信也成立。正式循环里不会白送四张头像：这四人只是任务范围内已经安排好的**可调用来源**；点一个具体问题时，协作栏常显其中2–3个真正匹配的来源，而本周期实际只能完成两次介入。谁留馆维修、谁随队、谁占远端岗位、通信是否接通，先由出发包锁定；未出勤、无设备或无合法信息来源的人不会出现在协作栏。因此多带一种协作来源，就会少一个留馆工作或别的支援岗位，这也是编队成本。

所有协作结果都用同一张信息卡，不让“估计”看起来像“批准”：

`已确认／估计／未知｜来源与共享者｜观测／收到时间｜有效期｜置信依据｜何时失效｜下一位读取者`

方案提交前另列四道彼此独立的门：`信息够不够｜权限是否成立｜物理是否可行｜驾驶者与机魂是否接受`。一次协作介入只包含“一次完整提案＋一次明确回应”；直接接受回应里已经列出的反提案不再收费，若改目标、机体、动作或新增信息源，就要使用新的介入，或退回玩家手动画保守方案。

在当前主推荐的短全队协同纸案里，协作介入只作用于尚未提交的具体动作：玩家可以在逐台编辑期间调用角色，但长按`执行本战术周期`后，不能看见敌人真走哪条路再临时买一次帮助；那时只能触发提交前已经预留的保护、截击或中止。每个共同世界周期总计两次介入，下个周期才重置，不会因为切换三台机而刷新三次。若用户改选逐台行动备选，同样的两次额度属于整个共同世界周期，只能在当前单位确认前使用。

本文完整推演选择 `纪存＋七海`。

## 5. 一次机魂拒绝：请求失败，但战术周期没有死掉

玩家点纪存的路线卡，再点砧城重机。地图出现两条候选：

- 蓝线：从检修湾穿过，六秒到北坡口，最快；
- 白线：绕到低位承台 `G`，八秒到位，慢两秒。

玩家试点蓝线。驾驶者先回应“操纵上能进去，但出来后无法横转”；砧城机魂再对自己是否参与这项具体动作单独回应。它的拒绝不是随机“心情不好”，而是：

```text
拒绝：检修湾内仍有两名维修人员。
这具身体进入后无法在两格通道内横转；任何前向受击都会把载荷传给湾内。
可接受条件：清空检修湾，或改走低位承台 G。
```

系统保持请求记录，但不执行路线。纪存已经使用的这次协作介入不返还，因为路线拼接和请求确实发生了；驾驶者与机魂的回应本身不是玩家购买的资源，也不额外收费。

玩家选择回应里已经列出的白线 `改走 G`，不再花一次协作；驾驶者与机魂都接受这条替代。预览变绿：重机在高度 0 绕行，最后用 3×3 空地转身，正面朝北稳固。它晚两秒到位，却不会压到人，也没有夺取机魂控制权。

如果玩家仍强点原路线，确认键保持不可用，并写明：`主体拒绝；没有合法身体动作`。合法替代不是“提高好感后强迫成功”，而是接受条件、换身体、换路线或放弃这一职责。

## 6. `封撤离＋迫退`的具体点击

### 玩家使用鼠标时怎么点

1. 点击东门 `E` 的权限标记，再从合法来源中选择七海。右侧显示：`签发者：K-17当班安全主管／授权对象：K-17现场安全组／可转授：仅本地登记工程执行者／实际执行：轨匣／有效期：16秒／不得锁死应急叉路`。点击 `核验`后，七海只确认这份既有回执真实、对象匹配且尚未过期；协作介入显示`1／2`。若对象不匹配或不可转授，结果就是“不成立”，玩家只能请求真实权利人、使用公开紧急停止，或换方案。
2. 点击砧城重机与北坡口的路线问题，再选择纪存，勾选检修区占用回报和砧城自愿共享到本周期末的正面视野。玩家看到蓝线被驾驶者或机魂拒绝后，选择双方都接受的白线 `经 G 拦截`；协作介入显示`2／2`。
3. 点击轨匣工程机，按住左键从后格拖到控制台旁。滚轮或 `R` 旋转预览，让前格工具舱对准接口；点动作条 `临时关门`。
4. 点击砧城重机，沿白线逐点拖到 `G`。终点拖动正面箭头朝北，选择 `盾梁封路`，并预留 `样本携带者进入时稳固`。
5. 点击针行机，拖到高度 2 射位；本战术周期只完成上高处并预留闪避，不提前建立压制线。压制动作留到敌方公开改走宽货运坡道 `C` 的下一战术周期。
6. 点击中央 `N0`，检查工程机下一战术周期的接管路径。屏幕显示当前周期只够关门，不能同时接管节点。
7. 点击右下`提交摘要`。这一步不锁定计划，只列三件真正需要承担的事：东门将在第6秒关闭；砧城第8秒才完成转身；敌侧锤机的佯动分支仍未识别。玩家长按`执行本周期`后，才锁定全队命令并推进世界。

右键撤销最后一段路线；`Esc`退出当前对象；越过“执行本周期”后不能因为敌人真的改线而免费倒带。

## 7. 敌人怎样佯动、取样和重新规划

敌人不读取玩家还没提交的路线。它在战术周期开始时有公开意图和一个预先存在的条件分支。

### 第一个 8 秒战术周期

- 取样机意图：`4 秒取得样本；随后走东门`。
- 侧锤机表面意图：`锁定北承力销 P1`。
- 未识别分支：`若砧城转身朝北并离开 G，则侧锤机改冲 N0`。

侧锤机的炮口、脚步和传感器都真的朝 P1 做动作，所以这不是系统给玩家假图标；它用一个低成本动作试图诱使重机离开承台。选择白鸢比较方案可以提前标出这个异常。不选白鸢，玩家只能根据可见身体语言猜，或用站位容错承担未知。

执行到第 4 秒，取样机建立保管链；第 6 秒，东门在合法权限下关闭。取样机的原路线被实体门挡住，它按预先登记的“安全中止”规则停在最后安全格，而不是穿门或瞬移换路。

这次提交也关闭了一扇机会窗：门体落下后，`P2`开始承担关门结构的载荷，本次行动不再允许改走“切P2”路线。第二轮换选白鸢和陆衡，只能把已经承诺的封路路线做得更可靠，不能免费拿回第一轮没选的切销解。

### 第二个 8 秒战术周期

第 8 秒的新决策窗，敌方更新公开意图：

```text
取样机：东门关闭 → 携样本改走宽货运坡道 C。
后备动作：存在，但当前传感来源不足，触发条件未知。
侧锤机：佯动未拉走砧城 → 改为牵制工程机，不冲入已稳固正面。
```

这叫重规划：敌人根据已经发生并且它实际看见的门、身体和火线改变下一战术周期的计划。它不能在玩家提交以后偷偷选择一个从未存在的克制技能。

第二个战术周期的协作介入重新显示`0／2`。此时至少有四个具体问题：改线后的敌人会怎样保全身体、`G`还能否持续承载、取样机的新位置怎样转报给针行机、既有授权是否收到撤回。玩家先点前两个问题，再分别选择白鸢与陆衡；这不是从四个头像里领取固定答案。东门原有16秒授权仍覆盖关键窗，代价是本周期没有纪存的新路线汇总，也没有七海的撤回复核；界面把两项标成“沿用上一周期来源／将在本周期末到期”。玩家是在接受信息老化，而不是四个人轮流全拿。七海即使被选，也只核验撤回通知并提醒 **K-17当班安全主管／现场工程机** 按既有规则执行安全停止，不直接操作地方设施。

白鸢给出的不是答案，而是一张统一格式的条件假设：`估计｜来源：刚发生的东门改线、取样机身体姿态、公开保全规则｜收到：第8秒｜有效：本战术周期｜把握约七成｜敌方出现新动作即失效｜下一读取者：针行机压制计划`。正文结论是：`若携样本路线 C 被实体封住，同时在火线内继续前进会触发拦截，取样机可能优先保全身体，放下样本后改走 R。` 玩家可以依此下注，也可以把这格协调留给别人并承担未知。

玩家让：

- 针行机在高度 2 建立四格压制线；
- 砧城在 `G` 四点稳固，盾梁朝向北坡；
- 轨匣转到 `N0`，用前格接口臂执行本地安全接管。

取样机进入压制线后，机动状态在这条火线内由`可自由通过`变成`继续前进会触发拦截`，但核心、腿部与取样夹爪都没有受损。它看到东门关闭、携样本路线 `C` 被 2×2 身体封住，继续带样本只会失去退路，于第 16 秒触发预先登记的“优先保全身体”判断：把样本放在本地控制区的安全挡边、收起夹爪，再从不被东门授权锁死的窄叉路 `R` 撤出高价值区域。离开压制线后，这个限制不写成持续身体伤；敌机以完整身体离场。样本此时只是“现场待回收”，不是演出替玩家生成的新保管人。白鸢只是提前给出了一个可能条件；真正结果仍由敌方初态、玩家动作和同一规则核结算。

玩家赢的是一次可解释的迫退，不是剧情脚本忽然让敌人逃跑。

## 8. 另一条完整解：`切节点＋功能缴械`

玩家若在第一个战术周期选择白鸢＋陆衡，操作会明显不同：

1. 白鸢比较两案，指出侧锤机对 `P1` 的攻击是高概率佯动；真正危险是取样机的东撤路线。
2. 陆衡读取现场测量，核验：砧城在 `G` 正向稳固时，可以只切 `P2`；平台会向东倾一层，不会整体坠落。
3. 提交栏分开显示三项：`权限：设施权利人的紧急结构隔离规则已覆盖一枚销`、`物理：陆衡核验成立`、`主体：砧城驾驶者与机魂分别接受承接`。陆衡只负责第二项；任一项不成立都不能切。
4. 玩家让砧城先在 `G`稳固。若承接条件尚未完成，轨匣的 `切 P2`按钮显示`不可提交：承接条件未成立`，并给出先稳固或换路线的替代。
5. 轨匣以前格对准 `P2`，消耗一格工具刃。承力销失效后，东段变成倾斜坡面，东门路线被断开；`N0`同时失去敌方远程供能，进入中立隔离。
6. 取样机为保持平衡，把夹爪抬到低墙之上。针行机从高度 2 选择已经识别的 `取样夹爪`，使用一次功能针击。
7. 结算为 `取样功能：正常 → 失效`。敌机仍能移动、观察和撤退，但保管链断开，样本留在倾斜台的安全挡边内。

这条解的纸面代价：

- `P2`从正常变为失效，新增一项场地维修债；
- 轨匣工具刃消耗一次；
- 针行机消耗一发精确弹；
- 砧城左前腿因承接倾斜平台从正常变为受限，下一场不能在左侧做四点稳固；
- 敌取样机的取样夹爪失效，但主体安全、机动和撤离仍成立。

与`封撤离＋迫退`相比，它更确定地废掉敌方取样功能，也不需要东门权限；代价是破坏公共结构并把我方重机伤损带出战场。本轮要求两条解在责任、结构代价和敌方后果上明显不同，不能只是少一发弹药的差别。

## 9. 如果玩家不行动，或者计划失败

05f的维护车／主桥题面属于00c的`无法形成合理继续态`：少于两辆车撤出时，救援前提已经不存在，因此回稳定检查点重试。本页属于`主要目标失败，但世界仍有合理后续`：样本和节点已经改变，却仍能继续追踪或隔离。两者不是同一张地图，也不是两套失败规则。

不行动不是隐藏的第三种好结局。玩家可以查看后果：

- 当前战术周期不关东门：取样机第 4 秒取得样本，第 12 秒通过东门；
- 不处理 `N0`：敌方继续拥有控制与观察来源；
- 两项都放弃：主要目标失败，战斗不会伪装成胜利。

只要故事仍有合法继续态，失败会转入后续任务，而不是随机删除我方角色。失败卡标题直接显示`主要目标失败／世界继续`：

```text
样本：已被敌方带走
N0：仍受敌方控制并继续提供观察
身体／结构：保留本次实际损伤和消耗

[追踪样本]       下一段截停携样本敌机；N0继续泄露信息
[先隔离N0并撤离] 下一段先切断敌方观察；样本追踪窗口缩短
```

敌人以后获得一条有来源的反制：它见过我方身体和信号，不是凭难度等级突然加强。下一次相关部署开始前，玩家会看到这张卡：

| 敌人学到了什么 | 证据来源 | 玩家怎样提前看见 | 什么时候触发 | 至少两种回答 | 结果写回 |
| --- | --- | --- | --- | --- | --- |
| 我方常用重机横住宽路，再用高处火线迫使携带者放下物件 | K-17撤离机体的观察记录；取得时间和可信度可见 | 任务简报显示“敌方已针对低位承台准备一次诱导冲击” | 我方再次用同尺寸身体、同承台、同一时点封路 | 换身体或换封路时点；先在承台做假动作，再转切节点方案 | 记录这条敌方判断被强化、被证伪或开始过期；下一场只读取已发生记录，不读玩家草稿 |

局部操作信息不完整时，必须拒绝提交：

- 权限记录不完整时，东门按钮显示 `未知，不能当作批准`；可改用已公开的现场紧急隔离，或换到`切节点＋功能缴械`。
- 2×2 转向被墙挡住时，砧城停在最后安全占位；不会穿模，也不会扣一笔抽象移动点后原地成功。
- 工程承接条件尚未成立时，`切 P2`不可提交；系统不让玩家用未知结构开奖。
- 敌方在提交后改变了已经公开的身体位置时，功能针击按真实射线打到掩体或安全中止；日志必须写清是哪个新观测触发，不能暗改命中率。

失败继续不是“随便点都行”。它保留已经发生的样本归属、结构伤损、弹药、机体功能、敌方学习与责任记录，下一段必须真实消费这些后果。

## 普通 C2 完整例到此为止

第 4–9 节已经交代玩家先点什么问题、角色怎样提供有来源的帮助、介入花什么、谁执行身体动作、主体拒绝后如何继续，以及成功／失败如何留下后果。请只把这些作为[核心玩法总案](00c-core-game-design-master-review.md#活的机群与人物组牌同伴会改题不替玩家解题)的旧例对照，不单独批准。

### 10. 未来若比较时制，哪些玩法事实必须保持不变

这里的“二十秒”是同一个战场动作片段，不是提议把一轮改成二十秒。它由两个完整 8 秒战术周期和第三周期前 4 秒组成。四版必须读取同一初态、敌方意图、身体动作时长和最终业务状态，只改变玩家怎样提交命令。

对照使用上面的 `封撤离＋迫退`方案，目标后态固定为：东门关闭、`N0`本地安全控制、样本留在安全挡边等待现场回收、取样机从窄叉路 `R` 撤出、砧城稳定但当前战术周期的反应已经用完、针行机消耗一发。

| 版本 | 玩家实际怎样操作这二十秒 | 玩家主要在烦恼什么 | 不能偷偷获得的优势 |
| --- | --- | --- | --- |
| A 显意图交替激活 | 选轨匣，用 2 点行动代价走位＋关门；敌方激活取样机；选砧城并处理拒绝后改走 G；敌方激活侧锤机；选针行机上高处并预留闪避。下一轮再建立压制、稳固和接管，直到第 20 秒后态关闭 | 先动谁会把什么机会交给敌人；单次决策最短 | 不能预先草拟整队时间轴，也不能看完所有敌方激活再改首台命令 |
| B 短脉冲同步 | 在 0–8 秒时间轴上同时摆好轨匣关门、砧城绕行、针行机上高处，检查冲突后一并提交；8–16 秒再排压制、稳固、接管；16–20 秒只看已承诺的撤离收束 | 三台身体在同一时刻会不会撞、迟到或漏出空窗 | 不能得到更精确的敌方真相；完整时间轴只显示当前已经可知的事实和误差 |
| C 交替锁计划＋同步 | 玩家先锁轨匣关门，敌方锁取样；玩家锁砧城路线并接受机魂替代，敌方锁侧锤；玩家锁针行机。全部锁定后同步执行 0–8 秒；下一战术周期重复 | 现在锁哪台，是否会把自己尚未承诺的意图暴露给对手；已经锁的单位不能回头重写 | 不能在最后一台锁定时免费修改第一台；敌方也只能按它合法观察到的锁定信息行动 |
| D 传统阵营回合 | 我方阶段自由选择轨匣、砧城、针行机的行动顺序，并为砧城／针行机预留反应；随后敌方按战术周期开始时冻结的意图执行。双方阶段合起来只关闭一个 8 秒战术周期，第三周期在第 20 秒收束 | 怎样避免整队先手把敌人压成木桩，以及该不该牺牲一次攻击来留反应 | 不能让车辆、门、样本或任务截止时点在每台单位行动后多走一次；不能在敌方阶段临时买一个未预留反应 |

四版都必须回答同一因果问题。若某一版需要更弱的敌人、更长的关门时间、更多协作介入次数或更完整的预测才能完成，就不是公平对照。

这张表只保存对照关系，不再把四种方式列成等权候选。当前总案已采用短全队协同；逐台行动只是未来低负担模式的研究备选，其余旧时制只作比较参考。本页不另开一次时制裁决。

C2只作用于尚未越过本版锁定点的动作：A在确认当前单位前，B在`执行本周期`前，C在锁定该单位计划前，D在确认该单位动作前。越过锁定点后不能看见结果再临时调用角色，只能触发预留反应。四种对照都共用“每个共同世界周期两次介入”，不会因逐台行动或分阵营而重复刷新。

### 11. 完整／精简／跳过：观看长度不同，结果相同

重大交接只在玩家已经完成因果链以后进入演出。`封撤离＋迫退`的完整版约二十秒，五拍如下：

1. **接上真实权限：** 轨匣前格咬住控制台，经七海核验的既有临时授权范围沿门体逐段点亮；镜头同时保留取样机夹住样本的画面。
2. **门落而敌不停：** 东门砸落，取样机在最后安全格急停，脚下刮出火花；侧锤机向 `P1`虚晃一击，砧城没有上当转身。
3. **大身体完成替代路线：** 砧城四条腿依次踏入 `G`，最后一次 90 度转身把盾梁横在北坡，不进入曾被机魂拒绝的检修湾。
4. **高处压制形成退路判断：** 已经就位的针行机在 `C` 前建立压制线，射线从低墙上方切过；东门与携样本路线同时变红，但主体安全区和空载叉路 `R`没有被锁定。
5. **主动放下而非被剧情救场：** 取样机松开夹爪，样本落入本地控制区的安全挡边，标记为“现场待回收”；它收拢身体后从窄叉路 `R`后撤。镜头最后回到玩家地图，`N0`显示本地安全控制。

玩家选择精简版时，只保留关门、砧城横身和取样机放下样本三次关键接触；选择跳过时，立即短切回地图并弹出三行结果摘要：样本留在安全挡边等待现场回收，`N0`已恢复本地安全控制，敌取样机已撤离且我方本周期的反应和弹药已如实消耗。完整、精简与跳过写入同一结果；演出不能替玩家击坏夹爪、取得权限、回收样本或迫使敌人凭空放下样本。

### 12. 规划、暂停和结算后都能点开的因果日志

规划时打开，尚未发生的条目标`预计`；执行暂停时打开，已结算的条目标`已发生`，其余仍是预计；结算后打开则保留完整因果。玩家点任一结果，日志按“来源 → 请求／计划 → 接触 → 变化”展开，而不是只写“成功”。默认层只用中文，内部状态键仅在专家层展开。

```text
04.0s  [已发生] 敌取样机完成实体接触
       来源：上一战术周期公开意图
       结果：样本由本地安全挡边保管 → 敌机正在取样

06.0s  [已发生] 东门关闭
       来源：七海核验过的既有 N0／东门 16 秒临时授权 + 轨匣实体接口动作
       结果：东侧路线开放 → 被实体门阻断

08.0s  [已发生] 敌取样路线安全中止
       来源：门体实体阻挡 + 敌方预先登记的安全中止规则
       结果：原东撤计划取消；下一战术周期允许重规划

12.0s  [已发生] C 坡道压制线建立
       来源：针行机高度 2 射线 + 1 发弹药
       结果：携样本进入 C 会触发机动控制

14.0s  [已发生] N0 接管完成
       来源：轨匣前格对准接口 + 已核验授权仍在期限内
       结果：中央节点由敌方控制 → 本地安全控制

16.0s  [已发生] 取样机放弃样本
       来源：东门阻断 + C 坡道压制 + 砧城实体封路 + 预先登记的保全身体规则
       结果：样本由敌机取样中 → 现场待回收

20.0s  [已发生] 敌方撤出高价值区域
       结果：主目标两项成立；敌方保留完整取样功能与观察记录
```

若玩家当时不知道侧锤机的佯动分支，日志也不能事后伪装成玩家早已知道。它应标注：`当时未知；战后由敌方动作证实`。

### 13. 简洁、标准、专家：同一规则的三种读法

三种信息层不能变成三套难度或三套物理结果。

它们也不等于难度档。若以后调整挑战，只能改变提示出现得多早、预测解释量、安全纠正窗口、敌方合法改策频率和局部检查点；事实来源、权限有效期、驾驶者／机魂回应、物理碰撞、每周期协作上限和已经提交的结果都不能随难度偷偷改变。这沿用[核心玩法总案的公共难度纪律](00c-core-game-design-master-review.md)。

#### 简洁

- 敌方头顶只显示 `要做什么／大约何时／目标是谁`；
- 路线同时显示实线圆标`能到`、三角虚线`会迟到`、叉形断线`转不过去`；颜色只作辅助；
- 身体卡只显示“还能做什么”和“会失去什么”；
- 提交前只列三个最大风险，不显示公式。

适合第一次玩和只想抓住战场问题的玩家。它不会替玩家选择切销还是封门。

#### 标准

- 显示准备、作用、收招时间；
- 显示具体身体依赖、掩体射线、权限来源和未知条件；
- 敌方行动意图显示已确认条件分支；
- 可以比较两个已保存的玩家方案。

本文正文默认描述标准层。

#### 专家

- 展开每 0.5 秒事件、转向扫掠格、承力／功能差值与观察来源；
- 可过滤控制链、主体同意、物理接触和 AI 重规划；
- 可逐事件回看同一计划的完整／精简／跳过版本为何得到相同结果。

专家层给更多解释，不给隐藏敌情、额外协作介入次数或更高命中。

### 14. 无障碍不是降低规则完整性

- 规划阶段没有强制倒计时；执行可暂停、逐拍、0.25×／0.5×／1×播放。
- 高度、敌我、确认／估计／未知同时用文字、形状、纹理和线型表达，不只靠红绿色。
- 所有语音、警报和震动都有字幕、屏幕图标或边缘脉冲替代；震动可完全关闭。
- 路线拖拽可切换为“逐格放路点”；长按确认可改为单击、双击或按住；所有键可重映射。
- 可启用 `自动加入明显安全中止`。系统会明确显示它占用哪个反应槽，不会免费替玩家获得更好结果。
- 可固定当前单位与目标的两张卡，避免在地图、日志和身体树之间反复记忆。
- 因果日志支持逐条朗读顺序、字号、背景对比、关键字简写和“只看这次失败原因”。
- 动画可永久设为完整、精简或跳过；故事与业务结果不因演出选择缺失。

这些是当前无障碍设计要求，最终键位、字号、对比和语音反馈在后续界面方案中再定稿。

### 15. 附录索引：这些细节在支持什么

这里不是第二份批注表，只说明附录与[核心玩法总案](00c-core-game-design-master-review.md#活的机群与人物组牌同伴会改题不替玩家解题)的关系：

- 身体足迹、高度、转向、承力地形和两条打法，支持总案第 1 项“主战棋是否成立”；
- 两次协作介入、信息来源、真实权限、驾驶者／机魂回应和拒绝替代，支持总案第 4 项“角色 C2 是否像协作而非技能按钮”；
- 敌人佯动与学习、完整／精简／跳过、时制对照和无障碍，是支持总案主推荐的说明；本页不另开一次批准。

所有批注仍统一带回核心玩法总案；本文不会自动改 Canon、Reader、Runtime 或章节设计。

### 16. 以后继续细化时再处理的项目

- 三台示例身体的最终尺寸、速度、动作时长、射程、损伤阈值和镜头尺度；
- 每个战术周期最多两次协作介入是否合适，以及不同场景是否需要别的团队负担；
- 四种时制各自最小 UI、教程顺序、敌我提交公平性和存档边界；
- 敌方佯动在低情报时应该显示多少，才既不撒谎又不会被一眼看穿；
- 多格单位在狭窄地图中的转身频率，是否会从“身体感”变成纯操作摩擦；
- 功能损伤带出本场交锋后，维修、编成、剧情和失败继续怎样共同消费；
- C2 角色方案随着全队人数增长怎样防止每周期弹出十几张卡；
- 机魂拒绝由哪些稳定状态与剧情事实驱动，如何避免看起来随机或被攻略表彻底算死；
- 两种解的真实数值差、敌方反制、重复游玩变化和最优解收敛问题；
- 正式地点的承力点、门、权限和人员位置必须来自上游地点档案，不能照搬这张中性图临时生成。

### 17. 本页的结论边界

当前最诚实的结论是：**这是一套可以被阅读、批注和继续收束的角色C2玩法提案；它还没有迁入正式游戏规则。** 本轮只判断操作链、人物边界、两条解与失败后果是否值得保留。
