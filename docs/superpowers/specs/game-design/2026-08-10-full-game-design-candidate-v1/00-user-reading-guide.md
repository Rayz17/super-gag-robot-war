# 从这里开始：核心策划与玩法说明评审入口

> 当前状态：`Candidate / integrated_core_design / product_direction_approved / no_production_signature_requested`

本轮只交付一组**你能直接阅读和批注的核心策划说明**。我们现在不做程序、原型、真人测试、资产生产或逐章关卡；也不拿表格数量和机器检查冒充玩法成立。

## 现在只需要读什么

如果只读一份，请读：

**[《超GAG机器人大战：万机残响》核心玩法总案](00c-core-game-design-master-review.md)**

它是唯一玩法总案，也是唯一正式批注入口。它负责讲清：

- 整款游戏从返馆、准备、选任务、现场行动到结算怎样循环；
- 主战棋每一轮具体做什么，机器人身体、敌方行动意图、预备反应、规则精通和四类战斗题型怎样形成深度；
- 普通战为什么不靠大招也好玩，焦点战和高潮战怎样由玩家亲手搭出名场面；
- 活的机群、人物出席与五张战术牌怎样改变打法，却不替玩家排完整方案；
- 城市巡访、残响深潜、返馆、手修、布展、成人关系、战报、LLM陪伴和世界内Meta怎样组成长期RPG；
- 奖励、情绪、难度、无障碍、资源、失败延续、内容复用和全剧复杂度怎样控制。

原八项方向已经归并并获得用户接受；总案现在是整合后的唯一设计基线，不再要求你重答一轮问卷。仍可直接在正文旁写“这里不懂／不喜欢／想换方向”；意见只用于修改Candidate，不会自动批准制作或修改Canon。
