**读法：** 先把“敌方意图”理解成敌人头顶公开的当前行动预告，把“决策段”理解成玩家安排一轮短动作的时间。其他英文缩写和数据表都可以不看。

读完这个例子后，如果想知道这些操作怎样变成全游戏共用规则，再读 [主战棋白话规则](05b-main-tactics-rules-in-plain-language.md)。

## 1. 玩家这一关要做什么

四个短决策段内，让三辆撤离车里至少两辆从地图右侧离开。

同时有两个可选目标：

- 尽量不让断桥完全垮掉；
- 不让敌方猎手把中央样本箱带走。

三个结果分别记账。救出两辆车不等于桥自动修好，也不等于样本自动保住。玩家可以为了主要目标主动放弃一个次要目标。

## 2. 地图一眼看懂

```text
                 向右是撤离方向 →

主路   车1  车2 ── 护卫机 ── [断桥危险段] ── 敌重机1 ── 出口
                    │              □样本箱          │
                    │                                 │
侧路   车3 ── 游击机／工程机 ── [关闭的闸门] ── 猎手＋敌重机2 ── 出口

橙色直线危险：敌压制机正在盯主路和侧路的长直线。
```

我方三台机体不是“坦克、输出、奶妈”换皮：

- `护卫机`体重大，能站稳、挡路、接住冲撞和拖拽物件；转身慢。
- `游击机`跑得快，能压制一段路线或预留闪避／拦截；弹药有限。
- `工程机`能开闸、临时加固、救援和拖车；操作时必须停住，容易暴露。

## 3. 玩家在屏幕上先看到什么

进入决策段时，屏幕不会先弹出技能表，而是显示三个问题：

1. `敌人想做什么`：每台已确认敌机头上有箭头、目标和预计接触时间。
2. `现在什么最危险`：断桥应力、侧路闸门、车辆路线和样本归属都在地图上。
3. `我方身体还能做什么`：点击单位，动作旁直接写身体条件和执行后会失去什么。

例如第一段开始：

- 敌重机1：`4秒后冲入断桥，目标车1`；
- 敌重机2：`6秒后攻击侧路闸门`；
- 猎手：`5秒后接触样本箱`；
- 主路压制：`进入橙色走廊会被迫减速或中止动作`。

如果玩家没有在探索中扫过样本箱，猎手的目标会显示成“中央物件，身份未确认”，而不是系统撒谎。

## 4. 一轮具体操作：选择“开侧路分流”

### 第一步：先改车辆路线

玩家点车1，在主路与侧路之间的连接点画一条折线，把它设为“闸门打开后改走侧路；若闸门未开，就在连接点停车”。

UI 立即回答：

- 这不是瞬移，车要按自己的速度行驶；
- 若工程机来不及开门，车会安全停车，不会穿门；
- 改走侧路可以避开断桥，但会和车3争用狭窄路线。

这一步没有消耗机体行动，因为车辆是自主对象；玩家改变的是已获允许的路线计划，不是直接驾驶。

### 第二步：工程机开门

玩家点工程机，画一格短路线到闸门机械端，再选 `打开闸门`。

屏幕出现一条 8 秒预览：

```text
0–2秒  工程机走到机械端
2–6秒  停住并操作闸门
6秒    闸门预计打开
6–8秒  原地观察；若闸门被同时破坏则立即中止
```

旁边有一条红色提示：敌重机2也预计在第6秒打到闸门。结果带不是隐藏抽签，而是来自两项具名未知：敌重机受压制后的实际接触时刻为 `5.8–6.6秒`，闸门旧锁止机构的释放时刻为 `5.8–6.2秒`。前者来自尚未确认的敌机稳定功能，后者来自缺失的维护记录；玩家补做扫描或找到记录就能缩小对应范围。预览把分支条件直接列出来：

- `敌机接触晚于闸门释放0.2秒以上`：工程机先完成并安全打开；
- `两者相差不超过0.2秒`：敌重机在释放过程中撞击，闸门变成“打开但锁止机构损坏、不宜重型单位通过”；
- `敌机先接触`：操作被安全中止，闸门仍关闭。

### 第三步：游击机选择保谁

游击机一次不能同时保护闸门和样本。玩家看到两个有意义的选择：

- `压制侧路东端`：让敌重机2进入时减速，提高开门成功率；猎手更可能拿到样本。
- `拦截猎手`：保住样本；工程机和闸门要独自承受重机冲击。

本例选压制侧路。玩家画到侧路内侧的短路线，选择一段扇形压制区，并设置安全条件：“车3进入火线就停火”。预览显示消耗一发弹药；未触发停火时不会伤到友军。

### 第四步：护卫机决定承力位置

护卫机可以：

- 站在断桥西端 `稳固`，接住敌重机1，让车2继续走主路；
- 移到连接道口 `保护`，若车1转侧路时被撞就替它承担；
- 直接推敌重机，但会增加桥应力并失去本轮保护反应。

本例选择第一项。玩家画一个很短的前移，面向东，选择 `稳固`，并预留“敌重机撞入时承接”的反应。当前例子的敌机质量、速度和桥面支撑均已确认，因此 UI 给出确定预览：护卫机不会位移，左臂会从正常降为受限。

### 第五步：提交前看一次冲突摘要

屏幕只列真正要决定的三件事：

```text
主要目标：车1/车3准备走侧路，车2继续主路
已知代价：游击机消耗1发；护卫机左臂将变为受限
未解决风险：猎手大概率先接触样本；敌机接触为5.8–6.6秒，闸门释放为5.8–6.2秒，分支条件已在时间轴列出
```

玩家可以返回改尚未提交的计划；按下提交以后，只能靠事先预留的停止／反应条件改变动作，不能免费倒带。

## 5. 提交后发生什么

执行不是一段不可读的长动画。相机先按正常速度播放，真正的交接点会短暂停顿：

1. 工程机走到闸门机械端；
2. 游击机的压制线建立，敌重机2减速；
3. 敌重机1撞上已稳固的护卫机，护卫机没有被推开，但左臂承力功能 `正常 → 受限`；
4. 工程机在第6秒打开闸门，敌重机2晚半拍撞到闸门外侧的锁止机构；门保持打开，但机构局部损坏，重型单位不能安全通过；
5. 车1开始转向侧路，车3继续前进；
6. 猎手接触样本箱，建立“正在取得、尚未撤离”的保管链。

回放后，玩家点护卫机左臂，会看到清楚原因：

```text
敌重机冲撞力
→ 护卫机正面稳固抵消位移
→ 承力集中到左臂
→ 左臂功能降为“受限”
→ 下个决策段仍能挡路和保护，但不能安全拖拽重物
```

这就是“身体损伤”，不是 HP 从 82 变 61。受伤机体不会立刻退出故事，而是改变下一轮能承担的职责。

## 6. 下一轮为什么仍有判断

第一段结束后：

- 两条路都还存在，但侧路闸门已经受损；
- 护卫机守住主路，却失去部分拖拽能力；
- 游击机少一发弹药；
- 工程机还剩一次高价值工具使用；
- 猎手拿到了样本，但尚未从右侧边界离场。

玩家现在必须决定：

- 让游击机追猎手，还是继续保护侧路车辆；
- 让工程机修闸门，还是去桥边降低应力；
- 让受伤护卫机继续挡重机，还是后撤保全身体。

上一轮没有“解完一道题”，而是用代价把战场变成了新的问题。

## 7. 另一种真正不同的战法

玩家也可以完全不开侧路。第一段采用和前一方案相同粒度的操作：

1. 玩家点车1和车2，保留主路路线；点车3，把条件改成“停在侧路安全点，不抢占连接口”。这等于先承认车3可能无法在本次主要撤离中离场。
2. 玩家点工程机，画到断桥西侧维护点，选择 `临时加固`。预览显示消耗一份支撑材料，能降低本段桥面恶化，但工程机不会去开侧路闸门。
3. 玩家点游击机，移到中央连接道，画出覆盖猎手路线的压制扇区，并设“车辆进入时停火”。这样更容易保住样本，却不能减速撞向闸门的敌重机2。
4. 玩家点护卫机，在断桥支撑点面向东 `稳固`，预留“敌重机1冲入时承接”。它仍可能让左臂受限，但能把冲撞留在桥西端。
5. 提交前摘要显示：车1和车2可以继续主路；桥面消耗一份材料后仍处于危险态；样本更安全；车3大概率本段留在原地；侧路闸门将被敌重机2继续破坏。

执行后，敌重机1撞上护卫机，工程机完成加固，车1和车2继续向出口移动；游击机迫使猎手减速，样本仍在原位；敌重机2撞坏关闭的侧路闸门，车3只能等待。第一段结束时，主路方案取得了更集中的防线和更安全的样本，却把桥、护卫机左臂和车3的后续都压成了下一轮问题。

这条路线的关键判断是“用一个大身体撑住危险面”；开侧路路线的关键判断是“用工程时间换空间分流”。如果实际原型最后只剩一套固定点按顺序，这张地图就算设计失败，不能说玩家没学会。

## 8. 失败怎样继续

- `桥断了，但两辆车仍从侧路撤离`：主要目标成功，地方交通永久受损，回馆出现维修债与后续路线变化。
- `样本被带走，但两辆车撤离`：主要目标成功，敌方以后会使用从样本学到的反制；不是读档理由。
- `一辆车撤离、一辆受困、一辆损坏`：如果故事仍有可继续状态，Operation 进入救援／谈判后段；若四段结束仍没有两辆车的合法撤离可能，才从稳定检查点重试。
- `我方机体伤损`：带伤进入下一 Encounter 或返馆维修；不会因一局失败被随机永久删除。

失败继续不是“怎么都算赢”。主要故事目标仍有明确底线，只是次要损失会成为后续内容，而不是统一 Game Over。

## 9. 主角团能力以后怎样加入

这张基础地图先关闭所有主角能力，证明移动、身体、地形、反应、Intent 和目标本身好玩。通过后才加入：

- 纪存：把两个现场来源拼成一条可行路线，请求某台机体协作；不能替它移动。
- 白鸢：比较“开侧路”和“守主路”的两三种条件结果，显示哪些未知会让预演偏离；不保证未来。
- 七海：核验某个闸门或设备的真实授权链，能拒绝无权操作；不能凭空给权限。
- 工程组：用测量把“桥也许能撑”变成“可以／不可以这样承力”；需要时间和实体工具。
- 机魂／驾驶者：对具体动作接受、拒绝或附条件回应；不是好感值满后永远服从。

这些能力只改变知道什么、可以提出什么、谁同意和什么物理上成立，不给免费增伤、额外回合或万能提示。

## 10. 现在请你判断的不是数值，而是五个体验问题

1. 你是否能从例子中看懂一轮的操作顺序？
2. “身体功能受损但仍能继续承担别的职责”是否比单 HP 更符合本项目？
3. 守主路与开侧路是否看起来像两种不同思路，而不是同一答案的先后顺序？
4. 敌方 Intent 公开到“目标＋预计接触时间”，会不会太透明或刚好可读？
5. 桥断／样本丢失作为前向后果，而不是一律重开，是否符合重故事、轻刷级的方向？

这五个问题得到方向判断以后，才值得讨论 A/B/C/D 哪种时制最适合承载它；在此之前，任何公式、状态表或 Gate 都只是工程附录。
