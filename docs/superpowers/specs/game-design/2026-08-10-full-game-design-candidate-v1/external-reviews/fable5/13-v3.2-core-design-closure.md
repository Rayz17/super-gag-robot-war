## 1. 最小战棋规则（冻结版）

以下规则闭合到"玩家能预测结算"为止；写不清的项已删除，没有"未来UI会说明"。

### 1.1 出手与占用

- **一轮**＝我方阶段→敌方阶段→场地阶段。**标准时长**：普通战8-12轮，章级高潮战15-20轮（14号A包的3-4轮推演是规则证明用的切片，不是标准战斗长度；完整长度波形见14号D1）。
- **一次出手**＝移动＋一个主动作（或放弃主动作换第二段移动）。我方阶段内各机出手顺序自由，选中→预览→按执行才结算，执行前任意反悔。
- **主动作**七类：攻击／工程（抓、顶、固定、拆装）／互动（对物件与人）／识破／变形／**预备**（把主动作存成"若X则Y"）／引爆名场面前的就位动作。
- **精神指令**不占出手：出席人物每人每战1次，随时按（见§3）。
- **名场面引爆**不占出手：条件凑齐时按下，消耗该机满格气势。

### 1.2 确定结算四则

- **推挤**：推移格数＝推方承力−受方立足（≥0）；撞障碍时，双方按未走完格数各受1级功能损伤。
- **阻挡**：大身体占格即墙；小单位被大身体经过时强制让位，无处可让则受压（平民区此类格子直接红线禁入，不结算伤害）。
- **功能损伤**改动词不减血：断臂关"抱"开"肩顶"，伤腿减移动开"跪射稳定"。三级：碍事→缺位→瘫痪，跨战持续到手修。
- **同刻冲突**：同一事件触发多个我方预备→玩家当场排序；敌我预备同刻→**我方先结算**（玩家的预备是本作核心表达，给确定优先权；删除11号"后设置者先动"）。敌方的预备型行为在意图区公开显示为"待机·条件未知"——你看得见它留了后手，看不见条件。

### 1.3 意图、佯动与识破

- 敌方**真实意图**每轮亮出（谁、动作类型、作用区）；**内部优先级**（先打谁、什么时候撤）不公开——这是研究对象。
- **佯动**只属于名角与精锐（杂兵永远诚实，行为合同写明谁会佯动、在什么情境佯动）；假意图与真意图同形，破绽藏在身体（配重、视线、姿态）。
- **识破**＝一个主动作，指定一台敌机：它确有假意图→全部翻明＋它气势−1；它是真的→主动作用掉，换得"确认为真"标记。成本内建（占出手），收益双向（翻假或确认），所以既值得尝试、又不会退化成免费逐个点——对杂兵用识破纯属浪费。

### 1.4 气势与名场面（修订裁决）

- **气势**0-3格保留；上涨判定改为**标签计数制**：每机2-3个公开风格标签，做出符合标签且服务当前目标的行为＋1，**每个标签每战前2次有效**（删除"第二次减半"的分数运算）；被迫违背标签或看着该护的受损−1。满3格该机**请战**（指名一个名场面机会，不给解法）。
- **名场面机会**：由"危险源×身体能力×时机"的客观组合在地图上生成，UI直接列成立条件清单（例：重物坠落中＋接住者气势≥2＋落点两格内）。玩家凑条件→引爆→该机执行一段改变棋盘的定制动词链→气势清零＋该机标签计数重置（可以再攒）。系统永不自动播放。
- **失败延续**：目标失守→当场目标转换（追缴／护送残局／谈判）；机体带伤回馆；名角记账跨章。

## 3. 出席与编组（收敛版）

### 3.1 按钮规模封顶

- 产生**战中主动按钮**的只有：现场同行（≤2人）、随乘者（每机≤1）、通讯台（1席）、远援（1次）。**每战人物主动按钮≤5**。
- 工修坊、资料席**不产生战中按钮**：他们的贡献是战前准备（预置路线注记、整备加成）与被动改动作（同一动词换形状）。
- 每人**精神指令统一1个**（删除"1-2个"浮动），形状随岗位变（七海在通讯台是「记录在案」、到现场变「以我的名字」——同一个人，一个按钮，两种形状）。
- 参战人数增加不膨胀：按钮绑**岗位**不绑人数——岗位数固定，人越多只是"谁坐哪"的选择越难。

### 3.2 必带与缺席（修订裁决）

- 没有永久必带：指令每战1次＋人物会拒绝（每人合同里写明拒绝线）＋出席有机会成本。
- **缺席窗口制**（删除"不知情永久错过"）：缺席者的个人事件有窗口，窗口内馆内新闻会预告（"七海最近在整理听证材料"）；窗口结束事件按她自己的意志解决，结果可回看。你知情、可选、错过的是"参与"而不是被暗雷。
- 编成页显示"最近三战出席表"——常带某人的代价（她自己的线在等）可见，不是惩罚，是取舍。

### 3.3 关系多样性在四种模式里的读取

同一份关系状态（标签＋边界表＋共同记忆）被四种玩法各读一面：**战棋**读共同动词与指令连发资格；**巡访**读同行视角（带谁看见什么）与人情门（谁的熟人网开哪扇门）；**深潜**读接驳资格与译本倾向（机魂让谁陪它进记忆、信谁的读法）；**返馆**读动线与裁决台词（谁走进谁的工位、修理分歧时谁站你这边）。机体关系同构：宿敌账（名角）、搭档默契（驾驶对）、客将回访（地方机）在四模式中同样各有读法——关系系统只此一套，四处消费。

## 4. 探索共同语法（收敛版）

- 共同动词裁到五个：**观察／交谈／攀爬／拆装／撤回**（删除"扫描/标记/采集"三个泛动词；"记录"取消手动——馆藏档自动记；"调谐"并入深潜的译读）。
- **巡访**独有判断：路线选择（真实移动，非热点菜单）＋人情窗口（谁在什么时段愿意见你）。
- **深潜**独有判断：记忆空间导航（在机体的记忆场景里走动、翻找、比对）＋**译读**（同一层记忆选一种读法，读法决定看见与失去）。
- **入口更名**（事实纠正）：深潜入口为**黑匣接驳窗口**（维护读取窗），Candidate新名；`灯槽短窗`归还深空通信专用，不再用于深潜。馆长旧版/代哥合规版等译本用于深潜同为Candidate设计（版本外壳的世界内复用），不称正典动词。
- **接驳稳定档**（替代百分比信号条）：三档"稳→晃→断"；每层大动作可能降档，档位决定还能带走几件与能否再深一层——离散、可读、可规划。
- 深潜的长期变化来自问题组合与关系（机魂开放哪层、现实物证解锁哪种对照），不新增资源。

## 5. 关系链规则接口（三事件结构）

- 关系状态三件套冻结：**标签**（公开）、**边界表**（随事件改写）、**共同记忆**（含LLM软记忆）。无好感度数值，无恋爱＝战力。
- **视角切换规则**：七海/白鸢的自主场景由玩家**临时直接操作她们**（界面明示"此刻你是七海"）；边界＝仅限该场景、只能做该场景议题内的选择、不可替她们做关系级不可逆表态——她们的自主戏不是纪存的遥控。
- **嫉妒/误判/拒绝三出口**：说开／退一步／改变自己的位置——三个出口都继续故事，拒绝者永不被写成坏结局；退出是完整结局。
- 成人浓度三档只改镜头与文本；未成年角色空间与事件池物理隔离。
- 房间与值夜动线只能由人物协商事件改变（不是家具摆放玩法）；标签和记忆卡帮助理解已发生的事，不替人物演戏。
- 完整三事件链（共同工作→错位→重谈）的操作实证在14号§B3。

## 6. LLM：记忆所有权与"只在不可替代处"

### 6.1 三种记忆所有权（事实纠正后的最终版）

1. **生成服务摘要**——玩家全权：预览后才保存、可纠正、可禁调用、可导出、**可删除**；删除只意味着系统不再主动调用它组织台词，**不编辑任何人的心智**。
2. **世界确定事实与硬承诺**——确定状态保存；撤回要走正式撤诺流程（当面说、付代价），违约按约定后果结算，**删摘要不能逃债**。
3. **人物/机魂自己的记忆**——属于主体。它是否记得你删掉摘要的那句话、是否误记、是否拒绝忘记，只由人物性格与剧情决定（旧守护者会记得你没让系统记的事——这是它的权利）。

### 6.2 只在不可替代处开放自由输入

判据一句话：**只有"怎么说"本身构成关系质感时，才开自由输入**。开放五类场景：命名与称呼／安慰与陪伴／请求（冒险、帮助）／道歉与修复／边界谈判。其余一律作者选项。纪存不知道的内容不做"打不出来"的输入拦截：照常发出，由对方或纪存自己以世界内方式困惑、反问或拒绝（"这话你从哪听来的？"）。自由表达可改变口吻、共同笑话、回提措辞与结构化提案；不能生成Canon、能力、主线结果、恋爱终局或战斗胜负。LLM关闭/离线时，五类场景由作者意图选单＋固定文本完整等价，无独占内容。

## 7. 版本外壳Meta最终规则

- **完美版的优势全部是确定规则**（删除12号"高命中"表述——基础战棋无命中骰，不迁移底盘）：①敌方**内部优先级全解**（意图区直接显示先后手剧本）；②**反应自动排序**（同刻冲突系统代排最优）；③每轮**一次额外撤销**（已执行的出手可收回一次）；④名场面成立条件**放宽一项**；⑤目标替换：把当前目标换成**更窄更省步骤**的版本。每项都注明它改写了哪条§1规则；每项启用时对应折叠一种差异（优先级全解折叠"研究敌人"的乐趣、自动排序折叠你的排序权、额外撤销折叠"落子有悔的重量"、放宽条件折叠攒局的成就、窄目标折叠"麻烦但完整的胜利"）。
- **升级并入日常**：第一次错位不预标"剧情模式"——它以QoL补丁的样子出现在例行操作里（14号§C2完整链）。玩家利用完美版是被祝福的；折叠的发现全部走确定状态（空泊位、纸质台账、他人记忆），LLM只放大裂缝不承担成立。
- 安全边界照Working全文；降敏模式保留全部谜题信息。
