## 1. 全剧统一玩法命题：他们能复制打法，复制不了想打的心

写进L1宪章§3.4的原话，就是本作系列级玩法的总发动机：

> **"索引可以完美复制一句口号在什么时候最有效，却越来越不懂为什么有人会在明知无效时仍然喊出来。这条差异将成为G.A.G.、精神指令、IP投射与终局'完美机器人大战'的共同发动机。"**

再看母盘里断冠一系反派在做什么：C04偷走"巨机如何交棒"的样本；C08同时读取红面具的政治战与沈砺的标准撤退；C09观察地球把哪种角色送往哪条防线；C11记录全球校时与后勤指纹；C14夺走标准指挥样本；C16组装"地球标准编队"；C17末证零号"**能从历次公开战斗中复现玩家最常使用的合体、援护和必杀开局**"；C16索引天使以"**已收录**"正面击败百相。而C05正典同时写明了反面："战装局能复制已经发生的画面、动作、通讯与路线，**却复制不了纪存临时改主意、被别人叫停和事后后悔的部分**。"

**这不是剧情设定，这是一条现成的、贯穿22章的核心玩法律：**

### 1.1 收录律（系列级机制）

1. 玩家每次公开战斗中的高频行动（同一机体同一动词、同一合体开局、同一援护链）会被写入**敌方收录账**（对玩家可见，就在机体档案页——你能看见断冠已经"看会了"你哪几手）。
2. 收录条目达到阈值后，对应敌系开始**预置反制**：你最爱的开局会被卡位、你的招牌援护会被诱杀。反制强度随部数递增（P1几乎无感，P5的索引天使把它做成Boss核心）。
3. **三类行动永不可收录**：机体自己举手提出的临时方案（欲望）、玩家中途撤回后改变的主意（后悔）、机体拒绝命令后给出的反提案（拒绝）。冷门机的首次登场动作、从未用过的替补链，同样是收录账上的空白。
4. 于是系列长线的战术压力自动生成：**标准答案会过期，活着的队伍不会。**玩家被系统本身推着去用整个收藏、去听举手、去接受"不够最优但是它自己想的"方案——L1第一幻想"把偏爱的冷门机用到终局"从道德呼吁变成最优策略。

### 1.2 它统一了什么

| 层 | 收录律的表达 |
| --- | --- |
| 玩法 | 举手制/残响经济的长线必要性（`04`的五机制因此不是风味，是对抗收录的唯一武器） |
| 反派 | 断冠→索引天使→末证零号→归一星/脚本敌，全是同一条律的不同阶段 |
| 主题 | "机器人文化是活的共同语言"——活的语言不可被穷举 |
| IP投射 | 名场面的力量在于"此人此刻为什么喊"，复读机喊不出第二次 |
| 终局 | C22万机殿"任何成员都能拒绝、换位、接替和退出"＝收录律在玩法上的最终答案 |

## 2. 角色系统：驾驶席与导览席的精神指令

L1§3.4对精神指令的定义："**驾驶员、机魂和支援者把一生的习惯压进一个有限资源的戏剧按钮**……人物成长、关系变化和创伤会改变其精神指令，而不只提升数值。"本案照此建立双层角色系统——**人类角色不是头像，是牌**。

### 2.1 双层结构

- **驾驶席指令**（驾驶员×机魂成对持有）：机上释放，消耗残响，绑定这对搭档的关系状态。
- **导览席指令**（舰桥人类，即`04`E01里的"场外牌"）：每话限量、由纪存席位发动申请、对方是否接受取决于关系与剧情状态。**这就是玩家与人类群像的战斗接口**——你不是看着他们演戏，你在战斗里向他们求助，他们用自己的方式回答你。

### 2.2 三主角指令卡（含成长与创伤变形）

**纪存｜听真 → 代答 → 全域接驳**

- `听真`（C01起）：指定一台机体，公开它此刻的真实意愿——隐藏举手、犹豫、伤势、想停。侦察系指令，也是全作核心动词"听"的按钮化。
- `代答`（C05起，**危险指令**）：机体犹豫时强行替它接下方案。即刻全额执行，但若事后查明它当时想停（结算时公开），生成**心债**：该机体此后数话不再举手，直到在舰内完成一场道歉戏。——C05正典里纪存"过早判定一台已经想停的机体仍愿意继续"、被韩秀雅强行纠正、"必须亲口承认自己听见了，却还是替对方说完了"，**这个错误现在由玩家亲手去犯**。这是本作把主角缺点做成机制的核心样本。
- `全域接驳`（C11起）：一话一次，全队所有举手案同时亮起并允许跨机连携编排——百机统帅的爽感按钮；代价是本话纪存无法再`听真`（听得太多就听不清单独一台，C09正典"主动关闭普遍监听"的机制化）。

**七海｜撤令 → 停机席 → 世界停机席**

- `撤令`（C01起）：撤销一条场上的制度限制（停机令、禁飞区、企业锁），**每次生成她个人担责的承诺条**（C01正典原句"损失会先查到你这里"印在卡面上）。
- `停机席`（C10起）：政治大胜后升级——冻结一个敌方制度系动作一整拍（征用、锁权、清噪协议启动）。
- `世界停机席`（C19起）：全剧一次，带真实终止时间的全域停机（C19正典"有明确终止时间的世界停机席"）。
- 关系变形：与纪存/白鸢关系破裂期间（C14-C16），她的指令只能通过公共频道申请，回应有延迟——**冷战被做进操作手感**。

**白鸢｜预演 → 共作 → 保管**

- `预演`（C02起）：对一个完整回合方案做一次"未来放映"——确定物理下的全结果预览（她的反事实共感）。强大，但每次预演在她的**死亡感受计**上留痕（预演里看到的每次阵亡都留在她身上，C17/C18正典），计满则指令锁定，只能靠舰内照护戏清空。
- `共作`（C03起）：她交出的路线**允许任何驾驶员当场改坏**；被修改后完成的方案给全队士气加成，且署名共同作者（C03正典"允许地方驾驶员把她的构图改得面目全非，并仍署共同作者"——她的成长课题就是这张卡的使用条件）。
- `保管`（C18后）：她主动限制预演，把最自私的几段未来交给七海保管——此后`预演`变为**双人指令**，必须七海在场共同发动。创伤改变按钮，不是数值削弱，是两个人从此绑在一张卡上。

## 3. C02《木桶街，万机初开》完整玩法适配

> 章新维度（承00d纪律，每章只学一个）：**市集与擂台——残响经济的民间面**。C01教"被见证"，C02教"被交易、被误标、被重涂之后，见证还算不算数"。

### 3.1 逐话玩法结构（对齐Reader四话）

**E01《救命零件，限定发售》**——寄售仓与扫描门。

- 玩法：非战斗的**市集斡旋**（L1§3.7"谈判"玩法的首秀）＋小规模护件战。转子是"唯一的重载位"上的现货，玩家用C01赚到的残响声望、承诺条与唐胶的读痕在收藏者生态里换取交易资格；扫描门争夺战教"运输中的身体战术"（六米巨环滚动运输＝移动掩体＋易碎货物双属性）。
- 举手制新样本:量产清扫机在市集里认出同型号退役同伴挂在寄售墙上——它举手申请"买下它"。接不接？接＝第一张为机魂花钱的承诺条。

**E02《同模不是同一个人》**——玩法层证明章题。

- **同一底盘、四种机魂**：火种重涂机等四台同模具机体进入可用池，面板数值完全相同，但**举手倾向完全不同**（一台永远抢先、一台只肯殿后、一台专提歪主意、一台从不举手只用请求线）。玩家用手感而不是台词理解"同模不是同一个人"——本作最便宜也最深刻的一次主题机制化。
- 归一星是本章敌位，也是同意链的反面教材：它以成本逻辑主张"拆掉三台，足够让一台继续飞"，替镜星回答"无需承担判断压力"，而镜星当场说出"我没有同意"（Reader原文）。战斗目标不是击毁归一星，而是保住四台机各自的判断权——玩法与章题在同一个动作里。清噪式"替你决定"的民间变种在此埋下，槐系"口令还原"是它的远期解药。

**E03《拳王赢了》**——擂台规则战与第一盏绝活灯。

- **擂台=有规则的战斗**：回合裁判、有效部位、倒地读秒——非歼灭目标库的喜剧变体；观众密度全章最高（残响丰产区）但**规则本身限制你最强的牌**（重武装禁入），逼出身体战术基本功。"真正的基本功"一节直接可玩化：闪避、承力、第二步反送。
- **旧拳王绝活点灯**：`逆转天冲拳`不是解锁即用——按validation/d06纪律分解为TACT动词链（走位＋承力＋反送），玩家先在训练赛里把三个组件各打出一次（E02-E03跨话进度），决赛"这份不签"拒约后条件齐备，**第一次完整放出=C02章级名场面**。绝活系统的教学章。
- "小拳登巨锤"：小体量机体攀附巨型敌机的**登乘动词**首秀（后续C02E04锚索登鲸、C20登舰链全部复用）。Reader原文有一处必须原样机制化的细节：旧拳王在锤柄上滑倒后，"没有停在原地等影子集锦重播，而是**用失败录像里那一步后退重新找回重心**"——失败也是残响，翻看自己的失败记录换取一次重心恢复，应成为残响系统的固定小动词（尊严垫的战内版）。

**E04《万机初开》**——第一次策展演出＋压街巨鲸。

- **开馆演出**（非战棋新模式首秀，详见§6.3）：六座展位怎么摆、谁站C位、放什么旧影像——摆出来的展直接决定本话残响初始池与木桶街民心。
- "清仓鲸压街"战斗：巨型清仓运输鲸失控压向市集——纯身体战术＋登乘（锚索登鲸），零击毁目标；被你在E01-E03帮过的市集NPC与机体会到场举手（**善意回流的第一次机制展示**：你种下的承诺条开花成援军）。
- 谢幕："第一次同桌"——全章承诺条在饭桌上清算，白鸢以临时乘员身份入队（她的`预演`卡解锁，附教学：她的分镜被平台盗用的愤怒就是这张卡的性格）。

### 3.2 本章沉淀

转子到手但需工务城校正（对C03的真因果）；旧拳王入列（第一台玩家亲手点灯的绝活机）；四台同模机证明举手制的表达力；市集/擂台/演出三个非战棋模式各完成教学；唐胶`读痕`升级。

## 4. C03《工务城，谁在让城市站着》完整玩法适配

> 章新维度：**城市即棋盘——会动的地图与不能打的敌人**。

### 4.1 逐话玩法结构

**E01《整座城压上来》**——地图本身是一台机器。

- "城市会在早高峰换一条街"直接做成规则：**棋盘按时刻表重构**（移动道路、翻转轨道、换位街区），敌我都要背时刻表；这是继C01"见证舞台"、C02"规则擂台"之后第三种地图人格。首战"上面是城，下面是馆"：万机馆舰体首次作为多格我方单位进入棋盘（L1§3.2"有一天它会站起来"的第一步兑现）。

**E02《城市的手不是零件》**——不能打的敌人。

- 衡令用删去语境的廉价稳定程序把市政吊装机、交通塔锁成"征用姿势"——**全部敌单位是被劫持的城市工务机，一台都不能击毁**（非歼灭伦理的章级大考）。解法组合：唐胶`读痕`找出每台机的民间修痕（它真正的握持习惯）→陆衡`翻译`搭出承力旁路→身体战术把它按进安全姿势→**口令还原雏形**唤回本机记忆。每解放一台，它立刻转为我方举手源——**敌人变队友是本章的核心爽感曲线**。
- "做坏的第一只适配环"：修复线失败样本入库——失败件也是锚件（§6.4修复系统的教学）。

**E03《社勇王，现场合体》**——批准与交棒。

- 玩具品牌的真机现场合体：Reader原文里，工务城把公共救援任务发给社勇王主体AI、核心车回传接受，但"驾驶舱还没有他的名字"——豪司没有驾驶资格，被企业按在地面协作位，替工作人员拖断梁、清轨道。**批准主题的章级兑现**：玩家侧的战斗目标之一就是让豪司在众目睽睽下挣回那个驾驶舱（"最终合体，批准"是本章名场面标题）；`批准`指令卡的原型在此诞生，C08豪司×金章将把它带成长线。第一锤赢、第二锤被反制（收录律的第一次剧情级亮相：衡令看会了第一锤），逼出"老巨神给新勇者开路"——馆守Z用C01的旧伤之躯开路，新王打出致胜一击。**交棒动词在此教学**（C04断冠要偷的就是它）。

**E04《第一座可以回来的城》**——回航港与战后生活。

- "英雄打完，东西还得装回去"：战后收尾做成低压玩法（把城市搬回去＝反向身体战术，喜剧丰产区）；"社勇王不是奖品"——它留在工务城做地方防卫，**不是所有点亮的机体都随舰**（L1§3.2"万机馆不能是无限格纳库"的第一次执行，也是让告别从第一部就开始练习）。

## 6. 非战棋玩法与内容呈现

L1§3.7写明循环："舰内生活→现实/残响层探险→多玩法改变局势→带入SRPG→战后回馆看见一切已不同"，并要求胜利是"**我准备出来、发现出来、修出来和打出来的**"。以下四模式全部服从一条铁律：**每个非战棋产出必须在SRPG里有一个可指认的落点**（改地图/改部署/开隐藏目标/开说得窗口/加支援/改损伤）。

### 6.1 残响深潜（探索模式）

- **三层结构**（L2原文）：实体遗址（身体探索：废墟、沉舰、旧乐园——用小队机体的身体动词爬、撑、照）→黑匣子构造层（结构解谜：还原一台机体的最后一次行动）→灯槽信号层（听觉/信号谜题：在噪声里辨认一个还在重复的名字）。
- **队伍**：1台机体＋1-2名人类（不同组合有不同对话与到达能力——带白鸢能预演塌方，带唐胶能读修痕开捷径；深潜是关系戏的第二主场）。
- **资源**：残响灯（照明即消耗）；越深越暗，最深处的东西要摸黑听。
- **产出**：锚件（绝活线索/机体唤醒/改装图）、**被删除的拒绝**（大清噪受害者的最后一句话——C11索琳公开名单、C18分支真相的玩家侧证据链）、隐藏机体（L1§3.5"隐藏机唤醒"）。
- **SRPG落点**：唤醒机入列、锚件点灯、深潜取得的旧航标改变战役地图、证据开启说得窗口。

### 6.2 舰内生活与关系（L1§3.6的机制承载）

- **日结构**：每话之间1-2个生活段，AP轻量制（三行动位，不做日程表暴政）：陪修/饭桌/放映/洗衣间/夜班巡馆/训练。
- **陪修**是关系主动词：修一台机时在场的人决定发生什么戏——兜灯×唐胶的维修间火花、纪存替白鸢清死亡感受计、七海在修理灯下清算承诺条。**心债道歉戏、死亡感受清空、承诺条兑现，全部只能在生活段发生**——战斗系统欠下的情绪账必须回家还，这就是"非战棋内容"的机制地位。
- **成人向呈现**：三档关系接口（暧昧/明示/修罗场，用户裁决），场景发生在L1点名的位置（驾驶服整备、伤口护理、故意说给第三人听的双关）；七海×白鸢拥有不经纪存的独立场景树（事业互救线C09/C10/C17为骨）。儿童角色物理隔离于此系统。
- **群像自转**：每个生活段有1-2条不点不看的群像事件在背景自行发生（战争角色的糟糕歌会、量产工会例会）——世界不等玩家翻牌。

### 6.3 策展与开馆演出（经营层）

- **展位语法**（C02E04"六座展位"起步，随舰体升级扩容）：每站开馆前把机体/锚件/影像分配进展位；展陈组合决定本站残响初始池颜色、门票收入、当地关系事件，以及**机体心情**（被冷落的老机会闹脾气——经营失误变喜剧素材）。
- **开馆演出**：低压玩法——巡展路线编排＋现场小事件应对（孩子爬上展台/老兵在某台机前站了很久/平台来拍"违规展品"），用五动词处理，产暖/笑残响。
- **战役层**：巡展路线选择（下一站去哪）＝战役分支；回航港网络（C03起）逐站累积——L1§3.2"从一栋建筑成长为跨城市跨舰队的关系网络"的玩家侧账本。C11百机祭是本模式与战争系统的合流大考。

### 6.4 修复与改装（工房层）

- **三工位**：唐胶（非标修法：便宜、快、留个性痕迹，小概率出"错版奇效"）、陆衡（工程校验：贵、慢、稳定、可量产）、兜灯（装配与应急：战间快修）。同一件事三种修法三种结果——修理是表达，不是进度条。
- **锚件六动词**（L1§3.5原文）：识别、校准、改装、支援、隐藏机唤醒、实机修复。
- **生涯件**：馆守Z右臂的十九章弧（C01毁损→C04承力背架→C09代用臂架→C19后继右臂）是本系统的展示橱窗——每阶段是真实玩法差异（无拳路→只能架盾拖拽→完整新武装），不是皮肤。

### 6.5 内容呈现（把"番剧感"做成格式）

- **每话格式**：话数标题卡（《拳王赢了》式命名直接来自Reader）→冷开场→A线（章目标）/B线（机体或角色私心）→谢幕（三色残响计数、观众短评、承诺条、机体心情）→**下话预告**（根据本话选择实时装配的30秒预告——分岔的实感化）。
- **导览席POV**：主UI即纪存的席位视野——机魂头像举手气泡、台词流、被导览对象的视线反馈；菜单是万机馆的房间（整备＝去机库，档案＝去展厅），**UI就是家**（L1§3.2依恋第一层"我住在这里"）。
- **OP级演出预算**：每部一次PV级奇观固定给万机馆形态升级（L1§3.2原文要求），C01E04升空、C11百机祭、C14暴走、C20天穹联装——舰是主角机，它的变身就是每部的OP。
- **玩梗四层门**（L1§3.4原文机制化）：一次玩梗内容要过"认出来/属于角色/撞出新东西/留下后果"至少三层才能入库——写进内容生产验收，防止致敬退化成复读。梗的机制落点：举手台词、擂台解说、谢幕短评、承诺条文案四个低压位。

## 7. 动人设计：眼泪的机制学

"动人"不能只靠Reader写得好，玩法必须自己会疼。七个机制化的痛点/暖点：

1. **心债**（C05）：你替一台想停的机体说了"它愿意"。系统不骂你，只是它再也不举手了——直到你在机库找它道歉。玩家亲手犯纪存的错，才懂纪存的忏悔。
2. **被删除的拒绝**（深潜）：黑匣子最深处，一台被大清噪处理的机体反复重播它说过的最后一句话："我还能再修一次。"没有战斗，没有奖励结算画面，只有把这句话带回地面的选择。
3. **右臂生涯**（C01-C19）：馆守Z的残缺不是立绘差分，是你十九章里每一场战斗的操作现实——所以C19新臂首装那一战，装的是你自己的十九章。
4. **无解题的诚实**（C14）：托梁还是脱离，两条路的确定物理预览**全部展示**——你清楚看见每条路上救不到谁。没有隐藏的第三选项，机体只请你确认两次。事后没有"其实有完美解"的攻略可查，因为真的没有。
5. **假姐姐知识战**（C18）：完美的姐姐知道所有档案大事，但你的锚件收藏知道小事——C12她故意漏掉的那条终端请求、她拒绝换掉的旧补板。**对话战的弹药是你的收藏**：收集在此刻变成爱的证据，图鉴党第一次为自己的强迫症流泪。
6. **残响回归**（终局）：阵亡/离队机体若锚件保存完好、谢幕曾被郑重对待，C20-C22可作为残响投射短暂归队完成一个动作（L2"残响回归"关系结局的机制位）——你好好告别过的，都会回来。
7. **迟到的回答**（C15）：方舟T的异步卡在日常里的样子——陆衡对着通讯器讲完笑话，几小时后才收到"哈哈"。玩家学会珍惜每一条延迟的回复，然后在C22，深空断口另一侧传回最后一条延迟讯息。

**情绪成立顺序纪律**（L1§5.3原文）："先让玩家想拥有它，再让玩家认识它；先让角色一起生活，再让他们互相伤害；先让一次胜利真的快乐，再揭示它打开了什么危险。"——落成排期硬约束：C06合体的快乐先于C07的争论，C11大胜的完整先于C13-C14的失去，C12生活先于一切修罗场，C20全胜先于C21的尸检。任何章不得在快乐尚未成立时预支它的代价。
