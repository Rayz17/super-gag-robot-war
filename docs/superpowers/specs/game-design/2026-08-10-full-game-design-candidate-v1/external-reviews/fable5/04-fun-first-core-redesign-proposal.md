# Fable 5 外审｜好玩优先的核心玩法重设计案：《导览席与万机残响》

> Status: `external_review / Candidate_input_only / user_review_required / no_design_authority`
>
> **本文取代同目录`02`成为主提案。**`02`的三张规则卡（英雄拍/命名席位/信任折叠）在本案中全部被更本质的机制吸收；`01`的证据与诊断继续有效；`03`的迁移矩阵若本案被采纳则作废重排。撰写原因：用户裁定前一轮"定点修订"思路不够好、不够创造性，并把验收轴改为——**在项目设定的基础上，游戏部分必须好玩。**

> 本案立场：不再问"文档怎么改"，只问"玩家哪里爽"。所有机制均从已验收正典（L1宪章、L2世界基线、C01 Reader）中生长，不外挂。

## 0. 转向声明：我上一轮错在哪

上一轮我把这当成审计题：找缺口、开补丁、排迁移。补丁本身没错，但它默认了一个前提——**现行00c的体验骨架就是这款游戏的快乐来源**。用户的反馈推翻了这个前提。重新审视后我承认：00c是一台纪律优秀的"责任机器"，但它的每一个默认值都在产生摩擦而不是快乐——玩家提案、机器审批、结算出账单。把燃和笑"补"进这样的骨架，是给图书馆装霓虹灯。

这一轮我换一个问题：**这个世界里唯一好玩的事是什么？**

答案就写在C01正典里（Reader v3，用户验收的最好一章）：

> 纪存坐进去。馆守Z的视野接入屏幕……那不是他的身体，他也碰不到巨机的手脚；他能做的，只是把街道、人员和危险方向放到旧守护者眼前。
>
> **馆守Z自己抬起了头。**

玩家不开机器人。玩家让机器人**想起自己是谁**——然后看它自己站起来。这是全行业没有第二家在做的核心幻想，而现行00c把它做成了审批流程。本案把它做成快乐引擎。

## 1. 好玩论纲

### 1.1 一句话幻想

**你是万机馆的导览席：一群退役传奇机器人的经纪人、报幕员和最后一个还愿意听它们说话的人。你的工作是把世界指给它们看，把它们重新指给世界看——然后在它们燃起来的时候，喊出那句预告片台词。**

### 1.2 快乐从哪来（三源）

| 快乐源 | 一句话 | 对应L1情绪 |
| --- | --- | --- |
| **活的队伍** | 每回合是机器人们在向你举手、抢活、抬杠、毛遂自荐，你在编排一群有性格的老将，而不是移动棋子 | 笑/暖 |
| **赢来的燃** | 绝活不是按钮，是你亲手布置的舞台：让它当着人群做回当年的自己，残响涨满，那一拳才轰得出去 | 燃/爽 |
| **有脸的代价** | 每个越界决定都变成一张具名的承诺条和一段回馆后的戏，而不是一行账单 | 痛/色 |

### 1.3 三个尺度的循环

- **10秒**：看敌意图（确定物理，继承00c）→ 看谁举手 → 接欲望/下导览/织连携 → 看结果炸开。
- **10分钟**：一话（Episode）：冷开场 → 主目标（非歼灭，继承00c）→ 机体私心副线 → 清噪场攻防 → 残响满 → 名场面 → 谢幕与下话预告。
- **10小时**：巡展（Tour）：城市→策展→深潜→战斗→舰内生活→下一城；沿途点亮一台台传奇的绝活，宿敌一路学你，大清噪的真相一层层揭开。

## 2. 五大核心机制

每条机制附：规则 / 正典根 / 爽点 / 防线。

### 2.A 导览指挥·举手制（基础输入的反转）

**规则。**沿用00c的B短全队协同时制（约8秒一拍、全队同时规划、确定物理、敌方意图透明）。反转的是**提案方向**：

1. 每拍规划期，场上每台机体根据自己的性格、履历和视野**举手提案**1-2个完整预演过的行动（带台词短句＋确定结果预览）："让我接住它！""那辆车，我熟，我来。"
2. 玩家的三个动词：
   - **接（0成本）**：采纳举手案。机体做自己想做的事，附带**机魂全开**加成（更快/更稳/更帅）。
   - **导览（低成本）**：不下命令，而是**把一个事实指给某台机体看**——标记一条街、一群人、一个危险方向、一台敌机。被导览的机体下一拍会围绕这个事实重新举手。这是纪存在C01里做的事，原样机制化。
   - **请求（高成本）**：要求机体做它没提的事。顺性格的请求即刻通过；逆性格或高危的请求触发**一句话谈判**——机体要么拒绝并当场反提案（"我不踩草坪。但我可以把你扔过去。"），要么开条件（生成一张承诺条，见2.E）。
3. **审批默认消失**：顺应欲望＝零审批。同意链只在"逆本性/高危/涉及第三方"时出现，且永远以反提案或条件的形式出现——**拒绝必须好玩**，这是文案铁律。

**正典根。**C01导览席原文（"把街道、人员和危险方向放到旧守护者眼前""馆守Z自己抬起了头"）；L2机魂主体性与可撤回协作。00c同意链的哲学全部保留，只是把"玩家提案→机器审批"倒转为"机器提案→玩家编排"。

**爽点。**棋盘会说话。每回合开局不是空白焦虑而是三四个带性格的选项在抢你的注意力；辅助模式免费送——新手可开"让机魂们自己来"（自动接案），这是设定自带的无障碍设计。

**防线。**举手案数量硬上限（每拍全队≤4个），防信息过载；举手内容全部走确定物理预演，不存在"提案骗人"；逆性格请求的谈判永远一句话内解决，不打断心流。

### 2.B 残响经济（燃料与见证）

**规则。**残响是本作唯一的战斗资源，产自**被见证的、有真实赌注的行为**：

1. 地图上存在**见证者**（观众、市民、镜头、孩子、其他机魂）。机体在见证者视野内完成"配得上它传说"的行为（真实救下、真实接住、真实挡住——确定物理保证赌注为真），产生残响。
2. 残响有色：**燃**（英雄行为）、**笑**（滑稽行为、失败得漂亮、GAG连锁）、**暖**（保护、安抚、修复）。三色共池但影响演出与谢幕评语。
3. 残响的三个出口：
   - **绝活**（见2.D）：机体的必杀技，唯一的大额消费。
   - **残响投射**：中额消费——让一台机体的高光记忆短暂显形为场上实体（当年托起列车的那个剪影再托一次桥）。视觉奇观＋战术实用，正典直供（L2："让残响暂时投射"）。
   - **尊严垫**：失败保险。一话打崩时，残响自动兑换成"有尊严的失败"——留下残响、遗物、支援或另一位幸存者（L1原文），下一话获得复仇钩子加成。**输了故事变厚，不游戏结束。**

**正典根。**副标题《万机残响》；L1第31行把"残响探险"列为产品五编织之一；L1第82行"失败也要有尊严：留下残响、遗物、支援"；L2残响道具/残响接口/残响回归。

**爽点。**游戏第一次在机制上奖励"打得像最好看的那集动画"。效率与奇观成为真实的战术取舍：走安静的近路，还是绕人群多的广场？

**防线。**防刷：残响只产自"确定物理判定为真"的赌注（敌方那一击真的会命中，你才算真的救）；同机体同动词递减；见证者是活的——危险太近会逃散，人群一散舞台就塌，想刷险情反而关掉自己的舞台。

### 2.C 清噪战场（敌人踩在主题上）

**规则。**主要敌系（裂星潮突入体、后续清噪协议执行方、索引侧单位）携带**清噪场**：

1. 清噪场内：残响不产出、举手被压制（机体提不了案，只能被动接请求——**敌人机制性地删除你队伍的欲望和声音**）、残响投射无法显形。
2. 清噪场发生器是实体（投射车、桅杆、协议节点），可用最朴素的动词拆掉（推、拉、断电、遮挡——继承00c身体战术核）。
3. 于是每张图的宏观题都是**舞台争夺战**：先用无声的脏活撬开清噪，再在夺回的舞台上兑现大场面。战术节奏天然形成"憋—爆"波形。

**正典根。**L2清噪定义："筛掉低置信、低频、矛盾、停顿和不兼容信息……也可能把人格、失败和拒绝一起删掉"；大清噪历史创伤（"救下社会，也杀死、拆散、禁言或替换大量主体"）。敌人做的事＝当年大清噪做的事，主题与玩法同一条脊柱。

**爽点。**每一场胜利都是"让声音回来"，玩家用手而不是用过场理解本作命题；憋爆节奏是战术游戏最可靠的快感曲线。

**防线。**清噪场必须永远可拆（保底路线），拆解动词全部复用既有身体战术，不新增输入；压制举手≠压制行动，机体在场内仍执行已接指令，防止瘫痪挫败。

### 2.D 绝活与锚件（收藏的心脏）

**规则。**

1. 每台可用机体有**一个绝活**（必杀技）：满编演出、改变棋盘的一次性大招。绝活默认**封印**，解封条件不是等级而是**戏剧条件**——写在它的传说里，需要玩家去发现和布置：
   - 馆守Z：残响满＋馆内无人受伤＋有孩子在看。
   - 勇拳：先替它赢回"被批准"——任意一次官方认可（哪怕是七海手写的）。
   - 量产型：全体三台同框且都没被打坏。
2. 解封线索藏在**锚件**里：模型、旧胶片、展牌、粉丝信、黑匣子（L2锚件定义："保存版本、结构、关系或共鸣入口的物件"）。锚件从残响深潜、策展整理、市民赠礼中获得。**收藏循环＝收集锚件→读懂一台机体→点亮绝活→在正确的舞台放出来。**
3. 绝活有**真实代价**：老机体的旧伤是真的。放完绝活可能掉一格永久装甲、进厂一整章、或唤醒不该醒的东西。放不放、在哪放、为谁放——这是本作最重的玩家决定，每话至多一次。
4. **宿敌**：敌方具名指挥机（BREAKER系及后继）跨话学习你的绝活与习惯（继承00c敌方学习梯度，指到一张脸上），复现时带反制；宿敌战的解法是用它没见过的那台老将。

**正典根。**C01勇拳的红色"未批准"与违令助战；馆守Z"多年未见的金光"；L2模型→锚件→残响→工程→实机因果链；L1对精神指令的定义（预先承担＋主体同意＋不可逆）在此以"戏剧条件＋主体自愿＋永久代价"完整兑现。

**爽点。**SRW的"我抽到了新机体"升级为"我终于让老枪手肯再拔一次枪"；每台机体是一个心的谜题，不是一列数值。

**防线。**绝活每话≤1，条件不可用资源购买跳过；代价明码标价在确认框里（本作全部后悔机制继承00c的可撤回哲学，但绝活提交后不可撤——这是"不可逆"的仪式位）。

### 2.E 共振与承诺（连携的糖与责任的脸）

**规则。**

1. **共振**：连续采纳举手案、或让一台机体的欲望成全另一台的欲望（把敌机扔进拳手的反击弧），积累共振度。高共振解锁**合奏名场面**（多机合演的组合绝活，后期含合体）。
2. 共振超过安全阈值有**暴走风险**——万机馆的系统会自作主张地一起响应：贩卖机器人加入战斗、导览广播开始放热血OP、展厅灯光全部打向敌人。多数时候是GAG（笑残响入账），极端时是真失控（正典："G.A.G.暴走是……失控共振"）。玩家自己选择把共振推多高。
3. **承诺条**：一切越界决定（接下勇拳的违令举手、请求机体逆本性、动用第三方资产）生成一张**一句话承诺条**，有脸、有期限、回馆兑现："欠赞助商一场道歉直播""欠七海一次她不用说理由的调令""欠量产三号一个单独展位"。同时在场≤3张，逾期变成剧情而不是罚款。00c的合法性簿记（授权/借期/保管）全部折叠进承诺条；`02`的信任折叠自然发生——兑现过的对象，同类承诺自动免签。

**正典根。**L2"万机馆不同系统在危急时共振"；C01七海撤令的个人担责（"损失会先查到你这里"）——责任在正典里就是具名的、戏剧的，本案只是拒绝把它退化成表格。

**爽点。**连携是欲望的化学反应而不是数值配表；责任变成回馆后有人找你，痛得具体、笑得具体，还是关系戏（色）的天然入口。

**防线。**承诺条≤3硬上限防债务地狱；暴走的下限锁死为"喜剧＋可收拾"，只有剧情章允许真失控。

## 3. 示例关卡：E01《最终开放日》（垂直切片）

> 改编自C01 Reader正典高潮，用户验收过的最好一章。正典发生的事在这里全部变成**玩家亲手做出的事**。地理略作压缩。

**舞台**：万机馆主厅＋南侧旧会展广场。见证者：撤离中的观众（含抱着社勇王模型的小满）。我方：馆守Z（半跪展品，不可移动，绝活封印中）、旧守护者（导览车，可动）、量产清扫三机。场外牌：勇拳（在测试场，屏幕上挂着红色"未批准"）、七海（代哥联络室，持有撤令牌）、兜灯（维修架，持有直连牌）。敌方：BREAKER（30米，红缝，无视一切直奔万机馆）＋随行突入体×4，携两台清噪投射车。

1. **冷开场**：地面拱起警报。第一拍，旧守护者举手："撤离路线我带过二十年，交给我。"【接·0成本】量产三机举手："我们去堵西侧门！"【接】——开局十秒，玩家什么都没"下令"，队伍已经活了。
2. **导览教学**：纪存入座导览席（教学词只有一句："你不能碰它的手脚。你能做的，是让它看见。"）。玩家把"东侧还有滞留观众"**指给**旧守护者→它下一拍重新举手改道。基础动词教完。
3. **清噪压境**：两台投射车展开，主厅东半陷入清噪场——场内量产机的举手气泡"啪"地熄灭（敌人删除声音的瞬间，玩家用眼睛看懂本作主题）。残响停产。
4. **舞台争夺**：玩家用身体战术拆场：量产一号推倒展架砸停投射车A（无声脏活，0残响），导览量产二号绕后断电B。清噪一破，全场举手气泡重新亮起——**声音回来了**，配乐进。
5. **赌注为真**：BREAKER随行体轰塌二层看台，确定物理预览：三拍后砸中撤离队尾。旧守护者举手："我挡。"玩家接。真实拦截成立→**暖残响大额入账**（见证者：全体观众）。
6. **场外牌·勇拳**：豪司的通讯切入：勇拳在测试场**自己举手了**——"申请出战。第十一次。"接受＝违令（生成承诺条：**欠公司一场公开听证**，有脸：金章）。玩家接。金色试作机撞开测试场大门跑步入场——正典的"违令助战"，现在是**玩家签的字**。
7. **勇拳的私心副线**：勇拳的举手案永远带着过分标准的英雄措辞（笑残响小额入账）。它的绝活封印条件公开显示："等一个被批准。"本话无法解封——玩家第一次看见一个"心的谜题"，记住它。
8. **中盘高潮·撤令**：BREAKER突入广场。馆守Z胸口亮起金光，但停机令仍锁着它。七海的场外牌亮起：撤回自己签发的停机令——牌面写着代价原文："**你撤令以后，馆守Z造成的损失会先查到你这里。**"【玩家确认→承诺条：七海担责】。这是本话最重的一次点击。
9. **老神起身**：停机令解除＋残响池已满＋小满在看（条件三项达成的瞬间，UI逐项点亮）——馆守Z**自己**站起来。十八米的半跪展品在主厅里直起身，镜头从它膝盖抬到馆徽。这不是玩家按的，是玩家**布置**的。
10. **绝活抉择**：馆守Z绝活可用，本话唯一一次，且代价明示：旧动力线过载，放完本章进厂。两个合法舞台：**A.** 接住BREAKER砸向撤离队的第一击（暖燃双色大额，BREAKER未损）；**B.** 直击BREAKER红缝（战术重创，但看台危险自己扛）。没有正确答案，谢幕与下话预告随之分岔。
11. **共振彩蛋**：若本话共振度顶格，贩卖机器人推着饮料柜冲进广场给BREAKER一柜子可乐罐（笑残响，无战术意义，纯GAG，见证者笑声写进谢幕）。
