### 3.2 剧情设计干货

1. **第一话不是教程关，是生日被踩。** 黑底史诗把客串宇宙收到「鲁路修死后一年」，再落 14 岁艾蒂卡过生日。玩家先被拉到人物日程，再被杜拉士砸进地图。
2. **史诗和现场交替，不一次灌完设定。** 00:45 黑底 → 03:00 地图说话 → 06:00 黑底 → 07:00 第一人称。C01 序章如果只堆字幕或只堆通讯，都会少一拍「现场已经在」。
3. **地图是剧情舞台。** 09:15 起，认敌、爆炸、不想波及城镇、ZERO 认出机体，全部压在同一张等距图上。蓝菱形不收走。
4. **身份晚于行动。** 21:00 天雷剑，25:00 才解释「新时代忍者」。C01 对馆守 Z / 勇拳已经是这个顺序（先起身、后补头衔），保持。
5. **花田是书档。** 09:00 战前花田，23:30 战后同一场景。一话有可回的地点，不是过场馆。
6. **清图后先还人，再给系统。** 23:30–26:40 人物与城市合并，27:25 才打开战略和 MXP 教程。奖励系统不抢战后第一句。

C01 可吸收：交替开场、地图说话、身份晚于行动、书档场景、战后先人后系统。

### 3.3 机制设计干货

1. **一话骨架稳定：** 史诗/ADV →（短出击准备）→ OPERATION → 地图剧情 → 我方阶段 → 战斗演出 → 敌方阶段 → 中途剧情 → 清图 → 战后 ADV → 战略。C01 现网是序章 ADV → E02 1/2 画路出击 → 接触 → 桥 → E03 → E04 → Clear → 收尾 ADV。缺的是 OPERATION 短面、预测、敌方走一拍、清图后的「下一站表面」。
2. **阶段是顶栏家具，不是日志一行。** TURN n + 红 ENEMY / 蓝 PLAYER。C01 馆守 Z 威胁廊是局面，没有阶段条。要学的是「现在轮到谁」可见，不是学回合经济。
3. **底栏是选中单位卡，不是变量表。** HP/EN/气力/SP/击坠/移动/尺寸/四地形。C01 规划右栏已经是打法，不要把 museumWarmth 一类内部变量送回主界面。
4. **UNIT / ASSIST 是共享后援计数。** 第一话顶栏就亮。C01 七海继续做通讯后援，计数不进 Demo。
5. **战斗演出是第三层，不是唯一层。** 斜切 HP/EN、说话、快进、具名 cut-in。C01 接触留地图、关键招进组合画面，方向一致；不要为了像 Y 把每下都切全屏。
6. **升级贴在地图上。** LEVEL UP!! + MONEY。C01 Clear 已是 gf_modern panel；不要做成网页成绩单，也不要为第一话做金钱。
7. **战略是清图后的家。** 任务 / 自定义 / STG / 数据库。MXP 教程 1/4 盖在菜单上。C01 不做改造树；若以后做巡展整备，只保留「看机况 / 出击」语言。

### 3.4 交互语言与模式干货

1. **键位永远写在当前层的铬上。** 黑底只有继续/跳过；ADV 多 AUTO/记录/百科；地图多转镜/缩放/切单位；战斗多快进；战略多确定/返回/教程翻页。换模式就换键，不共用一块永远正确的帮助条。
2. **说话人是签，人是卡。** 名字在盒顶色签（阿尼娜青绿、ZERO、库罗斯）。人铺在场景或半身卡上，不是镂空视窗。C01 B6 已按这个收。
3. **百科是提问，不是侧栏。** QUESTION 列表、当前关键词黄高亮、显示中角标、J/K 进出。C01 关键词事典可后做；现在不要把资料常驻右栏。
4. **光标有形状。** 蓝菱形 + 地面白框。C01 一颗选中菱形。可吸收：停在友军 / 空地 / 敌 / 占地冲突时颜色或教练必须不同。不因此开六指令。
5. **地图说话不收光标。** 09:15 / 16:00 / 18:30 对白压上去，菱形还在。玩家一直知道「这是棋盘」。
6. **教程盖在真菜单上。** 27:25 STG 教程 1/4，底下能看见左栏高亮和右侧立绘。不是另开说明页把游戏藏起来。

### 8.2 语法（这才是语言）

1. **一层一件主确认。** 继续 / 下一句 / 选中 / 确定，同一时刻只有一个「往前」。可选工具（AUTO、记录、百科、转镜、缩放）全部靠边，不和主确认抢位置。
2. **取消永远拆当前层，不拆底下。** 同一颗 K：在百科是返回，在黑底是跳过这一段，在战斗是跳过这场演出，在教程是跳过说明。意思都是「关掉我正在看的这一层」。C01 已经在换义：对白 A = 下一句，EDIT A = 落格。语言是对的。换义时铬必须跟着换，不能还写着上一层的键。
3. **底下有意义就留着。** 地图 ADV 留光标，因为玩家还在棋盘上。教程留菜单，因为说明的就是这张菜单。百科留对白，因为词是从这句话点出来的。战斗不留地图，因为这一层的主读变成双方机体和 HP。
4. **台词是角色说的，键是系统说的。** 两集对白正文里没有「请按 J 继续」。键写在盒外铬上。C01 B6 已把 `StoryControlHint` 赶出对白井，对齐这条。
5. **换层就换键面。** 黑底两键；ADV 四件套（AUTO / 跳过场面 / 记录 / 百科）；地图转镜·缩放·切单位·能力；战斗快进；战略确定/返回。不存在一块永远正确的帮助条。
6. **跳过有种类。** 跳过场面 ≠ 跳过战斗演出 ≠ 跳过教程。第一种拆剧情块，第二种拆这一击的动画，第三种拆盖在菜单上的说明。C01 现在只有对白跳过。接触短，可以暂时不分第二层；但地图上若压对白，跳过只能拆对白，不能拆规划。
7. **玩家何时能动手，用模式告诉，不用说明书。** 对白一收，键面从四件套换成地图铬，这就是「轮到你了」。敌方阶段顶栏变红，这就是「现在不能走」。C01 缺的是这层可见差，不是一句教练「请出击」。
8. **光标是「你现在指着谁」。** 蓝菱形 + 地面白框。对白期它还在，表示棋盘没走。操作期它是主语。底栏单位卡跟着光标，不是跟着剧情。C01 一颗选中菱形；规划右栏跟着打法，不跟着光标。两套都能成立，不要合成一块。
9. **有人说话就有脸+签；系统说话不用角色卡。** 阿尼娜/库罗斯/拓马用半身卡+色签。CAUTION、STG 教程、黑底史诗是系统层。C01 七海必须是通讯投影，不能是没脸字幕，也不能本人到场。
10. **先看后指，先指后承诺。** 官方整圈和体验版专栏把「指着 → 选武器（半屏留地图）→ 目标头顶命中/击破 → Battle Data 预伤 → 确认」写成一条链。两集实况没稳定抓到后半段。C01 合法方案一下出击，等于跳过了承诺层。下一刀薄预测只补「谁打谁 / 会不会叠格 / 保护对象还在不在」，不搬半屏武器表。

### 8.3 方式：Y 怎么让玩家「会玩」

不是靠第一话教程关，是靠层自己说话。

- **阅读层**把世界和人给你，键很少，逃是跳过。
- **查阅层**从台词里长出来，盖住阅读，返回就回到原句。
- **空间阅读层**（地图 ADV）让你一边听一边看见敌我，但还不能走。这是两集里对 C01 最缺的一层。
- **指认层**（我方阶段）光标变成主语，底栏变成「你指着的那台」。体验版比 30 多做的事：资料沉底，光标对准就能读，少开一页能力。
- **承诺层**（选武器/目标/预测）让你在按下之前看见后果。体验版：半屏留地图选武器；射程内敌机头顶出命中和击破；Battle Data 出预伤和 SHOOT DOWN。两集实况待补。
- **观看层**（战斗/cut-in/LEVEL UP）把盘面交给演出，逃只逃这一击。
- **对方层**（敌方阶段）颜色反过来，你变成观众，但仍可读敌机卡。

C01 现网有阅读层（序章/桥）、指认+决策层（PUBLIC/EDIT 合成一层）、观看层（接触/过场）、结果层（RESULT/Clear）。缺空间阅读层、对方层、承诺层。查阅层后做。

## 9. 操作引导：好在哪 / 借鉴什么 / C01 怎么复刻

7. **跳过有种类。** 场面 ≠ 战斗演出 ≠ 教程。逃的是当前层，不是整局。
8. **光标是「你指着谁」。** 底栏单位卡跟着光标。资料沉底，少开一页。

体验感好，是因为**玩家很少被说明书打断，也很少在同一面里听到两种声音**。角色说话时世界还在；系统说话时键在铬上；能动手时铬一定换了。

### 9.3 现网裂缝（复刻靶子）
