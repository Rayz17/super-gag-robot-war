## 0. 本章剧情梗概

一句话梗概：

> 闭馆后的万机馆被代哥清算部以“风险封存”的名义接管，东侧火警同时爆发；纪存和守展众人先在火警与封存流程中保护留言墙和孩子，再让馆守Z以半损状态站上战场，最后发现固定馆址守不住，只能启动旧移动底盘，把半座博物馆变成流亡展舰。

火灾没有取消。第一章的火灾线按四步展开：

| 阶段 | 发生位置 | 剧情作用 | 玩家感受 |
| --- | --- | --- | --- |
| 冷开场 | 火灾后30秒的主展厅 | 先展示后果：留言墙被烧、馆守Z巨掌挡墙、旧守护者仍广播“观众仍在馆内” | 玩家知道今晚会出事，但不知道原因 |
| 1-1后半 | 东侧服务通道/前厅/主展厅 | 法务封存接管时，东侧火警同时响起；火灾和封存一起把人关在馆里 | 玩家刚喜欢上的展区正在变成保护目标 |
| 1-2 | 主展厅正式战棋地图 | 火势变成地形压力、封锁L2天桥、推高馆守Z过热风险 | 战斗不是清怪，而是在燃烧和封存中护展 |
| 1-3 | B1机库与撤离路线 | 火势和第二轮封锁让固定馆址守不住，逼出资源取舍和展舰化 | 不是胜利，是带着损伤撤离 |

本章不是“火灾发生后再开馆”，而是“今晚火灾后的第一次重新开灯”。标题里的“火灾后的开馆”指第一章结尾：万机馆已经烧损、被清算标记、失去固定馆址，但仍在移动中的临时展厅贴出新的开馆标题。

三话梗概：

| 话数 | 标题 | 剧情梗概 |
| --- | --- | --- |
| 1-1 | 今日闭馆后 | 三小时前，纪存在固定博物馆万机馆执行闭馆巡检。玩家通过前厅总图、档案终端、万机中庭、模型病院、现实机器小舞台、留言墙和0号侧廊认识这座馆。闭馆时，代哥清算部远程接管，七海以合法清单列出0号异常、馆守Z右臂脉冲、未归档留言和展项活化接口；封存无人机进入，东侧火警响起。玩家在6回合保护战中撤离孩子、守留言墙、阻止0号开启臂。结尾馆守Z胸牌接入，B1路线亮起。 |
| 1-2 | 展厅里的旧守护者 | 旧守护者回到18米馆守Z本体，但它的启动语仍是“请勿奔跑，展厅地滑”。玩家第一次操作馆守Z进行正式战棋：击退回收无人机、保护展岛和留言墙、控制过热、安全锁和火势。豪司第3回合支援，七海远程指出馆守Z活动构成事故前置，0号侧廊声音干扰馆守Z。战后系统显示胜利，但众人不承认这是胜利；馆长录音提示“保住能开灯的人”。 |
| 1-3 | 流亡展舰 | 众人进入B1展舰机库脊柱，看到馆守Z被固定在重型维修架上，也看到移动底盘和中型泊位。火势和封锁逼近，玩家只能在救人、救展品、救服务器中完整救两类。纪存进入馆长办公室，发现移动底盘启动钥已插入，馆长录音要求把能开的灯带走。万机馆启动旧移动底盘，从旧会展区撤离。七海承认自己延迟了东侧消防锁四十秒。最后孩子们在移动中的临时展厅贴上新标题，第一章以“闭馆记录：未完”结束。 |

## 0.1 本章统一标准

每一话都按同一套检查项写作：

| 项目 | 要求 |
| --- | --- |
| 剧情功能 | 本话必须推动一个清楚的章节动作，不用闲聊堆容量。 |
| 地图锚点 | 每场都绑定万机馆具体空间、展区、终端视图或泊位规则。 |
| 玩法触发 | 探索、选择、战斗、回合事件或结算必须明确进入哪些变量。 |
| 台词口吻 | 先像人话，再体现角色职业、欲望、听众和动作。 |
| 资产锚点 | 给美术可画的空间、物件、界面或单位，不只写情绪。 |
| canon边界 | 七海第一话不到现场；豪司不进1-1保护战；馆长不做谜语人；0号不解释真相；火警线贯穿三话。 |

第一章三话功能：

| 话数 | 标题 | 玩家做什么 | 本话结束时玩家明白什么 |
| --- | --- | --- | --- |
| 1-1 | 今日闭馆后 | 闭馆巡查、看展、回复留言、保护留言墙6回合 | 万机馆值得保护，代哥清算的表面理由成立，火警和封存正在同时逼近 |
| 1-2 | 展厅里的旧守护者 | 操作半启动馆守Z正式战棋，控温、护展、击退回收无人机 | 馆守Z能战斗但不是救世主，旧守护者从规则管理员变成会选择的守护者 |
| 1-3 | 流亡展舰 | 进入B1机库，做资源取舍，启动移动底盘，选择临时开馆标题 | 固定馆址守不住，万机馆变成流亡展舰；这不是胜利，是带着损伤开灯 |

### 1.4 闭馆路线规则

档案终端显示三档路线，不在角色台词里解释制作术语。

| 档位 | 剧情表现 | 后续影响 |
| --- | --- | --- |
| A档 | 必经主线：前厅、中庭、留言墙、维修角、0号侧廊、法务接管、保护战 | 推进主线变量和战斗目标 |
| B档 | 可选调查：合体变形环廊、模型病院、现实机器小舞台等 | 进入`exhibit_seen_set`，七海清单和保护战副目标动态回收 |
| C档 | 远景/灰显：L2舰桥、L3远星、B1机库、B2残响接口 | 只提供万机馆厚度，不新增长期变量 |

## 4. 第一章台词复核清单

| 角色 | 本章说话底线 |
| --- | --- |
| 纪存 | 用终端、记录、分类和具体物件表达感情；不直接讲主题。 |
| 兜灯 | 用维修、安全锁、温度和旧件说担心；不讲抽象守护论。 |
| 唐胶 | 先挑工艺问题，再动手帮忙；不堆塑料梗和金句。 |
| 旧守护者 | 规则在努力长出感情；不卖萌，不讲人类之爱。 |
| 七海 | 礼貌、授权链、风险和报告；不现场登场，不纯反派威胁。 |
| 小满 | 贴纸、社勇王、逞强、错误逻辑；不讲世界观。 |
| 阿澄 | 数人、收纸条、问具体异常；不当温柔旁白。 |
| 馆长 | 像熟人临时留言，有具体禁令和旧习惯；不当神谕。 |
| 陆衡 | 参数、工况、失败记录和工程吐槽；不只负责“不科学”。 |

每场台本拆事件脚本前必须问一次：这句话换另一个角色说是否仍成立？如果成立，重写。
