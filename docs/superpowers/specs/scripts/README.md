## 写作规格

- `剧本` 负责角色行为、对白、情绪和节奏。
- `流程` 负责玩家目标、触发条件、教程点、变量变化和资产需求。
- `悬念账本` 负责记录本话已经揭示什么、故意不解释什么，以及后续在哪一章回收。
- 写对白前先查 [角色声音数据说明](../data/character_voice/README.md)，确认角色小传、欲望、恐惧、应激动作和禁用写法。
- 第一章后续做事件脚本、地图原型、战斗验证或美术拆单时，优先读取 `2026-06-25-chao-gag-chapter-01-standardized-script-v01.md` 与 `../data/story/chapter_01_standardized_flow.tsv`。
- 当前第一话如需更细对白，可继续回看 `2026-06-25-chao-gag-episode-01-merged-v03.md`；`2026-06-22-chao-gag-episode-01-02-optimized-v01.md` 和旧第一话 v0.4/v0.3/v0.2 只作为历史素材库。
- `2026-06-19-chao-gag-chapter-01-full-script-v01.md` 保留为旧四话素材包，不再作为当前第一章主 review 入口。
