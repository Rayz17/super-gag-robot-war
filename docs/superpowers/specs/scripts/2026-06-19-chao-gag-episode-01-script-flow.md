# 《超GAG机器人大战：万机残响》第一话详细剧本与流程 v0.1

> 第一话标题：**今日闭馆后**  
> 所属章节：第1章《火灾后的开馆》  
> 覆盖场景：`SC01-01 今日闭馆后`、`SC01-02 展柜右臂`、`SC01-03 法务警报`的引爆段  
> 对应数据：`D001`、`D002`、`D003`、`D004`前半，互动 `IN001`、`IN004`前置  

## 1. 第一话定位

第一话的核心任务不是解释世界观，而是让玩家在万机馆被袭击前，先相信这里是一个值得保护的地方。

本话要做到五件事：

| 目标 | 设计要求 |
| --- | --- |
| 让玩家喜欢万机馆 | 展厅要有生活痕迹：孩子留言、旧守护者巡馆、兜灯修机、唐胶挑水口 |
| 给玩家第一个身份感 | 玩家不是战士，而是闭馆后的档案员/策展人，用记录和回应影响世界 |
| 揭示机魂异常 | 展品会回应玩家，但所有人都把它解释成老设备、传感器误差或展馆怪谈 |
| 引入清算部压力 | 七海用礼貌、合法、优雅的方式宣布回收，不做扁平恶役 |
| 留下核心疑问 | 主角为什么能听见展品？黑展柜是什么？馆长去哪了？G.A.G. 为什么识别主角？ |

本话不完成正式战棋关。结尾进入“法务警报”，把第二话的保护战点燃出来。这样第一话像《机器人文化版十三机兵》的开场：温柔、怪异、可玩，最后突然被更大的系统咬住。

建议时长：

| 内容 | 预计时长 |
| --- | --- |
| 冷开场与标题 | 2 到 3 分钟 |
| 自由巡馆与三处展品调查 | 10 到 14 分钟 |
| 展柜右臂事件 | 6 到 8 分钟 |
| 留言墙回复与馆长录音 | 5 到 7 分钟 |
| 法务警报与七海登场 | 5 到 7 分钟 |
| 总计 | 28 到 39 分钟 |

## 2. 已揭示与未揭示

### 本话明确揭示

1. **万机馆是机器人文化博物馆，也是避难所**  
   它有展厅、机库、模型维修角、孩子留言墙、旧时代服务器和半沉睡机体。

2. **G.A.G. 是一个真实存在的巨型档案系统**  
   表层是资料库和资产索引，清算部也使用它作为合法回收依据。

3. **机魂现象存在，但还未被命名为神话**  
   展品会对玩家产生异常回应，旧守护者也有超过普通 AI 的反应。

4. **代哥清算部不是普通军队**  
   它以授权、合规、资产状态、风险封存等语言行动。

5. **主角不是普通旁观者**  
   终端把主角识别为“空白展柜临时策展人”，黑展柜对主角有反应。

### 本话故意不解释

| 疑问 | 本话表现 | 后续回收 |
| --- | --- | --- |
| 主角到底是不是人 | 终端识别异常；旧守护者说“第0次闭馆” | 第9章、第11章、第12章 |
| 黑展柜里是什么 | 只给噪声、裂纹和一句不完整声音 | 第1章后半、第12章 |
| 馆长去哪了 | 只留下不完整录音和钥匙权限 | 第11章、第12章 |
| 七海为什么知道主角档案号 | 她称呼主角不是名字，而是“馆内编号” | 第8章清算都市 |
| 机魂是科技还是神话 | 展品异常可被解释成旧设备故障 | 第3章、第10章 |

## 3. 主要角色状态

| 角色 | 本话表层 | 本话深层 |
| --- | --- | --- |
| 纪存/玩家名 | 万机馆档案员，执行闭馆巡查 | 能听见展品残响，但自己尚未意识到这不是常人能力 |
| 兜灯 | 嘴硬手巧的魔神整备继承者 | 害怕祖父留下的是暴力遗产，不只是守护遗产 |
| 唐胶 | 模型修复师，毒舌，挑剔 | 相信手作痕迹比完美更接近人的记忆 |
| 旧守护者 | 老派半 AI 机体，像展厅管理员 | 记忆缺损，却本能地把孩子和展品都当作要保护的人 |
| 守展小队 | 在馆里帮忙的孩子们 | 让万机馆从博物馆变成家 |
| 七海 | 清算部档案官，礼貌优雅 | 真心相信秩序能避免更大灾难 |
| 馆长 | 不在场，只留录音 | 可能知道主角与黑展柜的真相 |

## 4. 变量与教程点

| ID | 名称 | 来源 | 初始影响 |
| --- | --- | --- | --- |
| `protagonist_tone` | 主角回应语气 | 留言墙和对话选择 | 影响部分主角台词风格 |
| `museum_warmth` | 万机馆家感 | 完成巡馆、回复孩子、帮旧守护者 | 影响第二话守展小队士气 |
| `flaw_preserved` | 破损保留 | 展柜右臂选择 | 影响第9章非最优记忆节点 |
| `model_trust` | 模型信任 | 支持唐胶或承认手作痕迹 | 影响第2章模型线初始 |
| `enterprise_trust_seed` | 企业信任种子 | 对七海态度 | 影响第8章七海晚餐初始语气 |
| `black_case_resonance` | 黑展柜共鸣 | 互动黑展柜和馆长录音 | 影响第1章后半黑展柜异常强度 |

教程点：

| 教程 | 形式 |
| --- | --- |
| 移动与调查 | 闭馆巡查清单 |
| 对话选择 | 留言墙回复和角色对话 |
| 档案记录 | 三处展品自动加入档案 |
| 变量提示 | 用轻提示显示“某段记录被保留了”，不显示数值 |
| 战斗预告 | 结尾法务警报显示保护目标 UI，但不进入正式回合 |

## 6. 详细剧本

### EP01-A 冷开场：未归档残响

场景：黑屏。没有标题。只有旧录像噪声。

演出目的：先给玩家一种“世界发生过无法完整记录的大事”的感觉，但不解释。

```
[黑屏]
[音效] 老式录像带转动。远处有展馆广播残响，像水下传来。

未知广播：
第七展区封存失败。
重复，第七展区封存失败。
请所有观众不要靠近……不要靠近……

[画面闪一下]
一只巨大的机械手从火光里垂下，手掌里像攥着一张儿童留言纸。

儿童声音：
叔叔，如果机器人摔倒了，它还能参加展览吗？

[画面再闪]
黑色展柜。展柜铭牌看不清，只有编号：GAG-00。

馆长录音：
如果你听见它说话，不要回答。
如果它叫你的名字，尤其不要回答。

[系统噪声]
Great Archive Grid 正在恢复索引。
临时策展人权限检索中。
检索结果：空白展柜。

[短暂停顿]
未知声音，很轻：
……今天也要闭馆吗？

[标题出现]
第一话 今日闭馆后
```

说明：

- 这里不出现“机魂”一词。
- 儿童留言和黑展柜同时出现，建立“温柔的小事”和“巨大谜团”并置。
- “空白展柜”是主角身份伏笔，不解释。

### EP01-B 闭馆广播

场景：万机馆档案室。晚上。灯光温暖但有几处闪烁。玩家第一次取得控制。

演出目的：主角不是战士，而是执行闭馆的人。玩家从“整理”和“回应”进入游戏。

```
[画面淡入]
档案室桌面。旧终端、手写便签、半杯冷茶、几张展品卡。窗外能看见主展厅上方悬挂的旧机体手臂。

[系统]
闭馆流程载入。
今日值班：纪存。
今日异常：3。
今日未归档留言：7。

纪存：
又是三条异常。
这个馆要是哪天全绿了，馆长大概会觉得自己被系统演了。

[馆内广播，旧守护者的声音]
闭馆时间到。
各位观众，请带好随身物品、未完成的作业、以及不方便交给大人的愿望。
请勿奔跑，展厅地滑。

纪存：
旧守护者，最后一句今天已经播了六次。

旧守护者：
记录更正。七次。
楼梯口有一名儿童以每秒三点二米速度接近危险区域。

[远处传来孩子急刹车声]

小满：
我没有跑！我是滑行！

旧守护者：
滑行是奔跑的阴谋。

[玩家获得控制]
[教程]
移动：前往主展厅。
调查：检查发光物件。
档案：发现异常时会自动记录。
```

可调查物：

| 物件 | 文本 |
| --- | --- |
| 冷茶 | “馆长的杯子。茶已经凉透，杯底有一圈细灰。今天馆长没有来催你交闭馆报告。” |
| 手写便签 | “0号展柜今晚不要开灯。字迹是馆长的，但最后一笔像被什么东西拖断。” |
| 旧终端 | “G.A.G. 子节点连接不稳定。主机状态：离线。离线时间：-00:00:17。” |

说明：

- `离线时间：-00:00:17` 是时间异常伏笔。玩家可以忽略，但会被细心玩家记住。
- 小满的“滑行”提供轻喜剧，旧守护者不是冷系统，而像唠叨长辈。

### EP01-C 孩子留言墙

场景：主展厅入口。墙上贴满纸条、电子留言、旧票根、涂鸦。守展小队正在把留言贴歪。

演出目的：建立万机馆的家感，同时埋下跌跌、现实机器人和“失败也能参展”的主题。

```
[玩家走近留言墙]

阿澄：
纪存哥，留言墙今天又满了。

小满：
是因为有人把“社勇王最强”贴了十二遍。

阿澄：
你贴的。

小满：
我是在做统计学。

纪存：
统计学不会用彩笔写“最强”。

旧守护者：
纠正。统计学偶尔也需要彩笔。

[系统]
未归档留言：3条需要回复。
请选择回复语气。此选择会影响主角初始表达倾向，不影响剧情路线。
```

留言一：

```
展会孩子：
如果一台机器人老是摔倒，它还能不能放进展览？
我觉得它努力站起来的时候，很像真的机器人。
```

回复选项：

| 选项 | 主角回复 | 变量 |
| --- | --- | --- |
| 温柔 | “可以。摔倒也是它来过这里的证据。” | `protagonist_tone=gentle`; `museum_warmth+1` |
| 冷静 | “可以。失败记录也是展品说明的一部分。” | `protagonist_tone=archivist`; `现实机魂伏笔+1` |
| 吐槽 | “当然可以。我们馆里还有每天摔三次的自动门。” | `protagonist_tone=wry`; `museum_warmth+1` |

留言二：

```
匿名观众：
0号展柜为什么没有说明牌？
我昨天听见里面有人敲玻璃。
```

回复选项：

| 选项 | 主角回复 | 变量 |
| --- | --- | --- |
| 安抚 | “展柜老化会有热胀冷缩声，别怕。” | `black_case_resonance+0` |
| 记录 | “已记录。请不要独自靠近0号展柜。” | `black_case_resonance+1` |
| 玩笑 | “如果它敲出节奏，麻烦帮我录下来，馆里缺片头曲。” | `black_case_resonance+1`; `protagonist_tone=wry` |

留言三：

```
旧纸条，像很久以前贴上去：
如果我明天又忘了这句话，请告诉我我来过。
署名被撕掉，只剩一个“存”字。
```

玩家不能直接回复，只能选择归档方式：

| 选项 | 归档文本 | 变量 |
| --- | --- | --- |
| 普通留言 | “年代不明。可能来自旧馆时期。” | 无 |
| 异常留言 | “署名残缺，与值班员姓名存在重合。” | `black_case_resonance+1` |
| 暂不归档 | “稍后处理。” | 第8段法务警报时此条会被自动删除 |

后续对白：

```
阿澄：
纪存哥，你脸色不太好。

纪存：
看到旧纸条会这样。
像被以前的自己催稿。

小满：
以前的你也这么会拖吗？

纪存：
看这张纸条的语气，可能更会。

旧守护者：
闭馆提示：拖延不是美德。

小满：
那为什么馆长总说“明天再修”？

旧守护者：
馆长拥有高级拖延权限。
```

说明：

- 旧纸条不能写得太惊悚，要像生活玩笑里的一根刺。
- 玩家如果选择“暂不归档”，后面会看见清算系统删除它，制造第一次小后悔。

### EP01-D 旧守护者巡馆

场景：主展厅。中央是“馆守Z”展区，机体处于半跪陈列状态，巨大但旧。装甲上有擦拭痕迹和手写维修标签。

演出目的：让第一台机器人有“长者”和“家用守护者”的气质，而不是马上卖酷。

```
[玩家进入主展厅]
[镜头从机体脚部向上，不做英雄式仰拍，而是先拍擦得发亮的地板、儿童围栏和手写告示]

告示：
请勿攀爬展品。
请勿向飞拳发射口投币。
请勿询问旧守护者“你和馆长谁更老”。

旧守护者：
第三条是馆长加的。
缺乏客观性。

纪存：
你确实比他早入馆。

旧守护者：
入馆不等于变老。
这是展品尊严问题。
```

调查点一：馆守Z胸牌

```
[系统]
展品：馆守Z
状态：封存展示
说明：旧世界早期超级系机魂投射样本。现作为万机馆主展区守护展品。
异常：胸牌热源波动。

纪存：
胸牌又热了。
今天没有参观团，也没有人偷摸许愿。

旧守护者：
纠正。上午十点二十三分，有三名儿童向本机许愿。

纪存：
许了什么？

旧守护者：
一名希望考试及格。
一名希望社勇王最强。
一名希望你不要每次都加班到睡在档案室。

纪存：
最后那个是谁？

旧守护者：
匿名。

[远处小满吹口哨]
```

调查点二：飞拳发射口

```
[系统]
发射口封条完整。
封条日期：G.A.G.事变后第七年。

纪存：
封条还在。

旧守护者：
本机已连续一千九百四十二天未发射右臂。

纪存：
听上去很骄傲。

旧守护者：
本机正在学习和平展陈。
```

调查点三：旧守护者本体终端

```
[系统]
本体记忆区存在缺损。
缺损区域：第0次闭馆记录。

纪存：
第0次？

旧守护者：
今日也是第0次闭馆。

纪存：
你上周也是这么说的。

旧守护者：
每一次闭馆都应该像第一次一样谨慎。

[短暂噪声]
旧守护者：
尤其是你。

纪存：
我？

旧守护者：
记录缺失。请忽略上一句。
```

说明：

- “第0次闭馆”是主角身份伏笔。
- 旧守护者的怪异要迅速被喜剧带过，避免第一话变成悬疑恐怖。

### EP01-E 展柜右臂

场景：维修角。兜灯正在拆一块旧右臂外装甲，唐胶抱着工具箱旁观，嘴比手快。

演出目的：通过一块破损零件建立本作核心伦理：修复不是把东西变新，保存也不是把东西供死。

```
[玩家靠近维修角]

兜灯：
别踩那条线。

纪存：
哪条？

兜灯：
你已经踩了。

唐胶：
这就是为什么我说展馆地面应该画水口线。

纪存：
水口线听上去不像安全规范。

唐胶：
大部分安全事故都源于不尊重水口。

兜灯：
你再把我爷爷留下的右臂叫成水口事故，我就把你塞进旧零件箱。

唐胶：
祖传零件也要看水口。
历史不能成为打磨不干净的借口。
```

兜灯展示右臂零件：

```
[镜头推近]
一块旧外装甲。边缘有烧痕，内侧刻着很浅的日期和一个儿童手印。

兜灯：
这块甲片是馆守Z第一次入馆时留下的。
馆长说应该换掉，裂纹会扩。

唐胶：
换是对的。
但换下来别扔。裂纹有裂纹的用法。

纪存：
比如？

唐胶：
比如提醒后来的人，别以为机器人一开始就是干净漂亮的。

兜灯：
它不是模型。

唐胶：
所以更不能只看正面官图。
```

### EP01-F 黑展柜

场景：0号展柜所在的侧廊。灯更暗，告示牌被拆掉，只剩地面黄线。旧守护者会提示不要靠近，但不会阻止。

演出目的：给核心谜题第一下，让玩家知道万机馆的秘密不只是温暖。

## 8. 第一话结束后的玩家状态

玩家应带着三种情绪进入第二话：

1. **想保护**：留言墙、孩子、旧守护者、兜灯的右臂都已经有意义。
2. **想知道**：黑展柜、馆长、主角权限、G.A.G. 时间异常都没有解释。
3. **想反驳但不能简单反驳**：七海并不疯，她的语言甚至很有秩序，这让清算部更有压迫感。

第一话最后的心理钩子：

> 万机馆不是被坏人袭击了。万机馆是被一个看起来比它更正确、更合法、更冷静的世界判定为危险。

## 10. 制作备注

资产优先级：

| 资产 | 优先级 | 说明 |
| --- | --- | --- |
| 万机馆主展厅 | P0 | 第一话和第二话核心空间，需支持正常、警报、损毁三种状态 |
| 留言墙 UI | P0 | 兼具剧情、选择、变量和后续回收 |
| 旧守护者 Q版待机 | P0 | 不必做战斗动画，但要有巡馆、胸牌亮起、广播头像 |
| 兜灯/唐胶/七海立绘 | P0 | 第一话最重要人物立绘 |
| 黑展柜 | P0 | 简单但要有强识别度：反射异常、裂纹、弱光 |
| 法务机兵剪影 | P1 | 第一话只需入侵预告，第二话进入战斗 |
| 馆长录音 UI | P1 | 可用音频波形和旧终端画面代替立绘 |

实现建议：

- 第一话用 2D 探索地图即可，不需要战棋格。
- 结尾出现战斗目标 UI，但正式回合从第二话开始。
- 对话选项只给轻提示，不显示具体数值，避免破坏文学感。
- 旧守护者的广播头像可以复用为教程提示头像，形成“系统提示也是角色”的质感。
- 黑展柜所有演出保持低成本：音效、反射缺失、细裂纹、终端文本即可。
