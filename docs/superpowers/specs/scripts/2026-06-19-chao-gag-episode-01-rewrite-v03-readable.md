# 《超GAG机器人大战：万机残响》第一话《今日闭馆后》可理解性重构 v0.3

> 本稿针对 v0.2 暴露的问题重构：空间不清、机体尺度不清、交互方式不清、火灾前置不清、与第1章大纲关系不清。  
> v0.3 的目标不是更炫，而是让一个第一次打开游戏的人知道：我在哪里、我是谁、我在做什么、什么东西值得我稍后拼命保护。

## 0. 先承认 v0.2 的问题

v0.2 的对白比 v0.1 更像人，但它依然失败在“入口设计”上：

| 问题 | 为什么会让人看不懂 | v0.3 修正 |
| --- | --- | --- |
| 万机馆没有先定义 | 读者只能脑补成普通展馆、飞船、机库或AVG背景 | 第一页明确：第一话时它还是固定博物馆，火灾后才改造成流亡展舰 |
| 馆守Z尺度不明 | “胸牌、右臂、导览、旧守护者”混在一起，像巨机、AI和模型同时存在 | 明确馆守Z是18米级巨型展品；旧守护者是它的导览/安全AI，平时通过小导览机和广播行动 |
| 交互语法不明 | 一会儿像文字AVG，一会儿像地图探索，一会儿像战斗预告 | 明确第一话主玩法是俯视角探索地图 + 对话框 + 调查UI；无战斗，结尾只预告1-2混合战 |
| 火灾缺席 | 第1章叫“火灾后的开馆”，但第一话没有让读者理解火灾何时发生 | 第一话是“火灾前夜”；冷开场用火灾后残片做悬念，结尾切入法务警报和火警，火灾在1-2发生 |
| 谜团太早太密 | 玩家还没喜欢万机馆，就被0号展柜、明日权限、清算部塞满 | 0号展柜只作为锁门和一声敲玻璃；七海不在第一话正面长谈，留到1-2 |

一句话：**第一话不应该负责解释世界真相，它负责让玩家知道万机馆是一座会呼吸的地方。**

## 1. 与第1章大纲的关系

第1章《火灾后的开馆》不是单一一话，而是四话开局弧线：

| 话号 | 标题 | 类型 | 本话功能 | 是否战斗 |
| --- | --- | --- | --- | --- |
| 1-1 | 今日闭馆后 | 船内探索 | 火灾前夜，玩家认识万机馆、主角、留言墙、馆守Z和日常交互 | 无战斗 |
| 1-2 | 法务警报 | 混合 | 清算部突袭，火灾发生，玩家保护留言墙6回合 | 小规模保护战 |
| 1-3 | 展厅里的旧守护者 | 战斗 | 馆守Z半启动，第一次正式操作Q版战棋单位 | 正式战棋 |
| 1-4 | 流亡展舰 | 船内/幕间 | 博物馆被毁，幸存者把核心展品装上移动基地，万机馆成为流亡展舰 | 资源取舍 |

因此，第一话的结尾只做到：

1. 玩家已经走过将要失火的地方。
2. 玩家知道留言墙、右臂、馆守Z、档案室各有什么意义。
3. 法务警报和火警同时响起。
4. 屏幕切到第二话标题《法务警报》。

第一话不展示完整清算逻辑，不让七海长篇登场，不展开正式战棋。

## 2. 万机馆是什么

### 2.1 第一话时间点

第一话时，万机馆还不是流亡展舰。

它是旧世界最后一座中立机器人文化博物馆，坐落在半废弃城市的旧会展区。它白天对外开放，晚上收容少量无处可去的孩子、修复师、粉丝和维修人员。火灾和清算发生后，幸存者才把展品、服务器、模型柜、留言墙和半成品机库装进移动基地，形成后续的“流亡展舰万机馆”。

### 2.2 空间尺度

第一话开放的是博物馆的一小块，不是整座基地：

| 区域 | 尺度 | 玩家是否可走 | 作用 |
| --- | --- | --- | --- |
| 前厅 | 约25米宽，售票口、纪念章台、安检门 | 可走 | 让玩家看见普通观众刚离开，万机馆不是军事基地 |
| 主展厅 | 约70米长、45米宽、24米高，三层挑空 | 可走 | 馆守Z半跪陈列，形成第一视觉记忆 |
| 留言墙 | 主展厅入口侧墙，约12米长 | 可走、可互动 | 玩家回复留言，建立万机馆家感 |
| 维修角 | 主展厅侧面半开放工位，右臂外装甲放在维护台上 | 可走、可互动 | 兜灯、唐胶、旧件选择 |
| 档案室 | 后台小房间，终端、纸质档案、馆长茶杯 | 可走、可调查 | 教学、闭馆清单、馆长缺席 |
| 0号侧廊 | 主展厅后方封闭走廊，只开放门口2到3格 | 半开放 | 只给异常敲玻璃，不做完整谜团展示 |

### 2.3 玩家第一次看见什么

第一话不能一上来就黑展柜。第一眼应该是：

1. 快闭馆的前厅，普通观众往外走。
2. 孩子在留言墙前争“最强”要几个感叹号。
3. 一个半人高导览机用旧守护者的声音提醒“请勿奔跑”。
4. 镜头抬高，玩家才看见主展厅中央半跪的18米级馆守Z。

先有生活，再有巨物，再有异常。

## 3. 馆守Z、旧守护者和尺度口径

### 3.1 正式口径

| 名称 | 尺度 | 第一话状态 | 玩家如何接触 |
| --- | --- | --- | --- |
| 馆守Z | 18米级巨型机体，半跪时头部接近三层天桥 | 封存展示，右前臂拆下维护，主反应炉断开 | 作为主展厅巨型展品调查，玩家不能驾驶 |
| 旧守护者 | 馆守Z的导览/安全AI，也管理部分展厅广播 | 平时住在半人高导览机和馆内广播里 | 像NPC一样跟随或插话；1-3回到馆守Z本体 |
| 导览机外壳 | 约1.2米高，轮式小机器，胸前有旧馆徽 | 旧守护者的日常身体 | 可在探索地图上作为Q版NPC移动 |
| 右臂外装甲 | 约5米长，放在维修台上，玩家站在旁边显得很小 | 兜灯正在复核封条，唐胶挑毛边 | 作为物件调查和选择对象 |
| 0号展柜 | 约2.3米高的黑色人形展柜，不是馆守Z的一部分 | 封闭，不反射纪存 | 第一话只靠近门口听见敲玻璃 |

### 3.2 镜头表达

第一次展示馆守Z时，不要直接给英雄仰拍。顺序是：

1. 地面上“请勿向飞拳发射口投币”的告示。
2. 小满从馆守Z脚边跑过，脚掌比他还高。
3. 二楼维修天桥有一条黄色安全线，兜灯在上面检查胸牌灯。
4. 镜头才上移到馆守Z的脸。

玩家应先理解：它大，但它被展馆生活驯化过。

## 4. 第一话交互方式

第一话采用“探索地图为主，AVG对话为辅”的交互。

| 模式 | 玩家看见 | 玩家能做 | 第一话用途 |
| --- | --- | --- | --- |
| 俯视角探索地图 | Q版纪存在展馆里移动，类似GBA RPG/阿猫阿狗式小地图 | 走动、按确认调查、与NPC说话 | 第一话主模式 |
| 对话框+角色立绘 | 触发剧情或NPC对话时出现半身立绘和对话框 | 读对白，少量选择 | 角色交流 |
| 调查UI | 物件放大图、展签、手写备注、档案按钮 | 归档、选择回复、拍照留存 | 档案员身份 |
| 闭馆清单 | 屏幕右侧任务列表 | 选择下一个调查点 | 引导不迷路 |
| 战斗预告UI | 结尾短暂出现方格与保护目标 | 无正式操作 | 告诉玩家下一话进入混合战 |

第一话玩家的核心循环：

```text
走到地点 -> 看见物件和人 -> 对话 -> 调查/归档 -> 闭馆清单更新 -> 下一个地点
```

第一话不出现：

- 回合制战棋操作。
- 机体移动和攻击指令。
- 复杂养成菜单。
- 大量G.A.G.术语解释。

第一话只要玩家学会三件事：

1. 我可以在万机馆里走动。
2. 我可以调查物件并改变档案。
3. 我回复过的东西，后面会成为战斗中要保护的东西。

| 段落 | 场景 | 玩家目标 | 说明 |
| --- | --- | --- | --- |
| A | 火灾后30秒冷开场 | 观看 | 让玩家知道“这里会烧起来”，但不解释原因 |

| F | 维修角 | 处理右臂旧件 | 交代兜灯、唐胶和“破损是否保留” |

| I | 法务警报/火警 | 观看 | 切到第二话，不在第一话解决 |

## 6. 详细台本 v0.3

### EP01-A 火灾后30秒：冷开场

模式：短过场，30到45秒。

目的：先让玩家知道第1章为什么叫“火灾后的开馆”，但不要让玩家理解全部原因。

```text
[黑屏]
[音效] 洒水喷头。远处警报。木头和塑料烧焦后的细小爆裂声。

[画面亮起]
主展厅地面。水流把彩色留言纸冲到排水沟边。
半张纸还贴在墙上，能看见几个字：
“机器人摔倒了……还能……”

旧守护者[广播断续]：
闭馆流程未完成。
观众仍在馆内。
重复，观众仍在馆内。

[镜头低角度]
一个半人高的导览机倒在地上，轮子空转。
它胸前的旧馆徽还在闪。

[镜头抬高]
馆守Z巨大的手掌挡在留言墙前。
手掌上有烧痕，指节间夹着一张没烧完的儿童留言。

系统字幕：
火灾记录：未归档。
距离第一次警报：00:30。

馆长录音，很近：
纪存，别把这段转文字。
你一转文字，就会装没听懂。

[画面切黑]
字幕：
三小时前。

[标题]
第一话 今日闭馆后
```

这里的冷开场告诉玩家：这座馆会失火，馆守Z会保护留言墙，旧守护者会把“观众仍在馆内”当成最高规则。然后立刻回到火灾前的日常。

### EP01-B 前厅：最后一批观众

模式：探索地图开始。

场景：万机馆前厅。售票灯半关，纪念章台旁排着几个刚盖完章的孩子。门外是半废弃会展区的夜色。

```text
[探索地图]
玩家控制纪存站在前厅服务台旁。
屏幕右上角显示：23:07 / 闭馆巡查。

旧守护者[广播]：
万机馆今日闭馆。
请各位观众带好随身物品、纪念章、未完成的作业，以及不方便交给大人的愿望。

游客甲：
这个广播每天都这么说？

纪存：
它最近学会了“愿望”这个词。
馆长说比“遗失物”听起来不那么倒霉。

旧守护者的小导览机从屏幕右侧滑过。
它约到纪存胸口，轮子有点偏，走直线时会轻微拐弯。

旧守护者：
本机未学习。
本机只是把遗失物扩大分类。

小满从留言墙方向冲出来。

旧守护者：
小满未奔跑。
小满正在以奔跑速度否认奔跑。

小满：
我没有跑，我是在让鞋先过去！

纪存：
让鞋回来。闭馆了。
```

教程提示：

```text
[教程]
左摇杆/方向键：移动。
确认键：调查发光物件或对话。
菜单键：查看闭馆清单。
```

前厅可调查物：

| 物件 | 文本 |
| --- | --- |
| 万机馆招牌 | “旧世界机器人文化博物馆。下面贴着一行新纸：今日主展，馆守Z修复展。” |
| 纪念章台 | “印章图案是馆守Z胸牌。小满把自己的本子盖到纸快破了。” |
| 导览地图 | “本次开放区域：前厅、主展厅、留言墙、维修角、档案室。0号侧廊不对观众开放。” |
| 关闭的纪念品柜 | “里面有拼装工具、旧录像带、便宜贴纸和一排卖不动的馆守Z钥匙扣。” |

完成前厅调查后，闭馆清单弹出。

```text
闭馆清单：
1. 去档案室确认今日异常。
2. 检查留言墙未归档留言。
3. 检查馆守Z主展区。
4. 协助维修角封存右臂旧件。
```

### EP01-C 档案室：主角身份

模式：探索地图 + 调查UI。

目的：交代纪存是档案员/临时策展人。他的“能力”先表现为熟悉馆内琐事，不是神秘主角光环。

```text
[探索地图]
纪存进入档案室。
房间不大，一张旧桌、三排铁柜、一个终端、一杯没洗的茶。

纪存：
馆长的杯子还在。
人不在，杯子倒挺守时。

旧守护者[广播]：
馆长不在。馆长杯具仍在。
该组合不常见。

纪存：
你别学我说话。

旧守护者：
本机未学习。本机正在复述不常见组合。
```

调查终端：

```text
[调查UI：旧终端]
今日值班：纪存。
身份：档案员 / 临时闭馆负责人。
今日观众：143。
未归档留言：7。
展品异常：3。

纪存：
三条异常。
馆长要是在，会先擦屏幕，再说是屏幕脏。

旧守护者：
屏幕表面洁净度：87%。
馆长借口可信度：中。
```

调查茶杯：

```text
纪存拿起茶杯，又放回原位。

纪存：
没洗。

阿澄[门口探头]：
馆长每次出远门都会洗杯子。

纪存：
也可能只是忘了。

阿澄：
馆长会忘记关投影机。
不会忘记杯子。
```

调查便签：

```text
[便签]
0号侧廊今晚别开。
不是坏了，是太像没坏。

纪存：
太像没坏是什么坏法。
```

这里不解释0号展柜。只让玩家知道侧廊禁止进入。

### EP01-D 留言墙：观众如何和万机馆互动

模式：探索地图 + 留言墙UI + 角色对话。

场景：主展厅入口侧墙。留言墙不是普通公告栏，而是一整面由纸条、旧票根、拍立得、电子便签混合起来的“观众回声”。玩家以后会反复回到这里。

```text
[探索地图]
留言墙前，小满在贴一张很大的“社勇王最强!!!”。
阿澄站在小凳子上，把贴歪的票根扶正。

纪存：
小满，感叹号不算独立展品。
两个也不算。

小满：
少一个感叹号都不算最强。

唐胶[路过，没停下]：
第三个贴歪了。

小满：
你这个大人怎么连感叹号都挑水口。

唐胶：
字也有水口。
```

留言墙UI说明：

```text
[教程]
留言墙不是收集品列表。
你回复的留言会改变后续档案、角色台词和部分战斗目标。
第一话只显示轻提示，不显示数值。
```

留言一：

```text
如果一台机器人老是摔倒，它还能不能放进展览？
我觉得它努力站起来的时候，很像真的机器人。
```

回复选项：

| 选项 | 回复 | 作用 |
| --- | --- | --- |
| 温柔 | “可以。展签上不用只写成功动作。你要是记得它摔了几次，也写上。” | `museum_warmth+1` |
| 档案员 | “可以。摔倒次数、扶它的人、地板材质，都算记录。” | `real_machine_trust_seed+1` |
| 吐槽 | “可以。我们馆的自动门每天失败三次，目前仍然厚着脸皮营业。” | `protagonist_tone=wry` |

选择后：

```text
阿澄：
那它摔倒的时候，展签要写疼吗？

纪存：
如果有人问，就写“维修中”。

阿澄：
骗人。

纪存：
嗯。
那写“当时有人在旁边”。
```

留言二：

```text
0号侧廊为什么总锁着？
我昨天听见里面有人敲玻璃。
```

回复选项：

| 选项 | 回复 | 作用 |
| --- | --- | --- |
| 安抚 | “老展柜夜里会响。听到的时候别一个人过去，叫旧守护者。” | `museum_warmth+1` |
| 记录 | “已记录。0号侧廊今晚不开放，也不回答问题。” | `black_case_resonance+1` |
| 玩笑 | “如果它敲出节奏，先别鼓掌。馆里没给它批演出许可。” | `protagonist_tone=wry` |

选择后，旧守护者插话：

```text
旧守护者：
建议忽略0号侧廊。

纪存：
建议来源？

旧守护者：
记录缺失。

纪存：
那不叫来源。
```

留言三：旧纸条。

```text
阿澄从留言墙最下层抽出一张发黄纸条。

阿澄：
这张不是小满写的。

小满：

纸条内容：
```

归档选项：

| 选项 | 归档文本 | 后续 |
| --- | --- | --- |
| 普通留言 | 年代不明，可能来自旧馆时期 | 安全但不触发额外异常 |

这里给谜团，但不再继续追问。玩家的目标仍然是闭馆。

模式：探索地图 + 镜头演出 + 三处调查。

场景：主展厅。这里必须让玩家明确馆守Z不是模型，不是人大小机体，而是完整18米级超级系展品。

```text
二楼维修天桥上，兜灯正拿着灯笔检查胸牌。

18米级旧式守护机。
```

```text
合体审批未申请。
```

```text
旧守护者：
上午十点四十一分，一枚游戏币。

纪存：
唐胶？
```

调查点二：胸牌。

```text
[调查UI]

你每次都说会掉灰。
```

## 7. 1-2 与 1-3 的战斗承接

为了避免第一话读起来像“应该战斗但没有战斗”，后续明确承接如下：

| 后续话 | 战斗形式 | 规模 | 玩家目标 |
| --- | --- | --- | --- |
| 1-2 法务警报 | 同一展厅地图叠加6x8小战术格，偏人/小机器尺度 | 纪存、旧守护者导览机、兜灯、唐胶对法务无人机 | 保护留言墙6回合，救出孩子，避免0号侧廊被开 |
| 1-3 展厅里的旧守护者 | 主展厅展开为10x8正式战棋地图，馆守Z占2x2大单位 | 馆守Z半启动，敌方回收无人机和封存框体 | 击退回收机，不让展品被删除，不追求全灭 |

1-2 的燃点不是“我方机器人开大”，而是玩家发现自己刚刚回复过的留言会成为地图目标。  
1-3 的燃点才是馆守Z回到18米本体，但它的启动台词仍然不是英雄宣言，而是：

```text
旧守护者：
主展厅进入紧急闭馆。
请勿奔跑。
展厅地滑。
```

## 8. v0.3 的美术和实现指令

| 资产 | 规格建议 | 备注 |
| --- | --- | --- |
| 前厅探索地图 | 俯视角tilemap，约24x16格 | 展示普通博物馆入口 |
| 主展厅探索地图 | 约36x24格，中心为不可穿越巨型馆守Z展区 | 可先用静态大图+碰撞块实现 |
| 馆守Z探索表现 | 半跪巨型背景物，不是普通NPC sprite | 后续战棋才有Q版单位 |
| 旧守护者导览机 | 48x48或64x64小Sprite，轮式移动 | 平时承担系统提示头像 |

| 0号侧廊 | 锁门、窄玻璃、黑展柜剪影 | 第一话不展示完整内部 |
| 法务警报 | 白色扫描线、出口锁定、火警灯 | 只做结尾预告 |

## 9. 当前推荐口径

第一话的推荐口径现在是：

> 火灾前夜，玩家以纪存身份在固定博物馆“万机馆”执行闭馆巡查。玩家通过俯视角探索地图认识留言墙、主展厅巨型馆守Z、旧守护者导览AI、兜灯和唐胶的维修角，并第一次听见无法解释的机魂残响。第一话结尾，闭馆刚完成，代哥清算部接管出口，东侧火警响起，玩家进入第二话《法务警报》的保护战。

这比 v0.2 更少谜语，但更适合开局。谜团不是被删掉，而是被放到玩家已经站稳之后再压下来。
