# 《超GAG机器人大战：万机残响》第一、第二话剧情与台本优化版 v0.2

> 覆盖范围：第1章 1-1《今日闭馆后》、1-2《法务警报》。  
> 本稿承接第一话 v0.4、第一章完整台本 v0.1、剧情设定与主线可读版、角色声音 Bible 和第一话角色深度小传。  
> 目标是把前两话从“结构正确”推进到“玩家能玩进去、舍不得、并且理解七海为什么可怕”。

## 0. 本轮优化总判断

第一、第二话的旧骨架成立，不需要推翻。

需要优化的是三件事：

1. **第一话的可逛感要更像博物馆，而不是教程走廊**  
   玩家必须在战斗前亲手看过展岛、留言、旧机器、模型、废案和0号侧廊门口。火灾和清算发生时，玩家失去的是刚刚开始熟悉的一整座馆。

2. **第二话的压迫要来自“合法清单”，不是反派威胁**  
   七海不需要大声。她只要把玩家刚喜欢上的东西逐项念成“待处理资产”，玩家就会自然想挡在前面。

3. **玩法目标要在剧情中成立**  
   保护留言墙、转移孩子、阻止0号侧廊开启、挡封存框体、触发燃魂，都不是教程按钮，而是角色在火警、封存和恐惧中不得不做的事。

### 0.1 C01内容预算锁定

本稿按 [多玩法内容预算与数据架构约束](../2026-06-22-chao-gag-hybrid-content-budget-data-architecture.md) 收束。  
第一、第二话只允许一张内容图：

```text
喜欢万机馆 -> 发现清算压力 -> 保护留言墙/展品 -> 黑展柜轻触
```

机器可读节点见 `data/story/chapter_01_content_nodes.tsv`。台本新增或改动事件时，必须先看该表是否已有节点；没有节点的内容优先改成演出、调查文案或删掉。

| 类型 | C01锁定内容 | 台本用法 |
| --- | --- | --- |
| 线索 | 留言墙、右臂旧件、防火/封存记录、七海清单、0号侧廊敲门 | 只服务玩家理解当下目标和黑展柜轻触 |
| 可带回物/证据 | 维修件、旧纸条、封存清单截片、防火记录残片 | 不跨章滚雪球，第一章内回收或结算 |
| 战斗修正 | 留言墙耐久、右臂援护、防火减伤 | 改变保护战起手条件，不解决保护战本身 |
| 核心变量 | `museum_warmth`、`enterprise_pressure`、`black_case_resonance` | 每次小玩法最多输出2个变量变化 |
| 标记 | `exhibit_seen_set`、`old_note_state`、`first_soul_burn` | 用于条件台词、动态清单和教程，不当长期变量 |
| 长期轻触 | 黑展柜、企业清算账本 | 只轻触，不解释真相，不开新阵营 |

本稿不再把展岛喜爱、现实机器预热、模型病院预热和旧守护者好感全部当长期剧情变量。它们在前两话里只作为 `source_nodes`、`unlocked_flags` 或战斗状态存在；后续章节若要正式使用，必须在对应章节内容预算里重新登记。

### 0.2 对白重写口径：先像人话，再像角色

第一话对白不追求每句都漂亮，也不追求每句都有梗。人说话要有语气、助词、停顿和听众；角色特征从顺嘴、犹豫、补一句、做一件小动作里出来，而不是从一句被设计好的俏皮话里出来。

写对白时按以下顺序检查：

1. 先读顺。句子要像嘴里说出来的，不像写在设定表里的。适当保留“啊、吧、嘛、你看、那就、先别”等口语连接。
2. 动作只写有结果的动作。比如“低头看了一眼杯子”可以，因为它改变纪存的判断；“若有所思”不写，因为它替角色总结。
3. 人类角色少用拟人化机智句。唐胶可以嘴损，但先说模型、断口、水口、补土；纪存可以吐槽，但先处理记录、展签和现场。
4. 机器角色可以怪一点，强调逻辑、数字和分类；孩子可以跳一点，先像孩子在对某个人说话，不承担设定说明。
5. 同一场内不要每个人都在输出信息。有人接话，有人没听懂，有人补一句，有人只做事。

## 1. 第一话《今日闭馆后》

类型：船内探索 / 开场日常 / 悬念建立。  
目标时长：25 到 35 分钟。  
战斗：无。结尾只预告第二话保护战。  
本话唯一优先目标：**让玩家喜欢万机馆，还没逛够。**

### 1.1 本话体验曲线

| 段落 | 玩家感受 | 作用 |
| --- | --- | --- |
| 火灾后30秒 | 这里发生过很糟的事 | 先给损失感，不解释真相 |
| 前厅闭馆 | 这馆有点旧，但很会照顾人 | 建立纪存、旧守护者、小满、阿澄 |
| 主展厅展岛 | 这里不只有馆守Z，还有很多没来得及看的东西 | 建立“可逛可失去” |
| 档案室 | 馆长缺席不对劲 | 建立馆长、纪存职业习惯、0号侧廊禁令 |
| 留言墙 | 观众也在这座馆里留下灵魂 | 建立玩家亲手保护的对象 |
| 馆守Z主展 | 旧守护者不是萌AI，是旧规则在照顾人 | 建立18米机体尺度和第0次闭馆谜题 |
| 维修角 | 破损不是瑕疵，是有人摸过的历史 | 建立兜灯、唐胶、右臂残响 |
| 0号侧廊 | 谜团轻轻敲一下，不抢情绪主线 | 建立空白展柜 |
| 闭馆熄灯 | 玩家刚熟悉的角落被依次关灯 | 为第二话清算清单蓄力 |

### 1.2 开场：火灾后30秒

```text
[黑屏]
[音效] 洒水喷头。远处火警。塑料受热后的细小爆裂声。

旧守护者[广播断续]：
闭馆流程未完成。
观众仍在馆内。
重复，观众仍在馆内。

[画面亮起]
水流把彩色留言纸冲到排水沟边。
半张纸还贴在墙上，能看见：
“机器人摔倒了……还能……”

[镜头抬高]
馆守Z巨大的手掌挡在留言墙前。
掌心烧黑，指缝里夹着一张写着“最强!!!”的贴纸角。

系统字幕：
火灾记录：未归档。
距离第一次警报：00:30。

馆长录音：
纪存，如果你听见这段，先确认观众。
别先查我去哪了。你会把救人写成调查步骤。

[短暂噪声]
未知声音[极轻]：
今天……也要闭馆吗？

[切黑]
字幕：三小时前。

[标题]
第一话 今日闭馆后
```

优化点：冷开场只给“损失”和“声音”，不解释 G.A.G.、机魂、清算部。馆长录音像熟人，不像预告片。

### 1.3 前厅：取得控制

地图：万机馆前厅，普通探索格。  
教程：移动、调查、对话、闭馆清单。  
关键角色：纪存、旧守护者、小满、阿澄。

本段必须交代：小满和阿澄不是主角队友。闭馆后仍有未成年人滞留，纪存作为临时闭馆负责人要把他们带回前厅黄线内等待接走；小满想先贴回从留言墙掉下来的“最强!!!”贴纸、取回送修的社勇王，阿澄想收完留言并告诉纪存馆长杯子的异常。

```text
[前厅]
闭馆广播播到第三遍，纪念章台里卡着半张票根。
旧守护者的1.2米导览机从售票口旁滑出来，左轮轻轻蹭着黄线。

旧守护者：
万机馆今日闭馆。
请各位观众带好随身物品、纪念章、未完成的作业，
以及不方便交给大人的愿望。
（胸牌灯闪了一下，旧守护者停住，像在确认“愿望”能不能算遗失物。）

游客甲：
这个广播每天都这么说？

纪存：
今天少了“雨伞”。
（纪存伸手把卡住的票根抽出来，票根撕下一小角。）
馆长说老把雨伞放第一位，听起来像我们馆专门丢伞。

旧守护者：
本机未学习。
本机只是将遗失物扩大分类。
雨伞仍位于第六项。

旧守护者：
补充提示。
馆内仍有未成年人二名。
请临时闭馆负责人确认照看。

小满从留言墙方向冲出来，手里攥着一张掉下来的“最强!!!”贴纸。

旧守护者：
小满未奔跑。
小满正在以奔跑速度否认奔跑。

小满：
我没有跑，我是在让鞋先过去！
（他说完才发现左脚还踩在黄线外，赶紧把脚拖回来。）

纪存：
鞋和人一起回来。闭馆了。
贴纸也贴回去。少一个角，阿澄明天会看出来。

小满：
那我先贴，再去拿社勇王？

纪存：
对。
贴好，拿模型，回前厅黄线里。
不是跟着我逛一圈。

小满：
我本来就是这么计划的。
只是顺序还没排好。

阿澄从导览地图旁探头，手里捏着一张折到发白的地图。

阿澄：
纪存哥，馆长今天还没回来。
（她没有进前厅中间，只站在地图架旁边，把地图边缘抚平。）

纪存看向档案室方向，先看表，再看闭馆清单，又把撕坏的票根夹进记录板。

纪存：
他杯子还在吗？

阿澄：
还在。水槽边。
馆长要出远门会洗杯子。上次没洗，是他忘带钥匙。
留言墙也还剩两张没收，我收完就回前厅。

旧守护者：
馆长不在。茶杯未清洗。
该组合不常见。

纪存：
我去看一眼。
小满，把贴纸放回去，拿完社勇王就回来。
阿澄，你只到档案室门口，别进去。

小满：
那我能不能顺路看一眼合体台？

旧守护者：
顺路定义不包含绕路。

纪存：
看路线。
不看心情。
```

可调查物：

| 物件 | 调查文案 |
| --- | --- |
| 万机馆招牌 | 旧世界机器人文化博物馆。新贴纸写着：今日主展，馆守Z修复展。贴纸边缘有点翘，像临时撑了太久。 |
| 纪念章台 | 馆守Z胸牌图案被盖到纸快破。坏掉的章印是“勇气已受理”，旁边小字写“审批结果以现场为准”。 |
| 导览地图 | 主展厅标出八个展岛：馆守Z主展、合体剖面台、勇气审批角、现实机器小舞台、模型病院、旧影像厅、废案柜、留言墙。 |
| 纪念品柜 | 便宜贴纸、旧录像带、拼装钳、馆守Z钥匙扣。最里面还有一盒“不要卖，馆长说以后有用”的断色贴纸。 |

### 1.4 主展厅展岛速览

触发：前厅关键调查后，旧守护者给出闭馆护送路线。  
目标：让玩家觉得万机馆不是单机体展厅，而是一堆被人摸过、修过、争过、贴过标签的旧东西。注意：这不是纪存带孩子自由逛展，而是沿“留言墙 -> 模型病院 -> 前厅黄线”的闭馆路线顺路经过部分展岛。阿澄主要留在留言墙收纸条，小满只在取社勇王和被拦住时出现。

```text
[玩家进入主展厅入口]
中央是18米级馆守Z半跪展示，灯未全开，只能看见胸牌、巨脚和右臂维护架。
两侧展岛没有排得很整齐，像馆长每次想到什么就顺手多摆一张桌。
二楼天桥挂着旧海报、坏掉的灯箱和孩子贴的“最强榜”。

旧守护者：
闭馆护送路线生成。
留言墙，模型病院，前厅黄线。

小满：
合体台呢？

纪存：
不在路线里。

旧守护者：
合体台位于模型病院前方三点二米。
若不触碰按钮，可判定为顺路经过。

纪存：
你别替他钻空子。

小满：
我还什么都没说。
```

玩家可以任选 3 到 6 个展岛调查。看过的展岛会在第二话被七海列入封存清单，制造“我刚看过”的刺痛感。

```text

状态：演示暂停。
暂停原因：二号机卡扣松动。

小满：
我不按。

旧守护者：
请勿触碰按钮周边区域。

小满：
空气也不行？

旧守护者：
按钮周边区域包含空气。
请将手指后撤三厘米。

[按钮咔哒]

旧守护者：
检测到按钮被触碰。
演示继续暂停。

系统：
二号机卡在合体轨道中段。
一号机继续播放胜利音效。

纪存：
别再按了啊。
二号机卡扣有点久了，硬掰不行。
（他说着伸手松了一下卡扣，卡在半路的二号机慢慢滑回轨道。）

小满：
那我刚才算不算帮它热身？

不算。

```

```text

唐胶：

阿澄：

我没有这个权限。
```

优化点：七海第一次被孩子刺到，不是因为她心软倒戈，而是因为制度真的没有回答孩子问题的字段。

### 2.5 战斗准备

地图：前厅到留言墙的小型战术地图，6x8 或 8x8。  
目标不是歼灭，而是挡住流程。

主要目标：

| 目标 | 说明 |
| --- | --- |
| 保护留言墙6回合 | 留言墙耐久归零失败 |
| 小满、阿澄撤到档案室门口 | 任一孩子被困在封存路径中失败 |
| 阻止0号侧廊被开启 | 开启臂完成2回合开锁失败 |

次要目标：

| 目标 | 结算口径 |
| --- | --- |
| 封存标记少于3个展岛 | `variable_delta:museum_warmth+1`；`source_nodes:C01_FLAG_EXHIBIT_SEEN_SET` |
| 现实机器小舞台未被扫描 | `unlocked_flags:real_machine_stage_preserved`；第3章若使用，需在C03预算重新登记 |
| 模型病院未被装箱 | `unlocked_flags:model_hospital_preserved`；第2章若使用，需在C02预算重新登记 |
| 旧纸条成功保留 | `variable_delta:black_case_resonance+1`；`source_nodes:C01_ITEM_OLD_NOTE` |

1-1闭馆探索和右臂微修复输出示例：

| 字段 | A001 闭馆巡查/极简开馆结算 | A003 右臂旧件微修复 |
| --- | --- | --- |
| `score_band` | `clear/good/perfect` | `fail/clear/good` |

| `battle_modifiers` | `message_wall_hp:+20%`、`fire_suppression:minor` | `right_arm_support:once` |

我方单位：

| 单位 | 定位 | 技能 |
| --- | --- | --- |
| 纪存 | 指挥 / 归档 | 归档保护：让一个目标免受一次删除；临时封门：生成1回合障碍 |

### 2.6 回合事件

#### 第1回合：跑不跑

```text
旧守护者：
请勿奔跑。
但可以跟紧本机。

小满：
你这句听起来像可以跑。

旧守护者：
本机未批准跑。
本机批准跟紧。

纪存：
小满，跟紧旧守护者。
阿澄，别回头数纸条。

阿澄：
我不数会少。

纪存：
那先数人。
```

教程：移动、挡路、孩子撤离。

#### 第2回合：火和封存同时推进

```text
东侧烟雾扩大，二楼天桥变成不可通行。

兜灯：
东侧天桥不能走了。
胸牌下面也别站。

唐胶：
你每次都说胸牌会掉灰。

兜灯：
这次会掉灯。

七海：
火势已纳入封存顺序。

纪存：
火势不用你纳入，它自己会走。
```

教程：地形危险、灭火器启动、封存标记。

#### 第3回合：0号开启臂

```text
0号侧廊门口出现开启臂。
白色机械臂没有武器，只带授权针和封存锁。

七海：
0号侧廊优先移交。

纪存：
那里有火。

七海：
那里有更高风险。

纪存：
你看见里面是什么了？

七海：
我看见过风险摘要。

旧守护者：
建议忽略0号侧廊。

纪存：
现在不是忽略的时候。
```

教程：阻止开锁目标。开启臂需要连续2回合开锁，玩家可以击退、眩晕或临时封门。

#### 第4回合：未归档旧纸条

若第一话 `unfiled_old_note=true`：

```text
系统：
未归档项目清理。
旧纸条：
“如果我明天又忘了这句话，请告诉我我来过。”
状态：未申诉。
处理：删除镜像。

纪存：
阿澄，你刚才看见那张纸了，对吧？

阿澄：
看见了。
只剩一个“存”字。

纪存：
好。
你记得就行。

阿澄：
我怕我记错。

纪存：
那我也记。

旧守护者：
两名观众记忆不构成正式备份。

唐胶：
那就三名。
我也看见了。
别写我名字，写了也不好看。
```

若旧纸条已归档，则触发替代事件：

```text
系统：
异常留言已归档。
删除镜像失败。

七海：
谁给这张纸加了异常标签？

纪存：
我。

七海：
你知道异常标签会提高风险等级。

纪存：
也会提高被看见的概率。
```

#### 第5回合：第一次燃魂

触发条件：留言墙耐久低于50%，或小满/阿澄被封存框体逼近。

```text
系统：
共鸣异常。
指令：燃魂。

纪存：
这是什么新按钮？

旧守护者：
不属于闭馆流程。

唐胶：
那就更像馆长写的。

兜灯：
能不能用？

纪存看向留言墙。
几张纸条边缘亮起微弱的光。

纪存：
不知道。
先别让它灭。
```

燃魂效果：

- 选择一个目标：留言墙、孩子、0号锁、旧纸条、展岛。
- 该目标获得一次“不会被删除/封存”的保护。
- UI 不显示“伤害免疫”，显示“本回合仍被记得”。

使用后追加一句：

```text
七海：
未授权机魂处理。

纪存：
那你晚点再给我开罚单。
```

#### 第6回合：胸牌亮起

```text
火势逼近主展厅中央。
封存框体被暂时挡下，但旧守护者导览机轮子卡住，还在往前顶。

旧守护者：
导览外设行动能力下降。
主展厅紧急闭馆权限请求。

兜灯抬头，看见馆守Z胸牌亮起。

兜灯：
不行。
现在不行。

旧守护者：
观众仍在馆内。

兜灯：
我知道！
我就是知道才说不行！

馆守Z胸牌第二次亮起。
右臂维护架发出金属疲劳声。

纪存：
兜灯。

兜灯：
别叫我。
你一叫，我就要同意。

纪存：
那我不叫。
你看留言墙。

兜灯看过去。
小满和阿澄已经撤到档案室门口，但阿澄还在回头看。
留言墙被烟熏黑，仍有几张纸亮着。

兜灯低声：
胸牌供电先开一档。
掌心挡板开半寸。
脚踝锁不动。
旧守护者，听见没？

旧守护者：
请求已过期。
本机正在闭馆。
```

### 2.8 失败与分支处理

| 情况 | 处理 |
| --- | --- |
| 留言墙耐久归零 | 不直接 Game Over，进入“封存失败教学”短回滚：旧守护者提示本流程不可接受，回到第5回合前 |
| 孩子被困 | 直接失败回滚，因为本话主题不能允许玩家把孩子当代价 |
| 0号侧廊被开启 | 进入失败演出：黑展柜低频冲击，全员短暂失神，回滚到第3回合前 |
| 封存展岛过多 | 主线继续，但1-4临时开馆标题减少，后续第2/3章对应台词更冷 |
| 未使用燃魂 | 主线继续，但第二话闭馆记录显示“机魂处理倾向未定”，第1章结算不出现燃魂说明 |

## 5. 这一版相对旧稿的具体优化

1. 第一话主展厅的展岛不再只是设定罗列，每个展岛都给一段可直接落事件脚本的短互动。
2. 留言墙的三条留言都绑定后续变量：现实机魂、空白展柜、纪存身份。
3. 七海的压迫从“反派气场”改成“清单、权限、顺序、流程”。
4. 第二话清单动态回收玩家第一话看过的展岛，使玩家自然产生“别碰我刚看过的东西”。
5. 保护战的每回合事件与教程绑定：移动、地形、开锁、归档、燃魂、馆守Z接管。
6. 燃魂第一次出现不作为热血大招，而是“保护一个名字不被删除”。
7. 战后不急着胜利结算，而是让旧守护者导览机停下，顺滑推到第三话馆守Z启动。

## 6. v0.2全文排查修正记录

本轮按万机馆空间锚点、角色声音规则和用户反馈，对全文做了一次硬伤排查，先修会造成后续资产、剧情和事件脚本误读的问题。

| 问题 | 修正 |
| --- | --- |
