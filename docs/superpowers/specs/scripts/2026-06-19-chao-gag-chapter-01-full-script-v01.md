# 《超GAG机器人大战：万机残响》第1章《火灾后的开馆》完整台本与演出包 v0.1

> 本文用于一次性 review 第1章所有话的剧情、演出、交互与战斗承接。  
> 覆盖话数：1-1《今日闭馆后》、1-2《法务警报》、1-3《展厅里的旧守护者》、1-4《流亡展舰》。  
> 口径来源：商业蓝图、剧情扩写、场景矩阵、第一话 v0.4、角色深度小传。

## 0. 第1章总目标

第1章不是“主角拿到第一台机体”，而是“玩家先喜欢上一座机器人文化博物馆，再眼睁睁看它被清算和火灾撕开，最后把它变成流亡展舰”。

四话情绪曲线：

| 话 | 玩家情绪 | 戏剧动作 |
| --- | --- | --- |
| 1-1 今日闭馆后 | 这地方好像很好逛 | 火灾前夜闭馆巡游，认识万机馆展岛群 |
| 1-2 法务警报 | 别动我刚看过的东西 | 七海正式登场，保护留言墙和孩子 |
| 1-3 展厅里的旧守护者 | 这台旧机器真的站起来了 | 馆守Z半启动，第一次正式战棋 |
| 1-4 流亡展舰 | 没赢，但不能关馆 | 救人与救展品取舍，万机馆起航 |

第1章结束时，玩家应明确三件事：

1. 万机馆不是军队，也不只是基地，而是一座会被人爱上的机器人文化避难所。
2. 清算部不是普通恶役，它用合法、礼貌和流程把热爱的东西写成“待处理资产”。
3. 旧守护者和馆守Z不是主角机爽点，而是第一位“机器人也在守家”的同伴。

## 2. 1-1《今日闭馆后》

类型：船内探索。  
时长目标：25到35分钟。  
核心功能：让玩家喜欢万机馆，学会探索、调查、留言回复和档案归类。  
战斗：无。结尾只预告1-2保护战。

### 2.1 开场：火灾后30秒

演出：

- 黑屏先有洒水喷头声。
- 画面低角度扫过被水冲开的留言纸。
- 馆守Z巨掌挡在留言墙前，掌心有烧痕。
- 旧守护者广播断续，不播热血台词，只重复“观众仍在馆内”。

```text
[黑屏]
[音效] 洒水喷头。远处火警。塑料烧焦后细小爆裂声。

旧守护者[广播断续]：
闭馆流程未完成。
观众仍在馆内。
重复，观众仍在馆内。

[画面亮起]
水流把彩色留言纸冲到排水沟边。
半张纸还贴在墙上，能看见：
“机器人摔倒了……还能……”

[镜头抬高]
馆守Z巨大的手掌挡在留言墙前。

系统字幕：
火灾记录：未归档。
距离第一次警报：00:30。

馆长录音：
纪存，别把这段转文字。
你一转文字，就会装没听懂。

[切黑]
字幕：三小时前。

[标题]
第一话 今日闭馆后
```

| --- | --- |

### 2.5 留言墙：三条留言

留言一：

```text
如果一台机器人老是摔倒，它还能不能放进展览？
我觉得它努力站起来的时候，很像真的机器人。
```

回复选项：

| 选项 | 纪存回复 |
| --- | --- |
| 温柔 | 可以。展签上不用只写成功动作。你要是记得它摔了几次，也写上。 |
| 档案员 | 可以。摔倒次数、扶它的人、地板材质，都算记录。 |
| 吐槽 | 可以。我们馆的自动门每天失败三次，目前仍然厚着脸皮营业。 |

留言二：

```text
0号侧廊为什么总锁着？
我昨天听见里面有人敲玻璃。
```

回复后旧守护者插话：

```text
旧守护者：
建议忽略0号侧廊。

纪存：
建议来源？

旧守护者：
记录缺失。
```

留言三：

```text
如果我明天又忘了这句话，请告诉我我来过。
署名被撕掉，只剩一个“存”字。
```

归档选项：普通留言 / 异常留言 / 暂不归档。  
如果暂不归档，1-1闭馆前给一次补救，1-2仍未归档则会被清算流程优先删除。

## 3. 1-2《法务警报》

类型：混合话。  
时长目标：25到35分钟。  
核心功能：七海正式登场；第一次保护目标教学；清算部把“热爱的角落”变成封存清单。  
战斗：6回合小规模保护战，偏人和小机器尺度。

### 3.1 开场：门关在里面

地图：前厅与主展厅入口，叠加6x8战术格。  
玩家单位：纪存、旧守护者导览机、兜灯、唐胶。  
非战斗保护目标：小满、阿澄、留言墙、0号侧廊门锁、灭火控制箱。

```text
[接1-1结尾]

旧守护者，开东侧门。

以及，东侧消防通道的外部锁，我延迟了四十秒。

纪存：
为什么？

七海：
因为那里有人。

纪存：
报告里怎么写？

七海停顿。

七海：
信号延迟。
```

`enterprise_pressure_seed` 高时，七海更冷；若1-2玩家尽量不伤害法务无人机，她会加一句：

```text
七海：
你们刚才没有击毁三号封存框体。
它里面不是武器，是灭火泡沫。
我记下了。
```

### 5.6 临时开馆

结尾不是庆祝胜利，而是灾后第一次开灯。

```text
[移动中的万机馆临时展厅]
留言墙被拆成几块，临时固定在机库墙上。
纸条少了很多。
有几张边缘发黑。

小满拿着一张新纸。

小满：
今天写什么？

阿澄：
不能写赢了。

小满：
那写没输？

唐胶：
听起来像考试差一分。

旧守护者：
建议标题：闭馆流程未完成。

兜灯：
不吉利。

陆衡：
诚实。

纪存看着临时展厅的灯。
```

玩家选择临时展览标题：

| 标题 | 语气 | 后续影响 |
| --- | --- | --- |
| 今天没有胜利，只有第一次开灯 | 温柔正统 | `museum_warmth+1` |
| 闭馆流程未完成 | 旧守护者线 | `old_guardian_trust+1` |
| 没扔掉的东西先放这里 | 唐胶/模型线 | `model_trust+1` |
| 观众仍在馆内 | 谜团/黑展柜线 | `black_case_resonance+1` |

选择后：

```text
纪存把标题贴上去。

旧守护者：
当前状态不符合开馆标准。

纪存：
临时开馆。

旧守护者：
临时开馆不在流程内。

小满：
那你加进去。

旧守护者沉默两秒。

旧守护者：
流程更新。
临时开馆。
低照度。
观众可停留。

馆守Z胸牌亮了一下，很弱。

[镜头外推]
破旧移动底盘载着半座博物馆驶出旧会展区。
身后火光还没有完全灭。

[第1章结束]
```
