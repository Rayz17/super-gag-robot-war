# 《超GAG机器人大战：万机残响》第一话 v0.4：让玩家喜欢上万机馆

> 本稿承接 v0.3 的可理解性重构，专门修正一个更关键的问题：  
> v0.3 能让玩家搞清楚万机馆，但还不足以让玩家喜欢万机馆。  
> 原因很简单：展馆太像一个小教程场，视觉和互动上过度依赖馆守Z撑场，无法让玩家觉得这里是“机器人粉丝的天堂”。

## 1. 新原则：馆守Z是主轴，不是全部

第一话的目标应该从：

> 玩家认识馆守Z、留言墙、维修角。

升级为：

> 玩家在15到25分钟里走过一座大型多层机器人文化馆的一段闭馆路线，知道这里远不止眼前这一圈展岛。火灾发生时，玩家不是失去一张背景图，而是失去一个刚刚开始喜欢、还没真正逛完的地方。

关键不是把第一话做成全馆自由探索，而是在有限路线里露出大馆尺度和展品密度。

第一话可操作区域仍然只开放前厅、主展厅、留言墙、维修角、档案室、0号侧廊门口，但主展厅从“馆守Z展区”改成“万机馆夜间主展厅”，里面至少有八个可见展岛：

| 展岛 | 玩家第一眼感受 | 剧情深度 | 资产压力 |
| --- | --- | --- | --- |
| 馆守Z主展 | 18米巨型守护机，第一视觉锚点 | 高，本章主轴 | 高 |
| 合体剖面台 | 三台小机悬在透明支架上，按钮坏了一半 | 低，后续合体谱系伏笔 | 中低 |
| 勇气审批角 | 勇者胸像旁挂满“合体申请未通过”章 | 低，喜剧和第8章企业审批伏笔 | 低 |
| 现实机器小舞台 | 小型双足机在充电桩旁，摔倒记录写满一板 | 中，第3章跌跌伏笔 | 中 |
| 模型病院 | 唐胶修旧模型，孩子排队等补件 | 中，第2章模型街伏笔 | 低 |
| 旧影像厅 | 循环播放剪坏的旧战斗录像和观众弹幕 | 低，SRW/玩家文化气质 | 低 |
| 废案柜 | 未完成机设、废稿、断掉的样件 | 中，第6章作者遗迹伏笔 | 低 |
| 留言墙 | 观众纸条和孩子涂鸦 | 高，1-2保护目标 | 中 |

这样玩家会觉得：馆守Z只是万机馆最大的一件展品，真正让人喜欢的是这座馆里到处都是“机器人文化曾经被人爱过”的痕迹。

## 2. 空间修正：主展厅不是小房间，是机器人文化夜市

v0.3 的主展厅约70米长、45米宽、24米高，这个尺度可以保留，但要改变描述方式。

玩家进入主展厅时，看见的不该只围绕馆守Z，而是：

1. 中央半跪的馆守Z，像一座旧神像，也像一个大型游乐设施。
2. 左侧低层展岛摆着模型病院，灯是暖的，唐胶坐在那里修东西。
3. 右侧有现实机器小舞台，白天用于展演，晚上只有一台小双足机还在充电。
4. 二楼环形天桥挂满旧海报、坏掉的立绘灯箱和孩子贴的“最强榜”。
5. 主展厅深处有旧影像厅，传来压得很低的老录像声音。
6. 0号侧廊不是唯一神秘点，它只是这座热闹展馆里唯一没有声音的地方。

第一话不是“一个展厅”，而是“一个浓缩版万机馆”。玩家不需要了解所有展岛，但必须看见它们存在。

## 3. 新增展岛设计

### 3.1 合体剖面台

投射功能：合体机器人文化、盖塔/战队/勇者式合体梗，但不在第一话展开。

展品外观：

- 三台约1.5米长的小型机体模型悬在透明支架上。
- 中央有一个“合体演示”按钮，但贴着维修条：“请勿连续按，第三次会卡住。”
- 透明剖面里能看到齿轮、磁锁和几根明显是后补的胶带。

互动：

```text
[调查：合体剖面台]

系统：
展品：三相盖流合体剖面模型。
状态：演示暂停。
暂停原因：二号机卡扣松动。

小满：
我按一下。

旧守护者：
请勿按。

小满：
我还没按。

旧守护者：
本机正在提醒未来。

纪存：
未来听了吗？

[按钮咔哒一声]

旧守护者：
未来未听。
```

玩家可以选择是否帮旧守护者复位按钮：

| 选项 | 效果 |
| --- | --- |
| 帮忙复位 | `museum_warmth+1`，旧守护者感谢但说法很机械 |
| 假装没看见 | 小满开心，旧守护者记录“未来继续未听” |

作用：让第一话出现第二种机器人形态，不抢主线，只制造“这馆里还有好多谱系”的感觉。

### 3.2 勇气审批角

投射功能：勇者机器人、企业审批、合体许可、第8章清算都市伏笔。

展品外观：

- 一个约3米高的金色勇者胸像，手持巨大的印章。
- 背后墙上贴满“合体申请表”“必杀技噪音评估”“公共道路变形许可”。
- 旁边有孩子盖章台，章文是“勇气已受理”。

互动：

```text
[调查：勇气审批角]

系统：
展品：勇气株式会社 旧式审批胸像。
说明：旧世界曾尝试把自主AI的合体行为纳入城市安全流程。

小满：
勇气还要申请？

纪存：
在这个馆里，飞拳发射口都有人投币。
勇气申请一下也合理。

旧守护者：
合体审批状态：未申请。

小满：
你怎么又未申请。

旧守护者：
本机勇气正在排队。
```

作用：让“机器人大战梗点”以展馆生活方式出现，不必让勇者角色正式登场。

### 3.3 现实机器小舞台

投射功能：现实机器人、跌跌、第3章“第10742次站立”情感核心前置。

展品外观：

- 一块小型演示地毯，边上放着软垫。
- 充电桩旁站着一台约70厘米高的小双足机，膝盖贴满补强胶。
- 白板写着：“今日演示：站立 27次，摔倒 26次。第27次被掌声打断。”

互动：

```text
[调查：现实机器小舞台]

阿澄：
它今天站起来了。
站了很短。

纪存：
多短？

阿澄：
旧守护者刚说“请勿鼓掌”，它就摔了。

旧守护者：
本机提示并非摔倒原因。

唐胶[远处]：
你那句提示比它腿还硬。

小满：
那它明天还演吗？

纪存看着白板，把“失败”两个字划掉，改成“第27次未完成”。

纪存：
演。
闭馆清单没写它退休。
```

作用：让第一话不仅有巨型超级系，也有现实小机器。玩家会更容易理解后续第3章为什么感动。

### 3.4 模型病院

投射功能：模型文化、唐胶、阿猫阿狗式生活感、第2章模型街前置。

展品外观：

- 一张长桌，摆着断角、断翼、旧关节、胶水、贴纸。
- 墙上写“模型病院：今日号已满。急诊请找唐胶，态度自理。”
- 孩子把断件放进小盒子，每个盒子贴名字。

互动：

```text
[调查：模型病院]

唐胶：
别碰那排。
左边是没干，右边是救不了，中间是本人觉得还能抢救。

纪存：
本人？

唐胶：
送修的小孩。
你以为我问模型？

小满：
我的社勇王手断了。

唐胶：
那不是断。
那叫你昨天让它连续挥拳一百三十次。

小满：
它很努力。

唐胶：
所以我在修。
```

作用：让唐胶不只是维修角吐槽役，而是玩家一眼能明白“这家伙嘴坏但手很软”。

### 3.5 旧影像厅

投射功能：玩家文化、弹幕、旧录像、机器人大战感。

展品外观：

- 一个小放映角，十几把不成套的椅子。
- 屏幕循环播放旧战斗录像，画面被火花、掉帧和弹幕遮住。
- 弹幕里有“这里应该响BGM”“飞拳来了”“别跳OP”等玩家式留言。

互动：

```text
[调查：旧影像厅]

旧录像：
第七回合，右臂返航失败。

画面卡住。
弹幕停在一行：
“这里我小时候看哭过。”

纪存：
这卷又卡在这里。

旧守护者：
建议更换磁带。

纪存：
馆长说不能换。
他说卡住的位置，也是这卷带的一部分。

旧守护者：
馆长维修观念不稳定。
```

作用：让玩家感到这座馆不只保存机体，也保存观看机体的人。

### 3.6 废案柜

投射功能：作者遗迹、废案角色、未完成也有生命。

展品外观：

- 一个半透明柜，里面有未完成机设、没上色的头部、断掉的武器样件。
- 展签写：“未采用方案。请勿嘲笑。”
- 柜角贴着孩子写的：“没采用也可以很帅。”

互动：

```text
[调查：废案柜]

阿澄：
这个为什么没有名字？

纪存：
因为它没做完。

阿澄：
没做完就不能有名字吗？

纪存沉默了一下。

唐胶：
先叫它“别扔”。

小满：
这个名字好弱。

唐胶：
比“垃圾桶二号”强。
```

作用：让第6章作者遗迹的核心问题提前变成一个孩子能问懂的小问题。

## 4. 新版第一话动线

v0.4 不把第一话变大，而是把动线改成“主线闭馆 + 自由展岛”。

| 阶段 | 必经 | 可选展岛 | 玩家情绪 |
| --- | --- | --- | --- |
| 前厅闭馆 | 招牌、纪念章台、导览地图 | 纪念品柜 | 这是正常博物馆 |
| 主展厅第一次进入 | 馆守Z远景 | 合体剖面台、勇气审批角、旧影像厅 | 这里好多机器人梗 |
| 留言墙 | 三条留言 | 最强榜、孩子涂鸦 | 这里有人来过 |
| 展馆生活段 | 馆守Z尺度调查 | 现实机器小舞台、模型病院、废案柜 | 这里每个角落都有人在乎 |
| 维修角 | 右臂旧件选择 | 唐胶模型病院回访 | 旧东西不是摆设 |
| 0号侧廊 | 敲玻璃 | 无 | 这座馆也藏着危险 |
| 闭馆确认 | 低照度照明 | 回看展岛灯逐个熄灭 | 我刚认识它，它就要出事了 |

关键变化：玩家不是按任务线直奔“留言墙 -> 馆守Z -> 右臂”，而是在主展厅中有三到四个可选展岛。闭馆清单仍然引导主线，但旧守护者会提示：

```text
旧守护者：
闭馆巡查允许顺路看展。
顺路定义：不超过七分钟。

小满：
那八分钟呢？

旧守护者：
馆长称之为热爱。
本机称之为加班。
```

## 5. 结尾情绪强化

v0.3 结尾只有“留言墙灯还亮着”。v0.4 要让玩家看到整座馆熄灯。

闭馆确认时，镜头按玩家刚刚可能互动过的展岛依次切：

1. 合体剖面台的透明支架灯熄灭，卡住的二号机轻轻晃一下。
2. 勇气审批角最后一个“勇气已受理”章盖在空白纸上。
3. 现实机器小舞台的小双足机进入充电，白板上“第27次未完成”还没擦。
4. 模型病院的胶水灯熄灭，唐胶把小满的断手模型塞进“明早先修”盒。
5. 旧影像厅卡住的弹幕停在“这里我小时候看哭过”。
6. 废案柜的灯灭前，那个“别扔”标签亮了一秒。
7. 最后才是留言墙低照度灯。

然后法务系统接管，火警响起。

这样第二话保护战的目标不只是一面墙，而是玩家刚刚见过的一整座小世界。

## 6. 资产控制

这次扩容不应该爆制作量。推荐规格：

| 内容 | 第一版资产做法 |
| --- | --- |
| 合体剖面台 | 静态展台图 + 一个按钮抖动动画 |
| 勇气审批角 | 胸像静态图 + 印章图标 |
| 现实机器小舞台 | 小双足机静态Sprite + 充电灯闪烁 |
| 模型病院 | 桌面背景 + 断件小图标 |
| 旧影像厅 | 小屏幕循环2到3帧噪声 |
| 废案柜 | 半透明柜 + 剪影图 |
| 闭馆熄灯 | 同一地图做灯光遮罩，不额外做新场景 |

大资源仍然只给馆守Z、留言墙和右臂。其他展岛承担“密度”和“预告”，不是主线资产黑洞。

## 7. v0.4 推荐口径

第一话现在应该这样描述：

> 火灾前夜，玩家以纪存身份在固定博物馆万机馆执行闭馆巡查。第一话不是战斗关，而是一场可自由顺路看展的夜间闭馆探索：玩家会看见18米级馆守Z、合体剖面台、勇气审批角、现实机器小舞台、模型病院、旧影像厅、废案柜、留言墙和0号侧廊。馆守Z是第一章主轴，但万机馆不只围绕馆守Z；它是一座把超级系、真实机器、模型、旧录像、废案和孩子留言混在一起的机器人文化避难所。结尾整座馆熄灯，法务警报和火警同时响起，第二话进入保护战。

这才更接近“机器人粉丝的高潮大作”的开场：不是先解释宇宙终局，而是先让玩家觉得“靠，这地方我还没逛完，别烧啊”。
