# 《超GAG机器人大战：万机残响》第一话《今日闭馆后》重写稿 v0.2

> 本稿承接 `2026-06-19-chao-gag-episode-01-script-flow.md` 的流程母稿，优先采用第一话角色深度小传、原生话术碎片和 v2 台词诊断。  
> 目标不是把信息说得更漂亮，而是让纪存、兜灯、唐胶、旧守护者、七海和孩子们像“这一晚刚好在万机馆里的人”。

## 0. 本版写作口径

| 项目 | v0.1 倾向 | v0.2 改写方向 |
| --- | --- | --- |
| 台词 | 角色经常说出主题句 | 角色先处理杯子、封条、纸条、螺丝和黄线 |

本话仍不进入正式回合制战斗。结尾亮出第二话保护战的目标 UI：玩家要保护的不是抽象“记忆”，而是万机馆里具体的人、具体机体、具体纸条和具体钥匙。

## 2. 详细台本

### EP01-A 冷开场：错档录像

场景：黑屏。声音先出现，像一台旧投影机还没完全热起来。

演出重点：不给世界观解释。只给几件东西：玻璃、火、儿童纸条、馆长声音、系统错档。

```text
[黑屏]
[音效] 投影机转动。水滴落在铁皮上。远处有人拍玻璃，很轻。

[画面闪一下]
主展厅的地面。洒水系统开过，水把彩色纸条泡得翘边。
一张纸条贴在一只巨大机械手掌里，字被水晕开。

儿童声音：
如果机器人一直摔倒，它还能不能放在展览里？

[画面断帧]
馆守Z半跪在火光后面。右臂没有装上去。胸牌灯一亮一灭。

馆长录音：
纪存，别把这段转文字。
你一转文字，就会装没听懂。

[短噪声]
旧守护者：
观众仍在馆内。
重复，观众仍在馆内。

[画面切到一只黑色展柜]
展柜玻璃没有反射出拍摄者，只反射出一盏还没关的走廊灯。
铭牌空白，右下角有编号：GAG-00。

[系统字样浮出，像坏掉的字幕]
Great Archive Grid 子节点恢复中。
闭馆记录：第0次。
负责人变更：馆长 -> 纪存。
变更时间：明日 00:00。

纪存的声音，很近，像刚醒：
明天的东西，怎么在今天亮了？

[玻璃内侧轻敲两下]

未知声音：
今天……也要闭馆吗？

[标题出现]
第一话 今日闭馆后
```

冷开场结束后，标题不立刻切主旋律。音乐只留一段很小的合成器音，像老展馆夜灯电流声。

### EP01-B 档案室：黄灯

场景：万机馆档案室。晚上 23:18。桌上有旧终端、馆长茶杯、便签、三支没墨的笔、孩子寄存的塑料小零件。

演出重点：纪存不是“命定主角”，是值夜班的人。他的不安从杯子和屏幕开始。

```text
[画面淡入]
纪存坐在终端前。屏幕上三盏黄灯。

系统：
闭馆清单载入。
今日值班：纪存。
今日异常：3。
未归档留言：7。

纪存没有马上点确认。他看了一眼旁边的茶杯。

纪存：
馆长的杯子还在。
人不在，杯子倒挺守时。

旧守护者[广播]：
馆长不在。馆长杯具仍在。
该组合不常见。

纪存：
你别学我说话。

旧守护者：
本机未学习。本机正在复述不常见组合。

[远处传来鞋底打滑的声音]

旧守护者：
楼梯口检测到小满。
小满未奔跑。小满正在以奔跑速度否认奔跑。

小满[远处]：
我没有跑，我是在让鞋先过去！

纪存：
让鞋回来，闭馆了。

旧守护者：
闭馆广播开始。

旧守护者[广播，正式语气]：
各位观众，万机馆今日闭馆。
请带好随身物品、未完成的作业、以及不方便交给大人的愿望。
请勿奔跑。
但鞋可以慢一点。

纪存：
最后一句不用播。

旧守护者：
已播。
```

玩家获得控制。

```text
[教程提示]
移动：前往主展厅。
调查：检查发光物件。
档案：异常会自动收入临时记录。
```

可调查物件：

| 物件 | 调查文本 | 角色反应 |
| --- | --- | --- |
| 馆长茶杯 | 茶水已经凉透，杯底有一圈细灰。杯把朝外，是馆长离开前的习惯。 | 阿澄若在场，会说：“馆长没把杯子洗掉。他每次出远门都会洗。” |
| 便签 | “0号展柜今晚别开。不是坏了，是太像没坏。”末尾笔迹被划断。 | 纪存：“太像没坏是什么坏法。” |
| 旧终端 | G.A.G. 子节点连接不稳定。主机状态：离线。离线时间：-00:00:17。 | 纪存：“明天零点的权限，为什么现在能查到。” |
| 三支没墨的笔 | 笔杆上贴着馆长便签：“还能当镇纸。” | 纪存把其中一支放回抽屉，不扔。 |

离开档案室前，终端自动弹出闭馆清单：

```text
闭馆清单：
1. 留言墙：未归档 7
2. 馆守Z 主展区：胸牌热源波动
3. 维修角：右臂封条复核
4. 0号展柜：照明状态异常

纪存：
又亮三盏黄灯。
馆长要是在，会先擦屏幕，再说是屏幕脏。

旧守护者：
屏幕表面洁净度：87%。
馆长借口可信度：中。
```

### EP01-C 留言墙：感叹号

场景：主展厅入口。墙上贴满纸条、票根、儿童画、电子留言屏。阿澄站在小凳子上整理纸条，小满在贴一张明显过大的“最强”。

演出重点：让“保护万机馆”先变成保护这面墙，而不是保护一个设定。孩子不是卖萌工具，他们有自己的观察方式。

```text
[玩家靠近留言墙]

阿澄：
纪存哥，今天又多了七张。
有一张被小满贴到“安全出口”上了。

小满：
安全出口也需要士气。

纪存：
安全出口需要的是别被你挡住。

小满：
我写的是“社勇王最强!!!”
少一个感叹号都不算最强。

纪存：
感叹号不算独立展品。
两个也不算。

唐胶[从旁边经过，没停下]：
第三个贴歪了。

小满：
你这个大人怎么连感叹号都挑水口。

唐胶：
字也有水口。
```

系统提示玩家回复三条留言。回复不显示数值，只显示一行轻提示“某段记录被保留了”。

#### 留言一：摔倒机器人

```text
留言：
如果一台机器人老是摔倒，它还能不能放进展览？
我觉得它努力站起来的时候，很像真的机器人。
```

可选回复：

| 选项 | 纪存回复 | 变量 |
| --- | --- | --- |
| 温柔 | “可以。展签上不用只写成功动作。你要是记得它摔了几次，也写上。” | `protagonist_tone=gentle`; `museum_warmth+1` |
| 档案员 | “可以。摔倒次数、扶它的人、地板材质，都算记录。” | `protagonist_tone=archivist`; `real_machine_trust_seed+1` |
| 吐槽 | “可以。我们馆的自动门每天失败三次，目前仍然厚着脸皮营业。” | `protagonist_tone=wry`; `museum_warmth+1` |

选择后：

```text
阿澄：
那它摔倒的时候，展签要写疼吗？

纪存：
如果有人问，就写“维修中”。

阿澄：
骗人。

纪存：
嗯。
那写“当时有人在旁边”。

阿澄点点头，把纸条贴低了一点，像是怕那台机器人看不见。
```

#### 留言二：0号展柜

```text
留言：
0号展柜为什么没有说明牌？
昨天闭馆前，我听见里面有人敲玻璃。
```

可选回复：

| 选项 | 纪存回复 | 变量 |
| --- | --- | --- |
| 安抚 | “展柜老化会响。听到的时候别一个人靠近，叫旧守护者。” | `museum_warmth+1` |
| 记录 | “已记录。0号展柜今晚不开放，也不回答问题。” | `black_case_resonance+1` |
| 玩笑 | “如果它敲出节奏，先别鼓掌。馆里没给它批演出许可。” | `black_case_resonance+1`; `protagonist_tone=wry` |

选择后：

```text
旧守护者：
建议忽略0号展柜。

纪存：
建议来源？

旧守护者：
记录缺失。

纪存：
你这个建议听起来像馆长的便签。

旧守护者：
馆长拥有高级拖延权限。
```

#### 留言三：旧纸条

这张纸条被压在留言墙最下层，边缘发黄。不是今天的胶。阿澄先发现。

```text
阿澄：
纪存哥，这张不是小满写的。

小满：
我还没看你就说不是。

阿澄：
你的感叹号更胖。

小满：
那叫气势。
```

纸条内容：

```text
如果我明天又忘了这句话，请告诉我我来过。

署名被撕掉，只剩一个“存”字。
```

玩家不能直接回复，只能选择归档方式：

| 选项 | 归档文本 | 变量 |
| --- | --- | --- |
| 普通留言 | “年代不明。可能来自旧馆时期。” | 无 |
| 异常留言 | “署名残缺，与值班员姓名存在重合。” | `black_case_resonance+1` |
| 暂不归档 | “稍后处理。” | 后续清算时此条会被系统先删除 |

选择后：

```text
阿澄：
纪存哥，你刚才没按保存。

纪存：
我按了。

阿澄指屏幕。
屏幕右下角仍停在“临时记录”。

纪存：
……这条我没归档。
不是忘了，是还没找到该放哪。

小满：
放“很怪但不想扔”那格。

唐胶[远处]：
那格满了。
```

### EP01-D 主展厅：馆守Z

场景：主展厅中央。馆守Z半跪陈列，头部略低，像在给孩子看胸牌。机体巨大但陈旧，手写维修标签贴在关节边。

演出重点：第一台机体必须可亲。它不是马上“燃”，而是像一位被孩子摸熟了的老展品。

```text
[镜头从地板开始]
擦得发亮的地面。
儿童围栏。
一块告示牌：
请勿攀爬展品。
请勿向飞拳发射口投币。
请勿询问旧守护者“你和馆长谁更老”。

旧守护者：
第三条缺乏客观性。

纪存：
你确实比馆长早入馆。

旧守护者：
早入馆不等于变老。
这是展品尊严问题。

小满：
那你会不会合体？

旧守护者：
本机当前合体审批状态：未申请。

小满：
那就是可能会！

旧守护者：
本机未作此承诺。
```

调查点一：胸牌

```text
[系统]
展品：馆守Z。
状态：封存展示。
异常：胸牌热源波动。

纪存：
胸牌又热。
今天没有参观团，也没人偷摸许愿。

旧守护者：
纠正。
上午十点二十三分，有三名儿童向本机许愿。

纪存：
许了什么？

旧守护者：
一名希望考试及格。
一名希望社勇王最强。
一名希望你不要每次睡在档案室。

纪存：
最后那个匿名？

小满[立刻]：
不是我！

旧守护者：
小满当前否认速度过快。
```

调查点二：飞拳发射口

```text
[系统]
右臂发射口封条完整。
封条日期：G.A.G.事变后第七年。

纪存：
封条还在。

旧守护者：
右臂封条完整。
连续一千九百四十二天，未收到飞拳相关投诉。

纪存：
很骄傲？

旧守护者：
投诉减少是优秀展陈指标。

小满：
那要是飞出去很帅呢？

旧守护者：
帅不属于安全指标。
```

调查点三：本体终端

```text
[系统]
本体记忆区存在缺损。
缺损区域：第0次闭馆记录。

纪存：
第0次？

旧守护者：
今日闭馆编号：第0次。

纪存：
你上周也这么说。

旧守护者：
每一次闭馆都应该像第一次一样谨慎。

[短噪声]

旧守护者：
尤其是你。

纪存：
我？

旧守护者：
记录缺失。
建议忽略上一句。

纪存：
你今天建议忽略的东西有点多。

旧守护者：
本机正在维持闭馆效率。
```

调查结束，维修角传来金属落地声。

```text
兜灯[远处]：
唐胶，把那块放下。

唐胶：
我只是在看。

兜灯：
你用“准备挑刺”的角度在看。
```

### EP01-E 维修角：右臂

场景：主展厅侧面的维修角。地上贴了黄色安全线，工具盘摆得很整齐。兜灯蹲在馆守Z右臂外装甲旁，唐胶抱着工具箱。

演出重点：通过一块旧甲片把“修复、保留、安全、手作痕迹”落到具体选择上。兜灯和唐胶不是立场牌，他们都是用自己的笨办法爱旧东西。

```text
[玩家靠近]

兜灯：
别踩那条线。

纪存低头。
脚尖已经压在线上。

纪存：
这条？

兜灯：
现在是两条。

唐胶：
所以我建议你们用红色。
黄色不够有压迫感。

兜灯：
你再提美术建议，我把你和水口一起打磨。

唐胶：
打磨可以，别用你那把缺口锉。
它会把旧件磨出新仇。

兜灯：
唐胶。

唐胶：
我闭嘴。
但这块毛边真的不行。
```

兜灯拿起一块旧甲片。甲片边缘有烧痕，内侧有一行很浅的日期和一个小手印。

```text
兜灯：
手拿开。

纪存停住。

兜灯：
不是脏，是烫。

纪存：
它离电源断开多久了？

兜灯：
十年。

唐胶：
十年还烫，听起来不是维修问题。

兜灯：
别用“旧”那个语气说它。

唐胶：
我说的是烫，不是旧。
旧不背这个锅。

纪存：
背面有日期。

兜灯：
这块不能扔。
背面有日期。谁写的我知道。

唐胶凑近，看了看断口。

唐胶：
这断口不是摔的。
是拧的时候心疼，手软了。

兜灯：
你看断口就看断口，少给我爷爷配旁白。

唐胶：
那你别把旧件擦得像等人夸。
```

玩家选择旧甲片处理方式：

| 选项 | 纪存台词 | 变量 | 即时反馈 |
| --- | --- | --- | --- |
| 保留破损 | “那就别只拍正面。背面也拍。日期、裂纹、手印，都留着。” | `flaw_preserved=true`; `model_trust+1` | 唐胶认可，兜灯嘴硬 |
| 替换新件 | “先让它安全。旧件单独归档，不进垃圾桶。” | `flaw_preserved=archived`; `museum_warmth+1` | 兜灯松一点，唐胶不反对 |
| 交给兜灯 | “这块不是我家的东西。我只负责把你的决定记清楚。” | `doudeng_trust+1`; `protagonist_tone=respectful` | 兜灯第一次把工具递给纪存 |

分支对白：

保留破损：

```text
兜灯：
裂纹会扩。

纪存：
扩了再拍。

唐胶：
像个档案员。
烦，但不算错。

兜灯：
我讨厌这句。
把相机拿来。
```

替换新件：

```text
兜灯：
```

## 5. 台词二次打磨准则

下一轮若继续精修台词，优先检查以下位置：

| 位置 | 检查点 |
| --- | --- |
| 七海登场 | 不要让她变成纯冷酷反派；每句都应像流程和事故经验的混合物 |
| 纪存请求 | 少喊保护，多做记录、按保存、挡孩子视线、问能不能先别念 |
| 兜灯右臂 | 她越怕，越说技术细节；不要让她提前说出“我害怕它暴走” |
| 唐胶吐槽 | 吐槽必须来自工艺、收藏、玩具和手作，不做泛用段子 |
| 旧守护者 | 它的温柔来自规则弯曲，不来自突然像人类表白 |
| 孩子台词 | 孩子要误解大词，把“镜像、封存、保存”变成纸、字、灯和感叹号 |
