# V35.8 Canon迁移与锁定报告 v1

Status: locked_candidate_baseline  
Date: 2026-07-13  
Scope: V35.8装载合同、V35.9 Pressure Board生产前置

## 1. 迁移原因

V35.8初版虽然覆盖95作者槽，但仍存在首见/首控混淆、集合机群无法解析、来源笛卡尔过绑定、条件支援被误算实际部署、资产数量虚高和场景预显影被强制要求完整战斗资产等问题。继续直接写V35.9会让Pressure Board在错误合同上越写越厚，因此先完成语义闭合并锁定输入层。

## 2. 已批准变更

1. 心墙、岛卫、潮墙相关机体由旧C07时序迁移到V357-C04身体来源分支；C09保留回收、换装和主体问题，不重复首登。
2. 白色样机、红面具机在V357-C06-S03以实体射击、换位、推舰完成正式`first_visible`；白色样机首控仍在C07，红面具首控仍在C08。
3. 方舟折叠探测器`V353U050`与C07红线广播采样器补入Canon实体表，Pressure Board不得再以无实体字符串临时造物。
