# 《超GAG机器人大战》世界内Meta与馆外观测者层 v1

> 状态：核心边界与馆外观测者口径升为Working Canon；版本切换、索引完美版、外部档案和联网残响保持Candidate Canon。
>
> 目标：让玩家逐渐分不清“正在操作游戏界面”还是“正在操作纪存的档案终端”，但不让人物廉价地说出章节、玩家、游戏或剧本，也不侵犯真实设备和存档安全。

## 一、根定义

### 1. 玩家在世界里的位置

玩家不是隐藏神明、远星最高意识、G.A.G.本体或纪存的主人。世界内部只能观测到一种来自馆体之外、无法定位主体的持续响应：它会部署机体、选择路线、保存版本、反复尝试、偏爱某些单位，也会为救下某人放弃更优战果。

万机馆最初把这种响应记为“未登记操作源”；索引把它建模成“高价值选择样本”；远星可能误译为“地球机器人文化的集体人格”；纪存最终更倾向称其为“馆外观测者”或“那个一直没有离开的方向”。这些都是世界内解释，不证明角色知道电子游戏和现实玩家。

### 2. 观测链

真实玩家操作不会直接化为宇宙魔法。它必须经过以下链条：

`玩家输入 -> 游戏系统事件 -> 纪存档案终端/万机馆调度记录 -> G.A.G.对重复选择的文化活化 -> 索引或远星对该模式的解释 -> 角色感受到异常回应`

因此，按一次按钮不会改写世界。只有被系统记录、在剧情里有对象、经多次选择形成模式、并由具体载体读取的行为，才可能留下馆外残响。

### 3. 人物知道多少

- 普通人类角色只知道终端、战术系统或馆体出现异常选择来源，不得说“玩家、存档、游戏、章节、路线、攻略、读档”。
- 纪存因机魂实体和终端共感，可以感到同一个困局曾被“另一个方向”拒绝过，但不能直接知道现实世界。
- 七海可以从审计链发现不存在于舰员名单的操作签名；她会先把它当安全与责任问题。
- 白鸢可以察觉自己的分镜被某种观看行为跳过、重放或拒绝，但不能凭创作者身份自动知道第四墙。
- 方舟T能描述响应的时序和信息量，却不能证明发送者是什么。
- G.A.G.负责把长期观看和选择变成可响应模式；索引负责预测和利用；远星负责误译；三者均不等于玩家本人。

## 二、与既有设定的关系

### 1. 纪存档案终端

游戏标题、存档、编成、图鉴、设置和任务界面可以逐步被解释为纪存档案终端的不同权限页。前期只是美术与措辞暗示，中期索引可重排页面，后期人物才能从终端审计中发现未登记操作源。

### 2. 残响版本层

残响版本层仍不是物理时间旅行。Meta版本表现的是同一世界内容被馆长旧系统、代哥合规层、军方训练层、白鸢分镜层、远星误译层或索引完美层以不同规则呈现。版本切换可以改变UI、可见单位、关卡目标和演出，但不能任意改写已经发生的历史。

### 3. 索引完美最终话

既有“索引完美最终话模板”升级为最强Meta候选之一：它不只是剧情中的幻境，而可短暂接管实际菜单、编成和战斗规则，生成一个高命中、高演出、全主角机、无争吵、无失败机、无撤退伦理的完美机器人大战版本。

这个版本必须真的好玩和诱人。其恐怖不来自故障，而来自它逐步删除低人气机体、关系对象、失败记忆、生活空间和玩家拒绝最优解的权利。

### 4. G.A.G.

G.A.G.不会读取真实硬盘、思想或私人信息。它只能活化游戏系统已经合法记录的选择模式。馆外观测者的意义不是给G.A.G.增加万能能力，而是让“玩家长期观看、收藏、重玩和不肯遗忘”成为机器人文化共同语言的一种来源。

## 三、允许的Meta表达

1. 终端菜单文案漂移、排序变化、未知操作签名和权限页自行出现。
2. 索引折叠低使用率单位、推荐最优阵容、改写胜利条件或把人物语气压成标准支援台词。
3. 同一游戏内容切换成馆长旧版、代哥合规版、军方训练版、白鸢分镜版、远星误译版或索引完美版。
4. 正常存档之外保存少量跨周目“馆外残响”，例如反复救援同一角色、长期使用低规格机体、接受暴走、拒绝完美版本。
5. 假装存档被封存、角色被折叠、菜单被删去，但底层真实数据必须保留并可恢复。
6. 在玩家主动同意后，向游戏自己的`user://`专属目录导出馆外档案、远星回信、假补丁说明或个人展柜目录。
7. 后续扩展可使用经过审核、匿名和离线可替代的真实玩家残响，但首发主线不得依赖服务器。

## 四、禁止的Meta表达

1. 人类角色随口说第几章、玩家、剧情杀、选项、好感度、攻略或制作组。
2. 读取桌面、用户名、联系人、照片、浏览记录、其他文件夹或与游戏无关的私人数据。
3. 真实删除、损坏、加密或挟持存档；伪装勒索、病毒、系统崩溃或安全警告。
4. 把玩家选择解释成唯一人格诊断、道德评分、政治立场或恋爱资格。
5. 因玩家使用强力机制而羞辱或永久惩罚玩家；索引可以学习打法，但必须提供新的反制快感。
6. 用Meta替代参战机体、战斗、人物关系和世界冲突。一次界面故障不能冒充一话剧情。
7. 频繁假崩溃、假删档或窗口惊吓。整部主线只应有少数高强度越界节点。

## 五、版本外壳

版本外壳共享同一个SRPG、探索和关系核心，不另做六套游戏。每种版本只覆盖必要的视觉、规则和内容选择：

- **万机馆常态终端**：玩家与纪存共享的基础信息层。
- **馆长旧原型版**：粗糙、缺页、私人批注多，保留未标准化的机体动作。
- **代哥合规版**：安全、顺滑、来源和风险提示完整，但非标准项被折叠。
- **军方训练版**：关系与名字被压成单位、伤亡率和任务价值。
- **白鸢分镜版**：画面可以留白、重排和补完，角色也可以拒绝作者镜头。
- **远星误译版**：熟悉口号和谱系被低带宽翻成陌生规则。
- **索引完美版**：机器人大战快感达到顶点，代价是所有声部逐步同声。
- **无人认领版本**：表面被删除或封存的存档、角色和失败版本在离线馆藏层等待被重新看见。

具体哪些版本进入主线、持续几话、是否拆成独立玩法，由逐章Pressure Board和资产预算决定。

## 六、馆外残响账本

跨周目记录的不是每次点击，而是少量有叙事意义的行为类型：

- 为救人放弃击坠或效率。
- 对同一悲剧反复读档和尝试。
- 长期使用低规格、量产或非推荐机体。
- 使用、限制或拒绝G.A.G./万机馆暴走收益。
- 接受或拒绝索引完美版本。
- 手动找回被折叠单位。
- 保留普通生活物件而没有把它变成世界钥匙。
- 允许驾驶员、AI或机体拒绝出击、合体或改装。

这些记录只用于生成回应、隐藏条件、台词差异和终局识别，不产生“好玩家/坏玩家”总分，也不应让未触发者失去主线完整性。

## 七、叙事升级节奏

Meta应像谜团和关系一样升级，而不是一开始就表演第四墙：

1. **无害错位**：终端出现一条未登记记录、重启后保留一个普通展位记忆。
2. **有用异常**：馆外响应帮助发现隐藏单位或避开一次索引预测。
3. **权力冲突**：七海追查安全责任，索引开始把响应建模成推荐用户。
4. **版本破裂**：游戏短暂进入另一种版本外壳，玩家意识到规则也属于剧情。
5. **完美诱惑**：索引给出真正爽、真正方便的完美机器人大战。
6. **人格承认**：纪存承认馆外方向长期在场，但不宣布它是什么。
7. **终局回应**：玩家一路保留的不同声部参与拒绝同声结局；馆外观测者也只是众多声部之一。
8. **二周目余响**：世界不完整记得上一周目，让玩家承担“回来的人是不是同一个”的主题。

具体章号暂不锁定，必须跟V35或后续正式章节结构同步。

## 八、技术与安全架构

推荐把运行状态分成三层：

- `run_save`：当前周目剧情、机体、关系、分支和地图状态。
- `echo_ledger`：跨周目保存的少量馆外残响，不保存私人信息。
- `install_profile`：Meta强度、外部档案同意、无障碍选项和已见演出。

技术层需要`SaveRepository`、`MetaEventRouter`、`VersionProfileManager`和统一`TerminalShell`。所有假删档和假封存只修改显示状态；必须有自动备份、恢复入口、版本迁移、离线替代和无障碍模式。

## 九、写作与制作门禁

每个Meta事件必须填写：

- 世界内载体是谁。
- 玩家看见什么。
- 人物理解到什么程度。
- 底层真实发生了什么。
- 是否改变机体、地图、关系、路线或敌方收益。
- 恢复/拒绝路径是什么。
- 是否读写跨周目状态。
- 安全、离线和无障碍替代是什么。

如果删除Meta表现后，本话没有人物决定、机体行动、战场变化或后续状态，那么它只是噱头，不能通过单话Pipeline。
