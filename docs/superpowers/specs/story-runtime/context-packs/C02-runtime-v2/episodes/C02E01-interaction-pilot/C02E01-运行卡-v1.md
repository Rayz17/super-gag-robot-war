# C02E01《大船停在模型街外》运行卡

- 前因：万机馆离开旧址后只有短程航行能力，必须取得全尺寸主循环转子并建立第一个外部泊位。
- 唯一主要目标：安全进入木桶街旧港，并谈成一条不会让街区停工的转子置换路线。
- 中段转向：转子不是仓库里的闲置奖品，它正在维持木桶街的全尺寸仓与公共设施。
- 独立高潮：馆守Z、火种货柜领袖与无牌一号用三种不同能力把万机馆固定进旧港。
- 结束状态：泊位安全、置换提案成立但尚未兑现、无牌一号完成首次可控、四台重涂机苏醒。
