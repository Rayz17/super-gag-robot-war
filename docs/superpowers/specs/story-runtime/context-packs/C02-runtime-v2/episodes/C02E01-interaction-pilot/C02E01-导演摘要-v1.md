# C02E01 导演摘要

这份摘要只测试交互级 Runtime，不提升为正式 Reader 或 C02 剧情权威。

## 本话发动机

万机馆必须在木桶街旧港停稳，并找到不让街区停工也能取得全尺寸主循环转子的现实办法。唐胶必须重新走进自己离开的维修生态，纪存则第一次在陌生城市把机体、街区和团队组织成一场共同解决问题的行动。

## 玩家经历

1. 从木桶街街面看百余米巡展舰越过屋顶，先建立规模和陌生人的反应。
2. 进入港区泊位战。玩家不是微调厘米误差，而是打开卡死的大门、阻止舰体撞向废吊塔，并让三台不同尺度机体完成一眼能懂的协作。
3. 战后步行进入维修街和全尺寸仓，看见主转子正在给街区设施供能，理解它不能被直接拿走。
4. 唐胶利用旧人脉和维修经验提出置换路线，兜灯明确模型经验与全尺寸工程的边界。
5. 玩家首次操纵全尺寸竞赛实机无牌一号完成外部模块教学；四台重涂飞行机在仓内以不同动作苏醒，发动下一场。

## 视觉和制作边界

- 泊位、长街、全尺寸仓是三个普通而可复用的空间，不新增廊、槽、架、根、锚式专名。
- 主要大动作只有三个：万机馆压入旧港、货柜领袖作业变形撑开泊位门、馆守Z巡展臂放下巨型系泊锚。
- 主转子是重型工业总成，必须依靠运输、吊装和全尺寸安装；缩尺模型不放大。
- 七海只通过私人通信提供一次独立生态判断，不能远程授权木桶街。
- 白鸢肉身不在本话；她的作品若出现，只能作为可被人讨论和修改的预演资料。

## 关系与情绪

- 纪存不替唐胶解释旧事，但置换谈判不能绕开唐胶本人。
- 唐胶和兜灯在模型经验与全尺寸安全上发生真实分歧，并通过行动互补。
- 七海与纪存保留旧私交的温度，但本场不把没吃完的饭写成关系总结。
- 本话可以完整赢得泊位，不在结算时把胜利翻译成新的惩罚。
