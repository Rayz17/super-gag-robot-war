# C02 作家上下文胶囊 v1

## 使用方式

写作者只需常驻读取：

1. `01-C01期末清晰状态.md`
2. 本胶囊
3. 当前正在写的单话卡与上一话成稿

`02-04`三份原始检索包只用于查证，不作为整包提示词。遇到人物权限、机体状态、根机制或素材来源疑问时，按本胶囊列出的节点键和素材键回查。这样既保留全量证据，又不让作家被十几万字节的后台资料淹没。

## 权威分层

### 已锁定

- C01 已发生事实，以`01-C01期末清晰状态.md`为准。
- L1/L2 的体验承诺、世界总发动机和常识重力。
- Current Canon 中的人物身份、机体状态、万机馆物理边界、机魂机制、模型/实机关联和白鸢当前能力边界。

### 本章必须实现，但场面仍可重构

- 木桶街拥有停产全尺寸主循环部件、旧式泊位与全尺寸物流能力。
- 唐胶必须面对自己参与模糊维修史的过去，并采取会改变今后做法的行动。
- 重涂机证明同模具不等于同一主体。
- 旧拳王必须以完整机器人机体参加机械擂台，并成为本章明确、长期可用的战力奖励。
- 白鸢肉身到场，当前只会把纸面创作、现场信息和模拟器整理成可讨论预案；她不能画稿改现实。
- 万机馆拿到主循环部件后仍需去工务城做全尺寸校正。

### 可选创作材料

- 各场战斗的具体对手、空间、胜负方式与先后顺序。
- 四台重涂机是临时友军、当地盟友还是其中个别可操作。
- 无牌一号在本章承担首控、改装教学或只作为完整实机样板。
- 白色采样机本章露面到什么程度。
- 真实母亲接续儿子模型零件事业的故事放在哪个日常场，以及采用直接致敬还是明确来源的合成角色。

### 禁止使用

- 当前 C02 Reader、Episode、导演板、战斗预案、审稿问题和现成场面顺序。
- 后期白鸢未来视、反事实共感、画稿改现实、战斗指挥权。
- 七海登舰、贴身接口检查、后期三角关系、牺牲路线。
- C03 以后机体、关系和城市结果。
- 用 C02 Current Canon 中出现的旧 Episode 编号决定出场先后。

## 一句话故事

刚把博物馆开上天空的纪存一行来到唐胶不愿回去的木桶街，发现维持万机馆航行的巨型转子正被一套把修补史、重涂人格和失败战绩都包装成商品溢价的生态控制；他们必须在真正的机器人追逐与机械擂台中赢下部件，也要让这条街第一次把“修过、改过、输过”当成价值公开给人看。

## 章级人物欲望

### 纪存

- 表层目标：拿到主循环部件、让万机馆停稳、证明自己不是只会把馆开离原城。
- 私人欲望：第一次在外地让别人愿意走进万机馆，而不是把它当事故载体或旧时代废物。
- 魅力动作：他要主动识别木桶街真正的权力关系、把不同机体组织成漂亮胜局，并作出一次不是“批准/记录”的公开承诺。
- 风险：他很容易替机体解释“你真正是谁”。本章应让他学会问对方想怎样被介绍，但不能把全部英雄性缩成让权。
- 神秘感：他对旧巡展路线、某些机体动作或馆藏关系有超出普通人的直觉；表现为及时认路、认出缺失动作或听见不属于通信频道的回应，不解释其机魂真相。

### 唐胶

- 表层目标：利用旧人脉取得部件，又不想承认自己曾参与这套生态。
- 过去：他替摔坏、改坏或缺件的收藏物修出第二次生命，也曾用模糊认证帮助它们进入正规寄售；有人因此渡过难关，平台也借此把手修史抛掉，冒充“近似原装”卖出更高价格。
- 不能写成：站出来念一篇公开道歉，发个维修页便结清。
- 应有动作：在真正会失去部件、名声或旧关系的场面里，他选择公开可复做的方法和修补痕迹；别人因此不再只能依赖他，也有人因此来质问他。
- 人味：回木桶街后他会认摊主、躲债主、嫌旧工房更乱、下意识替别人摸关节松紧；嘴上嫌弃，手比任何人都快。

### 兜灯

- 目标：让馆守Z和万机馆活着离开木桶街，不允许“机器人动画气氛”掩盖明确风险。
- 不只是刹车人：她应在擂台或巨件运输中创造一种别人想不到但一眼能看懂的安全打法。
- 与唐胶：两人是长期维修间火花线。争执应来自材料、习惯和对机器的具体照顾，关键时刻动作默契先于告白。

### 旧守护者 / 馆守Z

- 旧守护者是馆守Z机魂，不是轮式终端里的独立 AI。
- 它对模型和玩具有导览知识，但不会因为看见锚件就换魂、升级或认亲。
- 馆守Z仍缺右战斗前臂。黄色巡展臂只能抓、锚、牵引和固定。
- 本章亮点应利用残缺形成独特战法，例如以巡展臂固定巨件、封住擂台边界或抓住变形机的脱离轨迹，再由左拳完成决定性动作；不能无损补回右拳。

### 七海 / 佐伯七海

- 她仍在原城接受调查，只能远程出现。
- 她与纪存已有私交和一顿没吃成的饭，但本章不把饭写成反复结算的“债”。
- 她可以从代哥生态内部提供一条事实、风险判断或对手背景，不能遥控解决木桶街的地方冲突，也不能代表军方、平台和城市同意。
- 她与纪存的关系动作应有生活温度：例如纪存让她看木桶街吃什么、她发现他仍没正经吃饭，或两人都装作只是谈工作。不能让白鸢凭空知道这顿饭。

### 白鸢 / Evelyn Voss / White Kite

- 英国成年创作者，White Kite 是英文署名，白鸢是中文意译笔名。
- 她因作品被盗用而主动追到木桶街，不是等纪存发现后才被邀请。
- 当前能力链：纸面分镜/设计 -> 合法数字化 -> 现场传感与地形数据 -> 战术模拟器生成若干候选路线 -> 驾驶员、机体、维修者修改或拒绝 -> 现实执行。
- 她没有战斗指令权、未来视、造物能力或画稿改现实能力。
- 入场气质：观察锋利、嘴不饶人、有作者控制欲，也能画成人向擦边同人；本章只需让玩家看见一点成年、好笑、略带色气的反差，不急于兑现恋爱。
- 与纪存：初见应有互相误读和吸引的种子。她觉得他未经许可使用了作品；他觉得作品已经救过人，仍必须把使用经过告诉作者。两人都不应立即占据道德高位。

## 机体与参战包

### 万机馆巡展舰体

- 百米级低速移动基地，不是人形机器人。
- 当前只有有限近防炮和旧航行系统。
- 本章所需的`主循环磁流散热转子`是数米级以上的重型工业总成，必须用全尺寸运输架、吊装设备和万机馆检修窗处理。
- 转子不是人格机体，不计参战数；安装只恢复有限航行，不解决校正、永久泊位和保险。
- 不描写密集内部机构，不用十几个新空间解释安装。

### 火种变形者组

- **货柜领袖**：已有全尺寸载具身体和独立人格，可进入作业变形形态。主要作用是地面护送、挡路、牵引和领袖号召；它不是星火车队、火种源或 G.A.G.。
- **喷气叛星**：高速空战、诱饵分身、品牌背叛路线；内在投射 Starscream 式叛星与大量重涂角色。它可以反对领袖，又在关键时刻保护同族。
- **死锁式重涂机**：近战突入，旧人格与“被改成更好卖的英雄版”冲突；正式名称可在稿中继续原创化。
- **镜像重涂机**：电子干扰、敌我标识翻转。镜像配色不能自动等于邪恶。
- **雷翎式远射重涂机**：远射、侦察、机动换位，承担重涂军团中不靠近战和领袖关系的独立动作。
- 四台重涂机必须有不同头部/翼型/武器/习惯，不能只靠颜色区分。
- 同一工厂动作库可以相似，但各自在本地 AI、身体磨损、维修史、关系和选择中形成不同主体。

### 商品回收王牌“归一星”

- 实体敌机，不是算法弹窗、胶价主持人的投影、索引人格或 G.A.G.病毒。
- 它可使用商品回收设施，并复制已经取得的工厂动作库；它复制不了四台机在后来生活里形成的判断。
- 视觉冲突应清楚：它用同一套“标准开场”压制四机，四机用不同结尾打破它。
- 它的操作者、授权来源和物理中止方式必须在场面里能看见。

### 旧拳王与影子陪练机

- 旧拳王是完整、可驾驶/可操作的拳击机器人，右拳护具只是锚件和规则钥匙。
- 旧拳王必须靠步法、挨打、判断和自己的最后一拳赢得魅力，不能全靠一张维修单催泪。
- 影子陪练机能够复制训练动作和反击窗口；它可作为对手或临时支援，但不是旧拳王的幽灵。
- 作品精神来自《铁甲钢拳》式失败者、父子/师徒修复和机器人身体尊严，不复刻原电影关键亲子场面。

### 全装冠军“百刃”

- 完整的拳斗/竞技实机，是旧拳王在擂台上的强敌。
- 过量尖刺、背包、武器包带来真实正面战力，也造成一眼可懂的转身、场地和重心问题。
- 不能只把它当“复杂设计都是错的”的笑话靶；它的驾驶员/机体应真正喜欢全装形态，并打得漂亮。

### 玩家模型机“无牌一号”

- 木桶街已有的全尺寸模块竞赛底盘和低权限竞赛 AI。
- 缩尺模型只提供结构对照、改件同构数据和个人偏好，不会放大成实机。
- 可承担改装教学和本章首控，但不应抢走旧拳王的正式加入奖励。

## 五条稳定机制

### 1. 模型/玩具到实机

正确链条是：

`缩尺物与私人记忆 -> 识别形态/关系/动作偏好 -> 模型师判断手修痕与装配逻辑 -> 工程链转译材料、承力、控制和安全 -> 已有或新造的全尺寸身体 -> 机体/驾驶员/机魂确认 -> 实战验证`

模型提供的是信息、关系和选择，不提供凭空长大的物质。

### 2. 机魂形成

机魂在具体机体的本地 AI 核、身体、实时黑匣或明确根节点中长期形成。身体经历、记忆连续、人机关系和 G.A.G.文化反馈会促进主体闭合，但命名、玩梗和修理不是造魂咒语。相同型号可以形成不同主体，也可能都没有机魂。

### 3. 唐胶与以后陆衡的分工

- 唐胶：识别手修痕、公差手感、旧材料、民间装配、收藏关系和量产图纸没记录的做法。
- 陆衡：把上述发现转译为全尺寸承力、材料、控制、安全和可复验工程。
- C02 只需要把唐胶的边界讲清，不提前让他包办全尺寸工程；因此新转子装上后仍要去工务城校正。

### 4. 白鸢预演

白鸢能提高“大家看见几种可能”的能力，不能替大家执行。任何有效路线都必须显示：

- 数据从哪里来；
- 谁把纸面方案送入模拟器；
- 谁能修改；
- 谁最后驾驶或操作；
- 现场变化后为何需要重算。

### 5. 平台、回收、白框与索引

- 木桶街商户/修件师：拥有实物、维修经验、地方关系。
- 平台：掌寄售页面、结算、流量和物流接口，不直接控制所有机体。
- 代哥售后/复产部门：掌部分商品资格、召回和复产条件，不等于整个平台。
- 胶价主持/拍卖前台：可控制价格屏、直播和拍卖节奏，不应一句话获得军队与机体控制权。
- 归一星：按取得的商品回收凭证执行实体回收，是可战斗、可中止的身体。
- 白色采样机：白框生态的采样前台，只证明有人系统收集样本；本章仍不揭示总指挥。
- 白框：企业、城市、军方和平台共同使用的采样、兼容、回收与标准身体生态，没有单一幕后主谋。
- 索引：本章至多留下“某些优化动作被无主缓存保存”的微弱影子，不直接出场下令。

## 木桶街空间模型

为避免临场增加名词，本章只使用五个可复用空间：

1. **巨构泊位**：旧巡展舰和全尺寸舞台机械使用的外港泊位，能让万机馆停靠但接口老旧。
2. **模型/修件街区**：面向普通收藏者的店铺、模型病院、寄件台和生活空间。
3. **全尺寸仓与物流坡道**：街区背后的实机拆件、竞赛底盘、重型运输和寄售仓。
4. **机械擂台**：木桶街公共竞技与拍卖活动共用的大型场地，可容纳 15-25 米级机器人。
5. **万机馆公共开放区**：本章结尾的第一次外地开馆，只开放一小段真实展区，不临时造新馆。

木桶街能同时处理模型与巨件的候选解释：它原本就是巡展、特摄舞台机械、工业机器人和玩具/模型供应链共同形成的旧港区；前店处理缩尺与收藏，后场处理同一谱系的全尺寸样件、竞赛底盘、舞台巨构和退役实机。这个解释属于本章 Candidate，写作后若成立再回流 Canon。

## 玩法与战斗语法

- **探索/生活**：走街、辨修补痕、分拣补件、找全尺寸货源、听店主和收藏者讲具体物件。
- **改装/竞赛教学**：用无牌一号把缩尺改件数据转为全尺寸模块选择，玩家看见“模型影响实机”的正确链条。
- **SRPG空地追逐**：货柜领袖和重涂机在全尺寸仓、坡道和泊位之间争夺身体与转子运输路线。
- **SRPG机械擂台**：旧拳王对百刃/影子陪练，规则是击倒、读秒、出界和护具损耗，不是杀敌。
- **大型章末战**：归一星把商品回收和重涂动作库转成实体压制，馆守Z、旧拳王、货柜领袖与重涂机各用不可替代动作破局。
- **开馆/经营**：玩家决定第一次外地开放展示什么、由谁讲述、哪些修补痕保留可见；选择要影响地方信任、临时支援或后续补给，不做行政填表。

## IP 与机甲文化吸收

### 变形生命

- 吸收：变形是身体语言、领袖与叛徒都可有自由意志、同模重涂能成为受欢迎角色、镜像配色不自动等于邪恶。
- 可识别记忆：领袖货柜、喷气叛星、重涂军团、死锁/漂移式改模、镜像宇宙。
- 可用梗：同一说明书被几台机分别划掉“官方配色”；“同一个模具，也可以有不同脾气”。
- “直到万众一心”只作内部锚；若直接短引，必须发生在角色真的理解“同心不等于同声”的场面，不能当随口口号。

### 机器人拳击

- 吸收：旧机逆袭、影子学习、失败录像、父子/师徒修复、机器人作为拳手而非工具。
- 名场面压力：观众都以为旧拳王会复制最漂亮的连招，它最终关闭提示，用长期挨打学来的朴素步法赢。
- 爽点：一台外形过时的老机，在全装冠军武器全开后仍然站起来；最后一拳必须由玩家操作或明确战术选择触发。

### 模型竞技

- 吸收：玩家审美、混搭改件、认真对战、模型知识通过工程成为实机能力。
- 禁止：缩尺模型巨大化、盒子参战、自由改装没有重量和安全后果。

### 模玩生态

- 共模既能省成本，也能意外形成谱系和人格争议。
- 灰色改件可能救机，也可能引入风险，不写成简单正邪。
- “未拆”与“手修”都是合理收藏选择；故事不能判未开封收藏者错误。
- 热爱有现实体积，展位有限、零件会老化、维修史会影响价格，也会保存人与物的关系。
- 过度配件既是槽点也是玩家审美，百刃必须先展示“全装真的很强”，再让其代价进入战斗。

## 情绪与关系素材

### 可使用

- **唐胶×兜灯**：在维修、装件或擂台整备里吵材料和安全，手上却自然完成互补动作。
- **纪存×七海**：一通不解决主冲突的远程私聊；饭、木桶街小吃或睡眠是生活话题，工作事实夹在其中。
- **纪存×白鸢**：授权争执、创作被挪用、对“救急使用”与“作者同意”的不同直觉；初次见面有身体距离和成年观察，但不过早亲密。
- **白鸢×七海**：本章最多通过纪存通信屏、署名或工作痕迹知道对方存在，不安排成熟默契或牺牲认同。

### 暂缓

- 七海贴身检查纪存后颈、白鸢主动要求纪存选择靠近、三人嫉妒修罗场、任何牺牲与复活语法。
- 检索到这些素材说明未来关系池存在，不代表 C02 已满足前置。

## 现实共鸣

可直接致敬“母亲在儿子离世后学习 3D 打印与模型零件处理，继续完成他留下的订单”这一公开故事。使用原则：

- 用未完成订单、备用关节、支撑、打孔和笨拙备注等具体物件表达。
- 她不是战斗单位、长期队友或万能理解者。
- 场面不狗血重演死亡，不把真实悲剧当开启部件仓的钥匙。
- 最适合作为唐胶旧工房线的对照：真正的修补史并不降低价值，它也可能是后来者学会理解某个人的方式。
- 正式公开前需要来源、署名、致敬方式和虚构化程度复核。

## 本章制作门槛

- 一眼可辨的新实机不少于：火种货柜领袖、四台重涂机、旧拳王、影子陪练、百刃、归一星；无牌一号可作为教学实机。
- 每台首次出现的机体必须有来源、尺寸级别、行动主体、当前目的和是否可操作。
- 不把全部机体塞进一场混战。先让玩家分别认识，再在章末组合回收。
- 主要场地五个以内，同一场地至少复用两次并改变意义。
- 一话原则上只让玩家理解一个关键机制。
- 大动作优先，工程细节只保留能改变决策的部分。
- 任何敌对行动必须先通过“为什么不能停下谈、切断远程、交给第三方、等确认或各拿一部分”的常识检验。
- 一场胜利应当让玩家真的高兴；后果可以存在，但不要每赢一次就立刻宣布玩家做错了。

## 写前仍需解决的开放问题

1. 本章究竟四话还是五话，由场面容量决定，不沿用旧 C02 Episode 标题。
2. 火种货柜领袖为何愿意帮助万机馆，它和四台重涂机是什么关系。
3. 唐胶旧关系由谁具体承载，不能只用“旧街所有人”。
4. 主循环转子当前归谁所有，为什么不能直接买或借。
5. 归一星取得实体回收资格的现实原因是什么，怎样被玩家合法或物理中止。
6. 旧拳王由谁操作，原主人是否仍在，影子陪练保存的失败录像属于谁。
7. 白鸢为何在此刻亲自抵达，她的作品怎样已被平台使用，又怎样不变成万能战术图。
8. 第一次外地开馆具体为了什么：筹到校正旅费、让地方机体获得公共身份、还是建立下一站护送承诺。必须是现实目标，不是主题仪式。
