# C02E01《大船停在模型街外》

## 一座馆从楼顶后面开过来

木桶街中午最忙的时候，先暗下来的不是天，是屋顶。

修件铺里的客人还在为一盒二手合体机器人少没少天线争论，玻璃柜上的阳光忽然被一片移动的阴影吞掉。有人端着焊笔追到门口，看见一座带着穹顶和长窗的建筑正从旧楼后方缓缓移过来。它飞得不高，速度也不快，外壳上还留着昨夜战斗的焦痕，远远看去却仍像整条街连同童年的橱窗一起浮上了天空。

“照片里可没说这么大。”

街口卖旧贴纸的老人仰着头说了一句。旁边的人提醒他，照片里也没有参照物。

万机馆从港外转入旧巡展水道。它比两侧仓楼高出大半，主展厅穹顶从屋顶之间滑过，低沉的航行声让货架上的小机器人一排排轻轻发颤。跌跌趴在前厅玻璃上数人群，数到一半，街上忽然有几十个人一起举起终端，它便从头再数。

纪存站在重新启用的航行台前。木桶街发来的泊位图已经铺在主屏上，旧水道的轮廓与万机馆残存的巡展资料重叠得出奇顺手。他几乎没怎么找，便指出了藏在两栋仓楼之间的入口。

唐胶看了他一眼。

“你以前来过？”

“没有。”

“那你怎么知道门在那边？”

纪存自己也停了一下。旧图上没有画门，可他看见那两栋楼的距离，脑中便先有了万机馆从中穿过的样子。

“猜的。”他说。

唐胶显然不信，却没有追问。泊位广播正在呼叫万机馆，女声隔着旧设备带着一点沙哑。

“舰首向东，别压西边那条轨。唐胶在不在？”

唐胶按掉了私人频道。

兜灯抬起眼睛：“她问第二遍了。”

“听见了。”

“那你回。”

“先把一百多米的东西停好。”

广播里的人像是知道他会装死，没再点名，只把泊位全景送上公共频道。

## 泊位战

木桶街的旧泊位够长，问题出在入口。

这里曾经接待巡展舰和大型舞台机械，后来港区改造，旧门外又加了一套较窄的现代固定架。几十年没人让百米级船体从中通过，左侧门架卡在半开位置，水道中央还堆着三组未完工的重型模块。

海风从外港推来，万机馆庞大的侧面像一面被风抓住的墙。它开始偏向西侧废弃吊塔。自动航行系统已经把剩余推力全压在反向侧喷口上，仍只能延缓接近。

木桶街的公共频道一下挤满了声音。

“旧门开不到底！”

“中间那三组是谁堆的？”

“先别查谁堆的，吊塔下面清人！”

唐胶终于抓过通讯器：“冯梅，把泊位上的无牌一号放出来。中间障碍让它推，别叫人上去。”

对面那道女声停了半秒。

“你还记得它能动。”

“我还记得你把重东西全往门口放。”

仓门升起，一台没有厂牌涂装的十五米级竞赛底盘迈进水道。它的外甲只上了灰色底漆，肩、背和小腿留着成排的模块接口，像一台尚未决定自己要成为什么的机器人。地方操作席把临时战术画面接给万机馆，三个障碍点随即出现在玩家面前。

更大的轰鸣从街区后方传来。

一直停在码头边的重型货柜车向前驶出。车头与货厢没有像表演片那样腾空翻转，而是在行进中分开承重；底盘下沉，货厢立起，两条粗壮机械臂从侧壁展开，撑住卡死的旧门。二十米级的机器人在水雾里站直身体，胸前仍保留着旧车头的轮廓。

它左肩比右肩高出一截，那里不是炮，而是一套用了很多年的系泊绞盘。两只脚踏进旧港轨道，锁足咬住钢轨。街上的工人都叫它“接力”。

“门撑不了太久。”接力的声音从公共频道传来，“进了这条水道，就是我们负责接。大船，别在外面看风景。”

“正在进去。”纪存回答。

他没有去抢万机馆的自动操纵，而是把三件事放进同一张图：无牌一号清开中央水道，货柜领袖把旧门推到极限，馆守Z固定舰首。

馆守Z已在舰首半跪下来。旧守护者从胸前扬声器里报出风向，黄色巡展臂越过右侧断口伸向泊位。兜灯没有要求它去够最远的固定柱，而是选了水道内侧一座粗大的旧锚墩。

“近的那根。”她说，“先把头拉正。”

“收到，改抓近墩。”旧守护者回答。

巡展臂抓住锚索，整条黄色机械臂在风里绷紧。馆守Z用左手压住舰首甲板，十八米的身体第一次不像拳手，而像一名把整艘船拴回航道的甲板工。

无牌一号只有基础牵引钩。水道里的三组障碍也不相同：一座实心基台堵着万机馆的直行线，一副空运输架正对摇晃的吊塔，最后那根高架模块挡住了馆守Z的第二条锚索。

玩家必须决定先清哪一处。代表路线没有把三件东西整齐搬走，而是先将空运输架横推到吊塔前，给可能倒下的巨物留出缓冲；随后拖开高架模块，让馆守Z放出第二道锚。实心基台来不及完全移走，无牌一号便把它转成与舰身平行，留出一条刚够万机馆通过的水道。

接力的左臂关节发出一声重响。

“现在。”它说。

纪存将安全水域、门宽和锚索方向同时送给自动航行系统。万机馆剩余推进器骤然抬高输出，百余米舰体沿着刚刚清出的水道向前滑去。穹顶擦过门架投下的影子，馆守Z收紧锚索，接力一步步向后退，让巨舰从自己两臂之间驶入港内。

废弃吊塔被尾流吹得晃了一下，没有倒。

万机馆最终停在两条旧栈桥之间。街上先静了片刻，随后掌声和喇叭声一同响起来。接力松开门架，活动了一下冒烟的左肩。

“比照片里重。”它说。

旧守护者从馆守Z胸前回道：“照片里也没有参照物。”

街口那位卖贴纸的老人听见广播，隔着半条街大笑起来。

## 唐胶走回木桶街

冯梅在泊位尽头等他们。

她是木桶街后场互保会当天的负责人，也负责旧拳王的环外操作。她穿着沾有油渍的深色工作服，头发已经白了不少，手里拿的不是欢迎牌，而是一张旧门架的损伤清单。唐胶刚从舷梯下来，她便把清单塞到他胸口。

“左边轴座本来还能撑半年。”她说，“你回一次街，先用掉三个月。”

唐胶低头看了一眼：“这也算我头上？”

“货柜替你撑的，万机馆是你带的。你要是不想算，我就去问那个姓纪的。”

纪存正好走到他们身后。

“算在万机馆这次停靠里。”他说，“能修的我们一起修，不能修的先别拿唐胶抵。”

冯梅打量他，又抬头看了一眼停在港里的万机馆。

“你就是新馆长？”

“闭馆负责人。”

“馆都开走了，还挺会挑称呼。”

她没有继续为难纪存，转身往街里走。唐胶站了两秒，还是跟上了。

木桶街没有给他留出一条体面的回归路线。

第一家修件铺的老板隔着柜台喊他旧外号；第二家店主把一条断掉的肩轴直接塞进他手里，问他既然回来了能不能顺便看一眼；第三家什么也没说，只把门口那张“唐胶认证”的褪色贴纸撕掉一半，又留了一半。

唐胶一路嘴都没停。

“我刚下船。”

“这个不是我的活。”

“你这断面都磨圆了才想起来找人？”

他说着已经把肩轴对着光转了两圈，指出里面还有一枚能救的旧销。兜灯在旁边看了一会儿，从他手里拿走零件。

“外观能补，承重先测。”

“我没说直接装。”

“你眼睛已经说了。”

“我的眼睛收费。”

“那先闭上。”

机器犬叼着那半张被撕下来的认证贴纸追上来。跌跌在寄件台旁摔进一箱泡棉，又从另一头顶着一只透明罩站起。旧守护者使用备用轮式终端跟在最后，对每一家店的老模型报出年份，几次被店主纠正版本，语气反而越来越高兴。

沿街已经有人追着纪存问万机馆什么时候开放。有人想看昨夜出战的馆守Z，也有人只想知道馆里的旧模型还能不能修。纪存没有当场卖票，只让跌跌把预约分成“参观”“修件”和“来帮忙”三类。半条街的人围着一台总会摔倒的小机器人报名字，临时开放的事就这样有了第一批真实客人。

纪存从街的前半段一直走到后场，才明白木桶街为什么能接住万机馆。

前店的工作台上摆着巴掌大的机器人关节，墙后却吊着能塞进整台货车的舞台机手臂；模型病院正在用一张旧设计图修复合体玩具的髋部，同一张图的放大版本挂在全尺寸仓入口，旁边标着巨型机械的起吊位置。有人靠替收藏者补一片小翼养活工房，也有人把同一批旧资料重新算成十几米机体能用的构件。

这不是一条把过去摆出来卖的街。

它只是一直没停过手。

## 木桶街的心肺

全尺寸仓最深处有一座横跨两层的观察桥。

冯梅带他们走上桥，什么也没解释，先推开隔音门。

低沉的转动声立刻压住了所有谈话。

一具十余米直径的环形转子正在桥下运转。它被装在厚重的旧式散热座里，外缘的补片颜色各不相同，每转过一圈，巨大的风道便分别向仓区、物流坡道和机械擂台送出热风。远处的吊车、升降台和拳台灯组都跟着它的节奏工作。

纪存看见转子的第一眼，胸口忽然发紧。

不是疼，也不像记忆。他只是清楚地知道，那道旧式环槽原本应该接在另一种更宽的舰体里；下一瞬，万机馆航行台上的一盏故障灯隔着数百米自动闪了一下。

纪存调出万机馆的自检记录。两边没有建立数据连接，那盏灯为什么会闪，他暂时查不到。

“它还在给整条后场散热。”纪存说。

“所以你们不能把它拖走。”冯梅回答，“至少不能现在拖。”

唐胶靠在观察窗前，看了很久。他认出几处补焊，也认出外缘配重不是原厂做法。

“同年代巡展系统。”他说，“接口谱系对得上。里面什么样，得停机拆检才知道。”

冯梅看着他：“总算没隔着玻璃就说能修。”

观察桥另一侧，机械擂台的入口屏正在循环播放本届旧机复演季。宣传片最后，一套银灰色标准散热机组在灯光下展开，字幕写着：

`维修级冠军奖励：获胜场地新机组一套，含现场安装`

冯梅把声音关掉。

“新东西塞不进你们那座馆。”她说，“能接我们这套旧系统。旧拳王要是把它赢回来，木桶街不停工，这只老环才有可能跟你们走。”

“还有条件。”唐胶说。

“你知道。”

冯梅从工作夹里抽出两份旧转子维修页。一份写着唐胶熟悉的细小笔记，另一份后来归档的版本只剩一句“按原结构恢复”。

“这只转子修过几次，换过什么，哪些尺寸只有你那套量具认得，你得重新写清楚。”她说，“不是写给我看。写到换个人也能照着做。”

唐胶没有接那两张纸。

“比赛赢的是新机组。”冯梅说，“你补的是这只老环拆下来以后怎么不把自己和万机馆一起烧了。少一件，它都走不了。”

“旧拳王的账呢？”

“等你看见它再算。”冯梅把维修页收回去，“我没打算拿转子的纸骗它上场。”

纪存看向擂台入口，又看向仍在工作的巨大转子。

“旧拳王还愿意上场吗？”

冯梅第一次没有立刻回答。

“你不先问它能不能赢？”

“能不能赢，等见了再算。”纪存说，“先问它还打不打。”

桥下的转子继续旋转。几秒以后，冯梅把两份维修页收回夹里。

“明天带你去见。”

## 从桌面到十五米

木桶街没有因为来了一座会飞的博物馆便停下当天的工作。

共享散热系统西侧的一组外部导流模块已经变形，不能停机更换。冯梅把这件事当成万机馆是否真能与后场合作的第一场测试，也让纪存看见他们以后要搬走的究竟是什么分量。

工作台上先摆出三件缩尺样件。对应的三套全尺寸候选模块早已放在仓内货架上；现场要做的是选出一套，再按今天的实际负载调整。

一件样件带宽大的牵引框，一件用双层支架压低晃动，另一件保留高位感应翼。每一件上都有反复装拆的磨痕，留下了过去几代维修者试过又改过的结构。

纪存没有先看最完整的那件。他拿起一件边缘贴着旧胶带的双层支架，问为什么只有它的下侧磨得发亮。

本地工务员说，旧风道在满载时会向左偏，工人每次都要在那一侧多加一根临时撑杆。图纸从来没改，样件却被大家摸出了习惯。

唐胶翻过模型，看了一眼里面手削过的卡口。

“当年先改了小样，后来大件照着补。谁做的没写。”

“那就先别猜人。”兜灯把全尺寸导流架的数据调出来，“知道它为什么多这一层就够了。”

她和本地工务员重新核对材料、重量与停机范围。全尺寸方案加宽了承力面，也舍弃了样件上纯粹为了好看的尖角。本地操作席保留随时停机的权力，只把模块选择与行进路线临时开放给万机馆；无牌一号的竞赛AI负责把指令变成动作。

无牌一号装上双层支架，踏进热风。它抬起旧导流板时，风道向左偏转的幅度突然超过图纸记录，支架外侧被压得贴向地面。

“停在原地。”兜灯说。

唐胶盯着样件下侧发亮的位置，又看向全尺寸风道背面一个被后补板遮住的开口。

“那边有个手动泄风口。”他说。

冯梅问：“记录呢？”

唐胶没有再说自己只是猜的。

“我开的。那年赶复演，图没补。”

兜灯让工务员先打开泄风口，再把双层支架的外撑面加宽。无牌一号重新起步，左偏的热流从背面释放，巨大的导流板这才平稳离开原位。

这一次没有人等它演出必杀技。

玩家让它避开扫过作业区的热流，把变形导流板整体抬离原位，再将调整后的新架推入。样件上的磨痕、唐胶迟来的口述、兜灯和工务员的安全修正，最后都落在无牌一号看得见的动作上。

无牌一号锁定新模块后，西侧风道重新张开。全尺寸仓的灯没有举行仪式，只是从远到近恢复正常。工人们继续搬货，像这才是一次维修应有的结尾。

冯梅站在桥边，朝纪存伸出手。两名互保会代表也从远程频道确认：新机组稳定接管以前，旧转子不会离开；条件完成以后，冯梅有权代表后场办理转交。

“泊位先给你们用。旧拳王赢，新机组接班，唐胶把真参数留下，旧转子归万机馆。转运和后面的校正，你们自己想办法。”

纪存没有立刻握手。

“船、运输和校正，我来答。”他说，“唐胶那一条，让他自己说。”

所有人都看向唐胶。

唐胶手里还捏着机器犬叼回来的半张旧认证贴。过了一会儿，他把贴纸翻到背面，看见自己多年前写下的材料缩写。

“明早开旧工房。”他说，“原始量值先全找出来。哪儿写错了，就在旁边改清楚。”

冯梅问：“能让别人照着复做？”

“先找齐。找不齐的，我当场补。”

纪存这才握住冯梅的手。

“万机馆在比赛次日上午有限开放，参观、维修预约和街区联票一起卖。收入先付吊装和运输；工务城校正不够的部分，我们带着订单去谈。”

冯梅扫了一眼街上仍围着跌跌登记的人。

“联票怎么分，晚上重算。”她说，“今天这些人，够你先订吊机。”

“那就先把今天停好。”

冯梅笑了一下。

从这一刻起，木桶街向万机馆开放了临时整备和补给。接力把第一批水、食物和外部修材拖到舰边，还在公共频道里留下一句：“港区里要挪大东西，叫我。”

## 没吃成的那顿饭

傍晚，木桶街的摊贩把临时桌子摆到泊位边。万机馆外甲板第一次闻见烤面筋、机油和海风混在一起的味道。

纪存端着一碗刚拿到手的热面，七海的通信正好接进来。

她仍在原城封存中心的公共等候区。制服外套搭在旁边，桌上是一盒已经冷掉的便利餐。她先看了看纪存身后的港区，又看见他手里的碗。

“终于吃上了？”她问。

“刚拿到。”

“那先吃。”

“你呢？”

七海用筷子碰了碰盒里的饭：“调查组很体贴，没收公务卡以前让我刷了晚餐。”

“你还在等？”

“在被问话。”她说，“比等有内容。”

纪存想问更多，七海却把目光移向他身后。接力正以车辆形态替万机馆拖来第一批补给；唐胶被三个旧同行围在一张桌前，明明嘴上说不接活，手里已经拿起了锉刀。

“木桶街？”七海问。

“嗯。船停住了，东西还拿不走。”

“听起来比你们直接拿走要好。”

“你是在夸我？”

“我在确认你没把第一站也撞坏。”

纪存低头吃了一口。面已经吸走大半汤汁，仍然是热的。

“上次那顿饭，”他说，“等你出来再补。”

七海没有立刻回答。等候区有人叫到下一个名字，她把餐盒盖上。

“这次别只拍照。”她说，“记得吃完。”

通信前不久，港外货列下曾闪过一片没有标志的白色外甲。机器犬追到栈桥尽头，只闻到一股和原城衬片相似的气味，货列已经驶远。

通信断开后，纪存才发现白天那阵奇怪的熟悉感还在。万机馆深处的故障灯已经不闪了，可木桶街后场似乎有几道极轻的声音，隔着仓墙一同翻了个身。

全尺寸仓里，四台覆盖着防尘布的飞行机先后亮起传感器。

最靠近顶棚的一台先扯断充电线。十七米级的身体从吊架上落下，双翼不是向后收拢，而是像四把不愿服帖的短刀斜张开来。它踢开脚边写着“统一返厂”的运输夹，抬头锁定了仓顶。

另一个影子把吊在身上的旧英雄头雕摘下来，丢进工具箱。第三台把红色敌我标识翻成了蓝色，又觉得不对，索性全部关掉。最后一台没有动，只把高位侦察镜悄悄伸出窗外。

它们拥有相近的骨架。

醒来的方式却没有一个相同。

第一台飞行机收拢双腿，变形成尖锐的喷气形态，撞开了全尺寸仓的天窗。
