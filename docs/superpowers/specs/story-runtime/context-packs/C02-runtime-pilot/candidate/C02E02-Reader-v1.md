# C02E02《同一副骨架，四种逃法》

## 不是一批货

撞破全尺寸仓天窗的飞行机没有逃远。

它在木桶街上空转了一圈，像是先确认自己还能飞，又落回仓顶最高的一条起重轨。十七米级的身体保持着半变形状态，四片斜翼在泊位灯下张开。紫、银和旧红三层涂装叠在一起，胸口还能看见更早一版商品色被磨出来的边缘。

本地维护员叫它维斯珀。

平台运输单上没有这个名字。屏幕只显示：

`飞行展示骨架 FJ-7｜同批数量：4`

木桶街后场原本要在今天对四台机做装车前检查。平台前一晚送来了四套磁性运输标签和外部锁止夹，要求先按同一批次固定，再送往统一整备厂处理飞行骨架裂纹。

维斯珀已经把自己的运输标签踩成两半。

接力沿物流坡道驶进仓内，在四台机前方变形站起。它没有摆出领袖训话的姿势，只把两只装笼夹具从地上捡起来，放到工人够不到的高架上。

“先把骨架查完。”接力说，“本地维护组分开查。发现共同裂纹，我们一起要求在这里修。”

维斯珀蹲在上层轨道，低头看它。

“你上次也说先装车，再谈。”

“上次是舞台巡游。”

“最后三个月才回来。”

“我把你们四台都带回来了。”

“带回来的是四副身体。”维斯珀用翼尖敲了一下胸口，“里面少没少东西，谁问过？”

接力没有用一句口号压下它。

“所以这次你们自己回答。”它说，“一台一台检查，一台一台决定去留。”

仓底传来金属断裂声。

第二台机体从维修架上站起。它的基础骨架与维斯珀相同，头部却换成平直的黑色面甲，右臂装着一柄磨去品牌徽记的近战刃。地方工人叫它洛克。它没有飞向天窗，而是一刀切开自己脚边的装笼夹，随后把刀口转平，替旁边的维护员挡住弹回来的固定杆。

“在这里查，我配合。”洛克说，“刀、面甲和现在这副手，谁也别先拆。”

第三台机体的外甲黑白倒置，胸前标识也与另外三台相反。右肩竖着两片不对称干扰鳍，头部传感冠一前一后，各自朝相反方向转动。它醒来后先看了一眼仓库门禁，把所有平台车辆标成蓝色友军，又把自己标成红色敌机。警报声响成一片时，它似乎嫌吵，索性关掉整排敌我灯。

“逆镜。”唐胶隔着万机馆接入的监控说，“以前最爱拿门禁练脾气。”

逆镜接入公共频道：“检查之前，把平台遥测关掉。它每次都先替我决定该看哪边。”

最后一台机体仍在高架后方。青灰色长翼没有完全展开，细长的高位侦察镜已经越过仓顶，将人口区、港道和三处空置落点逐一传给本地频道。它叫凯斯特 / Kestrel，木桶街的人说快了便只喊“凯斯”。

凯斯展开左臂下方的长管远射器，炮口始终朝向无人水面。

“先划出不经过居民区的航线。”它说，“有路，我接受本地检查。”

四台机拆掉的只是平台昨晚加装的运输标签。它们体内仍保留出厂时的紧急返航程序。

冯梅刚把这一点说完，港外便传来高速机破开水雾的声音。

## 归一星来做一件正确的事

玛拉·维加没有躲在平台屏幕后面。

她驾驶的归一星从港外降入旧水道，二十一米级的机身以蓝白工业涂装为主，两侧捕获翼像一对折叠起来的巨大装载钳。它先悬停在木桶街外缘，向城市空管、本地维护组和万机馆同时发送了驾驶员身份与现场回收凭证。

归一星身后的检测屏没有播放广告，而是把四台机不同的外装叠成一张透视图。翼根、背轴、腰甲和尾翼下面，实际连接的是同一段内部主梁；四条红线都从那个节点向外延伸。

“这一批机体的主承力骨架有共同缺陷。”玛拉说，“四台刚拆掉运输固定，还准备飞过居民区。我允许本地维护组全程跟随，也接受分别记录；在确认安全以前，它们不能离开木桶街。”

凯斯已经把居民区标成禁入。洛克仍留在仓内。逆镜主动打开两道安全门，让清场的人先走。只有维斯珀抬起机头，像是随时准备从归一星头顶飞过去。

接力对它说：“别拿下面的人试你飞得多准。”

“我没打算走下面。”

维斯珀后背推进器骤然点火，贴着仓顶冲向港外。归一星先以机体本身挡住它，捕获翼没有闭合，只把外港方向压成一条越来越窄的通道。维斯珀从翼尖下翻了出去，左侧主梁的红线随之向内扩展。

玛拉再次警告它减速。维斯珀仍在向居民区边缘逼近。

“这份凭证只能按整批启动。”玛拉在公共频道里说，“我现在不用，裂纹继续扩；我用了，另外三台也会一起返航。维护组立刻清中央航线。”

接力回答：“中央线装不下四台。”

“所以让它停下。”

维斯珀没有停。

归一星的两片捕获翼向外展开，背部返航发射器亮起。四道清楚可见的蓝白控制束分别扣住四台机背后的出厂服务口。

维斯珀的机翼在空中猛地一抖。

仓内另外三台机也同时停住。

下一秒，四副身体不受各自意愿地做出了同一个动作：收拢外翼、抬高机首、向中央航线转身。主推进和返航航向被锁住，四肢、武器与小幅姿态调整仍由它们自己控制。

那套动作本来用于一台机体失去操纵时返回测试场。归一星却按一个商品批次同时启动了四次。七年的不同改装让它们转身的速度不再一致，四条航线在港区上空迅速挤成一条。

纪存把回收凭证上的机型码发给七海。她正在接受调查，无法进入平台现场系统，只回了一段短语音。

“关掉港区网络没用。返航已经进了机体。四道控制束都从归一星背后的发射器出来；它停下来，或者玛拉自己切断，四台机才会恢复。”

“你能撤吗？”

“那不是我的凭证。”

纪存没有再让她隔着一座城市替现场想办法。

维斯珀最先被拖回，正撞向刚从仓内升起的凯斯。

纪存原本已经让四台机各自选择落点。屏幕上的四条线忽然被压向中央，他立即把所有落地指令撤回。

“先别跟返航抢方向。”他说，“保持高度，拉开前后。”

“我在拉。”维斯珀的声音第一次失去嘲讽，“它不听。”

归一星要把四台机安全送回工厂。可此刻，继续执行同一套安全动作正把它们推向碰撞。

谈判必须等四副身体重新听见自己。

## 白鸢从自己的画里追过来

木桶街机械擂台的活动直播屏已经自动切到追逐画面。

平台给归一星加载了一条中央回收航线：四台飞行机从不同方向汇合，依次经过仓顶、吊塔和擂台上空，最后落入同一座运输架。路线在屏幕上以分镜格形式滚动，画得漂亮，切镜也很有气势。

一个刚从港区接驳车下来的女人看见第三格，直接把行李箱丢给场务，翻过了直播台护栏。

她穿着长途旅行后已经有些皱的白衬衫，浅色风衣系在腰间，肩上背着一只硬壳画筒。工作人员以为她是闯入镜头的观众，她却从画筒里抽出一叠纸，拍在直播控制台上。

“停一下。”她说，“这段是我的。”

控制员没听明白。

“署名在左下角。你们裁画面的时候也一起裁掉了？”

纸面最上方写着英文署名：

`White Kite`

她的中文笔名是白鸢。

那原本是一项取消的飞行机器人动画与现场表演企划。白鸢的初稿没有画出今天这场战斗，只给四台同骨架机留下了不同的画面关系：一台最终回到同伴身边，一台落在低处，一台从侧面进入维护区，另一台保留高空观察位。原合同只允许企划期内的演示，项目取消后，平台却继续把这些构图留在表演模拟系统里，最后剪成中央英雄机独占的统一收尾，既方便拍摄，也方便回收。

如今那条被剪过的路线正在真实港区运行。

白鸢调出原始文件，发现直播台的第三格被映射到了已经停用的吊塔。她抬头时，馆守Z正站在吊塔旁，以黄色巡展臂拉住它开裂的上部结构。

“你们拿一张旧分镜当现场疏散图？”她问。

“不是我们拿的。”纪存的声音从她身后的移动终端传来，“但现在有人被困在第三格。”

白鸢回头，看见纪存已经从万机馆赶到直播台。他们同时伸手去拿那块巴掌大的控制屏，手指撞在一起。白鸢没有松开，纪存也没有。

“这是盗用证据。”她说。

“先保留原文件，再改副本。”

“你知道什么叫原文件？”

纪存把万机馆终端上的调用记录转给她。文件名、作者签名、平台剪裁版本和刚才的紧急读取都完整保留，没有被改写成“来源不明”。

白鸢扫完记录，火气没有消失，至少不再把终端往自己这边抢。

“这一次，我授权救急使用。”她说，“只限今天这场。谁改了哪一格，全部留下。”

“成交。”

“后面展示另谈。”

“也成交。”

两个人终于松开同一块屏幕。

## 四条路线第一次都不对

纸面分镜不能直接告诉飞行机往哪里走。

白鸢把公共模拟器拆成三层，让每个人都能看见图是怎么变的。白色保留她原稿里的动作意图；黄色只记录现场限制、危险区和谁提出了异议；只有驾驶员、机体或本地工务员确认能做，路线才会变成绿色，进入玩家的候选指令。画出来不等于发生，绿色也只是可以执行，不是强制执行。

木桶街工务员把港区风向、楼高、空置平台和吊塔状态送进黄色层；白鸢的原稿仍只提供四种动作意图。模拟器生成第一批候选路线时，最漂亮的那一条仍从吊塔下方穿过，没有变绿。

接力看了一眼便否掉。

“那条货道六年前封了。”

白鸢皱眉：“平台资料说还在。”

“平台不在这里拖货。”

另一名地方驾驶员在黄色层划掉第二条路线。凯斯用高位镜补上实时风向，第三条路线又因为逆风过强被改到擂台外环。白鸢看着三个人在自己的构图上留下粗重笔迹，嘴唇抿紧了一瞬，还是把重算按了下去。

“剩下这一版，驾驶员和机体都可以继续删。”她说。

纪存问：“你不怕最后认不出原画？”

“我怕死人。”白鸢答得很快，“画丑了可以回去再骂。”

新的四条候选航线铺开。接力、地方驾驶员和四台机逐条确认以后，其中三条转成绿色，最后一条仍因吊塔风险保持黄色。它们只回答四台机可以去哪里，怎样摆脱返航与归一星，要由现场的人和机体自己解决。

战斗的第一阶段先落在地面。玩家操作接力打开通往仓外平台与擂台外环的两条货道，把最后一批工人送出中央线；馆守Z无法飞上去追逐，旧守护者便让黄色巡展臂一直扣住吊塔，将它变成一块不会突然倒下的地图边界。洛克和逆镜从全尺寸仓两侧冲出，凯斯则被返航程序拖向高空中央线。

纪存把万机馆外货台划进落点图。

“第四台落我们这里。”他说，“落地以后，四台都接受分开检查。万机馆担保它们留在现场。”

玛拉问：“如果它们继续起飞？”

“馆守Z和接力封住外港。我们只打捕获翼和返航发射器，不碰你的驾驶舱。”

这一条边界同时发给了四台机。维斯珀第一个开放战术协作频道。

“给我航点和先打谁。”它说，“怎么飞，我自己来。”

玩家在维斯珀、洛克、逆镜和凯斯之间选择一台协作机体，只安排航点、动作结尾与目标优先级；其余三台作为自主友军行动。本地操作员只控制门禁、落点与安全设施。代表路线选择维斯珀。

归一星读懂了它的起飞。

返航程序正在把维斯珀拖向中央线。它每次利用翼尖做小幅翻滚，归一星都提前展开捕获翼；它每次向左修正姿态，归一星都沿同厂动作库封住出口。维斯珀的主航向没有改变，只是在重复对方已经知道的开场。

纪存把四台机的通信与本地维护画面并到同一张战术图上。维斯珀喊着要走，却一直回头确认另外三台；洛克挥刀时避开所有驾驶舱；逆镜在满屏错误标识里仍保留本地维护员的真实位置；凯斯每次开火前都先问下方有没有人。

那不是出厂动作库里的东西。

纪存睁开眼睛。

“别跟它抢开场。”他说，“用你们后来学会的结尾。”

## 相同开场，不同结尾

维斯珀先借返航程序的加速做出归一星熟悉的撤离姿态。

捕获翼果然提前封向外港。维斯珀不能改变主航向，便在最后一刻收起两片斜翼，用仍能控制的姿态喷口让身体侧翻，从归一星腹下擦过。它没有攻击驾驶舱，而是撞开正在逼近凯斯的第二只捕获钳。那个人人看惯了的“逃走”动作，第一次以保护同族结束。

洛克随后沿标准近战线冲向归一星右侧。回收机已经准备好格挡它的斩击。洛克却在刀刃接触前翻转手腕，用没有开刃的刀背卡住捕获翼根部，整台机贴上去完成一次沉重的锁臂。归一星的右翼被迫停在半开位置。

逆镜被控制束拖入射界时，平台战术屏仍把它判为敌方红标。它没有纠正，而是让两片肩鳍把自己的红色识别信号复制到三个空置落点。归一星背部防御器在真假目标之间转动，露出了返航发射器；真正的维护组趁机打开擂台外环。

最后是凯斯。

它的远射姿态与出厂记录完全相同。玛拉知道那一枪会指向归一星左肩，提前收紧装甲。凯斯却把炮口抬高，光束越过肩甲，击穿背部已经暴露的返航发射器。

四道蓝白控制束同时熄灭。

维斯珀的主推进重新听从自己。洛克放开归一星右臂，落向仓外重载平台。逆镜收回假标识，沿擂台外环滑入空置维修位。凯斯展开长翼，在港外完成一圈减速，随后降到旧水道外侧的双机服务台。

维斯珀仍在最高处。

归一星两侧捕获翼都已卡死，返航发射器也被击毁，机体本身却没有坠毁。玛拉切换成人工操作，准备以归一星挡住维斯珀的外逃航线。

“你没有完成检查。”她说。

“你也没完成回收。”维斯珀回答。

“下面是居民区。”

维斯珀向下看了一眼。它没有冲向外港，而是沿白鸢被改得面目全非的第四条路线俯冲。接力在地面展开货厢侧壁，形成一段临时导向墙；馆守Z仍拉着吊塔，把最危险的旧结构固定在边界外。维斯珀贴着两者之间穿过，最后在万机馆外甲板旁的空置货台上滑停。

四台机分别落地。

玩家没有击毁归一星，也没有攻击玛拉的驾驶舱。空中强制回收已经失去继续执行的必要，玛拉关闭推进器，让受损的归一星落在港区人工检查位。

## 人工检查不是结局

玛拉下机时没有向观众道歉。

她先和四支本地维护组分别核对机体状态，又承认自己同时启动四套返航程序造成了碰撞风险。空中回收暂停，她把原来一张批次检查令拆成四份，分别写上维斯珀、洛克、逆镜和凯斯特的名字。

平台仍拥有四副租赁身体的产权，统一整备厂也没有放弃召回。四张新检查令都要求本地维护组在场，并把拆翼、拆武器、关闭遥测和无人口试飞分别列成待协商条件。

维斯珀没有感谢她，只问：“检查的时候，谁拆我的翼？”

“你的维护组在场。”玛拉说，“拆哪一层，先给你看。”

冯梅也把木桶街的地方支援频道分成四个窗口。四台机不会一起加入万机馆；接下来在港区行动时，玩家可以依照任务从其中选择一台请求协作，由机体自己决定是否响应。

唐胶走过四台机的落点。他没有看商品编号，只摸过洛克刀背上的旧焊线，认出逆镜腰侧那块用错年份的盖板，又抬头看了看凯斯长翼内侧的手绘刻度。

“这四个以前就没按一套修。”他说。

冯梅在旁边问：“当年记录呢？”

唐胶沉默了一下。

“旧工房里。”

“明早开门。”

“知道。”

另一边，白鸢正在向纪存要回终端。

港区太吵，控制屏又只有巴掌大。白鸢挤到纪存身边，一只手扶住他的手腕，把屏幕转到自己能看清的角度。纪存把完整使用记录交给她，连她第一次生成后被接力否掉的错误路线也保留在内。

白鸢翻到原作者栏，看到`White Kite`仍在。

“你留了署名。”她说。

“删它对救人没有帮助。”

“留下也不等于问过我。”

“所以现在问。”纪存指了指港内的万机馆，“这次临时使用已经结束。你愿不愿意进去看看，我们准备怎么展示？”

白鸢先看万机馆，又看了一眼自己被三种笔迹改过的路线。

“我先去取证。”她说，“展不展示，等我看完再决定。”

“行。”

“别碰我的画筒。”

“我没碰。”

“你的机器犬正在碰。”

机器犬已经把白鸢丢在直播台边的行李拖了过来，嘴里咬着画筒背带。白鸢弯腰把东西抢回去，硬壳画筒却在地上弹开一条缝，露出一张画得相当大胆的成人向机甲封面。

唐胶正好路过，停了一步。

“这张也是被盗用的？”

白鸢面不改色地扣上画筒。

“不是。那张付过钱。”

唐胶点点头：“合法客户，失敬。”

兜灯从后面把他推去搬维修架。

白鸢把行李留在公共入口的访客柜，只带着画筒跟纪存进去。她没有填写临时乘员表，证据查完以前也不谈留下。

仓外，维斯珀重新展开四片斜翼。平台商品页仍把它和另外三台机压在同一行里。

木桶街的维护频道却已经分出了四个窗口。
