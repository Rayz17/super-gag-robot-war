# C02E03《旧拳王没有原装漆》

## 旧工房重新开门

唐胶在门口试了三把钥匙。

第一把插不进去，第二把只能转一半，第三把刚碰到锁，卷帘门便从里面自己升了起来。

冯梅站在黑暗里，手上拿着另一只遥控器。

“锁三年前就换了。”她说。

唐胶把那串旧钥匙塞回口袋：“那你看我试半天？”

“想确认你还记不记得哪把是这里的。”

旧工房封了很久，里面却没有落满整齐的灰。靠墙的工作台上还压着半截切到一半的胶板，零件柜有几格空着，说明这些年一直有人进来拿旧材料。唐胶先打开窗，再去摸电源总闸。兜灯已经从另一边找到了灭火器和应急断电，检查完才让跌跌进门。

跌跌进去三步，踩上一根滚落的笔，仰面摔进废纸箱。机器犬跳过它，从桌下拖出一本发黄的登记册。

唐胶没有笑。

那本册子里是他当年的内页：替换了什么材料、手工修到什么程度、哪些位置最好不要再承重。他写给修件师看，字小得像怕浪费纸。旁边另一台旧终端里，则存着真正对外出售时使用的标题。

`按原结构恢复`

`近原版状态`

`收藏级复原`

冯梅把两边都投到墙上。

“你写的内页，买家看不懂。”她说，“我改的标题，买家看得太懂。”

“看懂的是价钱。”

“也看懂这东西还能卖。”冯梅拉出一只退件箱，“你走以后，人家拿着这些标题回来，问我为什么里面有替件。你猜我怎么答？”

唐胶翻开箱里第一件模型。肩部卡扣是他做的，后来又被别人换过一次。

“我在的时候也看见过标题。”他说，“没拦。”

“这句还算人话。”

“后来你把它印成模板，不算我的。”

“这句又不像了。”

冯梅把退件箱推到唐胶面前。唐胶没有接她的话，先把旧转子的资料单独放到一张桌上，又从箱里拿出第一件待验物。

唐胶看着墙上那一排好卖的标题。

“先把机器能不能再用说清。”他说，“价钱后面再吵。”

## 她接着做完的订单

隔壁打印间已经有人工作。

许岚五十多岁，戴着一副不太合脸的护目镜。她正在把灰色树脂支撑从一批小腿关节上剪掉，动作不快，桌边放着三件打废的练习品。寄件袋沿墙排成一列，每只袋子上都有两个日期。

唐胶认识这间小店以前的主人。

“小许的单还没清完？”他问。

“去年就清完了。”许岚没有抬头，“这些是后来又来的。”

她的儿子去世以后，旧账号仍不断收到模型玩家的留言。有的是以前答应补发的零件，有的是别人拿着旧教程找来。许岚一开始只会把文件发给打印机，前三批支撑拆坏了大半，孔也总打偏。后来她学会重做，不会的便拿到木桶街问。

唐胶从成品袋里拿起一枚髋关节，看了看侧面的孔。

“这孔不是小许打的。”

“嗯，我打的。”许岚说，“头三个都废了，这个能装。”

“位置往外了半毫米。”

“装甲厚，我试过。”她把旁边一台普通量产机模型拿过来，关节推入以后正好避开内甲，“旧图是他的，改孔是我的。袋子里分开写了。下一个人照着做，省得猜。”

唐胶看了一眼袋内。旧图纸署着她儿子的店名，新工序下面写的是“许岚，第四版”。

“这批我帮你复核。”唐胶说。

“收费吗？”

“你们木桶街的人怎么一见我就先问钱？”

许岚终于笑了：“因为以前问晚了。”

旧工房的第一段探索由这张长桌开始。玩家要从三件寄售物中各找出一处对不上号的地方：把内页记录、公开标题和实物磨痕并排比较，再亲手完成一次开合或承重验证。支撑没拆净的退回，孔位不符的重做；只有记录与实物都说得通的零件才能装袋。

其中一枚未登记的拳击机衬套坯被唐胶留了下来。它暂时不能直接上机，但可以在后续训练中加工成旧拳王的场间快修件。完成判断环后，委托栏多出一张普通订单：

`协助完成普通补件订单`

许岚封好最后一只袋，接着拆下一组打印支撑。

## 盒子拆开以后

待复核的订单里，有一台旧拳王的缩尺模型。

它已经被拆到只剩内甲，左侧胸板里面歪歪扭扭写着：

`谭国伟，十一岁`

名字旁边画了一只比拳头更像土豆的手套。

唐胶认出肩部那枚灰色卡扣。那是他二十年前补的，材料来自旧工房最便宜的一批余料。公开商品页却把这件模型写成“未修复初版”，照片特意避开了卡扣内侧。

冯梅看着页面：“这个标题不是我改的。”

“模板是。”

“所以今天一起改。”

她联系了寄件人。不到二十分钟，一个身材发福、右膝戴着旧护具的男人从擂台方向赶来。谭国伟曾是木桶街的机械拳手，后来转到教练席。进门后，他先看见模型内甲上的名字，停了片刻，没有伸手去摸。

“卡扣还能开吗？”他问。

唐胶把胸板扣回去，又打开一次。

“能。白痕留着，再硬开几百次就不好说。”

“那就少开。”谭国伟把模型接过去，“白痕不用磨。”

“价格会掉。”

“十一岁写的字也不值钱。”他看着那个土豆手套，“我留着。”

纪存问他愿不愿意把这件模型和维修过程放进万机馆第二天的有限开放。谭国伟没有立即答应，只说先让他看看真实那台还能不能打。

于是冯梅带他们去了机械擂台。

## 十八米的旧拳王

擂台维护层的升降台从地下缓缓升起。

先露出的是一双很旧的拳。

右拳护具换过三代，表面颜色不一；左拳更小，指节处有反复打磨留下的凹痕。十八米级的机体继续上升，胸口不是耀眼的冠军徽章，而是一块重新焊过的深灰色补板。两侧髋部高度略有差异，右腿在站直时会自然向外留一点角度。

这就是旧拳王。

它没有保持博物馆展姿。升降台停稳后，它先抬脚跨过地面电缆，再走到谭国伟面前，低下头。

“还打吗？”谭国伟问。

旧拳王活动右拳，护具里发出一声不太圆润的锁定响。

“打。”

它拥有本地拳击AI，能自己保持平衡、判断距离和完成出拳。谭国伟在教练席报组合与节奏，兜灯坐进赛事安全席，手边是能直接切断动力的红柄。玩家决定旧拳王的步法、格挡方向、目标和出拳时机；最后是否出拳，由旧拳王响应。

另一座升降台随之打开。

影子陪练机从黑暗里走出来。它是擂台公用的十八米级训练机，与旧拳王使用相近的拳击骨架，外甲却是没有宣传色的深蓝。训练AI自主出拳，赛事安全席负责限幅和停机；这一场玩家只操作旧拳王。

第一轮训练中，玩家若照着屏幕上的标准连招输入，影子总会在最后一拳之前侧开。屏幕上的漂亮组合，它已经挨过几千遍。

谭国伟盯着旧拳王被击中的右髋。

“它以前不会往那边退。”

唐胶蹲在全尺寸检修台旁，看见右髋内部那组不属于原厂的工业转轴。

“后来换过。”他说。

“什么时候换的？”

“你离开擂台以后第二年。”唐胶说，“原件裂了，我拿工业转轴救回来的。修法写在内页。”

冯梅站在后面：“教练组拿到的那张，只写了原结构恢复。那句是我改的。”

“我这几年还拿它从前那条腿教它退。”谭国伟看着旧拳王右髋外张的角度，“难怪每到这一步，它宁可挨拳。”

旧拳王没有回头，只在原地重新摆了一次步。右脚刚向后撤，影子陪练便追上来，一拳打在它肋侧。

谭国伟把旧战术板从教练席上摘下来，折成两半。

“以前那套别练了。”他对旧拳王说，“今天从你现在这条腿重新教。”

## 把手艺放到别人手里

旧工房下午把卷帘门全部打开。

唐胶没有只发一份终端说明。他把测量模具、材料样片、几种替件和仍然不能确定的旧记录都摆到长桌上，让本地修件师当场复做。

第一项就是旧拳王右髋。

唐胶当年为了让工业转轴适配拳击骨架，在衬套内侧留了一条手工卸力面。那条修法救过旧拳王，也让后来每次换件都只能找他或猜他的手感。

年轻修件师照着唐胶刚写出的步骤复做，试转两次以后，发现卸力面角度太激进，会让新材料更快磨损。

整条街都等着唐胶怎么说。

唐胶拿过试件，转了几次。

“是大了。”他说，“旧材料软，当年靠磨损自己吃掉了。新版减一档，再试。”

年轻人改完，旧拳王右髋的试件顺利通过重复转动。她和两名本地修件师把新版限位衬套装上实机，兜灯连续做了三次承重和急停测试。

旧拳王再次面对影子陪练。这一次，它向左横移时右髋没有突然下沉，顺势躲过了第一拳。它仍然无法完成年轻时那种漂亮的贴身绕背，谭国伟却在教练席上拍了一下护栏。

“这步能用。”

玩家由此获得一枚旧拳王右髋快修件，可在下一场正式比赛的局间整备中使用一次。新版本下面同时留下唐胶和复做者的名字。

兜灯把自己一直不外借的止动量具放到长桌上。

唐胶看见了，往旁边挪开半个工位。

“这个很贵。”他说。

“所以谁用谁登记。”

“你现在说话越来越像冯梅。”

“那你今天最好听一点。”

冯梅则把那批由自己改过标题的寄售物全部调出来。她没有说都是为了救店，只在每一条标题后补上对应内页。价格屏很快开始下落。

有人当场冲进工房，问为什么一件昨天还叫收藏级复原的模型今天变成了多处替件。

“因为昨天那句写得不完整。”冯梅说。

“我按昨天的价收来的！”

“不愿降价就撤售。已经成交的，我和当时参与维修的人一起处理。”

唐胶抬头：“我在场时签过的，算我一份。”

“你走以后新增的，我来。”

两个人没有握手。价格屏还在往下掉，下一位寄售者已经把另一只盒子放上桌，要求查清里面究竟换过什么。

## 从怀旧组调到公开组

旧拳王的赛事资料很快得到复核。

右髋是工业替件，拳部执行器换过非原装版本，胸口补板也改变了重量分布。它不再符合“原结构怀旧表演组”的条件。

胶价主持立刻在直播屏上弹出一个夸张的遗憾表情，准备把故事包装成“传奇失去最后入场券”。纪存没有顺着它演。

他直接问赛事方，维修级冠军奖励是否只属于怀旧组。

答案是否定的。

公开组也能赢得新散热机组，只是对手不再是配合复演的表演机，而是本季全装冠军百刃。

冯梅把两张报名页都放到旧拳王面前。

“不打也行。”她说，“新机组我们再想办法。”

旧拳王先看向较轻松却已经不再符合的怀旧组，又看向公开组。它抬起右拳，在公开组报名屏上按下确认。

谭国伟没有替它欢呼，只把自己少年时的缩尺模型放到教练席边。

“那就先学怎么少挨两拳。”他说。

## 白鸢先问它现在能怎么动

白鸢原本只是来取回被盗用的分镜。

她在万机馆里查完调用记录后没有立刻离开，理由是平台把她的作品用于四台机的回收，后续调查仍要看现场。但旧拳王训练开始时，她已经带着画板坐到擂台边。

“我只是观察。”她说。

纪存看见她画了两笔又停下。她先把模拟器的黄色层推给谭国伟和兜灯。

“右髋现在能转多少？护具能挨几次？别拿它年轻时的录像回答。”

谭国伟在黄色层圈出右侧退步的死角，兜灯补上护具的承受范围。白鸢没有先画一套漂亮打法，只留下一个很窄的测试区域：旧拳王修完右髋后，能不能在不急停、不绕背的情况下向左迈出一步。

影子陪练用旧拳王最熟悉的起手逼近。旧拳王没有打完整组合，只在直拳到来前向左横移。新衬套承住了重量，右髋没有下沉。它避开第一拳后立即停手，兜灯完成检查，谭国伟才在那一步上按下确认。

模拟图里，一小段路线由黄色变成绿色。

“今天只验这一步。”白鸢说，“晚上怎么打，等对手来了再画。”

纪存正在旁边摆比赛次日上午有限开放的试展台。许岚的补件袋和谭国伟的模型前都只放了空支架；两位本人没有点头，灯也没有接上。白鸢被盗用的原稿没有出现在展台上，正中却空着一块能放下一页纸的位置。

白鸢扫了一眼那块空位。

“我的画呢？”

“你只授权了昨天救急。”

“学得挺快。”

“主要是你说得很大声。”

白鸢把训练中被修改的那一页抽出来，放到清单旁边。

“这一张可以放。原稿不行。”

“作者说明写什么？”

“写这是一次测试，不是必胜路线。”她看向场上的旧拳王，“等它真打完，再补后半张。”

## 全装冠军

机械擂台的顶灯依次亮起。

影子陪练站到对面，摆出的正是旧拳王职业生涯里最漂亮、也最容易被观众认出的起手式。旧拳王没有跟着摆，它的右脚仍然保持那一点不对称的外开。

另一扇重型闸门在场边升起。

先进入灯光的是两面肩盾，随后是背包推进器、可展开副臂、远射单元和层层叠起的胸甲。二十二米级的百刃走入预备区，每一步都让擂台承重灯多亮一格。

它的装备不是挂上去逗人笑的装饰。试射开始后，三种武器在同一轮内完成切换，影子陪练还没接近便被逼出场外。

驾驶员阿列克斯·杜兰从公开频道里向旧拳王问候。

“海报说我要打原装传奇。”他说，“现在海报改了。”

唐胶看着旧拳王身上深浅不同的补板。

阿列克斯继续说：“机体没换就行。我来打它。”

旧拳王抬起双拳。

拳台铃第一次响起时，本话的剧情教学结束，旧拳王自由训练与赛前调试永久开放。

下一场铃声先开始影子陪练的公开组认证回合。通过以后，百刃与旧拳王的正式比赛随即开场。
