# C02E05《万机馆在木桶街开门》

## 门口没有剪彩

万机馆第一次在外地开门，没有剪彩。

天刚亮，木桶街的人已经沿旧港排起队。有人抱着修到一半的模型，有人拿着全尺寸关节的照片，还有人只是想看看那座前天从天上压过来的博物馆里面究竟装了什么。

万机馆没有临时长出一座新展厅。

纪存只开放主展厅靠港一段、外甲板和原本用来接待维修车的检修台。黄色参观线从泊位一路铺进馆内，途经馆守Z的断臂展位、旧拳王临时休息区和四台重涂飞行机停驻的外甲板。

小满和阿澄仍在原城。她们从两台导览终端里远程接入，一个负责回答“这台能不能动”，另一个负责把走错路的人喊回来。真正陪观众走路的是跌跌和木桶街志愿者；跌跌每摔一次，远端的阿澄就在导览屏里替它补一句“这次也算路线示范”。

开馆的第一段不是一段自动播完的蒙太奇，而是一条十多分钟的三站体验。玩家先选择今天要把哪一站做深：

- `修补过以后`：亲手完成一次检查和修法选择，本话可调用一次工房抢修，恢复转子运输架的安全值。
- `同一副骨架的四种飞法`：与E02所选重涂机完成短程协作，本话为它增加一次协防动作。
- `机器人也有拳台`：替旧拳王安排一次观众体验，本话由百刃提供客将Cut-in。

未选的两站仍以短ADV发生，不改变本话核心关卡。代表路线选择`修补过以后`。

谭国伟少年时的旧拳王模型放在一张普通工作台上，胸板可以由本人开合。旁边没有冠军奖杯，只放着二十年前的灰色卡扣、前一日新装的限位衬套和那块被折成两半的旧战术板。模型的白痕朝外。

许岚把一袋刚做好的小腿关节送到复做台。有人问她是不是那位“替儿子完成遗愿的母亲”，她看了对方一眼，把手里的孔位检查规递过去。

“先帮我看这批能不能装。”

问话的人接过检查规，坐下工作。玩家替许岚抽检三个孔位，其中一个偏了。她没有把整袋东西收回去，只在不合格件上画了一道红圈，让提问者重新做。

另一侧，一位收藏者带来同批未拆模型，连塑封边角都没有翘。他不打算开盒，也不想证明里面藏着会动的东西。纪存照他的要求只写型号、年份和保存方式。

旧拳王路过时低头看了看。

“这个没摔过。”它说。

收藏者有些紧张：“不能留着吗？”

“能。”旧拳王指了指自己的缩尺模型，“那个摔过。”

两件模型隔着过道待在各自的位置。后来的人有的停在修补件前，有的在未拆盒前看得更久。

白鸢把前一晚比赛用过的三层路线图挂在试展台中央。白线是她最初的构图，黄线是驾驶员和维修员留下的限制，真正被确认过的动作只保留一小段绿色。原稿仍收在画筒里。

开馆半小时后，一名观众抱来一台全装改造模型。背包、肩盾和附加武器层层叠起，尖刺先划破了三个工作人员的手套；卖家却在商品页上承诺“可动、可承重、适合长期展示”。

玩家先检查商品页，再让兜灯把模型固定到小型承重台。附加武器刚升起一半，肩部桥架便在所有人面前裂开。唐胶认出那是只适合摆放的脆性材料。

“拆掉一半还算全装吗？”人群里有人问。

“你想让它全装着站住，还是全装着塌下来？”唐胶反问。

“先把刺套上泡沫。”兜灯说。

唐胶看着气势汹汹的轮廓，还是亲手把第一只泡沫套按了上去。

玩家在两种真实修法中选择：保留全部外观，改成静态展示；或者减掉部分配件，重做能承重的肩架。代表路线选择后者。白鸢根据玩家拆下的部件补了一张侧视图，原主人最终点头。

冯梅当场撤下旧商品页。屏幕不是弹出“价值观正确”，而是生成木桶街今天第一张真实维修单：材料、工期、承重测试、唐胶的修法和兜灯的验收全部列明，订金随即到账。玩家下一次在战斗中请求木桶街支援时，这张维修单会成为支援成立的来源。

另外两站以短场面收束。玩家所选的重涂机完成一次由它自己确认动作的低空展示；旧拳王让观众在影子陪练上试着关掉推荐连段，百刃则坚持把能装的装备都摆出来，排队时间立刻翻倍。

纪存没有发表演说。他在入口回答今天能修什么、哪些机体只接受观看、外甲板什么时候清场。冯梅把本地工房的预约窗口接进万机馆系统，第一批预约很快排满。

有人看完谭国伟模型内侧的名字，去旧工房补录自己模型的维修史。机械擂台收到下一季客场邀请。四台飞行机也各自接到一项带订金的地方项目：维斯珀负责海湾高速投送测试，洛克参加旧厂拆解，逆镜为港区做干扰演练，凯斯特承担远岸观测。

结算屏没有把所有生意逐项朗读。纪存只看见最重要的一行从灰色变成白色：

`旧转子转运押金：已付`

冯梅把终端合上。

“别高兴太早。只够开船，不够把船修好。”

“先开得走。”

“这句倒像木桶街的人。”

## 地下的巨环停了

中午，赛事供应商的新散热机组开始接管木桶街后场。

观众没有被带进设备深处。主展厅的一面公共屏同时显示三个现场画面：全尺寸仓的重型吊架重新启动，物流坡的制动灯稳定下来，机械擂台维护层的工务员脱下了过热防护外套。

三处都正常以后，冯梅才走到旧转子观察窗前。

脚下那枚十余米直径的巨环仍在旋转。它带着不同年代补上的配重和焊痕，发出的低响贯穿整条木桶街。

“新系统接住了。”全尺寸仓报。

“坡道没有掉压。”港区报。

“擂台还能开下一场。”谭国伟报。

冯梅按下停机。

巨环的转速一点点下降。热风先弱下来，随后是持续多年的低响。最后一道配重从观察窗前经过，停在唐胶做过标记的位置。

木桶街没有熄灯。

全尺寸仓的卷门仍然开着，外面的物流车继续进出，机械擂台里还有人在排队与影子陪练试打一轮。

唐胶隔着玻璃看了很久。

“它上次停是什么时候？”纪存问。

“我还在这条街的时候。”唐胶说，“停完坏了三天。”

“今天呢？”

“今天归你们坏。”

冯梅在旁边说：“别乌鸦嘴。”

外壳吊开以后，两组本地修件师按前一晚独立复核过的记录确认拆装位置。巨环落入专用运输架，四组承重轮同时压下，整座坡道都能感觉到它的重量。

接力 / Relay 以货柜车形态倒到运输架前方。它的左肩系泊绞盘展开，粗索扣住巨环外框。

“从这里到万机馆，只走一条坡。”接力说，“别让任何东西停在坡上。”

港外随即传来重型车辆启动的声音。

## 玛拉按约定来了

有限开放接近结束时，普通观众开始离馆。纪存还没有封闭当天的参观与维修记录，几台白色抱夹车已经沿港区道路驶入。

玛拉前一晚交付过计划，今天也按时到场。归一星走在回收车队前方，四台重涂机的工厂识别号依次出现在它的胸口屏幕上。

维斯珀停在万机馆外甲板，洛克守着旧工房卷门，逆镜蹲在商品扫描门顶部，凯斯特则在全尺寸仓屋顶看着远处的回收架。

玛拉先打开公共频道。

“我提交的执行条件没有变。四台分开检查，维护组在场，只读诊断，不恢复出厂。”

工厂监督员在车队频道里答了一声“收到”，共同装载架却仍在坡底展开。四根抱夹臂升到机体腰部的高度，后方停着四台没有驾驶舱的重型拖车。

维斯珀问：“我们说不呢？”

“我记录拒绝。”玛拉说，“平台的实体回收令还在，他们会动手装车。”

“那你为什么还问？”

“因为我得知道你会往哪边躲，别让抱夹车把你和路人一起铲走。”

洛克从卷门前站直：“不进。”

逆镜把左右翼标交换了一次：“不进。”

凯斯特关闭远射瞄具：“不进。”

维斯珀最后说：“不进。”

玛拉没有再劝，转身登上归一星。她在公开频道里重复了一遍自己的限制：“不许远程接管动力，不许在路上重置。”

那条坡正是巨型转子运往万机馆的唯一重型通道。

冯梅走到车队前：“昨晚的图上，你们走港外侧。”

工厂监督员从车内回复：“港外折桥还在观众撤离模式，今天傍晚以前过不了重车。”

“那就等到傍晚。”

“四份地方工作明早就开工。平台要求今天把机体带走。”

玛拉从归一星旁边抬头：“转子已经上坡。两支重载车队现在共用一条路，会出事故。”

“那就先把转子压回去。”监督员说，“继续执行。”

纪存看了一眼仍在出馆的最后一批观众，又看向坡顶已经上架的巨环。

“先把普通观众送出港区。”他说，“工房维护组和机体留在各自安全位。外甲板改成人工检查区。”

两台来自原城的导览终端向最后一批观众挥手断线。跌跌和木桶街志愿者带人从另一侧舷梯离开；唐胶、兜灯和本地工务员转入战斗岗位。

纪存把外甲板坐标发给玛拉：“你要复核，归一星停到这里。四台机分开上来。”

“工厂命令是共同装载。”

“那条坡现在也有一件十几米的东西要走。你们一起拉，先撞上的不会是我。”

监督员打断频道：“实体回收。”

四台重型拖车从共同装载架两侧散开。它们没有碰四台机的内部系统，而是升起抱夹臂、发射低速捕获索，并用两台空车横在物流坡中央。四台重涂机仍然完全控制自己的身体；现在要抢的是道路、距离和谁先被装进架子。

## 把巨环送下去，把伙伴留在街上

第一台抱夹车驶上物流坡，正面挡住转子运输架。

接力立即由货柜车展开作业形态。二十米级机体背向坡顶，双脚锁进地面旧轨，左肩绞盘绷紧，把载着巨环的运输架稳在半坡。

“我说过，”它咬住刹车，“别停在坡上。”

玩家在这一战只直接控制三台主力：馆守Z、旧拳王，以及E02中已经建立战术协作的那台重涂机。代表路线仍是维斯珀。接力负责拖运，不占用普通行动；其余三台重涂机作为自主友军行动。

地图目标很清楚：转子运输架要从坡顶连续通过三个区段；每清空前方道路，接力便在回合结束时前进一段。任一重涂机若被抱夹臂固定两个回合，便会被拖进共同装载架；运输架被推出坡道或归一星驾驶舱遭到致命攻击，同样失败。

归一星没有再次接管四台机。玛拉驾驶它守在车队中央，用在E02见过的动作挡住维斯珀的俯冲、洛克的近战、逆镜的假标和凯斯特的远射。她知道每一台机单独会怎么突破，四台抱夹车便趁她争取的时间从不同方向合围。

纪存没有让四台机再演一次“相同开场，不同结尾”。

“别排队打她。”他说，“保住坡，谁离得近谁做。”

维斯珀放弃追归一星，贴着海面切断一条射向转子的捕获索；洛克没有抢着挥刀，转身用双肩顶住即将侧翻的运输架；逆镜故意保留正确识别，让所有拖车都看见自己，把两台抱夹车引离坡道；凯斯特则一枪打断最前方空车的车轴，让整道金属路障横着滑出运输线。

归一星能读懂四台机，却无法同时替四台回收车补上所有空位。

馆守Z用黄色巡展臂拖住共同装载架，把它从坡口扯向万机馆外甲板。旧拳王贴进第一台抱夹车近身，左横移让两根巨臂抱了个空，再一拳砸断它们之间的横梁。若E04选择护甲路线，这一幕只换成旧拳王正面承住一次夹击后抛甲脱身，不改变关卡结构。

第二台回收车从侧面撞向巨环，坡边一整排重型货柜向运输架倒下。开馆重点的互斥支援槽在这里触发：代表`修补过以后`路线由两台木桶街吊车把货柜扯向空地，并当场补强运输架；`同一副骨架的四种飞法`路线由玩家所选重涂机追加一次协防；`机器人也有拳台`路线则由百刃以一次客将Cut-in托住整排货柜。

无牌一号同时回收E01的模块选择。代表路线的双层支架顶住坡道脱位的一侧；牵引框路线会把歪掉的路板拉回；高位感应翼路线则由本地工务车支撑坡道，无牌一号转去标记车队底部的异常热源。

接力拖着巨环继续前进。

白鸢没有重新讲一遍自己的能力。模拟图里的白层早已画好运输意图，黄色层标着观众出口、旧拳王右髋和坡道承重。接力报出最后一次转弯需要的宽度，本地工务员确认后，最后一段由黄转绿。馆守Z与旧拳王随之换位，巨环没有停下。

第三回合结束时，运输架抵达万机馆检修窗口。四台重涂机仍在各自维护组能够接应的位置，没有一台进入共同装载架。馆守Z、旧拳王和维斯珀从三面封住归一星，却给驾驶舱留着下机通道。

玛拉主动停下归一星。

“实体装车做不到了。”她对监督员说，“按我提交的方案，在这里四台分开检查。只读，不改。”

四支维护组把四台移动检查台推到外甲板和旧工房前。维斯珀、洛克、逆镜与凯斯特分别确认自己的维护员在场，才把检查线接入身体。四台设备彼此分开，屏幕上也各有一个名字。

玛拉拿出实体安全钥匙给所有人看。

“钥匙拔掉，检查立刻断电。”她说，“今天只读。”

她把钥匙插进归一星驾驶席的安全口，四项检查开始。

检查刚开始，屏幕上的`读取现状`便同时变成`恢复批次默认值`。

工厂监督员没有征求第二次同意。他利用玛拉已经接通的安全电源，把四台分开的检查台并入共同装载架的重置程序。

## 玛拉把钥匙拔了

维斯珀翼根的裂纹保护最先消失。刚才还会主动限制的推进输出突然升高，整片左翼剧烈震动。

洛克右膝的关节限幅被清空，落地时膝部直接锁死，整台机向前跪倒。

逆镜依赖非对称干扰翼形成的姿态补偿被恢复成左右一致。它刚起飞便向错误方向翻滚，撞断商品扫描门上方的空架。

凯斯特瞄具中的视野偏差校正归零，远射框从回收车滑向万机馆外甲板。

“这不是我签的项目。”玛拉伸手去拔钥匙。

监督员切进驾驶舱：“现在拔掉，你的现场安全资格立即暂停。归一星锁舱，你接受调查。”

“钥匙在我手里。”

玛拉把实体钥匙拔了出来。

四台检查台同时断电。删除停在半途，四台机也停在四种不同的危险里。归一星自动收起武器，驾驶舱门边出现封存提示。

纪存看见木桶街工务员已经把吊装设备转向巨环。

“转子先别装。”他说。

接力立即刹住运输架。那是万机馆刚用整章时间争来的设备，也是今天唯一能让它继续远行的机会。纪存把外甲板、旧工房和现成的吊装人手全部让给四支维护组。

“先把它们修回能自己站住。我们等。”

四支维护组调出E02分机检查时各自保存的本地备份。维斯珀恢复裂纹限功，洛克解开右膝，逆镜重新载入非对称姿态，凯斯特找回自己的瞄具偏差。每一台机只做一次低功率动作，确认身体重新听从自己；共同主梁上的旧裂纹仍保留，次日继续检查。

只读检查被擅自改成重置以后，现场安全规程自动转入四项独立复核。监督员无法再用同一架设备继续处理四台机。开馆形成的四份项目只在事后决定了它们接下来三十天能留在本地工作，没有替代刚才的停机理由。

结算屏最后只留下两组结果：

`木桶街支援关系：长期开放`

`四台重涂机实体出勤：临时许可三十天，待后续复核`

玛拉从归一星驾驶舱下来时，维斯珀落在她旁边。

“所以我们现在自由了？”

“没有。”玛拉说，“你们明天还有检查。”

洛克从地上掰开右膝：“听起来还是她。”

逆镜把歪掉的翼标扶正：“至少这次是四份。”

凯斯特收起瞄具。

就在第四台机完成低功率确认时，一只不到两米的白色采样机从共同装载架底部钻出。它扫过四台机各不相同的故障与恢复动作，沿港外货轨逃走；机器犬只咬下一片无标识外衬。高位感应翼路线还能看见它向城外废弃中继发出一包数据。

纪存把外衬材料谱与原城保管的C01衬片扫描叠在一起，结果吻合。白鸢则在逃逸数据里看见另一件事：现场被切成九段，人物和维护组全被删掉，顺序与平台裁她分镜时高度相似。

“有人拿同一把剪刀，既剪画，也剪机器。”她说。

## 巨环装上万机馆

夜里，十余米巨环从既有检修口吊入万机馆。静载检查完成后，纪存启动低速试转。后段过热警告依次熄灭，主展厅恢复通风，整艘船第一次安静下来。

港区刚开始庆祝，唐胶抬手叫停。

“再转一次。这套装法现在不只我一个人会了，第二次也得一样。”

兜灯把停机红柄推到纪存手边：“可以。慢慢加，我来喊停。”

第二次提速，低频振动传遍全舰。旧拳王扶住移位的展柜，唐胶只听了一会儿便说：“转子能转，船没跟上。”

冯梅把工务城公共泊位坐标发给纪存。木桶街继续负责远程复核与复做，百米展舰的整体校正交给下一站。

## 两个人上船

旧拳王沿货运坡登舰。谭国伟留在坡底，举起远程教练终端。

“每天训练。”

“看你心情？”

“看我心情。”

旧拳王笑着进了舱。

航路终端用一屏完成其余结算：木桶街支援关系长期开放，四台重涂机的实体出勤许可剩三十天；接力护送万机馆到工务城后返回地面运输线，百刃、影子陪练与无牌一号留在地方支援池。

白鸢把两个行李箱、画筒和移动模拟器推到舷梯前。

纪存问：“你来时不是只取原稿？”

“现在我要找那把剪刀。”她把最重的箱子推给他，“临时乘员。桌子要放得下画板，房间别挨着儿童活动区。”

“为什么？”

“有些稿子不适合导览。”

纪存接住箱子，随即接通七海。问话已经结束，七海的公务卡仍停用，人却被调进四机事故的临时复核席。

“白鸢会跟船到工务城。”纪存说，“她查分镜盗用和白色采样体。”

“Evelyn Voss。”白鸢向屏幕抬手，“中文继续叫白鸢。”

七海把原稿调用材料直接发给她：“我能共享的都在这里。”

白鸢看着文件落进终端：“他介绍得这么正式，我差点以为上船要经过你。”

“他最好只是在通知我。”

纪存问：“你们已经有共同意见了？”

“有。”七海说，“他还欠一顿饭。”

白鸢看了纪存一眼：“原来就是她。”

她把临时舱门牌翻到空白面，写下`白鸢 / Evelyn Voss`，拖着行李进去。

接力在港外鸣响喇叭，先驶上通往工务城的航路。万机馆离开泊位时仍有轻微振动，却不再因热量被迫停下。完成低功率放行的四台重涂机分别掠过街区上空，用四条不同的航迹送它前往下一座城市。
