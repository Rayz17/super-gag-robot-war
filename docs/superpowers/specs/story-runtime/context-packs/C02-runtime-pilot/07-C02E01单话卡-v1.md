# C02E01《大船停在模型街外》单话卡 v1

## 本话唯一发动机

万机馆必须在旧港安全停泊，并找到一条不让木桶街停工也能取得主循环转子的现实办法；唐胶必须亲自走回自己离开的那条街。

## 本话开始状态

- 时间：离开原城约六小时后的中午。
- 万机馆：低速抵达木桶街，热循环不足，但不是倒计时坠毁。
- 馆守Z：位于万机馆舰首，缺右战斗前臂；黄色巡展臂可抓取、放锚、牵引。
- 纪存：前厅航行台，负责路线与现场汇合，不操纵万机馆内部机构。
- 唐胶、兜灯、跌跌和机器犬在舰内；七海仍在原城接受调查。
- 木桶街尚未承诺交出转子。

## 玩家在本话必须看懂的四件事

1. 万机馆是百余米巡展舰，木桶街是能接待这种巨物的旧巡展港。
2. 旧转子正在维持全尺寸仓、物流坡道和机械擂台，不能拿钱直接拆走。
3. 擂台冠军奖励的新散热机组可以接替旧系统；旧拳王获胜与唐胶公开真实维修参数，是置换成立的前提。
4. 缩尺模型只能提供结构思路和使用经验；兜灯与本地工务员必须完成全尺寸安全换算，已有实机无牌一号才会执行。

## 允许保留的疑问

- 唐胶为何离开木桶街，冯梅与他究竟发生过什么。
- 万机馆为什么会对某些旧巡展部件产生异常响应。
- 全尺寸仓深处的四台同骨架机为何同时苏醒。
- 港外白色小型单位是否与C01采样机同类。

## 场面顺序

### 1. 巨舰进入旧港

- 从木桶街普通人的视角先看见万机馆穹顶越过屋顶，建立规模、惊喜和一点荒诞。
- 火种货柜领袖以重型货柜车形态等在泊位；木桶街人称它“接力 / Relay”，不在正文反复使用材料定位名。
- 唐胶认出码头广播里的冯梅，却不接私人频道。

### 2. 泊位战

- 旧泊位尺寸足够，现代固定设施却无法直接接住万机馆。
- 海风把万机馆推向废弃大型吊塔，构成地图级危险，不写厘米校准。
- 货柜领袖完成第一次作业变形，撑开卡死的泊位门。
- 馆守Z以黄色巡展臂放下第二道锚；无牌一号清开泊位中的大型模块障碍。
- 玩家目标清楚：打开航道、固定舰首、让万机馆进入安全水域。
- 结果是完整成功，不附带“赢了但全错了”的结算。

### 3. 唐胶回街

- 冯梅先处理泊位费用和受损设施，再谈旧关系。
- 唐胶被旧摊主以不同态度认出，表现他过去确实生活在这里。
- 唐胶与兜灯的默契来自实际工作：一个看旧接口，一个看承力与停机条件。

### 4. 前店与后场

- 跌跌、机器犬和旧守护者的轮式终端参与生活观察。
- 同一条长街从模型病院、寄件台延伸到全尺寸仓，不再另造新地点。
- 纪存看到缩尺图、舞台巨构吊点和实机模块共享一部分设计祖谱，理解这里不是怀旧商场。

### 5. 看见正在工作的转子

- 转子位于共享散热系统内持续转动，热风和动力分配让三个区域同时工作。
- 冯梅让纪存看见“拿走”的现实后果。
- 唐胶只能从外观确认同源与维修痕，不能凭手感宣称适配。
- 擂台入口的新散热机组样机或宣传实体同时入画，提前建立冠军奖励。

### 6. 置换提案

- 冯梅说明：旧拳王代表木桶街赢得新机组，唐胶公开旧转子的真实维修参数，新机组稳定接管后，旧转子转给万机馆。
- 纪存先确认旧拳王是否仍愿上场，再接受合作。
- 开馆承担运输、首次装机和工务城校正资金，不是主题仪式。

### 7. 全尺寸教学

- 共享系统不停机，玩家用无牌一号更换一组大型外部导流模块。
- 三件缩尺样件分别体现牵引、稳定、侦测方向；玩家从使用磨痕和实际任务选择。
- 兜灯与本地工务完成全尺寸换算；无牌一号执行。
- 选择在E05形成不同支援，但本话三条均能完成任务。

### 8. 生活收尾与下一话钩子

- 七海远程出现一次，只提供生活温度和“仍在被调查”的事实，不解决木桶街冲突。
- 夜前，全尺寸仓深处的四台同骨架飞行机以不同动作醒来；只完整看清其中一台。
- 白色小型单位可在港外货列下短暂掠过，不确认身份。

## 主体与站位

| 场面 | 人物/机体 | 位置 | 控制权 |
|---|---|---|---|
| 入港 | 纪存、唐胶、兜灯 | 万机馆前厅航行台 | 自动航行系统执行，纪存选路线 |
| 泊位战 | 馆守Z、货柜领袖、无牌一号 | 舰首、泊位门、港区障碍区 | 旧守护者、货柜领袖本体、地方操作席 |
| 走街 | 纪存、唐胶、兜灯、跌跌、机器犬、轮式终端、冯梅 | 模型/修件街区 | 人物自由行动 |
| 后场 | 同上 | 全尺寸仓与共享散热观察桥 | 本地工务负责系统 |
| 教学 | 无牌一号、兜灯、本地工务、纪存 | 全尺寸仓外部作业位 | 地方临时开放操作，玩家给模块与路线选择 |
| 远程 | 纪存、七海 | 万机馆外甲板 / 原城调查等候区 | 普通私人通信 |

## 机体认识预算

- 完整首登：火种货柜领袖、无牌一号。
- 既有机体高光：馆守Z利用残缺右侧完成锚定。
- 预显：四台重涂机，只清楚看见喷气叛星，其余以不同动作与局部轮廓区分。
- 不登场：归一星、旧拳王本体、影子陪练、百刃、白鸢。

## 关系动作

- 纪存×唐胶：纪存不逼问旧事，但也不允许唐胶只当向导；置换谈判时让唐胶本人回答是否愿意交出真实参数。
- 唐胶×冯梅：熟悉、怨气和共同做过生意的事实同场，暂不完成清算。
- 唐胶×兜灯：泊位协作与全尺寸教学中互补；笑点来自专业习惯，不靠互骂金句。
- 纪存×七海：没吃成的饭继续作为生活事实，两个人都避免把关心说得太满。

## 语言与概念禁区

- 不使用“你可以……但别……”“今天先……但……”“不替谁背”“债务”“慢半拍”等旧句式。
- 不把转子写成权限、证书或资产条目之争；先让玩家看见它在转、街区在用。
- 不详细描写万机馆内部活动机构、毫米误差、十几个设备专名。
- 不用旁白宣布“修过也有价值”；让街、机器和具体选择表达。
- 不让纪存替旧拳王、货柜领袖或木桶街发表最终定义。

## 本话结束状态

- 万机馆取得临时泊位。
- 木桶街与万机馆达成清楚的转子置换提案，尚未兑现。
- 无牌一号完成首次全尺寸改装教学，章末留在木桶街。
- 木桶街开放临时整备与补给；接力与万机馆建立第一次协作，并解锁港区拖援。
- 唐胶同意回到旧工房查看完整记录，但尚未公开。
- 七海仍在原城。
- 四台重涂机与白色采样疑问发动E02。
