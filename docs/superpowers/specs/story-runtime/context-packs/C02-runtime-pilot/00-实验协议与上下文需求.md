# C02 Story Runtime 盲测协议与上下文需求

## 实验目的

从已经完成的 C01 连续故事出发，测试 Story Runtime 能否在不阅读现成 C02 场面稿、对白、逐话结构和审稿结论的情况下，组装足够稳定的写作上下文，并据此重新创作一版可连续阅读、逻辑清楚、机战感充足的 C02。

这不是“完全不知道 C02”的无约束即兴：

- 允许读取 L1、L2、世界机制基线和 L3 对 C02 的章级职责。
- 允许读取 Current Canon 中已经固化的人物、机体、机制与物理边界。
- 允许读取创作素材池、参战包、IP 精神、名场面、模玩生态和真实共鸣案例。
- 禁止读取当前 C02 Reader、Episode Reader、完整逐章总纲、导演板、战斗预案、审稿稿、问题账和现成场面顺序。
- 禁止检索 Current Canon 中的 C02 `scene` 节点；实体事实可以使用，但不得把实体说明里的旧场面动作直接当作新稿剧情。

## 章引擎

- 主角此刻最想得到什么：让刚离开原城的万机馆获得能继续航行的全尺寸主循环部件、安全泊位与第一批真正愿意同行的机器人伙伴。
- 唐胶此刻最想得到什么：从自己熟悉又不愿回去的模型/修件生态里拿到救命件，同时不让同行者看见自己曾经怎样帮助平台把修补史抹成“近似原装”。
- 对手正在主动做什么：平台、售后、寄售、直播与实体回收链正把短缺、争议和人格差异重新压成可定价、可复制、可强制回收的商品状态；白色采样链继续寻找可复制的机体与关系样本。
- 本章不可逆结果：万机馆取得真正重要的全尺寸部件，但仍需去工务城完成校正；唐胶公开一部分修件方法与旧责任；白鸢肉身到场并成为临时乘员；至少一台完整、可长期使用的机器人机体加入或建立稳定调用关系。
- 下一章如何被发动：新部件装上后无法只靠木桶街经验完成全尺寸校正，工务城成为现实必需的下一站，而不是又收到一封任务通知。

## 本章必须回答的问题

1. 木桶街为什么既能修模型，也能处理百米展舰所需的全尺寸部件？
2. 唐胶的模型手艺、民间修件史与陆衡以后承担的全尺寸工程职责有什么区别？
3. 模型、玩具和锚件怎样影响实机，但绝不凭空放大成巨型机器人？
4. 同骨架、同模具、重涂和改模为什么可以形成不同机体主体？
5. 旧拳王为什么是完整实机，如何通过战斗而不是维修单证明自己的魅力？
6. 白鸢的分镜怎样进入战术现实，为什么当前仍只是可讨论、可修改的预演，而不是画稿施法？
7. 平台、代哥售后、胶价主持、实体回收单位、白框采样与索引留痕分别是谁在做什么？
8. C01 的白色采样机钩子怎样推进，却不在 C02 就揭晓白框、索引和二十七年前全部真相？
9. 万机馆第一次抵达外地以后，玩家为什么会觉得世界突然打开，而不是换了一个地方继续维修和救援？
10. 纪存、七海、白鸢之间的关系怎样从 C01 的旧私交与缺席晚饭自然增加一个新变量，不能提前写成三角恋既成事实？

## 质量底线

- 先有连续故事和人物欲望，再有机制说明。
- 战斗必须由完整机体、明确对手、清楚空间和互斥目标推动；不得用模型盒、手套、扫描门、框体或标签冒充机战单位。
- 至少有一场能做 PV 的大开大合机器人战，不能全章都是救援、搬运、认证和十分钟倒计时。
- 可以有商品、维修、授权和平台生态，但常识后果先于术语；一场戏只让玩家理解一个关键控制变化。
- 不用“你可以……但别替我……”“今天先……也别……”“不替谁背”“债务”“语法”“槽”“锚”作为人物万能句式。
- 人物对白必须有听众、情绪、语气和生活反应；唐胶不说项目汇报，纪存不只做流程判断，七海不只给权限缝隙，白鸢不只画线。
- 不重复 C01 的撤离、城市救援和临时许可结构；木桶街的主快感应是发现、争夺、竞技、说得、改装和第一次公开开馆。
- 燃点、爽点、梗点、泪点、关系点都应来自同一条剧情因果，不能在结尾各补一段。
- 名场面和作品精神允许短引、误记、融合与原创变奏；不必假装所有原作表达都需要纠正。

## 必检索实体与主题

- 人物：纪存、唐胶、兜灯、旧守护者、七海、白鸢、跌跌、机器犬。
- 我方机体与舰体：万机馆巡展舰体、馆守Z、黄色巡展臂装、万机馆主循环部件。
- 候选机体：火种货柜领袖、喷气叛星、死锁式重涂、镜像重涂、远射重涂、旧拳王、影子陪练机、玩家模型机/全尺寸竞赛底盘。
- 阵营与执行链：木桶街修件生态、平台传播与交易、代哥售后/复产、实体商品回收、白框采样。
- 根机制：机魂本地涌现、主体连续性、模型/实机跨尺度译制链、万机馆馆藏关联、白鸢预演边界、G.A.G.文化行动反馈。
- 文化素材：变形生命与重涂人格、机器人拳击、模型维修史、限定与溢价、过度配件、未拆与手修之争、真实玩家家庭接续模型事业。

## 制作边界

- 主要可见空间控制在：木桶街巨构泊位、模型/修件街区、全尺寸寄售或物流仓、机械擂台、万机馆公共开放区。
- 新空间必须说明为何不能用已出现空间承载；不得边写边增加十几个“廊、槽、井、架、池”。
- 大机战动作使用一眼能懂的动词：追、变形、撞、挡、夺、起身、出拳、摔出界、护送巨件；不以厘米级关节动作承担高潮。
- 白鸢当前只能把纸面创作、现场信息和战术模拟整理成候选方案，真实动作由驾驶员、机体和工程链执行。
- 万机馆仍是低速巡展舰；不能变成人形、暴走、打拳或突然获得完整战舰火力。
- 馆守Z仍缺原装右前臂，黄色巡展臂只能抓握、固定和搬运；不得悄悄恢复右拳或常态飞行。
