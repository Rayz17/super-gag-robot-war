# C02E05《万机馆在木桶街开门》单话卡 v1

## 本话唯一发动机

木桶街的新散热机组、万机馆的第一次外地开馆、旧转子的转运和四台重涂机的实体召回在同一天发生；纪存必须让一场公开活动真正为街区和机器人带来生路，并在不伤害玛拉与归一星的前提下，把四台机和巨型转子一起带出被封死的物流坡道。

## 从E04继承

- 旧拳王已击败百刃，为木桶街赢得标准散热机组及安装服务，并自愿加入万机馆。
- 木桶街只有在新机组稳定接管全尺寸仓、物流坡和机械擂台以后，才能把旧式主循环磁流散热转子交给万机馆。
- 四台重涂飞行机已完成分机检查并拥有各自维护组，但身体仍属平台租赁批次。
- 玛拉已在庆祝结束前公开实体召回计划；重型回收车队已经停在港外。
- 白鸢只能提交基于传感数据的可修改路线，不可画什么就让现实发生。
- E01无牌一号模块与E05开馆重点产生机制差分；E02只决定直接操作的重涂机与专属台词；E04轻装/护甲只改变旧拳王外观及一次支援Cut-in，不改战斗主结构。

## 玩家必须看懂

1. 开馆不是讲话会。它带来真实观众、维修订单、合作方、转运费用和木桶街未来生意。
2. 旧转子是十余米直径的工业总成；只有新系统接管成功，它才会在玩家眼前停下并进入运输架。
3. E02只解决“四台机不能用一个动作安全落地”，没有解决租赁身体归谁；平台此次只用实体抱夹车、捕获索、道路封锁和共同装载架回收，四台机从头到尾保有身体控制。
4. 玩家保护移动中的巨型转子，并阻止任何一台重涂机被实体装车；身体内部的唯一危机来自战后“只读分机检查”被工厂擅自切换成批量恢复出厂。
5. 玛拉不是重新学习E02的教训。她从一开始就坚持分开、只读、维护组在场；工厂越过她的许可后，她立即拔掉实体安全钥匙并失去现场资格。
6. 转子装上万机馆不等于彻底修好；第二次运行出现舰体级振动，工务城因此成为下一站。

## 场面顺序

### 1. 万机馆第一次在外地开门

- 只开放现有主展厅的一段、外甲板和临时检修台，不凭空新增大展区。
- 玩家选择本次开馆重点：
  - 修补史：本话获得一次工房抢修，只恢复转子运输架安全值。
  - 变形与重涂：E02所选重涂机获得一次行动后协防。
  - 机器人竞技：本话由百刃提供一次托住坠柜的客将Cut-in。
- 三项共用一个互斥支援槽，不改变直接操作编成，也不会同时触发。
- 三站均可走到，选择只决定哪一站成为10至15分钟的主要可玩段。代表路线“修补史”必须包含检查商品页、实际承重测试、两种修法选择、观众质疑和一张当场生成的真实维修单。
- 展品包括谭国伟的旧拳王模型、被改乱的训练路线、四台重涂机各自修改后的说明页、馆守Z断臂后使用的黄色巡展臂，以及一件主人坚持未拆的同批收藏。
- 许岚只作为普通摊主继续交付补件，不把她的故事推成活动中心。
- 四台重涂机各取得一份带订金的地方项目；结算不逐项念账，只让玩家看见“旧转子转运押金已付”。
- 纪存不发表主题演说。他负责接待、回答具体问题、安排检修预约，并第一次看见万机馆能给下一站以外的人留下持续工作。

### 2. 一件冠军奖品真的接管街区

- 新散热机组在全尺寸仓启动，玩家通过三处可见负载确认接管：仓内吊装恢复、物流坡制动稳定、擂台维护层温度下降。
- 地下旧转子的转速逐渐下降，木桶街没有停电、停工或清场。
- 冯梅确认三处都在工作，才下令拆开旧系统外壳。
- 十余米巨环被吊上专用运输架。开馆收入、维修订单预付款和合作押金支付运输、首次装机与工务城校正的启动费用。

### 3. 实体召回进入现场

- 玛拉先公开重申她在E02后提交的执行条件：四台分开检查、维护组在场、只读诊断、不恢复出厂。四台仍拒绝自愿装车。
- 港外折桥仍在观众撤离模式，重载支撑尚未复位；物流坡是当前唯一通过重载认证的通道。平台为赶在四份项目生效前回收，拒绝等待傍晚，主动征用坡道。
- 四台重型拖车使用实体抱夹臂、低速捕获索和道路封锁抓机，不访问机体内部控制。共同装载架与转子运输队争夺同一条坡道。
- 玩家必须保护移动中的转子运输架，并阻止任何重涂机连续两回合被抱夹固定。不能用近防炮。

### 4. 群机大战：把坡道打开

- 地图复用E01巨构泊位、物流坡和万机馆外甲板，但目标从“把舰停稳”反转为“让伙伴和巨件一起离开”。
- 玩家直接控制馆守Z、旧拳王和E02所选重涂机；接力是移动护送目标，其余三台重涂机为自主友军。
- 转子运输架分三个区段移动：当前方道路清空，接力于回合末自动前进一段。
- 馆守Z拖开共同装载架，旧拳王以近身步法拆抱夹梁；归一星保护回收车但不得成为击坠目标。
- 四台重涂机不再重演E02的“分别拿回动力”，而是交换战场职责：断索、顶住运输架、引开拖车、打断路障。
- 只有选择“机器人竞技”时，百刃与阿列克斯才以一次客将Cut-in撑住坠落货柜；代表“修补史”路线改由无牌一号与本地吊车处理同一事故。
- 无牌一号回收E01模块选择：
  - 牵引框：拉回唯一重坡一侧脱位的备用承重板；
  - 双层支架：代表路线，顶住承重板并替运输架分担一次侧撞；
  - 高位感应翼：提前标出白色采样机脱离位置。
- E04轻装/护甲只替换旧拳王拆抱夹梁的Cut-in与外观，不改变地图路线、敌军波次或结算。

### 5. 白鸢实时修正路线

- 白鸢沿用E02建立的固定三层图：白色原始意图、黄色现实限制、绿色经机体/驾驶员/工务员确认的可执行段。
- 路线一开始便避开前店与观众出口；接力只补充最后一次巨环转弯半径，本地工务员确认后转绿。不再重复“漂亮路线被划掉”的人物课。

### 6. 只读检查被换成批量重置

- 实体装车失败后，玛拉主动停下归一星，坚持在现场用四台分开的设备做只读检查。四台机在维护员陪同下自愿接线。
- 玛拉插入实体安全钥匙只为检查供电；工厂监督员利用已接通的电源，把四套独立设备切入共同装载架的恢复出厂程序。
- 四台机的本地安全校准依次消失：维斯珀的裂纹保护、洛克的关节限幅、逆镜的非对称姿态补偿和凯斯特的视野偏差被改回默认。
- 玛拉立即拔掉钥匙。代价是现场安全资格暂停、归一星锁舱并接受调查；擅自把只读改为写入则自动触发四项独立事故复核。
- 纪存停止刚争来的转子吊装，把外甲板、吊装设备和工务员先让给四支维护组，承担延误安装的现实代价。
- 四组维护员使用E02分机检查时保存的独立备份恢复本地校准，并完成低功率放行；共同结构裂纹仍留待次日检查。
- 木桶街支援关系永久开放；四台机的实体出勤只获得三十天临时许可，后续必须解决产权与结构问题。

### 7. 白色采样链再次出现

- 四机恢复各自备份时，一台无标志白色采样机从共同装载架底部脱离，扫描四种故障和四种恢复动作后逃往港外。
- 机器犬咬下同C01白色采样身体一致的外衬材料。
- 若E01选择高位感应翼，玩家能提前发现并多取得一段去向信息；其余路线仍取得材料，不在本章抓住采样机。
- C01实物仍由原城保管，本话只与原城传来的材料谱和断面扫描比对。

### 8. 把巨环装进万机馆

- 夜里，转子运输架进入万机馆已有检修窗口。
- 动画只表现巨环被吊起、装入旧接口，舰体灯光由后向前依次恢复，整艘船第一次长时间保持稳定；不展示密集内部机构。
- 既有安装位锁定、外部复接和静载检查完成后，第一次低速试转成功，万机馆能在不继续积热的情况下离开泊位。
- 重复运行时，舰体出现能被所有人看见和听见的低频振动。木桶街能把旧件修好并装上，却无法完成百米展舰的整体校正。
- 冯梅把工务城公共泊位坐标交给纪存，C03成为现实需要。

### 9. 离港与关系收尾

- 旧拳王登舰，谭国伟保留缩尺模型和远程教练席。
- 白鸢发现采样机切分现场数据的顺序与自己分镜被盗裁的顺序高度相似，以此作为个人调查线索成为临时乘员；她带的是行李和工作，不是被纪存一句邀请收编。
- 接力护送万机馆前往工务城后返回地面运输线。
- 四台重涂机、百刃、影子陪练和无牌一号留在木桶街，成为可召回地方支援。
- 纪存主动接通七海，正式介绍白鸢成为临时乘员及其调查范围；七海把原稿调用材料直接交给白鸢，三人第一次在彼此知情的情况下同场。
- 七海的问话已经结束，公务卡仍停用，当前在四机事故临时复核席；未吃成的饭只作为一句私人打趣。

## 战斗与玩法

- 前半：三站有限开馆，其中一站成为10至15分钟可玩段；随后完成新旧散热系统交接。
- 主战地图：巨构泊位 + 物流坡 + 万机馆外甲板。
- Boss：归一星第二战；四台重型抱夹车、共同装载架和实体捕获索是地图压力，不新增万能形态。
- 直接操作单位：馆守Z、旧拳王、E02所选重涂机。接力为移动护送单位，其余重涂机为自主友军。
- 我方主目标：让转子通过三个坡道区段，阻止任一重涂机被抱夹固定两回合，并迫使实体回收停止。
- 失败条件：转子运输架坠落；任一重涂机被装入恢复出厂架；玛拉驾驶舱遭致命攻击；观众区受重型事故波及。
- 战中阶段：
  1. 实体抱夹车封坡并分头抓机；
  2. 群机交换职责，护送移动转子穿过三个区段；
  3. 玛拉停战并转入四台分开的只读检查；
  4. 工厂偷换为批量重置，玛拉拔钥匙，玩家完成四机恢复。
- 章末：巨件吊装与双次点火测试。

## 机体认识预算

- 归一星：完成“统一工厂动作很强、驾驶员职业判断也真实”的第二次兑现。
- 四台重涂机：各有独立战术动作，E02玩家选择产生可操作差分。
- 馆守Z、接力、旧拳王：承担主力战法。
- 百刃：仅在“机器人竞技”支援槽中以一次高成本客将Cut-in回收全装英雄感，不长期占用本话操作预算。
- 无牌一号：回收E01改装选择。
- 白色采样机：只推进谜团，不抢Boss位。

## 关系动作

- 纪存×白鸢：从授权合作推进到共同工作与登舰；纪存主动把她介绍给七海，不让关系信息成为偷看或误会的偶然产物。
- 纪存×七海：远程生活联系继续，七海把调查材料直接交给白鸢，三人第一次公开知情同场。
- 唐胶×兜灯：开馆时由唐胶判断修法、兜灯做承重验证；转子首次成功后由唐胶主动要求第二次测试，兜灯同意受控加速并握住停机柄，完成一次角色位置反转。
- 唐胶×冯梅：冯梅承接公开记录与报价；转子测试后，三人与万机馆建立远程复核窗口，仍不和解成一场拥抱。
- 玛拉×四机：她保留结构风险调查职责，也第一次为四台机的本地状态承担职业决定。

## 语言与概念禁区

- 不用“开馆权”“证词”“债务”“让权”替代具体行动。
- 不让角色朗读产权哲学；用回收车辆、身体失控、维护组、工厂复位和临时项目表达。
- 不把白鸢写成画一条线就改变现实。
- 不把玛拉写成看见友情便叛变。
- 不用微小时间、距离或机械细节制造虚假紧张。
- 不在转子装舰时发明新的内部空间、导轨或零件名。

## 本话结束状态

- 主循环磁流散热转子已装入万机馆；单次点火成功，重复运行振动，必须前往工务城。
- 旧拳王正式随舰，接力临时护航，白鸢成为临时乘员。
- 木桶街地方支援位永久解锁；四台重涂机保住现有身体与维护组，获得三十天实体出勤许可，留在木桶街作为限期可召回支援。
- 百刃、影子陪练、无牌一号留在地方支援池。
- 木桶街获得新散热系统、持续订单和与万机馆的远程维护关系。
- 白色采样链确认在不同地点反复收集机体协作数据。
- C03以全舰校正和长期推进可靠性自然发动。
