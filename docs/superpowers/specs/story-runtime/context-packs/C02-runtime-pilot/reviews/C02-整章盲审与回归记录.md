## 首轮整章结论

四位独立审稿职责分别从连续性、机器人文化与玩法、人物关系与娱乐性、可制作性与玩家可见性审查五话，均判定无需整章重写，但存在跨话级`TARGETED_REVISION`：

- E05重复E02的返航接管与发射器破坏，E02结果没有改变下一次冲突。
- 小满、阿澄从原城留守状态无解释地肉身出现在木桶街。
- 三天内的“明天、昨晚、昨天”互相冲突。
- 四台机在重置受损后没有恢复校准便飞行送别。
- C01白色衬片由原城保管，E05却凭空出现实体。
- E05缺少明确的直接操作预算、移动目标和可视失败条件，开馆仍偏菜单与蒙太奇。
- 白鸢连续多话重复“漂亮方案被现实划掉”，七海反复使用饭梗，唐胶与兜灯关系没有质变。
- E05分支组合过多，支援单位堆叠；战后尾声过长。

## 章级返修

- 锁定三日历法：D1为E01/E02，D2为E03/E04，D3为E05。
- E05取消返航中继与动力接管，改为实体抱夹、捕获索、道路封锁和移动巨环护送战；四台机全程保有身体控制。
- 只读分机检查被工厂暗中切换成批量恢复出厂，成为本话唯一内部控制危机。玛拉拔掉实体钥匙并失去现场资格。
- 纪存停止刚争来的转子吊装，把整备资源先交给四支维护组；四机用E02独立备份恢复校准并完成低功率放行。
- 小满、阿澄改为从原城远程导览，本地志愿者执行实体疏散。
- C01白色衬片只通过原城传来的材料谱和断面扫描比对。
- 开馆改为三站体验，一站形成10至15分钟实操；三项开馆重点共用一个互斥支援槽。
- 直接操作固定为馆守Z、旧拳王和E02所选重涂机；接力为移动护送单位，另外三台重涂机为自主友军，百刃只在拳台支援路线提供一次Cut-in。
- 白鸢形成“E02建立三层图、E03先问身体、E04贡献独立判断、E05熟练使用并取得个人调查线”的递进。
- E04把七海关系动作改为识别纪存紧张时的旧习惯；E05明确她问话结束、卡仍停用并进入事故复核席。
- 转子第二次测试改由唐胶主动提出、兜灯批准受控升速。
- E05冲突后尾声压缩为采样钩子、装机复测、旧拳王与白鸢登舰、七海交接和离港。
