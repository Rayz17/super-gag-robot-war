# C02E04 盲审与返修记录

## 首轮结论

两名独立审稿人均判定为 `TARGETED_REVISION`，无需重写。

共同高严重度问题是：旧拳王最后把百刃打出界以后，百刃仍可用推进器回场，胜负实际由阿列克斯是否顾及观众决定，玩家的战术没有形成真正将杀。

其余问题包括：

- 教练、玩家、旧拳王本地AI和安全席的控制权在关键动作中混淆。
- 18米对22米公开组缺少载荷、输出、推进与观众安全规则。
- 战斗更接近线性QTE，轻装与护甲没有各自完整行动链。
- 白鸢独自给出装备和路线方案，越过自然职能边界，并伴随作者自证式旁白。
- 影子资格赛的通过标准、赛后检查与安全值重置不清楚。
- 百刃的主体性到赛后握手才突然出现。
- 唐胶与冯梅没有完成单话卡承诺的共同庆祝。
- 旧转子转交缺少E01约定的独立复核条件。

## 定点返修

- 赛前公开规则：不按身高分级，限制总载荷、单次冲击、远射输出和推进时长；地图提前显示八个方向区、两处换装口与两片禁喷红区。
- 玩家在前两轮主动逼百刃转盾、远射和推进，积累热量，再把它诱进背朝观众的禁喷区。
- 百刃换装时收回稳定腿并交出一面肩盾；旧拳王只负责把已经失衡、临界出界的对手送出去。推进联锁随后生效，阿列克斯的安全选择不再决定胜负。
- 锁定四层权限：谭国伟报建议，玩家下战术指令，旧拳王AI确认执行，兜灯只做安全否决与停机。
- 影子资格战改为三个方向的安全有效命中，结束后完成结构检查并重置安全值。
- 轻装路线利用八方向区和肩盾；护甲路线包含承伤进入、主动抛腿甲恢复横移、掷胸甲干扰副臂。
- 唐胶、兜灯和谭国伟分别提供热量、安全区与防守节奏，白鸢只把信息整理成候选走廊，最后一格保持空白。
- 百刃在巡场、装备决策、转入拳战和赛后握手中连续表现主体性。
- 唐胶把真实现状图交给冯梅，两人共同决定胜利巨屏的最终画面。
- 两组本地修件师按唐胶的新记录独立复核旧转子，完成最后一项转交条件。
