# C02E02《同一副骨架，四种逃法》单话卡 v1

## 本话唯一发动机

四台长期生活在木桶街的同骨架飞行机拒绝被送回工厂重置，却在逃离时被体内的厂商紧急返航程序强行拖向同一条航线；纪存必须先让四副身体分别安全落地，才有资格继续谈它们是谁。

## 从E01继承

- 万机馆已取得临时泊位，但尚未拿到转子。
- 货柜领袖与万机馆共同完成过一次泊位协作。
- 全尺寸仓内四台同骨架飞行机已经醒来。
- 玩家已经看懂模型经验必须经过全尺寸工程转译，不能在本话退回“画一张图便控制现实”。
- 七海仍在原城，白鸢尚未与纪存见面。

## 先锁死的简单机制

### 四机拆了什么

四机拆掉的是平台为了第二天装车而临时加装的磁性运输标签和外部锁止夹，不是体内的厂商安全模块。标签被拆后，它们能自行起飞；厂商紧急返航程序仍在身体里，归一星可以凭现场回收凭证启动。

### 归一星能做什么

- 归一星是玛拉驾驶的实体回收机。
- 它能启动同厂机体内置的紧急返航程序，并读取共同的出厂动作库。
- 它不能读取后天记忆、复制人格、瞬间控制所有机器人或代表索引。
- 它的捕获翼和返航发射器位于外部，能够被非致命击毁。

### 白鸢的分镜怎样有用

- 四台飞行机原本参与过一项取消的商业动画/现场表演企划，白鸢为它们分别画过四种落地结尾。
- 平台后来将纸面动作合法数字化为表演模拟素材，却删成一条便于统一拍摄和回收的中央路线；白鸢正因盗用和剪裁追到木桶街。
- 她带来的原稿不是导航地图。地方工务先把港区传感与地形送入公共模拟器，模拟器再将四种动作意图映射成候选落地点。
- 本话固定白鸢的三层图语法：白色保留她的原始意图，黄色记录实时限制、危险与具名异议，绿色只显示已经得到机体/驾驶员/本地工务员确认的可执行段。绿色仍是候选，不直接驱动机体。
- 第一次候选有一条撞上已停用吊塔，必须由货柜领袖、地方驾驶员和机体自己否决并重算。
- 最终执行者仍是四台机体、地方操作员和玩家。

## 玩家必须看懂

1. 四台机拥有共同身体来源，也各自积累了七年的改装、关系和判断。
2. 玛拉的安全担忧有现实依据；四机擅自起飞确实可能撞入人口区。
3. 战斗不是用拳头证明人格，而是先夺回身体控制、分别落地，再让人工复核成为可能。
4. 白鸢是一位追着自己的作品来到现场的成年人，不是天降军师。

## 场面顺序

### 1. 货柜领袖与喷气叛星

- 早晨或午后，全尺寸仓准备对四机做装车前检查。
- 货柜领袖劝它们先分别接受本地维护组检查，再共同拒绝恢复出厂。
- 喷气叛星认为“先检查”最终仍会变成“先装笼”，撕掉运输标签冲出仓顶。
- 首场只让玩家完整认识领袖与喷气叛星。

### 2. 另外三种逃法

- 死锁式机不追随喷气叛星，选择切开地面装笼夹具。
- 镜星关掉平台敌我标识，导致门禁短暂误判；它优先替维修工打开安全门。
- 雷翎先升到高位侦察，标出人口区与安全空域。
- 三机各自在改变局势时获得名字和清楚轮廓。

### 3. 玛拉与归一星

- 玛拉按既定现场复核计划抵达，展示批次断裂记录与实体回收凭证。
- 她允许本地维护组跟随，却不能放任四机从人口区上空飞走。
- 归一星起飞，先以专业、克制的方式封锁空域，不作邪恶亮相。

### 4. 返航程序造成碰撞

- 纪存尝试让四机分别降落。
- 归一星启动体内紧急返航程序，四机同时做出同一套返航转身，正在挤向一条中央进场线。
- 立即危险可见，和平谈判暂时失去物理条件。

### 5. 白鸢抵达

- 白鸢从活动直播台或场务通道追到现场，先认出平台使用的是她被删改的分镜。
- 她与纪存第一次碰面就是争抢同一块终端：她要留住盗用证据，纪存要先救下进入第三格危险区的机体。
- 两人达成临时合作，不完成授权和关系和解。

### 6. 空地追逐战

- 地面：货柜领袖清空货道、撑开落地空间。
- 港区：馆守Z用黄色巡展臂固定无人吊塔，不能飞行追敌。
- 空中：玩家临时选择一台重涂机直控，其余三台作为有明确目标的友军。
- 白鸢原稿进入公共模拟器；第一条路线因吊塔仍处于黄色风险层，接力与地方驾驶员确认后，安全段才逐段转绿。

### 7. 相同开场，不同结尾

- 归一星预测四机共同的出厂开场。
- 喷气叛星把撤离动作改成折返保护；死锁把斩击改为锁住捕获翼；镜星用错误标识掩护真实落点；雷翎故意射偏切断牵引索。
- 纪存只提供战术判断：“别跟它抢开场。用你们后来学会的结尾。”

### 8. 停机与余波

- 玩家击毁归一星外部捕获翼与返航发射器，不攻击玛拉驾驶舱。
- 四机分别落入有维护组的安全区，玛拉停止空中强制回收，改为分机复核。
- 玛拉保留身体产权和统一整备主张，为E05埋下第二轮冲突。
- 白鸢取得完整使用记录，进入万机馆公共区查证；行李尚未正式搬上舰。

## 战斗与操作

- 地图：全尺寸仓、物流坡道、港区空域、分布在三个区域的四个安全落地格、一座大型无人吊塔；万机馆外货台是纪存主动开放的第四落点。
- Phase 1：仓内突围，货柜领袖主控。
- Phase 2：返航程序启动，玩家取得一台机体主动开放的战术协作；只选择航点、动作结尾和目标优先级，不接管其身体。
- Phase 3：破坏归一星捕获翼/返航发射器，让四机分别降落。
- 胜利条件：四机全部安全落地，且归一星驾驶舱未遭致命攻击。
- 失败条件：任意两机在中央进场线发生碰撞，或机体坠入人口区。

## 新机体认识顺序

1. 喷气叛星：异议者，高速。
2. 死锁式重涂机：近战、改模身份冲突。
3. 镜星：镜像配色与电子标识。
4. 雷翎：远射、侦察。
5. 归一星：专业实体回收机。

四机共享基础骨架和出厂开场，必须以头部、翼型、武器、声音和结尾动作区分。

## 关系动作

- 纪存×白鸢：互相误读、近距离共同看终端、临时合作；白鸢确认纪存保留了作者名，但仍追究未经同意的使用。
- 纪存×七海：七海只远程确认“现场凭证能启动厂商安全模块，她无法替平台撤销”；随后退出本话主场。
- 货柜领袖×四机：它保护同族但不要求服从，喷气叛星可公开反对它。
- 唐胶×木桶街：唐胶从不同修补痕一眼区分四机，证明他过去确实参与其生活，却不据此宣称拥有它们。

## 语言与概念禁区

- 不使用“一个编号不等于一个人”作主题宣讲；用四台机的动作让玩家先看懂。
- 不把分镜称为战场改写、现实出口、未来路线或控制语法。
- 不把归一星写成病毒、弹窗或全知AI。
- 不靠标签/文件在战中直接获胜；实体动作先把危险停下。
- 不让全部五台新机同时自报姓名、履历和立场。

## 本话结束状态

- 四台重涂机分别安全落地，留在木桶街接受本地维护。
- 平台空中强制回收暂停，租赁产权与恢复出厂争议未解决。
- 归一星受外部损伤但未被摧毁；玛拉保持职业立场。
- 白鸢正式进入故事，与纪存建立未解决的授权冲突和合作可能。
- 货柜领袖成为可在后续战斗调用的地方盟友。
- 归一星已取得四机本话动作样本，仍只能学习发生过的动作。
