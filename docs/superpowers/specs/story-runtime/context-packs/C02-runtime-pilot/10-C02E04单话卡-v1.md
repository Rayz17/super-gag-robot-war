# C02E04《拳王输过》单话卡 v1

## 本话唯一发动机

旧拳王必须用自己输过、修过、老化过以后形成的身体，击败保存其最佳动作的影子陪练和真正强大的全装冠军百刃，为木桶街赢得替代散热机组。

## 从E03继承

- 旧拳王已退出怀旧表演组，进入同样有维修级冠军奖励的公开组。
- 唐胶与冯梅已公开部分维修史并承受价格与信任损失。
- 谭国伟是教练席，兜灯掌物理安全与停机，旧拳王自控身体，玩家给步法、格挡、目标和时机。
- 白鸢已在E03先读取旧拳王当前限制，只验证过一段左横移；她不会指挥旧拳王。
- 百刃与阿列克斯已完整亮相，并被证明真强。
- E05的四机实体召回尚未发动，但玛拉仍在木桶街处理分机检查。

## 玩家必须看懂

1. 影子陪练只记得发生过的动作与反击窗口，不是幽灵或预知AI。
2. 百刃的全装美学、火力与换装能力都是真的；最后代价来自场地、热量和转身，不是“配件多就错”。
3. 旧拳王不是靠观众眼泪、维修网页或秘密外挂获胜；玩家要读距离、挨打、改装和时机。
4. 冠军奖励在E01已公布，本话赢下的新散热机组会真实安装在木桶街。

## 场面顺序

### 1. 赛前生活与整备

- 机械擂台观众真实兴奋，胶价主持尝试包装“原装传奇”，被补板与公开资料自然拆穿。
- 唐胶与兜灯完成护具和止动检查；护具只让旧拳王合规，不提高拳力。
- 谭国伟的少年模型放在教练席，不成为战斗钥匙。
- 百刃全装巡场，让观众先喜欢它。

### 2. Phase 1：影子资格战

- 影子陪练使用旧拳王历年最漂亮动作和相应反击窗口。
- 玩家照标准提示输入便会连续被截断。
- 必须主动关闭连招提示，使用E03训练中保留的不漂亮横移，才首次命中。
- 关闭提示是玩家动作，不是角色一句话自动获胜。

### 3. Phase 2：百刃全装压制

- 百刃以远射、副臂、肩盾和背包推进形成真实优势。
- 旧拳王第一次被击倒；读秒保留机器人拳击共同记忆。
- 百刃临时展开稳定副腿，封住赛前绕行判断；白鸢不重复受教，而是从巡场和比赛画面中独立看出：百刃离开背包推进后，过量装备会拖慢换向，禁喷区因此能成为战术核心。
- 玩家必须在边界、掩体和装备投放位之间撑过第一轮。

### 4. 中场选择

- 保持轻装：保留旧拳王熟悉步法，承伤更高。
- 临时护甲：更容易撑过火力，最终必须主动抛甲才能完成前踏。
- 两条都能赢，不把玩家审美判成正确或错误。
- 代表路线为轻装。

### 5. Phase 3：最后一拳

- 玩家在前两轮逼百刃反复转盾、远射和推进累积热量，再诱导它背朝观众进入预先标示的禁喷红区。
- 百刃在边界换装时收回稳定腿、交出一面肩盾；唐胶、兜灯和谭国伟提供结构与步法信息，白鸢贡献禁喷区画面判断，并用白/黄/绿三层图整理成候选走廊。
- 谭国伟放弃旧口令，玩家选择向内前踏并下达左刺拳、右直拳时机，旧拳王确认后执行，把已经失衡的百刃送出界。
- 推进联锁禁止百刃在红区点火；强制越权会直接判负。阿列克斯保留安全底线，但胜负已经由玩家战术决定。
- 读秒结束后，旧拳王把百刃拉起。

### 6. 胜利充分呼吸

- 观众、木桶街工务和万机馆成员完整庆祝，不立即送来一张惩罚单。
- 维修级冠军的新散热机组与安装服务正式归木桶街。
- 胶价主持想剪成原装复活，镜头先拍清补板；商业前台开始学会另一种卖法，但不代表生态被一战改好。

### 7. 旧拳王选择后续

- 谭国伟与冯梅不把旧拳王当作转子付款物。
- 旧拳王自己表示愿意随万机馆巡展，继续寻找不同规则的拳台。
- 木桶街保留维护关系与远程训练；旧拳王成为长期可操作战力。

### 8. E05前置

- 新机组开始运入全尺寸仓，旧转子将于接管后停转。
- 玛拉收到平台正式的四机实体召回计划，并在开馆前公开告知纪存和四支维护组。
- 回收车辆在港外入场，不能到E05才凭空出现。

## 战斗

- 地图：一座大型机械擂台；内圈、中圈和出界带沿圆周分成八个方向区，两处换装口和两片禁喷红区清楚，百刃的盾墙、远射区与副臂控制会动态改写通路。
- Phase 1 Boss：影子陪练。
- Phase 2/3 Boss：百刃。
- 胜利：百刃出界读秒或倒地读秒完成。
- 失败：旧拳王无法站起、护具安全值耗尽，或攻击驾驶舱致命区。
- 核心玩家动作：关闭自动连招、选择中场装备、前踏/后撤、触发最后一拳。

## 机体认识预算

- 旧拳王：从训练单位升级为本话主力与正式加入机。
- 影子陪练：正式战斗功能完整兑现，章后留木桶街。
- 百刃：全装性能完整兑现，章后成为友好宿敌。
- 馆守Z、接力和四台重涂机只在观众/整备/支援Cut-in中出现，不进入擂台代打。

## 关系动作

- 唐胶×兜灯：中场共同决定轻装/护甲；专业信任比碰手脸红重要，同时保留轻松火花。
- 纪存×白鸢：纪存把完整比赛画面交给她；白鸢提出一项别人没看见的禁喷区战法，第一次不只做信息整理。
- 纪存×七海：七海从远程画面认出纪存紧张时捏住终端边角的旧习惯；不再重复吃饭提醒，也不介入比赛。
- 唐胶×冯梅：两人第一次共同庆祝一件没有被包装成原装的胜利，关系仍未和解。

## 语言与概念禁区

- 不让角色讲“失败也是价值”。
- 不使用“慢半拍”“几秒窗口”“一厘米前踏”等芝麻量级称道。
- 不把拳击写成工程术语连发；用站起、挨打、距离、换装和出界表达。
- 不让百刃驾驶员狂妄降智，也不让全装机因一颗螺丝输。
- 不在胜利后立即宣布索引因此更强或玩家做错。

## 本话结束状态

- 木桶街赢得标准散热机组与安装服务。
- 旧拳王正式成为长期可操作机体，并选择随万机馆巡展。
- 百刃与阿列克斯保留为地方友好宿敌和后续支援。
- 影子陪练留在木桶街，开放训练功能。
- 新机组开始接管准备，旧转子转运进入现实阶段。
- 四机实体召回计划可见地进入港区，直接发动E05。
