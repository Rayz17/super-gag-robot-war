# C02E03《旧拳王没有原装漆》单话卡 v1

## 本话唯一发动机

唐胶必须打开自己封了多年的旧工房，并决定是否把旧拳王与旧转子的真实修法交给别人；一旦公开，旧拳王会失去怀旧表演组资格，却也第一次能以真正的身体参加比赛。

## 从E02继承

- 万机馆取得临时泊位、整备和接力拖援，尚未拿到转子。
- 旧拳王若为木桶街赢下公开赛，冠军奖励的新散热机组可替代旧转子。
- 唐胶已承诺打开旧工房、找齐原始量值并现场补正。
- 四台重涂机分别落地，仍留木桶街；平台召回争议延后。
- 白鸢进入万机馆公共区取证，尚未成为乘员。
- 七海仍在原城，本话不需要远程出场。

## 玩家必须看懂

1. 唐胶的手艺曾救过很多物件，也曾因模糊记录被市场拿来抬价；他既不是纯受害者，也不是秘密造假的恶人。
2. 缩尺旧拳王模型保存的是试修、装配与人的使用痕迹；真实旧拳王本来就存在，不由模型变大。
3. 公开维修史会产生可见损失：价格变化、寄售者质问、旧拳王改组、唐胶不再垄断修法。
4. 母亲接续儿子订单只是一段具体生活，不是钥匙、战斗外挂或主题证明。

## 场面顺序

### 1. 旧工房开门

- 唐胶、冯梅和兜灯打开木桶街旧工房。
- 现场有两套长期并存的记录：唐胶的内页细记与更好卖的公开标题。
- 唐胶先处理转子的原始量值，再发现旧拳王与一批寄售物也沿用了相同模糊写法。
- 冯梅与唐胶用具体订单争执，不做互相洗白的忏悔戏。

### 2. 母亲继续一个普通订单

- 采用虚构化合成角色，正式公开前再完成真实来源与致敬审核。
- 她正在拆支撑、打孔、重做儿子去世前留下的一批普通模型零件订单。
- 唐胶把一个新孔认成她儿子的旧做法，她纠正：“这个孔是我打的。旧图写他的，新工序写我的，分开记。”
- 她不参与主冲突，只让“记录修补”落到一种真实生活中。

### 3. 盒内名字与退休教练

- 一个旧拳王模型已在工作台拆开，内甲上能自然看见退休教练谭国伟少年时写的名字，不发生隔着盒子看内侧的错误。
- 唐胶认出自己修过的卡扣；公开商品页却把它写成未修复旧版。
- 谭国伟到场后先问卡扣还能不能再开一次，不先为童年落泪。

### 4. 真实旧拳王登场

- 机械擂台维护层升起18米级旧拳王，补板、旧伤和不同年代护具清楚可见。
- 旧拳王拥有本地拳击AI和自己的平衡判断；谭国伟是教练席，兜灯负责物理安全与停机，玩家给步法、格挡、目标与出拳时机。
- 影子陪练机播放旧拳王的训练和失败窗口，不是亡者灵魂。

### 5. 唐胶公开方法

- 唐胶把测量模具、材料替换、可复做步骤和仍不确定的位置摆上公共工作台。
- 本地修件师当场复做一处，发现其中一项旧手法并不完美，唐胶允许修正进入新版本。
- 冯梅同步公开自己改过的商品标题，并接受一批寄售物重新估价。

### 6. 可见代价

- 几名寄售者质问，部分物件价格下降；也有人要求补回维修史。
- 旧拳王因替换髋件、非原装拳部执行器和多次结构修改，退出怀旧表演组。
- 它仍有资格进入维修级奖励所属的公开组，对手从表演机变成全装冠军百刃。
- 路变难，但奖品与胜利可能没有被作者拿走。

### 7. 白鸢先问机体现在能怎么动

- 白鸢沿用E02的三层图，但不先画完整打法。她主动请谭国伟标出右髋死角、请兜灯标出护具上限。
- 旧拳王修完右髋后只做一次受控左横移，验证那一步真实可用；不在本话完整关闭连招或击败影子。
- 经旧拳王、教练和安全席确认后，图上只有一小段由黄转绿。完整战术留给E04。

### 8. 对手钩子

- 影子陪练用旧拳王曾经最漂亮的动作站到对面。
- 百刃只在结尾完成全装亮相或开机，不提前打完E04。
- 旧拳王自己走向拳台门，确认愿意参赛。

## 玩法

- 旧工房探索：对照内页、公开标题和实体修痕。
- 补件分拣：普通订单与可选现实共鸣。
- 旧拳王训练：维修后的单步验证；完整关闭连招、格挡与反击教学留给E04。
- 开馆准备：玩家选择是否征得本人同意后展示某件修复史。

## 机体认识预算

- 完整首登：旧拳王、影子陪练机。
- 结尾预显：百刃。
- 四台重涂机只作背景维护状态，不重复抢首登。
- 馆守Z、接力和无牌一号不需要战斗。

## 关系动作

- 唐胶×冯梅：公开各自做过的具体事，几乎决裂；两人仍一起完成复做，不和解。
- 唐胶×兜灯：兜灯把不外借的止动量具放上公共工作台，唐胶主动让出一半位置。
- 纪存×白鸢：纪存不催她授权展览；她已经学会先问现实边界，再决定画什么。关系由对彼此工作方式的改判推进，不提前恋爱化。
- 纪存×木桶街：他让第一次开馆展示取决于物主和维修者是否愿意，而不是替他们定主题；同时必须保留主动组织和经营能力。

## 语言与概念禁区

- 不用“修过也有价值”作人物宣言。
- 不用“你可以……但……”“不替谁背”“记录就是生命”等整齐金句。
- 不把真实母亲角色写成理解一切的贤者。
- 不把公开网页、价格或比赛分组写成行政流程；要让人当场失去钱、资格或轻松路线。
- 不把白鸢的分镜写成战斗现实修改。

## 本话结束状态

- 唐胶公开部分可复做修法，失去个人垄断与一部分旧同行信任。
- 冯梅公开自己参与过的商品标题改写，木桶街开始补修史。
- 旧拳王转入公开组，下一话将对战影子陪练与百刃。
- 谭国伟、兜灯、旧拳王和玩家的操作分工清楚。
- 白鸢从E02的“允许别人修改”推进到本话“落笔前主动索取限制”，不重复上一话人物课。
- 真实母亲与旧拳王模型是否进入E05展项，保留为经本人同意的支线选择。
