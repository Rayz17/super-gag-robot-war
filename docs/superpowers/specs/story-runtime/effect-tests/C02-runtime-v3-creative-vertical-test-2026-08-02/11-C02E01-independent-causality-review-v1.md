> 审稿范围：只检查B+A选案、人物与机体准入及E01预案是否讲得通；不创作新高潮，不替主笔写正文。

## 一、可成立的因果脊柱

1. 万机馆用旧引擎余量降落在木桶街外的废弃会展承台。承台只能承受静载，不能提供泊位、散热或补给；人员由既有出口下舰，馆守Z由机库出口落地。
2. 舰上旧散热循环已到极限。仓内主转子负责散去主循环余热，不提供动力；发动机仍是万机馆的动力来源。
3. 平台依仓储合同合法保管转子。合同到期、费用未结，拆件买家也已经付款；唐胶过去的模糊认证使木桶街无法立刻证明整套设备应当排除在可拆库存之外。
4. 玛拉已经请求暂停。普通谈判被既成订单拒绝，街区付不起多份回购和违约成本，诉讼赶不上第一刀，停产规格又没有兼容现货。
5. 纪存不裁决最终产权，只决定先保存不可复原的整件。万机馆接受临时保管与使用，不因此取得收藏所有权。
6. 唐胶标出不可切割处和承重点；兜灯限定馆守Z只用环身牵引架承力，巡展臂只导缆；玛拉组织自愿参加的运输班。
7. 无牌一号的所有者授予临时驾驶许可。纪存先完成低速操作确认，再亲自承担受益方的身体与法律风险；玛拉、唐胶和兜灯各有不可替代的现场岗位。
8. 货柜领袖自主接受运输请求。仓储主管先撤出人员，再关闭仓门、启动切割台和回收机，战斗成为对完整实物的即时争夺。
9. 玩家用无牌一号清出运输架周边、守住承重点、停下切割台，并转动带轮载架；货柜领袖开门和牵引，馆守Z稳定尾端。无牌一号不独自举起转子。
10. 转子完整离仓，仍留在同一载架上，尚未安装。主管提交失窃报告，平台关闭自己控制的重载出口；普通道路无法承载，直接发动E02。

## 二、知识、权利与站位

| 主体 | 知道与拥有 | 能做与不能做 |
|---|---|---|
| 纪存 | 知道舰况，不知道最终产权 | 只驾驶获许可的无牌一号；不驾驶馆守Z或货柜领袖 |
| 玛拉 | 知合同、路线与维修史 | 控运输班、前导车和部分吊具；不控制仓门和自主机体 |
| 唐胶 | 知旧签名、修补痕和承重点 | 作判断与标记；开战前撤到加固控制室 |
| 兜灯 | 知馆守Z的损伤上限 | 控制整备许可和外置牵引架；不控制馆守Z的自主动作 |
| 馆守Z | 自主主体 | 自主决定移动；不拳击，不让巡展臂承担主载 |
| 货柜领袖 | 自主载具人格 | 自主决定接单、变形和牵引；玛拉只能提出请求 |
| 平台主管 | 有合法保管和现场执行权 | 控仓门、切割台、回收机和人员撤离；不控公共道路 |
| 白鸢 | 本人不在场 | 仅留下被抹署名的作品痕迹，不提供方案或远程控制 |
| 七海 | 可以远程知情 | 没有木桶街现场权限，不能授权、开门或把夺取洗成合法 |
