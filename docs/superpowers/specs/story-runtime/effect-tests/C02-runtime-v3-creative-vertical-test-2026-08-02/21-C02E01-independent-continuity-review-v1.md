# C02E01连续性、常识与物理因果独立审查

> Verdict: `REWRITE_ONCE`

## 阻塞问题

1. C01结尾已经给出木桶街边缘的四角巨构泊位，并由唐胶判断“能停”；C02却把它改成完全无泊位的废弃承台。应明确这里就是照片中的泊位：承力框还能静载，锁泊、冷却和补给设施已经拆空。
2. 正文没有排除“只停切割机，明天再争”。需要直说：明天只是开始受理，不会在舰况窗口内产生停止令；平台可修复切割机或把整件转移，兼容替代件停产且重造需数月。
3. 白天权限只覆盖人员检查，战斗开始时无牌一号和馆守Z却已经在仓内。应让两机先在门外，主管制止后，它们才在门落下前公开越线。
4. 熟练驾驶员的岗位只被台词宣布。应让他们在战斗中持续操作吊装监视、载架支撑和前导车；纪存利用准备时间完成停车、转身和紧停训练。
5. 重载臂路线不能拖着锁死转盘和轮组硬转。三路线共享“解除载架机械制动”前置，再按模块各自完成转向；不得拿脆弱载荷的动量甩敌机。
6. E01出口不能一面宣称所有重载路线关闭，一面立刻安排三车出发。应改为平台关闭三条自有直达出口，仍有一条公共重载线通往E02；三辆同型牵引车在有顶货道内遮蔽，信号伪装留到E02。

## 非阻塞提醒

- 补一句航行途中轮休，可避免C01至C02连续无休。
- 兜灯战斗时应明确位于加固控制室的馆守Z整备席。
- 馆守Z、货柜领袖、七海、白鸢和陆衡的知识与控制边界均已成立。
- 白色采样机与右拳残片可延至E02片头，但不能从后续消失。
