## 一、准入结论

- 章级常驻视点：纪存、唐胶、兜灯。
- 远程人物：七海四话均在东区封存中心；她在木桶街没有授权，只能处理本人签发的记录并表达个人判断。
- 作品痕迹转肉身：白鸢在E01、E02只有作品痕迹；E03拳赛开始前经可见交通抵达，此项需要迁移当前“E03话末到场”。
- 中途到场：豪司在E03由勇气株式会社送来驾驶百刃，不得写成早已随舰。
- 新长期角色：玛拉·瓦尔加。现有人物无法同时承担木桶街生活史、转子运输组织和旧拳王驾驶关系，因此准入为B级长期人物。
- 不准入陆衡：本人C03才正式登场。C02不让他远程解答工程问题，也不拿“提过名字”冒充出场。
- 不新增具名平台反派。E01使用轻量“仓储值班主管”，E02由归一星成为具名执行者，E03由百刃与企业安排构成人物对手。

## 二、新人物稳定模型

### 玛拉·瓦尔加 / Mara Varga

- **身份**：匈牙利人，四十多岁。灾后早期随大型展会物流队来到木桶街，后来成为公共重载运输班负责人，也是旧拳王现任驾驶者。
- **本章欲望**：在午夜拆运前保住整套主转子，并让木桶街继续拥有修全尺寸机器的能力，而不是退化成只卖怀旧盒子的景点。
- **害怕**：平台有合法合同、街坊又确实靠它活过几年；她怕自己带人抢回转子后，先被拖垮的是木桶街的普通店家。
- **核心矛盾**：她不相信漂亮宣言，却把一条街最冒险的决定压在自己身上。她能接受输，不能接受机器被拆成更好卖的零件后还被称为“保存”。
- **与唐胶**：两人十多年前在同一维修网络工作。唐胶用模糊认证救过许多修件；他离开后，玛拉把认证附进担保文件，换来试机台和三间工房的修复款，也替平台留下了扩大解释的口子。两个人都参与过问题的形成。她生气时叫他“唐启明”，平时仍叫唐胶。不是恋爱线，不挤占唐胶与兜灯。
- **压力反应**：先确认人、车和吊具是否到位；真正着急时会亲自上驾驶席，不站在频道里讲道理。
- **亲密方式**：记得别人怎样握操纵杆、哪条腿受过伤；她关心人时会直接改座椅、递护具或替人留一条下车的路。
- **声线**：中文流利，句子朴素完整，偶尔先叫对方名字再说事。少用比喻，不讲主题金句，不模仿外国人口音。
- **知道**：转子九年维修史、平台仓储合同、木桶街运输路线、旧拳王与影子机记录。她不知道G.A.G.和纪存真相。
- **控制**：本地运输班、旧拳王、部分老式吊装设备。她不能控制货柜领袖、万机馆、平台回收机或四架重涂机。
- **章末**：她因组织夺回转子成为平台追责对象，与旧拳王正式随舰；木桶街原运输班成为地面联系人。后续她既是驾驶员，也是模型街公共物流线的代表。

## 三、轻量NPC场景卡

### 平台仓储值班主管

- 无专名、无半身立绘；以仓库广播头像或驾驶舱通讯出现。
- 想按合同完成午夜拆运，也要让本班工人平安下班。
- 能控制仓门、仓内回收机、自动切割台和本仓人员撤离；不能控制木桶街公共道路、归一星、代哥或索引。
- 看见万机馆介入后先清空人工作业区，再让回收机阻拦。这样对手不是草菅人命，战斗也能成立。
- E01结束后只提交失窃报告，不跨话抢占归一星的反派职能。

### 木桶街重载运输班

- 集体角色，不逐一命名；负责前导车、吊装控制室和两辆空载诱饵车。
- 他们会质疑玛拉，不因一句号召全员同意。最终参加者是自愿留下的班组。
- E04之后留在木桶街，承接地面节点，不随舰挤占角色席。

## 七、实体门遗留迁移

1. 白鸢E03到场时间提前到拳赛前，但E01、E02存在方式不变。
2. 当前E01的`WANJI_ROTOR_SECURED`延后到E04，E01只完成完整离仓。
3. 当前E03拍卖巨台、巡演基座与核心战退役；旧拳王获胜和正式加入保留。
4. 当前E04开放日、清仓鲸与空测试架主事件退役；白鸢临时登舰、转子需C03校正保留。
5. 玛拉新增为B级长期角色，需用户确认后再进入人物模型注册表与Canon实体表。
6. 纪存作为无牌一号C02默认首控者是本方案Candidate；机体仍可换驾驶者和由玩家命名。
7. 馆守Z新增的是可牺牲的外置牵引架，不是后继右臂；需在E04结算报废，防止连续无成本重载。
8. 右拳残片继续保留为白框生态后台钩子。本章若只出现一次物流短镜头，不把平台、归一星或代哥写成白色采样机的主人；若要追查其去向，必须先建立具体承运与检测主体。
9. 无牌一号的本章使用权由木桶街公共竞赛工房合作社现场授权，不由玛拉个人出借。合作社本章只作为集体所有者存在，不新增具名负责人；后续若承担独立剧情，再升格建模。
