# C02E01《救命零件，限定发售》导演、因果与玩法预案

> Status: `candidate_scene_plan_pass / independent_causality_reviewed`
>
> 本话目标：只完成“把一套完整主转子从平台仓库运到木桶街内环”。不安装，不开开放日，不解释G.A.G.，不让白鸢本人或陆衡提前出现。

## 一、一句话冲突

平台要在午夜把公共试机台上的主转子拆成高价零件运走；木桶街和万机馆必须在它被切开前，把同一件巨物完整拖出仓库。

## 二、因果脊柱

1. 万机馆依照C01收到的邀请抵达木桶街，降入照片中的四角巨构泊位；泊位仍能静态承重，锁泊、冷却、补给和长期固定设备已经拆空。
2. 玛拉告诉唐胶，木桶街曾靠平台垫资保住工房。唐胶当年出具维修认证，玛拉在他离开后把认证放进担保附件；平台如今用这份附件把整套设备拆分计价。
3. 万机馆到达后，兼容零件的买价上涨。平台把原定整件转运改成午夜拆件发车，因为拆开出售更快、更值钱，也更难被街区追回。
4. 玛拉已申请暂停并提出回购，平台依据现行仓储合同拒绝；正式争议处理赶不上午夜。木桶街也无法在几小时内另造一套停产设备。
5. 纪存确认主转子一旦被切开，万机馆无法可靠起飞，木桶街也失去唯一的大型试机能力。他决定先保住实物，再承担这次夺回的法律与现实后果。
6. 运输班并非全员同意。愿意参加的人留下，其余人和平台工人撤出战区。平台仓储主管关闭仓门，启动无人重载回收机和自动切割台。
7. 唐胶在实物上找出自己参与过的修补位置，重新标出整件起运的受力点；兜灯否决烧损右肩直接承重，选择现成的外置牵引架。
8. 无牌一号属于木桶街公共竞赛工房，由仍在场的合作社成员现场表决，授予纪存本次临时驾驶许可。玛拉必须统筹运输，唐胶必须在吊装控制室看实物，兜灯必须负责馆守Z，纪存又是万机馆这一直接受益方中唯一能进入巨机驾驶舱的人；他先完成低速操作确认，再承担驾驶和被追责的风险。无牌一号的竞赛辅助只负责平衡与安全，不替他做决定。
9. 玩家操纵无牌一号和馆守Z，击退回收机、停下切割台并清出主轨。无牌一号卸下比赛背包，换上重载模块，把主转子转到能够穿过仓门的方向。
10. 玩家完成转向条件后，货柜领袖自主进入作业形态托住下降的主门并拖动载架；一块货柜外板被压弯。馆守Z通过外置牵引架稳定尾端，巡展臂只引导缆索。
11. 主转子完整离仓。平台关闭三条自有直达重载出口并把事件升级为货物劫取；普通街道与桥梁承受不了这套载荷，车队只能沿仍开放的市政重载环线突围，E02由此开始。

## 三、时间与空间

### 时间

- C01战后同日，万机馆用剩余航行能力抵达邻近的木桶街，约在下午。
- 平台午夜货列是公开既定班次，不使用十分钟、八回合或一厘米制造虚假紧迫。
- E01覆盖下午到深夜：到达与交涉、短探索、准备、仓库战。E02从出口关闭后的夜间直接接续。

## 四、知识、所有权与控制

| 对象 | 归属或争议 | 谁能操作 | 本话限制 |
|---|---|---|---|
| 主转子 | 平台持有仓储与担保文件；木桶街主张公共设备例外；本话不判最终所有权 | 吊装班能搬运，任何一方不能凭文件让它自行移动 | 必须整件运；切开后不能用于万机馆 |
| 万机馆 | 万机馆共同体 | 自动航行系统负责舰体动作，纪存决定去向 | 旧引擎不能支持再一次可靠起飞，且不能进入内街 |
| 馆守Z | 旧守护者为机魂主体 | 旧守护者自主运动，兜灯负责整备和停机 | 右前臂缺失；巡展臂不能格斗；外置牵引架承担主要载荷 |
| 无牌一号 | 木桶街公共竞赛工房的合作社共有全尺寸底盘；在场成员现场表决授予本次许可 | 纪存驾驶，低权限竞赛AI只辅助平衡与安全 | 纪存先完成低速操作确认；合作社许可不等于转移所有权 |
| 货柜领袖 | 独立机械生命 | 自己决定承运和变形；玛拉只提出请求与路线 | 不接受玩家战斗指令，不击败敌机 |
| 平台仓储设备 | 平台仓储执行链 | 值班主管控制本仓门、回收机与切割台 | 不能调动公共道路、代哥、归一星或索引 |
| 唐胶 | 知道修补史，无所有权 | 能判断维修痕和现场吊运，不能替兜灯批准馆守Z承力 | 他的旧签名既是帮助，也是争议来源 |
| 玛拉 | 运输班负责人，无平台设备控制权 | 控制前导车、本地吊装班和运输计划 | 不能驾驶货柜领袖；E01不驾驶旧拳王 |
| 七海 | 留在东区封存中心 | 只可通讯和查看本人合法可见记录 | E01不能叫停平台或开放木桶街；她只确认这会被记录为夺取行为 |
| 白鸢 | 本人不在场 | 无现场能力 | 只在被裁掉署名的安全分镜中留下作品痕迹 |

## 五、普通办法审查

| 普通办法 | 为什么不够 |
|---|---|
| 请求平台暂停 | 玛拉已经申请，平台以有效仓储合同和午夜货列拒绝；本话让玩家看见拒绝结果，不靠旁白补充 |
| 回购 | 转子已按拆件预售，价格超过万机馆与街区现有资金；更重要的是木桶街拒绝再买一次自己共同修回的公共设备 |
| 等法院或仲裁 | 可以继续，但赶不上午夜切割；夺回不是合法胜利，而是先保物、后承担追责 |
| 另造一套 | 停产规格与全尺寸材料至少需要数月，万机馆无法在无冷却条件下停留到那时 |
| 只拿必要的小零件 | 主转子是一个完整工业总成，切开即失去平衡与适配，不存在一枚手掌大的万能件 |
| 让万机馆直接开到仓门 | 百米舰进不了内街，街区道路和仓门只容纳标准巨机与重载车 |
| 让货柜领袖自己抢 | 它能运输，不能同时清场、保护载荷和操作吊装；它也只在确认有人承担收货与后果后接受任务 |

## 六、七场连续流程

### S1 万机馆落在街外

- **载体**：短动画转ADV。
- **视点**：纪存。
- **画面**：百米巡展舰越过密集的模型招牌和巨机吊架，最终落进C01照片中的四角巨构泊位；承力框仍能接住舰体，锁泊臂、冷却管和补给井却只剩空接口。
- **戏**：兜灯确认万机馆能落下，当前状态未必还能再起飞。唐胶听见玛拉叫自己的本名。玛拉用平台公开拆件画面说明午夜危机。
- **场尾问题**：纪存问清楚“现在进去算什么”，得到“算抢”的直接回答；他要求先看实物和合同。

### S2 这条街不只卖盒子

- **载体**：连续探索。
- **视点**：纪存、唐胶。
- **玩家可见**：普通模型店位于全尺寸工房和货运轨道下方；同一面墙上既有缩尺盒绘，也有实机维护照片。未发售两米工程样机在工业测试架内首显。
- **三项必要信息**：主转子是一件巨物；平台确有仓储文件；唐胶的签名被扩大使用。
- **白鸢痕迹**：平台安全动画使用她的分镜，却裁掉署名，只留下一个未清干净的白色鸟形角标。现场无人知道作者本人是谁。
- **不做**：不塞三段支线哭故事，不通过资料卡解释模型与实机规则。

### S3 留下来的人

- **载体**：工房食堂/运输班ADV。
- **视点**：玛拉、纪存。
- **戏**：玛拉把计划和后果讲明，运输班自行决定去留。有人离开，也有人留下；没有“全街同声”。
- **七海**：纪存用私人频道告诉她自己准备做什么。她不能授权，只要求保留现场影像，并直说这会让他成为货物劫取案的当事人。两人的关系推进来自他主动告知、她没有假装这件事合法。
- **场尾决定**：纪存参加，并明确万机馆只做移动保管；转子的产权继续悬而未决。

### S4 三个人，各管一件事

- **载体**：模块选择与整备玩法。
- **纪存**：从无牌一号三组现成模块中选一组，完成基础驾驶适应。
- **竞赛工房合作社**：仍在场的成员确认无牌一号是共有底盘，并以现场表决授予一次性驾驶许可；不新增具名负责人。
- **唐胶**：在转子外壳和载架上重新标出整件搬运点。
- **兜灯**：否决重拳式临时右臂，选择外置牵引架；唐胶按她给出的身体边界修改连接件。
- **货柜领袖**：听完目的地、载荷和风险后自行接受承运。它不是玛拉的车，也不是纪存的召唤物。

### S5 平台清场，战斗开始

- **载体**：短动画进入SRPG。
- **对手动作**：仓储主管先让工人撤离，再关门、启动回收机和切割台；平台要保住当前控制下的货物，不主动杀人。
- **玩家单位**：无牌一号、馆守Z。
- **NPC单位**：货柜领袖与空载架在仓外等待，玛拉和唐胶进入加固控制室，兜灯在馆守Z整备通讯席。
- **战斗人话**：玩家要在切割台完成第一刀前，打退阻拦并把主轨让给运输架。

### S6 无牌一号把整件转过来

- **载体**：战中事件与一次高成本机体动画。
- **第一阶段**：玩家击退仓内回收机并停下切割台。
- **第二阶段**：转子停在无法穿门的横向位置，低载架由一根机械制动杆固定。
- **玩家胜负手**：无牌一号卸下比赛背包，以本话选择的模块解除同一根机械制动，再用全身把载架推向仓门。
- **协同奇观**：转子转正后，货柜领袖自主托住下降的主门并拖动载架，一块货柜外板当场折弯；馆守Z以外置牵引架稳定尾端。无牌一号挡开最后一批回收机，让巨环从它身后穿过主门。
- **归属感**：玩家第一次亲手决定无牌一号装什么、怎样赢，货柜领袖和馆守Z不能替代这一步。

### S7 货出来了，街关上了

- **载体**：战后ADV与地图变化。
- **状态**：主转子完整离仓，仍在同一载架；平台关闭三条自有直达重载出口，市政重载环线仍然开放。
- **物理限制**：平台只能关闭自己控制的重载出口；即使人员可以离开，普通街道和桥梁也运不走十四米转子。
- **对手收益**：平台取得无牌一号的实战构筑影像和货柜领袖的作业变形记录，但没有得到人格或机魂。
- **人物余震**：唐胶看见自己的旧签名出现在失窃报告上；玛拉直接叫他去检查载架，两人继续处理眼前的问题。
- **下一话**：车队必须让平台无法确认哪辆车运着真转子，并突破城市外环。
- **后台钩子**：白色采样机带走的右拳残片只以独立物流短镜头继续移动，不与平台追击线合并；若本话篇幅过满可移到E02片头。

## 七、SRPG与多玩法

### 战前玩法

- 木桶街短探索：看见模型、实机、工房和物流共存。
- 无牌一号构筑：玩家在重载臂、推进腿、折叠盾中选择一组主模块。
- 馆守Z整备：外置牵引架是固定选择，避免把安全边界做成“选错即人物不懂事”。

### 战斗地图

- 单层仓库与仓前装卸坪。
- 可破坏对象：平台无人回收机、切割台总电源、空隔离栏。
- 不可破坏对象：主转子、载架、有人值班室、未发售样机测试架。
- 平台不使用致命武器，以抱夹、推挤、黏着索和路障控制为主；我方也以击倒、断电和推离为主。

### 胜负条件

- **第一阶段胜利**：停下切割台并清空主轨。
- **最终胜利**：无牌一号完成转向，主转子载架通过仓门。
- **失败**：主转子两处主要支撑同时损坏，或无牌一号失去行动能力。
- 不使用回合数作为剧情夸耀。切割臂的位置是清晰的地图阶段压力，玩家可通过切断总电源永久停下。

### 模块差分

- **重载臂**：代表性Reader路线，拔起机械制动杆并直接推动载架。
- **推进腿**：无牌一号从维护坡道踩下机械制动，再借速度推动载架。
- **折叠盾**：盾展开成临时杠杆，带动同一根机械制动杆；本地吊装机协助转向。
- 三条路线改变动画与后续初始模块，不改变主故事结果。

## 八、玩家可见证据

| 玩家必须当场明白 | 可见方式 |
|---|---|
| 万机馆到了，但不能长期停靠或再次可靠起飞 | 舰体落在断电承台；兜灯当面对纪存说明；冷却警报只作背景，不念参数 |
| 主转子是一件巨大完整设备 | 远景、仓内实物与载架，不靠术语解释 |
| 平台不是凭空抢东西 | 玛拉出示平台持仓文件；平台主管能合法清场与操作本仓设备 |
| 唐胶的旧签名确实造成今天的问题 | 实物上的修补标记与拆件清单同屏；他本人承认 |

| 白鸢本人不在场 | 只有被盗用作品角标，没有通讯、感知或新路线 |

## 九、对白与概念重力门

- 禁止使用“你可以……但别替我……”“今天先……但也别……”“不替谁背”“债务”“证词”“语法”“锚定某人的选择”等作者句式。
- 对白先回应听众和眼前事。人物说“这套东西一切开就废了”，不说“完整主体将失去连续性”。
- 唐胶只在看见具体修补时说材料和手艺，不长篇自白。
- 兜灯只需要说清“肩扛不住”“用外架拉”，不报受力公式。
- 玛拉不发表木桶街宣言；她给计划、后果和退出机会。
