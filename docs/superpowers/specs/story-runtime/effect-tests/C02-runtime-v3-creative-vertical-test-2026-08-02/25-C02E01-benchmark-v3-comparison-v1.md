## 两稿白话复述

### 旧V3

万机馆抵达木桶街，现代固定爪接不上，旧主转子也已过热开裂，必须换上木桶街库存里的退役转子。寻找适配方法时，唐胶被街坊认出，并遇到一份二十七年未完成的模型委托和一盒不敢拆封的旧教学模型。盒内手修斜垫暴露了真实机器早已遗失的装配偏差，也迫使唐胶公开当年含糊处理过的维修记录。工房据此验证并做出适配座。

万机馆合法买下转子，平台却把唯一重载通道拿来竞价。追逐中转子脱架，万机馆、馆守Z、货柜领袖和无牌一号共同控制巨环并完成安装。唐胶公开的维修资料又让平台发现四台同骨架飞行机，直接发动E02。

### B+A新稿

万机馆停进四角旧泊位，却无法锁泊、冷却或可靠再次起飞。玛拉告诉众人，一套可用于万机馆的公共试机台主转子将在午夜被平台拆分发货；唐胶以前签下的维修认证、玛拉后来加入担保的附件，正被当作拆件计价依据。

暂停和回购均失败后，玛拉决定整件抢出转子。部分运输员因家庭和账户风险退出，纪存主动驾驶公共竞赛机无牌一号，并把计划如实告诉七海。兜灯与唐胶为馆守Z制作避开伤肩的牵引架，货柜领袖自主接受承运。玩家操纵无牌一号和馆守Z停下切割台、转正载架，与货柜领袖共同把十四米转子拖出。平台封锁自有出口，转子仍困在街内；玛拉准备诱饵车，四架飞行机进入E02。

## 七项比较

| 维度 | 旧V3 | B+A新稿 | 判断 |
|---|---|---|---|
| 可读性 | 人情味浓，但模型委托、教学史、适配和竞价规则接连出现，主线多次停靠 | “转子要被切，必须整件运走”始终清楚 | 新稿小胜 |
| 因果常识 | 合法买件成立，但关键教学模型、移动交付和巨环事故明显为战斗服务 | 仓储权、撤人、非致命回收和断电反制更可信 | 新稿胜 |
| 人物魅力与关系 | 唐胶有完整的羞耻、公开和后果链；纪存与七海从遮掩走到坦白 | 纪存更主动，玛拉利落，但唐胶、兜灯和七海的情感过程较薄 | 旧稿明显胜 |
| 机器人大战感 | 高架、失控巨环、百米舰牵索和多机共托的气势更强 | 仓库攻防规整，馆守Z伤势与货柜领袖主体性扎实，但偏工业搬运 | 旧稿小胜 |
| 玩家可操作感 | 模块选择明确，但控制权较模糊 | 玩家单位、NPC边界、阶段目标与地图变化可直接想象 | 新稿明显胜 |
| 设定负担 | 人物、课程、模型产权、售后、竞价和资料卡同时进入 | 仍有合同说明，但制度链收窄 | 新稿胜 |
| 继续读欲 | 唐胶的公开行为反过来危及四机，人物选择直接引爆下一话 | 诱饵车与追击能继续玩，但更像运输任务前半段 | 旧稿胜 |

## 结论

新稿在游戏工程层面超过旧稿，但当前成稿体验没有形成净胜。它得到更单纯的发动机、更可信的现场逻辑、纪存首控和更强的玩家操作映射；代价是削薄了旧稿里最有生命的三部分：唐胶面对具体物主与旧手艺的情感过程、纪存与七海从遮掩到坦白的关系动作，以及本话人物选择直接反咬下一话的钩子。

关键风险只有三项：

1. 公开抢夺的必要性在逻辑上成立，在情感上还不够压倒性。
2. 人物关系参与了行动，却尚未真正改变行动的方向或结局。
3. 本话交付“离仓而未送达”，连续性增强，单话满足感下降。
