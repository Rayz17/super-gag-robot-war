# C02三案独立盲审综合

> Status: `preselection_review_complete / awaiting_user_selection`
>
> 两名审查者只读取三案正文，不读取旧C02稿、Canon答案、Runtime设计理由和主笔推荐。一席以商业长篇编剧与普通玩家复述，一席以机器人文化专家与SRPG制作人审查。

## 一、盲审是否读懂

两席都能用白话准确复述三案的发动机、四话走向和高潮，因此三案没有依赖作者后台解释才能成立。两席也独立指出了相同的弱点，说明问题不是个人审美偶然：

- A的比赛卖相最强，但四种玩法更像并列节目，前三战对最终反攻的不可替代因果仍不够。
- B始终围绕同一套主转子推进，四话从突围、诱敌、过桥升级到停舰吊装，行动脊柱最完整。
- C的双门高潮与“万机馆提供去路而非所有权”最独特，但E01-E04反复证明同一命题，且玩家、驾驶者、AI与独立机体谁在作选择仍不够清楚。

## 三、人物行动审查

### A

- 纪存拒签并让参赛机反攻，成立。
- 七海公开揭破赛事真实条款，能改变舆论与调查态势，但需在选案后说明它怎样影响现场敌方行动。
- 白鸢交出原稿，帮助驾驶员识别预定败位，成立。
- 唐胶与兜灯共同把漂亮的一击型右臂改成真正用于高潮承重的右臂，成立。

### B

- 纪存停下整艘万机馆等全部重件通过，是三案中最外放且最清楚的主角选择。
- 兜灯把馆守Z右臂用途改为牵引，直接改变最终运输，成立。
- 唐胶目前只被写到“找齐维修者”，尚缺一个由他亲手完成、会改变运输成败的结果。
- 七海目前主要制造未来调查压力，尚缺一个不越权、却能影响本章战场的真实行动。
- 白鸢的动态改线有作用，但需要在E04明确一次“她改了哪里，因此哪一段转子或哪组人得以通过”。

### C

- 纪存打开双门成立。
- 七海、白鸢、唐胶和兜灯大多停在理解、旁观或象征动作，尚未共同推动高潮。
- 每台机体主体资格不同，极易迫使正文不断解释“到底是谁在选”。

## 四、机器人与游戏审查

### A

- Build改装、重涂同模、Real Steel拳击和过度全装都有可辨识的名场面潜力。
- 影子陪练机虽然启动，却尚未改变拳赛胜法。
- 四话分别引入障碍改装、空战、拳赛和全机群战，制作上接近四套玩法；E04还同时承担拆台、空战、承重与吊装。

### B

- 货柜领袖主动撞门，四架重涂机把相同雷达与工厂动作反过来用于真假车队，机器人性能持续推动因果。
- 四话共享运输与护送主轴，玩法可以在同一套城市路线、货运设施与敌军上递增，复用性最好。
- E02的三段货物、真假车队和多高度容易看不懂；正式预案应减少同时存在的真假目标数量。
- E04的三线运输也需要压成玩家一眼能读懂的主目标，不能把空地、吊装和动态改道全部做成同权重系统。
- 影子陪练、百刃和归一星的章后状态仍需在实体建模时落地。

### C

- 同模不同命和双门通路有强烈原创辨识度。
- 玩家若决定机体去向，会削弱机器人主体性；若所有去向预定，玩家又会像护送演出。必须重写玩家能动性的落点。
- E02逐台阵营变化与E04分歧援军会形成较高组合成本。

## 五、对主笔原推荐的修正

主笔初评偏向“C为主，吸收A的机械拳击”。两席盲审均不支持直接采用这一组合：C当前章骨架不够扎实，再叠加A的拳击只会把问题藏进更多场面。

依据盲审，当前更稳妥的建议改为：

**以B《零点转子劫案》为母案，吸收A中旧拳王走出预定败位、百刃卸下过量装备的拳赛功能；不吸收A整套大会，也不把C的双门防卫完整塞进B。**

B现有高潮已经是万机馆横停、让整条运输列通过。它可以继承C“万机馆是一条路”的含义，但无需再增加两扇门、机体去向分支和第二套终局规则。

## 六、进入下一阶段前必须解决

用户若选择B或上述B+A功能融合，实体建模与C02E01预案必须优先回答：

1. 无牌一号由谁驾驶，玩家如何获得首控而不把低权限AI写成机魂。
2. 旧拳王原驾驶者是否随舰；若随舰，必须升格稳定人物模型。
3. 百刃、影子陪练机和归一星的控制者与章末去向。
4. 唐胶在运输可靠性上完成什么不可替代的行动。
5. 七海怎样在不拥有木桶街控制权的前提下实际改变一次敌方行动。
6. 白鸢哪一次改线产生可见、可复述的结果。
7. E02与E04怎样压低同时目标数量，保持SRPG可读性。

这些问题属于选案后的实体建模、因果预演和战斗预案，不在正文中临场补设定。
