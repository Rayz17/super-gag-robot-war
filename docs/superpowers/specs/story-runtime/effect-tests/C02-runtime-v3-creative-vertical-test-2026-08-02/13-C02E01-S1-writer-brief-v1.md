## 戏剧要求

万机馆刚离开故城，靠所剩不多的航行能力抵达木桶街。它没有找到能接住自己的泊位，只能降在街外一块断电的旧会展承台。兜灯检查后告诉纪存：落得下来，不代表还飞得起来。

唐胶的旧同行玛拉来接他们。她不是来欢迎开馆，而是让他们看平台正在公开播出的拆件预告：仓库里那套主转子将在午夜拆卖。它既是木桶街最后一套全尺寸公共试机设备，也是万机馆当前唯一可能适配的散热总成。

纪存先问清介入的性质。玛拉直说，按现有文件，现在去拿就是抢。纪存不立刻喊口号，也不宣布所有权；他要求先看实物和合同。场景结束时，一行人进入木桶街调查。

## 已锁事实

- **场景前**：万机馆刚离开故城；舰上人不知道木桶街具体出了什么事，只知道那里发过邀请并可能有兼容改件。
- **场景后**：玩家明白万机馆不能长期停留、主转子今晚会被拆、玛拉和唐胶有旧关系、介入并不合法；纪存决定先调查，尚未决定劫仓。
- 万机馆约百四十米，只能落在街外承台；人由正常舷梯下舰，馆守Z由机库出口落地。
- 主转子是一套十四米级完整工业总成，负责散去万机馆主循环余热，不是能源核心。
- 平台依据仓储合同准备在午夜拆卖它；玛拉已经申请暂停并被拒绝。
- 本场只看直播或远景，不进入仓库，不驾驶无牌一号，不开始战斗。
- 七海本场不通讯；白鸢本人和陆衡都不出现。

## 人物此刻

- **纪存**：第一次作为巡展负责人抵达陌生地方。他会先确认人、舰和现实后果，再主动往问题中心走。他可以有一点干冷幽默，但不替作品总结主题。
- **唐胶**：对木桶街熟悉，也明显不愿碰过去。玛拉叫他本名“唐启明”时，他会有真实反应；不必当场解释十年旧账。
- **兜灯**：正在担心馆守Z和万机馆的身体状况。她说话直接、具体，只报告这次能不能做，不念参数，也不是唐胶的助手。
- **旧守护者/馆守Z**：同一主体。可以通过舰内广播或馆守Z扬声器简短回应，不需要承担信息讲解。
- **玛拉·瓦尔加**：四十多岁的匈牙利裔本地重载运输负责人，中文流利。她务实、完整地说话，不模仿口音，不发表宣言。她认识唐胶很多年，今天没有时间替他留面子。

## 主笔可改写范围

- 先建立空间：万机馆在哪里，木桶街在哪里，人怎样下舰，玛拉从哪里来。
- 让信息通过舰况、直播画面、人物问答和旧人反应进入，不写百科旁白。
- 对白先回应眼前的人和事。允许停顿、没说完、被具体动作打断；不要人人都说完整观点。
- 机器人规模要可见，但不堆部件名，不写一厘米级动作，不把场面拍成广告蒙太奇。
- 喜剧来自巨大巡展舰只能停在旧会展承台、唐胶被叫本名等具体处境，不靠语义拼贴或四十个人一起摔倒。
