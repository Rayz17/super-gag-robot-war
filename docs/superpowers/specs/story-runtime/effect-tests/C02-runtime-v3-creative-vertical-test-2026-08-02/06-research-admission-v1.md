## 变形采用

- “Real Steel式影子模式”从模仿名招改成“平台只会预测旧录像中的漂亮败位，玛拉用今天真实的身体节奏走出镜头”。它服务人物，不服务致敬点名。
- “全装模型过度设计”从纯吐槽改成豪司的职业选择：装备确实强，他卸掉的是会伤到场外人、也会让平台远程接管的部分。
- “同模重涂”不靠说明书证明差异，而在E02让四机分别承担诱敌、截断、误导与掩护，玩家先从行为认出它们，再理解商品身份争议。

## 暂不使用

- `C10`三法城材料：与本章戏剧问题无关。
- 旧C02开放日、拍卖巨台、清仓鲸：会让单一运输主线再次分裂。
- 检索记录中的候选终局动作：只作长期库存，不进入本章。
- 胶价王具名Boss：B+A目前由平台仓储执行链、归一星和百刃构成逐级对手；另加主持人格会分散火力。
- 直接引用名台词：E01先验证人物与行动是否成立；拳赛台词到E03再定，不为凑锚点提前写。
