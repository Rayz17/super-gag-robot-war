# C02E01完整Reader主笔短交接

> 同一主笔继续第一场。完整Runtime包只供定向查事实，不进入正文Prompt。

## 已锁事实

- 第一场冷读已通过；整话沿同一天从下午写到午夜。
- 万机馆只能降在街外会展承台，舰内温度继续上升，不能保证再次起飞。
- 主转子是十四米级完整散热总成，当前在平台仓库的低载架上；E01只把它完整运出仓库，不装舰、不运转。
- 平台当年为木桶街垫付公共试机台维修和仓储费用，并依据担保合同及唐胶维修认证中的可替换件清单执行拆售。平台兼具债权、仓储和交易执行角色，但不控制全城。
- 玛拉的运输班在六点换班前有装运验收时段，可带三名外协维修人员入仓。夜班接管后，平台有权关闭本仓和自己控制的重载出口。
- 无牌一号属于木桶街公共竞赛工房合作社；现场成员表决后，只授予纪存本次临时驾驶许可。
- 货柜领袖与馆守Z都是自主主体。货柜领袖自行接受运输请求；馆守Z由旧守护者自主运动，兜灯只负责整备与停止。
- 七海在东区封存中心，只能私人通讯；白鸢本人不在场，只出现被盗用的作品痕迹；陆衡不出现。

## 戏剧要求

- 唐胶必须从“回到熟街不愿碰旧账”走到承认那张维修认证确实给今天留下了口子，但不能一场忏悔便结清过去。
- 纪存必须主动问清普通办法、把风险告诉七海、亲自进入无牌一号，并由玩家通过他的驾驶赢下离仓动作。
- 兜灯必须凭独立判断保护馆守Z：重量绕过烧损右肩，由环身牵引架承担；唐胶按她给出的边界改工装。
- 玛拉既是本地行动发动者，也是会害怕街区普通店家被连带追责的人；运输班不能全员同声追随。
- 至少兑现两种机器人快感：无牌一号的玩家模块构筑与首控，货柜领袖的自主作业变形；馆守Z以受损身体完成不可替代的协同。
- 战斗要一眼能懂：平台先撤人，再以非致命仓储机阻止擅自搬货；玩家停切割台、清主轨、转正载架、把转子送出门。

## 主笔可改写范围

- 保留第一场主体，但按冷读意见改正落点坐标、舰温、平台关系、回购费用和入仓身份。
- 街内探索可自由选择两至三个可见细节，重点是模型、原型与全尺寸工房共存，不建立新支线人物。
- 运输班讨论、合作社表决、七海私人通讯和唐胶/兜灯整备场可以自由调度先后，只需让决定逐步形成。
- 战斗动作可在单层仓库和门前装卸坪内重排，优先使用巨机、载架、切割台、仓门和回收机这些已有资产。
- 对白允许停顿、误会、玩笑和未说完；不要让所有人准确说出自己的主题。

## 开放问题

- 唐胶在实物上首先认出哪一道自己留下的修补，它为何既救过设备又被平台用来拆分计价？
- 哪些运输班成员离开，留下的人为什么仍愿意参加？不需要逐一命名。
- 纪存在无牌一号第一次站起时，怎样显示他有组织机体信号的天赋，却没有夺取AI或机魂动作？
- 货柜领袖为何愿意承运，它会用什么简单条件表达自身边界？
- 旧守护者对“再次被当成一台会工作的机器看见”有什么具体反应？
- 第一场出现的白鸢作品痕迹，怎样既能被玩家注意，又不抢走转子主线？
