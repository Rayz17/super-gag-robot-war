# C02E01机器人文化与游戏制作独立审查

> Verdict: `REWRITE_ONCE / causal_repair_required`

## 已成立

- E01以无牌一号、火种货柜领袖两台主首登，加一台静态工程样机与共骨架杂兵，数量健康。
- 无牌一号的模块三选一和不可替代胜法已有玩家操控感。
- 馆守Z的带伤老将表达最好：缺臂边界、巡展臂用途和躯干牵引均被尊重。
- 战斗理由清楚：我方把验收转为夺取，平台先撤人再保货；地图为单层仓库与装卸坪，可制作。
- 三机、巨环与仓门联动值得保留为本话PV级动画。

## 必须一次修正的根因

1. 无牌一号仍只有借用感。公共所有权可以保留，但玩家需要在E02钩子前获得可见的持续承认，如保留构筑与贯穿本章的临时驾驶钥匙。
2. 第二阶段叠加锁死转盘、未解轮组、门锁、拔锁销和副臂分别操作，宏观动作被微操切碎。只保留一个物理瓶颈、一次敌方封门、三台机体各一个全身动作。
3. 火种货柜领袖已经像独立生命，却还没有以自主代价选择证明“领袖”；需要它主动改变战场并承担可见损伤。
4. 模型与实机关系应由样件、试装和玩家构筑结果表达，删除防误解式说明。
5. 无牌一号三条模块若后续不持续复用会成为隐性高成本；本次测试应把所选构筑明确保存到后续话。

## 成本提醒

- 仓库专用机关应压缩为可复用的门、切割台与低载架，不制作复杂转盘多状态。
- 两米工程样机若E04真正变形并可控，将形成独立比例与骨架成本，后续需另行裁决。
- E03影子陪练机若只服务一场，应共用拳王骨架或降为地图机制。
