## 可操作段落

1. **木桶街连续探索**：模型店、全尺寸工房、两米变形工程样机、平台仓与主转子实物。
2. **无牌一号构筑**：重载臂、推进腿、折叠盾三选一；三路线都先解除载架机械制动，再用不同全身动作完成转向。所选构筑保存到后续话。
3. **仓库SRPG**：单层主仓与装卸坪。第一阶段托住切割臂并关闭总电源；第二阶段释放载架、转正车身并护送转子离仓。

## 单位与边界

- 玩家单位：无牌一号、馆守Z。
- NPC单位：货柜领袖。它在主门下降时自主变形托门并承受一处货柜外板损伤，随后牵引载架；不接受玩家战斗指令。
- 敌方单位：四台共骨架平台重载回收机、切割台与仓门；只使用抱夹、推挤、黏着索和封路。
- 三名运输班驾驶员持续操作吊装监视、载架支撑和前导车；普通人员位于加固控制室或撤离区。

## 战斗大动作

1. 无牌一号以所选模块托住切割臂，馆守Z撞开回收机并关闭切割台总电源。
2. 无牌一号解除唯一机械制动，用全身把低载架转向仓门。
3. 货柜领袖自主变形托门，馆守Z稳住尾端，无牌一号击退主轨上的回收机，巨环完整穿门。

## 胜负

- 胜利：切割台停止，载架制动解除，主转子完整通过仓门。
- 失败：主转子两处主要支撑同时损坏，或无牌一号失去行动能力。
- 不使用故事性回合倒计时；切割臂的位置和仓门下降构成可见阶段压力。
