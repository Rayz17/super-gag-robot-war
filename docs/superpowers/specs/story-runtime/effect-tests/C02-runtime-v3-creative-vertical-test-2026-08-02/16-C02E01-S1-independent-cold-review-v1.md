## 白话复述

万机馆载着纪存、唐胶和兜灯到了木桶街，但当地没有能接纳这艘百米巡展舰的泊位，只能降在街区外废弃展会留下的混凝土承台上。落地后舰体仍在发热，能不能再次起飞没有把握。

三人带着馆守Z下舰，见到了邀请他们来的重载运输班负责人玛拉。她认识唐胶，也称他本名唐启明。

玛拉给他们看了一套仓库里的大型主转子。兜灯确认整套转子能接入万机馆，但它已经被平台拆分卖给多个买家，自动切割机将在午夜开始拆件；一旦切开，万机馆就不能用了。平台处理它的合同依据里还有唐胶当年的签名。

正式申诉赶不上切割，回购又付不起退款和违约金。玛拉直说，按现有合同进去拿就是抢。纪存最后没有立即决定抢，而是先去看实物和完整合同，看完再决定。

## 六项评价

- **可理解性**：主事件清楚。万机馆可能飞不起来，救命转子午夜要被拆，正规办法来不及，唐胶又被旧文件牵连。平台、木桶街和买家之间的权利关系还可再说准一些。
- **自然人声**：兜灯短硬、纪存务实带一点干笑、唐胶回避旧账、玛拉直截了当、旧守护者礼貌规范，遮住名字后多数台词仍可辨认。少数来回略显“接得太漂亮”，但没有轮流发表主题。
- **空间与动作因果**：百米舰、十八米通道、街外承台、舰腹机库、引导车和步行馆守Z均可直接画成镜头。邀请方为何未事先说明落点、维修人员凭什么进入仓库，需要补明。
- **戏剧吸引力**：唐胶在拆件依据中认出自己的签名，以及玛拉直说“算抢”，是有效翻面。平台垫款、合同到期与拆件依据一段略糊。
- **机器人存在感**：万机馆是一具落下后可能无法再起飞的百米身体；馆守Z的缺臂、夹爪和步行尺度可见；主转子也是必须运输的巨物，而非手掌大小的任务道具。
- **设定表达**：没有过度解释机魂、G.A.G.或模型与实机规则。主要风险不是说太多，而是商业关系的名词指向还不够准。

## 局部修正点

1. 把“散热还在往上走”改成“舰内温度仍在上升”一类普通说法。
2. 明确平台兼具垫资方、仓储方和拆件交易执行方，不让“平台”成为万能抽象名词。
3. 明确唐胶签的是维修认证中的可替换件清单，后来被担保合同引用；他的签名不是一句话便产生所有权。
4. 把“我们付不起退款和违约金”改成木桶街若回购，须退还多个买家已付款项并承担解约费。
5. 说明玛拉的邀请已附会展承台坐标，但该处只能落舰，不能提供泊位服务。
6. 说明运输班在换班前有装运验收时段，玛拉可带有限数量的外协维修人员入仓。
