## 二、三案是否真的不同

三案并非同一动作链改名：

- A的主要欲望是赢得冠军，翻面后主动毁掉已经赢下的商品化胜利；本质是竞技番。
- B的主要欲望是在零点前带走转子，纪存选择让万机馆成为逃亡船；本质是机甲劫案与运输大战。
- C的主要欲望是决定“谁跟谁走”，纪存放弃一次性收编机群；本质是多方冲突与战场说得。

三案的主动对手、战斗起因、高潮原则、关系压力和结尾局面均不同，差异门通过。

## 五、创作质量判断

### 方案A

最容易让玩家立刻进入机器人番剧状态，机体和玩法密度最高，也最适合作为开局第二章换气。真正难点是让比赛从第一话起就带着同一股平台压力，否则会散成四个活动。

### 方案B

行动线最强，C01起航后马上让万机馆承担一次有争议的大选择。风险也最明确：一旦作者开始解释产权、认证和追责，故事就会重新变成行政文本。正式稿必须让巨物运输和人物关系承担绝大部分信息。

### 方案C

最能建立本作独有的万机馆使命，也给纪存、七海和白鸢制造了真正持续的关系冲突。它不是最稳妥的一案：若机体选择没有被做成阵营变化、驾驶行为和清楚地图目标，就会变成主题辩论。
