## 一、章节总述

万机馆第一次离开原馆区，没有飞向宇宙，也没有立刻遇见更大的救世任务。

它先在木桶街外面停不下来。

现代泊位的固定爪卡在舰底两侧，既不敢夹紧，也不敢松开。馆守Z在闭馆夜临时装上的巡展臂出现裂纹，换下来的抓钩在装卸坪上躺成一排，像一艘百米旧舰刚刚抵达现实生活便被拆穿了底细。

木桶街不是一条只卖模型的怀旧街。外圈停着退役作业机、变形货柜车和比房子还宽的巨构零件；中圈工房能铸造全尺寸承重件；内圈才是模型、玩具、涂料、旧盒、寄售柜和吵到凌晨的收藏者。这里有人保存未开封的孤品，也有人专门把摔坏的旧机补到还能继续玩；有人靠独家拍卖维持维修费，也有人宁可把一台机器拆成三份，保证至少一台能继续服役。

万机馆必须在这套生态里找到自己的位置。

四话分别完成四种不同的机器人冒险：

1. 用一台维修教学模型留下的旧痕，找到六米实物的真实故障，再从平台货运线上夺回它。
2. 帮四台同骨架重涂机从“一个号、四种颜色”变回四台拥有不同声音、伤痕和选择的机器人。
3. 让旧拳王先堂堂正正赢下一场比赛，再从一座沿固定基座竖起的机械拍卖场手里保住胜利。
4. 由纪存主动举办第一次外部开放日，让白鸢真正进入主角团，并用全章机体正面击落一艘越过普通寄售、专门夺取工程原型和巨舰转子的取件飞艇。

章末，万机馆得到转子、外泊校正架、复产网络、第一台正式加入的新主力和前往工务城的通行。木桶街没有被搬进万机馆；它仍在原地营业，只多出一条会在以后回应巡展舰的盟友航路。

## 二、C02E01《救命零件，限定发售》

### 1. 第一站，接不上

万机馆在C01黎明起航后按来电者发来的坐标低速飞了近六小时，第一日临近中午才抵达木桶街。

街外泊位的两只现代固定爪沿舰底反复校正，最后停在离旧接口半米的位置。再往里夹会压坏舰体，松开又承受不了海风。馆守Z沿前甲板南侧的巨机坡道走下外泊坪，右侧巡展臂只完成一次抬举，接头便发出刺耳摩擦声。旧守护者昨夜换上的库存备用轮式外壳跟在坡道边缘；被横梁压碎的旧外壳没有自行复原。

旧守护者把三种情况说得很简单：舰能走，不能在风里睡；胳膊能抬，不能再挨一拳。

纪存原本想先把万机馆固定下来，再联系七海。他在私人频道里只说“到了，正在做常规保养”。七海那边有人等她进入C01撤令问询，她没空追问，只让他发一张外景。

纪存把镜头抬高，避开泊位爪和地上拆下来的臂装。

工务城的预检车就在这时到达。车门打开，一个高大的黑人男子先看万机馆，再看纪存精心挑过的取景角度。

陆衡·姆旺吉没有问谁是馆长。他从车上拖下一只磨损得很厉害的工具箱，让万机馆停机开壳。旧接口后方的主循环转子留下明显热变形，正是C01高负荷起航和终战留下的后果。低速航行还能维持，若再遇到一次急转、炮击或长时间加速，周围动力节点也会被拖坏。

“你刚才把哪一面拍给她看了？”陆衡问。

纪存把终端收起来：“比较能让人睡着的一面。”

“那她今天睡不了多久。”

陆衡拒绝为万机馆签发工务城接舰单，但给出一条现实路线：木桶街仓库里有一套退役巡展舰用六米级转子。它来自相近年代，未必能装，却值得检查。木桶街还保留旧式泊位模具和臂装端头，至少能把万机馆修到工务城愿意看第二眼。

### 2. 从巨人的脚边走进一条街

万机馆不能进入内街。玩家从馆守Z脚边出发，沿一条连续路线穿过木桶街的三种尺度。

外圈的六米转子躺在十二轴运输架上，连架超过二十吨。旁边退役作业机把整栋店面的旧屋顶吊起换梁。一辆深色货柜车停在物流闸前，车头和货柜都有年代不同的补漆。

中圈工房从屋顶伸出天车，火光隔着半条街都能看见。唐胶刚一进来，已经有人从二楼喊他年轻时的外号。他假装没听见，走得比平时快了半步。

内圈则是另一种壮观。盒子从地面堆到二楼，透明柜里有完成品、半成品、改了三遍又拆回去的机体，也有一整排物主坚持不拆封的收藏。靠墙停着一座工业测试架，外部检测线、承载铭牌和安全索都还在，里面固定着一台折叠成运输形态的两米工程原型。机内测试电池仍显示一次额定循环，物主七年没有启动它，也没有出售。

一位中年女人坐在最热闹的路口修模型。她面前摊着一份很旧的委托单，签收人仍写着她儿子生前使用的店名。儿子去世后，她花了很长时间才看懂每种零件和胶水，现在继续完成他没做完的修件。当天缺的最后一片装甲来自二十七年前远征补给清单的退役库存，兜了很大一圈才寄到木桶街。她打算在开放日那天把完成件交上跨城邮运车。

她没有说儿子回来了。

她只把装甲压实，重新写好收件地址。委托人收到成品时，可能不会知道修到最后的人已经换了。

唐胶站在旁边看了一会儿，伸手替她调了一次夹具高度。女人认出他，问当年那批教学模型是不是也经他修过。

### 3. 盒底的名字和唐胶的手

陆衡检查六米转子后发现，安装叉与万机馆旧脊柱偏差太大。官方电子手册明确写着两个批次不能混用，木桶街工房也不愿拿百米舰体冒险。

一名中年收藏者带来自己儿时卖掉、成年后又买回的维修教学模型。那批模型原本随巡展舰的家庭维修课发放，课程停办后才作为“老玩具”流入收藏市场。外盒被寄售商标成“未拆原版”，他买回后一直没有打开。他害怕里面不是自己那一台，也害怕一旦开盒，价格和过去会一起掉下去。

唐胶没有替他拆。

收藏者自己割开胶带。盒内侧还留着半张童年姓名贴，左卡扣下面垫了一片灰色斜片。唐胶一眼认出材料，也认出斜片边缘那种懒得磨圆的做法。

是他年轻时修的。

这类教学模型原本用来告诉维修员：某批巡展车总成会向一侧偏磨，安装时要留出修正。后来电子手册更新，这页被删了。唐胶为了让摔过、补过的模型还能进入正规寄售，也曾把一些维修说明写得很含糊。有人因此及时拿回了急需的钱，也有人多年后才发现，自己珍惜的维修史被平台包装成“接近全新”。

唐胶最初只想把斜垫的意义告诉陆衡。

兜灯看见他手腕在发抖，扶住他的手，却没有去碰公开页面。唐胶最后自己把旧工房的量具、材料表和关键修补位置摆到长桌上，只遮住物主姓名。

有工房员把工作灯打开，过来复做测量；也有人摘下墙上写着“唐胶担保”的牌子，表示以后不会再只凭他的名字收件。

陆衡扫描模型，但没有按比例放大任何东西。他爬上六米转子，在同一方向找到磨损和被抛平的旧焊补。模型提供的假设成立。中圈工房重新测量，用全尺寸合金另铸适配座。

唐胶把自己用了很多年的量具推给年轻工房员：“先拿去。磕坏了照价赔，别装可怜。”

那名收藏者把教学模型重新装回盒里。这一次，姓名贴朝上，修补说明也一起放了进去。

### 4. 一条只给大客户的快路

罗莎琳·维加从代哥售后仓接入。她愿意按退役件价格把转子留给万机馆，也把停产模具和附属件目录公开给木桶街。她没有许诺免费复产：若开放日拿不到真实订单，今天拆出的库存就是最后一批。

跨城平台很快发现万机馆正在抢救“心脏”。

胶价王接管街区价格屏，把普通退役件包装成“流亡巨舰唯一适配核心”。转子的货价没有改变，唯一能运走二十余吨巨件的当日重载位却被推上直播竞价，运输架也按原计划转向出城仓。万机馆可以按罗莎琳给出的价格买件，却必须在运输架驶入不可返回的出城坡道前证明自己能接货。

平台同时给万机馆开放一条付费快线，条件是整支普通车队继续留在闸后等待。

那辆深色货柜车在闸前熄火了几秒。

它没有接受快线。车头压低，货柜左右分开成为承重框，轮组沿腿侧后移。十几米高的机器人在行驶中站起，双臂扣住两边高架，身体展开成跨越两条轨道的作业门架。

“都走。”它用很旧的车队广播频率说。

普通货车、叉运车和维修车从它脚下通过。木桶街有人喊它“火种货柜领袖”。它对“货柜”鸣了一声喇叭，对“领袖”没有回答。

一台约八米的模块底盘则从工房冲出来。它还没有正式道路登记，街上暂时叫它“无牌一号”。工房为它摆出两种全尺寸模块：能挡住装卸机推击的防护肩盾，以及搬运更稳却把结构露在外面的配重叉。

玩家选择其中一项装在主侧，另一侧保留原来的旧附件。选肩盾时，它第一次过弯仍会因重心偏移栽进路坑，却能挡住装卸机的迎面撞击；选配重叉时，它搬运更稳，却必须绕开敌机正面。无牌一号从坑里或侧道重新起步，把新造适配座扣上副臂，沿运输架追了上去。

### 5. 六米巨环遮住天光

重载夺回战沿三层货运环线展开。

平台竞价装卸机从两侧争夺作业位，无牌一号和货柜领袖追着十二轴运输架向上爬。旧守护者从第六次巡展记录里找出一座已拆转台的位置；机器犬在墙后找到同型铆钉，陆衡实测后确认地基仍能承受万机馆主索。

纪存必须决定是否让刚换件未成的万机馆再次高负荷牵引。

他看了一眼仍在转向出城坡道的运输架，把两条主索放了出去。

平台的自动作业警示已经清空出城坡道。判断交付即将失败后，回收臂切断转子固定索。六米金属巨环离开运输架，从高架外侧摆向无人货运区，内街抬头仍能看见天光被它整个遮住。

万机馆从街外拉住巨环上缘；馆守Z踏上货运坪，单膝压住颤动的整段高架，以左臂托住最重一侧；货柜领袖从门架态转为机器人，双臂卡住外环；无牌一号卸掉另一片肩甲，沿倾斜梁面冲上去，把适配座扣进承点。

四个大动作在同一幅画里完成。

巨环停在城市上空，随后被送进万机馆装卸位。

### 6. 第一晚

转子没有让万机馆满血复活。它先低速旋转，确认没有偏磨，才逐渐把舰内照明从应急档提起来。

木桶街替巡展臂做了三种可换作业端头：抓钩、固定叉和地锚。兜灯反复试过后最满意固定叉，认为它比临时抓钩更适合承接大件。它们能让馆守Z拖东西、稳舰和撑地，仍然不是一只可以打必杀技的右拳。

罗莎琳完成退役件交付，提醒所有人复产订单尚未出现。唐胶在夜宵桌边发现自己的量具已经被三家工房轮着用，脸色很不好看，却没有要回来。

他顺手把外卖袋挂到新装的固定叉上。兜灯看见后立刻把袋子拿下来：“这是我刚验完的设备，不是衣帽架。”

半夜唐胶回工房取量具，发现她靠着固定叉睡着了，手里还攥着巡展臂的检查单。他没有叫醒她，只把已经凉掉的夜宵换到保温箱里。

纪存终于把真实舰况发给七海。她刚从问询室出来，看完那些他早晨故意避开的裂纹，只问：“现在修到哪一步了？”

“能到下一站。”

“我问的是你。”

纪存看了看自己满手的金属粉，回答得慢了一点。七海没有继续逼问。两人第一次因为彼此都想保护对方，反而隔出了一小段不舒服的距离。

唐胶公开维修页时，也公开了自己旧工房使用过的认证方式。平台顺着“唐胶担保”追查仍在服务的旧件，发现四台飞行机明明留下四套不同维修记录，却仍共用一个服务号。商品回收部门随即冻结其中三台的充电与空管服务，派归一星前来执行“拆三保一”。

木桶街另一面价格屏上，一段四机变形广告正在循环。画面右下角的作者署名被裁去，只剩“平台智能生成”。

## 三、C02E02《同模不是同一个人》

### 1. 一种经典，四款必收

第二天，四台飞行机同时降落木桶街。

红翼的喷气叛星、黑色近战机死锁、银白镜星和深蓝长翼雷翎共享同一套基础骨架。它们完成完全一致的变形起手时，连老玩家也会先看颜色。

胶价王已经把画面剪成广告：

> 一种经典，四款必收。

街边有人喊“红色果然快”。喷气叛星来不及得意，便冲过停机线，绕了半条街才刹回来。镜星替它清空交通频道，死锁假装没看见，雷翎在远处说：“红色不是快，是刹车晚。”

笑声很快停下。

四座充电架只有一座开启，空管屏只显示同一个控制号，三台机体被物流闸判作“重复资产”。平台允许其中一台继续服役，其余三台将作为同模备件回收。

### 2. 当年的召回救过人

镜星的老驾驶员莉亚·陈来到维护仓。她没有把平台的错误全部推给七海。

多年前，这批骨架曾出现空中锁翼故障。莉亚亲历过一次失控，七海签发的召回令让后续机体停飞，也确实避免了更严重的事故。问题在于召回后的四台机体走了完全不同的修复路线：

- 喷气叛星的左翼补过三次，速度更快，也更难停。
- 死锁换上取消英雄方案的近战臂，机体平衡已经改变。
- 镜星增加双重敌我识别，长期负责替其他三台收拾空域。
- 雷翎为了远射改成长翼，几乎放弃低速近战。

平台为了节省维护成本，把四次维修重新压回当年的一个召回号。代哥商品回收部门据此委托归一星执行“拆三保一”。

纪存主动联系七海。

七海把自己当年签过的原始召回和后续四份维修记录公开，姓名没有隐去。原召回仍保留“当时有效”的结论，四份维修则把今天的四台机重新分开。木桶街管理方承认四个呼号，关闭统一调度；归一星却先一步占住三座服务塔，继续以备用电源维持“只留一台”的空管规则。

文件让四台机有了反抗的理由，三座塔、地面主钥和归一星的回收索仍要在战场上夺回来。北塔、直播飞艇和归一星背部中继成为三处可自由选择攻略顺序的目标；四台机都能夺点，速度、近战、识别和射程则决定不同路线的难易。

### 3. 作者从广告里把手伸回来

胶价王的广告突然黑屏。

一份跨国权利申诉覆盖画面。署名是`Evelyn Voss`，中文发行名为白鸢。她指出平台使用了自己多年前为同骨架机设计的变形分镜，却裁掉作者、修改结尾，并把作品标成系统生成。

纪存终端里也缓存着那份分镜。他立即停用，没有先拿“现在要救人”作借口。

他把四台机体的当前照片、维修差分和现场视角发给白鸢，同时附上四台机体对战术使用的同意。白鸢没有恢复原广告。她重新画了一张非常简陋的当前候选图，只保留共同起手和四条没有收尾的线。

四台机体自己补完最后一步。

喷气叛星把终点画得更远；死锁直接划掉英雄式落地；镜星先绕去保护一艘被困的交通艇；雷翎把最后一枪移到城市合并域之外。

白鸢第一次看见一张自己的图被四个人改成四种样子。她没有撤回许可，只要求保留修改痕。

### 4. 归一星的答案

归一星从高空下降时，四根回收索先于身体展开。

它没有把四台机体都当成废件。它护在镜星前方，把银白机判为最接近原始设计、维护成本最低的“保留体”，另外三根回收索则直接扣向红、黑、蓝三机。

“四台都修，谁付下一次的钱？”归一星问。

罗莎琳承认自己过去也支持过合并维护。她的小批复产方案更慢、更贵，必须靠足够订单才能成立。归一星的拆三保一至少会让一台活下去，只是它从来没有问另外三台愿不愿意成为零件。

纪存就在这时看见了一个不属于任何单机的片段。

同一条生产线上，四副相同骨架依次翻身；同一套机械臂落下，同一段测试动作反复播放。片段只持续一瞬，他甚至不能判断是记忆还是眩晕，却因此明白归一星为什么能提前封住四台机的下一步：它只看共同过去。

纪存盯着四台机今天的翼、臂和热量警告，提出反过来利用共同起手。四台机先把同一套过去完整给归一星看。

### 5. 同样开始，各自结束

玩家夺回三处中继后，四台机体主动执行同一套变形起手。

归一星的四根回收索同时射向标准落点，三座服务塔也把空域封成同一条路线。

下一秒，四机从四个方向炸开。

喷气叛星拖着两根索穿过直播飞艇，冲得过头，补翼警报一路尖叫。它没有再转第二圈，而是反向翻转，让索头缠住飞艇中继。

死锁没有追驾驶区，取消英雄方案的近战臂插进归一星背部。臂与骨架不完全兼容，第一次重击后便卡在半开位置，它干脆把整条臂留在装甲里，借爆破劈开控制发生器。

镜星先放弃最接近Boss的路线，冲向一艘被合并空管困住的交通艇。它把归一星识别码反射给回收群，再将四个独立呼号送回空管。双识别器过热，银白外甲冒出白烟。

## 四、万机馆故障与三项资源

### 4.1 为什么刚到木桶街才发现转子问题

C01只证明旧引擎能可靠抵达一个邻站。抵达后，现代泊位夹具无法合拢，工务城因此派陆衡做预检。拆开旧接口时才能看到主循环转子的热变形。它不是突然坏掉，也不制造倒数：继续低速移动可以，下一次战斗机动可能带坏周围动力节点。

### 4.2 为什么不是换一枚小密封环

本章主要故障是六米级主转子、旧式泊位和开裂巡展臂装。三者都能在外景中看见，并足以决定百米舰能否航行、停靠和作业。

### 4.3 为什么木桶街不能一次修好全部

- 转子是退役同型件，只恢复有限航行。
- 外泊校正架仍需工务城对百米舰实装。
- 巡展臂三端头只是作业工具，不是战斗右臂。
- 正式接舰与长期航行许可需要公开测试和工务城复核。

## 五、模型到实机的因果链

1. 收藏者的教学模型来自真实巡展舰维修课程，内部斜垫记录某批次偏磨。
2. 物主自己开盒；唐胶凭材料和手法认出旧修补，只能提出假设。
3. 陆衡在六米转子上找到同方向磨损和被抛平的旧焊补。
4. 工房按实物重新测量，用全尺寸材料另造适配座。
5. 兜灯完成万机馆停机和安装验收。
6. 模型回到收藏者手中，姓名贴和修补史保留。

**更简单办法为何不行：** 电子手册删掉了该批次修正；强装会毁掉新件和舰体。模型不是答案，只是让工程师知道去哪里找证据。

## 七、E01物理因果

1. 罗莎琳能按退役价放出代哥名下转子，但平台拥有仓储运输合同；自动作业先封闭无人货运坡道。
2. 交付要求万机馆证明装得上，并在运输架进入出城坡道前完成接货。
3. 平台装卸机争夺作业位；货柜领袖开放公共通道，无牌一号携适配座追车。
4. 旧守护者从巡展记录指出墙后重载基座，机器犬找到同型铆钉；陆衡测出基座仍可承力。纪存不靠幻听地基。
5. 回收臂在无人货运坡道上切索后，巨环向外环摆动，不越过仍有人活动的内街。舰索、馆守Z、货柜领袖和无牌一号分别承担上缘、地基、外环和适配座。

**为什么不用馆守Z直接抱回去：** 它只有左臂和不能承受战斗冲击的巡展臂；二十余吨巨环在摆动时会把单臂机体拖下高架。四方分担才成立。

## 八、E02物理与权限因果

1. 四台机魂和身体始终独立；一个服务号只让一台获得充电、空管和维修配额。
2. 七海公开原召回与四次维修，证明平台用错了今天的对象。文件本身不会让护盾消失。
3. 木桶街管理方承认四个呼号并关闭统一调度；归一星先一步占住三座服务塔，以备用电源继续执行“只留一台”。三座塔是可自由选择攻略顺序的地图目标，玩家随后夺塔并保护地面主钥。
4. 民用空域在开战前关闭；最后一艘已经进入走廊的交通艇必须被送出。北塔是无人中继，直播飞艇改为远程控制，主钥柜位于人员已撤出的维护区。
5. 白鸢先发停止使用通知。纪存停用盗版页并取得四机同意后，她才发一张当前候选图。
6. 四机各自改末格，先打破归一星按标准落点布置的第一轮。
7. 归一星约16米；胸前托架只能固定一台收拢机翼的13米同骨架机。它能学习已经发生的收招。第一阶段完成后，它把过热镜星扣在外部托架上；第二阶段由玩家分配三台机牵引、切索和压制，打开至少两处脱离点后，镜星才从内部恢复同伴呼号。
8. 纪存短暂看见共同生产线，只帮助他理解敌方第一轮判断来源；反预测和救援仍根据四台当前改装与现场选择完成。

**为什么不能只改数据库：** 三座中继、主钥、充电架和归一星回收索仍在物理执行服务合并，必须由现场夺回。

## 九、E03物理因果

1. 旧拳王与百刃分别约3.6米和3.8米，能在同一拳台按同一规则比赛。
2. 影子陪练的旧集锦让拳王落点固定；纪存从完整录像中看出“等对手恢复承重”不是程序卡顿。失败录像提供的是新动作选择，不是数值加成。
3. 赛事只交付票房和保证金。外泊校正架仍因旧债扣在固定地下基座的侧仓；公共港测试资格尚未取得。
4. 旧拳王拒绝不可退出的独家巡演后，观众撤入独立安全层。固定地下基座不移动，只有竞技台和升降框升到地表服务院并组合成二十米巨台。
5. 小拳王不能正面对轰巨台；百刃用两片透明翼卡住右侧承重支架、货柜领袖和无牌一号从相反方向拉住校正架、影子预告巨锤共同提供登顶条件。纪存以承重指示确定起跑时机，玩家完成绿灯起跑输入。巨台只能转动上部设施和挥锤，不能从固定基座迈步。
6. 巨台被毁后，旧拳王的拒绝触发次日批量取件，直接发动E04。

**为什么比赛和巨台战必须分开：** 前者回答谁打得更好，后者回答旧拳王拒绝独家巡演后，平台能否把校正架和拳馆的未来使用权一起拿走。地下基座没有移动，竞技台战后仍能降回原处维修。两场战斗的胜利条件、尺度和情绪都不同。

### 白鸢

1. 白鸢在C02只能使用自己亲眼所见，或得到明确授权的试航录像、现场摄像、地形与风况。
2. 她把这些输入移动模拟台，跑出三套候选动作；清仓鲸从与试航资料不同的高度入场后，第一套路线当场撞上货柜塔并作废。
3. 余下两套由驾驶员和街区调度员修改后执行。终端只负责把路线叠到实景，不能替机体下指令。
4. 未发售样件本来是两米全尺寸工程原型，运输时固定在有承载铭牌、真实磨损和安全索的工业测试架；机内短时测试电池仍有一次额定循环。它不是玩具变大，控制器也不决定它有没有人格，货柜领袖声纹不为它供电。
5. 清仓鲸抓起测试架并切断外部供电后，样件切入内置电池自行解除固定。玩家在固定节点间使用移动、支撑、变形和交互，取回旧控制器、沿抓臂移动并打开检修口；白鸢根据实时摄像另画撤离草图，样件选择背离草图，证明白鸢没有控制现实。

### 开放日

1. 旧拳王拒绝独家合同后，平台发出次日批量取件通知。纪存主动多停一天，以真实订单启动复产，并用公开演示争取公共港测试。公共港远程验收席在开场前声明：必须完成一次载人区外的转向、牵引和紧急停机记录。
2. 物主在战斗前选择出售、短借、展示后带回或不参加；木桶街管理席将当天清单送入平台本地结算席，真实成交与修件母亲的邮运包裹进入独立地面路线。
3. 清仓鲸按旧寄售、自动续约和场馆债务取得进场资格，并提前发出自动作业警示；其取件优先级却被白色组件改成工程样件、维修数据和新转子。观众撤入加固参观廊，战斗开始时内街没有普通人。
4. 六座展位已在战前分开并接好缓降线。第一阶段，清仓鲸跳过普通寄售、拔起中央测试架；模块吊装机“拼装诸侯”依次释放六座展位，并把三条应急索扣到测试架吊耳，索尾接入下方清空的缓冲架和地面绞盘；馆守Z固定叉和货柜领袖共同承接测试架。三索只负责断电后的受控下降。
5. 第二阶段，飞艇抛下货柜墙并以磁索反拖馆守Z。固定叉折断，兜灯抛叉保住肩座，改用地锚。
6. 第三阶段，清仓鲸转向万机馆新转子护罩。纪存以新转子驱动万机馆沿西侧清空扇面转艏约三十度；船尾三点夹具、岸侧承力座、舰索和地锚共同受力，把Boss拖离主街，旧拳王沿锚索攻入腹部。
7. 取件核被毁后，三条应急索把测试架降入缓冲架，飞艇迫降东南无人装卸区；核内白色组件的表层材料与C01原馆区清障队封存的白色衬片检测记录一致。木桶街管理席与平台本地结算席以当天物主清单替换清仓鲸携带的旧批量名单；已到账的票房改作旧场馆欠款的分期首款。公共港远程验收席收到转向、牵引和停机记录，开放下一站测试泊位。合法车队始终沿独立路线离开。

**为什么不能直接关闭平台：** 木桶街日常仍依赖平台物流，罗莎琳复产也需要跨城配送。战斗阻止的是一架已经开始实体拆取的自动设施；旧合同、默认续约和平台替代方案留到战后处理，不占Boss战胜负条件。
