# C02E01 S3 主笔简报 v1

## 一句话胜负

主转子即将越过最后一道岔进入拆解桥；玩家用无牌一号夺取并守住道岔，把转子导入合作社旧泊位线，再由货柜领袖、馆守Z和万机馆共同接住失衡的巨环。

## 入口与空间

紧接S2。纪存已在八米级无牌一号的控制位内，负责方向和动作，低权限竞技AI负责平衡。玛拉留守中央安全台，按无牌一号的行进方向清场和断电；唐胶赶往旧泊位末端恢复接货机构；兜灯留在万机馆上。战场只保留四个一眼可分的区域：合作社仓区、环形货运线、桥前道岔与拆解桥、外侧旧泊位及其上空的万机馆。

## 对抗为什么成立

四台平台白色货运机拥有车载动力，任务是把运输架送入拆解桥。它们不会开枪杀人，但会把无牌一号识别成侵入运输区的巨型障碍，使用货叉、推臂、锁链和自身重量将它推出轨道。桥前防护机负责锁住道岔。玩家不能摧毁民用机，也不能让转子滚入仓街。

## 三段战斗功能

1. **追上：** 无牌一号离仓，玩家第一次感到八米机体的重量和竞技底盘的灵活；必须突破货运机的阻挡，真正发生一段机器人近身对抗，而不是只跑到开关旁。
2. **夺岔：** 无牌一号到达桥前，与防护机争夺能扳回旧泊位线的巨大实体道岔。玩家必须通过一次清晰、漂亮、属于这副竞技身体的动作赢得位置，并守到运输架前轮通过。
3. **接住：** 改道成功不等于胜利。巨型转子因速度和转向失衡，运输架向仓街一侧倾斜；这时货柜领袖必须以真正的作业变形形态参与，兜灯必须主动让130至160米的万机馆压到外泊上空，18米馆守Z则从舰艏用左臂和临时右臂的锚定、拖曳能力参与。四种尺度完成同一个肉眼可懂的大动作。

具体怎样打赢、怎样失衡、三台机如何接力由主笔创造，不必逐项照抄动作。每段只保留一个主要视觉问题，让初次读者能跟住位置和目标。

## 角色与能力边界

- **纪存：** 此刻只在无牌一号内，不能同时驾驶万机馆。他要从生疏变成敢于作出一个关键动作，但不在一场里变成王牌驾驶员。
- **兜灯：** 负责万机馆飞行与舰上安全，最后的大尺度决策由她主动做出，不只是批准纪存的请求。
- **唐胶与玛拉：** 一人在旧泊位恢复接货，一人在安全台清场；两人的现场判断可通过战中通讯改变路线。
- **货柜领袖：** 有独立人格与全尺寸载具身体，可进入作业变形形态；本场是自主友军，不宣布永久入队。
- **馆守Z：** 18米、自主行动、原右臂缺失。黄色临时右臂可锚定、抓持、拖曳，不能打拳或独自承担整具转子。
- **万机馆：** 130至160米低矮巡展载舰，尚非人形。仍悬在不匹配的泊位上方，可做一次明显的舰体悬停转向和承重，不做精密机械杂技。
- **无牌一号：** 不获得C03才确定的永久作业模块；可以使用基础竞技身体和现场原有的简单竞技器材。

## 场尾

转子完整进入合作社旧泊位线，由恢复的接货机构和现场工班接管；所有人和民用货运机均存活。平台运输任务失败，随即冻结合作社的仓储权限。S4从战后众人面对“有实物胜利、却仍缺系统证据”的局面开始。

## 写作要求

写成约2500至3800汉字的连续Reader战斗场。战中通讯只服务眼前动作和人物关系。让机体身体、尺度和选择承担戏，不用作者旁白解释“这很燃”。结尾不要提前写S4的母亲、维修页或公开决定。
