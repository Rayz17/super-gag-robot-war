# C02E01 S5 主笔简报 v1

> 本简报暂不交给主笔。待用户选择并完成S4后，与被选S4出口一并使用。

## 共同入口

唐胶已经发送四位实机物主分别授权的维修页、自己的材料方法与签名；修件母亲已经决定最后委托的寄件署名；纪存以万机馆频道作为共同发布者。合作社因此取得紧急人工复核资格，但四台重涂实机也已经能被平台对应到现役机体。

主转子仍固定在合作社旧泊位线上，尚未装入万机馆。平台冻结的是仓储、邮运和平台设备权限；旧泊位接货机构与合作社工班已在S3恢复，仍可完成眼前的实体吊装。

## 本场必须兑现的三件事

### 1. 完整而具体的胜利

现场工班使用S3恢复的两侧接货臂，将直径约十二米的主转子整体抬入万机馆打开的侧部检修口。只写一个宏观吊装画面和几个人人看得懂的确认动作，不展开内部机构。兜灯确认固定完成后让转子低功率启动；万机馆停止持续失温，一侧长期熄灭的舷窗从前到后重新亮起。

这只恢复有限航行与循环。泊位仍不匹配，舰体仍需到工务城做全长校正；胜利不能被写成免费解决所有问题。

### 2. 战后人物余波

纪存离开无牌一号后身体应有真实的初次操作反应，但不演成重伤。玛拉、唐胶、兜灯或七海至少有一段短而自然的关系动作，承接刚才共同涉险与公开选择。七海可从远程发现纪存此前把舰况说轻了；她不能替平台解冻，也不使用“替谁决定”式主题句。

### 3. 两个不同来源的下一话钩子

- **四机召回：** 平台把已授权维修页与现役仓储接口对应。只切到四处不同机库同时收到召回、夹具合拢或局部机翼自行启动；不报齐喷气叛星、死锁、镜星和雷翎四个姓名，不让它们提前完整出击。E02再正式亮相。
- **白鸢作品痕迹：** 万机馆公共频道把仓库安全示范屏上被裁掉署名的旧分镜一并传出。白鸢本人不出现，只发来清楚的停止使用通知：画稿属于她，流传版本删了署名和一页，她会在公开拍卖前到场。她不声称自己影响了S3战斗。

## 场尾

本话先让玩家看见万机馆真正恢复一侧灯光，再让四处机库的召回提示依次响起。完整胜利在前，反咬在后。最后一个画面应明确发动E02，而不是用抽象系统术语收尾。

## 写作范围

约1200至1800汉字。与被选S4正文可在同一次主笔调用中顺序写出。主笔可自行决定人物短场与两个钩子的前后次序，但不得新增组织、机体、万能安装技术或白鸢能力。
