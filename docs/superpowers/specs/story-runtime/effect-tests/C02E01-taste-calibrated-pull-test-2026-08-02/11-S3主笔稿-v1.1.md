# C02E01《救命零件，限定发售》S3主笔稿 v1.1

无牌一号迈出侧仓。

第一步落下，整个控制位都向前沉了一截。纪存本能地把两根动作杆同时往后拉，八米高的身体顿时僵住，左脚还在地上，右脚已经抬到一半。

“别扶它走路。”玛拉的声音从通讯器里传来，“你只管想往哪儿去。”

仓门外的警示灯转成绿色。通往环形货运线的隔离栏依次缩回地下。

纪存松开一半力道，向前推杆。

无牌一号晃了一下，自己放下右脚，膝部随即压低。第二步比第一步快，第三步已经踩过仓门标线。它的肩甲擦着门框掠过，把悬在上方的塑料促销牌撞得转了三圈。

“我没撞人。”纪存说。

“牌也不是人。”玛拉说，“继续。”

转子已经走过大半条环线。断电后的旧轨道不再助推，四台白色货运机拖得吃力，车腹的备用灯全亮着。它们刚过下一处弯道，最后方一台便转动传感器，发现追来的无牌一号。

货运机脱开运输架，横在轨道中央。两根货叉同时升起，像一扇白色的栅门。

纪存让无牌一号减速。货运机却先冲了过来，货叉顶住它胸口下缘，车轮发力，硬要把它推出运输区。

八米机体的脚掌在地上擦出两道灰痕。

“它在推我！”

“因为你挡路了。”玛拉说，“右边断电区已清空，能让。”

纪存朝右侧一带。无牌一号立刻侧身，动作快得他自己都没跟上。货运机的推力从胸前滑开，车头冲过半个身位。

他看见了空隙，刚想控制双臂去抓货叉，无牌一号的手肘却一高一低，差点把自己的左腕别住。

“别管手指了！”玛拉喝道，“推大的！”

纪存干脆压下整根右臂杆。

无牌一号用前臂架住一根货叉，腰部顺着来势转开。白色货运机被带得偏离轨道，直冲右侧空仓。它紧急刹车，轮胎冒出一股白烟，停在距离墙面不到一米的位置。

无牌一号已经从它身后穿过。

“这也算没撞？”兜灯问。

“它自己开的。”

“你现在很像唐胶。”

刚被甩在身后的那台货运机重新追了上来。这一次它没有迎面推来，而是从车尾甩出两条装卸锁链。链头在地上弹了一下，缠住无牌一号右脚踝。

纪存才跑出一步，机体便被向后猛拽。视野骤然倾斜，环形货运线从屏幕中央滑向右上角。

他两手死死握住控制杆。

无牌一号却没有直挺挺摔下去。它左膝先跪地，右手撑住轨旁护墙，将八米高的身体稳在离地不足半米的位置。锁链仍在收紧，货运机拖着它往仓街方向挪。

纪存看见右手边那段护墙的尽头立着一根废弃的吊装柱。

他没有去解脚上的链，只让无牌一号撑地转身。

机体以跪地的左膝为轴，右腿向外扫过半圈。缠在脚踝上的锁链随之绕上吊装柱。货运机继续后退，链条迅速绷直，车尾被自己的绞盘拉得横了过来。

“停下！”纪存喊。

货运机的轮组立刻反转，却已经晚了。它被锁链拴在柱边，只能原地磨动四只车轮。

无牌一号站起身，抬腿挣出已经松开的链圈。

拆解桥的长鸣再次响起。转子前方，只剩最后一台里程牌。

“还剩三分钟。”玛拉说，“桥前人区已经清空。道岔旁有防护机，它在锁轨。”

纪存把两根动作杆一并推到底。

无牌一号沿环线加速。最初几步仍然沉重，随后那副竞技底盘像是终于认出了奔跑：上身向前压低，双臂自然摆开，脚掌每一次落地都恰好踩在轨道外侧的混凝土带上。十二米巨环在前方越来越大，转动的外缘不时遮住拆解桥的红灯。

另一台护送货运机守在运输架后方。它展开两侧推臂，想把无牌一号夹向护栏。

货柜领袖从侧线冲了出来。

它在两台机体之间猛然抬起车头。原本平伸的车头立起成为胸身，两侧货柜展开成粗壮的作业手臂，中央货柜框架收拢到背后；车轮分列在双腿外侧，四根支腿落地撑稳。转眼间，一辆重卡已经站成十余米高的作业机器人。

货柜领袖侧身踏进推臂之间，一手托住下方，一手抓住上沿，将白色货运机的车头稳稳挡在原位。它没有扭断推臂，只把两条机械臂向两边分开，为无牌一号撑出一道入口。

“走。”货柜领袖说，“我只替你开这一次门。”

纪存没有减速。

无牌一号收紧双肩，侧身挤过两车之间。白色推臂擦过它背甲，刮出一道长长的白痕。下一秒，它已越过运输架，与巨型转子并行。

转子遮住了纪存左侧的全部视野。隔着不到一臂的距离，外圈上的旧吊痕和补过两次的护板从他眼前缓慢移过。它并不是仓库里一件等待处理的零件了，而是一堵正在向拆解桥移动的金属墙。

桥前道岔终于出现。

一台低矮的黄色防护机伏在分岔中央，四只锁脚钉进地面。实体道岔的长柄被它压在车腹下，两侧还有两根粗推臂扣住柄端。远处的拆解桥已经完全张开，入口内的切割架亮起蓝白色预热光。

“它锁得死吗？”纪存问。

“对货车够死。”玛拉说，“对你，看你会不会用腿。”

无牌一号跃下环线外沿，直冲道岔。

防护机抬起推臂迎击。纪存想起模拟设备里那些规整的闪避路线，向左带杆，屏幕边缘却立刻跳出仓街护栏。向右是还在移动的转子，根本没有绕行空间。

只能从正面过去。

他让无牌一号压低身体。黄色推臂撞上双肩，巨响震得控制位里的观察屏一齐发白。防护机四只锁脚牢牢咬住地面，无牌一号却仍被顶得后退。

转子的前轮距离道岔只剩几十米。

“纪存，别跟它比推力。”唐胶的声音忽然接入，喘得厉害，“竞技底盘是拿来换位置的，不是拿来当墙。”

“你那边怎么样？”

通讯里传来扳手落地的声音。

“接货机构开了一半。你先把东西送来，另一半我骂开。”

防护机再次抬臂。纪存看着那两根并排逼近的推臂，忽然放松控制杆。

无牌一号没有倒下。低权限AI接过平衡，让机体顺着推力向后退了半步。

就在防护机追着向前压时，纪存猛地让身体向右转。

无牌一号双手抱住一根推臂，左脚踩上防护机车头边缘。它没有硬拔对方的锁脚，而是借着推臂上扬的力量腾起身体，腰腿从黄色车顶上方荡过。八米高的机体像跨过一件竞技器械，翻到了防护机背后。

落地时，它的右脚正踩在道岔长柄外侧。

纪存向后拉杆。无牌一号双手抱住长柄，整个身体坐低，背部抵住防护机。黄色推臂反向扣来，卡住它的肩膀；双方一前一后，围着那根长柄同时发力。

长柄先是一动不动。

转子前轮已经逼近分岔口。

纪存咬紧牙，再次把动作杆拉到底。无牌一号的双脚在地面慢慢滑开，膝盖几乎压到胸前。防护机的车轮发出刺耳尖响，四只锁脚中有一只被拔出了地面。

还不够。

纪存看见道岔旁的维修架上挂着一根红色道岔检修杆。它比无牌一号的手臂还长，一端正好朝着他。

他松开一只手，抓下检修杆，将尖端插进长柄下方的承力孔。

防护机立刻把另一根推臂压向检修杆。

“那就一起压。”

纪存不再向后硬拉。他让无牌一号踩住道岔底座，整副身体沿检修杆向上撑起。防护机的推力反而成了另一端的重量。

红色道岔检修杆骤然下沉。

实体道岔发出一声沉闷巨响，长柄越过中点，重重倒向旧泊位线一侧。分岔钢轨在转子前方完成咬合。

无牌一号也被反弹的力量掀离地面，后背撞上防护机。两个巨大身体一起翻向空置的检修坪。纪存慌忙抓住控制杆，机体却先伸出左臂撑地，带着防护机滚过半圈，把它稳稳压在没有轨道的一侧。

没有碾碎，也没有摔进仓街。

“道岔到了！”玛拉喊，“守住它，等前后轮全过去！”

运输架的前轮驶上分岔。两台仍在拖行的白色货运机同时转向，巨环开始偏离拆解桥。

被压住的防护机伸出推臂，重新去够道岔长柄。无牌一号翻身跪起，用红色道岔检修杆横卡在两根推臂之间。另一台挣脱吊装柱锁链的货运机也从后方赶到，货叉顶住它腰部。

纪存的身体被安全带勒得发疼。无牌一号一手压着检修杆，一脚抵住货叉，另一脚牢牢踩在道岔底座上。

转子像一轮缓慢转向的金属月亮，从它身边擦过。

前轮过去。

中轴过去。

最后一组轮子轰然压上分岔。

“全过去了！”玛拉说。

纪存松开检修杆。无牌一号借着货叉的推力向侧面一滚，离开轨道。防护机终于扳回长柄，但运输架已经完整进入旧泊位线。

拆解桥的切割架在空轨前落下，蓝白光只照亮了一片什么也没有的地面。

纪存刚喘出一口气，唐胶突然在通讯里喊：“别高兴！旧线弯得太急！”

转子脱离主环线后，前方货运机已经转入旧泊位，后方运输架却还带着原来的直行惯性。十二米巨环在支架上向仓街一侧倾斜，外圈越过安全栏，大片阴影压向模型店屋顶。

两台白色货运机同时刹车。急停反而让运输架倾得更快。

无牌一号从地上撑起，扑向运输架尾部。它双手推住支架，脚掌在轨旁一路滑行，只能把巨环倒下的方向稍稍拖回。

“我撑不住！”

旧泊位尽头，唐胶站在一组锈迹斑斑的巨大接货臂之间。左侧接货臂已经张开，右侧只抬起不到一半。

“让低的一边先进来！”他挥动手里的信号灯，“右边机构没醒，别把重量全给我！”

货柜领袖甩开白色货运机，以作业机器人形态沿旧泊位线大步追上。

它从巨环倾斜的一侧踏入轨道，转身背向压下来的外圈。背后的货柜框架向两侧展开成承重背架，双臂向后抱住运输架横梁；腿侧车轮同时锁死，四根支腿从小腿旁落下，钉住轨道两边。

“把低的一边给我。”

货柜领袖屈膝迎住重量。巨环压上它的背架，十余米高的身体被压得向下一沉，两只脚掌和支腿一同陷进轨旁软垫。

无牌一号趁势推动运输架，把低侧向已经张开的左接货臂送去。

可巨环上端仍在继续倒向仓街。

万机馆的阴影忽然越过旧泊位。

“馆守Z，解开安全缆。”兜灯说。

玛拉抬头：“那是你们现在唯一拴住舰体的东西！”

“所以得趁推进器还撑得住时自己过去。”

馆守Z松开黄色临时右臂抓住的安全缆。失去最后一道牵引后，万机馆在空中明显向外漂移，舰腹各处的推进器随即同时加力。

一百多米长的低矮舰体没有再停留在不匹配的泊位上方。它保持舰艏朝向，依靠自身推进器整个横移出去，缓慢而明确地压向外侧旧泊位。巨大的舰影越过仓顶、货运线和倾斜的转子，最终覆盖接货区。

气流掀起轨旁防尘布，也把模型店的遮雨棚压得紧贴屋顶。

馆守Z站在舰艏边缘。

它先将黄色临时右臂的锚索射向巨环上沿。锚头扣住一道旧吊装孔，索缆瞬间绷直。随后它俯下身体，左臂越过泊位外沿，张开的手掌抵住转子最高处。

巨环猛地一沉。

馆守Z的右肩被拉向前方，脚下舰艏也随之下压。万机馆没有后退。兜灯让整艘舰保持推进，以宽阔舰身承住锚索传来的拉力。

“Z，左边只扶方向！”她说，“重量给舰体！”

馆守Z调整左掌，不再硬托，只把巨环推回接货臂正上方。

下方，货柜领袖的承重背架托住最低点；无牌一号抵着运输架尾部，将最后一组轮子推入泊位；上方，馆守Z以双臂固定倾角，绷紧的锚索把最重的一股力量传给悬停的万机馆。

四种不同尺度的机器围住同一具巨环，谁也没有独自承担全部重量。

“右边开了！”

唐胶踹下最后一根机械锁销。沉睡多年的右接货臂在一阵铁锈碎落声中猛然抬起，与左臂同时扣住运输架底座。

巨型转子向下落了半米。

两侧接货臂一齐压低，液压缸发出长长的泄力声，终于把它稳在旧泊位线中央。

馆守Z松开左掌，右臂锚索缓缓放长。货柜领袖收低承重背架。无牌一号仍扶着运输架，直到唐胶举起绿色信号灯。

“接住了。”他说。

环形货运线上的白色货运机停止前进。防护机从检修坪翻正身体，传感器依次扫过已经进入合作社泊位的转子，最终收回推臂。四台货运机和防护机都还在，只在车身和轮胎上留下了擦痕。

现场工班从安全门后跑出，将新的固定锁一根根扣上运输架。

纪存松开动作杆。无牌一号也慢慢放下双手，站在那具终于不再移动的巨环旁。

中央安全台响起一声短促提示。

玛拉腕上的清场画面全部变成灰色，只剩平台刚刚下发的一行通知：

`清仓运输任务失败。木桶互修合作社仓储权限已冻结。`
