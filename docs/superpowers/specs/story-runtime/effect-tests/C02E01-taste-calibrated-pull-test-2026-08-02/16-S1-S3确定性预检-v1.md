# S1-S3确定性预检 v1

## 结论

`PASS_WITH_THREE_MECHANICAL_FIXES`

本预检只检查事实、位置、数量、尺寸和生命周期，不评价S4情绪方案，也不替代完整E01冷读。

## 时间与因果

- S1发生于午后；S2紧接转子被拖走；S3在拆解前的同一连续时段完成，没有跨日或无说明转场。
- S2依次尝试产权凭据、买回、租借、人工复核、轨道断电和远程改岔；纸面争议成立但赶不上实体拆解，进入战斗具有必要性。
- S3胜负可用一句话复述：无牌一号夺下桥前道岔，把转子导回旧泊位；四种尺度机体共同接住转弯失衡的巨环。

人物没有瞬移、串台或同时控制两个身体。

## 机体与尺寸

- 万机馆：约130至160米；始终为悬停载舰，未写成人形。S3使用舰体横移和悬停承重。
- 馆守Z：18米；始终站在舰艏，没有在通道未接时擅自下舰。黄色临时右臂只锚定和拖曳，没有出拳或精密作业。
- 主转子：本轮Candidate直径约12米，与S1“接近第四层步道”相容；从仓内运输架到环线、道岔和旧泊位的路线连续。
- 火种货柜领袖：全尺寸载具身体，S3进入十余米作业机器人形态；本话仍为自主场景友军，不宣告永久加入。
- 无牌一号：8米级全尺寸竞技底盘，不由模型放大；纪存只使用基础身体和现场道岔检修杆，没有提前获得C03永久模块。
