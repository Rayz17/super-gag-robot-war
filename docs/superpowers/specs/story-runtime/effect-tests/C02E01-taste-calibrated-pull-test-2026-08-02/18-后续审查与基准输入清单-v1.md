# 后续审查与基准输入清单 v1

## 完整稿形成方式

用户选定S4方案后：

1. 恢复同一正文主笔Agent。
2. 只交付S3确认出口、被选S4方案、S4/S5正向简报与必要人物事实。
3. 一次调用顺序完成S4正文和S5。
4. 由制作席机械合并S1、S2、S3、S4、S5，不进行二次风格拼写。

## 确定性校验

- 人物在场与控制权：纪存、唐胶、玛拉、兜灯、七海、修件母亲、白鸢痕迹。
- 生命周期：无牌一号首控但不提前获C03模块；货柜领袖只作自主友军；四重涂机只预警不提前正式行动；白鸢不提前到场。
- 空间尺寸：万机馆130至160米、馆守Z 18米、无牌一号8米、货柜领袖十余米作业形态、主转子约12米。
- Canon边界：模型不巨大化；馆守Z右臂未恢复；万机馆不变人形；七海不替平台授权；白鸢不改现实。
- 对白确定性脚本与禁用语义扫描。

## 独立冷读

冷读席只读取C01已知出口、完整新E01和已校准提示词。先闭卷复述：

- 为什么来木桶街；
- 为什么纸面办法赶不上；
- S3玩家做了什么并怎样取胜；
- 唐胶为什么公开；
- 母亲具体完成了什么；
- 转子最后到了哪里；
- E02为什么立即发生。

不得读取Canon、场面链、简报或本测试评价。

## 机战与游戏审查

只检查：

- S3是否能成为SRPG关卡，而非动作小说；
- 无牌一号、货柜领袖、馆守Z和万机馆是否各自以身体改变胜负；
- 尺度差是否可感；
- 玩家目标、阶段变化和胜利反馈是否明确；
- 机体人格、变形文化和构筑机快感是否成立。
