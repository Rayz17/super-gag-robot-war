# S2白话门 v1

## 闭卷事件复述

合作社拿出主转子的原始寄存单，平台调度承认争议已经登记，却拒绝撤回已经成交的清仓运输。人工复核赶不上拆解。玛拉切断旧轨道供电，只让运输架和平台货运机减速；平台货运机启用自带动力继续前进。唯一能避开拆解桥的旧泊位道岔被平台远程锁住，巨物运输期间人行通道也已清空封闭。玛拉必须留守安全台，唐胶必须先恢复旧泊位接货机构，因此她把无牌一号的实体钥匙交给有模拟操作经验的纪存。纪存进入控制位，玩家获得首控，目标是赶到道岔并把主转子完整送回旧泊位线。

## 判断

`PASS_TO_S3`

- 主行动者、实物、时间压力与行动目标可以一次复述。
- 普通方案确实被尝试，失败来自权限差与移动中的物理事实，而非角色集体失智。
- 纪存、玛拉、唐胶与兜灯各有不可互换的当场职责。
- S2没有提前写出S3的具体胜法。

## 仍需由S3兑现

- 无牌一号必须真正像机器人作战，而不是只跑去扳一个开关。
- 货柜领袖、馆守Z和万机馆都必须以身体参与同一胜负，不能成为远程口头支援。
- 平台货运机是民用执行单位，阻拦要可信且具有战棋对抗性，但不能突然升级成杀人军队。
