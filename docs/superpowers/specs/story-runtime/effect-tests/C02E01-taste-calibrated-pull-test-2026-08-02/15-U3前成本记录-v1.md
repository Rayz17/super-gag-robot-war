# U3前成本记录 v1

## 模型调用

1. 冷读提示词匿名回归：1次独立冷读席。
2. 同一正文主笔S2初稿：1次。
3. S2两处定点因果修正：1次。
4. 同一正文主笔S3初稿：1次。
5. S3三处定点物理修正：1次。
6. 同一正文主笔S4双演绎方案：1次。

从S2到U3共5次主笔调用；Runtime/Canon查询均为本地确定性查询，不消耗模型调用。用户选择后，预计以1次完成S4正文与S5初稿，再用2次独立审查完成冷读和机战/游戏检查，仍可落在既定7至9次主要模型调用范围内。
