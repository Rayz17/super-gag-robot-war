# S3白话与机战门 v1

## 一句话复述

玩家驾驶无牌一号突破民用货运机，夺下并守住桥前实体道岔，把主转子从拆解桥改送旧泊位；转子转弯失衡后，无牌一号、变形后的货柜领袖、馆守Z与悬停横移的万机馆按四种尺度共同把它接住。

## 判断

`PASS_TO_S4_TREATMENTS`

### 已成立

- 玩家始终知道争夺的是哪一个实物、要到哪里、怎样算赢。
- 无牌一号经历了追击、近身阻挡、夺岔与守岔，不是去按一个开关。
- 货柜领袖有可辨识的十余米作业机器人形态，并以独立选择参战。
- 纪存只操作无牌一号；兜灯操纵万机馆，人物站位未串台。
- 馆守Z的临时右臂只用于锚定和拖曳；万机馆保持载舰形态并以百米舰体参与承重。
- 胜利完整可见，同时平台冻结合作社，为战后选择留下压力。

### 仍需后续审查

- 正文动作密度较高，完整E01冷读时需验证初次读者能否稳定跟住，而非只看懂设计摘要。
- S4必须从这场实物胜利自然转向人物选择，不能退回一场维修资料说明会。
- 平台货运机仍是民用设备；S4不得把本场擦伤偷换成暴力犯罪或军方冲突。
