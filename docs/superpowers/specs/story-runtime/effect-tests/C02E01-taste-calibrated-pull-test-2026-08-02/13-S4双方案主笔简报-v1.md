# C02E01 S4 双方案主笔简报 v1

## 任务

只写两个各500至800汉字的“演绎方案”，不写完整Reader。两个方案必须拥有完全相同的入口事实与出口事实，但中间由不同的人先行动、以不同的误解或需要发动，并让唐胶作出同一公开选择时具有不同含义。方案应能让用户比较“哪一种情绪过程更动人”，而不是比较措辞。

## 共同入口

S3刚结束。主转子已被完整接回旧泊位，平台四台民用机也都存活；平台随即冻结木桶互修合作社的仓储与邮运权限。合作社有原始寄存单，唐胶有二十多年前的离线维修交接，但平台可以把两份孤证说成临时拼出的例外。若要迫使人工复核立刻发生，需要若干位独立物主自愿拿出同一旧工房体系的原始维修页，与眼前实物编号交叉印证。

这样做有真实风险：这些纸页也会让平台第一次把当年的匿名改件、今日仍在使用的实体机和具体物主对应起来。七海只能远程说明这一后果，不能替平台解冻，也不能替任何人同意。

## 可准入的情绪素材

木桶街有一位继承亡子工房的母亲。儿子病逝前留下最后几份模型维修委托，其中一件一直缺装甲。迟到的旧库存最近才补到，她正在用自己后来学会的手艺完成它；委托单和收件地址都仍有效。她不是来解释主题，也不要求别人同情，更不把儿子复活。她要处理的是一个很普通的问题：这件东西修好以后，究竟该以谁的名字寄出去。

四台同骨架重涂实机的物主也持有旧维修页。有人依赖平台生计，有人怕公开改件后失去维护服务；他们必须分别同意，不能被唐胶、纪存或母亲代表。

纪存能做的是开放万机馆自己的公共频道、逐项遮掉未授权的私人信息，并让万机馆作为共同发布者承担现实后果；他不能替唐胶按发送。玛拉既想救合作社，也有理由怨唐胶当年用“近似原装”帮助客户变卖、同时抹掉维修史。

## 方案A方向：继承先于坦白

让母亲因邮运被冻结，带着刚修完的委托和旧维修页来到现场。她的具体工作和寄件选择先改变唐胶，再由唐胶面对玛拉和四位物主。情绪主要来自“人不在了，工作仍由另一个不完全相同的人继续”，过程应安静、具体，不靠哭诉。

## 方案B方向：冲突先于继承

先让唐胶、玛拉和物主围绕是否公开发生真正的关系冲突：有人认为唐胶当年帮过自己，有人认为他替自己抹掉了历史，也有人拒绝冒险。母亲不是温柔裁判，而是在冲突最难堪时提出一个出乎唐胶意料的实际要求，使公开从赎罪转成“活着的人如何接着做”。情绪可以更锐利、更外放。

主笔可偏离上述具体场序，只要两案的核心情绪发动方式确实不同。

## 共同出口

至少四位实机物主分别明确同意；母亲决定寄件时使用的署名；唐胶只发送获得授权的页面、自己的材料方法和签名；纪存把万机馆频道开放为共同发布，不发表主题宣言。发送完成后，合作社获得紧急人工复核资格，但四台重涂实机也因此变得可被平台识别。S5将负责转子临时落座、万机馆恢复舷窗，以及四机召回与白鸢通知，不在这两个方案中展开。

## 评价目标

每案写清：谁先做了什么；唐胶最难面对的具体东西是什么；母亲的动作如何改变局面；四位物主为何跟进；唐胶按下发送时人物关系改变了什么。避免把维修史、继承或公开拔成宇宙意义。
