# C02E01 S4双演绎方案 v1

> 两案入口、出口与事实边界完全相同。本文件只供U3判决场选择，不代表已写成正文。

## 方案A：继承先于坦白

主转子刚在旧泊位固定，平台便冻结合作社的仓储与邮运权限。寄存单和唐胶的离线交接仍是两份可被推成例外的孤证；要立刻触发人工复核，必须有多位物主自愿公开同一旧工房体系的维修页。七海从远端说明：公开会把匿名改件、现役实机和具体物主第一次对应起来。

争论尚未开始，那位母亲先抱着刚修完的模型来到安全台。邮运被冻结，她只想确认这件亡子留下的最后委托还能不能寄。模型缺失的装甲已经补齐，颜色略有差异，却被她磨到了严丝合缝。她请唐胶检查，并拿出儿子的旧委托页和自己续写的维修记录。唐胶最难面对的不是亡者，而是纸上清楚并列的两种做法：母亲诚实写下谁做了哪一步，他当年却在同类页面上反复写着“近似原装”。

母亲不要求他解释，只把寄件单推过去：“活不是他做完的，就不能签他的名字；但这是他接下的委托，也不能当他没来过。”她决定自己承担寄件人身份，同时保留儿子的工房名。唐胶因此不再替物主判断风险，而是逐个拨通四台重涂实机的主人。第一人为了保住当年真正救活机器的方法同意；第二人只授权遮住地址后的单页；第三人确认平台可能停掉维护后仍说可以；最后一人沉默许久，要求唐胶也把自己的签名放上去，才明确答应。玛拉看见他第一次只请求许可、不代别人作答，把发布台让给了他。

母亲最终把寄件人写成自己的名字，在维修附注保留儿子的工房名。四位物主逐一说出“同意公开这一页”，唐胶只发送获授权的维修页、自己的材料方法和签名；纪存逐项遮掉私人信息，以万机馆频道共同发布。发送完成，合作社获得紧急人工复核资格；四台重涂实机也同时进入平台可识别状态。

## 方案B：冲突先于继承

主转子刚在旧泊位固定，平台便冻结合作社的仓储与邮运权限。寄存单和唐胶的离线交接仍是两份可被推成例外的孤证；要立刻触发人工复核，必须有多位物主自愿公开同一旧工房体系的维修页。七海从远端说明：公开会把匿名改件、现役实机和具体物主第一次对应起来。

玛拉先把四位实机物主接进公共通讯。唐胶提出公开维修页，一人立即拒绝，怕平台断掉自己的营生；一人说当年若没有“近似原装”，机器根本卖不出去；另一人却反问唐胶，为什么连真正救过机器的人也要从历史里消失。玛拉压了多年的怨气被这句话点燃：唐胶总说替客户留后路，其实也替自己省掉了署名和责任。唐胶承认那些字是自己写的，却拿不出一句能让四个人共同冒险的理由。争执最难堪时，母亲抱着修好的模型挤进安全台，打断他们：“吵完能不能先告诉我，这件该签谁？”

她不要裁决旧账，只要求唐胶检查她补装甲的手艺，并帮她把交接写准确：儿子接下委托，她完成维修，谁也不能吞掉另一人的那部分。她随后把自己的旧维修页放到扫描台上，明确说这页由她承担风险。这个实际要求改变了争论：公开不再等于把所有秘密一次交出去，而是每个人只为自己做过、拥有并愿意留下的部分负责。四位物主于是分别划定授权边界：有人公开改件方法，有人公开编号，有人遮掉地址，有人在确认唐胶会同时署名后才同意。玛拉不再替他指责或辩护，只把发送键留在唐胶手边；他按下去，等于第一次与物主共同承担那段历史。

母亲最终把寄件人写成自己的名字，在维修附注保留儿子的工房名。四位物主逐一说出“同意公开这一页”，唐胶只发送获授权的维修页、自己的材料方法和签名；纪存逐项遮掉私人信息，以万机馆频道共同发布。发送完成，合作社获得紧急人工复核资格；四台重涂实机也同时进入平台可识别状态。
