# C02E01《救命零件，限定发售》S2主笔稿 v1.1

纪存顺着她指的方向看去。

侧仓里，那台人形底盘半跪在检修架之间，灰白装甲只覆盖了胸口和四肢要害。头部没有徽记，肩上也没有编号，几根外露线缆接进墙边的维护柜。它像一件还没决定要卖给谁的巨大商品。

“先等等。”纪存抬起手，“那是你们的转子，总有能叫停的人吧？”

“我正在叫。”

玛拉从控制台下抽出一只铁皮文件匣。匣盖弹开，里面不是芯片，而是一叠边角起毛的寄存单。她翻到压在最底下的一张，再次按进识别台，同时接通平台现场调度。

屏幕里出现一个戴橙色安全帽的中年男人。他那边风声很大，背后正是拆解桥的入口。

“木桶合作社，争议已经登记。”调度员看着另一块屏幕说，“原始寄存凭据也收到了。”

玛拉把单据压在台面上：“那就让你的车停下。”

“停不了。零点清仓批次已经成交，买方付过款，牵引任务也下发了。现在撤回，我这里没有权限。”

“东西不是你们的，怎么成交的？”

“库存表把它列成多年无人认领。你要追责任，可以申请人工复核。”

玛拉望向远处。转子的外圈正从一排仓库门前缓缓掠过，四台白色货运机的警示灯依次闪烁。它们速度不快，却一刻也没有停。

纪存凑近屏幕：“我们把它买回来呢？差价也行。”

调度员摇头：“订单锁定了。”

“租？”

“已经不在可租库存里。”

“等复核要多久？”

“快的话，今天下班前。”

唐胶抬眼看了看轨道尽头：“拆解桥多久开机？”

调度员沉默了一下。

“十二分钟后接货。入桥先切外圈，复核结果出来也拼不回去了。”

仓库里的运输警报又响了一遍。像是为了替他作证，拆解桥上方亮起两排红灯，沉重的定位夹从门内慢慢滑出。

玛拉切断通讯，转身掀开控制台旁的保护盖。里面一排老式闸柄都贴着合作社自己的手写标签。她握住“外环货运”那一柄，用力扳到底。

仓库顶灯暗了一瞬。沿街的轨道灯一盏接一盏熄灭。运输架下方的旧轨道轮立刻失去助力，巨型转子的速度缓了下来。

四台白色货运机也停顿了一拍，随即车腹亮起此前没有出现过的备用灯。轮组里的电机重新加力，继续拖着转子向前。

玛拉盯住那些灯：“它们什么时候加的车载动力？”

调度员的声音从公共频道追过来：“清仓车队去年换装的。备用系统归平台调度，你们的轨道闸管不到。”

玛拉看了一眼转子与拆解桥之间的距离，没有把闸柄推回去。

“那就让它们拖着十二米的死重走。”她说，“慢一点也算我们赚到的。”

唐胶已经趴到另一块监控屏前。他调出旧货运图，手指沿着环线往前划，停在拆解桥前的一处分叉。

“这里还能转出去。”

玛拉点头：“旧泊位线。以前运整机用的，够宽。”

纪存看见监控画面里有一副低矮的实体道岔，横卧在两条轨道之间。转子只要在那里改道，就会绕开拆解桥，回到合作社外侧。

“远程扳过去。”

“权限在平台手里。”玛拉说。

纪存重新接通调度：“帮我们切一次道岔。”

“争议货物不能改线。你们的人也别过去，巨物运输期间，人行门全部锁闭。”

画面一转，道岔旁的黄色通道门正在落闩。两名维护工隔着护栏向他们摆手，示意前方已经清场。

“那从轨道边爬过去？”

唐胶看了纪存一眼：“等你爬到，转子已经比你先过去了。更别说它只要晃一下，你就会变成那张寄存单的附页。”

侧线忽然传来轮胎摩擦声。

货柜领袖倒车撞开挡杆，车头转向主轨。它试着从后方追近运输架，伸出的牵引销却被一台白色货运机横移挡住。两辆车轮贴着轮打滑，货柜领袖挤出半个车身，仍够不到转子。

“我可以再接一次。”它说，“但它们不会让我靠近。”

兜灯的声音从纪存终端里传出：“别指望馆守Z。我这边还悬着，唯一那根安全缆一松，万机馆先去给人家仓库加盖。Z最多站到舰艏边缘，用右臂帮你们锚一下。让它独自拖十二米的转子，胳膊和转子总得留一个在地上。”

纪存望着监控。白色货运机经过一块里程牌，拆解桥的红灯已经从慢闪变成了快闪。

普通办法没有哪一条是错的。

寄存单证明合作社有理，争议登记会有人处理，钱也可以追回。可轨道上的东西不会等那些人坐到桌前。

“那台能赶到道岔吗？”他问。

玛拉已经走向侧仓：“能。”

“能不能把四台车全掀了？”

“也能。然后你赔四台民用货运机，再解释为什么转子滚进模型店。”

纪存跟上她：“所以只扳道岔。”

“只扳道岔。”玛拉拉开无牌一号脚边的控制柜，从腰间取下一枚齿痕斑驳的实体钥匙，“不碰工人，不拆货运机。把转子送回旧泊位线，它们自然会跟着转向。”

唐胶却转身提起工具箱：“旧泊位线停了二十多年。就算道岔扳回来，末端的接货机构也未必张得开。”

“你去把它弄醒。”玛拉说，“转子一回来，总得有东西接住它。”

唐胶看了一眼无牌一号，又看向远处的旧泊位：“行。这里别等我。”

玛拉把中央安全台的控制画面调到腕上。仓区各段的人行门和断电状态同时亮起。

“我得留在安全台清场。你往哪一段走，我就先断哪一段的电；少看一块屏，路上都可能多出一个人。”

她把钥匙递到纪存面前。

纪存没有立刻接：“我只在馆里的模拟设备上练过。”

“唐胶去接转子，我守着整条线。”玛拉说，“现在能马上进去、又知道动作控制怎么用的，只剩你。”

她顿了一下，把钥匙又往前送了送。

“模拟的也算。今天不收出场分，只要你别撞人。”

纪存接过钥匙。

无牌一号胸前的检修踏板降到地面。他踩上去，被升降架送进狭窄的控制位。里面没有完整驾驶舱，只有一圈贴近身体的动作杆和几块磨花的观察屏。

钥匙插入后，屏幕依次亮起。

“平衡交给它自己。”玛拉的声音从外部扬声器传进来，“方向和动作由你选。别跟它抢每一块肌肉。”

纪存握紧控制杆。无牌一号先抬起头，空白的面甲映出仓门外迅速交替的红色警灯。随后它撑住一侧膝盖，脚掌在地面试探着压实，检修架接连松开。

八米高的身体带着一阵金属震响，从半跪中站了起来。

玛拉仰头看着它。

“去拆解桥前，把实体道岔扳回旧泊位线。转子要完整回来，人和车也都要完整。”

纪存望向正在远去的巨大圆环。

“明白。”
