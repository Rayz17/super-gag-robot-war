# C02E01 S2 主笔简报 v1

## 本场入口

紧接已完成S1。直径约十二米的退役主转子已被四台平台白色货运机拖离合作社仓库，正沿环形货运线驶向拆解桥。货柜领袖拒绝拖运，已被卸开并推到侧线。玛拉指向侧仓里的八米级全尺寸竞技底盘“无牌一号”：“馆守Z下不来。要追，先把那台一号开出来。”

## 本场要让玩家看懂的事

纪存等人不是一言不合就抢机器。他们先用最普通、最合理的办法制止错误拆解；这些办法能证明他们有理，却赶不上正在移动的实物。平台不是神秘AI，也不是索引化身，只是一套把仓储、转卖与货运绑在一起的本地商业系统。合作社拥有转子和纸面凭据，平台拥有轨道、牵引机与远程调度。平台收到产权争议后会进入人工复核，但不会主动撤回已经付款的清仓批次。

玛拉应先出示原始寄存凭据并要求停运；纪存再问能否买回、租下或等待复核。对方的现场调度员承认已登记争议，却说明复核要晚于拆解。玛拉切断合作社轨道电源后，四台货运机仍用自身动力继续拖行。拆解桥前有一处能把转子导回合作社旧泊位线的实体道岔，但远程权限在平台手里，人行通道又已因巨物运输封闭。至此，行动成为必要，而非为了制造战斗硬拗出来。

## 人物与声音

- **纪存：** 先找简单办法；确认无路后迅速决定。他有主见，也会紧张，不用管理术语说话。
- **玛拉：** 熟悉现场，恼火但不莽撞。她拥有合作社的纸面凭据、无牌一号实体钥匙和本地竞技控制器，没有平台后台权限。
- **唐胶：** 了解机器和玛拉，能用一句实际判断拆穿假希望；此时不抢走纪存的决定。
- **兜灯：** 留在万机馆上远程参加。她说明万机馆仍悬在泊位上方，馆守Z只能在舰艏和泊位边缘活动；其临时右臂可锚定拖曳，不能独自承受整个转子。
- **货柜领袖：** 自主场景友军，拒绝平台路线后正在尝试重新接近转子。

## 无牌一号的当前用法

无牌一号是全尺寸竞技底盘，不由模型放大。它尚无正式驾驶员和永久工作模块。玛拉把实体钥匙交给纪存，让他进入近场竞技控制位；纪存负责方向与动作选择，机体自己的低权限AI只维持平衡。可以用一句自然对话说明纪存只在馆内模拟设备上练过，不把这写成已固定的驾驶天赋。

## 场尾必须达到

纪存接过钥匙、进入控制位，无牌一号站起。玩家第一次取得行动权。目标用白话说清：赶到拆解桥前扳回实体道岔，让转子转入旧泊位线；不伤工人，不摧毁仍属民用设备的货运机。S3从无牌一号冲出侧仓开始。
