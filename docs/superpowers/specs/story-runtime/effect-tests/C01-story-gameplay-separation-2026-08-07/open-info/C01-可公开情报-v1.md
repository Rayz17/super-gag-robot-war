# C01 可公开情报

## E01后

### 万机馆过去会飞吗？

会。万机馆主体原本就是一艘巡展舰，曾带着机器人展品沿海岸和不同城市巡回开放。第六次巡展结束后，舰体固定在旧会展区，外围逐步接上门厅、道路和城市管网，才成为今天的固定博物馆。固定期间它仍接受过维护、城市化改装和设备换装，不是把某个年代的整艘船原样封存到今天。

玩家此时只知道它过去飞过，不知道现有舰体能否再次航行。

### 模型、全尺寸装备和实机有什么区别？

- 模型与玩具保存外形、装配方法、使用痕迹和收藏者记忆，不会无条件放大成真实机体。
- 退役重盾、巡展臂和推进骨架是巨型机器人或巡展舰真正使用过的全尺寸装备。
- 馆守Z和勇拳拥有真实尺度的身体、动力与行动系统，属于实机。

### 海面上的小型接触点是什么？

它们与BREAKER一同出现在本次警报中。此时只能确认它们是同类弱小突入体：大多被海防挡在城市外，各自行动，没有统一方向。故事不锁定精确数量、物种名或更深目的。

## E02后

### 观众已经撤离，为什么馆守Z还要保护东门？

观众已经离开主厅并进入封闭通道，但最后的消防和应急车辆还要从东门撤出。BREAKER破坏地面时，少量弱小体也从缺口漏进相连街区，各自追逐车辆、出口和警戒设施。

因此馆守Z起身后的第一件事不是追杀Boss，而是站到巨兽与撤离线之间，保护收尾车辆离开。

### 旧守护者和馆守Z是两个机器人吗？

不是。旧守护者是馆守Z的机魂人格，也是它在馆内使用的日常称呼。

轮式导览终端、馆内广播和胸前扬声器都是同一主体使用的远端感官与输出设备。轮式终端受损，只相当于一副外壳坏了；馆守Z胸腔内的主体没有因此消失。

### 纪存在馆守Z里做什么？

馆守Z自己决定并控制身体动作。纪存所在的是灾时导览席，他把今天的街道、避难点、友军与敌情整理给一台停用多年的巨机。

纪存不是馆守Z驾驶员，也不能直接命令它挥拳或转身。

### 重盾拍击之后战斗结束了吗？

没有。馆守Z借退役重盾保护撤离线，并第一次把BREAKER拍倒。重盾因此多出第四处焦痕，受热变形，但此时尚未裂穿。BREAKER很快重新起身，街区边缘也仍有散乱小体活动。

## E03后

### 小型突入体是什么时候开始统一行动的？

漏入街区的小体在E02各自追逐不同目标，BREAKER倒地也没有令它们停下。直到地面壳被击毁、飞行核心展开，红孔的第一次脉冲才让街区幸存体与外海同类同时停顿、转向；下一拍，它们开始让路和包夹。

玩家看到的是一次明确升级：`散乱个体 -> 首次同步`，不是飞行核心凭空召来一批新敌人。

### 重盾上的贯穿裂纹从哪里来？

E02话末的重盾只有烧蚀和热变形。E03继续战斗后，重新起身的BREAKER正面撞击盾面，首道贯穿裂纹当场形成。后续小体撞击只会延长已有裂纹或崩落边角。

### 馆守Z的右臂还能立即装回去吗？

不能。原右前臂以过载方式发射后贯穿BREAKER地面外壳，肩内回收机构同时烧毁，主要残片留在封锁广场。右肩仍保留固定接口，但需要新的工程装备或真正的新右臂。

### BREAKER为什么有两种身体？

本章现场只能确认：厚重黑甲负责钻地、冲撞和城市近战；较小的飞行核心藏在其中。地面壳被击毁后，核心展开薄翼并同步附近同类。这不证明所有地外个体都具有相同结构。

## E04后

### 万机馆现在是什么状态？

万机馆已从固定展馆恢复为约130至160米级的低速巡展母舰。主展厅、穹顶和主要展廊随舰离开，后来加建的外围门厅与城市接驳结构留在原地。

当前舰体只有基础航行、有限近防和少量泊位功能。它不是完整军用战舰，也没有在本章变成人形机器人。

### 黄色巡展臂能做什么？

巡展臂过去用于装卸和高空救援。三指夹爪能抓取、放锚、牵引并抛开贴舰小体，不能握拳、发射火箭拳或擒住BREAKER。终战归舰时托住馆守Z左肩的是勇拳，巡展臂没有参与。

### 飞行核心毁灭后，小型突入体为什么散开？

红孔同步消失后，残余小体失去共同节奏：有的继续前冲，有的盘旋，有的转回外海。它们没有被瞬间消灭；城市防空与万机馆有限近防随后才开始处理余敌。

### 重盾和推进骨架怎么样了？

重盾先后保护撤离线、万机馆离地与两台机体归舰，最终完全破裂。推进骨架只支撑馆守Z从舰艏完成一次高速出击，随后熄火报废。馆守Z仍不具备常态飞行能力。

### 为什么万机馆必须先去木桶街？

终战后，主循环转子的温度没有随功率下降，舰腹还出现了异常震动。当前低功率飞行尚能维持，但兜灯无法保证停机后还能重新启动；附近普通泊位也承不住百米级舰体，无法完成全尺寸检查。

万机馆因此公开发出维修请求。赵梅看到舰体尺寸、震动记录、接口图和唐胶的联系方式后才回应：木桶街有重载泊位，也有一具尺寸接近的新转子正在试车。她只承诺落地实测，不承诺一定兼容。主轴是否弯曲、测试转子能否真正救急，留到C02靠泊后确认。

### 无标志白色采样机确认了什么？

只确认它在战后进入封锁广场，带走一块馆守Z右拳残片，并掉落一枚未知白色复合材料衬片。它的制造者、所属机构、目的和下一步行动均未知。
