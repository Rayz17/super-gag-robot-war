## E01《最后一位观众》

### 游玩顺序

1. **馆内自由探索**：跟随最后导览，查看馆守Z、退役重盾、巡展臂、推进骨架和少量未开放层线索。
2. **勇拳公开测试**：用固定回放让玩家先看懂拳甲“承受冲击、下一拳送回”的能力，以及豪司被困在标准动作里的处境。
3. **关系ADV**：纪存与七海约饭，建立两人已有私交及闭馆后的个人去向。
4. **敌袭与撤离**：BREAKER钻入地下，十余个小型接触点大多被海防挡在城外。玩家带观众离开主厅、进入封闭通道。

### 边界

- E01结束时，馆内观众已经离开主厅；最后的应急车辆和东侧撤离线仍在收尾。
- 普通人不进入后续巨机棋盘成为可控单位。消防与应急车辆作为地图内的非可控保护状态短暂存在。
- 这是存档点，不是敌袭结算。BREAKER仍在地下逼近，海空小体仍在城外游荡。

## E02《巨神从展台起身》

### 户外滚动SRPG

**地图：** 旧会展广场、东侧撤离线、相连街道和建筑。镜头随单位滚动；楼房、道路、破损连廊和可破坏设施属于棋盘本体，不放在固定小屏之外充当前后景。

**玩家单位：** 馆守Z。纪存以导览协战提供现代城市位置和敌情，不直接驾驶四肢。

**并行压力：** BREAKER破防后，少量同类弱小体漏入街区。它们各自扑向应急车辆、出口或警戒设施，没有统一队形，也不接受Boss战术指挥。

**阶段目标：**

1. 让馆守Z站到BREAKER与东侧撤离线之间。
2. 在抵挡Boss的同时驱散、牵制漏入的小体，保护最后的应急车辆完成撤离。
3. 撤离线清空后，利用主厅破口取得退役重盾。
4. 在BREAKER蓄积正面冲击时满足站位条件，开放一次“重盾拍击”情境指令。

**阶段失败：** BREAKER越过北侧防线；应急撤离线在清空前被突破；馆守Z失去行动能力。

**不是目标：** 全灭小型突入体。压力降到阈值后，余体退到街区边缘或脱离本阶段交战，至少保留一组可见幸存体及位置进入E03。

### 剧情战斗动作：重盾拍击

- 前置事实：馆守Z已经取得退役重盾；撤离线刚刚清空；双方位置满足正面反击。
- 开放方式：仅在当前情势成立时出现，不靠练级或技能树解锁，也不成为常驻菜单技能。
- 必看语义：人物高潮台词可与短Cut-in交错；馆守Z把BREAKER首次拍倒，但没有击杀。
- 状态结果：重盾留下第四处焦痕并发生热变形、边缘凹折；此时没有贯穿裂纹。Boss倒地后重新起身，Operation继续。
- 首次演出必须完整传达因果；跳过或重看后都恢复到同一准确状态。故事层不规定秒数、帧数、Godot节点或最终逐字台词。

### Episode出口

`Phase Checkpoint / 非Mission Clear`。街区破坏、Boss状态、重盾状态和散乱小体的位置全部保存；不治疗、不刷新敌人、不做战后奖励结算。

## E03《双拳打碎外壳》

### 同一广场、同一时间

读取E02存档后，地图仍保留翻起的路面、封闭东门、散乱幸存小体、站起的BREAKER和烧蚀变形但尚未裂穿的重盾。

BREAKER复战后的既有正面冲撞由馆守Z举盾承受，首道贯穿裂纹在玩家眼前形成。豪司随后驾驶勇拳越过测试黄线入场，玩家取得第二台机体。

### 地面壳战

**大分工：**

- 馆守Z正面卡住巨兽，防止它转回万机馆或居民区。
- 勇拳从侧面吸收冲击，再把力量送回同一处黑甲。
- 纪存读出馆守Z出手方向，把可见红裂共享给勇拳和城市炮火。

**阶段推进：**

1. 双机压住Boss并打出胸前红裂。
2. 兜灯说明过载火箭拳会连同回收机构一起烧毁；馆守Z自己决定发射。
3. BREAKER夹住飞拳，勇拳从断裂高架补上回送拳，右前臂从内部击碎地面壳。

玩家负责执行合击和路径选择，不获得“保住右臂却得到同样结果”的伪分支。馆守Z原右前臂和肩内回收机构永久报废，右肩固定接口仍可使用。

### 首次同步升级

地面壳毁灭只完成地面Encounter。飞行核心随即展开：

- 第一拍，红孔脉冲令E02街区幸存体与海面、低云同类在同一瞬间停顿并转向。
- 第二拍，它们才一起让出核心航线、包夹万机馆。

这是小体第一次从`scattered`变成`synchronized`，不是它们第一次出现，也不是核心凭空召来一批新敌人。

### Episode出口

`Encounter Complete + Checkpoint / 非Mission Clear`。地面壳被毁，飞行核心仍是同一个BREAKER主体；馆守Z缺失右前臂、重盾已经裂穿、勇拳带伤、小体已同步，全部继承到E04。

## E04《博物馆追上天空》

### 出航Encounter P3

**地图：** 从万机馆外泊位、出航街区滚动到海岸走廊。换区域不重开任务。

**玩家目标：** 在飞行核心与同步小体持续进攻下，完成万机馆最低限度离地准备，并把战线带离居民区。

**主要可见动作：**

- 馆守Z把重盾带回泊位，挡住高空攻击和贴舰小体；小体撞击只能延长既有裂纹或崩落边角。
- 黄色巡展臂接入右肩，只夹取、抛开贴舰小体，不擒拿Boss，也不承担归舰。
- 万机馆以多格母舰单位起航；近防只处理贴舰目标，勇拳与城市防空压制飞行核心。
- 玩家选择东侧净空航路和整备次序，但不能替纪存决定是否以万机馆引敌离城。

城市楼群退到后方、敌群转而追舰时，完成一次`Phase Checkpoint`，不是Mission Clear。

### 沿海Encounter P4

**地图：** 海岸空域与万机馆外部泊位。万机馆、馆守Z和勇拳的前段损伤全部保留。

**玩家目标：** 拆开同步小体的包围，逼飞行核心进入舰艏直线，再完成一次性终结。

**阶段：**

1. 以母舰转向、有限近防、馆守Z巡展臂和勇拳截击打开航线。
2. 勇拳承受并回送Boss俯冲，让核心回到馆守Z的直线出击轴。
3. 兜灯只批准推进骨架点火一次；纪存报出时机，馆守Z从舰艏升空，以左拳贯穿红孔。
4. 核心毁灭后，同步小体立即失去共同方向。城市防空与有限近防随后处理残余。
5. 推进骨架熄火；勇拳托住馆守Z左肩，两机落在放平的裂盾上。巡展臂不参与托举，裂盾和推进骨架报废。

这是`OP-C01-BREAKER`唯一的`Mission Clear`。

### 战后ADV与片尾

Mission Clear以后不再增加一场战棋关卡：

1. 舰内短ADV先让玩家听见舰腹闷响，并看到主循环转子温度不降、震动异常。兜灯只判断低功率飞行还能维持，不能提前确诊C02才会确认的主轴损伤。
2. 玩家在航行台确认发布维修请求。请求公开舰体尺寸、震动记录、接口图和唐胶的技术联系方式，不要求玩家填写工程参数。
3. 赵梅远程回应木桶街具备重载泊位和一具正在试车的新转子，但不承诺兼容。唐胶说明她是已故徒弟的母亲，并确认接应可信；系统将木桶街设为下一目的地。
4. 片尾短演出切回封锁广场：无标志白色采样机取走馆守Z右前臂残片，并意外留下白色衬片。该演出只建立暗线，不给玩家追击或即时鉴定任务。

转子故障发动下一章，但不反写本章Mission Clear；白色采样机与木桶街求援是两条彼此独立的尾声信息。

## 玩家代理权限

- `execution_only`：是否撤离、馆守Z是否发射右臂、纪存是否引敌离城等人物决定已经由剧情角色作出；玩家负责把决定执行成功。
- `cost_or_route`：玩家可选择馆守Z站位、优先驱散哪处小体、勇拳进攻路线、万机馆整备与离城航路，但不能改写主要人物动机和不可逆结果。
- 本章没有授权剧情分支。关卡内路线差异不得静默改变伤亡、右臂损毁、万机馆离港或勇拳暂离。

## 制作与职责边界

- 故事层和结算层拥有剧情战斗动作的触发事实与状态结果。
- `BattlePresentationPlayer`只读取并播放已批准的剧情动作，不反写故事答案。
- 制作人镜头单负责构图、落拍、时长、音画、跳过与回退，不得改变“盾拍只拍倒、右臂在E03报废、核心在E04毁灭”等事实。
- 户外正式地图必须支持滚动街区和建筑入图。现有`art-g1-5/b3-tactical-map`仍是旧12x9、无小体固定几何Candidate，不得升格。
