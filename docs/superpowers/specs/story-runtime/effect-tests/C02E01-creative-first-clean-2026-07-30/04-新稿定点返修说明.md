# C02E01 Creative First v1 定点返修说明

只修以下问题，保留v1的场面顺序、人物动作、巨环高潮、母亲交付和E02尾钩。不得重写整话，不得读取旧稿或A版内容。

## 必修一：转子权属与平台权限

在寻找转子阶段用极短信息建立：

- 退役转子的物主或本地联合仓已经同意按普通退役件价格转给万机馆；
- 平台掌握仓储、运输架、重载路线和直播包装，不拥有否定转让的权力；
- 平台竞价的是运输优先、独占赞助或展示权益，不是把已经转让的转子卖第二次；
- 终局播报要确认万机馆完成合法交付。

不要增加合同解释场。用一句现场说明、屏幕上的物主确认和平台立即改包装即可。

## 必修二：人类声线

重写七海通讯中“我生气不是因为……是你又先替我决定……”的总结式对白。她要像一个熟悉纪存、担心又不耐烦的人：她知道自己帮不上现场，但不接受纪存挑过坏消息以后才告诉她。

删减火种货柜的宣言密度：

- 把抽象的“救援必须让整条街闭嘴”改成它眼前看见的药车、出货车和排队的人；
- 把“这句话够我向前一步”改成简短行动回应；
- 终局“交付给让路没有断掉的人”改成处理眼前卸货或道路的普通话。

保留“不是四步，是同一步”，它属于本话机战高潮口号。

## 必修三：少替正文总结

- 战后不说“赢的是出发，不是痊愈”，改成纪存确认能否到工务城的普通对话。
- 删除“没有用一句轻描淡写的话盖过去”这类作者说明，直接写纪存把真实舰况逐项发给七海。
- 火种货柜首次自报要让玩家听见正式称呼“火种货柜领袖”，后续可简称货柜领袖。
