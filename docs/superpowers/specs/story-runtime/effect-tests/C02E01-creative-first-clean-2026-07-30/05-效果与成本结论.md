# C02E01 Creative First效果与成本结论

> **后续用户裁决（2026-07-30）：不通过。** 当时两份盲审只证明新稿相对旧稿更完整，并未证明它本身是好故事。本文保留调用数、成本和局部改进观察；凡称“质量通过”或“方法有效”的结论均已被用户首读覆盖。

## 一、结论

这次测试只通过了“相对旧 Runtime 的低成本结构试验”，没有通过创作方法有效性，也没有资格替换 Current Reader。

干净语料、Creative First和整话直写的组合，明显优于此前Runtime 2.1的六段事务循环。提升不来自字段填得更全，而来自主笔先找到一个能统摄全话的戏剧动作：平台把万机馆急需的旧转子包装成限量运输权益，纪存最终不去硬拦失控巨环，而是让四种尺寸、四种身体功能的机器在同一拍补出一段临时装配线。

两份独立盲审都选择新稿B：

| 盲审 | 旧稿A | 新稿B | 结论 |
| --- | ---: | ---: | --- |
| 商业剧情与人物 | 28/40 | 37/40 | B胜出 |
| 机器人文化与游戏制作综合 | 61/80 | 77/80 | B胜出 |

新稿已经证明：Runtime更适合做后台资料员、连续性审查和写后校验，不适合把正文拆成六次受合同支配的场面生产。对普通厚度单话，默认方法应改为“一次整话创作、一次整话盲审、最多一次定点返修”。

## 二、新稿真正改善了什么

### 1. 一因多果取代素材并排

维修史被抹去同时造成：

- 唐胶必须面对自己的旧选择；
- 平台能把旧件包装成“原装限定”；
- 自动吊装读取错误重心，直接引发巨环脱架；
- 模型磨痕、实物复核和全尺寸适配座共同决定最终胜法。

同一条因果推动人物、生态、工程、战斗与主题，读者不再反复寻找本话究竟在讲什么。

### 2. 纪存重新成为主角

纪存没有停在审批、记录或挨批评的位置。他先拒绝只让万机馆通过的独占快线，随后选择无牌一号的配重叉，并在假二选一面前提出第三种解法。他的判断同时改变地图、机群关系和人物观感。

### 3. 机体以身体完成首登

- 火种货柜领袖先变作业门架让车队通过，车过完才站成人形；变形是它的伦理和身份。
- 无牌一号因玩家选择配重叉而立刻改变外形、重心与战术作用。
- 馆守Z没有拿残损右臂硬接巨环，而是服从停机判断，改用整个身体压住高架。
- 百余米万机馆停在地图外缘，只以舰索支援，不会和十八米机体混成同一尺度。

### 4. 生活、关系与泪点进入同一条行动链

乔梅用饭盒分格完成亡子留下的模型订单，右肩零件既是生活笑点，也是战中回收，最后完成真实交付。唐胶与兜灯的身体距离来自共同维修，纪存与七海的关系变化来自他终于把完整舰况告诉她，不再另开一段关系汇报。

### 5. 战斗可以被玩家复述

玩家能说清楚地图、单位、目标和阶段：

- 上层运输架、中层普通车队、下层装卸机捷径；
- 第一阶段护送车队并保护适配座；
- 第二阶段截住运输架；
- 巨环脱架后即时变更目标；
- 四个宏观动作构成终结技。

这比“许多机体各挪一点、打开一条小缝”更像可玩的机器人大战。

## 三、一次返修解决了什么

初稿最严重的缺口是转子权属不清，容易把公共道路冲突读成主角抢走拍品。v1.1补成：

- 本地物主已按普通退役件价格把转子转给万机馆；
- 平台只能控制仓位、运输路线、优先次序、赞助和直播展示；
- 战斗争夺的是合法交付与公共道路，不是转子所有权。

同一轮还自然化了七海的通讯，删减火种货柜领袖的口号和若干作者总结。主结构、乔梅线、巨环高潮及E02钩子没有重写。

## 四、仍存在的风险

### 1. 输入包遗漏了少量上层合同

测试输入没有完整带入两个既有事项，因此新稿也没有兑现：

- 木桶街主动邀请万机馆来巡展和改装的前情；
- C02第四层原定的“巡展臂三种作业端头”收获。

这不是主笔发挥问题，而是精简上下文编译时删得过头。以后输入包必须有一张不超过八项的“本话不可漏交付”，从L3/L4和生命周期表机械比对后生成。

### 2. 白鸢痕迹需要后文明确回认

署名被磨去的旧折页已经承担“普通创作痕迹”的功能，但本话没有说明它与白鸢有关。这一处理可以保留神秘感，前提是E02权利申诉明确回认那笔上扬墨痕或折页内容，不能像临时补认。

### 3. 最强场面仍需空间预演

万机馆在街外、主索横越坡道、馆守Z压外环、货柜领袖托外侧、无牌一号送入适配座，在文字中可读，进入SRPG前仍需一张俯视灰盒验证索线、坡道转弯和四台机体不会互相穿模。这属于演出与关卡预生产，不要求在Reader里再解释一遍。

### 4. 金句倾向没有因清退自动消失

v1.1的阻塞级“你可以……但……”模板为零。机械扫描仍命中10处否定式、14处账本/技术词、2处微量词和6处灯光词；人工复核后，大部分是“牵引锚”“维修记录”“饭盒一格”等具体正常用法。真正需要继续警惕的是角色在高潮处轮流概括主题，例如“不是四步，是同一步”这类句子只能少量保留。

这说明坏文风既来自旧语料污染，也来自模型自动追求金句。正确解法是写后语义审读，不是把更多禁句塞回作家提示。

## 六、连续性核对

当前通过项：

- 七海仍在原城，只通讯，不替木桶街或平台授权；
- 陆衡以木桶街现场工程顾问出现，未提前完成C03正式入队；
- 万机馆停在街外，不变人形，只恢复有限低速航行；
- 馆守Z右侧巡展臂只牵引和固定，没有恢复原装右拳；
- 模型只提供调查方向，实物由陆衡复核，工房另造全尺寸部件；
- 火种货柜领袖与无牌一号的尺寸、身体和本话身份符合C02预生产模型；
- 转子装舰后仍必须去工务城校正；
- 四机共用服务号自然发动E02，没有提前揭晓归一星或白鸢能力。

待正式采用前补齐：

- 在开场用一句行动事实回收木桶街的主动邀请；
- 决定三种巡展臂端头是在E01战果中恢复，还是显式迁到C02后话；
- E02回认白鸢痕迹；
- 关卡阶段制作一张巨环高潮俯视灰盒。

## 七、对Runtime的裁决

### 通过

- 生产源清退与History隔离；
- Creative First最小内核；
- 先选戏剧发动方式、再显式准入素材；
- 6至12条正向继承事实；
- 整话独立盲审；
- 写后自然语言与连续性检查。

### 降级

- 六场事务循环不再作为普通单话默认路径；
- 场面级合同不再直接进入初稿上下文；
- 正则lint不承担“好不好看”的裁决；
- 审稿不再逐字段补丁式修正文。

### 候选默认生产法

1. 后台从Canon、L3/L4、生命周期和上一话状态编译精简输入。
2. 主笔比较三种发动方式，选定一条主因果。
3. 只准入真正改变这条主因果的少量素材。
4. 一次写完整单话。
5. 用商业剧情/人物和机器人文化/游戏两种视角做整话盲审。
6. 只允许一次定点返修；若问题需要改发动机，退回上游重选，不在正文上连贴补丁。
7. 用户确认后才替换Current Reader、回写状态并迁移Canon。

只有超长、多地图或高密度高潮章，才在整话导演板之后拆成少量完整场面；拆分依据是可叙述的戏剧单元，不是模型一次能吐多少字。
