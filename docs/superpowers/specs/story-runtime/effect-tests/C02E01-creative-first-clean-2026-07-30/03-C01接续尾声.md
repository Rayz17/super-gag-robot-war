# C01接续尾声

七海离开危机联络室时，天已经快亮。她又回到滨海塔楼。餐厅正在收拾空桌，靠窗的位置仍摆着两只没有用过的主餐盘。

纪存的通讯接进来。背景里，万机馆前厅已经恢复了稳定照明。

七海先开口：“我让你离开楼群，没让你把整座馆开走。”

“留在那里，它们还会回来。”

“我知道。”

她看了一眼空着的另一张椅子。

“餐厅把位置留到警报解除。现在厨房下班了。”

“下次我来订。”

“行。先找个能停稳的地方。我不想在会晃的桌子上吃饭。”

“好。”

通讯刚结束，一个陌生声音插进万机馆的公共频道。

“你们没有家了，但我知道木桶街有你们要的东西。”

对方没有报姓名，只发来一张照片。晨雾里，一座四角巨构泊位立在木桶街边缘，中央尺度足以容纳万机馆；泊位旁堆着不同年代的巨机接口，最前面正是馆守Z黄色巡展臂使用的同代零件。

唐胶看见照片，脸色变了。

纪存问：“认识？”

“认识声音。”唐胶说，“不想见。”

“那里能停？”

唐胶把照片放大，又看了一遍泊位。

“能。至少比我们现在一直飘着强。”

纪存把木桶街标进下一段航向。

万机馆转向东南。

舰体离开以后，一台没有标志的白色采样机进入仍在封锁的广场。它从积水和黑甲残片之间捞起馆守Z右前臂的一块碎片，收进腹部仓。转身时，断裂的支撑座刮过它的夹爪，一枚指节大小的白色衬片掉进水里。

采样机没有回头。
