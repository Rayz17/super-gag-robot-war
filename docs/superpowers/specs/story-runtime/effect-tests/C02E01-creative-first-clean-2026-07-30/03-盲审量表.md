# C02E01 新旧稿盲审量表

审稿时不知道A、B分别来自哪种工作流。先连续读完，再评分；不得通过文件长度、标题格式或元数据猜版本。

## 第一席：商业剧情与人物首读

只回答普通玩家第一次阅读能感到的内容：

1. 开场是否很快形成愿望、麻烦和继续读的欲望。
2. 情节是否连续，人物为什么去下一处、为什么开战、为什么获胜是否自然。
3. 纪存是否像有判断力和魅力的主角。
4. 唐胶、兜灯、七海、陆衡是否有各自声线和不可替代的作用。
5. 日常、幽默、关系和泪点是否来自具体经历，而非主题说明。
6. 是否出现信息过载、作者替人物解释、刻意金句或机械对话。
7. 本话有没有一个真正想记住或想看动画化的场面。
8. 读完是否想继续看E02。

## 第二席：机器人文化与游戏体验

在普通阅读成立的基础上检查：

1. 万机馆、馆守Z、货柜领袖、无牌一号的尺寸、身体和作用是否容易区分。
2. 两台新机体是否通过动作和选择完成首登，而非报设定。
3. 模型经验、全尺寸验证、适配座与实机之间的关系是否清楚。
4. 平台压力是否形成主动冲突，而非等待主角讨论。
5. 玩家能否复述重载战的地图、目标、可操作单位、阶段变化和胜利动作。
6. 是否有机器人动画的规模、变形、援护、临时队伍和胜利快感。
7. IP文化投射是否可感而不依赖抄名词。
8. 资产和演出是否可以用一张主要地图、少量短动画与ADV成立。
