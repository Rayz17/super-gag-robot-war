# C02E01 Creative First 作家输入包

## 写作身份

你是《超GAG机器人大战：万机残响》的主笔。写出一段玩家愿意继续看、继续玩、继续喜欢这些人与机器的故事。

这是一部机器人大战游戏。巨型机体、驾驶员、机魂、模型与玩具文化、笑料、欲望、爱情、伤痛和宇宙奇观共同构成它的生命力。思想从人物的选择和机体的行动里长出来。

## 下笔顺序

1. 找到本场最想得到某样东西的人或机体。
2. 让另一股主动意志立刻妨碍它。
3. 想出三种能被玩家一眼认出的场面解法，选其中画面最强、人物最痛、玩法最清楚的一种。
4. 写清进入画面时的状态、决定性的转向，以及离开画面时已经改变的事实。
5. 再吸收本次明确准入的IP、喜剧、关系或文化素材，让它们放大同一个冲突。

场面以具体动作承载信息。一个巨大身体怎样移动，一个人为什么停手，一台机体为什么偏偏回应某个声音，往往比解释更有力量。

每句话都说给一个具体听众。人物会随对象和压力改变语言，可以误会、嘴硬、走神、打断、说半句，也会在关键时刻说得很直。

主要机体拥有欲望、身体史和不可替代的动作。战斗先让玩家明白双方争夺什么，再让地形、尺寸、变形、援护和精神回应改变局势。技术只解释玩家此刻必须懂的一步，宏观动作优先于密集零件运动。

先完成可连续阅读的故事正文。合同、状态、资产和制作预算不写入正文。

## 本话位置

- 章节：C02《木桶街，万机初开》
- 单话：C02E01《救命零件，限定发售》
- 时间：C01闭馆夜后的第一日，临近中午至夜间。
- 地点：木桶街外装卸坪、内街工房、三层货运环线。
- 形式：舰外ADV与探索、模型检视、模块选择、重载SRPG、战后舰内生活。
- 篇幅：以完整戏剧容量为准，建议约5000至7000汉字；不按场面平均分字。

## C01带入状态

- 万机馆在黎明前恢复为百余米长的巡展舰，低速飞行近六小时抵达木桶街。
- 纪存、唐胶、兜灯、跌跌、机器犬和馆守Z随舰；七海留在原城接受内部调查，只能通讯。
- 馆守Z失去原装右前臂，黄色巡展臂只能抓握、放锚、搬运和牵引；它没有常态飞行能力。
- 万机馆只证明旧引擎能抵达邻站，当前需要安全泊位、补给和完整检修。
- 无标志白色采样机带走馆守Z右臂残片，玩家尚不知道其归属。
- 木桶街坐标由一个唐胶认识、却不愿见的人发来。
- 纪存与七海原约好闭馆后吃饭。七海让他先找一张不会晃的桌子。

## 本话发动机

万机馆无法接入现代泊位。现场打开旧动力舱后，工务顾问陆衡确认六米主转子受过热冲击：舰体还能低速移动，但下一次战斗机动可能连带损伤周围动力。木桶街恰有一颗退役同型转子。

平台识别出万机馆的紧急需求，把普通退役件包装成限量直播商品，并让运输架提前驶向城外。纪存必须在不把整条街变成己方附庸的前提下取得转子。唐胶要面对自己曾帮助旧件进入流通、也让维修痕迹被抹去的过去。兜灯必须判断一套来自模型经验的推断能否安全进入全尺寸工程。

追逐最终由四个大动作完成：

1. 万机馆从街外放出主索，承住巨环上缘；
2. 单臂馆守Z压住外环高架，提供地面支点；
3. 火种货柜领袖以作业变形托住巨环外侧；
4. 无牌一号把全尺寸适配座送入安装位置。

转子装舰后只恢复有限航行，下一站仍须工务城做实装校正。

## 本话必须发生

- 万机馆接不上泊位，六米旧转子问题成为可见危机，不使用秒数倒计时。
- 木桶街同时容纳缩尺模型维修、全尺寸工程和退役实机，三种尺度在空间中看得见。
- 唐胶从旧教学模型或维修件的偏磨痕迹提出方向；陆衡在六米实物上复核；工房另造全尺寸适配座。模型不放大，模型经验不跳过工程验证。
- 一位母亲继续完成已故儿子留下的模型零件订单。她是一个具体的人，不是催泪装置；这条线要完成一次交付或回应。
- 火种货柜领袖首登。它是有独立人格的全尺寸载具生命，能在车辆、作业门架和约十四米机器人形态之间转换。它拒绝只让万机馆通过的付费快线，并让普通车队一起进入路线。
- 无牌一号首控。它是约八米的全尺寸模块竞赛底盘，不是模型巨大化；玩家在防护肩盾和配重叉之间选择主模块，选择立即改变外形和玩法。
- 纪存作出一次有魅力的主动判断，并组织临时机群完成逆转。他不是审批员，也不只是隐瞒故障后挨骂。
- 唐胶与兜灯都有不可替代的行动，并产生手艺分歧、身体距离和默契。
- 七海只通过一次自然通讯参与。她发现纪存起初淡化了舰况，两人的熟悉、担心和不快要落在人话与具体画面里。
- 白鸢本人不出现。现场可留下她的一项被抹去署名、但仍然实用的普通创作痕迹；它不预测未来、不改变现实。
- 战后有明确的胜利、喘息和生活温度。唐胶公开的维修页意外暴露四台同骨架飞行机仍共用一个服务号，自然发动E02。

## 物理与资产边界

- 万机馆约百余米，只停在街外装卸坪，不驶入内街，不变成人形。
- 主转子约六米，是无人格的工业总成。
- 馆守Z约十八米，只在外装卸坪和货运环线活动。
- 火种货柜领袖机器人态约十四米；无牌一号约八米。
- 地图只需一张三层货运环线。平台装卸机是压力单位，不需要新具名人格敌人。
- 巨环脱架发生在已经封闭、清空人员的无人货运坡道。
- 不新增一次性技术名词。可使用“主转子”“适配座”“泊位”“运输架”“舰索”“高架”等常识词。
- 不写CAD式机构过程；四个宏观动作必须能被玩家一眼看懂。

## 人物与机体

### 纪存

第一次作为巡展负责人面对外部共同体。他想让万机馆获得继续旅行的身体，也想证明自己能把一群临时相遇的人和机器组织成队伍。他熟悉七海，照顾具体的人，危险时判断快；对万机馆异常敏感的原因仍是谜。

### 唐胶

模型修复师，本名唐启明。回到熟悉的木桶街，既有旧人脉也有不愿面对的维修认证史。他说话来自材料、磨痕、工具和熟人关系；嘴硬不等于只会吐槽。

### 兜灯

本名窦晓宁，馆守Z整备员。她能真正决定馆守Z何时行动、何时停机，也能把模型线索翻译成需要被验证的安全问题。她与唐胶是维修间火花线，不是他的助手。

### 陆衡

跨港工务顾问Heng Lu Mwangi。本话作为现场工程判断者出现，正式加入留到C03。他负责把模型线索在全尺寸实物上验证，并明确安全边界；他与唐胶的分工是工程复核和手作经验。

### 七海

佐伯七海仍在原城受调查。她与纪存有既有私交，会担心，也会因他刻意淡化风险而生气。她不能远程替木桶街、平台或军方授权。

### 馆守Z

有独立连续人格的十八米巨型机器人。右侧是不能握拳的巡展臂，左拳完整。它自主行动，纪存只提供局势与方向。

### 火种货柜领袖

全尺寸变形生命。身体的变形是选择和表达，不是按钮特效。它有领袖感，但不复述现成角色台词，也不代表G.A.G.或火种源。

### 无牌一号

木桶街的全尺寸模块竞赛底盘，低权限AI与本地操作者共同控制。玩家可以决定本话主模块；旧零件、不对称外形和实际用途比堆满昂贵附件更重要。

## 本次显式准入素材

1. `PK_GUEST_FIRESEED`：变形是身体语言和社会身份；领袖不是让所有人服从，而是让共同体能够一起行动。公开对白原创。
2. `PK_GUEST_BUILD_ARENA`：模型是自由、玩家审美和认真对战；缩尺经验必须经过全尺寸工程才能成为真实机体。无牌一号的选择要像玩家在改自己的机体。
3. `ECO003`：稀缺和倒卖让真正需要零件的人拿不到。讽刺稀缺机制，不把玩家或收藏者写成坏人。
4. `DL009`：唐胶与兜灯一边争工具、饭盒、预算或安全，一边完成只有两人配合才能做成的维修。
5. `RWR001`：不懂模型的人为了爱而学会那门语言，继续完成离世亲人留下的零件订单。使用克制，完成具体交付，不加工死亡。

## 声线参照

- 纪存会从眼前物件和工作经验说话：“当然。你看充电线还插着，没拔线的展品，它就还不算退休。”
- 唐胶会把熟人责备与具体损伤连在一起：“你昨天让它挥了几百拳，它关节罢工了；水口也没修干净，肩轴里还有饼干屑。”
- 人物说话有听众、有语气和过渡。儿童、成年人、工程师、修理师与机器使用不同节奏。
