# C02《最后一届木桶杯》游戏流程解构

> Status: `candidate_game_adaptation`
>
> Source: 本目录五份 `纯剧情Reader-v2`
>
> 目标：把已经成立的比赛篇和机器人动画故事转换成五次不同的实际游玩，不让赛事规则、构筑字段和救援条件反向污染纯剧情。

## 全章主循环

```text
木桶街Hub与万机馆检修
-> 无牌一号资格战
-> 缩尺动作构筑与旧拳王训练
-> 资料探索与两场半决赛
-> 三分制冠军战
-> 多机群巨构救场
-> 转子安装、机体加入、白鸢登舰
```

玩家本章的长期所得必须清楚可感：

- 第一台可长期构筑的自主巨机：无牌一号；
- 一台武斗导师型主力：旧拳王；
- 万机馆新的主转子与木桶街维修网络；
- 模型动作意图 -> 工程验证 -> 实机训练的改装循环；
- 白鸢实体加入队伍；
- 完全版王者、重涂飞行队和火种货柜领袖成为可回援的地方伙伴。

## E01《无牌一号，出场！》

### Hub段

**地点：** 木桶街外圈泊位、内街模型市场、中圈旧件区、外圈全尺寸工房。

**玩家行为：**

1. 观看火种货柜领袖变形并牵引货运环入位。
2. 跟随兜灯检查万机馆主转子，确认无法再次起航。
3. 在赛事台询价、借用和抵押均失败，理解冠军转子的必要性。
4. 在合作社见到赵梅、三种工作尺度和无牌一号。
5. 选择少量可选旧件、寄售和模型互动，不改变主线报名结果。

### 资格战

**地图：** 固定货运环的一段直道，中央巨钟清楚可见。

**玩家单位：** 无牌一号；万机馆侧推器提供一次短冲。

**敌人：** 盾门将、重型门将，两者只推、拦、摔，不使用杀伤武器。

**胜利条件：** 九十秒内撞响巨钟。

**失败条件：** 时间耗尽，或无牌一号整机出界。

**剧情规则：**

- 第一次接住重型门将时自动触发收拳动作，但必杀不可使用。
- 玩家必须放弃未完成拳势，保留最后一次侧推冲过门将并撞钟。
- 本话不给复杂评分。钟响就是完整胜利，未完成拳成为下一话欲望。

### 话末状态

- 无牌一号取得四强最后一席。
- 万机馆无法横移，必须固定在泊位等待比赛结果。
- 完全版王者称无牌一号为A-7。
- 白鸢发现分镜被未授权用于赛事宣传，动身前往木桶街。

## E02《必杀技未完成！旧拳王的挑战》

### 缩尺动作构筑

这不是模型巨大化小游戏。玩家用手掌高素体选择和观察三个动作节点：

1. 接住；
2. 向前踏步；
3. 转腰出拳。

不同摆法只改变训练提示和容错。唐胶负责把动作意图说清；陆衡远程判断真机身体能否承受；本地工房制作防摔训练架；兜灯拥有停机权；无牌一号自己完成动作。

### 白鸢到场ADV

- 玩家陪白鸢撤下被盗用的补图广告，核对宣传来源。
- 纪存正式介绍白鸢与七海，完成首次有限原片保全协作。
- 本段不授予白鸢战斗改写能力。

### 重涂小品与飞行队预告

- 模型店发布三盒同模重涂，玩家可检查相同板件、新天线和不同贴纸。
- 随后红、蓝、黄三台同骨架实机从上空掠过，以高速、护航和远射三种动作建立差异。
- 三机不进入四强赛，不在本话成为可操作单位；E05回收预告。

### 旧拳王指导战

**地图：** 小型红环训练场。

**目标：** 在限定回合内完成“接住并踏出第一步”；不要求击败旧拳王。

**规则：**

- 旧拳王会在不同轮次使用重拳、假动作和主动撤力。
- 只等对手冲撞无法完成动作；玩家必须主动进入其拳距。
- 训练结束时仍不能打出完整逆转天冲拳。本话奖励是招式名、动作理解和半决赛准备，不偷跑高潮。

## E03《逆转天冲拳！师徒真打》

### 资料探索与选择

**地点：** 合作社资料室、两台巨机近端检查区。

**玩家行为：**

- 由跌跌与机器犬发现旧工号；对照舞台资产与维修册确认两台实机身份。
- 按时间查看原最终话、白鸢三年前补图、后续维修史和赵梅儿子的动作样机。
- 玩家可以选择赵梅资料公开程度和无牌一号内部呼号，但两台机体看见完整结局是主线事实。
- 退赛选项在故事内真实存在，不能靠菜单强迫机体上场；两台机体知情后自行选择继续。

### 半决赛A：完全版王者对坞工杰克

短战或演出战，核心是破解“全装过重”的直觉：坞工杰克把王者托起，王者不卸装备，而以长翼和双盾把倾倒变成换位，随后把对手推出界外。

### 半决赛B：无牌一号对旧拳王

**玩家单位：** 无牌一号。

**Boss：** 旧拳王。

**胜利条件：** 主动进入拳距，接住真打重拳，连续踏出两步，以逆转天冲拳把旧拳王送出界外。

**失败条件：** 无牌一号出界或机况跌破安全值。

**关键区别：** 本场不是资格战再演。旧拳王会拒绝免费送力，玩家必须主动制造必杀条件。

### 话末状态

- 无牌一号拥有完整逆转天冲拳。
- 完全版王者与无牌一号进入决赛。
- 两台机体知道旧角色结局，并约定在决赛后寻找第三种终局。
- 赵梅、唐胶、白鸢和三主角对“角色惯性与自由选择”的不同判断进入后续。

## E04《全装王者！三比二》

### 冠军战

**地图：** 固定货运环外圈擂台。中央转子检修区以实体防护墙隔离，不参与战斗。

**玩家单位：** 无牌一号。

**Boss：** 完全版王者。

**规则：** 三分制；击倒压制五秒或整机出界得一分，每分后重置站位。

**固定比分波形与玩家解法：**

1. 王者以长翼和双盾先得一分。
2. 王者用钻头假动作和压制再得一分，比分0:2。
3. 玩家正面承受盾墙，首次用逆转天冲拳破盾，1:2。
4. 王者拒绝送力，玩家用侧推主动贴身完成压制，2:2。
5. 王者全装备封路；玩家主动抢进冠军拳距，以自己的前冲叠加对手反击，终结为3:2。

玩家可以决定前四分的局部策略和损伤，但最终三比二及冠军归属不变。每一分必须有不同视觉，不用同一HP战斗重复五次。

### 赛后终幕与事故

**载体：** 短ADV、不可操作舞台演出、事故撤离短玩法。

- 两台机体再次确认后参加不计分、不剪辑的失落最终回演出。
- 无牌一号走出牺牲炮门；完全版王者放弃接甲，和它一起转向舞台炮。
- 老炮车制动失效，完全版王者为推开无牌一号跨上外轨；全装重量压断锈蚀支座。
- 白鸢立即停演，胶价王停播。玩家在人类尺度完成撤离和人数确认。
- 所有人撤出后，巨机构造事故才成为E05战场。

## E05《新的最终回！万机同援》

### 战场

倾斜的货运环临海侧、平行作业道、万机馆舰侧和拆解架组成一个多尺度地图。普通人已撤离，只保留远程操作的工程车和测绘无人机。

### 玩家单位与职责

| 单位 | 主要职责 | 记忆动作 |
|---|---|---|
| 无牌一号 | 顶住舞台炮，终结时回送全队力量 | 逆转天冲拳把巨炮送回拆解架 |
| 完全版王者 | 支撑无牌一号，主动卸甲脱困 | 全装各自转为桥、盾、警报和固定件 |
| 万机馆 | 多格支援单位，接住下沉一侧 | 不托整环，只改变战场边界 |
| 馆守Z | 以巡展臂固定断环 | 缺臂状态仍能承担巨构支点 |
| 火种货柜领袖与车队 | 沿有地面支撑的作业道拖近万机馆 | 变形生命的重载牵引 |
| 红机 | 一次高速标出承重区，随后过热 | 红色速度梗回收为有代价的优势 |
| 蓝机 | 低速护送工程单位跨裂口 | 稳定护航 |
| 黄机 | 高位击断支架并清障 | 精准远射 |
| 坞工杰克 | 托举工程车 | 作业机以力量改变通路 |
| 旧拳王 | 清障、牵引并提供终结判断 | 师父不抢徒弟最后一拳 |

### 阶段

1. 飞行队标路、护送、切断拖裂环面的支架。
2. 货柜领袖拖近万机馆；馆守Z与旧拳王建立稳定线。
3. 胶价王取消“牺牲剪辑”，承担商业损失，开放完全版王者的事故解锁资料。
4. 玩家由完全版王者本人确认卸下重炮与被卡长翼；其余装备转作战场构件。
5. 所有单位为无牌一号创造一条正对拆解架的力量通路。
6. 无牌一号以逆转天冲拳把舞台炮送回拆解架，事故解除。

### 结算

- 决赛结果保持三比二，不重赛、不加赛。
- 无牌一号把冠军转子限定用于万机馆本次航程。
- 无牌一号与旧拳王随舰；完全版王者、坞工杰克、飞行队和货柜领袖留在木桶街或转入陆路任务。
- 白鸢主动登舰；七海留在原城。
- 新转子启动后不能中途停机，工务城成为唯一下一站。

## 分支边界

本章可承载但不改变主线结果的差分：

- 无牌一号是否保留现名或登记内部呼号；
- 赵梅资料公开到何种程度；
- 决赛和事故原片立即公开还是延后整理；
- 万机馆是否继续与杂鱼港保持发行合作。

分支必须影响后续台词、支援、资源或公众理解，不能只生成一行理念评价。

## 制作边界

- 货运环决赛期间固定，不制作整环边打边转。
- 中央转子只做背景与章末交付，不成为战斗机关。
- 三台重涂飞行机共用基础Rig和动作集，只在喜剧预告与E05救场使用。
- 失落最终回用静止画、配音和少量舞台演出表达，不制作一整话旧动画。
- E05只保留六个大动作，不把每根索、每个支架和每台工程车的厘米级移动写进剧情。
- 白鸢的图只作为阅读、比较和规划界面，不直接生成现实道路、攻击或出口。
