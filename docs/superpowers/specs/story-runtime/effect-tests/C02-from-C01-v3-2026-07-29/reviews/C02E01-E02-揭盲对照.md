# C02E01-E02 揭盲对照审稿

## 审稿边界

- 只比较新稿 C02E01-E02 与旧稿 C02E01-E02。
- 旧稿后两话的完成度不计入优劣；“未来可扩展性”只看前两话已经留下的接口。
- 新稿未写后两话不构成缺失，不以旧稿后续已有回收为由扣分。
- 本报告只判断连续阅读效果，不校验 Canon。

## 总判定

**总体效应量：中度改善。**

新稿不是只把旧稿写长。它真正修复了三类关键问题：万机馆如何靠岸、为何必须整件换转子以及如何合法取得转子；模型线索怎样经过实物测量、失败试制和全尺寸复验才影响巨机；四台同骨架机为何必须拥有四套维护方式、四个呼号和各自决定行动的权利。这些改善已经进入事件和动作，不只是补在设定说明里。

但新稿也确实存在明显的长度收益递减。按同一文本计数口径，新稿前两话文本量约为旧稿对应部分的 **2.41 倍**；E01 约为 **2.58 倍**，E02 约为 **2.25 倍**。增加的篇幅中，一部分形成了必要的因果台阶，另一部分则在动作已经说明问题后再次用规则、总结句和对举句解释一遍。结果是逻辑更稳，阅读却不成比例地更顺。

因此，新稿适合作为更可靠的底稿，但还不是以当前体量全面压倒旧稿的版本。

## 效应量总表

| 比较项 | 效应量 | 核心判断 |
|---|---|---|
| 连续可读性 | **中度改善** | 场景之间的因果接力更完整，但节奏显著变慢，连续高潮和复述造成疲劳 |
| 因果和常识 | **显著改善** | 靠港、诊断、替件、产权、适配、安装限制均更可信；战区清场与平台割索逻辑仍有硬伤 |
| 目标与场面规模 | **中度改善** | 大小尺度和多单位分工更清楚，但单话容纳的目标层级过多 |
| 机体／模型／IP／玩法 | **显著改善** | 模型不再越权成为答案，机体差分进入操作，玩法目标更可执行 |
| 人物主动性和关系 | **中度改善** | 主角群与四机的选择更有代价，关系更深；旧稿的职业人物网络和轻快交锋有所流失 |
| 概念密度 | **退步** | 局部解释更清楚，前两话需要同时记忆的制度、权限、节点和主题却更多 |
| 情绪与生活 | **中度改善** | 战后、吃饭、修理、夜市与关系推进更充分；生活感过度集中在段尾 |
| 未来可扩展性 | **无实质改善** | 新稿留下的角色和状态接口更扎实，但旧稿的产业、工务城和职业角色接口更宽 |

## 逐项比较

### 一、连续可读性：中度改善

新稿最明显的进步，是每一步都能推出下一步。外港无法稳定靠泊，才需要馆守Z、货柜领袖和旧轨共同受力；停机检查排除外壳、轴和轴承问题，才得出必须整件替换；公共转子不能直接拆，才进入旧版本调查；维修页公开导致资产升值，才触发平台回收；四机被一个服务号压住，才依次追查召回、后续维修和旧广告。两话内部不再像若干设定场景拼接，而像一条连续运转的链。

旧稿的优势是进入快。固定爪接不上、街区纵深、母亲修模型、盒底姓名、巨环运输，几次转场都很短。E02 让四台机以相同变形、不同落地性格直接登场，几页内便完成“同模不是同一个人”的建立。它有跳步，但读者抓得住主线。

新稿的问题是每个因果节点都被扩成完整小戏，且小戏结束后常再补一段结论。E01 实际包含靠港、故障诊断、街区调查、模型验证、产权争夺、三点夺控、巨环失控、联合承接、购买安装九个阶段；E02 又包含充电差分、召回翻案、作者授权、三节点战、捕获救援、夜市善后。作为连续两话，几乎没有真正的低潮。

所以，新稿的“连续”更强，“一口气读下去”却未同比提升。改善成立，但没有达到显著。

### 二、因果和常识：显著改善

新稿对旧稿中最容易让人停下来追问的地方，给出了有效回答：

- 万机馆不是一句“停在城外”，而是有海锚、最低反推、中心桩、岸侧导向和旧闸的具体靠泊过程。
- 转子不是工程师看一眼便判死刑，而是依次校外壳、换轴承、拉直轴心，仍证明转子本体热变形。
- 木桶街正在使用六米转子，主角不能为了救自己让整片工房停摆。
- 模型只提供版本关系和检查方向；结论来自六米实物的整圈磨损、真实接口测量、全尺寸材料、失败件和第二次试制。
- 转子先恢复街区替代散热，再按旧租牌残值买回、转让给万机馆，最后低速安装复验。产权、公共利益与修船需求不再互相跳过。
- 四台机的充电、停放、识别和热限制都由真实身体差分产生，不只是服务页上写了四个名字。
- 七海没有靠否认旧召回来证明今天正确，而是区分“当年统一停飞合理”与“维修后永久合并不合理”。

不过仍有三处显著常识风险。

第一，平台在有人作业的外环启动紧急割索，让二十吨级巨环荡向港区，已经从强硬回收越过到极端公共安全事故。文本说明这是为无人区准备的脱困方案，却没有充分解释为什么系统在当前有人环境仍可执行，也没有给出平台承担如此资产和人身风险的决策链。

第二，新稿 E02 开战前缺少旧稿已有的民用空域关闭、交通艇撤离、维护区清空和人员进入防护区。三座节点、高架、工房与飞行仓之间发生空战，读者看不到明确清场，和 E01 对道路及工房不停摆的谨慎形成反差。

第三，旧广告为何能被空管当成合规动作模板、又为何能成为归一星的预测资料，仍偏概念先行。作者权利纠纷写得可信，艺术分镜进入安全与回收系统的技术路径尚未同样可信。

### 三、目标与场面规模：中度改善

新稿对尺度的组织明显更好。手掌大模型、工作台大小适配座、六米巨环、八米无牌一号、十八米馆守Z、百米万机馆彼此不混用；每个尺寸都有对应工作方式。巨环失控时，上端由无牌一号锁支点，下缘由货柜领袖托行，馆守Z只改方向，万机馆以舰侧吸收摆动，没有任何一机凭气势独扛二十吨级摆载。这是新稿最成功的巨物场面。

目标设计也更具动作性。“夺的不是转子，是那一天”“先拿回充电节点，但仍只能轮流实体接线”“两个锁扣必须都开”都能让读者理解当前阶段真正要完成什么，而不是只看一群机体混战。

代价是目标层级过密。E01 的靠港本身已经足以做一次开场任务，后面又连续升级到夺控与接环；E02 的三节点战已完成一轮完整高潮，归一星捕获镜星又立刻开启第二轮高代价救援。每话都像压入了两个主关卡和一个长尾结算，导致后续再出现更大场面时，升级空间反而被提前消耗。

### 四、机体／模型／IP／玩法：显著改善

模型线的改善最扎实，但也要看清其中哪些是新增，哪些是加固。旧稿已经做到“不把模型尺寸直接放大”，也已有实物磨损和全尺寸适配座试验。新稿真正新增的价值，是把证据链做成可反驳过程：先排除错误旧盒，取下灰垫做对照，清完整圈磨损，不围着假设找答案，第一件实机适配座失败，第二件才通过，并把失败原因交给本地工人复述。模型从“神奇答案”进一步退回到“提出可检验方向”，这是实质改善；但并非整条逻辑从无到有，部分新增篇幅是在重复加保险。

四台机也不再只是同一骨架的四款涂装。换装翼锁、偏重近战臂、双层识别、远射热区分别改变充电姿势、停放位置、节点打法和战后状态。IP辨识不只落在名字、配色和变形广告上，而进入“商品版本”与“经历过维修的主体”之间的冲突。

玩法表达更完整：无牌一号的模块由竞赛AI拒绝或接受，玩家选节点顺序会改变增援分配，取得充电节点后也必须让机体轮流返航接线，空管呼号和实体供电没有被一个按钮同时解决；救援阶段则要求三机放弃各自的击破机会。这些都比旧稿的三中继结算更能体现玩法代价。

仍需警惕叙事被设计说明侵入。新稿先枚举三种开局收益与代价，再完整演示其中一条，读感接近关卡文档；“玩家下令”“纪存规划”“机体自行选择”三种控制权有时同时存在。文本不断声明机体有主体性，但战斗关键动作仍常写成“玩家把路线交给某机”，戏内控制关系尚未完全清晰。

### 五、人物主动性和关系：中度改善

新稿中的人物选择大多有不可撤销的代价：

- 纪存撤回错误靠港方案，拒绝停掉木桶街救自己，动用维修储备，并向七海如实交代舰况。
- 兜灯能当众叫停馆守Z硬接巨环，也能压住唐胶抢装，专业判断不再只是陪衬。
- 唐胶承认灰垫出自自己，保护盒底姓名，公开方法和失败件，却不冒充全尺寸签字人。
- 馆守Z主动要求以残缺一侧面对街区，也主动选择工作方式。
- 四台机拒绝由平台挑出唯一留存者，分别决定开放哪些身体资料，并在救援中主动放弃战果。
- 七海公开完整召回史，以失去复职通道为代价，同时拒绝把过去改写成错误。
- 白鸢先行使停用权，再决定是否合作；她提供的是可修改候选稿，不是现实控制权。

关系也比旧稿更往前走。唐胶与兜灯在狭窄作业道里的互相制动、受伤包扎和斗嘴，纪存与七海围绕“别让我从警报里猜”的坦白，纪存与白鸢从权利冲突到彼此挑刺，均形成了持续关系，而不是任务性对话。

旧稿的损失同样明确。陆衡、罗莎琳、莉亚等具名职业人物，让工程验收、售后库存、召回亲历者分别拥有不同立场；新稿多由“领班”“老驾驶员”和平台统一承担，主角关系更深，社会关系却变窄。尤其平台在旧稿中有售后、回收、本地结算等不同职责，新稿更像一个单一的压迫意志，制度人物的层次下降。

### 六、概念密度：退步

新稿不是句句难懂，问题在于前两话累计要求读者保留的概念过多。E01 同时处理港口受力、主循环诊断、公共散热、批次缺页、教学模型、实机适配、平台所有权、街区租用权、一天优先期、远程保护、三个线路控制点、临时实机挑战、替代设备和残值转让。E02 又叠加服务号、四种充电协议、召回史、档案公开权、作者授权、行为模板、三服务节点、地面主钥、归一星预测、四呼号和远程支援网。

新稿通过解释降低了每个概念的局部理解难度，却没有减少概念总数；反而常在动作后用“不是……而是……”重新定义一次主题。读者不容易误解单个机制，却更容易在两话中途疲劳。

旧稿也密，但它把不少边界压进可选资料，并让人物和动作先行。新稿把几乎所有边界都搬入连续正文，可靠性提高，叙事弹性下降。概念密度因此判为退步。

### 七、情绪与生活：中度改善

新稿的情绪不是只靠胜利结算。母亲继续拆开站不稳的旧模型，收藏者亲手剪掉估价，馆守Z想让街区看见“风接回来了”，死锁失臂后保留临时配重与空肩，镜星过热时两层声音拒绝统一，四机留在木桶街却接入可拒绝的支援频道，这些都把主题落回具体生活。

两次夜间收束尤其有效。E01 的凉风、餐巾纸、机器犬、热粥和没吃成的饭，让修船后的身体感回来；E02 的风扇、夜市、四条不同高度的航迹、凉了一半的食物，则让战损和关系同时沉淀。新稿在情绪后果上明显强于旧稿。

旧稿仍保有新稿没有完全替代的轻盈：唐胶被整条街叫住、机器犬挂上“可摸”牌、喷气叛星落地刹不住、死锁拒绝广告式单膝动作、莉亚与七海之间的旧关系，都以很短篇幅给出性格。新稿的幽默更多集中在长机制段落之后，生活感分布不如旧稿均匀。

### 八、未来可扩展性：无实质改善

新稿留下了扎实的状态接口：万机馆只能低速前往工务城，维修储备见底；馆守Z仍缺原装右臂；死锁失臂、镜星过热；归一星只带走有限动作样本和匿名重载扫描；四机留守木桶街并拥有可拒绝的支援位；七海准备到现场，白鸢也在赶来；第三记拳馆铃直接开启下一话。这些接口都保留限制，没有把前两话胜利写成彻底解决。

但旧稿前两话同样留下了外泊校正、停产件复产、工务城预检、售后库存、未发售工程样件、拳馆广告、白鸢来访和馆守Z断臂数据等多方向接口。新稿的人物接口更集中、更有情感牵引；旧稿的产业、城市和职业角色接口更宽。

新稿还把两话的场面抬得很高。百米舰接巨环、三点夺控、三节点空战、二阶段捕获救援都已用过，后续升级容易继续依赖更大事故和更多系统权限。它的状态延续性更好，但空间并没有明显比旧稿更大，所以判为无实质改善。

## 新稿真正改善了什么

1. **把“能解释”提升为“能验证”。** 靠港、故障诊断、模型线索、适配件和四机维修差分都经历了可见检查，而不是只靠权威角色宣布。
2. **把伦理约束变成行动约束。** 不停掉木桶街、不泄露盒底姓名、不替四机同意资料使用、不拿旧召回抹掉后续身体，都会改变人物下一步怎么做。
3. **把大场面拆成真实分工。** 万机馆、馆守Z、货柜领袖、无牌一号都只承担自己尺寸和结构能完成的部分。
4. **把胜利写出后果。** 钱花掉了，舰仍不能战斗，死锁失臂，镜星过热，七海失去复职通道，四机也没有因此被收进万机馆。
5. **把人物关系推过了任务合作。** 唐胶与兜灯、纪存与七海、纪存与白鸢都形成了下一话仍会继续变化的关系。

## 新稿失去了旧稿什么

1. **更快的抓人方式。** 旧稿的“固定爪接不上”和四机同步变形、分别落地，都是更短、更有记忆点的开场。
2. **更均匀的街区生活。** 旧稿把食物、橱窗、笑声、店主和交通细节散在任务途中；新稿常先连续讲机制，到 F06 再集中补生活。
3. **更宽的职业人物网络。** 工程师、售后负责人、事故亲历驾驶员在旧稿各自代表一套专业与责任，新稿将这些功能压回主角和匿名角色。
4. **更克制的平台冲突。** 旧稿把合法所有权、运输优先权、售后与回收命令分开；新稿虽补足条款，却让平台连续取消宽限、锁死急停、切索、冻结服务、侵权并控制空管，制度复杂度反而收束成单一反派性。
5. **更利落的单话轮廓。** 旧稿每话有一个主问题和一次主要战斗；新稿每话包含多次任务重定义，高潮辨识度被摊薄。

## 是否只是变长

**不是，但有相当一部分只是把同一结论证明了更多遍。**

必要新增包括：完整靠港、转子不可局部维修的排除诊断、公共转子不能直接拿、产权转让、四种实体充电方式、召回令原本应逐机解除、白鸢授权与四机同意、节点恢复后仍需实体接线。这些内容改变了因果和人物选择，删掉就会退回旧问题。

收益较低的新增主要是：模型证据链在已经成立后继续增加多个同义保险；平台条款和节点状态被人物、界面、叙述者重复说明；每次行动后再用主题句解释“真正夺回的是什么”；玩法分支先完整讲一遍，再演一遍所选路线。新稿的长度并非虚增，但目前没有把新增信息压缩到最有效形态。

## 仍未解决的问题

1. **前两话容量超标。** 每话六个 F 均承担新机制或新高潮，读者很难判断哪个才是该话的主峰。
2. **平台危险行为缺乏足够决策依据。** 有人环境下切索释放二十吨巨环，是全稿最大常识断点。
3. **E02 战区安全没有交代。** 空战发生前应能从正文确认民用空域、工房人员与地面通路的状态。
4. **旧广告进入空管和预测系统的技术链仍悬空。** 权利问题已写实，系统使用方式仍像主题装置。
5. **玩家、纪存与机体的控制权边界仍摇摆。** 机体被写成主体，却常由玩家逐台确认关键动作；需要让“战术建议、操作输入、自主拒绝”在文本中稳定区分。
6. **平台部门层次被压平。** 所有权、租赁、回收、竞价、空管、档案与广告像由同一个意志即时联动，削弱了新稿努力建立的现实制度感。
7. **解释性总结过多。** 动作已经证明主题后，正文仍频繁复述结论，造成“读者刚看懂，叙述又讲一遍”的拖感。
8. **未来升级压力偏高。** 前两话已连续使用百米舰、二十吨巨环、多节点空战和捕获救援，后续若只靠扩大规模会迅速失去层次。

## 最终意见

新稿应判为一次**有真实结构收益的中度改善**，不是无效扩写。它在因果、模型与实机边界、玩法可执行性、人物选择代价上明显优于旧稿；最值得保留的是完整靠港、诊断排除、模型到实机的反证链、四种实体维护方式、七海对两段历史同时负责，以及四机放弃战果回救镜星。

它尚未达到“显著整体改善”，主要不是因为没写后两话，而是因为前两话自身已经过载。若只看连续阅读效果，新稿当前最大任务不是再补解释，而是确认哪些机制已经被动作证明、哪些高潮可以只留一次、哪些生活与人物反应应提前穿插。逻辑底座已经更强；下一步真正决定成败的是节奏，而不是继续增加证明材料。
