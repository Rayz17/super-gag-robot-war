# C02E02《同模不是同一个人》运行卡

## 本话职责

- 前因：E01公开维修史并夺回转子，平台沿同一服务号冻结四台重涂机，派归一星回收。
- 唯一主要目标：夺回四台机各自的基础服务与行动权，并阻止“拆三保一”。
- 中段转向：统一召回当年确实救过驾驶员；错误发生在后来把四种维修人生重新压回一个商品号。
- 独立高潮：四机用共同起手骗过归一星，再以四种结尾取胜；归一星二次学习抓走镜星，另外三机回头夺人。
- 结束状态：四台机恢复独立呼号并成为后续援军；归一星带走有限战斗样本；白鸢决定亲自到木桶街。

## 必须兑现

- 四台机的差异必须来自头雕、翼型、武器、维修史、声线和战斗选择，不只是颜色。
- 七海承认原召回的正当性，也公开后来四份维修记录；她因此付出现实职业代价，但不远程授权胜利。
- 白鸢先保护作品，再提供一张可被现场否决和修改的候选图；图不驱动物理世界。
- 纪存主动停止使用侵权旧图，随后以对四机当前状态的观察提出战术反转。
- 归一星不是索引人格；它的“拆三保一”有资源理由，但没有替另外三台决定死亡的正当性。
- 战斗必须让玩家亲手使用四台机的不同性能，并在第二阶段主动回头救镜星。

## 不得提前消费

- 白鸢肉身登舰、未来视或战斗改写席。
- 四机永久加入万机馆本队；本话只建立木桶街支援关系。
- 索引显形、真正重涂人格战争或C05百相事件。
- 归一星知道四机内心、维修者私人记忆或未来动作。

## 期末状态要求

- 记录四机、归一星、货柜领袖、无牌一号、馆守Z和万机馆的位置、损伤与后续用途。
- 记录七海公开资料后的处境、纪存与七海的关系变化、纪存与白鸢的第一次冲突和吸引。
- 由白鸢到场追稿与旧拳馆挑战双钩子发动后续，但不在本话展开。
