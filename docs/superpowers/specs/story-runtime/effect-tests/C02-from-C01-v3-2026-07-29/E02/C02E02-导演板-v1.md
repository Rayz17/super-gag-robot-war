# C02E02《同模不是同一个人》导演板

## 一句话戏剧

- 表层争夺：平台冻结四台同骨架飞行机的充电、空管和维修服务，派归一星执行“拆三保一”。
- 深层压力：当年的统一召回确实救过人；问题不是标准本身，而是平台在四台机已经活出不同人生后仍把它们压回同一个商品号。
- 本话大画面：四机先故意重演同一套出厂起手骗归一星收索，随后分别以叛逃、近战、自我反射和远射四种结尾撕开统一空域；归一星二次学习后抓走镜星，另外三台放弃胜利回头抢人。
- 关系核心：七海公开自己当年签过的召回并失去内部回旋余地；白鸢先以权利申诉与纪存冲突，再把一张没有结尾的候选图交给现场修改。
- 结束新局面：四台机恢复独立呼号但留在木桶街；归一星带伤撤走有限样本；白鸢决定亲自来追回原稿，旧拳馆的挑战铃同时响起。

- 只需产生疑问：归一星护框里的馆守Z负载扫描来自谁；平台样本是否流向更大的执行链。
- 后台真相：索引不在本话显形，G.A.G.不替四机发言。
