# C02E02-F03 作者从广告里把手伸回来

白鸢发现自己的旧分镜又活了，是因为它正在平台广告里把四台机变成同一个人。

远端工作室的屏幕上，四种涂装依次掠过同一条城市航线。它们用完全一样的角度展开机翼，以完全一样的姿势转向，最后并排收束成一个标准剪影。广告把这段旧动作重新送进木桶街空管，准备用它判断四台机是否服从统一服务号。

原稿右下角的署名被平台标志盖住了。画面里的四机也不是现在的身体：翼锁还是旧式，双臂同重，识别器只有一层，远射组件根本不存在。

白鸢追查复制记录时，看见万机馆的战术桌也调入了这组分镜。

她发出权利中止请求，接通木桶街之前，已经准备好先骂人。

通讯打开，战术桌却是一片黑。

纪存站在拔掉信号线的投影机旁，平台广告已经从飞行仓的本地屏幕上消失。桌面只剩一行断开提示。

几分钟前，平台刚提出用旧广告动作重新识别四台机。纪存本想从中找出空管会如何判断它们，却在放大画面时发现原始格号被重新排列，角落还有一道被粗暴裁掉的白色鸢形署名。

他没有等作者出现，也没有先问能不能借用。他关掉投影，清除战术桌上的广告副本，又让木桶街停止转播这组画面。平台自己的空管还在使用旧模板，但现场不再拿侵权图做计划。

权利请求上的正式姓名是Evelyn Voss，英文署名White Kite。中文界面把她显示为白鸢。

她没有开摄像头。通讯里先传来纸张被快速翻动的声音，随后是一道清楚而偏低的女声。

“断开画面不能证明你们没留副本。”

“使用记录和删除回执都给你。”纪存把终端转向通讯窗口，“我先停，是因为作者被抹掉了。现在才轮到解释我们为什么打开它。”

“博物馆的人总觉得，只要把偷来的东西摆得足够认真，就算保护。”

这句话正好扎在纪存最不愿被碰的地方。

“作者也别把每个打开文件的人都画成贼。”他说，“你打进来以前，这张图已经停了。”

白鸢沉默了一下。不是被他的礼貌打动，而是在检查他发来的日志。广告副本确实只被调用过一次；投影中止早于她的权利请求，本地缓存也已经清空。

七海从另一条私人通讯接入。她已经失去内部档案权限，只能用公开登记核对署名。她确认那道被盖住的鸢形记号属于白鸢，平台广告没有展示作者，也没有取得继续改作的许可。

“他至少把顺序做对了。”七海说。

白鸢问：“你经常替他解释？”

“只解释我亲眼确认的部分。”七海答得平静，“剩下的麻烦通常由他自己制造。”

纪存看了七海一眼。白鸢听出了两人不是今天才认识，却没有沿着这句话追问。

“停用成立。”她说，“合作不成立。那是两回事。”

纪存也没急着求她。他重新打开的是四台机当前的现场影像，不是旧广告。

“你的最后一格要求它们同时收翼、同高度并排。”他说，“喷气叛星的新翼锁会被卡住，死锁会被重臂拖偏，镜星会让空管看到冲突回波，雷翎的远射系统会贴进快充热区。那段结尾现在一台都做不完。”

通讯里传来笔尖突然停住的轻响。

“那是给旧基础型号画的商业分镜。”白鸢的语速慢了下来，“你拿我没见过的四副身体来批改旧稿，挺会挑便宜。”

“平台正拿这份旧稿决定它们今天应该怎么飞。便宜已经被别人占了。”

这次轮到白鸢被冒犯。可她没有切断通讯。

纪存不是拿作品当装饰，也不是只会说尊重作者。他一眼找出了漂亮结尾落不到现实里的四个原因。更令她不舒服的是，他说得对。

“我可以看当前资料。”她说，“不保证给你答案。”

白鸢先列出自己缺的东西：四台机此刻的正面、侧面和可动部位照片；飞行仓的风向、仓门、三座服务设施和空域识别回波；每台机剩余电量与明确的维修禁区。最后一项不是数据，而是四台机各自是否愿意让她使用这些资料。

纪存把要求原样转给四台机，没有代它们回答。

喷气叛星同意提供照片，却要求删掉旧广告里那张整齐领飞的脸。死锁开放重臂承重数据，但不接受被换回轻型手臂的假设。镜星允许白鸢读取双层识别回波，保留随时撤回干扰数据的权利。雷翎只上传当前传感范围，不预先交出它会选择的目标。

四道确认逐一亮起后，白鸢才把工作画面共享到战术桌。

她没有让旧广告重新播放。屏幕上出现的是一张带格号的工作稿，旧广告的整齐收尾被粗黑笔整段划掉。四台机最后并列成一个剪影的画面彻底消失，只剩最前面那段共同起手：同一副基础骨架都能完成的展开、加速和转向。

从那个共同动作之后，纸面分成四条空白结尾。

“我只知道它们现在给我的资料。”白鸢说，“风向会变，识别会变，对面下一步做什么也没有画在这里。这是一次排练，不是预言。”

纪存盯着那段共同起手。平台既然把旧广告当作识别模板，就会期待四台机沿着同一套工厂动作继续收束。它们不必从第一步就各飞各的，反而可以先让空管看见熟悉的开头，再由四个主体决定各自如何离开。

“开头别改。”他说，“它们一起演到平台相信为止。后面四条路，谁的身体谁来填。”

“你刚停掉我的图，现在又告诉我哪一格该留。”

“停掉的是未经许可的广告。现在我在给一张新方案提意见。”

白鸢笑了一声，很短，听不出是恼火还是觉得有趣。

“你的礼貌长得很像挑衅。”

“你的帮助也不太像帮助。”

“很好。至少我们都没认错。”

她保留了共同起手，没有替四条空白线补上英雄式结尾。现场的修改随即开始。

喷气叛星把第一条线拖离整齐队形，留下可以临场改向的宽阔出口。死锁把第二条线压低，删掉无法承受的高位急转，让重臂能在地面设施附近真正发挥。镜星把第三条线分成正反两层，只标出可以扰动识别的范围，不预写它要把谁变成敌人。雷翎把第四条线移出热区，在远处留下一片待选目标，而不是一个已经替它决定好的射击框。

木桶街工房员随后把仓门开度、承重边界和不能碰的检修区画进底图。几处白鸢原本留得很漂亮的弧线被当场截短，一条构图最利落的高速路线因为喷气叛星翼锁的真实限制整段作废。

白鸢看着自己的图被改得满是粗线和维修记号。

她没有恢复旧版本。

她把所有现场修改保留在可编辑层里，又在四条结尾末端各留出一块未封死的空白。导出的文件只有画面顺序、现有数据和需要现场确认的分支，没有任何能接入四台机控制系统的指令。

“这张图不会让它们动。”白鸢说，“真正起飞以后，驾驶和机器决定动作，工房判断哪些还能做。现场一旦和资料不一样，先改图。”

纪存试着把共同起手与四条路线在桌上推演一遍。旧广告原本只会得到一个漂亮剪影；现在，同一个开头能通向四种彼此不冲撞的行动，而且任何一台临时改主意，图上都有地方容纳。

他不得不承认，白鸢把一堆互相顶撞的照片、回波和维修限制整理得极快。白鸢也不得不承认，纪存没有把她请来画一张稳赢的答案。他先停掉作品，再指出她没看见的身体，最后把决定留回现场。

“这回算合作？”纪存问。

“算一份随时可能被现实改坏的候选稿。”

“那就比旧广告有用。”

“这是我今天听过最讨厌的夸奖。”

她的通讯没有断。

战术桌上，共同起手与四条可修改结尾已经就位。飞行仓里的四台机仍没有获得电与空域，发动机也一台都没有启动。

图只把选择摆到了它们面前。

真正的第一步，还要等现场亲手执行。
