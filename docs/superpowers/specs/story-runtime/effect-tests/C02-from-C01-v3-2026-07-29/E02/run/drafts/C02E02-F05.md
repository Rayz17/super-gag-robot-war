# C02E02-F05 三台叛星一起回头

三个服务节点全部亮回木桶街的标记，四个呼号第一次各占一条航路。喷气叛星已经冲过最高的塔架，死锁沿低空逼近，雷翎在货运高架外侧拉出射线，镜星则守在识别节点上方，用两层镜面维持四路通行。

归一星没有再抢节点。它收拢胸前的移动托架，像是终于承认失败，转身向街区外空域撤退。托架中央的回收核心完全暴露，后方推进器也失去节点掩护。三台追击机的界面同时亮起扩大战果的机会：喷气叛星可以抢到敌机前方，死锁可以再给装甲一记重击，雷翎则握着贯穿退路的最佳射界。

它们追了上去。

归一星就在这时放出四根回收索。

它没有猜中任何人的下一步，也没有多出第五根索。它只是把刚才看见的四种收招倒着铺回天空：一根横在喷气叛星急转后最爱占据的高位，一根贴住死锁重臂落下后的低空直路，另一根守着雷翎避开正面射线时会换去的侧翼。最后一根没有扑向镜星，而是横过镜星刚刚用来分出四个识别信号的反射通道。

第一根逼得喷气叛星抬头，第二根压住死锁的进身路线，第三根把雷翎挡在远射角外。镜星看见三条航路同时被截，立刻转动头部识别器，想把四个呼号再反射一次。

它的镜面亮了，却没能及时分开。

高架节点上的第一次拆分已经让识别器烧到警戒线，面罩边缘还在向外排热。归一星的扫描光从它脸上一掠而过，公开的过热标记直接跳在战场上。那根横在反射通道里的回收索猛然折返，另一根也从死锁脚下抽走。两根索一上一下扣住镜星，把它从识别节点前拽进移动托架。托架合拢，四个刚刚分开的呼号顿时缺了一路。

死锁看着自己的重臂挥空，终于明白归一星做了什么。

它不是学会了四台机。它只把四个刚见过的句号，摆成了四个陷阱。

归一星重新加速。被它拿来捕获镜星的两根索缩进托架，另外两根在外侧交错护航。屏幕上的追击目标仍然敞开：喷气叛星再向前一段就能撞上回收核心；死锁只要沿低路追到底，重臂就能砸进敌机腹甲；雷翎换回原来的远位，依旧有机会打穿撤退推进器。继续追，它们甚至可能把归一星留在木桶街。

万机馆本体从泊位传来一幅简图。移动托架由上下两处大锁扣住，只开一处，托架就会带着镜星翻转，另一处反而越咬越紧。无牌一号守在地面的总控钥匙旁，把刚夺回的四个呼号持续送进本地空管，却够不到正在远离的托架。

归一星拖着托架穿过货运高架之间，所过之处，统一空管把沿线航路一段段标成封闭。它想在离开街区前重新获得高度；一旦越过最外圈塔架，托架便会藏到它身后，地面再也看不见两处锁扣。

玩家界面上的战场目标随之改变。击破归一星的标记没有消失，只是退到次要位置；托架上方和腹部各亮起一个脱离点，计数仍是零。三台机都能看见自己的胜利路线，也都能看见镜星被两层甲板挤在中央。那不是一道选择题，而是三条已经伸到手边的战果，等着它们亲自松开。

纪存把追击标记全部压到界面一侧，只留两个醒目的脱离点。

“先把它带回来。上锁、下锁，都得开。”

玩家的行动选择落下。

喷气叛星最先取消了撞击回收核心的路线。它已经抢到归一星前方，本可以把第一份战果算在自己头上，却忽然收翼翻身，从敌机鼻尖倒冲回来。

“少一台，谁来承认我是第一？”

它故意亮出自己的呼号，又重演了一半方才的急转。归一星外侧的两根索果然同时追来。喷气叛星没有把动作做完，而是在高架支柱间猛然改成贴地俯冲，把两根索引离托架。玩家沿连续亮起的空隙穿过塔架，两根回收索被拖得越拉越开，最后缠上不同方向的钢梁。喷气叛星失去了撞击敌机核心的正面机会，却替另外两台机清出了一条直通托架的路。

两根索在高架两边同时绷直。喷气叛星把双翼喷口全开，沿街区航路正中向前猛冲，竟拖得归一星的上身向后偏转。钢梁上的索痕一路炸出火花，归一星只能自行切断外索，才没有被整个拽停。断索从喷气叛星左右甩过，它从交叉的火花里冲出来，回收核心已经被敌机转身护住。属于它的击破机会到此为止，救援通路却真正打开了。

雷翎也放弃了原先的最佳射界。它收起已经对准撤退推进器的长射线，从货运高架外侧压到近处。距离变短，托架和镜星叠在一起，任何偏差都会击中被捕者。

镜星的声音忽然从托架内部传出来。一层高，一层低，先后报出四个已经分开的呼号。过热的识别器无法再把它们送到整片空域，它便把托架自己的扫描光折回内壁，让四个呼号分别落在四处感应面上。

归一星的托架原本只准备收纳一个统一目标。四个有效呼号同时从内部出现，上下锁扣开始反复确认，没能继续收紧。镜星没有替外面的三台机开门，却让那两扇门暂时无法重新咬死。

雷翎看见上方锁扣露出。

它把最适合击落敌机的那一枪，换成贴着镜星头顶掠过的近线射击。长光击碎托架上锁，半边外壳猛地弹开。雷翎被爆开的气流掀离射位，退路推进器则趁机滑出它的准星。归一星没有被击落，但第一处脱离点亮了。

弹开的甲板迎面扫来，雷翎收枪横挡，整台机沿托架外壳擦过。玩家要在短暂露出的锁扣与镜星之间压住准线，射偏便只能重新绕行；这一枪命中后，上锁化成一圈翻飞的碎片，镜星头顶第一次露出木桶街的天空。雷翎的远射翼还在震动，却没有退回远处补那一枪。它留在近线，替下一个破口挡住归一星的转身。

下锁还压在托架腹部。归一星一边撤退一边翻转身体，用剩下的装甲把它藏向死锁另一侧。死锁的改装重臂本来就是为正面打穿敌甲装上的，它与这副量产身体并不相容，每一次全力挥击都在机身接口上留下新的裂响。

现在，敌机腹甲和下锁同时落进它的攻击范围。重臂若砸向腹甲，归一星会再受重创；若伸进托架，手臂就会被合拢的甲板卡死。

死锁没有减速。

玩家推动它穿过喷气叛星引开的索路。死锁贴上移动托架，将整条改装重臂刺进下锁旁的装甲，折叠刃在敌机内部完全撑开。下锁被顶得变形，归一星急转，想连同手臂一起把死锁拖走。死锁肩部的警报连成一片，重臂与身体之间只剩最后的供能连接。

归一星带着它撞过高架外沿。死锁没有用另一只手去抢回重臂，而是反扣住托架缺口，让自己的身体成为一枚楔子。玩家继续压住攻击，改装臂便在敌甲深处越撑越开；若此刻松手，它还能带着手臂脱离，但下锁也会重新缩回装甲。镜星就在锁后，隔着裂缝伸出一块反射板，把死锁自己的呼号照回它面前。

镜星从托架里看见那条手臂已经拔不出来。

“死锁。”

“出口归我。”

死锁主动断开肩部。它的身体猛然后退，改装重臂永久留在归一星的甲板里。紧接着，手臂剩余的动力全部灌进撑开的折叠刃。沉闷的爆炸从托架内部顶起，下锁连同腹部装甲一起被炸开，第二处脱离点终于敞开。

四个独立呼号在破口里同时亮了一次。镜星把托架最后一轮识别光分向四面，合拢机构再也找不到一个可以统一回收的目标。它从上下裂开的托架中冲出，带着烧红的面罩和两道索痕翻向低空。

死锁用仅剩的手臂接住它。冲力把两台机一起撞向高架边缘，喷气叛星从下方掠过，用推进气流托住它们的下坠；雷翎转过枪口，击断了还挂在镜星背后的残索。

“四号归队。”雷翎说。

“第三名归队。”喷气叛星立刻改口。

镜星的两层声线在死锁臂弯里重合了一瞬，又重新分开：“四个呼号，全部响应。”

死锁看了一眼空掉的肩部，只回了一声：“收到。”

喷气叛星本想抢到队形最前面，翼尖却先向镜星那边偏了一下，确认它能自行推进才重新抬头。雷翎没有回到已经失去的最佳射位，而是横在四台机与归一星之间，长武器稳稳指住敌机，让负伤的死锁先降到安全航路。镜星则把自己的呼号从另外三个信号中单独点亮，再依次回传三次回应。

没有哪台机变回同一种声音。它们只是第一次把彼此的差异，当成了队形里必须留下的位置。

归一星没有坠毁。它的移动托架被上下撕开，腹甲里还嵌着死锁烧毁的重臂，四根回收索也只来得及拖回残段。它放弃街区节点和新的捕获目标，把全部动力转给撤退推进器。

爆开的托架深处，一块受保护的数据匣闪过最后的存量：四机共同起手的记录、四种首次收招，以及一份没有来源标记的十八米级重型机负载扫描。那份扫描只有缺失原装手臂、黄色作业臂与巨型受力轮廓，像馆守Z，却没有名字，也没有采集者。刚刚发生的三段救援动作所在的外层记录器，已经和死锁的重臂一起烧穿。

归一星带走的只有这些有限样本。它没有得到四台机为何回头，也没有得到任何人的私人记忆。

受伤的敌机升出木桶街外空域，统一空管的声音随它一起远去。四个本地呼号仍分别亮着。镜星离开死锁的单臂站稳，喷气叛星和雷翎一左一右靠回队形。

这一回，没有一台继续追。
