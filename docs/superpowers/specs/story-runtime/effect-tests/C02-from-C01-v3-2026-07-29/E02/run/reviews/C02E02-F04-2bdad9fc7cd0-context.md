# C02E02-F04 同样开始，各自结束

三座服务节点同时转红，木桶街上空只剩一条平台允许的航线。

飞行仓旁的节点控制充电设备，高架顶端的节点控制空域识别，货运轨道外侧的节点控制维修通路。三处都被回收无人机占住，地面主钥也被切到远程一侧。四台机还有起飞所需的残余电量，却既不能补充，也会被统一空管驱赶进同一条标准路线。

商品回收王牌“归一星”从三座塔之间降下。

它没有模仿任何一台喷气机。宽阔机身背着整齐的回收架，四只缆鼓分列两侧。它的能力只有三件：四根索抓回四台机；统一空管封锁高度和航线；读取已经发生过的动作，再用工厂记录推断下一步。它没有火炮，也不知道四台机心里会怎样选择。

平台的理由并非凭空而来。一个旧服务号只供应一套标准资源，留下最接近原规格的一台，拆下另外三台作为备件，确实最省维护。归一星要做的，就是把这个答案变成现实。

万机馆的战术桌展开木桶街空域。三座节点可以任意先夺，地面主钥则必须由地面单位亲手扳回。万机馆只在地图边缘提供传感与返航引导；全舰尚未校正，不能离泊追击，更不能替四台机开火。

玩家把光标停在三个起点上，三种打法都能立刻看懂。

若先攻高架识别节点，镜星必须带着低电量冲进空管光束，喷气叛星在外侧拖走回收索，死锁和雷翎替它挡开无人机。成功后，天空会先承认四个呼号，四台机也能各走一条航路，充电系统也会先建立四份并行排队资格；但充电节点和地面主钥仍在平台手里，墙内机械臂不会为这些呼号伸出，第一轮谁都不能落地补电。

若先攻货运侧维修节点，雷翎会从远处打断外门锁销，无牌一号便能沿轨道进入通路，提前占住地面主钥。代价是充电和识别都没恢复，空中的四台机只能交替诱索、交替滑翔，用轮换和回避省下残余电量。

这一轮，玩家先选飞行仓旁的充电节点。

它不会向天空送电。拿回它，只能让木桶街重新操作飞行仓里原有的机械充电臂与手动切换台。在高架识别节点夺回之前，四台机仍共用一个旧服务号，机械臂每次依旧只认一台。收益是续航能够一台接一台稳定下来；代价是每次都有一台离开战场返航接线，另外三台必须替它守住天空。

木桶街公共竞技场再次开放无牌一号的地面支援席。八米全尺寸竞赛实机仍装着攀轨模块，玩家可以让它沿地面设施接近主钥，却不能代替四台飞行机夺取空中节点。

白鸢的候选图悬在地图上层。共同起手是一条实线，后面四条路线仍可修改。图上没有自动执行。纪存把首选目标送进四台机的驾驶界面，展翼、转向和射击都要由玩家逐台确认，再由机体真实完成。

工房员拉起飞行仓的机械应急门。那只是打开现实出口，没有解除平台空域。

“先把旧广告演完开头。”纪存说，“等它把四根索都交出来。”

喷气叛星、死锁、镜星和雷翎排成旧广告里的标准队形。它们同时展开基础翼架，同时加速，同时沿红色航线完成同一轮转向。

归一星的识别光逐格复现旧广告。按照它读到的共同过去，这段起手之后，四台机应该同时收翼、降低高度，并排进入回收区。

四只缆鼓一齐打开。

四根回收索抢先射向广告里预定的收束位置。

玩家把第一道分支交给喷气叛星。

它猛地离开队形，高扬双翼贴着归一星正面翻过，把追着自己的索拖向高处。归一星转动整副回收架追它，索头才刚贴近翼尖，喷气叛星已经突然下切。

“共同动作到此为止。”它笑道，“后面这段，你没买到。”

回收索没有抓中它，反而横在归一星与飞行仓之间。为免自己的索缠住回收无人机，归一星不得不抬高机身。充电节点下方露出低空通路。

玩家切到死锁。

死锁没有跟着升高。重型近战臂把它的身体拖得更低，它便贴着塔基直扑节点。几架无人机挡在前方，死锁用肩甲撞开第一架，随后抡起那条不在工厂记录里的重臂，一击砸碎节点外侧的回收封罩。

破开的只是平台加装的装甲壳，塔体和供电线路都留在原位。死锁把折叠刃插进裂口，整片封罩被它扯落。飞行仓墙内传来沉重的滑轨声，原本缩回去的机械充电臂重新伸到本地工位上。

它没有隔空给任何机体补电。

死锁打完这一击，电量警报已经压过一切声音。玩家命令它脱离低空，返回飞行仓。工房员先用地面支撑托住重臂，再扳动手动切换台。旧服务号只亮起一个接入框，机械臂沿滑轨移动到死锁侧面，实实在在扣上接口。

死锁接线时，场上只剩三台飞行机。

喷气叛星继续把一根索引离仓门，镜星反射另外两根索的测距，让它们反复扑空，雷翎则从远处打掉试图重新罩住节点的无人机。死锁只补到足够完成下一次大动作便主动断开，机械臂收回，手动切换台才把那个唯一接入框交给喷气叛星。

喷气叛星返航时，死锁重新升空接替它的位置。它让换装翼锁保持展开，机械臂绕开高翼，从另一侧扣紧接口。随后是镜星，工房员先隔离双层识别回波再接臂；雷翎最后落到仓门外的低负荷工位，由同一条机械臂拉出实体延长线，接上远离远射组件的接口。

四台机轮流短充，没有一刻同时受电。每次轮换，玩家都少一台空中单位，另外三台必须改换站位守住充电节点。它们得到的也不是满电，只是把摇摇欲坠的残余航程接成了能继续作战的续航。

归一星趁轮换把无人机集中到高架识别节点。代表路线的第二处因此比开局更难攻；若玩家第一步先拿高架，这批增援会改去堵充电节点，四台机虽然早早分开呼号，却要用初始低电完成第一次强攻。

白鸢原先画给镜星的直线路线被增援堵死。她只在共享层上划掉那条不再成立的线，新的入口由玩家选择。

镜星从服务塔背面升起，双层视窗同时亮起，前臂干扰板向外翻开。高架节点正在把四台机的回波压成同一个对象，它便把识别光完整反射回去，再从相反方向送出四道位置不同、声纹不同的回答。

高架屏幕上，一个重叠图标分成了四个。

守塔无人机收到反向识别，眼中的四台目标短暂消失，归一星的回收编号却在四个方向重复出现。它们齐齐转身，在塔前堵成一团。镜星从中穿过，以自己的双层声纹完成本地确认。

空管先承认了四个呼号，唯一的红色航线裂成四条。可维修节点和地面主钥还在平台手中，飞行仓仍只开放那一条机械臂；呼号已经分开，充电设备尚不能分别响应。

货运侧节点的厚重外门紧闭。归一星把剩余无人机压在门前，四根回收索开始重新收回。它已经看见喷气叛星的急转、死锁的低空重击和镜星的反向识别，却都只能在动作发生之后记录。

玩家把最后一条远射路线交给雷翎。

雷翎借新开放的独立航路换到远处。侦察翼扫过货运轨道，原定射线前方多出一架侧翻无人机，继续射击会把碎片打进工房。玩家移开目标框，雷翎也放弃那条漂亮直线，把射口换到外门裸露的锁销。

远射组件只响了一次。

锁销被打断，外门向两侧弹开，塔身和工房都没有中弹。无牌一号立刻沿货运轨道冲上斜坡，攀轨模块扣住边沿，把全尺寸机体送进维护通路。它来到地面主钥前，双手握住长柄。

玩家压下最后一道指令。

无牌一号把主钥从远程端硬扳回木桶街一侧。

直到这一刻，三座节点和地面主钥才全部回到本地。维修通路重新开放，高架空管保留四个独立呼号，充电节点也终于能够把四个呼号分别交给不同工位。飞行仓墙内其余机械臂沿滑轨伸出，各自停在真实接口前，等待返航机体逐一接线，不再争抢同一个接入框。

木桶街的欢呼声这才彻底盖过警报。

四台机没有照旧广告并排收尾。喷气叛星抢过塔尖，死锁贴着建筑掠回，镜星在两道识别光之间翻身，雷翎远远占住能看见全场的位置。共同开头还在，结尾没有一台相同。

白鸢的图没有驱动任何机器。玩家选了顺序，四台机执行动作，工房员一台一台接臂，无牌一号亲手扳动主钥。她只把被现实改过的线保留下来。

归一星仍悬在三座塔外，没有被击毁。四根索缩回缆鼓，它的识别光不再播放旧广告，而是依次扫过刚刚发生的四种结尾。

那是它第一次没能提前封住的动作。

现在，它已经看见了。

但此刻四台机都还自由。三座节点和地面主钥属于木桶街，四个呼号在空域里同时亮着。这一阶段，他们确实赢了。
