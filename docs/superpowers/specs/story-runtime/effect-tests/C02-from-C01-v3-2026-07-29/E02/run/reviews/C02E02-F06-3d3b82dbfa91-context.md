# C02E02-F06 四条航迹飞过夜市

归一星的信号退出木桶街外空域时，飞行仓里先响起的不是欢呼，而是四台机争着报自己的停靠位置。

喷气叛星要最高的吊架，雷翎说那里正好挡住远距校准线；镜星要避开所有识别灯，死锁则只要求一块能承住现在这副身体的地面。四个呼号已经分开，公共服务位却没有凭空多出三个。纪存听着频道里互不相让的声音，反而笑了出来。

至少今晚，没人再把它们当成一台。

死锁最先落地。失去改装重臂的一侧轻得过头，它一收推进便整个向另一边沉。唐胶推来一条旧配重梁，刚比到空肩下方，兜灯就用扳手柄敲住了他的手背。

“焊死以后，它连自己偏向哪边都试不出来。”

“我没说焊死。”

“你已经摸焊口了。”

唐胶把手从焊口旁移开，改去拆配重梁上的活动卡扣。兜灯钻到死锁肩下，举灯查看断开的接口；唐胶蹲在她身后，用肩背托住她往外探的重量。她腾出一只手调低断口附近的供能，另一只手把临时护板压进卡槽。唐胶沿死锁腹侧装上一段可卸配重，再把剩余推进限制在低空平衡范围。

两个人轮流拧完最后一组卡扣，都没有往断口外面添假手臂。护板只遮住裸露线路，空掉的肩形仍清清楚楚。

死锁试着迈了一步，身体不再突然侧倒，却也无法像战前那样转身挥击。

“临时的。”兜灯说，“走低线，别追高。”

死锁低头看了看她，又看向唐胶。

唐胶拍掉手上的金属屑：“不好看，正合适。”

“保留。”死锁说。

镜星坐在飞行仓另一头，双层面罩只开了一半。两台从夜市摊位借来的大风扇对着它吹，彩色纸条被热风卷得笔直。唐胶想把第二台风扇再推近些，兜灯伸脚挡住轮子，先把镜星的主动识别切到休眠，只留下普通收听和自己的呼号响应。

镜星用一高一低两层声音报温度。高声说已经可以重新扫描，低声紧接着说还不行。

唐胶抬头：“你们内部先统一一下。”

“拒绝统一。”两层声音这次倒答得完全一致。

飞行仓里终于笑成一片。兜灯也笑了，却没有把识别器重新打开。镜星今晚能飞一段慢航，不能再做大范围反射，也不能承担空域识别。回收索留下的擦痕还横在背甲上，唐胶只擦掉会落进接口的碎屑，没碰那几道焦黑。

外泊位渐渐有了饭菜和烤物的味道。夜市把临时长桌摆到万机馆舰侧，刚才还用来封路的挡架撑起了雨棚。馆守Z用黄色巡展臂稳住顶梁，缺失原装右臂的一侧依旧空着。货柜领袖变成作业形态，把成箱的饮料和维修垫从街口送进来；无牌一号停在运输架旁，竞赛AI一遍遍回放自己守住地面主钥的动作，等人经过就把画面放大一次。

万机馆的主循环保持着低沉、均匀的转声。它能继续去下一站，却没有多余泊位把四台飞行实机全装进去。纪存端着一盘刚出炉的食物走到飞行仓门口时，四台机已经各自挑好了今晚的位置，也把“不上舰”说了四遍。

喷气叛星不肯把木桶街的最高航路让给任何人。死锁的配重、支撑架和后续修复都在这里。镜星需要飞行仓现有的识别设备慢慢恢复。雷翎则把外环塔架当成了自己的观察位。它们愿意一起救人，不等于愿意被整齐停进一排收藏位。

纪存没有再劝。他让万机馆打开一条外部支援频道，把四个空白响应位分别送到它们面前。

“万机馆离港以后，频道还在。木桶街有事，我们听得见；万机馆需要空中支援，你们也自己决定来不来。”

喷气叛星第一个写入呼号，顺手把自己的响应顺位调到最前。

雷翎立刻把顺位改成按距离和射界判断。

镜星没有碰它们的排序，只确认四个响应位不会再次合并。死锁最后接入，保留低空与近战受限的当前状态，没有把失去的重臂从频道资料里删掉。

四个呼号逐个亮起。那不是四张登舰许可，而是一张从万机馆伸回木桶街的支援网。四台机继续留在自己的飞行仓、维修架和航路上；万机馆多了四个可以呼叫、也有权不应答的远方同伴。

夜市上空为它们让出了一轮试航。

喷气叛星从最高处冲出去，双翼切过屋顶灯带，故意把自己的尾焰拉得最长。雷翎没有跟它争高，而是沿外环飞出最远的一道弧，远射组件始终朝向街区外侧。镜星保持在招牌与高架之间，慢慢掠过一面面亮着的窗，只用普通航灯回应自己的倒影。死锁飞得最低，临时配重在腹侧清楚可见，缺臂一侧朝着宽阔街面，转弯比另外三台都大。

四条航迹没有排成队形，却在夜市上空同时绕回了一圈。

支援频道也一刻没安静。喷气叛星宣布自己是首席响应机；雷翎纠正它，频道里没有这个席位；镜星把两句话分别转回左右声道；死锁只说谁先到谁先打。它们吵得万机馆的外部扬声器都自动调低了音量，下面的人却越听越高兴。

纪存站在舰侧，看着四道不同高度的航迹从头顶经过。此前他想要一支能和万机馆并肩战斗的队伍，总觉得那意味着把它们带走。现在四台机留在木桶街，反而第一次真正答应了下一次呼叫。

他的私人通讯在这时亮起。七海那边没有公务界面，只有她的声音和很轻的翻页声。

“死锁呢？”

“断臂还在。今晚只能走低线。镜星也没恢复扫描。”

“这才像真的战后。”

纪存把盘子放到舰侧栏杆上。两个人沉默了一会儿，他才问：“你公开旧签名，是因为不想让平台拿它压死今天的四台机。这个我知道。”

七海没有马上回答。

“还有别的。”

“你还是会追问第二遍。”她轻轻呼出一口气，“那份召回救过人，我不会为了今天好听就否认它。四份后续记录也是真的，我不能让它们只躺在我还能进入的内部档案里。两件事都公开，别人以后才不能只挑一半。”

“代价是你的复职复核。”

“我知道。”

“这也不是全部。”

通讯那头又静了一会儿。夜市的喧闹从纪存身后穿过去，七海终于说：“我一直告诉自己，等复职、等回总部、等事情变得好处理，再去见你。公开以后，那条最方便的退路没有了。”

纪存没有接一句漂亮话，只把已经凉下来的食物拿起来咬了一口。

七海听见了：“又放凉了？”

“这次只凉了一半。”

“那就记着。上次没吃完的饭还算数。”

她没有约日期，也没有把损失说成成全谁。纪存却听懂了：她公开资料首先是为了让两段都真实的历史留在众人眼前，也是在逼自己停止把生活永远排在下一次之后。

通讯结束不久，另一道语音请求跳了出来。白鸢开口便问：“纸本原稿找到了吗？”

“只确定还在木桶街流转，没有拿回来。”

“很好。”

“这哪里好？”

“说明我还能亲手拿。”

她把一张已经订好的行程凭证甩进共享窗口。纪存还没来得及开口，白鸢已经继续说：“我不是来看你们庆功。旧广告用了我的稿，你们又在复制件上改了四条丑得惊人的线。原稿必须回到我手里。”

纪存看着那四条被现场反复涂改的路线：“最丑的拐角是我画的。”

白鸢停了一下。那一小段安静和七海刚才的沉默完全不同，像是在重新端详一个本来已经下过判断的人。

“那我更该亲自来。”她说，“隔着通讯骂不准。”

“你先把最早那格也带上。四台机想看你原来画错了什么。”

“它们想看，还是你想看？”

“都有。”

白鸢低低笑了一声，很快又收住：“替我守住原稿。我到木桶街以后自己取。”

她没有请求加入万机馆，也没有让纪存来接。共享窗口只留下不断靠近的行程状态，以及那张仍允许现场留下粗线修改的候选图。

就在这时，夜市另一头传来一记沉重的金属响声。

四条夜航同时停住争吵。旧拳馆高处那盏多年未亮的挑战灯骤然点起，第二记铃声穿过街区，也闯进白鸢尚未关闭的通讯。

“那是什么？”她问。

纪存转身望向声音来处。

第三记挑战铃响了。
