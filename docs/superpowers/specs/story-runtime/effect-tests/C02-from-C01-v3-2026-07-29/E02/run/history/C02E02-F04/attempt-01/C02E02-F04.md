# C02E02-F04 同样开始，各自结束

三座服务节点同时转红时，木桶街上空像被画进了一张只许走一条线的图。

靠近飞行仓的节点管充电，高架顶端的节点管空域识别，货运轨道外侧的节点管维修通路。三处都被平台的回收无人机占住，地面主钥也被切到远程模式。四台机即使靠残余电量冲出仓门，也会被统一空管驱赶进同一条标准航线。

平台的回收王牌从三座塔之间降下来。

商品回收王牌“归一星”没有模仿任何一台喷气机的外形。它的身体更宽，背后是一副整齐的回收架，四只缆鼓分列两侧。没有多余武器，也没有夸张变形。它一到位，四根回收索便垂向飞行仓，空中的红色引导线同时收窄。

它带来的判断也很简单：现有服务资源只维持一个标准对象。四副身体既然共享旧服务号和工厂动作，保留其中一副，其余三副拆回备件，成本最低，风险也最容易控制。

归一星能调动的东西一眼就能看懂。四根索负责抓回四台机；统一空管负责封住高度和航线；它还能读取已经发生过的动作，再用旧广告和工厂记录推断下一步。它没有火炮，也听不见四台机在想什么。

万机馆的战术桌把木桶街空域铺成可玩的地图。三座节点都可先选，地面主钥则必须由地面单位实际扳回。

玩家若先夺高架空管节点，四台机能更早取得自由高度，却要顶着低电量完成后续动作；若先夺货运侧节点，无牌一号可以更快接入维修通路，但归一星会有时间把无人机集中到另外两塔。这一轮，光标落在飞行仓旁的充电节点。先拿回一点电，再把战线推远。

地图边缘的万机馆只是一处支援点。低电量机体可以退回泊位上空接收传感和返航引导，万机馆本身却不能离泊追击，也不能承担战斗负载。它给玩家留了一条退路，没有替四台机清场。

木桶街公共竞技场重新开放无牌一号的地面支援席。八米全尺寸竞赛实机仍装着攀轨模块，玩家可以让它沿地面设施逼近主钥，却不能代替四台飞行机去争空中的节点。

白鸢的候选图悬在地图最上层。共同起手被画成一条实线，后面的四条路线仍能随现场修改。图上没有自动执行键。纪存把选定的节点和归一星位置送进四台机各自的驾驶界面，真正何时展翼、何时转向，仍由玩家逐台确认，机体自己完成。

工房员拉起飞行仓的机械应急门。那只打开了现实出口，没有恢复平台许可。四台机依靠各自剩余的电量滑上外环。

“先把旧广告演完开头。”纪存说，“等它把四根索都交出来。”

喷气叛星、死锁、镜星和雷翎排成旧广告里的标准队形。

四台机同时展开基础翼架，同时加速，同时沿红色航线抬头。它们甚至照着旧画面做出同一轮转向，像四种颜色终于被压回一套模具。

归一星面部的识别光依次复现旧广告格。展开、加速、转向，全部吻合。它没有预知四台机接下来的选择，只是旧记录告诉它，这段起手之后应当是同时收翼、降低高度、并排进入回收区。

四只缆鼓一齐打开。

四根回收索抢先射向广告里预定的收束位置。

就在索头快要合拢时，玩家把第一道分支交给喷气叛星。

它突然离开队形。

高扬双翼在红色航线里猛地一翻，喷气叛星不是向最近的节点冲，而是从归一星面前斜穿过去，把追着自己的回收索拖向高处。它故意让索头贴着翼尖追了半圈，又在归一星转动回收架时骤然下切。

“看清楚。”它在公共频道里笑，“这才叫叛离。”

索没有抓中它，反而横在归一星与充电节点之间。为了不让自己的回收索缠住回收无人机，归一星不得不抬高机身。充电节点下方露出一条低空通路。

玩家随即切到死锁。

死锁没有追着喷气叛星飞高。它收紧双翼，从低空直扑充电节点。无人机挡在塔前，统一空管也把标准上升线压到它头顶；死锁干脆不升，任由重型近战臂把身体拖得更低，从服务塔基座旁擦过。

它抡起那条不在旧工厂记录里的重臂，一击砸碎节点外侧的回收封罩。

破开的不是充电塔本体，而是平台扣在塔外、禁止本地接入的装甲壳。死锁把折叠刃插进裂口，整片封罩被它扯下来，塔内原有的本地接头重新露出。充电节点由红转白，四台机的残余电量同时得到一小段应急补充。

木桶街地面爆出第一阵欢呼。

归一星马上压回一个敌方回合。统一空管把剩余红色航线全部弯向刚夺回的充电节点，逼四台机挤在同一片空域；回收无人机也从两侧围拢，试图让刚分开的单位重新叠成一个目标。

玩家没有让四台机一起退。喷气叛星继续在高处拖着自己的回收索，把归一星的机身牵向外侧；死锁留在充电塔前，用重臂扫开试图重新扣上封罩的无人机；雷翎退到万机馆支援范围边缘，替全队照出高架节点后的空隙。镜星由玩家从那道空隙送上去，四个单位仍各占一处，归一星没能把刚夺回的节点重新压成单一目标。

先取充电的代价也立刻出现。归一星把剩余无人机集中到高架空管节点和货运侧节点，第二处防线明显变厚。若玩家第一步先夺高架，这批增援会去堵充电塔；若先开维修通路，无牌一号会更早抵达主钥，但四台机必须一直省着电。顺序改变压力落在哪里，三座节点却一座都不能少。

战术桌上，白鸢原先画给镜星的高架直线被新增无人机堵死。她没有向镜星下令，只在共享层上划掉那条已经不成立的路线。新的选择停在玩家面前。

镜星自己打开双层视窗。

它迎着高架节点的识别光升上去，前臂两块干扰板向外翻开。节点正把四台机都压成同一个旧服务号，镜星便把那束识别信号完整反射回去，再从反面送出四道位置不同、声纹不同的回答。

高架屏幕上，原本重叠的一个图标被硬生生分成四个。

守在塔前的回收无人机同时收到反向识别。它们眼中的四台目标消失了，归一星的同一回收编号却在四个方向重复出现。无人机齐齐转身，把通路让给镜星，又在空中互相堵成一团。

镜星从它们中间穿过，双层声音一前一后报出自己的呼号。高架节点第一次单独回答了它。

第二座塔转回本地控制。天空中那条唯一的红色标准航线裂成四条可选航路，喷气叛星立刻抢了最高的一条，死锁仍贴着地面，镜星留在识别阴影里，雷翎则从始至终没有进入近距离混战。

货运侧节点的外门还锁着。归一星把最后一批无人机压在门前，四根回收索也开始重新收回。它已经看见喷气叛星的急转、死锁的低空重击和镜星的反向识别，却只能在动作发生后把它们记下来。

玩家把第四条路线交给雷翎。

雷翎借空管刚放开的高度换到远处，侦察翼扫过货运轨道。它没有照白鸢图上的第一处射击框开火，因为现场多出一架侧翻的回收无人机，原路线会把碎片打进工房。目标框在玩家界面上移开，落到节点外门裸露的锁销。

远射组件只响了一次。

那一击穿过无人机之间的空隙，打断锁销。厚重外门向两侧弹开，塔身和周围工房都没有被击中。雷翎在命中后立刻换位，没给归一星复现射线的机会。

地面上，无牌一号已经沿货运轨道冲到节点下方。攀轨模块扣住斜坡，它顶着落下的外门爬进维护通路，双手握住地面主钥的长柄。

玩家压下最后一道指令。

无牌一号把主钥从远程端硬扳回木桶街一侧。

三座服务节点同时亮起本地标志。充电臂从墙内伸出，空域屏幕不再显示一个重叠对象，维修通路也重新向工房开放。喷气叛星、死锁、镜星和雷翎的呼号依次出现在四条独立航路上，每台机都得到自己的回答。

第一阶段胜利的提示在战术桌上亮起，但真正让木桶街欢呼的是天空。

四台机没有照旧广告并排收尾。喷气叛星抢过塔尖，死锁贴着建筑掠回，镜星在两条识别光之间翻身，雷翎远远占住能看见全场的位置。共同开头还在，结尾没有一台相同。

白鸢的图没有让这一幕发生。玩家选了节点，四台机执行动作，工房保住设施，无牌一号亲手扳动了主钥。她只把刚才被现实改过的线保留下来。

“最后这一格，我没画。”她在远端说。

“所以挺好看。”纪存答。

归一星仍悬在三座塔外，没有被击毁，也没有退出回收。四根索重新缩回缆鼓，它的识别光不再播放旧广告，而是依次扫过刚刚发生的四种结尾。

那是它第一次没能提前封住的动作。

现在，它已经看见了。

但此刻四台机都还自由。三座节点和地面主钥属于木桶街，四个呼号在空域里同时亮着。这一回合，他们确实赢了。
