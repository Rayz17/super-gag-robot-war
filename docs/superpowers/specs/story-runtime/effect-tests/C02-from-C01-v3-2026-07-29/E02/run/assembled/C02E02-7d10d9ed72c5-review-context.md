它的头部是左右分开的双层视窗，翼面朝向也和喷气叛星不同；两块电子干扰板收在前臂外侧，像两面随时会翻转的薄盾。镜星没有碰充电线，只把识别信号反射回服务位，让平台那套只认一个对象的设备同时看见四个入口。

它用两层方向相反的声音说：“现在它认为，我们四个都是第一。”

充电臂转得更快了，一头撞上自己刚合起的维护板。

死锁默默把板拆了第二次。

最后醒来的重涂机“雷翎”根本没有下地。它伏在第四间仓顶的承梁上，窄长感应头正对着公共充电位，一侧侦察翼展开，另一侧让出身旁那门修长的远射组件。那套远射系统不能贴着快速充电臂硬灌电，过热会先烧掉它的远距感应。

雷翎从高处放下一条远程搭电线，越过三台机的肩头，准确勾住充电座刚被死锁打开的测试口。

全场绿灯熄灭。

片刻后，只有雷翎身边一盏小小的诊断灯亮起。

“我没抢你们的电。”它的声音清晰而平稳，“只借它查是谁把门关了。”

喷气叛星仰头看它：“趴在房梁上说这种话，很没有说服力。”

“房梁不折我的翼，也不碰我的炮。”

纪存、唐胶和兜灯赶到时，看见的就是这样一幅清晨景象：喷气叛星用一边高翼挡着充电臂，死锁蹲在拆开的线路前，镜星把识别灯反射得满仓乱跑，雷翎则从屋顶垂下一条搭电线。四台同骨架飞行机围着一个插口，谁也没有真正充上电。

唐胶带来的是一套标准转接头。

“共同底盘，共同接口。”他把接头往工具台上一放，“先别拆了，轮着——”

话没说完，他先看见喷气叛星撑开的换装翼锁，又看见死锁偏向一侧的近战臂。镜星的识别器让他的检测表反复跳号，雷翎甚至没有能安全落进充电框的远射组件角度。

唐胶拿起那只标准接头，在四台机之间比了一圈，又原样放了回去。

“行。这东西只够证明插头长得一样。”

他把工具布摊成四块。给喷气叛星的留出翼面空间，死锁那边搬来地面支撑，镜星旁边放下独立检测器，雷翎的检查线则直接拉向高处。原本的一张维修单，在他手里变成了四张。

兜灯先把四台机按同样时长排了顺序。喷气叛星刚重新接电，充电臂又去压它的翼；换死锁上位，沉重近战臂把机体拽出正中；镜星一开识别，服务位便再次分不清对象；雷翎甚至拒绝从梁上下来。

兜灯当场拉下公共快充。

“不能轮流。”她说，“四台机要四种停法。这个服务位只会把同一个动作做四遍。”

纪存让木桶街终端把四台机的正式名分别写进本地界面。喷气叛星、重涂机“死锁”、重涂机“镜星”、重涂机“雷翎”，四个名字都显示成功。

供电没有增加。

雷翎借来的诊断灯把底层编号投到墙上。四个名字下面，仍压着完全相同的服务号。喷气叛星一接电，绿框就套到它身上；死锁把线引到自己这边，绿框便跟着跳走。另外三台随即被判成重复设备。

外环空域灯也使用同一个编号。无论谁得到插口，四台机的飞行许可都保持冻结；系统无法确认究竟是哪一副身体要升空，干脆把所有仓门都锁在地面模式。

纪存终于明白，这不是把四个名字写得更大就能解决的事。服务号握着的是电、充电方式和离开仓库的天空。一个编号下面塞了四台机，平台就只需要保留一次服务，也只承认一个能飞的对象。

公共屏幕随即弹出选择框：指定一台继续上线，其余三台转入等待回收。

喷气叛星头顶的绿框正好亮着。只要它继续占住插口，屏幕就会把它当成留下的那一个。

它盯着那个框看了一会儿，忽然抬手拔掉自己的充电线。

绿灯熄灭，空域仍是一片红。

“我当然是第一。”喷气叛星说，“但轮不到这块破屏幕替我选后三名。”

死锁停止继续拆线，把维护板按回原处。镜星收回反射信号，让四个名字重新各归各位。雷翎则把借来的微弱电流全部送进诊断终端，拖出昨夜刚写入的冻结记录。

平台正是沿公开维修史找到这四台机，再把它们重新压回同一个旧服务号。记录里只有一个对象能充电、一个对象能获得空域，其余三台都被标成多余。

纪存原本准备今早借公共服务位继续检查万机馆。现在他关掉了万机馆的预约，把充电区完整留给四台机和本地工房。

“万机馆还能低速待着。”他说，“先别让这四台在查明之前被断电带走。”

这一次，唐胶没有把标准接头重新收进箱子。他把四张维修布压好，分别记下翼锁、近战臂、识别器和远射系统的限制。兜灯也在四台机脚下放了不同的停止标记，谁都不能再被同一套动作强行塞进充电框。

四台机仍然互相不服。喷气叛星嫌死锁拆线太慢，死锁嫌镜星把灯弄得眼花，镜星把两句话原样反射回去，雷翎则在房梁上建议三台都降低音量。

但纪存、唐胶和兜灯已经不再把这当作四款外观不同的同一台机器。

眼前是四副已经活成不同用法的身体，四套维修限制，四种声音，也有四个会在同一个选择框前作出不同决定的人。

墙上的旧服务号仍亮着。

它为什么曾经把四台机写成一个对象，成了他们接下来必须先弄清的事。

# C02E02-F02 当年的召回真的救过人

飞行仓的公共屏幕开始循环播放一段旧事故影像。

画面里的飞行机和眼前四台机共享同一副基础骨架。它刚贴近地面，左翼便突然向下折落，翼尖拖出一路火花。机体被那股力猛地拽偏，撞破空置的检修围栏，侧身滑出去很远。驾驶舱几乎贴着地面擦过，救援人员从提前清空的通道两侧冲上来，把里面的驾驶员拖了出去。

影像随即停在七海当年的签名上。

平台给出的说明很简单：同批翼锁存在失效风险，四台同型机因此被统一召回；旧服务号至今有效，而现有资源只够维持一个标准对象。于是拆三保一看上去不再像一次回收，而像一项从事故里延续下来的安全措施。

远在东区封存中心的七海盯着那段画面，没有立刻反驳。

“签名是我的。”她对纪存说，“召回也是我要求当天执行的。”

喷气叛星的高翼动了一下。死锁仍蹲在拆开过的维护板旁。镜星把公共屏幕上的签名反射成左右两份，雷翎则从房梁上把感应头转向七海的通讯窗口。

“所以我们四个被塞回一个服务号，是你留下的？”喷气叛星问。

“这个开头，是。”七海答得很平静，“但平台把影像从最要紧的地方截断了。”

她仍保有停权前下载到私人工作区的一份事故索引，却没有原始影像的公开权。唐胶从木桶街旧维修名册里找到了当年的驾驶员。对方没有到场，只从街区另一头接入通讯。屏幕里是个上了年纪的男人，身后挂着已经褪色的飞行服。

“先放完整的。”他说，“别急着听我替谁说话。”

他上传的影像比平台版本多出前面一段。

当年的飞行机原本正沿跑道加速，准备爬升做满载转向。召回警报在它离地前压进驾驶舱，命令同批机立即取消任务，以低速、双翼展开的姿态返回，并清空降落通道。驾驶员在旧录音里骂了一句，还是收掉推力，沿最低路线折返。

正因为速度已经降下来，左翼锁断裂时，机体没有在高空翻滚。正因为通道已经清空，那片扫过检修区的机翼没有打中正在换班的地勤。救援车也早已等在围栏外，驾驶舱一停便有人冲了上去。

老驾驶员看着年轻的自己被抬出座舱，抬手摸了摸膝盖。

“那天我嫌她胆小。飞行员最烦别人替你判断飞机还能不能飞。”他说，“后来翼锁在我眼前断了。我如果照原计划带着满载上去，掉下来的就不只是我。”

他把当年的头盔转向镜头，边缘还留着被舱壁磨白的长痕。

“召回不会自己把飞机停下。警报响了以后，是我收的推力，是地勤清的跑道。那张命令能救人，是因为它指向一个真的故障，我们愿意照着做。要是只为了让货号好管，我不会出面作证。”

他没有赞美七海，也没有替平台说话，只把那天自己的判断完整说完。

“那张召回令救了我，也救了跑道边的人。谁要说它当年签错了，我第一个不同意。”他顿了顿，望向飞行仓里的四副身体，“可它召回的是一批装着同样坏翼锁的机器。拿我活着这件事去证明今天应该拆掉其中三台，也不对。”

七海调出原召回的后一页。召回要求同批机停飞、共用一个冻结服务号，是为了不让任何一台漏过检查；完成实体维修和单机复验后，本应逐台恢复服务。她当年签下的是这项紧急处置，而不是永久把所有后续机体合并成一个对象。

问题出在后面。

平台公开页只保留了事故、签名和统一服务号。四台机此后各自经历的维修，被收进了不对外显示的后续记录。如今平台仍按最初那副骨架提供一份标准充电和空域资源，任何偏离出厂形态的部位都被算作非标准改装。这样做确实最省维护，也最容易保证留下的那一台符合旧检查法。

可眼前已经没有哪一台还符合那套检查法。

纪存把飞行仓的四路镜头接到七海的屏幕上。唐胶和兜灯不念记录，而是让四台机把对应部位真正动给她看。

喷气叛星首先展开高扬双翼。旧事故里的同型翼锁早已从它身上拆掉，后来的维修者为高速转向换上了另一套锁翼结构。它充电时必须让一侧翼锁保持展开，硬压回出厂姿态反而会卡住新翼。

死锁把重型近战臂放上地面支撑。维修影像里，那条手臂是在旧召回结束多年后接上的，连机体的重心都随之偏向一侧。让它按原版悬空受电，头顶机械臂会先把整台机拉歪。

镜星收起前臂干扰板，又逐一亮起双层视窗。它的识别系统经过两次重做，已经会同时检查正向与反向信号。旧服务号把两个回波压成一次故障，正是公共充电位刚才反复误认的原因。

雷翎最后从承梁上放低侦察翼，把远射组件的热影投到墙上。它的感应与武器沿同一侧重新布置，必须远离快速充电臂，以低负荷线路慢慢补电。旧记录里的标准停放姿势，对它来说连安全检查都做不了。

四份维修影像和四副眼前的身体一一对上。不是纸面上多了四个名字，而是旧翼锁已经不在，重臂确实压着地面，双层识别正在工作，远射系统也真实占据了原本没有的位置。

七海把四份后续记录拖到发布栏时，屏幕弹出警告。记录里不只有改装照片，也有四台机各自不能承受的维修方式。公开它们，回收队同样能看见这些弱点。对七海本人，后果写得更直接：她正在等待的复职复核将立即终止，停权调查升级为内部资料公开调查，现有档案访问资格同步撤销。

纪存看见她习惯性地整理了一下袖口。

“佐伯七海。”他叫了她的全名，“你回总部的路会被关掉。”

“已经关到一半了。”七海说，“剩下这一半，是我自己选。”

她没有替四台机决定。她把警告转到飞行仓，让它们也能看见。

喷气叛星先把换装翼锁完全亮给镜头：“发完整。又删掉难看的部分，最后还是只剩一张商品图。”

死锁把近战臂继续压在支撑架上：“重量也写上。别把我修得像没发生过。”

镜星让两层声纹一前一后响起：“错误识别也保留。删掉错误，只会得到另一次错误。”

雷翎扫了一眼外环仍然全红的空域灯：“公开热限制。对方知道，并不等于对方知道我会怎么选目标。”

七海按下发布。

她当年的原签名、未截断的事故影像、幸存驾驶员的叙述和四份后续维修记录同时进入公开页。她没有撤回召回，也没有把自己改写成从未参与过统一冻结的人。她只在原签名下面补上今天的判断：当年的同批停飞救过人；今天的四副身体必须分别检查，不能用当年的紧急处置替其中三台决定去留。

发布完成的同时，七海那边的档案界面一层层熄灭。复职复核的预约从日程上消失，工作证旁的内部访问灯变成灰色。她还能留在私人通讯里，却再也不能沿内部档案替纪存悄悄往前查。

老驾驶员在公开页面留下了自己的影像确认，然后切断通讯。他没有要求四台机原谅谁，也没有否认那张签名救过自己。

喷气叛星看着七海：“你的签名确实把我们锁在一起过。”

“是。”七海说，“我不会否认。”

“现在也没解开。”

“资料不会替你们打开仓门。”七海看向仍在红灯下的四台机，“我能做的是让所有人看见，今天站在门后的已经不是当年那批等待同一种检查的身体。”

平台没有因为公开记录自动退让。公共充电位仍只有一条机械臂，四个名字下方仍压着同一个服务号，外环空域也没有放行。

但屏幕上那段事故不再只有一个结论。它既清楚地证明七海当年的召回救过人，也清楚地照出了四台机此后各自走过的路。

四台机仍被困在地面，却不再需要靠否认那场事故来证明自己应该活下去。

# C02E02-F03 作者从广告里把手伸回来

白鸢发现自己的旧分镜又活了，是因为它正在平台广告里把四台机变成同一个人。

远端工作室的屏幕上，四种涂装依次掠过同一条城市航线。它们用完全一样的角度展开机翼，以完全一样的姿势转向，最后并排收束成一个标准剪影。广告把这段旧动作重新送进木桶街空管，准备用它判断四台机是否服从统一服务号。

原稿右下角的署名被平台标志盖住了。画面里的四机也不是现在的身体：翼锁还是旧式，双臂同重，识别器只有一层，远射组件根本不存在。

白鸢追查复制记录时，看见万机馆的战术桌也调入了这组分镜。

她发出权利中止请求，接通木桶街之前，已经准备好先骂人。

通讯打开，战术桌却是一片黑。

纪存站在拔掉信号线的投影机旁，平台广告已经从飞行仓的本地屏幕上消失。桌面只剩一行断开提示。

几分钟前，平台刚提出用旧广告动作重新识别四台机。纪存本想从中找出空管会如何判断它们，却在放大画面时发现原始格号被重新排列，角落还有一道被粗暴裁掉的白色鸢形署名。

他没有等作者出现，也没有先问能不能借用。他关掉投影，清除战术桌上的广告副本，又让木桶街停止转播这组画面。平台自己的空管还在使用旧模板，但现场不再拿侵权图做计划。

权利请求上的正式姓名是Evelyn Voss，英文署名White Kite。中文界面把她显示为白鸢。

她没有开摄像头。通讯里先传来纸张被快速翻动的声音，随后是一道清楚而偏低的女声。

“断开画面不能证明你们没留副本。”

“使用记录和删除回执都给你。”纪存把终端转向通讯窗口，“我先停，是因为作者被抹掉了。现在才轮到解释我们为什么打开它。”

“博物馆的人总觉得，只要把偷来的东西摆得足够认真，就算保护。”

这句话正好扎在纪存最不愿被碰的地方。

“作者也别把每个打开文件的人都画成贼。”他说，“你打进来以前，这张图已经停了。”

“那就记着。上次没吃完的饭还算数。”

她没有约日期，也没有把损失说成成全谁。纪存却听懂了：她公开资料首先是为了让两段都真实的历史留在众人眼前，也是在逼自己停止把生活永远排在下一次之后。

通讯结束不久，另一道语音请求跳了出来。白鸢开口便问：“纸本原稿找到了吗？”

“只确定还在木桶街流转，没有拿回来。”

“很好。”

“这哪里好？”

“说明我还能亲手拿。”

她把一张已经订好的行程凭证甩进共享窗口。纪存还没来得及开口，白鸢已经继续说：“我不是来看你们庆功。旧广告用了我的稿，你们又在复制件上改了四条丑得惊人的线。原稿必须回到我手里。”

纪存看着那四条被现场反复涂改的路线：“最丑的拐角是我画的。”

白鸢停了一下。那一小段安静和七海刚才的沉默完全不同，像是在重新端详一个本来已经下过判断的人。

“那我更该亲自来。”她说，“隔着通讯骂不准。”

“你先把最早那格也带上。四台机想看你原来画错了什么。”

“它们想看，还是你想看？”

“都有。”

白鸢低低笑了一声，很快又收住：“替我守住原稿。我到木桶街以后自己取。”

她没有请求加入万机馆，也没有让纪存来接。共享窗口只留下不断靠近的行程状态，以及那张仍允许现场留下粗线修改的候选图。

就在这时，夜市另一头传来一记沉重的金属响声。

四条夜航同时停住争吵。旧拳馆高处那盏多年未亮的挑战灯骤然点起，第二记铃声穿过街区，也闯进白鸢尚未关闭的通讯。

“那是什么？”她问。

纪存转身望向声音来处。

第三记挑战铃响了。
