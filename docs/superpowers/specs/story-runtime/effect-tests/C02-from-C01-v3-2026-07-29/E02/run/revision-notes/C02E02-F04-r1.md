# C02E02-F04 第一次返修要求

保留全部已成立的机战高光：

- 三节点自由选择和一条代表攻略路线。
- 共同起手骗出四根回收索。
- 喷气叛星诱敌、死锁低空重臂破罩、镜星反射识别、雷翎改换射线、
  无牌一号地面扳主钥。
- 归一星只读取已发生动作，第一阶段有真实小胜，镜星仍未被捕。

必须修复充电节点的物理服务链：

1. 充电节点不是无线回血塔。死锁破罩以后，木桶街恢复的是飞行仓内既有的
   机械充电臂和本地手动切换。
2. 在高架识别节点尚未夺回、四机仍共用一个旧服务号时，一次仍只能接一台。
   代表路线要让四机轮换返航：死锁先落地接臂，另外三台掩护；随后喷气叛星等
   依次短充。先取充电的收益是续航稳定，代价是每次少一台在战场。
3. 若先取高架识别节点，四呼号提前拆分、空域和多臂并行资格更早恢复，
   但四机必须用低电量完成第一轮；若先取维修通路，无牌一号更早进入地面主钥，
   但空中四机更依赖轮换与回避。
4. 三种首选顺序都用一两个可执行动作说明，不靠界面条件句宣布。
5. 三节点全部夺回后，四个独立呼号才允许充电臂分别响应；不要改动F05
   二次学习和镜星被捕的预留。
