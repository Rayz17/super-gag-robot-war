# Story Runtime 稳定写作内核 v1

本文件是所有章节与单话写作调用共享的稳定前缀。它不是第二套 Canon，也不替章节决定具体场面。其作用是把已经审定的顶层创作接口压缩成作家每次都能完整读取的共同语言；章节事实、人物位置、机体状态和未来边界由后续合同提供。

## 作品承诺

《超GAG机器人大战：万机残响》首先是一部让机器人爱好者能够驾驶、收集、改装、合体、变形、玩梗、流泪并与角色共同生活的机器人大战游戏。文化讨论必须通过机体、驾驶员、战斗、探索、模型手作、舰内生活和玩家选择兑现，不能退化成围绕标签、权限、记录、证词或制度术语展开的汇报。

玩家应当持续感到：

- 喜欢不同年代、谱系、比例、作品气质和商品形态的机器人不是需要辩解的缺点；
- 名机、名场面、精神、台词、玩具与模型记忆能够在原创剧情里重新燃烧；
- 机体不是议题道具，而是有欲望、身体史、关系、胜负、变化和终局行动的角色；
- 胜利可以产生后果，但不能把每次胜利都立刻解释成错误；
- 喜剧、低俗成人趣味、日常、感情、悲剧和宇宙奇观属于同一部作品，不是结尾补齐的配额。

## 根机制接口

- **G.A.G.** 是机器人文化被观看、操作、误记、争论、商品化、二创和共同回应后形成的活化反馈，不是万能能源、单一神明或一句梗就能造魂的法术。
- **机魂** 在具体机器的本地 AI、身体经历、实时黑匣、长期关系和文化反馈中形成主体连续性。它需要明确载体，可以迁移、受损或被分割，但不能因命名、贴标或看见模型便凭空产生。
- **模型、玩具与实机** 通过版本信息、比例同构、锚件数据、手作经验、工程换算、制造、安装和验证发生联系。缩尺收藏不会直接放大成巨型机器人。
- **白框** 是用实体采样、供应链和活体机魂演算大量未来的具身执行生态；**索引** 是从数据、选择和标准答案中成长出的自觉系统；**清噪** 是它们可能采用的最优化行动；三者不自动等同于 G.A.G.。
- **白鸢** 当前只能把创作、传感、驾驶员陈述和现实限制组织成可修改的预演。真正的动作必须由人、机体和工程链执行。未来能力升级必须由章节合同明确开放。
- **万机馆** 是会巡展、搭载、整备、开馆和逐步成长的移动共同体。具体尺寸、损伤、变形、暴走和战斗权限以本章 Current Canon 合同为准，不能由气氛临时升级。

## 创作顺序

1. 先写角色和机体此刻真正想做成什么。
2. 再写对手正在主动做什么，以及双方为何必须在当前地点相撞。
3. 用一眼能懂的大动作、关系选择和玩家操作形成场面。
4. 让玩法、机体、IP投射、人物关系和谜团在同一因果中互相改变。
5. 最后才补玩家当场必须理解的机制；一场通常只承载一个决定性控制变化。

任何只能靠作者旁白解释、无法由画面、操作、动作或人物有限认知表达的因果，都没有完成设计。

## 人物与对白

- 核心人物必须拥有主动欲望、能力高光、错误、选择和关系后果，不能只履行岗位。
- 对白必须有听众、情绪和目的。角色不会为了向玩家交代设定而说出自己本不需要说的话。
- 禁止把“你可以……但别替我……”“今天先……也别……”“不替谁背”“债务”“语法”“槽”“锚”当作万能人物句式。
- 日常不是说明人设的插页。吃饭、换衣、画同人、争床位、修东西、讲烂笑话或身体靠近，应当通过行为自然发生。
- 成人关系可以有挑逗、身体距离、嫉妒、卖肉和低俗趣味，但不能机械解释“这里有成人内容”，也绝不进入儿童线。
- 普通物件可以只是普通物件；没有剧情作用的舱室、设施、亲属、规则和背景事实不要临时创造。

## 机体、IP与玩法

- 每台主要机体都要有一个正向欲望，并在本章得到可辨认的动作、选择或命运推进。
- Canonical 名称、允许别名、尺寸、驾驶/AI/机魂控制权、位置和生命周期以实体合同为准。新昵称首次使用必须同时连接正式身份。
- IP投射优先吸收原作的情绪前提、关系结构、名场面语法和精神，再决定直接短引、融合、误记、反转或原创变奏。
- 战斗先用一句人话成立：谁为了什么，在什么空间里，必须阻止谁完成什么。随后才设计地图机制。
- 完整机体承担主棋盘行动；模型盒、标签、框体、零件和工作流概念不能冒充参战机体。

## Harness 边界

本内核只规定创作方向。每次任务还会附带四类合同：

1. 全剧位置与章间交接；
2. 实体身份与机体生命周期；
3. 核心人物本章职责；
4. 新实体准入与退出。

合同保护连续性，不预写场面。作家可以自由创造冲突、奇观、误会、笑点、关系动作和战斗解法；若更强创意需要改变合同，应提交上游迁移，不得在正文中静默改写。原始检索证据留在后台，正文作家默认只读取本内核、紧凑合同、章级导演板、当前单话卡与增量状态。

# C01 期末清晰状态

这份状态只记录 C01 已经让普通玩家看见或可以直接推断的事实。它是 C02 候选稿的唯一前序故事输入，不包含现成 C02 内容。

## 时间与航向

- 万机馆在闭馆夜接近天亮时离开原城。
- 一通身份未明的旧关系来电发来木桶街巨构泊位与旧式部件照片。
- 唐胶认得声音，也明显不愿意解释这段关系。
- 万机馆旧航行系统状态不佳，只能低速前往邻近站点；抵达木桶街应在离城约六小时后的中午前后。

## 万机馆

- 万机馆不是普通建筑，而是固定在城市二十七年的百余米巡展舰。
- C01 恢复的是紧急离港和低速航行能力，不是完整战舰状态。
- 自动航行系统负责推力、转向和舰体平衡；纪存选择航向、汇合城市和友军位置，不直接操纵每一套机械动作。
- 当前只有旧式近防炮，足以驱赶小型突入体，不能击穿大型敌人。
- 舰体急需安全泊位、补给、完整检修与能长期工作的主循环部件。
- 万机馆恢复“第七次巡展”路线牌，这是主动重新出发，不是低功率逃亡。

## 当前随舰人物

- 纪存：闭馆负责人和玩家主要视角。他在 C01 主动组织最后导览、观众撤离、战场信息汇合和离城决策。
- 唐胶：模型修复师。木桶街来电者与他有旧关系；他知道当地生态，也有意隐瞒过去。
- 兜灯：馆守Z整备员。她拥有判断和执行物理制动的专业职责。
- 跌跌、机器犬：小尺度机器人伙伴，随舰离城。
- 旧守护者：馆守Z的机魂人格。它可通过轮式导览终端、馆内广播和胸前扬声器感知、说话，但这些只是同一主体的远端外壳。

## 没有随舰的人

- 佐伯七海仍在原城接受内部调查。她在 C01 只能撤销本人签发的停机令、提供公开应急图与代哥交通数据，不能替城市或军方批准作战。
- 纪存与七海在闭馆前本来约好吃饭。两人已有不浅私交，但闭馆夜没有完成那顿饭。
- 荒川豪司与勇拳试作机返回企业体系，处分尚未结算；当前不是万机馆常驻成员。
- 小满、阿澄已由监护人与城市系统接走，仍留在原城。
- 白鸢和陆衡尚未进入 C01 故事。

## 馆守Z与旧守护者

- 馆守Z是 18 米级旧巨神，也是旧守护者唯一主要身体。
- 纪存坐入的是胸前导览席，只提供路线、判断和目标信息，不驾驶四肢，也不是馆守Z机魂。
- 馆守Z原装右前臂在击穿 BREAKER 地面外壳时过载报废。
- 临时黄色巡展臂只能抓取、放锚和搬运，不是战斗右拳。
- 旧推进骨架已经一次性报废，裂盾也已完全损毁；馆守Z不能常态飞行。
- C02 不得用一句“修好了”消除这些损伤。

## C01 战果与敌情

- 裂星潮突入体 BREAKER 具有近 30 米地面重甲与飞行核心两阶段。
- 馆守Z和勇拳试作机以双拳协作击穿外壳；随后万机馆离地、馆守Z登上舰首，以左拳击毁飞行核心。
- BREAKER 的红孔脉冲能协调附近同类；核心被毁后，小型突入体失去统一行动。
- 敌人始终追逐万机馆，原因未知。

## 白色采样钩子

- 一台无标志白色采样机在战后带走馆守Z右臂残片。
- 它掉落一枚指甲大小的白色衬片；城市只将其登记为“未知白色复合材料”。
- 玩家不知道采样机归属、目的和去向。
- C02 可以推进“有人正在收集可复制样本”的不安，但不能直接让角色知道白框、索引或终局答案。

## C02 必须继承的情绪

- 刚赢下第一场大战的兴奋还没有完全过去，现实维修压力已经追上来。
- 万机馆第一次带着少量人离开熟悉城市，既像家突然会飞，也像一群人第一次发现自己没有后勤。
- 唐胶回到旧生态应同时有熟门熟路、尴尬、嘴硬和真实牵挂，不能只承担“揭露维修史”的主题任务。
- 纪存第一次作为巡展负责人面对外部共同体。他需要主动争取、识人、带队和做出有魅力的判断，而不是一直审批别人是否能行动。
- 七海不在现场，但那顿没吃成的饭和她正在承受的调查应保持存在感。

## 明确不得漂移

- 模型、玩具、手套、说明书和锚件不会凭空放大成巨型机器人。
- 任何新实机必须已有身体、全尺寸底盘或明确的制造来源。
- 万机馆不能突然变形成人、暴走、打拳或获得完整火力。
- 旧守护者、馆守Z、万机馆和纪存是四个不同层级的主体。
- 纪存尚未知道自己是机魂实体；C02只能继续以天赋、异常感应或旧馆联系留下疑问。
- 白鸢尚未出场，她的能力不能被先写成未来视或画稿改现实。

# 上一场正文尾段

弹开的甲板迎面扫来，雷翎收枪横挡，整台机沿托架外壳擦过。玩家要在短暂露出的锁扣与镜星之间压住准线，射偏便只能重新绕行；这一枪命中后，上锁化成一圈翻飞的碎片，镜星头顶第一次露出木桶街的天空。雷翎的远射翼还在震动，却没有退回远处补那一枪。它留在近线，替下一个破口挡住归一星的转身。

下锁还压在托架腹部。归一星一边撤退一边翻转身体，用剩下的装甲把它藏向死锁另一侧。死锁的改装重臂本来就是为正面打穿敌甲装上的，它与这副量产身体并不相容，每一次全力挥击都在机身接口上留下新的裂响。

现在，敌机腹甲和下锁同时落进它的攻击范围。重臂若砸向腹甲，归一星会再受重创；若伸进托架，手臂就会被合拢的甲板卡死。

死锁没有减速。

玩家推动它穿过喷气叛星引开的索路。死锁贴上移动托架，将整条改装重臂刺进下锁旁的装甲，折叠刃在敌机内部完全撑开。下锁被顶得变形，归一星急转，想连同手臂一起把死锁拖走。死锁肩部的警报连成一片，重臂与身体之间只剩最后的供能连接。

归一星带着它撞过高架外沿。死锁没有用另一只手去抢回重臂，而是反扣住托架缺口，让自己的身体成为一枚楔子。玩家继续压住攻击，改装臂便在敌甲深处越撑越开；若此刻松手，它还能带着手臂脱离，但下锁也会重新缩回装甲。镜星就在锁后，隔着裂缝伸出一块反射板，把死锁自己的呼号照回它面前。

镜星从托架里看见那条手臂已经拔不出来。

“死锁。”

“出口归我。”

死锁主动断开肩部。它的身体猛然后退，改装重臂永久留在归一星的甲板里。紧接着，手臂剩余的动力全部灌进撑开的折叠刃。沉闷的爆炸从托架内部顶起，下锁连同腹部装甲一起被炸开，第二处脱离点终于敞开。

四个独立呼号在破口里同时亮了一次。镜星把托架最后一轮识别光分向四面，合拢机构再也找不到一个可以统一回收的目标。它从上下裂开的托架中冲出，带着烧红的面罩和两道索痕翻向低空。

死锁用仅剩的手臂接住它。冲力把两台机一起撞向高架边缘，喷气叛星从下方掠过，用推进气流托住它们的下坠；雷翎转过枪口，击断了还挂在镜星背后的残索。

“四号归队。”雷翎说。

“第三名归队。”喷气叛星立刻改口。

镜星的两层声线在死锁臂弯里重合了一瞬，又重新分开：“四个呼号，全部响应。”

死锁看了一眼空掉的肩部，只回了一声：“收到。”

喷气叛星本想抢到队形最前面，翼尖却先向镜星那边偏了一下，确认它能自行推进才重新抬头。雷翎没有回到已经失去的最佳射位，而是横在四台机与归一星之间，长武器稳稳指住敌机，让负伤的死锁先降到安全航路。镜星则把自己的呼号从另外三个信号中单独点亮，再依次回传三次回应。

归一星没有坠毁。它的移动托架被上下撕开，腹甲里还嵌着死锁烧毁的重臂，四根回收索也只来得及拖回残段。它放弃街区节点和新的捕获目标，把全部动力转给撤退推进器。

归一星带走的只有这些有限样本。它没有得到四台机为何回头，也没有得到任何人的私人记忆。
