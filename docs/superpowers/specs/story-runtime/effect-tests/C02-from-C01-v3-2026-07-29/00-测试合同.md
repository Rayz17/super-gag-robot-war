# C02E01-E02 隔离测试合同

## 必须证明

- C01 的损伤、位置、人员、关系和敌方样本能够自然进入 C02。
- 木桶街不是“模型盒变大”的魔法街，而是缩尺模型、全尺寸工房、实机和收藏者
  共同存在的机器人文化生态。
- 模型只能保存版本、结构和维修线索；全尺寸部件必须由真实测量、材料、工艺和
  工程验证完成。
- E01 必须让玩家获得一次巨型工业夺回与六米转子大场面，并保留有限而真实的胜利。
- E02 必须让四台同骨架机体拥有四种可辨认的动作、声音、伤痕和选择；归一星必须是
  可理解但可反对的商品回收执行者。
- 纪存、唐胶、兜灯、七海都要主动改变局势。白鸢在 E02 只能提供可修改预演，
  不能画线施法，也不能提前肉身登舰。
- 火种货柜领袖、玩家模型机“无牌一号”、四台重涂机都按正式身份与生命周期出现。

## 明确禁止

- 陆衡在 C02 肉身出现或替木桶街解决转子。
- 模型、画稿、标签或名字直接改变物理现实。
- 把馆守 Z 写成恢复右臂、飞行或双拳作战。
- 万机馆在 C02 变形、暴走、起飞或获得完整战舰性能。
- 用“你可以……但别替我……”“不替谁背”“债务”“多少秒、多少厘米”作为戏剧高潮。
- 以连续救援、手续争议、授权小动作或工程术语代替机器人大战。
- 新造没有必要的具名人物、空间名和机制名。

## 效果验收

1. 两话连续读时不需要作者在正文外解释因果。
2. 每话都有一项玩家能复述的主要目标、一次大反转和一个大画面。
3. 机体不是工具清单；玩家能说出至少六台机体各自想做什么、怎样打。
4. 人物关系来自共同经历、判断、误解或吸引，不来自设定说明。
5. E02 的发生是 E01 行动结果，而不是下一项主题排队上场。
6. 与旧稿相比，新增复杂度没有超过新增戏剧收益。
