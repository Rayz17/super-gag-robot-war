# C02E01《六米巨环遮住天光》运行卡

## 本话职责

- 前因：C01终战与紧急起航损坏了万机馆主循环；它只能勉强抵达木桶街。
- 唯一主要目标：在不让木桶街停摆的前提下取得、验证并有限安装六米主循环转子。
- 中段转向：模型中的旧修补不是怀旧物，而是找出全尺寸实物版本错误的线索；公开它也会让平台找到其他被抹去维修史的机体。
- 独立高潮：玩家先夺运输路线，再在平台切索后以万机馆和三台巨机控制失控巨环。
- 结束状态：万机馆恢复低速循环但仍需C03全尺寸校正；平台冻结四台重涂机服务，E02立即发生。

## 必须兑现

- 纪存主动提出并执行“公共诊断换真实部件”的方案，并在巨环战中成为总指挥，不做审批员。
- 唐胶凭旧人脉、手艺与公开教学分别解决问题，不用一段忏悔结清过去。
- 兜灯至少否掉一次会毁掉馆守Z的英雄方案，并给出更强、更好看的安全解法。
- 七海只从远端识别平台回收链，不授权现场；纪存与她的旧关系由说真话或不说真话推进。
- 火种货柜领袖以全称首登，可作业变形；无牌一号是八米全尺寸竞赛实机，模型只提供同构数据。
- 馆守Z保留缺失右前臂、不能飞的限制；万机馆只做低速舰体支援。

## 不得提前消费

- 陆衡肉身出场。
- 白鸢肉身出场或画稿改变现实。
- 归一星完整战斗。
- 馆守Z新右臂、万机馆变形或暴走。
- 木桶街最终开放日、旧拳王决赛与C03城市接舰。

## 期末状态要求

- 记录万机馆、转子、馆守Z、货柜领袖、无牌一号和四台重涂机的位置、控制权与损伤。
- 明确哪些工程问题已经解决，哪些必须带进C03。
- 下一话由四台机服务被冻和回收队抵达直接发动，不以“继续调查”收尾。
