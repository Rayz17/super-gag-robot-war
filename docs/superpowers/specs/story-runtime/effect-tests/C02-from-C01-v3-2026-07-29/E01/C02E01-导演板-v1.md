# C02E01《六米巨环遮住天光》导演板

## 一句话戏剧

- 表层争夺：万机馆必须在当天拿到一套六米主循环转子，否则下一次加速或受击就会拖坏整条动力脊。
- 深层压力：木桶街愿意帮忙，却不能为了救一艘外来的巨舰让自己的工房和生活停摆。
- 本话大画面：平台装卸机割断固定索，六米金属巨环横扫外港上空；万机馆横过舰身充当承力墙，馆守Z、货柜领袖和无牌一号从三个尺度把它接住。
- 本话情绪核心：一个母亲继续完成去世儿子留下的修件委托；唐胶第一次把“修过”从缺陷改成能救实机的历史。
- 结束新局面：新转子完成有限安装，万机馆恢复低速航行；平台顺唐胶公开的维修史锁定四台同骨架机，直接发动 E02。

## 玩家可见门槛

- 必须当场理解：万机馆为什么必须修；模型怎样提供线索而不是变成实机；转子为何不能直接拿走；平台为什么能制造争夺；四台机如何共同接住巨环。
- 只需产生疑问：平台为何已经知道馆守Z与万机馆的负载特征；谁在远处收集这些样本。
- 后台真相：索引、白框、G.A.G.完整机制不在本话解释。
- 删除旁白后仍成立：热警报、六米实物、正在运转的街区设施、开盒痕迹、同向磨损、竞价屏、切索动作和巨环大场面都能被玩家直接看到。

## 资产与概念约束

- 主场景只用四个可复用区域：外港、全尺寸工房街、模型收藏内街、环形货运高架。
- 不新增具名空间和具名章内NPC；修件母亲、收藏者、本地工房领班均以角色功能存在。
- 工程表达只保留三项玩家必须懂的概念：主循环转子、批次不兼容、全尺寸复验。
