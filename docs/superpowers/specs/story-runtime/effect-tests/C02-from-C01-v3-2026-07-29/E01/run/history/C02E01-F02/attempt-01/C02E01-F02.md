# C02E01-F02 从巨人的脚边走进一条街

舷梯落下时，唐胶第一个走了出去。

馆守Z还站在旧泊位外侧。它的救援锚没有收，黄色巡展臂也仍夹着缆索，十八米身体像一座刚落成的门楼。街上的运输车从它脚边穿过，司机经过时会抬头看一眼缺失的右前臂，然后继续按喇叭、倒车、赶自己的货。

馆守Z进不了更窄的工房街。旧守护者便把视线换到从它脚边驶来的轮式导览终端上。刚才还从巨神胸前传出的声音，现在贴着唐胶的裤脚响起。

“这里比从海上看见的更忙。”

“别停在路中间感慨。”唐胶用鞋尖替它挡开一辆倒退的小拖车，“木桶街的车只认喇叭，不认老前辈。”

他嘴上仍旧不客气，脚下却熟得不需要看路。哪一处地面会忽然降下吊钩，哪一扇卷门里会倒着推出巨大的腿部外甲，他都提前半步避开。有人从焊光后认出他，喊了一声“唐胶”；也有人隔着整条工房街叫“唐启明”。他只抬手算作听见，没有停。

纪存和兜灯跟着他从馆守Z脚下走进街里。外圈停的是完整实机和运输架，一只脚便高过人头；再往里，工房把巨机拆成能工作的尺度，肩甲竖在墙边，关节躺在轨道车上，工人踩着升降台钻进它们之间。万机馆的检修窗也已经打开，本地工匠从里面带回一段停机影像。

影像中，原有主循环转子被人力慢慢盘动。它每转过一圈，边缘都会蹭过外壳，留下刺耳的刮响。几处金属已经变色，继续强行运转，只会把更多碎屑带进整条循环。

“难怪它一路越来越安静。”兜灯把影像倒回去看了一遍，“不是警报好了，是能转的东西越来越少。”

本地工房领班领着他们穿过一座全尺寸仓。仓门另一头，十二轴运输架占满了整条通道。运输架中央竖着一只六米金属巨环，外缘宽得足以让人并排走在上面。粗大的临时管线从巨环两侧伸出去，接进周围几座工房；转子在支架中低速运行，带起的风把高处成排的警示旗吹得笔直。

唐胶停在运输架前。万机馆要找的东西就在眼前，大得没有任何误认的余地。

“主循环磁流散热转子。”领班拍了拍运输架，“全尺寸，能转，也确实到了该退役的时候。”

纪存沿着那些管线望去。风从仓顶送进相邻工房，正在工作的切削机、材料柜和整备台都亮着同一种运行灯。转子并不是等人提走的旧货，它正撑着这一片全尺寸仓的公共散热。

领班将转速稍稍降下一档。远处几台机器立刻停刀，仓顶的警示灯接连亮起。有人从升降台上探头大骂，领班又把速度推了回去，满仓的风声随即恢复。

“看明白了吧？”他说，“拆它不难。它一走，这里的机器也得跟着歇。”

纪存没有再问价钱。他伸手按住正要弹出的交易界面，先把它关掉。

“我们不是来把你们的工房换成我们的机舱。”他说，“先查它到底能不能用，再谈怎么让两边都继续转。”

领班调出两份手册。六米转子的铭牌与万机馆旧系统属于相近年代，外形和连接位置也十分接近，屏幕上的结论却干脆得近乎无情：批次不同，不得混用。

兜灯绕着运输架看了一圈，没有因那相似的轮廓松口。

“直径对得上，不代表受力和停转方式也对得上。”她说，“没有全尺寸复验，我不会让它进万机馆。”

唐胶蹲在转子铭牌前，用手指擦掉铸字间积的灰。他没有反驳兜灯，也没有说自己一眼就看出了答案。他只是拍下那串年代标记，又看了很久手册中间那一段过于整齐的空白。

“首批，末批。”他低声说，“中间几年像没生产过一样。”

领班摊了摊手。平台上能调出的资料只有这些。转子仍在运输架上缓慢旋转，每一阵送往工房的风，都在提醒他们这件救命设备已经属于许多人的一天。

唐胶没有留在原地硬猜。他收起照片，继续往街里走。

全尺寸工房之后，路忽然窄了下来。升降台换成木梯，整面外甲换成挂在墙上的手掌，工业风机的轰鸣也被电磨、喷笔和小风扇的声音盖过去。玻璃柜里挤着各个年代的机器人，有的完整站着，有的只剩躯干，有的被拆成几十个小格，旁边压着写满日期的维修纸条。

纪存回头时，已经看不见馆守Z的上半身，只能从屋顶之间看见它的一小段肩角。轮式导览终端仍跟着他们，摄像头从方才的六米巨环转向一张只够两个人并坐的维修桌。

桌边坐着一位母亲。

她面前是一台拳头高的旧合金机器人。胸口的漆被许多年的手指磨亮，左腿则从膝部完全拆开，螺丝和垫片依次放在画了圈的白纸上。她照着一张已经翻软的维修单，用镊子夹起刚从小包裹里取出的棘轮和弹簧。

弹簧从镊子尖上滑了一下。

旧守护者把导览终端的灯转过去，照住透明袋口。母亲顺手让它靠近些，头也不抬地说了声谢谢。

唐胶站在桌旁，看见维修单上是另一个人的笔迹。每一步都写得很细，最后几行却停在“旧件到货后试装”，后面再没有字。

“别急着上胶。”他说。

母亲点了点维修单：“他也写了，还画了两个圈。”

她把包裹的外袋折好，放进桌角的纸盒里。

“这东西不是我儿子的，是人家托他修的。客人小时候就抱着它，舍不得换新的。我儿子订了旧库存，说新弹簧太硬，会把另一边也顶坏。”她把棘轮放到轴上试了试，“零件来晚了。快递打电话的时候，他已经不在了。”

她说完便继续低头对位置，没有等谁安慰。她显然还不熟练，装一次，发现方向反了，又拆下来照着儿子的图重来。桌上还有几袋分好的螺丝，说明她已经这样做过不止一天。

唐胶没有抢走她手里的镊子。他把装零件的小碟推近一些，替她压住那张总被风扇吹起的维修单。

“这一面有磨亮的地方，朝里。”他说。

母亲依着亮痕把棘轮翻过来。旧机器人的膝部终于合上，却仍有些歪。她试着让它站立，机器人晃了两下，靠住装工具的铁盒才没有倒。

“还差一点。”她说，像在给自己记下一项普通工作。她在维修单后添了一行字，又把机器人重新放倒，没有急着宣布完成。

唐胶的目光落在桌角那只旧库存外袋上。

袋上的印刷已经褪色，生产年份却还清楚。正是六米转子铭牌与现行手册之间缺失的那几年。小小的棘轮当然修不了万机馆，甚至不能证明两种巨型转子可以混用；可这个被官方资料轻轻跳过的年代，并没有真正消失。它变成了旧库存、再版零件、盒底批注和一张张不舍得扔的维修单，留在这条模型内街里。

唐胶拿起自己的终端，把转子铭牌照片与旧袋年份并排放在屏幕上。

兜灯看了一眼：“同一年，不等于能装。”

“当然不等于。”唐胶说，“它只说明我们该往哪几年找。手册从首批直接跳到末批，这里的人却一直修着中间的东西。”

纪存望向两侧高到顶棚的旧盒和纸档，没有让人回去拆那只正在为街区送风的转子。

“先把被跳过去的部分找出来。”他说，“在证明它既能救万机馆、也不会让木桶街停下来之前，我们不动运输架。”

兜灯收起终端：“找到旧说法以后，要回六米实物上复验。”

唐胶点头。他看见母亲又俯下身，开始拆那条仍然站不直的膝关节；旧守护者安静地替她照着桌面。

这张维修桌没有给出万机馆的答案。它只是让唐胶第一次确定，官方手册缺掉的那段时间，或许还活在木桶街更小、更旧的东西里。
