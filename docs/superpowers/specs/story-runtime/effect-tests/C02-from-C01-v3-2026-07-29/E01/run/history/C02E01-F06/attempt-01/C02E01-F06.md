# C02E01-F06 第一晚，四种醒法

巨环落上万机馆时，木桶街的欢呼只持续了很短一阵。

街区的公共循环已经停下，万机馆的主循环也仍是一片红。两边都得先把机器重新转起来，才有资格庆祝。

恢复的一天没有被浪费。傍晚，火种货柜领袖沿外港货道拉回了木桶街选定的替代机组，万机馆提供重载空间和护送，本地工房负责接入。替代机组第一次转动时，几排工房只恢复了够当夜收工的风量，但不会再因为六米转子离开而整条街停摆。

领班随后在旧租牌上完成了木桶街的选择：街区不承接原转子，由万机馆按公开方案承接；平台仍可按原有报价处理所有权转移，却不能再跳过停机置换期远程提货。事故中的切索记录已经公开，平台装卸队暂时退出了外环。

入夜以后，木桶街的全尺寸工人登上万机馆。

六米转子从舰侧承载架缓缓送进主循环安装位。白天试制通过的全尺寸适配座被吊入巨环下方，本地工人负责起重和固定，兜灯守着万机馆的制动状态，唐胶则把失败件上那道翘痕留在所有人都看得见的作业板上。

没有人再照着模型尺寸做东西，也没有人因为第二件试制成功就跳过复查。

第一轮落位后，唐胶想让工人继续收紧，兜灯把手横在他面前。

“先转一圈。”

“还没接完，怎么转？”

“人推。蹭不蹭，先听清楚。”

唐胶咂了下嘴，却还是跟着她钻进安装位旁的狭窄作业道。两人一前一后贴着六米巨环走，本地工人在外面缓慢推动转子。他摸安装座外缘，兜灯从他肩侧伸手，把检查片送进另一边。空间窄得两个人转身都会撞到一起，唐胶只能侧着腰给她让位置。

巨环转到磨损带附近，作业道忽然轻轻一震。唐胶脚下沾着白天留下的油，身体向后一滑。兜灯一手撑住安装座，另一手直接揽住他的腰，把他拽回自己身前。

“你这算扶人还是夹工件？”唐胶问。

“工件没你乱动。”

她嘴上没客气，等巨环完全停住才松手。两个人离得太近，唐胶回头时差点碰上她额头。他没再往后退，只低头看见她掌侧被地锚链擦开的一道口子。

“手给我。”

“先看检查片。”

“片没流血。”

唐胶从衣袋里摸出修件时常用的软布和绷带，托着她的手包好。兜灯没有抽回去，另一只手仍举着那张检查片。片面干净，没有新的擦痕。

她把结果递给外面的工人。

“可以接低速循环。”

最后的固定由本地工人共同完成。唐胶只标出要保留观察的位置，兜灯则在主控旁加上临时止动，让万机馆在重新校正前无法把转子推入高负载。两人都在作业记录上签了名，也把复核位置留给了后续工程队。

夜色彻底压下外港时，纪存站在万机馆内街，合上低速启动开关。

六米巨环先发出一声沉重的低鸣，随后缓慢转过第一圈。安装位没有跳动，适配座也没有滑开。冷却流重新进入万机馆的旧管路，从舰侧一路向内推进。

沉寂了一整天的通风口逐个吐出凉风。挂在展柜旁的旧宣传页轻轻掀起，维修间里闷住的热气被抽走，厨房门口那团迟迟散不开的蒸汽终于顺着走廊跑远。跌跌追着一张被风吹动的餐巾纸跑了半条内街，机器犬把纸踩住，自己先趴在了恢复凉意的地板上。

低速试转通过。

万机馆可以继续航行，足以带着所有人前往工务城。可全舰各段还没有重新校正，新的转子也没有接受加速、急转或战斗负载。兜灯把这些限制留在主控最醒目的位置，纪存没有关掉它们。

“平着开，慢慢走，能到下一站。”唐胶从作业道里爬出来，拍掉衣服上的金属屑，“真要挨打，先找地方躲。后面的全舰校正不是我这双手能签的。”

兜灯从后面跟出来，把他漏在肩上的一片包装纸拿掉。

“这句话可以写进报告。”

“前面那句不写？”

“那句写给纪存看。”

工房送来的夜宵摆在没拆封的零件箱上，不过是热粥、咸菜和一盘很快见底的煎饼。工人们坐在舰侧和内街门口吃，谁也没有把食物翻来覆去检查。货柜领袖收起作业骨架，停在外港补充能源；它答应把万机馆和街区需要的后续货物一起护送到工务城。无牌一号则由竞技场维护者按正常运输流程带回公共整备位，临时挑战席已经断开，攀轨模块还没卸下。馆守Z坐在舰侧作业平台旁，黄色巡展臂安静放在腿上，原装右臂的位置仍旧空着。

旧守护者从万机馆广播里听了一会儿碗筷碰撞声，才开口。

“下次开馆，能让木桶街的人也上来吗？”

兜灯抬头看向馆守Z。

“你想见他们？”

“我想让他们看看，我们把风接回来了。”

纪存没有替它回答，只把这句话记在下一次开馆要做的事里。

他端着一碗已经不烫的粥走到内街尽头，接通七海的私人通讯。画面里没有公务界面，七海仍在原城，身后只亮着一盏临时通道灯。

“修好了？”她问。

纪存看了一眼主控上仍亮着的限制。白天那场胜利太痛快，他本来很想只回答一个“好了”。

“能走到工务城。”他说，“不能打。舰侧刚吃过一次重载，转子也只通过低速试转。再加速会发生什么，我们还不知道。”

七海看着他，忽然笑了一下。

“这次没等我从背景警报里猜。”

“以前也没每次都瞒你。”

“你每次说这句话，通常都已经瞒了一半。”

纪存把主控画面完整转给她，没有删掉红色限制。七海的笑意停留了一会儿，随后被另一组不断弹出的公开记录压了下去。

唐胶公开的维修页没有泄露收藏者姓名，却公开了被平台手册删掉的中间版本、旧批次磨损和全尺寸复验结果。平台沿着这些真实的版本关系反向检索，在木桶街外环的代管停放仓里找到了四台使用同一基础骨架、却留下不同改装记录的飞行实机。

四条服务同时变成冻结状态。

“它们把四台机都锁进了同一批回收名单。”七海把位置和冻结通知发给纪存，“我不能解除服务，也不能批准它们出动。我能做的是告诉你，平台回收队已经接单，正在往停放仓走。”

纪存放下粥碗。

“你还留在那边？”

“今晚是。”七海说，“去工务城的票我已经改好了。这次有些话，我到现场说。”

两人的通讯没有来得及正常结束。

木桶街外环的四间停放仓同时断掉平台维护电源。黑暗只持续了一瞬，四套本地系统先后自行亮起。

第一间仓里，喷气叛星猛地扬起双翼，发动机用一串轻快又尖利的高鸣顶开沉重仓门。它没有等待统一牵引，声音从门缝里抢先钻出来。

“关掉保养就想让我趴着？开门，我自己飞。”

第二间仓里，重涂机“死锁”没有抬翼。它伏低身体，一把扯断锁在胸前的维护牵引，金属落地声短而沉。它的声纹像砂砾擦过钢板。

“旧名字还在。敢来拿。”

第三间仓没有传出撞击。重涂机“镜星”先点亮电子干扰，仓内所有敌我识别灯同时交换位置。它用两层方向相反的声音平静开口。

“你们的识别表，错了。”

最后一间仓里，重涂机“雷翎”只展开一侧侦察翼。远方回收队的灯刚出现在高架尽头，它已经转动远射组件，清晰的声纹切入另外三台机的频道。

“东侧有队伍接近。不是来维修的。”

四台同骨架实机做出了四种完全不同的动作。平台试图用同一条冻结命令让它们归入同一个货号，却同时惊醒了四个声音。

万机馆刚刚恢复的内街警报再次亮起。

这一次，警报来自木桶街的天空。
