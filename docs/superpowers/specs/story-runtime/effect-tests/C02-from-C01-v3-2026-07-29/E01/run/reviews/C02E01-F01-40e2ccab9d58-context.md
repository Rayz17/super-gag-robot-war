# C02E01-F01 大船停在模型街外

离开旧城六小时后，万机馆终于看见了木桶街。

最先从海雾里升起来的是一排巨型吊臂。吊臂下方，能容纳全尺寸机器的工房与层层模型店挤在同一片岸线上。巨大的腿部装甲悬在门外翻修，隔壁雨棚下却有人举着放大镜修一只手掌大的旧玩具。万机馆横在外港，百余米舰身遮去半条街的天光，像一座搬家搬到别人门口、才发现自己进不了门的老房子。

它已经用了所有常规办法减速。

最低反推从入港前便没有停过，舰尾只剩一层薄薄的白浪；两具海侧临时锚拖在后方，把水面犁出长痕，却只能压住前冲，管不了横风。港里仅有的两艘作业拖艇也接上了引绳，可风一撞上万机馆宽大的侧舷，拖艇便被带得横着滑。它们能扶住运输驳船，拉不动一座离开地基的展馆。

现代泊位又短又窄，万机馆连舰首都塞不进去。唯一够宽的是木桶街留下的旧泊位，入口却横着一道沉重的旧闸。街区愿意开闸，前提是万机馆先在外面稳住；否则闸门一开，百余米舰身就会顺风扫进岸边，把工房的吊装路和水上作业道一起堵死。

舰桥地板烫得隔着鞋底都能感觉出来。主循环的警报没有停，自动航行系统仍在维持推力、转向和舰体平衡，却越来越难把船头留在航线上。

纪存看着旧泊位中心那根粗大的系缆桩。只要先把舰首送过去，用短缆扣住，再让万机馆以最低反推贴上外侧护岸，就能抢在主循环继续恶化前靠住。

“拖艇松开，别让它们被带翻。舰首对中心桩。”他把路线压到最短，“我们自己靠上去。”

外壳作业席立刻传来兜灯的声音。

“不能贴。”

她此刻不在漂移的船岸之间。万机馆进入主港前，纪存已经让馆守Z从原有的外部作业甲板转上岸边的驳运平台。现在十八米旧巨神正站在旧泊位外侧，双脚踩着能承受全尺寸装卸的地面。它失去右前臂的位置迎着海风，临时黄色巡展臂抱着救援锚，兜灯则伏在它肩侧检视岸边的旧结构。

她把镜头转向中心桩。桩身顺着泊位方向的旧磨痕又深又长，朝街区的一侧却已经裂开。

“它能牵住船头，不能替整条船扛横风。现在贴上去，船尾会绕着它扫向街里。直接从岸上拉也不行，缆索要横过吊装路，而且第一下就会把这根桩朝裂口方向拔。”

纪存没有为刚才的命令辩解。他立刻把靠岸路线从图上抹掉，只留下仍在拖行的海侧临时锚和最低反推。

“那就不让中心桩受横力。”他看向馆守Z所在的岸侧，“海锚继续减速，中心桩只定舰首。馆守Z在外侧落救援锚，把船身拉回泊位方向。”

“一根岸缆还不够。”兜灯说，“拉早了，舰身撞岸；拉晚了，船尾堵住水道。我们得让拉力沿着岸走，还要能换位置。”

舰桥旁，一条私人频道已经亮了很久。

“唐启明。”

对面的声音没有报名字，只叫了唐胶的本名。

“旧泊位还是那个脾气。别把缆索铺过工房门口。”

唐胶盯着呼叫灯，没有回应。他伸手放大岸边图，在堆满旧货的地面上圈出一段废弃轨道，又把紧挨着主路的区域整片划掉。

“这段旧轨底下是实的，旁边还有一座没拆走的港区绞盘。”他说，“主路必须留着。你们要在这儿停一天，不能先让别人停工一天。”

纪存把废轨、馆守Z和万机馆连成一条折线。图上已经有了三个清楚的受力点：海侧临时锚拖住前冲，旧泊位中心桩稳住舰首，岸侧再用一个可以移动的导向点控制船身偏转。

可木桶街没有能承担第三个位置的重型设备。

街口忽然传来一声低沉的汽笛。

一辆全尺寸重型货柜车从正在撤离的运输架之间驶出。驾驶室里看不见人，庞大的车身却自行避开每一辆叉车，沿唐胶圈出的废轨来到岸边。它停在旧绞盘旁，车灯越过海面，正对舰桥。

开放频道里响起沉稳的声音。

“我是火种货柜领袖。第三个位置，我来。”

它并没有等木桶街替自己答应，也没有问万机馆拿什么交换。它看了一眼仍在通行的工房主路，说：“大船可以靠岸，路也得继续走。把缆给我。”

货柜领袖向前驶过旧绞盘，确认拉力方向后骤然变形。货柜从中轴分开，向两侧展开成长形作业骨架；轮组收拢到轨道正上方，粗大的轨道夹从底盘落下，咬住两根旧轨。数条支撑桩随即扎进轨旁的承力地面。最后，作业骨架抬起港区绞盘的导轮，把万机馆递来的岸缆扣入其中。

这一次，承担百米舰载荷的不是轮胎。旧轨、地面支撑和港区绞盘一起成了它的新身体。

“位置能换，方向能改。”货柜领袖说，“船上的领队，告诉我往哪儿走。”

岸边，兜灯正要让馆守Z把受损的一侧转离街区。馆守Z胸前的扬声器先响了。

“让我面向他们。”

兜灯抬头。

旧守护者望着那些停在工房门口的人，也望着玻璃后面一排举起的旧机器人模型。

“我不是来躲伤的。”它说，“我想以现在的样子，站一次别人的门口。”

兜灯没有替它润色，也没有撤掉安全限制。她解除救援锚的运输卡扣，把黄色巡展臂限定在搬运和放索范围内。

“右边只送缆，左手控制。脚下有滑动就停。”

馆守Z点头，将救援锚砸入岸侧承力地面。它用黄色巡展臂放出缆索，再以完整的左手握住受力端。街上的人看清了它缺失的右前臂，也看清它仍能工作。

旧泊位外，横风再次推来。两具海侧临时锚在水下拖紧，万机馆的最低反推持续喷出白雾，舰身仍缓缓偏向作业水道。

纪存没有关掉反推，也没有让船故意失控。他等舰首进入中心桩的短缆范围，才下达第一道命令。

“扣住舰首。”

短缆落上中心桩，只给船头一个位置，不替它承受横风。

“馆守Z，收岸缆。货柜领袖沿轨向外移，让拉力顺着岸走。”

馆守Z左臂扬起，救援锚承住第一股力量。货柜领袖松开前方轨道夹，作业骨架在后方夹具和支撑桩保护下挪向外侧；港区绞盘的导轮随它转动，把原本会横过工房主路的缆索改到废轨上方。船身没有撞向岸边，而是绕着被固定的舰首，一点点转正。

风把两艘拖艇推向外侧，它们终于能松开引绳撤走。万机馆的船尾也从作业水道口退开。纪存看见街区的吊装车重新开动，才下达最后一道命令。

“保持反推。三处一起稳住，开闸。”

旧闸从水面上缓慢抬起。万机馆在海锚的拖力、中心桩的短缆和岸侧导向线之间低速前移，舰首进入泊位后便停住。主路没有被缆索截断，水上作业道也完整露了出来。

岸边安静了一瞬，随即响起一片敲击车壳和工房栏杆的声音。

馆守Z没有把残缺的右侧藏到身后。火种货柜领袖仍维持作业形态，轨道夹牢牢咬在废轨上。它们与万机馆一起，把一艘无处可停的大船留在了街外，也把木桶街自己的生活留在了街里。

纪存等全部缆索稳定，才让自动航行系统把反推降到维持档。

舰桥上的主循环警报仍在扩散。没人能仅凭这一路的热响判断究竟坏在何处，但有一件事已经没有余地：万机馆必须在当天彻底停机，打开系统做全尺寸检查。它经不起未经诊断的下一次离港。

唐胶的私人频道又亮了一次。他仍没有接，只把工具袋从椅背上取下来。

“船先留在这儿。”他说，“剩下的，得下去看过才知道。”
