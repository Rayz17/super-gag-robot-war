# C02E01-F01 大船停在模型街外

离开旧城六小时后，万机馆在正午的横风里看见了木桶街。

它先看见的不是街，而是一排高低错落的吊臂。巨大的旧吊塔跨在外港上，下面塞满全尺寸工房、货运架和细得像模型跑道的街巷。再往里，招牌、雨棚和晾晒的零件层层叠叠，一直挤到巨机也迈不开腿的地方。百余米长的巡展舰停在这一切外面，像一座刚学会移动的老房子，忽然发现别人家门口没有留给它的位置。

舰桥地板已经热得隔着鞋底发烫。主循环警报从清晨响到现在，声音越来越轻，不是故障缓和，而是几组散热风机先后停了。自动航行系统仍在努力修正横风，万机馆却只剩下缓慢转向的余地。每一次调整，舰体深处都传来沉重的摩擦声。

纪存盯着港区旧图。能容下万机馆舰首的泊位只剩一个，入口正对风口，后方又紧贴工房街的主路。再退回开阔水面，主循环未必撑得过下一次转向。

“舰首进旧泊位，速度压到底。”纪存把航向标移到两排旧桩之间，“先让前段靠上承力墙，船尾留在港外。别碰街里的路。”

万机馆刚偏过舰首，外壳作业席的通讯便抢进来。

“停推进。现在。”

兜灯的画面被风吹得直抖。她半跪在馆守Z肩侧的检修架上，身后是巨神空着的右前臂位置和那只临时黄色巡展臂。她没有等舰桥重复命令，直接压下泊靠制动。舰底的反推口逐级闭合，整艘船在水面上沉沉一顿，仍被惯性推着向前滑。

“那些旧桩能拉船，扛不住船横着撞。”兜灯把镜头转向岸边。风吹过时，几根泊位梁已经在一起摆动，“硬靠上去，下一阵风会把泊位和后面的吊装路一起掀掉。我们能停，半条街今天都别想开工。”

港区的公共频道顿时挤满了叫喊。有人催万机馆退出航道，有人让工房关门，还有人隔着噪声反复叫着一个名字。

“唐启明，听见没有？别往里面顶。”

唐胶就站在纪存右后方。他看着那条私人呼叫亮起，没有接，只伸手把旧图向外拉了一截。

“她说得对。”他指着旧泊位旁一条被杂物压住的装卸轨，“这条路以前走过重货，后来才废。可以吃力。右边那条不能碰，早市收摊以后，工房的东西全从那儿过。”

纪存取消了原航向。万机馆失去主动推力后，船头像一扇巨门，被横风缓缓推向街区。警示标线已经越过第一排屋顶。

兜灯否掉了最快的办法，却也把真正能用的地方指出来了：旧泊位只负责牵住舰首；馆守Z可以把救援锚带到废弃装卸轨上；还缺一个能在岸侧移动、把横向拉力顺着街排出去的支点。

纪存刚把三处位置连起来，街里忽然响起一声低沉的汽笛。

一辆全尺寸重型货柜车从撤离的叉车和运输架之间驶来。驾驶室里没有人，方向盘却随着路面自行修正。它没有听从港区要求车辆后撤的广播，径直停在废弃装卸轨前，车灯抬起，像在审视水面上的庞然大物。

开放频道里响起沉稳的声音。

“船上的领队，我是火种货柜领袖。你们还缺第三个支点。”

货柜领袖没有询问谁会付钱，也没有等街区替它做决定。它看了一眼仍在通行的工房主路，继续说道：“船留在外港，路得给这里的人留下。我帮你们挡这一阵风。”

“不是挡。”纪存把刚画出的受力路线传过去，“你沿旧轨向北，把力送回岸线。馆守Z负责另一侧，万机馆自己做转轴。风越大，我们越不能和它迎头较劲。”

“这才像领队的话。”

重型货柜车骤然压低车身。锁扣沿着货柜两侧依次弹开，长箱并未卸下，而是从中轴分成两片，向外展开成一副贯穿车身的作业骨架。后轮组前后错开，数条支撑腿落在旧轨的承力带上；驾驶室沉入骨架中央，整辆车从公路上的载具变成一座可以移动、可以转向的长形绞架。它的变形不是为摆出威风凛凛的站姿，而是把自己的每一段身体都变成了能托举、能牵引的工作结构。

馆守Z也从万机馆侧舱踏入风中。它不能飞，只能沿放下的重型坡板一步步走到岸侧。临时巡展臂夹着救援锚，左手拖住缆索，曾经属于右拳的位置直接迎着整条街。

兜灯让它侧过身，尽量把受损的一面避开人群。馆守Z胸前的扬声器却先响了。

“不用藏。”

兜灯停下手。

“我想看看这里的人，也让他们看清我现在是什么样子。”旧守护者说，“这一次不是撤离。我能站在门口。”

兜灯没有替它回答。她跳下检修架，亲手解除救援锚的运输卡扣，又把黄色巡展臂的动作限制在放索和扶持范围内。

“可以站。”她拍了一下馆守Z的小腿外甲，“左手吃力，右边只送缆。觉得不对就停，我也会让你停。”

巨神向她低了低头，转身走向纪存标出的岸侧位置。

三条缆索同时从万机馆舰首放出。第一条扣上旧泊位的中心桩，第二条穿过馆守Z脚边的救援锚，第三条被货柜领袖展开的长骨架接住。唐胶始终没有回应私人频道，却把对面传来的每一句提醒都变成图上的避让区：哪段旧轨补过，哪块地面下方是空的，哪一排店门必须保持畅通。

纪存把三台庞然大物的动作接到同一张航向图上。

“货柜领袖先走，让岸侧缆绷起来。馆守Z，锚落下后别急着拉。万机馆放开舰首，让风把船尾送过去。”

船员席上有人以为自己听错了。街区也响起一片惊叫。纪存没有改口。硬把舰体拽回来，只会让三处同时承受冲击；顺着风转过最危险的角度，万机馆的重量反而会压向港外。

货柜领袖的轮组沿旧轨轰然转动，展开的骨架带着缆索向岸线后方拉长。馆守Z把救援锚砸入承力带，黄色巡展臂稳稳送出余缆，左手却暂时没有收紧。万机馆的船尾扫过水面，掀起的浪撞上旧泊位，舰首离街区只剩最后一道空隙。

横风在这时骤然加重。

万机馆深处一声闷响，最后一组主循环风机停了。舰首猛地向内一偏，旧泊位的中心桩发出刺耳呻吟。

“就是现在！”纪存喊道，“馆守Z收缆！货柜领袖继续走，别停在原地！”

馆守Z左臂扬起，整条缆索从水面上绷直。它没有把船硬拽向自己，而是以救援锚为轴，改变了舰首偏转的方向。另一侧，火种货柜领袖的作业骨架在重压下发出连串爆响，轮组仍沿旧轨前进，把足以掀翻车辆的力量一点点送向岸线深处。

万机馆借着风完成最后半幅转向。百余米舰身横在外港，替街区挡住了正面来风，舰首则慢慢落入旧泊位中央。三条缆索一条接一条稳定下来，没有一根越过仍在通行的工房主路。

旧泊位的机械闸终于从锈迹中抬起。岸边的红灯熄灭，换成一盏迟缓却清楚的绿灯。

港区先安静了一瞬，随即爆出一片拍打金属和敲击车壳的欢呼。馆守Z站在街口，没有把缺失的右臂藏到身后。火种货柜领袖仍保持作业形态，用自己的长骨架撑住第三条缆。它们和万机馆一起，把一条没有为巨舰准备的旧岸线变成了临时泊位，也把街区赖以开工的路完整留了下来。

纪存直到确认最后一道机械闸落稳，才松开一直按在航向台上的手。

主循环警报仍在。屏幕上的温度没有继续上升，却也降不下来。万机馆已经安全抵达，但它无法靠这套系统再离开一次。

唐胶的私人频道又亮了一遍，很快被对面挂断。他望着熟悉的街口，脸上没有重逢的轻松。

“靠住只是第一关。”他说，“天黑以前，得给它找到一套真的主循环转子。”

纪存隔着舰桥玻璃看向木桶街。货柜领袖抬起车灯，馆守Z也从岸边回望着他。万机馆第一次停在陌生人的门前，没有压住他们的生活，也没有独自完成这次靠港。

“那就从这条没被我们堵住的路进去。”纪存说。
