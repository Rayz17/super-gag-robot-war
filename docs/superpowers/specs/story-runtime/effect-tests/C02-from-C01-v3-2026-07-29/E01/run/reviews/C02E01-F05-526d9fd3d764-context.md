# C02E01-F05 六米巨环遮住天光

木桶街终端上的日轮刚刚恢复，平台的竞价装卸机便同时停下倒车。

它们不是认输。平台仍拥有六米转子，也仍握着运输架上的远程保护装置。如今两座转辙台和岸侧绞盘都回到街区手里，平台判断原定提货路线已经无法完成，于是把回收方式从“装车运走”切换成了最后的紧急方案。

工房上空响起刺耳警报。运输架先远程关闭转子，切断通往各家工房的循环管线。巨环的转动缓缓停下，街上一排排抽风机也跟着沉默。

高架屏幕随即画出一条简单得令人发冷的图：平台会保留悬在高处的回收缆，割断木桶街固定在运输架上的其余索具，让转子直接荡进外环另一侧的无人货运区。只要街区交还转辙台，平台装卸队就能在那里接住资产。

这是为无人区准备的脱困办法。它不需要工人靠近卡死的巨件，也能防止平台资产被留在失去控制的现场。可此刻通往回收区的路线已经被夺下，平台仍启动它，等于把一套二十吨级的工业总成挂在所有人头顶，逼木桶街先放弃刚拿回的选择时间。

领班冲向本地急停，屏幕只回给他一行红色警告：回收已开始。

被困在支线里的装卸机升起切割臂。它们隔着货柜领袖展开的骨架够不到转子，外环上方的运输无人机却沿着维护轨道滑到固定索旁。平台没有切断自己的高位回收缆；它割开的是把巨环固定在十二轴运输架上的三道索具。

第一道索断开，巨环向外一偏。

第二道索炸出火花，整座高架跟着一沉。

最后一道索被割断时，六米金属巨环从运输架下猛然摆出。它仍被高处的回收缆吊着，却像一只突然脱手的巨大钟摆，越过无人货运区，直扫外港。

高架屏幕在巨环下方弹出一幅新的路线图：只要木桶街把两座转辙台切回平台方向，高位回收缆就会把巨环拉入封闭货道。平台没有打算白白毁掉自己的资产，它确信眼前的危险足以逼所有人让路。领班看着那个巨大的“恢复接管”标记，没有伸手。

阳光从巨环中央穿过，下一刻又被整片金属遮住。街上的人只来得及看见它的影子从屋顶、高架和海面一口气压过去。

馆守Z最先动了。

十八米旧巨神从岸侧绞盘旁跨出，完整的左臂迎向巨环，黄色巡展臂也抬了起来。它没有右拳，不能飞，更不可能在半空中给这股摆动找到另一边支撑。但旧守护者仍本能地站到了木桶街与巨环之间。

纪存的第一句话几乎已经冲出口：“馆守Z，接住——”

兜灯直接切进全频道。

“停！”

馆守Z的左脚压碎地面积水，硬生生停在巨环下方。金属阴影正从它头顶掠过。

兜灯把馆守Z的受力图推到所有人面前。图上没有密密麻麻的数字，只有一个结果：单臂抱住巨环以后，摆力会拖着馆守Z一起转向，先折掉黄色工作臂，再把它和巨环一同甩回工房街。

“它少的不是一只用来好看的拳头。”兜灯说，“现在少的是能从另一边拉住它的力量。硬接，只会多砸下一台。”

她一把抹掉馆守Z独自挡在正面的路线，重新画出四个巨大的箭头。

“万机馆横过来，拿舰身挡住外摆。货柜领袖托下边，不让巨环落地。无牌一号守住上面的回收缆。馆守Z只推方向，把它送向船，别背它的重量。”

唐胶已经跑到全尺寸工房外侧。他抬头看见巨环上那条刚刚测过的磨损带，抓起作业灯照向另一侧宽阔的外缘。

“货柜领袖，接亮的这一面！”他喊，“那边能放上承载架！”

兜灯看了一眼他照出的落点，改了货柜领袖的行进箭头。唐胶没有替她判断馆守Z能承受多少，兜灯也没有拒绝工房刚刚验证过的实物经验。

纪存看懂了整张图。

单机接不住的东西，就让一艘百米舰、一台旧巨神、一位载具领袖和一台竞赛实机共同接。

“按兜灯的方案。”他把四个目标同时送出，“无牌一号锁住上边。货柜领袖跟住下缘。馆守Z把它推向外港。万机馆，准备横舰。”

战场目标从“守住运输架”变成了“控制巨环摆动”。

高架上，玩家让无牌一号离开第二座转辙台的平面，沿攀轨模块直接冲上外侧钢梁。八米实机追着正在滑动的高位回收缆爬去。平台运输无人机向它撞来，无牌一号没有停下与它们缠斗；玩家让机体跃过一段空轨，把四组攀轨夹同时打进转辙台的主梁。

机体被巨环的摆力猛地拉成斜线。

攀轨模块承受住了。无牌一号像一枚钉进高架的巨大楔子，锁住回收缆上端，不让平台把支点继续拖向封闭货道。玩家不需要举起二十吨巨环，只要守住这一个高处，巨环就无法再越摆越远。

下方，火种货柜领袖收回封路的横架，沿无人货运区全速追向巨环的影子。它没有恢复成普通货柜车，而是在奔跑中把作业骨架完全展开，形成一条贴着地面移动的长承载架。

巨环下缘砸落，货柜领袖从侧面切入。

沉重金属压得整副骨架向下一沉，车轮在地面拉出长痕。货柜领袖没有试图停住它，而是托着巨环继续向外港移动，让原本会砸穿地面的坠落变成一段仍可追赶的滑行。

“货物会说自己想去哪儿。”它顶着轰鸣开口，“至少这一次，路上的人先说过了。”

巨环的上端被无牌一号钉住，下缘被货柜领袖托起，最危险的坠落已经被拆成了一个缓慢变大的摆弧。可它仍朝外港侧面扫去，正对着万机馆的舰首与旧泊位。

馆守Z在这时落下地锚。

它没有抬起黄色巡展臂去假装那是一只新拳。工作臂把地锚链压在身侧，完整的左手则迎上巨环外缘。二十吨级金属撞上左掌，馆守Z沿岸坡滑出一道深痕，却没有抱住它。

旧守护者只用一条完整手臂，持续把巨环向海面方向推。

“我守过门。”它的声音从胸前扬声器震开，“今天也送客。”

地锚绷紧，馆守Z终于稳住脚。它承受的不是巨环全部重量，而是改变摆向的那一下力量。巨环从会扫回工房的弧线上被一点点推出，正面转向外港。

那里，万机馆开始移动。

百米巡展舰没有长出四肢，也没有暴走。自动航行系统只执行纪存给出的低速转向，旧舰体在三处泊系之间缓缓侧过身。整面宽阔舰舷横到外港上，像一堵从水中升起的承力墙。侧面安装位保持敞开，承载架正对着被三机送来的巨环。

街区里的人第一次从这么近的地方看见万机馆整个身体参与作业。它没有发射武器，也没有做出人形机体的动作，只以百米舰身压住海面，把原本横扫天光的巨环挡在所有工房之外。旧泊位的索具被拉得笔直，先前帮助它靠港的三点固定，此刻成了它敢把侧舷送上去的底气。

可是万机馆的身体太大，惯性也太大。舰身若完全锁死，巨环撞上去只会被弹回高架；若过早放开泊系，主循环不足的旧舰又会被横风带离接环位置。

纪存盯住外港全图。

无牌一号把高处支点守成一条直线；货柜领袖托着下缘进入舰侧阴影；馆守Z以左掌推完最后一程，随即借地锚停住。四台巨体第一次在同一张图上形成一条从高架通向万机馆的斜线。

巨环撞向舰侧。

“就是现在。”

纪存释放舰侧绞盘。

锁住万机馆外侧的泊系随之放开。百米舰体没有顶着巨环硬扛，而是顺着冲击转过半个舰身。巨环的摆动被这座移动的墙整个接走，沿着宽阔舰舷滑向敞开的安装位。货柜领袖在下方继续托举，无牌一号守住高处不让它仰翻，馆守Z的左掌贴着外缘，把最后一点偏向推正。

万机馆剩下的泊系绷到极限。巨舰、巨环与三台机器人在外港上构成一幅几乎静止的画面。

随后，六米巨环重重落上舰侧安装位的承载架。

高架不再震动。货柜领袖的车轮停在舰边，无牌一号仍牢牢钉在转辙台主梁上，馆守Z单膝抵着岸坡，右侧只有那条被压低的黄色工作臂。没有任何一台机体独自举起巨环，也没有任何一个位置能够被省掉。

木桶街的工人冲上舰侧作业面，用运输索把巨环固定在承载架上。平台的高位回收缆失去载荷，装卸机与无人机开始沿原路退回；竞价屏仍亮着，立即提货却已经彻底失败。

纪存没有让人把全尺寸适配座装上去。巨环已经离开危险摆弧，公共管线也已安全断开，但万机馆的主循环仍未恢复，真正的安装和复验还在后面。

这不妨碍欢呼先从木桶街高架下爆开。

玩家松开无牌一号的操纵杆时，八米实机的攀轨模块仍亮着。货柜领袖抬起承载架，像向舰上的新货物致意。馆守Z则把左手从巨环外缘慢慢收回，胸前扬声器里传出一声满足的呼气。

纪存站在万机馆舰桥，看见那只曾压住整片天光的六米巨环终于安稳落在自己的船上。

他没有独自救下它。

他第一次真正把一群愿意行动的机器人，组织成了一支队伍。
