# C02E01-F04 平台把救命件变成限时拍卖

全尺寸适配座通过试验后，唐胶公开的维修页在木桶街传开了。

起初只是工房之间互相转发。很快，外地的旧机收藏者、工业件商人和巡展舰爱好者都开始搜索那套六米转子。十二轴运输架旁的旧货屏一遍遍刷新：原本按退役总成计算的价格跳过数级，运费也跟着向上翻。不到一顿饭的时间，它便从“没人愿意拆走的公共旧件”变成了限时竞价资产。

平台并非凭空取得这份权力。

当年转子无人问津，木桶街又拿不出一套十二轴运输架和长期外环维护费，是平台把架子送来，承担了检修与远程调度。作为交换，只要这件货物重新达到可交易价值，移动它就必须走平台的独家货运线，平台也拥有优先提货权。那份安排曾让一件卖不掉的旧总成继续为工房送风；如今公开诊断证明它能救一艘百米巡展舰，过去看似便宜的条件同时醒了。

外环高架的信号由绿转红。数台竞价装卸机沿平台货运线驶入，先占住两座转辙台，再把远程夹具扣上十二轴运输架。岸侧绞盘也切换为平台调度。它们没有攻击工人，只是不再允许任何未中标者改变运输方向。

屏幕给木桶街的收购价很高。有人看见那笔钱，觉得足以换掉几处漏雨的工房顶；也有人指着仍在旋转的公共转子，问钱到账以后下午靠什么给机器散热。平台承诺的是后续补货，不是眼前这一阵风。

本地领班把决定推到纪存面前：“你们也出价？”

纪存没有立刻抬价。他把刚才的公开诊断、万机馆的货运空间和外港地图一起投到大屏上。

“木桶街把转子交给万机馆，万机馆留下完整诊断和适配方法；街区选定替代设备后，我们负责重型运输，火种货柜领袖负责地面转运。货到以前，转子不离开公共管线。以后木桶街有必须跨城送出的全尺寸件，万机馆提供一段航路和护航。”

这不是一笔能立刻变现的最高报价，却让街区保留生产，也把万机馆获得的东西变回木桶街可以反复使用的能力。

唐胶看向领班：“他们至少知道自己要拿什么，也知道这里不能少什么。”

平台的提货倒计时仍在走。领班还没有来得及召集所有工房作出决定，第一台装卸机已经开始收紧运输架的远程夹具。独家货运线不需要等街区讨论结束，只需要按旧协议把货送上外环。

纪存这才改变目标。

“先不碰转子。”他把战术图放大到三处：“拿回运输架、两座转辙台和岸侧绞盘。只要路还在平台手里，木桶街就不是在选择卖给谁，只是在看它被谁运走。”

七海的私人通讯在这时接通。她仍在原城，背景不是办公室，而是一条临时公共通道。纪存把竞价屏与装卸机标记发给她，没有问她能不能批准行动。

七海看过货运编号，脸色很快沉下来。

“这些不是普通拍卖设备。”她调出一串相同前缀的旧货记录，“平台先维护无人问津的资产，等搜索热度和适配证据把价值推高，再用独家运输权把货送进统一回收链。价格确实会付，原本的使用者也确实会失去选择买家的路。”

“能停掉它们吗？”

“我没有停掉它们的权限。”七海说，“我只能确认这是一条回收链。那两座转辙台和绞盘属于木桶街的实体设备，现场的人决定怎么用；平台的装卸机则会继续执行提货。”

她把回收链的货运编号和目的标记转发到公共风险页。内部界面随即切断了她最后一条只读通路。她盯着熄灭的页面，呼出一口气。

“现在他们也知道是我把路线给了你。别浪费。”

纪存把三处目标同时点亮。

外环地图随之展开成一条清楚的运输链：十二轴运输架要先过第一座转辙台，才能并入高架；第二座转辙台决定它驶向木桶街岸线，还是驶进平台的封闭货道；岸侧绞盘则控制最后一段升降坡。只夺下一处，装卸机都能从另外两处把货绕走。纪存把三台机体分开，没有让任何一台冲向仍在工作的转子。

“运输架留给街区，转辙台切断装卸队，绞盘封住岸口。”他把三个行动标记发给现场工房，“我们不替你们决定卖不卖，只把决定之前那段路抢回来。”

原本还在为高价争吵的工人动了起来。有人拉开空置支线的防撞挡，有人把平台铺在地上的引导标识翻到背面，还有人跑去确认公共管线的压力。街区没有突然变成同一种声音，但至少都看懂了纪存要争的不是报价。

全尺寸工房的一扇高门在他身后打开。

里面不是模型盒，也没有任何东西迎风放大。八米高的竞赛底盘早就站在模块架之间，腿部关节、主躯干和低权限竞赛AI都是真实制造并长期维护的全尺寸设备。它的正式登记名是玩家模型机“无牌一号”。缩尺模型只曾帮助工房测试不同改件的形态关系；门后排列的轮组、抓臂与攀轨组件，则是街区依照那些数据真正制造出来的实机模块。

临时控制界面接入纪存的战术席。无牌一号的AI没有替玩家作出选择，屏幕上展开三套现成模块。纪存看了一眼外环高架，选中全尺寸攀轨模块。

工房吊臂落下。宽大的轨道夹与辅助轮组扣上无牌一号的四肢，固定销逐一锁紧。八米实机踏出高门时，脚下地面真实地震了一下。玩家第一次接过它的移动与模块控制：抬脚、夹轨、转身，每一步都由全尺寸身体在街区里完成。

“无牌一号，去第一座转辙台。”纪存说，“别追装卸机，先改它们的路。”

纪存第一次推下行进指令，无牌一号只迈出半步便停住。前方是工房横跨街面的送料吊杆，八米机体不能像桌上的模型那样随手越过去。竞赛AI只标出碰撞位置，等待玩家重选路径。纪存让它侧身收肩，从两排工房之间挤过；街边的人抬头看着这台原本为比赛造出的实机第一次承担街区作业，纷纷把悬挂的料筐向内收。

无牌一号沿高架支柱攀上外环。攀轨模块夹住侧轨，它没有在狭窄轨面上硬挤，而是把身体悬在高架外侧移动。平台装卸机伸出推臂阻挡，玩家松开一侧轨夹，让八米机体绕过横梁，再从下方扣住转辙台的手动杆。

第一座转辙台转向空置支线。

几台已经提速的装卸机来不及同时换轨，被顺势引入支线。它们没有翻覆，前路却被一副突然展开的货柜骨架截住。

火种货柜领袖已经从旧泊位解除部分作业固定，沿地面货道赶到外环下方。它再次完成作业变形，货柜两侧展开成长形承载架，轨道夹咬住支线底部。平台机器想倒车，货柜领袖便将骨架向前一送，把整列装卸机稳稳收进空置货位。

“路不是谁先标价就归谁。”货柜领袖说，“至少先让站在路上的人说话。”

装卸队被截断，无牌一号获得了通往第二座转辙台的空档。玩家切换攀轨模块的抓臂，直接越过一段被平台锁死的轨面，从高架侧壁横移过去。第二座转辙台的远程机构拒绝指令，它便用全尺寸抓臂拔出平台锁销，将巨大的道岔推回木桶街的岸侧线路。

另一边，馆守Z沿地面走向岸侧绞盘。它不能飞，也没有恢复右拳。黄色巡展臂只负责托住绞盘链条，完整的左手则握住手动轮。平台运输无人机试图重新接管，万机馆从外港传来的观测标记让纪存看清了它们的接近路线。

“馆守Z，等它们都压低再转。”

纪存先让万机馆关闭高处引导灯，只保留岸侧信号。无人机为读取地面标记一起降低高度，馆守Z这才转动绞盘。沉重链条横移，把岸侧入口封在无人机与运输架之间。无人机没有被击毁，只能停在链外寻找新路线。

三处控制点同时由红转白。

十二轴运输架上的平台夹具失去独家线路支持，依次松开。无牌一号站在第一座转辙台上，攀轨模块仍扣着高架；货柜领袖以展开骨架封住装卸支线；馆守Z守在岸侧绞盘旁，左手没有离开手动轮。

领班带着两名工人登上运输架，把平台的远程调度牌摘下，换回木桶街自己的作业牌。各工房的旧终端逐一收到架台位置和道岔状态，方才只能看着倒计时的人重新获得了停机、放行与改道的按钮。平台仍可以出价，也可以来谈旧协议，却不能再靠一串远程命令完成提货。

纪存将运输架控制交回本地工房。转子仍在低速运转，公共管线没有拆，六米巨环也没有被吊起。平台的竞价屏还亮着，提货指令同样没有撤销，但它已经无法绕过木桶街，把运输架直接送进独家货运线。

纪存没有宣布胜利属于万机馆。

“路拿回来了。”他对领班说，“现在由你们决定这件东西怎么走。”
