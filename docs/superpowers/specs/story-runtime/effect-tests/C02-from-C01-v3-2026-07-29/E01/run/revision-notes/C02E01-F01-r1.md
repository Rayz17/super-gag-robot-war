# C02E01-F01 第一次返修要求

保留以下高光：

- 百米万机馆初见木桶街的规模反差。
- 兜灯否决纪存的危险方案，纪存立即重组。
- 火种货柜领袖自主首登并完成作业变形。
- 馆守Z不隐藏残缺，以当前身体面对新观众。
- 靠港后仍保持木桶街主路畅通。

必须从危机起点重写并解决：

1. 先交代为什么常规减速、抛锚、港内拖带或直接岸缆不能单独完成靠港，不能让危机来自专业角色漏做常识动作。
2. 馆守Z在万机馆抵达前已可通过C01既有外部作业甲板/驳运平台下到岸侧，或采用另一条玩家一眼能懂的连续路径；不能在船岸相对漂移时临时走坡板。
3. 火种货柜领袖必须通过可见的轨道夹、地面插桩或港区绞盘成为移动导向器，不能只靠轮胎承受百米舰载荷。
4. 三点受力链必须清楚：海侧临时锚负责减速，旧泊位中心桩只定舰首，馆守Z岸锚与货柜领袖导向绞架共同改变偏转方向；万机馆保留最低反推用于控制，不主动制造失控。
5. 本场只能确认主循环持续恶化、必须当天停机诊断。转子故障要留给F02/F03由可见检测得出，唐胶不能无来源提前报出精确部件。
6. 避免新增专名和细碎工程解释。用四五个大动作让普通玩家看懂即可。
