# C02E01-F06 第一次返修要求

保留现稿：

- 木桶街替代机组先落地，公共生产不因万机馆取件停摆。
- 全尺寸适配座、手推整圈检查、低速恢复通风与高负载实体止动。
- 普通夜宵和舰内重新有风的生活感。
- 唐胶与兜灯的搀扶、包扎、专业分工和身体距离。
- 纪存向七海主动展示限制，而不是让她从警报猜。
- 四台重涂机以四种动作和声纹醒来，回收队接近但尚未开战。

必须在安装前补成可验证的资产处置：

1. F04恢复的一天内，木桶街先接入替代机组，满足安全交还条件。
2. 旧租牌赋予木桶街按固定残值优先买回的权利。纪存决定动用万机馆所剩的
   大部分维修储备金，由木桶街完成买回，再把转子与适配成果转让给万机馆。
3. 平台自动结算接受租约约定的残值，所有权标记从平台转为万机馆；平台仍可追究
   F05阻断装卸、切索事故和公开资料等事项，但不能再声称万机馆盗装资产。
4. 用支付、旧租牌状态变化和实体所有权牌交接三个画面说明，不把场面写成合同汇报。
5. 资源代价只需清楚：万机馆拿到转子，却几乎清空短期维修储备，后续更依赖
   工务城校正与新伙伴。不要把胜利立即贬成错误。
