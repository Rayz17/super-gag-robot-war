# C02E01-F06 第一晚，四种醒法

六米巨环落上万机馆以后，谁也没有急着把它往主循环舱里送。

它被救下来了，却还属于平台。木桶街的一天已经恢复，先要做的是让街区能够安全交还旧转子，再把所有权真正转到万机馆手里。

傍晚，火种货柜领袖沿外港货道拉回木桶街选定的替代机组。万机馆让出重载空间并一路护送，本地工人负责接入。替代机组第一次转起来时，几排工房的抽风口重新有了风，虽然只够维持低速作业，却不会再因为六米转子离开而整条街停摆。

领班这才擦亮运输架上的旧租牌。平台抬到天上的竞价仍挂在远处大屏上，租牌本身却只亮出一个多年没有变过的残值。那是木桶街在优先期内买回这件退役设备的价钱。

街区账面凑不出全部数目。

纪存打开万机馆的维修储备。那笔钱原本留给旧舰接下来一路上的管线、外壳和馆守Z整备。他看着余额停了一会儿，把其中大部分转进木桶街的公共账户。

唐胶皱起眉：“再坏一处，你拿什么修？”

“先让它能走。”纪存说，“剩下的路，找会一起修的人。”

领班没有再劝。他在旧租牌上按下买回，木桶街账户里的钱整笔划走。平台没有接受外环高价，也没有重新谈条件；系统照租牌约定收下固定残值，运输架上的平台所有标记熄灭，紧接着亮起“木桶街”三个字。

另一侧屏幕上，装卸冲突、切索事故和公开维修资料的追查仍保持开启。平台以后仍能逐项追究，但转子已经结清，它不能再把万机馆的安装称为偷走资产。

领班拧下巨环外缘那块实体所有权牌，翻过来，当着街区工人的面压上木桶街的转让印记。他没有把牌留在自己手里，而是递给纪存。

纪存接过金属牌，将它插进万机馆舰侧安装位的识别座。

平台结算屏最后刷新一次。所有者从“木桶街”变为“万机馆”，旧租牌上的日轮随之熄灭。万机馆的维修储备只剩下一小截，六米巨环却终于可以名正言顺地进入它的身体。

“现在装。”领班说。

入夜后，木桶街的全尺寸工人登上万机馆。

转子从舰侧承载架缓缓送入主循环安装位。白天试制通过的全尺寸适配座被吊到巨环下方，本地工人负责起重和固定，兜灯守着万机馆的制动状态，唐胶则把失败件上那道翘痕摆在作业灯下，提醒所有人别因为抢回了转子就省掉复查。

第一轮落位后，唐胶想让工人继续收紧，兜灯把手横在他面前。

“先转一圈。”

“还没接完，怎么转？”

“人推。先听有没有蹭。”

唐胶咂了下嘴，还是跟她钻进安装位旁的狭窄作业道。本地工人在外面缓慢推动转子，他摸着适配座外缘往前走，兜灯从他肩侧伸手，把检查片送进另一边。空间窄得两个人一转身就会撞在一起，他只能侧着腰让她贴过去。

巨环转到旧磨损带附近，作业道忽然轻轻一震。唐胶脚下沾着白天留下的油，身体向后一滑。兜灯一手撑住安装座，另一手直接揽住他的腰，把他拉回自己身前。

“你这是扶人还是夹工件？”唐胶问。

“工件没你乱动。”

她等巨环完全停住才松手。两个人离得太近，唐胶一回头，差点碰上她额头。他没有再退，只低头看见她掌侧被地锚链擦开的一道口子。

“手给我。”

“先看检查片。”

“片又不会流血。”

唐胶从衣袋里摸出软布和绷带，托着她的手包好。兜灯没有抽回去，另一只手仍举着那张检查片。片面干净，没有新的擦痕。

她把结果递给外面的工人。

“可以接低速循环。”

最后的固定由本地工人共同完成。唐胶只标出需要继续观察的位置，兜灯则在主控旁加上临时止动，让万机馆在重新校正前无法把转子推入高负载。两人都在作业板上留下姓名，也把下一次复核的位置完整保留下来。

夜色压满外港时，纪存站在万机馆内街，合上低速启动开关。

六米巨环发出一声沉重低鸣，随后缓缓转过第一圈。安装位没有跳动，适配座也没有滑开。冷却流重新进入旧管路，从舰侧一路向内推进。

沉寂了一整天的通风口逐个吐出凉风。展柜旁的旧宣传页轻轻掀起，维修间闷住的热气被抽走，厨房门口那团蒸汽终于顺着走廊散开。跌跌追着一张被风吹动的餐巾纸跑了半条内街，机器犬把纸踩住，自己先趴在恢复凉意的地板上。

低速试转通过。

万机馆可以继续航行，足够前往工务城。可是全舰各段还没有重新校正，新的转子也没有接受加速、急转或战斗负载。兜灯把限制留在主控最醒目的位置，纪存没有关掉。

“平着开，慢慢走，能到下一站。”唐胶从作业道里爬出来，拍掉衣服上的金属屑，“真要挨打，先躲。后面的全舰校正不是我能签的。”

兜灯跟着出来，伸手摘掉他肩上一片包装纸。

“这句话可以写进报告。”

“前面那句不写？”

“那句写给纪存看。”

工房送来的夜宵摆在没拆封的零件箱上，不过是热粥、咸菜和很快见底的煎饼。工人们坐在舰侧和内街门口吃，谁也没有把食物翻来覆去检查。货柜领袖收起作业骨架，停在外港补充能源；它答应继续护送万机馆前往工务城。无牌一号由竞技场维护者按正常运输流程送回公共整备位，临时挑战席已经断开，攀轨模块还没卸下。馆守Z坐在舰侧作业平台旁，黄色巡展臂安静放在腿上，原装右臂的位置仍旧空着。

旧守护者从万机馆广播里听了一会儿碗筷碰撞声，才开口。

“下次开馆，能让木桶街的人也上来吗？”

兜灯抬头看向馆守Z：“你想见他们？”

“我想让他们看看，我们把风接回来了。”

纪存没有替它回答，只把这句话留进下一次开馆要做的事里。

他端着一碗已经不烫的粥走到内街尽头，接通七海的私人通讯。画面里没有公务界面，七海仍在原城，身后只亮着一盏临时通道灯。

“修好了？”她问。

纪存看了一眼主控上仍亮着的限制。白天的胜利太痛快，他很想只回答一个“好了”。

“能走到工务城。”他说，“不能打。舰侧刚吃过重载，转子也只通过低速试转。再加速会发生什么，我们还不知道。维修储备也用掉了大半。”

七海看着他，忽然笑了一下。

“这次没等我从背景警报里猜。”

“以前也没每次都瞒你。”

“你每次说这句话，通常都已经瞒了一半。”

纪存把主控限制和只剩一小截的维修储备一起转给她，没有删掉任何红色提示。七海的笑意停留了一会儿，随后被另一组不断弹出的公开记录压了下去。

唐胶公开的维修页没有泄露收藏者姓名，却公开了中间版本、旧批次磨损和全尺寸复验结果。平台沿这些真实的版本关系反向检索，在木桶街外环的代管停放仓里找到四台使用同一基础骨架、却留下不同改装记录的飞行实机。

四条服务同时变成冻结状态。

“它们把四台机锁进了同一批回收名单。”七海把位置和冻结通知发给纪存，“我不能解除服务，也不能批准它们出动。平台回收队已经接单，正在往停放仓走。”

纪存放下粥碗。

“你还留在那边？”

“今晚是。”七海说，“去工务城的票已经改好。这次有些话，我到现场说。”

两人的通讯没有来得及正常结束。

木桶街外环的四间停放仓同时断掉平台维护电源。黑暗只持续了一瞬，四套本地系统先后自行亮起。

第一间仓里，喷气叛星猛地扬起双翼，发动机用一串轻快又尖利的高鸣顶开沉重仓门。它的声音从门缝里抢先钻出来。

“关掉保养就想让我趴着？门开了，我自己飞。”

第二间仓里，重涂机“死锁”没有抬翼。它伏低身体，一把扯断锁在胸前的维护牵引，金属落地声短而沉。它的声纹像砂砾擦过钢板。

“旧名字还在。敢来拿。”

第三间仓没有传出撞击。重涂机“镜星”先点亮电子干扰，仓内所有敌我识别灯同时交换位置。它用两层方向相反的声音平静开口。

“你们的识别表，错了。”

最后一间仓里，重涂机“雷翎”只展开一侧侦察翼。远方回收队的灯刚出现在高架尽头，它已经转动远射组件，清晰的声纹切入另外三台机的频道。

“东侧有队伍接近。不是来维修的。”

四台同骨架实机做出了四种完全不同的动作。平台试图用同一条冻结命令把它们归进同一个货号，却同时惊醒了四个声音。

万机馆刚刚恢复的内街警报再次亮起。

这一次，警报来自木桶街的天空。
