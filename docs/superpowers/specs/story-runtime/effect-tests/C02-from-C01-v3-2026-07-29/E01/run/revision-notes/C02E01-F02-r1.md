# C02E01-F02 第一次返修要求

保留现稿已经成立的部分：

- 从馆守Z脚边到全尺寸工房，再到模型维修桌的连续尺度变化。
- 公共转子正在维持街区生产，不能当作仓库奖品直接拿走。
- 修件母亲、迟到零件、儿子留下的步骤与仍站不稳的结果。
- 小零件年份只提供搜索方向，不证明巨件兼容。

必须重建的前置因果：

1. 本地工房和兜灯先完整检查万机馆原转子。用一组玩家看得见的大证据说明：
   转子主体经历C01高热后已经永久变形并刮伤循环外壳，轴心也失去同心；
   若只换轴承或修外壳，变形主体再次转动仍会破坏整条循环。
2. 明确他们已经比较过当天可行的直接办法：校正外壳、修轴、更换轴承和原件重加工。
   原件重加工并非永远不可能，而是必须返大型铸造厂、工期超出万机馆当前停泊能力，
   因此此刻需要一套完整替换总成。
3. 由上述诊断自然进入六米公共转子，而不是角色先认定要整件再去寻找理由。
4. 保持工程解释简短、可视，不新增术语。重点仍然是三种尺度、母亲和唐胶从
   “拿走部件”转成“寻找被官方手册跳过的版本史”。
