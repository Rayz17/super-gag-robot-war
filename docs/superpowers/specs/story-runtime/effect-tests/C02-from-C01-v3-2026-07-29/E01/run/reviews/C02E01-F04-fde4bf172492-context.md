# C02E01-F04 平台把救命件变成限时拍卖

全尺寸适配座通过试验时，木桶街的人还围在失败件旁边看那道翘痕。唐胶公开的维修页已经越过街区，被旧机收藏者、工业件商人和巡展舰爱好者一层层转发出去。

六米转子旁的旧货屏随之亮起。

原本无人问津的退役总成突然多出一排竞价者，价格连续上跳，唯一可选的运输方式也变成了平台货运。十二轴运输架的远程维护灯由绿转红，外环高架两头同时响起装卸车的进站提示。

本地领班没有说平台在抢木桶街的东西。他从运输架侧面扯下一块沾满油灰的旧租牌，擦出两行已经褪色的字：转子退役时由平台买下，木桶街以低租金长期借用；十二轴运输架和远程维护也由平台承担。

这些年，正是这份安排让一件卖不掉的旧总成留在这里，为周围工房送风。平台重新找到买家后，本来就有权收回。

领班的手指停在租牌下方一个画着日轮的标记上。那是留给木桶街的一天：街区可以按原定条件优先承接，也可以停下各家机器，接入替代设备，再把转子安全交还。

如今屏幕上的日轮被一道红线划掉了。

“聚众干预，远程保护。”领班念出新出现的提示，抬手按下本地急停。十二轴运输架没有反应，反而落下四组远程夹具，把仍在低速转动的巨环锁得更紧。

平台把公开教学、围观测量和不断上传的试验记录一并判作了资产风险。保护条款一启动，原本的一天被直接跳过，先装货，补货安排等提走以后再谈。

竞价装卸机沿外环高架驶来。它们没有撞向工人，也没有破坏工房，只依次占住两座转辙台和岸侧绞盘，把从运输架到封闭货道的整条路接成平台的独家线路。

街上的争执因此分成了两边。有人指着屏幕上的高价，说平台确实是所有者；更多人则指着还在运转的抽风管，问没有那一天，谁能在装卸机抵达前让整条街安全停下来。

纪存没有跟着竞价。

他把刚才完成的公开诊断、万机馆的重载空间和外港航路并排投到工房大屏上。

“方法和失败记录都留在木桶街。你们要留，就用这一天优先承接；你们要换，万机馆负责把替代设备运来，火种货柜领袖负责进街转运，跨城路上我们护送。”纪存指向租牌上被划掉的日轮，“等街区停稳，万机馆再拿公开诊断、重载和护航向平台承接这套转子。所有权照旧，巨环不能先走。”

这不是更高的即时出价，也没有让木桶街出售不属于自己的东西。纪存把万机馆排在街区优先权之后，把转子的转移与替代设备到位绑在一起。可这项交换要成立，首先得把被跳过的一天拿回来。

第一台装卸机已经开始收紧运输架夹具。

纪存放大外环图，没有把攻击标记放在转子上。他依次点亮十二轴运输架、两座转辙台和岸侧绞盘。运输架决定巨环能不能离开工房；第一座转辙台接通高架；第二座决定货物驶向木桶街岸线还是平台封闭货道；绞盘控制最后一段坡道。少拿一处，装卸队都能绕开街区。

“先让它停在原地。”纪存说，“我们夺的不是转子，是那一天。”

唐胶把试制记录推给领班，没有替他表态。

“我把人招来了，这个结果算我的。”他说，“可围着一张维修图看，不该等于谁在破坏机器。”

领班看过身后仍在工作的工房，又看向各处正在收拢的装卸机。他抬手扳下街区作业灯。原本犹豫的人开始把料车退出高架下方，为纪存标出的三条行动线让路。

纪存同时拨通七海的私人通讯，把旧租牌、消失的一天和装卸机货号发过去。

七海没有先问他准备怎么打。她逐个看完货号，又把几条退役资产记录叠在一起。

“平台确实买了这套转子，也确实维护过它。”她说，“所以保护系统会默认平台可信。问题在这里。”

她点出所有装卸机上相同的货号前缀。公开维修页让资产重新升值后，回收链先把聚集、教学和第三方测量归进风险，再用保护条款越过原使用者的停机期。平台会付收购和维护成本，也会让使用者来不及找下一台机器。

“能让系统恢复那一天吗？”纪存问。

“我没有权限停掉它，更不能替木桶街批准你动手。”七海回答，“我只能告诉你，这些机器最终都要经过同一条回收线。你要截的是它们汇合以前。”

她把回收线的去向编号和保护触发记录发上公共维修页。发送完成后，她屏幕上那条返回内部复核队列的通道变成灰色。七海看了一眼，没有撤回。

“这次我把看见的东西放在外面。”她说，“现场怎么做，你来决定。”

纪存把她找出的汇合点加入战术图，装卸队的路线立刻从一片红色箭头变成三股清楚的车流。他没有向七海要第二句话，转身把目标分别交给馆守Z、火种货柜领袖和街区愿意开放的机体。

外环下方，木桶街公共竞技场的整备门向上升起。

八米高的全尺寸竞赛实机站在门后。它是玩家模型机“无牌一号”，由竞技场和历届参赛者共同维护，没有固定驾驶员。缩尺模型只为改件提供形态和连接关系；眼前的底盘、关节以及靠墙排列的模块，全都是真实制造、反复比赛过的全尺寸设备。

竞技场维护者把公开挑战席推到场边，却没有立刻接线。

“这台机不是谁招招手就能开走的。”他看向领班，也看向刚刚主动让出道路的工人，“不过你们的方案，我们听懂了。今天开一次临时实机挑战，替木桶街把该有的停机时间打回来。”

几名在场维护者依次确认，挑战席上的操纵画面才亮起。玩家坐入竞技场提供的标准操纵位，获得本次出动权。纪存的声音进入战术频道，却没有接管任何操纵杆。

无牌一号的低权限竞赛AI唤醒，面前展开三套实机配装。一套有夸张的展开翼和过多外饰，刚被吊到接口前，AI便熄掉对应位置，拒绝接受；那套东西在竞技场灯光下漂亮，却会卡住外环狭窄的侧轨。

AI转动头部，看向另一侧的全尺寸攀轨模块。四组轨道夹和辅助轮随之亮起绿灯。它主动接受了这套不够华丽、却适合眼前道路的配装。

吊臂把攀轨模块扣上八米实机。固定销逐一落下，无牌一号踏出整备门。玩家第一次真正控制它抬脚、侧身和夹轨；纪存只在战术图上划出第一座转辙台的位置。

“别追车。”他说，“先改它们要走的路。”

装卸机正从高架正面压来。玩家让无牌一号攀上外侧支柱，轨道夹咬住侧轨，八米机体悬在高架之外横移。平台机器伸出推臂封住正面，无牌一号便收起一侧轨夹，从横梁下方绕过，把抓臂扣上第一座转辙台的手动杆。

道岔轰然转向空置支线。

前列装卸机被迫改道，后车还在沿回收链汇合点加速。火种货柜领袖从地面货道驶入，先让两辆载着工房材料的车穿过路口，才在它们身后完成作业变形。货柜两侧展开成长形承载骨架，轨道夹从下方锁住支线。

“路先留给每天用它的人。”货柜领袖说。

它把展开的骨架横进空置货位，稳稳截住整列装卸机。平台车辆没有被撞毁，却无法倒回第一座转辙台。

玩家趁空档让无牌一号继续沿高架外侧前进。第二座转辙台已被远程机构锁死，AI只标出承力位置，没有代替玩家动作。玩家松开后侧轨夹，让机体绕到道岔下方，再用全尺寸抓臂托住转轨梁，拔出平台落下的锁销。巨大的道岔被推回木桶街岸线。

岸侧绞盘旁，馆守Z已经站稳。它仍缺少原装右前臂，也不能飞。黄色巡展臂只托住绞盘链条，完整的左手握住手动轮。兜灯检查过受力方向，向旧守护者点头。

“能转。别拿工作臂硬扛车。”

“我只是把门关上。”旧守护者从胸前扬声器回答。

纪存看着三股车流在七海给出的汇合点前挤成一线，等最后一台街区料车离开岸坡，才下令合拢。馆守Z转动绞盘，沉重链条横过岸侧入口；货柜领袖同时收紧支线骨架；无牌一号把第二座转辙台压回本地止动位。

三处平台线路同时断开。

领班冲上十二轴运输架，重新按下本地急停。这一次，远程夹具停止收紧，平台提货标记由红转灰。工房终端上的日轮重新出现，从完整的一天开始计时。

平台仍拥有六米转子，竞价也没有取消。它的装卸机被困在支线却仍保持运转，运输架上的保护装置和固定索同样完好。纪存没有让任何机体靠近巨环，更没有开始拆管。

他把运输架、两座转辙台和岸侧绞盘的现场控制交给领班。无牌一号仍由玩家握着操纵，攀轨模块扣在高架外侧；货柜领袖以展开骨架守住道路；馆守Z的左手没有离开绞盘。

木桶街没有因此得到不属于自己的转子。它只重新得到租牌上本来就有的停机、承接和寻找替代设备的时间。

纪存望着重新亮起的日轮。

“现在再决定它该怎么走。”
