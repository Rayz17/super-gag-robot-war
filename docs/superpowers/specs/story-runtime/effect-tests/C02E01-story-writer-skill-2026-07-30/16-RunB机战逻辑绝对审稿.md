# C02E01 Run B 机战逻辑绝对审稿

> 审稿身份：独立机战玩家、机器人文化与游戏制作/逻辑审稿人  
> 审稿范围：只评价《救命零件，限定发售》Run B 正文及必要因果、连续性边界，不以作者意图、字段完整或其他稿件作为通过理由。

## 总判定

`PASS_FOR_USER_READ`

这是一话可以独立交给用户首读的机器人故事。它把模型文化、地方修理史、品牌标准化、运输安全和万机馆的生存时限压进同一件二十余吨载荷，并让四个机器人单元用彼此不可替换的身体动作解决。核心冲突不是误会，也不是谁忘了关开关，而是同一运输框在唯一岔口只能去往两个相反终点：江薇要把它送回已验证的应急位，纪存必须让它在当天跨过万机馆交付线。双方都聪明、都在保护东西，也都为自己的选择留下了真实代价。

## 一句话战斗

纪存必须在演示桥回收的唯一岔口，让无牌一号用伤痕红箍移开标准零号的前向约束，护送火种货柜领袖背着转子走完旧桶运外圈，再由单臂馆守 Z 把万机馆交付门变成最后一段路。

这句话同时包含争夺物、地图、双方目标、玩家动作和胜利条件，玩法已经成立。

## 四个机器人单元

| 单元 | 清楚度与魅力 | 身体人格与本话生命 |
| --- | --- | --- |
| 火种货柜领袖 | 首登先用动作立人：一手救限定盒，一手护二十屉蒸笼，严肃地把两种载荷都判为“完好”。十四米载具、人形与四足作业门架的功能关系清楚，喜剧不损领袖气。 | 它的欲望是完成自己接受的交付，而非听纪存口令。它扫描旧轮压、请求侧向支撑、逐足确认落点，以四点承载把承诺走完。结尾回到街口等下一份委托，仍是有去处、有职业生命的独立机器人。 |
| 无牌一号 | 本话最有魅力的机体。褪色蓝甲、黑色替膝、横灯、身体左倾和两道宽得“很没礼貌”的红箍，形成一眼可认的轮廓。 | 它先拒绝安装，待林澍调低支座并复查锁销后才接受；过弯时再次由黄灯转绿，自主确认“可继续”。胜法不是突然变强，而是把历次伤损留下的偏置变成滚罐、侧护和移位能力。首伤、当前校准和名字是否仍叫“一号”都进入长期状态。 |
| 标准零号 | 白甲、黑色 0 字、无垫片严丝合缝的模块、路线翼、牵引架、制动轮和地钩，和无牌一号构成极清楚的标准体/地方改装体对照。 | 它与江薇构成完整的有人驾驶机器人单元，正面欲望是让人、机与唯一转子一起回到可验证的安全结果。全程只牵引、制动、封路和报载荷，不靠恶意攻击制造 Boss 感；失败后仍保住专业判断、设备争议和明日继续谈的资格。 |
| 馆守 Z | 十八米、原右臂缺失、黄色巡展作业臂不能当拳，这三件事在开头用泊位锚和孩子提问重新建立，高潮无需解释。 | 它不是纪存的遥控工具。纪存只解除门保险，它自行扫描门根、载荷与路线后才转门；唯一左手接住八米标准零号，黄色作业臂继续扣住门轮，恰好把残缺身体写成不可替代的终局构图。它没有提前获得新右臂。 |

四者不能互换：货柜领袖负责承诺与四点承载，无牌一号负责侧向几何，标准零号负责前向约束与安全反对，馆守 Z 负责舰体末端和巨型接应。机体数量因此构成参战感，不是陈列数量。

## 模型锚点

模型没有提供能量、身体或现实改写。它只保存三类信息：

1. 异色补件、垫片和反装桶箍留下的维修先后；
2. 四张失败记录与唐胶旧认证暴露的错误“原状”叙述；
3. 与全尺寸模块机同构的偏置假设。

真正参战的是木桶街原有的八米底盘、三套全尺寸模块、林澍的实机安装、锁销复查和真载荷测试。红箍第一次被拒绝，调整支座后才接入；过弯能力也必须在发酵罐、运输框和四点读数上重新证明。因此不存在收藏模型放大成巨机，也不存在模型数据绕过工程复核。

## 控制、尺度与状态

| 项目 | 绝对判断 |
| --- | --- |
| 所有权与交割 | 转子跨线前由几家老工房共有，交付地由共有人确认；旧物牌在跨线后才交给纪存。公司控制演示桥、路线接头和标准零号，但不拥有转子、无牌一号、货柜领袖或万机馆。 |
| 操作权 | 林澍驾驶无牌一号，机体决定模块接受与继续；江薇驾驶标准零号；货柜领袖自主接受委托与道路；纪存只能提出路线、承担万机馆代价并解除交付门保险；馆守 Z 自主执行舰边动作。没有一处把“看见办法”偷换成“能命令所有机体”。 |
| 尺度与承载 | 百米万机馆、十八米馆守 Z、十四米货柜领袖、两台八米机、近六米且二十余吨的转子可以稳定同框。运输框从起吊到安装始终保持四点支撑；无牌一号只修正侧倾，标准零号只提供前向约束，二者都没有被写成单机凭空承受全部载荷。 |
| 空间 | 工房起点、演示桥、旧失败点、唯一岔口、桶运外圈、接岸缺口、万机馆交付线组成可画成俯视地图的单链。桥回收后岔口落锁，地图从可退回状态永久切成旧外圈状态；交付门再把最后的水面缺口改成道路。 |
| 时间 | 临近中午靠泊，午后起运，夕阳时跨线，安装持续到夜里。安全回收、复核与重新排路会耗尽当天路线，安装还需数小时，次晨泊位期限与数周后的下一班重载共同关闭“明天再来”。 |
| 万机馆状态 | 开场是不适合再做长航、最多再短挪一次的循环故障；转子安装后只恢复有限稳定航行。交付门轴因越过维修止点而变形，万机馆当晚仍不能离泊。胜利解决循环危机，却没有免费消除泊位、门体和维修债。 |

## 冲突必然性与和平解

正文已经排除足以消灭整场冲突的普通办法：

| 普通办法 | 为什么不能同时满足双方 |
| --- | --- |
| 先安全回收，明天再运 | 回收后当日演示结束；重新排路时已经天黑，数小时安装赶不上次晨泊位期限，下一班同级重载在数周后。 |
| 在弯段停下慢慢谈 | 演示桥弯段没有可承重停点，安全停机只能回到应急位；回到那里就会错过唯一岔口。 |
| 让标准零号脱开，货柜领袖自己走 | 回收中的桥面后退与载荷侧转同时存在，前向约束此时不能安全解除；货柜领袖还需要无牌一号的侧护和万机馆末端接门，不能用一句“自己搬”跳过三项物理条件。 |
| 让标准零号和平改为协同制动 | 这要求江薇主动把公司机和唯一载荷带进她尚未验证的旧路，不是同时完成“已验证回收”和“当日交付”，而是让安全方先放弃自己的目标。她被迫进入旧路后报压力、放慢步幅和切钩，是事故已发生后的损害控制，不等于此前路线已经得到安全认可。 |
| 报警、改产权或事后追责 | 这些能决定责任，不能改变桥正在回收、前梁仍受零号约束、岔口即将落锁的物理状态。 |

江薇在无牌一号成功后立即承认结果、允许保留校准，证明她不是为了抹掉地方机体才开战；纪存在询问共有人、林澍与货柜领袖后才选择改道，也不是擅自处分他人身体。冲突由两个不能并存的终点点火，双方的合理性成立。

## 玩家体验与机战爽感

玩家先通过纪存作出不可撤回的路线选择，再围绕三个连续目标行动：

1. 保持运输框四点为绿，取得从标准零号前向约束中侧转的空间；
2. 用无牌一号的红箍管理外倾，让货柜领袖逐足走完旧外圈；
3. 放下交付门，移开封线的标准零号，让载荷跨过黄色交付线。

地图会实际变化：演示桥后退、岔口升起又落锁、旧路成为唯一前路、接岸缺口被舰门填成桥。第一种安全打法确实有效，对手也据此调整；人物关系随后改变战术，江薇一边反对一边报告真实载荷，无牌一号的伤损身体完成不可替代的旋转移位，馆守 Z 以单臂完成巨型接应。胜法完整回收了模型修理顺序、红箍偏置、四点承载、巡展作业臂和交付门。

最值得动画化的画面是交付线亮起前：百米万机馆压住远景，单臂馆守 Z 左手吊住标准零号、黄色作业臂扣住门轮，受伤的无牌一号跪在门板侧护，火种货柜领袖背着低速旋转的暗银巨盘跨线。这是只能由巨型机器人、运输重量和残缺机体共同成立的画面。

制作成本也集中在值得记住的对象上：一套街区/旧罐/演示桥地图，四台动作语法不同的机器人，一次交付门巨构变化。没有为了数量另开无关战场。

## 本话边界

- C02E01 的本话任务完整结束：转子交割并安装，万机馆取得有限稳定航行；唐胶撤回错误认证，地方维修史重新打开；模型与全尺寸机体的正确关系已经通过实战建立。
- 后续拳赛没有被提前消费。本话的对抗是围绕载荷方向、滚箍侧护和制动的低速物流战，没有拳台、拳王胜负、竞技荣誉或正式拳招结算。无牌一号证明的是“怎样带着旧伤承载”，不是提前赢下一场拳赛。
- 没有提前正式入队。货柜领袖完成一次联合委托后停在街口等待新工作；无牌一号留在木桶街卸载、焊箍并继续决定名字；标准零号仍归公司与江薇。单次协作没有被偷换成常驻席位。
- 四台同骨架飞行机只以高架广告剪影发出下一话信号，没有展开人格、控制权或战斗解法。

## 首读注意力

- **最想继续看**：唐胶把四张失败记录重新排序，厂房阴影里的全尺寸无牌一号随后走出来。模型文化、逝者维修史与真正能上场的机器人在这一刻接成同一条因果。
- **最强回报**：无牌一号不是复原成标准姿态，而是用没有被抹掉的偏置越过旧失败点，并在高潮用同一身体语法移开标准零号。
- **最接近走神的位置**：旧外圈中“宽轮压/窄轮压”的再判断发生在岔口争夺之后、交付门高潮之前，属于一次额外的工程停顿。它因江薇主动报险并放松制动力而同时完成对手人格转折，尚未形成阻塞性拖沓。

## 非阻塞制作风险

1. “万机馆能留在应急位”容易让人误读为百米舰体能进入演示桥应急位；分镜和台本应明确是万机馆继续留泊、运输组退回应急位。
2. 无牌一号在旧失败点最初由右箍贴罐、左侧贴框，岔口推挤段一度把贴框/贴罐的左右称谓交换。Reader 的总体运动仍可理解，但进入战斗台本前必须统一朝向，避免红箍在镜头间穿帮。

这两项属于台本空间标记，不动摇本话发动机、胜法或首读资格。
