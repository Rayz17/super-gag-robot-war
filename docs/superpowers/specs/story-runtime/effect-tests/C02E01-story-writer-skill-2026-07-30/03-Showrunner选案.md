# C02E01 Showrunner 选案

> Status: `selected_for_causality_preflight`

## 选择

采用方案 C《冠军没有出厂姿势》作为唯一主发动机。

不采用方案 A 作为主案，因为“平台运输、追车、巨环脱架、多人接停”与此前已经失败的 Creative First 稿过近，难以检验新 Skill 是否真的创造了新戏。保留它的一个功能：转子必须在当日完成一次真实的全尺寸交付验证，而不是赢了口头名次便自动装舰。

不采用方案 B，因为“街区倾覆、众人抢险、巨舰作配重”虽然奇观更大，却会再次把开篇推回连续救援，也很容易诱发复杂力路、建筑结构和微观工程说明。其视觉只保留为未来城建型关卡素材，本话不用。

## 选案后的戏剧核心

木桶街拥有万机馆需要的退役转子，却没有任何现成设备敢为百余米旧舰完成交付。负责这套重载系统的模块赛事公司提出一场公开的全尺寸交付演示：标准零号用官方模块把转子送到万机馆，借此取得整条街的模块数据和长期品牌权；若万机馆接受赞助，转子当天免费装舰。

无牌一号原本只是这套系统的地方测试底盘。亡子留下的模型和失败记录证明，本地人早已用它试过另一条路；唐胶当年为了让模型取得正规资格，却把这些尝试认证成“标准零号的近原状样品”，让赛事公司有理由宣称所有本地改装只是品牌试制。

纪存真正受到的诱惑是：只要把单臂馆守 Z、受损万机馆和无牌一号一起包装成“标准修复限定版”，所有迫在眉睫的维修都有人买单。他最后选择以万机馆真实状态承担无牌一号的试运风险，把选装和是否保留首伤的权利交给无牌一号与本地操作者。

## 与 C02E03 的差异

本话不是正规竞技章，不使用回合擂台、裁判判分、拳赛晋级、胜负奖金或“老将学会新拳”的结构。

它是一场会被对手恶意改写的工业交付演示：

- 前段让玩家在街区立体物流线上试装并护送巨型转子；
- 对手在发现无牌一号足以否定“只有标准方案能交付”后，启动远程回收，把动态路线收拢为品牌独占通道；
- 后段转为争夺无牌一号身体控制、转子去向和现场数据的实战；
- 玩家不是为了冠军头衔，而是要让一台没有正式名字的机体完成一次不会被赛后清零的真实交付。

C02E03仍可保持传统机器人拳赛的规则、宿敌、观众、输赢与老将尊严，两话不共享情绪发动机。

## 必须保留的高光

1. 开场让木桶街具有双尺度生活：百米舰挡住广告与阳光，巨构物流和模型店在同一条街上运作。
2. 姚岚不是控诉者或圣母。她接着完成儿子的模型，却主动否定“替儿子赢”这一目标；她提供失败顺序，不提供天才遗稿。
3. 唐胶必须承认自己曾真心帮助别人，也曾享受认证权带来的便利和名声。他的现实损失是撤回旧认证，使一批旧寄售与赛事履历需要重验。
4. 火种货柜领袖先履行承运职责，待对手要求它抛弃载荷或故意收桥时才拒绝。它帮助的是“载荷与道路”，不是先天站队。
5. 无牌一号的首个玩家模块、首伤与拒绝覆盖必须成为后续身体史。
6. 高潮保留“转子成为巨大外置飞轮”“火种货柜领袖成为移动路线”“馆守 Z 转动交付门而非替新人打赢”三幅图，但具体动作顺序由因果预演与主笔重新决定。
7. 纪存与七海的关系动作是他在签下风险前承认自己差点接受赞助，不是事后报平安，也不是让七海远程许可。
8. 本话胜利必须完成合法交付、实物复核和全尺寸安装；不能以比赛结果代替工程。

## 需要因果席回答

1. 谁真正拥有转子，赛事公司为何有权组织交付演示、远程回收或控制路线？
2. 木桶街主动邀请万机馆的具体发起人是谁，为什么此前不能直接说明条件？
3. 万机馆为何不能等待另一套运输设备或让馆守 Z、货柜领袖直接搬走转子？
4. 标准零号及赛事公司为何在演示中升级为实战对手，怎样避免一键断网解决？
5. 姚岚、唐胶、陆衡各自提供的信息如何严格分层，避免模型直接决定全尺寸工程？
6. 无牌一号的低权限 AI 怎样作出可见选择，又不突然成为成熟机魂？
7. 巨型转子作为外置飞轮在视觉上成立到什么程度，怎样避免详细机械计算？
8. 高潮后谁签收、谁复核、谁安装，如何用少量动作说清而不写行政流程？
9. 这一事件如何只露出四台飞行机冲突的钩子，不提前消费 E02？
