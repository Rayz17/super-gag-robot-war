## 1. 因果脊柱

战斗段只使用三处可见空间：

```text
演示桥：[承接位] <- 安全回收方向 <- [旧失败点 / 唯一改道口]
                                      |
                                      v
                               旧桶运外圈
                                      |
                                      v
                         万机馆交付门 / 交付线
```

1. 开场、转子复核与赞助诱惑保持不变：万机馆只能占用外泊到次日清晨，当前循环状态不适合再做一次长航；当天只有赛事公司操作的演示桥能把二十余吨运输框送到交付方向，下一次同级承运要等数周。
2. 姚岚交出失败顺序，唐胶撤回旧认证，老工房决定用真载荷复核地方改装；纪存提出红箍，林澍与无牌一号经实际调整后接受，火种货柜领袖接受“把转子送到万机馆”的联合委托。
3. 起运前，所有人共同确认演示桥的可见边界：偏移越旗便连续退回应急位，弯段没有可承重停点；旧失败点之后只有一次转入旧桶运外圈的机会，退回承接位后若想再进外圈，必须重新走一遍演示桥。
4. 当天剩余时间只够完成这一次交付；安全回收、落地检查与重新布置会耗尽公司的当日路线，无法再起第二趟。转子越过万机馆交付线前仍归老工房，工房不能提前安装；安装又需要数小时，因此回收等于错过本次交付窗口。
5. 无牌一号以保留至今的偏置和红箍越过旧失败点，运输框四点支撑始终稳定；这个成功同时证明它能为旧桶运外圈提供侧向支撑，也触发演示桥对机身偏移的安全回收。
6. 江薇承认过弯有效，并明确允许无牌一号保留当前校准、把校准与数据争议留到以后；她仍坚持整组随演示桥退回应急位，因为这是她能确认承重、制动和落地的唯一安全结果。
7. 纪存据此看清代价：接受回收可以保住校准和载荷，却会让未过交付线的转子留在老工房；万机馆到次日清晨便失去泊位，既拿不到数小时安装时间，也没有另一套承运设备，随后只能带着不稳定循环离开或原地失去行动能力。
8. 纪存主动选择在唯一改道口尚未错过时走旧桶运外圈，并承担旧路承重、红箍受伤、公司设备争议及交付门损坏的后果；老工房确认交付地仍是万机馆，林澍确认无牌一号可继续，火种货柜领袖据此接受新道路。
9. 江薇驾驶标准零号扣住运输框前梁并横在改道口，把整组牵回应急位。标准零号必须保持前向约束：演示桥正在弯段回收，若它放开或允许货柜领袖横切，二十余吨载荷会在没有安全落点时同时承受回收与侧转；它阻止的是未经验证的改道，不是在夺取转子。
10. 纪存方只争夺“让载荷安全转入外圈”的动作空间：无牌一号以内侧红箍承受外倾并移开标准零号，火种货柜领袖保持四点支撑向交付门前进，标准零号持续制动、封路和尝试把前梁带回应急方向。
11. 纪存放下可能变形的交付门，馆守 Z 自主确认后以黄色作业臂把门降到承载位；无牌一号清开交付线，馆守 Z 接住被移开的标准零号，火种货柜领袖背负低速旋转的转子跨线，形成原终局大图。
12. 老工房在跨线后交出旧物牌，纪存签收，陆衡复核，工房立即开始数小时安装；万机馆恢复有限稳定航行，却因门轴变形当晚不能离泊。无牌一号保留当前校准和首伤，江薇保留安全与数据争议，双方都没有被结算成愚蠢或恶意。

## 3. 阻塞问题与最小修正

### 普通办法排除

| 普通办法 | 当场测试 | 排除原因 |
| --- | --- | --- |
| 等待、以后再谈 | 保留无牌一号当前校准，随回收落地，次日再议 | 校准可以保留，但当天路线在回收、检查后结束；转子未过线便不能安装，数小时安装无法赶在次晨泊位期限前完成，下一次同级承运又在数周后 |
| 中途停机 | 在演示桥弯段停住，再慢慢协商 | 弯段没有可承重停点；安全停机只能发生在承接位，结果等同于失去当天窗口 |
| 拆路线接头 | 让公司退出，货柜领袖自行离开 | 回收中的前向约束一旦拆除，载荷会在弯段同时承受桥面后退与机体侧转；到承接位再拆虽安全，却已错过唯一改道口和第二次起运时间 |
| 换路 | 改走旧桶运外圈 | 这是纪存方主动采用的方案；它只能在无牌一号越过旧失败点、证明红箍可承受侧向力后，于当前改道口立刻执行，不能等回收完成后再补做 |
| 报警、停权、事后追责 | 老工房报警或宣布终止公司操作 | 报警能确定责任，不能改变演示桥正在回收、公司仍控制前向接头、载荷即将越过改道口的物理状态 |
| 让货柜领袖直接搬 | 货柜领袖背着运输框离开演示桥 | 它本来就是承运主体，但转入旧外圈仍需要标准零号解除前向阻挡、无牌一号提供侧向支撑、交付门补上末段；“直接搬”不能跳过这三项 |
| 安全回收与交付同时完成 | 一边退回应急位，一边把载荷交给万机馆 | 两个目标在改道口方向相反；回收终点是演示桥承接位，交付终点是旧外圈之后的万机馆交付线，同一运输框不能同时到达两处 |

### 标准零号的主动性

江薇的最优选择始终一致：承认无牌一号的成功，暂不恢复校准，把人机和转子带回已验证的承接位，再处理产权与数据。纪存方开始横切后，标准零号若主动放开，就等于让仍受演示桥回收力的载荷在弯段失去前向约束；因此它必须扣住前梁、封住改道口并把整组拉回。它失败后留下的是公司设备损伤、路线责任和运行数据争议，不取得转子或无牌一号的身体。

### 战斗一句话

纪存为了在万机馆失去本次交付窗口前把转子送过交付线，必须在演示桥的唯一改道口阻止江薇驾驶标准零号把整组载荷安全牵回应急位，并用无牌一号、火种货柜领袖和交付门共同承担旧桶运外圈的风险。

## 4. 给主笔的肯定式交接

1. 保留现稿开场、赞助诱惑、姚岚失败顺序、唐胶撤证、纪存与七海通话、红箍首装及无牌一号越过旧失败点；前半段只补足“回收后当日收工、旧外圈只有一个当场改道口、跨线后才能安装”三项可见前提。
2. 江薇在触发回收后主动承认验证结果，允许保留当前校准，并提出安全落地后再谈；这项让步彻底排除“公司强制清零所以开战”的旧发动。
3. 陆衡把回收的具体后果报给纪存：错过当日路线、转子不能交割、数小时安装来不及、次晨失去泊位、下一次承运数周后。纪存据此亲自选择当场改道，并预先接下门轴、设备和责任代价。
4. 老工房只确认交付地不变；林澍只确认无牌一号可继续并选择保留；火种货柜领袖自行接受旧道路。任何人都不拔牌、误按、忘带工具或临时越权处分别人的机体。
5. 战斗第一目标是从标准零号的前向约束中取得侧转空间，第二目标是让无牌一号以红箍支撑货柜领袖走完旧外圈，第三目标是在标准零号封住交付线前放下万机馆交付门。
6. 标准零号全程使用牵引、制动、封路和约束动作；无牌一号全程使用偏置、红箍、贴靠和移位动作；货柜领袖全程保护四点支撑；馆守 Z 全程守门、转门并接住被移开的标准零号。
7. 终局保留原大图：受伤偏斜的无牌一号跪在门板上，单臂馆守 Z 一手吊住标准零号、黄色作业臂扣住门轮，火种货柜领袖背着低速转动的巨型转子跨过交付线，万机馆在后方接住载荷。
8. 出站保留原结果：转子交付并安装，万机馆只恢复有限稳定航行且当晚不能离泊；无牌一号留下首伤和当前校准；江薇保留合理争议；四台同骨架飞行机的终幕预告不提前展开。
