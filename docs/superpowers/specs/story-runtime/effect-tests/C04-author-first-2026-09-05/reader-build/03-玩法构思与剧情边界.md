## 本章为什么值得玩

首先是和三台地方旗舰并肩正面打赢外敌；随后走进仍在工作的巨机工房，看见机体、驾驶员和生产者如何生活，为七号配置第一件实用工具；最后把熟悉的主力与百相组成能主动进攻的阵容，击败已经见过我方战法的敌人。奖励包括一个会随舰生活的公共体伙伴、馆守Z的实用牵引背架、远航维修支持和可再次联络的地方驾驶组，不是三旗舰全部加入。

战斗优先检验普通移动、朝向、攻击、预备和身体差异是否已经有趣。不是先把一套五机接力动画写完，再让玩家按按钮依次认领。

## 两场样稿怎样转成玩家经历

### 车间重逢

重逢与争执由ADV完成，玩家不替七海选“支持军方/关闭工房”，也不替韩秀雅选择牺牲百相。两人的核心决定由故事承担。

中间的工房巡访允许自由走动和停留：试用区看普通身体如何工作，装配区看百相，公共体区听七号的问题。主线所需事实在必经场面中自然出现，可选巡访只增加了解、照片和后续对话，不搜满零件或对完档案才能继续。

七号固定选择公共体。此后玩家参与的是它愿意尝试哪件首装工具：维修臂、救援钳或探索传感。三者共用一副约8米主体，不分人格和命运。工具更换由车间完成，不能在战场上无消耗瞬换。

- 维修臂：可在安全工作区修复轻损作业件，换取战后维修便利；不在炮火中瞬间补回主力肢体。
- 救援钳：可整理、夹取散落物和普通障碍，换取多保住一批有明确来处的工房物资；不夹住几十米巨机。
- 探索传感：可检查人员不便接近的狭窄空间，换取设施现状和一处安全通路的信息；不扫描人格、未来或敌人私密记忆。

这些是待逐话正文确定后的模块适配建议，不先写进故事当能力实证。试用需要本人回应和工房安全条件；不合适可退回选择。照相、看百相、与同伴聊天不必转化为战斗增益。

### 百相冲出工房

主家族是正面会战，后段突出百相与断冠的名场面对撞。操控以00c短全队协同回合为基准，编辑计划时现实时间不推进。地图是可滚动的山谷厂区：厂房、出击场、侧路和山坡属于地图本体；不恢复多层圆环迷宫。

敌方要摧毁制造能力，分裂体封路、断冠压制出击口。它的针对性来自第一战实际目击的站位和火力轮换，不来自读取玩家草稿。部署前展示它正在盯防谁的装填空档；战中每轮先冻结敌方意图，再允许玩家规划。正文中的临场惊险，在玩法中体现为事先公开的预备反应或误差，不能执行一半才临时替Boss换目标。

玩家可以尝试至少两种有实质区别的办法：

1. 抢先拆阵：机动与近战主力尽快攻破分裂体封锁，集中火力打断断冠的压制，使百相获得进攻位置。更快，但暴露侧面，防壁与伤机容易承受额外压力。
2. 诱出重击：让重机顶住一处正面，远射机预备惩罚断冠转身攻击；打破一侧攻击能力以后推进。更慢、更稳，工房外围可能承受更多可修复损伤。

两种都不要求“馆守Z第一、社勇王第二、心墙第三”这一条唯一动作序列。角色不会报出完整解题顺序。Reader只是其中一次可信的经历，不是所有合法战法的逐字录像。

百相终击的固定故事事实：韩秀雅决定出击并亲自驾驶；纪存在万机馆提供有限现场导航；冠骨已受过可见损伤；百相抓住并扭断受损部位，断冠带着永久缺损退走。玩家负责造成/扩大机会、取得接近位置、压住反击并选择发动时机，不通过对话选择让韩秀雅放弃决定或把最终控制交给纪存。

这个固定人物高潮不代表整场只能观看。终击应接在玩家已经做成的局势上；前置不成立就仍打战斗，不能强播成功动画。普通攻击也能推进敌方部位状态；正式胜利收束的独有动作须明确为本章作者型剧情动作，不伪装成全局通用技能。终击落空时返回已有战局继续争取机会，不清空我方此前伤势、不免费治疗、不读一遍对白就重开整张图。

## 跨话与所有权

故事分话尚未确定，先不虚构Operation编号表。确定后必须满足：工房围攻中的间歇仍继承战损、制造排期、敌方已知战法和人员位置；标题切换、存档和返回游戏不是新一轮世界。

外围首次击退与后续反攻可以是同一危机内不同操作段；只有断冠真正退离并确认工房保住，才结束本次围攻。制造与巡访可以插在中间，不能为了每话结算而再编一次敌袭。

剧情持有人物动机、关键选择、身份与永久结果；游戏解构持有玩家方法、风险、失败/恢复与状态承接；演出持有画面和声音。谁发现冲突，谁提出问题，不用“演出会解释”补不存在的因果。
