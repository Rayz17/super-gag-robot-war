# C04游戏流程解构：原型工房

状态：creative_candidate，2026-09-07。对应同目录五话纯剧情Reader。

这是本章的玩法设计与纸面推演，不是可玩Build、正式关卡数值或制作验收。沿用`game-design/2026-08-10-full-game-design-candidate-v1/00c-core-game-design-master-review.md`整合版v0.4；不修改原总案。正文是一条代表性经历，玩家可以用其他合法战法达成相同关键结果。

## 一、玩家这一章要得到什么

从“帮助陌生地方守住工房”走到“认识制造者和驾驶员，带走一个新伙伴，再同他们打赢一次正面反攻”。机战是主体验，身体制造是本章独有的生活体验。

固定所得：七号公共作业体随舰；馆守Z获得牵引背架，真正右臂仍未修复；万机馆获得远航承重维修支持；三地方驾驶组成为外线伙伴。三旗舰不永久入队，百相仍属于工房、由韩秀雅驾驶。它们的可操作客援体验不等于永久获得机体。

可变所得：七号首模块、首战和反攻中实际保住的普通物资、战后维修负担。不给每次聊天加奖励，也不让所有胜利都变成未来灾难。

## 三、跨话战斗拓扑

本次候选Operation：`OP-C04-WORKSHOP-SIEGE`，取代旧候选铸环守城映射，不回写正式拓扑表。

| 世界状态 | 所在话/操作段 | 输入 → 输出 | 边界含义 |
| --- | --- | --- | --- |
| W0→W1 | E01 / FIRST-DEFENSE | 已有地方机伤势与工房受袭 → 我方援军投入、七号被找到、错误外运暂停、冠段受伤、敌方暂退 | 首个Encounter结束/Checkpoint；不是围攻胜利 |
| W1→W2 | E02—E03 / WORKSHOP-INTERLUDE | 战损、外线警戒和已有观察记录继续 → 七号具身与模块、百相试装排期变化、有限临时维修 | 制造与生活间歇；无敌人复活、免费全修或学习清空 |
| W2→W3 | E04 / RETURN-ASSAULT前段 | 断冠带着原伤和观察回归 → 轮换遭反制、地方机展开、百相准备、有限导航成立 | Phase转场；不把剧情受压写成强制损失全部玩家优势 |
| W3→W4 | E04末—E05 / RETURN-ASSAULT主体 | 原有位置、伤势、装填和压制 → 玩家攻破封锁、制造攻击机会 | 同一Encounter、同一地图连续；允许Checkpoint |
| W4→W5 | E05 / 终击及清残 | 机会成立 → 冠段永久断离、断冠撤退、局部残敌得到处理、工房保住 | 唯一Mission Clear / Operation End |
| W5→W6 | E05 / 战后整备与出航 | 战果、损伤、模块、物资实际结果 → 机体去向和C05交接 | 可见时间流逝和维修才改变状态，不靠结算清零 |

跨段必须携带：馆守Z左臂/空肩/背架状态；七号持续意识、主体和首模块；百相左侧损耗与未装右臂；三旗舰弹药、屏障损耗、已有伤情；断冠冠部受损与实际观察过的战法；双方存活单位、位置、地图破坏、工房安全区域、已用物资、剧情动作是否已经执行。

`carry_from_state`按上表严格是前项输出。间歇有来源明确的装填和临修，不默认恢复到开章初值。敌方第二次进攻允许外线仍在的敌体重新集结；不能把玩家已消灭的小体以同一身份重生。精确数量属于关卡平衡，不新增物种。

## 四、两场战斗怎样好玩

### 首战：强机各有所长，玩家先享受它们

主家族为正面会战。地图的直接目标是打退压在出击场前的断冠、守住正在使用的厂门。可接受普通外墙受损，关键生产区完全失守则重试，不把每台NPC货车都设为一碰即失败。

可操作：已有主力馆守Z、社勇王、无牌一号、旧拳王，及三旗舰客援。普通警戒机负责远处警戒，不新增必须精操的编队。七号此时没有可用身体，不出现在战棋里充输出。

心墙能挡主要射向但防护并非无限；岛卫适合利用高处射线并承担装填空档；潮墙擅长站稳近战、压迫体量相近的大敌。旧拳王和无牌一号的近战机动可以清路，馆守Z仍要照顾缺臂状态，社勇王提供正面破拆。具体武器/动作只从现行机体资料挑选，不临时给每台机发明一项专属系统。

敌方起始意图先显示已能观测的攻击方向和目标；未知区明示未知。玩家用短全队协同回合安排移动、攻击或有成本的预备反应，不在填写计划时耗时。

断冠首退不是因为一条隐藏轮数到期。需要玩家形成实际火力压力并造成冠部可见损伤。最终收束保留岛卫击伤冠段这一代表性动作；玩家可以先让近战破坏支撑、让防壁保住炮位，或先清高地获得射线，不能要求全员按唯一顺序走格子。岛卫遭压制时必须先解除，不能让动画替它穿墙命中。

胜后不结算整章，只保存这一战确实发生过的策略签名，例如常用掩护对象、装填窗口和主攻方向。断冠学习可见部分，不掌握人物秘密，也不读取玩家下一次草稿。

首战开局、玩家接手当地三旗舰之前，已经发生过一次可见的“心墙掩护、岛卫炮击、潮墙接续”轮换，正如E01的抵达画面。它是断冠第二战能够针对这套旧协作的最低证据，不伪装成玩家自己的习惯。接手以后玩家若没有重用它，敌方只保留这条较旧的观察；不能声称玩家屡次上当。玩家额外采用的战法只在真实记录存在时加入第二战的针对策略。

战前明示岛卫炮击能力是首战关键保护对象。若只是暂时压制，可通过战斗解除；若炮击能力在本次尝试中不可恢复，公开宣告本次战斗失败并回合法Checkpoint，不让Cut-in在失能状态替它开炮。角色并未因此在故事中永久死亡，重试支线不回流Canon。百相终战同理，关键左侧或推进不可恢复时不能继续承诺固定终击。

### 反攻：同一地图，敌我用法都变了

山谷厂区用三个直观区域组织，不做同心圆：北侧高地、中央厂房/出击场、南侧运输道；一侧为山壁，另一侧有可退向谷外的开阔空隙。地图尺寸、格数和距离尚待灰盒，建筑属于棋盘，会遮射线和阻挡通行。山壁不是能凭对白任意穿过的背景。

客援和主力继承首战；百相入场使本段最多八台可控巨机。八台是否造成规划疲劳，列为灰盒重点，不以纸面宣称轻松。优先缩短每台决策、复用上一轮计划、减少同轮强制活跃单位；如仍过载，再提客援编队控制方案，不静默把三旗舰改成只播动画的NPC。

敌方反攻开局展现它已见过的“炮击—掩护—近战接续”窗口。玩家可以主动改节奏。不能先让玩家安排一个很好的分散方案，随后用剧情把所有人强制拉回旧阵形再打败他们。剧情中的第一轮反制作为进入可编辑态前的可见局面；第一次可编辑态起，玩家计划必须受尊重。

本章最多引入一个新决策维度：同时利用各机已有的视野和作用窗口。纪存只帮助更及时地理解队友已经共享的信息；不增加全图透视、不公布不可见敌方答案、不接管其他人的操纵。玩家的全队指挥抽象不等于纪存拥有夺机能力。

## 五、同局势两种战法：纸面走查

### 共用起点

百相在出击场，断冠盯住出口；南侧潮墙被分裂体牵制；岛卫在北侧装填，心墙正在保护厂房与出口。旧拳王/无牌一号在侧路，馆守Z/社勇王有通向出口的可走区域。受损冠段可观察。

这只是初始局势，不假定所有单位一轮内都能到目的地。灰盒必须核实移动预算、武器射程、转向、遮挡与反应时点；距离不够就需要多一轮准备，不能靠Cut-in瞬移。

| 步骤 | 抢先拆阵 | 诱出重击 |
| --- | --- | --- |
| 准备 | 集中近战清南侧封锁，岛卫完成装填；心墙优先保出击口 | 潮墙守住可承受正面压力的位置，机动主力清退路；岛卫转入有射线的高处 |
| 本轮公开敌意 | 断冠准备压制出口；分裂体继续牵制潮墙 | 同样的出口压制意图；不能为了“诱敌”在本轮临时改成攻击潮墙 |
| 玩家执行 | 百相不硬吃封锁，主力先打穿侧翼；若伤害不足，下轮继续争取，不强播成功 | 保住出口的同时让潮墙逼近；以本轮动作影响敌方下一轮评估，不宣称已经骗中 |
| 下一轮变化 | 敌人发现南侧有缺口，公开它准备应对的方向，玩家再安排多面施压 | 若断冠下一轮转向潮墙，岛卫预备惩罚其转身；若它仍盯百相，玩家改用已腾出的南侧直接进攻 |
| 取得机会 | 百相牵动正面，潮墙与岛卫在同一行动窗口施压；分裂体无法同时封两侧 | 重击被顶住或避让后，远射与近战利用已发生的收招空档；不要求敌方必须按诱饵脚本行动 |
| 代价差异 | 快速突入更可能让冲锋机侧面暴露，花费防护资源 | 通常需多一轮准备，外围工房更久承压，消耗装填/防护，但降低百相硬吃正面打击的风险 |
| 固定汇合 | 冠段仍为既有受损部位；百相可接近，敌方反击受牵制 | 同左；不凭选择路线直接写“机会已满足” |

纸面结论：两条策略的决策对象不同，且都有失败后继续调整的分支；未发现必须改变故事才能表达的矛盾。尚不能证明数值可达、两路强度平衡或八机操作舒服。不能将本表叫实跑。

供灰盒落实的两条最短状态走查如下。`T`只指连续的可规划窗口，不是正文时间或最终回合数；任何射程/行动时间不满足条件的步骤都不得强行成立。

| 战法 | T1结束 | T2结束 | 终击可提交的状态；任一缺失就继续准备 |
| --- | --- | --- | --- |
| 抢先拆阵 | 南侧封锁的实际单位被击退/消灭；岛卫完成装填；百相仍在出口内 | 潮墙沿清出的可达路径进入侧压位置，岛卫有直达炮线，心墙防护持续覆盖百相通过出口的时间 | 断冠已在本轮面对实际侧面攻击；百相普通移动预算能到接触位置；冠段裂口可见；反击受压窗口不短于其接近与抓取时间 |
| 诱出重击 | 退路可走；潮墙在可防守位置；岛卫完成装填并取得炮线 | 若公开敌意转向潮墙，执行防守/让位和已准备的远射；实际重击已消耗后才出现收招空档。若敌方未转向，本列不标记成功 | 百相在空档结束前能到接触位置，岛卫仍能维持火力牵制；冠段可见。空档太短时先靠近或继续压制，不能把“诱敌方案”本身当成功条件 |

这里列明待测的行动时序，而不是编造已经存在的伤害/秒数。若灰盒无论怎样调已有合理参数都到不了这些状态，应退回战斗构思调整地形与路线；不升级百相速度、重写机体能力或把敌方冻结更久来保住纸面答案。

断冠每轮真实计划必须先冻结。它可以根据上一轮的公开行动改打法，不能读取当前未提交草稿；“学会了”只影响下一轮选择，不授予必中。预备反应也必须事先表明条件、消耗和能否被打断。

## 六、七号：固定身体，真实而轻的工具选择

Reader使用维修臂代表路线。游戏允许在试用区先看/试三种工具，再由七号认可一个首装方案。约8米公共主体、人格连续、随舰去向都固定；不是四条身体命运路线。

| 首模块 | 本章可见差分 | 后续读取 | 不允许的扩写 |

## 七、高潮、存档和不越权

百相折冠是情境剧情动作，不是练级解锁的常驻必杀。前置至少包括：韩秀雅已驾驶出击；冠段已受损且在百相可接近的位置；压制使断冠不能直接脱离；百相左侧与推进仍可完成动作。

两战档位分别为基准战与章高潮战。反攻允许百相成为唯一我方聚焦机、断冠成为唯一敌方聚焦机，但不靠升档多送一轮行动。折冠归本章作者型事件，不是另一套气势技能；不另收一条秘密气势条。普通移动、攻击、预备和推进仍结算当前总案的真实行动/能源成本，具体值由关卡适配，不在正文增加规则。

终击随全队计划提交，预览标出其接近时间与前置；执行到接触判定点才再次核验。如果本轮更早的公开敌方行动破坏条件，取消尚未执行的抓取/推进，只保留已经发生的移动与消耗，返回可继续战斗的局势并显示原因。不播放成功、不补回已用资源，也不扣未发动的剧情动作成本。接触核验通过后，抓空再抓稳属于一次已经提交的成功剧情事件，不再让播放器掷骰决定成败。

玩家创造前置并发起，剧情呈现抓空、纪存承认看不清、韩秀雅自行改抓、扭断、落地。抓空不再额外掷一次暗骰惩罚已经满足前置的玩家；它是同一成功动作内部的险情。若前置未达成，玩家可以作普通尝试，但不能先扣掉剧情终击资源、播放一半再被无提示判失败。

Full/Skip都必须提交同一结果：冠段断离、百相落地及损耗、断冠撤退、敌群和地图现状。演出播放器只读，不决定战果；跳过也不能提前给胜利。之后清残是确认安全的短收束，可压缩显示已经无关键威胁的地方机行动，不增加重复刷敌的第三场Boss战。

Retry回到玩家选择的合法Checkpoint快照，不自带额外修复；Resume保留单位位置、装填、轻分支、敌方观察和动作执行标记；Replay只看演出不重复发奖励。E04标题切入E05不重新部署，不恢复护盾，不能把围攻拆成两次领取奖励。

对白、特写、全身比例短画面仅在需要辨认意图和大动作时使用。百相折冠是最高演出峰值；其余以地图动作、静态Cut-in和短ADV完成。不开平台/性能/资产采购投票来阻断Reader。
