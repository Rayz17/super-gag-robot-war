## 仍然不应掩盖的问题

**一、13分钟入侵影像尚未恢复。** 当前章正文没有这段，不以元数据写着“保留”冒充读者已经看见。本轮也没有采用06号概要的普通事故预演解释。准确旧稿仍未定位；找到的另一版“七小时后六秒战况”不能证明用户记错。

已向用户提出三种安排，尚未自行选择：

- 推荐留C05：收到疑似未来入侵影像，先给可核对的冲突证据，来源与真伪暂不揭晓。保留C04完整告别，C05开写前必须决定来源限制与后续回收，不能再临场编真相。
- 放回C04章尾：需要改当前邀请/出航尾声；压低这一章的收束感，换取悬念。仅表现影像本身不足以授权真实信息倒流。
- 改为真实提前预警：影像记录远处已经发生的敌袭，比敌人抵达本地早13分钟。能接外战/通信线，但不等同“看见本地尚未发生的未来”，必须让用户明白体验取舍。

根机制目前不支持未经迁移就把未来真实信息发回过去。故暂不在正文中定性，也不继续C05规避这一问题。用户只需决定这条线索放在哪里、要保留怎样的悬念感；不需要替主笔发明技术接口。

**二、体验风险还在。** 陆衡本章主要是可靠工程伙伴，个人戏不强；三旗舰的IP精神有生活与身体体验，但完整地方故事留后，不能声称已兑现全部名场面；试航通知是自然发动，不是强烈惊悚钩子。用户读后若仍觉得中段分散，应调整场面选择，不再给每人加一段履历。
