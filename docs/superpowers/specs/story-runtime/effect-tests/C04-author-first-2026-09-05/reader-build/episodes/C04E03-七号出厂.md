# C04E03《七号，出厂》

七号第一次抬手，先碰到了自己的脸。

手掌太宽，它只看见一片橙色。韩秀雅在旁边叫它慢一点，七号把手放下，又抬起来，这一次停在眼前，翻过来看。

“有几根手指不好动。”它说。

“都能动。你还不习惯。”

调试员没有急着拆掉临时供电。保存七号的原设备已经装进公共体胸部的保护舱，接好新的感官和手脚；人们仍守在两边，听它应答，看它能不能把看见的东西指出来。

纪存站在警戒线外，向它挥手。七号也抬手，过了头，又放低。

“太大了。”它说。

“以后会熟的。”韩秀雅答道。

“不是手。你们都变小了。”

车间里有人笑起来。七号低头，摄像头随着身体转动，终于看见了自己两只脚。

唐胶站在检验台前，手里拿着七号原来那副身体的小模型。模型手指间标着一处磨损，他刚才从维修记录里找到了对应说明，确认那是七号以前搬东西时经常压住的地方。

“先照它熟的来，别一开始就教一套新的。”他把模型放回台上，向调试组比了一个抓握动作。

陆衡看完记录，请本地工程师调整试用设置。他们没有拿模型上的尺寸去套眼前的巨手，而是换了一个七号现在能稳稳抓住的测试块。

第一回还是掉了。

七号盯着落在软垫上的测试块，好像有点难为情。

“我原来会。”

“知道。”韩秀雅说，“我换手的时候，连门卡都掉过。再来。”

它重新俯身。车间里没有人催。等测试块真的被拿起来，唐胶从台边退开，抬手同陆衡碰了一下掌。

“这就行了。”他说。

“还早。你别拿自己的杯子去试。”

“我又没那么傻。”

唐胶把刚端起来的杯子放回桌上。

七号练习起步的时候，兜灯离开了车间。馆守Z已经进了维修棚，本地师傅看过它的右肩和留在舰上的巡展臂，给她带来的消息不算坏，也没有她希望的那么好。

“能做，但这里没有整套合适的现货。”

“找呢？”

“能替你问。接口要重新量，内部损伤也得一并处理。不是接一条能抬起来的手就算修完。”

兜灯点点头。她站在馆守Z脚边，仰头看了半天，才去看工房已经能提供的东西。

那是一副用于牵引的背架。外形不漂亮，能配合馆守Z现有的地锚承担拖带，作业时不必把所有力都压在剩下的左手上。

“先试这个吧。”她说。

馆守Z缓缓转过身，让工人接近背部。兜灯跟上去，把自己画满标记的检修图铺在工作台上。

唐胶回来找她时，本地师傅已经在图上补好了几处尺寸。他看见她有点闷，没开玩笑，蹲在旁边帮她把记录按日期理好。

“问到哪里了？”

“有人肯接着查。”

“那就记下来。下次我跟你一起去。”

兜灯把一支笔递给他。“字写清楚点。”

***

午后，伤机的驾驶员终于轮到休息。

新垣凪站在岛卫三号脚边拍录像。他挑了好几个角度，刚把肩部的损伤避开，同学的通话就来了。

屏幕里是一间正在收拾的教室。有人趴到镜头前，问他身后是不是原型工房，又有人催他把画面转过去。

“先别吵。”一个女孩说，“毕业照的日子定了，你能回来吗？”

凪瞥了一眼维修棚。

“应该能。”

“又是应该。”

“真的。零件都到了。”

纪存和白鸢经过时，正听见他向同学保证。他们没有走过去打断。等通话结束，白鸢才指了指他刚才藏到画面外的肩甲。

“他们会看新闻吧？”

凪不好意思地笑了。“所以我得先发一段好的。”

“那我给你拍。别站伤口前面挡着了，你没它高。”

她让凪站远一点，把工房、岛卫三号和正在忙碌的人都收进画面。凪看过以后，犹豫了一下，没有要求裁掉正在维修的肩膀。

“这张也发吧。”他说。

回库区的路上，白鸢看了一眼纪存。

“你跟七海，也是那么早就认识的吗？”

“你想问什么？”

白鸢笑了。“她今天看见秀雅，高兴得连包都忘了放。平时可不是这样。”

纪存想了想。“平时也高兴。就是有些事没办完，她会一直惦记。”

“你呢？”

纪存指了指前面的车间。七号又在叫人去看它刚拿起来的测试块。

“我现在也有点。”

他们走回库区。白鸢来取自己的资料，本地档案员把找到的制造记录放在两份机体履历旁。记录中的机身特征与无牌一号、完全版王者相符，也能接上后来维修过的部分；仍没有任何一次维护记录显示，有人把白鸢的补充分镜输入它们的控制系统。

她已经在工务城排除过这一种可能，今天得到的是更早的一段证据。

“别再只找数据导入了。”她说，“原来的设计和演出资料，也帮我查一查。我想知道它们当时见过什么。”

档案员问她，找到制作人员的联络方式是否也发过来。白鸢点头，把自己的号码留下。

韩秀雅从隔壁叫他们，七号可以离开装配架了。

***

临时供电拆掉以后，七号先在原地站了一会儿。

它仍能看见、听见，也能让手掌在眼前打开。韩秀雅问它有没有不一样的感觉，七号想了很久，说自己一直在等有人把摄像头推走。

“现在不用等了。”她说。

公共体胸前装的是一套普通维修工具。七号试过夹具，又看过传感设备，最后还是问能不能先带这套：万机馆有那么多机器，它想跟唐胶去看看。

“看可以。先练稳，别一到船上就拆东西。”唐胶答道。

七号迈出一步，停下，再迈一步。公共体的脚落在地面上，声音比它以为的重。它沿车间中间的宽道走过去，路边的工人收起梯子，有人站到门口给它看距离。

白鸢拿着分镜板，本来想画一个跨出厂门的姿势。七号走到日光下面，却没停在她选的位置。

它先看了山，随后看天，又转过身看自己刚出来的门。

“你们一直能看见这个？”

“山吗？”纪存问。

“还有那边。”

它指向很远的运输道。几辆普通货车从山口驶来，车身上落着一层灰。

纪存跟着望过去。“嗯。以后还能到那边去。”

七号举起手，像是想挡住日光，又把手放下。它还没习惯身体投在地上的影子，走了几步，低头看影子也跟着移动。

白鸢放下分镜板，拿出相机。

“拍一张吗？”

“要全身。”七号立刻说。

她往后退，镜头里终于装得下这副身体。七号低头看自己的脚，又问脚也有没有拍进去。

“都在。手不用举那么高，放着就好。”

照片拍好，纪存把画面送到七号能看见的屏幕上。它一时没说话，韩秀雅站在旁边，也看着那张照片。

公共体站得还不太自然，保护纸只撕掉一半，背后是忙乱的工房门口。

“再拍一张。”七号说。

白鸢抬起相机。

“这次把她也拍进去。”

韩秀雅走到它脚边。她的头顶还不到公共体的膝部，必须站远一点，才能看见七号的脸。

“你别为了看我低头。”她说，“会挡住自己。”

七号努力看着前方，直到白鸢说拍好了，才慢慢低下头。

七号看过合照，才让白鸢把两张都留下。

更远的山口传来警戒机的呼叫。没有刺耳的近袭警报，工房的人仍然听清了：敌群在谷外重新聚集，防卫队要求所有驾驶员准备返机。

韩秀雅看过终端，把照片发进自己的私人相册。

“我去看看百相。你跟着维修组，先别走远。”

七号望向出击场。韩秀雅已经跑了过去。
