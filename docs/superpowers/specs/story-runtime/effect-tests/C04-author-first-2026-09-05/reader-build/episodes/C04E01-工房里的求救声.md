# C04E01《工房里的求救声》

万机馆越过山口时，第一批炮弹正从谷中升起。

纪存放慢航速。前方的山壁之间悬着一座巨大的铸造环，转动得很缓，尚未完成的机体固定在它内侧。那就是求援画面里的地方。更低处，厂房和露天船坞沿山谷铺开，断掉的运输道旁冒着黑烟。

一头冠部残缺的巨兽掠过屋顶。炮弹打在它周围，炸开的火光中，有更小的敌体向地面俯冲。

舰桥收到当地防卫频道的警告。

“来舰停在外泊区。北面厂房仍在交火，不要从上方经过。”

纪存报出万机馆的名字，问求援是谁发的。

“身体工房。有人已经去接你们。能出击的机体，请先帮我们守住外泊路。”

豪司已经站在门口，头盔夹在腋下。

“我过去。”他说。

纪存看了一眼舰外。社勇王的巨锤还留着工务城那场战斗的裂痕，维修后的固定带已经拆开，金色锤头朝向谷口。

“那锤子……”

“问过了，能用。不能老往同一个地方磕。”豪司戴上头盔，“知道你要问。”

“我想问的是，要不要让馆守Z跟你一起去。”

“那当然要。”

兜灯从整备席抬起头。“它已经在等了。”

馆守Z站在出击坡道上，空着的右肩朝向舰桥。那只黄色巡展臂在进山后的整备中拆了下来，固定在旁边的装备架上，外壳仍完好。兜灯想让工房看一看真正受损的部位，不打算再用那件临时工具遮着。

她向馆守Z挥了一下手。

“先去。回来就给你约到了。”

馆守Z低头看看她，随社勇王踏上地面。

远处突然升起一道灰白色的防壁。扑向厂房的火光在它表面散开，整座车间在强光后露了出来。防壁旁站着一台瘦长的巨机，身上的灰白战装和它颈部的深色组织并不相像。它抬手时，动作里有一种近乎人的紧绷。

频道里的驾驶员叫阿米娜。她开口有些急，仍把每个字说清楚。

“心墙零式，正面挡住了。里面的人先出来。”

另一名年轻驾驶员答应一声。较小的岛卫三号贴着厂房外墙疾走，肩部火炮接连抬起，将围住出口的分裂体打散。

“新垣凪，岛卫三号。”他向新来的频道补报身份，“刚才说能出击的，是哪边？”

社勇王的金色巨锤轰然落下。一只越过运输道的敌体被砸进空地，泥土和碎甲喷得比屋檐还高。

“这边！”豪司回答。

凪笑了一声，随即又忙着避开从头顶扫来的冠骨。

断冠贴着防壁上沿压下。心墙零式后退，脚跟撞到厂房基座。纪存看见远处的另一台巨机跨过运输道，宽阔的肩背几乎占满了两栋厂房之间的空隙。

“潮墙到位。”一个女人说，“阿米娜，往后退。”

“后面是装配区。”

“我们在你前面。”另一个女人接道。

潮墙巨兵顶着正面冲来的敌体向前踏出，拳头砸上断冠的下颌。巨兽翻起，冠部擦过山壁，大片岩石落进谷底。潮墙也退了一步，双脚陷在运输道上，粗重的身体摇晃片刻，重新站稳。

万机馆已经降进外泊区。来接他们的工房员跑到舷梯下，先确认七海到了，才像终于能喘气一样扶住栏杆。

“是您本人，太好了。库区的启动命令还在发，我们停一批，它又叫下一批出去。”

七海接过终端。画面里，一个没有头部外壳的巨体堵在厂房门口，手臂朝着废弃的高架举起。它背后还有尚未装好腿部的身体，正在装配架上反复做起步动作。

“谁在现场？”她问。

“值班组。负责人在百相上。”

“先带我们去值班室。我没有你们的操作权限，要有人当面停。”

纪存叫上陆衡，跟着她下舰。白鸢带着自己的资料箱，走到车门前，又回头望了一眼交火的方向。

唐胶从另一侧追过来，把箱子接进车里。

“你那两台机的资料吧？别搁最下面，到了还得找。”

“你怎么知道？”

“从木桶街抱到现在，我又不瞎。”

白鸢笑了一下，坐进车里。

工房内部的路并不安静。急救车辆不断经过，工人把刚装好的部件往回推，也有人抱着工作服从更衣室里跑出来。七海看见一副腿部只有一边包好装甲的身体，被运输车慢慢拖回车间。

“别启动它。”她向值班员指出正在反复发送的那行命令，“这一批本来不是防卫机。原授权只允许试机，后面加的武装调度不是我签的。”

本地值班员核对过后，关掉了那组反复催它们出动的命令。工房员随后逐台取消自动行走，堵在门口的巨体终于垂下手臂。

陆衡沿控制台查看。他在工务城见过的那套稳定程序也装在这里，但它不是今天发号施令的源头。

“这边只是照收到的命令走。”他说，“先把新的远程命令拦住，本地检修还能继续。”

七海把冒用签名的原始文件另存下来。眼前的机器停了，发送者还没查到。

纪存一直站在门边。

他听见了一个很轻的声音。它不在控制台的广播里，也不像外面机体的警报，夹在风机和金属震动声中，断断续续地重复同一个词。

“这里。”

纪存朝走廊另一端看去。

“有人在叫。”

值班员关小了广播。“哪里？”

“里面，靠窗那间。”

对方愣了一下，带他过去。

那里没有巨人，只有几套大小不同的维持设备。保温外壳接着电源和冷却管，旁边放着从破损身体上拆下来的部件。工作人员正在检查其中一套，抬头看见纪存，示意他靠近，但不要碰外壳。

小摄像头慢慢转向他。

扬声器里再次响起那个声音，这一次大家都听见了。

“你听见了？”

“嗯。刚才是你在叫吗？”

“他们说，馆里来的人能听见。”

值班员介绍说，他们一直叫它七号。身体在以前的事故中毁坏了，仍能回应的部分被保存在设备里。工房在找能够修复它的零件，已经换过几批修复方案。

纪存看见外壳旁有一本翻开的图册。完整机体的复原图很漂亮，颜色也已经标好。

“你现在觉得怎么样？”他问。

“能看见。能听见。有时候他们说我已经睡着了，其实没有。”

那名工作人员叹了口气。“它把休眠调短了，一有车进来就醒。我们还以为是炮声吵的。”

“今天是炮声。”七号说，“以前是零件车。”

纪存在它的摄像头前蹲下来。窗外有阴影掠过，他抬头，看见旧拳王和无牌一号已经走到维修路边，正在帮当地防卫组清掉漏进来的敌体。

七号的镜头也跟着转了过去。

“那两台，是你们带来的？”

“嗯。也是从工房里修好的。它们刚打过木桶杯。”

“谁赢了？”

纪存指向无牌一号胸前还没卸下的冠军标。

七号安静了一会儿。

“能把窗边的架子挪开吗？我看不全。”

值班员把空架推到一旁。十几米高的无牌一号回过头，从窗外向里看。纪存朝它招手，将屋内的声音接到了维修区频道。

“有人想认识你。”

无牌一号俯下身。

“我叫七号。”扬声器说。

“无牌一号。”

“你后面那个呢？”

“旧拳王。”

窗外的老机体抬了抬拳头。七号问它是不是也参加过比赛，旧拳王说参加过，不只这一场。

它们还没说到下一句，远处再次传来炮声。

断冠在潮墙面前抬起冠部，火光正向一点集中。心墙零式从侧面挡住它，凪则赶到了受损冠骨的上方，肩炮连射。

这一次，冠骨边缘真的崩下了一块。

断冠发出刺耳的啸声，撞开潮墙，向谷口升去。分裂体群仍在追逐落后的防卫机，社勇王横过巨锤，馆守Z与无牌一号从地面逼上去，将它们赶离通往车间的道路。

“它退了。”防卫席报告，“各机别追过山口，先接回伤机。”

凪在频道里长长呼出一口气。阿米娜关掉防壁，心墙零式靠着厂房蹲下来。潮墙的两位驾驶员先确认彼此没有受伤，随后才向工房报出机体损伤。

纪存扶着窗沿，看见守住的道路重新有车辆通过。

七号仍在问无牌一号。

“你们接下来去哪儿？”

无牌一号看向纪存。纪存笑了笑。

“先把这里的事情办好。后面的路，还要商量。”

“商量完，会走吗？”

“会。”

七号的镜头停在窗外，跟着一辆驶向谷口的维修车转了很远。

“我也想走。”它说。
