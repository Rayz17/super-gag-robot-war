## C04：百相的第一次试航

万机馆抵达天空铸环时，“首次公开试航”的横幅还挂在库门上，下面却是一台只有左臂的巨人，正在把受旧命令驱动的空壳顶回库内。韩秀雅原想亲手驾驶五十五米的百相走过这里，让人看见通用身体工房也造得出王牌，如今连安全出库都做不到。纪存留在舰内，经库区通讯辨认那些混在报错声里的回应：有些机体只是程序运转，有些已经在害怕；七号还困在接着维持电源的匣中，反复要求取消自己的重战身体分配。它想要的是一具能自行保养、走出库门的普通身体，不是替工房赢下战争的资格。

应求援赶来的心墙零式、岛卫三号与潮墙巨兵，把接应变成了第一次反攻。驾驶员自愿开放视野，纪存辨认哪些机体能够自行配合，帮助各队在炮火间交接护送；韩秀雅终于带着百相冲出库门，打退袭击者。她刚来得及笑，远处的断冠便折返了。它看过一次防壁收起、下一队接手的次序，这次佯退，专等交接时突入，将百相与接应队截开。百相带着推进损伤勉强撤回，守军再不能照搬刚才的胜法。与此同时，七海查到同一份停用签名被反复附在新启动命令上，保存了原始记录，请工房切断这条命令入口而保留机魂供电。谁递交了启动包仍须追查，但眼前的人不能继续替那份签名出战。

短暂的停火里，唯一还能工作的装配位摆着两份工单：修复百相的推进系统，或者完成七号的八米公共体。韩秀雅先拿起自己的工单。断冠还在外面，她有充分理由让所有人继续等。七号也没有求她，只问下一次排期会不会仍然叫“等打完再说”。韩秀雅最终撤掉百相的工单，亲手给它接上装配电源。她不愿承认自己守住的工房，竟没有一天能交付战争以外的身体。唐胶保留七号已经用惯的接口，陆衡校核全尺寸承载；原核心带着持续供电的维持匣转装进新身体。七号第一次抬脚便踩坏了一只工具筐，韩秀雅蹲在它脚边调限位，笑得比刚才击退敌人时还响。

白鸢却迟迟没交出最后一页预演。她画过再次利用护送交接诱敌的办法，但需要纪存同时核对几路主动开放的视野；第一次导航后，他已吐得站不稳。她把这一页抽掉，递出一份更保守的撤离方案。韩秀雅追问为什么放弃反攻时，隐瞒才露出来。纪存生气的不是她担心自己，而是大家已经在讨论谁留下断后，他却连另一种办法都没有看见。白鸢交出原稿，也没有因此撤回担忧。复核后的方案缩小了纪存的职责：只报告看见的交接空隙，不替驾驶员决定出手；任何一路都可以停止共享，其余人按现场情况接续。他们要再用一次敌人见过的动作，但不再把所有人的下一步压在同一个人身上。

百相被固定在试航拖架上，公开驶离修理场，像是终于放弃作战的伤机。断冠追着熟悉的护送次序逼近，准备在换手时夺下它。这次，被交接的却是仍有余力近战的韩秀雅。七号藏在拖架内部，沿巨机无法进入的检修通道抵达释放机构；外壳挨炮后，锁扣卡死，它用刚学会控制的双手拆掉锁销，把百相从固定架上放下来。外面的战斗并未照着分镜逐格发生：心墙的驾驶员叫停承受，友军便改换掩护位置；断冠试图绕开一面火力，又被另一队逼回。韩秀雅等到自己认定的距离，才将剩余推进全部压上。百相用独臂扣住冠根，在众机争出的射界中死死不放。合击撕碎一段不可再生的冠基，断冠带着再也合不拢的缺口撤退。工房没有被搬空，百相也真正赢下了自己的首战。

清残后的试航场摆起临时饭桌，七号站在旁边，认真追问第一天就刮花的外壳还算不算保修。韩秀雅说算，修之前得先让她拍照。三旗舰完成临时整备，各返防线，留下下次能够直接呼叫彼此的协力约定；万机馆则获得返航维修的去处。七海把调查进展发给原来的同事，没有撤回职业申诉。白鸢与纪存尚未和好，但下一次讨论时，她把整本分镜放在两人中间。离港前，韩秀雅约他们回来观看百相的正式试航。七号已经替自己订了观众位置：不在库里，也不在谁的驾驶舱里，就站在场边，看她完整地走一趟。

**玩法概念**
