**C04：七号出厂**

万机馆抵达天空铸环时，韩秀雅正驾驶五十五米高的百相，用唯一的左臂把一台无舱巨机拖回库门。那台机体不断被启动命令推向炮火，却又挣扎着往回爬。纪存留在舰内，终于从杂音中听清它的请求：别再启动，我的腿还没装好。它只知道自己叫七号。韩秀雅切断驱动，保住仍在供电的核心，将它拖离投放线。她原本准备趁下一轮袭击前补全百相；七号却问起车间里那副八米灰模骨架。它不想等一个庞大身体全部完工，只想有一双真正能用的脚，自己走出库门。

响应求援而来的心墙零式、岛卫三号与潮墙巨兵，给了工房第一次喘息。驾驶组自愿开放部分视野，纪存替他们辨认被机架遮住的同伴，将接应位置报给各机。几次原本要冒着炮火硬闯的拖救顺利完成，连韩秀雅也开始等他报出下一个空当。断冠就在这时逼近。它不急于追杀撤退者，而是照着刚才看过的换防节奏，把炮口提前转向下一处接应点。护送队几乎迎着炮火交接伤机。阿米娜喊停，心墙撤下防壁，百相只能用身体挡住拖救队退回库区。纪存的屏幕还亮着，大家却已经不敢照旧出发。

七海查出，停用授权是被本地值班负责人重新启用的。他绕过逐机核验，把未完成机统一编入守厂队列，认为哪怕它们只能挡住一轮炮火，也好过整座工房失守。七海保全了原始记录，要求他撤销命令；他反问，撤下来以后谁去守。韩秀雅本来可以用百相回答，但唯一可用的总装工位一次只能完成一种装配。七号听见争执，开始询问自己的核心还能维持多久，像在替他们计算可以继续拖延的期限。韩秀雅没有让它算完。她把百相退出工位，将等着校准的右臂留在运输滑台上，要求先装好那副普通身体。

唐胶保留七号核盒的原接口，陆衡接入独立维持电源，再将持续运行的原核移入灰模骨架。七号迈出第一步时，误把八米的脚当成原先那双巨足，撞翻了工具架；它蹲下来捡，比站起来还费劲。白鸢看着它，终于交出被自己扣下的一张图：万机馆可以沿外泊道转移待身载体，为守军腾出反击空间，但巡展舰会暴露在敌方射界里。她先前只说那里走不通，因为纪存还在舰上。陆衡复核后确认路线可用。纪存没有立刻接受她的道歉，也不再要求同时看见所有人。他只保留自己能处理的两路视野，约定任何一路关闭，接应就重新确认。

万机馆开始转移，断冠再次抢占它观察过的交接位置。这一次，接应者没有依次填进去。各机依据眼前的炮口与同伴位置继续行动，纪存只报告被遮住的危险，不替谁决定下一步。断冠仍能逼退一台机，却无法靠打穿一个交接点拆散整支队伍。七号已经随载体队抵达掩体，却发现总装滑台的远程接口毁了，主动折返巨机进不去的检修廊。韩秀雅先问它还能不能走稳，才同意接应。七号在里面手动接通滑台，把百相那条未完成的右臂连同重载底座推出，封住断冠的一侧退路。百相从另一侧贴身冲入，用空着的右肩挤过机架，左手扣住展开的冠根，将全身推力压向立柱。冠部连根折断。断冠挣脱后带着不可再生的缺口退向轨道外，守军夺回了出厂通道。

战后，三旗舰参与清残和临时整备，再返回各自防线，留下下一次能够直接求援的联络。七海把调查证据续交给原来的审查渠道，这回还有必须具名承担责任的现场记录。韩秀雅留下恢复生产，独臂百相取得正式试航资格；万机馆则在工房完成承力脊节维修，馆守Z的空肩装上牵引背架。临走前，七号提出想随馆走一程，亲眼看看那些回信的地方。韩秀雅原本已经给它留了车间工位，听完后撤掉排班，把保养工具交给它。七号走到舷梯口，又自己退回来拧紧一颗松动的踝部螺栓。这次没有等谁抱它上船。
