## 世界-机魂主体定义 | fact / working

**机魂是机器在一个可追踪的本地物理载体中，经持续经历形成、并能在有限载体变化中保持自我认同的主体连续性。**

它可能由以下内容共同形成：

- 原生AI或学习系统。
- 驾驶员长期操作形成的动作偏好与互相适应。
- 维修、损伤、改装和零件替换留下的身体史。
- 被称呼、观看、表演、收藏和共同记忆形成的文化关系。
- G.A.G.文化反馈中被放大的自我识别、他者承认与拒绝。

机魂不是五项材料相加达到100点后的固定产物。一台普通工业机可能在多年共事中形成很强主体，一台华丽超级机器人也可能主要由驾驶员和普通控制程序行动。

## 世界-载体不能消失 | fact / working

机魂可以离开原身体，但不能没有连续载体而漂浮：

- **活体维持。** 原生AI核、实时黑匣、专用维持包、万机馆B2待机槽或持续网络会话可保持主体运行。
- **无损移交不存在。** 身体感、时间差、缓存丢失和新身体适应都会改变主体，只是变化不等于死亡。
- **同时并存即分支。** 若备份和原体都持续运行，从分岔时刻起就是两个主体，不得说成一个灵魂同时在两处。
- **残响不是本人。** 录像、台词、动作签名、模型锚和别人的记忆可以参与新主体的形成，但不自动构成原主体复活。

## 玩法-产品方向不是章节事实 | presentation_option / candidate

这是一款**让玩家带领一群有身体、有脾气、有历史的机器人，在确定可钻研的战棋中亲手搭出名场面，再把胜负、伤痕、关系、藏品和传说带回万机馆的群像机战叙事 RPG**。

它的核心幻想不是“替一群数值单位下命令”，也不只是“谨慎处理工程事故”。玩家要同时得到五种满足：

1. **像战棋高手一样解题：**读敌方行动意图，用朝向、站位、身体、预备反应和行动顺序组成强解，甚至合法地把一关玩坏；
2. **像机器人番剧导演一样搭台：**让一台被误解、想出风头或怕再次失败的机体，靠玩家亲手创造的条件打出只属于它的名场面；
3. **像队长和同伴一样组队：**战前选择人物出席与战术牌，战中让专业、关系、争执和共同动词改变打法，而不是走一串审批菜单；
4. **像收藏家和馆主一样生活：**巡访机器人文化、进入残响记忆、亲手修复和布展，让万机馆、藏品和冷门机因偏爱发生可见变化；
5. **像长篇RPG玩家一样被世界记住：**战报怎样发布、谁亲眼见过、谁被照料或被放手，会改变宿敌、城市、关系、后期Meta与终局回收。

本作允许纯粹的燃、爽和完整胜利，也允许救到一半、带伤撤离和有遗憾的继续。代价不是每次胜利后的罚单；先让玩家爱上、玩爽、想拥有，真正的代价才有重量。

## C03-当前求援及七海去留 | fact / working

当下的信号来自天空铸环。

画面不稳定，只能看见整座轨道工房正在缓慢旋转，外侧不时闪过炮火。库区里整齐排列着一批没有驾驶舱、也没有名字的巨型机体。

讯息只有几句：

“天空铸环遭到轨道外袭击。未完成机体库已紧急启动。请求能辨认机魂者到场。启动命令正在使用一份已停用的生产签名，请签名本人到场核验。”

七海只看了一遍，便认出命令末尾的签名。

那是她已经停用的生产授权。

旧讯息则来自二十七年前的深空远征队。画面已经丢失，语音里充满噪声。一名女性通讯员断断续续地说：

“地球，如果你们还能收到……回答我们一个名字就行。任何一台还在行动的机器人。我们想知道，那边还有人在回应。”

讯息在一串遥远的爆炸声中结束。中继站的值班员检查了很久，确认这条旧信道还保留着回传入口，但谁也不知道回复会离开工务城，还是只会继续存进本地缓存。

七海的车已经到站。

纪存没有要求她做决定。他把当下讯息的原始画面发给她。

“馆守Z醒过来的时候，我听见的就是这种声音。”他说，“那批机体里，也许有人已经醒了，只是没人认得出来。我得去看看。”

七海看着屏幕上那串已停用的签名。

她打开复职材料，将其中关于旧授权冒用的全部记录发给替她争取审查的同事。随后她退掉车票，也取消了自己下午的说明会。

“证据我照常发。今天的说明会我赶不上了，名额取消吧。”她给同事留下一段语音，“我得去天空铸环，当面查是谁还在用我的签名。”

列车门在她面前关上。

七海拎着行李箱走回纪存面前。

“刚才你问的，还算数吗？”

“当然。”

“那我不回去了。”终端上的退票页面已经跳到“完成”，七海把它收回口袋，“先跟你们去天空铸环。”

她把行李箱的拉杆递给纪存。这次他立刻接了过去。

回到万机馆时，白鸢正在仓门边收线。她看见七海又把行李箱带了回来，挪开脚边的线盘。

“记住了。真缩了我赔你。”

“那更不行，绝版了。”

舷梯旁的临时乘员表需要填写身份。七海在上面写下“随舰事故观察员”，调查事项填“旧签名滥用”，所属机构一栏空着。

## 世界-机魂主体定义 | fact / working

**机魂是机器在一个可追踪的本地物理载体中，经持续经历形成、并能在有限载体变化中保持自我认同的主体连续性。**

它可能由以下内容共同形成：

- 原生AI或学习系统。
- 驾驶员长期操作形成的动作偏好与互相适应。
- 维修、损伤、改装和零件替换留下的身体史。
- 被称呼、观看、表演、收藏和共同记忆形成的文化关系。
- G.A.G.文化反馈中被放大的自我识别、他者承认与拒绝。

机魂不是五项材料相加达到100点后的固定产物。一台普通工业机可能在多年共事中形成很强主体，一台华丽超级机器人也可能主要由驾驶员和普通控制程序行动。

## 世界-载体不能消失 | fact / working

机魂可以离开原身体，但不能没有连续载体而漂浮：

- **活体维持。** 原生AI核、实时黑匣、专用维持包、万机馆B2待机槽或持续网络会话可保持主体运行。
- **无损移交不存在。** 身体感、时间差、缓存丢失和新身体适应都会改变主体，只是变化不等于死亡。
- **同时并存即分支。** 若备份和原体都持续运行，从分岔时刻起就是两个主体，不得说成一个灵魂同时在两处。
- **残响不是本人。** 录像、台词、动作签名、模型锚和别人的记忆可以参与新主体的形成，但不自动构成原主体复活。

## 世界-手艺与工程 | fact / working

唐胶能从一道磨痕看出某个玩家怎样掰过关节、从一块垫片看出谁曾努力让它继续活。他把这种微观经验转成**结构假设和可保留的身份**。陆衡把假设放进全尺寸材料、载荷、热和控制里，决定它是否能成为**现实工程**。

两人都不可缺：没有唐胶，工程可能把修补史洗成标准件；没有陆衡，手作经验可能在十八米尺度上害死人。两人的戏不应总是“浪漫手艺人对理性工程师”，而是互相指出对方看不见的尺度。

`CURRENT`

## 玩法-产品方向不是章节事实 | presentation_option / candidate

这是一款**让玩家带领一群有身体、有脾气、有历史的机器人，在确定可钻研的战棋中亲手搭出名场面，再把胜负、伤痕、关系、藏品和传说带回万机馆的群像机战叙事 RPG**。

它的核心幻想不是“替一群数值单位下命令”，也不只是“谨慎处理工程事故”。玩家要同时得到五种满足：

1. **像战棋高手一样解题：**读敌方行动意图，用朝向、站位、身体、预备反应和行动顺序组成强解，甚至合法地把一关玩坏；
2. **像机器人番剧导演一样搭台：**让一台被误解、想出风头或怕再次失败的机体，靠玩家亲手创造的条件打出只属于它的名场面；
3. **像队长和同伴一样组队：**战前选择人物出席与战术牌，战中让专业、关系、争执和共同动词改变打法，而不是走一串审批菜单；
4. **像收藏家和馆主一样生活：**巡访机器人文化、进入残响记忆、亲手修复和布展，让万机馆、藏品和冷门机因偏爱发生可见变化；
5. **像长篇RPG玩家一样被世界记住：**战报怎样发布、谁亲眼见过、谁被照料或被放手，会改变宿敌、城市、关系、后期Meta与终局回收。

本作允许纯粹的燃、爽和完整胜利，也允许救到一半、带伤撤离和有遗憾的继续。代价不是每次胜利后的罚单；先让玩家爱上、玩爽、想拥有，真正的代价才有重量。

### 玩家期待的是四种不同的日子

本次写法：采用以下轻量创作方法辅助构思，内部完成必要判断即可，不输出沙盘/清单；只交任务要求的一份故事。方法不能凌驾于常识和角色反应，素材允许不用。

# 创意提案与角色沙盘

## 目标

在详细正文和生产板之前，决定值得讲的故事。方向明确时一个主案即可，有真正分歧或用户要求比较时再给2-3案。提案不是把必须元素换三种排列，而是比较冲突、人物选择和高潮含义。

## 第一步：欲望与对抗

先用一句人话回答：

```text
谁现在最想得到什么？
谁或什么也在主动争取另一种结果？
若主角不来，双方各自会继续做什么？
```

“完成任务”“保护文化”“查清真相”通常还不是欲望。继续追问角色想保住的人、身份、身体、关系、尊严、机会或秘密。

主要机体也回答同样的问题。它可以想赢、再战、变形、合体、保护某人、选择驾驶员、证明设计、回到舞台或摆脱被赋予的身份。

## 第二步：角色沙盘

对每个驱动角色和机体，后台写六行：

1. 此刻最想要什么；
2. 不肯直说什么；
3. 错看了谁或什么；
4. 若没人阻止，下一步会主动做什么；
5. 哪件事会让其拒绝参与；
6. 哪种行动会让其被另一个角色吸引、激怒或动摇。

沙盘角色可以反抗章引擎。若所有人只能因为“剧情需要”同行，提案未成立。

## 第三步：故事提案

每种方案回答：

- **一句话戏眼**：当前人物能听懂，不用世界观术语。
- **开场抓力**：第一个具体画面和立即出现的麻烦。
- **冲突拓扑**：追逐、围困、交易、误会、竞赛、救援、诱惑、背叛、共同敌人或其他结构。
- **中段翻面**：观众对谁、目标或代价的理解怎样改变。
- **主角选择**：不是按钮选项，而是会暴露欲望并改变别人看法的行动。
- **机体选择**：一台机器怎样用身体作出不可替代的决定。
- **关系体验**：亲密、误会、体谅、笑话或共同经历怎样让人愿意关心这些角色，不要求每段改变主因果。
- **喜剧或生活入口**：来自人物和情境，不是插播笑话。
- **玩家经历**：玩家具体操作、判断或承担什么。
- **高潮图像**：一眼能画出来，但不把每一步动作写死。
- **所得与余波**：胜利如何被享受，人物得到什么；确有损失或后果再记录，不要求每次胜利付同一种账。
- **下一话愿望**：人物还想做什么，不用神秘名词硬钩。

## 差异门

多案比较时，检查是否在重要方面真正不同，而非仅更换场地：

- 主动对手；
- 主角最困难的选择；
- 战斗为何发生；
- 高潮胜法的原则；
- 关系受伤或靠近的方式；
- 玩家获得的东西；
- 结尾的新局面。

只更换场地、Boss名字或机体站位不算不同方案。

## 惊喜与必然

对每种方案各写两句：

- 首次看到时，玩家为什么想不到？
- 回看前文时，为什么又觉得只有这些人物能做到？

若第一句答不出，方案平；若第二句答不出，方案乱。

## 选择

选择一个最能同时满足人物、机体和玩家欲望的方案。可以从其他方案吸收一个功能，但不得把三套高潮、泪点和IP全部合并。

如果提案只是任务说明，回到欲望，不进入昂贵扩写。
