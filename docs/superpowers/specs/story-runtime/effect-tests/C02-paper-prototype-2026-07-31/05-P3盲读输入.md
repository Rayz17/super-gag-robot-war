# C02三案盲读输入

> 本文件不提供作者意图、Runtime资料、旧稿对照或主笔排序。

## 极短前情

闭馆夜，18米旧巨神馆守Z与勇拳试作机击毁了入侵城市的BREAK​ER；馆守Z失去右臂。万机馆恢复为百余米巡展舰，离开被毁旧址，开始第七次巡展。它缺少现代泊位、补给和完整检修，只能先飞到发来巨构泊位照片的木桶街。纪存、唐胶、兜灯、馆守Z和两台小型机器人随舰；七海留在原城受调查。白鸢尚未正式登场。

## 方案A

纪存必须把把机器人当商品的收藏者、把机器人当同事的工坊和一台拒绝被拆卖的货柜领袖组织起来，正面打退要吞掉木桶街的拆解队。

万机馆抵达木桶街后，只能停进巨构泊位接受最基本的补给。外来拆解商正在收购泊位和老机器，并把能变形成门架与作业机器人的火种货柜领袖列为最值钱的整机商品。唐胶当年曾把一件带有真实修补史的稀有模型修成假原装，借此获得名声，却让坚持保留修补痕迹的旧伙伴背了粗制滥造的骂名。白鸢来到木桶街，是为了追查拆解商擅自使用并删改了她的旧行动草图。纪存通过不同机器上的共同磨损判断哪些工坊实际互相依存，白鸢提供数套防守预演，各机组在模拟后选择并修改其中一套。拆解队强行拖走货柜领袖时，纪存发动已经取得信任的工坊机组，从正面、侧翼和泊位高处同时反击。胜利后，货柜领袖只承诺护送万机馆到工务城并接受未来召回。

玩家探索工坊，实际争取参战机组并改变战场地形；大战中分配正面、固定、侧击和撤离职责。高潮时，货柜领袖在被拖运途中从载具形态展开成门架，托住装满生活物资的货柜；馆守Z把黄色巡展臂固定在泊位主桩上，以自身作为支点，用左拳迎击大型拆解实机。跌跌和机器犬进入拖运底盘，释放车轮，货柜领袖带着整列货物冲出包围。

唐胶当众拆开自己最得意的“原装修复”，承认哪些痕迹是他伪造的；旧伙伴仍不原谅他，却允许他以唐启明的身份留下完成返工。章末，万机馆B1获得缺失工具、人员和可拆式维修设备；货柜领袖短期随航；白鸢用证据整理、现场预演和公开记录换取工作位。

## 方案B

唐胶的旧伙伴要用一台封闭巨型展示架夺走全街的民间模块，纪存必须把无牌一号构筑成能够逐件夺回模块的开放式战斗机体。

木桶街正在举行全尺寸模块展，无牌一号由本地操作者驾驶，准备第一次留下真正的身体构筑史。唐胶的旧伙伴经营着一套封闭模块品牌，并宣称街上的民间改件都源于自己的创意；这个指控并非全假，因为唐胶年轻时确实把对方的一项模型改装思路当成自己的独门手艺展示过。白鸢主动争取了大型发布行动的创作工作，但执行机组在模拟中删掉了她多项无法实现的动作。旧伙伴随后利用展示活动，以大型固定作业架和护卫实机强行拆取各工坊的真实模块，准备拼成一套只能由他控制的商品体系。纪存和唐胶根据模型版本、修补习惯和实际所有者找回愿意参战的人，兜灯再从中选出无牌一号确实能够承受的少量真实模块。玩家带领无牌一号和独立工作机正面攻入展示场，逐件打掉大型作业架的抓取、护卫和移动能力。胜利后，无牌一号保留玩家第一次选择的构筑，旧伙伴的封闭展示架被永久拆散。

玩家战前从少量真实模块中构筑无牌一号，战中决定先压制哪个大型部件，并与独立机组夺回被抢模块。高潮时，大型展示架带着四个作业模块横穿展场，无牌一号从下方突入，馆守Z把展示架的一条移动支腿固定在泊位重载桩上，独立机组趁机夺回模块。

唐胶公开交出当年的模型记录，承认旧伙伴确实是原始创意者，同时证明后来几十种实机改件并不属于他们任何一人。章末，无牌一号形成玩家首个构筑版本并成为长期伙伴候选；木桶街把便携工具安装进万机馆B1；白鸢以持续预演工作换取设备位和食宿。

## 方案C

纪存要帮助一台被完美修复毁掉打法的旧拳王重新学会带着伤痕战斗，并堂堂正正赢下木桶街的全尺寸机器人拳赛。

万机馆抵达时，木桶街正在举办决定下一支工务城客场队伍的全尺寸机器人拳赛。旧拳王机和影子陪练机所属的老拳馆已经无力维持公路维修设备，若再次失利便只能拆卖机器还债。唐胶年轻时曾擅自把旧拳王修成外观对称的“完美状态”，抹掉驾驶员与机体多年共同形成的偏重站姿，拳王随后输掉关键比赛，他却带着修复名声离开。白鸢此前筹备的机器人运动项目临时取消，使她带着设备困在木桶街；她主动加入老拳馆，希望完成一份能真正被执行者采用的现场作品。纪存从旧模型、失败录像和机体磨损中看出拳王不是衰老，而是在强迫自己使用一个从未真正拥有过的标准姿势；兜灯负责确认哪些结构调整能够安全恢复。馆守Z以自己的单臂防守提供训练样本，影子陪练复制对手动作并赢下一场独立热身赛，白鸢提出的方案则由驾驶员和机体修改。玩家通过正式回合把旧拳王带进决赛，旧拳王最终放弃漂亮外壳和标准连招，以恢复后的偏重步法干净击倒新冠军。

玩家探索模型铺、拳馆和维修区，训练影子陪练，并在比赛中选择防守、压迫、诱导出界或非致命击倒。决赛时，新冠军逐招反击旧拳王过去最著名的进攻，把它逼到边绳。旧拳王主动让对称肩甲在重击下脱落，恢复偏重站姿，以贴身闪避让对手冲空，再用完整的身体转动完成干净击倒；观战机器人同时敲响金属护栏。

唐胶亲手拆掉自己当年的“完美修复”，承认那不是挽救而是抹掉机体与驾驶员共同学会的动作。章末，旧拳王和影子陪练保住身体与公路维修设备，成为万机馆第一组巡展竞技伙伴；比赛奖金和工务城客场邀请提供下一段航程；白鸢以巡展动作预演和赛事记录工作加入。
