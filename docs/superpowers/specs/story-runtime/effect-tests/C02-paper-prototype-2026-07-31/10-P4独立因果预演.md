# P4 独立因果预演

## 阻塞因果

1. **经营者的控制权没有落地。**投入标准装卸线，只能解释他的利益，不能解释他为何能清走共用货运道上的设备。当前方案混淆了机群所有权、本批操作权、道路使用权和他人物件处分权。

2. **经济冲突尚未必然变成机器人战斗。**“双方不能接受停工谈判”只是结论。若暂停、分单、让经营者代装或等待裁决仍能保住木桶街资格，工业机体没有必须争夺作业面的理由。

3. **首批货被赋予了过大的决定力。**普通第一批货不能自动决定长期路线；本章只完成装船，尚未在工务城交付。装船即宣告经营者永久失去线路，因果不成立。

4. **万机馆断开供能的输入、输出和代价混在一起。**岸上供能被断开后，万机馆仍可用自身储备外供，但当前没有说明具体供应对象，也没有把“可能被困”落实成检修停止、补给撤回和出发余量不足。

5. **三人的知识来源不完整。**白鸢在万机馆抵达前不能预知接收船数据；货柜领袖不能凭直觉认定密封柜有问题；唐胶能认出旧模型，不等于能判断当前全尺寸身体与门架承力。旧模型在场面六突然出现也缺少空间来源。

6. **最简单办法仍会穿透高潮。**纪存可保持中立离开；双方可让经营者代装；可暂停等待处理；馆守Z也可能直接击倒总机。方案必须把这些办法分别写成真实诱惑、等同失去目标、来不及保住本批，或会毁掉共用设施与货物，而不是让角色忘记它们。

7. **E01移动大体成立，但信息顺序有跳步。**纪存接受经营者安排、货柜领袖据此拒绝、白鸢补测万机馆、唐胶认出轮廓，必须发生在同一条“泊位—标准装卸场—主工房带”轴线上，并有先后关系。

## 最小修正

1. 锁定经营者只拥有标准机群，并取得本批标准装卸场与总吊架的操作时段；主货运道仍为共同使用。测试失败后，他有权接手本批装卸，但无权取得整条街或他人机器人。他靠重型机群实际占住外段瓶颈，混合工房靠自身机体拒绝交班。

2. 将本批明确为工务城路线的首航验收批：混合工房先执行，失败后经营者自动接手。停工即失去本批资格；由经营者代装即把路线证明交给标准线；唯一适配万机馆的外段瓶颈被占，双方因此必须争夺连续作业面。战斗目标是夺回总吊架并完整装船，手段是推挤、固定、封路和夺位。

3. C02胜利只决定混合方案完成装船、取得出发事实并进入工务城交付验收，同时取消经营者的自动接手；长期线路在抵达工务城后决定。木桶街当场用于修舰的是装船节点已经产生的收入，不是尚未完成的全程货款。

4. 岸缆负责给万机馆储能并带动B1检修；断开后，兜灯用舰内储备仅供应本地绞盘、外泊甲板导引设备和必要舰内负载。结果立即表现为B1检修停下、经营者撤回零件与人员、非必要区域降载、出发储备跌破安全线。胜利后仍须由木桶街完成再充能和收尾检修，万机馆才能离泊。

5. 白鸢先做标准线通用预演，万机馆靠泊后才补入其数据；货柜领袖依据任务清单、实体编号与责任人栏不一致拒柜；唐胶凭自己删改过的独特轮廓认图，并在E01将旧模型随修复箱带下船。他只指出被删除的身体历史，当前动作由货柜领袖说明、兜灯与本地工程人员实检确认。

6. E01固定顺序为：万机馆靠泊；纪存与唐胶从B1下船；货柜领袖从工房带驶到标准装卸场并因密封柜停下；经营者和白鸢在观察位加入；纪存返回泊位查看条件并接受安排；货柜领袖看见接收船安排后拒绝；白鸢补测万机馆；唐胶留在观察位认出轮廓。馆守Z与兜灯始终留在泊位侧。

7. 馆守Z只在核验受力方向后用巡展臂牵住舰船约束桩，承担抗推和牵制；货柜领袖的门架只转运既有载荷等级内的货柜与中型机组。最后夺回作业面来自货柜领袖自主改变战法，馆守Z不直接摧毁共用总机。

## 是否可进入短样

**可进入短样，但必须先把以上七项作为锁定因果写进短样事实。**核心发动机成立：纪存拥有可行的安全退路却主动押上它；经营者有现实利益和执行能力；货柜领袖的身体选择改变战法；白鸢与唐胶的错误直接造成并修正同一场失败。短样应只验证E01移动、经营者控制依据、拒柜知识来源和纪存接受安全方案四件事。当前方案无需返回 `RESTART_FROM_IDEATION`。
