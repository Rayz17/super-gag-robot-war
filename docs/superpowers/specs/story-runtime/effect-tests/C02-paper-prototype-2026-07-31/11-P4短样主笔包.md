## 这段故事要做到什么

玩家刚经历万机馆闭馆、城市遭袭、馆守Z起身、旧馆化舰出航。现在第一次抵达木桶街。

这段短样结束时，读者应自然明白：

- 万机馆已经安全抵达，但舰况只够再可靠航行一段；
- 纪存因为不想再拿全舰冒险，接受一份能立刻修舰和去工务城的安全交易；
- 货柜领袖是木桶街真正生活着的机器人，它有自己的工作习惯、过错与拒绝权；
- 白鸢是标准装卸演示的创作者，渴望自己的大型现场作品终于被真正执行；
- 唐胶认出白鸢方案里藏着自己多年前做过的事，却选择暂时不说；
- 纪存的安全选择使货柜领袖不再信任他。

不要解释后半章会怎样，不要预告正确答案。

## 只写这四个连续场面

### 1. 只报平安

万机馆正在接近木桶街。兜灯把舰况说成人能听懂的话：靠岸后能修一部分，但现在的储备只够他们再稳妥走一程。

七海仍在原城接受调查。她与纪存私人通讯，问抵达情况。纪存只说已经到了，隐瞒了续航底线和下一站尚无保障。两人有熟识、吸引和没有说破的分歧，但这不是告白场。

### 2. 靠岸

木桶街只有一处能容纳百余米万机馆的巨构泊位。万机馆固定后不再移动。

馆守Z留在万机馆外泊位置，用不能握拳的黄色巡展臂搬下破损设备，完整左拳收着。兜灯在B1、外泊甲板和岸上供电之间检查，不随众人深入街内。

纪存、唐胶、跌跌和机器犬经B1货运升降区下船，沿主货运道边缘向标准装卸场走。玩家沿途看见模型修复箱、零件铺、小型职业机和全尺寸作业机共用同一条生活与工作路线。不要用百科旁白罗列生态，让三四个互相影响的具体动作说明它。

### 3. 货柜领袖拒绝一个箱子

货柜领袖从主工房带沿同一条货运道驶来。它是拥有独立人格的全尺寸变形货运生命，可以在大型载具、门架和作业机器人形态之间切换；本场以载具形态工作，不展示完整变形。

它会主动给行动迟缓的老机器腾路，也会检查自己承运货物的编号和责任人。一只密封柜的实体编号、任务清单和责任人栏对不上，它因此停下整队，拒绝继续运送。

周围人并非都支持它。它过去曾因怀疑一只货柜而擅自开箱，毁掉货物并让合作工房损失惨重。它没有因此变成只服从清单的工具，也没有假装自己的判断从不犯错。

纪存一行、标准线负责人和白鸢在标准装卸场自然相遇。先让现场的人试图解决眼前这只箱子，不要立即讨论全章主题。

### 4. 纪存接受安全交易

标准线负责人拥有本批次标准装卸场和总吊架的操作时段，也拥有自己的装卸机群；他不拥有木桶街、货柜领袖或共用货运道。

这批货是前往工务城接受交付验收的首航货。万机馆是当前唯一能从这里直达工务城的大型接收船。负责人愿意立刻提供岸上检修、B1急需工具、生活补给和装船安排，换取万机馆担任标准线接收船。

白鸢在万机馆抵达前已经受聘制作标准线的通用预演；靠泊后，她才开始把万机馆的真实位置与尺寸补进方案。她手中的货柜领袖轮廓来自一份被当作可靠资料的旧商业模型。

纪存查看真实补给与舰况后接受交易。货柜领袖亲眼看见万机馆进入标准装卸位，也听见纪存接受，随后拒绝他的协作请求并返回主工房带。

唐胶在白鸢的方案里认出自己当年删改过的独特轮廓。他带下船的修复箱里正有那件旧演示模型，但本场不揭晓旧事。

短样停在这三个裂口上：纪存隐瞒舰况，货柜领袖拒绝纪存，唐胶隐瞒旧模型。

## 一眼能懂的空间

```text
主工房带
  -> 主货运道
  -> 标准装卸场 / 白鸢工作位
  -> 总吊架
  -> 巨构泊位 / 万机馆外泊甲板
```

- 万机馆、馆守Z和兜灯主要留在最外侧泊位。
- 货柜领袖从最内侧向外驶来。
- 纪存、唐胶和小型机器人从外侧向内走。
- 双方在中间的标准装卸场相遇。
- 白鸢和标准线负责人原本就在装卸场附近，不突然从别处出现。

## 人物当场欲望

- **纪存**：想给同伴一条不会再赌命的安全去路，也不想让七海知道他刚离城便陷入困境。他观察力强、说话克制，但会逃避亲近之人的追问。
- **兜灯**：想让所有人面对舰体真实状况。她直接、务实，不替纪存做航路决定。
- **唐胶**：不想面对木桶街旧事，又忍不住评价别人怎样理解模型与实机。平时嘴碎、生活化，心虚时会改口或转移话题。
- **白鸢 / Evelyn Voss**：想让第一件署自己名字的全尺寸现场作品真正被执行。她聪明、自信、有些好胜，面对修改会本能地护住作品；她不是系统UI，也没有画稿改变现实的能力。
- **货柜领袖**：想知道自己运的是什么、为谁承担。它体贴、固执，也记得自己判断错误造成过的损失；它会自己决定是否承运和与谁合作。
- **标准线负责人**：想让自己投入多年的标准装卸线拿到通往工务城的实际机会。本场以现实利益说服纪存，不露出反派腔。

## 少量正面声线锚

这些只用于理解人物松紧，不要照抄，也不要把每句都写成俏皮话。

- 纪存对唐胶：“明早最难搬的是你的模型病院。”
- 唐胶：“那不叫搬。那叫把没修完的病人按科室拆散。”
- 唐胶想拿兜灯旁边的饭盒：“那个也是扳手？”
- 兜灯打开盒盖，里面是螺丝：“你的晚饭怎么会响？”
- 七海等纪存赴约：“它要是再漏油，你把馆守Z一起带来。我当面问。”
- 纪存：“你要跟十八米的机器人挤一张桌？”
- 七海：“它应该比你准时。”

## 写作门

1. 第一段先说明谁在哪里、正在做什么；不要用拟人比喻或广告短片式奇句开场。
2. 一段只推进一个可见动作或人物反应。空间、移动和信息来源要让普通读者跟得上。
3. 先写人和机器人眼下怎样办事，再让意义从选择和后果里出现。
4. 不使用作者说明替角色补动机，不用“这证明了”“真正重要的是”等总结句。
5. 技术信息先说普通人能执行的话。本样不得新造接口、槽、锚、校准廊或一组专有名词。
6. 对白都说给具体听众。允许废话、打断、改口、误会、语气词和长短不一；禁止全员轮流说完成度很高的金句。
7. 不使用“你可以……但别替我……”“不替谁背……”“没有把……说成……”之类对称宣言。
8. 不追求最低字数。四场成立便停止；若开头和第一次冲突本身不吸引人，直接返回`SCENE_CHAIN_NOT_READY`，不要靠辞藻补救。
