# P3 选案与根因修订简报

> Status: `isolated_method_test / architect_revision_brief`
>
> 本文只决定纸面原型下一步，不升级任何方案为正式C02。

## 一、盲审共识

两名审稿人都能准确复述三案，说明“少量事实先选故事、再定点检索”至少没有再次生产出语义不明的方案。

两份盲审也独立指出了相同缺陷：

1. 纪存有章任务，却没有非做不可的个人欲望、诱惑和风险；他仍像很能干的组织者。
2. 白鸢拥有功能，却没有一件只能由她主动选择、并会令她付出代价的事情；她仍像按时抵达的新岗位。
3. 唐胶比两位主角更像活人，但旧账容易成为单独外挂的忏悔支线。
4. 机器人文化已经进入故事，机器人主体性却不稳定：人类替机体解释立场、选择身体或决定归属。
5. 三案都还没有同时满足“整章规模、机器人角色、主角变化、长期获得感”四项要求。

## 二、两份盲审的有效分歧

- 普通读者排序为 `C > A > B`：C最清楚、最有情感，旧拳王最像角色。
- 机战与游戏审稿排序为 `A > B > C`：A最有章级社会空间、SRPG群体调度和相对C01的体验升级。
- B的“构筑—出击—断部位—回收—永久身体史”是最清楚的玩法商品点，但目前不像完整剧情章。

这不是要投票取平均。它说明：

- C是一则先天成立的机器人角色故事，可保留为后续一至两话的竞技单元，不塞进本次A案。
- B适合单独验证构筑玩法，不拿它承担C02全部人物和航路职责。
- A最适合继续回答本次实验的原问题：Runtime能否帮助主笔从零创造一个比旧C02更清楚、更精彩、同时像“第二章”的故事。

## 三、P4暂选方案

暂以A“木桶街街区与货柜领袖”作为整章候选。

这不是接受P2中已经写出的反派、盗图、旧伙伴、拖运或高潮动作。架构编剧可以删除这些具体设计，甚至重写A的冲突形式；只能保留以下核心方向：

> 万机馆来到一个机器人、工房、收藏与日常生活真正共存的地方。这个地方正在失去继续以原有方式生存的条件。纪存不能只求一份补给，必须让原本互不信任的人与机器人形成一次能够改变现实的共同动作；货柜领袖是拥有自身生活、判断和选择的核心机器人，而非被争夺的贵重物。

如果下列根因无法在一个清楚故事中解决，架构编剧有权判定A不成立并退回选案，不得靠增加设定或支线硬撑。

## 四、重构必须解决的六个问题

### 1. 给纪存一件私人的、会失去的东西

“证明万机馆能帮助别人”仍是正确话，不是人物欲望。

本章必须让纪存面对一个会使自己动摇的现实选择，例如：

- 只要接受某种条件，万机馆便能立刻得到急需的修复与安全去路；
- 若他选择站到木桶街一边，可能失去唯一泊位、补给、航行窗口或团队对他的信任；
- 他的决定必须来自C01之后的创伤、骄傲、责任或渴望，而不是因为他天然知道主题答案。

具体选择由架构编剧创造，但高潮前必须由纪存主动押上一样真实资源或关系，不能只负责识别磨损、联络各家和宣布反击。

### 2. 让白鸢从同一场冲突中长出来

删除“主冲突之外另有一宗盗图案，刚好把白鸢送到现场”的做法。

白鸢必须：

- 在冲突开始前已经为某个现实目的来到木桶街；
- 想完成一件对她本人重要、又与本章核心事件不可分割的作品或行动；
- 她的预演只能让人看见可能性，不能代替驾驶员、机体和工程人员作决定；
- 她至少一次因控制欲、职业野心、误判或害怕作品失去作者而把局势弄坏；
- 最后同行不是奖品，而是她与万机馆彼此都仍需要对方，并且原来的生活已发生不可逆变化。

她和唐胶可以冲突，但不能让两人的火花吞掉纪存的主角位置；她与纪存应在解决同一件事时形成第一层吸引、警惕或互相看见。

### 3. 让货柜领袖拥有一条自己的戏

在大战以前，玩家必须看见它：

- 平时怎样生活或工作；
- 讨厌什么、珍惜什么；
- 曾因自身判断犯过什么错，或坚持过一种会给别人添麻烦的选择；
- 为什么一开始不愿帮助万机馆；
- 最后为何改变或加深自己的决定。

它在高潮中的关键动作必须是它自己的选择，并改变人类原定计划。章末应产生明确、可期待的长期关系：正式加入、可召回伙伴或有清楚条件的未来再会；不能只是完成护送后从故事里蒸发。

### 4. 只保留一个主对手欲望和一条升级因果

P2的拆解商同时强购泊位、吞街、抢机体、盗图和追债，像一个装满反派功能的袋子。

新方案只能有一个主对手及一个最主要欲望。这个欲望应当在木桶街的经济、产业或机器人生活中有现实依据，并且在万机馆到来前就在行动。战斗必须由双方一连串能理解的决定升级出来，不能从产权、经营或创作纠纷一步跳成公开武装抢劫。

对手可以自私、残酷或错误，不必被洗白；但玩家必须能说清：

> 他要什么，为什么现在动手，为什么普通交涉已经不够，为什么最终只能由机器人战斗决定局势。

### 5. 把唐胶的过去接进主因果

唐胶只能保留一件具体旧错。它必须直接造成今天的利益关系、误解、技术习惯或某台机器的处境。

不要同时安排旧伙伴、伪原装、品牌争议、工房背叛和匿名担保。唐胶的旧错应：

- 确实有他的私心，不能再次变成“本意救人，只是流程不透明”；
- 让他失去面子、独门性、信任或一段自我神话；
- 又让他的手艺在今天真正救回某种可能。

对方不必当场原谅他，事情也不必靠公开声明结清。

### 6. 用一个玩家能看懂的主战场完成章级升级

主战场优先是一片连续空间：万机馆停泊处、货运作业区与木桶街主工房带之间有一眼能懂的物理关系。不要预设三层地图、复杂高低轴和大量一次性机关。

大战至少满足：

- 玩家能用一句话说出胜利目标；
- 木桶街探索所得直接改变可操作机体、可用路线或一个显眼地形；
- 货柜领袖、馆守Z、兜灯、小型机器人各做自己尺寸与身体适合的事情；
- 馆守Z不能再次用最后一拳夺走新机体的高潮；
- 不以连续接人、托住坠落物和搬运伤员作为主要快感；
- 胜利首先值得庆祝，再留下现实后果。

## 五、必须保留的章级输出

不限定实现方式，但章末必须自然得到：

- 万机馆补齐一部分B1整备、生活补给与继续航行能力，L1不被临时改成工厂；
- 至少一台具有独立主体、值得长期期待的全尺寸机器人与玩家建立持续关系；
- 白鸢获得登舰的现实原因，并与纪存、唐胶形成已经发生过事情的关系；
- 兜灯、馆守Z、跌跌和机器犬都真正改变一次局势；
- 唐胶的木桶街过去被打开，但没有用一场坦白全部结清；
- 通往工务城的下一步不是比赛奖品或作者硬发的邀请，而是本章行动产生的必要结果；
- 白色采样链可以留下一个可见钩子，但不能解释或操纵本章全部冲突。
