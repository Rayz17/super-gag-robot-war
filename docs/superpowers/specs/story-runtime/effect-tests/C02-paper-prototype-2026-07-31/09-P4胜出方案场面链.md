# P4 胜出方案场面链

> Status: `isolated_method_test / scene-chain candidate`
>
> 判定：A可行，但P2的具体反派、盗图入口、唐胶旧伙伴和拖运高潮全部撤销。以下方案仍是纸面原型，不升级为正式C02。

## 1. 重写后的一句话发动机

为了换取让万机馆安全续航的修复和去路，纪存先答应让它成为标准物流经营者争夺工务城货运线的样板船；当这个选择将使木桶街原有的人与机器人失去生路时，他必须押上万机馆仅剩的修复机会，联合不信任他的货柜领袖夺回主货运道，并把木桶街真正完成的第一批货送上自己的船。

## 2. 全章因果链

1. 木桶街依靠模型铺、修复工房、零件商、普通职业机器人和全尺寸作业机共同维持一套混合货运生态。它效率不稳定，却能让不同年代、不同身体条件的机器人继续工作和生活。
2. 货柜领袖是这套生态的核心。它坚持知道自己在运什么、为谁运，曾因怀疑一只密封货柜有问题而擅自打开，结果毁掉货物并让合作工房背上债务；它此后仍拒绝把自己当成只服从清单的运输工具。
3. 一名本地标准物流经营者已经投入全部资源建设统一装卸线。他唯一要得到的是工务城长期供货线，因为首批订单由谁完成，后续货运就会围绕谁的设备和方法建立；混合工房若再次失败，他便会按既定安排接管整批货运。
4. 万机馆以只能再可靠航行一段的状态抵达。经营者愿意立即补齐它最急需的B1工具、生活补给和出发保障，条件是万机馆担任标准装卸演示的接收船，让他的系统完成首批工务城货物。
5. C01之后，纪存最害怕的是再用一次漂亮但冒险的决定让全舰替自己付账。他把这份有保证的修复看成终于能给同伴安全的机会，因此先接受了经营者的安排，并只向远方的七海报告已经抵达，没有说明万机馆可能无法完成下一段航程。
6. 白鸢在万机馆到来前已经受经营者邀请来到木桶街。她想完成第一件真正由自己署名、能被全尺寸机器人执行的大型现场作品，于是把地形、天气、机体数据和工房出货顺序整理成一套高度整齐的装卸预演。
7. 货柜领袖平日会主动替老机器留出转向位置，也会因为拒绝不明货物让整条货运道停下来。它不愿帮助万机馆，因为纪存刚到便站进标准物流一边，而且它认为博物馆也可能把自己变成供人观看的符号。
8. 唐胶认出白鸢预演中那套过分规整的货柜领袖轮廓来自自己多年前制作的商业演示模型。当年他为了让变形过程漂亮、容易销售，明知实机已有一处笨重但必要的后加支撑，仍在模型里删掉它，并接受了“最懂这台机器”的名声和报酬；那套演示后来成为说服工房相信货柜领袖可以被标准化的材料之一。
9. 第一次联合装卸测试中，现场驾驶员和工房要求为旧机增加停顿与绕行。白鸢害怕作品再次被改到看不出作者，保住了过多统一动作；执行者只能在现场各自避让，货柜领袖又擅自切入帮助一台被夹住的小型载具，最终让主货运道发生大面积堵塞。
10. 经营者据此启动早已准备好的替代方案，以重型标准装卸机占据主货运道并清走混合工房的设备。他不是突然抢劫：若他不能按期装出首批货，自己的投入同样会崩溃；而木桶街工房一旦让路，便会失去足以继续生存的订单。双方都不能再接受单纯停工谈判，工业机体开始用推挤、固定和封路争夺实际作业面。
11. 经营者仍允许万机馆保持中立并完成修复。兜灯明确告诉纪存，一旦离开供能泊位，万机馆现有储备不足以同时维持自身整备和支援街区；如果失败，他们可能被困在木桶街。纪存仍主动断开修复供能，把万机馆的剩余输出交给本地绞盘和工房设备，并开放外泊甲板接收木桶街的货物，押上了自己刚刚向同伴承诺的安全去路。
12. 白鸢发现纪存不是请她画一张新的正确答案，而是要求她把目前真实可行的几条路同时摆出来。她选择放弃经营者的正式发布、尾款和独占署名，把候选预演交给驾驶员、机器人和兜灯删改；她的原计划从作品变成了共同动作的草稿，她也失去原有工作场地和返程安排。
13. 唐胶拆开自己保存的旧演示模型，指出被他删除的后加支撑和历次修补痕迹，并承认自己从未真正懂得货柜领袖的全尺寸身体。货柜领袖亲自说明哪些动作仍属于自己，兜灯和本地工程人员用实机检查确认它能够安全采用其中一种门架动作；唐胶的手艺救回了被他抹掉的身体历史，但不能替实机作决定。
14. 人类原计划让货柜领袖固定在主货运道上充当屏障。它拒绝再次成为别人安排好的工具，临场选择跨过货运道展开成可通行门架，让本地机组从重型装卸阵线头顶越过并进入其后方；它还主动允许一批已经说明责任人的密封货物通过自己，第一次在不拆箱的情况下选择有限信任。
15. 馆守Z以黄色巡展臂固定在巨构泊位的舰船约束桩上，正面牵制经营者的重型装卸总机，但不负责最后击倒。跌跌进入低矮维护道释放被锁死的机械挡块，机器犬把来自B1的实体导引索拖到本地绞盘，兜灯据此把万机馆外泊甲板接入共同装卸路线；货柜领袖带领侧翼机组迫使总机退出主货运道。
16. 木桶街完成首批工务城货物并装上万机馆，胜利首先证明混合机器人生态能够工作，而不是靠声明保住。经营者失去独占这条货运线的事实基础，但带着自己的设备和损失离开，没有被当场说服或洗白。
17. 木桶街用本批货运的实际收入与现有设备补齐万机馆一部分B1整备、生活补给和可拆式工具。货柜领袖以“货物责任必须说明、自己保留拒绝权”为条件正式成为可召回伙伴，并自主随首批货前往工务城。
18. 白鸢需要万机馆提供移动工作场地、设备位置和继续完成这次共同作品的路线，万机馆也需要她为陌生机体和复杂现场提供可讨论的预演，因此双方形成现实合作。她已经看见纪存会在安全和他人之间作出危险选择，纪存也看见她能够亲手放弃作者控制，两人的吸引与警惕从同一件事中开始。
19. 唐胶的旧错只打开没有结清：货柜领袖允许他参与后续修复，却不接受他重新代表自己。章末整理战场记录时，白鸢的远景素材里出现一台无标识白色采样机带走损坏装卸机的一小块材料，只留下与C01相连的可见疑问。

## 3. 六至九个场面的全章场面链

### 场面一：安全去路

万机馆抵达巨构泊位，兜灯确认它只有一次可靠续航余量。标准物流经营者提出立即修复、补给和接入工务城货运线，纪存因害怕再次让全舰冒险而接受。白鸢作为装卸演示的现场创作者出现，货柜领袖在远处看见万机馆站进标准装卸区后拒绝靠近。

### 场面二：木桶街怎样活着

玩家沿一条连续货运道进入主工房带，看见模型修复、职业小机、零件搬运和全尺寸作业彼此依赖。货柜领袖一面为老机器让路，一面因拒运不明密封货柜让整条线停摆，具体呈现它的体贴、固执和曾经造成损失的判断方式。纪存试图请它协助万机馆，被直接拒绝。

### 场面三：漂亮方案里的缺口

白鸢展示标准装卸预演，各机组从身体限制出发提出修改。她接受局部改动，却为了保住作品的统一性拒绝改变核心节奏。唐胶认出预演使用了自己当年的商业模型轮廓，先隐瞒旧事，并用含糊的工艺意见与白鸢发生冲突。

### 场面四：联合测试失败

标准机群、混合工房和万机馆外泊甲板开始第一次联合装卸。旧机无法跟上统一节奏，执行者临时避让，货柜领袖擅自切入救出被夹的小载具，主货运道堵死。白鸢的控制欲和货柜领袖的独断共同把局势弄坏，经营者得到启动替代装卸的现实理由。

### 场面五：谁承担失败

重型标准装卸机进入主货运道，混合工房拒绝撤走自己的机器，推挤与封路开始。经营者保证只要万机馆保持中立，修复与去路仍然有效。唐胶向纪存、白鸢和货柜领袖承认商业模型的删改，货柜领袖进一步拒绝成为任何一方的计划工具。

### 场面六：押上万机馆

兜灯给出清楚代价：断开供能泊位便可能无法离开。纪存仍切断修复供能、开放外泊甲板并把剩余输出交给木桶街，第一次把自己的安全渴望和航路信誉押进选择。白鸢放弃正式发布与独占署名，将多套候选行动交给现场采用和修改；唐胶修复被自己抹掉的模型版本，兜灯与货柜领袖完成实机核验。

### 场面七：主货运道争夺战

胜利目标是一句话：夺回主货运道和总吊架，让木桶街完成首批装货。探索中取得的机组、侧面维护道和绞盘直接进入战斗；馆守Z固定并牵制重型总机，兜灯接通外泊甲板，跌跌释放机械挡块，机器犬拖设导引索。货柜领袖拒绝原定的固定屏障角色，自主展开成跨道门架，改变进攻方向并带领侧翼迫使总机退出作业面。

### 场面八：真正出发的第一批货

木桶街在庆祝中完成装货，万机馆得到B1工具、补给、同行技术人员和前往工务城的真实任务。货柜领袖提出自己的合作条件并成为可召回伙伴，白鸢以移动工作换取登舰条件，唐胶只取得继续修补错误的机会。万机馆离泊后，远景记录里出现白色采样机的短暂身影，但它不改变本章胜负。

## 4. C02E01的三至五个场面链

### E01-1：只报平安

万机馆接近木桶街，舰内仍保留C01战损后的临时生活状态。兜灯确认现有补给和整备只能支持一次可靠续航，纪存收到七海的私人通讯，却只回复已经抵达，没有说明舰况和自己尚无下一步。

### E01-2：停进唯一能接住它的地方

万机馆进入巨构泊位，馆守Z停在外部整备位置，黄色巡展臂首次以日常搬运而非战斗方式帮助卸下破损设备。跌跌与机器犬从B1货运升降区进入泊位，玩家第一次看见小机器人、模型货箱、普通职业机和全尺寸作业机共用同一条物流线。

### E01-3：货柜领袖拒绝一个箱子

货柜领袖以载具形态运送多个工房的货物，又在发现一只责任人不明的密封货柜后停下整条队伍。它主动替行动迟缓的老机器腾出道路，却拒绝为恢复效率而服从催促；周围人的不满说明这种坚持过去已经造成真实损失。

### E01-4：纪存接受安全方案

标准物流经营者向纪存展示可立即补入B1的工具、生活物资和去工务城的装运安排，白鸢以本次标准装卸演示的创作者身份介绍自己的预演工作。纪存选择让万机馆担任接收船，以换取确定的修复和航路。货柜领袖看见这一选择后拒绝纪存的协作请求，唐胶则认出白鸢图中的熟悉轮廓而没有说出原因，E01结束在三个尚未公开的裂口上。

## 5. C02E01人物、机体、地点和移动关系的白话空间预演

### 一眼能懂的地点关系

木桶街这一段只需要一条主轴。最内侧是连续的主工房带，中间是一条足够全尺寸作业机通行的主货运道，货运道向外经过标准装卸场和总吊架，最后抵达巨构泊位；万机馆停在泊位最外端，外泊甲板正对总吊架。主货运道旁有一条较窄的维护道，连接工房带和泊位设备，但E01只让玩家看见，不把它当机关使用。

### 人物与机体初始位置

- 纪存、唐胶和兜灯最初在万机馆内。纪存从指挥位置观察进港，兜灯往返B1和外泊甲板确认整备，唐胶跟随货运升降设施下船。
- 馆守Z始终位于万机馆外泊甲板与巨构泊位相接的位置，不进入街内。它用黄色巡展臂搬运破损设备，完整左拳保持收拢，先建立生活尺度。
- 跌跌和机器犬从B1货运升降区下到泊位地面，沿主货运道边缘活动。它们能进入小型机器人使用的空间，但不会离开玩家视线独自解谜。
- 货柜领袖最初在主工房带取货，以载具形态沿主货运道朝泊位移动。它在标准装卸场前因密封货柜停下，并在那里第一次与纪存正面接触。
- 白鸢和标准物流经营者最初位于标准装卸场。两人沿主货运道走向万机馆说明演示计划，白鸢的工作位置随后设在能同时看见总吊架、货运道和万机馆外泊甲板的地面观察区。

### E01移动顺序

1. 万机馆从外部航路进入巨构泊位并固定，整艘舰不再移动。
2. 纪存、唐胶、兜灯、跌跌和机器犬从万机馆经货运升降区下到泊位，再沿主货运道向工房带移动。
3. 货柜领袖从相反方向带货驶来，在标准装卸场停住，使纪存一行与木桶街工作队自然相遇。
4. 货柜领袖拒绝密封货柜后返回主工房带，不经过万机馆；它与纪存的距离重新拉开。
5. 纪存随经营者和白鸢返回泊位查看B1补给与装运位置，唐胶在白鸢的预演图前停留，兜灯回到外泊甲板核对真实能力。
6. E01结束时，纪存站在万机馆与标准装卸场之间，货柜领袖留在工房带，唐胶夹在白鸢的预演与真实街区之间，人物立场和物理位置保持一致。

## 6. 主动删除P2内容及原因

1. **删除外来拆解商强购泊位、吞街和抢夺货柜领袖。**这些功能使反派欲望过多，也会让经济冲突直接跳成武装抢劫。新对手只争夺工务城长期货运线，所有升级都来自谁能实际完成首批货运。
2. **删除白鸢追查盗图。**盗图是主因果之外的额外案件，只能把她送到现场。修订后她从一开始就是标准装卸演示的创作者，她的野心、错误、损失和登舰理由都发生在同一场冲突中。
3. **删除唐胶的伪原装修复、旧伙伴和公开和解。**三者会形成独立忏悔支线。修订后他只有一次旧错：为商业演示删掉货柜领袖真实身体历史并从中获利，这件事直接帮助了今天的标准化误解。
4. **删除把货柜领袖当作被争夺的贵重整机。**它现在拥有日常工作、明确厌恶、一次真实误判、对万机馆的拒绝和临场改变战术的自主决定。人类不能替它决定归属或合作条件。
5. **删除纪存“证明万机馆能帮助别人”的泛化目标。**他的私人诱惑改成获得确定修复和安全去路，私人风险则是主动放弃这份保障并可能失去续航、同伴信任和对七海隐瞒舰况后的退路。
6. **删除馆守Z抓住吊索托举整排平台。**新战场只让它固定在可约束百米级舰船的泊位主桩上，承担正面牵制；最后改变战局和迫使对手退出货运道的是货柜领袖自己的选择。
7. **删除L1整层改造成维修与生活区。**章末只补强既有B1重型维修架、工具、人员和可拆式设备，大型伙伴使用外泊甲板，不迁移L1展陈功能。
8. **删除多层街区、复杂吊架机关和逐户取得许可。**主战场压成“主工房带—主货运道—标准装卸场—巨构泊位—万机馆外泊甲板”一条连续空间，探索所得只改变参战机组、侧面维护道和绞盘。
9. **删除货柜领袖只护送一程后离场。**它在章末建立具有明确条件的可召回关系，并自主参与工务城首批货运；同时保留它拒绝不明货物和拒绝被代表的权利。
10. **删除以拆解、接人、托举和搬运伤员作为大战主要快感。**新战斗的核心是争夺连续作业面、突破重型装卸阵线和让多种机器人以自身身体夺回共同劳动能力，完成装货是胜利结果而不是反复护送玩法。
