# C02E01 Reader短样

## 1. 只报平安

万机馆正沿木桶街外缘的引导灯缓慢靠近巨构泊位。纪存在B1货运升降区上方的观察窗前看着距离缩短，兜灯蹲在他脚边，把舰体刚报上来的数字一项项换成他们接下来能做的事。

“靠岸以后，木桶街能替我们修回一部分。”兜灯用指节敲了敲屏幕，“但没修好以前，现有储备只够再稳稳当当地走一程。”

纪存看着前方。木桶街能容下万机馆的地方只有一处，两侧作业塔已经亮起接引灯。

“一程有多远？”

“够到一个肯接手大修的地方。中途别改主意，也别再挨一下。”兜灯起身，把屏幕塞给他，“这回要说给谁听，你自己挑。”

纪存的私人通讯正好亮了。

七海坐在原城调查处门外的长椅上，胸前还挂着临时通行牌。门缝里有人念她的名字，她抬手示意再等一分钟，转回来先看纪存身后的窗。

“你那边在动。”

“最后一点。”

“所以，到了吗？”

泊位还在缓慢迎面靠近。纪存把镜头往上抬了些，不让她看见手里的舰况。

“到了。”

七海没有立刻接话。她靠回墙上，像是把这两个字翻过来检查了一遍。

“馆呢？”

“在。”

“馆守Z？”

“也在。”

“你呢？”

“七海，我拿的是自己的通讯器。”

她终于笑了一下。“这只能证明通讯器还跟着你。下一站定了吗？”

纪存低头看见屏幕最下方那条只够一程的余量。

“先把木桶街这边办完。”

“纪存。”

调查室的门又开了。里面的人这回没有叫她，只扶着门等。

七海站起来，把通行牌翻回正面。“行。你先欠我一句完整版。我出来以后会问第二遍。”

“等你出来。”

两个人都没有先按结束。门边的人轻轻咳了一声，七海才把通讯切断。

兜灯已经提起工具包，往B1内侧走了两步。

“下一站没定。”她说，“这句你也没说。”

“她还在接受调查。”

“舰况不会因为她听见就再坏一点。”

纪存把屏幕还给她。“准备靠岸吧。”

## 2. 靠岸

万机馆进入木桶街唯一的巨构泊位。两侧固定臂依次合拢，泊位信号由红转绿。固定完成以后，万机馆便留在原位，不再移动。

馆守Z站在最外侧的泊位作业区。它把完整的左拳收在身侧，只用那条不能握拳的黄色巡展臂工作。夹持器从外泊甲板上托起一台烧坏的设备柜，转身时先停一下，等地面人员退开，再把柜子放进岸上的检修区。巡展臂合不成拳，搬东西倒比左手稳。

兜灯没有跟纪存他们进街。她从B1跑到外泊甲板，盯着第一批设备落地，又折回岸上供电处看了一遍。

“我就在这三处转。”她在通讯里说，“B1有动静叫我，岸上的电断了也叫我。最好都别叫。”

B1货运升降台落到地面。纪存、唐胶、跌跌和机器犬一起下船。唐胶亲自拖着一只边角包了布的修复箱，机器犬刚想凑近闻，他便把箱子换到另一只手。

“闻路。”唐胶说，“别闻病人。”

机器犬转头去闻货运道，差点把鼻子伸进一筐滚动的螺栓里。跌跌一把拽住它的尾把。

他们贴着主货运道边缘往里走。前面一家零件铺正把一只新轮毂推到门口，一台全尺寸作业机就在路边屈膝换轮，半条路都被它的小腿占住。挂着模型修复牌的小型职业机拖来两只透明修复箱，没有绕行，只从那台大机器收起的脚掌旁贴过去。

最外侧的修复箱蹭歪了螺栓筐。机器犬咬住筐沿，跌跌跪下来捡滚远的两颗螺栓。全尺寸作业机便把脚再抬高一点，等他们都钻出来，才让零件铺继续装轮。

唐胶护着自己的箱子从它脚下经过，抬头看了看那条横在半空的机械腿。

“这里修模型和修实机，是按谁先伸脚排队吗？”

小型职业机从前面回了一声短促的喇叭，像在催他别挡路。

主货运道再往里，便是标准装卸场。几台带着同一标记的装卸机停在场边，一个负责人正在逐台核对。白鸢的工作位就在总吊架下方，她撑着测量杆，对着远处已经固定的万机馆记下新数字。

纪存一行还没走到她面前，主工房带方向先传来两声低沉的车鸣。

## 3. 货柜领袖拒绝一个箱子

一支载货队列从主工房带驶入主货运道。领头的重型载具比后面的货柜宽出一截，车首低，车身两侧收着门架。它没有展开作业形态，只以载具形态缓慢领队。

一台行动迟缓的老清扫机正横过路口，身后的集尘箱歪向一边。货柜领袖提前停下，前轮转向路边，也让后车依次偏过去。老清扫机花了很久才走完，抬起刷盘向它晃了晃。货柜领袖回了一下车灯，等路口彻底空出来才继续。

每经过一只柜子，它车侧的检查灯便扫过实体编号。它同时念出任务清单和责任人，后车听到一致才起步。

“柜身一七二。任务一七二。责任人有签名。走。”

下一只密封柜来到它身边。检查灯从柜门移到清单，又移回来。

“柜身一七四。任务单写一七九。责任人栏空着。”

货柜领袖亮起刹车灯。

“这只不走。后车停。”

整支队列停在标准装卸场前，后方很快排起等路的小车。标准线负责人从自己的机群旁赶过来。白鸢也放下测量杆，拿着手里的总清单走了几步。纪存他们正好从外侧到达，五拨人和机器被同一只柜子拦在场边。

一名装卸员先爬上柜门，用袖口把编号擦了一遍。

“漆没掉，就是抄错了。先运过去，到了工务城再补。”

“谁补？”货柜领袖问。

装卸员看向负责人。

负责人接过清单。“这一批归标准线。责任先写我的名字。”

“柜身和任务单还是两只柜子。”

“先把一七九划掉。”

“凭哪一份划？”

负责人没有乱答。他转身叫人联系交货方。连拨两次，对面都无人接听。

旁边一名工房师傅等得烦了，隔着后车喊：“你上回也是觉得箱子不对。你自己把门开了，里面那批货受潮，合作工房停了一个多月。现在一张纸又要拦整条路？”

货柜领袖没有把声音调高。

“上回是我开的。赔单在我那里，损失也是我记着。今天我没碰封条。”

它把车首对准那只密封柜。

“编号、任务和责任人对上，我再运。”

白鸢翻到自己收到的货物页，又走近看了看柜门。“我这里也是一七九，责任人这一格确实没有。昨天确认总清单的时候，它就是空的。”

“那先别让它进场。”纪存说。

负责人转向他。

纪存指了指场边那几台带有负责人标记的装卸机。“你的机器能把它单独移出主路吗？不拆，不改编号，先让后面的车走。”

“能。”

负责人叫来两台自己的装卸机。它们从密封柜两侧托住底部，把柜子移到场边空位。白鸢撕下一张纸，写上三处待核，贴到柜门最显眼的位置。

货柜领袖的检查灯在纸上停了停，又转到纪存身上。

“这只留下。其余跟我走。”

它松开刹车，带着后车驶入标准装卸场。堵住的主货运道重新流动起来。

## 4. 纪存接受安全交易

负责人没有急着谈远处的事。他先领纪存看场边已经备好的东西：一组能立刻去外泊位开工的检修班，两车B1急需的工具，封好的生活补给，还有排在总吊架下等待装船的货。

“这些今天就能给你们。”负责人说，“检修先上船，工具先下B1，不用等装货结束。”

纪存逐项看过封签，又把工具清单发给兜灯。她很快从外泊甲板回话。

“东西对。岸上也真有人能修。做完这些，去工务城那一程能走稳。”

“再往后呢？”

“到了再修。别临时换地方。”

负责人等他们说完，才把交付文件递给纪存。

这批货是标准装卸线的首航货，要送去工务城做交付验收。负责人有这一批次，有总吊架接下来的操作时段，也有场边那组装卸机。他筹备多年，缺的是一艘能把整批货直接送到工务城的大型接收船。现在泊位里只有万机馆合适。

“我不是让你替我赌。”他说，“工务城会接收，也能继续修你们。那只编号不对的柜子留在这里，什么时候三处对上，什么时候再谈。”

白鸢把工作台推近。她原本已经做完一套通用预演，万机馆靠泊以后，才把这艘百余米巨构的真实位置和尺寸补进去。屏幕一角署着她的名字：Evelyn Voss。

“我接这份工作的时候，还不知道来的会是万机馆。”她按住一张被风掀起的尺寸表，“通用版只能先用可靠资料。现在实船就在这里，我把船位补完，总吊架和全尺寸现场就能第一次完整跑起来。”

她说到“完整跑起来”时快了一点，手指也已经移向下一项数据。负责人提醒她先等纪存答复，她才把手收回来。

唐胶站在屏幕侧后方，本来还在看万机馆的尺寸，视线忽然停在一幅载具轮廓上。

那是预演里的货柜领袖。车身后段有一处被削平的转角，底边还多了一小段不必要的退让。唐胶认得那个改法，也认得先删哪一条、再补哪一条才会留下这样的轮廓。多年前，动手的人就是他。

他的鞋尖抵住了自己从万机馆带下来的修复箱。

“这个轮廓哪来的？”他问。

白鸢立刻转过来。“旧商业模型。来源和版本都被标成可靠资料。怎么了？”

唐胶张了张嘴。

“车尾太顺。”他说完又摆手，“我是说，商业模型一般都爱把实机修得顺眼。老毛病。你继续。”

白鸢仍看着他。“你见过原件？”

“我见过的模型多了。病人不能算熟人。”

他低头去整理修复箱的提带，没有再看屏幕。

纪存重新走到补给车前。泊位那边，馆守Z正用黄色巡展臂把第二台破损设备搬下船。完整的左拳仍收在身侧。B1入口处，跌跌和机器犬已经在等第一车工具。

纪存翻到文件最后一页。

“检修现在开始，工具和生活补给先上。”他说，“那只柜子继续留在岸上。其余货，万机馆接。”

负责人签下自己的名字。白鸢吸了一口气，立刻俯身把万机馆的最后一组尺寸填进预演。

万机馆没有再移动。总吊架沿轨道来到它上方，标准装卸位的地面灯从内向外逐段亮起，把已经固定的万机馆完整圈入装卸范围。负责人的装卸机群同时启动，转向第一批货。

货柜领袖停在场地另一端。它看见吊架就位，也从现场扩音里听见了纪存接受交易。

纪存走到它车首左侧，站在它能看见的位置。

“一七四号柜不动。”他说，“剩下的装卸，我想请你带队。”

“不接。”

纪存停了一下。“你刚才同意运其余的货。”

“运到这里。没有同意进入她的预演。”

白鸢看向屏幕。那幅来自旧商业模型的轮廓，正处在总吊架动作线的中央。

纪存说：“合同写的是接收船和货。负责人有自己的机群。你的参与，我现在问。”

货柜领袖的检查灯转向亮起的装卸位，又转向屏幕上的自己。

“船已经进位，吊架已经过来，图上也早就有我的身体。你不是现在才需要我的回答。”

它把门架往车身里收紧。

“我现在不知道，你问我的话还算不算数。所以我不跟你协作。”

货柜领袖倒出装卸场，等一台沿共用货运道经过的小车先走，才转向主工房带。它始终保持载具形态，没有回头。

纪存的私人通讯又亮了一次。七海发来四个字：完整版呢？

他看了片刻，把通讯调成静音，屏幕朝下放在交付文件旁边。

白鸢仍停在那幅轮廓前。她回头问唐胶：“你刚才说车尾怎么了？”

“没怎么。”唐胶把修复箱推到工作台更深处，“大船靠得挺正。先忙大船。”

箱子里有一件东西轻轻碰了下内壁。屏幕上，那道由他多年前亲手删改出来的轮廓还亮着。
