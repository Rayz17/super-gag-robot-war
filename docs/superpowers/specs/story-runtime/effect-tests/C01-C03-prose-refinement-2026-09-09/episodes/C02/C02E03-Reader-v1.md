# C02E03《逆转天冲拳！师徒真打》

### 夜里开柜

第二日夜里，货运环上的灯已经熄了一半，合作社资料室还挤着人。

赵梅把傍晚从钥匙圈上拆下来的钥匙插进柜门，却没有马上转动。历任物主、维修人和仍在木桶街的工房代表都已到场，不能赶来的人开着远程画面，谁也没催她。

白鸢坐在赵梅白天答应留下的椅子上，行李箱仍靠在脚边。她把自己的分镜本压在膝上，没有放到柜前。

胶价王最后一个进门，怀里夹着两只从舞台库搬来的纸箱。他一进来就看见白鸢。

“站外、入场页、北侧投影都撤干净了。”

“还有合作社门口那块。”

“也撤了。”胶价王把纸箱抱高一点，“刚从舞台库找出来的，你先看看这个。”

唐胶站在老工作台旁。他一晚上没碰那张桌子，等赵梅核过到场的人，才问：“人齐了？”

“到不了的人都开着远程。”赵梅转动钥匙，“开吧。”

柜门打开，维修册挤着舞台稿，宣传胶片压着退件箱。赵梅抽出最下面一只塌角纸箱，先放到脚边，才把历年的记录一册册搬出来。纸张和工房印记，换过不知多少次。

赵梅把三类东西分别放上桌。

“我按年分过了。最早的在上面。”

白鸢先从胶价王带来的纸箱里抽出一张舞台调度稿。

她只看了页眉，便把纸翻过来，让所有人看见右下角的年份。

“这不是我画图的那一年。”

七海的远程窗口在工作台另一端接通。她仍留在原城的调查等候区，面前摊着项目历次授权的时间记录。

“早很多。”七海说，“先看原件。白鸢的文件排在后面。”

胶价王抱起纸箱，领着众人往舞台库走。

### 最终话先没有播出

舞台库就在合作社后街。卷门升起时，里面先露出一排拆下来的背景板，接着是模具箱、没有用完的售票牌和一座躺倒的宣传机头部外壳。

胶价王把纸箱放到当年的调度桌上，从最底下取出一卷原始预告胶片。白鸢没有碰播放设备，她先检查了胶片盒上的手写编号，再对照舞台调度稿。

两边一致。

当年的预告没有完整动画，只有配音、连续分镜和用于舞台宣传的静止画面，但最终话的故事已经排完。

敌方轨道堡垒进入地球上空，主炮对准完全版王者守了一整季的城市。王者在突入途中依次损失长翼、双盾、钻进组件和重炮，只剩受损的基础身体，仍被最后一道发射闸挡在炮口外。

A-7从堡垒内部的维护通道赶到。它没有站在外面替王者承受一发炮击，而是冲进即将闭合的发射闸，用自己的双臂和左肩把闸门撑开。下一张分镜里，它拆下胸前护甲和通路钥匙，一起送向王者。调度稿写得很清楚：王者将以A-7的护甲穿过高热炮道，打进堡垒核心；A-7则留在闸内，负责让唯一的通路保持开启。

最后一组分镜上，完全版王者把全季残存装备合在一击里，沿A-7撑开的通路贯穿轨道堡垒。主炮在城市上空解体。王者独自降落在黎明的基地，胸前多了A-7留下的护甲；它连续呼叫三次，通讯里都没有回答。

舞台调度稿在最后一页写着：

`A-7留在发射闸内，信号中断。王者单机返航。`

这套最终话在进入正式动画制作前停摆，宣传实机的后续巡演也一并撤销。

完全版王者和A-7的故事，先死在了播出以前。

纪存看向白鸢。她已经把自己的分镜本打开，翻到那张把A-7拉出发射闸的补图。

“我不是原作作者。”她说，“三年前，杂鱼港想做一次失落最终话复播，委托White Kite补缺页。我拿到的就是这份原分镜。”

她把后来补的几页排在原稿旁边。

原稿里，A-7送出护甲以后留在发射闸内。白鸢把王者接过护甲、继续冲向核心的那一格删掉，改成王者在闸门合拢前回头抓住A-7。两台机体都离开了必死位置，轨道堡垒的主炮却仍然在充能。她把下一页留成白色。

“我当时只想先把它拉出来。”白鸢的手指停在空页边缘，“可王者一回头，谁去停主炮，我没想出来。复播企划后来也停了。”

纪存翻向后面，才发现真的没有下一张了。他把空页放回原处。

七海把委托日期标在补图旁。两份稿件隔着很多年，不能再被宣传片剪成同一个结局。

胶价王没有躲开白鸢的目光。

“复播没做成，文件留在杂鱼港的项目库。本届宣传包从那里调了图，没有重新找你。”

“可这份委托上也有你的名字。”

“下午我只说是项目库出了问题，没说当年就是我找你补的图。”胶价王说，“现在说清楚：这次拿‘失落最终话’做卖点，也是我定的。”

唐胶一直在看原分镜里的身体姿势。他伸手比了一下A-7腰部那道转线，又把手收了回来。

“图能说明当年想演什么。”他说，“外面那两台是不是当年的机器，靠这几张认不了。”

众人带着舞台调度稿，回到全尺寸工房。

### 工号在漆下面

无牌一号已经在检修位停稳。两侧支架承住身体，兜灯确认过四周安全，才让低位检查开始。

“得打开这块护板。”纪存仰头说，“里面可能有你过去的工号。查吗？”

“查。”无牌一号回答。

另一处维护位上，完全版王者听见了。它没有等人去问，先收起外翼和盾组，自己打开了大腿外侧一块一直被追加装备挡住的护板。

“我的也查。”

跌跌戴好手套，蹲到无牌一号膝部外侧。机器犬紧跟在安全线内，鼻尖贴近一处颜色不同的检修盖，低低叫了一声。跌跌用布擦去盖板边沿积下的油灰，一排被新漆盖住大半的冲印字符慢慢露了出来。

赵梅翻开最早一册维修页。工号相同，授权牌拆掉后留下的四个孔，也与工单照片分毫不差。

完全版王者那边也传来了兜灯的声音。

“找到了。”

完全版王者也保留着同一时期的工号。后来追加翼组、换盾换炮，里面的冲印始终没动过。

白鸢从两台机之间退开。她画过那么多遍的身体，原来一直站在这里，只是换了许多东西，连名字也换了。

七海把两处机身近照与舞台调度表附带的资产记录放在一起。

“眼前这两副身体，就是当年的全尺寸宣传实机。不是后来照着图另做的。”

记录往后翻，两台机离开舞台，辗转过不同物主与工房，又进了地方赛事。有人给它们换零件，有人修旧伤；每翻几页，便换一种笔迹。

无牌一号腰髋外侧那圈不规则的修补边界，第一次出现在其中一册中段。

唐胶看见那一页，终于走近了。

“这几笔是我的。”

### 妈妈从“我不会”开始回信

赵梅把从资料柜底层取出的塌角纸箱也带了过来，放在工房检查台旁。寄件标签上的账号叫“牛牛补件”。

唐胶看见那四个字，搭在桌边的手收了回去。

“这个号还在？”

“在，我一直用着。”赵梅把纸箱放稳，“他走了以后，还有人来问。”

她的儿子去世以后，订单和求件消息仍不断发来。赵梅没有假装自己会修。她找出的第一封回复只有一句很普通的话：

`我是他妈妈。这个我看不懂。你要是愿意等，我去问。`

纸箱里留着她最早寄错的两件东西。第一回左右发反，第二回方向对了，材料又不对。退件单、赔付记录和重新寄出的运单都夹在一起。

远程画面里，一位老物主举起同样的退件纸。

“第一箱是我退的。我画了个特别大的箭头，话也不太客气。”

赵梅说：“箭头有用。第二次我至少没再发反。”

检查台边有人笑了。远程画面里的老物主也笑，随后把那张退件纸放正。

“后来我每次问，她都先说不会。”他说，“但她真会找人。问到第三个，事情就能接着走。”

赵梅翻开最早的笔记。前几页写的都是日常词：

`机体自己的左。`

`这个颜色不是材料名。`

`别猜，先打电话。`

每句话旁边都有一个联系人。有人补图，有人改掉她记错的型号，有人把只会口传的手艺写成别人也能照着查的步骤。最初只有她家里一张桌，后来模型师、打印师、工程员和物主把自己的工位也接了进来，才成了今天的合作社。

说话间，那个账号又收到一张求件照片。赵梅没有硬答，也没有让消息停在儿子的头像下面。她把照片转进合作社工作群，叫了两个真正做过这种件的人。

“现在还是有人以为回信的是他。”赵梅说，“我每次都重新说一遍，是我。”

纸箱底下还有一具手掌高的动作样机。它没有头，也没有完整手臂，只能做出护住、转腰和踏步三个姿势。旁边一张便笺写着：

`接住以后，往前。别让它一直留在那里。`

唐胶认出自己画过的辅助线，伸手托起样机，指腹在那道接缝上停了停。

赵梅儿子照着做过小样，后来的工房据此重新设计了实机腰髋。唐胶翻到改造后的照片：无牌一号往前迈步，旁边的人扶着它，脸都拍糊了。

“他知道后面怎么打吗？”无牌一号问。

赵梅摇头。

“不知道。他连你今天会站在这里都不知道。”

她把那张便笺放在样机旁边。

“他只是觉得，你不该每次都停在那儿。”

无牌一号低头看了很久，随后抬起右拳，缓慢收回腰侧。左脚向前踏出时，身体仍然晃了一下。

兜灯在检查台下看完这一遍。“关节没卡。明早我再给你查一次，别连夜练了。”

唐胶没有抢过检查工作，只把样机的现有资料交给合作社工房员。

“这几张也留好。以后修腰髋，得跟今天的检查一起看。”

天快亮了。半决赛入场提示沿货运环亮起，旧拳王已经在红环里等候。

### 它们还愿意比赛吗

白鸢把自己的补图从展示顺序里抽了出来。

“我的这几页，先别播了吧。”

七海在远程窗口里立刻发现中间少了一段。

“为什么？”七海问，“它昨天那个动作，和你补的这一页很像。省掉这几张，它们看不出区别。”

“它上午就要比赛了。”白鸢按住空白页，“原稿要它死，我说能救它，结果只画到这里。它看完以后，还打得下去吗？”

纪存站在两人中间，看着工作台上那一段被抽空的位置。

“它已经想不明白自己为什么停住了。”纪存说，“我们查了一夜，不能到了这儿又瞒着它。”

“纪存。”七海叫住他，“先去问清楚。它看完以后要是不打，赛事有没有地方让它退出？”

纪存没有继续争。他转身去找胶价王。

胶价王已经在门口听完了后半段。他把随身价格屏放上工位台，先调出半决赛的退票数、赞助扣款和冠军转子安排。

“无牌一号退出，它这一边停赛。完全版王者退出，另一边也停。直播空一场，观众退一场。万机馆拿不到转子，木桶街也少一大笔搬迁款。”

“该退多少，你列给我。”纪存说，“它们不打，转子我们另想办法。”

胶价王盯着他看了片刻，把两条半决赛的自动入场提示一起关掉。

“行。它们谁要退出，我就停谁的比赛。”

白鸢松开了手。

七海把退票页发给纪存，等他看完，才轻声问：“你想清楚了？”

纪存点头。“它真不想打，就停。”

“好。我把这份留着。”

胶价王没有让那页账停太久。他又翻出另一组数：模具在仓库存放两年的租金、迁址运输、积压订单、下一处全尺寸工位的设备缺口，以及失落最终话如果复播能够换来的预售和授权收入。

白鸢看完了。

“这些钱是真的。”她说，“你拿我的补图去卖A-7再死一次，也是真的。”

胶价王把价格屏朝向所有人，没有收回。

“没骂错，但是冷门货堆在仓库两年时，难道用情怀付租金吗？”

他点开预售页。最醒目的标题仍然是“失落牺牲结局重现”。

“那批订单还没做完，人家钱早付了。新工位不开，我拿什么交货？”胶价王说到这里，声音低下来，“可它现在站在外面。我还一直照着那张预售表办事。”

赵梅把那张预售页往下推了推。“这笔成本我认。最终话怎么演，先问它们。”

胶价王没有还价。

原企划的影像按现有许可保留在私人展示里；白鸢的补图由她本人限定为只给两台机体看，不进入公开宣传；今天比赛是否继续播，等两台机体自己回答。

原稿、白鸢的补图、后来留下的维修照片，按年份排上工房的屏幕。纪存检查过，才走到两台机体面前。

“资料里写了你们原定的最终话。”他说，“无牌一号会在那一话消失。现在愿意看吗？”

无牌一号先回答。

“完整地看。”

完全版王者展开了一半外翼，又慢慢收回。

“播到没播出的地方。”

### 两台机体看完以后

工房墙上放起原始预告。无牌一号看到发射闸合拢，低头看了看自己的双臂；完全版王者一直盯着独自返航的画面，直到预告结束也没转头。

白鸢的补图接了上去。王者回身拉出A-7，然后是那张空白页。

“后面这几张才是我画的。”白鸢站在两台机都看得见的地方，声音比刚才轻了，“没有再往后。”

无牌一号抬起双臂，做出撑开发射闸的动作。

“你的图也停在这里。”

“是。”

“你不知道我后来做什么。”

白鸢低头看着那张空页。“不知道。”

维修记录接在空白以后出现。屏幕上没有新动画，只有两副实机在不同工房、不同赛事和不同物主手中留下的伤痕与修补。无牌一号看见了那具腰髋动作样机，也看见后面一整册全尺寸工房的签字。

完全版王者忽然抬起一面盾。

“最终话还没有结束。”

它看向无牌一号，背后的重炮转回朝海的安全方向。

“决赛，我们找第三种结局。”

无牌一号没有站到它的护甲交接位置。

“旧拳王在等我。”它说，“半决赛先打。”

完全版王者把盾重新扣回手臂。

“坞工杰克也在。”

胶价王走到两台机体之间，第一次没有先举麦克风。

“上午的比赛，照常公开播吗？”

无牌一号说：“播今天的。”

完全版王者说：“全套都播。”

胶价王这才把麦克风别回领口。他删掉预售页上那条“牺牲结局重现”，换成了已经发生的四强签表。

半决赛入场提示重新出现在货运环上。

### 第一场，完全版没有少带一件

第三日上午，非致命界外擂台沿货运环内侧展开。

半决赛不累计小分，也不要求击毁。让对手整机越过红色界线，这一场就结束。

九米冠军转子仍封在中央运输架上。看台上能同时看见它和两场半决赛的出入口，胶价王没有再把分镜放上巨幕，只报今天真正站在场上的四台机体。

第一场，完全版王者对坞工杰克。

完全版王者入场时仍然背着长翼、盾组、钻进组件和背负式重炮。原剧本中的护甲交接尚未发生；它今天带来的每一件装备，都是这些年在真实比赛里逐步换上的。昨夜看完最终话以后，它一件也没卸。

坞工杰克把两支举升臂压得极低。

铃声一响，它没有去撞盾，而是从完全版王者的正面火力下方贴地冲入。举升臂沿两侧插进冠军的重心下方，四只承重轮同时咬住地面。

二十米高的完全版王者连同全套装备，被整机顶离了擂台。

背负重炮在空中晃过一道巨大的影子。看台上的欢呼一下变了声。坞工杰克没有急着摔它，只托着这副比自己高得多的身体，稳稳朝界外推进。

完全版王者没有丢炮，也没有拆盾。

完全版王者用双盾压住举升臂，背后长翼轰然展开。坞工杰克想把它举出界，它却借势跃过对手，带着全套装备落在了身后。

擂台震起一圈尘土。坞工杰克面前忽然空了。

坞工杰克立即转向，完全版王者已经把两面盾并到它背后。

冠军没有开炮。它推着那副低矮结实的作业身体向前走，坞工杰克的承重轮在地面留下四道深痕，仍然没能在边界前转回车头。

最后一只轮子越过界线。

第一场半决赛结束。

完全版王者把盾分开，给坞工杰克留出回场的位置。坞工杰克收起举升臂，向它按了一声低沉喇叭。

完全版王者以同样的声音敲了一下盾面。

胶价王举起麦克风。

“完全版王者进入决赛！各位，装备清单都看见了，想照着买的也得先会这一跳！”

冠军没有留在胜者位摆姿势。它转身看向第二座出入口。

无牌一号和旧拳王已经分别站在界外线两端。

### 第二场，逆转天冲拳

旧拳王走上红环，对无牌一号抬起右拳。

“看完了？”

“看完了。”无牌一号说。

“还想打？”

“想。”

旧拳王摆好架势。

“好。昨天我喂你拳，今天可没那么便宜了。”

铃声响起。

无牌一号等着接拳。旧拳王却只用短促的刺拳和假动作，一次次碰开它抬起的手臂，每次都在力量真正压上来以前收走。无牌一号能挡，却蓄不起资格赛那样的冲击；右拳始终停在身前。

旧拳王连续三次逼退它，把它压到红环边缘。

“明白了吗？”旧拳王问，“等别人把力量送给你，这一拳一辈子也练不成。”

它第四次逼近。无牌一号没有后退，反而迎着拳锋跨进旧拳王的攻击距离。第一记重拳这才完整地砸在它的左臂上。

十六米的身体猛地一沉。

它接住了。

右拳随着冲击收回腰侧，脚下的红环向外震开一圈尘土。旧拳王没有留情，左拳紧跟着轰向它还没来得及合拢的胸前。

无牌一号朝前踏出第一步。

左拳擦过肩甲。它没有被打回原位，反而挤进了旧拳王怀里。两台巨机的装甲近得几乎贴在一起，旧拳王已经来不及再拉开距离。

“就是这里！”旧拳王喝道。

无牌一号踏下第二步。

积在肩、腰和右臂里的力量同时向前爆发。它的拳头从两台机体之间升起，正中旧拳王胸前护甲。

拳声像在货运环中央炸开一门巨炮。

十七米高的旧拳王整个离开地面，越过红色界线，落向场外。它在半空收紧身体，双脚先后踏上承重板，向后滑出数十米才停住；脚下已经稳稳站住，界外判定也同时全亮。

无牌一号保持着出拳姿势。右臂仍在震，左脚稳稳踩在它自己抢出来的位置上。

看台上的安静只持续了一瞬。

“逆转天冲拳！”胶价王从播音台上吼了出来，“完成！”

旧拳王低头看了一眼胸前凹下去的拳印，抬手示意裁判不用停机。

“这回打出来了。”

无牌一号收回拳头。

“你教的。”

旧拳王看着胸前的凹印，笑出一阵沙哑的扬声器声。“学得好。就是打老师也真不客气。”

它跨回红环，向无牌一号伸出右拳。两只巨大的拳甲在界线中央碰了一下。

“决赛打完，继续练。”

“好。”

场边，赵梅把今天的动作记在新的维修页上，没有写进儿子的账号。白鸢也没有补画最终话，只把无牌一号主动迎上第一拳的画面存进当日比赛记录。

完全版王者在胜者位展开全部外翼。

它已经等了二十多年。现在，那个原本要为它留在发射闸里的角色，带着自己的必杀技走进了决赛。

### 货运环上的决赛

胶价王等旧拳王走回维护区，才走到两台决赛机之间。

“最后确认。决赛继续？”

完全版王者把盾、长翼、钻进组件和背负重炮全部保持在位。

“全装进入。”

无牌一号看了一眼仍在发热的右拳，又看向完全版王者。

“进入。”

胶价王指向港区临海一侧的环形重载平台。

“冠军转子在中央检修架做最后一次低速空转，决赛在外圈打。两边有实体防护墙，互不干扰。”胶价王说，“想退出，现在还来得及。都确认，我就让观众进固定厅，环上只留你们、裁判和工作组。”

旧拳王回到维护区，搭着右拳，等决赛开场。兜灯让工房拆下训练辅助，只留下借来的舰侧推进模块。唐胶收好动作样机，赵梅把维修页放回袋里。

固定观景厅的入口开始放行。普通观众按地面引导离开货运环外沿，转入与擂台隔开的观景区。胶价王一边报两台决赛机，一边把分镜从所有公开页面撤下，只留下今天两场半决赛的真实结果。

白鸢把补图收回旅行袋，带着比赛记录去了工房的安全侧。

中央检修区里，九米冠军转子开始第一圈低速试转。外圈则降下安全墙，露出清楚的擂台白线。

无牌一号和完全版王者分别走上货运环两侧的决赛等待位。
