# C03E02《四机出击！把工作抢回来》

早班铃响以后，工务城没有停，只是处处都慢了下来。

换轨口积着一列等吊装的轨道，几百名工务员只能绕道上班；三片街区轮流供电，每次切换都会让升降梯在半层停一下；灰崎警备机失去了交通墙，只能站在路口，用自己的身体把工程车和通勤车分开。

四台市政机器人都还能走。它们只是做不了原来的工作。

市政吊装机反复抬起空荡荡的右肩。旁边的供能机叫预算二号，昨天还能给几段街区送电，如今背上只剩断开的接头。消防架桥机从万机馆出发的城市赶来参加事故复核，左前腿还带着那夜留下的伤，热障组件又被衡令拆走了。原驾驶组守在脚边，谁也没催它出发。

衡令已经带着四组工具上了中层货运环，正朝中央校正场移动。市政切断沿线供电、放下阻车架，它却用预算二号的供能架重新点亮轨道，又用吊装机的吊臂把挡路的钢架掀到一边。

它把一座城市每天用来工作的手，全装到了自己身上。

临时指挥厅里，陆衡把两份程序并排放上大屏。

左边是最初版本。机器偏离标准动作以后，系统会先问现场磨损、驾驶员准备怎样停机，也会给机体自己一次中止的机会。右边是后来卖到各地的商用版本，只剩一句话：偏离标准，立即锁定。

“右边这个版本，是我改的。”陆衡说，“那些现场确认，也是我删的。”

工务城的软件负责人盯着他的名字：“你现在撤回认证，半条工业带都得停下来重检。替代版还没写完，今晚就会有人来找你。”

陆衡盯着屏幕：“我知道。可别人还在照着我的认证开机，我不能当没看见这次事故。”

“你的工程资格也会一起暂停。”

陆衡摘下工作卡放到桌上，伸手去确认。七海叫住了他。

“先别按。”

屋里的人都看向她。

“外地那些机器还在运行，光发撤回通知，他们不知道该怎么办。”七海指向两个版本，“把改过的地方和临时停机办法一起附上。哪种能继续，哪种必须停，先说清楚。”

陆衡看了她一眼，把两份程序和工务城事故原片一起放进公开文件。他又补了一段很短的说明：各地可以自行决定是否继续运行，但从这一刻起，这个商用版本不再由他的名字担保。

确认键按下去以后，他的工作账号立刻变成了灰色。屏幕另一侧很快挤满质问，有人骂他现在才说，也有人追问手里的机器是不是必须停工。陆衡没有关掉频道，先回答那些今晚真的需要答案的问题。

白鸢站在最后一排。等他暂时停下来，她才问：“我还是想问一句。你当时真觉得，一套程序能管所有城市？”

“不全是。”陆衡说，“我知道各地会有差别，可统一版最容易卖。我也骗自己，先装上，现场的问题以后再慢慢补。后来就没人补了。”

白鸢看了看自己的分镜本。“我也说过回头再改。交出去才发现，后面的人已经照着做了。”

陆衡问：“你后来怎么收场？”

“赔钱，重画，还被编辑骂了一个月。”

陆衡点点头，拿起已经失效的工作卡，走向维修区。外地的询问还在不断进来，七海留在屏幕前，把停机、继续运行和已经发生事故的来电分开，让每座城市都能先找到自己需要看的资料。

市政还没有决定是否让四台职业机参加追击。它们刚摆脱衡令的控制，工具也不在身上，万一那套程序再次锁死，驾驶员很可能困在里面。

吊装机的驾驶员先走到机体脚下。

“老伙计，还想去吗？”驾驶员仰头看着它空荡荡的肩座，“你现在连吊臂都没有。”

吊装机把空着的肩座转向货运环。

预算二号拔掉外接电瓶，自己站了起来。灰崎机收起肩枪，露出六个空挂点。消防架桥机试着迈出一步，受伤的左腿明显一沉；原驾驶员等它站稳，才沿升降索回到舱内。

驾驶员们回到各自的位置，等市政确认出发。

中央校正场是全城唯一能让巨型机器人放开手脚的空地。用于校正重型工程机和巡展舰的巨环平躺在场中央，内外圈之间画着一条醒目的黄色警戒线。环心还立着一座老式机械台，褪色的外壳上写着：灾害时可手动启动。

今天原本还排着社勇王的公开合体试验。四辆模块运输车已经在外环候场，试驾资格被暂停的豪司只以地面工作组身份参加。市政取消试验，把校正场让给围捕队。

纪存看着衡令的前进方向，提出把那里当成围捕场。

“不能再让它往街区里跑了。”他说，“我们追着它打，最后只会把城拆得更烂。它既然想去校正场，就让它去，等它进了外圈再动手。”

陆衡指着黄线：“就在外圈截住它。它一进内圈，隔离门会把你们挡在外面。更麻烦的是那座手动台，断电也拦不住它开机器。”

纪存点了点头：“好。工具拿回来以后，谁也别追过黄线。”

纪存把计划说给四台职业机和它们的驾驶组听。吊装机先答了一声低沉的机械音，其他三台相继接入。四台职业机负责接回自己的工具，随舰机群负责打开衡令的外层。

移动平台沿货运环驶入校正场外圈，纪存发出了出击信号。高架旁等候的工务员们抬起头，望着追上来的机群。

衡令站在长达数百米的移动平台中央，吊臂横在肩上，供能架把背后照得一片发白，六面交通墙围着身体转动，最外层罩着消防机的热障。它不像一台完整机器人，更像把一座工务仓库穿在了身上。

货柜领袖沿公路追上，在高架尽头变形，将封路的交通墙推回平台。馆守Z从缺口跃上去，扯住衡令肩头的吊臂；无牌一号击开连接，旧拳王接下工具，送进旁边的维修线。

市政吊装机迎了过去。身后，自己的驾驶员喊得比全频道都响：“就是这根！别摔！”

追逐没有停。随着外层护卫被逼开，供能架、热障和几面交通墙接连卸下，追在后面的职业机忙着把自己的东西接回来。衡令手里还攥着最后一面墙。

吊臂回到市政吊装机肩上时，固定件怎么也扣不实。终端显示型号完全一致，工务员却不敢让它抬起旁边那段重轨。

唐胶看了一眼转座内侧，立刻把准备上紧固定件的学徒拦住。

“别硬扣，装反面了。你看这道磨痕。”唐胶指给学徒看，“它用了十一年，右边已经磨偏，得按原来的方向装。”

学徒转回吊臂，磨痕对上了。唐胶退开，让他完成固定；陆衡核过读数，先空抬，再试半载，才准它起吊。

重轨被吊装机横过内外环，追击队得以直插过去。灰崎机放下交通墙，消防架桥机张开热障，预算二号重新给线路送电。四台职业机拿回了本行，衡令撤向校正场的路，也越来越窄。

衡令没有冲向最近的出口。

白鸢把几次交锋的位置标在同一页上，很快发现那些点正在一圈圈靠近巨环。

“纪存，先别再往前压。”白鸢把那一圈标记放大，“你看，它每挨一下都往巨环里退。它在等我们把它打进去。”

纪存望向它身后的黄线。衡令的退路正对着内圈，那边从来不是他们要放它进去的地方。

纪存立刻改变命令：“停手！四台职业机封住前面，别让它过黄线！”

交通墙轰然落下，轨道断电。吊装机与消防架桥机从两侧堵住衡令，外圈围捕线已经合拢。

衡令忽然放开最后一面仍抓在手里的交通墙。灰崎机本能地伸手接住，四组工具至此全部回到原主。就在随舰机群收势的瞬间，衡令没有撞向出口，反而正面迎上馆守Z的冲击。它借着那股力量向后滑过黄色警戒线，撞进巨环内圈。

馆守Z已经开始刹步，还是晚了一瞬。灾害隔离门从地下升起，把衡令与随舰机群分在两边。那道门本来是围捕失败时保护外城区的最后屏障，现在却替衡令挡住了追兵。

四组工具已经夺回，四台职业机仍然站着。工务频道里的欢呼刚响起来，便被纪存打断。

陆衡却没有跟着抬头。

他看见衡令越过黄线以后，反而不再看门。衡令转过身，朝巨环中央的机械启动台走去。

“控制室，快把巨环停下来！”

频道里传来守卫的回答：“我们这边根本没开！它跑到手动台去了！”

衡令走到手动台前，熟练地伸进机械槽。这里的断电应急装置，它用过不止一次。

校正场地面发出一声沉闷的巨响。平躺的巨环开始缓缓立起，数十条埋在地下的工务缆索同时醒来，朝城梁巨机和万机馆所在的方向伸去。

衡令站在环心，抬头看着刚刚夺回工具的四台机器人。

“城市仍处于危险中。”它说，“现在开始最终固定。”

环外候场的重载车队被迫后撤。四辆运输车分别载着社勇王的核心、双臂、下肢和飞行模块。它们原本只需要完成一次公开合体，现在却正对着一座升起的巨环和正在被缆索拖动的城市。

豪司穿着地面工作组的反光背心，正和同事一起清开合体轨道。他的试驾资格仍在暂停，运输表上没有他的名字。

社勇王核心车从他身边驶过，主摄影机忽然转了过来。

豪司抬头看它：“看我也没用，我今天只能干地勤。驾驶舱都不让碰。”

核心车没有移开视线。
