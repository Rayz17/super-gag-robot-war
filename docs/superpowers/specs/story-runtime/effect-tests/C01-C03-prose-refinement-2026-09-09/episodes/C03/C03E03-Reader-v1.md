# C03E03《社勇王，现场合体》

中央巨环立起来时，工务城里所有开着的窗户都被震得响了一遍。

衡令站在环心。巨环上原本用来校正大型机体的成排作业臂已经全部竖起，在它背后张成一圈巨大的工具架。数十条工务缆索越过街区，一端扣住刚在新基座上站稳的城梁巨机，一端缠上停在待校正区的万机馆。更细的缆索已经沿交通桥钻进城市的承重层。

巨环基座周围还埋着一圈地震时固定大型机械用的缆索。黄色待机灯已经亮起，它们尚未伸出地面。

城梁的腿被重新拽向旧基座，万机馆两舷也绷满缆索。衡令要把城市、城梁和巡展舰固定在一起，再也不许它们离开。

市政切断了巨环的普通电源，它却没有停。衡令把预算二号刚恢复的那一部分城市电力全抽了过去。整个中层环路逐段慢下来，刚通车的工务线又开始拥堵。

工务总席把临时救援请求发给环外的社勇王。

企业调度当即拒绝。原定试驾员还被堵在城外，这趟运输只是公开试验，没有人获准让四辆模块车在实战中合体。

豪司正在地面上搬最后一段隔离栏。

豪司拍了拍核心车的装甲。“听见了吧？又没批。先给后面的工程车让条路，我接着问。”

核心车没有让路。

它的主驾驶舱开了。

豪司仰头看着那道门，过了两秒才问：“你……是在叫我？”

车内传出一个年轻而清楚的声音。

“豪司。上来。”

豪司的直播终端还在肩上。画面里的观众已经刷满了合体口号，企业也在另一个窗口里要求他原地等待。

豪司看了一眼缠住城梁的缆索，转向直播终端。

“我得上去了。下次再聊。”

他关掉直播，先去拉登舱梯。

豪司顺着登舱梯往上跑。他曾经是这套操纵系统的试驾员，也在模拟器里练过不知多少次四模块合体。试驾资格虽然停了，他还是能凭声音听出每一段变形进行到哪里。

企业调度还在通讯里喊：“合体许可没有下发！”

社勇王回答：“工务城救援请求已接受。由本机确认合体。”

豪司在驾驶席里笑出了声。

“全员让开合体线！”

四台职业机用刚夺回的工具清出合体线。轨架被抬开，隔离墙护住两边，热蒸汽压回地面。预算二号把最后的电力送进这条路。

四辆重载车同时加速。

下肢模块展开双腿，核心车沿斜坡跃起，轰然扣入腰腹。双臂从两侧赶来，肩部接合的巨响还没散，最后一辆飞行工具车已冲上高架。背翼、头部、金色巨锤在它上方展开，依次落定。

一台二十多米高的合体机器人落在巨环前方。

工务员、车站里的乘客和还没来得及散去的观众几乎同时喊出它的名字。

“社勇王！”

巨环的工具架朝它压了下来。数十种工具头在半空展开，像一座整体倾倒的工厂。

社勇王没有躲。

它把金色巨锤从背后抽出，双手轮起，迎着整座工具架正面砸了上去。

第一声巨响震得环路上的尘土成片落下。第二声来自巨环本身。那圈被衡令强行转成武器的工具架被一锤从中央砸成两半，通往城市工务缆索的控制接口也从裂口中露了出来。

豪司的右手被震得发麻，仍攥着操纵杆，声音冲出了驾驶舱。

“黄金重锤，化作光吧！”

城市频道里先是安静，随后笑声和欢呼一起爆开。

衡令的本体被打得退进环心，大片外甲从胸前脱落。工务席确认眼前的缆索都已经松开，没有继续承受城市重量。社勇王向前踏出一步，巨锤再次举过头顶。

“再来一锤，今天就收工！”

巨锤开始蓄力以后，衡令突然将双臂插入环心，把基座周围的地下固定缆全拉了出来。

缆索一根根绷直，直接连向医院交通桥与附近住宅的主梁。

巨锤停在最高处。

豪司猛地推了一下操纵杆：“社勇王？”

“下面有人。”

主屏上切出住宅承重层的画面。巨锤如果落下，力量会沿那些缆索直接送进桥梁和楼体。

豪司看见画面的同时便松开操纵杆。

“停！这锤不砸了！”

社勇王将巨锤迅速放低。衡令趁机压了上来，巨环正在下沉的一段重重扫向社勇王。它横过锤柄，用整个身体接住，把巨锤顶在那段环壁下方。

“改支撑！先把这段环壁顶住！”豪司咬着牙说。

“正在做。”

白鸢在观察席上看见一根断裂缆索从环壁后方扬了起来。按衡令当时的转速，它下一次扫过来时，正好会抽中观察席与城市指挥台之间的连桥。

她把折叠分镜板转向七海。

“下一次会扫到连桥！”白鸢在图上圈出断索可能经过的地方，“我拿不准角度，先别让人过去。”

七海望向连桥，让现场员核对。回答刚传回来，她便封住桥口，把人引向下层。白鸢还在扩大图上的范围。

最后一名工务员离开后，断索横扫而过，整座连桥在两人眼前被抽得翻转起来。

白鸢的手指在分镜板边缘停了一下。

七海拉住她的手臂，带她一起离开仍在震动的观察席。

“快走，这里也不稳了。你跟紧我。”

“左边还有两根，别靠那边。”白鸢跟上她，声音低了些，“刚才差点算窄了。”

环外四台职业机先集中剪断缠在万机馆两舷的缆索。最后两根缆索落地，纪存才启动推进器。

万机馆还没完成城市校正，两侧推进器在起动时发出发闷的轰鸣。百米舰体从待校正区沿重载道正面驶向中央巨环。

陆衡站在市政指挥席前，听见纪存要进巨环，立刻说：“你要把万机馆开进去？不行，低速校正还没做完。那个口子只比舰首宽一点，方向偏了，连倒车都来不及。”

“我不是去撞它。”纪存说，“衡令还在环心接线，我把万机馆横进去，堵住它。陆衡，把左边那条路清出来。”

陆衡看了看巨环容许的宽度，又看了一眼万机馆舰身上还没修完的外板。他骂了一声，按下全场广播。

“左侧全部清空！他要拿万机馆堵门，谁也别留在里面！”

馆守Z先撞开衡令伸向舰首的巨钳，将右肩外侧抵住钳口。

兜灯握住外部停机柄，盯着馆守Z的右肩：“那个固定口还要用！撑不住就喊，我马上停！”

“知道。”馆守Z将双脚踏进轨道，右肩继续顶住钳口。

万机馆从它身后驶过，半个舰身探入环内，将衡令重新连接城市的路径彻底挡住。

衡令将巨环朝内收紧。金属环壁擦过万机馆两舷，整片外板被刮得卷起。纪存的双手死死压在操舰台上，没有后退。

“再撑一下，我带工务组拆缆！”陆衡说。

“快一点！”纪存听见舰侧又一片金属被扯开，“这边还在收紧！”

水幕浇进过热的缆群，吊装机迎着蒸汽拔出缆索。灰崎机护住居民层路口，预算二号守着供电；只要万机馆还堵在那里，工务员就能继续拆下去。

城梁巨机终于在新基座上抬起身体。它顶住衡令的拖拽向前踏了一步，绷在腿上的最后两条缆索应声崩断。

社勇王还在巨环那段下沉的压梁下撑着。

豪司的两条手臂都在发抖，他看见城梁站稳，咬着牙笑了：“好。现在能把它拆了吧？”

“可以。”社勇王说。

金色巨锤展开成撑顶架与切割具，社勇王接手拆除。吊装机从断缆间伸进吊臂，将城市控制接口整个拔了出来。内侧固定架仍咬着万机馆。

馆守Z用左手揭开衡令的胸甲，无牌一号与旧拳王从两侧击穿固定架。纪存立刻倒退，万机馆擦着残骸退出环心，舰桥里绷着的一口气这才松开。

巨环工具架、外甲和城市缆索散落在衡令四周。它剩下的本体只比无牌一号高一些，胸前的稳定核已经裂开，原本连接工务城的接口只剩一片撕裂的金属。

它没有再试图接管城市。中央巨环底部被撞出一道裂口，衡令跳进城市下层废弃的重载维修道，很快便消失在暗处。

纪存没有让任何人追。

城梁巨机已经在新基座上完全站稳。医院交通桥平稳地把重量交了过去。城市工务席当众封存了从衡令身上拔下的控制接口；至少在工务城，它已经没有东西可以再接入。

工务城空了几秒，才有第一个人开始鼓掌。

掌声很快从工务席、车站和沿途屋顶连成一片。

社勇王将裂了一道缝的金色巨锤立在身边。豪司重新打开直播，镜头里先出现的却是他已经红了的眼睛。

他吸了一下鼻子，把镜头转向社勇王。

“刚才还想再来一锤，差点砸了医院。”豪司吸了吸鼻子，“它先停住了。”

社勇王说：“下次我喊停，你听见就停。”

“听你的。”豪司抹了抹眼睛，“你也喊大声点，我刚才嗓门太大。”

“你一直很大。”

豪司笑了，工务城里的欢呼也还没停。
