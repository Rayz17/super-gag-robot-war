# C02E01《救命零件，限定发售》S1开场短样 v1

午后，万机馆抵达木桶街。

从空中看，这地方先是一座退役货运站，然后才像一条卖模型的街。成排旧仓库沿着会展时期留下的环形轨道展开，低层橱窗里摆着手掌大的机器人，仓库门外却靠着比店面还高的肩甲和推进器。几台吊装机从屋顶轨道慢慢让开，给万机馆腾出通往外侧泊位的航路。

C01那张照片里的四角泊位就在前方。它足以容纳万机馆，四组固定臂却停在旧规格的位置。万机馆降到承台上方，左侧固定臂能够贴近舰腹，右侧还隔着一段明显的空隙。

兜灯把头灯推到额前，盯着泊位传回的画面。

“先停这儿。再往下，右边会先碰上。”

纪存让航行系统保持高度。舰体下方的推进声没有停，前厅地面也一直传来轻微震动。

“能撑多久？”他问。

“够你下去看东西，不够你在街上吃晚饭。”兜灯已经解开座椅扣带，“我留在舰上看着。谁要是告诉你‘老接口稍微磨一下也能用’，先别签字，叫我过去。”

唐胶望着泊位，没有接她的话。

公共频道响了一声，一个女人出现在主屏上。她穿着沾了机油的深色工作服，身后有人推着两人高的运输轮，画面一直在晃。

“玛拉·维拉尔，木桶互修合作社。”她说，“照片是我发的。左侧引导灯已经开了，先让你们的人下来。舰体别再降，我这里接不住右边。”

她说完才看向唐胶。

“唐启明，好久不见。”

唐胶把终端往低处放了一点，像这样就能少出现在屏幕里。

“你什么时候把合作社名字改这么长了？”

“你走以后，我们得让保险公司看懂自己在保什么。”

“那它现在看懂了吗？”

玛拉抬头看了看万机馆投在仓区上的影子。

“显然没有。”

她切断画面，去处理泊位。纪存看了唐胶一眼。唐胶已经转身去拿工具箱，动作比平时快了一截。

“别问。”他说。

“我还没问。”

“你那张脸已经问了。”

纪存低头检查随身终端：“那我换一个。她叫你本名，说明欠账不小？”

唐胶把工具箱提起来：“说明以前合作过。你再猜，我就把你留在这儿抵泊位费。”

他们从交通艇下到仓区时，玛拉已经让人把参观通道清了出来。通道一侧是模型店，透明柜里同一副机器人骨架被涂成十几种颜色；另一侧隔着防护栏，几名工人正给一条真实尺寸的机械腿换运输支架。唐胶经过时先看了那条腿的膝盖，又看了看工人用的垫片，最后忍住没开口。

玛拉注意到了。

“想说就说。”

“上面那片薄了。”

“换厚的会卡进货架。”

“卡货架也比落地的时候把腿留在车上强啊。”

玛拉向旁边的工人抬了下手：“换。仓储那边我去说。”

她没有谢唐胶，也没有借机谈过去，只领着他们穿过仓库。

最里面的隔离门升起时，纪存终于看见了主转子。

巨大的环状机组竖在运输架上，最高处接近仓库的第四层步道。外圈不是崭新的统一颜色：有些护板已经换过，有些地方保留着磨亮的吊装痕，底部还能看见旧工班一遍遍校正位置留下的标线。它没有启动，只靠自身的体量就把站在门口的几个人压得很小。

兜灯通过终端看了一会儿，先问：“这是实物？”

玛拉说：“二十七年前同批的退役件。没上过主舰，后来一直给巡展设备做备用。你们那台坏掉以后，它就是附近唯一还能接上的一具。”

唐胶走到防护栏边，眯起眼看向转子下方。

“左边第三块护板换过。”

“换过两次。”玛拉说。

“第二次是你们自己换的？”

“第一次也是。”

唐胶没再说话。他显然认得那些痕迹，只是不愿意当着纪存的面承认。

仓库上方忽然响起运输警报。

运输架底部的方向灯从泊位一侧转向另一条轨道。玛拉立刻抬头。

“谁改的路线？”

现场没人回答。她冲到控制台前，将一枚磨损很重的实体钥匙插进去，屏幕却只弹出一行平台通知：

`零点清仓批次已提前提货。`

“这东西属于合作社。”玛拉把寄存凭据拍到识别台上，“停止运输。”

识别台读完纸面编码，仍然没有停。

轨道尽头，一扇通向拆解桥的重门正在升起。拖在运输架前方的货柜车突然锁死车轮，轮胎在轨道上压出四道黑痕。它没有继续服从平台路线。

“我不送。”货柜领袖从车体扬声器里说。

下一秒，仓库两侧的白色货运机同时启动。它们绕过货柜领袖，把新的牵引索扣上运输架。

巨型转子离开原位，缓慢转向正在打开的拆解桥。
