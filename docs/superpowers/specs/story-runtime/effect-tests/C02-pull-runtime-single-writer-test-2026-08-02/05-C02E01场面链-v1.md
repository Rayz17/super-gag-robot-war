# C02E01《救命零件，限定发售》场面链 v1

>

## S1 到港：唐胶不想见的人就在泊位上

- **玩家先知道：** 万机馆必须尽快停靠和更换主转子；木桶街同时有模型店、实机工房、旧货运线和巨构泊位。
- **场面行动：** 万机馆因接口不合只能悬在泊位上方；玛拉实名接舰，唐胶与她的旧关系通过对话和现场反应建立；众人看见真正的主转子。
- **关系变化：** 纪存第一次发现唐胶在木桶街不是普通修理师，而是有人仍拿本名称呼的旧合伙人。
- **场尾变化：** 平台越过玛拉的现场停运指令，货运线自动把转子转向拆解桥；货柜领袖拒绝继续拖行，白色货运机群接管。

## S2 最简单办法失效：有纸也停不下正在走的巨物

- **先试简单方案：** 玛拉出示合作社寄存凭据；纪存询问购买、租借和等待人工复核；平台只承认导入后的无主库存状态，且清仓买家已经付款，现场工人被保险规则撤出。
- **冲突为何发生：** 转子一旦越过拆解桥就会被切开，之后即使申诉成功也无法复原；合作社有产权和代运授权，却没有平台货运系统的远程控制权。
- **场面行动：** 玛拉用本地机械钥匙把无牌一号交给玩家；兜灯确认馆守Z只能在泊位侧作业，黄色巡展臂不得承受主转子全部重量；纪存决定让万机馆进入旧泊位承接。
- **场尾变化：** 玩家取得行动权，任务从“谈判等结果”变为“在不伤及工人与街区的前提下阻止错误拆解”。

## S3 SRPG：把一座主机从拆解桥上接回来

- **地图：** 外侧巨构泊位、环形货运线、拆解桥和万机馆舰艏，四块空间一眼可分。
- **玩家单位：** 无牌一号为首控构筑机；万机馆为受限母舰支援单元；馆守Z为泊位侧主力。货柜领袖是自主NPC，不计正式入队。
- **敌方：** 无人货运机和拆解桥防护机，只执行运输与隔离，不突然变成杀人军队。
- **三次大动作：** 无牌一号拆掉桥前固定桩；货柜领袖变为作业形态托住倾斜运输架；纪存驾驶万机馆压入泊位，馆守Z从舰艏抓住巨环上沿，舰体承接脱轨转子。
- **胜利不是安装：** 玩家把转子送回合作社控制的货运线；玛拉和原工班随后完成临时落座。

## S4 战后ADV：谁愿意让自己的修件史一起被看见

- **场面行动：** 平台以“非法转移系统库存”为由冻结合作社；玛拉拿出原始寄存凭据，唐胶拿出能对应实体编号的离线维修交接；七海远程说明公开资料会使平台获得旧改件的匹配方式。
- **人物选择：** 玛拉原本只提交转子。亡故修件师的母亲主动保留儿子的签名；四台重涂机的物主分别同意把自己的维修页并入申诉。没有人被唐胶替着献祭隐私。
- **关系动作：** 纪存不替唐胶做决定，只先把万机馆公共频道和共同发布者身份准备好；唐胶最终按下发送键。七海看见纪存没有要求她开后门，也没有躲在她的风险判断后面。

## S5 本话闭环与反咬

- **完整回报：** 转子完成低功率临时落座，万机馆一侧长期熄灭的舷窗恢复；玩家得到明确的航行续命和无牌一号首控体验。
- **反咬：** 平台将四页获授权维修记录与现役仓储接口匹配，四台重涂机同时收到自动召回；其中一台在远处机库自行启动。
- **白鸢预显影：** 仓库安全示范屏中被裁掉署名的旧分镜随直播传出，白鸢发来停止使用通知并说明会在公开拍卖前到场。她本人本话不出现。
- **E02发动：** 重涂四机如果服从，会被压回一个货号；如果直接拒绝，平台的维护接口会令它们在空中失控。下一话必须立刻处理。
