## 这场要讲清的事

午后，万机馆为寻找替换主转子抵达木桶街外侧旧泊位。这里不是一条小商业街，而是旧会展货运区改成的机器人生态：低层是模型与改件店，高处和外环仍能搬运巨机、肩甲和舰用总成。泊位左侧固定臂能够接近舰腹，右侧固定臂位置过高，继续下降会刮到舰侧；万机馆只能悬在承台上方，当前航行炉撑不了长期悬停。馆守Z在舰艏用黄色巡展臂拉住安全缆，泊位通道未接通前不能下舰。

玛拉·维拉尔实名接舰：西班牙裔工程物流师、木桶互修合作社负责人、唐胶昔日合伙人，也是C01末发照片的人。她务实、直说、忙于现场，不作神秘人。她用“唐启明”称呼唐胶；两人的旧怨只露出“他当年走了、她把合作社接入平台”，不要在第一场讲完。

玛拉带纪存、唐胶、兜灯看见主循环转子。它是接近楼层高度的巨型环状工业总成，表面有二十年工班留下的维修与更换痕迹。让玩家一眼明白它足以影响百米舰体，且必须靠货运线和重型机搬运。不要描写密集内部机构。

转子原本由一辆具有自主驾驶人格的旧式重卡拖行，工人叫它货柜领袖；平台可以向它发送物流路线，但不能直接夺取车体控制。场尾，平台越过玛拉的停运要求，把转子运输架改道至拆解桥。玛拉出示原始寄存凭据仍无法让联网货运线停下。货柜领袖锁住车轮拒绝继续；平台自有白色货运机解除它的牵引销，换上自己的牵引杆并接管运输。玛拉随即指向仓侧的无牌全尺寸竞技底盘，明确下一场有机体可开。停在“巨环真的开始离开他们面前”。

## 活跃人物声线

- **纪存：** 先看现场、问最简单的问题；知道唐胶难堪也不替他解释。句子自然完整，不说主题结论，不用档案、证词、债务、命名等词。
- **唐胶：** 会啰嗦、会加语气词；熟悉现场和旧人，但越心虚越想挑工艺问题。台词来自他确实看见的修补和变化，不说金句。
- **兜灯：** 一边测泊位和舰体状态一边说话；判断直接、动作先于情绪。她不是安全规则播报器，也不是唐胶助手。
- **玛拉：** 说中文熟练，语序自然；工程物流负责人，说话以安排人和设备为主。她对唐胶有旧火气，但当前先救万机馆。
- **馆守Z：** 主要通过站位、视线和短句表达；自主行动，纪存不控制其四肢。

## 空间与控制硬边界

- 万机馆约130至160米，只进入外侧巨构泊位，不驶入模型店街道。
- 馆守Z为18米级，站在万机馆外部泊位或舰艏；右侧黄色巡展臂是抓取工具，不是完整拳。
- 主转子暂时仍在合作社仓区的运输架上；本场不脱轨、不落座。
- 玛拉控制合作社现场与工班，平台控制联网货运线；两者权限冲突必须通过真实设备动作表现。
- 火种货柜领袖是已有全尺寸载具生命，不属于万机馆；本场只承担拖车和自主拒绝。

## 文风边界

开头必须先让普通读者知道何时、何地、谁到了、为什么来。可以有幽默，但幽默来自百米博物馆卡在旧泊位、模型店与巨型零件并存、唐胶见旧合伙人的窘迫；不要用拟人化街道、豆浆波纹、广告蒙太奇或几十人同时摔倒制造“有趣”。
