# C02 Pull Runtime + 单一主笔试验

> Status: `candidate_effect_test / no_canon_migration`
>
> 目标：验证“单一主笔先做全章戏剧选择，Runtime只按具体疑问微查，随后才编译单话简报”的方法，能否以更低成本写出比旧V3更清楚、更有情绪、更有机器人大战感的C02。

## 本轮只允许带入的上游事实

- C01结束时，万机馆以约130至160米级低速巡展舰形态离开原址，急需能够承载舰体的泊位、全尺寸主循环转子和第一次完整检修。
- 纪存、唐胶、兜灯、馆守Z、跌跌和机器犬随舰；七海留在原城接受调查，只能远程提供自己合法掌握的事实；陆衡尚未登场。
- 馆守Z为18米级独立机魂机体，原右前臂已经毁损，黄色巡展臂只能抓取、放锚和搬运，不是完整战斗拳；它没有常态飞行能力。
- 木桶街是由收藏者、修件师、旧平台、实机拆解、物流、灰色认证和全尺寸改件共同维持的机器人生态，不是单纯模型商场。
- C02跨章职责：取得并安装可维护的退役主转子；建立模型/玩具锚与全尺寸工程、机魂识别的关系，但绝不让玩具凭空放大成巨机；让旧拳王正式加入；让火种货柜领袖、四台同骨架重涂实机、无牌一号和两米工程样机进入故事；白鸢肉身到场并以权利追索者身份临时随舰；章末因转子仍需校正而驶向工务城。
- C02共四话。具体仓库战、空战、拳赛、开放日及敌方动作属于可迁移Working，不作为本次主笔必须照抄的答案。

## 主笔拥有的自由

- 可以推翻旧C02每话发动机、旧高潮动作链、旧NPC和旧场景细节。
- 可以提出一名承担整章冲突的本地重要角色，但必须在脊柱中一次说清其身份、与主角的旧关系、当前欲望和章末去向。
- 可以改变白鸢肉身到场的具体话点，但不得让她在到场前直接控制现实，也不得提前引入陆衡。
- 可以让现有角色承担旧稿中匿名NPC的功能，优先避免一次性具名人物。

## 本轮隐藏材料

- `C01-C05连续阅读稿-v3.md`中的C02正文。
- 上一轮B+A完整方案、E01正文、全部审稿意见和失败样本。
- 旧L4/L4.5的详细场面答案。

这些材料只允许在短样完成后揭盲比较，不得参与前置创作。

## 成本门

本轮计划不超过七个创作/审稿Pass：

1. 单一主笔完成全章戏剧脊柱。
2. 一次定点事实与因果审查。
3. 原主笔修订脊柱并切分E01场面链。
4. 原主笔写E01开场及第一场短样。
5. 普通玩家冷读。
6. 机战/游戏审读。
7. 仅当两席指出同一根因时，允许一次返修。

## 停止门

本轮不写完整C02E01，更不写E02至E04正文。若一页脊柱本身不成立，立即停在章级；若短样的空间、人物声音或事件目的不清，立即熔断，不以继续写作掩盖问题。
