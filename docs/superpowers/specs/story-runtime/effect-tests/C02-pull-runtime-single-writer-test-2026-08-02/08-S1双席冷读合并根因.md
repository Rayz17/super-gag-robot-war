# C02E01 S1双席冷读合并根因

> 普通玩家/编剧：`REVISE`
>
> 机战/游戏制作：`REVISE`
>
> 两席均无P0。

## 已成立

- 普通读者能复述何时、何地、谁来、为何来、看见什么以及场尾发生什么。
- 纪存、唐胶、兜灯、玛拉声音可区分；幽默来自旧关系、保险和工艺习惯，没有复发“早餐、豆浆波纹、四十人被吹跑”的修辞失控。
- 木桶街同时呈现模型、同模重涂、实尺寸零件、工班和巨构货运，不再像普通仓库。
- 巨型转子被送往拆解桥是明确钩子，读者愿意继续。

## 共同根因

1. 泊位几何写反，无法画出“为什么不能继续下降”。
2. 货柜领袖开口前没有说明它是何种主体、为何能拒绝平台；白色货运机归属未说明。
3. 牵引关系不清：货柜领袖锁轮以后，平台机怎样接走转子没有连续动作。
4. 第一场尚未让馆守Z和下一步可控机体进入画面，机战席只能把后续理解为追货。

## 单次返修裁决

- 把泊位关系改为“左侧能接，右侧固定臂位置过高，继续下降会刮舰侧”。
- 在运输途中提前介绍货柜领袖是具有自主驾驶人格的旧式重卡，平台只能发送物流路线，不能直接夺取其车体控制。
- 场尾由平台自有货运机解除货柜领袖的牵引销，再换上自己的牵引杆，动作连续。
- 开头让馆守Z在舰艏承担安全缆，说明泊位未接通时它不能下舰；场尾让玛拉指向无牌一号，明确玩家下一步有实际机器人可开。
- 顺手删去“C01那张照片”的稿件编号感，并在首段直接说清万机馆来找替换转子。

只做这一轮，不再添加审稿席。
