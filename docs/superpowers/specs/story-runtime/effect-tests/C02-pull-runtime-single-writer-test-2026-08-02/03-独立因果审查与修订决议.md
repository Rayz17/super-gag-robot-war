# C02一页戏剧脊柱：独立因果审查与修订决议

> Review result: `REVISE`

## 两个阻塞根因

1. **维修史不能自动证明所有权。** v1让万机馆先武力抢走转子，再靠维修账证明正当性，常识上仍可能是盗取抵押物。修订必须明确：合作社始终是产权人和保管人；平台因旧资料迁移错误把转子归为无主库存；玛拉有权授权万机馆代运；唐胶公开的连续维修交接只用于证明平台认错了实体，不凭感情消灭真实抵押权。
2. **平台不能既掌握一切数据，又等公开账后才发现四机。** 修订必须明确：平台原先只有当前货号和仓储接口，不掌握唐胶年代的线下改件对应；四机物主知情后主动把自己的维修页并入申诉，平台才据此交叉匹配并触发召回。危机是共同选择的代价，不是唐胶再次替别人决定。

## 一并修正的连锁问题

- 玛拉控制原有货运环线，三台机只负责夺回、扶正与护送，原工班负责临时落座；木桶街只能恢复低功率循环。
- 归一星带走的是四机夺回控制权时的现场录像，平台将其剪成“私改导致失控”的宣传片，以此发动E03拍卖，而不是重复取得本来就有的工厂动作。
- 机械拍卖原本就有公开挑战条款：冠军败北会使“争议机体安全声明”失效，拍卖暂停一天复核。拳赛争取时间，不凭拳头裁决产权。
- 玛拉在E02末正式请豪司带勇拳事故记录作证；合作社、旧拳王和赛方分别完成驾驶授权与适配。
- 白鸢从E01看到作品被盗用并发出通知，因公开拍卖日程启程，E03到场；E04后由纪存邀请、她本人同意，才成为临时乘客。
- E03只取回外泊承托与测振架；它能看见问题，不能完成百米舰体全长校正。E04过载后，工务城成为物理上不可替代的下一站。

修订不得新增技术机制、幕后势力或另一套高潮。
