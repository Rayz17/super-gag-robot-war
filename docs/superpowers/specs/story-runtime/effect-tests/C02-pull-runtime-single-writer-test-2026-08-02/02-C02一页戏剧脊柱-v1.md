# C02《木桶街，万机初开》一页戏剧脊柱 v1

> Status: `candidate_story_spine / single_lead_writer`

## 一句话发动机

万机馆必须在木桶街取得一具能让百米旧舰继续航行的退役主转子；唐胶却发现，唯一能证明转子归属和维修价值的，是他多年前为了帮助收藏者变卖旧物而故意模糊过的修件记录。为了救万机馆，他把自己的旧账连同一整条街被擦掉的维修史公开，结果既唤醒了木桶街的机器人，也把平台的商品回收军招到了每一个被他修过的人门前。

## 本章真正的对手与本地人物

木桶街不是坏人窝。它正被“零点清仓”平台吞掉：平台替小店提供仓储、估价、保险和物流，也因此掌握了旧件的抵押权、维修数据和远程回收接口。整条街靠它活着，也越来越只能按它的商品页活着。

本地负责人暂定为**玛拉·维拉尔（Mara Vilar）**，西班牙裔工程物流师，唐胶昔日共同经营维修认证合作社的合伙人。唐胶当年替物主磨掉维修痕、写“近似原装”；玛拉则把合作社接入平台，换来合法仓库、保险和工人的饭碗。两人都救过人，也都给今天留下了麻烦。C01末尾匿名呼叫万机馆的人就是玛拉：她需要一艘不受平台调度的巨舰把主转子带走，却不打算让唐胶回来把整条街变成他的赎罪现场。

平台在地面的执行者不是抽象合同，而是商品回收王牌**归一星**、自动货运群、全装冠军**百刃**与最终进场的重型清仓飞艇。它们分别代表“同模具只留一套动作”“配件越多越值钱”“无法继续出售就整批搬走”。

## 四话因果链

### E01《救命零件，限定发售》：唐胶按下发送键

万机馆抵达木桶街时只能悬在旧泊位外，馆体持续失温。玛拉带众人去看退役主转子：那是一具接近楼层高度、必须由整条货运环线搬动的实物，不是小零件。平台得知万机馆到场后提前启动零点清仓，把转子送往拆解桥；不是因为“名字被改”便失效，而是抵押人和回收机真的在搬走它。

玩家第一次驾驶木桶街既有的全尺寸改装底盘“无牌一号”，在作业模块中选择一套临时构筑；馆守Z守住万机馆泊位，火种货柜领袖以自主载具生命身份变形成作业形态，从运输侧托住巨环。纪存没有躲在终端后，他把万机馆压进旧泊位，用整艘舰承接从高架脱轨的转子。三台机器完成的是一件肉眼可懂的大事：从即将闭合的拆解桥上抢回一具足以填满半个船坞的环形主机，并把它送进万机馆舰腹。

平台随即宣称转子属于“无维修史的原装库存”，要以盗窃冻结整条街。唐胶手里有唯一能证明它被木桶街维护了二十年的原始账，但同一套账也能暴露许多物主曾经隐瞒修件。七海从原城告诉他们后果，不能替任何人决定。玛拉要唐胶只救转子，别把其他人拖下水；一位仍替亡故儿子完成修件委托的母亲却把儿子留下的维修页放到桌上，要求保留那道被平台抛掉的签名。

唐胶没有发表宣言。他让物主先撤掉不愿公开的名字，随后亲手把自己的材料、方法、签名和转子的完整维修史发上万机馆公共频道。纪存把频道开放给整条街，并让万机馆以共同发布者身份承担后果。转子在章内第一次落座，万机馆重新点亮一整侧舷窗，E01获得完整胜利；同一时刻，平台利用唐胶公开的修件特征，锁定了四台曾被改装、重涂并分别生活多年的同骨架飞行机。人物的选择直接发动E02。

### E02《同模不是同一个人》：公开历史反咬了活着的机器

四台重涂实机原本由不同店家和驾驶组维护。平台以“同一货号、未经授权改装”为由向四机同时下发同一套工厂动作，试图让它们自行飞回回收站；归一星则读取它们共同的出厂动作，在木桶街立体空域逐一截获。四机第一次齐飞时反而险些相撞，因为它们早已拥有不同重量、旧伤、操纵习惯和与驾驶员约定的动作。

唐胶想关掉刚公开的账，玛拉当面阻止：抹回去只会让平台继续独占解释。兜灯则第一次真正同唐胶吵起来，因为“保留修痕”在模型上是历史，在巨机上还关系到谁会死；她要求每一处浪漫都先落到可承受的机况。两人由此明确分工：唐胶从修补痕里找出四机如何被各自的人改变，兜灯只把经驾驶组确认能安全使用的差异转成战斗条件。

玩家不靠四机故意乱飞取胜，而是依次夺回它们的本地控制：高速机用被加长的减速板逼归一星过冲，重装重涂机用后来加装的承力骨架硬吃一击，旧巡演机利用频繁更换留下的不同喷口节奏脱锁，镜像配色机则故意执行一次人人以为只是“换皮”的反向变形。四架同模机第一次在同一画面里做出四件完全不同而都很漂亮的事。归一星受创撤走，却带走它们最初共同的工厂动作样本，准备把“标准版本”交给下一场公开展示。

### E03《拳王赢了》：完整的失败录像比不败广告更能打

平台把主转子的外泊校正架、木桶街公共工位和四机抵押权打包进机械拍卖，并推出装满尖刺、背包和扩展件的全装冠军百刃做现场展示。市场里人太多，双方都不能开火；要阻止移动拍卖台驶出街区，必须在它自己公开承诺的非致命擂台里打倒百刃，逼平台停台检修。

被公司停飞的豪司来到木桶街，本来只为替勇拳的损坏作证。他没有公司机体可开，便坐进退役旧拳王。旧拳王的商业录像只留下胜利，影子陪练机却保存了它每一次被击倒、怎样爬起以及哪一拳从没打中的完整过程。豪司起初想用勇拳式的爆发解决，却发现旧拳王转身很沉，每一拳都要先把全身重量送到位；他最终接受这不是一台等待他证明勇气的替代品，而是另一名打过很多败仗的老选手。

百刃的全装确实强：更长臂展、更多防护和多方向推进先把旧拳王逼到围绳。破局不靠“配件多所以必然愚蠢”，而是让唐胶和兜灯在赛前只拆掉旧拳王一件华而不实的赞助甲，保留每一道旧修补；豪司在实战中故意重演一段著名败局，引百刃用宣传片里固定的终结姿势追击，再让旧拳王从当年没能站稳的位置完成迟到的上勾拳。百刃倒下，移动拍卖台停机，旧拳王赢得自己的身体与外泊架，正式加入万机馆。

百刃的宣传片使用了白鸢早年画过、后来被平台买断剪改的安全分镜。她在终场后本人到场，不是来加入队伍，而是要求停止使用、归还原稿，并追查为什么万机馆的战斗路线与她被盗的草图越来越相似。

### E04《万机初开》：把灰市的一天变成机器人动画的总动员

抢回零件不等于木桶街能继续活。玛拉提出举行一次白天的公开开馆：让收藏者、修件师、驾驶员和机器人自己展示“修过、改过、失败过”的东西如何安全工作，借此恢复合作社的直接委托与公共泊位资格。开馆不是经营菜单，而是本章所有人的正面反击。白鸢同意先帮他们把开放日做完，再带着侵权证据上舰；她用现场传感和旧分镜做一份任何人都能涂改的预演图，真实路线由驾驶员、工房员和机体共同改出来。

平台若让开放日成功，就会失去对维修数据和二手物流的垄断，于是派重型清仓飞艇连同归一星残部来整批吊走“争议资产”。战斗从街区开放日直接升空：四台重涂机各自迎击，货柜领袖保护撤离车辆，旧拳王在地面打断吊索，无牌一号按玩家构筑承担破甲或支援。两米级未发售变形工程样机从自己的测试架上脱出，用原主人保存的旧控制器确认协作，爬上清仓飞艇打开检修口；它从始至终都是实体工程机，不由盒中玩具放大。

纪存把刚装上的退役转子推到未校正功率。万机馆第一次在战斗中完成全舰转向，用百米舰体挡住清仓飞艇对街区的俯冲，并把馆守Z送到可抓住敌舰的位置。所有新机不是站在背景里声援，而是在同一套胜负里各自完成一项不可替代的大动作。平台清仓失败，玛拉留下重建合作社；货柜领袖答应护送万机馆走完下一段路，四台重涂机留在木桶街成为百机航路的第一组本地支援，旧拳王正式登舰，无牌一号取得前往工务城接受完整构筑席认证的资格。

转子救回了万机馆，却在超负荷转向后留下从舰腹一直传到展厅的持续震动。它能飞，不能再打第二次同样的仗。下一站不是因为一张手续，而是因为只有工务城能把这具旧转子与万机馆的舰体真正校正。白鸢以权利追索者和临时乘客身份上舰。她看见七海出现在纪存终端里，问：“不介绍一下？”七海先报姓名：“佐伯七海，调查他的人。”纪存补了一句：“也是我欠一顿饭的人。”白鸢打量两人：“调查对象还负责请客？”七海说：“本来不是。后来他把博物馆开走了。”三人的关系从一场信息来源成立的打量和试探开始，不靠任何人提前知道别人的私事。

## 本章的情绪与游戏回报

- 唐胶不是用一次忏悔还清过去。他公开方法后救下转子，也让四机暴露在回收链下；他和玛拉都必须继续承担木桶街重建，而不是当场洗白。
- 纪存连续做三件主角动作：把万机馆压进泊位接回巨型转子；以共同发布者身份接下唐胶选择的后果；在终战用新转子完成全舰转向。他不是资料管理员。
- 七海始终远程且无越权能力，但她提供别人不愿说的真实后果，也开始看到纪存不会把她只当后门。白鸢到场后，三人第一次产生成年人的打量、试探和职业敌意。
- 玩家取得完整E01胜利、E02四机差异化空战、E03机器人拳击Boss战、E04全机群与百米巡展舰总动员；永久回报为旧拳王、主转子、无牌一号后续资格、百机航路第一组支援和白鸢临时登舰。
- 本章的模型/玩具文化不是讲座：修补痕决定四机真实机况，模型同构数据帮助无牌一号构筑，未发售玩具与两米工程样机建立现实联系，旧拳王的失败录像改变驾驶方式。

## 候选迁移

1. 玛拉·维拉尔作为C02本地重要角色新增；C01末匿名呼叫者与她合并。
2. 豪司在E03驾驶旧拳王，不再为旧拳王另造具名驾驶员；此举不改变勇拳已被企业回收、社勇王留到C03的事实。
3. 主转子在E01完成物理落座，C02E04首次承受战斗负荷，C03继续承担完整校正；不再让E01只“离仓未送达”。
4. 白鸢在E03终场肉身抵达、E04临时登舰；其作品痕迹仍可从E01开始出现，但不参与现实控制。
5. 旧C02各话具体战斗动作、扫描门解法和开放日细节由本脊柱覆盖；跨章职责和实体生命周期继续保留。
