# C03E04《第一座可以回来的城》游戏流程解构

## 玩家体验一句话

玩家亲手把百米万机馆驶入第一座正式泊位，再经历社勇王归队、七海去留与两封跨越二十七年的求援，启动真正的百机航路。

## 游玩顺序

### 1. 战后城市自由活动

- 开放中央校正场、四台职业机工位、社勇王交接区和新公共泊位。
- 玩家可看到城梁巨机已改变的城市天际线，以及E02、E03中保下来的设施和伤痕。
- 可选对话交代四台职业机后续去向，不强迫所有机体登舰才算收集完成。
- 白鸢与陆衡完成一段短ADV：两台宣传实机没有共享数据，也没有被写入旧分镜；更早的生产记录不在工务城。此处只关闭“有人暗中塞入脚本”的简单解释，不揭示机魂真相。

### 2. 作业整备：无牌一号的跨城背架

- 唐胶、陆衡和本地工班为无牌一号装上导航应答、牵引钩与道路识别灯组成的作业背架。
- 整备使用已有改装界面，玩家完成固定套件的安装与外观确认；物理结构与主线结果保持一致。
- 这是无牌一号首个跨城作业套件，不改变它作为可换装构筑主力的定位。

### 3. 非战斗巨构关：万机馆归港校正

**操作形式**

- 使用一张简化的SRPG地图。无敌军，万机馆作为百米母舰单位，无牌一号作为前导单位。
- 城市职业机已提前把路线清成一条主通道，玩家只需完成一次大幅转弯、一次窄处通过和一次关闭主推进后的惯性停靠。
- 不做压载数字、接口对齐或多处微调QTE。操作重点是巨舰转向时的尺度感，以及城市机群在前后两端协同导引。

**成功结果**

- 播放万机馆入港动画，巨型停靠臂在舰体稳定后落下。
- 解锁工务城返航点：免费基础维修、职业机公共支援、城市后续委托与特定改装。
- 泊位供电恢复旧中继站，为本话后半的双时间讯息提供玩家已看见的物理前因。

### 4. 社勇王部署ADV

- 企业无人拖车要求社勇王分解返厂，社勇王自行收起牵引接收口。
- 工务城提出三个月公开道路试用，范围包括跨城公共任务与紧急救援；企业保留所有权、维护与检查，万机馆提供移动整备与任务场景。
- 社勇王在企业签字前先坐进外泊位，作为人格喜剧和主体选择，不写成纪存打赢便获得所有权。
- 豪司在签约后实体登舰。社勇王与豪司在三个月试用期内成为长期可操作编队，企业召回与续期作为后续剧情问题。

### 5. 舰内ADV：三人的下一程

- 白鸢把自己的成人向机器人样衣借给七海后离开处理工作；纪存随后到场，暧昧来自两个人真实的窘迫和停顿，不写三人轮流抖机灵。
- 七海收到真实复职审查通知，纪存送她去车站。在求援出现以前，两人的ADV必须让玩家明白七海真的可以选择回去。
- 关系高低只改变纪存是否能问出“你会不会和我们一起去下一站”，不让他提前直白告白，也不取消七海出于主线原因留舰的独立决定。

### 6. 双时间求援

- 旧中继站收到天空铸环当下求援，并同时释放滞留二十七年的深空缓存包。
- 当下讯息的玩家可见证据：轨道工房正遭外袭；未完成巨型机体库被启动；命令使用七海早已停用的生产授权。
- 旧讯息只播放一段女性通讯员的断续语音，不在此时展开远征队全史。值班员只能确认旧信道仍有回传入口，无法保证回复能够抵达当年的收信人。
- 两包包头都显示中继呼号 `WHITE ARK-03`，只作为疑问；不提前确认它们来自同一艘物理舰。

### 7. 七海留舰与百机航路解锁

- 七海让同事继续提交事故证据，自己取消必须本人到场的本轮复职说明会并退票，以“随舰事故观察员＋旧签名滥用调查员”身份实体登舰。旧口径“共同监督”登记为迁移债，不在正文使用。
- 解锁“百机航路”系统：来自不同城市的机体可以选择入队、地方支援、路线转发、泊位、维修或情报中的一种贡献方式。
- 陆衡以工程联络人身份随舰，继续追踪旧程序去向；他携带的是普通测量仪和手工具，不是方舟T或任何新AI载体。此项作为Candidate迁移，需用户确认后回写人物生命周期。
- 火种货柜领袖不占用舰内席位，转入地面路网为百机邀请转递消息；后续保留召回和剧情参战资格。

### 8. 结算与C04交接

- 万机馆：获得工务城正式返航泊位，完成低速校正；未解锁完全战舰化或人形变形。
- 无牌一号：获得跨城作业背架与道路作业资格。
- 社勇王/豪司：三个月试用期内长期可操作，保留企业所有权、召回与续期问题。
- 七海：放弃本轮复职审查并实体登舰，仍无代哥、军方或工务城命令权。
- 天空铸环当下求援、二十七年前白舰包与百机航路邀请共同构成C04入口。

## 变量与分支

- 归港校正的用时与碰撞次数影响本章维修费和城市对话，不取消返航点。
- 七海与纪存的关系状态影响车站ADV的直白程度。主线中她因当下授权冒用与天空铸环危机留舰，不将职业选择完全绑定恋爱值。
- 百机邀请初次只开放已认识城市与机体；后续章节再随公共信任、通信路线和展示成果扩展。

## 资产与演出级别

- A级：万机馆入港与公共泊位合拢；双时间讯息首次播放；百机航路启动蒙太奇。
- B级：无牌一号牵引导航；社勇王拒绝无人拖运并入位。
- C级：三人舰内生活ADV；车站选择；陆衡登舰；货柜领袖转入公路。
- 港口、中央校正场与工务城站台均复用本章已有场景；天空铸环只需少量通讯画面，不提前制作C04全量资产。

## 与纯剧情Reader的一致性

- 泊位、社勇王部署、七海留舰和百机航路都由Reader中已成立的人物选择与事件派生。
- 巨构校正只将Reader里的归港动作变成玩家操作，不另加一套转子、压载或接口剧情。
- 当下与二十七年前讯息的差异通过画面、时间戳和声音完成，不让角色朗读完整远征史。
- 七海保留了返回体系内的真实可能，留舰同时回应职业、主线和关系，不被简化为“为了纪存放弃一切”。
