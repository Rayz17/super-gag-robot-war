# C03E03 冷读与三层一致性审查 v1

## 审查边界

第一遍连续读取E01、E02和本话纯剧情；第二遍读取玩法与公开情报。独立审稿先判为`REWRITE_ONCE`，围绕物理站位、第二锤信息差和胜利结果完成一次定点修订。

## 白话复述

衡令占据中央巨环，把环上原本用于校正巨机的作业臂武器化，并用工务缆索把城梁巨机、万机馆和城市永久固定。企业拒绝让运输中的社勇王实战合体，社勇王却主动向正在清路的豪司开舱。四台职业机为模块车打通合体线，社勇王完整合体，一锤击裂巨环工具架。豪司准备第二击时，衡令才拉出埋在地下的固定缆，把医院和住宅接入受力路径。社勇王提醒下面有人，豪司立即撤回命令。万机馆脱缆后驶入巨环封住接线路径，社勇王与职业机改用支撑和拆卸动作，最终拔掉巨环的城市控制接口。衡令只带受损旧核逃走，工务城、城梁和万机馆获得完整胜利。

## 因果、尺寸与站位

- 巨环地下固定缆在开战时已亮起待机灯，第二锤反转使用的是既存设施，不是高潮临时发明。
- 万机馆开战时停在待校正区并被缆索缠住；四台职业机先替它脱缆，它才启动推进器进入巨环。
- 二十余米的社勇王只顶住巨环正在下沉的一段压梁，没有以小体型托住整座数百米结构。
- 豪司下令时，可见缆索已经松开；危险由衡令在蓄力后突然接入平民设施造成。豪司看到画面便撤令，不靠迟疑制造戏。
- 黄金重锤击裂巨环工具架，吊装机随后拔出实体城市控制接口。衡令能逃走，但在工务城已失去接入设备的物理条件。

## 人物、机战精神与声线

- 豪司关掉直播再登舱，先获得完整合体和必杀技大胜，再面对“英雄动作此刻会伤到谁”的选择。
- 社勇王拒绝的是一次危险动作，不是拒绝豪司本人；豪司撤令后仍留在驾驶席，共同完成终战。
- 白鸢只提出断索可能扫中连桥；七海要求现场复核后撤人，能力没有越级为画线改现实。
- 兜灯掌握停机准备，馆守Z自己回答是否继续；关系通过真实战斗动作表达。
- 纪存让百米舰体进入棋盘并承担风险，不只在后方调度。

确定性声线检查为`PASS`。独立复审仅发现玩法结算残留“临时承重位”旧句，修为万机馆退出巨环、城梁恢复承重后通过。

## 三层一致性

- 游戏流程先让玩家清出合体线，再操作社勇王完成首锤，最后转为全机群拆缆和拔接口，顺序与Reader一致。
- 没有新增无人工机、专用气力Buff或“工具协作”支援按钮；职业机直接以本体执行动作。
- 公开情报只解释豪司为何被选择、第二锤为何能停、衡令为何失去工务城接口。
- 社勇王正式随舰依据留到E04的三个月试用，不在胜利结算时自动转移所有权。

## 尚存但不阻塞的Candidate风险

1. 衡令旧核逃走后的能力上限必须在再登场前重新建模，不能默认仍可随意控制其他城市。
2. 社勇王的企业产权、三个月期限和机体主体选择已经同时存在，后续必须产生至少一次真实矛盾，不能只当入队手续。

`PASS_CANDIDATE_AFTER_ONE_CAUSAL_REPAIR`
