## 为什么原有检查没有发现问题

原稿已经避开了“你可以……但别……”“不替谁决定”等高风险模板，因此确定性检查为零命中；但四话的人类角色仍共享同一种表演状态：短句、冷静、反应过快、每句话都像已经想好。这个问题属于语义与表演，不属于禁词检测。

本轮不靠补语气词解决，而是逐场重新确认：这句话说给谁、希望对方做什么、角色此刻知道多少、两人熟到什么程度，以及是在日常、争执、关系试探还是抢险中说话。

## 声线重新分工

| 角色 | 本轮保留的说话习惯 | 不再共用的“酷句式” |
| --- | --- | --- |

| 七海 | 先回应眼前人的状况，再指出具体风险；私人场会故意逗人，也会照顾饮食、睡眠与行程 | 把关心写成流程，把承担写成判词 |
| 白鸢 | 句子偏长，会调侃、岔开、自曝创作糗事；判断不准时会承认并扩大误差 | 一开口就总结作者与角色的关系 |
| 陆衡 | 会把工程判断讲到听众能执行的程度；犯错时说清当年怎样说服自己 | 只报参数、只说“我知道”或冷静认罚 |
| 唐胶 | 工房口语、先拦手再解释，带“啊”“先别硬扣”等现场语气 | 把手艺写成一句漂亮原则 |
| 兜灯 | 仍然短硬，但担心直接落在馆守Z的伤处和纪存的操舰动作上 | 与其他人共享冷静口令 |
| 豪司 | 会抢话、主持、丢脸、把企业话术与热血口号混在一起；真正危险时立即撤回必杀 | 只有热血金句，或突然成熟得像审稿人 |
| 社勇王、馆守Z、衡令 | 保留字面、任务化、简短的机器声线 | 不用人类的语气词伪装成人 |

## 四话主要返修

- E01把纪存、陆衡、七海的重逢改成真实问候、熬夜与临时出差的交流；白鸢和七海第一次实体见面不再像两位冷面高手互换金句。白鸢询问隐藏维修坡道时明确承认自己只看见一半路线，并请本地女工把图改乱。
- E02把陆衡撤回旧程序改成一次有人阻拦、本人犹豫、七海追问“外地今晚怎么办”的现场决定；白鸢用自己赶稿失败的经历回应，而不是替陆衡总结主题。围捕说明改成可以听懂的现场交代，唐胶先拦住学徒再说怎样试装。
- E03保留合体、必杀与抢险时的短口令，因为那是危险状态；白鸢的预演明确带误差，七海先撤人再复核。豪司在战后承认自己会先争一句、然后听社勇王中止，不再用两句冷对白完成伙伴关系。
- E04让豪司与社勇王像刚开始搭伙的驾驶员和机体；七海、白鸢、纪存的生活与站台场允许玩笑、窘迫、停顿和没说准的话。纪存回应二十七年前的讯息时只回答对方真正问的一个名字，不再做机体点名播报。

## 语义复审

- **听众测试**：主要对白均能指出具体听众和即时目的；系统播报、城市调度与机器报告除外。
- **匿名换人测试**：纪存、七海、白鸢、陆衡、唐胶与豪司的生活及关系对白不可直接互换。少数战斗口令具有通用性，因其职责是让现场立即行动，予以保留。
- **句长与节奏测试**：日常和争执恢复中长句、追问、改口与停顿；短句主要集中在合体、撤招、操舰和紧急疏散。
- **角色知识测试**：白鸢承认预演误差，七海不把图当神谕；陆衡只解释自己掌握的工程记录；机器只报告自身感知和任务。
- **关系测试**：纪存与七海有熟悉和关心但尚未直白告白；白鸢与七海从视频协作过渡到第一次实体共事，不假装已经非常亲密。

结论为`READY_FOR_USER_REREAD`，不是用户验收。此前各话审查文件中的“声线PASS”仅证明当时的内部检查，本文件取代其声线结论；因果与三层一致性结论仍保留。
