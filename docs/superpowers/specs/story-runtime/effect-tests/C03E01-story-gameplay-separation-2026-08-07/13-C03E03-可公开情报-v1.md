# C03E03 可公开情报

> 只解释社勇王首次合体、停锤与衡令失去工务城接口的当话事实。

## 社勇王为什么选择豪司？

社勇王可以自主响应公共救援请求。豪司曾参与同一操纵系统的试驾和四模块合体训练；资格暂停后，他仍在地面工作组清理合体道路。

社勇王在紧急状态下主动向豪司开舱，选择的是一个熟悉自己、也正在现场承担工作的人。这次选择不等于企业已经恢复豪司的正式试驾资格。

## 社勇王为什么可以拒绝第二锤？

豪司负责驾驶意图和武装命令，社勇王负责合体校正与实时安全判断。豪司下令时，现场可见缆索都已松开；衡令是在巨锤蓄力后才启用地下固定缆，把攻击力量导向住宅和医院。

社勇王报告新危险并停下动作，豪司看见画面后立即撤回命令。双方都没有夺走对方的位置，而是共同把必杀技改成支撑巨环的工具。

## 衡令为什么失去了对工务城的控制？

衡令启动巨环后，利用巨环工具架内部的实体接口接入工务城设备。黄金重锤击裂工具架后，市政吊装机在终战中将这块接口完整拔出，工务席随后现场封存。

衡令的旧稳定核仍然逃走，但它已无法继续调用工务城的吊臂、缆索和供能设备。这是本章的永久胜利，不代表它在别处没有新的行动方式。
