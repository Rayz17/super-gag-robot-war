## 一页结论

**Opening Arc整体过关，阅读力排序为 `C01 > C03 > C02`。**

三章形成了一条无需重新发任务的连续主因果：

```text
固定馆将被拆散
-> 外敌突入，馆守Z起身，万机馆紧急离城
-> 航行损伤迫使一行争夺替代转子
-> 新转子只能把万机馆连续送到工务城
-> 以城市承重换校正和公共泊位
-> 衡令试图把万机馆、职业机与城市永久固定
-> 勇者合体与母舰入环赢下城市级Boss战
-> 得到第一座返航港、社勇王与百机航路
-> 天空铸环、旧签名与二十七年前远征包共同发动下一章
```

C03不需要重启或整章重写。用户指出E02战斗解构倒灌正文后，该话已按人物与局势主导的口径重写；新Reader连续冷读未发现P0/P1，四话因果和E02到E03的工具生命周期均已接通。

## 三章分别做对了什么

### C01：把“最后一次导览”一路推成机器人大战

- 开馆、闭馆、馆守Z、勇拳、观众和固定馆的历史都服务同一件事：今晚之后，这些东西还能不能继续在一起。
- 馆守Z从展台起身、用右臂打碎BREAKER外壳、万机馆恢复巡展舰身份，是开局最强的一条连续奇观。
- 纪存从导览员变成疏散、出击和离港的决定者；七海撤回本人旧命令，却没有越权替城市批准战斗。
- “第七次巡展”、木桶街邀请与白色采样机形成情感、下一站和敌方三重钩子。

### C02：机器人文化和机体人格最完整

- 无牌一号想打完自己的比赛，旧拳王要教完未完成必杀，完全版王者拒绝被全装和旧最终话定义，三台机的欲望彼此咬合。
- 赵梅从儿子留下的账号和笔记开始学，最终建立合作社，是前三章最扎实的人类泪点之一。
- “旧舞台撑不住新结局”、完全版王者亲手卸下全装、逆转天冲拳完成第二步，真正消化了机战和动画文化，不只是摆梗。
- 冠军、新转子、无牌一号与旧拳王登舰，都有物理交接和主体同意，玩家拥有感很强。

### C03：首次成为多机编队与城市级SRPG

- 城梁巨机换位、衡令锁舰、货运环追击、中央巨环、社勇王现场合体、黄金重锤和百米万机馆入环，构成稳定的城市级奇观链。
- 纪存连续作出会改变结果的决定：接受承重交换、主动设计衡令围捕、识破它真正追逐巨环、让万机馆进入巨环、回答旧讯息并发出百机邀请。
- 社勇王主动点名豪司、完成完整合体，又在第二锤会伤到居民时提醒停下；豪司立即撤令，二者共同完成终战。
- 七海错过本人必须到场的复职说明会，以“随舰事故观察员＋旧签名滥用调查员”登舰；这同时推进事业、主线和关系。
- 万机馆得到一座离开后仍为它保留的公共泊位，社勇王得到三个月跨城试用，百机航路收到第一批回复。胜利不是又一张未来罚单。

## 机器人大战体验

前三章已经明确是机器人作品，不是“救援故事恰好使用机器人”。三章各有一组可作为PV主画面的核心：

1. 馆守Z从展台起身，万机馆追上天空。
2. 无牌一号完成逆转天冲拳，完全版王者卸下全装走出旧结局。
3. 社勇王现场合体，黄金重锤劈开被武器化的巨环工具架，万机馆以母舰身体堵住巨环。

机体奖励也逐章扩大：

| 章节 | 长期获得 |
| --- | --- |
| C01 | 馆守Z、万机馆航行、旧馆核心团队 |
| C02 | 无牌一号、旧拳王、替代转子、木桶街支援关系、白鸢登舰 |
| C03 | 社勇王/豪司试用编成、工务城返航港、职业机公共网络、七海与陆衡登舰、百机航路 |

四台职业机已经拥有具体磨损、工作习惯和出战意愿，但仍主要以吊装、供电、封路和消防功能被记住。它们足以作为地方机群成立，尚未达到四名常驻角色的记忆强度；不应为了平均戏份再给每台追加完整个人篇。

## 人物与关系

### 纪存

他的开局成长已经从“替展品讲过去”推进到“组织仍在行动的机器走向下一站”。E02由他主动选择战场、设计围捕并识破衡令目的，终战再由他亲自把百米万机馆驶入巨环；他不再只是留在调度席替别人做细节安排。

C03仍有E01守桥与E03避开居民的保护性选择，但E02已经改为先赢下四机夺回、主动设计围捕并识破敌方意图，再由衡令主动舍弃工具换取环心。C04仍应继续换挡到主动进攻，不再用“放弃制胜一击、救人、敌人逃走”证明纪存正确。

### 七海、白鸢与纪存

- 纪存与七海从C01错过晚餐、C02远程报平安，推进到C03现场重逢、明确挽留和七海付出职业机会登舰。
- 七海与白鸢从证据合作推进到现场互救、共享生活空间。借衣场已去掉三人轮流抖机灵，暧昧来自真实窘迫。
- 纪存与白鸢目前仍以作品追责、机体选择和同行调查为主，没有为了形成等边三角而让她突然改动机。
- 白鸢来工务城调查两台宣传实机为何记得旧分镜。本章排除了“共享数据或暗中写入脚本”的简单答案，并让未完成机体库成为继续追查的自然联想。

### 群像债

- 旧拳王以继续训练无牌一号、收取“学费”为由登舰，C03只安排战术协作，尚未续写师徒关系。C04或其后的舰内事件必须兑现一次，不能让它退化为普通战斗单位。
- 唐胶和兜灯在C03保持职业辨识度，没有重复C02的旧错坦白；后续可推进二人关系，但不必每章都争论维修伦理。
- 陆衡撤回跨城认证只是一项长期事业的开始。其他城市的旧程序不能因一场公开承认自动消失。

## 仍然存在的共性风险

### 1. 保护性选择仍偏多，但E02已打断“放Boss走”结构

C02在冠军决赛之后又进入旧最终话、舞台事故和货运环救援，形成第二次终局疲劳。C03仍以守桥开章、以从居民梁上撤锤完成Boss战，保护性选择连续可见。

新版E02已将“回收热障、衡令趁机逃走”删除，改为玩家夺回全部工具并主动合围，衡令则以放弃装备、借力越线的可见行动进入环心。它至少让纪存和玩家获得一次主动战术胜利，也让敌方反转来自自己的选择。C04仍必须进入主动进攻、身体争夺、旗舰历史和地外敌人正面战，不再围绕一座设施正在塌展开。

### 2. 白鸢的路线戏必须暂停

C02末和C03E01已经使用“她画路线、现场人员修正”的结构。新版E02不再画战术路线，只让她从陆衡身上看见自己曾把不同角色改成同一个模板的错误。下一章不能再画一张路线证明她学会尊重现场；若能力升级，必须改变戏剧问题，而非只提高图的准确率。

### 3. C02仍是连续阅读的低谷

C02的高光很高，但五话体量里有冠军高潮、旧最终话和事故救援三次收束；关于模型/实机、主体同意和旧记录的原则也重复举证。此次任务不修改已验收C02，但未来若制作“纯剧情连读版”，优先做结构剪辑和资料卡外移，不重写已成立的机体故事。

### 4. 当前Reader格式尚未完全统一

C03已严格拆成纯剧情、游戏流程和公开情报三层；C01在章末、C02在每话后仍内嵌公开情报。以后回看C01、C02时，应机械拆出纯剧情连读入口，而不是在正文里继续混入制作说明。

### 5. E03中段仍有少量工程调度密度

独立连续冷读认为这不构成P1，但从社勇王第一锤到万机馆入环之间，人物有几段更像现场指挥。进入Episode Reader下一轮时，可在不改战斗因果的前提下再压缩一轮术语与逐机调度，优先保留豪司撤锤、七海与白鸢撤出观察席、纪存驾驶万机馆入环三个人物动作。

## C04不可违背的接续门

1. **类型换挡**：主轴应为天空铸环、身体制造、三旗舰历史和外敌袭击，不再以城市结构事故发动全章。
2. **轨道能力**：万机馆当前只证明低空与跨城航行。抵达轨道工房的方法、耗时和限制必须在C04开场讲清。
3. **谜团限流**：C04优先处理天空铸环、七海旧签名和未完成身体；白色采样机、BREAKER后台、`WHITE ARK-03`、纪存真身不能同时全部揭晓。
4. **纪存天赋有验证**：辨认机魂应允许误判、拒绝和他人复核，不能直接升级成全知认证器。
5. **关系不复位**：七海已实体登舰并失去一次复职窗口；白鸢的工务城调查有阶段结果。C04必须让共同生活、调查方法或能力分歧产生新后果。
6. **编队控席**：随舰已有馆守Z、无牌一号、旧拳王和社勇王。未完成机体库不能一话全变成新队员；百机航路先兑现一次具体外援。
7. **兑现旧拳王**：至少安排一次对无牌一号的训练、争执或战中配合回收登舰理由。
8. **货柜领袖不偷渡**：它已经转入地面路网，C04不能默认在舰内；若支援必须满足真实通信和路程。
9. **方舟T不藏在工具箱里**：陆衡带上舰的是测量仪和普通手工具。现行Canon只允许C04出现无人格折叠探测器，方舟T本人及与陆衡的正式关系仍在C10；若要提前，必须先做人物生命周期迁移，不能用一句“箱子醒了”偷换。
