# C03E02《四机出击！把工作抢回来》游戏流程解构

## 玩家体验一句话

在一条正在加速的城市货运环上夺回四台职业机的工具，再利用恢复的四种城市作业能力，把衡令完整逼进中央校正场。玩家先赢下一场主动围捕，再亲眼看见衡令从巨环中发动下一阶段。

## 游玩顺序

### 1. 早班自由活动

- 地点：工务城中层环、四个工位与临时维修区。
- 玩家可以依次看到失去吊臂、供能架、隔离墙和热障后，城市早班出现的具体后果。
- 与预算二号的维护员交谈，回收“一号预算没批”的日常笑点。
- 陆衡公开旧程序删改记录并撤回认证；七海要求同时给出临时停机办法。这段用ADV和现场屏幕表达，不做代码教学。

### 2. 出击编成

- 必定可用：馆守Z、无牌一号、旧拳王、火种货柜领袖。
- 万机馆留在待校正区，作为远程支援与纪存指挥席，不在这一关自由移动。
- 四台职业机开局可以移动，但不具备各自的地形能力；夺回附件后才转为完整友军。

### 3. SRPG：货运环夺回战

**地图轮廓**

- 只使用一张环形追击地图，保留外圈、内圈和一条低位货车道。
- 不再制作三层城市迷宫。地图的变化由四台职业机夺回工具后的大动作完成。
- 衡令沿主环向中央校正场推进。终点是玩家已知的围捕区，不把“追上逃跑Boss”作为唯一目的。
- 校正场内外圈、黄色警戒线、自动灾害隔离门和环心机械启动台在出击说明及地图远景中提前可见；社勇王四模块运输车作为不可操作背景单位停在外环候场区。

**主目标**

- 打断衡令身上四组附件的固定部位，并护送对应职业机完成回收。
- 四组工具全部夺回后，目标切换为利用吊装、供能、封路和热障四种作业能力收窄道路，将衡令压进中央校正场外圈。
- 阶段胜利条件是四组工具全部回到原机、四台职业机仍可行动，并在衡令越过黄色警戒线前完成外圈封路。结局固定为衡令主动舍弃最后一件工具、借馆守Z冲击越线；它以本体进入环心，不是因附件滑走或救援插曲自动逃脱。

**四次地图改变**

1. 吊装机夺回吊臂后，抬起一段重轨连接内外环，形成新进攻路线。
2. 预算二号装回供能架后，让移动平台恢复稳定速度，开放内圈转台。
3. 灰崎机夺回交通墙后，玩家可以在若干宽路口选择封闭两处，迫使衡令进入更窄的路线。
4. 消防架桥机夺回热障后，清除校正场入口的高温排气区，让四台职业机能够同时抵达最终围捕位置。

### 4. 战中剧情与演出

- **货运环奇观**：先以短动画展示衡令把四种城市工具穿在身上、万机馆机群从高架与外环两侧追上的全貌。
- **载具变形演出**：火种货柜领袖在货柜车与作业机器人之间切换，冲开外围护卫，为本地机体创造接取工具的窗口。
- **职业机合围**：四组工具全部归位后进入玩家主动布置阶段；四机的大动作改变道路，万机馆机群负责把衡令赶向玩家留下的唯一出口。
- **纪存与白鸢识破**：白鸢把几次受击位置叠在同一页，玩家看见所有点都在向巨环靠近；纪存指出“它不是在逃”，目标随即从追击改为抢先封住黄色警戒线。
- **敌方主动反转**：衡令主动放开最后一面交通墙，引导灰崎机接回全部工具；随后正面承受馆守Z冲击，借力越线。自动灾害隔离门闭合，把随舰机群挡在外圈。衡令再使用开战前已经展示过的机械启动台升起巨环。该动作是E03入口，不抹消E02已夺回工具和恢复四机的结果。

### 5. 战后ADV

- 四台职业机在校正场外重新列队，工务频道确认四组工具全部收回。
- 衡令以自己熟悉的旧式机械应急台启动巨环，转入下一话的城市级威胁；社勇王试验车队从本关开始前就在外圈候场。
- 社勇王四模块车按既定试验日程到站；豪司以地面工作组身份出现，核心车将镜头转向他。

### 6. 结算与下一话交接

- 市政吊装机、预算二号、灰崎机和消防架桥机恢复本地行动能力，并在本章后续战斗中临时协助万机馆；跨城公共支援关系留到E04正式建立。
- 陆衡旧程序认证及本人相关资质暂停，触发后续跨城问题线。
- 衡令保留受损本体并越过内圈警戒线；不携带四组实体附件。自动灾害隔离门把它与我方分开，它启动巨环后才重新获得场域优势。

## 变量与分支

- 玩家可以先夺回吊臂或供能架，改变前半场可走路线；后半场由玩家选择交通墙封路位置和四机围捕次序，剧情结果保持一致。
- 四组工具会保留本话造成的损伤外观，但不把“零件完整度”继续折算成下一话的隐藏强弱变量。

## 资产与演出级别

- A级：货运环全景追击；四机合围；话末巨环升起。
- B级：货柜领袖变形冲撞；四台职业机恢复工作后的地图改造动作。
- C级：陆衡公开撤证ADV；吊臂现场复装。
- 地图复用E01工务城中层资产，新增内容主要是移动货运环、四组附件及话末巨环远景。

## 与纯剧情Reader的一致性

- 玩家操作的就是“夺回工具”，不另造占点、解谜或数据收集任务。
- 四台职业机的玩法能力来自Reader中已写明的职业动作。
- 四组工具全部夺回是玩家主动完成的结果；衡令舍弃工具、借冲击越线和启动巨环均有可见动作与前置设施，不靠救援插曲或“Boss剧情无敌”强行收尾。
