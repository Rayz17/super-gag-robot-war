# C03E01《整座城压上来》游戏流程解构 v1

## 玩家体验一句话

玩家第一次进入一座由巨大公共机器人维持运转的城市，并在万机馆被迫充当城区支柱时，一边守住医院交通桥，一边阻止衡令把整艘展舰永久钉进城市。

## 游玩顺序

### 1. ADV：接近工务城

- 播放工务城远景：封路后的城区板缓慢换位，城梁巨机在远处行走，公共工务机仍在上班。
- 火种货柜领袖沿地面重载线出现，第一次完整开口，并承担最后一段道路引导。
- 陆衡在重载坞实体首登。对白明确回收他在木桶街的远程协诊，并说明万机馆来此是为了主转子的重载校正。
- 玩家此时只需理解一件事：不完成校正，万机馆下一航段无法可靠停靠和重启。

### 2. 自由活动：重载坞外环

用途是认识工务城，不设置缩尺机器人反复试路小游戏。

可选交互：

- 观察城梁巨机换位，得知工程已提前三天封路和疏散；
- 与陆衡查看新转子的航行记录；
- 与兜灯检查馆守Z外泊固定；
- 与唐胶观察工务城长期维修留下的不同年代补丁；
- 看见七海走访客通道入场，随后进入必经ADV。

自由活动结束条件：进入市政总席说明会。

### 3. ADV：交换条件与七海到场

- 工务城提出明确交换：万机馆替医院交通桥承重二十分钟，换取主转子校正和可回访泊位的测试资格。
- 陆衡用城市远景和工程时间表说明这是既定工程，不是临时制造危机。
- 纪存主动接受。
- 七海说明自己因停职后仍有人调用其电子签名而到场；她是事故证人，不拥有本地指挥权。
- 白鸢与七海完成首次实体见面，保持有限合作而非无前提熟识。

### 4. 短动画：城梁换位

- 万机馆进入交通桥下方并展开临时承重点；不展示接口逐件连接。
- 城梁巨机从旧基座缓慢走向新基座。
- 四台临时支撑突然离场，万机馆下沉。
- 衡令升起，新的固定架从重载坞两侧合拢。
- Hengling 宣布要把万机馆永久留作城市支点，切断联网控制。

动画结束后直接进入SRPG，不在剧情段继续解释关卡规则。

### 5. SRPG：托住桥，拆掉锁

#### 地图构图

- 下缘：固定于临时承重点的百米级万机馆，占据多格，不能常规移动；
- 上缘：医院交通桥，作为整体场景压力而非可遍历第二层小地图；
- 左侧：城梁巨机由旧基座向新基座缓慢推进；
- 中央：三副永久固定架与衡令；
- 两翼：市政工务机、维修坡道和自动工机入口。

地图只保留一个主要高差层，避免同时操作舰内、桥面、城市地下和多层环轨。

#### 我方单位

- 馆守Z；
- 无牌一号；
- 旧拳王；
- 火种货柜领袖，开战后以一次完整变形动画进入作业机形态；
- 万机馆作为固定母舰/场景单位，提供有限支援动作。

#### 敌方与中立单位

- 衡令；
- 三副固定架；
- 自动锁定工机与附件拖机；
- 四台市政工务机最初为受锁中立单位，本地驾驶组在战中逐台恢复控制。

#### 胜利条件

- 摧毁或拖离三副永久固定架；
- 在城梁巨机抵达新基座前保持交通桥稳定。

#### 失败条件

- 万机馆临时承重状态归零；
- 馆守Z、无牌一号、旧拳王或货柜领袖全部失去行动能力；
- 衡令完成三副固定架的永久闭合。

#### 主要玩法

1. 万机馆每轮只能在“稳住桥体”和“支援前线”之间分配一次母舰行动，不能移动。
2. 玩家帮助本地工务员解除一台市政机的锁定后，该机在本战提供一次场景援护，并为下一话保留不同起始状态。
3. 直接攻击衡令无法结束战斗；必须先处理固定架，故事目标与关卡目标一致。
4. 城梁巨机抵达新基座后触发地图变化，万机馆获得一次“抬起舰首”场景动作，使固定架失衡并进入最终进攻窗口。

#### 关键战中演出

- 火种货柜领袖首次完整变形；
- 本地工务员切断总席广播，改用现场频道互报位置；
- 白鸢用折叠分镜板叠加现场画面，一条未完成的路线异常地停在隐蔽坡道附近；本地女工接过同一支笔，补齐真实入口、限高和危险点，再由白鸢原样同步给舰桥。这是可共享的现场预演，不产生现实改写；
- 城梁落脚、万机馆抬首、馆守Z单臂拔出主锁架形成本话PV级高潮；
- 衡令撤退时带走四台市政机的重要附件，直接发动E02。

### 6. 战后ADV

- 工务城确认万机馆没有被永久固定，但校正和泊位仍未完成。
- 本地工务员请求联合夺回附件，建立临时共同战线。
- 陆衡从锁定记录中认出自己早年删去现场确认的程序版本，E02责任线正式发动。
- 纪存先询问随舰机体是否愿意继续，不直接替全队决定。

## 资产与演出级别

- 高成本短动画：城梁换位；货柜领袖变形；城梁落脚与馆守Z拔锁。
- 主地图：工务城重载坞一张，开战前后复用。
- 远景资产：缓慢移动的城区板与城梁巨机，可用预烘焙动画而非实时全城变形。
- 新战斗资产：衡令、三类固定架/工机、货柜领袖作业机形态。
- ADV新场景：重载坞入口、市政说明席、夜班维修位。
- 角色复用道具：白鸢的折叠分镜板。只需支持实景叠加、手写线条和多人接续修改；本话不做“画面改变现实”的视觉效果。

## 与纯剧情Reader的一致性

- 剧情中的“临时承重换校正”对应关卡中的固定母舰与桥体稳定目标。
- 剧情中的“三副固定架”对应唯一主要破坏目标，不另加无关护送或资格赛。
- 白鸢能快速把混乱现场整理成候选路线，但未经现场人员确认的线不能直接用于行动；折叠分镜板是共享工具，不是战斗指令器，她也不拥有画稿改现实的能力。
- 七海只作为事故证人和调查者到场，不替工务城、代哥或军方授权。
- 陆衡的旧程序只在结尾成为下一话问题，不在本话用长篇技术说明解决。
