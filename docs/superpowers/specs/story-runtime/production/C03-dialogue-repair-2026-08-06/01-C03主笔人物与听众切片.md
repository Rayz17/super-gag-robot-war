# C03主笔人物与听众切片

> 用途：C03 Episode Reader 的“全文对白去装腔”定点返修。
>
> 性质：写作上下文，不是Canon，不改写章节事实。主笔先读取稳定人物模型，再按场面只保留当下欲望、关系、知识和声线。冷读审稿不得读取本文件替正文补意义。
>
> 稳定人物源：`story-runtime/generated/characters/character_models.jsonl`、`data/character_voice/character_dossiers_core.tsv`、`data/character_voice/character_voice_rules.tsv`；场面事实源：C03当前L4、L4.5与四话Episode Reader。

## 一、全章对白目标

本轮不把人物写得更会说，而是让他们更像在现场生活和工作：

- 每句话都有具体听众和现实目的；没有听众的主题总结删掉。
- 人物可以没接住话、说半句、改口、误会、沉默或先做事。
- 同一场只允许一人偶尔说出完成度高的句子，其他意义交给动作和后果。
- 不用轮番机锋制造关系。关系由谁替谁拿东西、是否松手、记得什么、是否留下和是否改变行动体现。
- 工程人物先说别人能立即执行的人话。专业词只在它改变动作时出现。
- 机器可以更直接、字面、数字化；人类不能都像系统提示。
- 保留必要的经典口号、机体呼号和超级系舞台感，例如“最终合体，批准”。

## 二、稳定人物切片

### 纪存

- **当章欲望**：让万机馆脱困，也让工务城真的愿意成为可以回来的地方；章末主动召集百机航路。
- **压力反应**：先看谁仍在危险里，再给出能立刻执行的决定；不先打开终端讲原则。
- **关系方式**：记得七海的习惯和没吃成的饭；对白被戳中时会避一下，但不应每次都回一句漂亮话。对白鸢仍在建立熟悉，不能默认三人已经心照不宣。
- **句形**：中短句，紧急时直截了当；生活场允许普通、笨一点的回答。
- **本章不可写成**：冷面主持人、关系裁判、尊重选择宣言机器。

### 七海 / 佐伯七海

- **当章欲望**：查清自己旧签名为何仍在被使用，同时证明停权不等于放弃保护现场；她确实想回体系改革，直到天空铸环求援迫使她选择。
- **压力反应**：先指出哪里会伤人，然后亲自站到风险最近处；她没有工务城、军方或企业命令权。
- **关系方式**：对纪存有旧熟悉，体现在看伤、饮食、赶路和不必解释的生活细节；对白鸢先专业判断，随后因互救产生好感与戒心。
- **句形**：可以比别人说得完整，但一口气只推进一个判断。真正生气或着急时更直接，不用流程名词代替情绪。
- **本章不可写成**：全程冷幽默的御姐、放水官、责任结算人。

### 白鸢 / Evelyn Voss

- **当章欲望**：证明自己的预演能在真实大型现场有用，又不愿承认现场和驾驶员会把漂亮构图改得很难看。
- **压力反应**：先预想结果并抢着解释；真的吓到或受伤时反而短，甚至说不出漂亮话。
- **关系方式**：会用轻佻和观察测试距离，但第一次实体见七海时不能像熟识情敌；观察塔互救后可出现身体距离和尴尬，不用互相抖机灵证明暧昧。
- **句形**：平时较长、会岔开；真受伤时短。她可以有创作者词汇，但分镜只是候选预演，不是现实魔法。
- **本章不可写成**：原则宣言人、无所不知的关系旁观者、每句都色气或尖刻的金句王。

### 陆衡·姆旺吉

- **当章欲望**：先救下正在被自己旧程序伤害的机器，再追查十七城；不靠一场忏悔洗清过去。
- **压力反应**：报能执行的数据和步骤；被问到责任时不绕开，但不会当众发表伦理论文。
- **关系方式**：关心藏在维护建议里；唐胶若看出他手抖，他会先否认，再继续工作。
- **句形**：准确、偏短，但不是一句一顿的冷酷机器人。专业词后必须跟普通动作。
- **本章不可写成**：只会说“不科学”的吐槽役，或用术语替代羞愧。

### 唐胶 / 唐启明

- **当章欲望**：让本地学徒真的学会按磨损做适配，不让所有人继续依赖他。
- **压力反应**：先摸实物、挑毛病、动手；温柔藏在“我替你再试一次”一类实际帮助里。
- **关系方式**：对陆衡不说漂亮安慰话；对学徒允许啰嗦、重复和语气词；对兜灯会抢工具、被骂后照做。
- **句形**：中长句，带助词，先挑刺再把办法说清楚。
- **本章不可写成**：每句话都精准吐槽的段子手，或手作价值主题发言人。

### 兜灯 / 窦晓宁

- **当章欲望**：让万机馆、馆守Z和职业机都能在危险时真正停下来；把停机柄交给现场维护者。
- **压力反应**：先喊停、抢工具、检查伤处，再解释原因。
- **关系方式**：不直接夸唐胶或陆衡；允许别人碰她的工具就是信任。
- **句形**：短硬，可以打断，但不负责抛梗。
- **本章不可写成**：抽象安全原则或“只有我能叫停”的占有宣言。

### 豪司 / 荒川豪司

- **当章欲望**：想回驾驶舱、想让全城喊出社勇王，也真心不愿同事和市民替口号受伤。
- **压力反应**：情绪上来会抢话、说长；真正承担时反而直接。没有席位也会先搬梁、清场、帮工。
- **关系方式**：和社勇王不是一唱一和的吐槽组合；他会误解拒绝为“不信任”，之后才明白机体替他看见了自己没看见的人。
- **句形**：外放、带职业直播和超级系口吻；允许自恋、丢脸和改口。
- **本章不可写成**：只有口号的热血笨蛋，或句句完成漂亮成长的成熟英雄。

### 社勇王主体AI

- **当章欲望**：完成公共救援，并选择一个会继续听它说“不”的驾驶员。
- **声线**：字面、任务导向、偶尔给数字；不开哲学研讨会，也不连续抖机灵。
- **关系推进**：用开舱、拒绝第二锤、继续提供防壁和工程模式表达选择。

### 火种货柜领袖

- **当章欲望**：完成地面引路和后续转递，不自动成为万机馆随舰成员。
- **声线**：沉稳、路上经验多，完整句不多；不要写成神谕式领袖。

### 衡令

- **当章欲望**：让城市永远不停摆，即使必须把机器和万机馆固定成部件。
- **声线**：旧灾时调度逻辑，先报结论和行动；可以冷酷，但动机必须落在医院、列车和供水等具体对象上。

## 四、主笔自检

每改完一个场面，遮住名字检查：

1. 纪存、七海、白鸢是否仍能互换台词？若能，重写。
2. 连续三句是否都是短、准、带反转的回嘴？若是，至少让一人停下、改口、做事或说长。
3. 这句话是否只有作者知道为什么重要？若是，把动机变成现场动作或删掉。
4. 人物是否在回应刚才那句话，而不是借题发表自己的主题？
5. 朗读时是否像演员真的能说出口，而不是字幕卡上的文案？
