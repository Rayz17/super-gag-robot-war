# C02E04海上移动决赛因果骨架

## 白话发动机

一座两百多米的圆形擂台载着两台巨机驶向大海。冠军战的最后一关要求无牌一号回到旧故事的牺牲位；它站进去，却在最后一刻转身走出。完全版王者以为唯一知道自己过去的同伴又要让故事停下，主动追过去想把最终回完成。它连同全套装备和舞台炮架压到擂台的同一侧，裁判叫停、场地断电，却无法让已经偏过去的重量消失。货运环一边下沉，冠军被卡住，无牌一号明明有路退场，却回头去救它。

## 五段场面链

### 1. 一场配得上冠军的决赛

- 货运环低速驶入海上段，观众从固定观景厅和公共直播观看。
- 赛前画面只交代三条大规则：两台机分站擂台两侧；不能越过醒目的负载线；终幕舞台炮只装烟光弹、始终朝海。不念工程说明。
- 无牌一号的牵引带检查后重装。玩家使用它在一次大动作中借冲力绕开盾组，不再表演一串微操。
- 完全版王者的四套装备各在一个清楚的大场面中发挥作用：外翼越过断层，盾组逼窄路线，钻进组件打穿障碍，重炮封住远区。不要为每次换装发明新名词。
- 前半段必须有真正的进攻、追逐、反击和近身对拼，让玩家相信完全版王者配得上“王者”的名字。

### 2. 无牌一号离开旧站位

- 终幕舞台炮在擂台中央升起。直播只将一幅旧分镜轮廓和今日机位并置，不长篇回放E03调查。
- 无牌一号的身体凭排练惯性先站进旧牺牲位。完全版王者向它伸出手，等它交出护甲。
- 无牌一号不做演讲。它看见场边的退出线，停顿，用E02-E03学会的旋身从炮线里走出来。
- 这不是它拒绝保护人；是它第一次拒绝把自己消失当作保护的必要条件。

### 3. 完全版王者把“又要停下”当成眼前的背叛

- 完全版王者的反应先是困惑，再是恐惧，最后才是追击。它不是突然变坏。
- 它不向胶价王等待指令，只问无牌一号：“又要停在这里吗？”
- 它带着全装越过负载线，抓住舞台炮的演员用操作柄，要把炮位转向已经离开的无牌一号，继续完成那一幕。
- 裁判当即叫停、冻结比分；本地安全组随即切断舞台炮与货运环动力。从此刻起不再是比赛，也没有烟光弹发射。

### 4. 断电停下机器，却停不下已经倾过去的擂台

- 完全版王者的二十米身体、全套外装和被它拉偏的炮架同时压向外侧。玩家只需看懂一件事：原本分开在两边的大重量，现在全挤在一边。
- 电子限位阻止炮继续转动，但操作柄和外轨不是用来承受一台全装巨机的。外侧支承弯折，擂台倾斜。
- 画面证据是海平线在观景窗里明显抬高、场上松脱物品一起滑向外侧，不是人物朗读“负载超标”。
- 完全版王者的一条腿和外翼被弯折的外轨压住，无法直接跳离。断电后的重炮不能开火，但炮身沿斜面向它滑去。
- 无牌一号所在的内侧尚有离场路线。它没有被迫重演牺牲，而是在可以走时转身回去，站到滑落炮身与被卡冠军之间。

### 5. 三个人分别保住三件事

- 白鸢在决赛前只根据已知位置画过一张简单撤离草图。完全版王者自主越线后，她立即承认这张图已经不能用，要求停止旧分镜并撤人。她不画出物理出口。
- 七海把“停赛”拆成可执行的事：让本地裁判冻结比分，让本地安全组断场地动力，让赵梅与固定观景厅操作员保存事故画面。她只提出方法并用自己的调查身份署名，现场人员实际执行。
- 纪存不用“让它们选”作为万能答案。他先确认人员退路，再调动飞行队标出下沉范围，让火种货柜领袖与地面车队沿有支撑的平行作业道拖近万机馆。他为机体的选择创造不伤及人类的现实条件。
- 擂台倾斜时，安全控制室的设备箱滑向白鸢，纪存把她拉回固定座；纪存随即想解开安全带去拉卡住的门，白鸢反手按住他，逼他等工房人员从外面开门。两人互相保护，但她仍会直接责备他又想把自己丢进危险里。

## 为什么不能更简单

- **关直播。** 本地确实停止直播并断电；但两台自主机体的分歧已发生，重量也已移到外侧。
- **让无牌一号直接走。** 它本来就有路离开，这正是回头救人为什么是主动选择。
- **让纪存或胶价王遥控停机。** 两台机的机魂各自控制身体；本地安全组只能断场地和舞台设备。维护组的紧急停机也需要接近各机本体，不能把已经倾斜的环体变回去。
- **让万机馆飞过来。** 它的外泊修正器还在无牌一号背后，当前只能由火种货柜领袖与地面车队拖着船台托架沿支撑路面靠近。
- **让白鸢重画安全路线。** 她手里只有已知动作的短时预演；一台自主机体刚做出的新选择已经让旧图失效。

## 话末精确状态

- 比赛已停止、比分冻结，货运环和舞台炮均已断电。
- 货运环外侧支承弯折，一侧下沉；它并非整体悬空或已经掉进海里。
- 完全版王者的一条腿和一片外翼被弯折外轨卡住；它仍保持全装。
- 断电后的舞台炮沿斜面滑向完全版王者，不能发射。
- 无牌一号站在炮身和被卡冠军之间，尚未把它救出。
- 万机馆被火种货柜领袖和地面车队拖到平行作业道，只来得及接住下沉一侧，不能整体托起货运环。
- 纪存、白鸢已由外部工房人员打开安全室撤离门，不留在下沉一侧。
- 赵梅和固定观景厅已执行七海提出的事故画面保存；七海因公开署名要承担后续调查风险。
