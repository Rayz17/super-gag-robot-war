## 逐项裁决

### 1. 机器人而非资料是主语：通过

前半话资料量大，但资料只回答「旧故事想让谁消失」「眼前是哪两副身体」「身体后来由谁怎样续上」，没有替机体作出选择。

- 无牌一号自己同意开护板查工号，完全版王者自行收起装备、打开护板要求同查（E03:103-112）。
- 资料准备好后，两台机体分别选择「完整地看」和「播到没播出的地方」（E03:283-293）；看完后无牌一号不站回护甲交接位，而是要求先打当下的半决赛（E03:295-335）。
- 资料没有解锁胜法：无牌一号明说动作样机「没有教我怎么赢」（E03:209-213）；真正的越界胜利来自它对脱开柄、前臂、腰髋和第二步的现场使用（E03:433-489）。

因此，资料是身份与物质史的证人，机体才是知情、拒绝、参战和赢下当下的行动主体。

### 2. 模型、动作样机、CAD、全尺寸工程、实机机魂边界：通过

- E01 已建立「缩尺只传递外形/动作意图，全尺寸结构重做」的街区尺度基线（E01:193-205, 449-463）。
- E02 把当代链条做到可验证：缩尺选动作，陆衡按承力与避让重画，本地工房用全尺寸坯件制造，兜灯把断电脱开与实体停机做成安全边界，无牌一号本人同意试装（E02:17-103, 105-161）。
- E03 对历史链做了同样分层：儿子的动作样机只表达回转意图，CAD 把承载处留给全尺寸工房重算；之后的换算、制造、安装、试验、当前复检均有独立人员与实物结果（E03:169-207）。
- 工号、旧牌孔和连续维修位只证明实机身体连续性（E03:103-139）；为何认同旧角色关系、机魂如何产生被明示留为未解（E03:559-561）。

这条链没有「塑料放大」「CAD 自动造真机」「样机保存机魂」或「文档唤醒胜法」的越界。

### 3. 两场半决赛的远景、玩法、胜负与机体魅力：通过

**完全版王者 VS 坞工杰克**

- 同一界外擂台、同一边界目标、一次举升优势与一次越顶反转，远景上可直接画成短动画或事件战（E03:351-381）。
- 坞工杰克的低重心、双举升臂和承重轮先完整成立，并不是为冠军送分；完全版王者也不靠旁白声称「全装很强」，而是用重炮收线、翼面跃升、盾组借点和反推完成胜法。
- 最后一只轮子越线，胜负无歧义；王者给杰克留回场位、杰克鸣笛、王者敲盾回礼，败者的职业尊严也保住了（E03:379-389）。
- 本场是玩家可见的 NPC 事件战，不是直接操控战。它的地图、界外目标、位置状态和反转节点均可制作；整话的显式操作归属第二场。

**无牌一号 VS 旧拳王**

- 旧拳王不是拳套道具，而是会读牵引带、用断续压迫破坏借力条件、最后用整副身体推压的十七米完整机体（E03:397-427）。
- 玩家明确操作无牌一号「主动脱开牵引带」和「接臂，主动转身」（E03:433-455）。新模块完好却主动退出胜负，无牌一号再用自己的身体走完第二步，回收了 E02 的「半步」而不是重播旋身特效。
- 旧拳王双脚落场外但不倒，界外判定全亮（E03:469-477）；胜负清楚，老拳王的教练魅力和无牌一号的自主成长同时成立。

### 4. IP 精神辨识：通过

- **Build 系**：「我的构筑改变实机怎样战斗」通过动作意图、全尺寸重做、机体同意和主动停用同时成立。构筑不是装备堆叠，也不是塑料魔法。
- **G 高达/《铁甲钢拳》精神**：非致命拳台、老王者用真拳教第二步、可以命中却能停拳、输了仍站着约继续训练，让机动武斗和机器人拳击的情感都能被辨认。
- **腰斩超级机器人最终话**：没播出的牺牲结局、援护机交甲退场、主角机最终形态、宣传实机在企划死后继续活着，精神谱系鲜明；正文没有点出任何现实作品或把原作招式照搬进来。

三类投射最后都落在「机体怎么动」，而非角色互相报片名。

### 5. 生命周期、转子、货运环与 E04 出口：通过

- **无牌一号**：仍是合作社托管的全尺寸自主实机，只进入决赛，没有默认归万机馆或入舰。
- **旧拳王**：完成 `entities.tsv` 指定的 E03 正式半决赛；结尾只约定赛后继续训练，并明说维护与去向未交接（E03:479-489, 513），不提前代行 E05 随舰手续。
- **完全版王者**：自愿全装出战、靠实际装备价值赢得半决赛，但还没有进入「自主卸装后重新决胜」的终局状态。
- **白鸢**：E01 只有作品痕迹，E02 本人到达，E03 仍留在工房安全侧且「没有跟着任何人登舰」（E03:519），符合 `entities.tsv` 的 E05 才可首次登舰。
- **赵梅**：持续是组织知道「谁会什么」的人，不是模型大师或巨机工程师；儿子的材料也没有替机魂、物主或工房作决定。
- **冠军转子**：E01 确立其仍在货运环中央运输架，E02 明说未拆卸、交付或安装（E02:481-483），E03 仍封存于中央并随整环低速转场（E03:521-527）。
- **货运环/E04 入口**：普通观众先撤入固定观景区，支撑逐一释放，货运环连同转子和发射架沿预定轨道转向海面，两台决赛机只走到等待位（E03:517-527）。这是可直接接 E04 移动决赛的单一物理出口。

### 6. E04-E05 高光预支：未发生

- E03 只完成「看见旧结局后仍选择打今天的半决赛」，无牌一号和完全版王者对旧牺牲结局的最终处理明示尚未发生（E03:559-561）。
- 决赛未开，完全版王者的自主卸装/重新决胜未用，无牌一号的牵引带赛前去留也特意未宣布（E03:503-515）。
- 移动货运环决赛、转接桥事故、冠军转子交付与登舰均被明示留待后续（E03:7）。
- 旧拳王交接、无牌一号正式随舰、白鸢首次登舰均未被提前完成。

E03 用掉的是它自己应有的「身份真相 + 两场半决赛」；E04 的移动决赛与牺牲命题行动答案、E05 的交接和加入仍有独立高光空间。
