# C02E02开场熔断短样

次日上午，木桶街工房的卷门刚升过人高，海风就钻了进来。墙上的吊带轻轻碰响，门外，万机馆被防风缆索牢牢牵在泊位上。无牌一号站在舰体和工房之间，背后还装着借来的舰外停泊修正器。十六米高的影子从门口压进来，正好停在唐胶的工作台边。

墙上的资格赛录像已经重放了三遍。

无牌一号抢进失控的对手和护栏之间，抬臂、屈膝，用整个身体把对方护住。对手被接走，跑道已经空出来，它却仍留在原地。镜头继续向前，它的动作却像提前播完了。

唐胶按下暂停，把一具未上色的缩尺素体摆成同样的姿势。

“别看脸，看脚。”

纪存俯下身。模型的双脚一前一后，脚尖都向着被它护住的人；身后的跑道明明空着，髋部却没有回转的余地。

“它挺会护人。”纪存说。

“所以才麻烦。”唐胶用镊子尖点了点那只后脚，“它把别人送回去，自己就打算站这儿吃灰。加件漂亮东西当然容易，我这儿满柜子都是。先告诉我，它挡完以后要干什么。”

他把三件临时做的小东西排在素体前：一对加宽的肩壳，两片剪成翼面的薄板，还有一条红色织带。

肩壳扣上去。唐胶的推杆压上斜肩，来力沿着外撇的壳面滑向侧后；素体让开冲撞线，前脚顺势踏过原来的停位。

翼面展开。素体横向滑过底座时，一侧翼面翻下擦住边缘；它一面减速，一面绕出半弧，从跑道外侧切了回来。

最后，纪存把红带从抬起的护位臂牵到对侧腰部。唐胶从正面推了素体一下。织带猛地绷紧，磁性底座上的小小身体顺着这股力旋过半身，原来压在后面的那只脚，啪地落到了前方。

唐胶的手还扶在模型腰上，却看向门外的无牌一号。

“塑料只负责把意思说清楚。谁敢照它的材料和骨架去造十六米的，我先把他的剪钳没收了。”

门外传来无牌一号的声音，比吊带相碰的声音更低。

“我已经会停。”

它的头部略微偏转，看着那具只有手掌高的素体。

“我想转回来。”

纪存把肩壳和翼面放回桌面，手指按住了那条红带。

**【玩家选择：牵引带｜把护位承受的冲力变成旋身回位】**

赵梅这才把铅笔落到分派纸上。她划去肩板厂和翼面修配铺的本轮派单，却没有丢掉那两件试作，而是分别装进透明袋，在外面写下“卸力偏转，继续前进”和“侧向制动，绕回内线”。

“这个转身我不会算。”她说得很自然，一边说，一边已经拨通了远程电话，“这里有做过赛事牵引件的坯件，有能吊全尺寸机体的工位。唐胶拍动作，兜灯给实机数据。能不能做，让会的人说。”

工房里的行车很快响了起来。一只带着旧赛事涂装的巨型卷收坯件被从隔壁架位吊出，阴影一寸寸盖过工作台。红织带在它下面小得像一根线头。

移动屏上，陆衡的画面接通了。他还在工务城，人没有离开远处的检修台。赵梅把镜头转向模型，他却先抬手。

“先给我看昨晚停住的那三次。成功的那段等会儿再看。”

三次失败动作被叠在一起。陆衡扶了一下眼镜，又让兜灯把镜头对准无牌一号的肩、腰，以及背后那台借来的停泊修正器。

唐胶已经给模型上的卷收盒补了一道沿肩背抬起的弧壳。陆衡看了一眼。

“那道弧壳删掉。”

“早安也按吨收费？”唐胶问。

“早。删掉。”陆衡把三次停步的画面定在无牌一号向前跪住的那一刻，“模型抬手，壳跟着抬。全尺寸一抬手，它先撞肩，再把重心往上抬。这台机昨晚已经往前跪过，别把同一个失败做得更漂亮。”

唐胶“咔”地剪断了自己刚粘好的弧壳。

“行。弧线留在纸上，机器别背。”

陆衡在坯件图上把卷收位置压低，又画出一条从护位臂绕向对侧髋部的简单力线。

“力往下走，让身体转；肩背留空，不碰停泊修正器。护板做成能擦地的短壳，难看也先记着为什么难看。”

“还少一样。”兜灯打断他。

她已经绕到巨型坯件旁，手上沾了旧润滑脂。她先关掉试验电源，再把一支外置长柄插进机械脱开位。她全身压下去，坯件里的棘爪“哐”地松开，沉重的卷筒在无电状态下转过一段，把原本锁死的张力放掉。

兜灯把长柄拔出来，用油手套在低处的护板上留了一个黑印。

“停机柄朝外，我在断电时也要够得着。它要是说停，这个东西就得真能松开。做不到，我不装。”

陆衡在屏幕里点头。“保留。我这条线只传图，不接它的开关。”

无牌一号低头看着兜灯留下的黑色手印。

“脱开柄留下。”它说，“我愿意试。”

赵梅把陆衡修过的力线、唐胶拍下的动作，还有兜灯那个油手印一起转给了本地工房。她没问“尽量行不行”，只把分派纸压在工位台上。

“今天能不能造？”

一直在坯件旁核对工位的老师傅用粉笔画下新外壳的轮廓，又抬头看了看行车和无牌一号腰间的高度。

“坯件是赛事验过的，卷收芯能用。我们重做外壳和接位，停机柄按这个手印留。”

他在粉笔线末端重重点了一下。

“能造。”
