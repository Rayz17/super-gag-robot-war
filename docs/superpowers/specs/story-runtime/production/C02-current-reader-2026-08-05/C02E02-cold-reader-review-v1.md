## 最终结论

`REWRITE_ONCE`

这话的发动机成立，不需要推倒重想：无牌一号明确想解决“护住别人以后，自己还能继续走”的问题；牵引带把这个欲望变成了看得见的身体动作；积分预赛有一次真正成立的选择和回报；旧分镜与机体动作同时断在空白处，也留下了有效悬念。

但当前稿还不宜直接交用户首读。主要问题不是看不懂故事，而是同一个核心问题被解释、解决、再重新判成未解决，导致高潮归属摇摆；白鸢进入行动核心的速度快过了人物关系；该删的保证性说明很多，该在比赛现场说清的规则反而留到了文末情报。

## E02 实际发生了什么

第二天上午，唐胶反复看无牌一号的资格赛录像，发现它不是不会保护别人，而是每次保护完成后，身体仍朝着被保护者，自己没有“转回来继续比赛”的下一步。唐胶用缩尺素体试了肩壳、翼面和牵引带三种办法，纪存与玩家选择了牵引带。无牌一号也明确说，它已经会停，现在想学会转回来。

赵梅负责找人、分派和确认赛事条件；陆衡远程根据失败动作修正受力路线；兜灯坚持断电时也必须能人工脱开；本地工房用既有的赛事卷收坯件制造出全尺寸装置。第一次实机测试转过头，第二次才把后脚落到正确位置，无牌一号因此获准上场。

下午，白鸢赶到木桶街，先要求撤掉赛事未经授权使用的旧分镜广告。胶价王确认文件来源后撤图，但版权责任留待赛后追查。白鸢到工房追问无牌一号与旧分镜的关系，在遵守现场安全要求后见到纪存。无牌一号同意她查看当天试装和赛事数据，但拒绝开放旧记录。

白鸢根据现有资料，给三台同骨架飞行机画了三条相同的预判路线。比赛开始后，三台机却表现出不同选择：红机抢线，蓝机折返救援，黄机留在外圈远射。她先后三次划掉自己的预判。

积分预赛里，坞工杰克先拿到一个公开四强席。争夺另一个席位时，无牌一号本来可以直接穿过去，却又选择替蓝机和一台地方机挡下黄机的标记弹。它这次没有停在被保护者面前，而是让牵引带吃住冲力，旋身让开后续攻击，再冲过计分门，拿到最后一个四强席。完全版王者对它说：“这次，你回来了。”

签表随后确定：无牌一号对旧拳王，完全版王者对坞工杰克。正式半决赛前，旧拳王临时提出一场不计分的指导战。第一轮，它用假动作骗开无牌一号的防守，本可命中的拳却由玩家主动停住，等无牌一号恢复回应后才重开。第二轮它真正压上重量，无牌一号只转完半圈便再次停慢，被推到红环边跪下。旧拳王把剩下的半招留给正式比赛。

傍晚，白鸢把无牌一号三次护位动作与二十多年前的旧分镜逐格对照，确认两者都在“护住以后”停止，后面确实没有被藏起来的动作。无牌一号说自己原本就没有下一步，白鸢也承认自己的旧故事没有下一步。赵梅拿出合作社旧柜的钥匙，决定先找齐与资料有关的人再开柜；白鸢没有答应加入任何队伍，但明确要参加开柜。

## 主要人物为什么行动

| 人物 | 本文给出的行动原因 |
|---|---|
| 无牌一号 | 它不满足于只会替别人挡住危险，想在护位后转回自己的路线，打完自己的比赛。它同意试装、主动参赛、再次挡弹，也同意白鸢查看当天数据。 |
| 纪存与玩家 | 现实目标仍是帮助无牌一号赢得冠军转子，让万机馆能继续航行；当场做法则是把选择和数据权限还给无牌一号，并在比赛中帮助它完成已经选过的动作。 |
| 唐胶 | 他认为改装必须回答“挡完以后干什么”，而不是单纯加漂亮配件，所以用模型寻找动作，再把动作要求交给全尺寸制造。 |
| 赵梅 | 她不假装自己会算一切，而是负责找对的人、取得共同维护人的意见、协调工位和赛事条件。结尾她知道旧柜里还有多人共有的资料，因此不愿独自开柜。 |
| 兜灯 | 她只接受能实体检修、断电脱开、由机体本人叫停的装置；她的行动始终是确保试装和比赛不会越过现实安全边界。 |
| 陆衡 | 他要避免全尺寸结构重演无牌一号前跪的失败，并坚持保留失败数据。他只给工程判断，不替机体完成动作。 |
| 白鸢 / Evelyn | 她最初为未经授权使用作品而来；广告撤下后，旧分镜与现实机体的对应使她继续调查。她尝试用分镜预演赛道，也在判断错误时立刻划掉，不强迫现实服从画稿。结尾她留下，是为了知道旧故事和无牌一号为什么停在同一处。 |
| 完全版王者 | 它显然认得无牌一号的某种旧姿态，并持续观察它能否从那个姿态里回来；本文没有进一步证明它知道多少。 |
| 旧拳王 | 它不满足于看一次借助装置完成的过门，想在真实拳压下确认无牌一号是否醒着、能否把旋身走完，因此先停下必中的一拳，再用第二轮真打揭出“只完成半招”。 |
| 胶价王 | 他首先维护赛事收益和节目效果；证据明确后撤下侵权图，但仍让比赛继续，并借旧拳王登场制造现场看点。 |

## 结尾留下的问题

1. 白鸢二十多年前没有画出的“下一步”，为什么会与无牌一号现在的身体停点完全一致？这是制作、记忆、模仿还是别的关系，本文没有答案。
2. 完全版王者为何认得“援护机 A-7”的姿态，它与无牌一号过去究竟发生过什么？
3. 合作社旧柜里有什么资料，赵梅要找齐哪些人，他们各自掌握或拥有哪一部分？
4. 无牌一号在正式对阵旧拳王时，能否在真正持续受压的情况下走完剩下的半圈，而不是只靠一次冲力越门？
5. 无牌一号能否继续赢到冠军转子；完全版王者与坞工杰克的另一场半决赛会怎样；白鸢开柜后会留下、离开还是改变立场？
6. 谁把白鸢未授权的源文件放进赛事供应包，赛后责任如何处理？

## 绝对评价

### 一遍是否看懂

主线一遍能懂：找出无牌一号的停点，选择牵引带，完成制造和测试，在预赛中用它过门，再由旧拳王证明问题还没有完全解决。人物当场在做什么、装置大致怎样帮助旋身、白鸢为何来到木桶街，也都清楚。

比赛资格边界却没有完全靠场面讲清。正文只说今天点亮两个公开席，却让三台飞行机与无牌一号同时进入第二席的赛道对抗；直到文末“公开情报”才说明三台飞行机不占四强签位。冷读时会产生直接疑问：它们是在争席位，还是只负责阻止别人？如果不争，第二席究竟还有哪些竞争者？这会削弱“拿到最后一席”的胜负感。

### 是否有趣

有趣的部分是具体的。模型上的红带变成十六米机体的全尺寸牵引带；第一次转过头差点撞工作台；三台同骨架机用行为显出三种脾气；无牌一号在黄色色雾里旋身过门；旧拳王让玩家亲手停下一记已经能命中的拳。这些都不是靠旁白宣布“很燃”。

但本话有两个抢主位的高潮：预赛已经完整回答“它能不能护完以后转回来”，紧接着指导战又把答案改成“只能转半招”。后者本身也好看，连在同一话尾部却让前一个胜利像刚结算就被撤回一半，读者不容易判断本话真正完成了什么。

### 场面是否连续

时间和空间很清楚：上午工房试装，下午白鸢到站和预赛，签表后红环指导战，傍晚回工房对照旧分镜。制造、试验、上场的物理连接也扎实。

戏剧连接有两处跳步。第一处是白鸢刚以版权追责者身份进入工房，很快就获得数据、画赛道方案，并直接对纪存提出行动建议；“允许她看”成立，“团队为什么马上把她当临场方案提供者”还没有演出来。第二处是四强席刚决出，旧拳王便立刻进行一场可能磨损正式参赛者的非计分指导战；文本反复确认它不改签表，却没有给出“为什么非得现在打”的同等强理由。

### 对白是否像人

大部分对白有清楚的人声区别。唐胶会拿技术问题开玩笑，赵梅坦然说不会并立刻找会的人，兜灯只谈能不能安全停机，陆衡盯失败数据，无牌一号和旧拳王都说得短而硬。“回过头了”“再往里转，它得向我报名了”、“吊钩不管版权”、“醒着再挨”都像人物在具体处境里说出来的话。

少数台词太整齐地承担主题总结。“这一格它自己画得比我大”、“这次，你回来了”、“两台完整实机，都已经回到自己的拳里”连续落在高潮附近，每句单看都成立，挤在一起则能感觉到作者轮流给人物发收束句。纪存替白鸢系安全带后的交锋有火花，但“白鸢是图上的署名，Evelyn是现在被系在这里的人”精巧得明显，人物关系若没有更扎实的前后反应，容易像提前写好的暧昧台词。

### 关系是否有火花

最强的是机器人之间。完全版王者从嫌弃“装得太少”到承认“装得刚好”，再到不叫旧编号而说“这次，你回来了”；旧拳王先确认无牌一号醒着，再真打出它只会半招，这两组关系都通过动作改变了判断。

纪存与白鸢也有火花：追责、现场安全、替她理安全带、向无牌一号询问数据许可，形成了锋利又克制的初次交锋。问题不在没有火花，而在火花出现得比信任依据快。白鸢对纪存的态度从质疑到“怒气还在，眼神却已经变了”，中间主要依靠一次系带和一次尊重授权，转折略省。

### 信息是否靠正文成立

牵引带不是把模型直接放大、装置能人工脱开、陆衡只远程给工程判断、无牌一号本人同意试装和数据开放，这些都已经通过行动成立，不需要文末再解释一遍。旧分镜与停步动作的对应也由白鸢逐格核对得出，悬念成立。

较弱的是赛事规则和指导战必要性。三台飞行机“不占四强签位”、指导战“不改变正式胜负”等信息，要么只在文末补充，要么在报幕、赵梅复述、赛后播报和情报栏中反复保证。前者来得太晚，后者说得太多，却仍没有回答为什么此刻值得冒正式赛前受损的风险。

### 哪里重复、拖沓、突兀

- 重复：资格赛录像、模型旋身、两次摆锤试验、积分预赛旋身、指导战半次旋身，都围绕同一个“护住后停住”动作。层级虽有升级，但次数过密。
- 重复：模型只表达意图、全尺寸件另行制造这一点，唐胶先说，制造段再展示，文末情报又总结；读者在第二次已经明白。
- 重复：“指导战不计分、不改签表”被报幕、赵梅、胶价王和文末情报多次确认，像在防误读，而不是推动场面。
- 拖沓：上午从三件模型方案、远程改图、停机柄、工房制造到两轮摆锤测试，几乎每个岗位都完成了一次职责展示。信息可靠，但新冲突增长得慢，压低了白鸢到场和正式比赛的篇幅重心。
- 突兀：白鸢从版权追责进入战术讨论；纪存与她几乎立刻出现带姓名切换的暧昧；四强签表刚亮，旧拳王的额外指导战马上开打。这三处不是不能发生，而是当前正文给的过桥短于事件的重要性。

## 最多三个根因

### 根因一：同一核心问题在一话内完成结案，又被同一种测试重新打开

具体场面：上午无牌一号说“我想转回来”；摆锤第二试成功；积分预赛在真实干扰下护人、旋身、过门并赢得席位；完全版王者确认“这次，你回来了”。到这里已经形成完整高潮。紧接着旧拳王仍以“把停住的那里给我看”为题再测一次，结论变为只走了半招。

这不是单纯多打一场，而是两个场面争夺同一个问题的最终解释。重写时应明确本话到底完成哪一级：若预赛完成的是“借冲力转回赛道”，指导战就必须揭出一个清楚不同的新问题；若真正问题仍是“持续受压时会停”，前面的成功不能被写成已经整体归来。旧拳王可以保留，但不能像对同一道题重新判卷。

### 根因二：白鸢的身份、情绪和团队功能连续跨了三步，中间只有程序许可，没有人物过桥

具体场面：她在播控棚追究侵权；到工房与纪存发生安全带交锋；无牌一号允许她看当天数据；下一场她已经在廊桥画路线，并在比赛中直接叫纪存让无牌一号怎么走。

数据授权解决了“她能不能看”，没有解决“她为什么此刻愿意帮”“纪存为什么把她的判断纳入行动”“一次尊重许可为何足以改变她对人的判断”。她的预判随后全部失败，说明正文不想把她写成预知者，但这反而更需要一个人物层面的理由，让她的参与不是为了证明画稿可被现实推翻才被临时安放进队伍。

### 根因三：篇幅花在反复自证，真正影响胜负感的赛事规则却没有在场面中落地

具体场面：前半段多次证明缩尺模型不是实机材料、各岗位没有越权、装置可停机；后半段多次声明指导战不计分。与此同时，三台飞行机为何参与第二公开席的对抗却不占席、无牌一号究竟在和谁竞争最后一席、正式赛前为什么允许并值得打一场指导战，都没有得到同等直接的场内答案。

重写应削掉已经由动作证明过的保证性说明，把篇幅还给两件事：让预赛的竞争规则在开打前一遍说清；让旧拳王此刻开打拥有不可由正式半决赛替代的理由。这样既会更短，也会更可信。

## 裁决

`REWRITE_ONCE`
