# C02E05终局救援与冠军决胜因果骨架

> 本文不设玩家显示标题。显示标题必须等Reader完成后，从本话真正写出的画面中选择。

## 白话发动机

无牌一号回头救下曾经要求它消失的冠军。完全版王者必须亲手卸下全装，才有可能从倾斜擂台脱困；那些被卸下的装备又反过来成为救人的踏板、支撑和警报。危机解除后，两台机体都不肯让事故替自己决定胜负，于是在天亮前以基础身体重新打一场。无牌一号把过去只会用来替别人挡住危险的转身，第一次也用来保住自己，并堂堂正正赢下冠军。

## 七段场面链

### 1. 先让万机馆真正站进战场

- 三台飞行机依次完成三个大任务，不交叉表演细碎微操：红机用照明弹和低空航线标出尚能承力的区域；蓝机用宽翼护送最后的小型工程机撤过裂口；黄机从外圈打断两根仍拖着炮身撕裂环面的变形支架。
- 火种货柜领袖保持重型牵引态，把万机馆船台托架移到最佳位置。万机馆作为多格母舰支点承接下沉侧，不变形。
- 馆守Z在甲板上用现有黄色巡展臂固定一段断桥。旧拳王用红色擂台牵引带把一组松脱外装拖出工程员通道。
- 玩家先获得一次“全队同时有用”的大场面，再进入冠军卸装，不把救援写成十几个小开关。

### 2. 胶价王为了真实喜爱，第一次跟自己的生意翻脸

- 杂鱼港管理层要求先保完全版王者、冠军转子和稀有选装，准备把无牌一号重新剪成“牺牲成功”。
- 胶价王不是突然良心发现。他先想保节目，直到看见公司要用这场事故重复出售旧结局，才取消高价资产优先并开放装备解锁资料。
- 完全版王者旧承包商的当值维护员确认：事故自救可以拆离装备，事后仍归原持有人。胶价王由此损失保证金、库存和一部分复产预算。
- 他的选择只解决“能否安全拆装”，不替完全版王者决定卸装。

### 3. 冠军卸下全装，但没有否定全装

- 完全版王者自己决定先卸背负式重炮和被卡外翼，减轻向海一侧的重量，腾出双臂。
- 外翼展开后只形成供小型工程机通过裂口的宽踏板；双盾只支住一小段正在下沉的环面；头冠通讯器改作全场警报。每件装备只有一个清楚用途。
- 兜灯和本地工程员只确认安全用法；唐胶不靠模型知识直接指挥巨构。
- 装备依然强、依然漂亮，也依然属于冠军。它卸下的是“必须把所有好东西同时穿在身上，才能成为主角”的执念。

### 4. 两台机体合力把断电炮身送回海边

- 完全版王者脱困以后，与无牌一号分别顶住固定舞台炮两侧，把它推回朝海的拆卸位。
- 旧拳王用红带固定回转底座；飞行队清开外侧；馆守Z稳住连接桥；万机馆承受一次可见侧向冲击。
- 舞台炮全程断电。两台机推到位后，由工程机夹住炮身、人员卸走烟光弹箱、港口吊机把炮身移出环面。
- 救援胜利来自角色此前的选择与已有工具，不靠新装置或重新点火制造奇观。

### 5. 事故不能代替决赛

- 裁判确认：越线使E04当场停止，事故回合没有胜者；完全版王者取消本场全装资格。救人既不换算成冠军，也不抹去违规。
- 货运环损坏封场。两台机和维护方明确要求打完，裁判才把零比零重赛移到E02已经出现过的室外全尺寸测试场。
- 数小时检查中，完全版王者处理被卡腿、无牌一号卸下临时模块，万机馆收回外泊修正器。新场地只允许低输出、无武器、以倒地和出界判定。
- 决胜要短、清楚、好看：完全版王者的速度和经验占优；无牌一号只回收玩家实际选过的一种训练结果。它借冠军正面冲力转到侧面，重新站稳并形成明确倒地/出界判定。
- 无牌一号获胜。完全版王者自己摘下冠军标记，但保留名字和下次按冠军规格登场的要求。

### 6. 赵梅没有继承天才，只把工作继续做了下去

- 木桶街得到搬迁款与新址设备，原因是基础赛事和追加演出合同均已兑现；胶价王仍会围绕新冠军、基础素体与训练录像赚钱。
- 赵梅继续处理寄件。她使用儿子生前的工作账号，把自己的当前联系电话补在后面。此前的错单、退件、请教和合作社已经让玩家知道，她的能力是一点点学来的。
- 不再用演说解释母爱或传承。一张仍能让别人找到维修人的订单，完成这条情绪回收。
- 唐胶把无牌一号余下修法交给合作社工房员复做；兜灯检查别人能否独立完成。他们的靠近来自一起把事情交出去。

### 7. 把获得物一件件送上下一段旅程

- 无牌一号由历代共同维护人交接维修册、备件和一枚泊位钥匙，本人确认随舰；身体所有权不转给万机馆。
- 旧武斗馆移交训练记录和临时维护责任，旧拳王本人确认随行。两台机现有保险只延伸至工务城，正式运营与长期保险留给C03。
- 无牌一号依据赛前约定，把冠军转子交给赵梅合作社受限代管并用于万机馆必要维修。
- 自动港先稳定货运环。万机馆旧热损转子由B1维修轨整件移到旁侧锁架；九米新转子由港口龙门吊、原运输架、货柜领袖和泊位吊机连续送入B1。只用一段有尺度的运输蒙太奇，不钻入内部讲零件。
- 陆衡远程复核后只批准一次升到航行功率便不能中途停机的航程；工务城因此成为必去下一站。
- 三台飞行机留在木桶街成为地方回援队。完全版王者留下，保留宿敌和再战。火种货柜领袖护送至港区/陆路出口。
- 白鸢在所有救援和交接完成后登舰。她不是被纪存一句话说服，而是要亲眼看万机馆以后如何对待从作品里活出来的机体。七海远程确认她的登舰，三人关系以兴趣、警惕和未解决分歧进入C03。

## 为什么不能更简单

- **直接让万机馆托起整环。** 万机馆只在有地面支撑的平行作业道上承接一侧；另一侧仍靠货运环自身轨道和支撑。
- **让完全版王者跳出来。** 一条腿和外翼被外轨压住，全装又是最大偏载；先卸装才能降低重量并腾出双臂。
- **把装备都扔掉。** 装备有所有权和真实价值，且可在有限边界内救场；开放的是事故解锁和结构资料，不是无主化。
- **救完直接判无牌一号冠军。** E04赛事已停止，救援不是计分动作；重赛在检查后的既有安全场地进行。
- **把九米转子直接抱上舰。** 它有原运输架、港口龙门吊、重载通道和B1货运升降台；连续运输必须可见。
- **让赵梅把机体赠给纪存。** 她不是唯一所有者；共同维护人、旧武斗馆和机体本人分别完成交接，所有权不转移。
- **让万机馆修好后自由旅行。** 新转子与旧系统不完全匹配，只获得一次连续航行窗口，必须去工务城校正。

## 话末精确状态

- 无牌一号赢得木桶杯冠军，成为玩家首台可长期自由构筑主力；身体仍由原共同维护关系持有。
- 旧拳王以训练与临时维护交接方式随舰，旧武斗馆仍是原持有人。
- 完全版王者留在木桶街/杂鱼港竞赛线，保留全装、名字、宿敌资格与未来回归。
- 三台飞行机留守木桶街，形成地方回援队。
- 火种货柜领袖只承担木桶街至港区/陆路出口的阶段护送，不被静默收入万机馆永久编队。
- 九米冠军转子安装到万机馆；原热损旧转子锁在B1旁侧等待工务城修复。
- 万机馆只获得一次不停机抵达工务城的航行窗口，未获得正式运营身份或长期保险。
- 白鸢正式登舰；七海仍在原城远程，尚未上舰。
- 木桶街合作社、杂鱼港发行关系和地方机体支援继续存在，不随主角离开而消失。
