# C02E04前话交接

## 时间与地点

- C02E03结束于第三日下午，本话紧接着开始，不跳天。
- 货运环已离开静态泊位，沿港区早已清空的重载轨道低速驶向自动港。决赛与九米冠军转子的最后运输验证在同一趟行程中进行。
- 普通观众已转入不随擂台移动的固定观景厅。环上只留两台决赛机、裁判、安全组和少量工房人员。
- 纪存与白鸢在环体内侧一间既有的封闭安全控制室里，有固定座位和可由外部工作人员开启的撤离门。不新造观景台、升降舱或中继舱。
- 七海仍在原城调查等候区远程连线，不能控制木桶街的场地、擂台或转播系统。
- 万机馆停在与港轨平行的作业道泊位。外泊修正器仍装在无牌一号背后，万机馆不能自行横移追上货运环。

## 已发生事实

- 完全版王者击败坞工杰克，无牌一号在牵引带被旧拳王制住后主动脱开模块，凭当前身体和已学动作打进决赛。
- 两台机体已看完二十多年前的旧最终回：援护机A-7原定替王者挡下最后攻击、交出护甲并退场。原作在播出前取消。
- 无牌一号与完全版王者都是当年的自主全尺寸宣传实机，不是模型或分镜放大后生成的机体。
- 白鸢不是旧作原作者。她数年前受复播企划委托补过缺页，删掉明确死亡，却仍把A-7留在护位后的空白处。
- 两台机体在知情后都主动选择继续决赛，但它们怎样理解旧结局尚未发生。
- 无牌一号的牵引带已进入赛前检查。本话可在检查后重装，让玩家于冠军战前半继续使用；它只能提供牵引和旋身助力，不会自动出招。
- 完全版王者的外翼、盾组、钻进组件和背负式重炮都有实战价值。它不是配件过多的笑话，也不受胶价王遥控。

## 本话必须回答

- 一台把“完成最终回”当成自己愿望的机体，在唯一懂它旧名字的同伴离开原站位时，会怎样反应？
- 无牌一号离开旧牺牲位，是不再保护别人，还是第一次不用消失来证明自己会保护？
- 纪存、七海、白鸢对“应不应继续”的不同判断，如何真正改变现场行动？
- 一场已经被裁判叫停、被安全组断电的决赛，为什么仍会变成巨型擂台倾覆危机？

## 不得提前回答

- 不解释机魂、G.A.G.、纪存感应或虚构角色惯性的根本机制。
- 不让白鸢获得未来视、战场指挥权或画稿改现实能力。她只能根据已知位置和动作做短时预演，新选择会使它失效。
- 不在本话完成万机馆救场、冠军卸装、基础体重赛、转子交付、无牌一号/旧拳王随舰或白鸢登舰。这些全部属于E05。
- 不把胶价王写成遥控机体的反派，也不把事故写成场地本来就会坍。
