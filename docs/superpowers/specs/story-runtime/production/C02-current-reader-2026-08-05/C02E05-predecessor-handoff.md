# C02E05前话交接

## 时间与地点

- 本话从C02E04最后一个画面直接开始，不跳时、不先回顾调查。
- 两百多米直径的货运环停在港外重载轨道上，一侧仍由地面轨道和支撑承载，向海一侧已经下沉并压在万机馆舰侧。
- 万机馆位于平行作业道的船台托架上。火种货柜领袖和地面车队已经把它拖到最近位置；舰体只接住货运环一边，不能整体托举圆环。
- 普通观众在固定观景厅，环上人员已撤至内侧。纪存与白鸢已离开倾斜的安全控制室，赵梅、唐胶、兜灯和本地工程员在安全区组织救援。
- 七海仍在原城远程连线，只能提出调查与保全建议，不能操作木桶街设备。

## 机体与设施状态

- 无牌一号站在断电舞台炮和完全版王者之间，仍能行动；它的外泊修正器和全尺寸临时模块尚在。
- 完全版王者一条腿和一片外翼被弯折外轨卡住，仍保持外翼、双盾、钻进组件、头冠通讯器和背负式重炮等全装。
- 舞台炮已经断电、不能发射，烟光弹仍在安全弹箱里；由于止挡损坏，沉重炮身仍沿斜面滑动。
- 比赛已由裁判停止，比分冻结。事故发生后的救援动作不计比赛分数。
- 三台自主飞行机已经进入空域：红色高速机负责标路，蓝色护航机负责护送，黄色远射机负责处理远端危险构件。
- 馆守Z在万机馆甲板待命，仍缺右前臂；它只能使用现有巡展臂和一条完好的战斗臂。
- 旧拳王仍在安全侧，红色擂台牵引带可用于固定或拖离松脱设备。
- 九米冠军转子仍固定在货运环中央检修区，尚未交割、拆出或安装。万机馆原有热损旧转子仍在B1主循环位置。

## 人物和关系出口

- 无牌一号已经两次转身：先走出旧牺牲位，再在仍有出口时回头救完全版王者。它尚未赢得冠军。
- 完全版王者因害怕最终回再次中断而自主越线；它不是被胶价王遥控，也尚未理解如何保留主角身份而不要求同伴消失。
- 纪存先撤人、再调动救援，已经证明他不只会说“让机体自己选”。
- 白鸢的短时预演因完全版王者的新选择失效。她公开承认图不能用了，也与纪存在倾斜控制室中互相救过一次；两人的分歧没有消失。
- 七海公开署名发起事故画面保全，本地人员实际执行。她会承担后续调查风险，但没有取得木桶街控制权。
- 胶价王已主动停播赛事画面并听从现场安全安排，但尚未在“保贵重资产”与“保全所有机体和完整事实”之间作出最终选择。

## 本话必须完成

- 用清楚的大动作解除倾覆危机，让多台机体和万机馆各完成一件尺度匹配的事。
- 让完全版王者本人决定卸装；装备不能被写成累赘笑话，而要在离开身体后继续救场。
- 让胶价王付出真实商业代价开放解锁和结构资料，但不把他洗成好人。
- 在事故现场完全停赛后，经过检查、仲裁与转场，于既有室外测试场完成一场低输出基础体决胜。
- 无牌一号以一路学会的转身赢下冠军；完全版王者保留名字、主角欲和未来再战资格。
- 兑现赵梅从儿子资料一点点学起来、把个人工作变成合作社的现实情感线。
- 完成无牌一号、旧拳王随舰交接，白鸢登舰，九米转子吊运安装，并自然发动C03工务城。
