# C02E05终局精简主笔Brief

> 只写C02最后一话Episode Reader。本文不提供正式标题；完稿后附三类标题候选，再选玩家显示标题。

## 一句话故事

无牌一号回头救下曾要求它消失的冠军；完全版王者亲手卸下全装，和它共同救住整座擂台，随后两台机在天亮前以基础身体重新决胜，无牌一号终于把保护别人的转身也用来保护自己，并带着冠军转子和旧拳王踏上万机馆。

## 本话真正要打中的三件事

1. **机器人大战的全员终局。** 万机馆第一次作为多格母舰支点入场；飞行队、货柜领袖、馆守Z、旧拳王、无牌一号与完全版王者各完成一件尺度匹配的大事。不要把它写成抢险操作手册。
2. **冠军不是被拆掉，而是自己重新定义“完全版”。** 全装每一件都强、都漂亮、都在救场中有用；完全版王者选择卸装，是因为它宁愿失去眼前优势，也不再让无牌一号替自己的结局消失。
3. **赵梅的情绪回收必须轻，却不能丢。** 玩家已经看过她从错单、退件、儿子的笔记和别人的帮助里一点点学会。此刻只需让她继续用那个工作账号，并补上自己现在的联系方式。读者应在她不解释时明白她做了什么。

## 玩家经历顺序

1. **SRPG连续救场。** 三台飞行机按红色标路、蓝色护航、黄色断支架依次行动；货柜领袖牵引船台；万机馆成为多格支点；馆守Z固定一段断桥；旧拳王用红带拖走松脱设备。让画面由空中、巨舰和擂台三个尺度逐步展开。
2. **ADV与四个清楚Cut-in。** 胶价王拒绝公司只保贵货和重剪牺牲结局，开放事故解锁资料并付出钱；完全版王者本人卸下背炮和外翼，再让外翼、双盾、头冠分别成为踏板、局部支撑和警报。不要连写十种用途。
3. **设施Boss终结。** 两台机体一左一右顶住断电舞台炮，其他单位各守一个现有支点，把炮身推回朝海拆卸位。工程机固定、人员卸烟光弹、吊机移走炮身。全程不重新点火。
4. **短ADV与时间转场。** 裁判判事故回合无结果、冠军取消本场全装资格；经过数小时复检，零比零重赛移到E02已出现的室外测试场。用日落到黎明、外装被整齐放在场边、两台基础体重新站上白线来完成时间变化。
5. **基础体决胜。** 只写一轮完整攻防。完全版王者更快、更熟练；无牌一号只回收玩家实际选择的一种训练动作，以护位转身重新站稳并形成明确倒地/出界判定。胜利要堂堂正正，旧拳王不让赛，冠军不自毁。
6. **木桶街余波。** 赵梅继续寄件；唐胶把方法交给合作社，兜灯确认别人能复做；胶价王承认不独占也能卖，马上开始算新商品。生活气和笑点来自他们仍要过日子，不用再吃一顿饭代表日常。
7. **交接与启航。** 两台机体分别由原维护关系和本人完成随舰确认；新转子沿一条连续可见的重载路线进B1，旧转子移到旁侧锁架。白鸢最后登舰。陆衡给出一次不停机前往工务城的航行窗口，万机馆离港。

## 人物声音与关系

- **纪存**负责看全局、做决断，也会在冠军卸装时真正被震动。他不能把每个选择都解释成文化命题。决胜后，他向无牌一号提供泊位，不替它宣布加入。
- **七海**仍在远程。她会把救援后的调查、赛事仲裁和机体交接分开处理，但说普通话，不念制度摘要。她对纪存和白鸢的关心可通过确认伤势、追问谁还留在危险区、以及对白鸢登舰的反应表现。
- **白鸢**本话不再用图解决问题。她先帮着把救援现场可视化，随即把纸和笔收起来，接受机体本人做出的解决。登舰时可以主动、有挑衅感，也可以让七海听见，但不能靠一句“我来监督你”敷衍动机。
- **无牌一号**话少而不装深沉。它会明确要求“打完”，会在获胜后自己确认转子的用途和随舰选择。
- **完全版王者**有舞台感、自尊和对“完全”的欲望。卸装时不自怜；败后也不会说自己原来不需要装备。它应让玩家期待下一次全装再战。
- **旧拳王**以动作和一两句直白判断收徒，不讲哲学报告。允许在真正的大拳之前使用可辨认的武斗语气，但不要整段照抄原作。
- **胶价王**仍然精明、能算、会挣钱，也真的懂这批冷门机体。他付出损失以后仍马上找新卖点，才像活人。
- **赵梅**说订单、电话、谁会修、东西往哪寄。提到儿子时少说，情绪落在具体动作上。
- **唐胶与兜灯**一人教到别人会做，一人检查到真能复做。允许有自然打趣和身体靠近，不把他们写成发表手艺宣言。

## 情绪与画面目标

- **奇观目标：** 百米万机馆贴住下沉圆环，多台巨机和飞行机从不同尺度共同托住一个正在向海倾斜的世界。
- **燃点目标：** 完全版王者卸下全装后与无牌一号并肩推回舞台炮；黎明时两台基础体重新站上场，所有花活归零，只剩这一拳。
- **泪点目标：** 赵梅在儿子的工作账号后补上自己的联系电话。不要配主题演说。
- **关系目标：** 白鸢登舰使纪存、七海、白鸢从远程三角变成即将共享一艘舰的现实关系；七海仍不在舰上，因此她的反应要留下下一章张力。
- **结尾目标：** 万机馆不是“修好了”，而是在一次不能停机的航程中出发。胜利有获得感，下一站也有必然性。

## 概念与制作节制

- 场地只使用已经出现的货运环、平行作业道、E02室外测试场、自动港重载通道和万机馆B1，不发明新舱、新廊、新母架。
- 救援只让玩家理解一个主变化：先稳住下沉侧，再减轻偏载，最后移走断电舞台炮。
- 转子安装只表现四个大画面：旧件移出、九米新件吊起、运输架进舰、低功率试转。不得展开内部机构说明。
- 维护交接只写可见物：维修册、备件箱、泊位钥匙、旧武斗馆保管牌；不把合同条款变成人物对白。
- 本话可以长，但每一段必须推进危机、决胜、情绪或启航之一。不要为“完整”重复解释前四话结论。

## 禁止事项

- 不使用“你可以X，但别替我Y”“今天先X，也别Y”“谁替谁背”“没有把X说成Y”等旧句式。
- 少用“槽、锚、拍、锁、语法、债务、亮灯”；不靠几秒、几格、一厘米制造分量。
- 不把本话写成设置说明、合同摘要、所有权讲座或维修流程表。
- 不让白鸢画出物理结果，不让七海远程夺权，不让纪存一句话收服机体。
- 不让模型件直接顶住巨构，不让万机馆变形或把九米转子抱上舰。
- 不靠伤亡、随机爆炸或新敌人给终局加码。本章的敌人已经是旧结局、失控巨构和角色自己的选择。
- 不用“最后一拳是否……”之类莫衷一是的主题句作标题。
