# C02E01《没有名字也能报名》精简主笔Brief

> 用途：修复Runtime查询包与正文主笔输入混为一体的问题。查询请求和审计切片可以详细；主笔实际只读取本Brief，并在写到具体事实时向Runtime定向查询。

## 已锁事实

- C01结束后数小时，万机馆带伤抵达木桶街；纪存、唐胶、兜灯和旧守护者随舰，七海留在原城，白鸢尚未到场。
- 万机馆仍处于临时保全状态，能停泊和必要维修，不能拿待移交的馆藏参加商业赛事。
- 万机馆的主循环转子已经受热弯曲；木桶街无法完成整件修复，赛事奖品只能支持一次低功率航程。
- 木桶街同时存在模型与玩具、人可搬运旧件、全尺寸巨机工房三种尺度，三者不得混写。
- 赵梅靠笔记、订单、错单、退件、返工和不断请教逐步学会组织合作社；她不是万能技术专家。
- 无牌一号是十六米自主全尺寸实机，想完成一场属于自己的正式比赛；它不是放大的模型。
- 完全版王者是二十米全装卫冕冠军，追加装备都有真实战术作用，机体本人享受舞台与冠军身份。
- 本话不揭示赵梅儿子的死亡、纪存真相、G.A.G.完整机制、角色惯性的来源或白鸢能力全貌。

## 戏剧要求

- 把万机馆无法继续航行的生存问题，转成必须争取冠军奖品的竞赛发动机。
- 让玩家先通过一个大动作认识木桶街是能够容纳并维修巨机的生活共同体。
- 让赵梅与唐胶的重逢既有旧事未说的压力，也立刻参与眼前问题。
- 让完全版王者在成为对手前先值得佩服；让无牌一号在成为玩家单位前先主动选择参赛。
- 本话必须包含一场目标清楚、可操作、会因机体选择而改变目标的资格赛。
- 纪存与七海的远程关系场必须改变借件方案，而不是重复主题或进行权限说明。
- 结尾同时留下两台机体旧角色关系与白鸢动身两个相互咬合的钩子。

## 主笔可改写范围

- 到港、检修、谈判、进街和冠军首秀的具体顺序与转场。
- 木桶街生活、模玩生态和巨机产业通过哪些人物动作被看见。
- 纪存、唐胶、赵梅、胶价王和七海的具体对白与关系动作。
- 资格赛的地形组合、救场对象和玩家重新取得控制的时机。
- 旧角色记忆在动作中显露到什么程度，只要不提前解释来源。
- 白鸢收到线索的具体媒介和她决定动身的最后动作。

## 开放问题

- 怎样让购买、借用和等待都无法解决眼前问题，却不把竞赛必要性写成行政说明？
- 无牌一号做哪一个选择，能让玩家在正式操控前已经想把它留在队里？
- 完全版王者如何用一场首秀同时呈现压迫力、商品梗和真正实力？
- 赵梅怎样只用两三个生活证据，让玩家看出她是一路学来的，而不提前知道全部往事？
- 七海指出纪存遗漏的什么现实风险，才能让关心直接改变行动？
- 结尾哪一个身体动作可以暗示两台机体曾经共享剧本，同时仍保留它们现在的自主性？

## 未来保留

- 赵梅儿子去世、她如何从订单和地址逐个找人，以及合作社形成过程留给后续情感场。
- 旧拳王、正式淘汰赛、玩家构筑转化为全尺寸工程和冠军终局留给C02后续话。
- 无牌一号与完全版王者为何熟悉旧角色动作，后续必须让机体知情后再选择继续、修改或拒绝。
- 白鸢本话只通过作品痕迹和远程线索进入，肉身到场及有限预演能力另行展开。
- 纪存机魂真相、索琳、G.A.G.灾变与二十七年前全貌不得在本话提前消费。
