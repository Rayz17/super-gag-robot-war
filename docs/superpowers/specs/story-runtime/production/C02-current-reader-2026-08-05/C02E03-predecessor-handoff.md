# C02E03前话交接

## 时间与地点

- C02E02结束于第二日傍晚。第三话从当天夜里开始，延续到第三日上午的两场半决赛。
- 万机馆仍由防风缆索和地面支撑车固定在木桶街外泊位，舰外停泊修正器仍暂装在无牌一号背后。
- 九米冠军转子仍在赛事货运环中央，尚未交付或拆卸；货运环本话后段才开始低速转场，为E04移动决赛准备。
- 本话可用地点只有旧舞台库、合作社资料室、全尺寸工房安全侧、固定观景厅和非致命擂台。不得临时新造复杂地下空间。

## 已发生事实

- 四强签表已确定：无牌一号对旧拳王；完全版王者对坞工杰克。
- 无牌一号已经用全尺寸牵引带完成一次旋身回位，但面对旧拳王换侧追击时只迈出半步。
- E02已经完整使用“玩家短控旧拳王，主动停下一记必中拳”的高光。E03正式半决赛不得重复这一设计。
- 白鸢已实体抵达木桶街。她确认自己多年前画过的补充分镜，与无牌一号每次护位后的停点重合；她还不是万机馆成员，也没有未来视、现实改写或战斗指令权。
- 赵梅已经取出合作社旧柜钥匙，正在联系有权查看旧资料的人。E02只暗示她逐步学习，本话才公开儿子去世、错件返工和合作社形成过程。
- 七海仍在原城远程调查。她可以提供调查中取得的旧授权时间和文件真伪判断，不能替木桶街授权、控制比赛或肉身到场。
- 唐胶、陆衡、赵梅、兜灯的分工已经成立：动作与手作意图、全尺寸工程判断、协作分派、实机安装安全不能混为同一能力。
