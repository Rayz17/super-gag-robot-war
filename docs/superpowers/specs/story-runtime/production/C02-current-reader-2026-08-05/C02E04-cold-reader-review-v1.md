# C02E04《决赛驶向大海》冷读审查 v1

## 冷读边界

本审查以完全不知道作者答案的普通玩家 / 专业编剧视角，只读取当前 C02E01-E04 Reader，以及 `reader-review` 允许的普通读者 / 编剧绝对审查与人声语义门。没有读取 L4、导演板、物理板、主笔 Brief、因果骨架、Canon 后台、旧稿或其他审查。正文说不出的因果不以后台意图补齐。

## 结论

`REVISE_BEFORE_USER_READ`

E04 的移动冠军战、事故因果、两次转身、三主角关系动作和话末悬崖主体成立。退回只因一个直接伤到核心场面的前情契约缺口：E03 刚限定旧影像不得公开、两台机体只同意公开今天的比赛，E04 却未经页面内重新许可或告知，就把旧牺牲分镜轮廓放上公共直播，并以此组织终幕演出。

## 白话复述：E04 发生了什么

1. 货运环带着九米冠军转子驶离泊位。冠军转子交付前本来就要随货运环完成最后一次海上运输测试；胶价王为了省下一天场地，并做出木桶街独有的比赛，把冠军决赛和这次测试合在同一趟行程里。无牌一号与完全版王者都没有退出。

2. 两台机体原本分站圆环两侧，以重量互相压住。比赛前半的目标是把对手推过各自一侧的两道白色计分线；粗大负载线不能越过，越线、破坏要害或出界都会被裁判叫停。终幕舞台炮在中央，只装朝海发射的烟光弹。

3. 完全版王者把长翼、盾组、钻进组件和重炮全部用进比赛。它飞过断口、用双盾压缩路线、钻穿隔墙、打掉无牌一号准备借用的远区靶板，再用全装重量连续近身。无牌一号则利用牵引带吃住盾组冲力，旋过盾缘反推冠军。双方各自把对手压过两道计分线，前半战平。

4. 战平后，终幕舞台炮升起。公共屏幕左边出现旧分镜轮廓：A-7 站在炮线前，准备护甲交接；右边是今天的两台实机。无牌一号的身体先走进旧 A-7 的位置，但它看到脚边新增的退出线后，自己转身走出了牺牲位，并告诉完全版王者：“我不站那里了。”

5. 完全版王者把这看成最终回又一次停在半途。它不是要攻击无牌一号，而是害怕 / 拒绝结局再次中止，于是越过负载线追上去，抓住舞台炮的演员操作柄，把炮口转向无牌一号的新位置，要求它“回来”。完全版王者、全部外装、无牌一号和偏转的炮身因此集中到圆环向海一侧。

6. 裁判立刻警示并终止决赛、冻结比分。胶价王切掉比赛画面，只保留港外远景，命令环上人员听从安全组向内侧撤离。七海远程把责任拆清：本地裁判冻结比分，本地安全组断货运环与舞台炮动力，原始事故画面完整保存并写上她的名字；赵梅接过现场频道，落实撤离指引、画面另存和本地责任人。

7. 断电只让驱动与舞台炮停止主动运转，并不会把已经移到海侧的重量送回去。两台巨机、完全版王者的全套装备和偏转炮身仍压在同一边；外侧支承随后弯折，圆环向海侧下沉。完全版王者的一条腿和一片外翼被变形外轨卡住，失去动力的炮身又在斜坡上受重力向它滑去。

8. 地图从比赛切换成人员撤离。控制室倾斜时，纪存先拉住白鸢；他想解带出去拉门，白鸢判断门应由外侧开启，按住他，阻止他把自己先扔进危险。门被外侧人员拉开后，两人撤入内侧。

9. 纪存让红机巡查下沉外沿并吹开轻板，让蓝机护送最后一组工房人员，让黄机从高处把危险边界标在空地上。他又利用 E01 已知的地面作业道，叫火种货柜领袖和地面车队沿有支撑的平行道路把万机馆拖近。七海确认事故画面已保存后，叫所有人先停问责、把最后一组人撤回来。赵梅最终点清人员，一个不少。

10. 无牌一号已经走到安全出口，完全版王者甚至叫它离场。它第二次转身，背对出口跑回去，主动站到滑落舞台炮和完全版王者之间。这次不是旧分镜命令它牺牲，而是它知道危险后自己选择救对手。万机馆只来得及接住货运环下沉的外缘，炮身仍在下滑，危机没有解除。

## 六个关键问题

### 决赛为什么在移动圆环上打

仅靠 Reader 可以回答。冠军转子交付前需要随货运环完成最后运输测试，但测试与比赛并非天然绑定；胶价王主动把两者合并，以省下一天场地并做出木桶街独有的海上冠军战。E03 已在发车前说明两台机体只要有一台退出，货运环当天就不发车；E04 开头又给了最后退出机会。

### 完全版王者为什么追

仅靠 Reader 可以回答。它从 E03 起就想把被取消的最终回“打完”。无牌一号走出旧牺牲位后，完全版王者面对的是第三种中止：原稿停在强光，白鸢补图停在空白，今天的 A-7 又从交接位离开。“又要停在这里吗？”把它的恐惧和误解说清了。它追的是一个不肯再次中止的结局，不是单纯追杀无牌一号。

这让它的行为可理解但不被免责：它自主越线、擅自转炮，裁判立即停赛；被困后它又叫无牌一号离场。冠军因此既有欲望、错误和后果，也保留了对对手的关心。

### 裁判和安全组做了什么

仅靠 Reader 可以回答，权限也分得清。

- 裁判在完全版王者越负载线时立即警示，随后终止决赛并冻结比分。
- 胶价王停止比赛直播，向环上人员发布内侧撤离命令。
- 本地安全组切断货运环与舞台炮动力。
- 赵梅在现场复述撤离顺序、让固定厅只放撤离指引，并落实原始画面另存。
- 七海只提出并公开署名保存要求，没有远程碰木桶街开关。

### 为什么断电后还会倾斜

仅靠 Reader 可以回答。断电停止的是主动驱动，不会自动搬回已经偏移的质量。无牌一号、越线的完全版王者、王者全套外装和被拉偏的舞台炮都集中在向海一侧；既有偏载继续压住外轨，外侧支承弯折后，圆环进一步下沉。舞台炮不能发射，却仍会在斜面上受重力滑动。事故不是“断电后设备还自己开”，而是断电后重量和重力仍存在。

### 无牌一号两次转身分别意味着什么

第一次转身是拒绝：它走出旧分镜替 A-7 安排的牺牲与护甲交接位置，不再让过去替自己决定消失。

第二次转身是选择：人员已撤、出口就在前方、完全版王者也叫它离场，它仍主动回头救对手。两次动作把“不接受被规定的牺牲”与“仍愿意自己选择承担危险”分开，回收了 E01-E03 的整条“挡完以后还能继续走”主线。

### 纪存、七海、白鸢分别改变了什么

纪存先在控制室接住白鸢，随后接受她对门向的现场判断，没有继续抢着独自冲出去；撤离后，他把 E02 已见过的红、蓝、黄三机脾气转成侦查、护送、标界三种救援动作，又调用 E01 已建立的头车、地面道路和万机馆船台，改变了救援地图。

七海没有越权扮演远程总控。她把比分、断电、原始画面三件事分别交回本地权限，并用公开署名让保存事故证据不再是无人负责的要求；证据到手后，她立即把频道重心改回最后一组人员撤离。

白鸢先以两台机体不换位为前提画撤离图；前提被完全版王者打破后，她当场划掉自己的图，要求停止旧分镜、先撤人。控制室倾斜后，她又以具体门向阻止纪存无效冒险。她不再让图压过现场，也不再只站在纪存的保护动作里。

## 绝对标准审查

### 开头：PASS

第一句就是圆环越过泊位线、海面进入环心，第二段把冠军转子和两台巨机放到同一张移动远景里。十九行内说清“为什么移动”，六十七行进入冠军战。安全带回扣同时让纪存、七海、白鸢在开打前有生活气，不是纯规则宣读。

### 冠军战：PASS

战斗一句话可以复述：完全版王者用翼、盾、钻具、重炮和全装重量控制移动擂台，无牌一号借牵引带绕过盾缘反推，双方各拿两分后进入终幕。

路线断口、运输隔墙、远区靶板、中央斜面和移动方向都参与胜负。完全版王者的每件装备做了不同动作，无牌一号也不是被动挨打。比分虽然没有持续显示具体数字，但四次过线与最终战平仍能跟上。

### 完全版王者：PASS

它强，而且强得有身体逻辑：能飞越断口、把双盾变成移动墙、钻穿障碍、用炮封路线、用全装重量连压白线。它享受镜头和海风，有明确表演欲，不只是旧剧本的受害证物。

它的追逐是本话最大错误，也是最具主体性的动作。“又要停在这里吗？”让错误来自二十多年未完成的关系，而不是事故需要某台机违规。它造成后果、听见停赛后收手、被困时叫无牌一号离场，因此可责、可怜，也值得下一话继续看。

### 三主角与关系动作：PASS

开头安全带笑点、事故中纪存拉回白鸢、白鸢按住纪存、七海在远程听见两人说话并持续纠偏，都改变了现场行动。三人不能互换：纪存负责看见可调用的机体与道路，七海负责权限和留证，白鸢负责承认图已失效并以空间判断阻止无效冒险。

### 事故可读性：PASS

触发链可以一遍复述：无牌离位 -> 王者越负载线追 -> 王者拉偏舞台炮 -> 巨机、外装和炮身集中海侧 -> 裁判停赛、安全组断电 -> 偏载没有消失 -> 外侧支承弯折 -> 圆环下沉 -> 王者被卡 -> 断电炮身沿斜面滑落。没有依赖新增世界规则或后台物理板。

### 游戏承载：PASS

第一阶段有明确地图、负载禁区、计分线、平分后的终幕和玩家牵引带行动；事故后又明确切换地图状态与第二阶段目标“撤出人员，保住内侧通路”。红、蓝、黄三机分别承担侦查 / 清障、护送、标界，万机馆沿平行作业道靠近，玩家能理解地图和目标已经从夺分变成救援。

第二阶段没有再标一个单独的“玩家选择”，但作为 Reader，纪存下令、三机执行、人员标记归入安全区的承载仍可理解；精确可控单位与回合配置属于后续设计审查，不阻塞普通玩家首读。

### 话末悬崖：PASS

本话已经完成三件事：打出一场有胜负走势的全装冠军战；让无牌一号公开离开旧牺牲位；把事故第一目标“人员撤清”完成。结尾再留下更大的未决动作：无牌一号自愿回头，万机馆只托住一边，舞台炮仍在下滑。它不是把整话停在半句，而是在完成一次人物选择后停在物理后果上。

### 对白与叙述：主体 PASS，存在两处局部风险

无牌一号短而字面，完全版王者带着报幕习惯和舞台欲，纪存 / 白鸢互相拆台，七海习惯把权限说清，声线可以区分。没有大面积旧式拗口或文艺装精。

最接近技术 cookbook 的位置是七海列出三件事后，赵梅与叙述又把冻结、断电、留存逐项复述一次。它稍有重复，但每项立刻落到不同本地执行者，不足以构成退回根因。

“公共直播没有重播 E03 的调查过程”把剧内叙述写成了生产文档编号，局部出戏；“第一次旋身 / 第二次旋身”则虽直接总结意义，但动作差异足够大，当前仍可接受。以上均可局部修正，不要求重写场面。

### 标题：PASS

《决赛驶向大海》用本话第一眼可见的具体事物和动作命名：决赛、驶向、海。它同时承载移动货运环奇观与事故方向，不靠读完作者主题解释才成立，明显强于“拒绝牺牲”“自己选择回来”一类主题判断句。

## 两个强制冷读时刻

**最想继续看：** 完全版王者收回悬空的手，问“又要停在这里吗？”，随后越过负载线追出去。冠军从强大表演者翻成一个做错事的未完成角色，情绪与事故在同一个动作里发动。

**开始走神：** 裁判停赛后的第 219-231 行。七海列出三项，赵梅再转述，叙述又逐项确认，信息短暂重复。随后驱动声消失、桌上笔开始滚动，注意力立刻被事故拉回；这不是结构阻塞。

## 真正阻塞首读的根因

### 1. 终幕演出的公开与知情同意边界和 E03 正面冲突

**证据段落：** E03“看以前先要有离场的路”明确写道，旧影像按现有许可只保留在私人展示，白鸢补图只给两台机体看、不进入公开宣传；无牌一号只同意“播今天的”，本话公开情报又归纳为“两台机体只同意公开今天实际发生的比赛”。胶价王也刚删除“牺牲结局重现”的卖点。

E04 开场公开的三条规则只说明计分、终幕、负载线和停赛条件，没有说明终幕会把旧 A-7 牺牲画面拿来与实机并置，也没有出现白鸢或两台机体对此用途的新同意。到“炮口前少了一台机”，公共直播却直接把旧分镜轮廓放在左边，并按 A-7 护甲交接位置组织现场。无牌一号还是“身体先于任何指令”走入旧位。

这不是单纯版权小漏洞。E04 的核心价值是无牌一号在看清以后拒绝被旧故事安排，再于事故中自愿回来；如果赛事在它未获知情的情况下先把旧牺牲重新包装成公共终幕，那么 E03 花整场建立的退出权、公开边界和胶价王改错都会被暗中撤回，第一次转身的主体性也会被赛事诱导污染。

**最小修改方向：** 在“没有人退出”成立以前，补清旧轮廓的来源与公开许可，并让页面明确两台机体已经知道终幕的旧构图用途、拥有退出权且同意该范围；或者取消公共屏幕上的旧分镜并置，让旧构图只由两台机体今天的动作形成。只需修正这条同意链，不要改冠军战、追逐、事故机制或两次转身。

最终判定：`REVISE_BEFORE_USER_READ`
