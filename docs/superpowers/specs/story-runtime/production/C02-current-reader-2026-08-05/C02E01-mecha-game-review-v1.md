# C02E01 机战与玩法独立审查 v1

> 审查视野：C02E01候选Reader、C02战斗与玩法预案、章级演出承载规划、章级预生产模型及机战审稿规则。

## 成立部分

- 火种货柜领袖以变形牵引和喇叭反驳建立职业人格。
- 完全版王者用长翼、盾组、钻进组件和重炮分别解决障碍，证明全装是有效战力而非纯笑话。
- 无牌一号主动报名、决定奖品用途、救下对手并完成路线，不是供主题说明的工具机。
- 角色惯性只通过旧编号、身体熟悉感和半套站位显露；无牌一号此前已有多次自主选择，因此不会被读成旧剧本遥控。
- 模型用于表达形态、动作和构筑思路；全尺寸结构由工程重做，塑料模型没有直接变成实机或装备。
- 资格赛具备单一可控单位、地面借力、短空中段、对撞门、目标切换和玩家收尾动作，可落为SRPG关卡。
- 取得正式资格、王者认出旧搭档、白鸢动身，构成足够的单话奖励和下一话承诺。

`PASS_FOR_USER_READ`

机战席无阻断根因；只需确保冷读修订不削弱三台机的舞台动作、角色惯性和模型/实机边界。
