# C02E04海上移动决赛精简主笔Brief

> 只写一话Episode Reader。“海上移动决赛”仅是工作标题；完稿后再交付三个显示标题候选。

## 一句话故事

无牌一号在驶向大海的圆形擂台上走出旧故事的牺牲位；害怕最终回再次被取消的完全版王者带着全装追过去，将巨型擂台压向海面，而明明能离场的无牌一号又转身回来救它。

## 本话的戏剧重心

1. **先好看，再出事。** 前半必须是一场真正有攻防、追逐、反击和大动作的冠军战。完全版王者四套装备都有用，无牌一号用牵引带和自己学会的转身逼近。不要用微小关节动作代替大场面。
2. **冠军不是发疯的恶人。** 它真心享受冠军、全装和舞台，也真心想与唯一记得旧故事的同伴完成最终回。无牌一号走出原位后，它觉得自己正在经历第二次腰斩。
3. **无牌一号要完成两次不同的转身。** 第一次是从牺牲位走出，不再用消失证明自己。第二次是在冠军被卡、自己明明能离开时回头救它。两次放在一起，才证明它离开剧本不等于变得自私。
4. **三个主角都要使现场变得不同。** 白鸢撤掉已失效的预演，坚持先撤人；七海让本地人完成真正的停赛、断电和画面保存；纪存确认撤离线、调动飞行队和货柜领袖，为两台机的选择准备现实救场。

## 必须保留的玩家流程

1. **短ADV：决赛前。** 货运环驶入海上段。三条可见规则交代完成：两台机分站两边、不越过粗大负载线、舞台炮只装烟光弹且朝海。纪存、白鸢、七海的赛前交流要像人话，不讨论主题。
2. **SRPG第一阶段：移动擂台冠军战。** 玩家控制无牌一号，利用擂台移动、牵引带和掌握的转身迫近冠军。完全版王者的装备逐步将地图改造成它的主场。
3. **短动画/ADV：旧最终回重现。** 无牌一号先站进牺牲位，再自己走出。完全版王者问“又要停在这里吗？”，自主追出负载线。
4. **地图事件：比赛已经停止。** 裁判冻结比分，安全组断电。玩家看见大重量已经集中到同一侧，擂台开始倾斜。从这一刻起不再计分，不得继续把事故写成赛事规则战。
5. **SRPG第二阶段：撤人与保住出口。** 飞行队标出下沉范围，工作人员撤往内侧；玩家不在本话完成全部救场。完全版王者被卡，断电炮身滑向它，无牌一号回头。
6. **话尾悬崖。** 万机馆被火种货柜领袖和地面车队拖到平行作业道，只能接住下沉的一边。本话停在炮身仍在滑落、无牌一号挡在前面的物理状态。

## 人物声音与关系

- **纪存**会先问“人清完没有”“场地谁能真断电”“万机馆从哪条路过来”，不只问机体愿不愿意。他果断、会调度，也会一着急就想自己上。
- **七海**远程、成熟、清醒。她不能断电或夺台，但她知道该找本地哪些人做哪件事，并敢用自己的调查身份公开署名。她不用“四十秒”、审不审或无意义的权限术语表达关心。
- **白鸢**会直接承认自己的图错了，不用“我画出另一条路”补上。她的控制欲与保护欲同时存在。地板倾斜时，纪存拉回她，她又按住想解带冲出去的纪存；可以有呼吸、手、肩带和很近的距离，但不把危机写成突兀卖肉。
- **完全版王者**语气带舞台感，但不是口号机器。它会说得比无牌一号完整，也会因对方离位而失去原本的从容。
- **无牌一号**话少，但不用单字装深沉。它能说清“我不站那里了”，也可以在回头时不说任何主题句。
- **胶价王**在前半是会调动气氛的主持人，事故后立即停播并接受赵梅的现场安全指令。他不在此刻算钱或辩解。
- **赵梅、唐胶、兜灯**都要有现场行动：赵梅组织人员撤往内侧并决定保存画面；唐胶组织无牌一号的近端指引；兜灯直接确认机体与万机馆的安全状态。不必平均分台词。

## 玩家必须一遍看懂的四件事

1. 决赛为什么在移动擂台上打：木桶杯把决赛与冠军转子的最后运输测试合并，这是胶价王做的可避免商业冒险。
2. 完全版王者为什么追：它怕的不是输，是唯一与它共有过去的人也把最终回留下。
3. 为什么断电了还会倾斜：设备停了，但巨机、全装和炮架已经压在同一边。
4. 无牌一号为什么回头：它拒绝旧剧本要求的消失，但没有拒绝自己想保护的具体机体。
