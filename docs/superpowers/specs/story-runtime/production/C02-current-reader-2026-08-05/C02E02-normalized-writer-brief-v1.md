# C02E02《改装不是把所有东西装上去》精简主笔Brief

> 只写一话Episode Reader。查询包是资料室，本Brief才是正文主笔输入；写到不确定的身份、尺寸、能力或前史时，停下来向Runtime问一个具体问题。

## 已锁事实

- 次日上午，万机馆仍停在木桶街，舰外停泊修正器暂借给无牌一号，冠军转子仍在赛事货运环内。
- 无牌一号是十六米自主实机，已取得参赛资格但尚未进入四强。它每次护住别人后，都会停在旧故事要求它消失的位置。
- 本话代表路线采用“牵引带”：模型只表达护位后旋身回位的战术意图；工房使用预认证的全尺寸坯件重新制造，塑料模型不放大、不承力、不承载机魂。
- 唐胶讲动作和手作意图；陆衡只远程做全尺寸工程判断；赵梅联系并分派会做的人；兜灯负责安装、测试和实体停机。四人的工作不能互相替代。
- 白鸢从E01话尾的跨城列车于本日下午抵达。她先追究分镜的未授权使用，尚未成为同伴，也没有战斗指令权、未来视或画稿改现实能力。
- 完全版王者与旧拳王已有四强种子席；坞工杰克先取得一个公开席位；无牌一号争夺最后一席。三台同骨架飞行机是三个主体、三种战法，不占签位。
- 旧拳王是十七米级自主退役武斗机，不是拳套。预赛后指导战不计分，E03才是它与无牌一号的正式半决赛。
- 本话不揭示赵梅儿子死亡、机魂形成、两台机体旧身份全貌、纪存真相或G.A.G.机制。

## 戏剧要求

- 全话围绕一个问题前进：无牌一号挡住以后，能否不再停在牺牲位。
- 让构筑选择、工程落地、白鸢初见、飞行预赛和旧拳王指导战彼此改变，不能写成五项功能轮流展示。
- 模型到实机的四步要靠空间、材料和动作看懂，不靠人物轮流念设定。
- 白鸢与纪存第一次见面要同时有专业冲突、彼此看穿和成年身体距离；调情必须长在防护服、安全带或共同工作里，不单独插入擦边桥段。
- 唐胶、赵梅、兜灯与陆衡都要有不可替代的实际贡献；赵梅仍可当众承认看不懂并向真正会的人请教。
- 三台重涂飞行机必须一眼看出性格不同，既承接同模重涂梗，也让白鸢的第一次预演暴露边界。
- 玩家要亲手用本话构筑赢得最后四强席位，并短控旧拳王作出“已经能打中但选择停拳”的武斗判断。
- 结尾让白鸢发现自己的分镜与无牌一号的身体都断在同一个动作上，明确发动E03调查。

## 主笔可改写范围

- 晨间构筑、远程会诊、白鸢到场、装机与预赛的具体场面顺序和转场。
- 牵引带的视觉外形、一次最清楚的实战用法，以及另外两种构筑如何以简短分支界面呈现。
- 白鸢和纪存初见的具体对白、身体距离与互相冒犯方式。
- 三台同骨架飞行机的临时赛事称呼、动作习惯和预赛地图组合；不新增三名驾驶员或三套独立骨架。
- 坞工杰克怎样取得第一个公开席位，完全版王者怎样在场边保持冠军存在感。
- 旧拳王的出场、红色擂台牵引带和短促武斗台词；可以有玩家能认出的机动武斗式梗，但不复制整段原作台词或招式。
- 话尾白鸢、无牌一号与赵梅之间具体怎样把调查门打开。

## 开放问题

- 怎样让玩家在缩尺构筑时先产生“这是我的打法”，又在全尺寸成品出现时感到它真的变成了巨大机器人的力量？
- 白鸢第一眼为何会对纪存生气，第二眼又为何会对他产生兴趣？
- 三台重涂飞行机怎样用三次完全不同的身体选择，拆掉“一模三色就是同一个角色”的商品说法？
- 无牌一号怎样用牵引带完成一个PV级大动作，而不是几厘米、几秒或某个接口微调？
- 旧拳王为什么愿意停下必中的拳，又怎样在重开后证明这不是放水？
- 最后哪一句普通问答，能让玩家第一次意识到无牌一号的“没有下一步”并非机械故障？

## 未来保留

- E03公开赵梅儿子去世、合作社形成、腰髋改造和两台机体的未播最终话身份。
- E03旧拳王半决赛才完成后半招并决定正式胜负。
- E04-E05保留移动决赛、完全版王者追演旧结局、货运环事故、万机馆母舰救场、转子实物交付与白鸢登舰。
- 无牌一号与完全版王者必须在知情后重新选择怎样对待旧角色命运；本话不能替它们下结论。

## 声音与可读性

- 对白必须有听众、语气、反应和生活口吻。工程判断用日常比喻和可见后果，不堆“槽、锚、拍、锁、语法、债务”等内部词。
- 不用“你可以X，但别替我Y”“今天先X，但也别Y”“不是X，而是Y”的连排原则句。
- 不靠一厘米、几秒、一格、亮灯或终端登记制造戏剧分量。
- 巨机战用方向、冲撞、牵引、越界、起身和停拳等远景大动作；删掉作者解释后，玩家仍应看懂胜负。
