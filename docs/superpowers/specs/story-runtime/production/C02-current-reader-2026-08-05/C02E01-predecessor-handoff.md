# C02E01前情与进场状态

## C01已发生

- 万机馆在BREAKER袭击后恢复了巡展舰的有限航行功能，启动第七次巡展，但没有得到合法离港批准。
- 纪存、唐胶、兜灯、跌跌和机器犬随舰；小满、阿澄、豪司与勇拳、七海均留在原城。
- 馆守Z与旧守护者是同一机魂主体。十八米巨体的原右前臂已毁，右肩烧损；当前接了一具只能抓取、牵引和固定的黄色巡展臂。备用轮式终端只是它的远端外壳。
- 万机馆的裂盾和推进骨架已报废，舰壳、前甲板和循环系统带伤，不得进入C02便免费修复。
- 七海在C01只提供当时的民用净空航路和禁射区，没有批准万机馆起飞。她正留城接受调查。
- 纪存与七海有一年多的私交和未明言的吸引。C01结尾，他们又错过一顿饭；纪存说下次由他订，七海只要求先找一个不会晃的地方。这句话可在C02成为关心和反讽，不反复使用吃饭道具。
- 木桶街主动发来能容纳万机馆的巨构泊位照片。唐胶认出声音却不愿说明过去；纪存因为舰体需要落脚点而选定木桶街。

## E01进场时的硬边界

- 时间：C01离城数小时后，第一日临近中午。
- 位置：万机馆从外圈作业水道靠近木桶街巨构泊位，不驶入人尺度街区。
- 在场主角：纪存、唐胶、兜灯、旧守护者的备用轮式终端。
- 远程人物：七海可通过私人通讯参与一次决定；她无木桶街现场权限。白鸢本人仅在话尾的另一地点收到作品侵权匹配，不得提前到场或指挥战斗。陆衡本人不登场。
- 临时保全人只能处理停泊、保命、必要维修、可归还设备与救命替换件；不能拿待移交的万机馆与馆藏参加商业赛事、抵押或出售。
- 模型和实机分区展示。缩尺模型不长大、不承重、不保存机魂，不在E01直接变成巨机装备。
- 玩家依然不知道纪存是机魂实体，也不得在E01解释G.A.G.、索琳或二十七年前的完整真相。
