## 无回归裁决

### 1. 机战爽感：无回归

外翼越断口、双盾封线推过计分线、钻进组件正面破墙、肩后重炮打靶封路仍分别成立（E04:83-143）。无牌一号借盾力使牵引带旋身、推回冠军计分线的玩家回收也未改（E04:99-109）。

### 2. 两阶段玩法：无回归

- 第一阶段仍以无牌一号对完全版王者，以白色计分线、负载线、断口、隔墙与标记靶组成移动擂台战，前半仍以同分结束（E04:77-149）。
- 第二阶段仍在环体一侧下沉后切换为「撤出人员，保住内侧通路」，红机清障、蓝机护送、黄机标记危险区，直到全部人员标记进入安全区（E04:259-339）。
- 百米万机馆、两百米倾斜货运环、十几米机体与滑落炮身的多尺度地图奇观完整保留。

### 3. 机体主体性：无回归，且更清楚

无牌一号与完全版王者在赛前已知站位和退出权，终幕时又没有旧图上屏或外部口令。因此，两台机体自行走入旧站位、无牌一号用第一次旋身越过退出线、完全版王者因害怕终幕再停而越负载线，都更明确地属于机体选择（E04:161-205）。

第二次旋身仍发生在人员撤离目标完成、无牌一号可以离场之后；唐胶只报落脚点，纪存不代答，它自己回身跑向王者（E04:335-369）。

### 4. 事故因果：无回归

赛前分压两侧和粗负载线仍当场可见（E04:23-31）；王者带全装越线、把舞台炮沿外轨拉向同侧（E04:195-205）；断电后移位重量不回中央，轻物先滑、外侧弯折、环体下沉、腿与翼被卡、炮身下滑的大动作链仍连续（E04:233-259）。停赛段变短没有抽掉任何必要因果节点。

### 5. E05 保留：无回归

话末仍是「救援局面形成」而非「救援完成」：完全版王者未脱困、未卸装，舞台炮仍下滑，无牌一号仍在斜面后滑，万机馆只接住一边，货运环未回正，冠军转子未交付，无牌一号、旧拳王与白鸢的后续去向仍未决定（E04:371-421）。
