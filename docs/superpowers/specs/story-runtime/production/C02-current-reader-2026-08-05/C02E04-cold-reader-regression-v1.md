# C02E04 冷读窄回归 v1

## 范围

本轮只读取当前 C02E03、C02E04 与上一轮 C02E04 冷读报告，只回归原阻塞根因及其相邻修改。没有读取作者板、设计答案或其他材料，也没有重新全面审查未修改场面。

## 结论

`PASS_FOR_USER_READ`

上一轮“终幕公开与知情同意边界冲突”的根因已经关闭；相关改动没有引入新的首读阻塞。

## 1. E03 与 E04 的公开契约

**回归结果：PASS**

E03 的边界没有被改坏：旧影像只留在私人展示，白鸢补图不进入公开宣传，无牌一号只同意“播今天的”；决赛发车前，旧分镜也从所有公开页面撤下。

E04 现在明确写成“固定观景厅和公共直播里只有今天的广角实况”。终幕不再把旧图、白鸢补图或调查画面放上公共屏幕，观众看到的是今天两台实机正在做的动作。两话契约一致。

## 2. 两台机体是否知情并主动参赛

**回归结果：PASS**

裁判在赛前明确告诉两台机体：终幕炮位与旧站位会随赛程升起；到达终幕以后，任何一台不想继续演，都可以沿退出线离开，比赛按当时比分处理。

无牌一号回应“听清了”，完全版王者回应“我会到位”。更重要的是，退出权不是只在开赛前存在，而是保留到终幕现场；无牌一号后来确实沿退出线离位，证明这不是一句无效说明。两台机体是在知道炮位、旧站位与退出办法后继续参加。

## 3. 旧图撤下后的两次转身与追击

**回归结果：PASS**

旧图不上屏后，场面仍然清楚，而且主体性更干净。

- 终幕只有赛前告知过的旧站位升起，没有动作口令。
- 无牌一号已经看过旧故事，身体也记得排练路径，因此自行进入 A-7 原位置。
- 完全版王者同样自行进入旧主角机位置并伸手等待交接。
- 无牌一号看见退出线后第一次旋身，明确拒绝继续站在旧牺牲位。
- 完全版王者面对的不是屏幕替它解释的旧图，而是眼前真正空掉的交接位。正文再以它见过的强光原稿、空白补图和“又要停在这里吗？”连起追击动机。

因此，第一次转身仍然是无牌一号主动离开旧命运；王者追击仍然来自它不愿最终回第三次中断，而非看见公共屏幕后的机械反应。第二次转身也未受影响：无牌一号在安全出口前自行回头救王者，没有回到旧炮线或护甲交接位。

## 4. 停赛、断电与留证行动者

**回归结果：PASS**

压缩后仍可一遍分清：

- 裁判终止决赛并冻结比分。
- 胶价王切掉比赛画面，发布内侧撤离命令。
- 七海指出下一步应由本地安全组断电，并公开署名要求保存原始画面；她没有远程操作本地开关。
- 赵梅接过现场频道，要求固定厅不再切回比赛，并在内侧工位组织人员撤离。
- 本地安全组切断场地动力，固定观景厅操作员保存现场画面。

原先“七海列三项、赵梅再复述、叙述第三次确认”的重复已经消失，权限与执行人反而更清楚。

## 5. 新阻塞检查

**回归结果：无新增阻塞**

修改没有把旧图换成新讲解员，也没有新增许可文件、便利安全机制或替机体作决定的人。旧站位、退出线和两台机体的赛前回应都直接服务原有终幕；事故触发链仍是王者自主越线、拉偏舞台炮并造成同侧偏载，没有被修补改写。

最终判定：`PASS_FOR_USER_READ`
