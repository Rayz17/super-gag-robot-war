## 结论

`PASS_FOR_USER_READ`

一句话复述本话战斗：完全版王者用翼越断口、盾压计分线、钻进组件破墙、重炮封路，无牌一号借盾力旋身追平后走出旧牺牲位；王者因惧怕最终回再次中止而拉偏舞台炮，使比赛立即变成倾斜货运环上的撤离与救援战。

## 逐项裁决

### 1. 完全版王者的四组装备与冠军感：通过

- **外翼**：直接越过运输轨面断口，把地图的绕行限制变成王者的落点优势（E04:77-80）；后续短跃持续抢位，不是一次性展翼摆姿（E04:127-131）。
- **盾组**：两面盾先封内外线、把宽环道压成窄路，再把无牌一号推过计分线（E04:79-87）；近战时又作为合拢墙面、翻摔力量与事故后的撑炮/撑地结构（E04:129-137, 253-259）。
- **钻进组件**：不绕运输隔墙，而是在腿侧展开后以全装身体正面破墙，并在后续近战里改变进攻角度（E04:111-129）。
- **背负式重炮**：不用来直射对手，而是一发打穿远区标记靶，使无牌一号准备利用的整段路线本轮失效（E04:121-125）。

四组装备分别改变落点、通路宽度、障碍物和远程路线，最后合成「这张移动地图就是它的主场」。它享受冠军、海风、全装和镜头（E04:31），足以配得上冠军机的身体人格，不是配件清单或过载笑话。

### 2. 无牌一号的构筑、已学动作与自主选择：通过

- E03 已让玩家操作它主动脱开牵引带，再用腰髋回转和两步走完旧拳王教的「半步」（E03:421-501）。
- E04 赛前只重新确认脱开机构可用，兜灯没有替它拉，也没有新装突然出现（E04:33-41）。第一阶段的玩家行动是把既有牵引带用到新对手的盾力上，结果是可见的迫近与追平（E04:93-103）。
- 无牌一号首先受旧角色惯性影响，身体先于指令走入 A-7 位置（E04:155-161）；但它看见退出线后，用已学腰髋与两步回转自行走出牺牲位（E04:165-181）。
- 话末的第二次旋身不是新招，也不是玩家替机体选：人员撤离目标已完成、它本可离场时，它自己转身回到王者与滑落炮身之间（E04:337-371）。

这条「装上 -> 学会 -> 主动停用 -> 用自己身体完成 -> 自主回身」的回收完整，爽点由玩家前文投入和机体本人选择共同赢得。

### 3. 两阶段 SRPG 可操作性与地图奇观：通过

**第一阶段：移动擂台冠军战**

- 玩家单位是无牌一号，对手是完全版王者；胜负资源是两道白色计分线，越界、破坏要害或越负载线会直接停赛（E04:23-29）。
- 地图不是静止背景：整环在海上轨道移动，有断口、可破隔墙、远区标记靶、粗负载线、中央转子运输架和终幕舞台炮。完全版王者的四组装备分别改变这些地图条件。
- 无牌一号借盾力的玩家行动不是看动画：它改变了双方位置与分数，最后双方各过两道计分线，前半战平（E04:95-143）。

**第二阶段：倾斜环上撤人并保内侧通路**

- 地图状态从比赛切为「一侧下沉」，目标从计分切为「撤出环上人员、保住内侧通路」（E04:261-301）。
- 临时可用单位和目标一一对应：红机清散路面轻板，蓝机护送最后一组工房人员，黄机用标记弹刷出动态危险区（E04:297-307）；无牌一号则有明确内侧离场路线。
- 撤离不是旁白说「完成」：赵梅点人，蓝机将最后一组送过内侧线，地图上的全部人员标记才进入安全区（E04:293-341）。
- 百米万机馆沿平行作业道被拖近、两百米货运环向海侧倾斜、十几米机体与滑落炮身在斜面对抗，前景、中景和巨构背景均能在一张战场图上复述。

第二阶段的玩法任务在「人齐」处完成；随后无牌一号违背离场目标自主回头，是机体人格事件，不应被伪装成玩家替它作伦理选择。

### 4. 旧角色惯性与原创 IP 精神投射：通过

- **旧角色惯性**：无牌一号的身体先于指令走入 A-7 牺牲位，完全版王者也走到旧主角机位置、伸手等待交甲（E04:155-163）。这是身体演戏，不是口头说「我想起了设定」。
- **援护机拒绝牺牲**：无牌一号不否认自己会援护，而是用已学的两步走出被写死的炮线，再以「我不站那里了」明确拒绝旧角色对它的结局要求（E04:165-181）。
- **全装冠军害怕再次腰斩**：它收回交甲的手后问「又要停在这里吗」，不是受胶价王遥控或为了伤害无牌一号，而是越线拉动舞台炮，想强行让终幕继续（E04:173-201）。
- **原创变奏**：它们不是在复刻旧必杀技，而是两副活到现在的宣传实机，在移动工业擂台上对一个被取消的牺牲结局作出相反选择。类型粉丝能辨认超级机器人最终回、援护机献甲和被腰斩的情绪契约，正文却没有报任何现实片名。

更重要的变奏在话末完成：无牌一号拒绝「被剧本要求死」，但完全版王者真正遇险时，无牌一号仍主动回身援护。它拒绝的是牺牲义务，不是它的关系和身体愿望。

### 5. 巨构尺度、支援能力与 E05 保留：通过

- **货运环**：两百多米直径、港外重载轨道、中央九米转子和两侧十几米机体有稳定尺度参照（E04:11-17）。事故后是一侧外轨/支承弯折与下沉，不是整座二百米圆环无来由翻面。
- **火种货柜领袖**：只在有完整地面支撑的平行作业道上变为人形、接主牵引索，还要地面作业车从后方推船台托架（E04:321-331）；它没有凭空拖飞百米舰体，符合 `V353U043` 的作业变形与护送边界。
- **万机馆**：正文明说它自己追不上，因为横移设备仍在无牌一号背后（E04:313-320）；它全程依船台、作业道、主牵引索和车队靠近，最后仅用舰壳接住一侧，没有飞行、整体托环或自主变形（E04:375-393）。
- **三台飞行机**：红机只用高速尾流清障，蓝机只护送人员，黄机只以远程标记弹可视化危险区；三者的作用清楚且低破坏，没有解救王者、扶正货运环或变成新常驻机。
- **E05 保留**：王者仍卡住、未卸装，舞台炮仍在下滑，货运环只被接住一边，冠军转子未交付，万机馆没有整体托环，白鸢也未登舰（E04:387-421）。话末是救援局面成形，不是救援高光已结算。

### 6. 事故因果可见性：通过

事故不依赖一个需要读后台图纸才能理解的小零件，主因果是连续的大动作：

1. 开战前先在镜头里说清两台机应分压两侧，并让摄像头走过粗负载线（E04:23-29）。
2. 无牌一号走出旧位置后，王者带全装越过负载线，并把舞台炮沿外轨拉向同一侧（E04:191-201）。
3. 停赛断电只停住设备，没有把已经移位的两台巨机、全装和炮身送回中央；轻板、工具和海平线先可见滑动（E04:235-247）。
4. 外侧支承弯折、环体下沉、王者腿与翼被卡、断电炮身沿斜面下滑随后在同一镜头链里发生（E04:249-261）。

电子限位只说明炮架为何停在偏转位，不是唯一事故开关；即使不理解该部件，玩家也能从越线、同侧集中、弯折与下沉看懂事故。

### 7. 机器人大战快感、悲剧性与下一话引力：通过

- **爽感**：冠军机用四组装备连续改写移动战场，无牌一号把玩家做出的牵引带构筑用到冠军盾组上；两台十几米实机在海上移动的两百米圆环上正面碰撞，尺度与动作都配得上本话标题。
- **悲剧性**：无牌一号刚学会拒绝被写死，完全版王者却因害怕故事第三次停在半空而越线制造危机；它被卡住后又叫 A-7 离场，让「想要完整结局」和「不再要它牺牲」同时成立。
- **下一话引力**：人员已撤出，但王者的腿与翼仍被卡、断电炮身仍在下滑、无牌一号在斜面上往后滑、万机馆只接住一边。玩家会立即想知道谁能把全装冠军和圆环从这个位置救回来，以及这场没有胜者的决赛怎样才能重开。
