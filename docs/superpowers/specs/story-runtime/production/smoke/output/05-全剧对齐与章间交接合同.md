# C02 全剧对齐与章间交接合同

- 请求：`docs/superpowers/specs/story-runtime/production/smoke/C02-creative-first-smoke-request.md`
- 宏观波形：`A`
- 本章功能：木桶街，万机初开；L3/L4/L5/L6通过市场、拳台和白鸢权利申诉相撞
- 地点必要性：木桶街同时拥有旧件市场、模型维修生态、机械拍卖巨台与万机馆急需的全尺寸转子，能把收藏文化与实机生涯放在同一空间
- 主角欲望：纪存要在不把街区变成万机馆财产的前提下赢得零件、伙伴和第一个公开停靠点
- 对手主动动作：平台把维修史洗成近新商品；归一星把多种重涂压成一个货号；拍卖巨台用复制动作制造冠军
- 主玩法：旧件市探索→四机标签修正空战→机械拳台Boss→夜间复产巡展
- 永久获得：旧拳王正式随舰;转子与维修生态;四重涂机取得独立声纹
- 不可逆结果：唐胶公开旧修补方法；平台与白框取得不同样本；白鸢成为临时乘员
- 本章发动下一章：全尺寸转子仍需工务城校正，旧稳定程序开始追索万机馆

- C01 带入：原右臂永久留旧址；旧馆失去；白函带伤撤退并取得样本；只能去木桶街抢全尺寸转子、泊位与合法现货
