# 候选收件箱

这里可以记录新设定、新关系、用户裁决、剧情需求和图谱缺边，但所有内容默认都是 Candidate。

## 使用规则

- 一张笔记只提出一个清晰的候选事实或关系。
- 写明来源、提出原因、影响对象、与 Current Canon 的潜在冲突。
- 不要仅因笔记之间建立了链接，就把候选关系当作已成立事实。
- 经用户确认后，先迁移 Canon，再删除或标记本候选已经吸收。
