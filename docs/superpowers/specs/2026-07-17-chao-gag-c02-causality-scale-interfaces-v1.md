# C02因果、量级与媒介接口补丁 v1

> 状态：`working_canon_for_story / runtime_migration_pending`
>
> 适用范围：V35.9重构版C02及其后续C03接缝
>
> 目的：修复分镜纸越级改变战场、模型无身体实机化、阵营关系含混、万机馆故障过小、开馆目的悬空及连续救援语法。

## 一、万机馆在C02真正缺什么

C01起航时，万机馆的移动脊柱和六组动力节点强行完成了第一次脱地。主循环中的**磁流散热转子**因此发生永久形变。生活区的小泵仍能维持饮水、空气和低功率照明，但不能承担下一次长距离推进的热量。

C02的主补给目标不是一枚手掌大的密封环，而是一套直径约六米、二十余吨的退役主循环转子。木桶旧件市外环保存着一台报废移动会展车的同型总成，足以让万机馆恢复有限航行。密封件、净水膜和转接头仍然需要采购，但只作补给清单和生活细节，不承担整章主危机。

安装新转子只能解决“能够继续走”。外泊锁、姿态校正、移动设施保险和公共巨构港资格仍然缺失，继续把万机馆推向C03工务城。

## 二、白鸢分镜如何进入行动

### C02阶段：普通创作技术，不是超能力

白鸢在C02尚未取得战斗改写资格。她的纸本或数位分镜不会让机体移动，也不会改变物理世界。

可用链路只有四步：

1. 白鸢根据公开摄影、现场尺寸和机体动作画出运动预演。
2. 纪存的终端扫描画面，识别消失点、镜头高度和相对位置，把构图对齐到当前地图。
3. 陆衡、唐胶或现场专业人员复核承重、障碍、速度和真实尺寸；不合格的格子直接划掉。
4. 玩家把剩余线条当作敌方预告、候选路线或一次支援提示采用。机体可以拒绝、改道或在最后一格做出分镜之外的动作。

因此，白鸢在C02提供的是“很强的视觉预演能力”。她能把混乱画得可理解，也会因为控制欲而下意识删除摔倒、失败或危险的结尾。纪存与她的冲突发生在谁可以把最后一步画死，而不是一张纸为何能施法。

### 预言感的唯一例外

C01那卷提前画出万机馆起航、且使用非公开B1视角的旧分镜仍是谜团。异常之处是白鸢为何见过那些画面，不是纸本拥有力量。C02不得把她此后画的每一张图都写成预言，否则谜团会失去边界。

### C04以后

白鸢是否能在G.A.G.活化场、特定载体和主体许可下取得局部事件编辑能力，留给C04正式剧情决定。即使开放，也不得创造物质、强迫主体同意或凭纸面重写任意历史。

## 三、模型、锚件与实机的物理链

本章统一遵守：**小物件不能长成大机器。**

- 缩尺模型提供比例、版本差异、维修痕、动作习惯和关系来源。
- 残响资料提供旧录像、语音、维修日志或低带宽人格线索。
- 全尺寸实机、原型骨架或工房制造件提供材料、动力、强度和棋盘身体。
- 现场扫描只生成假设；陆衡和工房必须在真实身体上复核并制造承力件。
- 机魂或操作主体保留采用、拒绝和中止的权利。

C02的三个示例：

1. 无牌一号原本就是约八米级全尺寸竞赛底盘。缩尺改件只改变它采用哪套全尺寸模块及动作参数。
2. 童年模型保存了某批移动会展机的民间修正形状。陆衡据此检查巨型转子，木桶街工房另行制造全尺寸适配座。塑料件没有直接装上万机馆。
3. “未发售变形样件”改为本来就有两米高、为活动展示制造的全尺寸工程样机。它平时折叠在工业运输柜内；同批收藏级小玩具另放一柜，封盒与开盒都不被判成错误。

## 四、平台、胶价王、归一星、罗莎琳与索引

### 代哥商品生态与罗莎琳

罗莎琳代表代哥商品生态派。她掌握部分旧规格、售后库存、停产模具和复产谈判权，能让真正的零件重新生产，也会倾向把复杂机体压回容易维护和销售的SKU。她不能单方面撤销街区私人物件、平台寄售合同或城市物流规则。

### 平台

平台是跨城交易、寄售、直播、结算、物流和热度推荐基础设施。它既让冷门旧件找到买家，也会把危机、羞耻、维修史和人格争议转成溢价。平台不等于代哥，也不等于索引；双方通过合同和数据接口合作，同时存在利益冲突。

### 胶价王

胶价王是平台在模型与旧件市场使用的市场代理和主持人格。它控制价格屏、直播剪辑、自动竞价、拍卖台与取件流程，没有独立国家或军队。实体拍卖机械被打坏后，胶价王仍可退回其他屏幕继续服务。

### 归一星

归一星是代哥商品回收承包链的具名实体王牌。C02中，平台把四台共骨架飞行机合并成一张控制/物流凭证，商品回收部门据此把归一星派来执行回收。它能读取标准动作库和合并证书，但不是胶价王召唤出的魔法打手，也不是索引人格。

### 索引

C02阶段不出现会说话、会下令的索引人格。平台与代哥系统在处理大量版本时，会把未采用方案、不同翼标和失败路线送入一个没有明确所有者的优化缓存。读者只能看见它“没有删掉某些可能”，不能因此断言索引已经自觉、已经控制平台或已经与槐绑定。

## 五、木桶街为什么要外部开馆

C02末的活动改为**旧机复产开放日 / 万机馆联合试开**，从下午持续到旧件市最热闹的夜间营业时段。它不是纪存忽然想办庆典，也不是把全街物件收进万机馆。

活动有四个现实目标：

1. 让公众看到新转子、旧拳王、货柜领袖和重涂机确实能安全工作，换取移动设施的临时通行担保。
2. 为停产零件收集足够的真实订单，让罗莎琳和本地工房有理由开小批量生产线。
3. 让维修史成为售后知识，避免手修痕继续被当成降低售价的污点而被擦掉。
4. 证明万机馆可以在不搬空街区、不夺取所有权的情况下组织公共展览，为以后“会开馆的方舟”建立第一种可复制形式。

物主可以选择短借、远程展示、现场展示后带回、只卖不展或完全不参加。活动结束后物件归原处；万机馆得到的是生产、通行和伙伴网络，不是免费库存。

## 七、写作门禁补充

以后出现分镜、模型、扫描、标签、开馆、回收或残响时，正文必须回答：

- 作用发生在哪个物理载体上？
- 谁执行动作，谁只提供信息？
- 中间缺了哪一步制造、验证、运输、许可或通信？
- 玩家能看见的结果是巨机、地图、钱、身体、关系还是路线发生了什么？
- 如果把术语删掉，这场戏仍然成立吗？
- 本话主量级是否与机器人和战场尺寸相称？小物件若是关键，它最终撬动了哪一个大动作？

这些问题属于因果与量级门，不是要求正文写成工程说明。通过方式是给出一两个清楚的可视动作，而不是堆专有名词和毫米参数。

## 八、Canon迁移边界

本补丁已随C02 v2于2026-07-17进入剧情创作Working Canon。以下内容成为C03及后续写作默认口径：

- C02以`S01 / S02 / S03-A / S03-B`映射四话，仍占三个作者槽；
- 白鸢肉身到场前移但战斗改写资格不前移；
- 万机馆C02主故障改为主循环磁流散热转子；
- 未发售样件改为既有两米级工程展示机；
- 平台、胶价王、归一星和罗莎琳的隶属/合同关系；
- C02“开馆”改为有复产、担保和通行目标的联合试开。

本补丁不自动覆盖现行Runtime、美术锁或旧V35.8机器合同。制作层差异必须按`C01-v3.1与C02-v2创作工作基线迁移-v2.md`显式迁移；C03创作入口则必须读取本补丁。
