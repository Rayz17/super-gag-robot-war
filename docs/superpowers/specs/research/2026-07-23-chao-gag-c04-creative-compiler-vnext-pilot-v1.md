## 一、试验结论

这次试验有价值，而且比继续给旧流程增加审稿席更接近真正的问题。

新方法没有把C04判成“全部重写”。它正确放行了当前稿已经成立的主要成果：

- 六百米天空铸环与四机首套接力；
- 断冠通过真实战斗学习完整组合，而不是“同一武器失效”；
- 米拉、艾达与黑城的关系战；
- 纪存留在万机馆B1，韩秀雅独自驾驶百相；
- 白鸢E03路线经过提案、编译、驾驶员接受和真实执行；
- 四条BODY路线的物理差分；
- 五话容量不均；
- 竖环终战的第二套合击；
- 当前稿没有回流已知的责任结算腔。

它也抓出两处此前四视角审查已经宣布通过、但实际仍存在的阻断项：

1. **实体U盾在同一时段拥有两个位置。**  
   物理板写七海随舰携带U盾；导演板和总纲却写同一枚旧U盾七年来一直插在铸环授权机里。授权戏本身可理解，但物件因果不成立。
2. **E04把两种敌人、两条欺骗链揉成了一个动作。**  
   断冠根据现实战场学习；白框根据上传画面复制。现稿写白鸢完成总图、分裂体转向、七海拔镜像，却没有说明三旗舰实际做了什么让断冠上当。切断白框镜像也不能自动欺骗断冠。

因此本轮裁决是：

> `C04_KEEP_AND_TARGETED_REPAIR`

C04无需整体推倒。先修两处上游阻断，再处理三项故事/玩法警告，重跑同一试验；通过后再拿C05回放。现在还不应把vNext直接迁移进正式Writing Skill。

## 二、这次究竟测试了什么

本轮测试的不是“文档有没有填满”，而是五项能力：

1. 能否只读取会让C04写错的事实，而不是吞入全部历史资产。
2. 能否区分世界机制、人物、因果、玩法、导演、对白与状态问题。
3. 能否让角色按有限认知和自身欲望检验大纲，而不是替作者证明大纲正确。
4. 能否把关键情节还原为玩家看得见的动作、执行者和状态变化。
5. 能否让真实坏例失败、真实好例通过，而不是一律报错或一律同意。

## 三、最小上下文编译结果

### 3.1 权威优先级

本轮没有使用“搜到什么就全部塞进去”的办法。来源按以下顺序裁决：

1. `V35-PRODUCTION-STATUS.md`：唯一生产状态。
2. C03期末继承包：C04开场前已经发生的Working事实。
3. 世界机制Working基线：只读取C04会碰到的规则。
4. 当前C04第四层五件套：本轮接受审查的Candidate事实。
5. C04 Current Canon Pack：只负责边界与旧机制禁入；被当前章包取代的精确细节不再采信。
6. 旧用户审稿与12项回归：只作坏例，不向当前剧情回灌。

这一步已经解决一个实际漂移：旧Skill/旧Pack仍残留过时话数或重写任务，而Production Status与当前章包已经是五话。编译器没有让旧快照覆盖现状。

### 3.2 上章不可逆输入

- 万机馆只能低速航行，仍需高负荷承力脊节。
- 馆守Z仍缺右臂。
- 纪存只显露过低功率机群辨认、同骨架记忆区分和巨构重心预感；没有已公开的万能导航能力。

- 白鸢必须获得L2，同时留下路线外流的后患。
- 玩家必须赢下铸环、制造能力、馆守Z牵引背架和一条BODY路线。

### 3.4 可以推进但不能提前结算

- 纪存可以享受巨体力量并主动要求再次测试，但不能揭晓完整机魂身世。
- 七海可以处理本地旧许可，不能提前完成后期公开决裂。
- 白鸢可以做一次既救人又外流的方法选择，不能提前成为直接改写现实的作者。
- 断冠可以成为长期宿敌，不能在本章解释全部裂星生态。

### 3.5 只允许预显影

- C05将启用的四副旧校准身体。
- 百相座舱后的实体副驾驶电脑。
- 军方对纪存握手与白鸢路线的下一轮测试。
- 索引前态只能保存结果，不得在C04人格化指挥。

### 3.6 玩家认知边界

玩家在C04应当知道：

- 机魂需要真实载体和维持设备，G.A.G.不提供能源和质量。
- 空白骨架能复制动作，不等于原主体活在里面。
- 白鸢的路线必须由工程人员和驾驶员变成行动。
- 断冠只会学习它实际看见的战场关系。
- 纪存能连接机体主动开放的局部视野，但不能替驾驶员行动。

玩家只需怀疑：

- 纪存为什么与多机体有这种异常适配。
- 七年前许可为何持续被使用。
- 谁在汇总白框、战斗与路线结果。

本章不应知道：

- 纪存完整身世；
- 索引完全体；
- C05百相副驾驶最终形成什么主体；
- 远星与终局根真相。

### 3.7 硬冲突

- 七海不得同时拥有“随身U盾”和“七年插在铸环里的同一枚U盾”。
- 韩秀雅不得同时位于主铸井与百相驾驶舱。
- 百相不得因感应纪存自行行动。
- 白鸢不得画出物理通路，也不得让画稿直接驱动机体。
- 断冠不得读取人物私事或白框后台数据。
- 万机馆、百相和潮墙不得无支点拖动六百米铸环。
- C04不得恢复十二个纪存、人格真假问答和纪存肉身进入百相等旧机制。

**诊断：**前史、欲望、控制权和画面证据均成立。这一段不需要再补身份解释。

### 5.1 两个阻断

#### B01 实体U盾位置冲突

证据：

- 物理板第14行：七海“携带”实体U盾；
- 总纲第184行：旧U盾仍插在本地密封槽；
- 导演板第42行：同样显示旧U盾仍在授权机。

推荐的最简单修法是：

1. 七海本人携带实体U盾；
2. 铸环机器只保存她七年前的电子签名、旧序列和被伪造的远程调用；
3. 她现场插入真实U盾，证明本人权限仍有效；
4. C04先拔掉后加军用支路，保留救援线；
5. U盾仍由七海带走，给C05的正式覆写与烧毁留出条件。

这比“同一枚U盾七年不拔”更符合常识，也保留用户已经认可的C05授权戏。正式修订前仍需核对C05现稿，避免提前消费烧毁动作。

#### B02 E04双对手诱饵缺执行链

现稿需要拆成两条同时发生、但输入不同的链：

```text
对白鸢/七海这一侧：
白鸢完成假总图
-> 白框远端继续接收
-> 七海拔掉实时镜像
-> 白框只留下冻结假图

对断冠这一侧：
三旗舰驾驶员接受假动作的前半段
-> 机体在现实战场短暂朝中央汇入
-> 断冠分裂体按真实视觉/传感转向
-> 驾驶员在杀局前各自脱离
-> 真撤离改用口述、本地信号和BODY路线继续
```

白鸢设计的是“可由人执行的假动作”，不是让地图骗过现实。七海切断的是白框的数据，不是断冠的眼睛。

### 5.2 三个警告

1. **BODY选择的人物冲突不足。**  
   韩秀雅明确主张HERO，但代表COMMON路线里缺少她意见落败后的反应、争执和主动承担。
2. **E05同时活跃的规则过多。**  
   三制动、三锁、四红标、BODY差分、万机馆菜单和第二套合击必须按阶段显隐；BODY差分应替换某一步，不再增加独立目标。
3. **C03入口钩子的状态变化不清。**  
   双时间戳和母版控制码可以只负责把队伍带到铸环；若本章不推进，就不要在章级对齐中暗示它们已经得到解决。也可在破晓给其中一条一个很小但真实的新读数。

另有两项进入下游而不阻断当前章纲：

- 技术名可以留在作者板，Reader不应连续使用“相位焊接、接口握手、感觉织机构、低位槽、稳定场阈值”解释场面。
- 圣斗士原句在情境里有效，但正式台本前要登记来源、用途、长度和只用一次的边界。

## 七、四视角影子审查

本轮没有调用彼此隔离的独立Agent，因此以下只能称为**单一上下文中的四视角影子审查**，不能冒充真正独立投票。

### 7.1 编剧/人物：`warn`

- 主因果、宿敌欲望和纪存力量欲成立。
- 米拉/艾达是完整关系事件，不只是IP标签。
- BODY选择对韩秀雅的反作用不足，重要立场落败得过轻。

最早根因：人物欲望没有进入选择后的动作。  
禁止补丁：给韩秀雅加一句“我尊重你的选择”。

### 7.2 机器人文化/游戏：`warn`

- 第一套精密组合、圣斗士式反制和第二套新组合形成清楚递进。
- 机体用自己的身体语法解决问题，且有永久收益。
- E05的规则总量可能让玩家只记得任务图标，忘记第二套合击的情绪。

最早根因：终战目标没有按玩家认知顺序显隐。  
禁止补丁：再加一段战中通讯解释六套机制。

### 7.3 导演/制作：`block`

- 尺寸、站位和大部分执行链已比旧稿稳定。
- U盾出现物件连续性冲突。
- E04诱饵缺少断冠可见的实体动作，当前画面无法证明它为何上当。

最早根因：状态账与场面执行链。  
禁止补丁：让七海或白鸢用台词告诉玩家“它已经被骗了”。

### 7.4 对白/关系/喜剧：`warn`

- 当前章纲已经清除用户反复指出的四类责任结算句式。
- 七海/白鸢机娘速写、米拉/艾达观景廊和破晓早餐都能承载生活与关系。
- 技术名若原样进入Reader和台本，会再次让人物像在念制作手册。

最早根因：作者板语言与玩家文本没有分层。  
禁止补丁：只替换几个语气词，保留整段技术解释。

### 7.5 联合裁决

一个有证据的导演/状态阻断不能被其他三席的通过项抵消。C04当前不能直接升格，但只需定点修订，不需要重写五话。

## 八、vNext方法从这次试验学到了什么

### 8.1 已被证明有效

- **Production Status优先**能阻止旧Skill和旧Pack反向覆盖当前五话结构。
- **场面合同**能抓到“大家都知道是什么意思，但玩家看不见执行链”的问题。
- **角色沙盘**能区分“机制成立”与“人物把重大失败轻轻放下”。
- **故障路由**把U盾送回状态/物理层，把E04诱饵送回因果/导演层，没有继续向对白塞解释。
- **真实回归**能够同时放行好例与阻断坏例。
- **取消长度比硬门**没有削弱审查质量。

### 8.2 仍未被证明

- 四席尚未由真正隔离的审稿上下文执行。
- Context Pack目前由主笔手工编译，尚未自动从Canon查询生成。
- 术语密度只能作提示，不能用简单词频宣布故事失败。
- 本轮只做审查回放，没有证明vNext从零写新章更省Token。
- 尚未证明修复C04后不会在C05再次出现同类问题。

### 8.3 对Phase A的修正

原计划先用C05回放。用户改用C04后，实践证明这是更好的顺序：

1. C04拥有旧版真实翻车样本和当前已修正版本，可同时测坏例与好例。
2. C04已经发现既有四视角审查漏掉的两个增量问题，说明新方法不是重复报告。
3. C04修复后可作为C05的可信输入，再测主体/载体、U盾和白鸢能力是否连续。

因此Phase A现在应写成：

```text
C04只审不改回放
-> 修复两个block
-> C04复跑
-> C05只审不改回放
-> 若两章均能抓错且不误伤
-> 再迁移Writing Skill与Episode Loop
```

## 十、章级预生产层增补

首轮回放仍是在C04总纲已经写成后分析场面，因此能够发现问题，却不能阻止问题诞生。针对这一缺口，现已补入[《章级预生产模型》](./2026-07-23-chao-gag-chapter-preproduction-model-v1.md)，并把C04反向编译为[《C04章级预生产模型试验》](./2026-07-23-chao-gag-c04-chapter-preproduction-pilot-v1.md)与[c04_chapter_preproduction_model_v1.tsv](../data/research/c04_chapter_preproduction_model_v1.tsv)。

新增层把发现时点前移：

- U盾在实体表中只能有一个位置，未统一便不能进入导演板；
- 白鸢路线、飞控编译、驾驶员执行与白框复制必须是四个不同环节；
- 断冠的现实传感与白框的上传镜像必须拥有两条不同欺骗链；
- E05所有大动作先进入动作词库，再按战斗阶段显隐；
- 多尺度、竖环和控制权先用低精度灰盒验证，不在Reader里补机械说明。

场面合同现新增`prefab_refs`，检查器会拒绝引用不存在的实体、机制、空间或动作。这样预生产模型不是写完便搁置的设定清单，而是导演板、战斗预案和关键场面的可追踪输入。
