# 《超GAG机器人大战》创作素材包深度补全 v1

> 状态：候选研究层，不直接修改现行剧情、参战名单、V35结构或美术硬锁。
>
> 用途：为逐话 Pipeline 提供可检索、可组合、可追溯来源的创作弹药，修复“表格很多但场面仍小、强IP只有三条、关系与喜剧反复用同一种动作”的问题。

## 一、这轮补的不是又一套配额

旧素材的主要问题不是绝对行数少，而是分布和结构不利于写戏：

1. 强识别IP常被平均压成三条，未展开人物关系、战斗形式、名场面、玩具生态和历史语境。
2. “引用锚点”很多，“一场戏如何起、如何翻、如何落在棋盘上”的中间层很薄。
3. 关系戏、喜剧、产业生态、科幻机制、分支和博物馆现实各自只有少数规则，容易反复抽到“留权限、改记录、少一格、等几秒”。
4. 来源以二手百科为主，精确事件可以查到，但不够支持结构、产业和现实边界判断。
5. 旧15章60话素材与V35十八章候选并存，研究层不应替任何一个版本提前排班。

因此本轮采用“不平均深挖”：高识别、高情绪、高机战转译价值的作品允许多条；轻喜、生态型作品可以只贡献喜剧、玩法或设计语法，不硬造悲剧。每条素材都要能回答“它怎样变成原创场面”，而不只是“它来自哪个作品”。

## 三、逐话调用方法

Pipeline不应把整套表一次塞进上下文。每话只按戏剧需求选：

1. 先定本话的人物欲望、战场困局和不可逆变化。
2. 从IP深挖表选一个主投射和零到两个副投射；没有合适的就明确跳过，不能为了配额硬贴。
3. 从战斗场面表选一个“中盘反转”或“终局动作”，再让棋盘机制承载它。
4. 关系、喜剧、产业、科幻、分支、美术、博物馆表按需各取零到两条，必须绑定到具体场面。
5. 在`source_absorption.tsv`记录选中的row id、出现在哪场、改变了什么状态；只出现在字段名里算未吸收。
6. 同一结构连续使用两话即进入重复检查。例如连续两话都用“拒绝按按钮”“延迟几十秒”“公开一份记录”，下一话必须换发动机。

## 四、原创化与短引用边界

- 原作事实、名场面和名台词是内部识别锚，不等于公开文本。
- 可以在剧情高度匹配时保留极短、广为流传的短句，但必须单独过法务/引用审查；默认仍以原创角色关系、原创机体机构和原创后果重写。
- 原创化不是把名词全部换掉。应保留玩家能识别的动作结构、情绪次序或镜头语法，再改变人物、理由、代价和结局。
- 不把所有原作都“纠正”为更正确的结局。好的IF应尊重原悲剧的重量，错过隐藏条件也要留下有尊严的另一种意义。

## 五、版本兼容

本素材层同时服务已确认的现行章节基线和V35候选压力板，但不把“18章/约82作者话槽”升格为Canon。表中使用的是剧情窗口、角色线和参战谱系，不固定某一话排班。正式逐话吸收时，由Episode Loop结合当时有效结构、package UID crosswalk和首登账本选择。

## 六、通过标准

补全素材不等于稿件自动变好。单话使用这些表后，至少应出现一种可见增益：

- 新的机体动作或战场局势，而非新名词；
- 人物关系发生误解、欲望暴露、决裂、救场或重新选择，而非好感加一；
- 玩家能识别的机器人动画快感、名场面结构或模玩生态笑点；
- 阵营因真实利益采取连续行动，而非排队发表立场；
- 科幻规则带来可玩的限制和代价；
- 开馆/修复/授权有常识尺度的公共后果。

如果只是让文稿多了几个row id、设定词或来源链接，仍判定为未吸收。
