# 《超GAG机器人大战》机器人文化素材库 v0.1

> 状态：研究素材，不是 canon，不约束现有设定。  
> 用途：给下一轮重构大纲、逐话卡、台本、机体设计、关卡和资产 brief 提供“可原创化”的机器人文化弹药。  
> 原则：内部可识别，外部必须原创；不直接使用原 IP 名称、原造型、原长台词、原歌词、原剧情截图。

## 0. 这份素材库解决什么问题

上一轮写 A5 时暴露出一个核心问题：我们知道“想要机器人文化感”，但每次真正写稿，容易只剩几种笼统标签：合体、重涂、勇者、战队、特摄、模玩槽点。标签能说明方向，但撑不起一整篇，更撑不起 60 话。

这份 v0.1 先不把现有 canon 当边界，而是反向从机器人动画、机战游戏、玩具模型、粉丝社群、商品生态里抽材料。每个材料都拆成四层：

1. **可识别记忆**：玩家一眼能 get 到的结构、场面、语气或文化经验。
2. **原创化方向**：变成《超GAG》自己的机体、人物关系、事件和道具。
3. **玩法承载**：不要只做台词彩蛋，要能变成战斗规则、地图机制、支援、改装、深潜或开馆玩法。
4. **避险边界**：不复刻具体造型、台词、商标、歌词和桥段镜头。

## 1. 参战机体/IP设定映射总原则

### 1.1 不做“仿作清单”，做“机器人文化谱系”

内部可以清楚知道某条线吸收了哪些 IP 经验，但游戏内不要把它写成“某某作品的改名版”。更好的做法是：

- 抽取一个机器人文化问题：为什么人要驾驶巨大的机器？为什么机器会回应？为什么合体需要喊出来？为什么玩具的重涂也会成为人格？
- 给它一个原创社会位置：博物馆展品、退役实机、军方量产、玩具锚件、作者废案、索引模板、远星误译。
- 再给它一个可玩的冲突：保护、修复、说得、拆件、护送、发布会反证、三方混战、深潜取证、开馆选择。

### 1.2 主线机体不能靠 EX 补数量

> v0.2 修正：本节原本使用篇级最低数，且把可识别机体压到个位数，这是错误口径。后续按 [v0.2外部调研增量版](./2026-07-02-chao-gag-robot-culture-material-library-v0.2-external-increment.md) 的话级密度标准执行：每话至少 2 台新机体/机体单位曝光，每话至少 1-2 个名场面/名台词/文化梗原创映射。

EX/隐藏关可以放“高难梗”和“完整隐藏机”，但玩家对机器人大战的期待，必须在主线里就被满足。当前执行标准见 v0.2，本稿不再作为机体/梗点密度依据。

### 1.3 一台机体要有四种价值

一台新机体加入素材库时，必须回答：

- **外观/谱系价值**：它让玩家想起哪类机器人文化？
- **剧情价值**：它让谁被迫选择、误会、背锅、告白、撤退或改变？
- **战斗价值**：它在格子上改变什么？移动、地形、射程、合体、支援、暴走、维修、护送、士气？
- **收藏/资产价值**：它是全量主力、支援 Cut-in、场景巨影、敌方模块、玩具锚件，还是 UI/展柜藏品？

## 3. 名台词、机甲文化梗、著名场景素材库

### 3.1 机战爽点型

| 记忆类型 | 原创化方向 | 可玩法化 |
| --- | --- | --- |
| 红色王牌比别人快 | 红色路线是敌方宣传算法，不是物理真理 | 红色敌机先手但冷却长；玩家用等待和诱导破局 |

| 记忆类型 | 原创化方向 | 可玩法化 |
| --- | --- | --- |
| 限定、再版、抽选 | 代哥/平台把机魂归档为稀缺商品权益 | 玩家可走正规流程、黑市、交换展品，不同方式留债 |

## 4. 机甲与机器人模玩圈生态、槽点库

### 4.1 产业和购买生态

- **限定与区域差异**：同一机体因渠道、活动、地区产生稀缺感。可写成代哥封存、白名单预约、开馆资格。
- **预订焦虑和黄牛**：玩家不是只想买便宜，而是怕错过。可写成“错过再版就失去修复机会”的剧情压力。
- **再版/复刻争议**：老玩家担心情怀被稀释，新玩家需要入口。可写成“开馆给谁看”的价值冲突。
- **版本命名泛滥**：Ver、Mark、Full、Special、Anniversary、Clear、Metallic。可写成索引把名字当战力。
- **评测与带货生态**：内容创作者影响购买和口碑。可写成模型街主播、展签争论、错误教程扩散。

### 4.2 产品设计槽点

- **全挂完全版病**：配件越多越完整，但机体本体被遮住。
- **尖刺和大背包过度设计**：视觉刺激强，姿态和可动被牺牲。
- **展示支架依赖**：离开支架就无法站稳，适合转成战场地形机制。
- **手雷化/掉件**：摆 Pose 时零件不断脱落，适合转成战斗中“过载掉件”。
- **变形复杂化**：完美变形追求导致结构脆弱、步骤冗长，适合变成限回合调试关。
- **合体越多越好病**：七机、八机、十五机合体看似豪华，实际上失去设计理由。可让敌方把“越多越伟大”误读成胜利模板。
- **透明件/电镀件/金属色限定**：好看但易脆、易刮、易氧化，适合作为“漂亮但不可长期战斗”的资产。

### 4.3 拼装与改造生态

- **水口、白化、打磨**：模型手工的基本烦恼，也是角色劳动感来源。
- **分色贴纸和水贴**：视觉完成度与耐心之间的冲突。
- **补土、刻线、喷涂、旧化**：不是单纯美化，而是玩家把时间留在物件上。
- **改件、树脂、3D打印**：灰色地带，有创作自由也有版权/安全/耐久问题。
- **说明书和错装**：错装有时是事故，有时变成玩家自己的版本。
- **断件修复**：最适合和万机馆“模型锚件 + 实机接口”连接。

### 4.4 收藏与社群生态

- **堆盒和未拼积压**：买下的是未来的时间。
- **柜子空间和搬家**：收藏是现实重量，不是抽象热爱。
- **晒柜、摆拍、摄影棚**：玩家给模型创造舞台。
- **直做派、改造派、考证派、把玩派**：不同爱好者会互相误解。
- **原典厨、错版厨、童年党、性能党**：可以转成万机馆内部路线冲突。
- **盗版/KO/第三方件争议**：不能写成简单正邪，应该写成可及性、创作自由、质量和权益的纠缠。
- **儿童玩具与成人收藏并存**：机器人文化同时属于孩子和成年人，但成人向卖相必须隔离儿童角色。

## 5. 活用方法：怎么把素材写成《超GAG》的戏

### 方法一：交织

不要一话只用一个梗。比如“红色更快”可以和“限定商品”“敌方王牌”“重涂误认”交织：

- 敌方红色重涂车先手极快。
- 代哥系统把它标为“限定优先回收品”。
- 玩家发现它快不是因为红，而是因为它没有救援记忆，省掉了等待伤员的逻辑。

这样梗点、商品生态和主题同时成立。

### 方法二：融合

把多个 IP 记忆融合成一个原创机体群，但每个来源必须各有功能，不要糊成标签。

例：星火车队可以承载变形生命和救援车队，但不要同时吞掉战队、勇者和特摄。战队、勇者、特摄应以独立支援、残响、场景机体围绕它发生共鸣。

### 方法三：篡改

让反派、索引、远星或代哥误读名场面。

- 索引把“全员支援”误读成所有单位统一口号。
- 远星把“合体”误译成个体权利消失。
- 代哥把“限定”解释为保护资产，玩家要证明公开展示也是保护。

篡改的好处是：它既能玩梗，又能制造主线冲突。

### 方法四：影射

不直接复刻名场面，而是换物件、换关系、换胜利条件。

- 不写某句名台词，写“角色差点说出那句人人都知道的话，但停住了，因为对面不是原作里的那个人”。
- 不复刻红色机体造型，只写红色路线、先手权、撤退烟和压迫感。
- 不复刻五色战队 Pose，只写观众喊名会改变巨神站位。

### 方法五：吐槽

吐槽要有爱。目标不是嘲笑玩家，而是吐槽商品逻辑、系统误读和创作疲惫。

正确方向：

- “配件多”不是错；“配件多到机体忘了为什么需要身体”才是错。
- “限定”不是错；“把热爱变成错过惩罚”才是错。
- “重涂”不是错；“只承认标签不承认磨损和使用记忆”才是错。

### 方法六：反证

让玩家用具体物件反驳宏大模板。

- 维修单反驳“它只是商品”。
- 错版说明书反驳“原典只有一个正确答案”。
- 掉漆和水口反驳“完美展示才有价值”。
- 旧回信反驳“远星现在才理解我们”。

### 方法七：玩法化

每个梗点优先转成玩家要做的事。

| 梗点 | 玩法化方式 |
| --- | --- |
| 合体口号 | 站位、士气、许可、维修状态四条件 |
| 红色更快 | 敌方先手压力，玩家用诱导和等待破局 |
| 歌声停火 | 一回合禁止攻击，转为救援/说得/移动 |
| 全挂完全版 | 拆模块、断支架、释放本体 |
| 同模重涂 | 通过痕迹识别真假，不靠图标 |
| 迟到回信 | 信息顺序错乱，玩家选择公开顺序 |

### 方法八：情绪物件三次使用

一个物件至少三次出现：

1. 第一次当笑点或生活细节。
2. 第二次在战斗中变成规则。
3. 第三次在情绪高潮回收。

例：一张“巡游结束后再修门”的维修单，第一次像小笑话，第二次成为医疗车拒绝被拆成救援包的证据，第三次在终局开馆时作为展签出现。

### 方法九：成人关系卖相嵌入机器人语汇

成人向不是裸露描写，而是危险亲密、权限、距离和误会。适合用：

- 战损修复舱、贴身扫描、权限锁、同步舱过热、共用终端密钥。
- 驾驶服拉链、领口整理、手指停在封存键、低声倒数、战后湿发。
- 三角误会：七海给纪存流程缝隙，白鸢把它画进分镜；白鸢替纪存改危险记录，七海知道但不揭穿。

禁区：儿童角色完全隔离，不做暧昧、挑逗和性隐喻。

## 7. 需要进一步调研的空白

1. **中文机器人童年谱系**：国产动画、引进译制、电视台播放记忆、玩具摊和盗版碟生态还可以单独做一轮。
2. **女性向/乙女向机器人文化**：例如歌剧、驾驶员关系、舞台、偶像和机甲的交集，现在素材还偏男性模型玩家。
3. **现实机器人产业**：工业机器人、服务机器人、救灾机器人、军用无人系统、仿生机器人，后续可以加强陆衡线。
4. **模型圈现实访谈感**：可以进一步收集玩家真实用语、柜子照片、堆盒心理、改造失败故事，用来提升台词自然度。
5. **版权避险清单**：后续若把素材库进入正式设定，需要单独做一份“不能出现的直接引用、视觉特征、商标语汇”表。
