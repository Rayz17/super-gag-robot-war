## 1. 话级密度新标准

v0.1 还在用“篇级个位数支援/敌方/场景机体”的保守口径，这会直接导致机器人大战感不足。v0.2 改成话级标准。

### 1.1 每话至少 2 台新机体/机体单位曝光

这里的“新”不是只能指完整入队主力，但必须是玩家能识别、能记住、能参与战斗或剧情判断的机体对象。最低要求：

- **每话至少 2 台新机体/机体单位曝光**。
- 其中 **至少 1 台必须进入战斗规则**，不能只是背景图。
- 另一台可以是敌方单位、临时支援、重涂变体、场景巨机、机体模块、维修残躯、展柜锚件或深潜发现物，但必须有名字、谱系和用途。
- 重点话、篇章高潮、开馆战、发布会战、终局战不能只满足最低线，应当达到 **3-8 台新机体/单位/模块同场**。
- 老机体再次登场不算“新”，除非出现新形态、新武装、新驾驶关系、新损伤状态、新合体位置或新玩法功能。

如果主线按 60 话估算，最低就是 120 次机体曝光。它们不全是完整可操作主力，但故事层必须给玩家持续“又看到新机器人”的满足感。真正完整参战、可改装、可升级的数量另行筛选；素材库先不替制作预算缩小想象力。

### 1.2 每话至少 1-2 个名场面/名台词/文化梗映射

机体密度上去后，梗点密度也必须跟上：

- **每话至少 1 个主名场面映射**，最好再有 1 个副映射。
- 如果一话只有一个大情节，它也应当揉合多个可识别压力：例如“第六人加入 + 新武装销售压力 + 合体个体消失”可以合成一场队伍破裂战。
- 重点话应有 **3-5 个名场面/名台词/文化梗互相缠绕**，但不能堆成引用清单。
- 台词不直接改写原句，优先复刻“压力结构”：谁被逼、谁误读、谁沉默、谁救场、玩家要付什么战术代价。
- 每个名场面映射必须至少进入一个层面：战斗规则、地图结构、人物选择、情绪物件、敌方学习、分支债务。

### 1.3 篇级容量改成乘法，而不是平均数

一个 4 话小篇最低应该有：

- 8 台以上新机体/机体单位曝光。
- 4-8 个名场面/梗点映射。
- 1 个封面级主机体或机体群。
- 1 个敌方会逐话学习并升级的机体/Boss链。
- 1 个模玩/商品/社群生态问题贯穿，并在高潮变成战斗规则。

一个 6-8 话大篇，比如星火、白名单、远星、终局，应当有：

- 16-30 台机体/单位/模块曝光。
- 10-20 个名场面/梗点映射。
- 至少 2 个封面级机体群，或者 1 个主机体群 + 1 个强敌/Boss进化链 + 多个临时支援谱系。
- 至少 1 场“多个名场面揉成一个情节”的大场面，而不是每个梗排队出现。

### 1.4 资产分层不等于剧情缩水

为了避免误会：话级密度是写作和策划密度，不是要求每话新增两台全量高成本机体。资产可分层：

| 层级 | 作用 | 能否计入每话新机体 |
| --- | --- | --- |
| 完整参战机体 | 可入队、升级、改装、出击 | 可以 |
| 临时支援参战 | 本话可行动或提供支援，不完整入队 | 可以 |
| 敌方单位/Boss模块 | 有战斗规则、弱点、行动模式 | 可以 |
| 新形态/新武装/重涂变体 | 改变战斗或身份判断 | 可以 |
| 场景机体/巨影/工务机 | 改变地图、胜败条件或演出 | 可以 |
| 展柜锚件/残骸/深潜发现物 | 必须触发修复、改装、线索或后续解锁 | 条件计入 |
| 纯背景海报/路人展品 | 没有剧情和玩法功能 | 不计入 |

也就是说，故事要大，资产可以聪明。

## 2. 外部IP/机器人作品增量池

下面不是“要照搬的 IP”，而是可被拆成原创机体、人物关系、关卡和槽点的素材。

### 2.1 超级机器人：从“热血合体”扩展到“商品、伦理、灾难”

新增重点：

- **Zambot 3 型悲剧超级系**：超级机器人不一定是爽文，也可以是“为了保护人类却被人类恐惧”。适合写万机馆被市民驱逐、馆守Z被要求离城。
- **Daitarn 3 / Trider G7 型企业/少年社长超级系**：把“公司拥有超级机器人”变成代哥、模型厂、企业赞助与正义的复杂关系。
- **Dancouga / Gravion 型多兽、多机完全合体**：补强“多机合体不是越多越好”，可写成机体人格被大型合体吞掉。
- **Giant Robo 型复古史诗**：巨大机器人、秘密结社、父辈遗产和毁灭按钮，可给“万机馆馆长遗留命令”更厚的复古悲壮感。
- **Gaiking / Danguard / God Sigma 型太空超级系**：补足外太空、远星、宇宙舰队和超级系之间的连接。

### 2.2 真实系：从高达扩展到“劳动、雇佣、政治、后勤”

新增重点：

- **Dougram 型独立战争/殖民地政治**：真实系不仅是战场，还可以是自治、宣传、独立和地面泥泞。适合给远星共同体和废土城邦更政治化的机器人战争。
- **Xabungle 型荒野交易和破规则**：荒野机甲、二手市场、盗抢和规则被打破。适合模型街、废土商队、旧件黑市。
- **L-Gaim / Dragonar 型王朝和新兵器换代**：旧王朝机体与新量产技术共存，适合原典派和新玩家之间的代际冲突。
- **Fafner 型岛屿共同体**：驾驶不是个人英雄主义，而是整个社区把孩子送上前线的痛。可补“保护小孩”过多的问题：重点不是保护儿童，而是质问共同体如何消费驾驶员。
- **Eureka Seven / RahXephon 型恋爱、音乐、世界调律**：补充白鸢/七海/纪存关系线的“感情真的能改变机体和世界频率”。

### 2.3 变形与玩具生命：从“车队”扩展到“模具家族、镜像、商品人格”

新增重点：

- **Seeker 式同模人格群**：同一个基础模具通过配色、性格和剧情变成多名高人气角色。可转成“同模不是偷懒，是商品、角色和玩家投射共同塑形”。
- **Combiner Wars / Scramble City 型通用接口合体**：肢体可互换的玩具逻辑很适合转成战斗系统：强兼容带来个体消失风险。
- **Headmasters / Targetmasters / Minicons 型小伙伴接口**：小件不只是配件，而是驾驶员、头部、武器、钥匙。能解释缩尺锚件如何影响巨大机体。
- **Beast Wars 型野兽机械与CG时代记忆**：补足兽型机体和动画制作技术变迁。
- **Shellforming / Partsforming / Fake Parts 争议**：变形玩具圈非常有用的槽点，可以转成“完美变形”和“看起来像变形”的身份冲突。

### 2.4 战队、特摄与合体玩具：从“五色”扩展到“摄影棚、皮套、玩具销售周期”

新增重点：

- **追加战士/第六人传统**：第六人不是简单加人，而是中途打破原队伍关系。可写成某台机体加入后反而破坏原五机默契。
- **季度新武装/新萝卜销售节奏**：每隔一段时间出现新装备，剧中解释常常牵强。可转成索引/代哥逼团队不断换“完全版”。
- **怪人巨大化流程**：巨大化不是一招，而是从小队战切换到巨大战。可明确做成双阶段战斗。
- **微缩城市和摄影棚**：特摄不是低成本笑话，而是一套观众和镜头共同成立的美学。可做成地图尺度玩法。
- **超级战队 VS 电影式全员同框**：终局可以借鉴“跨世代全员支援”，但原创化为万机馆各展区开馆回应。

### 2.5 模型/玩具产品线本身也可以成为“参战谱系”

新增重点：

- **Chogokin / Soul of Chogokin 型合金重量感**：重量、冷金属、关节棘轮、展示底座，本身就是一种机器人文化体验。
- **Gunpla Grade 文化**：HG/RG/MG/PG/SD/EG 不只是规格，也代表价格、时间、精密度、门槛和玩家身份。
- **Metal Build / Robot Spirits / SMP / MODEROID / 30MM 型产品哲学差异**：成品、拼装、食玩、通用自组，各有生态。可转成游戏里的不同机体获取/维护方式。
- **Garage Kit / Wonder Festival 型一日版权与原型文化**：非常适合原型工房、废案角色、灰模、模型师势力。
- **Third-party add-on / conversion kit 型灰区生态**：改件、扩展包、非官方武器能救旧机，也能引发安全、版权和伦理问题。

## 3. 名台词、名场面、机甲文化梗增量

以下不是直接引用台词，而是把玩家熟悉的“场面结构”拆出来。

### 3.0 名台词短锚点库

v0.2 之前漏掉了“名台词”本身，这是错误。后续使用规则：

- 名台词可以作为**内部短锚点**记录，帮助编剧房识别玩家记忆。
- 游戏内不能直接照搬原句、原译文、歌词或完整口号，必须改成原创人物在本作处境下会说的话。
- 每条名台词进入逐话卡时，必须同时写清：谁差点说出它、为什么不能照说、改写后带来什么战斗或关系后果。
- 详见 `robot_culture_external_quote_anchor_expansion_v0_2.tsv`。这张表是 v0.2 的台词素材入口，不是可直接入台本台词表。

v0.2.1 已增强中文译制、燃系和舞台感锚点，并补了 `robot_culture_quote_roster_coverage_v0_2.tsv`，用于检查主要参战谱系是否都有可调用台词素材。新增重点包括“我来组成头部”、中文变形金刚译制口号、勇者系合体审批、魔神英雄传/光能使者/宇宙骑士/洛洛历险记/超兽武装/铁甲小宝/SD高达等中文童年入口，以及华击团、灯光、幕布等舞台型锚点。

示例：

| 短锚点 | 不应怎么用 | 应怎么转 |
| --- | --- | --- |
| 红色三倍速 | 直接写红机速度+3 | 写成“红色机体省略了等待伤员的逻辑，所以看起来更快” |
| 不要逃 | 让少年复读名句 | 让玩家选择是否拖延出击，以战术代价换角色意志 |
| 直到万众一心 | 直接当终局口号 | 写成每个展区用不同声音回应，拒绝统一口号 |

### 3.1 可以成为章节发动机的名场面

| 外部记忆 | 新增价值 | 原创化场面 |
| --- | --- | --- |
| “被市民憎恨的守护机器人” | 超级系不只是被崇拜，也会被驱逐 | 万机馆救城后被要求离开，因为它太像下一场灾难 |
| “少年社长/企业超级机器人” | 把正义和企业资产绑在一起 | 代哥提出赞助万机馆，但要拿走开馆命名权 |
| “第六人加入战队” | 关系结构被打破 | 新机体强到能救场，却让原五机觉得自己只是零件 |
| “组合金属玩具的重量” | 玩具体验转成叙事 | 某台旧合金机太重，展舰移动时必须有人亲手扶住 |
| “完美变形争议” | 技术理想 vs 把玩体验 | 一台机体坚持不用替换件，结果在战场上变形到一半卡住 |
| “追加装备季节性登场” | 商品节奏压迫剧情 | 敌方每两话强迫一台机体装新包，队友开始害怕自己原形不够卖 |
| “最终话全员同框” | 终局爽点 | 不是所有人喊同一句，而是每个展区用自己的语言回应 |
| “战争结束后的维修账单” | 真实系生活感 | 战后结算不是胜利音乐，而是桥梁、路灯、避难所门禁都要修 |

### 3.2 可以成为小桥段但不能小口径的梗

- **变形玩具的假胸/假车头**：可转成索引制造“看起来像真实变形”的伪机体，玩家用内部结构识破。
- **零件替换比变形还多**：可做成战斗中“替换件占行动点”的惩罚。
- **食玩补色贴纸**：可写成便宜小机体靠玩家耐心获得真正表情。
- **合金脚冷冰冰**：可做成唐胶或小满摸到旧合金机时的生活细节，之后回收为重量压住封存闸。
- **旧玩具松关节**：战斗中老机体会“膝盖软”，但某回合靠这个意外躲过攻击。
- **说明书漫画/设定小栏**：深潜时不是查资料，而是进入说明书边栏里被删掉的小故事。
- **贴纸翻译错误**：错贴的外文编号成为远星误读入口。
- **变形后剩一堆不用的替换件**：这些替换件被G.A.G.活化，问“那我算身体吗？”

## 4. 模玩圈生态增量

v0.1 写了限定、全挂、重涂、水口、堆盒，但不够细。v0.2 要把“模玩圈”写成有真实生活摩擦的生态。

### 4.1 产品和设计槽点

- **关节松紧差异**：同一套件有的紧到白化，有的松到站不住。可转成“同一量产模板也有个体命运”。
- **棘轮关节爽感**：合金玩具每一格卡位都有声音和重量。可转成战舰格纳库的机械仪式感。
- **ABS/PS材料兼容问题**：涂装、渗线、应力开裂。可转成“漂亮改装伤到旧身体”。
- **手型地狱**：握拳、平手、持枪手、造型手太多。可转成深潜小件管理玩法。
- **武器握不住**：装备很帅但手拿不稳。可转成战斗中“高火力武器需要支撑动作”。
- **腰裙甲挡腿**：机设外观和可动冲突。可转成“华丽外装降低机动”。
- **脚踝接地不足**：站姿不稳。可转成地形适应。
- **变形刮漆**：每次变形都损耗外观。可转成“每次形态切换都会留下战损痕迹”。
- **电镀掉漆**：漂亮但脆。可转成限定外装的单次高光。
- **说明书漏标/错误编号**：可转成错版路线入口。

### 4.2 收藏和生活生态

- **柜子不是无限空间**：玩家必须选择展示谁。可转成万机馆展陈层的路线选择。
- **搬家是收藏灾难**：盒子、泡棉、断件、遗失件。可转成展舰起航前的撤离关。
- **防尘、避光、湿度**：收藏需要照料。可转成开馆维护成本。
- **家人/伴侣对收藏的态度**：不一定是反对，也可能是“我不懂但我给你留一格柜子”。这能写出成人生活感。
- **旧玩具气味和塑料老化**：很有情绪，不要只写视觉。
- **二手交易的前主人痕迹**：贴纸歪、名字写在盒底、少一只手。可直接变成机魂线索。

### 4.3 社群争议

- **直做是否低级**：不能站队。直做派有“尊重原套件”的美学。
- **重涂是不是骗钱**：不能只吐槽。重涂也创造角色人格和玩家情感。
- **第三方件是否破坏原设计**：可以写成“救了旧机，也让法务和安全负责人头痛”。
- **考证派是否扫兴**：好的考证能救剧情，例如识破伪造展品。
- **强度党是否没有爱**：性能党也可能是因为小时候买不起，只能在游戏里把喜欢的机体练到最强。
- **女玩家/关系厨/舞台厨被边缘化**：机器人文化不只有机设考证和拼装技术，驾驶员关系、舞台、歌曲、服装、声优、同人也是真实入口。
- **盗版童年**：很多人的入门可能来自盗版碟、错译名、摊位玩具。不能简单道德判死，应写成“资源不平等下的热爱入口”。

## 5. 真正可用的原创化方法增量

### 5.1 “先做外部梗，再做项目翻译”

错误方法：看到“红色更快三倍”，直接写一台红色敌机跑得快。  
正确方法：

1. 先问原梗为什么好笑：颜色、性能迷信、宿敌魅力、玩家共同记忆。
2. 再问它在本作攻击什么问题：商品标签替代真实记忆。
3. 最后转成玩法：红色机体先手，但因为它省略救援等待逻辑；玩家用一张维修单证明真正的星火车不会这样跑。

### 5.2 “商品病要变成身体病”

模玩槽点不能停在嘴炮。全挂、支架、尖刺、替换件、重涂、透明件都要变成身体问题：

- 背包遮住门。
- 支架限制移动。
- 尖刺伤到救援对象。
- 替换件问自己算不算身体。
- 重涂色抢走身份。
- 透明件漂亮但碎裂后会割断线路。

### 5.3 “社群争议要让双方都说得通”

写原典厨、强度党、重涂党、盗版童年、第三方件玩家时，不能把一边写成坏人。每一方都要有一条能让玩家沉默一下的理由。

### 5.4 “擦边也可以从玩具/机体语汇来”

成人关系可以借机器人语汇增强，不必脱离题材：

- 同步舱过热。
- 贴身扫描。
- 维修舱换装遮挡。
- 权限钥匙共用。
- 驾驶服锁扣卡住。
- 战损后手指检查接口。

关键是：它要改变支援、权限、误会、Cut-in 或战斗规则，不只是卖相。

### 5.5 “名场面不要复刻结论，要复刻压力”

例如“少年被迫驾驶”的重点不是他说了某句台词，而是：

- 他没有选择。
- 成年人也知道不该这样。
- 战场正在逼他。
- 玩家如果拖延，会付出更高战术代价。

原创化时保留这个压力，不保留原句。

## 7. 后续建议

下一步不要立刻把 v0.2 全量塞进大纲。建议先做一个“筛选会”：

1. 从 `external_ip_expansion` 里选 40-60 个必须进入主线或临时支援的外部谱系。
2. 从 `external_scene_gag_expansion` 里选 80-120 个能变成话卡或关卡机制的名场面/梗点。
3. 从 `external_model_ecology` 里选 40-60 个最像目标玩家真实生活的模玩生态。
4. 再按“每话至少 2 台新机体/单位、每话至少 1-2 个名场面映射”映射回 15篇60话，检查每话是否真的比旧稿更机器人、更有戏、更有机体。
