# 05 证明测试协议：Gate A-D 执行细则与熔断规则

> Status: `candidate_research / fable_root_review_phase2 / protocol`
>
> 日期：2026-08-16
>
> 原则：处方靠样稿和盲比证伪，不靠自述。所有裁决与用户原话当日回写品味账本；所有预注册预测在 Gate B 后逐条回验并公开结果。

## 一、Gate A：章级创意证明（产物 = `06-C04-three-story-options.md`）

- **输入**：L3 C04 职责句与 C03 验收出口、委托书七项保留/迁移义务、04号文件第七节约束（禁环、极点分配、指纹四列互异）、未来峰值预留清单（索琳公开、C14 坠环、C20 全相环、万机馆暴走/变形、分舰、牺牲语法、远星回应——三案均不得提前消费）。
- **产物格式**：每案一页，只写七栏——白话发动机 / 人物欲望 / 主要场面 / 一个PV级画面 / 玩家主要动作 / 章末不可逆结果 / 制作风险；另附两张登记表：七项义务映射表、指纹四列自查表（含升级理由栏）。
- **不做**：不写 Reader、不写对白、不做预生产、不画分镜。
- **预算**：主要调用 ≤5 次。
- **P3 停点决策卡**：用户只答三题——选一案 / 指定两案功能融合 / 全部否决（须给一句方向性理由，直接触发方案 C 的 L3 复审）。

## 二、Gate B：单话短样证明

### 2.1 生产步骤（按 03号文件 B 方案流程）

1. 选中案 → 一页单话场面链（E01）：场序、每场一个关键变化、每场「非机敏位」指定（RC8）、字数带。
2. 第一完整场短样 1500-2500 字。主笔简报只含：选定案、场面链、活跃人物正面模型、C03 验收出口摘要、已准入素材；不含任何审稿史、负面案例、玩法字段。
3. 预算：场面链 1＋短样 1＋重写储备 1 ≤3 次；全 Gate ≤10 次。

### 2.2 隔离审查（先于用户）

- **冷读席**（独立子代理）：输入=短样全文＋玩家已知前情五句＋品味账本用户原话全集（校准集）。产出顺序固定：五句白话复述 → 「想不想读下一场」二值 → 结论（`PASS_FOR_USER_READ / REWRITE_ONCE / NOT_WORTH_TELLING`）→ 根因。禁止读取案文件、场面链、作者意图。
- **机战/游戏席**（独立子代理，design 视野）：机体是否在演戏、动作量纲、玩法可派生性；不与冷读席共享回执。
- **硬熔断自检**（任一命中即回主笔重写一次，不送用户）：复述与文本实际事件偏差；隐名台词认不出说话人；机体动作可换成人类而故事不变；单场新造术语>1；字数带超限 ±30%。

### 2.3 盲比包组装与 P4 停点

- **构成**：新短样＋两段基线段落（同场面类型，从 C01/C03 摘取；若新样为首战场，配 C01 广场首战段＋C03 社勇王合体段），三段统一去标题、去章节号、去哈希，随机排序标记甲/乙/丙。组装由非主笔完成，映射表密封在 `gate-b/` 子目录。
- **用户裁决单**（约25分钟）：三段各读→「最想继续读下去的一段」单选→三段排序→自由评语（原话入品味账本）。
- **判定**：新样被排第一＝明显胜过，进 Gate C；排第二＝第一次失败，回 Gate A 在剩余两案中换案重走 2.1-2.3；排第三或用户评语明确否定＝直接计为一次失败并同样换案。**累计两败即熔断**：停止扩写，产出《当前模型能力上限报告》（含预测回验表、成本账、失败对照包），不进 Gate C/D。
- **成本熔断**：单次尝试超 10 次主要调用 50% 仍未过隔离审查，视同一败。

### 2.4 预注册预测回验（Gate B 结束时逐条公布）

| 预测（源自02号文件） | 回验方法 |
| --- | --- |
| RC1：用户参与选案后，短样首次盲比进入前二的概率显著高于历史（历史内部稿 0/6 过用户门） | P4 排序结果 |
| RC2：过指纹门的案不再触发「似曾相识」类评语 | 用户自由评语关键词 |
| RC3：冷读席（校准集加持）与用户裁决方向一致 | 冷读结论 vs P4 结果 |
| RC6：预算内短样不被判「薄/失去因果」 | 用户评语与复述完整度 |
| RC8：隐名测试通过后，用户不再出现「装腔/都一个味」类评语 | 用户评语 |

## 三、Gate C：小规模回溯证明

- **目标段（预定，待 P1 问3 确认）**：C02E05「多机分工稳环救援」段——三症并发样本（分工清单化、浓度超载、全员机敏腔），且属最弱章的代表性段落；明确不选软柿子（不选已被公认最强的 E03 开柜段）。
- **步骤**：按 B 方案重写该段为 Candidate（不动现行验收稿）；同规格盲比（新旧两段匿名乱序）；P5 用户裁决。
- **附带**：C02 全章的标记/资料卡剥离方案（利用 effect-tests 既有纯剧情候补）作为 Gate D 的选项材料，不在 Gate C 内执行。
- **预算**：≤8 次主要调用。

## 四、Gate D：C01-C05 Candidate 范围决策（P6 停点）

用户三选一（决策卡一页）：

1. 定点重写 C01-C03 已登记弱段＋按选定案重建 C04，再建 C05。
2. C01-C03 整章 Candidate 重写（C02 优先）＋重建 C04-C05。
3. 先迁移 L1-L4 局部（方案 C 范围）＋全剧母盘极点标注，再重写 C01-C05。

执行规则不变：全部新稿入 `research/2026-08-15-fable-story-method-root-review/candidates/` 独立目录；现行验收稿、Canon、Story Chain 一字不动；任何晋升由用户逐项批准后按正式迁移流程另行执行。

## 五、记录纪律

- 每个 Gate 结束：品味账本回写（用户原话+推断边界）、成本账（实际调用数 vs 预算）、覆盖账增量。
- 每次熔断：失败对照包（原稿+判决+根因归位）存档，禁止静默重试。
- 本协议自身可被 P2 修订；修订记录附于本文件末尾。
