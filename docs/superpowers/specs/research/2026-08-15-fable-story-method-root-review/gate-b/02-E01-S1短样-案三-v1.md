# C04E01-S1《先到的客人》短样

> Status: `candidate_scene_draft_v1 / for_isolated_review_and_blind_compare / not_a_reader`

在看见天空铸环之前，先听见的是锤声。

不是警报，不是炮，是一记一记隔着云层传上来的重锤，慢，沉，中间夹着更小的锤子七七八八地跟。万机馆穿出云底时，纪存靠着前厅舷窗，第一眼没找到那座传说中铸过天穹环部件的工房——他在找一座巨大的建筑，而山麓上摊开的是一整片镇子。

三层石坪沿山脚铺开，像给巨人用的晒谷场。最下面一层晒的真是机件：肩甲挨着肩甲、小臂挨着小臂，按尺寸排开，油布掀了一半。中间一层立着工棚和吊架，几台起重机的长臂全朝同一个方向低着头。最上层是一排黑瓦长屋，屋脊压得很低，看不出里面有多深。

锤声就是从那儿来的。打铁的没有停工。

“还在开工。”兜灯在他旁边说，“打仗打成这样还开工，说明炉子不能停。”

“炉子不能停是什么意思？”

“意思是他们比我们急。”

坪外的战斗这时才进入视野。

十几具灰白色的机体正沿着进山道往石坪上推。它们没有完成：有的没装头，有的右臂只有骨架，胸口的舱盖用临时板钉着。可它们走得极齐，齐得不像一支队伍，像同一具身体被复印了十几份——抬脚是同一拍，落脚是同一拍，连被打偏之后回正的角度都一样。

挡在它们前面的是三台伤员。

一台四十多米的白色巨机只挂着左右两面大盾，正中间空着一块，两面盾斜插在道口，像两扇没上完漆的闸门。一台背着绞盘的机体把钢索抛出去，缠住最前面那具灰白躯体的脚踝，绞盘转得冒烟——那不是它自己的绞盘，焊口还是新的。第三台最高，六十米上下，只用一侧肩膀发力，把撞上来的两具躯体横着推下路基；它另一侧的手臂锁在胸前，锁扣上贴着一张纸，写着“待修，勿动”。

“心墙、岛卫、潮墙。”豪司在社勇王驾驶舱里念出三个名字，声音越念越高，“求援画面里那三台！它们都还没修好啊，喂——”

他话没说完，社勇王已经落进石坪。豪司盯上了那排灰白躯体里最大的一具，金色巨锤抡起来就要冲。

社勇王自己停了脚。

“干嘛？”豪司拽操纵杆，“就是它们在打工房！”

“看脚。”社勇王说。

那具最大的躯体正抬脚跨上石坪，膝弯里露出一截没接完的液压管，管口用布条扎着。布条是新扎的，扎法很仔细，是修理的人怕它漏油、想让它多撑几天的那种扎法。

“它们是这儿的。”社勇王把巨锤放低，“是被人拿线吊着的自己人。”

纪存在舰桥上听见这句话的时候，正在做同一个判断。

他从穿云开始就在听。那十几具齐步走的躯体，安静得可怕——不是没有声音，是没有里面的声音，像十几间开着灯却没人住的屋子。真正的声音在别处：黑瓦长屋的方向，很深，隔着石头和炉火，有人在数数。

一，二，三，四，五，六，七。

停一下。

又从一开始。

“万机馆。”一个女人的声音切进公共频道，不问好，不核身份，“你们谁是能听的那位？”

“我。”纪存说，“长屋底下有人在数数，数到七就重来。外面这些走路的，里面是空的。”

频道那头静了半秒。

“行，是你了。”她说，“外面这批是我们自己的待身骨架，三天前被人远程点了名，点名用的名单不该在任何外人手里。库里那七个才是活的。我叫韩秀雅，铸环原型工房。现在，先帮我把这批空身子拦下来——别拆。每一具我们都还要用。”

“不拆怎么拦？”豪司在频道里问。

“你们不是有会摔跤的吗？”

无牌一号和旧拳王从万机馆舷侧跃下石坪的时候，打铁的锤声还是没停。

两台拳机没有出重拳。旧拳王贴上最前排，用肩膀把一具无头躯体顶出队列，顺势别住它的膝弯，让它自己坐倒在路基上；无牌一号学得很快，接住第二具的手腕，转身，背摔，落地前左臂垫了一下，让那具没装完的胸口朝了天。心墙的两面盾趁机往里收，把进山道夹成一条窄缝；岛卫的钢索一根接一根，专捆脚踝；潮墙用那一侧能动的肩膀，把队列后半截整个别进了排水沟。

齐步走的队伍被拆成了十几个各自躺倒的零件。它们躺在地上还在动，同一拍地蹬腿，同一拍地回正，像一排上了发条忘了关的玩具。

兜灯看着这一幕，半天说了一句：“谁干的这事，缺德。”

先遣的分裂体是在这时候退的。

黑色的碎块从工棚顶上、吊架背面撤出来，退得干脆，没有恋战。纪存已经在防它们临走毁工位——上一座城的敌人就是这么干的。可这批碎块路过最下层石坪时，忽然齐齐停了一拍。

然后其中三块合起来，抱走了一具躺倒的灰白躯体。

不是拖，不是砸。是抱。三块碎片分别垫在那具躯体的肩、腰、腿下面，像搬一件怕磕的展品，贴着山道的阴影，几步就出了坪。

豪司愣在原地：“它、它们搬走一个干嘛？那里面是空的啊。”

没有人接话。

韩秀雅的白色巨机从中层工棚后面走出来，独臂，右肩以下是空的，肩口的接驳环在夕阳里泛着没打磨完的毛边。她把机体在石坪边跪稳，驾驶舱开了，人探出来，先用右手撑住舱沿——那只手是义肢，撑得比左手还稳。

她朝山道的阴影处看了很久。

“清点。”她对着频道说，“报名单。”

工棚里一个年轻的声音开始念：“一号在，二号在，四号在，五号——五号腿上的布条松了，六号在，七号……七号骨架在长屋没动。”

“三号呢？”

年轻声音卡住了。

韩秀雅没有再问。她转过头，隔着半个石坪看向万机馆的方向，看向舰桥里那个能听的人。

“听见了吧。”她说，“它们没来抢工房，也没来抢炉子。”

长屋底下，数数的声音又响起来了。

一，二，三，四，五，六，七。

停的时间比刚才长了一点。

然后，很轻地，从一，重新数起。
