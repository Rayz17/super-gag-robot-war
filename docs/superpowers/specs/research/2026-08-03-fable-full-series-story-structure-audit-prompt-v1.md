请你作为一名独立、挑剔、有长篇番剧统筹经验的**总编剧 + 游戏叙事总监 + SRPG制作人 + 机器人文化专家**，对《超GAG机器人大战：万机残响》进行一次**全剧层面的故事结构与生产方法总审**。

## 一、必须采用的阅读方法

1. 不要仅依赖文件名、搜索摘要或`passed / working`状态。按下面的优先级实际阅读正文。
2. 先建立一张“资料覆盖表”：文件路径 / 是否完整阅读 / 它实际管什么 / 与其他文件有无冲突。
3. 若上下文限制无法一次读完，请分批阅读后再统一作答；不要因为篇幅大就默默跳过文件。必须列出未读或只抽样的内容。
4. 不要把 Current Canon 当成不可改的圣经。Hard / Working / Candidate / History 只是生产权威，不是艺术质量证明。发现更好的故事需要迁移 Working 时，请明确提出。
5. 不要立即详写新的逐话Reader、台本或战斗动作。本轮审查对象是“这是否一个值得写的长篇故事和章级故事”。
6. 请引用具体文件路径和标题/段落作为证据，不要只给通用编剧理论。

## 三、必须接受的新证据

1. C01 V3获得用户明确正面反馈：它不是完美稿，但“明显好于任何一版前稿，可读性强，剧感和人物明显提升”。
2. C01的核心故事可以用白话说清：**最后开放日遇到专门追杀万机馆的外敌，跪在展台上的旧巨神重新起身，被当成商品样机的勇者违令助战，最后整座博物馆恢复巡展舰身体，把敌群引离城市并被迫远行。**
3. C02E01最新Pull Runtime试稿在逻辑、空间、主笔连续性和巨体动作上有改善，用户仍然给出核心否决：

> **“现在S2 S3都在很认真、仔细地写，但是写了一些无聊的故事情节。”**

4. S2/S3的中央事件是“平台误判转子归属，人物排除申诉/回购/租用/断电等简单方法，再驾机穿越货运群、扳道岔、接回巨型转子”。它因果更清楚、动作更大，但人物欲望不冲突，没有改变行动的大选择，没有真正反转，情感和IP/机战内核都被推迟到S4。
5. 这意味着失败不能只归因于句子、主笔、Runtime检索或一道太晚的用户门。必须向上追问：**L2和L3到底给了主笔什么样的长篇与章级故事？**
6. 当前权威存在漂移：可读L3母盘中C01已是`BREAKER+馆守Z起身+巡展舰恢复`版，但`v35_series_structure_master_board_v1.tsv`的C01仍保留`白函+火场+断臂桥`旧版。请检查其他章是否也有类似漂移。

## 四、对你上一次写作系统审查的反证问

你上一次给出的核心诊断是：“问题不是模型不知道设定，而是判断被放错了位置”；并建议T0-T3分级、前移用户选择、建立品味账本、判决场双变体与Pull Runtime。

请基于新的S2/S3证据，不偏护地重审你自己的方案：

1. “判断前移”是否仍然前移得不够？人类选择的不应只是S4演绎或单话场面链，而应先是L2/L3和章发动机吗？
2. 当上游章发动机是弱的，Runtime越精准、主笔越认真，是否只会更稳定地扩写无聊前提？
3. 品味账本能否识别“故事根本不值得讲”，还是只能防止语言和局部场面重蹈失败？
4. T0“不出错”是否真已由工程解决？当上游权威源本身不一致时，它应如何成立？
5. “每话不塌、每章一场被记住”是否仍然太低？对这个有很强IP与机战野心的项目，什么才是现实又有吸引力的T2验收？

## 五、全剧必审问题

### A. 整部故事的中央戏剧线

1. 请先用不超过500字白话复述你真正从当前资料中读到的全剧故事。尽量不用“证言、标签、债务、权限、接口、槽位、可撤回、共同体”等项目术语。
2. 如果去掉“机器人文化值得被承认”这个正确命题，剩下的是否还有一个能推动数十小时的人物故事？
3. 纪存正在主动追求什么？他的身世、力量、缺点、爱情和终局牺牲是同一条剧，还是五条并列设定？
4. 七海、白鸢和其他核心人物是否以不可替代的行动不断改变主线，还是只在轮到自己的议题时出场？
5. 谁是前半、中盘、后半和终局的长期对手？他们有脸、欲望、胜利和不等纪存出现也会执行的计划吗？
6. 断冠、白框、代哥、军方、索引、裂星潮和远星的作用是交织、递升和互相误判，还是依次换Boss？

### B. 六部二十二章结构

1. 每一章是“一件非看不可的事”，还是“讨论一种机器人文化命题、取得一项资源/系统”？
2. 哪些章已有强发动机，哪些只有潜力，哪些过载，哪些必须重写、合并、移位或删除？
3. C01对玩家做出的承诺是什么？C02-C03是否在前五至十小时立即违背了它？
4. 六部的中盘胜利、大败、分裂、归航、未来战争与终局是真正递升，还是只在概念上换了更大的名词？
5. 章间因果是由人物的选择、敌人的计划和未解决的伤口推动，还是主要靠“又缺一个零件/泊位/许可/下一种文化答案”推动？
6. 章数、章序和87话上界是真实剧情需要，还是旧框架的惯性？可以大胆提出变更。

### C. 机器人大战、IP投射与游戏主体性

1. 主要机体是否拥有驾驶员/机魂、欲望、宿敌、登场、合体/变形/升级、战损、离队与终局回援生涯，还是每章消费一批新机体？
2. IP投射是真的人物关系、遗憾、名场面和机器人精神，还是“合体伦理、撤退主题、量产机逆袭”等抽象标签？
3. 玩家在每章主要做什么？这些操作会改变人物命运和战斗结果，还是只为章主题提供一种展示方式？
4. 世界规模、外敌和宇宙战争是否从早期持续存在，还是要到某个“宇宙章”才突然出现？
5. 玩家在第一部、中盘和后半分别获得什么值得兴奋的长期拥有感？

### D. 人物、关系与情绪波形

1. 纪存、七海、白鸢的英雄弧是大事件中的大胜、越界、犯错、误解、破裂、崩溃、领悟和牺牲，还是小动作与制度选择的累积？
2. 三人是否具备真正的吸引、欲望、嫉妒、身体距离、共同伤害、误解与互救，还是只有职业欣赏和规范共犯？
3. 七海与白鸢是否拥有不经纪存中转的事业、秘密、吸引和冲突？
4. 唐胶/兜灯、陆衡/方舟T、豪司/金章、米拉/艾达、赤罡/莉歌等长线是否不等主题章才进度？
5. 每部是否有喜剧、日常、庆祝和纯胜利，避免一直用牺牲、清算和责任压住玩家？

### E. 设定与剧情的关系

1. G.A.G.、机魂、白框、清噪、索引、裂星潮、断冠和远星是否会通过一条可推理、有意外、有人物责任的真相链逐步揭示？
2. 玩家可以在什么时候用白话理解各概念？哪些是戏剧秘密，哪些只是作者后台规则？
3. 设定是不是不断生成“有效但很小的制度问题”，反而拦住人物、敌人和机器人奇观？
4. 玩具/模型、锚件、机魂、实机与工程制造的因果是否足以支撑剧情，却不需要每章解释一次？
5. 哪些设定应保留，哪些应降级为作者后台，哪些应迁移或退役？

### F. 写作系统与人类判断

1. 当前失败有多少来自L2/L3，多少来自L4选案，多少来自Runtime组包，多少来自主笔Skill，多少来自审稿席？不要用虚假精确的百分比，请分主因、放大因子和次因。
2. Runtime应该在哪些阶段查询什么？哪些阶段不应把Canon和合同塞给主笔？
3. 主笔什么时候应拥有否决上游章发动机的权力？谁来判断否决是艺术必要还是不愿承担约束？
4. 人类判断应放在L2、L3、章发动机、一页脊柱、开场短样、判决场和整话的哪些节点？怎样保持“人少量判断”而不把用户变成全职编剧？
5. 哪些工程门能自动化，哪些只能当作警报，哪些绝不能装作自动判断“好不好看”？
6. 如果重做一次系统，怎样以最少调用和Token证明它真能超过V3，而不是再跑二十一次Agent才让用户发现不好看？

### 4. L2全剧戏剧总发动机重构候选

提供三种真正不同的方案：

1. **保守增强案**：保留六部二十二章大体波形，让人物、敌人和宿命更强。
2. **结构手术案**：允许重组、合并、拆分和改变章序，保留项目内核和已证明高光。
3. **大胆重构案**：允许改写Working结构，寻找一个更简洁、更强、更有宿命与反转的主线。

每案必须包含：

- 纪存个人命运如何与世界主线是同一件事；

- 玩家在每部获得的机战幻想和不可逆成长；
- 会丢掉什么、保留什么、为什么。

## 七、审稿立场与禁止回答

- 不要因为项目信息很多就称赞“世界观宏大”。请判断宏大是否被人物行动和玩家体验兑现。
