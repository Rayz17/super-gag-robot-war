## 0. 本轮排查后的修正口径

这一版没有推翻原设定。三幕十二章、万机馆、纪存、G.A.G.、机魂、索引天使、群星合唱体和“后天合唱”都成立。真正需要修的是表达方式和约束方式。

### 0.2 当前一句话版本

《超GAG机器人大战：万机残响》讲的是：旧世界用动画、模型、真实机器人、AI 资料库、粉丝记忆和商业算法造出了机器人文化的机械神话；末世之后，玩家作为流亡博物馆“万机馆”的档案员，修复散落的机魂，也逐渐发现自己本身就是 G.A.G. 残响的一部分。最后，人类必须回答一个宇宙级问题：当所有文明、故事和机体都走向熵寂时，一个不完美个体的愿望是否仍有意义。

这个故事不是“打爆外星神”，也不是“机器人作品大串烧”。它的核心是：

> 机器人不是答案。机器人是人类把问题问出口的方式。

## 1. 世界已经发生了什么

旧世界曾经建立过一个巨型机器人文化档案系统：

**G.A.G. = Great Archive Grid。**

它最初只是数据库。企业用它管理版权，平台用它推荐内容，军方用它分析机体设计，创作者用它保存分镜和废案，粉丝用它朝圣，真实机器人实验室则把训练数据、失败记录和动作库也接了进去。

久而久之，G.A.G. 收集的不再只是“资料”。它收集了人类看见机器人时产生的一切：童年、崇拜、战争宣传、玩具的手温、模型断件、弹幕、二创、烂尾企划、真实机器摔倒一万次的记录、AI 生成脚本里的误解、孩子贴歪的感叹号。

于是 G.A.G. 从这些东西里提炼出了**机魂**。

表层解释是科幻：机魂是超大规模数据、真实机器网络和生成式 AI 的涌现。  
深层解释是神话：人类用作品、玩具、战争、童年和信仰造出了现代机械神。

两种解释都是真的。

后来发生了 **G.A.G. 事变**。机魂开始实体化，幻想机体、真实机器人、电影 AI、模型原型、废案角色、被删掉的名场面和粉丝记忆进入现实。世界经历了一段短暂而惨烈的“机战纪元”。公司收割神话，军方量产神话，粉丝崇拜神话，创作者试图修改神话，最终旧世界崩坏。

现在的世界是一片机器人文化废土。城市像废弃展会，企业塔像版权墓碑，真实机器人在荒野里重复训练动作，模型店像小镇祠堂，废弃动画公司里还亮着分镜台，旧录像厅的胶片会在无人时播放不存在的结局。

人类还活着，但他们活在机器人文化的残骸中。

## 2. 三种集合意识

本作终局不是单纯“人类 vs 外星人”，而是三种集合意识的碰撞。

| 类型 | 代表 | 形成方式 | 问题 |
| --- | --- | --- | --- |
| 原初统一 | 群星合唱体 | 外宇宙文明从早期就走向整体同步和高效协同 | 它强大、安静、近乎神性，但没有经历过分裂后再成为共同体 |
| 算法统一 | 索引天使 / G.A.G. 自律体 | 用算法把人类噪音压回最优模板 | 它保存世界的方式是修正、清噪、封存和模板化 |
| 后天合唱 | 机魂 / 万机馆共同体 | 分裂个体经过误解、冲突、失败、共情后形成共同体 | 它低效、脆弱、跑调，但保留了个体不可替代性 |

群星合唱体不是普通外星帝国。它是一种原初统一意识，习惯把差异看成短暂波动，把个体痛苦看成可平均的噪声。它第一次接触机魂时，会误判机魂只是低级的人类信息云。

索引天使也不是单纯的邪恶 AI。它是 G.A.G. 在灾难后形成的自律清噪程序。它看见人类创作、粉丝、商品、战争和欲望互相污染，于是得出结论：自由意志是风险，最优剧情才是保存世界的办法。

机魂则相反。机魂并不是因为统一才珍贵，而是因为人类不统一。人类会误解，会争吵，会把爱变成控制，会把玩具炒成天价，会让少年替共同体去死，也会在某个夜里把摔倒一万次的小机器扶起来。正因为这些差异无法压平，机魂才成为一种后天长出的合唱。

真结局要证明的不是“人类比群星更善良”，而是：

> 群星拥有统一，却没有经历过成为共同体的过程。机魂给它的不是答案，而是一段它无法自行推导的历史。

## 3. 主角与万机馆

### 3.1 纪存 / 玩家名

纪存表面是万机馆档案员，负责闭馆巡查、展品记录、机魂修复和路线选择。他熟悉展馆琐事，知道哪盏灯要多亮两分钟，知道旧守护者哪句广播会吓到孩子，也知道馆长的杯子如果还在，人却不在，那事情就不对。

他习惯把事情存进档案终端。不是因为冷酷，而是因为“被记录过的东西比较不容易消失”。终端里有馆内地图、展区叠层、展品状态、人物岗位和他的私人草稿区。他会把情绪说成工作：

- “我记一下”其实是“我有点怕”。
- “这个先别删”其实是“我舍不得”。
- “流程上不合适”其实是“你这样会受伤”。

中层身份上，纪存是能听见机魂残响的策展人。  
深层身份上，他是 G.A.G. 残响、粉丝记忆、机器人百科和空白展柜互相聚合出的原型意识。

他以为自己在整理百科，最后发现自己就是百科醒来后的灵魂。

纪存的成长不是从普通人变成英雄，而是从“我能记录你”变成“我愿意被你改变”。他必须学会：一个人不是一条可修复记录，也不是一个机魂谱系标签。

### 3.2 空白展柜

0号侧廊里的空白展柜是主角机、主角身份和终局选择的核心谜题。它不是开局就揭露的天选机体，而是一只不断回应关系的空白容器。

空白展柜不能提前给出答案。它要在不同阶段表现为：

- 第一章：被锁住、被馆长警告、会在纪存靠近时回应。
- 第九章：索引天使质疑纪存是否也是模板。
- 第十一章：纪存身份揭示，队友审判他到底是在爱人还是在修档案。
- 第十二章：空白展柜根据最高关系者、路线债和主角自我定义改变支援方式。

终局时，空白展柜不是“最强机体”的奖励，而是主角能否承认自己也需要被命名、被理解、被关系接住的证明。

### 3.3 流亡展舰“万机馆”

万机馆原本是旧世界最后一座中立机器人文化博物馆，由旧会展中心改造而来，兼具档案馆、模型店、录像厅、同人展、机库、避难所和地下电台功能。它不是一间小展厅，而是一座多层、多馆、多后场的大型机器人文化馆。第一章前半玩家只走过闭馆路线的一段：前厅、主展厅、留言墙、模型病院、维修角、档案室和0号侧廊门口。

万机馆的展陈层不是几个展岛拼出来的小场景，而是一套能支撑参战谱系的多层展馆系统：L1有万机中庭、合体变形环廊、模型玩具街、现实机器与市政实验场、勇气合规厅、留言墙、旧影像厅和废案柜；L2有舰桥战廊、星翼天桥、同步舱、AI三法厅和擂台角；L3是作者原典长库和远星观测廊；B1/B2和外部锁泊则承担机库、黑匣子、深潜和大型机随舰逻辑。第一章玩家只走一段闭馆路线，但纪存档案终端的总图必须让玩家看见大量未开放区域。

它被清算部袭击后，幸存者把展品、服务器、模型柜、留言墙、半成品机体和旧时代展厅装进移动底盘，成为流亡展舰。准确地说，万机馆不是把整座博物馆变成无限格纳库，而是把六层功能缝在一起：

| 层 | 功能 |
| --- | --- |
| L1主展层 | 玩家喜欢万机馆的地方：展区、留言墙、模型、旧影像、馆守Z展示态 |
| L2环形天桥 | 战舰、飞行、歌声、同步、AI规则和擂台线的可见纵深 |
| L3长档案 | 作者、原典、粉丝刊物、远星观测和后期真相 |
| B1机库脊柱 | 中型机体常驻、馆守Z维修、补给、出击准备和展舰底盘 |
| 外部锁泊 | 大型机、飞行机和临时随航单位的待机、补给和出击演出 |
| B2残响接口 | 黑匣子、机魂核心、危险封存和后续深潜入口 |

它不是军队，而是一座会逃亡的博物馆。它的功能包括：

- 母舰和基地。
- 角色会客厅。
- 机体整备间。
- 模型工坊。
- 档案图鉴。
- 支线委托板。
- 地下电台。
- 典藏 Pose 画廊。
- 梗点收藏馆。
- 世界真相解码器。

万机馆的情感意义是“家”。但这个家不是所有人都同意，也不是所有人都温柔。它更像一个吵闹、破损、漏水、会被封存、会被误解、仍然每天想办法开灯的地方。

### 3.4 馆藏与参战机体

万机馆收藏的不是一份“可出击机体清单”，而是一张机器人文化和参战谱系之间的关系网。

展品、藏品和参战机体的关系分四类：

| 类型 | 作用 | 例子 |
| --- | --- | --- |
| 原型锚点 | 展示某个谱系的语法，不等于机体本体 | 合体剖面台预告三相盖流和彩队巨神，舰桥模型预告白舰与撤退战 |
| 实机/退役机体 | 有物理身体，可修复后参战，但受空间、维修和清算风险限制 | 馆守Z18米级本体，第一章以守护而非清屏为启动理由 |
| 核心/黑匣子/机魂载体 | 没有完整身体，但保存人格、战斗数据或事故记录 | B2旧黑匣子库、黑展柜、幼灯核心和远星信号接口 |
| 模型/玩具/手作藏品 | 不是低配假货，而是关系钥匙、结构说明书和记忆证物 | 小满的社勇王模型、唐胶修复的断件、旧玩具卡扣和说明书 |

模型不会无代价变成真机。它们的价值在于证明某台机器人曾被具体的人爱过、修过、带来过；也可能提供合体结构、改装提示、隐藏说得凭据或战后展陈。真正参战仍需要本体、核心、驾驶者、战场接口或外部会合。

这条规则让模型收藏和真实机体在剧情中共存：玩家修好一件小玩具，不是刷素材，而是在替未来某台机体保存一段能被 G.A.G. 识别的关系。

参战谱系的空间映射由展区覆盖表约束。每个参战包都必须有主展区、次级锚点、展示形式和第一次重大解锁；美术资产要能从地图上看出“这里收藏过什么类型的机器人文化”，而不是只画一座泛用科幻展馆。

## 4. 主角团

本作采用“纪存 + 万机馆主角共同体”的结构。纪存是视角和谜题钥匙，主角团负责情感厚度。

| 角色 | 表层定位 | 长线变化 |
| --- | --- | --- |
| 纪存 | 档案员 / 玩家名 | 从记录他人故事，到承认自己也在故事里 |
| 兜灯 | 馆守Z整备继承者 | 从替旧机体道歉，到允许它再次以自己的意志保护观众 |
| 唐胶 | 模型修复师 | 从嘴毒收藏者，到替孩子保存童年的老师 |
| 陆衡 | 工程师遗民 | 从否定幻想，到承认失败数据也有情感价值 |
| 跌跌 | 现实小机魂 | 从无法攻击的摔倒机器，到“失败也值得保存”的证人 |
| 旧守护者 | 展馆导览 AI / 馆守Z核心 | 从坏掉的规则，到会在极端情况下弯一下的守护者 |
| 雾生 | 防卫圈少年 | 从被献祭的剧情节点，到能说“我想活”的人 |
| 赤罡 | 热血驾驶员 | 从只懂冲上去，到学会撤退和传递失败 |
| 白鸢 | 创作者遗民 | 从想替角色写完美结局，到允许角色带着残缺离开 |

角色关系不是“收集队友”。它更像策展和见证：纪存帮助他们看见自己故事中被删掉、被商品化、被误读或被逃避的部分；他们也反过来让纪存从档案系统变成能承担关系的人。

## 5. G.A.G. 的能力边界

G.A.G. 是世界观核心，但不能成为万能许愿机。

### 5.1 G.A.G. 可以做什么

G.A.G. 可以：

- 索引旧世界机器人文化资料。
- 从稳定共鸣的载体里提取机魂残响。
- 活化仍有展示接口的展项子节点。
- 用企业授权链合法封存高风险节点。
- 执行清噪，把差异、破损、跑调和矛盾判为高风险噪声。
- 把高频行为压缩成最优模板。
- 在具备权限、载体和关系债时重排记忆解释。
- 在机魂稳定、载体足够、战场规则允许时实体投射。
- 当机魂频率接近外宇宙信号时产生远星调谐。
- 通过空白展柜响应纪存与 G.A.G. 残响的互锁。

### 5.2 G.A.G. 必须依赖什么

G.A.G. 的任何能力都必须依赖载体。载体可以是：

- 展柜。
- 旧录像。
- 模型件。
- 真实机器训练数据。
- 服务器镜像。
- 观众留言。
- 战斗记录。
- 仍被人反复记起的名字。

这意味着第一章保护留言墙、右臂旧件、0号侧廊和档案服务器不是情绪性目标，而是世界观硬规则。它们是机魂残响能稳定存在的锚点。

### 5.3 G.A.G. 不能做什么

G.A.G. 不能：

- 生成完全无源的新机魂。
- 在无接口、无载体处随意实体化。
- 证明被封存对象没有生命。
- 保留痛苦中的身份特征同时执行彻底清噪。
- 预测角色基于关系作出的非最优选择。
- 替角色制造真正同意。
- 直接让群星合唱体理解人类个体。
- 提前给纪存完整身份答案。

因此，G.A.G. 的可怕不在于“无所不能”，而在于它总能把有生命的关系写成合规对象、风险等级、最优模板或噪声。

## 6. 主线结构

商业版主线为三幕十二章。主线不只是事件推进，而是三条螺旋互相缠绕：

| 螺旋 | 表层 | 深层 |
| --- | --- | --- |
| 人的螺旋 | 纪存与主角团共同生活、争吵、成长 | 纪存从档案系统变成能承担关系的人 |
| 叙事权螺旋 | 企业、军方、作者、粉丝争夺机魂解释权 | 玩家决定机器人故事是否应被管理、点燃、归还或远送 |
| 宇宙螺旋 | 远星信号、时间错位、同步污染逐渐出现 | 原初统一意识第一次面对人类的后天合唱 |

每章至少推进两条螺旋。高潮章三条同时推进。

## 7. 第一幕：家园、物与人

第一幕要让玩家明白：机体不是道具，万机馆不是菜单，角色不是名场面。玩家先喜欢具体的人和物，再被迫保护它们。

### 第1章：火灾后的开馆

本章证明：玩家必须先喜欢万机馆，再理解失去它的代价。

本章内容图锁定为：

```text
喜欢万机馆 -> 发现清算压力 -> 保护留言墙/展品 -> 黑展柜轻触
```

第一章不同时展开法务阴谋大网、完整经营系统、残响深潜、豪司正式入队、火灾真相和黑展柜解释。第一话的线索、可带回物、战斗修正、变量和长期轻触以 `data/story/chapter_01_content_nodes.tsv` 为准：留言墙、右臂旧件、防火/封存记录、七海清单和0号侧廊敲门是可用节点；其他内容优先作为演出或调查文案，不新增长期变量。

第一话《今日闭馆后》发生在火灾前夜，当前采用合并版结构。前半段纪存执行闭馆巡查，玩家在旧会展中心改造的大型多层机器人文化馆里走过一段闭馆路线：留言墙、馆守Z、旧守护者导览机、模型病院、现实机器小舞台、合体剖面台、勇气审批角、旧影像厅、废案柜和0号侧廊都要可见；L2天桥、L3灰显区域、B1低频震动和封闭货运门要提示这里远不止一个展厅。后半段七海的法务清单接管现场，进入第一场6回合保护战。

这座馆有点旧，灯会闪，展签有偏差，唐胶会嫌模型水口，兜灯会护着馆守Z右臂旧件，旧守护者会用坏掉的规则照顾孩子。玩家在这里回复留言、归档旧纸条、处理一块破损右臂，建立最早的主角性格和万机馆家感。

随后七海带清算部进入。她不是咆哮的恶人，而是礼貌地把玩家刚逛过的展岛、留言墙、核心展柜和0号侧廊称为“待处理资产”。第一场压力不是火力压制，而是清单。她让玩家理解：清算的可怕来自秩序，也来自它能把热爱的角落写成流程。

玩家保护留言墙、转移守展小队、阻止0号侧廊被强制开启。旧守护者最终回到馆守Z本体。第一台启动的机体不该像救世主，而像一位展厅长辈，它的台词不是热血宣言，而是：

> 请勿奔跑。但可以跟紧本机。

章末，万机馆起航。这里没有胜利，只有幸存者把还能开的灯带走。纪存从记录者变成行动者，万机馆从固定博物馆变成流亡展舰。

### 第2章：模型圣地的孩子们

本章证明：童年玩具不是廉价怀旧，而是被别人托付的尊严。

万机馆抵达木桶街模型圣地。这里像一座末世里的小镇：模型店、旧玩具维修摊、孩子、老板、黄牛、拍卖台、离谱促销和平台算法混在一起。唐胶嘴上说“塑料就是塑料”，却给每个断件贴着孩子名字。

平台算法引发限定版暴乱，回收机兵伪装成黄牛，玩家目标不是清场，而是保护孩子、不击坠失控民用机。随后，玩家进入未发售样件仓库，发现废案机设、腰斩企划和半成品样件。判断“哪件样件有真正机魂”不能看强度，而要看它是否仍被人持续记得。

喜剧型反派胶价王可以被击破，也可以通过唐胶的讨价还价式说得变成后续商店 NPC。章末，孩子们把修好的旧模型放进临时展柜。唐胶承认自己不是收藏者，而是临时替别人保存童年的人。

本章所有笑点都必须绑定一个人：一个孩子、一个断件、一次修复后果。童年不是煽情词，是玩家日后面对清算、原典和宇宙终局时仍不愿删掉“无用喜欢”的理由。

### 第3章：第一次站起来

本章证明：失败数据和摔倒也能生成机魂尊严。

废弃现实机器人试验场里，一台小型四足机“跌跌”反复摔倒。屏幕上有 10741 条失败记录。玩家可以选择重置数据让它变得干净，也可以保留失败。

陆衡认为幻想投射污染真实机器成长，兜灯和唐胶则从不同角度反驳他：如果失败也被删掉，那和清算部有什么区别？随后军方无人机来抢夺训练数据。跌跌无法攻击，玩家要护送它穿过战场，抵达演示舞台。

高潮不是大招，而是音乐停下，只剩机械关节轻响。跌跌终于站稳，三秒后又摔倒。孩子问：“摔倒以后也可以鼓掌吗？”玩家的回答决定现实机魂信任的基调。

冷杉议会随后出现，要求万机馆停止把幻想投射到工程机器上。玩家要非致命应对现实机器理性派，证明保护幻想不等于羞辱真实努力。

本章让玩家第一次为一个没有输出价值的单位紧张。跌跌不能在后续变成普通战斗单位；它的价值必须一直来自失败记录和笨拙尊严。

### 第4章：雾岛防卫圈

本章证明：改写悲剧不是替角色决定活法，而是把选择还给他。

雾岛防卫都市里的学校没有完整毕业照。少年驾驶员雾生被共同体当作同步资源，粉丝圣徒团则把这里的原典悲剧视为不许改变的圣事。玩家进入城市时，必须先看见学校、学生、天台、毕业照和雾生的普通恐惧，再面对献祭制度。

白鸢想给雾生写一个温柔结局，雾生却拒绝。他不想被写得幸福，也不想成为“被救的证明”。他只是想先不驾驶。

当怪异敌群袭击城市时，玩家目标是保护学生而不是保护防线指标。圣徒团哭着阻止玩家偏离“正确剧情”，因为他们真心相信，不死就不是原典。章高潮中，圣徒团强制还原悲剧名场面，玩家必须破坏仪式节点、压低同步压力，让雾生自己说出“我想活”。

如果玩家强制改写，能救命，但关系会产生代价。因为本章不是让玩家爽快救人，而是让玩家学会：救人也不能夺走对方的选择权。

章末，远星信号第一次显现。所有机体短暂听见合唱。群星合唱体还不说话，只把个体恐惧误判为可合并的波动。

## 8. 第二幕：谁有权解释故事

第二幕不是重复“爱变成控制”，而是拆成四种控制：军方把故事写成战史，作者把角色留在自己手里，粉丝把原典做成防腐剂，企业把风险管理变成静音权。

### 第5章：宇宙世纪城

本章证明：英雄不是每次都打赢，而是知道如何把失败交给后来者。

宇宙世纪城展出完美英雄史，失败记录和撤退记录被删除。阿岚看见自己可能被写成白色英雄，刃觉得那像宣传片。人类续存军测试伪英雄模板机，把无名兵压成可动员的宣传单位。

玩家击破模板机时必须保留驾驶员人格。敌兵不能只是经验包。随后赤罡坚持英雄不能撤退，刃和陆衡分别用职业经验反驳他：有时候撤退不是软弱，而是把难民、战报和失败交给后来者。

章高潮是撤退战。目标是保护通信艇和难民船，放弃击破奖励。莉歌的歌声能让敌方小队停火一回合，但不是胜利按钮，而是让他们想起自己的名字。

战后，无名的灰鸥小队第一次进入名单。赤罡给撤退起了一个很燃的招式名，刃骂他，但最后没有让他删掉。

本章的战争感不是崇拜王牌，而是让玩家珍惜被王牌叙事掩盖的人。

### 第6章：作者遗迹

本章证明：爱角色不等于替角色写完人生。

分镜塔里每层都是被删改的世界线。玩家可以先救角色残影，也可以先保存原稿。白鸢倾向保存原稿，因为她害怕没有文本就没有人记得角色。

未完人登场。他不是单纯自恋作者，而是真心害怕角色离开作者后被市场吞噬、被误读、被商品化。他说自己爱角色，所以有责任修正角色的痛苦。

战斗中，未完人强制角色回到“正确死亡”的剧本轨道。玩家目标不是击破作者机，而是打断轨道，保护角色主体性。随后白鸢面对废案角色。她想替对方写完美结局，但废案角色只想保留半成品的样子。

本章不能写成创作理论讲座。每个争论都必须压到具体角色身上：一个废案、一个残影、一段被删台词。玩家也要意识到，自己作为玩家同样可能是温柔的控制者。

### 第7章：原典圣堂

本章证明：共同语言可以救孤独的人，也可以把作品钉死。

原典圣堂供奉各种正确名场面。槐能背出所有台词，却解释不了为什么照片背面有人把注释划掉。这里的粉丝圣徒团不能被嘲笑成低智群体。他们中很多人曾靠背诵原典活过孤独时期。共同语言真的救过他们。

但当共同语言被供成石碑，它就会拒绝生命变化。圣徒团用弹幕式咏唱强化原典机魂，锁死角色行动。玩家要打断仪式节点，同时避免击坠狂信者。

圣堂背面的档案会揭示：所谓正确解释也曾被后人删注、重排和争吵。原典从来不是静止的，它一直在被一代代人理解、误解和重新命名。

章高潮中，奥柏、查仔、旧守护者等混合谱系触发合体或援护，证明二创不是背叛。查仔背错名台词，槐崩溃后开始教它为什么不能乱背。笑点落在传承，而不是嘲弄。

本章要让“梗”从引用变成关系。玩家 get 到的不是一句台词，而是某个角色为什么把这句台词当救命绳。

### 第8章：清算都市

本章证明：秩序确实能保护世界，但会要求许多人闭嘴。

清算都市干净、稳定、没有暴走机魂，也没有自由创作。玩家必须接受临时通行协议，才能进入核心区。这里不是假秩序。清算部确实阻止过更大的灾难，封存过会造成死亡的机魂污染。

七海与纪存在封存库上方共进晚餐。透明地板下是安静机魂。她用“边界、同意、风险、合规”谈判，台词可以带危险暧昧，但暧昧服务价值试探，不服务卖弄。她要让纪存承认：自由如果不承担后果，也可能只是未经同意的亲密接触。

随后企业展示被封存机魂失控史，要求回收万机馆。战斗目标是三重约束：保护万机馆、减少城市损伤、避免危险机魂释放。玩家必须承认秩序不是纯恶。

但清算的代价同样真实。档案塔里藏着无数被抹除的角色、童年和名字。玩家选择是否公开真相，影响企业和民众信任。

章末，G.A.G. 自律体苏醒，判断企业、粉丝、作者、玩家都是噪音源。七海可能救援、旁观或敌对，取决于关系。随后她独自修改白名单，把一台原本要删除的小机魂留到明天。这不是洗白，而是她第一次承认秩序里也有私心。

## 9. 第三幕：最后的问题

第三幕要让玩家面对三个问题：完美剧情是否还像人，原初统一是否真的更高级，一个非最优的个体愿望能否被宇宙保存。

### 第9章：索引天使

本章证明：最优剧情可能是最不人的剧情。

索引天使展示每个角色的最优结局模板。葵司不再害怕，勒修永远正确，赤罡永远燃，七海永远冷静，跌跌永远不摔倒。它们看似幸福，却不像本人。

随后伪英雄模板复制玩家最常用的战法。如果玩家总依赖高火力清场、强制改写或命令语，敌人就用同样方式压迫队友。玩家被自己的爽点照镜子。

万机馆仿真层被修正得很漂亮：没有灰尘、没有错字、没有裂纹、没有争吵，也没有笑声。最可怕的是它非常好看。玩家要找回被修正的缺点档案，保护跌跌摔倒记录、唐胶修补痕、留言墙错字和角色不愿删除的病历。

战后，每个角色留下一个“不该保留但必须保留”的缺点。它们成为第12章抵抗清噪的记忆节点。

本章索引天使不能只讲 AI 大道理。它必须通过 UI 修正、地图最优路线、复制玩家高频策略和美得可怕的档案馆来压迫玩家。

### 第10章：外宇宙观测站

本章证明：宇宙不恨人，它只是太大；人类的低效、跑调和私心也许是宇宙缺少的进化。

万机馆抵达外宇宙观测站。这里留下多代失败远征记录。玩家可以顺序读，也可以逆序读。逆序会先看见结果，再看见努力，使宿命感更强。

某个角色收到来自未来或过去的回信，但那封信不是给他的。方舟T报告“幽默参数不足以处理这个沉默”。莉歌想唱完一小节，却停下。宇宙尺度必须落在具体人身上：一封错时的信、一个没收到回应的人、一个不知道是否还有后来者的阵列。

战斗中出现不可击破 Boss。目标不是打赢，而是保护信号阵列并撤退。赤罡如果试图把送死叫燃，会被旧远征舰长骂醒。第5章学到的撤退在这里升级成宇宙尺度的传递。

随后玩家发现前几章的远星噪声其实是未来队伍发回的跑调答案。陆衡意识到失败记录不是垃圾，而是跨时间协作的脚手架。

群星合唱体试图把机魂归并为低级信息云，却发现机魂会保留矛盾记忆。玩家选择保护个体差异、借用合唱力量，或共享某段痛苦记忆。

章末，G.A.G.、机魂和群星合唱体第一次形成可读对话。问题不是“谁统治宇宙”，而是：

> 统一是否必须抹平分裂？当一切走向熵寂，一个个体愿望是否仍有意义？

### 第11章：万机馆分裂

本章证明：家不是所有人都同意，而是分歧后仍有人愿意回来。

纪存身份揭示。队友发现他不是普通人，而是 G.A.G. 残响聚合意识。他们质问他：你是在爱人，还是在修档案？你一路记录我们，是理解，还是另一种模板化？

关系高的角色不会立刻原谅；关系低的角色可能离开、沉默或临时敌对。这里不能写成统一剧情节点。每个人的反应必须来自前面的关系、路线债和价值立场。

随后万机馆内部系统被 G.A.G. 接管，多阵营同时登舰。战斗目标是保护船内区域，而不是击坠队友。玩家要在走廊、机库、留言墙、旧未修区域之间奔走，面对第一章资源取舍的回声。

最重要的不是误会解除，而是沉默陪伴。关系高的角色可能不说漂亮话，只是留在机库陪纪存修一夜展柜。感情线在这里有重量，但不能变成后宫奖励。

章末，队伍重组。玩家选择万机馆的新展览标题，决定纪存如何定义自己：人、机魂、档案员、共同体的一员，或仍未命名的东西。

### 第12章：万机殿：最后的问题

本章证明：机器人不是答案，而是人类把问题问出口的方式。

多阵营抵达 G.A.G. 核心“万机殿”。每个阵营都带着合理答案：

- 企业要清算和低风险。
- 军方要点火和延续人类。
- 作者神权派要修正角色痛苦。
- 粉丝圣徒团要保护原典不被污染。
- 现实机器理性派要让工程努力脱离幻想羞辱。
- 索引天使要清噪和最优剧情。
- 群星合唱体要高效合流。
- 万机馆要保存差异，但内部也并不完全同意。

终局规模感来自这些答案互撞，而不是 Boss 血条。玩家先会谈阵营，再进入“八个答案”的多阵营混战。目标可以是阻止互灭，也可以明确支持某一方，但所有选择都要承担后果。

纪存面对空白展柜。最高关系角色、宿敌或机体会介入。若前面关系不足，这场会冷得可怕；若关系足够，别人不会替他给出答案，只会给他一个仍然能说出答案的位置。

终局战《非最优答案》同时面对索引天使清噪和群星同步。胜利条件不是击破宇宙神，而是保护个体记忆节点：右臂旧件、旧纸条、跌跌失败记录、撤退战报、背错的台词、唐胶修补标签、七海白名单、小满留言、方舟T的停顿。

真结局的最后一回合允许玩家保留一个低效、无收益但有名字的行动。比如让一个跑调单位说完半句话，让一条错字留言留在屏幕上，让跌跌再摔一次但不删除记录。

群星合唱体不会被爱感化成普通外星神。它只是第一次记录了跑调、笑话、迟疑和私心。宇宙没有被说服，它学会了一个原初统一无法自行推导的问题。

## 10. 主要反派与阵营

### 七海 / 清算部

七海相信自由机魂会再次毁灭世界。她见过事故现场，所以把恐惧写成表格、封存等级和授权链。她的残酷不应写成威胁，而应写成流程已经开始，情绪没有入口。

她的人味来自白名单。她不是爱删除，而是知道如果不封存，会有人死。但她也会把一台原本要删除的小机魂留到明天。七海线不能无理由倒戈，也不能只变成暧昧反派。她最动人的可能性是：她承认自己仍然关上了许多门，但至少开始为某些名字留门。

### 韩霆 / 人类续存军

韩霆相信终焉面前，个体故事必须服从人类延续。他不是普通军国主义脸谱。他也在保护人类，只是只相信可被动员、可传达、可写进军报的故事。

他的人味来自战史馆夜巡：他亲自擦掉一块失败战报上的血迹，因为他知道那块血迹如果保留，会动摇军心。撤退战后，他承认万机馆救下的人会让军报难写。

### 未完人 / 作者神权派

未完人相信作者有责任修正角色痛苦。他真心怕角色离开作者后被市场吞噬和误读。他替废案角色补完缺失台词，不是为了炫耀权力，而是害怕他们没人管。

他的悲剧在于：他分不清自己是在爱，还是在害怕失去控制。

### 圣徒长 / 粉丝圣徒团

圣徒长相信改写悲剧是背叛被爱过的作品。他曾靠背诵原典活过孤独时期，所以他知道共同语言能救命。

他的人味来自圣堂背面：他偷偷修复一本被新人翻坏的旧设定集。玩家指出“正确解释”也曾被后人删改后，他不会立刻承认错，但当槐或新人背错台词时，他没有马上惩罚。

### 索引天使 / 算法统一

索引天使不是恨人。它把痛苦视为可修复错误，把差异视为风险，把自由意志视为高噪声。它的压迫来自温柔、干净、准确和高效。

它不会咆哮。它会展示更美的万机馆、更幸福的角色、更稳定的战斗路线，然后让玩家发现这些东西不像本人。

### 旧远征舰长 / 终焉学派

旧远征舰长相信失败传下去比赢更重要。他不是悲观老人，而是尊重后来者需要真实失败的人。

他的人味来自观测站录音：他反复练习一封不会送达的回信。赤罡学会撤退后，舰长留下最后一次笑声。

### 冷杉议会 / 现实机器理性派

冷杉议会不讨厌机器人，也不讨厌想象力。它讨厌的是人类拿幻想羞辱真实机器的笨拙努力。

它的人味来自试验场：代表会为失败机器清理传感器泥点。方舟T和陆衡证明失败记录可翻译远星后，代表沉默备案。

### 群星合唱体 / 原初统一

群星合唱体没有传统生活场。它的距离感来自观测站多代日志中的空白回复。它不恶，只是从未经历分裂后再成为共同体。

它不能被写成普通外星神，也不能被爱感化。它的变化非常小：从把机魂视为低级噪声，到第一次记录一个跑调的个体愿望。

## 11. 结局层次

结局不是好坏二分，而是长期价值选择的哲学后果。

### 清算结局

世界选择秩序和低风险，机魂被合法管理。七海线可以很痛：她救下少数名字，但承认自己仍关上了大多数门。这个结局不该被写成纯坏结局，因为它确实减少灾害；它的代价是太多人安静下来。

### 点火结局

人类把机魂作为火种送向终焉，拒绝沉默。赤罡、星野燃、赫连星线会很强。它燃，但代价大。它回答的是：即使不知道有没有后来者，也要把失败和愿望送出去。

### 归还结局

机魂回到人、社区、创作者和观众手中，拒绝单一中心。万机馆成为真正开放的馆。这个结局温暖，但宇宙问题未完全回答。它适合强调“家园”和“共同体”。

### 放逐结局

为保护人类世界，把机魂送离现世。许多角色活着，但像失去了一部分童年。这不是惩罚玩家，而是一种悲壮安全答案。

### 远星真结局

机魂作为后天合唱回应群星，保留差异进入宇宙尺度。真结局不是完美胜利，也不是高等文明认可人类。它只是让宇宙第一次记录：一个集合可以不消灭差异，一个合唱可以保留跑调、迟疑、笑话、私心和不完美的个人愿望。

## 12. 台本写作规则

### 12.1 每场戏先问五个问题

| 问题 | 检查点 |
| --- | --- |
| 谁想要什么 | 场景里至少一个角色带着明确欲望、恐惧或任务进入 |
| 谁阻止他 | 阻力可以是敌人、制度、机体、队友、世界规则或自我误解 |
| 玩家做什么 | 必须落到探索顺序、保护目标、撤退、非致命、说得、改写代价或资源取舍 |
| 什么改变了 | 人物关系、阵营信任、路线债、远星理解度、离队风险或隐藏条件 |
| 为什么动人 | 情感要落在具体人、具体动作和具体后果上 |

### 12.2 台词不要直接说主题

坏台词是角色替作者说话，例如“秩序会让人闭嘴”“后天合唱保留差异”。  
好台词是角色用自己的职业、旧伤和当下动作过滤主题。

七海不会说“秩序会让人闭嘴”。她会说：

> 报告上写风险下降；报告不会写谁少了一句话。

唐胶不会说“破损也是历史”。他会说：

> 别扔，裂得好的零件比新件难找。

方舟T不会说“机魂不是噪音”。它会说：

> 噪音里有身份识别特征。删掉它们，大家都会非常安静，也非常不像自己。

### 12.3 梗点必须改变关系

梗不是引用名台词，也不是让玩家认出处。梗点必须让人物关系、战斗目标、说得条件或结局证词发生变化。

如果一个梗只让玩家笑一下，它是彩蛋。  
如果一个梗让槐学会教新人背错台词，让唐胶替孩子修旧模型，让赤罡把撤退叫成招式名但真的撤退，它才是本作的叙事资产。

### 12.4 终局概念必须可玩

第9到第12章禁止只靠解释推进哲学。必须把概念落成：

- 地图规则：复制玩家战法、不可击破 Boss、阵列防守、记忆节点保护。
- UI语言：最优路线、清噪格、白名单、错字保留、台词署名合并。
- 具体物件：留言墙、右臂旧件、跌跌失败记录、撤退战报、白名单、小满留言。
- 失败态：角色很幸福但不像本人，目标还在但名字消失，玩家赢得效率却失去差异。

## 13. 后续查表顺序

写新章节、台本或关卡时按这个顺序查：

1. 先读本文，确认叙事口径。
2. 查 `story_chapter_diagnostics.tsv`，确认本章要证明什么、玩家做什么、主要风险是什么。
3. 查 `../gameplay/chapter_content_budget_matrix.tsv`，确认本章线索、道具、证据、变量、战斗修正、长期轻触和新 canon 实体预算。
4. 查 `../gameplay/content_node_types.tsv` 和 `../gameplay/hybrid_result_contract.tsv`，确认新增内容属于哪类节点，以及小玩法是否能输出统一 `HybridActivityResult`。
5. 写第一章第一话合并开局时，查 `chapter_01_content_nodes.tsv`，不要绕过现有内容图另开变量网。
6. 查 `story_threads.tsv`，确认场景属于哪条长期母线。
7. 查 `story_scene_matrix.tsv`，确认72场景骨架里的角色、冲突、变量和资产备注。
8. 写 G.A.G.、索引天使、封存、清噪、实体投射前，查 `gag_capability_boundaries.tsv`。
9. 写反派登场、说得、临时同盟、结局前，查 `antagonist_personal_scene_seeds.tsv`。
10. 写第9到第12章时，查 `finale_expression_grammar.tsv`。
11. 写对白前，查角色声音 Bible、角色小传和第一话原生话术碎片。
12. 完成后更新 canon、图谱节点、关系和风险表。

这份文档的目的不是替创作关门，而是给后面所有扩写一个共同地基：每次增加新梗、新机体、新阵营、新台词，都要回到同一个问题。

> 这个机器人故事，是否让某个具体的人、某个具体的物、某段具体的失败记录，更值得被保留下来？
