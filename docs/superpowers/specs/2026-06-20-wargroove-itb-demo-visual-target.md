# 《超GAG机器人大战》Wargroove + Into the Breach Demo 目标 v0.1

## 定位

本轮不追 SRW 全动画，不做网页式面板原型。

目标组合：

- Wargroove：像素 tilemap、清晰 SD 单位、战棋舞台感、紧凑游戏 UI。
- Into the Breach：敌方意图、结果预测、保护目标、每回合解局。
- 超GAG：机器人驾驶员、精神/气力、法务封印线、万机馆梗点。

## 画面标准

- 地图占第一视觉，不能被右侧大段文字抢走。
- 地图必须是 tile 风格：地砖、展柜、0号侧廊、留言墙、档案室、封存线。
- 单位必须像像素 sprite，而不是纯色方块：有头、身体、肩、腿、阵营色、朝向感。
- 敌意图必须画在地图上：封存线、攻击箭头、目标高亮。
- UI 必须像游戏 HUD：小型面板、图标/条、短文本，不像网页卡片。

## 交互标准

- 玩家移动光标时，地图格和对象反馈清楚。
- 选中单位后，移动范围/攻击范围覆盖在地图上。
- 攻击目标前必须显示预测，不允许点了就打。
- 预测层显示：伤害、命中、反击、目标 HP 变化、意图是否被解除。
- 击破关键敌人后进入 cut-in，再回闭馆记录。

## 本轮实现范围

- 不接外部美术文件，先用 Phaser 程序生成像素 tile/sprite 占位资产。
- 新增战术呈现数据接口，让渲染层不用猜地图含义。
- 重画战斗地图、探索地图、单位 sprite 和意图线。
- 保持管理/对话/探索/战斗四态闭环。

## 验收

- 浏览器首屏仍可直接运行。
- 战斗画面第一眼像 2D 像素战棋，而不是网页仪表盘。
- 不看说明也能看到敌人“准备打哪里/封哪里”。
- `npm test` 通过，浏览器关键路径可走完。
