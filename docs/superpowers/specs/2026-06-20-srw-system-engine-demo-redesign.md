# 《超GAG机器人大战：万机残响》SRW式系统与Demo重做调研 v0.1

## 1. 现有Demo问题复盘

上一版 `demo/chapter1` 的本质是“剧情review网页”，不是游戏demo。

主要问题：

- 没有SRW式光标语法：玩家不能用方向键/鼠标在地图格子上移动光标、选单位、选目标。
- 没有单位行动循环：没有“选择单位 -> 移动范围 -> 移动 -> 攻击/精神/待机 -> 单位行动结束”。
- 没有敌方阶段：战斗不是玩家和敌人轮流争夺地图目标，而是按推荐按钮推进。
- 没有战斗演出切换：SRW的爽点之一是地图攻击确认后切入战斗动画，再回到地图。
- 没有战前/战后整备：玩家没有“任务选择、机体状态、驾驶员精神、过关结算”的游戏节奏。
- 画面结构像管理后台：侧栏、按钮、文本面板太重，第一屏不像游戏。

结论：上一版只能验证剧情节点顺序，不能验证游戏性。

## 2. SRW基本游戏模式提炼

参考Steam版《Super Robot Wars 30》官方商店页：官方将其定义为 tactical RPG，玩家在 adventure 与 battle 之间推进；战斗中在 battle map 操作巨大机器人，流程在 ally phase 与 enemy phase 间切换；战后进入 Intermission，用资源训练驾驶员、升级机体，再进入下一章。来源：Steam《Super Robot Wars 30》页面。

因此SRW式demo必须具备五段循环：

1. 战前剧情/任务导入：对话、出击目标、胜败条件。
2. 地图战棋：格子地图、光标、单位选择、移动、攻击、精神、待机。
3. 战斗预览与动画：命中/伤害/反击或防御提示，随后切入大魄力短演出。
4. 敌方阶段：敌人按目标推进，玩家保护对象承压。
5. 战后整备/幕间：资金/经验/损伤/变量/下一话承接。

本作可以简化数值，但不能删掉输入语法。否则玩家不会觉得自己在“玩机战”。

## 3. Demo重做验收标准

第一章可试玩demo至少要做到：

- 画面第一主体验是Canvas游戏场景，不是HTML文档。
- 支持键盘：方向键/WASD移动光标，Enter/Z确认，Esc/X取消，E结束阶段，Space推进对话/动画。
- 支持鼠标：点击格子移动光标，点击单位/目标确认。
- 至少一张完整战棋地图：1-2《法务警报》保护留言墙。
- 至少一个巨型单位地图：1-3《展厅里的旧守护者》馆守Z 2x2单位。
- 有可见移动范围、攻击范围、单位HP/EN/SP、回合和阶段。
- 有精神指令的轻量版，例如“必中/不屈/燃魂”或本作等价物。
- 有敌方阶段，敌人会向留言墙、0号侧廊或馆守Z推进。
- 有战斗动画切换：地图攻击后进入短cut-in，再回地图。
- 有SRW式“胜败条件/战斗目标”栏，而不是网页按钮清单。

## 4. 引擎调研与选择

| 方案 | 优点 | 风险 | 本轮结论 |
| --- | --- | --- | --- |
| Phaser | 官方定位为HTML5 2D游戏框架，支持WebGL/Canvas、场景、输入、动画、相机、Tilemap，可用JS/TS开发；可用npm安装，适合Codex直接改文件 | 仍是Web技术栈，需要自己写SRPG规则 | 本轮采用 |
| Godot | 完整2D游戏引擎，适合商业版中后期原型；有Web导出 | 当前工作区要引入编辑器/导出链；Godot 4 Web导出涉及WebAssembly/WebGL 2与部分平台限制；Codex纯文本迭代不如JS直接 | 暂不用于本轮demo |
| PixiJS | 高性能2D WebGL渲染器，适合自研引擎和复杂演出 | 不是完整游戏引擎，输入、场景、状态机要自写更多 | 可作为未来高定制渲染层 |
| 纯DOM/Canvas自研 | 最轻，可完全控制 | 容易再次滑回“网页工具”，需要从零做输入/动画/场景 | 仅保留为规则模型测试，不作主渲染 |

本轮决定：`demo/chapter1` 主入口改为 Phaser Canvas 游戏。旧DOM版保留为 legacy 参考，不再作为默认demo。

## 5. 第一轮重做范围

第一轮只做“像游戏”的最小闭环，不追求完整SRW系统。

必须实现：

- `Mission 1-2 法务警报`：保护留言墙6回合。
- `Mission 1-3 展厅里的旧守护者`：馆守Z 2x2单位，过热风险，非全灭目标。
- 地图HUD：胜败条件、当前阶段、回合数、选中单位、操作提示。
- 单位菜单：移动、攻击、精神/燃魂、待机。
- 战斗动画：双方大头像/机体剪影、攻击名、伤害数字、短震动和闪白。
- 战后结算：闭馆记录，不叫胜利结算。

延期：

- 完整养成。
- 完整寻路动画。
- 复杂命中回避。
- 援护/合体攻击的正式系统。
- 全第一章AVG细节。
