# 《超GAG机器人大战：万机残响》第1章四态 Demo 重做设计 v0.1

## 目标

把 `demo/chapter1` 从“能运行的战斗原型”重做为一个四种主要交互形式都成立的可试玩切片：

`管理 -> 对话 -> 探索 -> 战斗 -> 结算/管理`

四种模式共享同一个游戏壳、光标/焦点、菜单、音效和反馈逻辑，不能像网页页签。

## 四种交互的职责

### 管理

作用：让玩家在出击前理解队伍、机体、资源和档案。

必须有：

- 出击单位列表：纪存、兜灯、豪司、唐胶。
- 机体定位：指挥、支援、超级系、地形控制。
- 资源：制作费、修理材、机魂样本。
- 可执行整备：给一台机体装备临时零件、查看武器/精神、查看档案。
- 出击确认：进入战前对话。

体验标准：像基地/格纳库 UI，焦点移动和确认/取消是游戏菜单，不是 HTML 表单。

### 对话

作用：交代动机、角色关系、任务目标，并埋下疑问。

必须有：

- 角色名牌、头像/剪影位、台词框。
- 自动推进/确认推进。
- 关键台词触发任务变量，例如“法务警报”“留言墙”“0号侧廊”。
- 对话结束后自然进入探索，而不是直接开打。

体验标准：台词从角色视角说话，不能像系统讲解设定。

### 探索

作用：让玩家在万机馆里“动起来”，建立空间感和物件关系。

必须有：

- 小地图光标或角色移动。
- 可调查对象：留言墙、0号侧廊、馆守Z胸牌、档案柜。
- 调查反馈：短对话、档案解锁、任务提示、资源变化。
- 至少一个互动触发战斗：法务封存线压到留言墙，进入地图战斗。

体验标准：探索不是“点一串按钮”，而是在场景里移动、调查、触发。

### 战斗

作用：展示 SRW-like 核心循环。

必须有：

- 常驻光标、单位选择、移动范围、攻击范围。
- 单位命令：移动/攻击/精神/待机。
- 武器/战斗预测：预计伤害、反击、命中、消耗、击破提示。
- 敌方意图：法务无人机要封印哪里、回收框体要攻击哪里。
- 战斗演出：普通攻击短演出 + 至少一个大 pose/cut-in。
- 战中对话：首次交战、援护、留言墙受损。

体验标准：每次行动都有 `预览 -> 承诺 -> 反馈`。

## 本轮实现范围

本轮先做一条完整可跑的垂直切片：

1. 管理界面选择“出击 法务警报”。
2. 战前对话交代火警、法务封存、孩子和留言墙。
3. 探索万机馆前厅，调查 3 个对象后触发战斗；也可直接调查“封存线”进战斗。
4. 战斗中显示敌意图和攻击预测；攻击确认后进入 cut-in。
5. 胜利后回到管理界面，解锁一条档案。

## 非目标

- 不做完整美术资产生产。
- 不做完整养成/改造系统。
- 不做完整第一章所有话。
- 不复刻 SRW 具体 UI、机体、镜头和素材，只学习交互状态机。

## 验收标准

- 打开 demo 后 30 秒内能看出它是游戏，不是网页。
- 玩家能明确知道自己当前处于管理、对话、探索还是战斗。
- 每个模式至少有一种玩家主动操作，而不是纯推进文本。
- 管理、对话、探索、战斗之间有剧情和目标上的因果。
- 测试覆盖四态流转、探索调查、整备选择、战斗预测、敌意图。
