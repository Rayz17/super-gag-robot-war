# 参战包原作遗憾与机战 IF 素材库 v0.1

> 状态：V31 写作流新增候选素材层。  
> 用途：给分支、隐藏机体、说得、救人、复活/残响回归、悲剧反转、名场面变奏和章节 route 设计提供“机战味”的意难平素材。  
> 边界：本库是内部策划锚点，不是公开文本。游戏内必须使用原创机体、原创角色、原创台词和原创事件承接。

## 1. 为什么要补这一层

此前的机体池解决了“有哪些参战包”和“每话要不要有新增机体”的问题，但还不够像机战。机战系列真正让玩家兴奋的部分，不只是机体上场，而是：

- 原作里救不了的人，在隐藏条件里可能被救回来。
- 原作里互相错过的人，在跨作品舞台上有机会听完一句话。
- 原作里注定牺牲的机体，在玩家的路线选择中得到另一种尊严。
- 原作名场面不是被复制，而是被反问、改写、戏仿、补完或付出新代价。

所以这层素材库的核心不是“致敬 IP”，而是“把玩家熟悉的遗憾变成可玩的 IF”。

### 3.1 v0.1.1 高密度修正原则

本池禁止为了表格整齐而把每个作品都凑成同样数量。机战玩家真正会兴奋的不是“每包刚好三条”，而是强作品的情绪矿脉被充分挖开：

- **强 IP 多给**：0079、Z、0080、CCA、SEED、EVA、Macross、Nadesico、Getter、勇者、变形生命等玩家熟悉度高、悲剧/关系/名场面密集的谱系，可以拥有 6-12 条甚至更多素材。
- **弱悲剧不硬凑**：轻喜、童年向、生态槽点或玩法型作品，可以只承担爽点、笑点、机体玩法、商品生态和支援功能，不需要强塞三条意难平。
- **一条素材必须能写进游戏**：每条都要回答原创化承载、可玩触发、失败尊严和禁用边界。只写“某人死了很可惜”不合格。
- **大作内部要拆层**：同一个高达系不能只写红白宿命，还要拆到舰桥恋爱、补给舰长、荣誉敌将、邻人互杀、童年幻灭、修正掌伦理、宿敌共担、政治恋爱、后继机继承等不同口径。
- **不把素材当定稿**：这些是 episode loop 的选材仓库，不规定每话固定使用。写到具体话时，由机体、地图、关系、分支和玩家行为共同决定选哪条。

## 4. 写作时怎么用

### 4.1 不是每话硬塞，而是每话挑一两个“可打动玩家的 IF”

写单话 episode packet 前，先从本池挑选：

- 1 个主 IF：决定本话最强戏剧问题。
- 0-1 个副 IF：用于支线、隐藏触发、敌方误读、角色关系镜像。
- 1 个失败尊严：玩家没有达成隐藏条件时，也要留下残响、支援、证据、遗物或后续说得窗口。

比如白舰纪元不要只写“红面具上场”。可以选：

- `WIF_R03_001`：理解发生瞬间的死别，改成停火一回合保护感应残响。
- `WIF_R03_002`：强化人少女被系统夺走自我，改成破坏家庭幻觉播报塔。
- `WIF_R03_003`：量产机撤退比王牌单挑更重要，改成撤退护送关的核心胜利条件。

这样一章就会自然有主线、分支、隐藏、战斗条件、人物冲突和泪点，而不是只堆机体名字。

### 4.2 机战 IF 的四种用法

| 用法 | 说明 | 示例 |
| --- | --- | --- |
| 救人 | 原作早死/必死角色有条件保留 | 吐槽战舰的宅驾驶员、强化人残响、三相盖流牺牲者 |
| 改死法 | 不否认牺牲，但让牺牲保护团队/世界/所爱之人 | 铁巨人朋友、迟到的火花、黑棋王座 |
| 反名场面 | 玩家不按原作爽点操作，反而得到更高阶结果 | 撤退胜过单挑、低效率拆件胜过完全版、拒绝同步胜过满同步 |
| 失败尊严 | 未达成隐藏也不惩罚式羞辱，而是留下残响、遗物、证据或二周目动机 | 查仔残响、无名量产机录音、迟归回信缺席 |

### 4.3 和分支设计的关系

本作分支不应只是“选 A 阵营 / 选 B 阵营”。更像机战隐藏条件：

- 在某一回合保护某个非高价值目标。
- 不击坠某个看似杂兵的敌人。
- 让特定角色同场并触发说得。
- 放弃高击坠、高效率、高报酬。
- 在深潜中拼对非线性证据。
- 承认某个角色“不归队”的自由。

这些条件的共同点是：玩家不是在选菜单，而是在战斗、探索、经营、关系和开馆中持续证明自己理解了某条机器人叙事。

## 6. 和其他素材层的调用顺序

写一话时推荐顺序：

1. 查 `v29_roster_bible_reserve_backfill_pool_v0_1.tsv`：先确保真实新增机体/敌方/支援单位。
2. 查本池 `roster_what_if_regret_pool_v0_1.tsv`：选择原作遗憾 / IF / 隐藏条件。
3. 查名台词/名场面素材池：决定是否直接短引、错引、原创变奏或只取场面结构。
4. 查 `robot_culture_value_axes_v0_1.tsv`：把 IF 升级成机器人文化价值，而不是讲大道理。
5. 查 `real_world_resonance_cases_v0_1.tsv`：需要现实泪点时再用，不替代机体/IP密度。
6. 写 episode packet：把所选 IF 记录到 Context Pack、Pressure Board、Episode Card、Draft 和 ledgers。

## 7. 使用红线

- 不得直接照搬受版权保护的角色名、机体名、势力名、造型、标志、长台词和具体剧情编排。
- 可以内部锚定“阿姆罗/夏亚/拉拉式死别”“凤/露莎美式强化人遗憾”“盖塔牺牲者”“Nadesico Gai式可救角色”等，但公开文本必须完全原创化。
- 直接名台词只能作为短锚、错引、误记、战场吐槽或法务可控短引用使用；优先使用原创变奏。
- 救人不能变成便宜复活。救下人也要产生新的心理、路线、战斗和公共后果。
- 失败路线也要尊严。没救到的人可以留下残响、证据、支援、遗物、日志或终局一声回应。
- 儿童/未成年人线只承载童年、托付、观众、家感和保护责任，不进入成人暧昧或擦边。
