## 0. 使用总规则

每个素材必须先问五件事：

1. **触发条件**：它为什么此刻出现？必须来自前文状态、地图压力、角色选择、敌方学习或资产边界。
2. **角色代价**：谁为它签名、背锅、受伤、被误会、失去隐私、降低权限或欠下维修债？
3. **玩法承载**：它改变什么格子、胜利条件、支援范围、敌方目标、证据牌或结算变量？
4. **资产层级**：full unit / support unit / enemy unit / Cut-in / anchor / scene module 必须分清；只有 full/support/enemy/Boss/scene-mecha 或改变战斗的形态/模块能计入机体密度。
5. **避免误用**：不能只把锚件当参战，不能把名场面堆成引用清单，不能让儿童承担成人关系张力，不能把真实 IP 名写成正式参战版权名。

真实 IP 只能作为“锚点/变奏/气质”使用。正式出场名统一使用本作机体、模块、势力或场景名。

## 2. C01-C03 PV级机体场面池

### C01 闭馆夺名与展舰起航

1. **被改名的出击名单墙**：展签一排排从“馆守Z”“社勇王送修模型”“跌跌小舞台”变成风险编号，纪存把代哥清单投到公开导览屏上。触发是七海远程封存；代价是纪存被记录为煽动风险；玩法是保护原名展签；资产是 UI/展签 scene module；避免写成设定说明。
2. **半跪巨机右臂成桥**：馆守Z不能站起，只把右臂旋成撤离桥。触发是路径框封路；代价是承重网格损耗；玩法是地图变形；资产是 full unit 动作；避免无损帅招。
3. **胸牌低热光禁止全功率**：胸口亮光扫过无人机，但只烧采样贴片，不烧机体。触发是冷却针车扎胸牌；代价是热量曲线被记录；玩法是低/高功率选择；资产是 Cut-in；避免“超级光线清屏”。
4. **飞拳不是飞，是轨道滑拳**：馆守Z右拳沿承重轨滑出，把封存锁杆打歪。触发是留言墙登记为公共展品；代价是维修债和兜灯停机签名；玩法是开新撤离线；资产是动作特写；避免复刻飞拳结论。
5. **勇气审批金章通道**：金章印记在地面、模型盒和右肩连线，馆守Z抬肩半格挡住 0 号开启臂。触发是三人责任签名；代价是越权待审；玩法是支援通道；资产是 Cut-in + 地图光路；避免社勇王真机化。
6. **B1 展舰脊柱点火**：地面像旧会展物流层一样打开，移动底盘、重型维修架、中型泊位、外部锁泊一排灰显。触发是原地封存不可逆；代价是旧址失守；玩法是撤离三选二；资产是大型 scene module；避免把泊位当无限容量。
7. **破损母舰带留言墙起航**：馆守Z半卧挡标记无人机，万机馆拖着烧焦外墙和半卷留言墙离开。触发是火锁回写被拦截；代价是移动风险编号成立；玩法是结算状态；资产是 PV 结尾镜头；避免胜利太干净。

### C02 模型街临时开馆

1. **木桶街旧盒绘墙入夜**：万机馆停在高架阴影下，街内旧盒、退坑柜、修模型长灯和寄售台一层层亮起。触发是 C01 缺件清单；代价是进入追踪物流链；玩法是四行动点调查；资产是场景大图；避免商店菜单感。
2. **姓名贴被镜头捕捉前的一挡**：唐胶挡住公文包姓名贴，兜灯坚持来源可追，纪存加“私密回访水印”。触发是采样夹臂要拍旧名；代价是证据弱化；玩法是公开/遮蔽/暂存；资产是手部特写；避免成人张力牵扯儿童。
3. **红蓝黑限定样件暴走护送**：红样件快到刹不住，蓝样件护过头，黑样件躲进物流箱。触发是价格屏跳红；代价是公开七海清单导致恐慌；玩法是非致命护送；资产是三台小机；避免把重涂当皮肤。
4. **旧货柜车灯错认商品标签**：货柜锚件把封存标签误读成同伴贴纸，生成诱饵标签。触发是样件被采样；代价是代哥记录玩具锚件干扰执法；玩法是诱饵支援；资产是 anchor + 灯光 Cut-in；避免解释成 G.A.G.本体。
