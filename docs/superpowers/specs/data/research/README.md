## 使用方式

1. 写新大纲或逐话卡前，先从研究表选素材，不要先用 canon 压缩想象力。
2. 每个素材进入剧情前，必须完成“可识别记忆 -> 原创化场面 -> 玩法承载 -> 避险边界”四步。
3. 被用户确认采用的素材，再迁移到 canon、图谱或正式大纲数据中。
4. 未确认素材只能作为候选，不得直接改角色登场、机体入队、章节顺序或美术资产硬需求。
5. v1深度池按剧情需求选用，不是逐话十表配额。选中的row id必须进入Episode Input Manifest、Scene Binding Matrix和`source_absorption.tsv`，并在可读稿与制作拆分中产生可见动作或状态变化。
6. 完整方法、版本兼容和原创化边界见 [创作素材包深度补全v1](../../research/2026-07-11-chao-gag-material-pack-depth-backfill-v1.md)。
7. 章级预生产模型已经接入第四层、正式Writing Skill与Episode Loop；关键场面必须引用已登记项。C04两个根因和C05四项物理阻断均已关闭，但预制/脚本PASS不代表Reader或人类声线通过。
8. C01-C05只作为真实故障回归集，不是未来内容范本；用户确认和Working状态提高推倒重写门槛，但不关闭独立审查。
