# 《超GAG机器人大战：万机残响》角色内在与声音数据说明 v0.1

本目录承接 [角色内在与声音 Bible](../../2026-06-19-chao-gag-character-interiority-voice-bible.md)，目标是让后续台词、演出和剧情推进从角色视角出发，而不是从设定框架直接发声。

## 文件

| 文件 | 用途 |
| --- | --- |
| `character_dossiers_core.tsv` | 核心角色小传、面具、欲望、恐惧、矛盾和成长考题 |
| `character_voice_rules.tsv` | 角色声音规则、词汇来源、句式、应激动作、亲密动作和禁用写法 |
| `character_voice_fragments_ep01.tsv` | 第一话角色原生话术碎片，优先用于重写对白 |
| `episode_01_line_diagnostics.tsv` | 第一话台词诊断与改写样例 v1，保留为问题样本 |
| `episode_01_line_diagnostics_v2.tsv` | 第一话台词诊断与改写样例 v2，后续重写优先使用 |

## 使用顺序

1. 写场景前，先查 `character_dossiers_core.tsv` 的角色欲望和恐惧。
2. 写对白时，再查 `character_voice_rules.tsv` 的词汇、句式和应激反应。
3. 改第一话时，优先参考 `character_voice_fragments_ep01.tsv` 和 `episode_01_line_diagnostics_v2.tsv`。
4. `episode_01_line_diagnostics.tsv` 是第一版诊断，保留用于观察“仍然太工整”的问题。
5. 如果角色尚未登记，先补小传和声音规则，再写台词。

## 设计原则

- 角色不能直接说主题，必须从自己的职业、旧伤、欲望和当下环境折射主题。
- 梗点必须改变关系、行动或选择。
- 越重要的角色，越需要“不说真话时的说话方式”。
- 台词宁可带一点笨拙、绕、误会和具体物件，也不要变成漂亮的主题句。
- 不把“你可以X，但别替我Y”当作通用强硬句式；同一意思要经过角色口气、听众关系和现场动作重新说。
- `债务`、`结算`、`共犯`、`权限`可以留在制作账本和系统状态里，不得自动进入恋爱、友情或牺牲对白。人物应说自己到底气什么、怕什么、舍不得什么。
- 同样禁用“第三面算我的”“这锅我背”“责任记我名下”一类责任结算腔来制造英雄感。先写角色看见了什么、抢了哪个动作、身体承受什么，再让台词只说当下需要说的半句，例如“墙停在两面。百相，下去接。”
- 设计文档可以讨论主体权、停止权与选择，但Reader和台本不得反复写“没有替某人决定”“不替某人背”“把决定权还给某人”。把抽象原则改成可见动作：谁松手、谁开闸、谁拒绝接管、谁听完以后改了路线。
