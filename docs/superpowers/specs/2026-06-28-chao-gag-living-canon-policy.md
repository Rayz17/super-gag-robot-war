# 《超GAG机器人大战：万机残响》Living Canon 政策 v0.1

本文件把 canon 从“旧资料的冻结索引”改成“多 session 协作的活准线”。它服务于剧情、台本、美术、玩法、Godot demo 和图谱，不是为了限制创作，而是为了让更强的创作可以被同步、追踪和验证。

## 结论

`$chao-gag-canon` 需要继续使用，但它不能再被理解成“旧 TSV 行说了什么就必须照抄”。正确用法是：

1. 先查现有 canon，知道当前基线和已锁资源。
2. 判断它是硬设定、工作设定还是候选设定。
3. 如果现有口径压低戏剧张力、机战爽点、成人关系卖相、梗点识别度、万机馆规模或多玩法结构，就做 canon 迁移。
4. 把迁移写进机器可读表、可读文档、图谱节点/边和一致性 watchlist。
5. 跑 `scripts/canon-smoke-test.sh`；涉及 Godot playable flow 时再跑 `scripts/canon-check-godot.sh --report` 或 `--strict`。

## Canon 等级

### Hard Canon

硬设定保护的是多人协作已经依赖的东西：

- 用户明确确认过的角色性别/呈现、机体尺度、关键美术锁定。
- 当前 demo 或第一章可玩流程已经使用的实体、场景、运行规则。
- 万机馆楼层、馆守Z 18米级、第一章七海不亲临现场、纪存档案终端、第一章火警/封存/展舰化等已经反复校准的根锚点。
- 会破坏大量地图、资产、台本、战斗和实现的底层规则。

硬设定不是绝对不能改，但要先说明创作收益和爆炸半径。

### Working Canon

工作设定是当前推荐方向，但允许被更好的戏替换：

- 全游戏46话梗概的未来章节。
- v10/v11/v12 里的50问题解决方案、戏剧能量诊断和施工约束。
- 关系推进、阵营行动、G.A.G.揭示曲线、万机馆阶段解锁、章节多玩法段。
- v12.1/v12.2 当前前三章展开样板，在用户审过并接受前仍应视为工作样板，不是硬锁。

工作设定被改动时，重点不是“违不违反旧表”，而是“新解法是否更能让玩家喜欢机体、喜欢人、记住场面，并且更利于制作”。

### Candidate Canon

候选设定用于大胆创作：

- 新增或重写的场面。
- 成人关系的擦边场。
- 机战名场面变奏。
- 反派胜利方式。
- 隐藏机体、后继机、支援台词、战斗演出。
- 未被用户确认的敌方王牌、远星误读、G.A.G.异常表现。

候选设定可以先进入 `needs_review`、watchlist、v13 复审表或问题文档。候选设定不能悄悄变成硬锁。

## 迁移模式

每次因为更强的创作而改 canon，使用这个格式：

- **Reason**：旧口径造成什么问题。比如“把纪存只写成犯错者，会损害主角魅力”。
- **Change**：改哪张表、哪条规则、哪个人物/机体/章节口径。
- **Level**：新内容是候选、工作还是硬设定。
- **Blast Radius**：影响哪些台本、地图、美术 brief、Godot flow、数据表、图谱节点和 watchlist。
- **Data Update**：具体新增/修改的 TSV、MD、HTML 或脚本。
- **Validation**：至少跑 canon smoke test；涉及实现时跑 Godot canon check。

## 对50项问题的影响

50项问题不再只问“怎么符合现有 canon”。应先问：

- 这个问题是不是因为旧 canon 把戏写小了？
- 当前的“施工约束”是硬规则，还是临时写法？
- 这个问题需要新增工作设定，还是只需要把旧候选降级？
- 这个问题是否应该反过来更新 canon，让后续美术/玩法/台本都跟着新方向走？

因此，v13 复审的职责不是替代 v10/v11/v12，而是在它们之前加一道活准线判断：哪些继续保留，哪些迁移，哪些降级，哪些必须大胆新增。

## 当前推荐口径

- `data/canon/*`：机器可读基线。读取时必须判断 Hard/Working/Candidate。
- `data/canon/character_mecha_art_locks.tsv`：角色、机体、美术当前锁定根表。已锁资产优先视作 Hard Canon；待锁条目多为 Working 或 Candidate。
- `data/canon/wanji_*`：万机馆空间、展区、泊位、藏品和档案终端根锚点。空间尺度和第一章开放状态偏硬；未来解锁方式偏工作设定。
- `剧情梗概/前三章逐话剧情梗概展开版-v12.2.md`：当前前三章工作样板。可以作为重写格式参考，但不应压住后续更强的爆点、感情线和机战场面。
- `data/story/issue_living_canon_review_v13.tsv`：50项问题的 Living Canon 复审表，后续重写全游戏梗概前应与 v10/v11/v12 并读。

## 禁区

- 不要把“有 canon 行”误当成“不能改”。
- 不要用 canon 检查来回避创作：机战爽点、泪点、擦边、梗点和大反转仍然要写出来。
- 不要把候选场面塞进 canon 后就放弃审稿。
- 不要为了自洽牺牲玩家的机器人文化期待。
- 不要把所有东西都升成 Hard Canon。项目还在生长。
