# 纪存与馆守Z评审结论 v2

> 状态：`candidate_review_resolution`  
> 日期：2026-08-04  
> Canon边界：本文件记录美术方向，不直接替换 `CML001/CML008` 的 Hard visual lock。

## 1. 纪存

结论：**设计方向通过**。

- 正比例候选的年龄、脸、肩颈和站姿可作为新母版方向。
- 保持无眼镜、无胡须，不用老化符号制造成熟感。
- Q版的成年感与信息压缩方向通过，但必须在最终正比例母版锁定后重新派生，不能把当前浅底评审图直接当 runtime 素材。
- 正式迁移前仍需补：透明正比例母版、正侧背三视、基础表情、对话半身、Q版方向锁和96 px验收。

因此当前状态是 `design_direction_approved`，不是 `runtime_asset_approved`；旧 Hard 锁暂不覆盖。

## 2. 馆守Z

结论：**图三只保留为比例、配色和清晰度参考，机设退回重做**。

通过项：

- 深海军蓝、红、金、银面罩和琥珀/微白灯光的主色关系。
- 不压矮的正比例、清楚的大色块和较现代的画面亮度。
- 金冠、银面罩、红胸门仍是有效的超级系/IP联想入口。

未通过项：

- 轮廓过于通用，遮住配色后缺少只属于馆守Z的识别点。
- 圆肩、胸门和长腿是造型元素，但尚未形成可操作、可讲述、可销售的机构。
- 当前右臂缺失态不适合作为唯一设计母体；它把剧情结果误当成了机体基础设计。
- 细节虽然减少，却从“工程模型”滑向“泛用勇者系”，没有建立馆藏、修复、飞拳与主角升级线之间的独有关系。

后续不再直接迭代当前Q版。先完成 C01E02 双臂完整的高细节收藏母版，再派生 E03 断臂、E04 巡展臂和未来后继臂。

## 3. 双层资产结论

“简化”只适用于游戏生产规格，不等于取消精细设定稿：

| 层级 | 用途 | 细节原则 |
|---|---|---|
| `COLLECTOR_MASTER` | 图鉴、海报、收藏卡、设定集、商品开发 | 高细节，但每处细节必须解释结构、机构、材料或修复历史 |
| `GAME_STANDARD` | 战斗大立绘、Cut-in基础、剧情特写 | 与收藏母版同骨架；减少约45–55%内部线，不改轮廓和核心机构 |
| `Q_RUNTIME` | SRPG sprite、头像小图、战斗棋子 | 约4–4.3头身；减少约70–80%内部线，只保留冠、脸、胸门、肩环和拳臂五个锚点 |

任何层级都禁止用随机划痕、伪文字、满身铆钉或碎小挂件充当“精细”。高细节版本负责近看奖励，游戏简版负责长时间可读性，两者必须能被认作同一台机体。

馆守Z的下一轮合同见 [高细节收藏母版与游戏简版合同](guardian-z-collector-game-dual-spec-v1.md)。

## 5. “土感”现代化修正

用户确认A/B较此前有提升，但整体仍显老派。诊断不是细节过多，而是以下视觉语法同时出现：红蓝金平均分配、金边包甲、完整圆环肩、圆筒前臂、对称柜门胸、厚直腿和产品目录式渲染。

本轮将“机设现代化”和“画风现代化”拆开验证：

- [C稿：现代化上限](art-delivery/review/guardian_z_collector_e02_modern_candidate_v3c.png)：金色降为机构点色，完整圆环改为开放转台弧，胸门改为斜轨档案闸片，肢体形成连续曲线；年轻、利落，但略接近潮流实系机。
- [D稿：现代经典平衡](art-delivery/review/guardian_z_collector_e02_modern_candidate_v3d.png)：沿用C的克制配色和负形，把肩弧收紧、头部放大、胸腔和前臂增重；当前工作建议以此作为机设基准。
- [E稿：二维图形画风](art-delivery/review/guardian_z_collector_e02_modern_graphic_candidate_v3e.png)：不改D的主要结构，只把超合金产品渲染换成线条层级、平涂色块和两级赛璐璐阴影，用于单独判断画风问题。

三稿仍是 Candidate，不自动覆盖 `CML008`，不进入游戏简版或Q版批量派生。

## 6. C×A融合与现代配色

用户选择C稿为较好方向，但指出整体偏纤细，希望吸收A稿体量，并让颜色更现代。

融合规则不是平均混合：C负责开放肩弧、斜轨胸闸、连续流线和低金色占比；A只提供胸腔厚度、前臂抓握感、承重腿、胸门物理厚度与玩具机构的明确程度。

- [F稿：轻盈融合](art-delivery/review/guardian_z_collector_e02_ca_fusion_candidate_v4f.png)：引入钴蓝转折面、冷白结构和更清爽的朱红；机构与颜色成立，但生成结果仍接近C的修长比例。
- [G稿：增重融合](art-delivery/review/guardian_z_collector_e02_ca_fusion_candidate_v4g.png)：在F同一身份上放大头部、增厚胸腔、上臂、前臂、大腿与小腿，约6.8–6.9头身；保留窄腰、开放负形与楔形足，不压回旧式矮墩体型。

现代色板锁为候选：墨蓝主甲、少量高纯钴蓝转折面、清亮朱红胸闸、冷白/银结构、极少淡香槟机构、微白/暖琥珀机魂光；禁止青光、金边包甲和平均彩条。

当前工作建议为G稿。仍待用户确认，不自动进入 `CML008` 或派生游戏简版/Q版。

## 7. A稿母体回归：厚重与强头冠优先

用户复评后确认：A稿仍优于C/G。A的厚重感更符合全剧主角机，头冠是核心识别标志；C虽较现代但偏纤细，G仍不够重，且弱化冠形后头部趋于圆滑、普通。

因此撤销“G为当前工作建议”，改为：A锁身体与头冠层级，C/G只贡献现代色板、材料克制和表面组织。

- [H稿：A母体现代化](art-delivery/review/guardian_z_collector_e02_a_modern_candidate_v5h.png)：约6.5–6.7头身，保留A的巨胸、巨肩、粗前臂、承重腿与宽足；使用墨蓝、钴蓝、朱红、冷白和集中于冠/机构的淡香槟金属。五段冠识别最强，但略有星芒/勇者冠风险。
- [I稿：厚钝屋脊冠](art-delivery/review/guardian_z_collector_e02_a_modern_candidate_v5i.png)：身体不变，只把H的尖长冠片缩短加宽，形成中央红目录钥、两根厚主屋脊和两段低侧檐；维持强标志，同时提高原创性与玩具制造可信度。

H/I仍为Candidate；用户确认冠形前，不生产三视、生命周期换臂、游戏简版或Q版。

## 8. 现代魔神系复审与A稿全身识别

用户明确否决H/I：两稿不是“更有特色”，而是把装饰粗暴堆到头冠，造成头身失衡和星芒勇者感；身体则仍是同一套普通重装机器人。H/I状态改为 `rejected_by_user`，禁止作为后续设计父级。

本轮重新审视 `Mazinger Z / INFINITY`、Mazinkaiser、ZERO、SKL与ZEST等现代魔神谱系。可用结论不是复制任一具体冠、胸板或面罩，而是：

- 冠、英雄脸、红胸和飞拳等经典锚点继续保留。
- 新意由一套结构主题贯穿全身，并通过开合、分离、变形或武器机构获得理由。
- 细节集中于关节、分离缝与真实活动区，外甲保持大色块和重量。
- 同一轮廓节奏应从头胸回声到拳、膝与足，不能只有头部有设计。

完整方法见 [现代魔神系设计审视](guardian-z-modern-mazinger-reference-audit-v1.md)。

[J稿：A母版全身识别型](art-delivery/review/guardian_z_collector_e02_a_fullbody_identity_candidate_v6j.png) 只以A为父级：

- 保留A的厚重比例、原三段冠、银面罩、红胸门与双臂等长。
- 用“馆藏转轴”统一肩、飞拳分离环与膝轴。
- 用“展门折线”统一胸门、前臂外壳与小腿前甲。
- 用“目录脊柱”统一头顶红钥、胸部中轴、腰扣与脚背。
- 取消枪状外挂、独立钴蓝块和过量金边，现代感改由结构、材质和色彩权重承担。

J仍是 `active_a_vs_j_fullbody_identity_review`，未进入Canon，也不派生三视、换臂、游戏简版和Q版。当前门禁只判断一件事：J是否在保持A优点的同时，建立了足够清楚、可操作、可商品化的馆守Z全身身份。

## 9. 经典、复古与朴素的重新划界

用户确认J的银色脸谱和粗飞拳已经能建立魔神投射，但否决整机方向：小圆盔、附着式冠件、金属圆环、对称柜门胸和通用重装四肢共同造成古朴、普通、缺乏主角感。J因此降为 `diagnostic_reference_only`，不得继续充当生产父级。

本轮不再把“经典”理解为保留更多旧式零件：

- **经典**：少量强形体、稳定比例和清楚层级，脱离配色仍能识别。
- **复古**：依赖时代化的圆筒、整圈金属环、柜门对称、方靴和红蓝金均分。
- **朴素**：去掉脸谱与配色后，没有可归属的剪影、动作机构或商品记忆点。

新方案以“断环 + 目录钥”作为贯穿头、肩、胸、拳和足的主符号，以“旋封飞拳”作为能在动画、战斗演出和玩具上复现的招牌机构；头部必须是有前额、中央冠壳、左右侧后盔壳和颈部接口关系的完整头盔，而不是圆帽上附着一组冠角。方法详见 [经典现代综合设计](guardian-z-classic-modern-synthesis-v2.md)。

- [K稿：重冠展架型](art-delivery/review/guardian_z_collector_e02_heavy_crown_frame_candidate_v7k.png)：第一次把完整头盔和肩胸大符号同时建立起来；肩弧过大、双前臂细节未严格镜像，只作结构参考。
- [L稿：断环飞拳型](art-delivery/review/guardian_z_collector_e02_compact_broken_frame_candidate_v7l.png)：收紧肩弧并锁定等长同构旋封飞拳；全身轮廓和动作卖点成立，但侧后盔片放大后层数过多。
- [L头雕三角度](art-delivery/review/guardian_z_head_sculpt_l_three_view_candidate_v7l.png)：作为过度分层上界，证明头盔架构有效，也明确排除鬃甲式连续叠片。
- [M稿：圆帽简化对照](art-delivery/review/guardian_z_collector_e02_plain_helmet_control_v7m.png)：作为朴素下界，证明删除侧后盔壳会立刻退回圆帽、眉条和脸谱的组合；内部否决。
- [N稿：三块盔壳型](art-delivery/review/guardian_z_collector_e02_balanced_vault_helmet_candidate_v7n.png)：沿用L身体，把头部收束为中央冠壳和左右一体侧壳；结构完整但上轮廓仍略圆，降为P的结构前身。
- [O稿：高断拱冠对照](art-delivery/review/guardian_z_collector_e02_high_vault_crown_control_v7o.png)：用左右深蓝侧冠建立强黑影，但抬升过高后读成兽角、虫颚或怪人头；只作角化上限。
- [P稿：低断拱冠型](art-delivery/review/guardian_z_collector_e02_low_vault_crown_candidate_v7p.png)：侧冠降低、后掠并钝化，中央红钥成为唯一最高点；当前推荐继续评审，但尚未通过。
- [P头雕三角度](art-delivery/review/guardian_z_head_sculpt_p_three_view_candidate_v7p.png)：正面、三分之四与侧面验证侧冠确实并入后脑，中央红钥持续主导剪影；是评审证据，不是锁定生产三视。

当前门禁不是让用户在所有历史稿中泛选，而是检查P的中央红钥与低断拱侧冠是否已有主角感、断环肩胸是否具有独占剪影、旋封飞拳是否足以成为馆守Z的商品与演出核心。P仍为Candidate；确认前不生产三视、生命周期换臂、游戏简版和Q版。

## 10. 九头身、分离式X与枢轴天线

用户对v7做出新的局部裁决：截图中的L头盔基础可用，天线需要继续设计；P/K两稿身体均可作为父级；整机改为九头身；肩甲适度复杂化并回收J稿胸肩连接铰链和点缀色；胸甲不能沿用大型飞翼胸板，胸前X应由肩甲继续；整机增加2至3处纹章、编号或标志。

本轮据此建立 [九头身铰接X综合设计](guardian-z-nine-head-hinged-x-synthesis-v3.md)：

- 比例增量集中于大腿、小腿和颈部，保留深胸、宽肩、粗旋封飞拳与宽足。
- 胸前X由四块短红楔组成，严格收在躯干；肩甲红白斜片隔着可见三轴铰链延续X，避免一体飞翼胸甲。
- 每侧肩甲最多三块大质量；J只贡献三轴铰、单枚香槟锁扣和小状态片，不恢复整圈金环。
- 标识限定为左肩几何馆章、右肩`MMM`、小腿候选`GZ-01`及三条刻度。生成图只验证位置和密度，正式版必须使用矢量贴花；`GZ-01`不构成Canon编号。

候选结果：

- [Q稿：九头身铰接X基线](art-delivery/review/guardian_z_collector_e02_ninehead_hinged_x_candidate_v8q.png)：身体方向成立，天线仍偏普通V角。
- [R稿：档案夹天线对照](art-delivery/review/guardian_z_collector_e02_ninehead_archive_clamp_control_v8r.png)：端部像钥匙齿/鹿角，否决。
- [S稿：剪式X天线](art-delivery/review/guardian_z_collector_e02_ninehead_scissor_antenna_candidate_v8s.png)：视觉联系最强，但跨角度不稳定，保留为风格化备选。
- [T头雕三角度](art-delivery/review/guardian_z_head_sculpt_pivot_antenna_three_view_candidate_v8t.png)：每侧内眉片、圆铰、宽钝外片均能跨角度保持。
- [T稿：九头身枢轴横冠型](art-delivery/review/guardian_z_collector_e02_ninehead_pivot_antenna_candidate_v8t.png)：v8当时的完整机设建议，身体沿用Q，头部采用T三视结构；后被第11节的用户裁决整体否决。
- [U稿：目录缺口对照](art-delivery/review/guardian_z_collector_e02_ninehead_catalog_notch_antenna_candidate_v8u.png)：缺口再次产生钥匙齿读取，否决。

上述是v8当时的候选结论；现已被第11节的K上半身回归裁决覆盖。

## 11. K上半身回归、横向红肩前甲与双辅助天线

用户明确否决v8的上半身解法：Q/T把“肩前甲”错画到真正肩甲上，又把K稿最重要的红色胸口卡扣拆成四块通用X楔，导致厚重上身和玩具识别钩同时丢失。因此Q、S、T不再是有效上半身父级，v8只允许继承腰以下的九头身增量、J式肩铰和稀疏贴花密度。

修正后的硬约束详见 [K上半身、红肩前甲与九头身综合设计](guardian-z-k-upper-red-shoulderfront-synthesis-v4.md)：

- K稿锁定腰带以上的体积、宽度、红色双片胸口卡扣、象牙白中轴、深蓝C形真正肩甲与粗壮双飞拳。
- 新增红甲是安装在肩关节正前方的“肩前甲”，从胸口红甲外上角向左右水平延伸；它与胸甲远看连续，但必须与深蓝主肩甲和石墨铰链近看分层。
- 九头身只通过大腿、小腿和踝段拉长；不减小头、胸、肩、上臂或飞拳。
- 头雕保留用户选定的完整深蓝头盔和宽主眉冠，只在中央冠后方增加正好两根短辅助天线。参考Z高达的“主天线 + 次级天线”层级，不复制其具体V角和头部轮廓。

候选结果：
