# 馆守Z：经典现代主角机综合设计 v2

> 状态：`candidate_design_synthesis`  
> 适用时点：C01E02双臂完整态  
> Canon边界：不新增武器、能力或剧情结果；只重构视觉身份、可动理由与商品机构。
>
> 后继：当前九头身、肩胸X、肩铰、标识与天线方案见 [九头身铰接X综合设计 v3](guardian-z-nine-head-hinged-x-synthesis-v3.md)。本文件保留为v7“经典/复古/朴素”判断与断环、旋封飞拳来源。

## 1. 先区分经典、复古与朴素

### 经典

- 只靠少数大形就能被记住，黑影、玩具、动画小图都成立。
- 头、胸、拳、足有清楚层级，十年后仍可被不同画风重新解释。
- 结构简单不等于没有设计；每一块大形都在塑造角色。

### 复古

- 依赖特定年代的现成语法：整圈金边、圆轮关节、对称柜门胸、圆筒前臂、红蓝金平均分配、厚方靴。
- 可以作为血统提示，但不能成为整台新主角机的主体。

### 朴素

- 拿掉脸谱和配色以后，头盔、肩、躯干、腿都能与普通重装机器人互换。
- 没有招牌姿态、招牌机构和能用一句话描述的独占轮廓。
- 这不是克制，而是设计尚未完成。

馆守Z应当“经典而不复古，清楚而不朴素”。

## 2. J稿的失败点

J稿只通过了两个项目：银色脸谱与粗壮飞拳让魔神投射成立；A稿的主角体量没有丢。

其余项目仍不通过：

- **头雕**：脸被一顶偏小、近圆形的深蓝帽壳包住；红额块和金色眉冠像外挂零件。正面尚可，侧面与后脑没有主角机级体积和走势。
- **肩胸**：肩壳、齿圈和红胸门彼此并列，没有共同组成一个大符号。
- **飞拳**：虽然容易联想到火箭拳，但仍是普通大圆筒；没有只属于馆守Z的发射前动作。
- **腿足**：承重成立，但与上半身没有形态回声，像从另一台重装机借来。
- **色材**：墨蓝、红、银、金本身没有错，问题是金属圆环和完全对称的大柜门继续强化了复古陈列品感。

J稿状态应改为 `diagnostic_reference_only`，禁止直接派生三视、游戏简版或Q版。

## 3. 可综合的现代主角机方法

| 参照 | 可用方法 | 馆守Z不照搬的部分 |
|---|---|---|
| `Mazinger Z / INFINITY` | 影片先保轮廓，机械细节服务动作；武器出口和装甲分割随演出建立 | 具体冠、面罩、胸板和分甲 |
| Mazinger X | 一个强图形同时进入强化装备和双臂玩法，让升级形态一眼可述 | `X`字、飞翼与切割器造型 |
| Grendizer U | 保留老识别点，同时重做头盔体积、肩胸关系、前臂动作件与身材比例 | 双角、胸纹、圆盘肩与双刃拳 |
| RIOBOT Mazinkaiser | 质量感来自厚重轮廓、动态姿态下不散架、全身可见机构与清楚材质层 | 皇帝冠、翼、剑与凯撒胸纹 |
| Mazinger ZERO / ZEST | 脸、胸、头顶接合和飞拳都能成为主动机构；透明件只放在关键能量/接合位置 | 开脸、高热板、飞行器及具体武器 |

综合结论：一台现代经典主角机需要“一个全身主符号 + 一个招牌动作机构 + 一个完整头盔架构”，而不是更多装甲块。

## 4. 馆守Z的新主符号：断环 + 目录钥

### 4.1 断环

- 取消J稿的完整金色齿圈。
- 左右肩各有一段厚实、深色、带负形缺口的三分之二展架弧；两弧与胸门上沿共同构成一个被中轴切开的“断环”。
- 正面看，它在中央目录钥两侧形成主角机级大框架；侧面看，展架弧后掠并包住肩轴，成为独占轮廓。
- 展架弧可小幅转动以配合抬臂和维修展示，但本轮不赋予武器能力。

### 4.2 目录钥

- 不再只是额头红块。它是一根从头顶嵌入头盔、在胸部继续、到腰扣终止的纵向视觉楔。
- 红色目录钥顶部略前倾，底部锁进深蓝眉架；胸部对应为窄而亮的钛白/象牙白中轴与微白核心。
- 目录钥与断环组合后，形成馆守Z独有的“中央钥开启展架”图形，但不写成字母或馆标。

## 5. 新头雕：低断拱冠头盔

头部必须分成三层，而不是“脸 + 冠”。

1. **脸层**：保留通过的琥珀眼与银色纵栅面罩；脸略宽、下颌短而有重量。
2. **盔层**：深墨蓝头盔由左右两块一体侧壳从太阳穴连续包覆到后脑。两壳低矮后掠、末端宽钝，与中央冠之间保留清楚负形；不得变成圆帽，也不得抬成兽角。
3. **冠层**：中央红目录钥嵌入屋脊状中央冠壳，并成为全头唯一最高点。淡香槟金只在眼线上方形成短承托边，不再承担长角剪影；整头严格保持中央、左、右三块主冠质量。

可加入两小块烟灰透明“馆藏玻璃”嵌片，位置限定在侧鬓与目录钥根部；它们只发微白光，不用青光。

验收：遮住脸以后，单看头盔黑影仍像主角机；正面先读中央红钥，三分之四角度再读到两块低断拱侧冠，侧面能读到侧冠并入完整后脑。

## 6. 招牌机构：旋封飞拳

- 前臂从圆筒改成三片大壳围成的略扁六边形拳舱，保持粗壮，但正面与侧面都有方向性。
- 发射前，三片外壳沿肘部断环旋转一个小角度，露出钛白内环和微白锁定缝；随后拳体脱离。
- 静止、解锁、发射后三个状态仅靠同一组零件完成，适合动画、Cut-in和玩具演示。
- 右臂生命周期继续使用统一肘接口：完整原臂、E03断口、E04巡展臂、未来后继臂都读取同一断环尺寸。
- 禁止做成钻头、炮管、刀刃或外置枪械。

## 7. 肩胸腿的整机回声

- 红胸门从矩形柜门改成两块厚实的内凹括片：上沿接住肩部断环，下沿斜切指向中央目录钥。
- 小腿不复制胸门，只在外侧保留一条后掠断环切口；脚背用短目录楔收束，避免全身贴同一图案。
- 肩、胸、拳承担高风格；大腿、腰与脚承担休息区。细节密度呈 `高—低—高—低` 节奏。
- 头冠最高点、肩环外缘、胸门下角、前臂外角与小腿切口应形成一条连续的下落曲线，让厚重机体仍有速度感。

## 8. 配色与材质

- 近黑墨蓝 52%，钛白/冷银 20%，清亮朱红 17%，石墨关节 7%，淡香槟金 2%，微白/暖琥珀光 2%。
- 金色只留在眉冠、门铰和少量旋封锁扣；不再出现整圈金环或金边包甲。
- 红色只集中于头顶目录钥、胸门和前臂一处识别块；小腿不铺大面积红板。
- 两三块烟灰透明件作为现代材料记忆，不能变成全身发光骨架。

## 9. 两条候选方向

### K：重冠展架型

- 更接近A的厚重与经典感。
- 强化完整头盔、宽眉架、肩部断环和胸门大框架。
- 旋封飞拳清楚但外形克制，目标是“看一眼就像能卖很多年的主角机”。

### L：断环飞拳型

- 同样保留A体量，但肩部负形更开放、前臂旋封更显性、胸门更图形化。
- 更年轻、更有动画招牌动作，现代感上限更高。
- 风险是过度开放后漂向实系/潮流机，必须保留银脸、粗拳与厚胸。

### N：三块盔壳结构前身

- 在L的叠片过繁和M的圆帽朴素之间先建立中央、左、右三块盔壳。
- 结构清楚但顶轮廓偏顺滑，证明“完整”不自动等于“有主角感”。

### O：高断拱冠上限

- 用深蓝侧冠替代金色长角，黑影强且能够回声肩部断环。
- 侧冠过高后会被读成兽角、虫颚或怪人头，只作剪影强度上限。

### P：低断拱冠当前建议

- 保留O的三块主冠质量，把左右侧冠降低约三成、末端钝化并以向后展开为主。
- 中央红钥成为唯一最高点；比N醒目、比O克制，也避开普通V角与星芒勇者冠。
- 身体严格沿用L的断环肩胸和等长旋封飞拳，只修头盔，不用更换整机掩盖判断。

## 10. 验收门

1. 遮住脸，头盔仍有主角感。
2. 遮住头，肩胸断环与旋封飞拳仍能认出馆守Z。
3. 不看说明，玩家能猜到胸门会开、肩架会动、拳舱会旋封并发射。
4. 黑影不依赖金色圆环、红柜门和方靴等复古语法。
5. 同时通过“魔神/火箭拳血统”和“万机馆独占身份”两次阅读。
