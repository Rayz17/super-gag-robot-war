# 馆守Z高细节收藏母版与游戏简版合同 v1

> 状态：`candidate_design_contract`  
> 目标：让馆守Z同时成立为全剧主角机、可商品化机器人和可持续生产的游戏资产。  
> 基础时点：先画 C01E02 双臂完整态；E03/E04状态作为同骨架换装，不反向破坏基础机设。

## 1. 一句话设计命题

**一台从万机馆中央展台醒来的经典超级机器人：外轮廓像能被孩子一笔画出，打开胸门、转动肩环、发射拳头以后，才发现整座博物馆的收藏与修复逻辑都藏在机构里。**

它不是“穿古董装甲的工业机器人”，也不是“把魔神零件换个颜色”；它必须先是一台有英雄脸、有拳头、有必杀姿态的主角机，再把万机馆身份变成可操作的原创结构。

## 2. 三道设计门

### 2.1 黑影门：三秒认出

关闭颜色和内部线后，至少保留五个独占锚点：

1. **万机冠**：中央竖直“目录钥”与两侧低展翼组成三段冠；不是标准V字天线，也不是多刺王冠。
2. **展门胸**：两片红色厚胸门形成向外开启的括弧轮廓，中间留出竖向馆藏核心。
3. **转台肩**：肩部不是光滑圆球，而是“外装甲弧 + 可见转台环 + 内侧轴肩”的三层剪影。
4. **目录拳**：前臂比上臂更有重量，拳套外壳形成一眼可懂的发射筒轮廓。
5. **展台足**：小腿下段与脚跟形成稳定的馆台基座轮廓，站姿厚重但不矮墩。

比例采用约6.8–7头身：胸肩宽、腰短而收、前臂有重量、小腿稳定。不能再做成长腿圆肩的泛用勇者体型，也不能回到等密度工程模型。

### 2.2 玩具门：五分钟能演一场戏

基础玩具至少具备以下可见玩法：

1. 左右拳可发射/替换，肘后能读到简洁的飞拳导轨。
2. 红色胸门可向外开启，露出“0号馆藏核心”；该机构当前只锁视觉，不擅自增加新武器Canon。
3. 肩部转台环可转动或外翻，为抬臂和飞拳姿态提供结构理由。
4. 右前臂采用统一接口，可换完整原臂、E03断裂封口、E04巡展臂和未来后继臂。
5. 头冠中央目录钥可升起/压下，用于待机与觉醒两种脸部轮廓；不做驾驶舱或飞行器直接对接，避免照搬经典合体头部结构。

可选商品玩法：展示底座做成万机馆展台，能收纳右臂模块并显示四个生命周期位置；该项不进入机体Canon。

### 2.3 IP联想门：像“这一脉”，但不是“那一台”

| 需要让玩家联想到 | 馆守Z的表达 | 禁止直接照搬 |
|---|---|---|
| 魔神系英雄脸 | 金色强冠、银色口罩、琥珀眼、黑/深蓝头盔 | 原版V冠角度、完全相同的五边形面罩、头顶飞行器轮廓 |
| 经典超级系胸部武装感 | 红色大胸门与中央发光核心形成正面视觉焦点 | 原版胸鳍/放热板的具体外形与展开方式 |
| 火箭飞拳 | 粗壮前臂、可见发射接口、拳头脱离后的干净套筒 | 直接复刻既有前臂花纹、切割和武器名称 |
| 老机器人升级史 | 同一骨架的原臂、断臂、巡展臂、后继臂 | 用无关装饰冒充升级，或每形态彻底换一台机体 |
| 本作万机馆 | 展门胸、转台肩、目录钥、馆藏核心、修复色块 | 满身标签、伪文字、随机编号和博物馆贴纸 |

验收不是逐件比对，而是两次阅读：第一眼让机器人动画观众感到“经典超级系/飞拳系血统”，第二眼能明确说出它为何只可能属于万机馆。

## 3. 造型与机构方案

### 3.1 头部：万机冠与档案面

- 额头中央为短而厚的红色目录钥，觉醒时上升半格；两侧金冠低平外展，形成屋檐/展柜门框联想。
- 银色面罩保留竖向通气节奏，但改成中央窄、两侧斜切的“闭合档案夹”结构，避免复刻魔神口罩比例。
- 面颊深蓝块向后包住圆形听觉/轴承结构，正面不增加小零件。

### 3.2 胸部：0号展门

- 红胸不是贴在躯干上的两块板，而是两扇真正有厚度、有铰链、有内侧结构的门。
- 闭合时红门与中央深蓝脊柱共同形成大写 `Z` 的抽象折线，但不绘制文字。
- 开启时露出象牙白内舱与琥珀/微白核心；内侧可有高细节机械，外表面保持清楚大色块。

### 3.3 肩部：馆藏转台

- 保留图三圆肩带来的厚重感，但把“圆”变成机构：外侧弧形护罩、金色展台环、内侧黑色轴肩三层分离。
- 抬臂时金环转向，与前臂导轨形成一条清楚的发射姿态线；静止时则像万机馆的旋转展台。
- 肩环是馆守Z最重要的原创商品记忆点之一，不能缩成普通圆肩描边。

### 3.4 手臂：剧情就是换装系统

- C01E02母版必须双臂等长、左右同源，先让观众记住完整机器人。
- 前臂外壳使用大面积深蓝，靠近腕部只有一组红/象牙白/金色档案色带；色带是模块识别，不铺满全身。
- E03损坏态拆成独立 `DAMAGE`：右臂在肘下缺失，断口封装成一个清晰大形，不能靠伸长、缩短或姿势错觉表达。
- E04巡展臂在相同接口上采用异色修复壳与更朴素的手型，长度仍与左臂相等。
- 未来后继右臂只预留接口尺寸和连接语言，不在本轮提前定外形。

### 3.5 腰腿：站得住的主角

- 腰部只留中央红色锁扣与左右两块蓝色髋甲，避免细腰叠甲。
- 大腿相对简洁，小腿外侧出现一条金色展柜框；膝部保留可动所需的机械层，正面不铺散热槽。
- 脚掌宽而前翘，脚跟形成展台台阶；必须支持双脚站立、飞拳前倾和单膝跪地三个玩具姿态。

## 4. 细节不是删掉，而是分配

### `COLLECTOR_MASTER`

- 外甲使用大块干净平面；高细节集中在胸门内侧、肩环内圈、肘部导轨、手指、膝后和脚底。
- 每个肢体最多2–3条主分件线；螺栓只出现在真实拆装点，不做均匀撒点。
- 修复历史用3–5块明确异材质补片表达，不使用满身随机掉漆。
- 材料分为：半哑光深蓝外甲、饱和红门、温金结构框、拉丝银面罩、深灰关节、象牙白/琥珀核心。
- 允许图鉴、海报、收藏卡显示门铰、导轨、内构和材料磨耗。

### `GAME_STANDARD`

- 100%继承收藏母版的轮廓、比例、门/环/拳机构和模块接口。
- 删除约45–55%内部线；单个色块小于胸宽1/20时原则上合并。
- 磨耗、标签、铆钉和内构默认不画；只有胸门开启或飞拳特写时临时恢复相关结构。
- 阴影保持两级，关节可用一组深灰概括，不把收藏稿直接缩小。

### `Q_RUNTIME`

- 约4–4.3头身，手脚放大但大腿和小腿都必须存在，避免一图多机时自动压矮。
- 只保留万机冠、银面罩、红胸门、转台肩、目录拳五个锚点。
- 肩环简化为一外环一内轴；胸门简化为红色双块加中央光；前臂色带简化为三格。
- 64–96 px下黑影仍能区分头、肩、拳和脚；随机磨损与伪文字为零。

## 5. 画风落点

馆守Z采用“现代动画机设线稿 + 选择性模型质感”：

- 轮廓和变形关系先按动画设定图建立，材料光泽只在第二层加入。
- 常态配色明亮、清洁、饱和，避免暗黑、异形和全身旧化。
- 线条以直线、缓弧和少量45度切角构成；不用全身尖刺，也不靠高达式密集分甲制造现代感。
- 图鉴/海报可提高内构、反射和局部磨耗；游戏版保留同一外形，用平涂与两级阴影减负。
- 强风格集中在出拳透视、胸门开启和机魂微白光时刻，不给每一帧持续套强滤镜。

## 6. 第一轮必须分开出图

1. `GZ_COLLECTOR_E02_INTACT_STAND`：双臂完整、前3/4、收藏母版。
2. `GZ_COLLECTOR_E02_REAR`：后3/4，验证肩环和飞拳接口。
3. `GZ_COLLECTOR_CHEST_OPEN`：胸门开启，单独展示内构。
4. `GZ_ARM_MODULE_LINEUP`：完整原臂、断裂封口、巡展臂三件同尺度；后继臂只留灰色占位。
5. `GZ_GAME_STANDARD_E02`：从1号母版人工提炼，不重新自由生成。
6. `GZ_Q_RUNTIME_E02`：从5号母版派生。
7. `GZ_GAME_E03_DAMAGE`：只替换右前臂状态。
8. `GZ_GAME_E04_TOURING_ARM`：两臂严格等长。

不得把三排多机、正比/Q版、站姿/必杀Pose塞在一张图里。每个资产独立画布、无场景背景、无日文、无伪文字，后续才便于切图、动画和版本管理。

## 7. 通过条件

- 纯黑剪影与旧图、普通勇者系、高达系机器人能明显区分。
- 96 px缩略图仍能读出五个锚点。
- 不看设定文字，也能指出至少三处可操作机构。
- 拆下颜色后仍是馆守Z；恢复颜色后能联想到经典魔神/飞拳系血统。
- 完整原臂、断臂、巡展臂在同一肘接口成立，且左右手臂总长一致。
- 收藏母版与游戏简版叠轮廓时，头冠、胸门、肩环、肘腕、膝脚关键点偏差不超过2%。
