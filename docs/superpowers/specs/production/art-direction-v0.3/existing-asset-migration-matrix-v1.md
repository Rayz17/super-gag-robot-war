# 既有美术资产复杂度迁移矩阵 v1

> 状态：`candidate_migration_matrix`  
> 基准：[美术风格与跨规格细节预算](art-style-and-complexity-budget-v1.md)  
> 原则：不把所有旧图判废；先区分基础母版、Q/runtime、Cut-in/主视觉和剧情状态层。

## 1. 迁移动作

| 动作 | 含义 |
|---|---|
| `P0_REBASE` | 身份、年龄、主角层级或基础结构有问题，必须先重做正比例母版，再派生其他规格 |
| `P1_Q_REDERIVE` | 正比例身份可保留，但Q版错误继承全部细节；从简化母版重新设计，不局部擦线 |
| `P1_SURFACE_PASS` | 保留轮廓与比例，只压缩面板、污痕、挂件和高对比小色块 |
| `P2_KEEP_CUTIN` | 细节密度适合作为海报、必杀、剧情特绘，不再当普通走图母版 |
| `STATE_LAYER_SPLIT` | 把磨损、污迹、纸页、灯效和剧情损伤从 `BASE_CLEAN` 拆出 |
| `DEPENDENT_REGEN` | 当前资产引用旧人物/机体母版；待新锁确认后整体重派生 |

## 5. 推荐生产顺序

1. 用户确认本轮纪存与馆守Z候选，确定成人化和英雄化的幅度。
2. 重做白鸢基础母版，同时把唐胶、兜灯、七海的Q版按三锚规则重派生。
3. 用同一机制处理馆守Z的E01半跪、E02双臂、E03缺臂、E04巡展臂装四状态。
4. 处理三相盖流三形态与三单体，先统一低细节色块映射，再做六张Q版。
5. 处理火种货柜全变形链、风险标记无人机B和其他地图单位。
6. 最后重派生C01剧情演出、头像、方向、动作与Cut-in，避免在未锁母版上重复生产。

## 6. 不变项

- 不因简化改变唐胶、兜灯、七海、白鸢已经确认的脸、性别、体态和职业身份。
- 不因强化馆守Z主角感而照搬原IP零件；联想依靠超级系比例、冠、金属面罩、红胸门和拳的组织方式。
- 不把三相盖流的模式差异、三机颜色位置和生物合体特征简化掉。
- 不把静态剧情特绘的细节上限强行压到Q版水平；规格分层而非全项目一刀切。
