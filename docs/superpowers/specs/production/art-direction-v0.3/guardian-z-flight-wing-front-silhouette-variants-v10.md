# 馆守Z：大型飞翼正面剪影五案 v10

> 状态：`a_twin_wing_reselected_as_hard_parent_for_v12_extremes`  
> 用户结论：v14双宽板主翼与两根上举小翼显得笨拙  
> 保留：W/X馆守Z本体、v14裸机八枚姿态喷口、可拆卸大型飞行背包分层  
> 本轮目标：只比较外挂飞翼的正面主角机剪影，不迁移Canon

## 1. v14为什么显得笨

1. 两片大红板几乎是完整实心多边形，负空间太少，翼面像两块标牌而不是飞行机构。
2. 两根短上稳定翼过细、过直、向上举起，从正面容易读成天线、把手或背后举着两根杆。
3. 主翼与小翼的体量差不是有意识的主次，而是“大板 + 小杆”的失衡；断X概念成立，造型却没有说服力。
4. 中央红白锁体过像第二个胸口，和馆守Z正面的红胸卡扣争夺主视觉中心。

## 2. 共同硬约束

- 馆守Z本体完全沿用W/X：头冠、面甲、红胸卡扣、厚上身、九头身、等长双飞拳和长腿不改。
- 翼根始终在肩后，不覆盖头冠、脸、红肩前甲、胸口、前臂、髋部和腿。
- 维持现代正红、墨蓝承力框、石墨机构、象牙白锁件与少量暖琥珀；不使用青光。
- 本轮为完整双臂工程视，不代表C01E04右臂毁损与巡展臂状态。
- 不画飞机机首、座舱、导弹、炮管、长圆筒、油箱、羽毛、蝙蝠膜或奇幻生物翼。

## 3. 五个正面候选

### A：红弓宽翼

- [正面挂载图](art-delivery/review/guardian_z_c01_flight_wing_front_candidate_v15a_red_bow.png)
- 每侧只有一片长翼，整体形成浅上弧红弓；完全取消小稳定翼。
- 优点：经典、直接，本体仍是视觉中心，最接近“现代化喷射飞翼”的安全答案。
- 风险：横向与航空翼感仍较强，馆守Z独占机构不足。

### B：折刃双段翼

- [正面挂载图](art-delivery/review/guardian_z_c01_flight_wing_front_candidate_v15b_hinged_blade.png)
- 每侧由短内段、巨大圆形铰链和长下折外段组成。
- 优点：折叠玩具机构一眼可读。
- 风险：从正面像背后多出两条机械长臂，飞翼读取弱；只保留为诊断稿，不建议推进。

### C：下掠披风翼

- [正面挂载图](art-delivery/review/guardian_z_c01_flight_wing_front_candidate_v15c_downswept_mantle.png)
- 两片大翼由肩后拱起，再下掠到小腿高度；中央使用巨大开口减轻实心板感。
- 优点：压迫感和强化形态尺度最强。
- 风险：大开口框架仍像巨臂或建筑门架，飞行速度感不足；只保留为诊断稿，不建议推进。

### D：分叉矢翼

- [正面挂载图](art-delivery/review/guardian_z_c01_flight_wing_front_candidate_v15d_split_arrow.png)
- 每侧一片长矢翼，以一条菱形负空间分成红色上承力边与墨蓝下承力边，只用一枚象牙白桥锁跨接。
- 优点：断框主题、商品机构和现代速度感统一，五案中最像馆守Z自己的飞翼。
- 风险：横向翼展最强，需要后续略收短约8%，避免装备压过本体。

### E：平衡四刃X翼

- [正面挂载图](art-delivery/review/guardian_z_c01_flight_wing_front_candidate_v15e_balanced_x.png)
- 上主翼与下副翼都有完整体量，以明显不同长度组成开放X，不再使用细小稳定杆。
- 优点：现代魔神系飞行强化关联最直接，正面主角机识别强，量产与动画拆分清楚。
- 风险：直线大翼容易靠近通用高达系背包，需要在翼根和翼端继续强化断框与短粗推力盒。

## 4. 当前建议

优先进入下一轮的是 **D与E**：D负责馆守Z独占身份，E负责魔神系飞行强化的直觉读取。A作为更经典、克制的安全基准保留。B与C已完成诊断职责，不建议继续精修。

用户选择方向后，再为入选稿补：单体背面、挂载背面、严格侧面、收纳态、翼根短粗推进盒和C01一次点火演出。当前不再为五案同时扩写全套资产。

用户随后确认E稿思路正确，但指出尺寸有余、特色不足，并要求把翅膀与喷射背包融合，同时完整交付正面、背面和背包单体。E稿已作为概念父级进入 [E2矢量喷翼一体背包](guardian-z-vector-jet-wing-integrated-e2-v11.md)；A至D保留为对照，不再并行扩写全套资产。

用户复核E2三图后进一步裁决：四翼机构仍然呆板，整体甚至不如A稿双翼。A因此从“安全基准”升为新一轮硬父级，E/E2降为失败机构记录。当前正面方向见 [A双翼极端推演](guardian-z-a-twin-wing-extremes-v12.md)。
