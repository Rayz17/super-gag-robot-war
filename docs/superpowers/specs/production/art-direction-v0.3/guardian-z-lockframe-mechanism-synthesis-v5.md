# 馆守Z：断框身份与万机锁架机构 v5

> 状态：`candidate_design_synthesis`  
> 当前父级：W稿，`guardian_z_collector_e02_k_upper_lateral_shoulderfront_candidate_v9w.png`  
> 适用生命周期：C01E01封存、C01E02双臂完整、C01E03火箭拳解锁与右前臂毁损  
> Canon边界：本轮只视觉化现有火箭拳、原右前臂毁损和回收接口烧毁；不新增武器、变形能力、防御功能或后继右臂定案。

## 1. 目标

W稿已经建立头、红胸卡扣、横向红肩前甲、深蓝C形肩甲与粗壮飞拳的正面身份。X稿不重做W，而是把这些部件收束为一套能同时承担主视觉、火箭拳演出、右臂伤口和玩具联动的“万机锁架”。

“万机锁架”只是设计工作名，不进入剧情显示、玩法名或Canon机构名。

## 2. W硬不变项

- 保留K/W的厚胸、宽肩、九头身长承重腿和大尺寸等长双飞拳。
- 保留红色双片胸口卡扣、横向红肩前甲、象牙白中轴和暖琥珀/微白核心。
- 保留用户选定头盔、宽金色主眉冠和正好两根短辅助天线。
- 保留墨蓝、清亮朱红、冷白/银、石墨、少量淡香槟与微白/暖琥珀灯光；无青光。
- 不增加大翅膀、巨大背包、额外变形模式、新武器、星芒冠、细碎贴花或随机损伤。

## 3. X稿三项结构修正

### 3.1 C形肩甲：完整轮胎感 → 厚重断框

- 每侧主肩甲仍是巨大深蓝C形承力框，但将过于顺滑的圆环改成三至四段宽厚折面。
- 在内前下方留一个唯一的矩形/梯形缺口，让红肩前甲的宽钝外端视觉上正好扣入。
- 断框必须仍保持巨大并独立于红肩前甲；不缩成高达式小肩盔，不变成轮胎、光环或翅膀。

### 3.2 飞拳上端：三段旋封环

- 在每只前臂靠近肘部的银白分离环上建立正好三块宽大旋封环片。
- 三片是大轮廓零件，闭合时组成一个完整粗环，解锁时以小幅径向张开显示深色接口。
- 不在环上增加齿轮集群、多层小门、警示文字或细碎内构。

### 3.3 下肢呼应：只重复一次断框缺口

- 在膝甲或脚背中只选一处，增加一个大尺度断框缺口。
- 当前优先脚背：象牙白脚背板与深蓝足甲之间留一个梯形咬合缺口，与肩断框同语法。
- 膝甲保持安静，不再叠加第二套彩色符号。

## 4. 万机锁架的四个验证状态

### A. 封存态

- C01E01展台时点，但机制图可以站立上半身示意，不代替正式“半跪展台”剧情立绘。
- 红胸卡扣与红肩前甲完全闭合，肩断框位于中性位，三段旋封环完全合拢，眼与核心暗。

### B. 启动态

- 双臂仍完整等长。红肩前甲从肩断框缺口中向外滑开少许，红胸卡扣只向外打开小角度。
- 肩断框小幅转动，露出石墨内轨与微白/暖琥珀灯线；不形成胸翼、肩翼或背翼。

### C. 火箭拳解锁态

- 默认演示机体自身右拳，在画面中位于观者左侧。
- 右红肩前甲后撤，右肩断框小幅转动承担发射动作；右前臂上端三段旋封环张开。
- 右前臂可与上臂肘端出现很小的清楚分离缝，但前臂仍完整可见，无损伤、无爆炸、无新武器。

### D. 失去原右前臂态

- C01E03之后：机体自身右前臂与右拳完全缺失，右上臂仍在，肩、上臂长度和左侧一致。
- 画面中缺失位于观者左侧；右肘端保留烧毁的石墨回收接口、少量断裂三段环片与极少暖橙余热。
- 不拉长残臂，不缩短上臂，不安装完整手臂、拳头、巡展臂装或后继右臂，不画大量喷火与血腥断肢。

## 5. 机制验证图版式

- 横向四格，每格使用同一比例、同一前三分之四上半身角度和同一光照。
- 不放置文字、日文、英文、伪字、界面、场景、爆炸或背景机体。只允许细浅灰分隔线与少量无文字机构箭头。
- 画面应让评审者不看说明也能读到“闭合 → 小幅展开 → 发射解锁 → 右前臂缺失”。

## 6. 验收门

1. X是否仍是W，而不是另一台机体。
2. 肩甲是否从“轮胎”变为带唯一缺口的厚断框，红肩前甲是否确实扣入缺口。
3. 三段旋封环是否使火箭拳分离更可读，又没有增加细碎内构。
4. 断框缺口是否只在脚背再出现一次，膝与小腿仍有休息面。
5. 四状态是否使用同一机体、同一比例和同一部件数量。
6. 毁损态是否只缺机体自身右前臂，右上臂与肘端烧毁接口仍清楚。
7. 整体是否无大翼膀、巨大背包、新武器、青光、日文、伪字和多余细节。
