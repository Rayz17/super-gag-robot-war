# 馆守Z：W母体短厚背面与“整机飞拳”推进骨架 v8

> 状态：`partial_parent_only_propulsion_concept_superseded_by_v9`  
> 保留：W稿正面、X稿断框机构、Y稿严格侧面比例  
> 废弃：V12YR纵向H脊背面、航空双圆筒推进骨架  
> 适用：C01E02完整裸机背面；C01推进骨架工程挂载验证  
> Canon边界：馆守Z没有常态飞行能力；推进骨架是全尺寸退役巡展装备，只支持C01E04一次直线离舰出击，随后报废。

## 1. 上一稿为什么不成立

1. V12YR把从后颈贯穿后腰的银色H架画成视觉主轴，背躯因此比W稿明显更长，失去“短、厚、上宽下急收”的上半身比例。
2. 背面用细长中脊组织结构，正面的横向红胸卡扣、宽肩断框和紧凑腰节没有在背面得到对应。
3. 推进骨架由两根长圆筒和管线构成，读取更接近航空发动机或火箭助推器，不像馆守Z自己的超级机器人装备。
4. 装具的视觉重量集中在长筒下半部，削弱头、肩和上胸的主角机中心，也没有复用断框、红锁块与三段旋封环。

## 2. W母体背面比例

- 正面W/X与背面必须共用同一骨架：后颈至腰带上缘的距离不得长于正面胸口至腰带的距离，上背高度约为整机一头半，不得出现贯穿躯干的长直脊。
- 肩框外宽、上臂位置、腰线、胯宽、腿长和足部尺寸与W/X严格一致；九头身来自长腿，不来自拉长胸腹或背脊。
- 背躯轮廓是宽倒梯形：肩胛处厚而宽，经过两级大甲片后立即收进窄腰。肩轴仍是断框的力路核心，但尺寸从属于肩甲，不成为背后两只轮胎。
- 上背使用左右两块大面积墨蓝肩胛甲，甲缝向中央构成短而宽的倒V/断X，不新增满背红甲。前方红肩前甲只允许在身体侧缘露出少量自然厚度。

## 3. 裸机接口与姿态喷口

- 取消可见的纵向H轨。四个挂载锁座分别嵌入左右肩胛甲下缘和左右后腰甲上缘，未挂载时与外甲齐平。
- 肩胛之间只保留一个短、厚、内沉的八角耦合盘，外圈为象牙白分段锁环，中心为暗石墨接口；不得延伸到腰部。
- 上下锁座之间由内部骨架承力，外观不画细杆、长梁或航空管线。
- 裸机正好四枚姿态喷口：两枚扁平梯形喷口藏在肩胛甲下缘，两枚藏在后裙甲上缘。喷口形状沿用小腿和胸腹的楔形通风口，不使用四只突出的圆形发动机。
- 四枚喷口只负责跳跃、落地、火箭拳反作用与舰面站立配平；无火焰、无常亮光，不赋予常态飞行能力。

## 4. 推进骨架：整机飞拳

推进骨架的视觉命题不是“给机器人装两台发动机”，而是“用一次点火把整台馆守Z发射成第三枚飞拳”。

- 骨架主体是一副裸露但粗壮的短X形承力架，通过四个锁爪和中央八角耦合盖扣入裸机接口；整体高度只从肩胛上缘到后裙下缘，不垂到大腿。
- 左右各有一块短粗的多边形推进胴，体积和馆守Z前臂相近但略短，外壳使用墨蓝厚断框、红色斜向锁甲和石墨内构。
- 每块推进胴下端使用正好三块宽银白旋封环片，直接回声双飞拳的三段旋封环；环内是一个巨大六边形/梯形喷口，而不是圆筒尾喷。
- 两块推进胴靠近中轴，外缘不得超过肩断框最宽处。上端可形成两枚短而钝的断框肩峰，强化主角机背向剪影，但不得展开成翅膀。
- 中央耦合盖使用短红色纵向锁块、象牙白分段框与单枚暖琥珀状态核，回应头顶红钥、胸口白轴和红胸卡扣；不新增文字与徽标。
- 退役感通过一侧推进胴缩短约8至10%、一枚外置补强箍和左右喷口内圈颜色不均表现。不得堆砌随机划痕、细管和铆钉。
- 装具没有武器炮口、油箱、进气道、翼面或长航空整流罩。两个大喷口只向后下方直推，服务一次直线发射。

## 5. 出图与验收顺序

1. 单图严格背面裸机：先证明它就是W/X的背面，而不是另一台被拉长的机体。
2. 单图严格背面挂载态：同一骨架、同一尺度，只增加“整机飞拳”推进骨架；不在一张图中并排压缩比例。
3. 裸机验收重点：短厚上背、宽倒梯形收腰、横向分布的四锁座、短八角耦合盘和四枚楔形姿态喷口。
4. 挂载态验收重点：第一眼像馆守Z的专属超级机器人装备；断框、红锁甲、三段旋封环和短粗大喷口形成统一语言；没有航空双筒感。
5. 两图均使用C01E02完整等长双臂作工程对照，不代表C01E04正式剧情状态。正式E04仍须换成原右前臂毁损与巡展臂装。

- [Z稿裸机背面：W母体短厚背躯](art-delivery/review/guardian_z_collector_e02_rear_wbody_candidate_v13z.png)：取消纵向长脊，后颈至腰带重新压回W/X的短躯；宽肩胛甲以短倒V/断X甲缝组织上背，并迅速收进高腰。双臂、长腿和宽足继续沿用W/X比例。
- [Z稿推进骨架：整机飞拳挂载态](art-delivery/review/guardian_z_c01_wholebody_punch_frame_mount_candidate_v13z.png)：粗短X架、中央红白八角锁核和两块飞拳式推进胴共同建立主角机背向符号；推进胴使用红锁甲、银白旋封环和巨大多边形喷口，不再读取为航空发动机。
