# 馆守Z：K上半身、红肩前甲与九头身综合设计 v4

> 状态：`candidate_design_synthesis`  
> 适用时点：C01E02双臂完整态  
> Canon边界：不新增武器、能力、编号史或剧情结果；比例、肩前甲、辅助天线与贴花均待用户确认。

## 1. 对v8误读的纠正

v8把“肩前甲”误读成真正肩甲，并把K稿最重要的厚上半身和红色胸口卡扣拆成四块独立X楔，导致主体特征丢失。Q至U的九头身下肢、J式肩铰和稀疏贴花可作局部参考，但其上半身不得继续作为父级。

## 2. 父级优先级

1. **K稿上半身为硬母体**：深厚胸腔、宽肩、巨大深蓝C形肩甲、红色双片胸口卡扣、中央象牙白目录脊柱、粗壮旋封飞拳全部保留。
2. **用户截图为头雕硬母体**：完整深蓝盔体、中央红额脊、银色纵栅脸谱、琥珀眼、圆形耳轴和三组后掠盔片保留。
3. **v8只提供下肢比例、肩铰与标识密度**：不得把Q/T的四楔胸X、缩薄胸腔或肩甲红白斜条带回。
4. **J稿只提供胸肩连接铰链**：不恢复整圈金环、对称柜门胸和复古圆筒语法。

## 3. 九头身：只拉长髋以下

- K稿腰带以上的宽度、深度和体积不得缩小；头、胸、肩、上臂与飞拳前臂保持同一相对尺寸。
- 通过大腿增加约16–18%、小腿增加约12–15%、踝段增加约4–6%，让鞋底至头冠读取8.8–9.0头身。
- 肩宽保持约3.2个头宽；胸腔高度不得减少，腰部只轻微延长，不做蜂腰。
- 目标黑影是“厚重上身压在长承重腿上”，不是把整台机体均匀纵向拉伸，也不是九头身轻型机。

## 4. K红色胸口卡扣：不可拆

- 保留K稿两块巨大红色卡扣胸甲：上缘从中央颈根向外抬升，外缘宽厚，下缘在腰上方向内收束。
- 两块红甲继续夹住象牙白中央目录脊柱和暖琥珀核心；不得拆成四块楔片、飞翼胸板或完全平直的横条。
- 卡扣的内凹负形、厚度和开合暗示是馆守Z上半身第一视觉符号。

## 5. 新增结构：红色肩前甲

“肩前甲”不是深蓝主肩甲，而是一对独立安装在锁骨外侧、肩关节正前方的红色横向装甲：

- 每侧肩前甲从K胸口卡扣的外上角附近起势，向左右延伸到深蓝C形主肩甲的前缘内侧。
- 正面配色和斜面连续，使红胸甲与红肩前甲远看像一片宽阔上身符号；结构上仍以5–8厘米深蓝/石墨铰链缝断开。
- 肩前甲为厚而扁的梯形/楔形，外端略上扬、宽钝，不形成细翼、刀刃或魔神原型胸翼。
- 红肩前甲位于真正肩甲前方偏内，不覆盖C形肩甲外轮廓，不妨碍主肩甲增加内圈、上盖和后承力片。
- 抬臂时肩前甲随胸肩铰小幅滑开，红色视觉带出现断口，从而证明它不是一整块胸翼。

## 6. 真正肩甲与J式铰链

- 真正肩甲继续使用K稿巨大深蓝C形展架弧，可增加深蓝上盖、内圈白色刻度和后侧承力片；红色只属于肩前甲，不涂满主肩甲。
- 胸侧与肩根之间露出石墨三轴铰链，配一枚淡香槟锁扣和一块小红/象牙白状态片。
- 主肩甲、红肩前甲、肩铰三者必须在近看时清楚分层，远看时共同增强K稿宽厚上半身。

## 7. 头雕：主眉冠 + 两根短辅助天线

- 主天线回到用户截图中的宽厚淡香槟眉冠，整体低位横向、外端宽钝；不采用v8的枢轴横冠、剪式X或目录缺口。
- 参考Z高达的“主天线之外还有短辅助天线”的层级关系，在中央冠壳后上方增加左右一根短天线。
- 两根辅助天线采用深蓝根部与淡香槟/象牙白短端，向外上方约20–25度；单根长度不超过主眉冠半边长度的28–32%。
- 辅助天线必须位于主眉冠后方，正面只露出小段，三分之四与侧面能看见根部；不得复制Z高达的具体V角、颜色分件或头部轮廓。
- 全头只新增这一对短件，禁止第四第五对角、星芒冠、兽角和细碎小刺。

## 8. 标识与配色

- 保留三处稀疏标识策略：深蓝主肩甲上的单色馆章、另一侧小号`MMM`、小腿候选编号/维修刻度。
- 标识不得放在红肩前甲和红胸卡扣上，确保红色大符号保持干净。
- 候选编号暂用`GZ-01`只验证位置；正式内容必须矢量重绘，用户确认前不构成Canon。
- 配色继续为墨蓝主甲、清亮朱红、冷白/银、石墨关节、少量淡香槟金与暖琥珀/微白灯光；无青光。

## 9. 验收门

1. 遮住头部后，是否仍一眼读到K稿厚上身与红色卡扣，而不是Q/T四楔X。
2. 红肩前甲是否远看接续胸红甲、近看又与真正肩甲和肩铰分离。
3. 九头身是否只来自髋以下增长，没有牺牲胸、肩、上臂和飞拳厚度。
4. 两根短辅助天线是否增加头部层级而不把轮廓变成Z高达复制品或星芒冠。
5. 三处标识是否仍然克制，并避开红色主符号。
