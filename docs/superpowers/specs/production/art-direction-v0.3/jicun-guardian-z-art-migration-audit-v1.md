# 纪存与馆守Z美术迁移审计 v1

> 状态：`candidate_migration_review`  
> 用户问题：细节过载、纪存年龄感偏幼、馆守Z主角机气质不足、整体风格辨识度偏弱。  
> 当前结论：问题成立，但不应通过继续堆装饰或全画面强风格滤镜解决。

## 1. 当前资产诊断

### 人物与Q版

- 纪存正比例同时保留多层外套、衬衫、领带/挂绳、胸牌、肩带、臂包、终端、垂带、拉链与多处金线。单张立绘精致，但派生四方向、坐姿、跑动和剧情照时容易漂移。
- 纪存Q版把上述信息几乎全部等比继承，还增加肩章、腕带和高密发束；Q版没有承担“压缩信息”的职责。
- 白鸢候选把纸页、印花、链饰、束带和衣片同时设为高对比，适合一次性海报，不适合作为所有普通对话和动作的基础母版。
- 七海、兜灯、唐胶的职业辨识成立，但仍应将污痕、工具组和法务饰边拆出基础母版。

### 纪存年龄层

- 当前脸型短、下颌窄、眼睛偏大、蓬松刘海占比高，视觉年龄接近19–22。
- 与成年且具有强权力/身体存在感的七海、白鸢同框时，容易形成“小奶狗 + 成熟女性”的单一读法，削弱三人都能主动选择和承担关系的平衡。
- 问题不在“必须显老”，而在缺少成年男性的稳定重心、肩颈体量、眼神余裕和社会经验感。

### 馆守Z

- 当前大面积小面板、铆钉、掉漆和结构缝让它像高完成度工业收藏模型，材料可信但主角机大轮廓被表面噪声吃掉。
- 肩、胸、腰、腿都接近同一细节密度，视线没有从头冠到胸板再到主拳的英雄路径。
- Q版继续复制面板网格、掉漆、标签与多色条纹，既难做动画，也使64–128 px下读成一团颗粒。
- 目前的头冠、金属口罩和红色胸板已具备超级系联想，应保留；需要增强的不是“更多魔神零件”，而是独有轮廓、主色块和一臂缺失后的英雄姿态。

## 2. 纪存候选迁移

### 年龄与体态

- 保持“青年”Canon，但视觉年龄调整为约26–29岁的成年青年。
- 面中略拉长、下颌更明确、眼睛缩小约10–15%，下眼睑更平，眉眼更从容。
- 肩背加宽、颈部更稳定，站姿从“防备少年”改为“安静承担决定的人”。
- 不加眼镜、不加胡须、不做纪文山年轻复制品；成熟来自骨相和姿态，不来自老化符号。

### 服装与身份锚

只保留：

1. 黑发蓝眼与较克制的侧分发型。
2. 深海军蓝馆员短外套/长夹克的大轮廓。
3. 左臂档案终端与微白机魂光。

删除或合并：挂颈证件、重复垂带、多只袖袋、装饰拉链、连续金线、小型肩章。证件改为胸前单枚平夹；终端成为唯一高密度配件。

### Q版

- 调整到约3.4头身，眼睛更小，头部不做幼儿圆脸。
- 只画黑发轮廓、蓝灰外套、白色内搭、左臂终端和一枚微白手光。
- 终端用一个发光矩形和两道边框表达，不复制完整屏幕与扣带。

## 3. 馆守Z候选迁移

### 主角机定位

方向定为“英雄化工业超级系”，不是放弃写实材料，而是让写实服从主角轮廓：

- 7–7.5头身，腿部拉长，腰部收紧，肩胸形成清楚倒三角。
- 保留金色头冠、金属面罩、红色胸板、深蓝主体和18米重量。
- 头冠改为万机馆屋脊/开启门框式三段轮廓；胸板形成“档案门开启”的独有几何，不照搬原IP部件。
- 左拳成为全剧识别锚；C01之后原右前臂明确缺失，缺口采用干净的大形而非一团管线。
- 一臂缺失后的站姿应仍然昂扬，形成“少一只拳也还是主角机”的海报剪影。

### 细节删减

- 每个肢体只保留1组主装甲分件和1处功能接口。
- 删除基础母版上的满身铆钉、方格面板、随机标签、细碎掉漆和多组散热槽。
- 磨损仅保留于关键接触面，并进入 `WEAR`；右臂毁损进入 `DAMAGE`。
- 胸灯、低热、全功率和硬停余辉进入独立 `LIGHT`。

### Q版

- 使用约4头身，不压成2.5头身圆墩。
- 只保留头冠、门形胸板、巨大左拳与缺失右臂四个信息层。
- 主色块控制在深蓝、红、金、象牙白、微白/琥珀光五组；取消表面颗粒。

## 4. 风格优化结论

不建议追求“每一帧都强风格”。辨识度分配如下：

- 常态游戏：清楚轮廓、两级阴影、低纹理，承担长时间可读性。
- 对话立牌：增加脸部与手部表演，不增加服装零件。
- 机体全身：增强宏观体块与材料差异，不增加面板数量。
- Cut-in/章节主视觉：允许档案框切割、强透视、局部高饱和与机魂白光，承担品牌记忆。

这样风格强度会形成节奏，而不是持续轰炸。

## 5. 资产影响

若候选通过，需要迁移：

- `CML001` 的 visual lock/current art reference；旧纪存正比例与Q版转 History。
- `CML008` 的 visual lock/current art reference；保留生命周期四状态，重新建立基础、缺臂、巡展臂装与后继右臂形态锁。
- 纪存所有方向、头像、立牌和剧情照从新简化母版重新派生，不从旧图局部修补。
- 馆守Z Q版、站立、半跪、必杀Pose、Cut-in统一读取新宏观设计；磨损/损伤/灯效拆层。
- 七海、白鸢和其他核心人物随后执行同一细节预算，但本轮不改她们的脸与身份锁。

## 6. 当前门禁

本轮候选图只用于回答四个设计问题。用户确认前：

- 不覆盖 `core_jicun_stand.png`、现有Q版或 `guardian-z-user-selected-base.png`。
- 不修改 `CML001/CML008` 的 `locked_current`。
- 不批量生产方向、动画、Cut-in或全角色重绘。

## 7. 候选实图结果

### 纪存

- [正比例候选](art-delivery/review/jicun_standard_candidate_v1.png)：视觉年龄约27–29，成熟来自面中、下颌、肩颈与站姿；配件压缩为胸夹和左臂终端。
- [Q版候选](art-delivery/review/jicun_q_runtime_candidate_v1.png)：约3.4头身，保留成年眉眼和腿长；身份信息压缩为黑发、海军蓝外套、左臂终端与微白手光。
- 仍需用户判断：成熟幅度是否正好，长外套是否需要缩短到更利于走图的长度。

### 馆守Z

- [正比例候选](art-delivery/review/guardian_z_standard_candidate_v1.png)：从写实模型密度改为宏观主角机层级；保留馆顶冠、金属面罩、红色档案门胸腔、圆肩与完整左拳。
- [Q版候选](art-delivery/review/guardian_z_q_runtime_candidate_v1.png)：约4头身，只保留冠、胸门、左拳、右前臂缺失和五组主色块。
- 正比例探索中淘汰了两张过度简化方案：它们虽清楚，却丢失万机馆身份并趋近泛用勇者系；最终候选重新加入圆肩展台环、档案门铰链、胸前空心馆藏印与左臂档案色带，均为大形而非微细节。
- 仍需用户判断：新的英雄化幅度是否足够，以及右前臂缺失是否作为C01后常态母版。

### 画风判断

本轮实图验证“中度风格化 + 峰值集中”可行：常态母版通过轮廓、比例和大色块形成辨识度，未使用全身纹样或持续强滤镜。后续若通过，应把更强的档案切割、白光和极端透视留给 Cut-in，不反灌到走图资产。

### 96 px 缩略验收

- 旧纪存Q版在96 px下，挂绳、胸牌、肩章、腰件与终端内线合并为灰色颗粒；新候选仍能直接读出成年黑发男性、海军蓝长外套与左臂终端。
- 旧馆守Z Q版在96 px下，掉漆、格线、标签与各处金边争夺注意；新候选仍能读出金冠、银面罩、红胸门、完整左拳与右前臂缺失。
- 两张候选目前仍为浅底评审图，不是透明底 runtime 成品；通过设计门后才生成透明母版、方向拆分和像素占位校准。
