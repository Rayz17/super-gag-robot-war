# 馆守Z：现代魔神系设计审视 v1

> 状态：`candidate_reference_audit`  
> 母版：馆守Z A稿 `guardian_z_collector_e02_intact_candidate_v2a.png`  
> 目的：保留A稿已经成立的厚重体量与主角冠，只从现代魔神系中提炼“经典识别如何被现代化”的方法，不直接挪用具体零件。

## 1. 本轮纠偏结论

H/I稿失败的原因不是“不够现代”，而是把新意集中成了更大、更复杂的头冠：

- 头部抢走全部视觉注意，身体仍是通用重装机器人。
- 冠形从经典魔神系的强横向眉线，漂成星芒勇者冠或多刺王冠。
- 配色靠零散钴蓝和大面积冷白制造新感，破坏A稿深色巨神的整体性。
- 没有新增一套贯穿头、胸、拳、腿的结构语言，因此也没有形成可商品化的独占记忆。

下一稿必须回到A稿，不沿用H/I的头冠和色块。

## 2. 现代魔神系真正做了什么

### 2.1 共同保留的经典锚点

现代版本即使改得很远，通常仍保留四个快速识别点：

1. 强横向眉冠或明确的头顶接合轮廓。
2. 发光眼、硬质面罩和压低的英雄脸。
3. 红色胸部主焦点。
4. 能读出分离、发射或展开逻辑的粗前臂。

因此，现代化不是把这些锚点换掉，而是让它们拥有新的结构理由。

### 2.2 五条现代化路径

| 参照谱系 | 公开产品可验证的设计/玩法 | 对馆守Z有用的结论 |
|---|---|---|
| `Mazinger Z / INFINITY` 与 METAL BUILD | 设计重排、裸露金属、为可动而重构关节、强调重量感 | 经典大块面保留；细节应集中在关节、分离缝和真实活动区，不平均铺满全身 |
| Mazinkaiser | 经典体量与高可动并存，以一套连续的尖钝曲线统一冠、胸、翼和肢体 | “厚重”不等于方箱；同一轮廓节奏应在全身重复 |
| Mazinger ZERO | 高热板、面部开启、背部组件可拆 | 新意来自一个主题被推到极致，并让脸和胸成为可动作机构，而非增加随机装饰 |
| Mazinkaiser SKL | 刀、胸部武器、步枪合体与翼部开合形成同一战斗身份 | 强风格应由武器/机构系统承担，并在静态剪影上预告功能 |
| Mazinger ZEST | 保留飞拳、切割器与头顶接合识别，同时建立全新的主轮廓 | 新主角机可以很新，但经典联想必须由头、胸、拳和功能共同完成 |

这里的判断是基于官方产品资料与实物图所做的设计归纳，不把任何单一机体的具体冠形、面罩、胸板或武器轮廓复制给馆守Z。

## 3. A稿为何仍然最好

A稿已有三项无法轻易替代的优点：

- **体量正确**：巨胸、圆肩、粗前臂、承重腿和宽足能承担全剧主角机。
- **头冠正确**：中央红色目录钥加两侧厚金冠，横向眉线清楚，没有H/I的星芒问题。
- **玩法正确**：胸门、肩环和飞拳模块已经具备商品化入口。

它的问题也很明确：头和胸有身份，肩以下大部分仍是“高级但通用的重装机器人”。

## 4. 馆守Z应采用的全身语法

下一稿只使用三种重复语汇，并控制每种最多出现三到四次。

### 4.1 馆藏转轴

- 肩环改成有三段锁扣的深色分度转台，不再是整圈金色轮胎。
- 同一分度圆语言缩小后用于肘部飞拳分离环和膝外侧承重轴。
- 这是馆守Z最独占、最适合做玩具机关的记忆点。

### 4.2 展门折线

- A稿两扇红胸门的上外角、下内角形成一条清楚的开门折线。
- 同一折线只在前臂外壳和小腿前甲各回声一次，形成从胸到拳、再到站姿的节奏。
- 不能画成高达式密集分甲，也不能在每块甲上复制红色装饰。

### 4.3 目录脊柱

- 头顶红色目录钥、胸部象牙白竖脊、腰部锁扣与脚背短脊构成一条纵向视觉轴。
- 它负责把宽胸、宽肩和粗腿收束为主角机，而不是让整机变成横向堆块。
- 只保留一条连续的象牙白/拉丝银轴线，不散落钴蓝高光块。

## 5. 下一候选的硬约束

### 保留A稿

- 约6.7到6.9头身；胸肩宽度、前臂体积、腿部承重感与A稿基本一致。
- A稿三段冠轮廓与横向眉线基本不变，不增加额外长角、后角或星芒。
- C01E02完整态双臂同源、等长。
- 深墨蓝为主体，红胸门为第一色彩焦点，象牙白/银为结构轴，香槟金只用于真实转轴和冠。

### 必须改变

- 肩壳从普通球甲改成“扁平上沿 + 前向压肩 + 分度转台内圈”。
- 前臂取消枪状外挂，改成一眼可懂的整圈飞拳分离缝与两段锁扣。
- 胸门、前臂、小腿共享展门折线，但保持大色块和低噪声。
- 金色面积至少比A稿减少三分之一，钴蓝独立色块归零。
- 高细节集中在胸门铰链、肩环内圈、肘部接口、膝后和手指；外甲保持干净。

### 禁止项

- 不以放大头冠、加刺、加翼解决“没特色”。
- 不做暗黑异形、生物甲、骷髅脸或全身裂纹。
- 不复制魔神Z、ZERO、凯撒、SKL、ZEST任一具体冠、胸板、面罩、飞行器或武器形状。
- 不出现文字、编号、日文、伪文字、馆标贴纸和随机磨损。

## 6. 视觉验收

1. 遮住头部后，仍能凭肩转台、胸门、飞拳环和腿部折线认出馆守Z。
2. 遮住配色后，剪影仍是厚重主角机，而不是泛用工程机或勇者系。
3. 96px缩略图只读到冠、红胸、圆转台、粗拳和宽足，不读到碎线。
4. 立体玩具至少能演示胸门开合、肩环转动、飞拳拆装和右臂换装。
5. 第一眼能联想到经典魔神/飞拳系，第二眼能说出“这是万机馆那台”，而不是猜到某个现成机体。
