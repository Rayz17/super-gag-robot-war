# BREAKER 共享结构与方向 Guide

三个缺失方向不是三次设计。每次调用都必须读取同一组正向母版，并继承前一张已通过硬门的同轮输出作为一致性辅助；任何一张失败，后续调用停止。

## 不变结构

1. 近 30m、3×3 footprint 的低伏巨体；整体不是龟、普通甲虫或对称梭形。
2. 黑色非均匀长叶叠甲沿前后轴成层流动；甲片长度、数量节奏和左右非对称保持。
3. 唯一低嵌红缝位于头端侧面，是方向极性主锚；不得生成第二只眼、面部或居中红灯。
4. 四条机械肢体共同承力，关节、足端和着地关系可读；不得收成无腿壳体。
5. 黑甲、暗金细缝、极少红色；无新增彩色区、武器、翼、尾、炮、触角或装饰。

## 固定相机与四向读法

- Camera 固定不动，机体只在同一地面上旋转；平行正交、约 2:1 dimetric、可见相近比例顶面、无透视缩放。
- NORTH `[40,-24]`：头端朝画面右上；现有母版。
- EAST `[40,24]`：头端朝画面右下；看见头端与一侧。
- SOUTH `[-40,24]`：头端朝画面左下；看见头端与另一侧。
- WEST `[-40,-24]`：头端朝画面左上；主要看见后部与另一侧，但红缝仍随头端正确转向，不得把尾端误作头端。

## 尺度与注册

- 最终每张 `384×384 RGBA8`。
- alpha subject bbox 以现有 NORTH 的 `351×304 / paste [16,16] / lowest contact y=320` 为体量基准；方向变化允许宽高自然差异，但不得把近侧肢体放大。
- pivot `[192,320]`，最低可见接地点对齐 `y=320`，`footprint_bottom_center`。

## Alpha 门

- 外部背景必须完全透明。
- 四肢之间、长叶甲片之间、腹部与地面上方的封闭负空间也必须透明。
- 在纯黑、深灰、白、高饱和洋红/青绿底上以 100% 和 50% 检查：不得残留白底、棋盘格、白色封闭块或光晕；不得误删暗金缝、红缝和真实高光。
