## What is working

1. **勇拳是完整机器人**：独立形态有完整头、英雄脸、胸、腹、髋与四肢，没有空胸腔、核心座或兽形核心。
2. **轻快与大拳同时成立**：暗骨架和较长的肢体使其比旧超级系巨神更轻快；双拳仍是第一眼识别件，没有缩成小手。
3. **合体关系可读**：中央图以暖色显示勇拳核心，灰色显示腿足、肩臂、拳后套筒和背／上身外装；社勇王不是换一台核心，也不是勇拳简单放大。
4. **保留件有正侧关系**：小图同屏对照了合体前后的正面与侧面，英雄脸、胸牌／中央胸块、腹部核心脊和大拳正面仍可识别。
5. **拳甲三态关系正确**：三格拳头大小和掌外轮廓基本恒定，主要变化在拳后蓄能环和套筒行程。
6. **50% 仍可判读**：A/B 两种形态、C 正侧保留关系和 D 拳甲三态在 1200x800 下仍可区分。
