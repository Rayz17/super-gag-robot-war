## 3. 体验命题

玩家的手必须在回答 00d 的三个问题。菜单不得代替其中任何一个答案。

| 玩法问题 | 玩家在盘上做什么 | 盘上必须立刻看见 |
| --- | --- | --- |
| 哪台身体现在能到危险点？ | 看冻结意图，选中馆守 Z | 冲线幽灵、车道幽灵、馆守 2×2 能否进入终点带 |
| 到达后朝哪边，才能完整挡或护？ | 摆终点，拧朝向 | 正面扇厚、侧向薄、背向空；接触边变色 |
| 谁承担代价？ | 点亮拦截或保护 | 防护／机动／热／路／车过不过，落子当时就能读 |

一句话检验：盖住右栏和 SUMMARY 文案，只看地图，玩家仍能说出「我挡的是冲线还是车道、这面挡不挡得住、谁会发热」。说不出，就还是说明书，不是棋。

第一轮玩家心里应被界面逼出这句，而不是被菜单替他说完：

> BREAKER 从南边冲进城。车要从东门走。我这台 2×2 卡不卡得住冲线口？脸要朝南。正面挡的话我用防护吃，车还能过。侧向的话它会更深。

## 4. 复刻版：收层，不收皮

复刻版舒服，不是因为六指令，而是因为玩家永远知道自己站在哪一层，棋一直留在盘上。132 只收了「光标停在机体上确认」。本文收下面这十条，并写成 E02 体验真值。指令词、我方／敌方阶段、HP／EN、HIT 数不是手感源。

### 4.1 必收

| 复刻里成立的手感 | E02 必须变成什么 | 现网若还在做的错切片 |
| --- | --- | --- |
| 一层一件主确认；取消只拆当前层；可选工具靠边 | LOOK 确认=选中，PLACE 确认=落格或采用，LOCK 确认=出击；Esc／B 只拆当前面 | 同一面里猜「现在这颗键干什么」 |
| 底下有意义就留着。地图 ADV 锁走格，蓝菱形还在；半屏武器左边仍是棋盘 | OPERATION、信息卡、PLACE、LOCK 都压在同一张活盘上，不得把棋盘换成另一张纸 | OPERATION 先盖死活地图再给看盘 |
| 光标是主语。蓝菱形+地面白框；底栏单位卡跟着光标，不跟着剧情 | 光标常亮；停在友军／空地／敌／占地冲突时，教练或光标色必须不同。信息卡跟着光标。右栏只在选中馆守 Z 之后出现拦截／保护／看预期 | 把单位卡和打法菜单合成一块右栏 |
| 动词点亮地盘。选移动铺蓝格，选攻击铺红格 | 点拦截，冲线带和南向扇亮；点保护，东门带和东向扇亮。不写死解 | 点拦截自动铺完 A 族 |
| 承诺层留在盘上。出手前还看见棋盘，预测贴在目标身上 | 接触边、车过不过、谁发热画在落子当时；LOCK 只锁已见之物。不搬武器表和 HIT% | 接触质量主要靠 SUMMARY 句子揭晓 |
| 动手用模式告诉，不用说明书。对白一收换成地图铬；敌方顶栏变红 | 规划中光标活着、题目在地上；共同结算中光标冻结，单位按已算完的一轮走。换面必须换键面 | 靠教练写「请出击」 |
| 先看后指，先指后承诺 | 活盘上先读冲线和车道（可对白、可 OPERATION，不可落子）→ 指馆守 Z → 点亮题目并摆身体 → 看齐再出手。`1/2` 出现在已经能指之后 | 盖住地图的短面上就给 1/2 |
| 结果盖在同一张活地图上。击坠、增援不切加载 | 热、防护／机动、车过没过，盖在下一轮 LOOK。问题换了，盘不能换 | 用过场或换页冒充写回 |
| 跳过有种类 | 跳过 OPERATION／对白 ≠ 跳过共同结算演出 ≠ 取消当前编排层 | 一颗 Esc 拆到底 |
| 地图干净。铭牌只写名字；范围只在进入空间层才铺 | 地上不写「A 拦截／B 保护／威胁」。黄字只给已经看得见的带起名 | 用地上说明书代替题目带 |

### 4.2 已经收对、不必再扩

选中才出菜单、检查敌人只出卡、Q／P 切单位、A 确认／B 取消、合法方案必须经过承诺层。这些 132 已经对齐复刻。再加条目会滑回六指令皮。

### 4.3 绝不能照搬

| 复刻里舒服的东西 | 搬过来会破坏什么 |
| --- | --- |
| 移动／攻击／精神／能力／待机 | C01 的棋是责任、朝向、挡护 |
| 我方走完再敌方；打完的单位变暗 | 共同结算；规划期谁都还没走 |
| HP／EN／热血／必中 | 身体功能账，不是血条战 |
| 半屏武器表、HIT 数、击坠 | 非歼灭；第一次巨体接触留在地图上 |
| 选完攻击切战斗舞台 | 规划接触的主读是棋盘 |

复刻「选单位 → 指令 → 移动范围 → 武器 → 演出」只学前半段的层和光标。后半段的回合制攻击链不进入本文。

规划期的对应不是「已行动变暗」，而是三种线：冻结的敌方幽灵（他们已经决定了）、玩家的黄路草稿（还没交）、LOCK 之后的锁住幽灵（看齐了，等出击）。

### 4.4 收错切片，现网必须改口

132 把复刻指令盒理解成「选中后出五条对等动词」，这是收错了。复刻指令盒小，而且选完一条地盘立刻改口。舒服的是「选一条，盘就换一种读法」，不是「菜单里有五件事」。本文只留拦截／保护／看预期；画路和朝向回到地上。

## 5. 现网为什么绑不成棋

不是 132 选错了，也不是 133 算错了。是两层没有共用同一个思考单位。

| 现网做法 | 玩家实际在做什么 | 棋被藏在哪 |
| --- | --- | --- |
| 选中后五条对等菜单 | 在选工具 | 责任、路、朝向、预演被当成同类按钮 |
| 点「拦截」自动铺 A 族并朝南 | 在确认系统的标准答案 | 三问里的前两问被菜单答完 |
| 已有 A 路再点「保护」不抢路 | 在保留旧作业 | 题目换了，盘上不立刻改口，SUMMARY 才失败 |
| 接触质量主要出现在 SUMMARY | 在出门核对 | 落子时没有共同时间，只有事后句子 |
| `1/2` 已降为幽灵，快捷却换到动词上 | 在走教程捷径 | 和「不要 1/2 自动出击」是同一类问题 |

保留：光标常亮、先出卡再选中、检查敌方只出卡、共同结算、合法方案必须经过 LOCK、Esc 一层一件、不搬六指令。这些也是复刻已经收对的切片。

改掉：责任动词写死解；画路／定朝向与责任并列；预期只活在摘要句里；OPERATION 盖死活盘；单位卡和打法菜单合成一块。

## 6. 玩家只面对三面

```text
LOOK  看盘：冻结意图长在地上；检查身体；1/2 只出双边幽灵
  → 确认馆守Z，进入这一手
PLACE 落子：点亮题目 → 摆身体 → 盘上出现共同预期
  → 一手齐了才能看齐
LOCK  确认：同一张地图锁住幽灵；一句结算；Start 出击
  → 演出已结算的同一轮，写回下一轮 LOOK
```

### 6.1 LOOK（现网 PUBLIC）

OPERATION 短面压在活盘上，冲线、车道和光标还在，只是还不能落子。对白若出现，同样锁走格、留光标。短面未关时不给 `1/2`。关掉短面之后才进入可指的看盘。

地上必须同时能读：

- BREAKER 北向冲线的冻结幽灵（不是一句「冲线」标签）
- 东门撤离线的冻结幽灵
- 小体扑线
- 两个题目带：南向冲线口、东门车道口（黄字只给已经看得见的带起名）
- 底部五时点仍可扫：应急车 / 小体 / 巨体接触 / 城市炮 / 赤红蓄能。扫到哪一点，盘上只加重那一拍的幽灵，不另开时间轴玩法

光标常亮，是「你现在指着谁」。停在馆守 Z、空地、BREAKER／车／小体、或占地冲突时，教练或光标色必须能分开。信息卡跟着光标，不跟着剧情，不和打法菜单合成一块。确认馆守 Z 才进入 PLACE，右栏这时才出现拦截／保护／看预期。确认 BREAKER／应急车／小体只留卡，不给编排。

`1/2` 或点黄字 A/B：只在已经能指的看盘上画出两条建议幽灵廊，**不写计划，不进 PLACE，不出击**。

键面此时是看盘铬，不是对白四件套，也不是落子铬。

### 6.2 PLACE（现网 EDIT，但不再先弹五条对等动词）

选中馆守 Z 之后，右栏只留三件事：

```text
拦截
保护
看预期   ← 一手未齐时不可用
```

画路不是菜单项。责任点亮后，点地格就是画路；A 只落格。  
定朝向不是菜单项。终点出现后，幽灵身体上长出面向玫瑰；N/E/S/W 或点花瓣。

**责任点亮题目，不写解。**

| 玩家点 | 系统写入 | 盘上点亮 | 系统不得做 |
| --- | --- | --- | --- |
| 拦截 | `responsibility=intercept`，主动作 `BODY_INTERCEPT`，清预备 | 冲线带、南向正面扇、终点带 `[20,9]` 一带；淡幽灵建议标「建议」 | 不写死路点；不把朝向当成已确认解；不进 LOCK；不出击 |
| 保护 | `responsibility=protect`，预备 `PROTECT_LANE_RESPONSE`，清主动作 | 车道带、东向正面扇、终点带 `[19,9]` 一带；淡幽灵建议标「建议」 | 同上 |

建议路是虚线。作者路是实线黄路。采用建议之后，虚线变成可改的实线草稿。

玩家真正下棋的三下：

1. **采用或自摆。** 点建议终点，或点终点带内空格：生成该责任的最短合法路 + 建议朝向，仍可改。点带外格：只当路点；盘上写「到不了挡点」或「到不了护点」。
2. **拧朝向。** 责任正面的花瓣更厚。南（拦截）／东（保护）= 正面挡；邻边 = 偏挡；对面 = 这面挡不住。改朝向不离开 PLACE。
3. **读共同预期。** 路和朝向一齐，盘上立刻出现第 7 节的落子预演。教练只点名盘上已有的东西。

允许先画路、后点责任。没有责任时，教练问「挡什么」。责任点亮后，同一条路立刻显示对新题目的质量。这是复刻「选一条，盘就换一种读法」的 C01 转译，不是选完移动就自动走到标准格。

### 6.3 LOCK（现网 SUMMARY）

合法一手仍必须经过 LOCK。它不再揭晓新信息。

同一张地图，冻结 PLACE 里已经画出的幽灵：馆守终点身体、BREAKER 接触位、接触边、车过不过、代价记号。右栏只留一句结算，例如：

`拦截 · 正面挡 · 馆守Z承担 · 车已撤 · 防护承力受损`

- `Esc` / `B`：回 PLACE，草稿还在
- `Start` / `Enter`：提交，演出已结算的共同一轮

玩家在 LOCK 里应觉得「我看齐了，出手」，而不是「原来是这样」。棋盘不得换成结算纸；右栏一句只复述盘上已见之物。这是复刻承诺层「半屏留地图」的转译，不搬武器表。

## 7. 落子时盘上必须长出的共同预期

PLACE 里只要「责任 + 终点 + 朝向」三件齐，Resolver 预演必须画在地上，不得等 LOCK：

1. 馆守幽灵身体停在终点，带朝向扇
2. BREAKER 幽灵停在本轮预计接触位（冻结计划，不是读玩家草稿）
3. 接触边：正面、偏挡、背向用三种能分开的边，不靠一段说明句
4. 应急车幽灵：过东门，或卡在线上
5. 代价记号挂在将要付钱的东西上：馆守防护或机动、热、路、BREAKER 深度

133 的质量表原样生效，只是提前显形：

| 责任 | 正面 | 侧向 | 背向 |
| --- | --- | --- | --- |
| 拦截 | 完整身体挡冲线；防护承力吃；热较低 | 接触成立；BREAKER 更深；馆守更热 | 挡失败；盘上写「这面挡不住」；看预期不可用 |
| 保护 | 完整身体护车道；机动换线；热更高 | 车仍可能过；BREAKER 更深；机动更伤 | 护失败；盘上写「这面护不住」；看预期不可用 |

背向或终点不在题目带里：一手未齐。可以继续改，不能进 LOCK。

规划期三种线必须能分开：冻结的敌方幽灵、玩家未交的黄路草稿、LOCK 锁住的预期幽灵。不要用复刻「已行动变暗」冒充这三种状态。

## 8. 换责任必须立刻改口

「已画路时不抢路」保留为作者权。敌意失败取消。

玩家从拦截改到保护，或反过来时：

1. 旧路留下，仍是草稿
2. 盘上按**新题目**立刻重画扇面、接触边、代价
3. 若终点不在新题目带里：实线路变问号态，写「这路挡不住冲线」或「这路护不住车道」，并点亮正确终点带
4. 点新带、或 `1`、或点建议终点：才改终点与建议朝向
5. 不得把失败留到 LOCK 才第一次说

## 9. `1/2` 只做建议，按所在面改口

| 所在面 | `1` / `2` / 黄字 A/B 做什么 | 仍不得做 |
| --- | --- | --- |
| LOOK | 画出两条建议幽灵廊 | 写计划、进 PLACE、进 LOCK、出击 |
| PLACE，尚未点责任 | `1` 点亮拦截+幽灵，`2` 点亮保护+幽灵；仍须采用或自摆 | 写死解、进 LOCK、出击 |
| PLACE，已有责任 | 填**当前责任**的可改建议（路+建议朝向） | 跳过 LOCK、出击 |
| LOCK | 无 | 改已锁预期 |

采用建议是棋手接受一站，不是系统替他下完。采用后仍可改路、改朝向、换责任。OPERATION 短面未关时，`1/2` 不出现。

## 10. 第一轮一手怎么走（玩家看见 / 操作 / 单位）

以「挡住 BREAKER」为例。保护是同一套手，换题目带。

### 看盘

玩家看见馆守 Z 在 `[15,11]` 朝东，BREAKER 在 `[20,13]` 朝北，冲线幽灵往北压，东门车道幽灵往东走。光标在。还没有黄路写在馆守脚下——那是未提交的手，不是已经走过去了。

点 BREAKER：卡上写朝北、3×3、冲线进城。没有菜单。

### 选中馆守 Z

确认身体后，卡留下。右栏只有拦截／保护／看预期。冲线口和东门车道口可以更亮，表示题目在地上，不在说明书里。

### 点拦截

冲线带亮，南向扇亮，`[20,9]` 一带亮，一条淡虚线建议出现。馆守仍站在原地。教练只说题目，不说「已写好合法方案」。

### 摆身体

玩家点建议终点，或自己点到 `[20,9]`。实线黄路出现。面向玫瑰开在幽灵身体上，默认朝南，南瓣更厚。接触边立刻画在馆守南缘和 BREAKER 北缘之间。车幽灵继续出东门。馆守身上挂防护承力，路上挂路损。

若这时把脸拧到北：接触边灭，写「这面挡不住」，看预期变灰。

### 看齐并出击

看预期打开 LOCK。盘上幽灵锁住，句子只复述已见之物。Start 之后，PerformanceDirector 播**已经算完的同一轮**：馆守沿黄路走到 `[20,9]` 朝南，BREAKER 按冻结北向同时压上来，车出东门，小体走自己的线。播完写回下一轮 LOOK。

规划阶段没有单位在走。出击之后也不是「我走完你再走」。写回必须盖在同一张 LOOK 上：热、防护或机动、车过没过。不切加载换盘。

## 12. 键、一层取消、换面换键面

- 移光标：方向键／鼠标／十字；近单位吸格
- LOOK 确认：Enter／A／点身体 = 选中，不直接落子
- PLACE 确认：A／点地 = 落格或采用建议格
- 朝向：N/E/S/W，或点玫瑰
- 责任：点右栏，或点题目带
- 看预期：一手齐了才能进 LOCK
- LOCK 出击：Start／Enter
- `Esc`／`B`：LOCK → PLACE（留草稿）；PLACE 有路或朝向 → 先撤最后一笔；PLACE 只剩责任 → 回到未选责任的选中；选中无责任 → LOOK
- 跳过有种类：跳过 OPERATION／对白只拆短面；跳过演出只跳这一轮播放；取消编排不跳过演出，也不关 OPERATION 以外的故事层
- 换面必须换键面。不存在一块永远正确的帮助条。对白铬、看盘铬、落子铬、确认铬、演出铬分开

不把 A 改成出击。不搬精神、气势、待机、攻击。可选工具（AUTO、记录、缩放）若出现，靠边，不和主确认抢。
