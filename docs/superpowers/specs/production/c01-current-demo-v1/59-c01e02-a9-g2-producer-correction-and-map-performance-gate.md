## 4. 地图内演出的唯一结构

### World Space｜主体

规划、摘要、车辆通过、小体扑线／被挡、馆守Z占线、BREAKER冲撞、城市炮、道路损伤和红缝聚光均在同一Godot战棋地图连续发生。执行态可以推镜、缩放和短时构图重排，但不得换成另一张不连续的全帧插画。

### Character Space｜短暂停顿

纪存、兜灯、七海或旧守护者通讯出现时暂停战术输入；人物层结束后缩回，不得在玩家编辑路线时遮挡敌人、冲线、终点、保护区或时间轴。纪存只提供路线、人员和危险判断，不得读成驾驶或遥控馆守Z。

### Peak Space｜有限 Cut-in

取盾后的赤红挡击、盾拍及少量机魂峰值可使用1–3秒Cut-in或经用户另行授权的LibTV短镜头。Cut-in首帧继承地图姿态与朝向，末帧必须返回同一地图的精确落点、朝向、破坏状态和幸存单位。

建议预算：常态战斗约80%在World Space，Character／Peak合计约20%；不得把共同回合剪成连续播片。
