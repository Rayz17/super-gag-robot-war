# C01E02 S01–S07 联合 Previs v0.1

> Status: `producer_previs_contract / G1_pending_user_visual_acceptance`
>
> 画幅：1280×720 运行时；世界空间候选底板 1920×900
>
> 美术语言：A `KINETIC_CEL` 常态；B `ARCHIVE_OFFSET` 仅局部峰值；C 本话不用

## 1. 三种空间不再混用

### World Space：玩家站在里面操作

- S01、S03 使用电影化斜侧视 2.5D 浅纵深，允许连续 X/Y 小范围绕行。
- 人物和小机使用独立 Sprite、统一脚底中心 pivot、Y-sort 与前景遮挡。
- 背景必须是 clean plate；可动门、火帘、终端、小机、人群、灯光和烟火均独立。
- 该空间不使用满屏人物 Keyframe 当地图，也不把正比例角色烘焙在背景里。

### Screen Space：信息和关系在屏幕上组织

- 对话默认使用克制的场内字幕或半身焦点，不长期挂旧式大头像框。
- S04 七海只通过危机联络室画面和通讯进入；她不作为馆内 Sprite 出现。
- S06 的目标、冲撞意图、预测和指令属于战术 UI；红区不是世界内实体光带。
- S02/S07 的人数确认、结果和可选资料页属于 Screen Space，不占据 World Space 因果。

### Shot Space：高价值瞬间暂时接管画面

- S02 BREAKER 破土、S03 声音续接、S05 馆守 Z 起身、S06 扯盾/挡击、S07 南向推进与强化盾拍使用动态漫画式镜头、局部 Cut-in、地图动作或短动画。
- Shot Space 可使用正比例人物/机体 Pose 和满屏构图；播放后必须回到同一 World/Screen 状态。
- 静态关键帧、有限分层运动和程序 FX 是本轮默认方案；视频只是未来可选增强，不是成立前提。

## 2. 推荐的探索镜头方案

沿用此前已验证的“斜侧视 + 三构图区 + 浅 X/Y”方法，但不沿用旧剧情、旧人物图或旧大厅贴图：

- 世界尺寸：1920×900；相机裁切 1280×720。
- 候选相机中心：A `(640,450)`、B `(960,450)`、C `(1280,450)`。
- 相机同区稳定；跨区才做 0.45–0.65 秒平移；不得持续贴身跟随造成小人走图感。
- 永久 HUD 安全区：上 56、左右 32、下 72；临时对白保留区下 118，但必须避让当前说话者、热点与脚点。
- 成人运行时高度候选 165–220 px；小机器人 60–100 px。儿童、轮椅和机器犬按真实尺度关系另做桥接，不机械套同一高度。
- S01 与 S03 可使用不同状态的同一大厅/坡道空间，但必须通过门、坡道、主展台、火帘和巨机尺度维持连续性。

这是 G1 推荐，不是已批准的正式视觉模板。若联合 Previs 仍像横版平台游戏或贴纸滑动，必须先修构图、相机区和遮挡，不直接扩大资产数量。

## 3. 七段镜头与操作板

### E02-S01 东侧撤离

**玩家欲望：** 把还在馆内的人送到东侧，而不是读一串撤离说明。

**世界构图：** 纪存从左中景带队向右侧坡道移动；远景馆守 Z 仍半跪，地面震动和烟火把正常导览线切断。主移动带保持前后两层可绕行，不做单线跑酷。

**六拍：**

1. 全景建立：西侧烟封、地下指示闪烁、东侧坡道在远端可见；玩家取得移动。
2. 跌跌主动抢到快速落下的防火门下，玩家确认通过点；Shot Space 只给 1–2 秒近景，不夺走操作。
3. 机器犬往返一次，自主找到老余并咬开轮椅旁障碍；玩家跟随它的尾灯确认老余已进入正确路线。
4. 消防架桥机从场外倒车进入，四腿落地、桥板越过头顶；用上下尺度差制造第一次职业机爽点。
5. 小满在模型病院门口停下，唐胶穿烟追上，把社勇王按回她怀里。
6. 人群进入消防通道；纪存最后回望，镜头把旧守护者小终端留在烟中。

地下错误入口必须在接近前给出明确危险反馈；玩家仍坚持进入时按 Candidate gameflow 判定撤离失败并回 CP0。`G1 Previs` 必须证明：不看文字也能指出出口、地下危险入口、跌跌、机器犬、老余、桥机与小满；移动不是只有左右；大画面不把玩家角色缩成无法识别的小点。

### E02-S02 撤离确认

**三拍：**

1. 避难所厚门闭合，阿澄握着人数卡，成人应急席确认“三十多人，一个不少”。
2. 阿澄回头问旧守护者；声音空一拍，切回馆内的小终端转身驶向烟里。
3. 画面切到雨中广场，路面拱起，BREAKER 破土；镜头保持万机馆在它的明确视线终点。

本段完成 CP1。巨机出现后，人群图标、职业机与小机不得留在 S06 棋盘。

### E02-S03 三人留下与同体揭示

**世界构图：** 同一斜侧视空间转入主展台区。纪存居中向展台移动；唐胶在近景拉火帘，兜灯在远近尺度之间的维修架上，旧守护者终端在地面。

**七拍：**

1. 唐胶拉下最后一张防火帘，推动工具车向主厅。
2. 兜灯在维修架上说“先站起来再说”，动作先于解释。
3. 纪存走到终端旁；横梁砸下，世界声短暂闷掉。
4. 终端说到“下一项工作是……”；声轨不断，镜头切馆守 Z 胸部。
5. 胸前继续“阻止敌体进入居民区”；B 档案套印只在声源转移边缘短促出现，不铺满画面。
6. 纪存抬头，问“旧守护者？”；馆守 Z 胸灯回应“我在”。
7. 兜灯打开导览席，实际座位和安全带说明纪存只是报路；馆守 Z 自己抬头。

**禁止：** 轮式终端变成独立人格死亡；纪存化光进入机体；用资料卡解释机魂学；恢复旧“低热掌防”镜头。

### E02-S04 七海撤令

**Screen Space 设计：** 左侧保留馆守 Z 胸舱/纪存，右侧是七海危机联络室。七海使用最新成年视觉锁，不出现旧头像。背景只需要三层：七海、同僚轮廓、公共危机窗；不做可探索办公室。

**五拍：**

1. 七海先问观众，再问兜灯；两项回答明确。
2. 同僚靠近，用一句人话提醒“没有上级复核，之后先查你”。
3. 七海看公共画面中 BREAKER 越过第一街口。
4. 她说“这道命令是我签的。我自己撤”，完成操作。
5. 红色停机标志熄灭；私人余味落在“别刚醒就把馆踩了 / 看路”。

复杂权限树、制度百科和战斗批准都不进入画面。

### E02-S05 巨神出馆

**默认 5–8 秒可回看的短演出，首次默认 Full、允许主动跳过。**

1. 左手按住展台，胸炉金光穿过烟。
2. 膝部旧扣连续崩开，积尘从肩头滑落；远处未开放层剪影被照亮。
3. 机体缓慢直身，18 米尺度与维修架/人类同时在画面里成立。
4. 南侧门来不及全开，馆守 Z 用肩撞开已裂幕墙。
5. 第一脚落地左膝晃动；镜头停住半拍；第二步站稳，切战术地图。

本段只需关键帧、分层位移、尘烟和有限机体关节动画即可成立。静态 fallback 必须仍完整表达五拍。

### E02-S06 广场首战

**战棋定位：** 一场 4–6 回合的机战姿态谜题，不做 RPG 数值碾压。

**灰盒候选：** 12×9 正交三分之四棋盘；馆守 Z 为 2×2 footprint，BREAKER 为 3×3 footprint。北侧 2 行是万机馆/居民区安全线，中央为主战区，南侧为空旷承冲区；西北墙面设唯一重盾热点。格数与 footprint 是 G1 灰盒参数，不迁移 Canon。

**可复现初态 `c01cdv1_s06_g1_v1`：** 坐标原点在西北，`x` 向东、`y` 向南；北侧安全线为 `y=0..1`。馆守 Z 的 2×2 anchor 候选为 `(5,3)`，BREAKER 的 3×3 anchor 候选为 `(5,6)` 且初始朝北，重盾热点位于西北墙面 `(1,2)`。若 G1 为可读性调整坐标，必须生成新 profile ID；失败重试必须按同一 profile 重建，不从失败帧续战。

**玩家指令：**

- `移动`：取得角度和阻挡位置。
- `推击`：从侧面改变 BREAKER 面向；正面硬推只能减缓，不能完成目标。
- `防御/支撑`：承受冲撞并保住站位。
- `调取重盾`：靠近破墙热点后触发，开放一次完整格挡；格挡成功并把敌体重新压回南向窗口后，开放强化盾拍。
- `结束行动`：明确结束，不隐藏在点击空地。

**阶段：**

1. 无敌方冲撞的基础回合：移动、选择动作、结束行动。
2. BREAKER 画出第一条宽预警，正面碰撞把馆守 Z 推退，玩家看懂只互殴会输。
3. 纪存只在亲眼看见馆守 Z 回望后标出重盾；玩家自行走到展墙旁。
4. 取得盾后，BREAKER 发射赤红冲击；玩家必须让馆守 Z 面向威胁并执行格挡。格挡成功才设 `red_impact_blocked=true`。
5. 玩家把 BREAKER 重新压回中央/南向窗口，满足 `north_safety_line_held`、`guardian_z_disabled=false`、`breaker_facing_redirected`、`retired_shield_acquired`、`red_impact_blocked` 后，只设置 `finisher_ready=true` 并开放“强化盾拍”终结指令；不得自动代按或直接提交结果。

**失败与重试：** BREAKER 越过北侧安全线，或馆守 Z 被击倒/禁用，立即显示具体失败原因并回 CP2。CP2 使用同一个 `c01cdv1_s06_g1_v1` 初态重建棋盘；不得保留敌我坐标、朝向、盾状态、回合或已消费事件，也不得重播 S03–S05。

**可读性门：** 敌方意图必须先显示行动者、目标、受影响区域和会越过的安全线；预测只说明结果，不替玩家自动选最优格。战场不出现杂兵、经验值、升级或必须刷出的强力招式。

### E02-S07 盾拍首胜

**玩家输入门：** S07 先保留在可控战场并显示“强化盾拍”。玩家亲手执行 `confirm_shield_bash` 后才设置 `finisher_triggered=true`，锁定一次结果提交并开始下列七拍。`Full / Skip` 只控制这次输入之后的演出长短；跳过不能替代终结指令，未确认时也不能进入 CP3。

**七拍：**

1. BREAKER 头部红缝亮起，红光直指万机馆。
2. 馆守 Z 左手立盾；盾面烧红，冲击从两侧分开。
3. 镜头给旧盾第四道焦痕，后方消防通道完整。
4. 馆守 Z 顶盾前进，步幅逐渐加快；城市炮火只在敌体侧甲暴露后命中。
5. 盾角撞入胸前，两台巨体犁过广场，BREAKER 被推回南侧。
6. 馆守 Z 追加强化盾拍，BREAKER 第一次倒地；地面壳未毁，仍能重新蓄势。
7. 馆守 Z 跪一下，右肩旧伤冒白烟，双前臂仍完整；纪存说“欢迎回来”，旧守护者看向仍能重新蓄势的敌人：“导览尚未结束。”

不追加勇拳金光，不播 Boss 击毁，不用长篇伦理结算。玩家获得完整小胜，画面同时明确下一话战斗还没结束。

## 4. G1 联合证据

美术和主程序必须基于同一坐标/镜头编号交付：

1. `PV01_S01_EVAC_WORLD`：S01 世界空间全景与可走带。
2. `PV02_S03_SAME_BODY`：终端到胸前声源续接的两帧或分屏。
3. `PV03_S04_QIHAI_SCREEN`：双地 ADV 与七海最新身份读法。
4. `PV04_S05_GUARDIAN_STAND`：起身五拍缩略镜头板。
5. `PV05_S06_TACTICAL_READ`：安全线、意图、两种 footprint、重盾热点。
6. `PV06_S07_SHIELD_IMPACT`：挡击、推进、强化盾拍倒地三帧。
7. 一张 `world_space / screen_space / shot_space` 联系表。
8. 一段 30–45 秒低保真 Animatic 或 Godot 实机捕获，证明载体切换而非单纯展示静态图。
9. 至少两张 50% 叠图：S01 世界构图与程序；S06 战术读法与程序。

所有 G1 图均标记 `candidate_previs / runtime_allowed=false`。不得因为画面好看就直接放进运行时。

## 5. G1 用户验收问题

1. S01/S03 是否像一个有镜头控制的轻 RPG 探索，而不是横版平台或俯视小人地图？
2. 正比例 Shot Space 与小比例 World Space 是否仍然读成同一人物、同一机体、同一画风？
3. 馆守 Z 当前 Previs 使用的视觉母版是否可作为本 Demo 继续派生的基准？
4. S06 是否一眼看懂“别让它冲向北面、把它转回南面、去拿盾”，并且愿意亲手完成？
5. S05/S07 的高光是否已经靠关键帧与程序运动成立，值得再决定是否投入 LibTV/短视频额度？

任一问题为否，先修 G1。不得用更多资产、更多对白或付费视频掩盖构图与玩法问题。
