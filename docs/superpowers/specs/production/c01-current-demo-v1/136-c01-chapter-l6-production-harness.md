## 3. 第一章必须做成什么

成品一句话仍以 128 §1 为准。玩家一次连续玩完：

```text
E01 馆内导览 / 勇拳测试 / 饭约 ADV / 警报
        ↓
E02 会展街区：馆守Z 起身 → 撤离线 → 取盾 → 挡赤红 → 盾拍
        ↓ 桥A：豪司越黄线，勇拳入队（无假选项）
E03 同一受损街区：双机失配 → 堵钻 → 红裂 → 双拳破甲
        ↓ 桥B：离港整备 / 航路 / 换装 / 万机馆起飞
E04 巡展舰空战：护航 → 核心俯冲 → 勇拳回送 → 左拳终结
        ↓ 战后：第七次巡展，下一站木桶街
```

L4 玩法预案锁死的三个教学观念必须可指认：

1. 不同尺寸的机器承担不同工作
2. 纪存通过观察和通讯组织，不直接控制别人的身体
3. 万机馆不仅是菜单基地，也能作为母舰进入战场

L3 指纹（成片不得漂）：固定博物馆 + 旧会展广场 + 城市上空；动词是导览 / 起身 / 接拳 / 升空；任务是守馆撤离 + 两阶段 Boss；高潮是舰首单点冲刺贯穿；代价是右臂报废、失去旧址。不得提前消费 C14 暴走 / C20 全相环 / 万机馆人形。

## 4. 玩法策划与游戏模式

### 4.1 玩法总案（00c，Candidate）

主次不得颠倒：主战棋（空间 / 身体 / 朝向 / 意图 / 预备 / 非歼灭）＞ 活机群与人物 ＞ 探索调查 ＞ Hub 长线 ＞ Reader 演出。

C01 四种日子的分配：

| 日子 | C01 落点 |
| --- | --- |
| 出门 | E01 馆内导览、模型病院、勇拳测试 |
| 打仗 | E02 / E03 地面战棋，E04 空战母舰战 |
| 回家 | 桥B 离港整备（短，不是开 C12 生活章） |
| 被世界回望 | 战后第七次巡展、战报与下一站，不另开 Meta 系统 |

战斗家族：E02 正面会战 + 护线；E03 双机大动作战；E04 追与走 / 母舰护航。不得把三场都写成「护送无行动力的车」。

### 4.2 模式栈（机战 Y §8–9，收层不收皮）

整章必须换得出这些层，一层一件主确认，取消只拆当前层：

| 层 | C01 现网 / 缺口 |
| --- | --- |

| OPERATION | E02 有；E03 / E04 要跟 |
| 看盘 LOOK | PUBLIC |
| 落子 PLACE | EDIT；A 只落格 |
| 确认 LOCK | SUMMARY；出击只在这里 |
| 观看 / 结算 | PERFORMANCE / RESULT。OG 动画 OFF 小窗=结算不离盘；不把全屏战斗舞台当主读 |
| 对方层 | **缺**：一拍可见「对方在走」，不搬回合经济。第 3 批才开，须口头放开 |
| 查阅 / 战略 | C01 外，本台不做 |

禁止：六指令、HIT%、半屏武器表、把 `1/2` 升回主动词、EDIT 里 A 当出击。

OG 实机对照（`synthesis.md`）再确认：舒服的不是菜单皮，是玩家永远知道自己站在哪一层、棋一直留在盘上。成片台**照抄层、不抄皮**：

1. 光标是主语；底卡跟光标占格者
2. 一层一件；取消只拆当前层；跳 ADV ≠ 跳结算 ≠ 取消编排
3. 动词点亮地盘，不点亮说明书
4. 非法三种，确认无事：灰掉 / 弹层「没有意义」/ 高亮无反应
5. 检查敌只出卡，不出编排菜单
6. 底下留盘：地图 ADV、作战目的、获得情报都盖在同一张图
7. 承诺层留盘；不把 HIT% 当 C01 主读
8. 结果写回同一张图（热 / 防护 / 身体），不另播离盘动画冒充写回
9. 键面每面重写（LOOK / WATCH / 立绘 ADV / 地图 ADV 同一颗确认含义不同）
10. 地图干净：地上不写「请移动」；菜单词自己解释

`00c`：题目按话变、字母不变；打仗的日子换题目，回家的日子换气并**认账身体**。切页 ADV ≠ 回家。不要搬全灭 / N 回合屠图 / HP·EN·气力 / PP 商店 / 援护次数当拦护。`00d` 三问 OG 没有现成解：朝向三档与拦／护继续走 `133`，不拿护航或防御姿态冒充。

## 5. 玩家幻想门（L1，必须接线）

评委冷读必须问，不得只写在宪章里：

1. **体验断粮**：连续一段只有功能道具和行政实体，没有让人记住一台新机器人及其欲望，即 fail
2. **玩梗四层**：认出来 / 属于角色 / 撞出新东西 / 留下后果，至少过三层
3. **每场欲望**：谁想要什么、谁阻止、为何非现在打不可；主语是人物或机体，不是工程
4. **C01 必须兑的幻想**：第一幻想（真的在打机器人大战）、第二幻想（万机馆是家也是将要起飞的主角机）、第五幻想（手修 / 展品能帮 18m 机体站起来，但不能把塑料放大）。第三 / 四 / 六幻想只许播种，不许提前兑现后章峰值

### 7.1 实玩轨迹是合票的前置

抽帧必须由真实输入走到，不得用 `e01_focus_*` 之类的调试传送（它会把前置旗强设为真）。抽帧同时产出 `frames/e01-play-trace.json`，逐拍记录：走到这一拍按了哪些键、确认之后 readback 变了哪些键、这一拍属于 `play` / `flag_only` / `walk_through`。

`flag_only` 的定义：确认之后除了 `confirmed_*` / `visited_*` / `on_*` 前缀、`_text` / `_confirmed` 后缀之外，什么都没变。也就是只翻了一个点名册旗、换了一句教练文案。

`scripts/chapter-desk close --jury pass|warn` 在下列任一情况下拒绝写账（exit 3）：

- 没有 `frames.json` 或没有实玩轨迹
- `teleport_helpers_used: true`（帧不是玩出来的）
- `flag_only_beats > play_beats`（这一段整体仍是点名册）

判 `fail` 不受此门限制。这一门只挡「宣布合票」，不挡「诚实记录失败」。

另记两道**过程账**，不能冒充用户验收：

- `chapter_wired`：前情→战后整条可走，状态按拓扑写回
- `art_matrix_ready`：P0 行都有 exact 绑定或诚实缺图 marker；签收仍只属于用户

制作组不能给自己打 `jury_consensus`。`machine_pass` 不能关 L1 幻想门或 134 体验门。

## 9. 评委会

**`gameplay`（玩法）与 `interaction`（交互手感）是每批必开的常设席，非战斗批也要开。** 成片台第 1–2 批（spine 与 E01，共 152 轮）从未开过这两席，`scripts/chapter-desk open` 当时只生成八张卡，于是 152 轮里没有任何一席被授权问「这段能不能玩」。八席全部判静止画面的可指认性，结果就是一段按方向键加确认、22 次确认里 18 次只翻一个旗的导览日拿到了合票。这是设计缺陷，不是评委失职。

破壳台六席（玩法 / 交互 / 冷读 / 实帧 / 程序 / 制作人）在战斗批必开。成片台常设加开：

| 席 id | 席 | 硬问 |
| --- | --- | --- |
| `mode` | 模式 | 层是否换得出？一层一件？取消只拆当前层？底下有意义是否留下？地图 ADV 是否压活盘锁走格？有没有搬六指令或把结算做成离盘舞台？ |
| `fantasy` | L1 幻想 | 断粮 / 玩梗四层 / 每场欲望 / C01 该兑的幻想 |
| `story_play` | 剧情游玩 | 是否仍走 L4.5 顺序？检查点语义？有没有假选项？ |
| `spatial` | 合理性 | 呈现／空间是否合理？布局是否正常？场景和剧情是否搭配？比例和表现是否搭配？转场是否接得上？挡一件事的是世界里的东西还是 UI？ |
| `art` | 美术清单 | 是否走矩阵与 CML130/131？有没有把缺图当完成？ |

纪律与 135 相同：并行、互不看稿、禁止共写补丁、多数票压不过有证据的 fail、同一子代理不得连评两席、主笔不得兼任评委。Grok 评手感 / 冷读 / 盘 / 机体 / 实帧 / 合理性 / 玩法 / 交互。Composer 评边界 / 批次 / Reader / 矩阵。Composer 不得单独裁定好不好玩；Grok 不得单独裁定升格或视觉过关。

再加两条：

- **只看静止图就能满足的席位不得构成多数。** `frames` / `spatial` / `fantasy` 这类判画面的席位全过，而 `gameplay` 或 `interaction` 有证据地 fail 时，本轮不合票。
- **执行一律走 Grok 4.6**，包括制作组、八席评委、生图与找精灵图、实机试玩。Opus / Fable 只用于研判与方案层，不进每轮循环。Composer 保留在边界三席，是为了不让 Grok 给自己的产出打分。
