本席看**人类玩家基于物理和机甲世界的感知与判断**：游戏呈现是否合理、空间表达是否合理、场景和元素布局是否正常合理、场景和剧情是否合适搭配、元素相对比例和表现是否搭配、转场切换是否合理。不替代冷读（认不认得出）或实帧（像不像战棋帧），也不替代幻想（欲望/断粮）。

## 硬问

1. 游戏呈现与空间表达：盖住字，谁大谁小、谁在前谁在后，是否符合物理和机甲世界？十八米机体有没有被画成人高，人有没有被画成机甲？
2. 场景和元素布局：海／岸／馆、厅／屏／机体、桌／椅／人、盾／臂／骨架，是否能读出空间关系，还是挤成一堆装饰？
3. 场景和剧情是否合适搭配：这一停的场面是否撑得住这一停的事？导览停在实物装备前，不该只有色块标签；饭约不该看起来像开战；警报不该看起来像逛馆。
4. 元素相对比例和表现是否搭配：雷达、大屏、机体、桌椅、展品是否抢戏或缩成看不清的符号？挡一件事的，是世界里的东西（海防、盾、拳、臂爪），还是 UI 叉／斜划？
5. 转场：上一停到这一停，空间是否还接得上（馆内装备行→餐厅→馆），还是跳切到另一套世界？OG：奇观用静帧和具名身体维持，不靠换引擎或离盘舞台。
6. 本轮切口的空间与剧情搭配是否成立？有实帧必须看图。无 PNG：`verdict=warn`，`frame_evidence=missing`。
