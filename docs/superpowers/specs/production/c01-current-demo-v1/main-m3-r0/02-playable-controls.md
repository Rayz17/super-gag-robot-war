# C01E02 M3-R0｜试玩操作

## 启动

从项目根目录执行：

```bash
./scripts/run_c01e02_m3_r0_sandbox.sh
```

脚本直接启动非默认场景，不经过 startup router，也不调用 materialize。

## 操作

| 状态 | 键鼠 / 手柄 |
| --- | --- |
| 局势公开 | `Enter` / `Space` / 手柄 A 开始规划 |
| 移动光标 | 方向键或 `WASD`；均可按住连续移动 |
| 画路线 | 点击蓝色落点，或光标停在落点后按 `Enter` |
| 终点朝向 | `Q / E`；不改变路线 |
| 主动作 | `1` 正面承力顶偏；`3` 守住出口 |
| 预备反应 | `2`：小体进入保护线 → 横腿侧顶 |
| 备用方案 | `F`循环；备用不是预备，也不赠送动作 |
| 查看摘要 | `Tab` |
| 返回修改 | 摘要页 `Esc` |
| 执行 | 摘要页按住 `Space`、`Enter`或手柄 A，直至进度条走满 |
| 清空草案 | 编辑页 `R` |
| 重置同一轮 | 回执页 `R` |
| 退出 | 回执页 `Q`或`Esc` |
| 操作说明 | `H`；默认关闭，不自动填计划 |

## 两个可验证起手

### 主动作前压

1. 从初始格 `(15,11)` 移到 `(18,10)`；
2. 终点朝南；
3. 选择`1 正面承力 / 顶偏`；
4. 查看摘要并长按执行。

结果：接触较早，馆守 Z 承力较高，路面形成长弧翻裂。

### 预备守线

1. 从初始格移到 `(19,9)`；
2. 保持朝东；
3. 选择`2 小体入线 → 横腿侧顶`；
4. 查看摘要并长按执行。

结果：预备恰好触发一次，接触稍晚，馆守 Z 承力较低，小体落位和路面损伤不同。

## 建议故意试一次错误

把馆守 Z 移到 `(17,12)`，朝西并选择主动作。摘要会提前指出未覆盖风险；仍可提交，并在回执中看到 BREAKER 北向冲线为何无人承担。

无论成功或失败，R0 都停在 BREAKER 开始聚集红光：盾仍挂墙，撤离线仍为 active，不释放赤红冲击，不出现盾拍，不写 P1。
