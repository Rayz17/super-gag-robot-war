# C01E02 M2.5-U3｜车辆自动撤离交互修正回执

## 结论

- 应急车辆是不可控的自动单位，玩家只操作馆守 Z。
- 立盾并不立即结算：按 `B` 确认立盾后，按 `E` 结束我方回合并结算赤红冲击。
- 挡击成功后，再按一次 `E` 坚守；两台车辆在敌方阶段自动走完剩余路线。
- 车辆通过后才出现一次性 `盾拍 [F]` 授权。

## 本轮修正

1. 战棋状态公开 `braced_this_turn`；撤离进度公开 `player_controllable=false`。
2. 立盾后的唯一推荐动作改为 `下一步：结算立盾挡击 [E]`，不再错误提示继续向东。
3. 挡击后的推荐动作改为 `坚守；车辆自动撤离`，不再使用会暗示玩家操车的“护送/推进车辆”。
4. `结束回合`按钮按阶段改名为`结算挡击`或`坚守回合`。
5. 任务面板、敌方意图面板和场景消息均明确显示车辆不可操作、会在结束回合后自动前进。
6. 地图上的应急车辆名称追加`[自动]`。
