## 1. 这次实际制作什么

本轮制作一条可以从头玩到尾的 C01E02 候选试玩：先在人类尺度完成东侧撤离，再经历旧守护者与馆守 Z 的同体揭示、七海撤回本人停机令、馆守 Z 起身，最后进入旧会展广场的小型策略战，以重盾挡下赤红冲击、把 BREAKER 推回南侧，并由玩家触发强化盾拍使其第一次倒地。

交付性质为 `candidate_runtime_demo`：它验证新版三层稿能否形成一段好看、能操作、能理解且可继续扩产的游戏体验。它不是正式 L6、不是 Current Canon Episode、不是商店发行版，也不自动替换现有已验收 C01。

## 2. 单一来源层级

发生冲突时按下列顺序裁决，不允许各 Session 自行拼接：

1. **Current Canon Hard/Working 锁**先约束人物、机体、尺度、生命周期、身份和已接受的不可逆事实；Candidate 无权覆盖这一层。
2. **本次用户签发的 `demo_source_authorization`**只允许在上述边界内把新版 Candidate 三层稿用作隔离试玩来源，不授予 Current/Canon 迁移。
3. **Candidate 迁移边界**约束三层职责和不可静默改变的已接受事实。
4. **新版 Candidate 纯剧情 Reader**决定人物动机、对白事实、可见动作和本话结尾。
5. **新版 Candidate 游戏流程解构**把已经成立的故事转换为玩家行为、载体、胜败和节奏；若它强化或改变纯剧情中的动作结果，必须登记为显式裁决，不得静默覆盖。
6. **新版 Candidate 可公开情报**只决定可选资料页，不得成为通关前提。
7. **Current L4.5、战斗预案和物理板**只保留稳定段落 ID、物理边界、控制权和回归事实；不得把已被 Candidate 删除的内容重新灌回。
8. **旧 Runtime、旧 Demo 和 History**只允许复用通用代码结构、测试方法与性能经验，不允许复用剧情内容、状态、节点 ID 或旧视觉资产。

语义来源、原始路径与 SHA-256 见 `01-source-lock.tsv`；不可变制作截面见 `09-frozen-source-snapshot.tsv`。人物/机体实际视觉母版另由 `09b-frozen-visual-snapshot.tsv` 冻结，任何 `.superpowers` 活动路径都不再作为 G1 直接输入。本 Demo 固定读取初始基线提交 `fe7a0764d11f5ac5f9d11accb7398df664132b0b` 中的 Git blob及合同内冻结副本，而不是读取工作树里的“同名最新版”。设定/剧情/台本 Session 可继续修改工作树和推进后续章节；这些变化不会自动进入本 Demo。只有用户明确要求刷新 Demo 截面时，制作人才可签发新的 snapshot ref、登记视觉差异、重新检查三层一致性并重算下游内容指纹。

主程序若需物化输入，必须从 `snapshot_ref:path` 提取到 Candidate 专用生成目录，并记录 `snapshot_ref + source sha256 + demo contract version + content fingerprint`；美术只从 `09b` 所列 Git blob 或合同冻结副本读取母版。两者都必须校验 `13-demo-build-contract.json`，不得从当前工作树复制后再声称它是冻结截面。

## 3. 已锁定的试玩裁决

- 段落固定为 `E02-S01` 至 `E02-S07`，不得改名为旧五节点或旧“四张封存令”链。
- S01 与 S03 的世界空间候选为**电影化斜侧视 2.5D 浅纵深走图**；G1 必须先交联合 Previs，由用户确认后才开放正式资产与完整运行时总装。
- S01 按 Candidate 游戏流程保留两项明确失败：仍有观众滞留巨机交战区，或玩家误入已警示的地下封闭区；失败回到 CP0，不静默改成“空气墙即通过”。
- S06 是一个紧凑的目标导向战棋：胜法是读懂冲撞意图、守住北侧安全线、改变朝向、取得重盾并完整挡下一次赤红冲击，不是练级、刷伤害或全灭杂兵。
- 馆守 Z 在本话始终保留两条原装前臂；右肩旧伤允许冒烟，但不得提前缺臂、换巡展臂或发射火箭拳。
- `D0_S07_OUTCOME=gameplay_finisher` 已由用户于 2026-08-07 明确接受：S06 只在完整胜利条件满足后开放 `confirm_shield_bash`；玩家必须亲手确认强化盾拍，才设置 `finisher_triggered=true` 并进入 S07 结果演出。BREAKER 被推回南侧后第一次倒地；地面壳仍活动，不得在本话击毁、展翼或召唤 E03/E04 敌群。Full/Skip 只改变确认后的镜头播放，不替玩家执行该指令。
- S07 按新版 Candidate 以“导览尚未结束”收尾；不自动恢复 Current L4.5 中“勇拳测试场亮金光”的旧钩子。
- S05 与 S07 的演出默认完整播放，但用户可主动跳过当前演出；完整与跳过必须提交完全相同的剧情状态。
- 可公开情报全部可选；任何资料卡删除后，主因果与操作目标仍须成立。
- 常态画面使用已确认的 `A / KINETIC_CEL`；`B / ARCHIVE_OFFSET` 只在同体揭示、机魂/胸灯和机战峰值局部开启；本轮不使用 `C / MATTE_GOUACHE`。
- 不调用 LibTV、不生产付费视频、不批量派生资产，直到静态构图、身份和运行时合成通过用户门禁。

## 4. 检查点与失败恢复

- `CP0`：E02 开始。
- `CP1`：S02 撤离完成；普通人、跌跌、机器犬与消防架桥机从巨机战棋盘彻底退出。
- `CP2`：S05 起身完成、馆守 Z 首次可控；战棋失败只回到这里，不重播同体揭示、撤令和起身。
- `CP3`：S07 结算原子提交；`BREAKER_FIRST_FORCED_HALT=true`、`BREAKER_FIRST_KNOCKDOWN=true`、`BREAKER_DESTROYED=false`。

试玩使用独立命名空间和存档槽，不读取或写入旧 `story_first` 正式/手动存档。

8. 用户实际试玩后决定 Candidate 是否值得继续；内部 PASS 不替代用户创作和产品判断。
