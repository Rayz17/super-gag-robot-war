## 制作人验收结论

A9.1-A文件、哈希、纪存Current消费及18m／近30m比例关系成立，但视觉验收不通过：`P0=0 / P1=3 / P2=2`。原包保留为返修输入，不得写成用户已批准母版。

P1：

1. 两机体仍有连续渐变、软明暗和材质渲染，尤其BREAKER仍是暗色半厚涂；`KINETIC_CEL`不能靠合规表自报PASS。
2. 馆守Z四向来自同一张生成turnaround的四个视图切片，但尚未形成同一结构母版／Rig；只测头身，未闭合肩宽、胸宽、前臂长、腿长。
3. BREAKER虽然保留高背壳、低头红缝和长前肢，却强烈读成“龟壳＋猿类四足”，触碰B＋X禁止的普通四足兽／穿山甲读法。

P2：CML128应登记为Working画法锁而非Hard身份锁；现有量尺板未证明真实pivot、脚点、footprint和遮挡。

## 仅允许的返修

### A. 馆守Z

- 保留A9.1-A当前V10X正面身份，不重新抽一台馆守Z。
- 以一个可追溯结构母版建立正、背、严格左、严格右；允许分层绘制、2D骨架、3D灰模或确定性结构重建，但不得用四次独立生成冒充四向。
- 逐向登记并叠合：总高、头高、肩宽、胸宽、上／前臂长度、髋宽、大小腿长度、脚底线；左右镜像关系和非对称件必须显式说明。
- 保持E02双臂、无翼、无背包，以及用户已限域接受的V10X身份锚。

### B. BREAKER

- 从已批准B轮廓＋X表面关系窄返修，不改变低头单红缝、前肢承重半直立、巨背壳、闭合胸缝、封闭上背出口。
- 消除龟甲、猿肩、地球脊椎动物腹腔和普通爪兽的第一读法；强化非地球攻城壳／生体装甲的受力连续性、异质关节和非哺乳动物体块。
- 规划与接触仍须由同一结构母版派生，不得另画第二台相似BREAKER。

### C. 真正的KINETIC_CEL常态版

- 两机统一为深墨蓝压力线、4–7个主色块、最多两级硬阴影、局部受控高光和有限磨损。
- 清除大面积软渐变、空气透视式体积光、商品渲染反射和随机材质噪声。
- 合规板必须同时展示原像素、缩至实际地图显示尺寸后的像素和色块／阴影抽样；不得只列文字PASS。

### D. 实际地图显示证据

- 使用A4投影 `tile_half=(40,20)` 和 `canvas_world_origin=(-880,-170)`，制作真实2×2／3×3落点、pivot、脚点、屋顶／前景遮挡与50%遮挡对照。
- 保留A5小体、纪存CML001及既有18m／近30m比例结论；纪存与总体比例不重做。
