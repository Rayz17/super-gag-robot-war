## GF-PLAN

- 产物：现代超级机器人 SRPG 的 16:9 成片规划态，不是设定板、草图、矢量夹具或宣传海报。
- 场景：雨夜旧会展街区，东门、展墙、中央广场连续；湿路、玻璃幕墙、青绿撤离灯、暖色馆内光。
- 馆守Z：V10X 裸机约四头身 Q/SD；金色多层头冠、中央红冠饰、蓝额、银格栅面、红X胸甲、金色圆核、宽肩环、等长圆柱前臂；无飞翼、无背包、无缺臂、未持盾。
- BREAKER：B 前肢承重半直立＋X 异质生体装甲；近30米、黑色叠甲、低头块、单一红缝、闭合胸缝、封闭核心出口；不人形、不普通四足、不通用黑圆壳。
- 小体：A 伏壳钳足型，散乱独立；应急车正通过东门；三旧痕高窄塔盾仍挂展墙。
- 规划读法：短路线、2×2终点幽灵、朝向、保护线、冲撞走廊、五时点；地图占主画面。
- 纪存：27–29岁中国成年男性，黑发蓝眼、无眼镜、深蓝馆务外套、左臂终端；导览席路线判断，不是驾驶员。
- 风格：KINETIC_CEL，深墨蓝压力线、大色块、两级硬阴影、有限磨损；禁止写实CG、玩具渲染、移动端杂乱和AI细节噪声。

- 以 GF-PLAN 为同场景母锚；保留相机、雨夜光向、东门、展墙、墙盾和街区身份。
- 移除规划路线、幽灵、朝向、威胁走廊和打开的命令抽屉；执行态 UI 退让。
- 应急车已安全过门；馆守Z正面承接更大的 BREAKER，被向北/东推出；双脚错位、后脚拖痕、前膝压缩、前臂承压。
- 只用压缩接触闪、路板翻起、长滑痕、雨水扇形和碎石表现重量；不做火球。
- 城市炮独立命中 BREAKER 侧甲；红缝开始聚光但不释放赤红冲击；核心保持封闭。
