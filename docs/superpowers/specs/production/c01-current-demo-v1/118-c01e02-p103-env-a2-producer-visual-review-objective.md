# C01E02 P103：ENV-A2 简单2D环境制作人视觉签收门

状态：`BLOCKED_BY_ENV_A2_DELIVERY / PRODUCER_ACTUAL_FRAME_REVIEW_REQUIRED`

## 1. 目的

ENV-A2完成后必须由制作人看实际1280×720画面再决定能否进入最终PLAN重组。脚本成功、哈希闭合或模块可分离，均不能替代本门。

## 2. 必看画面

- Camera V2共享PLAN全图，100%与50%各一张。
- A CONTACT与B CONTACT环境图各一张。
- 正常不透明建筑态与0.34显隐态各一张；必须看清被遮机体、路线与建筑底座。
- 六栋独立Structure、墙挂盾、东门、警戒设施和A/B道路后果的独立开关板。

## 3. 通过标准

- 3秒读出车向东门撤离、三只小体威胁、BREAKER北冲、馆守Z去承接。
- 10秒分清道路、选择口袋、承力大道、六栋建筑、盾、东门与警戒设施；建筑高存在感但不形成峡谷式遮挡。
- 30秒能从地图后果读出A“低热但设施/路面代价大”与B“保设施但高热、二轮余量归零”。
- GroundBake连续、无硬拼缝、无重复放大纹理；独立建筑/物件在Camera V2中透视、pivot、footprint和前后排序一致。
- 正常态建筑成立；显隐只影响真正遮挡关注点的对象，建筑底座与阻挡范围保持可读。

## 4. 停止边界

失败时只退ENV-A2环境支路，不回退R2C玩法、Camera V2、BREAKER或馆守Z单主体支路。通过前不得把ENV-A2像素用于最终PLAN、CONTACT、Runtime、UA91、G2-B或Canon。

P103通过后，才允许最终PLAN确定性重组同时消费已签环境、BREAKER、馆守Z与现有小体正例。
