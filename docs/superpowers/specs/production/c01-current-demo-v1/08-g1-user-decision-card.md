## G0.5 已完成决策 D0：S07 以强化盾拍取胜

`D0_S07_OUTCOME=gameplay_finisher`。独立审计发现新版三层稿在这里不一致：

- `纯剧情 Reader` 只写馆守 Z 顶盾把 BREAKER 推回南侧，令它“第一次被迫停下”；敌体随后仍能重新压低身体。
- `游戏流程解构` 把胜利强化为“取得重盾后发动强化盾拍，让 BREAKER 第一次倒地”。

两种候选曾为：

- `D0-A / story_minimum`：挡下赤红冲击，盾角推进，把 BREAKER 推回南侧并迫停；不倒地。
- `D0-B / gameplay_finisher`：完成上述动作后追加一次明确盾拍，让 BREAKER 第一次倒地；地面壳未毁并仍能重新蓄势。

**用户于 2026-08-07 接受 `D0-B / gameplay_finisher`。** 五分钟战棋先完成所有姿态谜题条件，再开放 `confirm_shield_bash`；玩家亲手确认后设置 `finisher_triggered=true`，让 BREAKER 第一次倒地作为完整小胜。敌体地面壳未毁且仍能重新蓄势，E03 才发生破甲、展翼和馆守 Z 右臂毁损。跳过只跳确认后的演出，不代替玩家输入。

该裁决只授权 `candidate_runtime_demo`，不自动修改 Candidate 纯剧情 Reader 或迁移 Current Canon。若未来决定正式迁移，须同步补齐纯剧情 Reader 的盾拍倒地结果并重建下游。

## 决策 D1：探索呈现

**制作人推荐：** S01/S03 使用“电影化斜侧视 2.5D + 浅 X/Y + 三构图区相机”。

通过条件：

- 20 秒内能证明不只有左右移动；
- 人物足够大，能看出最新设计；
- 同区相机稳定，跨区才运镜；
- 全屏剧情图明确属于 Shot Space，不冒充地图；
- 操作、热点和遮挡比旧俯视小人方案更清楚。

若不通过，优先改相机区、人物高度、行走带和遮挡；不立即退回全俯视，也不靠更多对话补救。

## 决策 D2：馆守 Z 的 Demo 视觉母版

当前存在两类证据：

- `CML008` 的 Current 锁与用户选定基础图，身份稳定但不是新 A/B 生产母版；
- 美术 v0.3 的 `CAND_GUARDIAN_Z_COLLECTOR_E02_V10X_LOCKFRAME`，生命周期明确为 `c01e02_intact_original_both_forearms`，但仍未获得正式身份/Runtime 批准。

**制作人推荐：** G1 将两者并排展示，实际 S05/S06/S07 Previs 暂用 V10X 候选做 `demo_visual_candidate`，同时用 CML008 锚定 18 米、完整双臂、胸/肩/头部识别和生命周期。只有用户看过 Previs 后，才决定是否以该候选派生 Demo 资产；这不自动迁移 Canon。V21 及所有 A3 飞翼/背包结构试验禁止进入 E02 Previs。

必须停下的情况：用户认为 V10X 不像馆守 Z、比例/冠/胸部/肩部不满意，或要求换回/重做母版。

## 决策 D3：S06 战棋是否值得继续

**制作人推荐：** 4–6 回合目标谜题；玩家读冲撞意图，通过站位和推击改向，取得重盾并挡一次赤红冲击，再执行强化盾拍使敌体第一次倒地。无练级、无杂兵清场、无数值磨血。

通过条件：

- 第一眼能指出敌人下一步要撞哪里；
- 玩家至少有两个可理解但结果不同的站位选择；
- 失败能说清是安全线、面向或支撑问题，而不是数值不够；
- 取得盾前后玩法和爽感明显变化；
- 5 分钟内完成，不吞掉剧情和演出。

若不通过，先改目标、意图、地图与指令；不靠增加技能树、升级、装备数值或更多敌人救场。
