# C01E02 A9｜Gold Frame 与 Golden Turn 成片美术目标

> Owner：美术资产 Session  
> 依赖：55、56  
> 生命周期：`production_quality_candidate / placeholder=false / intended_for_integrated_playtest=true / runtime_allowed=false`  
> 本任务不修改 Canon、不写 Godot、不自行签 handoff

## 1. 任务改变

停止沿用 A8 B1.1 的程序矢量草图路线。A4／A5／B1.1 只作拓扑、脚点、轮廓与碰撞参考，不作为成片像素来源。

本轮美术的验收单位是两张完整实机目标画面，而不是孤立三态表或 Atlas：

- `GF-PLAN 1280×720`：第一轮规划态；
- `GF-CONTACT 1280×720`：同一轮第一次巨体接触态。

两帧必须像同一款已经存在的游戏，同时达到可直接指导 Godot、后续 Atlas 和 Cut-in 的程度。

## 2. 必读来源与身份锁

- 55 质量重置裁决与 56 Golden Slice 母合同；
- 当前已验收 C01 Reader 对应 E02 段；
- 馆守 Z：`guardian_z_collector_e02_lockframe_candidate_v10x.png`，E02 裸机，不带 V21 飞翼；
- BREAKER：用户已选 B“前肢承重半直立”＋X“异质／生体装甲”；现有 B/X 板只作结构简图，必须完成成片级视觉设计；
- 纪存、七海、兜灯的美术 Session 最新身份设计；不得回流旧 Demo portrait；
- 旧守护者与馆守 Z 同一主体，终端、广播和胸前扬声器只是输出端；
- A4 的32×18拓扑、2400×1350画布与投影；A5小体“A伏壳钳足型”身份；重盾A高窄塔盾＋F-D70/P30与三道旧痕。

如发现“最新身份设计”与以上锁冲突，先报制作人，不自行折中。

## 3. 生产方法硬规则

- 新位图与编辑默认使用 ImageGen 的正式生成／编辑流程，必要时用 Blender 等距灰模、深度／姿态代理和 Krita 清稿；最终资产必须回存项目。
- 禁止用 Pillow、ImageDraw、Canvas、多边形／圆形程序绘制角色、机体、地图或 Cut-in 成片。脚本只可做装配、切片、遮罩、哈希、尺寸和 alpha 校验。
- 身份敏感资产必须用参考图约束并逐锚复核；禁止只写文字 prompt 反复生出不同机体。
- Q/SD 动作不得逐帧自由生图。先确定同一母版／分层 rig／toon代理，再派生朝向和关键姿势。
- 不批量生成完整 Atlas；先过 Gold Frame，再按被镜头实际消费的动作交 Golden Turn 最低集。

## 4. Gold Frame 双帧

### GF-PLAN

必须同时包含：

- 东门—展墙—中央广场走廊中的成片级雨夜战棋地图；
- 正式约4头身 Q/SD 馆守 Z、BREAKER、小体与应急车；
- 一条玩家短路线、2×2终点幽灵、终点朝向、保护线、BREAKER冲撞走廊和五时点图标；
- 最新纪存半身演出，明确是导览席的路线／人员判断，不是驾驶员；
- 正式 UI 层级：地图为主、一个当前目标、最多三个高威胁、可收起命令抽屉；
- 不显示坐标、hash、Stable ID、Candidate、debug、占位字或开发英文。

### GF-CONTACT

使用同一地图与光向，表现：

- 应急车已先通过；小体被横腿／身体挡开但未消失；
- 馆守 Z 正面承接 BREAKER，较小机体被推出，双方支撑点和受力方向清楚；
- 路面翻起、雨水飞散、城市炮即将或正在击中侧甲；
- BREAKER 红缝开始聚光但赤红冲击尚未释放；墙挂盾仍在展墙；
- 执行态 UI 自动退让，只保留必要目标和时点，不遮挡接触点。

### 双帧质量门

- 1280×720 原尺寸和 50% 显示都能一眼认出双方身份、支撑点和保护对象。
- 画风统一为 `KINETIC_CEL`；有限 `ARCHIVE_OFFSET` 只能用于通讯／机魂层，不把 A7 写实渲染直接夹进地图。
- 地图不再是通用灰楼块：能看出会展馆、玻璃幕墙、东门疏散设施、展墙、湿路与城市尺度。
- BREAKER 必须把 B+X 从简图发展为正式异质生体重甲，不得变成人形、普通四足或通用黑圆壳。
- 状态差异来自姿势、重心、构图和环境后果，不靠说明文字。

完成双帧、源文件、分层说明和身份叠图后停止，回传制作人；由制作人在本任务向用户展示。未获用户 Gold Frame 通过，不得进入以下阶段。

## 5. Golden Turn 真资产最低集（Gold Frame 通过后）

### 地图

- 生产母版建议 4800×2700，运行导出 2400×1350；保持 A4 精确坐标。
- 至少交：道路底层、建筑、屋顶、前景、遮挡／语义 mask、雨夜灯光六层。
- 第一轮前态与接触后态：路面翻起、玻璃／碎屑、炮击侧甲影响；盾仍墙挂。
- 本阶段只精修镜头实际经过的东门—展墙—中央广场走廊；不虚假宣布全32×18地图已经最终绘制。

### 战棋单位

- 馆守 Z：四朝向 idle／转身基态；第一轮所需重步、横腿挡小体、brace、后滑关键姿势。
- BREAKER：四朝向 idle／重心基态；north 冲撞蓄势、推进、contact压缩、侧甲中炮、red-charge。
- 小体：四向游走基态；扑击 telegraph、lunge、stagger／被挡开；群体保持 scattered。
- 应急车：east 6帧行驶循环，警示灯可独立；无医疗十字和“最后一辆”文字。
- 动画以8–12fps关键姿势＋Godot平移／补间／FX实现；不以大量低质帧换完成度。

### 人物／机魂

- 纪存：路线判断、接触承压两个真正不同的半身构图；眼、嘴、手、躯干、腕部终端可分层。
- 兜灯：机况观察／紧张两个状态，使用最新身份；如沿用已批件必须证明实机组合成立。
- 七海：只需撤令远程状态；闭口决定，不作为常驻战术队员。
- 旧守护者：`guide`稳定导览中景与`contact`承力近景两幅，均为V10X同一主体；不得用同一胸像换灯色。

### FX／声音

- FX：脚步／雨水、横腿挡开、首次巨体接触、道路翻起、城市炮侧甲命中、红光蓄能。
- 当前程序合成 WAV 只作历史时序证据，不得进入用户可见 Golden Turn。
- 声音至少包括伺服／脚步、低频体重、金属压缩、道路碎裂／碎屑、雨夜城市环境和 UI 提交反馈；每项给来源与授权状态。
- 临时 AI 配音和付费生成在制作人取得用户明确授权前不得批量执行；可先交声音脚本、层级和精确触发点。

### 输出

- 独立图层／Atlas／source master；
- `asset-manifest.tsv`、身份来源、媒体参数、frame／pivot／safe rect、状态与SHA；
- Godot消费说明和两张1280×720合成回放板；
- 45–75秒 Golden Turn 声画时间表；
- 明确列出尚未制作的取盾、挡击、盾拍、P1资产，不得假称完整E02。

## 6. 后续 Cut-in／LibTV 门

Gold Frame 和 Golden Turn 通过后，才为完整 Golden Slice 制作：

- 起身正比例关键帧3–5张；
- 赤红挡击关键帧4–5张；
- 盾拍关键帧约6张；
- 重盾墙挂／持用／烧红／第四焦痕／变形五态；
- BREAKER倒地与重新撑起；避难所反应与勇拳灯光钩子。

LibTV 仅通过官方 CLI 操作，且每镜先批准开始／受力／结束静态关键帧。推荐候选：起身3–4秒、挡光2.5–3秒、顶盾＋盾拍3.5–4.5秒；首次巨体接触先用分层静帧、镜头、FX与音频证明。无视频时静态 fallback 必须完整成立；视频不烘字幕、UI或状态，Full／Skip结果相同。

付费批量生成未获用户明确授权前停止在静态镜头本。
