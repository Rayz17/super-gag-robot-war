## 逐态首读硬门

### 00 机制常态

- **PASS_FOR_USER_REVIEW**：A33 的小型英雄头、短 V、机械虎鬓冠、完整胸腹、宽髋、承力腿和稳定足保持。
- 双臂对称健硕，双拳使用同一结构语法：四区钝性承击面、后退行程缝、腕臂嵌套套筒、双侧回送导轨与未充满指示带。
- 虎意只是双臂甲片的前肢肌肉节奏和少量宽凹槽；没有虎头肩甲、兽爪手、毛皮、尾巴、四足或变形铰链。

### 01 吸纳冲击态

- **PASS_FOR_USER_REVIEW**：两个拳面同时承击，两组套筒与回送导轨同时工作。
- 金色接触火花只在拳面，青金能量在臂内向肘侧回流；没有向外射出的光束。
- 双拳仍完整闭合且连接在前臂，没有炮口、飞拳、张开兽爪或单臂特化。

### 02 满载锁压态

- **PASS_FOR_USER_REVIEW**：外部冲击火花消失，拳面仍处于后沉锁定，双臂储压段和回送指示带对称满亮。
- 能量仍被限制在双臂结构内，拳面没有开孔或射击出口。
- **用户风格风险**：高亮可视储压段可能有约 `20%` 概率被短暂误读成“能量圆筒”；但其末端是完整闭合的四区重拳，没有枪管、炮口、准具或射线，Section 2 未判定为武器化失败。

### 03 整量释放态

- **PASS_FOR_USER_REVIEW**：两只闭合重拳仍与前臂连接，导轨和套筒向拳面完成短行程推送，非飞拳。
- 拳面外是宽而短的环状压力墙，不是细长光束；拳甲和钝性指节仍清楚显示在效果中央。
- 未出现孔洞炮口、枪管、抛射物、脱离拳、断裂或新武器。

## 四态同源与风险判断

- 头雕、胸甲、髋腿、足部和整体比例在四张中保持同一视觉身份。
- 双臂的虎前肢甲片节奏、宽凹槽、外侧护甲、压缩段、导轨与四区拳面持续可追认。
- 四态没有任何一张出现虎形、四足、尾部、兽头肩甲、动物关节或变形铰链；虎特征没有越过“双臂造型投射”的用户边界。
- 真实用户停门仍在：需要用户判断满载/释放态的可视储压段是否仍足够像机械液压结构，以及压力环是否准确读为钝性冲击而非能量射击。

## 后续生产硬锁

- 满载态的透明亮段定义为“封闭储压可视窗＋内部压缩套筒”，不是枪管、炮管、能量管或发射器。
- 四态拳面都必须保持封闭的四区钝性承击甲；后续不得在中央开孔、增加瞄准结构、枪口或喷口。
