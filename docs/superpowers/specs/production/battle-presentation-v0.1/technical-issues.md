# C01 切片技术问题单

## 已关闭

| ID | 问题 | 处理 |
|---|---|---|
| TECH-C01-01 | full / short / off 可能产生不同结算 | 结算移至演出前，播放器只读深拷贝 |
| TECH-C01-02 | 移动后攻击范围无敌人时可能卡死 | 命令状态支持取消、改待机或结束阶段 |
| TECH-C01-03 | 玩家仍有可行动单位时不能结束阶段 | 结束阶段始终可用并有确认路径 |
| TECH-C01-04 | 单位一回合可反复行动 | `READY → MOVED → DONE` 状态与阶段重置分离 |
| TECH-C01-05 | 敌方无行为 | 敌方意图、目标、移动与结算已进入独立阶段 |
| TECH-C01-06 | 返回场景重置到出生点 | 每个探索小场景保存当前位置，出口返回落在对应入口 |
| TECH-C01-07 | 七海通讯台过早可用 | 由 `zero_anomaly_heard` 门控热点生成 |
| TECH-C01-08 | 重复调查重复提交选项 | 首访与重访脚本分离，事务 ID 幂等 |
| TECH-C01-09 | 视频缺失或类型错误锁死 | present / missing / load-failed 三路径统一回退并发出一次完成信号 |

## 架构约束

- `EpisodeDirector` 只编排，不吞并探索、活动或战棋规则。
- 所有模式通过幂等事务写入统一状态；表现层永远不拥有伤害和剧情结算。
- 新玩法先映射到 Spatial / Constraint / Timing 三种活动引擎之一；无法映射时才提交新内核提案。
- 当前不引入插件、付费视频服务或新的商业授权依赖。
