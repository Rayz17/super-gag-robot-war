# 战斗演出 A/B/C 分级建议

> 状态：候选定义。本文不决定全游戏数量或比例。

## A 级：剧情不可逆演出

- 用途：首次觉醒、关系承诺兑现、断臂/合体/离别等不可逆动作、章级 Boss 决定性动作。
- 时长：约 6–12 秒，可由多个镜头组成。
- 资产：专用地图状态、角色 Cut-in、全比例机甲 Pose、Godot FX；视频仅为可选增强层。
- 规则：跳过不丢失结算；至少有一句由当前关系或选择触发的专属台词。
- 馆守 Z 半跪低热掌防目前属于 A 级候选，因为它同时承担机体限制、兜灯停机权和保护线成立。

## B 级：命名动作与角色协作

- 用途：命名武器、支援攻击、防御援护、角色关系组合、精英敌人的识别动作。
- 时长：约 2–5 秒。
- 资产：地图动画 + 一张 Pose 或一张 Cut-in + 复用 FX；通常不制作视频。
- 规则：复用同机体母体与镜头模板，但台词和命中节拍可按关系变化。

## C 级：常规反馈

- 用途：普通射击、撞击、格挡、状态施加、敌方量产动作。
- 时长：约 0.5–2 秒。
- 资产：地图 Sprite 状态、位移、闪光、伤害数字和音效。
- 规则：信息清楚优先；允许默认关闭，不阻断策略节奏。

## 分级判断题

一个动作每答“是”一次，等级倾向上升，但不是机械计分：

1. 它是否改变角色关系或机体永久状态？
2. 玩家是否会在数小时后仍用这个动作记住该角色？
3. 它是否只在一个特定剧情条件下成立？
4. 地图 Sprite 是否无法传达其身体重量、牺牲或反转？
5. 它是否值得在收藏/回看系统单独保存？

## 当前推荐

先用馆守 Z 验证 A 级生产，再选一台动作节奏完全不同的机体做 B 级复用试验。两者均通过后，才讨论全游戏各级数量、比例与预算；当前停止在候选定义，不提升为正式标准。
