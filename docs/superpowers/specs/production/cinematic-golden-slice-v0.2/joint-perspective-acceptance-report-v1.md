## 1. 制作人结论

“电影化斜侧视舞台 + X/Y 浅纵深 + 三个构图区相机”的方向成立，明显优于旧俯视管理地图读法，可以进入一次真实美术总装试点。

通过的不是完整美术包，而是以下生产判断：

- 斜侧视、190 px 左右成人比例和 60–100 px 小机器人比例能同时容纳角色阅读与探索空间。
- 三个固定构图区比持续跟随更接近镜头本需要的电影化舞台，同时没有取消 X/Y 绕行。
- R2 倒地点和 R3 低热扇区可以留在斜侧视同一房间，不必退回独立俯视棋盘。
- 1920×900 clean plate、可动物件、FG 遮挡和 MASK 的职责已经足够清楚，可以开始最小运行时资产生产。

当前不批准全量角色、全套动画、半身、Cut-in 或全场景资产批量生产。下一步只开放 Phase B1 总装试点，用真实资产验证 AI 美术经过压缩、分层、脚点、相机和 Godot 合成后是否仍然成立。

## 3. 锁定的联调决定

### 3.1 相机与世界坐标

- 正式试点采用美术 metrics：世界 1920×900，相机中心 `Y=450`。
- 三个相机中心锁定为 `(640,450) / (960,450) / (1280,450)`。
- 美术裁切锁定为 `[0,90,1280,720] / [320,90,1280,720] / [640,90,1280,720]`。
- 主程序不得把 clean plate 改裁到 `Y=400`；应把 walkable、热点、脚点、遮挡和战术图形同步到 A.5 metrics。
- A.5 的 `art-phase-a5-layout-metrics-v1.json` 成为 Phase B1 坐标权威；剧情 JSON 仍是因果权威。

选择 `Y=450` 的原因：它对应实际 1920×900 clean plate 的有效构图和三个已审查裁切；选择 `Y=400` 会迫使美术重新裁图并把近侧脚点压到视口底缘，增加无意义返工。

### 3.2 背景分层策略

Phase B1 不强制制造昂贵且容易接缝的 FAR/MID 视差拆分。允许：

- 一张 1920×900 的 `FAR + MID_CLEAN` opaque 基础底板。
- 独立 Alpha `PROP`、`FG`、`SPRITE`。
- 独立灰度/矢量 `MASK`。

只有后续镜头证明必须有视差时，才把 FAR 与 MID 拆成两张运行时纹理。斜侧视的关键首先是脚点、Y-sort、遮挡和构图区，不是为了“2.5D”标签强行堆层。

### 3.3 UI 安全区修正

A.5 v03 的纪存、唐胶和小机器人脚点部分进入原底部 118 px 安全带，说明一个安全区同时服务永久 HUD 与临时对白并不合理。Phase B1 改用双层规则：

- 永久 HUD 安全区：顶部 56、左右 32、底部 72 px。
- 临时对白保留区：底部 118 px；对白期间允许覆盖非交互地面，但不得遮当前说话者脸、当前热点或战术点击目标。
- 场内字幕优先跟随说话者或移到空侧；若与脚点/热点冲突必须自动换侧或上移。

该修正不改变对白 Profile，只修正布局责任。

## 4. Phase B1 开放范围

### 美术只允许生产

1. 一张正式试点用 1920×900 opaque 基础底板。
2. 一组前景栏杆/遮挡 Alpha。
3. 旧服务门开/关 PROP。
4. 环境灯、低热区、馆守 Z 胸灯/余辉 MASK。
5. 纪存四方向最小 idle/walk 走图。
6. 跌跌最小 idle/walk/fall/down 动作。

### 主程序只允许集成

- 上述六类资产。
- 相机 Y=450 与 A.5 metrics 坐标修正。
- manifest 驱动加载、脚点、Y-sort、FG 遮挡和 MASK 状态。
- 真实美术下的 Zone A/B/C、R2、R3 五图和 45–75 秒录屏。

其他 NPC、机器犬、成年观众、贴片机、七海/纪存半身、Cut-in、完整白框 FX 和全套动作继续使用明确几何占位；不得为了让画面“看起来完成”越界生产。

## 5. Phase B1 退出门

只有以下项目全过，才讨论 Phase B2 批量资产：

1. 真实底板在三个相机区均无裁切空洞、透视跳变或 AI 扩图接缝。
2. 纪存四方向在 165–220 px 范围内仍是同一人，走路脚点不漂移。
3. 纪存前后移动时缩放、Y-sort 和 FG 遮挡稳定，不像贴纸滑动。
4. 跌跌的主动摔倒在实际 R2 操作中方向、落点和 down 状态连续。
5. 旧门、低热区和胸灯 MASK 能由既有状态驱动，不烘焙在底板里。
6. R2/R3 点击命中与视觉贴花一致，不因相机 Y 修正产生偏移。
7. 永久 HUD、场内字幕和战术提示不遮关键人物、脚点与点击目标。
8. 1280×720 稳态 60 FPS；首次纹理加载尖峰有实测和预载策略。
9. 完整/跳过 outcome、Canon strict、旧基线回归继续通过。
10. 用户试玩后认为真实美术总装明显优于几何占位，且愿意继续同一方向。
