## 来源 A：旧解构（C01-游戏流程解构-v1.md:40–67，effect-tests/C01-story-gameplay-separation-2026-08-07/gameflow/）

阶段目标原文顺序：
1. 馆守Z 站到 BREAKER 与东侧撤离线之间（行 46）。
2. 抵挡 Boss 同时驱散、牵制漏入小体，**保护最后的应急车辆完成撤离**（行 47）。
3. **撤离线清空后**，利用主厅破口取得退役重盾（行 48）。
4. BREAKER 蓄积正面冲击时满足站位条件 → 开放一次「重盾拍击」情境指令（行 49）。

配套事实：拍击前置 = 已取得重盾 + 撤离线刚刚清空 + 位置满足正面反击（行 57）；
拍击后 = 重盾留第四处焦痕、热变形边缘凹折，Boss 倒地重新起身（行 59–62）；
出口 = Phase Checkpoint，街区/Boss/重盾/小体位置全保存，不治疗不刷新（行 65）。
失败条件：Boss 越过北侧防线；撤离线清空前被突破；馆守Z 失能（行 51）。

## 来源 B：新 Reader（C01-纯剧情章节Reader-修订稿.md:365–415，广场首战）

叙事顺序：
1. 正面相撞被推出；纪存把南侧空地标给馆守Z（行 355–361）。
2. 拦截炮命中侧甲，冲角偏开（行 377）。
3. **取得重盾**：固定扣弹开，从主厅侧面原展位整个扯下（行 381–385）。
4. 举盾承受冲击：盾面第四处焦痕；**后方最后的应急车辆与万机馆入口受盾保护**（行 387）。
5. **最后的应急车辆驶过东门，消防架桥机收桥，隔离门合拢**（行 389–391）。
6. 持盾侧压回南侧，横拍 BREAKER 头部，侧翻（行 399–401）；城市炮火重新压住（行 413）。
7. Boss 重新起身，馆守Z 持变形盾面向广场（行 411–415）。

## 两源共有、不可缺席的因素（两版都写明）

退役重盾（两层楼高、第四处焦痕、热变形）、护应急车辆撤离、合法站位触发的情景反击
（非击杀）、Boss 拍倒后重新起身、带伤损/破坏进入下一阶段、无治疗派奖。

## 裁决后果（供参考）

- 选 A（新 Reader）：护线反应的「撤离」条件改为以持盾承力事件为界；南向导流保留；
  取盾交互提前到承力段。首段两条可玩路线需重排。
- 选 B（旧解构）：维持 T5 设计稿现有两路线顺序；新 Reader 的炮火命中段作为第二段输入的叙事包装。
- 选 C（并置）：首段维持现状；完整 T5 适配时按所在章节再次确认（两次确认成本）。
