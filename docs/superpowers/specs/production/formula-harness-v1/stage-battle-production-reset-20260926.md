## 2. 根因与工具分工

当前 `forecourt.gd` 用两个侧身步姿轮换、左右镜像和上下位移表现所有方向。它没有各方向的真实接触姿态、重心转移、落脚和转身。多生成几张相近的图或增加抖动，不能补上这个缺口。

本机 Blender 为 4.4.3。检查 `artifacts/c02_stage_v8/source/guardian-v10x.blend`：112 个网格，有肩、肘、髋、膝、踝等刚性关节节点，**没有保存的 Blender 动作片段**。刚性机甲可以不用蒙皮骨架，父子关节本身没有错；不足是造型精度和动作没有被完整制作、接触校验及实机审看。将原来的基本几何换到 Blender 执行，也不自动提升质量。

采用的生产链是：**有效设计图 → 起模 → Blender 修形、分件、UV、材质、关节及动作 → GLB → Godot / 公式台。** Meshy 是可选起模工具，Blender 是制作与修整工具；Godot 和 Three.js 属于运行、渲染侧。Three.js 能加载复杂模型、蒙皮和动画，不限于小部件；当前项目已用 Godot，无须为资产精度再增加一个运行时。[Three.js 模型导入](https://threejs.org/manual/pages/loading-3d-models.html)、[Godot 三维导入](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html)。

Meshy 可先产生候选几何，不能把自动绑定等同于可用机械动作：非标准比例需要检查，机械关节、独臂状态和接触仍需修整。[Meshy 绑定说明](https://docs.meshy.ai/en/webapp/guides/3d-model/rigging)。本轮已读到登录中的 Meshy 工作区，未生成、下载新模型或消费额度；网页访问不构成本项目模型效果证据。

## 3. 按资产分别制作

| 资产 | 本次采用的制作方式 | 在实际地图中必须成立的结果 |
|---|---|---|
| 地图人物 | 先做一名匹配既定身份的 Q 比例三维角色，骨架制作待机、起步、循环、停步、转向；保留正常比例对白立绘。自由镜头先用实时三维；若二维更合适，从同一模型与完整动作烘焙方向图集 | 向任何方向移动时，腿与摆臂相配，支撑脚不滑，停下能站稳；侧后方仍保持身份。不能用镜像改变腕端设备、持书手等不对称设计 |
| 机甲 | 根据有效造型图选择 Meshy 起模或 Blender 直接硬表面建模；清理并分离装甲和关节，校转轴、刚性运动、接触点，再制作动作片段 | 全身参与发力；快拳、重拳、接拳的蓄力、接触和收势不同。馆守保留原右前臂缺失，左拳动作正确，装甲不软化或穿插 |
| 建筑与道具 | 生图用于确定配套风格、结构和材质；Blender 制作可读轮廓、屋檐、门窗开口、墙体厚度、支撑、入口与模块。规则建筑优先直接建模；Meshy 用于经检查适合的独立物件 | 门能通行，遮挡对应真实体积；缩放、转镜后依旧成立。人用门、检修台和巨型机甲设施尺寸有明确差别；不是贴在盒子上的透视图片 |
| 材质与效果 | 沿用 KINETIC_CEL 的轮廓、有限阴影、冷白/深墨蓝/朱红主调；必要贴图在模型上绘制或烘焙。Godot 承担地面规划遮罩、描边、接触特效和镜头 | 模型、人物、建筑同屏协调；场景退后、行动主体清楚。运行时能控制受击和伤损，静态贴图不焊死高光和战果 |

地图风格化不等于所有物件等比例放大。人类与巨型机甲的等级差继续保留；头身比、门窗概括程度、镜头和色彩在同一个场景里判断。Q 比例具体数字没有被用户锁定。

程序化建模仍可用于重复构件、管线、螺栓、阵列和导出；判定依据是成品，而不是是否手工点过顶点。LibTV 用于专门镜头，不能用预渲染视频替代可操作地图上的基础行走和接触。

## 4. 先完成这一组实际样板

下一份制作输出是同一公式台场景中的 **纪存一套走停转向、馆守一次完整左拳、一个可进入并有内外遮挡的检修铺**。这是生产次序，不是缩减全项目范围。

1. 先用当前身份图和已定风格制作模型及配套构图；同屏看人、机甲、门、检修平台，确认比例和轮廓后再扩动作，不批量生成未校验资产。
2. 动画包含准备、重心、落脚、接触、余势与回正。地图位移与动作步幅匹配；使用原地动作时由移动速度驱动播放，不能引擎位移和根运动重复叠加。
3. 馆守用明确的动作事件点对齐真实战斗事件：预演显示将发生什么，执行表现已结算什么。视觉接触不能擅自提前/延后同拍伤害，更不能改变规则来迁就动画。
4. 在正常战场镜头、转镜和特写下连续查看。保留可修改的 `.blend`、纹理、GLB、动作清单、来源与实机短录；离线美图不替代实际动作和操作体验。
5. 首组成立后，以相同方法做白鸢、无牌、旧拳王及场景模块，再扩到其他公式。失败项明确退回，不以“已生成”计入完成。
