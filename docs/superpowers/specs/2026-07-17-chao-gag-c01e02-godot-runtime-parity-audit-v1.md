## 3. 本轮补齐的关键行为

### 3.1 一份物理真相与三证调查

Episode 只读 E01 的 `RT013S_ATOMIC_PAYLOAD`。七海第一次系统命令只切东侧高压；电弧先停，旧风阀随后失去保持电流并抬高低位烟压。机器犬烟带、跌跌双色温度片、墙后双层旧管可任意顺序调查，可重复查看但只各产出一次证据。三证闭合只进入共同救援图，不提前写世界状态。

### 3.2 固定消防架桥机与三段地图施工

消防架桥机是完整可见、四腿固定、无 HP、无自由移动、无攻击反击的专业支援机。R1 的三段桥不是一个按钮：

- 地图同时显示 `SEG1 / SEG2 / SEG3`；
- 只有当前顺序段合法；
- 错误顺序可探测但零成本；
- 中段存档可恢复到下一段；
- 取消恢复桥段、消防点和行动；
- 只有 `SEG1 > SEG2 > SEG3` 全部确认后才提交 3 点。

### 3.3 四组人按 Tick 真正移动

四条撤离路线按 `C3 > B10 > D5 > A11` 的逐 Tick 优先级结算，共保存 41 条合法移动边。C3 每一步都带机器犬同行；D5 始终保留原维修员。R1-R4 结算时，这些边不再只写入 Session：地图按回执逐边插值播放，R1 先播放两台封存工具的实体路径，再播放群众路线；R4 在 `29/29` 后继续播放两名 F2 接驳员的五条入场边。播放期间输入只允许观看或主动跳过，Tactical 快照保存队列与进度，结果页必须等待播放结束。

R4 的四组人必须抵达四个各自的楼外端点，才会得到 `29/29`，随后隐藏而不是在 R5 被重刷。

### 3.4 两个 R2 选择与同一 R3 债务闭合

R2 在支援点提交前显示两种后果：

- 护人水幕：D5 烟值低，针车允许接触 SEG3；
- 抢先冲洗：针车提前后退，D5 烟值高。

标尺机在两路都沿实体轨道接触隔板再回弹。R3 只接受与 R2 匹配的补偿工序；两路最终都收束到 D5 烟值 2、针车收臂、标尺偏转以及同一条消防供水伤痕。

### 3.5 七海权限与城市消防严格分离

R3 只撤销七海本人签发的东侧高压锁，并停用她的系统写权限；普通语音和城市消防公共支援继续在线到 R5。泵站必须先由跌跌锁定机械离合，再由兜灯接低压旁路，最终只恢复 `MANUAL_OPERABLE_LOW_PRESSURE`，馆守Z主电仍硬停。

### 3.6 R5 五条真实退路

R4 后，纪存以“三十二，不是二十九”取消自动清场。两名不属于初始 32 人的 F2 消防接驳员沿两条互不撞格的西门路线进入，系统建立只在本地有效的 R5 检查点。勇拳只有被外部许可继电器截断的运输架请求，豪司不在场，机体压力和位移均为零。

SEG3 反折后，Session 按 `F2B > 唐胶 > 纪存 > 兜灯 > F2A` 释放顺序检查五条路径、静态占用、唯一坡道边、反折承梁和侧条状态。破坏侧条会失败并回到 R5；29 人仍在楼外且新应急点恢复为 1。

## 4. 失败规则

提前结束阶段仍被允许，但不再直接跳到错误页：已公开的敌方工具和环境先结算，受缺失工序影响的撤离组停在原处，然后才产生本地失败。

直接测试覆盖：

- R1 缺少桥，四组人不瞬移，针车和标尺机仍按预告入轨；
- C3 被拆分；
- D5 原维修员人口漂移；
- 任一撤离组烟值达到 3；
- B1 泵永久不可达；
- R4 只有 28 人楼外；
- R5 侧条被梁压坏。

所有 R1-R4 失败回战斗初态，R5 失败回 R5 检查点；两类失败都没有 Episode 快照、伤痕、地图权限或 V35 键写入。

## 7. 证明边界

本审计不证明：

- 消防架桥机、针车、标尺机、烟火和人群的正式 Sprite、骨骼或逐帧角色动画；当前只证明由正式回执驱动的候选 token 插值运动；
- 正式 SFX、语音、镜头震动、Cut-in 和伤害式演出；
- 目标时长、首次理解率、手柄人体工学和真人失败恢复；
- Windows / Steam 导出、GPU 兼容、跨版本存档和平台成就。

这些属于后续生产质量门，不得反向破坏 47 行状态机、41 条撤离边、五条 R5 退路或 RT038 唯一事务。
