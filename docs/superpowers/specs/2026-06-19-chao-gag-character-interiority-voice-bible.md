# 《超GAG机器人大战：万机残响》角色内在与声音 Bible v0.1

> 本文回应一个关键创作风险：台词不能像设定框架在自说自话，必须像角色在具体场景里，根据自己的背景、欲望、恐惧、关系和周边环境作出反应。

## 1. 问题诊断

当前人物层已经有角色定位、生活面、伤口、信念、长弧线和互动边，这足以证明“这个角色在策划上有功能”。但它还不足以写出真实台词。

坏台词常见症状：

| 症状 | 表现 |
| --- | --- |
| 设定替角色说话 | 角色直接说出主题句，例如“秩序不是假的，但秩序要谁闭嘴” |
| 梗点替角色说话 | 角色为了抛梗而说话，和当下欲望无关 |
| 作者替角色聪明 | 每个人都能准确说出本章哲学问题 |
| 人物只反映框架 | 角色的反应来自设计支柱，不来自经历、脾气和关系 |
| 情绪没有身体 | 角色只说观点，不做动作，不误会，不逃避，不岔开话题 |
| 对偶模板替人物说话 | 反复使用“你可以做X，但别替我做Y”“这份债以后再还”“现在还不能结算”等工整句式，角色像在朗读关系账本 |

正确方向不是减少设定，而是让设定经过角色身体和生活经验折射。

## 2. 角色反应模型

任何一段重要台词，写之前必须过六个问题：

| 问题 | 说明 |
| --- | --- |
| 他此刻想要什么 | 离开、留下、保护某物、避免被看穿、证明自己、争取许可 |
| 他误以为什么 | 误以为对方在嘲笑、误以为自己必须负责、误以为规则能保护人 |
| 他怕什么被暴露 | 无能、依赖、愤怒、私心、爱、罪责、不是人 |
| 他习惯用什么动作替代真话 | 擦零件、看终端、报参数、开玩笑、纠正用词、整理袖口、沉默 |
| 当前环境会刺到他哪里 | 展柜、孩子、旧零件、警报、封存清单、黑展柜、火光、留言 |
| 这句话在关系里做什么 | 推开、试探、求救、遮掩、攻击、承认、递台阶 |

台词公式：

> 场景刺激 + 角色旧伤 + 当前欲望 + 关系策略 = 角色反应。

不要从主题句出发。主题只能在角色反应后自然浮现。

## 3. 角色小传不等于履历

小传要回答的是“这个人为什么会这样反应”，不是列出生平大事。

每个重要角色需要六层：

| 层 | 用途 |
| --- | --- |
| 童年/形成性经历 | 角色的第一套世界解释从哪里来 |
| 当前面具 | 角色在别人面前装成什么样 |
| 核心欲望 | 他最想保住或得到什么 |
| 核心恐惧 | 他最怕什么成真 |
| 关系动作 | 他靠近别人和推开别人时分别怎么做 |
| 成长考题 | 剧情怎样逼他用旧办法失败，再学会新反应 |

## 4. 声音不是口癖

口癖只能做表层识别，不能做角色声音。真正的角色声音来自：

| 维度 | 示例 |
| --- | --- |
| 词汇来源 | 档案、维修、合同、工程、舞台、学校、战争、模型、宗教、儿童游戏 |
| 句子长度 | 短句防御、长句控制、半句退缩、疑问句试探 |
| 情绪处理 | 开玩笑、报参数、转移话题、咬字变硬、假装礼貌、沉默 |
| 权力姿态 | 命令、请求、建议、纠正、撒娇、讽刺、把话交回对方 |
| 不能说的话 | “我害怕”“我需要你”“我错了”“我不是人”“我想活” |

同一句主题，不同角色应该完全不同：

| 主题 | 错误写法 | 角色化写法方向 |
| --- | --- | --- |
| 破损也值得保存 | “破损也是历史” | 兜灯会摸裂纹说“这块拆下来以后，右臂会轻一点”；唐胶会说“别扔，裂得好的零件比新件难找” |
| 秩序会静音人 | “秩序要谁闭嘴” | 七海会说“报告上写风险下降；报告不会写谁少了一句话” |
| 机魂不是低级噪音 | “后天合唱保留差异” | 方舟T会说“噪音里有身份识别特征。删掉它们，大家都会非常安静，也非常不像自己” |

## 5. 剧本写作检查清单

写完任意重要场景后，逐句检查：

1. 这句话换成别人说，是否也成立？如果成立，重写。
2. 这句话是在传达设定，还是在改变关系？
3. 角色有没有用自己的职业、生活经验或旧伤过滤信息？
4. 角色有没有误会、遮掩、岔开、试探或身体动作？
5. 台词是否过早说破主题？
6. 梗点是否改变了关系、行动或选择？
7. 场景中是否至少有一个角色没有完全理解另一个角色？
8. 是否出现“你可以X，但别Y”的工整对偶？若不是角色在眼前冲突中自然脱口而出，就拆成反应、追问、迟疑或具体理由。
9. “债务、结算、共犯、权限”是否被人物当成感情词？除非角色真的在谈账单、作战结算或法律权限，否则改成人能感到的生气、害怕、亏欠、舍不得、没说完和不想走。

## 6. 第一话修正方向

第一话《今日闭馆后》目前有温度和结构，但部分台词仍偏“设定说明”。下一轮重写时应特别处理：

| 段落 | 当前风险 | 修正方向 |
| --- | --- | --- |
| 冷开场 | 谜团密度高，角色性还少 | 保留碎片，但减少主题句，让声音更像损坏档案和馆长个人习惯 |
| 闭馆广播 | 旧守护者声音较成立 | 继续强化“规则照顾人”的机械长辈感 |
| 留言墙 | 纪存回复选项偏系统人格 | 让每种选项都来自纪存的不同防御方式，而不是玩家性格菜单 |
| 右臂争论 | 接近角色冲突，但仍有主题句 | 让兜灯更防御，唐胶更手作，纪存少总结 |
| 黑展柜 | 悬念成立 | 纪存反应需要更具体：害怕、职业本能、想归档但手不稳 |
| 七海登场 | 气质成立，但金句太像作者 | 让七海更多用报告、授权链、风险责任说话，把残酷藏在职业礼貌里 |
