# 联动战役 α1：交付与验证

2026-10-03。Candidate 可玩切片；本轮验证核心机制和输入闭环，不代表正式剧情、美术或平衡已验收。

## 现在可玩什么

公式台首页右上角进入“联动战役 α1”，也可双击项目根目录的 [联动战役.command](../../../../../联动战役.command)。旧木桶街与章节入口保留。

一座城的两个局部战场共用四拍时钟：A「供能前庭」恢复母线，B「跨渠桥座」保护施工、接通桥面，让撤离车经过。每区两台己方机体。玩家可以来回安排，只有“全域执行”才推进时间。窗口边界不会清掉尚未完成的蓄力、收势或作业。

敌人有已公开的移动/攻击承诺、设施目标和增援入口；编辑计划不会重抽敌人的意图。可用推拉改变目标位置、让敌人落入深渠、打断尚未释放的招式，也可绕开交战直接保护工程。击杀不是唯一胜利条件。母线、桥面和撤离车用数据中的依赖与信号连接，核心结算没有按本关或机体名字写死这些关系。

纪存负责切换与调度，白鸢负责逐拍预演；七海目前以通讯交代抢修通行已获确认。七海的权限选择尚未做成可操作系统。开场为三段简短通讯，尚不是完整剧情演出。

## 机体尺寸已经进入规则与表现

地图单格为 10 米，身高、底盘占地、质量、行动耗时、净空和武器射程分别配置。无牌 16 米；馆守 18 米；旧拳王暂用 18 米作为本切片标尺。28 米、2×2 格的重体敌机是尺寸测试代理，不作为正式机设。

| 层面 | 当前处理 |
|---|---|
| 地图通行 | 寻路、争格、占用和强制位移检查整个矩形占地；19 米门架独立检查身高。大机不能按单格单位挤过窄口。 |
| 选择与攻击 | 点大型机任何占地格都能选中；距离取占地近边。一次攻击只记一次命中，不按覆盖格重复扣血。 |
| 地形后果 | 本轮多格单位要求全部底盘有支撑；普通机被推入深渠失能，悬浮机免深水失能。规则可在资讯中查看。 |
| 模型 | 模型本体按身高缩放，动作根节点保持单位缩放；统一地坪与脚底接触，保留原机体配色。 |
| 战斗演出 | 复用已有体术/射击动作，命中特效使用释放时的双方位置与身高；先接触后推移，避免先飞走再播放打击。缩放骨架的 IK 旋转另做兼容。 |
| 镜头 | 局部战场与双区总览，支持拖转、平移、缩放；大型底盘边界可读。极端尺寸差和正式巨构战斗仍需后续专门检验。 |

这是一套公开的格子规则，不是刚体物理模拟。悬浮不自动等于任意越墙；多格转台旋转尚不开放。

## 怎么操作

1. 点机体或底部机体卡，点亮起的目的地，自动计算绕路与等待。每个公开目的地都经过当前四拍的移动及攻击模拟校验。
2. 选招，再点出手格；可以瞄准敌人的预计落点。施工、封口需站在对象相邻格。地图资讯可查看机体尺寸、占地、地形及设施条件。
3. 切换另一战场继续安排，按“白鸢 · 预演”查看结果；预演不改当前局面。下方逐拍按钮可以查看未来位置。
4. 按“全域执行”推进四拍。若工程正在持续，就不用重复点施工。正在收势的机体可在收势结束后接下一招，剩余时间不会整窗作废。

`1/2` 切战场，`Tab` 全域，方向键移动自由光标，`G` 确认地格，`Esc` 退出选机，`M` 走位，`E` 施工，`U` 撤销待执行安排，空格预演，回车执行。左拖旋转、右拖平移、滚轮缩放，`F` 复位。重开在“操作说明”内。

## 与 v3 完整目标的差额

α1 是两个战场、固定四台己机。第三战场、跨区运机、自选出击（含社勇王等）、正式外敌资产、完整剧情特写、七海权限交互、回收/声誉等结算，以及长期战术平衡尚未实现。支援射手和外敌明确使用现有动作/尺寸代理。物理扩展里的垂直空域、多格转台、惯性与离心力没有冒充已做完。

下一轮以这份可玩底座继续打磨：先检查陌生玩家能否独立理解四拍、目标格与工程依赖，再扩充部署、第三战场及各机体的专属技能。正式资产和场景精修依照已定机设逐项替换，不能因规则通过就宣布视觉完成。
