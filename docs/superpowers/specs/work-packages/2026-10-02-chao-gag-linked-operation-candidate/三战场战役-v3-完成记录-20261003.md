## 这次接通的整场流程

**指挥廊三处现场 → 剧情事件与通讯 → 十四机自选部署 → 三个工作面共同规划/行动 → 首次真实联动特写 → 同一辆车抵达 → 留场或收队 → 事实结算与尾声。**

指挥廊可以查看失电母线、受损桥座和车内二十四人的事件。用新绘制的承运环、车厢和接回归途插画，配既有纪存、白鸢、七海立绘与轻微镜头运动。事件之后进入部署，不把全部剧情堆成战场说明文字。第一次玩家造成的供电、支撑或清场成果触发短暂、可跳过的总览回应。

A 是 8×6 的供能前庭，B 是 7×7 的跨渠桥座，C 是 9×6 的环下装卸站。三图共用同一拍号，世界坐标落在一套环梁、立柱、连接桥与轨道上；并非三个各自推进的独立关卡。车从 C 出发，在连接轨经过四拍，再由 B 驶向站台。切图不消耗时间。

## 时间与数值在本版的落点

方案中的数值是候选初值。本次把以下实施值固定进同一能力表，菜单、预演和结算共用：

- 没有另一套每轮重置的通用 AP。普通机每格一拍，重装每格两拍；招式单列准备和收势。准备可以跨四拍窗口；下一动作也可以接在本窗后半段的收势结束处。
- 无牌当前采用此前已修正的正蹬动作作推位招；旧拳王用摆身勾拳、正面一次接拳与重拳。没有重新启用被用户指出反关节的旧回旋踢。
- 重型楔入体采用 28 米、2×2 格、质量 3；对应强推为 3。轻推不会暗中叠成强推。四台宽体友机占 2×1 格，其余本次可控机占 1×1 格。
- 控制记录两拍；本地总席确认两拍；接回双路母线四拍。手柄旁路两拍，一次供一个工作面。
- 快修机准备两拍后按每拍 1 进度实施；普通机每拍 0.25；安全工班每拍 0.5。多人同修按最快工具推进，不因字典处理顺序叠加速度。已毁设施的战中修复更慢，并计入重建成本。
- 图集机体使用待机、准备、释放、恢复四种绘制姿态；货柜领袖、雷翎、歌翼另有机动形态。它们不是十四套新建的三维骨骼，原来的三台 3D 格斗动作也没有被删掉。

原方案中更丰富的职业招式列举，现收束为每台三项主技能加现场公共操作。例如本关消防机用架桥、抢修、牵引处理救援，未另造一套火灾/喷水系统；吊装机用吊移货柜、牵引、固定桥座，未加入失能机拖救。它们的实际菜单与作用均明确，不把未实现的列举放成可点击空按钮。

## 本轮排查并修复的问题

1. **预演后的幽灵敌人。** 预演到第四拍创建了新敌；回到零拍时旧渲染缓存仍遍历该敌，造成残留和逐帧报错。现在按快照成员关系恢复单位、临时墙、特效和气泡，入场也不会提前显示；封口外观不会因切图重新打开。
2. **点身体误选背后地面。** 改为身体/名称牌选取；需要打预测格时有明确地格模式与 Alt 点地，不用猜模型脚底。
3. **读档与重新部署串状态。** 新局清除旧事件、目的地与选中对象；读档恢复原编成和预备队；截图与 QA 使用单独存档。
4. **存储后的重放不一致。** 事件排序稳定化；多人施工选最快工具而不是先遍历者；五份持久化记录共五十窗重新计算一致。
5. **炮弹依赖发射者当前位置。** 在途攻击保留出膛快照；炮手之后失能、转场或参与寻路预测，都不改变已经发出的攻击。
6. **机体配色被照明冲淡。** 新战役单独修正复用模型的着色器，不改旧版本；场景材质和机体纹理分别保留。规划压低背景建筑，执行再回色。
7. **物件没有随结果变化。** 货柜推移/吊移和车行走补入拍内插值；母线、货柜被破坏后显示残骸，恢复快照会正确切回完整状态。
8. **公式台入口重叠。** 新战役、旧 α1 与帮助入口重新排位，原生窗口确认可以分别进入。
