# 三战场战役与核心机制方案 v2

2026-10-02 · 公式台候选设计 · 《工务城：把归途接上》

本版接续 [v1](三战场战役与核心机制方案-v1.md)，将工程救援扩成一场可以抢修突围、守住撤离、集中歼敌，也可以混合处理的战役。三张小棋盘共用一个时间制度，位于同一座城市承运环的不同部位；玩家从十台候选机体中选择出击阵容，利用战斗、工程和跨区调配改变局面。

v1 保留供比较。本稿是本轮讨论用的完整替代稿，尚未开发或通过试玩；人物身份沿用项目，具体任务、敌人变体、技能配置和数值属于新增 Candidate。它不改写已验收 Reader，也不替换公式台 P/Q 入口。

**一、这次修订改变的不是敌人数量，而是解决问题的自由度**

原案偏重“在干扰中完成工程”。新案增加另一条同等成立的因果链：**先消除干扰，换取从容完成工程的时间。** 战斗机与工程机的差别因此不是谁有资格通关，而是谁以什么成本、什么速度取得优势。

玩家可以形成这些判断：

- “它只打供电箱，我把它推开两拍，桥就能修完，不必追杀。”
- “这一处留两个守得住的人。我把远射机调到桥上，先击破重型外敌。”
- “我带的是强攻队，先封住后续入侵口，把三处清干净，再让工班出来。”
- “车已经走了，救援成立。还有一台重敌留下的完整器官，可以决定要不要继续冒险回收。”

这些不是进入关卡前选定的三个剧情分支按钮，而是同一棋盘规则下自然产生的路线。途中允许改主意，也允许先救人再清场。熟练玩家通过更好的编成与操作兼得更多目标，是应当奖励的结果。

首版的控制规模保持克制：初始六台友机，每区两台；每区同时最多三台敌对行动单位（含阻挠工机），三图不同时灌满。战中调配后每区最多四台可控友机。车、设备和大构件是任务对象，不占出击名额，但必须占实际空间。

**二、故事：工务城的一段承运环遭遇外敌袭扰**

沿用 C03 建立的工业城市、职业机群、环轨与巨型承重结构，另设一段独立试玩支线，不预先锁定其在正篇中的插入位置。

夜班交接时，承运环的外侧隔离廊被外体穿透。它们沿着供能与运输结构深入：有的啃断母线，有的在桥座扎根，有的架起远射器官，为后续群体打开通道。它们是具有直接破坏能力的外敌，不是靠换一句命令就能全部说服的工程机器人。

首轮撞击已触发管线自动隔离，低处留下水域和损坏设施，但水位不会无条件逐轮上涨。轨道车载着最后一批检修员停在 C 区；通向高处安全站台的桥锁受损，正常供电仍被过期的征用程序占用。两台受旧程序约束的无人作业机还在执行拆锁、拖车任务，与外敌的攻击叠在一起。

城防通报：封锁艇正在合围，第八窗口结束时会切断这批外体的外部接应。外敌届时转入撤离；玩家也可以在此之前击毁它们、关闭有限的入侵口，提前结束袭扰。**这里的八窗口是敌袭进程，不再是到点即失败的救援期限。**

自动隔离避免了“消灭最后一个敌人，洪水却莫名冻结”的矛盾。持续危险主要来自仍在行动的外敌、阻挠作业和已经发出的攻击。消除这些因素后，确实可以安心修复；已经造成的损坏仍须处理。

七海确认旧征用命令不适用于本次救援，将现场证据交给有权接管的本地负责人。她没有恢复代哥写权限。纪存安排几处互相等候的力量，白鸢根据已知设施、传感与敌方承诺画出可比较的路线；地方工班与友机共同决定怎么接回这条路。

“猎巢群”暂作这批外体的关卡工作名。当前索引未查到“猎巢体”这一确切已定型实体；项目已有的界外灾害生态允许独立的捕食体、遗战机械和近地漏潮。此处先选一支有共同身体语言的外体群做三个战术型，具体命名与谱系归属保持 Candidate，不伪称已获 Canon 确认，也不把所有外敌归为同一幕后阵营。

**三、三个战场是一座巨构上的三个工作面**

新设施暂名“西环承运架”：巨型环形钢桁架跨越城区和泄洪渠，下部承载检修轨道，上部搭载电力母线、维护廊和吊运轨。城市建筑依附在其支座之间，机体只是这座结构上的工作者。

宏观视图能看到 A、B、C 的连续位置。A 的供能干线沿环体通向 B/C；C 的轨道车沿环下轨道进入 B，再驶向图外高处站台。三张战斗地图是同一结构上的局部放大，不是三块没有物理关系的浮空方盘。

| 战场 | 局部棋盘与推荐两机 | 工作目标 | 战斗目标与可用地形 | 色彩、材料与巨构在镜头里的位置 |
| --- | --- | --- | --- | --- |
| A 供能前庭 | 8×6；无牌、雷翎 | 恢复正常双路供电，或用一路应急旁路 | 阻止母线被啃断；击退架设外体；关闭一处入侵廊口；利用绝缘屏与导电节点 | 象牙白陶瓷、炭灰金属、琥珀电弧；粗母线攀上环架，远处可辨 B 桥座 |
| B 跨渠桥座 | 7×7；馆守、预算二号 | 修复桥锁，或持续固定损坏支座 | 把驻定重敌推离切割位；保护施工；水域、桥板与承重基座改变站位 | 蓝灰湿混凝土、橙色支撑件、水面冷光；巨柱穿过画面，环体在上方形成压迫尺度 |
| C 环下装卸站 | 9×6；旧拳王、吊装机 | 移开货柜，发车并护送至 B | 阻止锁车；截击侵入者；移动货柜改写掩体与直射线 | 氧化绿箱体、暖灰棚架、乳白车厢；环下吊轨伸向 B，背景能看见同一根巨柱 |

地图主色不同，材质绘制与照明逻辑统一。不能把颜色差异仅做成一层滤镜；A 读陶瓷/金属，B 读湿混凝土/水，C 读涂装箱体/轨道。正常战棋距离下，机体轮廓与可交互表面先于微小划痕。

建议一格约 10–12 米作为灰盒起点，按十几米至二十米机体实量校正。宏观场景中的几百米级环架通过人类维护门、梯道、机体和轨道车逐级给出尺度。近处普通扶梯不能画成机甲能随便迈入的一米门。人类前置探索另用相符的场景尺度。

城梁一号是现有工务城 80–100 米级地方基础设施巨机，可以在远景或开场提供尺度参照。**本关主角是承运架本身的联动，不要求城梁一号再演一次已验收的迁座高潮**，也不把它临时塞进普通四机部署槽。

巨构在玩法上先限定三个明确功能：A 的电、B 的桥锁、C 的轨道与货柜。城市其余部分负责空间与生活表现。初版不把整座城的每根钢梁都做成可破坏模拟对象。

**四、敌人用目标和行动方式分级，不只增加血量**

首局先做三种外体、两种阻挠工机。三种外体用共同材质与器官语言统一族群，用轮廓、动作节奏和威胁方式拉开差异。

| 类型 | 试验耐久与速度 | 公开任务、动作 | 有效应对 | 地图上的表达 |
| --- | --- | --- | --- | --- |
| 轻型啮线体 | 3 耐久；1 拍/格 | 到达母线/车站接口，相邻准备 1 拍后造成 1 点损伤；不临时追赶编辑中的我机 | 一次集中击破；推走让它重新走位；占住工位；先修完或转供别路 | 低伏细长轮廓；抱住接口蓄亮，攻击线贴着真实接触点 |
| 远程架设体 | 4 耐久；1 拍/格；架设后不移动 | 展开支脚 2 拍、蓄能 4 拍，向固定格释放；部分攻击可从 A 投向 B | 提前击毁或推离架设位；搬掩体/撤离落点；不要把已出膛攻击当成还能取消 | 展开后成为高炮剪影；炮口与另一图落点共用标记，显示释放/到达时间 |
| 重型楔入体 | 7 耐久；2 拍/格 | 在桥座旁准备 2 拍，再持续切割 4 拍，造成 3 点结构损伤；要求持续接触 | 强推拉；合力击破；先引开其进路；用短时支撑抵消桥锁失效 | 宽重下盘、楔形钻切头；驻定、切割与失去接触三种明显姿态 |
| 自动拆锁工机 | 5 耐久；1 拍/格 | B 区执行过期拆除任务；两拍定位、四拍拆锁 | 击毁；推离；在安全控制点完成隔离停机；有效接管后停止任务 | 市政涂装与旧指令投影；不会与外敌长成同一种红色敌兵 |
| 自动牵引工机 | 5 耐久；1 拍/格 | C 区两拍固定、四拍锁车；目标是拖回检修库 | 击毁牵引器或本体；推离作业位；接管停机 | 吊钩/牵引架逐步接合，锁车进度挂在车上，不只在菜单里 |

重型楔入体建议质量 2，轻推力量 1 无效，馆守牵引或旧拳王重拳力量 2 可推动。首版不把两个力量 1 暗中相加成力量 2；协作可以是先改地形再命中、两个真实伤害，或一机吸引承诺、一机从侧面重击。以后若加入合力，必须另给可见规则。

三种外体的默认目标是设施与通路；挡路的我机、明确正在攻击它的单位可成为下一窗口的新目标。具体优先序在敌方意图面板可查。**玩家编辑期间不重选，跨窗蓄力不换目标。** 玩家将它推走后，依原目标绑定判断挥空、失去接触或射线改变，不能立刻重新瞄准补偿。

本关不把人类工班驾驶的自主机体默认改成可任意摧毁的敌兵。两台阻挠者明确为无人作业机。它们仍是市政资产，摧毁会留下真实设备损失；若别的任务采用有人/有主体性的机体，需另写参与关系与后果。

初始安排：A 为啮线体与架设体；B 为啮线体与拆锁工机；C 为啮线体与牵引工机，共六个敌对行动单位。两份有限增援分别预告在第二窗口进入 A 的啮线体、第三窗口进入 B 的重型楔入体。不是每轮无限刷怪。

增援入口、最早进入时刻、剩余数量在部署时可查，最迟提前一个窗口在棋盘明确预告。每区敌对行动单位上限为三；入口受阻则在区外等待，不能瞬移入场、挤走机体或凭空占格。同一排队单位使用同一身份，不重复生成。增援入场窗口只按预告进入部署格，不追加未展示的攻击；下一规划点才提交第一次完整作战意图。

封闭隔离廊口可以阻止尚未入场的增援：所有机体可在控制位花两拍拉闸；工程机可从适配的外接口操作。被挡在区外的外体不算击毁、不给击破素材。队伍也可不封口，把有限来敌全部击败。

**五、把救援完成、敌袭结束、战场安全分成三个状态**

这三件事可能先后发生，不能压成同一个“胜利”开关。

| 状态 | 成立条件 | 后续允许什么 |
| --- | --- | --- |
| 救援完成 | 同一辆轨道车及车上人员安全抵达图外站台 | 可以立即结算；也可明确选择留下清剿、修复、回收，承担后续机损 |
| 外敌退潮 | 第八窗口结束城防完成封锁，外体停止新进攻、开始公开撤离 | 仍要防范已经释放的攻击；无人作业机不会随外敌撤退而自动停机 |
| 战场安全 | 区内敌对单位已击毁、离开或停机；入侵口已关闭/增援耗尽/封锁完成；没有将进入该区的敌对转场和在途攻击 | 本地工班可出掩体接手工程；可用“推进至下个工程结果”减少空回合 |

全战役安全要求三个区域都满足安全条件。一个区清空时，HUD 只报告“本区清空”；存在跨区炮弹或待进入单位时，要继续显示这项威胁，不能误报已经安全。

退潮不是同一瞬间删除棋子。第八窗口结束切换外敌目标，下一规划显示其撤退路线；它们按实际移动到出口离场。封锁信号是部署时就公开的情景撤销条件：尚未释放的进攻取消并进入正常收势，已进入恢复的动作不跳过恢复；已经出膛的炮弹照常到达。出口受阻时公开等待或另选合法路径，持续占格，不再主动开展新设施破坏。若玩家用机体堵住撤离口，外体可在下一规划公开攻击阻挡者，为撤退开路，不能把撤退者做成可无限围打的木桩。预演必须包含这个已知的切换时刻。用户所说“守过若干轮”对应守过这场有限敌袭，实际清理结束时刻由出口与已发出的攻击决定。

提前清场也不隐藏后续增援：部署与总览都显示“在场 / 待进入”。杀光当前敌人而入侵口仍开着，只是暂时的施工空档。封口或消灭全部有限来敌后，才能提前进入完整的安全施工状态。

**清场后可以没有施工期限，但损失不会凭空消失。** 本关的桥锁、供电箱在耐久为零时进入“损坏、需重建”状态，不触发看不见的整城坍塌。静态水域、断桥和废骸仍在；工班有可显示的备用材料和较慢重建方案。基础撤离工程所需材料由任务保障，不因少带工程机而永久卡关；更快的战中修复、机体修复与可回收材料仍是有限资源。

轨道车耐久归零、人员失去救援条件会失败。仍有敌袭时全队失能且已无可执行的救援途径，会进入明确的失败结算；主动撤离也有结果。单一工程机失能、八窗口到达、一般设施受损，都不是隐藏的自动失败条件。安全建立以后，可由工班继续完成救援，不要求最后一台友机反复点等待。

“推进至下个工程结果”仍用同一求解器执行时间。只在全战役安全、所选工作已具备条件时开放；供电不足、支撑将撤离、材料选择未确定就停在相应节点。仅一个区域安全时，工班可以接手，但仍随全局每次四拍推进，不能跳过另一图的战斗。不得用快进绕过真实条件，也不要求玩家点二十次空回合。

**六、几种解法应该产生不同的感受与收益**

| 解法 | 实际操作重心 | 体验 | 主要收益 | 主要成本/风险 |
| --- | --- | --- | --- | --- |
| 边打边抢修，先把人送走 | 推开要害敌人；保护六拍作业；利用双路电与临时支撑 | 在压力下接上一连串空档，“刚好赶上” | 救援早、可能保住完整设施；可以少打很多敌人 | 作业者暴露，需处理多个局部条件；留场回收另担风险 |
| 守到退潮，再完成工程 | 保护车和关键设备；挡住进路、搬掩体；等外体撤出，再处理阻挠工机 | 守住阵脚，让敌人的攻势用尽 | 战斗压力有明确终点；可少消耗高输出武器 | 要守更久，可能失去早撤奖励；撤退敌人不留击破素材 |
| 集中清剿，再安心施工 | 配火力与控位；切断有限增援；击毁或停掉阻挠机 | 逐个解除威胁，取得主动，扫清整片场地 | 敌体素材、地方防卫声誉；安全后自由修复与调配 | 弹药/机损与可能的设备损失；清敌期间仍需保护车 |
| 分区混合 | A 清掉跨区炮，B 只推走重敌，C 抢先发车 | 从宏观上决定哪一场值得打、哪一场只需拖 | 往往能用较小代价获得组合成果 | 需要理解跨区因果；不能靠自动配队替玩家做判断 |

偏战斗编成确实能通关：没有维修机时，先让三区安全，本地工班再以较长工期修复桥锁、供电和车道。带工程机的价值是把这些工作提前到敌袭之中、减少重建耗材、创造战斗地形。战斗清场不能直接把桥变好，维修完成也不能直接把敌人删掉。

结算读取真实结果，不按玩家点击的“路线名称”发奖励：

| 记录 | 由什么决定 | 奖励或后果 |
| --- | --- | --- |
| 人员救援 | 车与人员是否到达 | 基础委托完成与基础关系收益；任何合法解法都获得 |
| 及时撤离 | 是否在第八窗口退潮前完成救援 | 一项独立的及时救援额外目标；逾时不是主线失败 |
| 外体威胁清除 | 击毁、迫退、封口分别记录 | 完整击毁/回收取得相应有限素材；迫退也算守住设施，但不虚报击破 |
| 市政资产保存 | 阻挠工机是否停机保全；控制记录是否留下 | 少付替换成本、保留本地协作能力与后续援助条件 |
| 修复与机损 | 真实消耗的备件、弹药、失能与重建项目 | 体现在净物资和战后维修负担，不重复叠多项同义扣分 |
| 设施重新投入使用 | 桥、主干线、装卸线是否恢复 | 城市生产关系与可选工务报酬；临时救援成功也可另行结算 |

声誉至少区分“救援信任”和“地方防卫认可”，不把所有行为揉成道德总分。击毁正在危及救援的无人机是可接受战术选择，代价主要来自失去设备；清剿应有足以与此比较的收益，不预设战斗路线天然低评价。

数值尚未锁定，不在此伪造三条路线已经平衡的收入表。原型必须用同一敌阵实跑至少两种编成、三种目标侧重，记录用时、伤损、耗材、资产与获取物，而不是只看能否通关。不可用“击杀总有奖励、等待无成本”让清剿成为唯一正确解；也不可用巨额声誉惩罚把战斗路线做成假选项。固定敌人总量、无刷怪收益，避免故意拖延刷素材。

本关不强制某一台机体出击。纪存、白鸢、七海在指挥层承担叙事功能，不占战场机体槽。以后剧情确需某机到场，可以标明一个剧情必选位，其余开放；通用任务条件仍优先检查能力而非姓名。

两组对照编成可从这里开始，均需实跑：

- 抢修均衡：A 无牌/雷翎，B 馆守/预算二号，C 旧拳王/吊装机。
- 战斗控场：A 雷翎/无牌，B 馆守/灰崎，C 旧拳王/货柜领袖；缺少快修和重吊装，必须用停机、破拆、地形控制和清场后工班补齐。

预备不是即时召唤。整机换入只能在安全交接点一换一，出场者先离开，预备者完成公开的转入行程再出现；不增加六台同时参战上限，不清空生命、冷却、消耗和已造成的结果。确认换人时给出这一段无人接替的风险。先验证直接部署，再制作战中换入；本案完成度目标包含可用的自选出击，不能一直停在固定六机。

**八、共同时间与基本判定沿用 v1 的统一底层**

三图一起规划、一起执行四拍，再进入规划。四拍是逻辑窗口的初值，美术慢放不改变它；逐台编辑只是一种输入方式，不触发额外敌方行动。工程、移动、蓄力、恢复和运输跨窗保留。

时间是主预算，不再叠加每轮重置的通用两行动点。普通机一拍一格、重机两拍一格；五格移动加两拍蓄力、第七拍释放、再恢复一拍，总占用八拍。窗口四拍不会因该机行动长而延长，也不吞后半招。弹药、备件和少量专属能量是独立且可见的资源。

每台机体先只有一条主要动作线；不让玩家分别编排左右臂、腿和肩炮。点“到桥锁维修”自动生成移动与工作阶段，已成立的持续任务不用重下。未知或不满足条件时等待指定条件，不自动追人或换招。

统一规则如下：

1. 每次规划展示所有已在场敌人在本窗口的承诺；在途攻击和增援另标。敌人不因玩家编辑而重算；空闲者只在下一窗口发布新计划。
2. 定向攻击从释放时实际位置沿承诺方向生效；定格攻击落在指定格，允许瞄准未来位置。首版不藏自动追踪、临时转向或隐藏命中骰。
3. 每拍先完成合法移动，以统一位置快照确定释放/工程完成/反应，再一起结算伤害，最后处理推拉和持续条件失效。同拍命中不能倒撤已经释放的攻击或已经完成的工程。
4. 要阻止第六拍完成的架设/切割，应最迟第五拍破坏其条件；HUD 直接显示截止拍。普通掉血不等于打断；强制失衡、失去接触、失去供电分别说明。
5. 工程进度归属项目，完成阶段保留。断电暂停，推离则按公开政策重做当前实施段；可以由有能力的另一机接手。
6. 先到者占格；同拍敌我争空格双方停步，后续依赖到位的攻击标为受阻，不自动无限重试。规划给出绕行/等待候选，故意拦截可保留。这个争格规则仍列为首轮可用性对照项，不能仅靠文字宣称已解决。
7. 友机不会被自动搬走；换位/让路需对应机体有真实移动承诺。入场和跨区出口也检查占用。
8. 推拉力量与质量公开；掩体、碰撞、水域和缺口按共同规则生效。飞行只先做低空能力，不能在水上悬停却隔空操作地面工位。
9. 直射、爆破、环境后果必须显示实际受影响者与友伤。HP 仍用友机约 4–9、敌人约 3–7、常用伤害 1–3 的小整数试验范围。

普通轻推不能打断一切，杀敌也不是唯一的“有效”。UI 应报告“切割者被推离，桥锁这次保住”“炮弹已发出，仍会命中 B 的落点”“只造成伤害，驻定继续”等真实后果。

**九、工程和跨区条件要有替代方案**

| 项目 | 常规方案 | 替代方案 | 真实代价 |
| --- | --- | --- | --- |
| A 供电 | 控制箱旁读取两拍、隔离两拍；当地有效接管后开放两路 | 两拍手柄隔离，或强力破拆；应急旁路一次只能供 B/C 之一 | 手柄保留后续升级，破拆丢设备/记录；一路电必须调配 |
| B 桥锁 | 维修能力：准备两拍、供电实施四拍 | 重型支撑持续固定支座；消防机放临时通路；安全后工班慢修 | 支撑占一机；临时通路车速/承载不同；工班较慢且损坏重建用材 |
| C 清障 | 重吊装六拍挂接、起吊、落放空货柜 | 重击推开、定向破拆；安全后工班清理 | 推柜可能堵侧道；破拆留下可见碎骸和回收损失，不能爆炸即全消失 |
| 阻挠工机 | 满足本地接管及物理停机条件 | 推开抢时间；击毁牵引器/本体 | 前者要工位与时间，后者要输出并损失资产 |

馆守固定的是已存在的桥板支座，不是独臂横跨几十米当桥。基础工班只在安全条件满足后出掩体，不能在漫天炮火中免费替代工程机；若区域再次出现已预告威胁，工班退回并暂停项目。

持续供给/道路成果在窗口边界发布；炮弹、转场和运输有公开到达拍。桥体真实承载与已进入 B 的车则每拍判定：未上桥就停在等候道，已上桥而支撑失效则执行公开的局部承载后果。消息延迟不能让车穿过坏桥。

轨道车只有一个实体：C → 连接轨 → B → 高处站台。机体与电池转场同样只保留一个身份，必须走到连接点，在途不行动、抵达不叠人。初值可用地面四拍、空运两拍，但应依巨构实际距离校正。切地图不花时间，移动实体才花时间。

**十、总览、局部战场、事件回看是同一套指挥视图**

这部分需要专门做交互，不能在角落加三个“地图 1/2/3”按钮就交付。

**总览看一座城。** 用倾斜的整座承运架视图呈现三个可点选区域。环梁、母线、轨道和支座有连续关系；可用电、正在行驶的车、已断的部件都是同一个世界状态的远景表达。总览只突出当前选择相关的连接，供电、运输、威胁不用三种同样的细直线铺满屏幕。

**局部下命令。** 点击 A/B/C 区域或按 1/2/3 进入各自棋盘，Tab 返回总览。局部界面保留三张小卡片：本区工作、最近危险、空闲/受阻数量。每区保存自己的镜头、选中单位与未提交安排，切回来不用重新找人。切换全程暂停逻辑，不改变共同时间。

**点击因果，跳到需要处理的地方。** A 完成供电时，显示“ A 干线已接通 → B 维修可继续 / C 牵引可启用”。从 A 的母线沿共同结构扫过一次光，再在 B/C 对应设备落点响应；卡片保留结果供点选。选择 B 的“等电”，能反向定位 A 的供电条件。它是可追索的关联，不只是角色说一句“好了”。

| 事件 | 源头表现 | 另一战场的变化 | 玩家能做什么 |
| --- | --- | --- | --- |
| A 双路恢复 | 开关落下、母线沿环体逐段亮起 | B 焊接机通电，C 牵引灯亮；显示下一窗口可用 | 点 B 继续原任务；可不切图，条件满足后既定工作自动延续 |
| B 桥锁闭合 | 实体卡榫合拢，桥面停止晃动 | C 发车路线变实线，总览该段轨道接通 | 发车或继续清敌；无需另点“接收成果” |
| A 架设体准备跨区攻击 | 炮口蓄能、准备条与最晚可打断拍 | B 出现同一编号落点和到达时间 | 点威胁可在攻击源/落点间切换；选择打源头或保落点 |
| 一区安全 | 廊口关闭、威胁记号退去 | 总览该区转为施工状态，工班请求接手 | 一次分配项目后继续别区，不反复结束空回合 |
| 机体/电池转场 | 离开本区入口，运输线有单一实体标记 | 目标区显示抵达时间与预留入口 | 调整接应位；若被占则显示等待，不瞬移 |
| 八窗口合围 | 城防封锁线在总览闭合 | 外体意图改为撤出，后续入口关闭 | 继续保护对象，或冒险截击回收，不强制追杀 |

同一窗口多件事发生时，默认不连续抢镜。当前战场主画面继续播，另外两区卡片显示结果；窗口结束只按“必须处理 / 可利用机会”归拢，最多突出两条因果链。完整记录按需回看。决定性的跨区配合可先后回放，但标注同一个时间点，不把后播画面伪装成后结算。

提交按钮明确写“执行全战场 4 拍”。旁边只报“空闲 1 / 已知受阻 1 / 风险 2”等可定位摘要；不强迫每轮逐张打开确认三图。继续既定任务无需新操作，关键失败风险必须能从卡片看到，不能因为玩家没切到那张图就漏报。

本案的交互验收目标：玩家在总览能指认“哪处正在拖住哪处”，切一次图能定位责任对象，再用一次普通指令改变结果。若总览只是看起来宏大、实际仍要翻三张表，它就没有完成任务。

**十一、三位主角的能力第一次应通过一次真实联动建立**

纪存的关键词是“把分散的行动接在一起”，白鸢是“让方案的后果可以比较”，七海是“使现场证据转成有效处置权”。基础切图、预测和合法操作仍是通用引擎接口，后续章节可由其他人物或终端承载，不锁死在三个人名上。

前置演出保留约 2–3 分钟目标，用可交互的指挥廊、事件插画加轻动效、统一比例立绘和场内动作结合。不是站在同一背景上把全部设定念完。

候选演出节拍：

1. 玩家在指挥廊看到轨道车上的工班，车前的道岔推不动；窗外一束电弧沿巨环熄灭，外体抱住供电节点的近景把威胁具体化。
2. 三处通讯叠进来：供电说已隔离、桥座说还差锁定、站台说车上有人。纪存短暂特写，三处现场回应以不同方位进入，镜头拉到同一座承运架的总览。表现他同时掌握几处节奏，不是复制出三名纪存。
3. 白鸢把两条可行路线叠在真实设施上：修好再走，或先固定桥座让车慢行。玩家能切换看后果，不由她代选答案。
4. 七海将现场控制箱的旧签名与实际用途对照，向本地总席取得适用的接管许可；A 区正常干线的可用条件出现。她做出判断，工班承担本地决定，物理隔离仍由战场单位完成。
5. 第一处跨区成果由玩家做出后，触发约 2–3 秒可跳过的回应：母线亮起，远处工位接电，纪存一句“桥上，接着做”。若玩家先采用别的解法，触发相应的支撑/清场因果镜头，不强迫走供电教程。

示例对白只供后续创作：

> 工班：“车道能清，桥那头还咬着一只。”
>
> 纪存：“先别跟它耗。把桥上的位置空给馆守。”
>
> 白鸢：“它这一口落下来前，车能过一节。后面得有人接住桥锁。”
>
> 七海：“总席同意把检修线交给我们。这一段能用，住宅干线别碰。”

战后画面依据结果区分：抢出的车停稳、人下车；清场后工班在敌骸旁接回母线；保留的市政工机恢复工作，或其损毁位置留下替换吊运。声誉与物资数字对应画面里发生过的事实。

**十二、保留战场操作感，别让总览吃掉局部玩法**

局部常用流程仍是选机体 → 点地点/对象 → 选一个相关动作。相关动作最多先露出三个，其余展开；目标绑定和出手格可直接在地图改。自由光标、Esc 退出选择、键盘移动、左键拖拽旋转、右键平移与滚轮缩放保留。血条、漂字和特效不能吞掉地面点击。

完整时间轴按需展开。常态用地图上的准备姿态、持续工作、路径终点与下一次关键发生时间表达。轻推/重推、普通掉血/失衡、定向/定格都要有不同符号和对应动作反馈，而非换一行长说明。

规划状态降低无关背景的对比，保留材质、落地感、关键结构与机体体积。普通环境有怠速、排气、灯光与水面细动；逻辑仍暂停。过渡回执行时环境回色、路径收束，随后真实动作发生。友军、敌人、目标通过颜色加形状区分，不能只靠红/绿。

外体啮咬、重型驻定、炮口储能应与市政焊接、吊移、拳击明显不同。火力清场路线要有击破、器官失能和重敌倾倒的满足感；成功推离切割位也要表现刀头离开、火花中止、桥锁险些断开的后果。两种成功不共享一个小漂字就结束。

**十三、一次跨战场选择的具体样例**

这是设计检查样例，尚非引擎重放所得。假设第二窗口开始：A 架设体将在第六拍释放、炮弹第八拍落向 B；B 预算二号还需四拍完成桥锁；C 车道即将清空。三图都处于同一个 t=4。

玩家可以：

- A 无牌第五拍强行破坏架设条件，让炮击根本不能释放，B 继续修；这是跨区救场。
- A 保留输出去杀啮线体，B 让馆守或货柜挡住实际弹道，预算二号保住工位；这是改变威胁的承受者，是否挡得住按武器/掩体规则预演。
- B 暂停维修退到安全格，A/C 集中清敌，下个窗口再修；这是拿进度换单位安全。
- B 改为临时支撑，C 尽快发车，放弃本次永久修桥；这是任务突围。

如果该炮采用高抛定格弹道，低矮直射掩体就不能挡它，第二种方法必须改为防爆掩体/撤离。不能为让示例成立而临时改武器规则。预演必须显示本关实际采用的弹道类别。

同一个敌招、同一个工程剩余时间，要能容纳至少两种真实可执行的处理。设计者不能把“第五拍推炮”藏成唯一答案再把其他解法全部判无效。

**十四、怎样把巨构做出来，而不把 demo 扩成整座城市模拟**

Godot 中可用一个战役状态配三个局部网格，各网格有明确的世界坐标变换、入口和视图。总览用共同的低细节承运架与局部状态代理；放大某区时显示该区精细资产。双方共用设施 ID 和事件，不建立三套各自决定“桥修没修好”的逻辑。

巨构只需一套可信的主要结构：环梁、三处承台、连续母线、C 到 B 的轨道。局部棋盘坐标必须能落回这套世界结构，宏观中看到的运输距离与动画应一致。总览不必同时高精度渲染三张全部场景，更不必模拟整城每根梁的刚体应力。

连接关系分为两类：不可直接操作的城市结构用于表达尺度；可操作节点与连接用于规则。首版可操作的是供电支路、桥锁、吊运/轨道、入侵廊口。桥锁修好通过实体部件状态与路径状态联动；断供通过同一个线路状态联动。巨构不是一条虚构的全局 HP。

跨区信息结构至少包含源节点、目标节点、发生拍、可用拍/到达拍、条件、实际结果与可回看的因果事件。敌方跨区攻击、友军供电、物资转运使用同类事件框架，但各自条件不同。

在已有场景组件、机体动作、材质、特效与相机基础上，这个范围有可行的实现路径；主要新工作是共同规则、宏观/局部映射、敌方任务 AI 与状态反馈。性能、镜头切换手感和实际视线遮挡仍须原型验证，不能由文档断言已经解决。

**十五、通用底层与旧公式台的关系**

| 通用对象 | 需要支持的内容 | 本案使用 |
| --- | --- | --- |
| 战役时钟 | 固定执行窗、持续动作、统一快照 | 三图四拍；工期/蓄力跨窗 |
| 区域与连接 | 网格、世界映射、出入口、占用、供给边 | 一座承运架上的 A/B/C |
| 单位能力 | 移动方式、质量、力、攻击/工作标签、资源 | 换机不换规则，六机自选 |
| 行动/项目 | 准备、持续条件、释放/完成、恢复、中止政策 | 炮击、啮咬、维修、吊装、锁车 |
| 势力任务 | 当前目标、承诺、有限增援、撤离状态 | 外体入侵、无人机旧任务、工班施工 |
| 跨区事件 | 来源、去向、在途、取消条件、到达与后果 | 炮弹、电池、通车、供电 |
| 范围许可 | 来源、对象、容量、适用范围与撤销条件 | 七海协调、本地总席接管 |
| 目标/阶段 | 救援、局部安全、退潮、清场、可选继续 | 不把所有状态压成一个击杀计数 |
| 结算 | 事实、资源净变化、不同关系、可选目标 | 不同解法的真实回报 |
| 呈现事件 | 同一时间的地图变化、提示、特写与回放 | 切镜不改变先后；巨构随成果发生变化 |

预测与执行共用模拟器，白鸢预演在状态副本上求解。演出消费事件，不另算攻击或工程成功。快照含三图、已承诺计划、项目、权限、敌人储备和在途状态；回放能查到直接原因。

无牌、旧拳王、馆守及已有特效/动作/工业材料作为起点；新机和外体按职责补独立表现。当前 P/Q 的逐机与团队时间差、隐式敌方激活、自动友机搬移不作为新分支规则。新增“联动战役”独立入口，保留旧版本可比较；本轮只交方案，未修改入口或脚本。

**十六、开发顺序与验证，不再等所有美术完成才发现机制走不通**

1. **单图公共规则。** 现有机体配轻敌/重敌代理，验证跨窗动作、全部敌意图、不同打断和争格绕行；让战斗/工程两种处理都能成功。
2. **两图战斗与工程对照。** A/B 共同时钟、跨区炮、电与持续维修；必须实跑抢修与清敌后工班接手两条路线，以及一个没有维修机的编成。
3. **三图与完整任务状态。** 加 C 和同一辆车、有限增援与撤退、安全施工快进；证明救援先达成与清场先达成都能正确收束。
4. **自选部署与宏观调度。** 补齐候选可选机的能力、地图定位与入场说明，做推荐队/强攻队对照；总览能回到源头并看见结果传递，转场不瞬移。
5. **连贯的剧情与视觉交付。** 巨构连续结构、三种局部材质、外体差异、机体招式、首次调度特写和结果演出一起对照实机。不能让灰盒代理长期成为交付美术。

| 验证问题 | 必须看到的证据 |
| --- | --- |
| 能否真用战斗解关 | 不带快修机的编成完成清剿、工班施工与同车撤离，没有剧情免费补一台工程机 |
| 不全歼能否真赢 | 存活外敌仍在场时救援达成，玩家可直接结算；守退潮分支也可完成 |
| 清场是否可信 | 留有入侵储备/跨区在途炮时不报安全；全部解除后无理由重新刷怪或增长灾害 |
| 无限施工是否仍有因果 | 只是去掉持续威胁与硬期限，损坏、材料消耗、既有危险区和慢工期仍保留 |
| 编成自由是否真实 | 替换名单单位后有不同可行方案；部署提示能力替代，不靠角色 ID 过检查 |
| 联动是否能被看懂 | 玩家从 B 的停工能找到 A 的原因，做完 A 后能指出 B 何时恢复；不靠设计者口头解释 |
| 切图是否增负担 | 正在正确作业的区域不需反复打开；记录每窗口切换、主要点击与撤回次数 |
| 一座城是否成立 | 总览与局部能找到同一巨柱/母线/轨道；车和物资身份连续，未打开区域也正确推进 |
| 不同解法是否有价值 | 同初始敌阵，比较救援时刻、受损、消耗、素材、设备保存和实际操作量，不用一个战力分代替 |
| 同拍规则是否可用 | 争格、提前/同拍打断、友机让位、已出膛炮弹分别由玩家预测并执行，记录误判原因 |
| 美术是否达到本关要求 | 关闭 HUD，仍能认出三工作面、巨构尺度、敌我谱系、机体动作和关键设施状态 |

数量、四拍长度、八窗口敌袭、初始六机均为需要实测的参数。若三图造成连续救火与翻页，优先拉开敌方压力的发生时间、减少需要重排的行动；仍不成立就用两图检验核心，不能以更多信息条掩盖失败。
