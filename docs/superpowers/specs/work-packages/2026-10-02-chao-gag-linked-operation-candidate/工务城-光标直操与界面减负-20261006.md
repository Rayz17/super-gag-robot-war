## 现在怎样操作

| 状态或输入 | 直接发生的事情 |
| --- | --- |
| 未选机体，移动光标 | 探索敌人、机体、设施与地形；附近出现简短信息，移开收起 |
| 按住 I / 松开 | 展开当前对象规则 / 收回细节 |
| 左键点己方机体 | 默认进入走位，显示已绕障验证的可达范围 |
| 悬停可达地格 | 绿色路线、终点占地与三维虚影随光标变化；真机和资源不变 |
| 左键点落点 | 立即移动；保留主行动，不经过走位菜单和确认按钮 |
| 点底部招式，悬停目标 | 显示作用格、推移方向、伤害，以及取消或增加的回合末威胁 |
| 左键点合法目标 | 立即出招；非法目标就地说明原因 |
| 有操作能力时悬停控制柜或裂口 | 直接显示复位、断电或封闭等具体动作及条件；左键执行 |
| 吊运 | 选招后点载荷，再悬停并点击落点；右键可重选载荷 |
| 右键 | 退出瞄准 → 取消选中 → 自由观察；自由观察时再按不会弹菜单 |
| Z / U | 撤回本回合上一步实际行动；悬停预览不需要撤回 |
| Q / E；1 / 2 / 3；Tab | 切当前战场的机体；切战场；城市总览 |
| Space / 结束回合 | 集中查看未行动机体、敌方与环境后果，再确认进入敌方阶段 |
| Ctrl + 滚轮 | 缩放战场 |
| Ctrl + 左键拖拽 | 旋转与俯仰 |
| Ctrl + 右键或中键拖拽 | 平移镜头 |

普通滚轮和拖拽不控制镜头；普通左键拖动后不会误当成落点点击。先按住 Ctrl 开始拖拽，即使先松开 Ctrl，再松开鼠标也不会误下命令。

蓄力释放、装填、变形等自身动作也先展示后果，再点棋盘或按 Enter 执行。多机联合编排保留为暂停菜单内的可选模式，默认关闭。

常驻只保留三面行动余量、救援与当前阻塞、当前小队、选中机体的平铺招式，以及结束回合。取消原来右侧整列操作面板、常驻后果长文、权限说明和多块教学卡。完整任务、敌方顺序、上一轮实绩在任务页按需查看。

## 手感与实现

光标在地格之间移动时更新局部预览，不重建整套 HUD。路径从真实寻路结果读取，随光标立即显示；全战场后果计算在后台处理，快速换目标或取消时丢弃过期结果。缓存包含当前局面和动作，不会把上一次选择的结果重新贴回来。

移动演出合并连续路径，保留所有拐弯与原始规则事件，取消每走一格停一次的播放方式。三维落点虚影按机体及变形形态缓存，保留 2×2 占地和飞行形态。既有战斗演出、推撞、友伤、环境与跨回合作业继续按同一个规则结果播放。
