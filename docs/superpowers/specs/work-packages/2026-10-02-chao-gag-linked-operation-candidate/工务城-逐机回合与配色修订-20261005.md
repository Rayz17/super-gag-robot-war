## 攻略研究后的第二轮修订：把每一手的因果放回棋盘

本轮已接入当前逐机版。研究依据见同目录《陷阵之志完整攻略与界面研究-工务城诊断-20261005》。任务、选招和棋盘现在围绕同一个问题组织：这一手改变了谁的位置、谁会受伤、哪段路能通，以及下一处阻塞是什么。

- **棋盘上的信息。** 显示经过规则验证的可选格，武器、控制器、吊运载荷和落点分别检查。推移显示实际落点；伤害与被减少的敌方威胁同时标在现场。敌方路线取自实际结算事件，因此被挡住时不会仍从原来的路线终点画攻击。移开的标签带指向线。撤离车的回合末路线和终点也直接画在轨道上。
- **一手的收益和代价。** 白鸢面板比较“不做这一手”与“做完这一手后”的同一次回合末结果。少受伤、设施耐久和行车距离的变化单独列出；新增的己方或关键设施损伤用红字提示。走进未断电的电弧带也会提前显示代价。
- **任务与跨区联动。** 开局根据实际编队提示，给出本回合能到达的作业位置；点击只会预览正常移动，仍需玩家确认。靠近设施后出现具名现场操作。任务栏说明当前阻塞，并能定位其所在工作面；七海的核验入口取得旧令记录后才展开。
- **HUD 主次。** 顶部直接写“余几次主行动”；底部把三处机体并列呈现，跨区增员后可以横向查看。任务、预告、当前机体、行动后果分区。上一回合实绩与本回合末预告使用不同标题，增援按工作面显示入场或延后数量。完成本回合后保留实绩，存档也保存这份回执。
- **操作。** 地图上的机体和设施标签均可点选；失败原因保留在现场面板，错误目标会清掉旧预览。Enter 与小键盘 Enter 都可确认，结束回合弹窗也支持；Space 打开结束回合审阅。左键只负责选择，右键拖转镜头，中键或 Shift＋右键平移，滚轮缩放，按住 I 查看对象规则。
- **与现行规则一致的招式说明。** 区分本次行动、蓄力至下回合、持续托桥及两个供电回合的抢修；明确导弹是中心与四邻格受伤、同一大型目标仅受一次，而不是沿用旧四拍模式的说明。

### 三个实际例子

1. 无牌移动后正蹬推敌：先显示敌人受伤和落点，再显示“01 → 无牌一号：少受 1 伤害”。敌人依旧按原方向出招，这次会落空。
2. 白色样机复位母线：B 抢修得电、C 行车供能接通；系统仍明确提示“工机锁车”，不会把供电当成车辆已经出发。
3. 吊装机移走锁车工机：撤离车本回合前进从 0 变成 2 段，棋盘显示这两段路线，同时标出下一处货柜阻塞。车辆跨战场也检查接收格，不能穿过占位机体。

## 前一轮的颜色修正

先前把“明亮”理解成了高白屋顶、白底界面与亮蓝按钮，造成视觉刺激，也偏离项目已有原画。本轮撤掉这套配色，采用中间明度的有色涂装、有颜色的暗部和有限的功能亮点。

| 工作面 | 主色关系 | 材质与结构 |
| --- | --- | --- |
| A 供能前庭 | 暖灰混凝土、钢蓝屋面、铜橙母线 | 设备舱、散热屋顶、瓷绝缘子、带检修沟的承重板 |
| B 跨渠桥座 | 青绿桥架、冷蓝灰地板、暖色安全标识 | 深水渠、桥座、承重梁、输送管线 |
| C 环下装卸站 | 蓝紫仓体、赭黄货箱、橙铜吊架 | 旋转台轴承、真实轨槽、装卸舱与滚筒 |

界面改为墨蓝仪表底，区域用 A / B / C 彩色识别牌，选中状态与结束回合分开着色；撤掉大面积白底和重复亮蓝装饰。机体保留各自身份色。移动范围、敌方威胁、增援预告的色义不随场景变化。

本轮使用项目已有 `industrial-trim-atlas.png` 制作嵌在实体结构内的设备舱，把重复办公窗格改为工业服务塔；地面保留凹槽、断面、轴承和贴图法线。对扫描地面的底色作去偏色处理，避免三块地板都变成棕灰。灯光提高暗部可读性，同时限制屋顶反光与材料白值。用户给的参考用于主色块、彩色阴影和冷暖关系，没有搬用其古建筑造型。

依据：项目《动画原画 × 档案套印美术方向 v1》、模型街原画 `model-street-v2.png`、工务城 `command-ring.png`、已有工业贴图，以及用户本轮提供的三张配色参考。常态不铺满霓虹，也不把角色统一染成环境色。

## 核心操作与结果

- 每台机体独立拥有移动格数和一次主行动。移动可以分段，攻击前后都能走；点地图上的机体可选中，点击可达格计算可行绕路，确认后立即行动。
- 完全版王者是 2×2 占地，寻路、碰撞、目标命中和危险支撑都按完整占地计算。三个战场扩大为 10×8、10×9、12×8。
- 敌人公开动作和执行次序。己方阶段不偷偷消耗敌方时间；按“结束回合”后，才共同推进敌人、地形、增援与撤离车。
- 重招在本回合蓄力，下回合释放；位移可以中断已架设的攻击。抢修需要工具、备件和跨回合供电；馆守可用左臂持续托举作为另一条过桥解法。
- 推拉、碰撞、坠落、火、电、护盾、连锁爆破和追击作用于通用对象。不同机体依据重量、飞行／涉水能力、装备与招式发挥作用。
- 敌方巢口提前标出出现位置与批次，周期增援；占住出口会付出伤害代价。可以战斗摧毁或让有工程工具的机体封闭巢口；第 8 回合后入侵潮撤出。
- A 恢复供电影响 B 抢修与 C 行车；C 切断馈电会阻止 A 的跨区炮。结束回合的镜头依次展示有结果的战场，全城视图可查看三个区域。
- 白鸢的联合预演是可选工具：按顺序排入多台行动，仍使用相同移动预算与主行动，不再额外赠送同伴瞬移和攻击。
