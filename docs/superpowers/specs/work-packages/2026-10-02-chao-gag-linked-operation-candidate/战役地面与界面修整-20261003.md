# 战役地面与界面美术修整 · 2026-10-03

本轮修复用户指出的“纯贴图地面像贴纸”。保持三张战场的规则、可走格、机体落脚高度以及四拍窗口；修改地面构造、材质受光与 HUD 美术。入口仍是项目根目录的 `联动战役.command`，旧画面入口 `联动战役-上一版画面.command` 保留。

## 问题与处理

原实现把建筑当作三维物体，却把大部分地面结构压成颜色线条。另一个实际原因是正交相机继承了过大的远裁剪距离，阴影图覆盖了大量无效深度，导致机体和结构缺少地面接触感。这些都是当前制作和渲染设置的问题，不是非像素画风的限制。

- **真实起伏**：混凝土板带侧壁、倒角和接缝；货运轨道进入下沉轨床，包含轨头、轨腰、枕木和固定件；服务沟有可透视格栅与下方管线。转台地板独立于固定轴承座旋转，露出边圈和凹槽。破损地格包含不规则断口、碎块与钢筋。
- **材料响应**：混凝土、破损混凝土与旧漆金属分别接入颜色、法线、遮蔽和粗糙度贴图；世界坐标投射避免立面拉伸。原始纹理保留 4K，运行时导入 2K 并开启 mipmap 与各向异性过滤。法线负责细微凹凸，轨槽、坑洞、格栅与断口由真实几何负责。
- **地形阅读**：B 深水沟保留连续空腔和下方水面，取消容易误读为可走桥梁的装饰横梁。C 坑洞保留开放轮廓。可走中心没有被装饰结构挖空。
- **受光和规划**：缩小正交相机远裁剪范围，使用 4096 阴影图并校正偏移；常态保留接触阴影。规划时减少背景亮度与色彩，但保留法线、粗糙度与遮蔽。
- **UI 美术**：新绘制的搪瓷调度卡、深色切角命令条和语义图标替代原绿色线框面板。选中态使用暖象牙色；目标卡、单位卡、四拍时间轴和执行区保持同一视觉体系。招式条显示总拍数，展开后区分准备和收势。
