# 联动战役 α1：供能与撤离

本轮把 v3 的底座做成公式台中可操作的两战场切片。目标是先证明玩家能观察、安排、预演、执行并完成一个跨区目标，不将数据代理、测试通过或此切片写成完整战役完成。

## 本轮交付

- A 供能前庭、B 跨渠桥座共用四拍窗口，每区两台己机；所有在场敌人的承诺同时公开，编辑计划不重算敌人。
- A 恢复电力，B 在供电下接通桥锁，轨道车通过桥面撤离。可以封口清剿后安全施工，也可以保护作业者先救人。
- 地点移动自动绕路；选招后直接点目标格，允许瞄准预测位置。已开始的蓄力/作业跨窗保留，暂停条件和打断原因可查。
- 先移动，以统一位置快照释放攻击，再合计伤害、强制位移与打断，之后处理施工、跨区信号和运输；同拍打死对方不会倒撤其已释放攻击。受击/被推离的作业者不能在该拍继续施工。
- 回放与预演共用结果；阶段、受损与阻挡显示在对应对象上。重复预演不扣资源、不推进世界。
- 复用无牌、旧拳王、馆守及现有远射动作资产。地方支援射手与外敌在此轮明确使用动作代理，不将其当成社勇王/完全版王者成品。

## 尺度与接触

地图单位为米，单格十米。无牌沿用十六米、馆守十八米；旧拳王暂取十八米作为本切片标尺。敌方重体用二十八米、2×2 占地验证大型单位，不改变任何正式机设。

高度、占地、质量、通行净空、武器射程独立配置。占地进入占用、寻路、争格、强制位移和命中判定；点击大型目标任一占地格都能选中。小机可以过的窄道大机应明确不能过。净空不足的门架有原因提示。大型机旋转占地的扫掠、任意多格转台载荷留待下一轮，不默默按单格穿过。

模型保留自己的色彩，用真实身高比例缩放，脚底回到同一地坪。攻击镜头的命中点依据目标体积高度和攻击者可触及范围确定；拳击不抬手打到大机头部之外，远射不从胯下发出。镜头构图须容纳攻击者、目标及武器，正常战棋镜头可读底盘占地和朝向。

## 明确的入口和范围

增加“联动战役 α1”独立入口，能返回公式台列表；旧 P/Q 保留。第三战场、自选十四机、正式外敌模型、长剧情、惯性甩投和完整结算经济不作为此轮已经完成的内容。

验证要求：实际窗口能完成指令闭环；无界面测试覆盖跨窗蓄力、同拍释放、提前打断、供电/工程联动、救援收束、尺寸占位与窄路；正常镜头检查模型比例和信息层次。错误反馈不能依靠开发者在旁解释。
