## 1. 一台机体的六层定义

| 层 | 定义什么 | 例子与约束 |
|---|---|---|
| 身体 | 战棋规格、脚印、质量、关节、净空、承重、移动方式 | 2×2 王者的炮口和站位是真正四格；不是把 1×1 模型拉大 |
| 装备 | 工具、武器、护盾、吊点、形态组件 | 没有焊具不能凭“工程任务”获得维修；卸掉翅翼就改变飞行资格 |
| 招式 | 形状、效果、目标、费用、持续阶段与演出 | 同一种推移可用于敌人、友机、货箱，结果由对象属性决定 |
| 驾驶/搭档 | 人物被动、有限精神、可携指令、适配资格 | 有人机不能默认无人化；独立机魂也可载同行者 |
| 机魂 | 公开的意愿、条件接受、拒绝与反提案 | 提交前知道，不在结算时随机反悔；不把玩家合理操作变成惩罚陷阱 |
| 关系/成长 | 通过战斗与剧情得到的合作方式、装备选择和表现 | 提升应改变选择，不只堆数值；正式剧情解锁与本 demo 测试开关分开 |

这些是数据责任，不要求玩家一次打开六个面板。战斗只显示此刻相关的两三件事，其余在整备和详情里阅读。

以下是整改的配置目标，均为玩法 Candidate。现有武器优先复用；新增装备要核对项目机设和挂载位置。每台至少有一个独有的战术长处、一项代价、可组合对象和可辨的动作，不给所有人万能维修/支撑。

| 机体 | 招牌选择与合作 | 必须保留的短板 | 动作与资产重点 |
|---|---|---|---|
| 无牌一号 | 截击后撤步；正蹬安全推位；回旋踢侧向控制 | 轻型力量，不能任意撬动重物；没有通用工程装备 | 快速连续步伐；正蹬/回旋踢的髋、支撑脚、屈膝分清；拳掌手刀明确 |
| 旧拳王 | 侧勾改变站位；接拳反击；重拳蓄势和额外碰撞收益 | 机动较慢；反击必须有公开触发条件 | 拳架、垫步、转肩转髋、贴身重击，与无牌的踢法不同 |
| 馆守 Z | 独臂牵引、承重与保护；拉敌离开工位、把同伴拉回安全面 | 右前臂仍缺失；撑住结构时不能自由游走 | 左臂受力、躯干顶撑；禁止演出里长回右手 |
| 社勇王 | 拳击自护；三格破围终式；救援与主体 AI 的合作选择 | 终式需要准备和气势；正面爆发会影响设施 | 勇拳核心连续性、强烈拳击与扇面反馈；驾驶员/主体双身份 |
| 完全版王者 | 双线压制、强推钻、合盾、外翼；卸装交换火力与机动 | 2×2 占地、蓄力、净空、弹药；装备越多越有取舍 | 对称头部、无典型嘴部刻线；右手钻；肩轴向前炮；武器包冗余感 |
| 预算二号 | 真维修、无伤液压顶推、预制墙；少备件解决多个问题 | 备件有限、载荷弱、直接杀伤有限 | 细而清楚的工具机关；维修与造物分开 |
| 市政吊装机 | 抓取重物、牵引、长距离安全落位、承重 | 吊装净空/质量/固定支腿；慢、需保护 | 真吊臂、支腿、钢索、载荷摆动；不播人形拳击 |
| 雷翎 | 直线标定→同伴破护；爆破导弹；快速观测与轻载投送 | 射线遮挡、弹药、切模式机会成本 | 预瞄、光束、标定、机翼转姿；不用强制隔回合停火来造差异 |
| 灰崎警备劳务机 | 拘束不致死、隔离墙改线、保全通道 | 控制强而杀伤弱；锁步不自动取消射击 | 钩索持续张力、折叠警戒段；驾驶员劝止危险操作的反馈 |
| 消防架桥机 | 敌我同效泡沫、灭火、临时桥、应急维修 | 备件、跨度、承重和工具距离；不能永久替代所有桥修复 | 泡沫喷射、桥板展开、涉水动作；与预算二号不是换色同招 |
| 货柜领袖 | 中心/邻接群盾、载运、变形护送、重物调位 | 护送形态和武器取舍；载荷与路线净空 | 独立原创载具人格与模型；轮轴折叠、承载、盾场，不沿用原 IP 原设 |
| 镜星 | 标定、定向干扰、可解释的光学协同 | 干扰只作用于可干扰承诺/设备；不万能清空敌人回合 | 棱镜转向、信号连接、被干扰源与失效落点同步可见 |
| 白色样机 | 贯穿两体的光束与近身剑；清理排成线的目标 | 实体墙截断、单次伤害有限、与敌位置有关 | 明确穿透第一目标到第二目标，与雷翎首物阻挡区别 |
| 歌翼可变机 | 四邻吹离的震荡弹；航空形态、覆盖与护送 | 形态限定武器、落位与防空风险；多目标输入不能繁琐 | 三形态连贯变形；震荡外推、扫射与广播演出分别制作 |

移动规格采用用户确认的几档：小型 1×1、标准 1×1、重型 2×2、巨型 3×3。更大的单位优先作为场景局部结构，不当普通棋子挤进小图。机设米数用于资料和角色表达，不按真实米数混乱缩放。当前优先把王者 2×2 做完整；3×3 在扩展验证场景检查，不强塞进救援主编队。

所有常规机体保持三维表现与相近制作精度。模型、贴图、骨骼、头像、动作、受击、失能缺哪一项就记录哪一项，不把有模型等同于角色完成。

报告 §7.4(a) 不是只要“七个新技能”，而是在问人物梗怎样进入玩法。逐项处理如下。

| 报告提案 | 整改设计 | 验证题 |
|---|---|---|
| 社勇王审批、实名、扇面 | 保留保护/越权的选择和实名承担结果；有效授权只改变已有法律/任务条件，不凭空增加拳力。救人、保护设施获得气势的来源可见；AI 反提案在提交前展示 | 直接终式、先保护再终式、交给另一机解决，三种代价不同；不能因“盖错章”随机拖走 |
| 王者四套装备与卸装 | 恢复合盾；分别定义炮、盾、翼、钻的挂载/可用状态。卸装后产生真实部件，占格、可搬、可损坏；当战斗无法重装时明确告知 | 丢盾护路、丢炮作固定火力、保翼越障；每种交换有失去的能力，不能无限生成部件 |
| 雷翎节拍、抢拍、投送、侦察 | 用快射/精瞄准备、标定链和轻载投送制造取舍；不硬性只准奇数轮开火。侦察揭示有承诺依据的远期计划或条件分支 | 当轮控敌与准备更强一击都值得；投送距离/载荷有实体过程 |
| 预算二号便宜补丁与真修 | 普通维修恢复永久耐久；便宜支架提供单独显示的临时支撑/临时耐久，期限到时按规则卸除 | 真修省后续行动，临时撑过这一轮省备件；旧血值不倒灌、不消除已受伤害 |
| 灰崎非致死与信任 | 拘束、隔离、关停接口构成保全路线；是否新增实弹装备先核对机设，不为“必须能杀”虚构大枪 | 同一工机可被保全或击毁，预览明确奖励/损失；反复造墙不刷声誉 |
| 货柜车形/载人/变形推物 | 车形脚印、转弯扫掠、载客质量与上下车落点真实；不采用“自己占着的空格突然冒出物体被变形推出”的错误几何 | 能把一台小机送到另一工作面，过程不免费复制行动，不丢失乘员 |
| 歌翼三形态/四点导弹/广播 | 三形态先给各自明确武器和速度；四点覆盖提供默认分布再允许调整，不必逐个模态点击。广播扰动只作用于声明的敌种/承诺 | 震荡拆阵、航空扫射、护送支援形成差别；无限变形不能刷新移动/延迟敌人 |

合体与变形还要检验组件从哪里来、身体形态如何连续、落地空间足不足；合体不能无来源地带来另一个队友。全装备王者的装备脱落、炮向、头部与钻臂沿用用户的明确形象约束。

## 5. 精神与角色卡：从确定指令开始

本节已补成[09册完整施工合同](09-人物指令与机魂施工规格.html#section-2)，不再保留“每场一次候选”的空位。人物头像、通讯双页签、目标旁快捷入口共用同一个能力实例、同一个次数；机体招式栏不复制人物能力。

| 能力 | 固定效果与费用 | 验证 |
|---|---|---|
| SPIRIT-1 再听一遍 | 每战1次。核对目标已公开的工单和意愿，写入自愿停工协议，取消该对象的作业承诺。本关B拆解工机的桥来袭伤害3→0；不改变异形、不返机体行动，不替七海签令。 | GW-R1-COMMS |
| SPIRIT-2 以我的名字 | 每任务1次；范围只限回执内的一道锁。七海撤回本人背书并提交请求，本地持权人按预先公布的回执在本轮work阶段解除该锁。先经过enemy阶段，不能事后抹去攻击。她不获得城市写权；被冒用签名须先记录在案。 | P02-PERMIT-01 |
| SPIRIT-3 记录在案 | 每战1次，将公开日志中的事件生成一份签名EvidenceRef。P02中它满足被冒用旧签名的证据条件，仍需SPIRIT-2及持权人回执才能解锁；它本身不增加伤害、不改变敌我阵营、不直接开门。 | P02-PERMIT-01 |
| SPIRIT-4 预演 | 不限次、免费。保存两份草案及各自snapshot_hash，比较HP、位置、资源、承诺取消和跨区变化。白鸢缺席时仍保留系统基础预演，但移除她的头像、声音和个人解释；不会让基础可用性依赖出席。 | GW-R1-PREVIEW |
| SPIRIT-5 补一页 | 每战1次，认证一个已列出的备用接线方案，省去一次现场测绘主行动。原接口、承重、风险一直可查；能力只使既有施工图可执行，不生成路、桥、机体或新电源。连接仍由具备线缆工具的机体邻接实施。 | P02-ARCHIVE-01 |
| SPIRIT-6 先吵一句 | 每战1次。已准备好的终式会损伤空置、非城防计分资产时，可选择承担公开财物代价的原命令，或采用可执行反提案。限次只在经协商的命令成功提交时扣；听取/预览/普通接受反提案免费。实名路线声誉−1/任务一次，物理损伤照算，不奖励败选方气势。 | P05-CONSENT-01 |

## 6. 人物岗位、驾驶员、机魂与关系

现场、通讯、驾驶与机魂是不同身份字段。社勇王由豪司与机体主体AI共同决策，不提前称金章独立人格；王者、雷翎、货柜保留自主主体。灰崎机保留驾驶席，但CH048实体资料指向C11，本测试不据报告映射宣称她在工务城到场。预算二号身份未明，不编造驾驶员或机魂。

[09册意愿卡](09-人物指令与机魂施工规格.html#section-4)逐台列明触发、四态、底线、反提案命令和说服边界。首关加入GW-R1-SOUL快照：社勇终式会伤及有人避难所，预演明确拒绝，并提出“移1格，改打单拳”；拒绝不扣，接受替案仍按实际移动与主行动收费。协商不是每次出拳的弹窗，也不是结算后随机反悔。

关系和成长按可归因事件计，不以恋爱加战力、故意制造分歧或最后一击抢经验。具体6/14XP阈值、credits/reputation、三关4/6/4曲线和反刷写入[10册成长规格](10-专关与成长对照规格.html#section-5)，版本GW-GROWTH-P04-v1。首关保留stock，不自动叠成长模块。

## 7. 角色卡与随机牌组，分别有明确出口

**配置A是主版确定指令。** 出席者带来1—2条可见能力，卡只是效果入口。卡面字段、三处入口互斥、取消扣次和整局验收均已写入09册。只要这一层完成，就可验证角色卡恢复；不必先开发随机抽牌。

**配置B是独立对照。** [P04-DECK-01](10-专关与成长对照规格.html#P04-DECK-01)固定六机、三面、6种子和16实例牌表。抽3／能量3／手牌5／末轮弃未用／每招附1；普通移动、武器和工程任务不依赖抽牌，不允许再行动牌。另设相同修饰池全部可见的A_plus，分清收益来自新工具还是随机性。

12人交叉体验、点击和思考时间、无效牌率、有效选择、种子依赖与重玩偏好都有采纳门槛。若B只增加操作，保留试验记录并搁置；若只有确定修饰有益，采用A_plus的构筑方向。结果必须来自真实体验，不能因写完牌表就决定随机卡组成为主玩法。

CARD-01—12已逐条补上固定手顺和失败样子，关间奖励、删牌升级和成长也有数字。完整设计未被删掉，但它不阻塞首关，也不能算旧系统原样复原。

## 8. 战斗里的台词、立绘、名场面和对手

现有台词首先挂到实际事件：选中、危险意图、发射、保护、碰撞、击破、拒绝、跨区抵达、居民获救。按说话人、情境、频率和冷却控制，避免每点击一次就弹一段台词。人物不在场时不能误用其现场口吻；机魂的气泡可以给解题提示，但不能替玩家报答案。

通讯和精神演出复用旧版立绘的长处：一致头肩比例、人物入场、表情、短句、角色来源。赵梅、胶价王等非路人若进入本任务演出，必须使用已有专门形象，不临时拿剪影凑数；兜灯比例单独校准。

必杀与重要跨区调度使用短分镜：主体准备→出手→棋盘后果→相关战场响应。完整名场面默认每场限制数量并可跳过；一键跳过仍落到相同结果。社勇王合体、王者全装、货柜领袖护送等要以真实动作和局面条件触发，不把战斗变成自动播放海报。

有名对手的设计包包括身份来源、机设、意图模式、弱点、阶段切换条件、台词和关卡用途。主救援任务仍允许保全/速救/歼敌不同解法；对手不能在动画结束后无视公开承诺突然重选目标。
