这些数值的设计理由是：桥4能承受单炮2，却承受不了拆解3加炮2，迫使玩家消去至少一项威胁；工机5不会被普通2伤打倒，鼓励位移和保全；爆破2恰好清箱和喷酸体，却给列车留下可见代价；18格行程以4格/轮需5轮，第6轮截止允许一次整轮延误。它们构成首关的可检验假设，不是全项目通用难度常量。

界面还要区分“来袭伤害”和“实际损伤”：桥HP4遭3+2，来袭5但实际最多损4；顶推后剩2，保住2HP及本次失效城防2点。短卡不能把来袭5写成实际损失5，也不能说顶推凭空恢复3HP。

城防扣点的完整映射只有上表三类：避难所实际受伤、母线首次失效、桥座首次失效。 列车毁坏单列失败；我方失能、市政工机损失、敌炮损失分别记账，不偷偷换算成城防。一次爆破可同时触发数类损失，全部如实预告。

4. 三道必须互相处理的题

A不接电：B的“复位桥座”不能完成，原因是升降液压泵无电。 顶推拆解者照常有效；货柜也可用自身动力临时撑桥，但被占住一台机体的主行动。A的价值是释放B一台机体，而不只是把按钮变绿。C列车牵引也须公共母线通电。

B不提供通桥：列车停在B(3,3)，下一节点B(4,3)显示“桥面未对齐/无支撑”。 C清空铁路仍不能越过这格。B永久修复要预算二号在(3,4)邻接接口执行通用“机械复位”动作，耗主行动1、备件1，恢复最多3HP并锁定桥面；货柜在(3,4)可撑起桥，不需A供电，但维持期间不能离开、吊运或攻击。

C不关专线：A(7,4)架设炮保留对B桥座的2伤承诺。 A可用王者把炮推出架设点，或用火力击毁；但这会留下A的啮线体去伤避难所。C关闭(6,4)专线柜，王者这一手便可用于清A的威胁。界面在C柜上明确画出“A炮停火 → B少受2伤”，不能只写“操作成功”。

“机械复位”与普通“补耐久”共用工具但有不同生效条件：结构具alignment_needed时，即使HP满也可换锁销并对齐；预览只报“桥面H0→H1、锁定”，不报假+3。已对齐且满血时禁止重复操作和扣备件。这个接口可配置在其他升降结构上，不按预算二号或桥座名字硬判。

这三题互相影响，但不是循环门锁：A接电不需要B/C先完成；C关敌炮线不需要A通电；B顶推和临时支撑也不需要先接电。玩家因此有启动点和替代解。

本方案R1末：城防7，桥4，列车4，市政损失0；列车走4节点，车头到C(7,3)。这不是完美无伤解，换来的是较快通路。

直射不是自动的无伤解： 雷翎从(4,5)向北直射，第一实体是箱(4,3)，2伤清箱，列车本手不受伤；但喷酸体(5,3)仍向原车头格喷酸2。若不另作安排，列车仍降到4，而且敌人活着。墙不挡抛射，不能把“造墙”算成这里的救车答案；货柜本轮从B调到C也赶不上敌方阶段护车。

确实可行的保车换编： 出击前交换货柜和灰崎的工作面，沿用对应出生格：B灰崎(2,6)，C货柜(5,5)。A社勇接电；王者飞到锚(5,4)，向东把炮(7,4)推至(9,4)，使其离开架设点，代价是A避难所受1伤。B预算到(3,4)先永久修桥，并承受工机贴桥的3伤；灰崎本轮不必为了用完行动而造墙。C雷翎飞到(4,6)向北射箱，货柜随后经(5,4)(4,4)到(4,3)，给列车加中心盾2；喷酸的2伤由盾吸收。R1末城防6、桥1、列车6，仍前进4格。它保住列车，但桥已经脆弱、敌人更多，且用了另一种部署；不是“六手之外再免费护一下”。在B给工机加拘束也不会取消它当前贴桥的3伤，不能把“锁步”当成“停止一切行动”。

省跨区操作替案： 不先切C断线，让王者把炮推出架设点，B仍安全；A避难所受到啮线体1伤，城防7→6。允许这个代价，不把未处理所有威胁当成操作错误。

R2先由货柜解除支撑并移出(3,4)，再让预算进入该检修工位永久修复桥；玩家阶段中途不行车，故这一短暂无支撑不偷走运输进度。解除支撑不另耗当轮主行动，货柜可以转去护场或吊运；若到轮末仍未修好，列车会按缺支撑停住。若R1没开车但R2解决线路，按每轮4格在R6可以撤离；R3才启动即赶不上公开时限，除非已经通过其他通路推进过部分里程。增援承担拖延和重新占路的压力，不为拖时长无限刷新。

后续意图在每轮刷新时一次发布：市政工机仍寻桥接口，炮只在架设点和专线均有效时开炮，幼体优先相邻可破坏的列车/公共设施，其次相邻机体；不相邻时公开步行路径及下轮威胁。等距按固定目标ID、邻格顺序北东南西决出，不在玩家行动后改选。三个增援均为HP2、步行3、邻接伤1的幼体；出生预告被实体占住则当轮不生成、该占位实体受1冲撞伤，延后一次并公开新时点，第二次仍被堵则这只取消，不能无限加出更多单位。地形已坍塌的出生格取消该只。

6. 调度和运输：时刻与落位写死

本关地面通道只有A↔B、B↔C。A入口锚(7,6)↔B(7,0)，B(0,6)↔C(8,6)；各保留2×2区域，1×1也只占一次容量。发起时显示主泊位和备用泊位；备用为B(7,6)、A(0,0)、C(0,0)，仍须逐个验证实际占地与结构。没有备用时就在边界运输队列等待，不生成半台机体。

地面：在R1玩家阶段出发 → R1敌方/环境期间在途 → R1抵达阶段到达 → R2才能行动。飞行：R1玩家阶段当下到达，余移动和主行动均为0；能提前提供被动保护，不能凭飞行白打一拳。地面相差的是本轮敌方阶段的位置和风险，不是文字上含混的“可能晚一点”。

全城地理中C位于西侧、B在其东侧，A是北侧供能台地；A/B/C导航顺序只是工作面编号，不是从左到右的地理排序。总览必须按这个地理关系摆放。列车路径按全城坐标连续：C(2,3)…C(9,3)→B(0,3)…B(9,3)→东侧出口两个节点。首尾跨图时分别画在相应区域并以同一列车ID选择。B的东西两岸铁路在H1，C到B的升坡在连接段内固定表达；正常缩略图保留向东箭头。

7. 同一时刻发生冲突，究竟听谁的

逐机只消除了“玩家同时点两台走位”，没有消除爆破多目标位移、坍塌和在途抵达的冲突。规则必须独立于动画先播谁。

主阶段固定为：玩家提交 → 公开敌方顺位 → 环境 → 持续工程 → 在途抵达 → 运输 → 增援 → 下一轮刷新。每一根事件先完成所有派生因果，再进入下一根。敌人顺位在发布时固定；环境、到达、增援在预告中标自己的阶段序号，不临时插到敌人第1位。

一个事件内同时受击：先按命中前状态取目标集合；按效果顺序聚合该批伤害并去重；先清理死亡与支撑崩塌，再收集强制位移提案。提案比较明确力量优先；同力按来源固定生成序号；同源再按目标生成序号。序号属于公开数据，可在预览详情看见。普通位移不自动互换；只有明确的“交换”复合动作整体检验、整体提交。
