地图面积不是质量指标。报告指出 266 个格子承载六台机体，很多时间耗在接近目标；这说明有效交战区过散。用户又明确希望地图别太小、王者有四格空间。因此先保留可调整的外轮廓，缩短任务与威胁之间的无效距离，比较紧凑 8×8、当前尺寸和有立体结构的布局。

每个工作面先写一张局面表：本轮会失去什么、可用机体能做什么、至少两种不同解法、各自放弃什么、对另一个区产生什么。没有这张表的格子和设施先不加。

| 战场 | 第一回合必须能理解并介入的选择 | 地图里的组合材料 | 与其他区的关系 |
|---|---|---|---|
| A 供能前庭 | 复位供电与压制架设炮之间分配行动；可直接打、移位断架设、断馈电或保护受击目标 | 导电沟、矮设备、射线挡体、电容、可断连接、安全绕行路 | 供电使 B 能永久抢修、C 能行车；C 可切断敌炮馈电 |
| B 跨渠桥座 | 先撑住桥、推开拆解者、修复支座或暂时吸收攻击 | 浅滩/深渠、桥墩、检修口、护栏、断销、承重面 | 桥可通后 C 列车继续；A 炮的跨区威胁需要当地或远程处理 |
| C 环下装卸站 | 解除锁车、挪货柜、保全工机、清敌/封口；为别区供料还是先开路 | 货箱、转台、吊机、轨道、输送、引爆/防火材料 | 可为 B 吊送支撑物，为 A 断炮供能；接到供电与桥路后撤离 |

至少准备三个完整编队/解法样本：近战控位＋工程保全、飞行射击＋快速调度、重装清场＋代价补救。推荐阵容只帮助理解，部署器按能力检查替代方案；没有工程机的编队不能悄悄进入唯一焊修才能过的死局。

地图功能不是每格都有复杂说明。保留安全空地、绕行路线、可利用危险与必要设施的清楚分工。首回合目标：各区至少一台出击机有能影响本轮局面的选择；两台机之间不是“谁离按钮近谁去按”的唯一答案。具体可达性由整片占地求路验证，不能只按直线距离算。

首关固定每区2台我方、2个敌人；R2末A/C各1台、R3末B1台，堵口延后一次再取消，全部按07配置。护群/防空/更多轻敌的密集压力关是全量扩展，不参与首关的敌数验收；单独测试多目标连锁与可读性，不能把两套敌数并列成当前值。

## 2. 战役目标、代价与共享阶段

主目标：把 24 人安全送到撤离终点。明确失败条件是哪些受保护设施造成城防耗尽、列车不可恢复毁坏或其他公开任务约束；“一处桥锁损伤 3”与“城防 −1”是不同量，始终分别显示。

允许多解：抢修/托桥赶在敌群撤退前救援；保全被劫持工机；清除外敌与阻挠者后疏通。清场后若环境仍有持续风险，必须显示并允许解决；真正已安全的场景进入可快进整修，不逼玩家空点十几回合。不同解法以救援、设施保全、市政损失、耗材、速度和奖励结算，不把杀敌作为唯一贡献。

建议的统一结算顺序为：**玩家命令即时后果 → 已公示敌方行动 → 环境变化 → 持续工程进度 → 在途抵达 → 运输前进 → 公示增援入场 → 下一轮刷新与发布意图**。这是拟定的新阶段合同，实施时与旧存档明确版本迁移。每项在预演中用相同顺序，不能 UI 预告另一种顺序。

当一个阶段内结构崩塌或供电改变时，相关即时级联先结清再进入下一条事件。持续工程在该阶段是否仍满足人员、供电、承重，重新验证。增援入场后下一轮才有行动；出生点、阻塞结果、撤退轮次事先公开。败局在真实触发点记录，不把全局动画与来源证据截断。

总览采用地理布局而非把 A/B/C 字母硬排成运输方向：**C 西侧装卸站 → B 中部跨渠桥 → 东侧撤离口；A 位于北侧供能台地，连接 B、C。** 列车跨图的出口与入口使用同一条全城路线参数；每个镜头都能看到方向标与北向标，不出现视觉左往右开、切区突然往左的错觉。

共享的大柱环、高架与供能管线跨三个场景保持结构对应。正常战棋镜头保留各区紧凑布局；总览把整体城市关系显示清楚。跨区事件以“源头一闪→沿真实连接→目标响应”串起来，短缩略窗可显示远区后果，点击才切主视角。敌方因果播放自动跟随时允许暂停与返回玩家镜头。

跨区调度直接在棋盘交接点或小地图选目标区，再选合法落位。预览出发费用、到达阶段、目标区容量、将被推迟的本地主行动；出发前为目的地保留位置。若目标后来因事件被阻，使用事先公开的等待/备用泊位规则，不能消失、重叠或卡在半途。

| # | 规则与本次具体处理 | 验收重点 |
|---|---|---|
| 1 高度 | 使用离散 h0–h3 作为战术高差；视觉间距按镜头调，不直接照报告 6m | 同一等级不因美术微坡产生隐藏额外步数 |
| 2 同格多面 | 同一 XY 最多两个可站结构面；位置必须带 surface_id，空中另有飞行状态 | 桥上、桥下能分别点中、选中和看到威胁 |
| 3 上下移动 | 常规攀升一档增加移动成本；两档以上需坡道、梯、升降或飞行能力 | 所有路径含层间边，2×2 完整脚印可通才显示可达 |
| 4 坠落 | 强制离开承重面后按落差与着陆材质结算，初值每档 1、上限 3；深渠/坑另外按能力判定 | 落在其他单位上的双方受力、合法终态与二次坠落都可预演 |
| 5 高处射击 | 高处射程 +1 为可配置候选，不叠加空中观测；使用真实起点/终点高度检测遮挡 | 不能用一条恒定水平高度线假装射向低处目标 |
| 6 向下接触 | 仅有检修口、边缘姿态和工具够得着时允许向下一面攻击/操作 | 平台地板本身挡住时，不隔板出拳 |
| 7 支撑网络 | 结构由锚点及最低支撑条件承重；条件失效后同一事件链结算 | 层叠支撑无循环；2×2 全部受力面检查，不只看中心格 |
| 8 机构档位 | 吊机、转台、升降台只到公开的离散位置；轨迹扫过体积也检查 | 终点空着但中途撞墙不能通过 |
| 9 边缘护栏 | 护栏属于边，而不是凭空占一整格；有阻挡和可破坏状态 | 先破栏再推与同招破栏后推的顺序有区别 |

重力、旋转和所谓“离心”采用可预测的离散效果：质量、承重、位移和明确方向。若设计高速旋转装置，可配置“解锁后对未固定物向外推 N 格”，不使用实时刚体随机飞散决定战棋结算。碎屑刚体只能负责装饰。

以下完整保留 SP-M1–12 的目标，各自先有独立验证局，再选合适组合进入任务。不是将十二种机关放满同一张图。

| 编号 / 原机制 | 规则设计与修订 | 玩家能做的组合 | 必须验证的边界 |
|---|---|---|---|
| SP-M1 临时顶升/斜坡 | 工具造出临时支撑面或顶升一档，费用/寿命可见；到期按下降、拆除或失去支撑显式结算 | 抬高射线、搭短路、临时挡通路 | 上面有单位时不能悄悄删格；2×2 搭半块不能算支撑 |

| SP-M3 塔吊 | 固定四档/配置档位；质量、吊距、扫掠净空和交接边界限制；手持工具与控制器操作资格有据 | C 吊箱给 B 堵口；挪货为列车开路；运王者卸下的组件 | 报告“目标有物双方扣血但货物留原地”改成明确撞击动作或禁止落位，不隔空扣血 |
| SP-M4 桥下拆解 | 桥上/下双面，检修口和下层路径；敌人的持续拆解以回合阶段计，不遗留“6 拍” | 桥上保护、下层突入、从口向下推敌、临时支撑争时间 | 默认就显示桥底威胁；转镜头发现解法，而非发现此前隐藏的死因 |
| SP-M5 隧道/暗渠转运 | 入口/出口配对；容量、时长、目标预留；出口占用时等待或选合法备用口 | 快速跨区、从下层到后方、运物料 | 等待能撤回/改派，不永久软锁；大机不能缩小穿隧道 |
| SP-M6 高架跨区火力 | 全城坐标、边界射线、起止高度、射程与遮挡真实；高处加成不叠算 | A 清 B 防空，或用 B 高台支援 C 轨道 | 不能用“目标在邻区”无视距离和中间结构；两端预演一致 |

## 6. 空地体系：先让现有飞行有意义，再增加高度选择

分开三种状态：地面、低空悬浮、空中模式。现有 hover 属于低空，可越过某些单位/危险但受高墙与净空限制；不能因为资料写“会飞”就让它在没有接口的位置维修地面工位。

空中模式不是“在一切之上”。每个位置有可用飞行高度带与结构占用体积；桥底不能进入高空，桥上方若有足够空域则能飞过。实体屋盖挡向下攻击，塔吊臂改变飞行走廊。这样才不与 3D 结构矛盾。

### 武器与对象层的矩阵

| 武器/效果 | 地面/悬浮 | 空中 | 约束 |
|---|---|---|---|
| 拳/钻/顶推 | 接触范围内可用 | 默认不能 | 俯冲是独立带落位的动作，不能借“拳很大”隐含对空 |
| 光束/双肩炮 | 射线通畅可用 | 装备声明对空且炮架仰角/射线合法 | 对空是挂载资格，不给所有旧枪自动升级 |
| 爆破/抛射/导弹 | 按范围与遮挡 | 需对空标签或追踪弹 | 引爆高度与范围明确，不能用地面十字直接打所有层 |
| 防空武器 | 本型不能对地 | 对空有固定伤害收益 | 地面单位可压制；若有警戒反应，范围、次数和触发条件提前显示 |
| 拘束/牵引 | 按质量可作用 | 专门对空绳索/干扰可迫降 | 普通拘束索不自动变成万能防空；迫降落点与伤害提前可见 |
| 墙/护盾 | 挡住相应移动/射线/伤害 | 墙不凭空延伸上天，罩体按高度覆盖 | 依结构体积，不按敌我决定穿不穿 |

### 报告七类空对地动作全部有处理

1. **俯冲：** 先确定合法着陆脚印和攻击接触，再扣移动/主行动；落地后身份改变。被吊着的机体不天然获得自主俯冲能力，需专门协作动作。
2. **投弹：** 条形/十字形按挂载定义；桥底被盖住就打不到，影子和爆心高度能看清。
3. **导弹覆盖：** 雷翎标定跟踪与歌翼震荡散布不同，目标、弹道、范围和友伤都预演。
4. **扫射：** 沿合法移动航线触发指定地面格，路线就是攻击形状；不再额外获得一次免费完整移动。
5. **空中撞击/迫降：** 推向障碍或失去飞行能力时进入降落求解；找不到完整落位则按坠毁/失能规则处理，不瞬移到最近安全格。
6. **空中抓取/投送：** 质量与吊点、负载形态、乘员脚印、卸载净空同时验证；不能隔空操作另一战场控制柜。
7. **观测：** 帮助已声明的武器获得一次射程/锁定收益，不与高地重复；真实遮挡不因观测而消失。

首关王者/雷翎飞行使用既定移动资格，无单独高低空切换费用；转区按07消耗主行动并清零余移，到达不返行动。全量S06才验证高低空起降与燃料费用，未完成前不得套在首关可达范围上。

防空警戒若采用，是公开的反应事件：起飞/进入射界之前就画出预计受击，不把它藏在敌方阶段以外。烟雾的射击阻断与强风的禁停分开；烟作用有高度体积，不把“烟不能开火”和“烟不能站”写成同一规则。燃料系统单独试验，只有能产生补给/路线取舍且不让玩家多做无意义起降才纳入默认版本。

## 7. 视角、拾取与遮挡

保留 Ctrl+鼠标自由操作，增加四向吸附、两档俯仰和恢复视角。悬停被建筑挡住的对象时局部透视；检查桥下时切到明确层面；正常状态不全场半透明。层标记、被挡轮廓和敌方落点帮助定位，不能靠反复转镜头寻找敌人。

多层选择先用当前可见结构面，悬停给层名；需要穿层时用清楚的层切换/循环对象键，不能默默选到头顶另一个目标。触控方案保留长按详情、拖动探索、双指镜头作为后续输入适配；它在完整计划中有测试项，不要求这次为了手机重写桌面鼠标语言。

## 8. 三套完整验证任务

| 任务 | 主要检验 | 完成要求 |
