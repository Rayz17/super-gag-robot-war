## 1. 行动预算必须一句话讲清楚

<!-- PLAN_FIGURE_END -->


本次以现有逐机回合作为基线：**一台机体每回合有一份移动额度和一次主行动，玩家自己选择各机的先后。** 移动格数不是攻击拍数，动画播放几秒也不消耗额外行动。

| 状态/动作 | 费用与后果 | 棋盘表达 |
|---|---|---|
| 移动 | 路线实际地形成本扣移动；可分段，主行动后仍可花剩余移动，除非该动作明确锁定站位 | 路线＋余格；主行动已用与仍可移动是两个图标 |
| 普通主行动 | 扣一次主行动；弹药、备件等只在成功提交时扣 | 技能旁显示代价，行动后收起选招，不误标完全待机 |
| 蓄力 | 本回合花主行动并扣物资，跨过指定敌方阶段后就绪；下回合释放再花主行动，不重复扣物资 | “本轮准备 → 下轮可释放”，保留完整炮线/扇面与锁定方式 |
| 持续支撑/作业 | 开始占主行动并锁位；按明确结算阶段累计进度；中断条件公开 | 承重线、工具动作、进度刻度；离开前预览会失去的支撑 |
| 解除持续动作 | 本轮按合同消耗主行动；不回溯已经发生的损伤。UI 先展示解除的后果 | “解除后桥将失去支撑”等具体因果，不泛称取消 |
| 跨区 | 本关地面跨过当前敌方/环境，在本轮抵达阶段到；飞行当下到；均耗主行动并清余移动，下一轮刷新 | 出发—在途—抵达三态；目标区显示预留位置 |

这是保留现有预算关系后的明确化，不能把旧版“6 拍”直接显示成“6 回合”。所有旧动作迁移时逐一登记 `立即 / 准备至下一轮 / 持续作业 / 运输在途`，持续时间写成结算阶段数量。释放失败应说明锁定目标、射线或接口出了什么问题，不能让玩家再点一次猜。

移动额度返还、抢拍、额外射击都必须是装备或人物能力中明确的例外。数值倍率和显示时间不能暗中创造额外行动。

### 对象由属性决定可受什么影响

机体、敌人、护送车、设施和可搬运货物共享可组合属性：占地、质量、承重方式、耐久、护盾、装甲、阵营、保全身份、可移动性、可燃性、导电性、接口、供能关系。不能仅以 `ally/enemy` 推断是否允许修理或施盾；敌对市政工机可以同时有“必须保全”的身份。

| 通用效果 | 关键参数 | 不能混淆的地方 |
|---|---|---|
| 伤害 | 接触/射线/爆破；命中形状；遮挡；护甲/护盾顺序；友伤 | 打中、伤害为零、打空是三个结果 |
| 位移 | 推/拉/侧移；方向；距离；力量阈值；完整占地；逐步碰撞 | 力量不是推距；重物不能随意被轻型拳击推出两格 |
| 拘束 | 限制移动/转向的具体范围；持续阶段；可解除条件 | 锁步不等于停火；若攻击要求接触而因此失效，另显示这个因果 |
| 吊运 | 拾取范围、载荷质量、投放范围、路径净空、落点承重 | 先选载荷再选落点，不能画成一格推箭头 |
| 造物 | 产物类型、占地、耐久、承重、遮挡、存续期限 | 不得在占用格/无支撑格凭空生成；到期移除也要处理上面的物体 |
| 修复/临时支撑 | 修复上限、备件、接口；临时耐久单独记录 | 不把临时补强写成真修满后突然扣回旧血量 |
| 护盾/防护 | 护盾量、影响对象/范围、阻挡哪些效果 | 默认按伤害点数吸收；盾只挡伤害时仍可能被推落；这个风险必须显示 |
| 标定/干扰 | 对哪一种防御或承诺有效、谁消耗、到何时 | 不能写成泛化的“取消敌人行动” |
| 变形/卸装 | 新占地、净空、移动方式、武器启用、遗留部件 | 切形态不是攻击；不能变到其他单位或桥墩里面 |
| 操作接口 | 工具资格、邻接、供电、权限、持续时间 | “有手能按开关”与“有焊具能修桥”分开；任务提供接口而非免费技能 |

普通盾、维修、推拉、爆破等按对象属性作用，敌我同理；特殊限制写进效果合同并在悬停中给出原因。保护敌人挡一次连爆、拉走友军、用墙改变炮线都应该自然成立，不靠专门的组合技按钮。

### 一份结果驱动四种表达

统一链路：`当前状态 → 校验/走近求解 → 模拟命令 → 有来源的事件与状态变化 → 棋盘预演 / 执行动画 / 回看 / 结算`。

事件至少带有发起者、对象、所在战场与格子、阶段、前后值、父事件、原因、规则版本。效果序列必须显式：例如“直接伤害→推移→碰撞→支撑变化→坠落→环境连锁”。生成的新事件按稳定顺序排队，每个触发点有处理标识，避免油火、电容、支撑相互触发成无限循环。

- 2×2 单位被同一个爆心覆盖多个格时，默认一次受伤；双炮两条独立射线是否各中一次写在武器合同中。不能按遍历了几个格偷偷多扣血。
- 碰撞、反弹、护盾与推移顺序用小局面测试；不是把每招都强行改成同一个顺序。
- 装饰弹壳与焦痕不占格；规则残骸有占地与可清理属性，显示完全不同的落点标识。
- 事件排序不能用显示名称或对象 id 字母序决定玩法。重命名和调换数据顺序后结果应相同。
- 改模块、换装备、释放蓄力、转动台座后，卡片、预演和演出使用最终解析的合同，不能读各自的旧字段。

## 3. 地形与状态不是单独的技能清单

| 盘面元素 | 共同规则 | 能产生的组合 | 必须画出的后果 |
|---|---|---|---|
| 深渠/坑洞 | 完整占地失去支撑；地面、涉水、悬浮、空中分别判定 | 推落、架桥、吊救、断支撑 | 落点轮廓、失能/坠毁符号及保全损失 |
| 油/火 | 满足点火类型才燃烧，连片范围与蔓延阶段明确 | 爆破引燃、消防隔火、敌人误点火 | 燃烧面＋发生时刻；不能把一簇微粒当规则区 |
| 积水/电弧 | 涉水成本与供电状态分开；导电规则按连通区域配置 | 切电救援、诱导导电伤害 | 通电连接与下个环境阶段预计伤害 |
| 护盾/装甲/标定 | 固定减免顺序；绕过的是哪种保护、是否消耗标记都明确 | 给敌人盾保全、标定再破甲、挡连爆 | 预计消耗的护盾量、实际扣血与取消的保护来源 |
| 烟/遮挡/掩体 | 每种效果明确阻挡移动、视线还是武器；烟不等于实体墙 | 改射线、保护工位、迫使敌人换发布前计划 | 被挡的第一位置；有效/无效射线分段 |
| 输送轨/旋转台 | 在规定阶段搬运或旋转对象，按占地、净空和方向绑定计算 | 移开架设炮、改变敌人方向、送料 | 机构动作后每个对象的位置、朝向和保留攻击 |
| 电容/易爆设施 | 伤害阈值、爆区与二次触发一次性标记 | 借刀引爆、移开友军、连锁击杀 | 连锁编号与受影响对象；不是只写“连爆×2” |
| 增援口 | 提前公示到达轮次、数量和格子；堵口代价由敌种配置 | 封口、推敌堵口、保留安全通道 | 本轮将入场与已经入场分开；被挡后会怎样提前显示 |

这些效果先在小型规则场景验证，再配置到战役里。并非要求一张图同时铺满所有地形，也不把完全安全的空格消灭；安全站位是有价值的选择。

## 4. 敌人要制造问题，但不能事后改题

发布意图前，AI 评估合法路径、真实命中、角色目标、危险、友伤和环境收益。发布后冻结计划，玩家看见的顺位、路径和锁定方式成为承诺。不能因为玩家推开它，就重新追踪到桥边补一刀。

| 意图绑定 | 被移位后怎样 | 预览表达 |
|---|---|---|
| 固定世界落点 | 仍攻击原格；是否需要从新位置可达由武器合同规定 | 原落点持续标注，阻挡/射程失败给原因 |
| 本体方向 | 从新位置沿承诺方向出手；台座携带旋转可转动本体方向 | 新旧轨迹叠加，误伤对象显现 |
| 持续接触 | 离开指定接口或失去资格即中止 | 接触线断开，任务进度停止/重置的规则说明 |
| 架设依赖 | 位移、断供或破坏支座中断 | 架设图标划掉，跨区落点同步取消 |

同一轮新进入的敌人不插队重排已经发布的编号；Boss/架设优先若采用，仅在下一次发布前按公开阶段规则排序。危险评分允许“为摧毁关键设施冒险”，不是把 AI 做成绝不走进任何可利用地形。

敌种组合按玩法区分：近战逼位、持续拆解、跨区架设、拖曳锁车、悬浮绕障、群体护卫、环境引爆、防空警戒；外形、步态、攻击方向和状态图标对应角色。前期一波只新增一个陌生规则，进阶再组合。被劫持市政工机保留身份标识，提供拘束、关停、断开控制或安全挪移等非致死解法。

**常态是光标自由探索，选中后默认移动。** 不用先打开“移动菜单”，也不要求到处点击才能知道对象信息。

| 当前状态 | 光标移动 | 左键 | 右键 / Esc |
|---|---|---|---|
| 自由观察 | 对象简卡、敌方轨迹、地形特性随指针出现 | 点己方机体进入移动态；点其他对象固定检查卡 | 关闭固定卡 |
| 己方已选 | 可达边界、绿色路径、落点虚影实时更新 | 合法格直接移动；点其他己方直接切换 | 退出选择 |
| 技能瞄准 | 合法目标、自动走近路线、完整后果随指针更新 | 无额外风险时点击目标执行；有误伤/致败等风险才确认 | 退回该机移动态 |
| 吊运等两段动作 | 先显示可抓对象，锁定后显示合法落点 | 选载荷→选落点，第二次才提交，之前不扣资源 | 退一层，不撤回无关操作 |
| 风险确认 | 留住影响对象与预计损失，棋盘继续可读 | 明确确认；Enter 等价 | 返回瞄准 |
| 敌方播放 | 可暂停、快进、跳过；检查已有事件 | 控制播放，不再发送玩家命令 | 关闭解释卡，不意外跳过整个阶段 |

这里**调整报告 O8 的两次点击默认确认**：报告记录了目前“准备→确认”可以运行，但用户反复明确要求减少点击。普通安全命令采用“悬停预演→一次点击提交”；只保留有实际必要的风险确认和两段参数选择。

Ctrl+鼠标是独立相机手势：按下 Ctrl+左/右键开始拖动时就占用这一整段手势，直到鼠标释放。即使中途松开 Ctrl，也不能在鼠标抬起时补发移动命令。Ctrl+滚轮缩放；UI 滚动与场景缩放分开。四个方位吸附和恢复镜头是补充，不取消已经要求保留的自由相机操作。

快捷键统一列于设置：1–4 选当前机技能，Q/E 循环可行动机，F1–F3 切区，I 按住详情，Z 撤移动，Enter 确认当前风险弹窗，Space 只负责明确标注的阶段动作。**不再让“按住 Space 预演”和“按 Space 结束回合”竞争。** 回合末预测随面板常驻摘要展示，详情用按钮/独立可绑定键。

## 6. 合法目标与走近使用同一个求解

移动、攻击、维修、支撑、控制柜、调度、吊运均走相同入口：先检查能力与资源，再找合法出手位置和路线，最后模拟结果。

- 玩家点目标时，自动选择满足当前意图的最小成本合法出手位置，并显示路线；同成本采用稳定且尽量不改朝向的选择。
- 对 2×2 机体按完整脚印与扫过的空间求路。飞越单位与能否落位是两种检查；不能在目标格安全就穿过高墙。
- 默认绕开障碍。可用途经点调整路线，但不强迫每格点击；备选路线存在时不要只给一条固定轴向路线。
- 无合法方案时显示真实原因：“差 1 格移动”“吊装载荷超重”“右后占地没有支撑”“操作需要焊具”“对岸无空闲交接位置”。不能统一写“先移动”。
- 自动走近加技能构成一个命令。最后一步验证失败时不能留下“已经走半路、技能没发、行动也扣了”的状态。
- 普通移动动画按路线连续跑/滑行；直段合并。有障碍才绕，转弯按占地留足余量。规则仍保留逐格费用与途中触发点，不能为做直线动画穿过危险格或免费抄近路。

## 7. HUD 分工与棋盘标记

| 位置/时机 | 显示什么 | 应该移走什么 |
|---|---|---|
| 顶部 | 当前回合、城防及预计变化、A/B/C 各一条紧急状态、全城入口 | 无解释的 0/2、设施英文编号堆叠、长期无效按钮 |
| 当前任务角标 | 此刻最关键的阻塞条件；点它定位实物 | 整段剧情和全部任务规则 |
| 底部 | 当前区小队头像＋移动/主行动状态；其他区有剩余行动的小徽标 | 全身图缩成邮票、每台机重复长文字 |
| 选中时 | 2–4 个主要招式；特殊现场接口靠对象呈现 | 固定展开所有工具、所有二级菜单 |
| 悬停时 | 名称、关键特性、现在可做什么；I 展开详细规则 | 常驻的大块百科文字 |
| 瞄准时棋盘 | 闪烁扣血段、护盾量、推移箭头、落点虚影、碰撞图标、取消的威胁 | 把所有结果塞到远处右面板 |
| 瞄准时短卡 | “桥来袭伤害 5→2；市政保全不变”；展开看来源 | 本招、下一敌方阶段、下一轮威胁混成一个扣血数字 |
| 回合结束 | 实际变化、未解问题、下轮已公示增援；可定位回放 | 没有来源的总损失和立即覆盖棋盘的失败大屏 |

显示优先级：当前操作直接后果 > 会致败的远处事件 > 本轮其他威胁 > 装饰信息。血条只对受影响、受损、选中/悬停单位突出；敌方顺位始终可找到，但不和建筑编号用同一种圆点。

白鸢的基础后果预演默认工作，免费且不需要开“高级联合预演”。保存并比较两套候选方案同样免费、不限次，不占精神槽；不能把读懂规则的能力当成消耗品。未公布的未来敌意仍然未知，已承诺的跨回合事件才进入条件分支。

## 8. 撤回、播放、性能

移动撤回仅限未引发不可逆效果且未被其他命令依赖的移动。回合重置恢复整份回合初快照，包括增援随机种子、资源、链路、人物费用和事件序列；不能只搬回模型。执行后退款式“精神撤回”与普通撤移动分开设计。

敌方按有意义的动作分段播放，同一爆炸链仍是一件事；不把每一个小粒子变成独立暂停。本关普通段43帧动作+12帧停留，跨区加10帧定位；结构失效72帧动作+48帧停留，长招按08自身帧表。快进统一倍率，跳过直接同步同一终态后给小结；致败一击保留定位和回看入口。

性能目标是制作验收预算，尚非实测成绩：RMBP 目标分辨率下普通悬停即时反馈 p95≤50ms、选择到范围出现 p95≤80ms；超预算则先缓存可达区、预演基线与贴图，按状态版本失效，技能小舞台只在打开时播放。鼠标快速划过十个格子时，旧异步结果不得覆盖新格子；动画期间可观察和选择下一对象，提交按状态版本验证，不能偷偷缓存过期攻击。

这些目标与规则准确性一起验收。不能为了快而显示一条尚未验证、实际上走不到的绿色路线。
