# 公式台 v11.1：膝踝修正

2026-09-29 · 根据用户四张截图修正；视觉满意度待重新试玩。

问题不限于回旋踢：旧拳王抱架、无牌抱架、无牌踢击足部和拳王肋击后腿，都存在关节方向错误。旧检查只覆盖了部分踢击阶段，未能发现共用抱架和源动画重定向中的问题。

## 根因与改动

- **大腿与小腿没有共用转轴。** 原先分别把骨骼指向目标位置，却保留了不同的轴向扭转。修正前两机抱架后膝的轴向差分别约 56°、76°；拳王肋击后膝还出现约 −68° 的反向屈伸。现在使用同一个膝关节铰链平面构建上下腿姿态。
- **膝盖朝向取错了。** 原先使用髋到膝的水平投影作为求解方向，会让后腿膝盖朝反。现在从完整髋—膝—踝三点求出膝盖相对腿轴的偏移，保留高度分量。
- **回旋踢的脚掌翻了 180°。** 足部坐标系叉乘顺序写反，腿的关节中心即使正常，脚和踝甲仍会反转。已改正，并重新约束脚掌随小腿转动时的内外翻和屈伸。
- **修正覆盖整套动作。** 两台机体的抱架、走路、拳击、踢击、受击、收招和混合过渡都重新烘焙。正蹬沿用原来的出腿路线；身体和髋部回旋编排继续保留。

此次不修改命中、伤害、费用、时序与反击判定。拳、掌、手刀及真实接拳反击仍沿用现有手部驱动。
