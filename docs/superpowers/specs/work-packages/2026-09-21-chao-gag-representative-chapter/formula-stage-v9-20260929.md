# 公式台木桶街 v9：双机体术试招与战场材质

制作时间：2026-09-28 至 09-29。状态：可运行的 Candidate，待用户试玩评价。

无牌一号与旧拳王现在可以在独立双机试招界面里演示快拳、踏步冲拳、提膝正蹬、转髋回旋踢、双掌气功波和天冲拳。战斗地图右上角新增“体术试招”，也可以从项目根目录的 `公式台-体术试招.command` 直接打开。Esc 返回进入前的战斗状态。

## 可以直接比较什么

按 1–6 或点击招式立即试打，Space 重播。界面可切换出招机体、命中／格挡／落空、正常速度／四分之一慢放、近景／战棋视角、特效开关。关掉特效仍应能分清出拳、蹬腿、转髋和双掌发波；慢放用来检查蓄力、接触和收招。

Blender 文件保留原 Meshy 网格与贴图，新增踢技和发波动画，并重做八个既有招式的关键姿态、骨盆移动和支撑腿。气功波有聚能、离手、飞行、命中四段；拳脚轨迹跟随骨骼；命中与格挡有不同反馈，落空不伪造命中闪光。试招的拳脚接触点已与目标表面校准，而非仅凭结算时刻播放爆点。

**已接回实际战斗：** 两台机体的八种既有动作片段，以及既有拳招的轨迹、格挡／命中反馈。**只在试招界面开放：** 新增正蹬、回旋踢和气功波，尚未改变现有攻击、伤害、协作、行动顺序或角色机设。这轮先检验呈现是否成立，再据机体特点决定正式技能。

## 战场与界面的可见变化

地面从低对比灰蓝改为较暖的工业灰，重新绘制板缝、边缘倒角、螺栓与外围警示标线；细节按世界坐标计算，避免把小块贴图放大。保留规划遮罩、路线与威胁标记，中央不堆装饰。

机体暗部适度提起，白色装甲限制过曝；远距降低细碎法线和纹理噪点，近景保留细节。建筑仍使用已制作的机甲工业场景。HUD 用暖白文字、薄暖色边线、深蓝底和朱红执行按钮，向前场的暖白／深蓝／朱红关系靠拢。这不是全部场景的重新绘制；当前试招台本身也是用于对照动作的简洁场地。

## 验证和保留版本

- 双机试招 48 项检查：动作片段、支撑脚、十个拳脚接触点、退出后的原战斗状态。最大接触误差约 0.764 个世界单位，机体高度为 16–17 单位；这是制作误差检查，不是游戏命中判定。
- 原有骨架与动作回归 178 项、部署／推演／执行交互 31 项、战斗 UI 与执行回归 37 项均通过。详情保存在 `artifacts/formulas/production-lab-v1/qa/stage-art-v9-20260928/`。
- 原生窗口实际点过慢放、正蹬、换机体、发波、格挡、落空、战棋视角；随后 Esc 回图，点选无牌、接拳反击并执行，耐久和剩余行动发生结算变化，切到下一台机体。对应 journal 已保存为 `native-input-session.jsonl`。这段是输入与状态衔接验证，不是整局胜利证明。
- 上一版 v8 的 56 个脚本／着色器及构建包已冻结，并核对还原资源路径与隔离类名后的哈希。根目录 `公式台-木桶街-上一版v8.command` 可对照，其他旧入口保留。

演示短片 `martial-v9.mp4` 是运行时动作捕获，展示正常速度的六段动作，不代表玩家完成了一局战斗。整套流派差异、生产级动作质量、音效层次和参考作品级的整体美术仍不能由这些检查宣告完成；本轮交付的是可以直接上手比较的动作与材质改进。
