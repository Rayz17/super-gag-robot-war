# 木桶街 v11.4：多路线与同拍抢格

2026-10-01。P 练兵场候选修复；Q 连续章节、正式 Reader 与 Canon 状态不变。

玩家在旧拳王侧袭和无牌绕行时遇到的问题已经从本次试玩 journal 重放。修复后，点选同一落点可以切换不同走法；自动靠近、团队就位和“修正落点 / 接招时机”也会检查完整路线，不再只采用 BFS 为终点保存的第一条路线。不会把挡住别人但自己的拳落空判为攻击成功。

入口：[整个公式台](../../../../../公式台.command)，其中 P 为 v11.4；也可用[木桶街入口](../../../../../公式台-木桶街.command)。

## 可操作的变化

- 点地面选择移动终点，默认优先能到达、能完成所选动作且不需要队友让位的走法。
- “换路 1/2”等按钮保持招式、目标与终点，只切换路径；地图即时展示另一条路线，U 可撤回。编辑路线不消耗行动、不提前挪动真实机体。
- “修正落点 / 接招时机”保留所选招式与目标，检查可达位置、不同走法、拳向与真实推位依赖；没有有效安排就继续提示失败，不暗换成更强的招。
- 冲突预告注明“第几拍、与谁争哪一格、双方停步”；时间轴加入实际冲突的对方，即使它不是本次攻击目标。停步后显示“留在原格”，真实落空显示“空挥”。
- 已知无法产生所选动作效果的安排仍需修正才可执行。仅部分公开拳路能成功的安排继续作为条件性选择，不伪装成已确定结果。

## 结算规则

每格移动占一拍，同拍先处理移动，再共同出手。敌我争同一空格或迎面对换时，双方留在原格，后续路线停止；出手仍按所选招式的时机检查实际位置。拦住移动不自动取消已经安排的拳，推离未出手者才可能打断。友机让位和合法换位沿用已有规则。

本次没有暗加速度优先级、随机先后或把同拍伤害改成逐个结算。逐机与团队原有的时间组织差异仍保留，不能把本次修复说成两种模式已经统一。
