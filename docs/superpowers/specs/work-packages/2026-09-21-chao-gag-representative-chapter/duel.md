## 打开与操作

Finder 双击 [启动师徒对练](../../../../../scripts/run_c02_duel_candidate.command)。也可在终端运行：

```sh
"/Users/rayz/Documents/超gag机器人大战/scripts/run_c02_duel_candidate.command"
```

[实机短录像](../../../../../artifacts/c02_duel/runtime/duel-session.mp4) · [重拳接触](../../../../../artifacts/c02_duel/runtime/05-heavy-contact.png) · [击倒压制](../../../../../artifacts/c02_duel/runtime/10-pin-count.png)

1. 推进开场四句对白，选择招式，再点地图落点。无牌每次能走三格；开侧推能多走两格，但不能穿过旧拳王。
2. 看右侧①地图落点、②所选招式、③对手回应，以及耐久、能量、得分或危险。地图路径连接当前位置与金色①落点；红格是旧拳王已经亮出的重拳方向。
3. 选择“执行本轮”后，无牌执行，对手接着行动，随后交还地图控制。上轮效果持续显示，H 可查看各轮。完整和快速演出使用同一规则。

| 输入 | 操作 |
|---|---|
| 1 / 2 / 3 / 4 | 直拳（对方倒地后为压制）/ 天冲拳 / 防守 / 移动或待机 |
| 方向键或地图点击 | 选择落点 |
| B / Enter | 开关侧推 / 确认行动或推进对白 |
| Esc / 右键 | 行动前取消，不消耗资源 |
| Space / Esc | 动作中跳过这一轮演出，包括对手行动 |
| Q / E、滚轮、F | 转镜头、缩放、恢复全场 |
| V / M / R | 切换演出速度 / 声音 / 重新对练 |
| H / Esc | 空闲时打开本局回顾 / 关闭回顾 |

修订版开始将操作保存到 Godot 用户目录下的 `candidate/c02_duel/logs/`；H 页底部显示实际文件路径。记录区分预览、提交与真实事件，重试另开局号；不采集桌面或其他应用。旧版没有持久记录，此功能不能补回之前两局。

## 已落地的规则

- 无牌耐久 18、能量 18；旧拳王耐久 24。侧推共两次，每次 4 EN；即使只走近处，打开侧推也要付费，预测会显示。
- 直拳 4 伤害、推一格、免费。天冲拳 9 伤害、推两格、6 EN；必须本体实际承受一次重拳伤害，返劲只保留到下一次行动结束。
- 防守 2 EN：轻拳不掉耐久；重拳仍受 4 伤害，但不后退。移动／待机免费，正常承伤，不能当免费防守。
- 旧拳王轻拳会追近至多三格，命中为 3 伤害；重拳预告两格范围，7 伤害、推一格。重拳不临时改向：移出范围会落空，先把他击退会打断。
- 推出场外得分。耐久归零只是倒地；下一行动要走到相邻格并选择压制，五秒模拟时间完成后才得分。没有及时压制，对手会恢复 6 耐久起身。本件压制开始后没有额外解脱操作或 QTE，快演出和跳过仍保留相同规则结果。

两种胜法都可以实际完成。边线打法要花能量接拳、绕位；相比已复现的边线路线，普通拳路线行动数更多、会承受轻拳，但不依赖天冲拳。中场加入天冲拳的复现路线却比纯直拳多一次行动、少 1 耐久与 10 EN；合法路线存在不代表战术差异好玩。当前敌方规律固定，不能据此推定正式比赛 AI 已完成。

- 失败：侧推到 (4,0) 选择待机，再原地待机。第二回合被重拳推出界，旧拳王得分。

## 制作与验证范围

旧拳王为本次 Blender 制作的 17 米可动造型候选；无牌复用上一件的 16 米模型。两机各有 15 个运动节点，实时完成移动、出拳、受击、倒地和压制。沿用 Godot，未新增引擎或生产框架。短对白用于本场练习，不替换正式 Reader。

**修订前版本**曾通过桌面操作工具完成一条出界路线：鼠标推进对白与点招式，方向键选格，确认执行，再用 R 重置。返回地图时无牌 14 耐久、0 EN，旧拳王 15 耐久并位于界外。该历史记录不证明当前修订版通过桌面操作复核；详见[原桌面记录](../../../../../artifacts/c02_duel/desktop-input.md)。本次桌面工具超时，当前新增证据为原生渲染下的引擎内自动输入与截图。

检查记录见 [evidence.json](../../../../../artifacts/c02_duel/evidence.json) 和 [原生窗口输入结果](../../../../../artifacts/c02_duel/runtime/checks.json)。规则检查与引擎内自动鼠标／键盘检查分别记录；自动输入录像不能代替人工试玩或美术验收。接触距离检查针对指定胸部受击点，不等于完整网格碰撞或足部 IK。

本次实际使用 Blender → GLB → Godot，以及 Godot 录屏 → FFmpeg。Meshy 和 LibTV 仍保留在[制作方案](production.md)中，本件没有发起新生成任务、上传素材或消耗生成额度。两台可复用机体与实时动作已经有产物，后续工具应解决具体造型或镜头缺口。
