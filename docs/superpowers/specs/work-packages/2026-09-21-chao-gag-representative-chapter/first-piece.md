# 无牌一号出拳练习：首件交付

2026-09-21 · 独立试做入口 · 造型与玩法候选

现在可以操作无牌一号走到落点、选择直拳或天冲拳、查看击退预测，再确认出拳。完整演出从同一台地图机体切到近景，拳头接触训练靶，训练靶退到预测位置，镜头回到地图。**后续的[旧拳王师徒对练](duel.md)已经实现敌方回合与整场胜负**；本页记录原始靶场首件。

## 打开与操作

在 Finder 中双击 [启动出拳练习](../../../../../scripts/run_c02_one_punch_candidate.command)。本机使用已安装的 Godot 4.7，无需改动正式游戏入口。如果文档面板只显示脚本内容，可在终端运行：

```sh
"/Users/rayz/Documents/超gag机器人大战/scripts/run_c02_one_punch_candidate.command"
```

1. 点蓝框内的机体，或右侧「选择无牌一号」。
2. 点蓝色移动范围内、训练靶旁边的空格。查看金框和耐久、能量预测。
3. 选直拳或天冲拳，点「确认出拳」。边线用直拳推一格仍在场内，用天冲拳推两格才会出界。
4. 用右下方按钮切换边线、中场、障碍，再试同一招。中场不会因为播完特写就宣布胜利；障碍会截住击退。

方向键选格，Enter 确认；Esc / 右键取消预测；动作中 Space / Esc 跳过；R 重置；F1 / F2 / F3 切局面；Q / E 转镜头；滚轮缩放；M 静音。顶部可选完整或快速演出。当前只有键鼠经过输入检查，手柄映射未做实体手柄测试。

## 核验与实际发现

规则检查通过。原生 macOS Godot 窗口通过 `Input.parse_input_event` 注入鼠标、键盘事件，验证了选机、选格、按钮确认、取消不消耗、完整/快速/跳过同果、重复跳过不重复伤害，以及动作中重置。三个预设得到不同的实际终点。完整及快速结果均为 EN 12、目标耐久 3，边线目标落在 `(9, 3)`、中场 `(7, 3)`、障碍 `(6, 3)`。检查记录见 [checks.json](../../../../../artifacts/c02_one_punch/runtime/checks.json)。

逐帧发现并修正了过曝、击退目标离开特写画面、动作重置后移动框不恢复、弯腿后脚底悬空的问题。接触测量使用模型拳部节点与指定受击面的距离，脚底检查使用模型鞋底包围盒；它们不是任意网格碰撞、完整足部 IK 或用户手感认可的证明。

这次的 Godot Canon report / strict 检查通过。正式 Reader、生产阶段、默认启动场景没有因本件改变。检查通过不代表造型、故事或玩法被用户验收。

启动脚本已实际启动 Godot 进程，日志无错误。之后尝试通过桌面工具复核点击时，工具报告 Mac 已锁屏，因此没有完成桌面输入复核；未尝试绕过锁屏。上述通过记录均指引擎自动输入检查。

## 工具如何继续接

本件实际跑通的是 **Blender → GLB → Godot**；录屏来自 Godot 的电影输出，再用 FFmpeg 转 MP4。未新增 Meshy 或 LibTV 生成任务，也未消耗它们的生成额度。

Meshy 仍是后续明确造型后的初模来源；Blender 保留拆件、轴心、动作与风格整理。LibTV / 切片用于能保持首尾姿态一致的短特写，动作的命中、受击方向和落点继续由 Godot 实时呈现。本件不需要为了凑工具数量，把已经能实时执行的接触换成视频。
