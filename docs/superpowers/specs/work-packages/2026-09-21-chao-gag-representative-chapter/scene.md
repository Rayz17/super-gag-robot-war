# 先别叫招式名

创作候选 · 2026-09-21。取材于已验收的 C02E02 非计分指导战；以下为新的对白与演出试写，不替换 Reader。前情：万机馆急需比赛奖品中的转子，刚获半决赛资格的无牌一号借用了它的侧推。无牌一号接住重击时右拳会积起力量，却总迈不出随后那一步。次日半决赛，它将对阵旧拳王。

---

“先别叫招式名。”旧拳王说。

无牌一号把已经抬起的右拳放低了一点。

擂台外，胶价王正带人撤广告。长条横幅从半空垂下来，挡住他半张脸，上面还剩一行金字：冠军同款，荣耀预订。

“这条没用她的画。”他捏着横幅的一角，向白鸢解释。

白鸢把背面的订书钉拔下来，翻过来给他看。

胶价王沉默了一下。

“背面按赠品算的。”

“撤。”

他叫工人把另一头也解下来。金字拖过地面时，台上响了一声闷响。

无牌一号的左臂接住了旧拳王的直拳。脚底的尘土向后喷开，肩壳碰到后面的围绳。右拳又亮起来，光从几块不同颜色的护板之间漏出。

它低下头，盯着那只拳头。

旧拳王抽手，一掌贴在它胸口。

无牌一号坐到了地上。

裁判刚要举手，旧拳王摆了摆手。“练习。不记分。”

那只发亮的拳头搁在膝上，慢慢暗了。

“这回接住了。”无牌一号说。

“我也看见了。”

“还差什么？”

旧拳王用脚尖点点地板。“起来。”

台边的纪存伸出手，才想起自己够不到它。兜灯已经抱着工具包站起来。唐胶把包接过去，没让她往台上跑。

无牌一号左手撑地，试着起身。腰部发出一声短促的干响。它停了停，换了个角度，终于站稳。

旧拳王等它抬起头，又朝胸前出拳。

无牌一号两臂同时向里收。拳却没来，旧拳王的肩膀晃过眼前，脚下轻轻一绊，它又倒了。这一回先着地的是屁股，声音比上次响。

胶价王望向唐胶。

“你们这机保修还在吗？”

唐胶没回头。“你这台地板呢？”

胶价王赶紧看向接缝。

白鸢蹲在台边。她原想用笔记下出拳的位置，画到第二遍，把那一页翻了过去。无牌一号每次向后滑，鞋底总在同一个地方停住；拳头亮起来，它就盯着拳头看。

“我能站近一点吗？”她问裁判。

裁判指了指台边的黄线。她走到线后，收起笔。

“我刚才打到你了吗？”旧拳王问。

“没有。”

“那你接什么？”

无牌一号没有答。旧拳王也不等它编一个答案，向它伸出左手，掌心朝上。

“你打。”

无牌一号犹豫了一会儿，向前出了右拳。

旧拳王接住。厚重的掌指合拢，只向旁边让开一点，无牌一号整条胳膊便被带偏了。它急着追回右拳，左脚也跟过去，险些撞进对方怀里。

“别追手。”旧拳王松开它，“再来。”

第三次，无牌一号先朝旧拳王迈了一小步，左膝微屈，再送出右拳。

拳仍被拨开。它的左脚压住地板，胸口没有再追着手歪过去。两人之间仍隔着半条胳膊，它站住了。

旧拳王看了一眼那只脚。

台边的纪存刚张嘴，兜灯用胳膊撞了他一下。他把叫好咽回去。

第四次，旧拳王的重拳迎面打来。

无牌一号接住了。肩壳向后一沉，脚底擦过地板。右拳亮起的时候，它抬起头，旧拳王已经收住手，等在前面。

它向前挪了半步。

那团光颤了一下，散了。

无牌一号没有坐下。右拳停在两人之间，指节上冒着细烟。它看向自己的脚，又看向旧拳王。

“这次你没推我。”

“明天会推。”

旧拳王退开，让裁判检查它的拳面。兜灯终于能上台，先摸腰侧，再去看接缝。唐胶在台下问她找到了什么，她说左脚迟了。唐胶点点头，把原本拿出的扳手收回包里。

白鸢将刚才那页翻回来，在脚下补了一道短线。旧拳王走过时，她把纸递高了一点。

“这儿？”

它俯身看了看。“让它自己踩到。”

擂台另一边的工作人员抬起新计分板。无牌一号的名字在左，旧拳王在右。刚才一直放在一起的两把椅子，被裁判分别搬到了两角。

无牌一号看了很久。

“明天你还教吗？”

旧拳王走向写着自己名字的那一边。

“明天算分。”

胶价王拿着最后一截横幅回来，问能不能给这场指导战起个名字，印在明天的节目单上。

旧拳王指了指仍在给无牌一号检查的兜灯，让他先去旁边等。

无牌一号忽然叫住他。

“名字先空着。”

它低头看了看刚才站住的地方。

“明天再填。”
