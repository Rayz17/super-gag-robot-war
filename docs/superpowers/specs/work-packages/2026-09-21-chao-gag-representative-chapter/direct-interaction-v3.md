**版本比较更新：** 现在可从 [统一入口](version-comparison-review.md)启动五份独立封存版本，F10 返回换版。v3 改变了行动规则、情报与协作成本，属于局部交锋实验，不作为旧版的完整升级；具体缺项和下一步取舍见该页。

从项目根运行：

```sh
./scripts/run_c02_squad_direct_candidate.command
```

默认重装破阵；`--scenario=escape` 进入突围，`--scenario=encounter` 进入清场。使用独立日志目录，不重置 v2 对局。当前没有在 v3 界面重新接入人物能力、精神菜单、完整全队时间轴或章节对白，它是针对群战操作的对照件。

## 直接怎么操作

1. 点友机或 **Tab** 切换。每台每轮行动一次，已经行动的按钮变灰。
2. **WASD / 方向键** 让选中机体在可达范围试走，也可点一个地面终点。试走可撤销，不扣资源；**Esc / 右键** 回起点。镜头方向改变后，方向键仍按屏幕方向选相近格向。
3. 点敌机选目标；**X** 轮换目标。拳向自动对准，不再另外进入目标/朝向编辑模式。
4. **1–6** 或底部招式按钮立即出手。移动、出拳和当前标出的敌方行动共同执行。**Enter** 使用当前预览招式。
5. 合适位置会出现队友接应按钮。**F** 加入、轮换或取消；绿色连线指向代挡的友机或夹击的敌机。队友每轮一次、耗 1 体力，条件消失仍可能落空。

**Q/E** 旋转、**中键拖动**平移、**Alt＋中键**调俯仰和旋转、滚轮缩放，**Home** 复位。**F1** 操作说明，**F2** 镜头面板，**H** 交锋记录，**R** 重来。手柄方向键/A/B/X/Y/肩键有对应操作，尚未做真实手柄体验验收。

地图上的试走仍是预览：确认后会从真实起点呈现这次双方交锋，以保持移动途中能被击中的规则与画面一致。这段重复移动是否仍显得拖沓，是本版尚待真实试玩回答的问题。

## 这一版实际保留的策略

| 做法 | 条件与结果 | 代价或失效 |
|---|---|---|
| 硬打、侧击 | 原招式、朝向、正面装甲、推退与打断；侧后命中 +3 | 正面装甲仍挡伤害，长蓄势可能被先推开 |
| 虚晃后追打 | 当前响应的莽进对手实际抢拳并打空，留下破绽、挣气势；其他机体能利用窗口 | 沉稳、已识破、已出手、撤步被占或仍在扫击范围都可能失败 |
| 接应夹击 | 已在目标旁边的拳手机加入一次短拳；两个攻击独立结算，场上实际接触 | 额外耗 1 体力及本轮接应机会；目标被先推开时可能落空 |
| 馆守代挡 | 馆守与受保护者相邻，左臂拦下一次来袭并减伤 3 | 馆守承受余伤；关系断开不代挡；不补回已毁右前臂 |
| 突围 | 无牌到达出口可直接完成任务，不强制清场 | 无牌退出即失败，时限仍在整轮末检查 |

使用原有 `squad_rules.gd` 接触解析；新 `exchange_rules.gd` 只调度局部交锋、轮末结算和接应。`resolve` 新增默认开启的轮末结算参数，v2 调用不改行为。恢复、期限与窗口过期都只在整轮最后发生一次。

## 当前证据的含义

规则专项 31 项通过，原群战规则 34 项及机会窗口/非战斗契约 32 项回归通过。原生窗口测试覆盖键盘试走与取消、点地图落点、点可见机体、单次提交、镜头俯仰、三种窗口尺寸和返回控制。具体次数、源码哈希和录像以 [本版证据](../../../../../artifacts/c02_squad/v3/evidence.json)为准。

自动规则探测中，破阵硬打路线在第 4 轮完成、无牌剩 1 耐久；骗招路线在第 2 轮完成、无牌剩 28 耐久并使用天冲拳；突围路线在第 3 轮完成、无牌剩 14 耐久。探测器枚举当前公开行动并择优，这些结果只证明规则能够产生不同后果，**不能证明玩家会自然发现、不能当作平衡或好玩已经通过**。目前破阵场景仍明显偏爱骗招。

美术仍使用已有 Candidate 模型与动作。当前没有新调用 Meshy、Blender 或 LibTV，避免把交互验证与新资产生产捆在一起。关卡扩充、预测能力接回、新合击演出和正式美術需要在当前操作方向获得有效试玩反馈后按同一施工表推进。
