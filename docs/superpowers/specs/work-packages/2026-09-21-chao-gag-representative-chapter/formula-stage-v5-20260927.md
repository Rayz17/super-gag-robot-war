## 剧情与演出的变化

开场围绕三台机体怎么配合展开：旧拳王的“三机合一”玩笑、无牌追问馆守的绳索、白鸢提醒看脚下落点，随后让玩家实际走去查看速写、选择演练任务。剧情没有预先替玩家决定胜负。

保留既有绘制前场、简化地图人物、最新立绘和 Meshy 馆守资产。重要对白加入镜头取景与轻微推移；机体说话时切到场内的实际机体，人物走位在前场地图内完成。探索交互点有访问状态，进战斗有短过渡，战后继续读取这一次真正发生的胜负、接力、天冲拳事件。重来会清空本次演练记录，避免沿用上局台词条件。

战斗规划保留更多建筑轮廓，路线与威胁标记加入节奏变化；材质统一处理时保留模型原有的颜色贴图。射击补充发射端蓄能、传播光束与接触表现；实际命中、被遮挡、空打使用实际结算位置，不伪造命中特效。任务进度在执行期间持续显示。状态提示区分护卫、迎击、破绽、后手与必中。

## 规则与操作的变化

| 问题 | v5 的处理 |
|---|---|
| 已知空打仍消耗行动 | 预演和提交共用公开分支检查。确定无效时提示对应机体；“修正落点 / 接招时机”保留所选招式与目标。高级选项仍可明确保留这份试打计划，修改后须重新确认。 |
| 先位移、后手仍打旧位置 | 团队草案在整体模拟后重新校验接续关系；修正后再次检查。确实没有用途的模板动作显式退回原地休整，卡片注明原因，不声称已经形成合击。玩家自己编写的计划不会被悄悄替换。 |
| 不知道从谁开始安排配合 | 既可从馆守/拳王邀请后手，也可从无牌借势突击反向邀请制造破绽。两份指令共享真实位移条件，撤回可恢复邀请前的安排。 |
| 看时间却看不到未来状态 | 地图试演支持拖动完整时间；机体位置、出招、受击和队伍耐久随时间同步。退出试演恢复实战状态，不扣资源、不积累观察。 |
| 数值不好心算 | 真正规则改为小整数：无牌 6、旧拳王 7、馆守 9 耐久；普通近战 4、射手 3、重装目标 9。基础伤害以 1–3 为主，侧背/破绽增益为 1。不是只缩短血条显示。 |
| 等待几轮就看穿所有敌人 | 按具体敌机的已观察出手累积识招；未观察的敌机仍保留可能分支。精神预测、白鸢与纪存入口继续保留。 |
| 目标完成像是动作丢失 | 任务完成可以合法中止后续动作，检查器区分胜利收招与无效计划；完成态显示任务结果。 |

## 仍然存在的差距

这次落地了修订方案中的一部分。逐机交锋与团队执行仍使用不同长度的交换过程，虽然共享敌方轮首承诺与核心结算规则，尚未合并为完全相同的时间制度。已知失败现在会提示；“为什么没有协作邀请”的所有原因尚未做成完整的可交互关系图。

无牌、旧拳王与敌机仍有测试外壳，战斗场景的建筑细节、材质与二维前场的整体美术一致性仍不足。动作谱系与射击反馈得到补强，但并非所有招式、蓄能层级和 Buff 都已有独立的高质量动态表现。本轮没有重新制作整套机体、建筑和角色图集。后续美术判断应以实际连续试玩为准，不能用测试通过或新增特效代替。
