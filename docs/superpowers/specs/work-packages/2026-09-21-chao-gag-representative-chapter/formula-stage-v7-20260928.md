# 木桶街 v7：演武整备

2026-09-28。公式台当前可玩候选。打开项目根目录 `公式台-木桶街.command`；`公式台-木桶街-上一版v6.command` 保留本轮修改前的版本。

这次集中补上一轮明显欠账的场景材质和训练机呈现。v6 的机甲整备港布局继续使用，但屋顶反复铺贴造成的杂乱、训练机整身染色导致的塑料感、射击缺少真实发射结构和动作，都在运行时作了修改。

## 能直接看到的改变

**机库从重复贴片变成有用途的结构。** 深蓝散热翼、朱红天窗脊、冷白吊装顶板分别构成三组大体块。维修廊改为连续顶板，接缝、锁扣、天窗和涂装按结构放置。新绘制贴图补充表面细节，不承担虚假的立体轮廓。仍保持 23 米净空机库门、2.7 米人员门，以及 16／17／18 米主机体之间的比例。

**训练机分成可辨认的格斗与射击装备。** 四台训练机在现有 CC0 可动模型上重新制作硬表面附件：格斗机增加撞击护臂、拳面和肩部识别件；射击机增加线圈步枪、背部电容和肩部测距器。冷白装甲、深蓝骨架、金属关节和传感器分别处理，红、青用作局部识别，不再把整台机体染成一种颜色。近战和射击仍沿用已有战术规则；外形区别没有被虚报成新的技能系统。

**射击有自己的动作与接触语言。** 持枪架势、短促蓄能、枪口收束、发射后坐、受击火花连成同一过程。骨骼按实际目标瞄准，光束取真实枪口坐标，试演也使用同一套姿态。零伤害格挡改为青色防御弧和“格挡”，造成伤害时才画橙色冲击与命中火花。声音补充线圈上升音和出膛瞬态。

**既有流程继续接在公式台里。** 前置机体通讯、人物交谈、场地探索、任务选择、规划遮罩、协作邀请和战后分支没有另起一套入口。无牌、旧拳王、馆守与人物立绘继承已有成果。
