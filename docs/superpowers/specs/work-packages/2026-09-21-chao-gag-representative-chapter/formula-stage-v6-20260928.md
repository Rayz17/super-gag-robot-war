# 公式台木桶街 v6：机甲整备港与试斗平台

本版将剧情前场和格斗场重新放进超 GAG 的机甲世界：人的零件铺依附大型整备设施，16–18 米的机体有自己的库门、搬运设备和承重场地。保留木桶街共同整备、地方格斗与玩梗的气质，不把它改成通用军事基地。

**试玩**：根目录 `公式台-木桶街.command`。**对照**：`公式台-木桶街-上一版v5.command`。原 v4 和第 1–13 号入口仍在。

## Astra 场景项目与技能研究

实际阅读了 [Codex and Blender](https://github.com/danielsobrado/Codex-and-Blender) 的制作记录及代码组织，并查看其实际森林场景渲染。它提供可编辑 Blender 源文件、图像贴图、镜头检查和多轮迭代的组合范例。采用的是这套制作次序，不能据此推导“换 Astra 就自动有好审美”。

同时阅读 [create-3d-model skill](https://github.com/CheshireJCat/create-3d-model-skill) 的入口、视觉验证、Blender 工作流与灯光部分。本版据此补上可重建场景、真实尺度、材质检查和正反机位检查；不照搬写实 PBR 风格。未安装不必要的工具或运行第三方自治脚本。

工业部件来自 [Quaternius Modular Sci-Fi MegaKit](https://quaternius.com/packs/modularscifimegakit.html) 免费 Standard 子集。实际使用 18 类、114 个实例，许可证 CC0，原始包、构件清单及许可证均保留。建筑整体形状、布局、尺度、绘制贴面和配色由本项目重新制作。
