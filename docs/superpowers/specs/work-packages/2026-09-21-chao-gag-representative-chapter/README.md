## 1. 这次作出的设计决定

| 问题 | 本案选择 | 需要什么证据才改变 |
|---|---|---|
| 游戏到底卖什么 | 机器人文化冒险：认识、喜欢、招待、并肩、改演。故事和战斗都必须出现跨作品性格与玩法的碰撞 | 完整章中，玩家仍只记得制度说明和普通攻击，需要回修人物与改演方式 |
| 基础操作 | 各版独立比较。下一候选方向：逐台完成普通行动，协作时局部组织计划；保留读招、反制和人物能力 | v3 同时改了 UI 与行动规则，当前不足以归因。先做相同规则的交互比较，再决定保留哪种群战组织 |
| 特色机制 | 将旧案的“发动、让台、拆台”接到正常战斗动作上，保留具体名场面、改演和跨机协作 | 如果只是换了技能名称，就重做作用；如果迫使所有战斗按一套解法，就撤掉强制触发 |
| 战外循环 | 到地方游逛、与人相处、决定帮什么忙；把得到的人、模型、片子或改件带回万机馆，影响后面的生活和出击 | 支线没有可见回报、馆内只有列表时先补循环，不扩一套独立经营模拟 |
| 故事组织 | 全剧用八个大段组织旅行与冲突；每章集中讲少数人的一件事，群像通过再次见面累积 | 实际章节难以承载时调章节切分，不能直接把整个产品砍成固定小体量 |
| 美术与引擎 | Godot + 简化的三维机体/战场 + 二维人物；Blender 整理资产与镜头；Meshy 作为可替换的初模来源；LibTV 用在特定短镜头 | 同一台机、同一动作的资产试制与实机观察，证明三维清理成本或画风不成立时再换承载方式 |
| 创作组织 | 一名主笔负责事件和对白，一份玩法承载稿，一名集成负责人；只在完成可读/可玩对象后做针对性独立审阅 | 不以“评委数量更多”替代改善；证据改变哪个决定，只更新该处 |

这组选择不是“已经验证好玩”。它让下一步开发能够回答明确问题。此前缩到 18–24 话、8–10 台机、只留地球等建议已撤回；本案也不以旧稿中的另一组数量承诺全产品工期。

## 2. 游戏如何连成一体

一次普通旅行的过程是：**去一个值得看的地方 → 因为某个人或某台机想做一件事 → 亲自参与 → 获得战果与关系变化 → 带着新东西回馆 → 出发时拥有新的组合。**

在木桶街，这件事是借侧推让无牌一号参赛，得到能让万机馆继续走的转子。它又引出一台原本只配牺牲的配角、一个不肯让它轻易赢的师父、一位作品被擅用的画师，以及一家真实在维持旧机器的补件合作社。冠军、伙伴、旧片的新结局和启航发生在同一段经历里。

旅程由世界航图连接地区，地区是可走动的紧凑场景，馆内是反复回来的生活空间。主要通路当场可看见，不要求逐项清空图标才能读下一句对白。逛模型摊、摆收藏、看地方配音、私下见伙伴可自行选择；影响主线理解的事实在必经场景中出现。

万机馆承担三种长期回报：

- **人回来以后真的住进来。** 旧拳王可以在训练区再次出现，白鸢有拍摄和自己的来往，角色不会只变成可选头像。关系线通过后续相处改变，不靠一次合击奖励恋爱。
- **收藏能被看、摆、玩。** 模型先提供陈列和姿态的乐趣；不同版本的海报、译名和台词可以比较，不要求背 IP 知识过关。得到新改件应让某种战斗方案可行，而不是每件都增加通用百分比。
- **出击组合逐渐丰富。** 机体身份决定主要能力，少量改件改变用途。战前先选队伍、武器/改件和可选演出；整备不做抓点、支撑点、朝向、指令牌等多套配置的总和。

文化笑点允许只为好笑存在。不是每个重涂玩笑都要通向阴谋，每段看电影、逛展或约会都要产出任务。正因为人确实享受过这些，后面的损失才有分量。

## 3. 从开场到结尾的全剧组织

以下是对现有 C01–C04 与《27》v5 素材的**组织建议**，不是新一版全剧 Reader。八段是阅读与生产上的大段落，不是八关，也不限制最终章数。后半部事件仍属于候选素材。

| 大段 | 玩家正在追求什么 | 主要事件与反复回来的人 | 这一段应兑现的体验 |
|---|---|---|---|
| ① 把家开出去 | 让万机馆重新动起来，找到愿意同行的人 | C01 启航；C02 木桶街与旧拳王；C03 伙伴入馆；C04 工务城。纪存、兜灯、唐胶、无牌、白鸢逐渐形成日常 | 一臂机也能打出重击，配角能赢比赛；第一次上舰有生活，不急着解释世界总谜底 |
| ② 去看真正喜欢的东西 | 认识各地机器人文化，并想自己办一届百机祭 | 百相/黑城和米拉、艾达；星火乐园；罗莎琳与胶价王；地方配音、创作者、机器人格斗；拉维与莱拉 | 合体成功、喜欢的东西买到、地方梗玩得成立；恋爱有相处，主角有主动办事的欲望 |
| ③ 一起办成百机祭 | 把不相容的机群、版本和节目凑上同一舞台 | 三防线；索琳与伊玛妮；阿德里安实际帮助与冲突；红面具、阿岚、钢花；创作排练到正式百机祭 | 玩家此前带回的东西变成展会和出击组合；给一场真正完成的庆典留足空间，之后再迎敌 |
| ④ 去接还活着的人 | 找到被留下的主体，也找到父亲 | 未来追猎者和设施真相；爱丽丝被掳；分工解放；阿德里安下令毁存证；索琳枪杀已被控制的阿德里安；父亲重逢与会面决定 | 多机群共同打赢解放战；在成功之后承担亲人自己做过的事。枪杀不是全剧唯一高潮，也不是对玩家的爽点奖励 |
| ⑤a 留在地球 | 把解放所得变成住处、工作和防卫 | 钢花工厂从开张到分家，民用交付，地方机群与少年宿敌，白鸢的新片和关系生活 | 赢得工厂的战斗与真正开工分开；有自己的事业、地方与伙伴；失去的是共同生活的方式 |
| ⑤b 去远方接人 | 把仍在战争和长航中的人带回家 | 四个月到港、两个月接应、三个月归程；迟归、遗灯、电磁五虎、五兽、T 与陆衡、赤罡；归静先以错过一次见面出现 | 真正的宇宙规模、巨大合体和远征生活；成功接人，同时明白有人不愿或不能一起走 |
| ⑥ 回家与造出巨人 | 让归来者有地方生活，让喜欢的巨人真正可用 | 两路在港区相遇；当地生活与返乡承诺冲突；百相继续成长；万机馆人形试验的成功、事故、修复；天穹联装；馆外来客窗口 | 路线带回不同见闻和资源；完整的人形力量得到反复使用，不是一露面就收回；收藏回望玩家的趣味 |
| ⑦ 我们真的打赢了 | 打断敌人的外层维修、轨道转运与海岸供应 | 三个战区各自发挥；迟归/天盖王打穿构造；红白协同；百相与三旗舰对断冠；馆守 Z 新右臂；万机馆真正的巨人战 | 主力机群是战争主角，必杀和合体有实在战果；货船复航、轮休、演出补办，胜利持续数周 |
| ⑧ 胜利以后还怎样一起生活 | 阻止战友把别人变成筹码，也兑现自己的承诺 | 红面具与沈砺武装施压，索琳选择，伊玛妮拒绝；有限交战/全面内战；分舰自愿接合万机殿；归静逐步恢复差异；重新开馆 | 前面做成的民用生活和返航保障影响战争规模；赢得更强身体，不接管所有人；下一届百机祭仍值得期待 |

⑤有两条实际经历的航路，不能把没走的一路讲成主角已经参与。另一个决定“带父赴约/隐瞒失约”独立影响信任、父亲的地点与问责时间。四种组合沿途可以共用战场与大事件，但对白、缺席者、见闻和关系不强行汇成一样。最终有限冲突或全面炮战也不能只靠终盘一句选项抹掉前面的投入。

生产上为每段保留“最想做的事—玩成的一场事—带走的东西—下次见面”。文化场景、爱情和战斗会重复交叉。新的 IP 与机体按它能带来的人物关系、战斗用途、笑点或景观进入一章，不要求首次出场就交代完整年表，也不要求每一位都卷进二十七年前的旧案。

## 4. 剧情最需要改变的写法

《27》v5 已有大量可保留的真实事件：师徒比赛、米拉救出艾达却失去共同记忆、钢花分家、远征返乡、红白从默契到对决、万机馆获得巨体。问题在于梗概经常在事件后立即给出“它意味着什么”和“它不能意味着什么”，读者还没来得及在意，就又进入解释。

接下来写正式剧情时，每场先交付人正在做的事和对白；因果依据留在制作旁注。需要观众知道的证据，要变成当场听见、看见、被阻止或做出的选择。对白不负责替所有立场提前辩护。

**阿德里安与索琳不能只靠枪杀前一章补说明。** 建议采用以下几次具体出现；其中新增日常场面是提案，尚未写入正式故事：

| 提前出现的场面 | 观众先经历什么 | 留给后面的反差 |
|---|---|---|
| 索琳与朋友的一次小放映 | 投影主体挑片、调焦、与伊玛妮争一个地方配音；有自己的怪脾气，能使别人开心 | 后来等待的是这个人，不是一件价值未知的放映设备 |
| 阿德里安推进公共身体试用 | 他确实解决过人的困难，七海与他有现场协作和意见差异 | 七海后来失去的是帮助过自己的导师；观众可以同时反对他的命令 |
| 一次找旧朋友未果的探访 | 索琳按上次约好的方式等，得到“没有可辨认内容”的答复；她发现有人曾改过转移去向 | 追索是持续行动，枪杀前已经发生过希望和落空 |
| 解放行动前后的记录对照 | 公共纪念片的胜利、战后未停的控制、父亲的紧急保全与后续隐瞒、阿德里安后来的销毁命令分开呈现 | 四件事有不同时间与责任，不能用一个“大清噪”总词代替 |
| 已缴械后的移交现场 | 众人正在等待当事人回答，索琳看得见这件事，却决定开枪 | 后果落在具体人身上：谁失去证词、谁与她断交、谁仍救人却拒绝让她指挥 |

**不为“全剧要死人”临时增加死亡。** 先把已有死亡、失踪、无法恢复的记忆和生活写成读者能记住的对象，再判断还缺什么。死亡人数不等于情绪力度；现在阿德里安段落不足的问题也不会靠一句“其实铺垫过”消失。完整的新场景需要在相关章编写时冷读检验，本包不会宣称已修好整部故事。

角色最低记忆点应来自一次独有的行为：旧拳王教完还认真赢人；胶价王算账却真正赔钱救场；赵梅拿起电话说自己名字；白鸢保护作品也愿意把片拍完。机魂与人类都可以有爱欲、嫉妒、笨拙和兴趣，不能只分配政治观点。

## 5. 为什么先用木桶街，以及它测不到什么

它集中包含本项目最有价值的组合：模型生意的笑话、被砍掉的最终回、配角与主角重新选择、机体人格、师徒真打、漂亮的必杀、集体救场、以及把伙伴带回馆。无需新建一个无关示范世界。

采用 C02E01–E05 的完整事件链；半决赛无牌胜旧拳王，决赛从 0∶2 到 3∶2，旧片加演之后才发生事故。完全版王者很强，拆外装是救场中的决定，随后仍保留自己的完整机体身份。旧拳王和无牌登舰，王者与地方机群留下。

**一项明确的待评阅改编差异：** 首次学成天冲拳仍放在半决赛，但与“必须用它打出最后一分”解除绑定。先用一段短教学演出完成首次成功，再让玩家自由打赢后续比赛；所有合法得分都算数。原 Reader 中天冲拳直接决胜的版本保留为来源，本包没有修改它。这样会改变首次成功与赢下比赛重合的戏剧节奏，需要连贯观看后判断，不能隐瞒这项取舍。

完整新编游戏呈现暂按 **约 50–65 分钟核心流程**设计：正文/演出 19–25 分钟，三段比赛操作 22–27 分钟，救场与收束操作 6–8 分钟，短转场 3–5 分钟；自由逛摊、看完整旧片、练习另计。它是章节切分的估算，不是整部容量承诺。五话现有 Reader 约 3.5 万字，不能原封不动朗读后仍声称只有半小时。本案提出删去重复说明、合并演出承载，保留事件和必要人物时刻；如关键情绪必须更长，就拆成有完整收束的上下篇，而不是加速台词。

这一章的单挑测师徒与招式，**不能代表多人 SRPG**。同批中型机资产另设一场不计剧情的 3 对 4 小队演练，复用擂台场景，检验强攻、诱敌反打、侧翼与突围的收益。它不产生新的故事赛果，不需要另写一章。当前实现与对照结果在 [squad-combat.md](squad-combat.md)，替代早期纸面数值和交替回合案。

美术试制先做**无牌一号的一次完整出拳**：地图上的起点、近景姿态、接触、受击者移动、地图落点连起来。受击端先用明确标注的靶模型。只有这次动作成立，才扩到旧拳王、王者，以及小队演练需要的馆守 Z 动作。先生成十台新机，再为每台修十个动作，会重演现在的成本问题。

当前优先冻结的是“这一章要让玩家经历什么”，不是一张永不许改的技术表。后续发现某工具不好用，替换其生产环节；发现整场战斗不值得玩，回修玩法；发现人物不吸引人，回修事件与对白。每次提出变更都写清是哪个观察推翻了哪项假设，避免一次不同意见就推翻整部游戏。

本包没有解决尚未制作的全剧成片质量、真实玩家手感、Meshy 机甲成模率和最终制作成本；已经把这些不确定性落实为有具体对象、可观察结果的下一步，而非继续扩展抽象设定。
