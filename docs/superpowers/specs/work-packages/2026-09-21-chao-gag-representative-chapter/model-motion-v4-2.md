# 机甲与动作 v4.2

2026-09-23 · 第 8 入口 · 外部模型试装，等待复玩反馈

本轮解决两件事：机体缺少造型细节，招式只动手臂而缺少身体参与。新增独立场景与脚本目录，延续第 7 版的预测落点、拳向、行动顺序、数值和任务判定。1–7 的封存保持原样。

## 直接体验

项目根双击 [试玩版本选择.command](../../../../../试玩版本选择.command)，选择 **8「机甲与动作 v4.2」**；F10 返回，可与 7 号相同任务比较。开发入口为 [启动脚本](../../../../../scripts/run_c02_squad_models_candidate.command)。

[五种招式实机录像](../../../../../artifacts/c02_model_motion/model-moves.mp4)依次展示无牌快拳、冲拳、接拳反击，旧拳王重拳，以及天冲拳。它使用受控战斗初始条件和自动按键，运行真实判定与演出，不是玩家通关录像。

## 动作具体改变

- 快拳：短前摇、快速伸臂、收拳回架。
- 冲拳：先沉身和后撤，再蹬地、转腰、身体跟进。此前算出的后撤、侧移没有进入实战根位移，本版已接通。
- 接拳反击：先合臂接拳，再侧身送出回击；击退与伤害提示延后到回击接触，不再在接拳瞬间让对方先滑走。
- 重拳：举臂蓄势后大幅下压，与快拳的平直路线分开。
- 天冲拳：深蓄力、躯干反拧、另一臂展开平衡；镜头先看蓄力机体，再拉开跟随击退对象。
- 移动使用资产自带的 Run 蒙皮动画；ATLAS 的受击和倒地也使用源动作。战斗镜头移到发招手可见的一侧，保留短停顿及短拳迹。

Godot 使用单独的骨骼适配层，把原程序关节语义映射到导入骨骼。它校正 A 字站姿、脚底接地和接触位置；不拿画面碰撞替代战斗判定。Blender 将两只脚各约两千个顶点化为约百点的精确凸包，降低接地运算成本，保留可复建脚本。

## 检查与边界

规则回归覆盖独立瞄准、侧击、打断、友军让位、持续防御；原生键鼠回放覆盖此前玩家的首回合侧袭及三个窗口尺寸。五种招式额外检查真实命中/反击、返回控制、预测与结算相符、脚底贴地，并记录接触偏差。实际回执集中在 [artifacts/c02_model_motion](../../../../../artifacts/c02_model_motion)。

细节外壳与其余方块机体的美术风格尚未统一。接触修正仍是近似拳面，厚装甲在极端动作中可能露出源模型的机械接缝；不能据自动检查宣称所有角度零穿插。人物/精神菜单和战斗平衡不是本次换模的完成项。
