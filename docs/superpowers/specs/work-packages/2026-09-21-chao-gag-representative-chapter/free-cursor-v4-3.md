# 自由光标与镜头 v4.3

2026-09-23，Candidate。对应本轮“不能退出选机、地面被遮挡、需要左右键拖动镜头”的反馈。

统一入口：项目根目录 `试玩版本选择.command` → **9「自由光标与镜头 v4.3」**。F10 返回版本选择。1–8 的独立封存、编号与玩法保持原样。

## 操作

| 状态 / 操作 | 结果 |
| --- | --- |
| Esc 或右键轻点 | 瞄准中先回路线编辑；再按一次退出选机，保留招式、路线和拳向 |
| 「自由光标」按钮 | 直接退出选机，收起编排栏 |
| 自由状态：方向键 / WASD | 任意移格，不受上次选中机体的移动范围限制 |
| 自由状态：Tab / Shift+Tab | 查看友机、敌机和已行动机体，不自动打开行动菜单 |
| 点友机或光标移到友机后 Enter | 打开该机计划；已行动机体只展示信息 |
| 左键拖动 | 旋转、俯仰；轻点才选机 / 选格 |
| 右键拖动 | 平移；拖动不会撤销计划或退出选机 |
| 滚轮 / Home | 缩放 / 复位镜头 |

路线编辑以实际地面格为准，不再让高大的机体碰撞框抢走后方空格的点选。状态条、血条、纯提示文字可透传鼠标；菜单按钮仍正常响应。拖拽从战场开始后，即使在按钮上松开也不触发按钮。

自由查看与编排共用同一镜头位置，收起或打开菜单不会重置视角。攻击方向、命中、侧击、打断、行动顺序、模型与动作全部继承第 8 版。
