# V3 试玩诊断与操作回修 v4

2026-09-22 · 独立 Candidate · 原五版封存不变

**这次问题的核心，是玩家无法可靠地把意图变成动作，也无法从结果学到规则。** 只减少按钮、只提高胜率、只多写教程，都不足以证明解决了它。v4 先修命令与反馈这一段，不宣布群战框架已经好玩，也没有替代 V2。

## 实际记录与根因

已复制最近两份 V3 玩家日志与一份 V2 日志到 [player-baseline](../../../../../artifacts/c02_squad/v4/player-baseline/audit.json)，保留原件散列。两份 V3 合计 40 次提交：9 次护卫/迎击未触发，7 次主动攻击没有命中，5 次路线在执行中被拦停。这些类别可以交叉，不应相加解释为失败次数。日志含重开和未完成对局；既有胜利也有失败，不能仅凭胜败评价理解程度。

| 玩家遇到的现象 | 能从代码和日志确定的原因 | v4 实际处理 |
|---|---|---|
| 选了动作却像没做事 | 迎击要等对方打到自己，护卫要有符合条件的来袭；V3 姿态只在当前短交锋里存在 | 姿态保留到本机下次主动行动，成功一次、被推开或让位后结束；准备姿态与“等来袭”有明确表示 |
| 后面敌人出手时没有保护 | 从全队同时执行改成局部交锋后，护卫没有跨交锋存续；界面仍沿用“本轮保护”的理解 | 保存防御状态，后续交锋继续判定，不重复扣费，触发后消耗 |
| 选远处敌人会空打 | 选目标只改变拳向，没有替玩家找到有效落点；对手又可能在执行途中改变位置 | 针对玩家已选的目标和招式寻找本机就位路线；确认前用同一个结算器显示命中、落空、受伤、拦停、打断 |
| 想拦路，但不知道是否生效 | 同拍占格与被阻挡路径只有短暂文字，移动被挡也不等于攻击被取消 | 地图画出停步点；身体前进受阻并停住；结果明确说明“截路，但仍可原地出拳” |
| 友军挤在一起，基本无法走 | V3 把所有已占格都从可达路径中剔除 | 同队机体让到移动者前一格；两台都产生真实移动事件，不消耗让位者的主要行动。敌机仍阻路；原有防御姿态会因让位结束 |
| 切换、重选之后计划丢了 | 重新选中机体会重建空路线，旧版没有说明重置发生 | 重选同一台不清空计划，切走再切回保留已选路线和招式 |
| 不可用招式按了没反应 | 禁用按钮不能展示理由；旧日志也不记录被忽略的原始点击 | 不可用招式仍可选看原因，确认执行禁用；拒绝原因写入新日志 |
| 画面里有一段双方不动 | 被打断或提前出手后，结算仍跑原来最长的尾部空拍 | 已无后续动作时结束交锋，不播放空拍等待 |

旧记录没有原始全量键鼠事件，无法反推出每一次未响应点击；这里区分可复现的代码路径与用户报告，不声称所有零响应都已被逐次还原。

## 操作如何变得可学

普通行动现在是：**选择一台机 → 点目标 → 选招式 → 看现场后果 → 确认。**

系统只给这台机补就位路线，不替玩家选另一台机、另一个招式或后续全队策略。自动路线可用地面点击或方向键修改。预览用半透明机体区分预计落点，实体在确认之前留在原位；取消不会再让“已经走过去的实体”突然回原点。

普通攻击不需要先弄懂时间轴。准备打断时，会看见敌机是否在这一击之前已经出手、是否能被推开；想护卫时，能看到保护对象是否相邻、什么时候等待、什么时候消耗。确认按钮只负责执行已经显示的计划，选招和执行分开，避免把试选当成提交。

**行动顺序仍沿用 V3 的局部交锋试验。** 当前谁响应、后面还有谁在上方一条简短顺序中显示。v4 没有暗中改成速度先攻，也没有恢复全队同步；跨交锋防御修正后，先准备保护、再让另一台行动才有稳定的后续作用。这两项规则修正（持续姿态、友军让位）已明示，不能称作纯 UI 对照。

## 三个可重复练习

按 **F1**，选择“练拦路、练打断、练代挡”。使用同一个战斗结算器，按真实事件判断是否完成；不按“点了推荐按钮”判成功。

- **拦路：** 先抢到敌人的路线中间。敌人停下来，但仍能从停下的位置出拳，练习会明确展示这个代价。
- **打断：** 快拳可以造成伤害，却不取消重拳；在重拳释放前用推进攻击把对方推开，才会取消出招。
- **代挡：** 馆守保护身旁的无牌。射击原本打向无牌，馆守上前接下，显示自身承伤和被保护者未受伤。

**T** 重试当前练习，**R** 返回整场。练习会另开对局，当前未完成战斗不续存。

## 动作与结果表达

普通命中和代挡也有较短的接触镜头；重拳在真正出手前保持蓄势姿态，快拳、推进、接拳反击使用不同的发力节奏。拦停有实际前冲受阻；受击姿态加大；接触时有短暂停顿和对应效果。镜头结束回地图，上次因果结果保留，不再立刻被下一台的操作提示覆盖。

这些仍使用当前简化机体与关节动作。已有强化不等于最终美术和视觉冲击力达标，音效层次、机体专属动作和群战连锁演出仍有空间。自动录像见 [三项练习](../../../../../artifacts/c02_squad/v4/practice.mp4)，它是运行时自动输入示范，不是新一轮人类试玩。
