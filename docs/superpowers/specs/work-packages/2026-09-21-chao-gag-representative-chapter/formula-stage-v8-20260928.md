# 木桶街 v8：部署、同拍检查与拳路

2026-09-28。公式台当前可玩候选。入口为项目根目录 `公式台-木桶街.command`；修改前的完整 v7 保留在 `公式台-木桶街-上一版v7.command`。

这轮把《幻影旅团》里有价值的“单位—指令—时间—地图”关系接进现有玩法，同时处理此前几招共用近似动作曲线的问题。没有把格子战棋改成逐秒拖拽的实时编辑器。

## 战前：看职责，调起始位

前置对白、人物探索和任务选择之后，进入出击整备。右侧集中显示本场目标、限时，以及选中机体的耐久、移动范围、职责与两种关键招式。点下方机体卡，再点地图起始位，就能交换三台机体的站位；可以一键恢复。键盘 1/2/3 选机，方向键上下换位，Enter 出击。

站位不是画面上的假变化：实际单位格子随之改变。确认以后才根据最终阵形重新生成本轮敌方承诺；换位不消耗行动，不带入旧预演。

## 战斗：时间总览按需展开

选招侧栏明确提示当前点击地图是在改走位，还是在指定出手格。招式小窗收进“招式示范”，三张小队卡集中保留耐久与当前安排。

团队快捷分工保留在“团队方案”菜单，应用后仍可逐机修改。完成一项安排后，可展开“时间总览”。每列是一拍，单位各有一行；移动、蓄势、出手、护卫、等送位会以不同块表示。拖动游标时，地图中的单位、耐久和状态同步到这一刻；点机名回去编排，右键或 Esc 返回实际站位。展开时镜头为检查区域让出空间。被打断、计划取消、协作没触发有明确文字，不再留下难以理解的空白。

时间轨道与地图都读取同一份**公开推演事件**，不读取隐藏敌方计划。不确定拳路仍标为一种可能；白鸢与纪存的用途继续保留。这里的拍不是《幻影旅团》的秒，时间轴也不允许绕过现有规则任意拖早攻击。

## 动作：不同发力方向落在模型上

原来的问题不只是特效弱：快拳、冲拳、借势、重拳和天冲拳有很大一段共用曲线，较早介入的接触修正又把姿势拉回相似的直拳。

本轮沿用已有 Meshy 外壳、绑定和贴图，在 Blender 分别重写八组关键姿态。快拳短促伸收；冲拳压低身体后平送；借势低身突入、向上挑起；旧拳王的勾拳有横向转腰与收势；重拳高举再下砸；接拳先拨开、再还拳；天冲拳由深蓄势转换为全身上冲。接触校正缩到更接近命中的短区间，特殊招式采用不同接触高度，避免吞掉动作区别。重拳与天冲拳的接触图形分别强调下砸和上冲。

下面是同一归一化接触时刻的模型检查，未加入自动位移和命中特效，便于比较姿态。它不代替战斗中的实际观感。

![不同招式的接触姿态](../../../../../artifacts/formulas/production-lab-v1/qa/stage-art-v8-20260928/motions-contact.png)

战场方面，提高了中央平台与深色机体之间的明度分离，降低周边材质的细碎凹凸和色彩噪声；常用镜头更近，规划及试演时环境退为暗色轮廓。继承原有科幻整备港，不另搭与前场脱节的场景。
