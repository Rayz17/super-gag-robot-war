# 师徒对练 v5：战场光标与按需展开的指令

2026-09-21 · 独立 Candidate · v5 师徒对练实现记录；2026-09-22 已保留为小队版对照

用户复玩 v4 后反馈“本轮的操作还不错”，随后指出常驻双机状态、提示和支援用量挤占战场，结束后留空，光标不能独立操作。本次改为以战场光标和当前机体为入口：观察、编排、推演、执行、对白和结果分别组织界面。沿用同一场战斗及全部既有判定；没有增加小队或章节。

[启动新对练](../../../../../scripts/run_c02_short_plan_candidate.command) · [v5 光标、编排与镜头演示](../../../../../artifacts/c02_short_plan/runtime/short-plan-v5-review.mp4) · [旧版对照](duel.md) · [导致这次修改的真实试玩记录](player-playtest-review.md)

打开脚本后，窗口标题为 **“超GAG · 师徒对练 / 战场光标 v5”**。旧窗口不会自动升级。本场继续使用原有两台 Blender 模型及 Godot 场景，没有新增引擎或模型生成流程。

## 1. 怎样操作

1. **观察战场**：方向键移动白色格子光标，Tab 切换机体；光标指到哪台机体，才显示它的耐久、体力和状态。鼠标可以直接指向模型。没有常驻的双方血条或已用支援统计。确认对手只查看已知拳路，不泄露隐藏计划。
2. **选中己方后编排**：在无牌一号上按 Enter 或直接点击模型，展开右侧指令。1—5 选招，Z / C 改拳向。方向键只移动光标，Enter 才把光标所在格确认为路线落点；也可以直接点地面。Backspace / 右键撤一步，最多移动两格。观察时优先识别模型，编排时按地面落点，避免旋转镜头后模型轮廓抢走相邻格的点击。
3. **按需推演**：T 展开预计损伤、原因与时间线；[ / ] 或“查看 1 / 2 / 3”切换站位。每列一拍，双方同时推进；预览不提交行动。T / Esc 收起后，战场取回这块空间。绿格只在出拳那一拍判定；争格会显示双方实际停步；未知位置用多个地面框表达。
4. **能力从机体指令进入**：B 打开人物能力，P 打开精神指令（J / I 仍可直达错峰 / 必中）。能力用量、精神消耗和已用状态在菜单里查看。↑ / ↓ 选能力，← / → 切分类，Enter 确认，Esc 返回；浏览不消耗。白鸢或预测生效后会自动展开推演区，显示此次能力带来的信息。
5. **Space 执行双方计划**：行动期间收起编排、时间表和范围，保留必要的战斗反馈。出现对白时由半身像和台词接管焦点，Enter / Space / Esc 继续。结束后返回战场观察，再选择己方编排下一轮。关闭指令面板会保存未执行草稿，不暗中撤销或花掉预订能力。
6. **战斗结束**：显示胜负、实际结束原因、再战和交锋记录。旧指令列和时间表不再占位。R 再战，H 回顾。支援剩余次数没有被搬到结果主画面上。

蓝色边角表示可移动格；绿色框是我方出拳命中区（接拳招式为接拳区）；橙色斜线是对手可能出拳区。全部为有深度遮挡的地面标记。详细图例随推演区展开，机体身上没有多层战术标签。

**绿色三格不等于持续扫过三格。** 快拳释放那一拍，对手站在正前、左前或右前任一格就能命中；对手只是此前经过绿格、释放时已经离开，就不会命中。接拳反击显示的是接拳区，必须先接到正面来拳才会回击。

| 招式 | 格子范围 | 额外条件 |
|---|---|---|
| 快拳 | 前方一圈的三格，含两个斜前格 | 不是两格直线拳 |
| 踏步冲拳 | 正前一格 | “踏步”是发力动作；战术移动仍由路线决定 |
| 天冲拳 | 正前两格 | 需要三格气势 |
| 接拳反击 | 正前方曼哈顿两格以内 | 先接到正面来拳才反击，不能当主动远程招式 |
| 旧拳王蓄势直拳 | 正前两格 | 第三拍释放；可能打中仍在移动的人 |
| 旧拳王横扫 | 前方和左右一圈 | 抓侧移，不能打到身后 |

**镜头操作**：WASD 平移，Q / E 旋转，PgUp / PgDn 抬高或压低俯角，− / + 或滚轮缩放；F 对准光标，Home 恢复默认镜头。中键拖移，Alt（Mac 为 Option）+ 中键拖转和俯仰。F2 打开有按钮的镜头面板，F1 查看操作说明。镜头面板暂时收起编排界面，关闭后回到原上下文。方向键随屏幕上的格子方向移动，旋转镜头后不需要记住世界东南西北。

编排时只为右侧指令留出一列；只有展开推演才为它留出底部空间。默认观察、执行和战后不保留隐藏面板的空栏。机体资料使用一个光标检查入口，**这解决 HUD 的组织方向，不等于已经实现多机战斗**。

V 切换完整 / 快速演出；执行期间 Space 跳过，H 查看交锋记录，R 重来。右上角“菜单”也可打开这些设置。快进与跳过不改变伤害、支援消耗或识招经验。每轮恢复 1 体力，“调整步伐”恢复 2；冲拳、接拳及天冲拳耗 2 体力。

## 2. 同一个开局，四种打法的实际区别

以下对照以**已确认敌方原地蓄势直拳**为前提。如果仍是“直拳 / 横扫”两种可能，绕侧也可能吃到横扫，界面会显示这种风险。数值来自规则及原生地图、按钮输入检查，不是通关步骤。

| 选择 | 这轮发生什么 | 取舍 |
|---|---|---|
| 原地快拳 | 第 1 拍打 4；第 3 拍仍吃对手重拳 7 | 免费、快、可回体力，但普通命中不取消对方动作 |
| 原地踏步冲拳 | 第 2 拍打 3、推 1 格；重拳被打断，我方不受伤 | 伤害较低、耗体力；出手太晚就不能阻止已发生的攻击 |
| 两步绕到侧面，再快拳 | 第 3 拍侧击 7；重拳仍朝原来的方向打空 | 路线与朝向产生实际收益；下一轮对方可能公开改用覆盖两侧的横扫 |
| 原地预备接拳 | 接重拳受 2，当场回击 6、推 1 格 | 花掉本轮主动作及体力；无正面来拳就不反击，不能白赚一次出手 |

其他关系也实际进入了规则：

- **打空后的破绽**：重拳打空后，下一次受击额外 +2。可以把出手排晚，等空当出现再打进去。
- **抱架有正面**：普通正面攻击会被接住并反击；侧击可以绕过。天冲拳可以直接破防。
- **气势来自打法**：有效侧击、打断重拳、接住重拳各有一个风格标签；每轮最多加一格，每标签整场最多两次。满三格由玩家决定何时出天冲拳。大招不会自己刷回气势，也不重置标签额度。
- **天冲拳改变站位**：基础伤害 10、推 2 格、消耗三格气势和 2 体力。擂台中央命中会继续打，越过边线才是出界。
- **压制规则双方相同**：致命伤保留 1 耐久并进入独立倒地状态；双方都要另花下一轮的主动作，才能近身压制。倒地者第 3 拍起身，压制必须更早到达。**起身不恢复耐久**，仅从倒地变为站立；仍是 1 耐久，任何后续实际伤害都会再次击倒，完全挡住的 0 伤害不会击倒。没有额外起身体力奖励，普通轮末恢复与对手相同。压制计时在这个比较件里合并为一次短演出，旧版五秒演出保留作历史对照。

敌方依据上一轮实际结果，在下一轮开始时冻结新计划，并公开与情报水平相符的线索。被绕侧后可能横扫，见到预备反击后可能抱架；这些变化发生在玩家编辑前。执行中绝不偷看草稿或重新追到新落点。移动争格按同一前态一起判定，被击退后的剩余路线停止。

这仍是可以停下来思考的回合战斗。恢复的是 **观察意图 → 排路线与动作 / 条件反应 → 双方共同执行 → 看新局面**，没有加限时输入或 QTE。

## 3. 本局怎样读招，人物能力怎样改变打法

| 层次 / 指令 | 当前实装 | 取舍与边界 |
|---|---|---|
| 拳术识招经验 | 实际观察到旧拳王出手才加 1；LV1 可见起势类别，LV2（3 次）识别具体重拳，LV3（6 次）进一步识别趋近路线 | 被打断而未放出的拳不给经验；预览和取消不刷经验。没有随机命中率。当前仅为本局拳术熟悉度试验，重开清零 |
| 白鸢·预演草图 | 根据已知拳谱，把每种可能方案的损伤结果分开列出，本场 1 次、本轮生效 | 不读取真正隐藏的计划；确认使用即消耗，不因取消草稿而返还 |
| 纪存·错峰调度 | 路线不变，将本次出手或抱架准备延后 1 拍，本场 1 次 | 占原来的主动作；可取消预订，提交才耗次数。能等直拳打空产生破绽后再打，不是免费加一拳 |
| 精神·预测 | 用本场已录入的招式与传感信息比对，确认动作和路线，耗 2 精神 | 不能无条件读取资料外动作；确认使用即付费，效果限本轮 |
| 精神·必中 | 出拳时在原拳向前半面内校准方向，耗 2 精神 | 不能补距离、转到背后、绕过抱架或救回已被打断的动作。可撤回预订，提交即付费，打空也消耗 |

初始精神为 4；两张人物牌各 1 次，同一轮只能选一人，人物牌可与精神配合。实际例子：两步绕侧的快拳原本在第 3 拍打 7；纪存将它排到第 4 拍，先让第 3 拍的直拳挥空，再打出 9。代价是用掉一次调度；如果对手其实是横扫，晚出手仍会吃到扫击，情报与相克需要一起考虑。

白鸢在当前设定中只能用已知分镜、现场传感和资料作有限预演；纪存不能代替机魂控制四肢。这里的人物按钮是本场 **Candidate 接口试验**，不是把新超能力写入正式故事，也不代表两人在正式 C02 赛场已经共同出席指挥。精神指令是训练用机制，不宣称属于两人的正式角色能力。

长期设计采用“人物能力 / 经验 → 对特定流派的认知 → 本场掌握的资料 → 指挥与精神补充”的信息层级。高等级不自动读心，机体相克也不只是一张加伤表：快拳抢先、冲拳拆未完成重拳、抱架接正面、绕侧避正面防守、横扫抓侧移、天冲拳破抱架，各自改变合法动作和结果。全角色等级曲线、跨战斗成长、更多流派与战前五卡编成尚未扩展，继续服从先磨好这一场的工作顺序。

这里有一个必须澄清的版本差异：Fable **13号**曾使用逐机交替回合，**17号 §2.1**明确将它替换为与 00c 一致的短全队协同。采用的是后者的执行合同；本场只有两台机，尚未验证多机共同计划的负担和价值。

开罗材料中可见的经营、训练和成长循环暂时没有进入这场对练。赛车片段不足以判断后期改装、气场或完整平衡；拳馆材料是剪辑过的官方预告，不能据此推断精确控制方式。这轮实际检查的是操作画面与执行反馈，不能写成完整玩过这两款游戏。

## 5. 不同招式怎样演出来

| 招式 | 可辨认的身体动作 | 镜头与反馈 |
|---|---|---|
| 快拳 | 左臂短刺、快速回手，身体转动幅度小 | 短促接触，保留双方关系 |
| 踏步冲拳 | 先沉身后撤，再蹬后腿、前膝承重，肩腰带右拳前冲，命中后延迟收势 | 接触后把对手推出格子，未放出的重拳划掉 |
| 接拳反击 | 双臂抱架和膝部下沉先接住，随后侧闪拧腰，从低位送出右手反击 | 接住和反击分别演出，仍属于同一拍中的条件反应 |
| 蓄势直拳 / 横扫拳 | 直拳抬后手后砸出；横扫大幅侧开肩、转髋横摆，出拳后继续随势转身 | 横扫用更高俯角看横向弧线，冲拳用较低机位突出前冲，空拳沿已锁定方向挥完 |
| 天冲拳 | 深蹲收右拳、蓄光、蹬腿转腰、左臂后摆，再贯出右拳 | 拳头特写 → 头部近景 → 全身发力 → 命中停顿 / 击退跟随 → 回到原地图；约 3 秒 |

继续使用已有的两台 **Blender GLB 刚性关节模型**；Godot 驱动各关节、实时摄影机和特效，不生成一条条预渲染视频。接触位置由实际站位适配，同拍互击限制前冲重叠，并用手臂接触校正减少空拳。它们只负责表现，不能修改命中、打断、伤害和行动次序；完整、快速和跳过消费同一份结算事件，没有格斗游戏的碰撞判定、帧数抢招或 QTE。

模型可以替换，但不是任意模型文件直接覆盖就完成：新模型需要提供肩、肘、拳头、腰、膝等关节映射，统一身高与原点，并复查接触和构图；Skeleton3D 可通过动画适配层接入。Meshy 可供外形候选，Blender 负责部件 / 关节整理，LibTV 可继续用于参考切片和镜头分析。本轮没有新增生成任务；能复用同一套场景和镜头是已实现的优势，最终资产成本仍需用下一台替换件核算。

## 6. 人物素材与对话呈现

能力菜单仅在条目里放紧凑方形头像；对话使用伸出下方框体的较大半身立绘，同时收起周围战斗 HUD。两者从同一原图分别取景，未复用旧像素头像或公式台 Q 版。原图保持字节不变，以 AtlasTexture 裁切区域显示；局部启用线性过滤与 mipmap，避免项目原来的像素画过滤把立绘缩小时变成锯齿。
