# 木桶街：完整章节、战斗与交互

设计候选 v1 · 与 [主案](README.md) 同属一个工作包。以下操作、数值和改编时长尚未实机验证；剧情固定事实来自 C02 五话已验收 Reader。

## 1. 章节的完整经历

开场用馆内两位伙伴的一段短交谈承接 C01；菜单中提供可跳过的前情，不要求玩家读生产文件。

| 场次 | 玩家与观众实际经历 | 交互、声画和结束状态 |
|---|---|---|
| 1 到木桶街 | 万机馆因转子受损停住。冠军奖品正能让它继续走。胶价王有办赛和安置的账，不能直接把奖品送人；完全版王者的豪华展示既好笑也确实强 | 操作纪存在一条有模型摊、工房和报名处的街上移动。路过一处完整武装演示，先看到王者做得到什么。主目标始终是报名，不是看完所有介绍 |
| 2 没有名字也能报名 | 无牌一号愿意参赛，借万机馆的侧推。资格赛中接重击，却没能打出拳，最后舍弃那次积力去敲铃 | 第一段可玩比赛，3–4 分钟。两台非致命守卫，目标是到铃前。玩家选绕行或诱开挡路者、决定侧推时机。那次未完成的拳是明确演出节点，随后交还控制去冲铃；不能伪装成玩家操作失误 |
| 3 今天教，明天打 | 白鸢来撤未经许可使用的画；三色重涂商品的笑话与三架飞机各自的习惯在同处出现。旧拳王指导无牌，只走出半步 | 主要是可推进对白与动作演出，约 3–4 分钟。第一次无需反复操作七拳三摔。额外练习自愿。完整口吻样本见 [scene.md](scene.md)；不借此提前教会必杀 |
| 4 晚上把旧片放完 | 原最终回里 A-7 留在炮门、王者独自回来；后来白鸢画过救回 A-7、城市却未获救的未完成续写。实机维修链与旧编号确认来历。赵梅拿起那些年接过的补件电话 | 先让观众看一小段有具体动作的片，再让角色认出彼此。留沉默和提问，不用三屏年表解释。必需信息 5–7 分钟；自选完整材料进入片库。两机明知前情仍选择参加明天比赛 |
| 5 师父就在对面 | 王者完整武装击败码头千斤顶。无牌与旧拳王正式交手，先被轻拳打乱，后来接住真正重拳，向前踏步完成逆转天冲拳；随后打赢半决赛 | 第二段可玩比赛，7–8 分钟。开场约 20–30 秒的短教学演出让第一次成功清楚发生在中场，尚未出界；接着解锁招式、交还完整操作。边线诱敌和中场迫近都可打出后续机会，普通得分同样有效。此次拆开“学成/决胜”是明确的候选改编差异 |
| 6 把决赛打回来 | 王者先得两分；无牌连取三分，以 3∶2 获胜。王者保留完整武装和求胜心，没有因为昂贵就成了假货 | 前两分明确为可跳过开场演出，进入操作即显示“0∶2，先得三分”。玩家控制全部三次追分，12–15 分钟；输一分则从该小局重试。不给玩家暗改伤害制造必败；通关后的练习允许从 0∶0 真打，但不重写故事赛果 |
| 7 这次一起出来 | 赛后非计分加演：无牌走出旧炮门，王者跟来。王者越过安全线踩上不承重的布景轨道，舞台坍塌；工作人员断电停演、疏散。双方先前的竞争成为合作 | 明确转入“救场”。不再计冠军分，不出现神秘袭击者。王者拆下武装，其他机群各自救人；玩家下三次较大的调度/攻击命令，6–8 分钟。装配、抓点、绳结由连续演出与队友自主动作承担 |
| 8 留下的人与上舰的人 | 转子装好，无牌与旧拳王愿意随舰；白鸢带自己的东西上来。王者留在木桶街修翼等再战。赵梅用自己的名字接电话，胶价王算过赔款仍要做生意 | 短距离回馆、看一处新住下的地方，然后启航。奖励显示在实物上：转子、参赛纪念、可回看的旧片、训练区的师父。照片不强行塞进没有登舰的人 |

正文/演出共 19–25 分钟、比赛操作 22–27 分钟、救场操作 6–8 分钟、转场 3–5 分钟，合计 50–65 分钟。自由逛街、完整旧片、反复练习不计。以上是编排预算，须由首次完整通读和实玩重新测量。

## 2. 基础战斗：玩家一眼看到什么

普通小队地图当前正在比较交互框架：[v3 地图直操](direct-interaction-v3.md)逐机试走并完成局部交锋，附近队友按条件接应；[v2 共同短计划](squad-combat.md)保留作为全队编排的对照。用户已理解 v2，却仍认为缺乏操作感，因此尚未把任一群战方案作为正式章节定案。

主屏只持续显示：胜负目标、目前可行动的机体、选中者耐久/能量、地图危险范围。点武器才展开射程、伤害、消耗和对方反应。主目标写“将旧拳王打出界”或“击破四台演练靶机”，不写“完成战术闭环”。

以无牌一号的天冲拳为例，确认前同时显示：

- 能否命中、预计伤害，对手会防御还是反击；无法预测的情况明确显示未知原因。
- 被击退的路径与最终格；会不会出界、撞到障碍或友机。
- 本机预计承伤与所耗能量；不可用招式直接显示缺什么，不要求翻图鉴。

比赛以“倒地压制五秒或全身出界”为得分条件；演练/普通战斗以耐久、任务目标结算。不能把同一条耐久归零规则偷偷当成比赛记分。物理表现服从确定的落点与规则，关掉镜头或跳过动画不改变结果。

演出开关为“完整 / 快速”。地图上的起势、接触与结果仍保留；完整模式增加同一动作的特写。必杀第一次默认完整，可按键跳过；后续按玩家设置。普通攻击不反复读长台词，特殊对手/首次配合才出现新对白。

鼠标：左键选择/确认，右键取消，拖动空白看地图；键盘/手柄：方向键或摇杆选格，确认/返回两键可完成全部战斗。焦点不依赖鼠标悬停，威胁范围和预测也能用按键查看。镜头可旋转至预设方位，自动特写结束后恢复玩家方位。摇杆速度、点选容差和震动都留到实机调试，当前不冒充已测手感。

## 3. “名场面改演”怎样产生玩法

**基础武器始终能用。** 名场面提供一项值得争取的局部优势，而不是通关前必须填满的全队总量表。每机先制作一个有识别度的本事和一个与他人相接的机会，后续靠作品与经历增加。

| 方式 | 木桶街的具体例子 | 实际作用与代价 |
|---|---|---|
| 发动 | 当前对练与小队版使用三格气势解锁天冲拳 | 实际侧击、拆重拳、接重拳积累，每轮至多一格、每类每场至多两格；馆守代接不会给无牌免费气势。早期受击一次获得返劲的方案保留为历史 |
| 让台 | 旧拳王选择压住敌人而非自己收掉，让无牌进入有效距离 | 消耗旧拳王本次行动，降低即时击破效率，换来另一台机出手的条件；不另做“搭台小游戏” |
| 拆台 | 看到敌机宣告蓄力，把它推出射线或击坏外置武器 | 直接改变下一次攻击；对手仍有基础武器和自己的应对，不能一键永久取消整台机 |
| 改演 | 旧片要求 A-7 留在炮门；加演里王者也来托住，无牌把坠落道具炮打回可处理的位置 | 不同的人承担原本不存在的角色，镜头与场上动作都变了。它在这一章是特定剧情合作，不包装成所有关卡都要解一次的谜题 |

完整游戏中的“大招、地图炮、精神/指挥类能力”仍可存在：普通攻击打得爽，强力攻击能清掉一片敌人，队伍能力能支持进攻与逆转。先把即时用途做清，再决定哪些值得保留为跨章系统；不能因为强调特色，把机器人应有的威力全收进维修和支撑。

不把笑话做成问答锁。没看过原作的玩家应能从本场看到：“过去配角要留下来牺牲；今天两台机想一起出去。”懂梗的人得到更多层次，普通玩家同样有局面和情绪。

## 4. 半决赛与决赛怎样避免一条提示路线

**历史实现对应关系（旧交替版）：**[独立师徒对练](duel.md)已经跑通边线反击出界与普通拳击倒压制，也能被重拳推出界。练习中防守耗 2 EN、侧推耗 4 EN；返劲须实际承受重拳伤害。压制开始后连续执行五秒模拟时间，本件没有额外解脱操作。以下仍是章内比赛的候选设计，练习胜负不写入正式半决赛，也不代表决赛压制/解脱系统已完成。

半决赛是第一次学会特定招式的关卡。原 Reader 将首次天冲拳与打出界的决胜合成一次；本候选改编将它们拆开：开场短教学演出在中场完成首次成功，随后自由战斗按正常记分。普通攻击、投摔、击退若满足合法得分条件，一律承认，不临时免死、吞分或回滚。

这个改动保留“在半决赛学成并击败师父”的事件，改变具体决胜动作与节奏，须在设计评阅时明说。通关后的对白和回放引用玩家实际用过的动作，不把每条录像都写成天冲拳决胜。游戏如果必须逐动作复现原文，应该公开采用线性演出承载，不假装仍是自由战斗。

| 选择 | 可见机会 | 得到与付出 |
|---|---|---|
| 边线诱敌 | 旧拳王面前有可站格，它的重拳范围清楚，身后离边界近 | 一次反击即可打出界，但自己也更容易被推出；需要留出正确站位 |
| 中场迫近 | 用侧推接近，迫使旧拳王用重拳阻止进身 | 站位宽裕，能量消耗更高，可能先要用普通攻击调整对方位置 |
| 避开重拳范围 | 能少承伤，普通攻击仍可用 | 不会积起新一次返劲，但仍可用常规方式合法得分，不因没用必杀而判失败 |

决赛每得一分复位，王者的应对随小局改变：第一次正面盾冲，第二次以射击和烟幕保持距离，最后用完整武装封锁两翼。压制计时的五秒做成明确的压制演出与解脱条件，不要求玩家连续空等五个回合。

第二分介绍投摔压制，最后一分提供适合天冲拳的攻防机会；具体得分方法允许由玩家决定。不同站位、行动顺序和承伤可以得到同一场 3∶2 剧情胜利。原 Reader 的具体三次得分手段不再要求每次游玩逐动作重演，这也属于上面明确列出的改编差异。操作失败正常重试，不编造新的永久死亡或把胜利强塞回玩家手里。

如果实玩证明三次完整小局重复，应先缩短相同接近过程、保留王者应对变化和最后反击；不能只把三分变成三个自动弹出的“发动”按钮。

## 5. 救场：控制关键决定，队友自己做事

事故起因、最终救回王者与冠军结果固定。救场是本章短暂的合作高潮，不作为以后战斗的默认结构。第一次观看仍需明显危险与出手反馈。

1. **先打开撤离空间。** 以无牌为操作主体，点选推开近处坠物或用侧推拉开更宽通道。两种方法都能救到当前观众，分别留下不同的可回收布景与侧推余量。镜头持续看见人穿过，不等结算文字宣布“已撤离”。
2. **决定如何进入托举位置。** 王者自行作出拆除外装的决定；旧拳王、飞机、码头千斤顶、馆守 Z、货柜领袖与万机馆按各自能力持续救场。玩家可让无牌靠近王者共同承担，或先清掉妨碍救援车的障碍后再进位。前者抢下更多完整道具，后者减少维修车辆受阻。两条路线的具体数值待实机验证，不把“救人/捡钱”做道德陷阱。
3. **一起改完这一幕。** 现场人员确认吊运已就位，王者接住道具炮。玩家选择无牌的出拳落点，预测明确画出安全落区；正确打向可处理位置后，王者与吊运共同把它卸开。保留关键动作的特写和一句新的回应，最后回地图看两台机都走出去。

不增加独立负载面板、绳索抓点清单、每架飞机的逐格微操，也不让万机馆突然飞起托住整个货运环。红机只做短时快速观察、蓝机护送、黄机切两处已确认的拖曳牵连；货柜领袖在地面拖带，万机馆依靠支承承担一侧。

人命与主线在正常完成时保住；失误造成明确失败重试。附加区别只记录可回收舞台/维修损伤及一两句回应，**不**把隐含失误转成死者又让剧情假装没发生。王者拆下的外装仍属王者，可以修复。

## 6. 同资产小队演练：当前实现

2026-09-22 用户批准由 v5 单挑框架推进到三对四小队样板。**当前交互实验以 [v3 说明](direct-interaction-v3.md)为输入；[v2 规则](squad-combat.md)仅约束保留的 v2 场景。** 原先本节的逐机回合、一次受击返劲、18/24/30 耐久和牵制减速方案已被替换，历史副本在 `artifacts/c02_squad/baseline-package/chapter.md`，不作为本次代码规格。

三台友机为无牌、旧拳王、馆守 Z，对阵两近战、两射击训练靶。中型机尺度保持 16/17/18 米；单格 20 米不直接用于超大型机。清场、重装破阵、掩护突围共用地图，各有明确目标和约束；具体站位与数值以小队规则页为准。

v1 试玩暴露了逐机编辑繁琐、战术意图不清和步骤按钮回调错误。保留的 v2 默认选择全队打法，再用 Space 提交；每台仍保留可以微调的路线、朝向和动作。敌我同时移动和出手，同格争抢会停步；有效击退才打断尚未释放的动作。射击锁地面，实体低台挡弹，途中敌对机体承伤。馆守护卫相邻指定友机，本轮一次减伤代接。普通拳选定一个目标，横扫才是范围攻击。

v2 复玩后，用户仍指出全队选打法有很强的信息组合感。v3 改为逐机地图试走，每次与当前亮出的敌机短交锋，相关队友可支付体力加入一次接应；整轮才结算恢复和机会到期。B 站实机观察、取舍和证据界限见 [交互研究](group-interaction-research.md)。

耐久归零或出界退出演练。清场要求击退所有敌机；重装破阵只需在限时内击破装甲目标；掩护突围只需让无牌抵达出口，后两者要求无牌留场。没有逐个机体的倒地压制；师徒对练保留自己的比赛规则。

虚晃撤步只诱发满足条件的莽进敌人抢先出拳；实际落空才打开破绽，随后可以降低气势门槛使用天冲拳。沉稳、已识破或已出手的敌人不受骗，撤步受阻或仍在拳区内会失败。它与正面打断、绕侧避开装甲产生不同结果。正常重装开局已通过原生输入完成两轮“骗招—开大”；三种清场打法与两个其他任务的对照数据见 [战术与任务因果](tactics-v2.md)。这些结果不能证明玩家理解、好玩或平衡。

任务与机会模块不含伤害或角色身份，可复用到同地图的调查等行为。本轮仅以无界面“引开巡检取证”验证顺序、资源、警戒和关系后果，没有制作新的非战斗章节。

本训练不产生实际剧情赛果，也不把馆守写成参加了一场新的正式比赛。完整章节的进入、比赛和启航尚未串联。

## 7. 一拳的完整镜头与输入关系

| 阶段 | 观众看到的内容 | 谁负责 |
|---|---|---|
| 选择 | 棋盘保留全局，路径、预测伤害、推退落点同时出现；玩家能取消 | Godot 规则与 UI |
| 起势 | 无牌在实际落点踏步、收拳，旧拳王所在位置可见 | Godot 三维动画；不得先切空镜遮掉移动 |
| 特写 | 肩肘压缩、脚与地面承重、拳光积起；必杀台词从机体发出 | Blender 整理的动作；符合姿态的 LibTV 短片可用在这个区间 |
| 接触 | 两个身体实际接上，旧拳王失去原站位；接触停顿、撞击音和镜头共同强调冲击 | 首选实时三维双方配合；视频不能另算伤害，也不能所有招式共用同一挥拳 |
| 结果 | 镜头跟被打退者穿过边界，裁判判分；返回原棋盘和一致位置 | Godot 按结果播放，数字只是辅助 |
| 恢复 | 玩家立即能选下一行动；首次对白结束可继续，后续不重复长台词 | Godot 控制焦点，跳过与完整播放落在同一状态 |

普通动作约 1–2 秒、必杀完整镜头约 4–6 秒可作剪辑起点，最终由实机重量感和节奏调整。不能把时间表当成手感通过。本包的 HTML 是可点选的分镜与方案示意，没有模拟完整战斗胜负；它不能代替上述 Godot 首件。

## 8. 本章应留下什么

玩家结束时应能不看图鉴说明：无牌原来总迈不出那一步；旧拳王会教也真的打；王者强、好胜，后来选择自己拆下宝贝；赵梅是那个接电话的人；白鸢不允许别人随便改她的画，也愿意继续把新片拍下去。

玩家也应能说出一件自己做过的事：为什么把对手引到边上、为什么改用投摔、为什么选择让另一台机出手。如果只记得“读完一段解释后按执行”，这章还没有做好。
